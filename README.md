**持续精读阶段。** 深读 v2 标准已确认。已启用每小时定时推进：同一时间只处理一篇；研究、复现或核验超过一个周期时，继续该篇，后续论文顺延，不补发追赶。完成核验后逐篇公开发布。当前论文阶段见 [进度记录](workflow/progress.json)。这不是每小时必定完成一篇的承诺，也不表示某一年代文献已被穷尽。
