# Huntington的三组公设：怎样证明一条假设真的不能省

## 1904年逻辑代数与AI前史回填精读

一套公设能够推出我们熟悉的定律，并不说明它没有多写条件；一个反例能破坏某条公设，也不说明它保住了其他公设。Huntington这篇论文把这两件事放在同一张工作台上：分别从两种组合规则、一个关系、一种组合规则出发，重建逻辑代数，再逐项检查哪些假设不可删除。

最容易读错的地方正在标题里面。原文第二组虽然列出十条，却明确说明其中两条可以互相替代，必须删去一条才得到九条独立公设。第一组的结合律不是假设，而是要证明的结论。第三组虽只用一种组合规则，补元也不是一个可直接用该规则写出的任意项。把这些细节压成“布尔代数公理化”六个字，会错失论文的方法。

本文以原刊288–309页全部正文、脚注、表格和附录为阅读范围，提供三组公设的条件化转写、关键证明、全部独立性模型的解释、有限分类的补证，以及原创可运行检查器。这里是AI与计算的数学前史，没有训练数据、智能测评或现代学习算法；不把1904称为AI的唯一历史起点。

## 1 他要改进的究竟是什么

### 1.1 从解释工具到抽象理论

288–291页的目标不是给逻辑运算增加一个应用，而是暂时搁置应用：先选未定义的概念，再选其应满足的命题，靠明确推导重建既有逻辑代数。集合区域的并、交、包含关系是一个解释；证明则应适用于满足条件的任何解释。

第一组承接Whitehead《Universal Algebra》1898年第一卷第二编。Huntington在291页明确说，这组的主要条件与Whitehead相近，差别包括把加法和乘法的结合律从基本命题移到导出定理。294页进一步定位Whitehead的35页与37页两份基础命题表。我们因此可以准确说“删除了这套背景表中的结合律假设”，不能把它夸大为“首次发现结合律”。

第二组承接Schröder《Algebra der Logik》1890年第一卷，291页脚注定位168、170、184、188、196、293、303页。变化的关键是以较简的公设9替代Schröder的一条分配性条件。300–301页说明关键分配律证明来自C. S. Peirce的1903年12月24日来信，并刊出1904年2月14日的解释信。这里有清楚的文本证据，不能把全套证明都算作Huntington独立发明。

原文291页把主要新意放在公设独立性的建立，另外谨慎提到几项证明。作者自己的贡献边界比“建立现代布尔逻辑”这样的后见概括窄得多，也具体得多。[原文288–291页](https://archive.org/download/jstor-1986459/1986459.pdf#page=2)

### 1.2 三个不同的合格问题

1. **可共同满足吗？** 展示一个同时满足全部公设的模型，例如两元素真假代数。
2. **能恢复目标理论吗？** 从公设推导出所需定律，并在不同原语之间给出双向定义。
3. **每条都必要吗？** 对指定的一条，构造满足其余各条、唯独不满足它的模型。

第二问不能用第一个两元素表代替；第三问不能靠“我还没找到证明”回答。Huntington在290页还提醒：一句话能否再拆、怎样衡量“简单”，不是已经解决的问题。所以独立性既不是公设条数的绝对最小性，也不是今天称作“完全独立”的所有真假组合均可实现。

### 1.3 为什么这次回到1904

本篇回填此前Sheffer1913直接引用的Huntington前驱。选择时，它是当前登记清单中年代最早、篇幅边界明确的未完成论文；这只是**当时清单内的选择**。更早的Boole1854、Schröder1890、Whitehead1898书籍已有公开来源，尚未完成相关全书或篇章深读，不属于“取不到所以跳过”。

本篇又给出更早的具体论文线索：Kempe1890的两篇文章、Christine Ladd1883的文章，以及Peirce1880、1885的相关位置。它们继续登记，不因这次完成1904就被抹去。没有穷尽所有语种、期刊、手稿和优先权；已有目录的最早完成年份不等于历史最早年份。[候选与历史覆盖记录](../../reading-paths/early-foundations-candidates.json)

## 2 先把符号和适用条件读对

### 2.1 两种运算起初不保证封闭

原文289页的rule of combination只保证有序输入决定唯一结果，不保证结果仍属于K。本文以 $`+`$ 表示原文圈加，以 $`\cdot`$ 表示圈乘，以 $`\le`$ 表示圈内的包含关系；乘法有时简写为ab。它们起初不是普通数字的加乘，也还没有通常布尔代数的全部性质。

教学上可以把规则看作

```math
+, \cdot:K\times K\longrightarrow E,\qquad K\subseteq E.
```

E只是说明可能存在K外输出的辅助范围，不是原文新增的原始对象。若内层输出不在K，不能直接当作下一次接受K输入的运算。原公设因此把某些等式限制在相关元素和中间组合全都属于K的情形。若一开始写成 $`K\times K\to K`$，就已经偷偷假定待检验的封闭性。

原文用形似空杯和满杯的符号表示特殊元素，本文改为0、1。在存在性与唯一性尚未证明时，这两个符号只是候选角色，不是预设的两个不同常量。补元写 $`\bar a`$；它开始是存在量词给出的见证，证明唯一性之后才能作为无歧义的函数使用。

### 2.2 条件公设与“空真”

命题“如果单位存在且唯一，则每个元素有补元”，在单位不存在或不唯一的模型里可以为真。不是该模型神奇地产生了补元，而是这条蕴涵的前提没有成立。原文296页专门用这一点验证反模型。

空真不等于计算失败就算成功。先写清公设前提，再判断哪些赋值符合前提；只有这些赋值才接受等式检查。执行器必须分别记录成员条件不适用、正常成立和真正失败，不能把任意异常吞掉。

### 2.3 一个贯穿全文的四元素解释

取 $`U=\{r,s\}`$，$`K=\mathcal P(U)`$，四个元素为 $`\varnothing,\{r\},\{s\},U`$。令+为并、乘为交、0为空集、1为U、补为相对U的补集，关系为包含。

例如

```math
\{r\}+\{s\}=U,\qquad \{r\}\{s\}=\varnothing,
\qquad \overline{\{r\}}=\{s\}.
```

两元素真假模型是最小的非平凡例子，但不穷尽全部模型。四元素例子既让定义可手算，也预告附录的 $`2^m`$ 分类。手算一个模型并不证明任意模型都能这样表示；后面的通用证明另有责任。

## 3 第一组：十条公设，没有结合律

### 3.1 全部条件

原文292–293页，原语为K、+和乘。以下a、b、c均遍历K。

| 编号 | 原条件的现代符号转写 |
|---|---|
| Ia | $`a+b\in K`$ |
| Ib | $`ab\in K`$ |
| IIa | 存在 $`0\in K`$，对所有a有 $`a+0=a`$ |
| IIb | 存在 $`1\in K`$，对所有a有 $`a1=a`$ |
| IIIa | 若相关两项都在K，则 $`a+b=b+a`$ |
| IIIb | 若相关两项都在K，则 $`ab=ba`$ |
| IVa | 若相关全部项在K，则 $`a+(bc)=(a+b)(a+c)`$ |
| IVb | 若相关全部项在K，则 $`a(b+c)=ab+ac`$ |
| V | 若IIa、IIb的元素存在且各自唯一，则每个a有某个 $`\bar a\in K`$，使 $`a+\bar a=1`$、$`a\bar a=0`$ |
| VI | K有至少两个不同元素 |

“相关全部项”在IVa中精确指a、b、c、a+b、a+c、bc、a+(bc)、(a+b)(a+c)；IVb指a、b、c、ab、ac、b+c、a(b+c)、ab+ac。IIIa、IIIb各包括两个输入和两种顺序的结果。只在十条全部采用之后，Ia、Ib才允许后文省掉这些成员条件。

### 3.2 先证明单位唯一，再使用V

若0和0′都是加法右单位，则

```math
0=0+0'=0'+0=0'.
```

中间一步使用IIIa。乘法单位同理。这是VIIa、VIIb（294页），也让V的条件真正生效。不能倒过来先把补元当现成函数，再用它证明V的前提。

### 3.3 幂等、吸收和补元唯一的依赖链

选a的补元。由IVa、两个单位及V，

```math
a+a=(a+a)1=(a+a)(a+\bar a)
=a+(a\bar a)=a+0=a.
```

没有使用结合律。交换+与乘、交换0与1，得到 $`aa=a`$。这是VIIIa、VIIIb。

再证 $`a+1=1`$（IXa）：

```math
a+1=(a+1)1=(a+1)(a+\bar a)
=a+(1\bar a)=a+\bar a=1.
```

对偶得 $`a0=0`$。由此，IVb给出吸收律（Xa）：

```math
a+(ab)=(a1)+(ab)=a(1+b)=a1=a.
```

对偶为 $`a(a+b)=a`$。

若u、v都是a的补元，则

```math
v=1v=(a+u)v=av+uv=0+uv=uv,
```

```math
u=u1=u(a+v)=ua+uv=0+uv=uv.
```

所以u=v。这是XI的教学拆解，对应295页。由对称性，a也是其补元的补元，因而 $`\overline{\bar a}=a`$。**补元唯一是定理，不是V原来就要求的内容。**

### 3.4 先得De Morgan，再证明结合律

在未证明结合律之前，括号不能随便移动。先建立两个带括号的辅助式：

```math
a+(\bar a+c)=1,\qquad a(\bar a c)=0.
```

第一式用 $`t=a+(\bar a+c)`$ 表示左端，则

```math
t=1t=(a+\bar a)[a+(\bar a+c)]
=a+[\bar a(\bar a+c)]=a+\bar a=1.
```

末步前使用已证吸收律；第二式由对偶得到。令 $`d=\bar a\bar b`$，分配律和上述辅助式给出

```math
(a+b)+d=[(a+b)+\bar a][(a+b)+\bar b]=1,
```

```math
(a+b)d=a(\bar a\bar b)+b(\bar a\bar b)=0.
```

第二式中处理b项只需交换内层两因子。补元唯一遂给出 $`\overline{a+b}=\bar a\bar b`$，对偶得 $`\overline{ab}=\bar a+\bar b`$。这对应XII（295页），证明没有借用待证的结合律。

现在令

```math
x=(a+b)+c,\qquad y=a+(b+c),\qquad
q=(\bar a\bar b)\bar c=\bar x.
```

先证 $`y+\bar a=y+\bar b=y+\bar c=1`$。第一项由辅助式与交换立即成立；第二项先算

```math
by=b[a+(b+c)]=ba+b(b+c)=ba+b=b,
```

于是

```math
y+\bar b=(y+\bar b)1
=(y+\bar b)(b+\bar b)=(yb)+\bar b=b+\bar b=1.
```

c项同理。把这套计算整体对偶，并将q写为 $`\bar c(\bar a\bar b)`$，便得 $`qa=qb=qc=0`$。这样写明对偶代入，避免把“类似可证”当作未经许可的重新结合。

最后只用两次分配：

```math
y+q=[(y+\bar a)(y+\bar b)](y+\bar c)=(11)1=1,
```

```math
qy=qa+(qb+qc)=0+(0+0)=0.
```

所以y和x都是q的补元，由唯一性得x=y。乘法结合律由De Morgan和刚证的加法结合律推出。这个证明的顺序是单位、幂等、吸收、补元唯一、De Morgan、结合律，不能把顺序颠倒。[原文294–296页](https://archive.org/download/jstor-1986459/1986459.pdf#page=8)

### 3.5 第一组怎样接到关系语言

结合律成立后，原文294页提出四个等价定义。本文记为

```math
a\le b\iff a+b=b\iff ab=a
\iff\bar a+b=1\iff a\bar b=0.
```

例如a+b=b给出 $`ab=a(a+b)=a`$；反过来ab=a给 $`a+b=ab+b=b`$，两步都用吸收。若ab=a，则 $`a\bar b=(ab)\bar b=a(b\bar b)=0`$；若 $`a\bar b=0`$，则 $`a=a(b+\bar b)=ab+a\bar b=ab`$。最后由De Morgan，$`a\bar b=0`$等价于 $`\bar a+b=1`$。

自反来自幂等，反对称来自交换，传递可由ab=a、bc=b推出 $`ac=(ab)c=a(bc)=ab=a`$。a+b是最小共同上界，ab是最大共同下界；单位、吸收和补条件给第二组4、5、8。若a不≤ $`\bar b`$，上述等价式说明ab≠0，取x=ab即满足第二组9。非平凡性从VI直接转成10。

这样确立第一组到第二组的具体桥梁，第二组再恢复分配等式以回到第一组。此时使用结合律合法，因为它已在3.4节证明；不能把这条捷径偷提前到3.3节。

## 4 第一组的十个反模型

### 4.1 完整二元素表

原文296页为前九条给出二元素表。下表每串按输入00、01、10、11排列；X表示不属于 $`K=\{0,1\}`$ 的输出，不是第三个K元素。

| 单独失败项 | +的四个输出 | 乘的四个输出 | 一处失败或关键机制 |
|---|---|---|---|
| Ia | 0,1,1,X | 0,0,0,1 | 1+1出K；条件化等式保留 |
| Ib | 0,1,1,1 | X,0,0,1 | 00出K |
| IIa | 0,0,0,0 | 0,0,0,1 | 不存在加法单位；V空真 |
| IIb | 0,1,1,1 | 1,1,1,1 | 不存在乘法单位；V空真 |
| IIIa | 0,0,1,1 | 0,0,0,1 | 0+1与1+0不同；加法右单位不唯一 |
| IIIb | 0,1,1,1 | 0,0,1,1 | 01与10不同；乘法右单位不唯一 |
| IVa | 0,1,1,0 | 0,0,0,1 | +为异或，乘为与 |
| IVb | 0,1,1,1 | 1,0,0,1 | +为或，乘为同或 |
| V | 0,1,1,1 | 0,1,1,1 | 两种规则都是或，两个单位角色同为0；元素1无补元 |

VI的反模型则是单元素K，唯一输入的两种运算都返回该元素。所有等式及存在要求成立，唯独没有两个不同元素。

### 4.2 三个手算检查，避免只信表格

**Ia模型。** +只有1+1出K；单位0、乘法单位1都存在且唯一。a的补元可选1−a。因此V成立。IVa若a=1且b或c=1，至少一个a+b、a+c出K，不属于其适用赋值；在实际可用赋值上等式成立。这里不能把X当作普通真假值接着运算。

**IVa模型。** 取a=1、b=0、c=1：

```math
a+(bc)=1+0=1,\qquad
(a+b)(a+c)=(1+0)(1+1)=1\cdot0=0.
```

异或对与的这条分配律失败，但与对异或的另一条分配律成立。V可用互补0、1；两个单位仍分别是0、1。

**IVb模型。** 取a=0、b=0、c=1：左边 $`0\cdot(0+1)=0\cdot1=0`$；右边 $`(0\cdot0)+(0\cdot1)=1+0=1`$。其余条件由表逐项检查，其中同或的单位是1，补对仍是0、1。

本篇执行器穷尽每张有限表上的合法赋值。检查器支持上述反模型，独立性论证则另依赖语义可靠性：若一条真能从其余条推出，满足其余条的任何模型都不会使它失败。不是“代码没报错，所以所有数学问题已解决”。

## 5 第二组：一个关系如何长出布尔运算

### 5.1 十条原公设，九条独立基

原文297页只有K与一个二元关系为原语。用 $`a\le b`$ 表示原来的“within”，逆向符号全部转成同一种朝向。

1. **自反：** $`a\le a`$。
2. **反对称：** $`a\le b`$且 $`b\le a`$蕴涵a=b。
3. **传递：** $`a\le b\le c`$蕴涵 $`a\le c`$。
4. 存在0，使所有a≠0满足 $`0\le a`$。
5. 存在1，使所有a≠1满足 $`a\le1`$。
6. 对不同且不可比较的a、b，存在s，满足a≤s、b≤s；每个不同于s的共同上界y都满足s≤y。
7. 对不同且不可比较的a、b，存在p，满足p≤a、p≤b；每个不同于p的共同下界x都满足x≤p。
8. 若4、5的元素存在且各自唯一，则每个a有一个见证 $`\bar a`$，使a和 $`\bar a`$ 的任何共同下界只能是0，任何共同上界只能是1。
9. 若1、4、5、8成立，且 $`a\le\bar b`$不成立，则存在非零x，满足x≤a且x≤b。
10. K有至少两个不同元素。

4、5刻意排除候选自身的比较；6、7对最后一项也排除与候选相同的对象。这使它们不把公设1暗中带入。假定1–3后它们才成为熟悉的最小元、最大元、上确界与下确界条件。

8的补元最初可能不唯一。9应对8允许的补元见证作检查，而不是先任意选定一种能让9通过的配对便停止；300页唯一性证明正会比较不同补元。如果没有保留这一点，就把原问题变成了另加一元函数的另一种公设化。

原文立即说明：全表不独立。加入其余条件后，6可以从7推出，7也可以从6推出（定理25）；为了对称保留两条。得到独立基时，任选删掉6或7。这里“ordinally independent”讨论的较弱前缀依赖，不能翻译成十条全部相互独立。

### 5.2 从关系构造运算

由2，0、1唯一。由1、2、6，a、b的上确界唯一：比较时直接取较大者，不可比时取6的s，相等时取自身。记为a+b。乘法由7同样定义为下确界ab。

例如共同上界s和s′若都最小，则s≤s′且s′≤s，由反对称得相等。这解释“存在一个s”怎样升级为良定义的运算。交换律来自a、b地位对称，不需要另假定。

结合律在此处很短：$`(a+b)+c`$与 $`a+(b+c)`$都是a、b、c共同上界中的最小者，所以相等。更具体地，前者是a、b、c的上界，后者≤前者；对调角色又得反向不等式，用2结束。下确界对偶。这里用的依据是关系公设及上确界性质，不能把这份短证直接塞回第一组未构造好序关系的早期步骤。

原文298–299页的11–16还给出单位、界、单调性。例如a≤b、x≤y蕴涵a+x≤b+y，因为b+y同时大于a和x。乘法单调性同理。下面的Peirce证明正需要这些基本序性质。

### 5.3 公设9为什么比“有补元”强

在有上下确界的情形，9可读成：如果a不包含在b的补内，a与b就有非零公共部分。这不是任意补格都满足的定律。

用9先证补元唯一。若u、v都是a的补元而u≤v失败，在9中取第一个元素为u、第二个元素为a，并以v作为a的补元见证，便得到非零x≤u且x≤a，与u和a只有零共同下界矛盾。于是u≤v；对换u、v得v≤u，故u=v。再由补的定义对称性得双补还原。

再证补反转次序。若a≤b却 $`\bar b\le\bar a`$失败，9给出非零x≤ $`\bar b`$且x≤a；传递性给x≤b，因此x是b与其补的非零共同下界，矛盾。所以

```math
a\le b\quad\Longrightarrow\quad \bar b\le\bar a.
```

由此得到De Morgan：a+b的补是 $`\bar a,\bar b`$ 的最大共同下界，即

```math
\overline{a+b}=\bar a\bar b.
```

证明要用两向界：a,b≤a+b给 $`\overline{a+b}\le\bar a,\bar b`$；任何t≤ $`\bar a,\bar b`$，取补得a,b≤ $`\bar t`$，故a+b≤ $`\bar t`$，再取补得t≤ $`\overline{a+b}`$。这些步骤都不曾假定分配律。[原文298–300页](https://archive.org/download/jstor-1986459/1986459.pdf#page=12)

## 6 Peirce的关键一步：分配律不是格的免费赠品

### 6.1 容易的方向

由上、下确界，ab与ac都≤a，并且分别≤b、c。因此

```math
ab+ac\le a(b+c).
```

任意格都有这个方向。需要额外条件的是反向不等式；只画一张集合交并图，会把我们要证明的结构先偷偷假定了。

### 6.2 两次抽取非零见证的引理

原文300–302页先证

```math
a(b+c)\le b+ac.
```

以下是保持原证明结构的现代符号重构。

1. 假定不成立。用9及双补还原，取得非零x，使

```math
x\le a(b+c),\qquad x\le\overline{b+ac}.
```

2. 第一项给x≤a、x≤b+c。第二项通过补反序及上界性质给 $`x\le\bar b`$、$`x\le\overline{ac}`$。不必预先使用分配律。
3. x≤c不可能成立。否则由x≤a、x≤c得x≤ac，又有x≤ $`\overline{ac}`$，只能x=0。
4. 因x≤c失败，再用9，取得非零y，使y≤x、y≤ $`\bar c`$。
5. 由y≤x≤ $`\bar b`$，并对y≤ $`\bar b,\bar c`$取补，可得b,c≤ $`\bar y`$，因此b+c≤ $`\bar y`$，再取补得y≤ $`\overline{b+c}`$。
6. 同时y≤x≤b+c。因此y只能是0，与选取相矛盾。

引理成立。两次9不是重复装饰：第一次得到“在a(b+c)里、却避开b+ac”的x；第二次从x不在c内取出更小的y，使它同时避开b与c，最终无处可去。

### 6.3 从引理得到完整分配律

对引理两边与a取下确界，利用单调性、幂等及已证结合律：

```math
a(b+c)=a[a(b+c)]\le a(b+ac).
```

再把同一引理的b换成ac、c换成b，得到

```math
a(b+ac)=a(ac+b)\le ac+ab.
```

合并便有 $`a(b+c)\le ab+ac`$；与容易方向及反对称性合并，得到等式。另一条分配律可用已证De Morgan对偶推出。这是由9支撑的实质性证明，不是把9换名叫分配律便结束。

### 6.4 为什么6和7不能同时算独立

假设留下7，即已有下确界、补的唯一性和反序。定义

```math
s=\overline{\bar a\bar b}.
```

由 $`\bar a\bar b\le\bar a,\bar b`$ 得a,b≤s。如果a,b≤y，则 $`\bar y\le\bar a,\bar b`$，故 $`\bar y\le\bar a\bar b`$，再取补得s≤y。于是s满足6的全部要求。对偶得到由6构造7。

这份证明实际上不需要先用两种运算的完整分配律；需要的是补反序与已有的一种确界。因此删掉6后再用定理25补回它，并不循环依赖已经删掉的6。这是独立基验收不可省略的依赖检查。

### 7.2 两个真正无限的模型

**4的反模型：** K为所有包含整数1的有限整数集合，关系解释为反向包含。不存在包含所有这些有限集合的有限集合，所以无最小元。最大元是{1}；关系的上确界是通常交集，下确界是通常并集。1–3、5–7、10成立，8因4缺失空真，9的条件也失败。

**5的反模型：** K为所有包含整数0的有限整数集合，关系解释为通常包含。最小元为{0}，没有最大元；并、交分别给两种确界，8、9空真。

“不存在最大有限集合”的证明是：给定任意候选有限集合S，选择一个不在S的整数n，$`S\cup\{n\}`$仍在K且严格更大。这覆盖任意S。把整数截断到有限窗口之后，全集会变成最大元素，恰恰破坏原反模型，不能用截断试验替代一般论证。

### 7.3 原文另论1–7的前缀独立

304–305页还给出几何的无限例子。取一个固定正方形里的各个轴平行小正方形、空区域、一个固定圆盘，以及由这些区域组成的有限并。通常包含下，有限并提供上确界，但圆盘与适当交叠小正方形的公共区域没有该类中的最大者，所以下确界要求可失败；反向包含交换两个角色。

这里“有限并”和边界如何处理必须明确，否则随意允许任意无限并会改变类。一个教学精确化是使用开放正方形及开放圆盘，选两者既相交又互不包含的配置：任何位于交叠区域内的有限小正方形并，都可沿圆弧附近再加入一个小正方形而扩大，且仍不成为完整交叠区域。因此没有最大共同内部区域。原文用几何描述，没有给出本文这套拓扑边界约定；这不是代码已穷举的有限表。

### 7.4 五元素模型揭示的差距

在五元素格中，2与4的补元都是3；3可取2或4为补。取a=4、b=3，并取 $`\bar b=2`$。4≤2失败，却没有非零x同时≤4、3，故9失败。

### 7.5 305页提出的替代条件，不冒充已解决

原文讨论用9₁、9₂、9₃替代9：在已有适当格结构的条件下，9₁为“bc=0则 $`b\le\bar c`$”；9₂要求bc=0时分配性困难方向成立；9₃为 $`a\le ab+a\bar b`$。原文展示这些形式之间的推导，并指出缺少他希望得到的对偶对称性。

### 8.1 原公设A–H、J

| B | a、b、a+b、b+a在K时，a+b=b+a |

### 8.2 恢复关系和乘法

定义

```math
a\le b\iff a+b=b.
```

A给自反；B给反对称：a+b=b、b+a=a时交换即a=b；C给传递：若a+b=b且b+c=c，则

```math
a+c=a+(b+c)=(a+b)+c=b+c=c.
```

D、E分别给界。F确保+始终可继续组合。a+b是a、b的共同上界，因为由A–C，$`a+(a+b)=a+b`$；若a≤y且b≤y，则 $`(a+b)+y=a+(b+y)=a+y=y`$，所以它是最小共同上界。

这样回到第一组。反方向，从第一组已有幂等、结合、吸收、补及分配即可验证A–J，故不是只建立单向类比。

## 9 附录：有限模型为什么恰好有2的幂个元素

### 9.1 原文结论与补齐的证明

308–309页把满足这些定律的结构称作logical field，名字类比Galois field。不要据此把它当作现代具有乘法逆元的数域：逻辑加法幂等，通常不是域的加法。

309页脚注还提到Poretskii、Schröder，并说明符号与证明方法受到E. H. Moore建议；这些归属也不应在现代重述中消失。

附录提出两点：有限非平凡模型的元素数必为 $`2^m`$（m≥1）；每个这样的大小都能构造模型，并且本质上只有一种。后者指同构意义，不是给固定标签的元素只有一张表。

原文用不相交的不可约元素展开所有元素，证明高度压缩。以下教学补证说明其中“不可约”与唯一展开不能省掉。

1. 在有限偏序中，每个非零a下面都存在一个最小非零元素，称原子：从a向下严格下降不能无限继续。
2. 两个不同原子u、v的交若非零，则交≤u、v；原子的最小性迫使u=uv=v，矛盾。因此不同原子交为0。
3. 对任意a，把a下面全部原子的并记为s（没有则取0）。显然s≤a。如果s≠a，令 $`x=a\bar s`$。x不能为0，否则由分配与补有 $`a=a(s+\bar s)=as+a\bar s=s`$。x非零，下面必有一个原子u；但u≤a，故u已在s内，同时u≤ $`\bar s`$，矛盾。因此a=s。
4. 不同原子子集的并不同。若两个子集不同，取仅属于其中一边的原子u；与两边分别相交，利用分配，一边为u，另一边为0。
5. 所有m个原子的子集共有 $`2^m`$个，步骤3给满射、步骤4给单射，因此K与它们的幂集一一对应。

并、交、补在这对应下分别就是原子子集的并、交、相对全体原子的补。因此每个固定m只有一个同构类型，也反过来构造了每个 $`2^m`$大小的模型。非平凡性排除m=0的单元素情况；若删去VI、10或J，就必须重新纳入它。

### 9.2 八元素完整手算例

取三个原子r、s、t，用三位二进制记录出现与否，r=001、s=010、t=100。则

```math
011+110=111,\qquad 011\cdot110=010,
\qquad \overline{011}=100.
```

序关系可用“每个1位都被包含”判断，例如010≤110，但011不≤110。对9取a=011、b=110；b的补为001，a不≤001，公共非零见证可取010。三种原语在同一对象上各回答不同接口问题，却恢复相同结构。

这项编码是教学实现，不意味着原文使用计算机位运算。附件检查若干m的构造，只验证那些具体表；任意有限大小的分类仍靠第9.1节的数学证明。

## 12 对今天的验证与AI可以借鉴什么

以下为现代延伸，不是1904年的应用主张。

**先检查测试器有没有偷带待测条件。** 如果数据生成器只产生封闭规则，便永远无法测试封闭性的独立性；只产生偏序，就无法检验自反和传递的独立性。这与软件规格检查、模型评测中的选择偏差相通。生成对象的类型约束也是假设，不能只审查屏幕上列出的条件。

**表示不同，证明难点的位置也会移动。** 第一组容易写出分配，却要努力推结合；第二组容易从确界得到结合，却要用9完成分配；第三组压缩原语，却把结构放进带存在条件的G、H。原语数、句子数、量词复杂度与计算代价是不同尺度。

**反例与证明可互相审计，但不是互相替代。** 小模型能揭露抄错的补号或未声明前提；一般推导能说明为什么删除某条后有限搜寻必然失败或必须转向无限结构。自动搜索提出候选、明确检查器验证候选，是可用的现代分工；检查器的承诺只能覆盖所实现的语义和范围。

### 答案

**1.** 若直接声明 $`K\times K\to K`$，Ia已是类型约束；另一运算同理。原规则允许出K，须恢复条件化成员语义才是原问题。

**2.** 修饰IIa、IIb的特殊元素；补元起初只要求存在。XI用两条分配、单位、交换与互补关系证明它唯一。

**3.** $`a+a=(a+a)(a+\bar a)=a+a\bar a=a+0=a`$，首步还用乘法单位1和a+补a=1；核心是IVa，括号没有重新结合。

**4.** IIIa模型为左投影a+b=a。0与1都能充当右单位，V的唯一性前提失败，故V空真；这不表示任意补元已经存在。

**5.** 与对异或确实满足IVb；失败的是异或对与的IVa。独立性必须匹配准确编号，不能只说“两者不是布尔运算”。

**6.** 避免把0≤0写进4，使自反性仍可独立失败。5、6、7的排除同一候选条件同样有此作用。

**7.** 它同时违反6、7，满足其余八条。删6的九条基中，它证明7不可省；删7时证明6不可省。不能当作十条全独立的证据。

**8.** 4不≤2；但4与3只有共同下界0。因此前提为真，所需非零x不存在。3另一个补元4不救回对指定合法见证2的失败。

**9.** 从非零x不≤c取得非零y≤x且y≤补c。结合x≤补b，就得到y同时避开b、c；又因y≤b+c而矛盾。没有这一步，不能直接由x不≤c断言x≤补c。

**10.** +在布尔解释中是单调的，任何只用它与常量组成的项仍单调；补不是。G用存在性刻画补元，H帮助证明唯一，不是给出一个纯+项。

**11.** 有限窗口的全集会成为最大元素。原无限族无最大元的证明依赖总能选出窗口外的新整数，有限截断不能保持这一点。

**12.** 三个原子。同构类型只有一个，但对固定标签可作不同标记，产生不同表；“本质唯一”指同构，不指逐格唯一。

**13.** VI、10、J都明确要求至少两元素；大部分等式在一个元素上两边自动相同。若改变非平凡性条件，分类也应允许 $`2^0=1`$。

**14.** 不能。那些只是具体构造的核验；一般证明必须给出有限下降、原子分解的存在、唯一性和幂集对应。
