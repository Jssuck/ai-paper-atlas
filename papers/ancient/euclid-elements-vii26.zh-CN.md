# 欧几里得《几何原本》VII.26：为什么四条跨组互素能推出两积互素？

> AI 数学与形式推理前史补读。约公元前 300 年的古代算术，实读 1908／2008 版。从现代论文主线回看形式推理史，不是 AI 论文，也不声称穷尽前史。

## 1. 书目与问题

- Euclid, *Elements*, VII.26。T. L. Heath, *The Thirteen Books of Euclid’s Elements*, 卷 II，Cambridge University Press，1908，[印刷页 327](https://archive.org/details/thirteenbookseu01heibgoog)。题句、六线图、完整证明及代数评注均在该页。
- Richard Fitzpatrick, *Euclid’s Elements of Geometry*（2008 修订），[希英对照，印刷页 215](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=215)。对读 [Clay 希英文本与第 141 叶入口](https://www.claymath.org/library/historical/euclid/files/elem.7.26.html)、[Joyce 在线本](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII26.html)。版本差异见[原典核对](../../reproduction/euclid-elements-vii26/source-review.zh-CN.md)。

45 和 75 共享 15，26 和 77 却各与前两数互素。这四个数并非两两互素，为什么 45×75 仍与 26×77 互素？本命题把“各自与一个固定数互素”的 [VII.24](euclid-elements-vii24.zh-CN.md) 当作积木：先把左组压成一个积，保留它对右组**每一项**的关系，再把右组压成一个积。关键不是两组各做一次乘法，而是**哪几条关系要在乘法后留下来**。

## 2. 对象、记号与量词

| 原文标号 | 现代记号 | 角色 |
|---|---|---|
| A、B／Α、Β | $`a,b`$ | 左组因数 |
| C、D／Γ、Δ | $`c,d`$ | 右组因数 |
| E／Ε | $`e=ab`$ | 左组的积，最后成为固定参照 |
| F／Ζ | $`f=cd`$ | 右组的积 |

“两个都与两个中的每一个互素”是四条跨组条件：A–C、A–D、B–C、B–D。它不是只检查对应位置，也不要求 A–B 或 C–D 两条组内关系。[定义 12](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII11.html)所说的是共同单位以外无公度，不要求任一因数本身为质数。线段图是标号示意，不应从它测出因数或比值。现代推导以正整数为域，允许 1；原书另分“单位”和“数”，附件的历史数输入约定也另行说明。

## 3. 原证：两次保留关系，一次合并结果

1. **固定 C。** A、B 各与 C 互素。按 VII.24，其乘积 E 与 C 互素。
2. **固定 D。** 原文紧接着用“同理”得到 E 与 D 互素。展开后，这一步用 A 与 D、B 与 D 两条输入，再对固定 D 调用 VII.24。它不是步骤 1 的结论自动覆盖了 D。
3. **固定 E。** 把已有的两条互素关系读作 C 与 E、D 与 E 互素。互素的对称性来自共同度量的定义，不是改动因数。再用 VII.24，C×D 与 E 互素。认出 C×D=F，得到 E、F 互素。

| 可核查的主张 | 证据位置 |
|---|---|
| 两组各二项及“各与每个”的全交叉条件 | Heath 327 页命题开头；Fitzpatrick 215 页题句与设例 |
| 得 E 与 C 互素；同理得 E 与 D 互素 | Heath 327 页图下；Fitzpatrick 215 页下部、英栏第一次 VII.24 |
| 固定 E，得到 F 与 E 互素 | Heath 327 页正文末；Fitzpatrick 215 页底、英栏第二次 VII.24 |
| “同理”没有额外编号，但有一次实质应用 | 两印本与 Clay、Joyce 正文都保留中间关系；Joyce 导读另作概括 |

Heath、Fitzpatrick、Clay 与 Joyce 正文都只在首尾两处明标 VII.24，中间以“同理”进行；把证明实施过程展开有**三次实例化、两个合并层级**。Joyce 导读称两次，并把相对于 C、D 的前两条结果合写；不能把它当成两次单一固定参照的调用。Clay 英栏在认出 F 为右组乘积处结束，希栏及两印本仍明说两积互素。见[原典核对](../../reproduction/euclid-elements-vii26/source-review.zh-CN.md)。

## 4. 教学建模：先覆盖四格，再按列合并

把互素写成 $`P(x,t):\gcd(x,t)=1`$。四个输入为 $`P(a,c)`$、$`P(b,c)`$、$`P(a,d)`$、$`P(b,d)`$。在同一个参照项上应用 VII.24：

$$
\begin{aligned}
P(a,c)\land P(b,c)&\Longrightarrow P(ab,c),\\
P(a,d)\land P(b,d)&\Longrightarrow P(ab,d),\\
P(c,ab)\land P(d,ab)&\Longrightarrow P(cd,ab).
\end{aligned}
$$

最后一行的两个前提正是前两行通过对称性转向后的结果。公式没有用到 $`P(a,b)`$ 或 $`P(c,d)`$。也可以交换左右两组，先按另一方向合并；原证走的是先造左积 E，随后固定 E。

现代 **逆向** 也成立，但不是把 VII.24 倒读：若 $`ab`$ 与 $`cd`$ 互素，则任取左因数 $`x\in\{a,b\}`$，由 $`x\mid ab`$ 和 [VII.23](euclid-elements-vii23.zh-CN.md) 知 $`x`$ 与 $`cd`$ 互素；再任取右因数 $`y\in\{c,d\}`$，由 $`y\mid cd`$ 得二者互素。因此在现代正整数域，四格全真与两积互素等价；**双向合读是教学重构，不是说 VII.26 原文给了两向证明**。

| 左组；右组 | 手算和对照 |
|---|---|
| (45,75)；(26,77) | 左积 3375，分别与 26、77 互素；右积 2002，两积互素 |
| (6,10)；(7,49) | 两组内部都不互素，却满足四条跨组关系；60 与 343 互素 |
| (6,5)；(9,7) | 只在 A–C 格失败，其余三格真；两积 30、63 共享 3，说明不能少核这一格 |
| (2,3)；(9,4) | 对应位置 A–C、B–D 皆互素，但另两格皆失败；两积 6、36 不互素 |
| (1,5)；(7,49) | 现代单位边界，左积仍是 5，满足所有条件；不是古书把 1 当作一般的数 |

对第三例，独立选择是否交换左组、右组的因数位置，可以把唯一失败移到其余任一格。因此四条前提中的**每一条**都不能简单删掉。相比之下，要求组内也互素只会不必要地排除第二例。

### 一个能逃过互素检查的算错

Joyce 导读的算例把 $`26\times77`$ 写成 1144，正文没有这组数字。重算得 $`26\times77=26(70+7)=2002`$；误值 1144 恰好仍与 3375 互素。因此“最后的互素判定通过”不能验证前面的乘法；必须另查 F 等于 C×D。本篇记录的是导读计算错误，不把它归为欧几里得证明的错误或正式勘误。

## 6. 复盘与练习（含答案）

复盘：**跨组四格，不查组内；固定 C 与 D 分别保留两条边，再固定左积合并。**

1. **按原证填出 (6,10)；(7,49) 的三个调用。** 答：先以 7 为参照得 60 与 7 互素；再以 49 为参照得 60 与 49 互素；最后以 60 为参照，得 343 与 60 互素。
2. **只检查 A–C、B–D，为何不够？** 答：(2,3)；(9,4) 满足这两格；A–D 共享 2，B–C 共享 3。其积不互素。
3. **能写出只让 B–D 一格失败的例子吗？** 答：把 (6,5)；(9,7) 的两组分别颠倒，得到 (5,6)；(7,9)。只有 6 与 9 共同含 3。
4. **两积互素时，可直接反用 VII.24 吗？** 答：不需要反用。两次用 VII.23，各把一方的积换成该积的因数，就能得到四条跨组互素。
5. **为什么拿 3375 与 1144 检查互素仍不够？** 答：二者确实互素，但 1144 不是 26×77。必须分别验证乘法产物和互素性质。
