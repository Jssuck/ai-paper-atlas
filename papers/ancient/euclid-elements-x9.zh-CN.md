# 《几何原本》X.9 深读：平方的比例能告诉我们什么？

> **年代标记：AI 数学前史补读，非 AI 论文。** 《几何原本》约成书于公元前 300 年。本篇读第十卷第 9 命题的四个方向及推论。附列的算术引理涉及传本问题，并非本命题的证明前提，也不表示本卷后续的分类已经收录。

[第十卷定义 1–2](https://mathcs.clarku.edu/~djoyce/elements/bookX/defX.I.html) 区分两个问题：有没有同一条小线段整倍量尽两条线？有没有同一块面积整倍量尽以这两条线作边的正方形？直觉上，好像后一问的答案总能带回前一问。X.9 给出更严格的门槛：**面积比不只要能写成整数比，还要能写成两个平方数之比。**

前面的 [X.5](euclid-elements-x5.zh-CN.md) 和 [X.6](euclid-elements-x6.zh-CN.md) 是「共同量尺」与「整数比」之间的桥；[X.7](euclid-elements-x7.zh-CN.md) 与 [X.8](euclid-elements-x8.zh-CN.md) 是这两条桥的逆否形式。X.9 把它们用于新的数据类型：线段到几何面积，整数边到平方数。Heath 提及古注将定理归于泰阿泰德；这是一条后世归属记录，不是现存作者原稿，不据此断定首创。

## 2. 符号与假设

固定两条**正长度** $`A,B`$，记几何正方形面积为 $`S_A,S_B`$。欧几里得的量之比例与整数之比例在这里要比较，但不把面积单位和线单位混成一种对象。在现代正实数模型中，选定同一个长度单位及其派生面积单位，设 $`r=A/B`$，$`q=S_A/S_B=r^2`$。比值不因共同换单位而变。

| 记号 | 意义 |
| --- | --- |
| $`L`$ | 长度可公度：某正长度 $`h`$ 和正整数 $`u,v`$ 满足 $`A=uh,\ B=vh`$。 |
| $`Q`$ | 平方可公度：这两块正方形存在共同面积单位；由 X.5 和 X.6，在现代模型里等价于 $`q\in\mathbb{Q}`$。 |
| $`P`$ | 存在正整数 $`m,n`$ 使 $`q=m^2/n^2`$，即面积比是平方数比。 |

整数见证用现代约定允许 1。若按 [VII.Defs.1–2](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII1.html) 区别单位与数，可把平方根见证两项同乘 2，例如 $`9:1=36:4`$；不改变比例，也不会让一个非平方数比变成平方数比。

## 3. 四个方向：两条正向证明、两次反证

| 原文顺序 | 证据链 | 结论 |
| --- | --- | --- |
| 1. 给定长度公度 | X.5 得 $`A:B=m:n`$；[VI.20 推论](https://mathcs.clarku.edu/~djoyce/elements/bookVI/propVI20.html) 给几何图形相应边的二重比，[VIII.11](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII11.html) 给整数平方的二重比；两边原比相同，二重比相同。 | $`L\Rightarrow P`$ |
| 2. 给定平方数比 | 由相同的二重比恢复相同的正原比，得 $`A:B=m:n`$；X.6 得长度公度。 | $`P\Rightarrow L`$ |
| 3. 给定长度不可公度 | 假定有平方数比，第二段将推出长度公度，与题设相反。 | $`\neg L\Rightarrow\neg P`$ |
| 4. 给定没有平方数比 | 假定长度公度，第一段将推出有平方数比，与题设相反。 | $`\neg P\Rightarrow\neg L`$ |

「二重比」不是把同一个比例数值乘以 2。按 [V.Def.9](https://mathcs.clarku.edu/~djoyce/elements/bookV/defV8.html)，三个量连续成比例时，首尾之比是相邻一比的二重比。整数侧有现成的中项：$`m^2:mn=mn:n^2=m:n`$。因此 $`2:3`$ 的二重比是 $`4:9`$，不是 $`4:3`$。几何侧用的是相似图形的面积关系，不是借整数乘法定义面积。

**正文省略的环节。** Heath 的评注和 Fitzpatrick 的两条脚注分别指出，原比相等如何推出二重比相等，以及二重比相等如何恢复原比，均未在此展开证明。这里至少要说清楚不同类型的比在何种表示下比较，以及为什么不存在两个不同正原比映到同一二重比。

**教学重构（现代正实模型）。** VI.20 推论给出的面积比较在现代模型中转写为 $`q=r^2`$。若 $`r=m/n`$，代入立得 $`q=m^2/n^2`$。反过来，先把面积式移到同一边，再因式分解：

$$
r^2-(m/n)^2=(r-m/n)(r+m/n)=0,\qquad r+m/n>0.
$$

只能有 $`r=m/n`$。共同长度单位可取 $`B/n`$。这一步的正性不是装饰：若改为有符号代数，$`3`$ 与 $`-3`$ 平方相同，却不表示相同的原比。

**教学重构（不先开实数平方根）。** 若已给出 $`S_A:S_B=m^2:n^2`$，把 $`B`$ 等分为 $`n`$ 份，取一份为 $`h`$，再拼 $`m`$ 份成 $`A'`$。以 $`h`$ 作边的小正方形可分别把 $`S_{A'}`$ 和 $`S_B`$ 分成 $`m^2`$ 与 $`n^2`$ 个相等格子，所以等倍比较直接得 $`S_{A'}:S_B=m^2:n^2`$。由 [V.9](https://mathcs.clarku.edu/~djoyce/elements/bookV/propV9.html) 对同一正面积的比例相同，$`S_{A'}=S_A`$；把两正方形的一角及两边方向重合，若边不等，小者就是大者的一部分，面积严格小（[共同概念 5](https://mathcs.clarku.edu/~djoyce/elements/bookI/cn.html)）。故 $`A'=A`$，$`h`$ 同时量尽二者。这是用格子补足本题跨类型推理的办法，不是把正文换写成一段假引文。

## 4. 推论、算例与反例

$$
L\ \Longleftrightarrow\ P\ \Longrightarrow\ Q.
$$

最后的箭头不可倒转。$`Q`$ 只要求两个面积拥有共同量尺，不要求共同的**线**单位能铺成两组平方网格。下面用精确比例作区分：

| 边长或面积输入 | 推导 | 长度 / 平方公度 |
| --- | --- | --- |
| $`A=6,\ B=4`$ | 长度见证 $`h=2`$；面积 $`36:16=9:4`$，面积见证为 $`4`$。 | 两者均是 |
| 同一正方形的对角线与边 | [I.47](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI47.html) 给面积比 $`2:1`$，所以平方公度。若 $`2=m^2/n^2`$ 且两根互素，则 $`m^2=2n^2`$ 迫使 $`m`$ 偶；代回后 $`n`$ 亦偶，矛盾。 | 长度否，平方是 |
| 只给 $`S_A:S_B=12:27`$ | 先约成 $`4:9`$；虽然 $`12,27`$ 本身都不是平方，见证 $`m=2,\ n=3`$ 仍成立。 | 两者均是 |
| 取 $`A=1+\sqrt{2},\ B=1`$ | $`q=3+2\sqrt{2}`$ 若有理，$`\sqrt{2}=(q-3)/2`$ 也有理，和上例矛盾。两类公度均失败。 | 两者均否；不把此输入交给只收有理面积比的程序 |

古代术语也要随参照对象读。按 [X.Def.3](https://mathcs.clarku.edu/~djoyce/elements/bookX/defX.I.html)，以这个正方形的边为标准时，和它仅平方公度的对角线也归为该定义的「有理线」；这和今天的实数 $`\sqrt{2}`$ 是无理数没有冲突。

**附列算术引理不承担本命题的证明。** 它谈的是边成比例的平面数与平方数比（[VIII.26](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII26.html) 及其逆命题）。Heath 记载希伯格对其插入性质的质疑，并指出逆命题并未在算术诸卷中得到明确证明。本篇既不依赖这条引理，也不把校勘疑问变成对四向正文的否定。

## 5. 现代判定与最小复现

对于**精确给出的正有理**面积比，约分为 $`a/b`$。若它等于 $`m^2/n^2`$，可先把 $`m/n`$ 约到互素；互素的平方仍互素，最简表示唯一，所以 $`a,b`$ 分别是那两个根的平方。反之，两项都是完全平方时，正整数根就是见证。计算可用整数平方根 $`k`$，核对 $`k^2=x`$，或用 $`k^2\lt x\lt(k+1)^2`$ 证明该项不是平方。对近似小数没有这项保证；对给定表达式的有理性，也没有借此得到通用判法。

**证据与局限。** 正文的四个条件式和推论分别见 Heath 页 28–30 与 Fitzpatrick 页 289–291；本篇的实数式、格子补证和算法是现代重构。实跑只核对特定输入范围及代码的见证，不是一般定理的证明，也不声称重现历史实践。将来读到用构形产生仅平方公度的线时，可以用三类结果来检验构形的目标。这里能给现代精确推理的启发是：保留足够强的表示见证；把「平方之比」压缩成「整数之比」之后，恢复原长度比所需的信息就丢了。

## 6. 复盘与练习

1. 为什么第一段用 X.5，第二段用 X.6？  
   **答：**第一段从共同量尺取得整数比，然后倍化。第二段从同一平方比恢复正原比，再用整数比构造共同量尺。
2. $`S_A:S_B=45:80`$ 时，长度比是多少？若 $`B=12`$，共同长度单位可取多大？  
   **答：**最简面积比 $`9:16`$ 给出长度比 $`3:4`$。取 $`h=3`$，两边分别为 $`9,12`$。
3. $`S_A:S_B=8:18`$ 和 $`18:27`$ 都是整数之比，为什么归类不同？  
   **答：**前者约成 $`4:9`$，长度比为 $`2:3`$；后者约成 $`2:3`$，最简分子不是完全平方，所以只平方公度。
4. 若题目只给「长度不可公度」，可断言两个正方形面积不可公度吗？  
   **答：**不能。第三段排除的是**平方数比**，不是全部整数比；对角线与边恰好留下 $`2:1`$ 这个整数面积比。

**一句话复盘：**长度公度会在面积中留下整数平方的比例；只找到一个普通整数面积比，还不足以恢复一把共同的长度尺。
