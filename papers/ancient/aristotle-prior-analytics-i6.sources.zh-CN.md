# 《前分析篇》I.6：原典、版本与全章覆盖账本

核验日期：2026-10-21 UTC。本文件为原创中文来源审计，不是原书全文翻译或扫描再发布。只完成 I.6；前后章只用于划定边界。

## 1. 核验结论与阅读单位

**完整边界是 Bekker 1831，28a10–29a18；下一章 I.7 从29a19开始。** Owen 1853对应印页94中部至98顶部，即所用PDF第113–117页（从1起算）。本次逐页看过五页英译扫描、两页希腊扫描、相关页底装置及指定ERRATA。不是只读第三格的六个有效式；无效配置、未定范围理由、末尾“不完善”和不能推出全称的总结也在阅读范围内。

发现一个明确的译编层例式问题：Owen p95 的 Ex.1 右栏末行引入了前三项之外的 horse。原印照录的短句为“Nothing inanimate is a horse”；同栏两前提及正文指定三项是 animal、inanimate、man。该行不能直接充当原正文所讨论的端项关系。这里报告印本不一致及现代形式检查，不把建议校读冒充作者正式勘误，不推测错误由谁造成。

## 3. 全章论证覆盖

以下采用原章英译P、R、S；S是共同主项／中项，R为结论主项，P为结论谓项。希腊符号对应Π、Ρ、Σ；展示实例另用Ν。现代AEIO及拉丁式名只用于今天定位，不倒署为原章命名。

|---|---|---|
| 28a10–17 | 第三格及共同主项；大小项和位置；无“完善”推论，但全称或非全称前提可构成有效推论 | 94 |
| 28a17–26 | 两全称肯定得特称肯定：换位后归第一格；另述归谬及取出一个S的展示法 | 94–95 |
| 28a26–30 | 大项侧全称否定、小项侧全称肯定得特称否定；换位及归谬路线 | 95 |
| 28a30–35 | 反向异质配置及双全称否定无所求结论；各给正、负端项配置的实词 | 95 |
| 28a35–28b4 | 全称情形的双向分类总结；须区分大项侧否定与小项侧否定 | 95 |
| 28b5–14 | 一全称一特称且都肯定，两种方向皆得特称肯定；转换、第一格、结论换位；也可归谬或展示 | 95–96 |
| 28b14–22 | 全称肯定在小项侧、特称否定在大项侧得特称否定；归谬与直接选择不属P的S | 96 |

前两条全称有效式的现代重建必须显示中项存在条件：原章28a24明确“取某个S”，不是凭空从空类取成员。原文的“无推论”须结合所求方向P述说R理解，不等于完全没有任何逻辑后果。“不完善”不等于无效，原章正在说明如何把必然性展示出来。

## 5. Owen注释、边注与勘误

本章**五条编号脚注**，不能按页将所有脚注都算进来：

1. **p94 n2，跨到p95开头的脚注续文**：说明ekthesis为展示个例，并提及单称前提推论；对亚里士多德是否把这种展示视为三段论表示疑问，引Aquinas及Zabarella。这是译注层疑问，不是原章作者自我否定。
2. **p95 n1**：说明“端项与端项”指大项与小项。
3. **p95 n2**：说明“对中项为全称”即被普遍谓述于中项。
4. **p96 n1**：解释未定范围段落中，所设是某个个体不被谓属的情形。
5. **p98 n1**：转引Hill、Whately、Aldrich关于本格及各格用途的讨论；不把后世用途评价作为古代正文。

**排除**：p94 n1属于I.5；p98 n2、n3属于I.7。p95页顶的脚注续文虽然在Ex.1前，仍是p94 n2后半，不能另增一条。

**三条编号边注**分别概括：第三格共同主项且无完善推论（p94）；全称前提的肯否组合条件（p95）；无全称结论（p97–98跨页）。另有p94“one指syllogism”、展示法的希腊词，以及各例号定位符号。边注2不是整个第三格所有特称情形的完整规则，不能脱离正文扩用。

**指定正式勘误表**：逐图核过PDF18，列印页219、273、594三项，没有94–98项。因此准确结论是“所核这张ERRATA未列本章更正”，不是“本章无错”或“所有后印本勘误均已查全”。Ex.1的异常并未获得该表的正式更正依据。

## 6. Bekker页底装置覆盖

本次看过相关两张整页并放大页底。本章适用装置位置为：

- **28a11、17、23、24、25–26、26、28、30、38**；28a3、4、9属前章，不算I.6。
- **28b2、8、11、15、17、20、22、28、30、31、32、38、39**。
- **29a1、2、6、7、13、16、17**；29a21以后及29b条目属于后章，不算I.6。

装置记有用词与词形、项符号、连接表达、删省、校改等异读。与论证阅读尤其相关的有：28b22的大项／小项及否定配置附近的扩展读法；28b30、31的句段省略；28b32关于小项肯定的省略；29a7双特称排列的省略；29a16全称推论表达的词序。这里不复制整栏，也不把手稿符号A/B/C擅自映射成未核定的馆藏。29a2有实词附近的C读法，说明装置不能被当作不存在；本文以声明的1831排印正文而非任选异读作论证基准。
