# 《后分析篇》I.34：来源、译差与证据定位

## 1. 对象、版本与实读范围

Aristotle，*Analytica posteriora*（《后分析篇》）卷I第34章，**89b10–20**。这是公元前四世纪古代推理与认识问题的前史补读，不是现代AI论文。版本的1831、1853、1928、1964年代不是古代章节写作年；章次也不能单独证明成文顺序。

- [Boyer希英对读页](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-34)：实读I.34完整短章与I.33末尾。网站标示希腊文据Ross（Oxford, 1964）、英译据Mure（Oxford, 1928）；本次使用的是数字转录，不是亲读Ross纸本全部校勘栏。
- [Bekker, *Aristotelis opera*, vol.I, 1831](https://archive.org/details/aristotelisopera01arisrich)：实看[印页89扫描](https://archive.org/download/aristotelisopera01arisrich/page/n104.jpg)，右栏I.34正文及页脚对应校勘记录。89b20后另列卷二标题Β，II.1从89b23起。本章确为所核版本的**第一卷末章**，不是全书末章。
- [O. F. Owen, *The Organon*, vol.I, 1853](https://archive.org/details/Aristotles_Organon_vol_01_1853)：实看印页315（PDF第334页）全章、边注和页底教学展开；再核印316（PDF第335页）明确的BOOK II标题，只用来确定边界，不把卷二作为本轮阅读成果。实看卷首ERRATA（PDF第18页），所列印页为219、273、594，没有315；这只说明该勘误表未列本章，不证明所有版本没有错误。

源扫描与原文全文仅供研究，不作为本仓库公开附件。正文是原创中文解析而非整章逐句翻译；此台账说明证据及解释限度，不冒充传本校勘研究。

## 2. 原文证据地图

| Bekker位置 | 本章作用 | 不应偷换为 |
|---|---|---|
| 89b10–11 | 将敏捷把握描述为在来不及审思的时间命中中项 | 任意快速回答都正确，或已经测得某个毫秒阈值 |
| 89b11–13 | 从月亮亮面朝向太阳，迅速把握受太阳照明的原因 | 已经给出月球物理、反射定律与观测误差的完整证明 |
| 89b13–14 | 与富人交谈而看出借款目的；友谊与共同敌人之例 | 凡与富人说话必为借款，凡有共同敌人必为朋友 |
| 89b14–15 | 以看到两端而把握作为原因的中项概括前例 | 观察一个结论便演绎保证唯一原因 |
| 89b15–20 | 明列A（亮面向光源）、B（受太阳照明）、C（月亮），由B对C、A对B得到A对C | 从A对C逆推B对C而无需其他根据 |

这里把“发现中项的方向”与“中项已取得后证明的方向”分开，是教学分析；原文没有给出搜索候选、评分、概率后验或自动证据核查算法。

## 3. 译差、编辑层与校勘限制

1. **ἀγχίνοια**：Owen用sagacity，Mure用quick wit。中文以“敏捷把握／迅速命中中项”提示本章局部意义，不等同一般智商、全部智慧或现代机器智能。定义中的εὐστοχία有命中意味；原文不是赞美不受真伪约束的猜测。
2. **时间**：Owen用extempore，Mure用instantaneously；希腊文的重点是未及审思的短时间。程序运行耗时不能当作古代心智能力的复现实验。
3. **月亮例**：两译均把朝向太阳的亮面关联到从太阳获得光；末段大前提以朝向其光源表述。将主项视为“月亮这个对象”、将谓词固定为同一光源和方面，可以重建形式推理；把两段中的太阳／光源偷偷换成不同对象则破坏论证。
4. **交谈与朋友**：三个例子用于展示中项被发现，而不是明列社会学全称规律。原文只在月亮例展开字母项。对另两例补出的规则必须标作教学重构，并允许替代解释与反例。
5. **89b15**：Boyer希腊转录在“看见”前列方括号[ὁ]；Bekker扫描正文没有此ὁ。本次保留版本差别，不把方括号内容说成各版一致原文。
6. **Bekker页脚**：右栏对应的b11、b12、b14、b15、b19有异文记录，例如b15涉及第二个τὰ的省略，b19记录λάμπτον。这里只说明已核见记录，不据单页缩写编造抄本身份或宣布解决校勘。总体“原因—中项—两端”的结构不依赖本篇另造一项校订。
7. **Owen编辑材料**：印315章题、边注对《伦理学》卷VI第9章的提示、解释两端为结论以及页底排列好的三段论，是译者／编辑教学层，不应假作亚里士多德另外写出的第四例。页上承接I.33的长脚注也不能当成本章古代正文。

## 4. 前驱问题与同作者背景

### 柏拉图：解释不只是列出条件

实读[Jowett英译《斐多》文本](https://classics.mit.edu/Plato/phaedo.1b.txt)中通常定位97b–99b的段落：对话中的苏格拉底叙述自己对阿那克萨戈拉解释的期待，继而区分身体的骨筋条件与选择留在狱中的理由。这里用于说明“指出某些伴随条件是否已经解释为什么”的前驱问题，而不是说I.34引用该段，更不能把对话角色的叙述不加区分地当作阿那克萨戈拉原著。该文本入口保留旧网页缓存包装；本次核读的是其中署名Jowett的正文，不据包装推断版本年代。

### 《尼各马可伦理学》VI.9：快与善于审议不同

按Owen边注，实读[Ross英译卷VI第9节](https://classics.mit.edu/Aristotle/nicomachaen.6.vi.html)：快速猜中与善于审议有所区分，后者涉及推思；得到合适结果但用错误中项也不够。它约束本篇不要把“快”或“结论正确”当作理由正确的保证。这是同作者问题背景，不据此断言两书写作先后、直接引用关系或同一技术定义。

### 《后分析篇》内部

实读[I.13开头78a22–78b10](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-13)，以事实与所以然、原因与较易知的可换谓词区分证明；其行星／月球球形例不移植为I.34原例。核读I.33末尾（89b7–9）将其他认知能力的分配留给自然和伦理研究；I.34随后讨论敏捷，不是把所有认知能力归并成一类。书中“中项作为所以然”的背景亦见I.33的89a11–22；相同中项链并不足以消除意见与严格知识之别。因此本篇的候选检查不能自称完成了知识认证。

这些来源按问题相关性选取，不是古代所有地区、机构、学派或同期文献的穷尽目录。没有点名的传统不能因此被判为无贡献。本次没有建立从本章到现代溯因、贝叶斯推断或AI系统的直接历史传承链；这些比较若出现，应明标为后设教学类比。

## 5. 对现代最小复现的约束

有限集合包含关系可以检查中项桥接是否成立，也能给出“结论成立但某个候选中项不成立”的反模型。它不能自动认证经验前提、自然原因、独一解释或主体的真正知识。添加多个同样能连接两端的候选，可揭示形式条件不足以唯一选出原因；这不是声称原文把每个候选都判作原因。真实测试日志仅支持所声明有限程序的行为，不证明人的敏捷、古代天文学或一般因果发现定理。
