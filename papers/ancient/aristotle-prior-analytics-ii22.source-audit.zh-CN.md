## 独立读取的证据

1. [Bekker 1831卷一](https://archive.org/details/aristotelisopera01arisrich)印页67、68扫描：核对II.22的67b27起点、完整正文至68b7、II.23在68b8的标号，以及页下注异文栏。解释以英译互校，不声称建立新的希腊文定本。
2. [Owen 1853卷一](https://archive.org/details/Aristotles_Organon_vol_01_1853)印页228–230：逐页读取II.22正文、边注及相关脚注，连读下一章标题。另亲读卷首完整ERRATA页，其三条分别涉及印219、273、594；没有本章228–230条目，不能由此推断本章没有其他文本问题。
3. [Jenkinson英译Book II固定电子转录](https://en.wikisource.org/w/index.php?title=The_Works_of_Aristotle/Prior_Analytics/Book_II&oldid=15924675)：完整读第22节及注90–96，兼读第23节开头与注97–99。亲读的是电子转录，而非1913原版扫描。

## 实质核验与修正

| 核验项目 | 结果 |
| --- | --- |
| 全章范围 | 正文没有只覆盖开头换位，而是包括二分、穷尽述谓、共同属性、偏好与爱情目的段。采用67b27–68b7；Owen与Bekker/Jenkinson对章际总结句归属不同，台账已记录。 |
| 精确位置 | 审查发现初稿把共同属性段截在68a24，已修为68a21–25；偏好段相应从68a25开始。68a25及68a39各有同一印刷行内的段落交接，因此相邻证据范围可共享边界行。 |
| 否定段校读 | 注92的67b37字母补足、注94的67b39补文、注95的68a1字母读法均列为译者采纳的校读，未假装各版本无差别。注90、91、93、96的演算与正文正/负关系区分相符。 |
| 互补论证 | Owen印229注1明确指出另一方向省略；正文补足双向证明，并区分不交与覆盖。生成/毁灭例在Owen与Bekker/Jenkinson中的顺序差异已正确记载，不据此当作不同史实。 |
| 自述谓例外 | 68a16–21的“除A自身”没有被删去；现代对象集合重构明确不声称解决词项自述谓层次。 |
| 与归纳的联系 | II.23原文回指先前共同属性段，注98定位68a21–25；正文只说明可核文本连接，未把穷尽归纳混为统计样本推广。 |
| 偏好与目的 | 数值对称和可加性标作充分教学假设；原文条件性应用、目的论承诺与现代经验事实已分开，不把程序当作伦理或爱情证据。 |
| 前人及注家归属 | Owen印230脚注的《会饮篇》联系被标为十九世纪译注，不冒充本章作者直接引文或已证的影响链。作品年代与版本年份、古代前史与现代AI论文也已区分。 |

README中的最新入口、年代行和附件说明与本章范围、正文覆盖相符。公开稿没有附扫描、全文翻译或私人执行资料；所列外部文献用于核查，正文是原创解析而非原文替代品。

## 限定

本审查认可的是上述证据足以支持当前稿的有限主张；不证明所有希腊文解释均已排除，不独立验证每一抄本的谱系，也不以现代集合语义裁定古代作者唯一意图。有限实跑及其计数另由技术审查承担。
