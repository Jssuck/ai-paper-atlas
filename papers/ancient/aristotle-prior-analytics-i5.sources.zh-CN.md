# 亚里士多德前分析篇第一卷第五章源本审计

核验日期：2026-10-21 UTC。范围严格限于《前分析篇》I.5完整一章及其所附出版装置；前后章只看边界，不把整卷作为本次阅读单位。本文件是原创中文校核记录，不是原文转录、译文或扫描再发布。

## 核验结论

本章的准确边界是 **Bekker 1831，26b34–28a9**。章5号印在26b34旁；章6从28a10开始。Owen 1853完整对应为**印页89下半至94首段**，即所给PDF的**第108–113页**（1起算，印页+19），不是印页89一页，也不是全部第一书。Owen的正文、脚注、例式、侧注与Bekker的正文、校勘栏分别属于不同证据层，不能混写为亚里士多德原文。

实物扫描确认三处例词差异：27a20的希腊词为“数”，Owen用“石”；27b7为“单位”，Owen用“石”；27b27为“石”，Owen正文用“雪”，但Owen自己的例6又用“石”。数字化Owen正文沿用了这些印本文字。不能静默统一词语，不能说已证明是哪次排版或哪位译者造成。

## 全章论证覆盖台账

以下用M为中项、N为大项、X为小项；希腊印本第三字母是Ξ，Owen英译改标为O。这里X只为中文说明便利，不冒充源本符号。现代A/E/I/O及拉丁式名是后设检索标签，不是本章原有名称。结论方向是“X是否为N”，不能把N、X随意交换。

| 位置 | 已读内容与论证动作 | Owen印页 |
|---|---|---|
| 26b34–39 | 第二格的中项作为两端项的共同谓项；界定大项、小项与其排列位置，中项置于两端项之外且列在前 | 89–90 |
| 27a1–5 | 本格无“完善”推论，但能形成全称或非全称推论；两前提全称时必须一肯一否 | 90 |
| 27a5–9 | M不属于任何N、M属于所有X；把全称否定换位，归第一格，得无X是N（现代EAE-2/Cesare） | 90 |
| 27a9–14 | M属于所有N、M不属于任何X；先换位否定，调为第一格，再换位结论（现代AEE-2/Camestres） | 90 |
| 27a14–18 | 上述结论也可归谬；有效但“不完善”，因展示必然性还用到原初假设之外的步骤 | 90 |
| 27a18–23 | 两全称肯定、两全称否定均不保证端项间的所求结论；给成对替换词例 | 90–91 |
| 27a23–25 | 全称前提情形的必要条件与排除小结 | 91 |
| 27a26–32 | 一全称一特称时，大项侧须全称、两前提异质，才有特称否定结论 | 91 |
| 27a32–36 | 大项侧E、小项侧I：换位E并归第一格（现代EIO-2/Festino） | 91 |
| 27a36–27b3 | 大项侧A、小项侧O：暂假定所有X为N，就会迫出所有X为M，与原假设矛盾；“有些不”及“并非所有”两写法（现代AOO-2/Baroco） | 91–92 |
| 27b3–8 | 若反而小项侧全称、大项侧特称，异质也不成所求推论；给两个成对例组 | 92 |
| 27b9–23 | 同为否定、大项侧全称（E/O）无所求推论；讨论若额外要求小项一部分属于M、一部分不属于M，为何某种全称端项配置取不到；转而利用“有些不”并不排除“全无”的未定范围 | 92–93 |
| 27b23–28 | 同为肯定、大项侧全称（A/I）亦不成立；引用前段的未定范围理由 | 93 |
| 27b28–35 | 全称落在小项侧，同为否定（O/E）或同为肯定（I/A）都不成立，分别给成对词例 | 93 |
| 27b36–39 | 两边特称，肯定/否定的各类组合、非全称和不定写法，均无所求端项推论；给共同词例 | 93 |
| 28a1–9 | 双向总结：所列配置足以且是相应推论的必要配置；本格皆“不完善”；补入必要转换或归谬假设来完成；本格只得否定结论，含全称与特称 | 93–94 |

“无三段论”在这些排除段落中是所求端项关系未被前提必然决定，不是前提必定假、不能写出一句结论或完全没有任何逻辑后果。“不完善”也不是无效：本章专门给有效的转换与归谬证明。归谬的临时假设是待撤销的证明手段，不是许可凭空添真前提。

三元组按(M,N,X)列出；“肯定配置/否定配置”意为同类前提可分别配合不同端项关系，并非承认由那些前提推出表中那行端项关系。

三处差异都是实物层面的观察，不是作者意图或版本源流的归因。可检视的1831页底装置没有把这些位置的“数→石”“单位→石”“石→雪”登记为这种替换；例如27b7的装置是周边措辞差别，不是把μονάς校成λίθος。没有查遍其他传本、Owen所用希腊底本或编辑手稿，故不作“唯一正确原文”式裁断。

## Owen全部本章出版装置

**编号脚注共8条，均为Owen层，非古代原文。**

- p90 n1：亚里士多德在各格分别定义三项；提及Cicero等人对中项的称法。
- p90 n2：解释“项为全称”的省略表达；强调ὅρος不宜直接当作前提。
- p90 n3：两全称前提中无论哪一个否定，另一个须肯定。
- p90 n4：解释“必然”为必然结论，并说明syllogism可指推论/推断。
- p91 n1：解释一肯一否；评论Taylor的术语译法，并引Hamilton。此处批评是Owen的，不是亚里士多德。
- p92 n1：对“同质”的翻译作评论，比较Taylor与Buhle。
- p92 n2：以归于Taylor的说明解释“不定”之所以未定，是未说明谓属仅在部分成立还是普遍成立；不能误读成现代量词恒等命题。
- p94 n1：本章末句脚注，指向Whately、Aldrich、Hill以及Lambert；第二格用于差异、第三格用于例外等说法在此是后世评论，不可作为本章原作者对AI的论断。

**边界排除**：p89页底的前章例7及脚注1、2，标记落在I.4结束句，尽管其下同页已开始I.5，仍不属于I.5。特别是页底谈几何图式、第四格、Galen等，不可误归I.5脚注。p94脚注2的“展示个例”附于I.6，亦排除。

**展开例式共10组**，页边的Ex.号码与页底的实际位置跨页：
- Ex.1在p90，示双A的实体/动物/人和石两配置；正文引用在p91。
- Ex.2在p91，示双E的线/动物/人和石。
- Ex.3在p91，示O/A的乌鸦两配置；正文引用在p92。
- Ex.4在p91，示I/E的石与知识；正文引用在p92。
- Ex.5在p92，黑/雪/动物。
- Ex.6在p92，白/天鹅/**石**；正文引用在p93却写**雪**。
- Ex.7在p92，以天鹅/鸟/白作两栏排列，左栏含“有些鸟不白”与“所有鸟是天鹅”的试置，右栏配合“所有天鹅白”推出所有鸟白；它服务于不可能配置/前述理由，不应当成一个新的有效第二格推论或古代正文例词。
- Ex.8在p93，O/E：动物/乌鸦与石/乌鸦两配置。
- Ex.9在p93，I/A：动物/雪与动物/天鹅两配置。
- Ex.10在p93，用括号选择肯定/否定的特称前提，配人及无生命物两个配置。

**边注**有五个编号概要（p89–90的1；p90–91的2；p91的3；p92的4；p94的5），另有p90对one的说明、p92的希腊术语、p93对them的说明和Ex.1–10引号。尤其第3概要只列“major A or E / minor I or O → O”，单独取出会误成四种笛卡尔组合皆有效；正文明确要求异质，只有E/I和A/O。发表时必须保留限制。

**ERRATA的有界核验**：完整看过PDF第18页，其三条只指印页219、273、594。其中273项在页边注说明里把“syllogistic”改为“asyllogistic”；594项的页码原件就是594，虽不在本册现有印页范围内，本次不替它臆改页码或扩查另一卷。89–94页没有列入这张表。可发表的结论是“所核勘误表未列本章更正”，而不是“本章没有错误”或“已穷尽全部更正传统”。
