# 欧几里得《几何原本》VI.19：相似三角形的面积比为什么是边比的平方？

> AI 数学与形式推理前史补读。年代位置约公元前 300 年；实读 1908 / 2008 版。这里选读可核对的证明结构，不是穷尽古代数学，也不把古典几何定理称作 AI 论文。

## 1. 书目、异文与问题

- Euclid, *Elements*, VI.19。T. L. Heath, *The Thirteen Books of Euclid’s Elements*, 卷 II（Cambridge University Press，1908），正文印刷页 232–233，附论校注见页 234；参见 [Heath 正文](https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/19/) 与[附论校注](https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/19/commentary.html)。
- Richard Fitzpatrick, *Euclid’s Elements of Geometry*（2008），[希英对照版](https://u.cs.biu.ac.il/~margolis/Euclidean%20Geometry/Euclid%27s%20Elements.pdf)，页 175–176。与 [Clay 的希腊文及 Heath 英文](https://www.claymath.org/library/historical/euclid/files/elem.6.19.html)（手稿叶 108）及 [Joyce 分步文本](https://mathcs.clarku.edu/~djoyce/elements/bookVI/propVI19.html)交叉核对。
- **文本差别**：Clay 网页英文止于附论标题；希腊文保留附论及一段方括号内的解释。Fitzpatrick 保留附论而不载那段解释。Heath 报告了“图形／三角形”等异读，并转述 Heiberg 的编辑判断；不把某一版本的取舍当作确定的作者原意。希腊 Γ、Ζ、Η 在此分别对应英译的 C、F、G；CB 和 BC 在比例里是同一无向长度。未将网页漏文当作古本勘误。

上篇 [VI.18](euclid-elements-vi18.zh-CN.md)回答的是如何在指定底边上造出相似多边形；现在问两个已经相似的三角形怎样比较面积。一个底边长 4、另一个长 6，面积的变化既不是 2:3，也不是把 2:3 的数值乘 2。难处在于两块原三角形通常不同高，不能直接套“面积比等于底边比”。欧几里得不是先量出两个高，而是**造一个与第二个等面积、与第一个同底线且等高的第三个三角形**。

## 2. 原文证明重建：先造桥，再比较

取非退化相似三角形 ABC 和 DEF，顶点对应 A–D、B–E、C–F。相等的角在 B、E；其两侧是 AB、BC 与 DE、EF。用方括号记非负几何面积，这里所有三角形的面积均正。

1. **造第三比例线段。** 由 [VI.11](euclid-elements-vi11.zh-CN.md)，取 BC、EF 的第三比例 BG。把 G 放在从 B 经过 C 的射线上，连 AG。这个位置同时保住夹角和底边所在的直线。

$$
BC:EF=EF:BG
$$

2. **把对应边的比例改写成反比条件。** 已知 AB:BC = DE:EF。用 [V.16](euclid-elements-v16.zh-CN.md) 交替比较，得到 AB:DE = BC:EF；再用 [V.11](euclid-elements-v11.zh-CN.md) 串联上一步，得到 AB:DE = EF:BG。注意右侧是 EF:BG，不是 BG:EF。ABG 和 DEF 的夹角相等，[VI.15](euclid-elements-vi15.zh-CN.md)的反向结论因此给出面积相等。没有得到全等，也不要求这两个桥接三角形相似。
3. **从面积回到底边。** ABC 和 ABG 的顶点都是 A，两个底边在同一直线上，故到该直线的垂距相同。用 [VI.1](euclid-elements-vi1.zh-CN.md)从面积比换到底边比，再将等面积的 DEF 换入（Joyce 标注 V.7）。

$$
[ABC]:[DEF]=[ABC]:[ABG]=BC:BG
$$

4. **识别平方比。** V.Def.9 将三个连续成比例的量中第一项对第三项的比，称为第一项对第二项之比的平方比。至此，原证明已完成；无需把长度化为数值再做乘法。以上四步对应 Clay 希腊文的构造段、反比等面积段及同高和末尾结论段。
   
   **点序是构造条件，不是额外结论。** 图上 G 可以画在 B 与 C 之间，但只有 EF 比 BC 短时才在其间；EF 较长时 G 在 C 之外；两底相等时 G 与 C 重合，两个比较中的三角形仍非退化。不能把 G 任意放在反向射线上：那可能把夹角换成补角，失去原证明直接调用 VI.15 的条件。

## 3. 现代重构：精确计算桥接点

令 p、q 分别是 BC、EF 的正长度。把 B、C 设为 (0,0)、(p,0)，令 A 为 (u,h)，其中 h 非零。教学模型可把 E 置于坐标原点、F 置于 (q,0)，取 D 为 (qu/p,qh/p)。这是把 ABC 整体按 q/p 缩放；把 DEF 再平移、旋转或反射并不改变通常的面积。第三比例要求 p/BG = (p/q)²，G 的横坐标是 q²/p。

$$
[ABC]=\frac{p|h|}{2},\qquad [ABG]=[DEF]=\frac{q^2|h|}{2p},\qquad
\frac{[ABC]}{[DEF]}=\left(\frac{p}{q}\right)^2
$$

这个推导显示为什么桥接三角形不是简单缩放 ABC：它只移动底端 C 到 G，保留高；原 DEF 则同时缩放底和高。两种不同变换恰好得到同一面积。现代行列式写法还说明反射为什么不影响命题：有向面积变号，无向面积不变。这是分析扩展，不是对古代证明使用坐标或行列式的历史主张。

**手算例。** B=(0,0)，C=(4,0)，A=(1,3)；E=(0,0)，F=(6,0)，D=(3/2,9/2)。取 G=(9,0)，确实超过 C。三个面积依次是 6、27/2、27/2；6 除以 27/2 得 4/9，不是 4/3。AB 与 DE 之比是 2:3，EF 与 BG 也是 2:3；若误读为 BG:EF，右侧会成 3:2。若改为 q=2 而保留第一块，G 的横坐标是 1；若 q=4，则 G=C。

**反例：面积比不能反向验出相似。** 只把 D 改为 (0,9/2)，保留 E、F 不动。底高和面积 27/2 都没变，面积比仍等于某对底边比的平方。但新的三角形在 E 处直角，ABC 没有直角（分别在 A、B、C 检验两条邻边向量的点积均非零）。所以相似能推出面积比；面积比加一对边长，一般不能推出相似。

## 4. 附论、使用范围和读史限度

原典的附论说：若 x:y=y:z，那么在第一、第二线段上作相似且对应边摆放一致的图形，二者面积之比是 x:z。**用来画图形的底边是 x 和 y，不是 x 和 z。** 例如连续成比例的长度 4、6、9，在 4 和 6 上作图形，面积比是 4:9；9 是表达比值的第三项，不是第二张图的底。VI.19 直接证明的是三角形，较宽的“图形”读法要到 [VI.20 原文](https://www.claymath.org/library/historical/euclid/files/elem.6.20.html)才得到一般相似多边形的证明。Joyce 索引还给出了后文调用该附论的例子，如 VI.22 和 VI.31。这里不提前把那些命题算作已完成。

书内的前件关系是明确的：VI.11 提供构造，VI.15 提供保面积替换，VI.1 比较同高图形，第 V 卷提供比的变换规则。把它与形式推理相联系，是说可将“整体结论”拆为若干有前提的规则，再引入可消去的中间对象，把两种局部关系串起来。这是今天的教学视角，不声称它直接启发了某个 AI 系统。非退化和匹配正确的对应边始终必要。古典比论不要求长度都是有理数；下列实验只覆盖可精确枚举的有理数样本。

## 6. 复盘与练习

抓住这条链：第三比例定位置，反比给等面积，同高把面积比换成底边比，定义识别平方比。

1. p=9、q=6，G 在何处？答：BG=36/9=4，故在 B 与 C 之间，原三角形的面积比是 9:4。
2. p=5、q=10 时，为什么不能为了把 G 留在线段 BC 上而把 BG 取成 5？答：连续比例要求 BG=20；取 5 会让前后两比成为 1:2 与 2:1，桥接面积不成立。
3. 若 h 为负，能否直接取 ph/2 作古典面积？答：不能；这会给带符号的现代量，普通几何面积应取绝对值。反射不改变面积比。
4. 把 DEF 换成同面积的任意三角形，为什么不影响最后的数值，却不能用它重走整个论证？答：等面积允许最后代换，但替换后未必与 ABC 相似，起点的对应角和边比可能不成立。
5. 连续成比例的线段为 2、3、9/2，在前两条上作相似且对应底边分别为 2 与 3 的三角形，面积比如何写？答：2:(9/2)=4:9；若改用 2 与 9/2 作底，面积比变成 16:81。
