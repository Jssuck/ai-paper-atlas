## 数学接口核查

1. 目标是等底、同一对平行线之间的平行四边形等积，不是同底命题。I.34 提供 FG=EH；结合已知 BC=FG 得 BC=EH；I.33 对同向对应端点连接提供 BE∥CH。EBCH 因此是合法辅助平行四边形。
2. 两次 I.35 的共享底分别是 **BC** 和 **EH**。第二次不能误说成 BC，也不能把 FG 与 BC 的等长当成同一条线段。最后用相等量传递，正文没有借用后续三角形面积命题或底乘高公式冒充原证。
3. 非退化和端点次序是模型前提。跨图顶点重合可合法：同底退回 I.35，上边重合使辅助图形成为原图形。交叉误接则不是该平行四边形。正文对分离、相接、交叠的说明没有把线段位置分类混同成整个多边形的不相交分类。
4. 正文参数 a、f、e 是独立的；源码以 A−B 为横截向量，故其 s=e−a、t=f。该换参不遗漏初始图形剪切。独立探针另外直接生成 a、f、e，不调用原 `cases.build`，覆盖平移、斜底、反向底、正负定向与各端点位置。
5. 行列式等式是现代教学证明，不是原文证明；它依赖双线性使底方向剪切项消失。有限有理样例无法证明所有实数配置，也不能证明欧几里得公理系统的完备性。
6. 手算主例面积 6、桥接向量 (4,3)、不同侧边长度及各反例成立。交叉例独立计算两对角线中点均为 (1,3/2)，交叉边界鞋带有向和为零；这个零不应称为合法平行四边形面积。

## 代码与攻击核查

公开验证入口为 `make_certificate` / `verify_certificate`，不是供教学使用的裸 `area` 函数。前者先检验完整八点输入、两个有向平行四边形、同向等底、上下共同支撑线和非零行列式，然后才生成证书。非法几何直接抛出 `ValueError`；给非法输入套用非空合法证书也返回 false。

输入只允许精确内置整数或规范有理数字符串、恰有八个键的内置字典及二维内置列表。布尔、浮点、Fraction 实例、整数/容器子类和非规范字符串均被拒绝。证书只含字符串、列表、字典；重新计算后进行规范 JSON 比较，绑定规范化后的完整坐标输入。相同有理值的两种合法表示不是几何篡改；换成同面积但不同坐标的输入必须拒绝。证书不是密码学签名或外部可信证明，仍依赖本地验证代码。
