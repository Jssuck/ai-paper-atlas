## 1 原文与现代重构的界线

独立对读材料包括：Bekker 1831 印24页 I.1全章及相邻页脚、标作1837本来源的完整希腊电子章文、Owen1853印80–82正文及八条页内脚注。Owen81页原则树实际目验；其译编注释归属没有转移给古代作者。另直接打开并有界阅读[Pickard-Cambridge译《论题篇》I.1开头](https://classics.mit.edu/Aristotle/topics.1.i.html)，核对原章的自引。其网页现代标示的成书年没有作为本报告的年代证据。

逐块核验结果：

| 原文范围 | 核验结论 |
|---|---|
| 24a10–16 | 研究围绕论证及论证性知识；定义次序确有前提、项、推论、完善性和全称述谓。正文没有把开头升级为完整科学知识论。 |
| 24a16–22 | 全称、特称、未定量及两个未定量例句均有依据。例句没有被当成在此处已证明的伦理或科学断言。 |
| 24a22–28 | 论证取矛盾一边，辩证问答提出矛盾选择；用于推论时共享肯定或否定某物的形式。形式共通没有被误写成根据相同。 |
| 24a28–24b12 | 推论前提、论证前提、辩证前提的地位与 Topics 自引被分开。真实不是科学论证的唯一资格；endoxa没有被改写成统计概率。 |
| 24b12–15 | 原文保留更精确说明；正文没有抹去这一范围限制。 |
| 24b16–18 | 主谓项与肯否联结分开；词项不是单个字符或现代 token。主项在前是本篇的符号约定。 |
| 24b18–22 | 不同的结果、必然性、通过所设者、外在项均有覆盖。现代后承只重构其中一面；未冒称与完整古代定义等价。 |
| 24b22–26 | 完善性关乎显示必然性所需的辅助环节；不完善没有等同无效，代码行数没有冒充历史判据。 |
| 24b26–30 | P述谓所有S被重构为S⊆P，方向正确；没有与物理部分关系混同。 |

本章 syllogismos 的一般定义没有被强制限定为恰好两前提、三词项。主文新增的明示说明与希腊定义中未规定这种数量的事实相符。有关“不同于”“通过这些”的实质新颖性、相关性和历史解释没有被简单的语法重复或依赖索引检测替代。

《论题篇》开头确实区分由真实、首要起点或从这些起点获得的前提出发的论证，与由普遍接受的意见出发的辩证推理；接受者类别包含众人、多数人或智者群体中的相应范围。主文的概括没有把这些类别缩成数值可信度。本报告只核该有界比较，不将《论题篇》另计为完成的历史单位。

## 2 现代模型的全部关键假设

以下是结论成立的合同，不是亚里士多德原章已经写出的公理表：

1. 使用经典二值集合语义；论域非空，可有限或无限。
2. 每个稳定的词项名表示论域中的一元子集。不同名称允许同外延，主项与谓项也可为同一名称。
3. 原子输入仅限 A、E、I、O；主项在前、谓项在后。
4. A、E只禁止反例，不默认产生存在见证；个别词项默认可空。
5. I、O各要求至少一个对象；“某些”允许包括全部，没有暗含“但非全部”。
6. 另行指明的非空项集合限制允许解释，不从“论域非空”推导所有项非空。
7. 现代后承对所有符合政策的解释量化；重复、冗余、空前提列和不可满足的前提列均不会被其定义自动排除。
8. 数学压缩论证针对固定有限个一元词项；实现刻意限制为1–3项。公式不计数，没有额外的个体常量、二元关系、模态、概率或自然语言消歧。
9. 证书只使用公布的有限规则和已声明前提。语义检查与证书检查是两种任务；没有自动搜索或完备性承诺，也没有给显式非空政策增加一条证书存在引入规则。
10. 输入词义与现实对象的对应、前提事实真假、首要性、公认地位、历史完善性和“真正通过这些”仍需别的证据。

这些假设在主文和模型说明中已公开，没有发现为使例子通过而临时隐藏存在条件或偷换主谓方向的情况。

## 3 逐步证明与具体反例

### 3.1 全部主要推导

- A(S,M)、A(M,P) ⟹ A(S,P)：任取同一个S对象，两次包含传递。S为空时仍有效，但没有存在结论。
- E(P,M) ⟹ E(M,P)：交集对称；再与A(S,M)得到E(S,P)。这是从原有条件得到辅助句，未增加事实。
- I(S,M)、A(M,P) ⟹ I(S,P)：保留第一个前提的同一见证，不能拼接两个不同存在对象。
- O(S,P)、A(S,M) ⟹ O(M,P)：同一S\P见证沿主项包含向M传播。
- O(S,M)、A(P,M) ⟹ O(S,P)：若原见证属于P便由包含属于M，与其不属于M矛盾。
- I(S,M)、E(M,P) ⟹ O(S,P)：见证同时在S、M；不相交保证它不在P。这是模型说明中的实际证书规则之一。

六种二前提模板及E对称均独立证明，并以独立脚本遍历所有1–3项支持和全部词项替换，包括重复词项。无需添加“所有项非空”的条件。主文更广的O传播规则没有被冒称为全部已实现；README明确列出实际子集。

### 3.2 主文每类数值例子

| 条件 | 独立真值结果 |
|---|---|
| S=P={1} | I真、A真、O假；“有”不排除“所有” |
| S={1}、P={2} | O真、I假；O不蕴涵I |
| S=∅、P={1}、D非空 | A和E真，I和O假 |
| S={1}、P={1,2} | A(S,P)真，A(P,S)假；对象2反驳逆向 |
| S={1}、M=P={2} | A(S,M)假、A(M,P)真、A(S,P)假，不反驳该模式的有效性 |
| S=M={1}、P={2} | 已给A(S,M)真，目标A(S,P)假，拟补A(M,P)也假 |
| S={1,2}、P={1} | O(S,P)真，O(P,S)假，E(S,P)假 |
| A(S,P)与O(S,P)并列 | 不存在同时满足它们的模型；经典后承空泛成立 |

主文两对象反例没有被叫作最小反例；允许空项时，A或O非法换项可以有一对象反例。正文是为易读而选例，数学上不需要误称最小。

配套报告另用S={1}、M={2}、P=∅展示“两前提均假、结论假”；中文走查已明确它与主文“假、真；假”的例子不同。新增的具名对象例子将主文对象1、2映为类型1、6，正确。A非法换项例将对象1、2映为类型3、2，排序支持为(2,3)，也正确。对象标签与类型编号没有再混淆。

## 4 类型压缩及计数的独立证明核验

对任意解释M，令H为实际出现的k位成员类型。D非空推出H非空；全0类型必须允许。建立新解释时直接以H为论域、以相应位为1的类型为每项外延，不需要从无限原域挑选代表。

A的反例恰为主项位1且谓项位0的已出现类型；O的见证也恰为同一种类型。E的反例与I的见证恰为两位均1的已出现类型。项非空恰为至少有一个已出现类型在该位为1。因此所有允许原子命题及非空政策在压缩前后同值，前提合取和后承反例也保持。反过来，每个非空H都由上述构造实现。

这给出对任意论域，包括无限论域的结论：若后承失败，就有至多2^k个对象的有限反模型。程序有限遍历的充分性依赖这项证明，不能单从实跑规模归纳出来。

计数独立核对：

- 所有非空支持为2^(2^k)−1，k=1、2、3分别是3、15、255。
- 两项全非空：15−3−3+1=10。
- 三项全非空：255−3×15+3×3−1=218。
- 两项仅要求一项非空为12；三项要求一项非空为240、指定两项非空为228。

全0类型不会被删除；H与加入全0类型后的支持可能对本语言所有命题取值相同，这种冗余枚举不破坏证明。报告的数目是支持数，不是互不等价的理论数、所有标签模型数或概率。

最小性也须分层：若按支持大小从小到大枚举，首个反例的r种类型可用r个对象实现；若有少于r个对象的反例，其支持至多少于r，矛盾。故这一排序能得到对象数最小反例。但当前实现按支持掩码数值升序，主文已明示不承诺这种最小性。独立数学脚本中的最小对象数来自另一套按大小枚举的检查，不是为生产程序补发的性能保证。

压缩不能保持“至少两个S”：单个S对象与两个同类型S对象有同一H，却使计数句取值不同。主文据此限制语言，正确。
