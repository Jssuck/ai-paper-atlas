## 2. 逐项数学审查

| 核验项 | 审查结论与边界 |
| --- | --- |
| 证明三要素 | 所证结论、公理、对象属没有误当作三段论三项 |
| 共同逻辑反模型 | P真而Q假，若没有连接前提，不能从共用逻辑推出Q；论证有效 |
| 几何/审美反模型 | 固定几何解释、改变未被几何前提约束的附加谓词，正确展示缺少逻辑后承；不推出审美永远不可研究 |
| 立方乘积 | 整数结合律与交换律允许(m³)(n³)=(mn)³；8×27=216正确 |
| 立方和反例 | 1³+1³=2非整数立方；没有偷换成一般倍立方构造问题的证明 |
| 相对保真归纳 | 基步要求事实真；后继步同时要求前提真及所用材料蕴涵真；没有把类型检查当成真理判据 |
| 假桥反例 | 声明P→Q可以通过结构检查而在P真Q假的解释下失败，正确说明定理前提被破坏而非定理被反驳 |
| 闭包后承证明 | 对有限正单前提系统，闭包赋真、其外赋假构成满足全部已接受规则的反模型；不推广到带否定、量词或不一致理论 |
| 无桥隔离 | 每步普通/共同规则域不变，按路径长度归纳正确；多域初始事实与跨域推导被明确区分 |
| 桥声明限制 | 名称、方向、源与目标谓词均精确；不自动形成现实科学的上下级关系或真理认证 |
| 范围与类型 | 模型只对所示Atom/Rule/Bridge等对象及有限完整原子域运行，不是任意不可信序列化输入的解析器或安全沙箱 |
| 原文与实现层次 | 原文允许从属科学，不等于作者提出此字符串类型系统；正文保持该边界 |

## 3. 独立实跑

独立脚本：[audit/independent_check.py](../../reproduction/aristotle-posterior-analytics-i7/audit/independent_check.py)。没有调用生产的`semantic_entailments`或`enumerate_checks`作为判断依据。

从复现目录运行：

```bash
python3 audit/independent_check.py
python3 -O audit/independent_check.py
python3 -OO audit/independent_check.py
```

三个模式各**8项测试通过**。实际日志：[普通](../../reproduction/aristotle-posterior-analytics-i7/audit/tests-normal.log)、[-O](../../reproduction/aristotle-posterior-analytics-i7/audit/tests-O.log)、[-OO](../../reproduction/aristotle-posterior-analytics-i7/audit/tests-OO.log)。全部检查使用unittest方法，不依赖会被优化删除的assert语句。

每模式覆盖：

1. **2304政策案例**：三域、两谓词、64桥登记集合、36有序原子对。预期由直接位表产生；同域采用common分支，与生产枚举的local分支互补。
2. **1024规则/桥/事实组合**：每组合枚举16布尔赋值。根据四条固定语义边及桥位独立选择规则，不调用生产`allowed`过滤，核对生产closure所得后承。
3. 假的跨域桥通过形式证书、却不保真这一限制的显式见证。
4. 普通/共同规则跨域、反向桥、错误属性、错误桥名均不被接纳。
5. 顺序证书可成立，前向、负、布尔、浮点、字符串索引及错误源引用被拒绝。
6. 无种子循环不产生事实，有种子双向桥循环只产生可达原子。
7. **289整数乘积案例**，m、n各取−8至8，全部符合立方乘积等式；另核8×27及立方和反例。这是教学公式的有限防错检查，一般等式仍靠运算律证明。
8. 同域规则也可能不真实，程序不认证它；没有推导时不能凭目标名称宣称得到目标。

生产的22项测试和2304/1024枚举记录在复现目录，独立8项不可与之混称30项生产测试。生产真值oracle共享allowed函数的限制已由README明确披露；本次独立固定边oracle减少这一共同失误来源，但仍只是有限输入族核验。
