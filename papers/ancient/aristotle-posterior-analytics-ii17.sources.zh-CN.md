# 《后分析篇》II.17：来源台账与章界核验

## 版本和实际阅读范围

- Aristotle，*Analytica Posteriora* II.17，通行Bekker位置 **99a1–99b8**。这是公元前四世纪逻辑与科学解释前史补读，不是现代AI期刊论文；不据章号推定实际写作先后，不声称选读穷尽历史。
- Immanuel Bekker编，*Aristotelis Opera*，第一卷，Berlin，1831，印99页。[原页扫描](https://archive.org/download/aristotelisopera01arisrich/page/n114.jpg)。已实际目视左右栏与页底校记；第17章从左栏第1行起，第18章标题在右栏第9行，故本章包含99b7–8的多中项末句。见到校记不等于完成全部抄本或异文研究。
- Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol. I，London: Henry G. Bohn，1853，印 **349–352页**。[原版PDF](https://archive.org/download/Aristotles_Organon_vol_01_1853/Aristotles_Organon_vol_01_1853.pdf)。已将PDF第368–371页渲染并实际阅读：349页中部章题开始，352页上部在第18章题前结束。正文、页边摘要和脚注分别处理，不把译者注释当作亚里士多德原句。
- [Boyer第二卷希英对照](https://aristotle.johnhboyer.com/APo/book/2/#ch-2-17)：已读取本章完整希文转录及Mure英译相关段落。该载体标注希文为Ross（OCT，1964），英译Mure（1928）；这只说明载体的底本声明，不表示已独立检查Ross印本全部校勘。

## 证据地图

| 原文位置 | 阅读要点 | 解析限制 |
|---|---|---|
| 99a1–7 | 问同一性质可否在不同对象上有不同原因；先限定自体证明与征象、偶然论证 | 不能把条件句改成“一切现实结果只有一个原因” |
| 99a8–16 | 线与数的交替比例，颜色与图形的相似，以及类比关系 | 同属、同名异义、类比不是同一层级；颜色例有试探语气 |
| 99a16–29 | 性质超出每一种而与相关种的全体等范围；外角、落叶、定义与中项 | “所有种”须在适当对象范围内，不是把任意有限样本的并集当科学普遍性 |
| 99a30–99b3 | A/B/D形式结构，区分一般普遍与首要普遍；另在E组寻找C | 后段A较B更广，不能与此前等范围设置无条件合并；形式有效性不自动建立解释方向 |
| 99b4–6 | 同一性质可以有多个原因，但对象并非同种；举古代寿命解释 | 无胆汁、干燥等是历史例证，不是本文核实的现代动物学结论 |
| 99b7–8 | 未立即达到直接前提且中项不止一个，原因也不止一个 | 这是本章结尾；关于哪一中项最近的下一章答案不在本次完成范围 |

## 分章、译词和勘误

### 1. 章末两行容易被英译分段遮住

Bekker99页、Owen352页及Boyer的希文分章都把99b7–8归入第17章。Boyer载Mure英译却把相应条件句接在第18章开头，与下一问构成一个英语长句。因此本次按Bekker边界覆盖该末句，同时注明英语分段差异；不能只截取网页的英文“第17章”而漏读。下一章仍从99b9开始，未计为本轮完成。

### 2. 普遍不处处等于等范围

99a33–35专门区分一种较宽的“普遍”用法与首要普遍：前者可以比某个种更广，后者与相关种的全体相称。Owen的脚注和正文也提示量的范围。现代集合式可以帮助拆解这些关系，但不能据词面把所有“普遍”替换成集合相等。

### 3. 后段范围论证存在需要保留的张力

99a36–37把A较B更广与原因方向相连；而本章前段、上章均允许某些因果说明中项与结果等范围。解析应明确不同讨论设置，且承认仅凭外延包含无法证明“谁解释谁”。可以展示其形式骨架，但不应冒称已用集合论消除了古代文本所有解释困难。

### 4. 植物例的译法并不完全一致

99a29的连接处表达，Owen译文涉及种子的连接，Mure译文具体化为叶柄与茎的连接。希文转录有σπέρματος。正文可以使用“连接处树液凝结”的概括，并注明差异；不宜无说明把某一译法当作精确现代植物生理事实。古代解释中“或其他类似情况”的保留也不能删去。

### 5. 网页转录与印本勘误应分开

Boyer所载英文外角例中有“triangle or are”的明显残缺；Bekker相应希文为τετράγωνον，Owen译为square。解析据扫描保留三角形与四边形的对象对照，不照抄残缺网页文字。已实际目视Owen卷首ERRATA，列项涉及印219、273、594页，未列本次349–352页；这不等于所有版本都没有其他错误。Bekker页底有异文校记，本文不宣称穷尽考据。

## 前驱、同期问题与历史关系

- 同书[I.4](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-4)的自体与普遍性问题，是本章区分种与相称范围的书内背景；这属于论证关联，不据此虚构成书年代。
- [I.13](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-13)及[II.16](aristotle-posterior-analytics-ii16.zh-CN.md)区分事实推知与原因说明，本章继续追问相同谓词是否对应相同中项。
- [II.8](aristotle-posterior-analytics-ii8.zh-CN.md)和[II.10](aristotle-posterior-analytics-ii10.zh-CN.md)讨论定义与原因，[II.15](aristotle-posterior-analytics-ii15.zh-CN.md)区分共享、同属和从属中项，构成本章最近的概念背景。
- Owen350页边注把比例涉及的增大解释为乘法，并参照Euclid第五卷。那是1853年译者的对照说明，不能改写为亚里士多德引用欧几里得，更不能把后来的《几何原本》当作本章前驱证据。
- 本章的几何、植物、动物例显示古代论证所选对象，但不提供现代式同期实验、样本、基线。本文不编造未能定位的前驱作者或直接影响链。现代类型检查与分组解释只是教学延伸，而非古代已提出机器学习因果识别。
