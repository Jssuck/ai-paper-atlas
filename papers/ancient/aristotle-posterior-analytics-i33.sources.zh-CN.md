# 《后分析篇》I.33：来源、译差与证据定位

## 1. 本次对象与实际核读范围

对象为 Aristotle, *Analytica posteriora*（《后分析篇》）第一卷第33章，**88b30–89b9**。I.32止于88b29，I.34从89b10起。本篇是公元前4世纪知识论与逻辑前史补读，不是现代AI论文；1831、1853、1928、1964是所用版本年代，不是古代章节的写作年份。这里列出实际核读的材料与限制，不声称穷尽传本或学术争论。

- [Boyer 希腊文／Mure 英译对读页](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-33)：实读I.33全章与章节边界。页面注明希腊文据W. D. Ross, Oxford, 1964，英译据G. R. G. Mure, Oxford, 1928。此处读到的是数字转录，**不是Ross纸本校勘栏**。
- [Bekker 1831 卷一扫描](https://archive.org/details/aristotelisopera01arisrich)：实看[印88](https://archive.org/download/aristotelisopera01arisrich/page/n103.jpg)右栏末段、[印89](https://archive.org/download/aristotelisopera01arisrich/page/n104.jpg)左栏及右栏开头，并检查两页页脚校勘条目。正文、异文记录与解释分层，不补造校勘字母所代表的抄本身份。
- [O. F. Owen, *The Organon*, vol.I, 1853](https://archive.org/details/Aristotles_Organon_vol_01_1853)：实看印页**312–315**（PDF第331–334页），包括本章首尾、边注及脚注。312页下半开始I.33；315页中部另起I.34，后者不纳入本篇主任务。另实看卷首ERRATA（PDF第18页）：表中更正针对印219、273、594，没有312–315；**这只表示该表未列本章，不证明所有版本均无错误。**

扫描PDF、原文全文和全文译文只用于研究核验，不随原创解析公开上传。全文阅读主要由公共领域的Bekker及Owen扫描复核，现代网页作为检索、定位和版本对读入口。

## 2. 全章论证与证据地图

| 位置 | 论证动作 | 必须保留的限定 |
|---|---|---|
| 88b30–35 | 知识及其对象区别于意见及其对象；以普遍性、必然性与不能另样为起点，排除可另样者成为此种严格知识的对象 | 这里不是现代所有经验性、概率性知识的无条件定义；实际为真不自动等于必然 |
| 88b35–89a4 | 排除这里所说的理智及非论证知识，转向对非必然直接命题的意见 | 直接性与必然性不是同一属性；“直接”不可译成仅凭感官或无心理加工 |
| 89a4–10 | 意见的不稳定与对象性质相应；人把不可另样的把握称为知道，把可另样的把握称为意见 | 关于“以为自己知道”的描述不能当作“自信便真的知道”的充分条件 |
| 89a11–16 | 提出难题：二者可能沿同一串中项直到直接前提；意见也能涉及事实及所以然 | 不能把意见一律定义为无推理、无中项或毫无解释 |
| 89a16–22 | 回答依靠对前提／属性的把握方式：作为不可另样、按本质和形式把握，与仅当作真实相区别 | 具有相同推理链不保证相同认识地位；知道一个口头理由不自动成为严格知识 |
| 89a23–33 | 用真／假意见的“同一对象”类比，分开共同讨论对象与所断言的内容；给出对角线可公度例 | 共同的对角线不使“可公度”同时成为真意见与假意见；不能偷换对象同一为命题同一 |
| 89a33–37 | “人／动物”例：同是人，但动物的归属被当作本质的、不可另样的，或不是如此 | 这里重点是述谓的归属方式，不是说某只动物可以存在或不存在的一般生灭问题 |
| 89a38–89b6 | 排除同一个人在同一时间、就同一事如此既知又持意见；不同的人可以分别如此 | 不应推广成“同一个人永远不能从意见转为知识”或“知识排斥现代广义信念” |
| 89b7–9 | 将思想、理智、知识、技艺、实践智慧、智慧等的进一步分类交给自然及伦理研究 | 本章没有给出所有认知能力的完整分类，也没有完成现代认知科学理论 |

## 3. 译差、校勘和误读风险

1. **ἐπιστήμη 与 δόξα。** Owen以science/opinion表述；Mure的scientific knowledge亦有时代译语色彩。本文用“严格的论证性知识／意见”提示语境，不把前者简单等同于现代科学共同体的全部成果，也不把后者等同于任意广义belief。88b35处νοῦς明确由作者在这里规定为知识的起点，不能直接替换为现代计算智能。
2. **89a1 的“真”。** 紧接的89a2已经允许意见涉及真或假。因此不能因为前句将意见与理智、知识并列，就写成“一切意见都为真”。两种英译对列举句的处理也不宜提升为穷尽所有心理状态的现代定理。
3. **89a8–11附近的异文。** Owen印313边注记录κωλύειν／κωλύει的差别；又说明Taylor与Buhle在“怎样可能同一对象既被意见又被知道”处添οὐκ，而Waitz、Bekker省去。本文按所读正文将此段处理为待解难题，不把某一增字后的问句当作无争议定论。
4. **89a17–18附近。** Owen印313边注记录问句／补足“是否应当说”的处理；Boyer希腊转录把ἔχει置于方括号。Bekker印89左栏及行18校勘项也显示该处有读法处理。本文只依段落整体的“如何把握”对照作解释，不声称独立解决该处句法或重建全部抄本。
5. **89a30 的对角线。** Bekker正文可见σύμμετρον（可公度），页脚行30列ἀσύμμετρον（不可公度）的异文记录。Owen印314及Mure所读英译均把例子处理为：真地认为对角线与边可公度是荒谬的。教学正文采用这一共同可读论证，但不把所列异文抹去，也不拿单一异文推翻全段的对象／断言区别。
6. **89a33–89b6 的人／动物。** Owen印314的英语存在容易使读者联想到动物自身存在与否的表达；须连读印315对“人本质上是动物”的澄清。Mure更明确地把它表达为动物属性的归属方式。中文应将其放回同一主体的本质述谓，避免翻成“知识认为动物必然存在，意见认为动物未必存在”。
7. **译者注释不是古代原文。** Owen印313引用Aldrich、莎士比亚《奥赛罗》、Butler；印314把一段关联到Protagoras及智者，并引用Mansel、Hill等；印315注释对διάνοια的译法作讨论。这些是后世译者／编辑的阐释或书目，不是亚里士多德在本章点名的作者、戏剧或现代心理例证。尤其不能仅依据该脚注断言本章唯一论敌是谁。

## 4. 实读的前驱与内部背景

- [Plato, *Meno*, Jowett英译](https://classics.mit.edu/Plato/meno.html)：实读通往Larisa的正确向导、真意见与知识的行动效用，以及Daedalus像与原因之系的段落（通常定位97a–98a）。前驱问题是：同样作出正确引导，为什么还要区分意见和知识？它提供问题背景，不意味着I.33逐句引用《美诺篇》，也不证明“多给一个理由”就是两部作品共同采用的充分条件。原文同时涉及回忆论，不能只截取“原因”而删去这一语境。
- [《后分析篇》I.2](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-2)，实读71b9–33及72a5–22：原因、不可另样、真而直接等知识条件；作者明确区分真正知道和自以为知道，并指出形式上的三段论不一定构成知识性的证明。对角线可公度也在71b25–26出现，不是本轮自创的古代案例。
- [《后分析篇》I.6](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-6)，实读74b5–75a17：本质归属、必要前提、非必要中项得必要结论，以及把非必要误当必要时只是自以为知道。它直接约束本篇：真结论、相同结论或推理形式有效，不足以证明具有严格知识。
- I.33自身给出对角线与人／动物两类例子，横跨数学对象与本质述谓；本篇不据此为古代不同学科、机构或文化编造影响力排序。章次用于阅读定位，不能独立证明各章写成的时间顺序。

以上是有限选择的来源链，不是全部前史目录。柏拉图与亚里士多德的文本关系仅按实际可见问题相似与内部论证定位陈述，不声称已经穷尽同期观点或建立唯一影响链。

## 5. 对教学重构的约束

命题真值、模态状态、主体／时刻索引、解释链标签、有限模型及程序测试均属现代教学重构，不是原文已经给出的算法。模型应区分：对象事实上必然、主体把它当作必然、其理由是否真的支持本质或原因。若仅用一个布尔标签把“认为必然”直接叫做知识，便遗漏I.2与I.6明说的错误自信。有限穷举只能核验声明的有限模型，不能证明本章全部认识论主张，更不能由此声称已形式化人的全部知识或现代AI的理解。
