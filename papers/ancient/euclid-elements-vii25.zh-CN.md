# 欧几里得《几何原本》VII.25：为什么平方不会破坏互素性？

> AI 数学与形式推理前史补读。约公元前 300 年的古代算术，实读 1908／2008 版。由现代论文主线回看推理前史，不是 AI 论文，也不声称穷尽前史。

## 1. 书目与问题

- Euclid, *Elements*, VII.25。T. L. Heath, *The Thirteen Books of Euclid’s Elements*, 卷 II，Cambridge University Press，1908，[印刷页 326–327](https://archive.org/details/thirteenbookseu01heibgoog)：326 页下有题设、图和主要步骤，327 页上收证并附脚注与评注。
- Richard Fitzpatrick, *Euclid’s Elements of Geometry*（2008 修订），[希英对照，印刷页 214–215](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=214)。对读 [Clay 希英文本及第 140 叶入口](https://www.claymath.org/library/historical/euclid/files/elem.7.25.html)与 [Joyce 在线本](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII25.html)。版本范围见[原典核对](../../reproduction/euclid-elements-vii25/source-review.zh-CN.md)。

8 与 15 互素，为什么把 8 自乘成 64，仍然不会和 15 产生共同约数？从现代符号看，把 [VII.24](euclid-elements-vii24.zh-CN.md) 的两个因数都填成 8 就够了。原文却特意造了一个等于 A 的 D。这个标号使证明中容易被略过的步骤清晰可查：**两个因数的位置可以填同一个数，但各自与固定比较对象互素的条件仍须核对。**

## 2. 对象与条件

| 原文标号 | 现代记号 | 角色 |
|---|---|---|
| A／Α | $`a`$ | 被平方的数 |
| B／Β | $`b`$ | 保持不变的比较对象 |
| C／Γ | $`c=a^2`$ | A 自乘得到的积 |
| D／Δ | $`d=a`$ | 给第二个乘法位置的同值副本，不是新选的公因数 |

[卷 VII 定义 12](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII11.html)以“仅单位共同量尽”表示互素。需要 A 与 B 互素；不要求 A 是质数，更不要求 A 与 D 互素。A 大于 1 时，A 本身恰恰就是 A 和 D 的非单位公度。图中的 A、D 是两个标号，同值由正文指定，不靠测量图上长度证明。现代模型使用正整数；1 是现代边界，原书区分“单位”和“数”。

## 3. 原证：同一个数填入通用命题的两个位置

1. **设立目标。** 已知 A 与 B 互素，让 A 自乘生成 C，欲证 C 与 B 互素。Heath 印 326 页下、Fitzpatrick 214 页末至 215 页开头。
2. **复制数值，转移谓词。** 令 D 等于 A。A 与 B 互素，且 D=A，于是 D 与 B 也互素。若某数能同时量尽 D 与 B，凭 D=A 就能同时量尽 A 与 B；这说明等值替换为什么合法。
3. **实例化 VII.24。** 通用命题的两个因数位置填 D、A，固定对象位置填 B；所需的是 D 与 B、A 与 B 的两个条件。它只要求这两条，不出现 D 与 A 互素或 D 与 A 不同的条件。
4. **识别输出。** 得到 D×A 与 B 互素。D=A，所以 D×A 正是开头所定义的 C。得到的结果是 C 与 B 互素，不是对两个因数之间关系的断言。

| 可核查主张 | 证据位置 |
|---|---|
| A 自乘生成 C | Heath 326 页命题开头；Fitzpatrick 214–215 页过页 |
| 令 D 等于 A；分别对 B 互素 | Heath 326 页下段；Fitzpatrick 215 页图下 |
| 使用 VII.24，再认出 D×A=C | Heath 326 页末注引与 327 页顶部；Fitzpatrick 215 页末段 |
| 题句的省略及此证属特例 | Heath 327 页脚注和评注，须与原正文分开读 |

题句的希文说由两数之一“生成”的数，Heath 327 页说明这里省略了“与自己相乘”，而设例明说自乘。Fitzpatrick 在题句中用括补提示平方，不能因此把平方解释成额外的独立命题。Clay 英栏止于辨认积为 C 的一步，希栏、两印本和 Joyce 都保留显式的互素结论。这里复核的是列明版本，不以未见正式勘误断言所有版本均无差异。

## 4. 教学建模：为什么两个参数可同值

将 VII.24 现代化为对任意正整数三个位置的定理：

$$
\gcd(x,t)=1\ \land\ \gcd(y,t)=1
\quad\Longrightarrow\quad \gcd(xy,t)=1.
$$

代入 $`x=d`$、$`y=a`$、$`t=b`$，其中 $`d=a`$。第一前提由同值替换给出，第二前提直接来自已知。乘积 $`xy=da=a^2`$，所以 $`\gcd(a^2,b)=1`$。注意这不是再次证明 VII.24，而是检查其**参数是否恰当**。同一个已知条件可以满足两个同值位置；它没有因此变成两份独立证据。

另一个方向也成立，但依据不同：若平方与 B 互素，由 $`a\mid a^2`$ 和 [VII.23](euclid-elements-vii23.zh-CN.md) 可推出 A 与 B 互素。这是现代合读，不表示 VII.25 单独陈述双向等价。并且“是否互素不变”不等于任意情况下最大公约数的数值不变。

| 算例或反例 | 读出什么 |
|---|---|
| 8、15；取 D=8 | 两个因数位置都为 8，64、15 互素；8 和自身并不互素 |
| 6、15；取 D=6 | 题设不成立。6 与 15 共约数 3，平方 36 仍和 15 共约数 3 |
| 4、8；取 D=4 | 最大公约数由 4 变成 8，但平方前后都不互素；不要把判定不变说成数值不变 |
| 1、15 | 在现代正整数模型中 1 的平方仍是 1，结论直接成立；不把程序的历史非单位输入约定强加到所有现代整数上 |

## 6. 复盘与练习（含答案）

复盘：**复制数值，不复制一个新假设；对固定 B 查两条前提，不查 A 与 D 互素；最后认回平方。**

1. **A=14，B=25，四个标号怎样填？** 答：D=14、C=196；A 和 D 各自与 25 互素，196 与 25 互素。
2. **能否把 D=8 换成 D=7，对 A=8、B=15 完成原证明？** 答：VII.24 能证明 56 与 15 互素，但 56 不等于 64；缺少最后的同一输出步骤。
3. **若程序要求两个因数数值不同，会漏掉什么？** 答：恰会漏掉本命题的对角代入 D=A；这个约束不在 VII.24 里。若误要求 A、D 互素，也会拒绝所有大于 1 的同值副本。
4. **已知 81 与 20 互素，能推出 9 与 20 互素吗？** 答：可以，由 9 量尽 81，直接用 VII.23。这不是把 VII.25 的蕴含无条件倒转。
5. **只用“对一个数平方”反复操作，能直接证明三次方吗？** 答：不能；从一次方开始反复平方得到指数 1、2、4、8 等。另用 VII.24 把平方和一次方相乘才可得到三次方。
