# II.22：来源、章界与校勘台账

本台账服务于[原创中文深读](aristotle-prior-analytics-ii22.zh-CN.md)。公开内容只含书目链接、原创说明及必要定位，不附原典扫描、未许可 PDF、全文译文或私人执行信息。

## 1. 原作和年代口径

- Aristotle，*Analytica Priora / Prior Analytics*，《前分析篇》第二卷第二十二章，**67b27–68b7**。这是公元前四世纪古代逻辑著作的单元，不是现代期刊论文；本次接续 II.21 作前史补读。
- 下列 1831、1853、1913 均为版本年份，不用于推定单章精确写作年。作品内部章节次序不是逐章发表年表。不声称覆盖所有前驱、同时代工作或历史影响。

## 2. 实际阅读的版本

### S1. Bekker 希腊文印本：章界与字母的原典定位

Immanuel Bekker 编，*Aristotelis Opera*，vol. I，Berlin，1831，印页67–68。

- [整卷扫描](https://archive.org/details/aristotelisopera01arisrich)
- [印页67扫描](https://archive.org/download/aristotelisopera01arisrich/page/n82.jpg)
- [印页68扫描](https://archive.org/download/aristotelisopera01arisrich/page/n83.jpg)

本次视觉核对两页：II.22 标号在67b27，II.23 标号在68b8；II.22 到68b7终止。正文持续到爱情、欲求和技艺的目的说明，不只读开头换位公式。核对两页页下注异文栏及关键字母位置，不声称独立校勘全部手稿或建立新希腊文定本。正文解释主要以以下两英译互校，并明确标注现代重构。

### S2. Owen 1853：全章扫描与译注

Octavius Freire Owen 译，*The Organon, or Logical Treatises, of Aristotle*，vol. I，London: Henry G. Bohn，1853。

- [全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)
- 本章：印页 **228–230上部**，该PDF第247–249页（按1起算）。实际逐页阅读正文、边注、脚注以及下一章标题；没有把机器OCR当作唯一证据。
- 印228章题强调第一格两端换位，但该题不能替代全章范围。
- 印228脚注1–6说明否定段的 Celarent／Camestres 路线，特别是由小前提的肯定反向与结论的否定换位组成的推导。
- 印229脚注1明说互补证明已展示一向，另一向证明相同而省略；正文第6节明确补足两向。
- 印230脚注1把爱情例联系柏拉图《会饮篇》。这是译者说明，不是亚里士多德本章直接点名的出处；本单元未把这一类比扩写成已证实的借用关系。

**正式勘误：** 本次亲读全卷 ERRATA 页，列印219章题、印273边注和印594章题三个条目，没有列本章印228–230。这个有限结论不等于“本章绝无文字问题”；下列译注校读及不同章界仍需单独记录。

## 3. 校读与章界差异：不能用程序决定版本

| 位置／注号 | 译注处理 | 本文怎样使用 |
| --- | --- | --- |
| 注90，67b27–32 | 将肯定段写成数个全称三段论 | 逐步重建以C、A分别作中项的两条反向包含 |
| 注91 | 把否定关系换位列成演算 | 解释为排斥对称，不写成外延相等 |
| 注92，67b37 | 依 Pacius 读 τῷ Α τὸ Β，替代较短字样 | 明确这属于译者采纳的校读，不假装所有版本字母完全一致 |
| 注93 | 从否定结论加全称肯定反向恢复否定大前提 | 现代重构显式给出 B 包含于 C，不由 C 包含于 B 偷得逆向 |
| 注94，67b39 | 补入 καὶ τὸ Β 等字样 | 说明“C 对 A 及 B 的转换”须区分否定、肯定关系 |
| 注95，68a1 | 依所列抄本／注家读 τὸ Α、τὸ Γ | 对照印本位置，跟随译注解释此句；不据计算裁定抄本优劣 |
| 注96 | 给出从换位结论与换位小前提的演算 | 正文以独立两步元素证明呈现可恢复条件 |
| 68b8起总结句 | Jenkinson列II.23开头；Owen列II.22末，旁注Waitz在此前结束章 | 正文采用Bekker67b27–68b7章界，兼读过渡句，不隐去分章差异 |

另一个可见编排差异：关于生成／毁灭的例子在 Owen 印229出现在第二个互补论证之后，Jenkinson 与 Bekker68a把它放在先前的对应项替换说明后。本文按论证所需条件解释这个例子，不利用位置差异制造不同的历史结论。

## 4. 主张—证据位置—教学责任

| 正文主题 | 原文依据 | 额外解释由谁负责 |
| --- | --- | --- |
| 两端同延迫使中项同延 | 67b27–32；Owen228上；Jenkinson注90 | 现代集合符号、允许空集合，是本文重构 |
| 否定换位及恢复大前提 | 67b32–68a3；Owen228及注；Jenkinson91–96 | 不交、同延、补集三分由本文明示，不声称希腊文仅有一种技术用法 |
| 严格二分及另一半等值 | 68a3–16；Owen228–229 | 两向元素证明与删假设反例为原创教学 |
| “仅 B、C”与“除 A 自身” | 68a16–21；Owen229中 | A=B∪C为限定的对象外延重构，并未消除词项自述谓层次问题 |
| 共同属性加反向覆盖 | 68a21–25；II.23在68b23–25回指 | 有限共现不能推出总体全称的例子为现代分析 |
| 相反项与组合偏好 | 68a25–39；Owen229下 | 对称可加效用是充分模型，非原文数值理论 |
| 爱情与目的应用 | 68a39–68b7；Owen229末–230上 | 不作经验普遍事实；目的推断另有实质承诺 |

## 5. 前驱、同期及后继的收录边界

本单元优先记录能由原文核实的同书关系：第一卷的换位及三段论规则、本章到II.23归纳结构的明确回指。I.2书目回指不改变该任务暂缓状态。Owen提及《会饮篇》只列为后世评注线索，未把它当成本章正文引文或完成了一篇额外前驱深读。没有充分原典证据时，不以作者名气推断影响，也不声称不存在其他同期传统。

对现代 AI 的联系仅限原创教学推论：规则的方向类型、覆盖条件、逆向推理和偏好识别的隐藏假设。没有把这条说明写成古代逻辑直接导致某现代算法的因果史。
