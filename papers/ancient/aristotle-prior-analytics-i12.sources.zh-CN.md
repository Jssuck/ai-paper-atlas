# 《前分析篇》I.12：原文、章界与译注账本

## 1. 阅读对象和版本

### 必须保留的章界差异

Bekker原图在32a15开启一个新段，先总结关于必然推理的讨论已足够，再于32a16–17转向可能性；章号13排在该段第二行旁。Owen将前一句总结置于I.12结尾，I.13才从可能性开始。因此本单元读完Owen的完整I.12时，也有界读取了**Bekker32a15–16的过渡句**。这不意味着I.13正文已读完。本项目不能把Owen的排章与Bekker的数字范围无说明地当成完全一致。

## 2. 原章主张与位置对照

| 位置 | 实际读到的内容 | 解释边界 |
|---|---|---|
| 32a6–8；Owen107开头 | 对实然与必然推理作对比：前一种需要两前提属于相应情形，后一种在仅一前提必然时也可能成立 | 是对先前式的回顾，不是“只要任意一个前提必然就足够”；数量、质量、项位条件不能删除 |
| 32a8–10；Owen107中上 | 肯定、否定推理都要求至少一个前提与结论相似 | 随后的解释指定的是模态相似，不是字面相同，也不是同一真假值 |
| 32a10–12；Owen107中段 | 解释相似：结论实然，对应前提实然；结论必然，对应前提必然 | 条件是至少一个，不是两者全部；不能倒转成充分条件 |
| 32a12–14；Owen107下半 | 无必然或实然前提，就没有相应必然或实然结论 | 在该文本的推理分类语境内理解，不能未经限定推广为任意现代逻辑系统的定理 |
| 32a15–16过渡句；Owen107末句 | 必然推理如何成立及与实然的差异，已有足够讨论 | 属章节收束/过渡，不是宣布所有模态逻辑问题解决；Owen将其置于I.12，Bekker排入新段 |

本表只作解释性概括。程序、可能世界、证明证书、现代反模型均是另外署名的教学重构，不倒署给古代作者。

## 3. Owen全部附属材料

本章有**两条编号页脚注、一个编号主边注、一个星号边注**，无编号展开例式、无图表。

1. 标题后的脚注1讨论模态与纯直言逻辑的研究对象，回指前注，并提及Edinburgh Review第118号、Kant《Logik》第30节、St. Hilaire序言和Whately。Owen主张逻辑学家关注形式后承，并报告可把模态附于词项从而作纯命题表达的观点。这是译者的十九世纪论述，不是亚里士多德正文；本轮没有独立阅读这些被引著作，不认证其报告的完整性或直接影响链。
2. 开头“being present with”之后的脚注2把相关情形解释为直言推理中，要得到肯定结论，两前提须肯定。它是Owen给出的解释，不应抹掉；也不能因此把整章的实然/必然区分简单替换为肯定/否定区分。
3. 编号边注1概括绝对与必然结论对前提的依赖及关联；它是译编导航，不是额外原文命题。
4. “both”之后的星号边注解释为纯推理与模态推理。它明确此处不是“两个前提”的both。

### 开头的翻译/解释张力

Owen正文开头使用de inesse和“being present with”，脚注2却诉诸肯定前提及肯定结论。希腊核心又在后文明确同时谈肯定与否定推理。故须把正文的模态类别、命题质量和译注解释分开记录。本轮不把脚注解释当成已证唯一古义，不据此武断宣布原文矛盾，也不把现代“必然蕴涵实然”的弱化原则无条件倒灌为作者分类规则。正文应在明确语义和推理范围后，才讨论现代重建成功或失配。

## 4. 校勘与勘误

已实际目验Bekker印32页底整段装置。左栏装置列第5、17、25、26、27、40行等异文；**没有针对32a6–14核心章的条目**。第5行属上一章结尾，第17行已涉及后续段落，不作为I.12核心修正。这里没有发现的含义仅限本页所印装置，不等于不存在其他版本或后世校订。

Owen本卷ERRATA页列印219、273、594三处修正，**没有印107条目**。因此开头脚注的解释张力与章界差异不称为官方勘误，亦不据它们擅改原图文字。没有独立检查所有后版、手稿、古代注释或Taylor/Buhle/Waitz全本。
