## 2. 完整章界及主张位置

| Bekker 范围 | 原文工作 | 解析时须保留的条件 |
|---|---|---|
| 95a10–21 | 因由作为中项；存在、生成、已经生成、将生成的形式相应；月食、结冰示例 | 结冰的“热完全缺失”是古代例示前提，不是现代热力学事实；不将其改写成实测结论。 |
| 95a22–24 | 上述这类原因与结果同时 | 限定“这类”，因为紧接着就问非同时情形。 |
| 95a24–95b1 | 从后发生者推先前者；不能仅由先前完成就断言后来已经完成；将来及中项的同类形式问题 | 区分事实发生次序、推知次序和解释次序；不宣布所有预测不可能。 |
| 95b2–12 | 完成之事之间、已完成与正在生成之间的相接难题；点、线、连续过程类比 | 原文将更充分讨论留给运动通论；不能把有限离散图的无环性当作对此问题的证明。 |
| 95b13–25 | 以较近现在的后件为推知起点，通过中项推出较早者；插入中项是否无穷的问题 | 此处“原因”不能未经区分就解释为后来的事件造成过去；95b24–25 存在关键异文，见下节。 |
| 95b25–37 | 将来情形与造屋、地基、石料例；提出直接起点 | 所取建筑方式的必要前提，不是所有建筑技术的普遍自然律。 |
| 95b38–96a7 | 中项及两端互相随从时，循环生成与推理；水分、蒸汽、云、雨例 | 这是条件性的互相随从；类型再现不同于同一事件倒流，不批准无根据的循环证明。 |
| 96a8–19 | 恒常／普遍与多半如此；男性长须例；两前提普遍便推出普遍结论 | 可重建必要的逻辑限制，不能据此断言两条多数关系任意传递，也不能引入未经给定的概率独立性。 |

## 3. 足以影响解释的版本差异

### 3.1 95b24–25：有中介还是无中介

Bekker 1831 的 95b25 印 **ἀπὸ μέσου**；相应页脚还记录 D 本的 **ἀπὸ τοῦ μέσου**。Boyer 所转录 Ross 文本此处为 **ἀπ’ ἀμέσου**。Owen 印刷页 338 正文采用 *immediate*，但边注明确说明这是 Waitz 的读法，而 Taylor、Buhle、Bekker 作 *mediate*。

因此，不能把“无穷插入问题已经由无中介前提彻底解决”写成所有版本一致无疑的原文结论。教学重构若采用直接前提作为链起点，须明说所取读法及模型假设。与此同时，95b15 的 **ἄμεσα** 以及 95b35–37 的直接起点讨论仍在；不能因这一处异文，反过来删除全章一切无中介前提。

### 3.2 95a37：同类不必等于同时

希腊文 **ὁμόγονον** 在此连接已发生／将发生等相应形式。Owen 印刷页 337 用“同时生成”的措辞，Mure 则强调中项与两端同类。应对照后文“已发生对应已发生、将发生对应将发生”理解，避免把本来专门讨论非同时事件的段落解释成所有中项必须同时发生。

### 3.3 96a8–19：长须例的对象与量词

希腊文使用 **ἄνθρωπος ἄρρην**（男性），Mure 作 man；Owen 印刷页 339 的 *vigorous man* 增加了“强健”语感。解析以原文对象辨认例子，不据此另筛“强健男性”而改变统计分母。原文没有概率参数、样本数据、独立性假设或抽样规则；现代有限集合例只用于揭示量词边界，不是古代生物学命题的验证。

## 4. 前驱问题、同一思想体系及范围边界

- [《后分析篇》I.2–3](https://classics.mit.edu/Aristotle/posterior.1.i.html)：实际阅读其“直接、在先、原因”的知识条件，以及无限后退和循环证明讨论。这提供 II.12 的问题背景；解释在先与我们据以推知的起点未必相同。I.3 对无条件循环证明的限制应与本章循环过程并读。
- [《物理学》VI.1](https://classics.mit.edu/Aristotle/physics.6.vi.html)：实际阅读连续、接触、相继的区分，及线、时间、运动不可由彼此紧邻的不可分者构成的讨论。II.12 95b10–12 的运动通论交叉提示支持此联系。此处只建立论题联系，不据篇章排序声称两书确定的写作先后。
- [《物理学》II.9](https://classics.mit.edu/Aristotle/physics.2.ii.html)：实读房屋材料、锯与假设必要性的段落（Part 9）。它明确区分实现目的所必需的条件与这些条件足以产生目的；用于核验正文的比较，不将材料例直接提升为现代建筑定律。
- [Plato《Phaedo》98b–99d 希英转录](https://viachrista.org/Library/Archer-Hind_Plato_Phaedo.html)：实读苏格拉底留在狱中的选择与骨骼、筋腱等条件的区分，特别是 99a–b。该前驱问题只支持“原因与不可缺条件须区分”的比较；不证明本章逐项借自 Plato。
- 本卷 II.11 已从多种原因与中项的关联展开；II.12 的推进在于时态、时间间隔、循环与“多半如此”。这是同一著作的衔接，而非声称各章是分别发表的现代研究论文。
- 本次原文未点名一位同期竞争作者来支持这些特定论证。故不为凑齐影响谱系而臆造“直接受某人影响”或优先权；对后世时态逻辑、事件图或概率推理的联系只能作为现代教学比较，不是已证实的历史传承。
