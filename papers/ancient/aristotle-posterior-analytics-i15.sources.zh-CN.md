# 《后分析篇》I.15：来源与证据范围

## 1. 书目与阅读单元

- 作者：Aristotle（亚里士多德）。作品：*Posterior Analytics*（《后分析篇》），第一卷第15章，**79a33–79b22**。年代按公元前四世纪作品处理，不指定未经证实的单一写作年；收录的是古代著作中的完整章节，不称现代AI论文。
- Immanuel Bekker编，*Aristotelis Opera*，vol. I，Berlin，1831，印页79。[扫描书目](https://archive.org/details/aristotelisopera01arisrich)；[印79页图](https://archive.org/download/aristotelisopera01arisrich/page/n94.jpg)。实际查看双栏页图及章号、行号：I.15自左栏33行开始，止于右栏22行；I.16从79b23起。
- Octavius Freire Owen英译，*The Organon, or Logical Treatises, of Aristotle*，vol. I，London: Henry G. Bohn，1853，印279–280。[扫描卷](https://archive.org/details/Aristotles_Organon_vol_01_1853)。实际阅读印279的Chap. XV标题至印280的Chap. XVI标题之前；对应该扫描PDF第298–299页。印279上部属于I.14，印280下部已进入I.16，均未混入本章。
- G. R. G. Mure英译，*Posterior Analytics*，Book I，Part 15，[MIT Internet Classics Archive文本](https://classics.mit.edu/Aristotle/posterior.1.i.html)。用作独立英译对读，不把网页发布年份当古代文本年份。
- [Graeco-Arabic Studies希腊正文](https://www.graeco-arabic-studies.org/view/arist.analytpost-orig-gr1)，第15节。该站标注底本为Bekker，Oxford，1837，卷I，182–257页。它不是上述1831版页图的逐字转录；本篇的Bekker行界依据1831页图核定。

## 2. 逐段证据地图

| 位置 | 可由原文支持的主张 | 对应深读部分 |
|---|---|---|
| 79a33–36；Owen印279章首 | 肯定与否定都可无中项；“atomic”的定义是中项缺席 | 第1、3、4节 |
| 79a36–79b5；Owen印279末及280初 | 在一端的上属项与另一端分离时，可通过肯定包含和否定前提推出全称否定 | 第5、6节 |
| 79b5–12；Owen印280上部 | 不交叠谓述系列使一端的上属不覆盖另一端成为可能 | 第7节 |
| 79b12–20；Owen印280中部 | 两端都不在整体中时，假设存在中项会要求至少一端有肯定包含；第一、第二格的前提结构构成反证 | 第8节 |
| 79b21–22；Owen印280章末 | 总结直接否定的可能性及其条件 | 第12节 |

“所有A都是C”并不单独证明A和B分离。原文在上述第二段实际使用“C不属任何B”这一全称否定前提；自然语言中的“不在整体中”不能无条件替换为现代集合式B不包含于C，再将其当成不相交。深读明确给出的有限集合反例是教学重构，用于检验这个更弱的误读，并非原文实例。

## 3. 版本、边注与勘误核查

1. 实际查看Owen卷首**ERRATA**。所列更正涉及印219章题、印273边注和印594章题；其中273把“syllogistic”改为“asyllogistic”的条目不属于本章。该表没有印279–280的更正。此结论只说明查到的这张勘误表，不声称所有版次或研究文献不存在其他修正。
2. Owen印279第二个例子的边注写Cesare；正文排列为“A不属任何D，D属所有B”。按深读采用的主谓项序可重建为第一格Celarent；将全称否定前提换位后也能写成第二格Cesare。因而本文明确给出关系式和换位，不把边注论式名直接当成亚里士多德正文。首个例子可以按第二格Camestres读出。
3. Owen印280底部“实体—物体”等与“性质—颜色”等序列示意，属于**译者脚注**。正文只有字母式不交叠序列。本文的数集、红色/木制对象等例子均自行构造，不冒充作者原例或古代经验数据。
4. 在线1837希腊转录第15节首段“或A或B在某整体中”的条件在页面上有缺字。1831页图包含完整条件；本文不凭缺损转录改动论证，也不把网页转录问题说成古代作者原稿的错误。
5. “atomic”“individually”等译法在本章指无中项的直接性，不是单称命题、物理原子或现代机器指令；英译措辞差异不替代原文给出的定义。

## 4. 历史联系及收录范围

《前分析篇》I.1的“在整体中”及I.4–6的格分类，是本篇论证背景；《后分析篇》I.2的直接前提、I.14的归约终点是同一著作的邻近背景。可从[《前分析篇》第一卷文本](https://classics.mit.edu/Aristotle/prior.1.i.html)及上述《后分析篇》第一卷对照这些章节。这些是文本内部关联，不是已证明的写作时间顺序或影响谱系。

本篇作为推理前史的年代回溯补读，既不将其称为第一篇AI论文，也不将图灵1936–1937样稿称为第一篇AI论文。不声称穷尽古希腊前驱、同时代研究、古代注释传统或现代诠释文献。没有足够来源支持的直接影响关系不作断言。

## 5. 原文、教学与实验的边界

- 原文：无中项的定义、两方向包含—排除推理、不交叠系列、第一与第二格的反证结构。
- 教学重构：现代集合记号、逐元素证明、命名论式、数值实例、双否定及第三格反模型。
- 分析推论：任意补集或同义项不能自动提供科学解释、开放世界数据库及知识图谱的设计启示。这不是把现代系统倒写进古代著作。
- 真实运行：只按[复现附件](../../reproduction/aristotle-posterior-analytics-i15/README.md)的代码、命令、环境和日志确认。有限枚举核查实现，不证明一般定理；给定词表未找到中项不证明实质或绝对直接性。一般有效性由深读的逐元素推导支持。
