审查对象为[深读正文](aristotle-prior-analytics-ii21.zh-CN.md)的证明、反例、七题答案，以及[教学实现与真实日志](../../reproduction/aristotle-prior-analytics-ii21/README.md)。审查独立通读 Jenkinson II.21 全章；历史版本与校勘范围由另份来源审查负责。本报告不把发布后远端核验或网页公式显示当作已完成的技术审查步骤。

## 结论和修订

**通过本单元限定范围的技术审查。** 修订后区分“不能推出 D 与 A 不交”与泛指任何关于 D 的否定结论：前三个前提其实足以推出 D 与 C 不交，所以原先较宽说法须缩窄。正文把“失败测试”改称非法输入与缺前提的拒绝测试，避免与实际测试失败混淆；实现测试名也不再把调用生产真值函数的检查称为独立验证。上述修正已复核。另核最终 59 处行内公式仅调整 GitHub 定界写法：逆向还原定界后全文哈希与已审旧稿完全相同，数学内容未变；本报告不据此声称最终网页显示已经核验。

## 数学与解释边界

1. 四全称承诺加 D 非空给出同一个见证既在 A 又不在 A；“有些 B 不是 A”需要存在见证。空 D 反模型正确，不能把现代空类允许性倒推为古代语义。各集合可相等，不要求词项外延互异。
2. 缺第四桥接前提的二对象反模型中 A=B=D 为一个单元素类，C 为另一个单元素类，前三项真而第四项假；它证明剩余承诺可共同满足，不表示任何缺桥心理状态都真实发生。
3. 同链包含的任意对象证明和全称实例化加肯定前件的推导正确。对象存在、分类识别、规则适用及实际合用分别表述，没有把客观可导误当实际完成认识。
4. 知识侧前提必须真；否定意见可以假，不因此成为知识。未记录、记录否定和已执行推导不是同一状态。固定真世界的记录模块并不假定全部后果自动进入实际运用记录。
5. 合用后的冲突报警保留错误意见用于诊断，不把两项相反断言同时称为真知识，也不宣称人可稳定保持该冲突。程序不推断心理概率或自动修正机制。
6. 善恶段的等式传递只是明示解释下的教学推理，不把意见默认设为无条件演绎闭包。正文保留尾段的试探性及偶然用法，未把已同指的 A、C 之同一当作善恶本质同一的证据。
7. 七题答案分别与存在条件、缺桥模型、识别/合用区别、潜在/已运用后果、事实性、等式/意见区别及有限检验边界一致。

## 独立实跑及可复算证据

另写 [`audit/independent_oracle.py`](../../reproduction/aristotle-prior-analytics-ii21/audit/independent_oracle.py)，不调用生产世界生成器或生产前提求值函数来生成预期答案。独立方法先枚举每个对象的 16 种四属性布尔型，用命题条件逐对象判断四前提；仅在比对阶段调用生产接口。对 1、2、3 对象共 4368 个世界，四项真值逐一相同。

计数还有独立闭式核查：四前提允许四种局部型且都没有 D；缺 p4 允许五种局部型，其中四种没有 D；单正路径或单负路径各允许八种局部型，其中六种没有 D。因此分别核对四前提空 D 的 4 的 n 次方、缺桥非空 D 的 5 的 n 次方减 4 的 n 次方、单路径非空 D 的 8 的 n 次方减 6 的 n 次方。生产输出全部吻合，三个返回缺桥反模型也经直接逐个成员检查而不是生产求值器验证。

- normal、`-O`、`-OO` 三模式独立脚本各通过，三个 `oracle-*.json` 逐字一致。
- 独立复跑生产 12 项 `unittest`，三个模式分别全部通过，真实日志为 `audit/recheck-{normal,O,OO}.log`。
- 另检查含“已合用”位的全部 16 个布尔组合：10 个满足状态约束、6 个非法组合被拒。核验可调用性、报警、原状态不可变、保留意见和重复调用幂等性。
- 另检验 8 类坏世界输入、非法论域大小、真假识别与非法识别参数、非布尔旗。错误明确抛出 `ValueError`，没有用优化会删除的裸 `assert` 承担检查。

运行命令（仓库根目录）：

```sh
cd reproduction/aristotle-prior-analytics-ii21
python3 -B audit/independent_oracle.py
python3 -O -B audit/independent_oracle.py
python3 -OO -B audit/independent_oracle.py
python3 -B -m unittest -v test_epistemic_routes
python3 -O -B -m unittest -v test_epistemic_routes
python3 -OO -B -m unittest -v test_epistemic_routes
sha256sum -c SHA256SUMS
```

有限世界核查和状态组合是有界软件测试；任意论域的双路径不相容由正文见证证明承担。没有据小实验声称完整复现古代认识论、证明人的心理规律或核验现实骡类生物学。
