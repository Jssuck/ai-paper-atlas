# 《后分析篇》II.11：来源台账与解释边界

## 1. 书目与实读范围

Aristotle，*Analytica posteriora* II.11，完整 **94a20–95a9**。按公元前四世纪作品范围收录为AI推理前史补读；它不是独立发表的现代AI论文，1831、1853、1928、1964是版本或翻译年份，不是本章精确写作年份。本单元考察解释类型与证明中项的关系，不声称穷尽古代因果理论或其他文化的推理前史。

- [Bekker编《Aristotelis opera》卷I，1831](https://archive.org/details/aristotelisopera01arisrich)：逐段目视[印94](https://archive.org/download/aristotelisopera01arisrich/page/n109.jpg)左栏章11起至右栏末、[印95](https://archive.org/download/aristotelisopera01arisrich/page/n110.jpg)左栏章12之前；兼核页脚校记。印95章12从95a10开始，不能漏掉本章跨页结尾，也不能把下一章算入本轮完成。
- [O. F. Owen译《The Organon》卷I，1853](https://archive.org/details/Aristotles_Organon_vol_01_1853)：目视印332章XI起至印335章XII之前（PDF第351–354页），包括印332注2、印333–334算例和印335注1–2及边注。核卷首ERRATA（PDF第18页）：列印219、273、594，没有针对本章印332–335的项目；仅说明这张勘误表未列本章，不证明本章绝无印误。

## 3. 版本与解释焦点

### 3.1 第二因与“质料因”的距离

94a21–22说的是某些东西存在时另一东西必然存在的原因。Owen印333边注把它标为质料因，然而正文没有简单改写成“由什么材料制成”。印332注2还讨论数学属性中质料因的地位，并指出本章例子里它与形式因相合；该注引Mansel等后世解释，不能冒充Aristotle自述。

《物理学》II.3把材料、部分以及前提对结论的关系同列于“所由来”的说明，因此传统联系并非凭空捏造。但安全写法是先保留II.11原句，再说明通常与质料/必然条件联系；不能只列四个熟悉标签，掩盖半圆例同时回到本质原因的困难。这也不许可把所有逻辑充分条件直接认证为现实原因。

### 3.2 散步例：两种排列不是凭空倒推

Owen印334显示两种三段论：初始B属于A的范围、C属于B的范围，得C属于A；另一排列以A作中项，由A属于B的范围、C属于A的范围，得C属于B。用现代集合记号分别是C⊆B⊆A，以及C⊆A⊆B。注意希文述谓句“A属于B”意为A谓述所有B，转为外延包含时写B⊆A；这里“属于某范围”说的是集合成员/外延方向，不能与希文述谓语序混用。后一排列需要章内“说明交换”的支持，不能仅凭第一组两个包含关系就推出A⊆B。原文把B称为仿佛A的说明；Owen脚注也明确按该健康说明处理。此处能展示目的进入理由位置的尝试，不能认证其生理前提为真，也不消除预先拥有哪些说明的认识论问题。

另一个不可掩盖的译法差异：94b20–21希文及Owen直问为什么B属于C；Mure改述为为什么B是A属于C的原因。前者更便于追踪换项所要解释的关系。本文采用希文/Owen的提问定位，把Mure视作解释性转述，不将两句当作逐字相同。

### 3.3 兼容不同原因，不等于无限制因果互换

同一事件可以从必要条件和目的两面回答不同的为什么，故灯笼两解并不互斥。原文条件词和毕达哥拉斯派归属必须保留。Owen印335脚注提醒：有木石灰泥并不必然有房屋；他的健康/安全注释援引其他故事作说明，这是译注材料而非本章新增证据。本文不把这些故事转成真实运行数据。

### 3.4 校记与转录限制

Bekker印94页脚可见94a22、25–26、28–35等及94b相应条目，印95页脚有95a1、4、7、9等异读记录。已核章界、关键条件词、末段与这些校记的存在；没有重建抄本谱系。Boyer转录使用的增补括号，例如94a36附近的ὄν及94b32附近的ὅτι，应视作版本呈现差异，不宣称自行确定唯一原始读法。核心解析不依赖这些小词的独断恢复。

## 4. 前驱与同系统对照

- [柏拉图《斐多篇》，David Horan英译](https://www.platonicfoundation.org/translation/phaedo/)：实读97b–99d附近，尤其对Anaxagoras的期待/失望、骨与筋和选择留在雅典的区别。它把行动理由与不可缺少的身体条件分开，为本章多种“为什么”的问题提供前驱对照。这里是问题比较，不声称II.11直接引该段，更不把对话中Socrates的叙述当作Anaxagoras原书的独立保存本。MIT《斐多篇》本次取得的页面止于较早段落，未将其冒称为这一段的实读来源。
- [Aristotle《物理学》II.3、II.8、II.9，Hardie/Gaye英译](https://classics.mit.edu/Aristotle/physics.2.ii.html)：实读四因分类及前提/结论的类比、自然目的与偶然、墙与锯的假设必要性。对照要点是：同物可有不同方式的原因；有材料不等于有成品；结果与目的吻合不保证该过程为了该目的而发生。II.9把推理起点与行动起点区别开来，帮助理解本章生成次序。这里只比较同一作者理论系统，不把卷章排列或现代书目顺序当作确定的写作先后。
- [同书《后分析篇》II.10–11](https://classics.mit.edu/Aristotle/posterior.2.ii.html)：前章把原因说明与证明的表达角色相连，本章扩展原因类型。II.12的时间问题只用作边界定位，不计本轮精读完成。

## 5. 对公开教学实验的约束

集合链可检验给定包含前提的形式有效性；目的标签、事件时间和解释角色的区分可由自有小程序演示。但是标签不是真实因果的证书，有限枚举不证明自然界的普遍目的性，几何数值例不替代一般证明。有关光、雷声、消化和石头运动的原文案例必须作为历史理论读，不作为现代科学复现实验。代码实跑、数学重构、古代文本主张与现代分析应分层记载。本台账是来源核对记录，本身不冒称已执行最终代码或完成终稿审查。
