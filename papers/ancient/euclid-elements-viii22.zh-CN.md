# 欧几里得《几何原本》VIII.22：为什么隔一个整数比例中项，平方性不会丢？

**年代跳转 · 数学与证明方法前史补读 · 深读 v1。** 《几何原本》约在公元前 300 年前后形成。这里只读卷 VIII 命题 22，讨论数论证明如何复用前一命题，不是现代 AI 论文，也不声称存在直接的技术传承。

## 1. 中项可以不是平方

$`4,6,9`$ 的两个相邻比都是 $`2:3`$，端点是平方，中项 $`6`$ 却不是。本命题说的是**相隔两步的端点**：三个正整数依次成同一比，若第一项是平方，第三项也是平方。等差链 $`4,6,8`$ 不适用。也不能只用“两个端点有实数几何平均数”替代原前提：$`4`$ 和 $`2`$ 有实数中项 $`\sqrt{8}`$，却没有整数中项，只有一个平方端点。

**书目。** 欧几里得，《几何原本》卷 VIII，命题 22。对读 [Heath 1908 卷 II，印页 379](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)、[Fitzpatrick 希英对照 p.249](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)、[Clay 希英网页](https://www.claymath.org/library/historical/euclid/files/elem.8.22.html) 和 [Joyce 正文](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII22.html)。[版本核对](../../reproduction/euclid-elements-viii22/source-review.zh-CN.md)记录了正文、编辑引用和英译截断的边界。

## 2. 原典推断：先换表示，再传性质

| 角色 | 记号 | 意义 |
| --- | --- | --- |
| 第一、中、第三项 | $`A,B,C`$ | 正整数，$`A:B=B:C`$，即 $`B^2=AC`$ |
| 第一项的根 | $`s`$ | 给定 $`A=s^2`$，$`s`$ 是正整数 |
| 相似平面数 | $`A=a_1a_2,\ C=c_1c_2`$ | 存在对应因子使 $`a_1:c_1=a_2:c_2`$ |
| 要构造的根 | $`t`$ | $`t`$ 为正整数且 $`C=t^2`$ |

1. **中项给出相似数。** 从 $`A:B=B:C`$ 调用 [VIII.20](euclid-elements-viii20.zh-CN.md)，可以给 $`A,C`$ 各选一对成相同比例的因子。不是说两项碰巧都能写成二因子积。
2. **平方性依赖于边的适当选择。** 平方数是等边积，参见 [VII.定义 18](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII15.html)；相似性参见 [VII.定义 21](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII21.html)。原文直接从相似且一端为平方推出另一端平方，省略了一个表示问题：即使 $`A=36`$，相似分解选中的两条边也可能是 $`3`$ 和 $`12`$，而不是 $`6`$ 和 $`6`$。不能把平方数的**任一**分解都当作两边等长。
3. **现代补步。** 从相似的选定边得 $`A/C=(a_1/c_1)^2`$，所以 $`s`$ 乘 $`c_1/a_1`$ 是 $`C`$ 的正有理平方根。正整数的有理平方根一定是整数：若最简分数 $`m/n`$ 的平方为整数，则 $`n^2`$ 整除 $`m^2`$，互素性迫使 $`n=1`$。现在才可选 $`C`$ 的两条等边。这一段是对省略步的补证，不是希文逐句翻译。

## 3. 直接造根：不是先开方然后猜整数

**教学重构。** 已知 $`B^2=s^2C`$，先在有理数域把 $`B/s`$ 化简为 $`m/n`$。由于 $`C=(m/n)^2`$ 是整数，按上节引理 $`n=1`$。因此 $`s`$ 除尽 $`B`$，而且

$$
t=B/s\in\mathbb Z_{>0},\qquad C=t^2 .
$$

这里整数性来自等式和约分，而不是浮点开方。例：$`36,60,100`$ 给出 $`s=6,\ t=10`$。同一组端点也可取相似分解 $`(3,12)`$、$`(5,20)`$；平方根构造把两对边重新选为 $`(6,6)`$、$`(10,10)`$，没有更改端点。

| 三项（或条件变化） | 核对 | 推断 |
| --- | --- | --- |
| $`(4,6,9)`$ | $`6^2=4\cdot9,\ t=6/2=3`$ | 两端平方，不要求中间平方 |
| $`(100,60,36)`$ | $`60^2=100\cdot36,\ t=60/10=6`$ | 倒序同样成立 |
| $`(8,12,18)`$ | $`12^2=8\cdot18`$ | 两端相似而皆非平方，说明首项条件不可删 |
| $`(4,5,9)`$ | $`5^2\ne4\cdot9`$ | 两端都是平方，也不保证随手取的中项合格 |
| $`(1,3,9)`$ 或 $`(9,9,9)`$ | 第三项的正根均为 $`3`$ | 只用于现代正整数模型的单位与相等边界 |

等端点没有严格位于二者之间的项；第七卷也区分单位与“数”。程序允许这两种现代边界，不据此推断原典已把它们纳入同一语境。

## 4. 证据与可迁移边界

- **原文位置。** Heath p.379 的正文用 VIII.20 后立即传递平方性质，末注说明这是相似平面数的特殊情形；Fitzpatrick p.249 最后引 VII.定义 21。Clay 希文给出平方结论，网页英译停在推出相似平面数处；Joyce 正文保留了结论。
- **实跑。** [代码、Notebook 和日志](../../reproduction/euclid-elements-viii22/README.md) 用整数验证比例、平方前提和返回的根。在 10,000 对有序端点中，构造接受 100 对，拒绝首项非平方但有整数中项的 210 对，以及整数中项不存在的 9,690 对。有限域里的独立直接枚举用于找出遗漏和错误接受，不证明一般命题。无历史实验、数据或性能基准。[独立技术核对](../../reproduction/euclid-elements-viii22/technical-review.zh-CN.md) 区分文本陈述、教学补步和程序证据。
- **现代扩展。** 从长度为 $`m+1`$ 的正整数等比链的第一项走 $`m`$ 步，若首项为 $`m`$ 次幂 $`s^m`$，末项是 $`(sr)^m`$，这里 $`r`$ 是后项除以前项的公比。由于 $`sr`$ 为正有理数，分母约尽后若其 $`m`$ 次幂为整数，则分母只能为 1（$`m`$ 为正整数）。这个推论不表示其他位置也保持 $`m`$ 次幂；三项平方情形已经给出反例。后继立方情形只作为同一思路的阅读方向，并非本命题已证明的陈述。

## 5. 练习与答案

1. 对 $`(49,77,121)`$ 不用对第三项开方，构造其根。  
   答：$`s=7`$，$`77/7=11`$；核对 $`77^2=49\cdot121`$ 后得第三项为 $`11^2`$。
2. 已知 $`(a,b,c)`$ 连续成比例，为什么不能只见 $`a=36`$ 就断言原构造中两因子各是 $`6`$？  
   答：平方提供一个等因子表示，不禁止其他分解。需要重选等边，或者用有理根的整数性补足。
3. 把 $`(36,60,100)`$ 的中项改为 $`61`$，命题是否被反驳？  
   答：没有，$`61^2\ne36\cdot100`$。这是输入违反比例，不是结论为假。
4. 若最后一项是平方而第一项未知，结论如何改写？  
   答：正整数比例链可逆，倒序应用同一个命题，第一项也为平方；这并不要求中项平方。
5. 能否把链的中项 $`B`$ 当成等比增量？  
   答：不能。增长倍率是 $`B/A=C/B`$，而 $`B=s\,t`$ 是两端正根的乘积。

**复盘：** VIII.20 提供对端点的相似表示，VIII.22 转移的是平方性质。写出现代检验时，最容易漏掉的是让有理根落回整数这一小步。
