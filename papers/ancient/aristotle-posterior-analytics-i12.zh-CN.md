# 亚里士多德《后分析篇》I.12：什么问题属于这门科学，什么推理真的成立？

> **前史补读／年代跳转。** 本单元是古代证明论的一个完整章节，不是现代 AI 论文，也不以它为“第一篇 AI 论文”。本系列以可核实的论证关系组织有限选读，不声称穷尽。上一单元为 [I.11：共同公理与证明](aristotle-posterior-analytics-i11.zh-CN.md)；本章从原则问题转向科学问答、错误诊断与知识增长。

## 1. 书目、范围与阅读方法

- 作者：Aristotle（亚里士多德）；作品：*Analytica Posteriora*（《后分析篇》），卷 I，第 12 章，**Bekker 77a36–78a21**。I.13 从 78a22 起，不混入本章。作品一般归于公元前四世纪；不把网站给出的约年当成本章确切写作日期。
- 实读底本：Bekker 1831 希腊文印页 77–78 的扫描；O. F. Owen 1853 英译印页 271–274；G. R. G. Mure 英译在线 I.12。版本、章界、分段定位及适用勘误见[来源核验台账](aristotle-posterior-analytics-i12.sources.zh-CN.md)。这里提供原创解析，不提供原文整章翻译或第三方 PDF。
- **适用勘误不能略过：** Owen 勘误表把印页 273 边注 4 的“syllogistic”改为“asyllogistic”，说明 Caeneus 的例子**不是有效的三段论**。这是译本边注订正，不是亚里士多德正文理论的更换；不能据未订正标题替火的论证背书。
- 标签约定：**原文**指章中主张；**教学重构**指本文为澄清而引入的集合、图和类型表示；**分析推论**指据此提出的现代比较；**实跑**仅指附带 Python 程序实际完成的有限计算。

## 2. 历史问题：有了公理，为何还会答非所问？

**原文动机。** 证明并不只是把任意真句子排列在一起。I.2 已把科学知识与原因联系起来，I.7 讨论证明越过属的限制，I.10–11 分辨本门原则与共同公理。I.12 追问：既然证明需要属于这门科学的前提，那么提问、回答、反对和犯错也需要相应的边界吗？数学有图形和较明确的项，是否因此不易出错？证明结果已经成立，能否反过来确认所找的原因？科学又如何增加结论？

这里没有现代实验数据、统计估计、训练集或经验基线。检验对象是论式及其认识论使用条件。作品与《前分析篇》的三段论分析相关，但本文不把同一作者各篇的逻辑关系强说成可确定的写作先后。Caeneus 的例子说明作者在批评某种实际流行的推理样式；本章不足以独立确定该人物全部生平或学派归属。Owen 引用的后世注释也不是古代正文的直接证词。

**分析推论。** 本章可帮助今天的自动推理系统区分三件事：查询是否在声明的任务范围内；一个词在两条前提中是否同义；即便结论真的正确，论证是否提供了所要求的原因。这是结构类比，不是说古代已有类型系统、知识图谱或 AI 验证器。

## 3. 科学问答的边界，不等于禁止外行提问

### 3.1 从前提到问题（77a36–77b15）

**原文。** 三段论式的问题与可用作前提的命题有关；每门科学有其适当的命题，因此也有其适当的问题。几何学者以几何原则及已证结果回答；与几何具有从属关系的光学可以进入有关讨论。作为几何学者，他不必在每次证明中重新证明所有原则。

这不是“专业人士说什么都正确”。原文同时警告：向不懂相应科学的人讨论，错误论证可能不被发现。此处是证明活动的知识条件，不是把身份当作真理条件。一个外行可以给出有效反例；一个专家可以把词用错。

**教学重构。** 给命题增加领域标签与来源标签，例如“几何命题／先前已证”和“光学命题／已声明从属于几何”。路由器可检查标签是否符合当前问答协议，却不能由标签推出命题为真，也不能自行批准所有跨学科迁移。光学的实例尤其提醒我们：边界不是互不相通的封闭盒子；跨域需要明确的证明关系，而不是字符串相似。

### 3.2 两种“非几何”（77b16–27）

**原文。** 音乐问题可以不属于几何；“平行线会相交”则是在几何对象上犯错。两者都可能被宽泛称为非几何，却不是同一种无知：前者是范围外，后者与相应知识相反。

不要直接把古代例子套在任意现代几何中。这里的平行线例子应在本章所假定的几何语境理解，不能拿另一套公理中术语的不同定义，伪装成对原论证的简单驳倒。本文程序不实现几何学，只演示显式范围声明的区别。

## 4. 中项同名，不保证同义（77b27–33）

**原文。** 数学中的谬误较少通过歧义潜入，因为中项比较容易被把握；原文用图形的圆与诗文的“圆／循环”说明同词不同义的危险。中项“二重”（διττόν）的译解有差别；以下侧重歧义例，并不宣称它只有这一种解释，详见来源台账。这里说的是相对较少，不是数学永不出错；可见图形也不是免于证明的许可证。

**教学重构。** 有效链需要两个前提中出现的是同一个属性。设 B 是“几何圆形”，另一个 B′ 是“诗歌循环”。从“所有 B 属于 A”和“所有 C 属于 B′”，不能省掉 B 与 B′ 的差别，写成关于 C 与 A 的链。

$$
C \subseteq B,\quad B \subseteq A\quad\Longrightarrow\quad C \subseteq A.
$$

这条集合蕴含成立，但如果其中连接 C 的前提实际是 C 包含于 B′，证明第一步便没有许可。把词面相同的两个节点强行合并，正是在输入阶段偷加了 B＝B′。

**算例。** A 是平面图形，B 是几何圆，C 是某类诗歌，B′ 是文学循环。诗歌属于某种循环结构不使它变成平面图形。附带 `same_middle` 检查显式词义标识，而不是看显示名称是否一致；标识也可能被人错误填写，因此它只是防错接口，不是语言理解的完成品。

## 5. 反对意见：不要把一段难文读成“反例无效”（77b34–39）

**原文。** 本段讨论归纳式前提、反对和三段论前提的要求，原文把反对与可进入论证的前提相连，并诉诸前提的普遍性要求；不能把这段困难论述只简化成一般的“意见要相关”。不同译者的句法处理和解释重点需要对读。Owen 印页 273 引 Pacius 尝试调和这里与其他论述的关系；那是注释层，不能不加标记地写成亚里士多德另证了一个一般定理。

**教学重构。** 区分“击破别人一个全称前提”与“建立自己的正面科学证明”。若待检前提是所有 B 都是 A，一个属于 B 而不属于 A 的对象就足以反驳它；这个对象本身却未必给出有关全部对象的原因理论。

$$
\exists x\,(x\in B\ \land\ x\notin A)\quad\Longrightarrow\quad B\nsubseteq A.
$$

**例子。** 声称“所有金属都在室温下为固体”，一个符合条件的反例可以击破全称句；要解释各金属的相态还需定义温度条件和相应理论。这里只用日常例子说明逻辑层次，不把它当作本章原例或新实验。更稳妥的纯形式例子是 B＝{0,1}、A＝{0}：对象 1 已经足够。不能把“科学反对要能进入论证”误用成拒绝这样一个有效反例的借口。

## 6. Caeneus 的火：共同后件不是包含关系（77b40–78a6）

### 6.1 为什么两句都可能真，而推理仍不成立

**原文。** 火增长得快，倍比增长也快，因此火按倍比增长——本章把这类推理指出为非三段论式论证。Owen 的适用勘误正落在这个例子。这里不建立现代燃烧模型，也不验证火在任何具体条件下遵从某种增长率。

**教学重构。** 令 F 为待说明的火增长实例，G 为倍比增长实例，R 为快速增长实例。论式只有：

$$
F\subseteq R,\quad G\subseteq R.
$$

它没有提供 F 与 G 之间的包含方向。共享一个上位属性，不等于两个类相等，也不等于其中一个包含另一个。

**非空反模型。** 在论域 {0,1} 中，取 F＝{0}、G＝{1}、R＝{0,1}。两个前提都真，F 包含于 G 却假。反模型既不靠空主项，也不靠经验上火究竟有多快。

### 6.2 有效修复要付出新的前提

**原文**的条件性修复明确改用“最迅速”的增长条件（78a3–5）：如果火的增长最迅速，且最迅速的增长属于相应倍比增长，论式才成立。不能把一般“快速”与“最迅速”混成同一个条件。

**教学重构。** 用 R* 表示“最迅速”而非上节的一般快速 R；如果确实有 F 包含于 R*、R* 包含于 G，便可得到 F 包含于 G。

逐步证明：任取 x 属于 F；由第一个前提，x 属于 R*；再由第二个前提，x 属于 G；因为 x 任意，所以所有 F 都属于 G。关键并非把箭头画得更漂亮，而是第二个前提已经与原来的 G 包含于 R 不同，连速度属性也须重新核实。

**局限。** 有效性不等于可靠性。新加的“所有这种最迅速增长都属倍比增长”以及火满足这个更强条件，都必须独立论证；从旧前提改写不出来。“最迅速”还须保持前后词义及比较范围一致。程序测试的是抽象论式，不为这个自然研究前提提供证据。

## 7. 从真结果倒推前提：分析不是自动的证明（78a6–13）

**原文。** 有时结果确实跟随而推理者未意识到；更一般地，真结果可能由错误前提出现在一个有效推导中。因此，先找到能导出目标的假设，不等于已证明假设。数学由于使用定义，推理较常能够相互换位，但原文的比较判断不能扩大成“一切数学步骤都可逆”。

**教学重构。** 若 H 蕴含 C，且 C 为真，H 仍可能为假。这与上一节的共有属性问题相通，但不要混淆集合包含与一个具体命题的真值。取 H 为假、C 为真，材料蕴含 H→C 为真，H 并未由此得到确认。这里是现代命题逻辑的有效性反模型，不是声称原文直接采用材料蕴含语义。

**可逆条件。** 如果还独立拥有 C→H，那么双向条件才许可往返。集合版本中，B 包含于 A 与 A 包含于 B 一起给出 A＝B；单向包含不够。证明：任取元素，两边的成员资格分别由两个方向保证；于是两集合含有完全相同的元素。

**算例。** 一个整数能被 4 整除，则它是偶数。知道 6 是偶数不能推出能被 4 整除。若将目标改成“偶数恰好是能被 2 整除的整数”，在同一整数论域与约定下才有定义性双向关系。这里用后世教学例子解释为何“定义经常有助于可逆”不同于“见到结果即可确认原因”。

**分析推论。** 自动求解器可以逆向提出候选条件，但最后仍需检验每一步的方向、等价条件和实际前提。目标达到不是解释充分的保证；这也不意味着逆向探索没有发现价值。

## 8. 知识怎样增长：延长链与展开分支（78a14–21）

**原文。** 本章末区分向极项方向的增长和横向的增长。它不是在此宣布现代图算法，也不是说数学从此不能插入新引理。章内还有数的属性示例；本文不把译者为这些例子补出的解释冒充完整古代数论证明。

**教学重构一：延长。** 已有 D 包含于 C、C 包含于 B、B 包含于 A，可以先推出 D 包含于 B，再推出 D 包含于 A。结论数量增加，但没有凭空生成新的经验前提。

**教学重构二：横向。** C 经过 B 到达 A，而 E 经过另一个中项 K 到达 A。二者共享上位属性，不表示 C 与 E 可以互相推出。若图中每条边均表示同一论域内的可靠包含，传递闭包可以整理可到达关系；若边只表示相关、原因、时间先后或同名，混成同一关系再闭包就会制造错误结论。

**逐步正确性。** 长度为 1 的路径由给定边成立；若长度为 n 的路径保证起点包含于中间点，再接一条有效包含边，集合包含的传递性给出长度为 n＋1 的路径。对有限路径作归纳，才能说明沿路径的推导为什么可靠。有限程序核查不是这个一般归纳论证的替代。

## 9. 最小复现：实际做了什么，没有做什么

附件为[原创代码、说明与真实运行日志](../../reproduction/aristotle-posterior-analytics-i12/README.md)。使用 Python 标准库，无外部数据和付费服务。命令、环境和文件校验值在附件中；三种模式 `python`、`python -O`、`python -OO` 均实跑，不把优化关闭的 `assert` 当作通过的测试。

**实跑结果：** 三元素论域有 8 个子集、512 个有序集合三元组。共享属性的前提组合为 125，其中错误地推出包含关系的反模型 61；限制两个相关类均非空，仍有 42 个反模型。64 个集合有序对中，单向包含后倒推反向包含的反模型为 19，双非空时仍有 12 个。有效包含链未出现反模型，双向包含却不相等的反模型也为 0。另枚举 512 个三节点有向图（允许自环），将闭包算法与独立逐起点可达性搜索 oracle 比较，差异 0。三个执行模式各通过 19 项测试。

**解释边界：** 数字回答的是指定有限模型中的问题，不证明所有论域上的定理，不识别真实火势，不自动判定学科合法性，也不能从词义 ID 保证解释者理解正确。一般包含传递性与双向包含相等已经在正文分别作证明；有限反模型则足以否定无效论式的普遍有效性。输入允许空集，是现代集合语义；重要错误同时列出非空反例，避免把结论偷建立在古代存在预设争议上。

## 10. 复盘：本章需要同时守住的四道检查

1. **范围检查：** 这是不是当前科学要处理的问题？跨域桥接是否真的给出？范围外与范围内错误要分开。
2. **词义检查：** 前提中的中项是不是同一个属性？词形一致不是证据。
3. **方向检查：** 两类共同属于第三类，不能彼此推出；由结果倒推原因也需要额外许可。
4. **解释检查：** 有效论式加上真实前提才有可靠结论；科学证明还要求相应原因关系。标签、图可达性与一次求解成功都不能包办这些条件。

本章的价值不是消灭提问，而是让提问、反对和解释各自承担应有的证据责任。其限制同样重要：学科边界的历史划分未必适用于现代研究；数学歧义较少是认识论判断，不是复杂形式系统的安全证明；原文短论证不能替代对每一种具体科学的实质研究。

## 11. 带答案练习

**题 1：** 一个音乐问题和一个关于平行线的错误断言，在本章中为何不可归为同一种错误？  
**答：** 前者可能在几何问答范围之外；后者涉及范围内对象但与知识相反。范围检查不能取代真伪检查。

**题 2：** 已知猫和狗都是哺乳动物，给出“猫都是狗”不成立的非空集合反模型。  
**答：** 取猫类 {0}、狗类 {1}、哺乳动物类 {0,1}。两个包含前提都真，而 0 不在狗类。标签只是教学名称，不需真的构造动物实验。

**题 3（抽象改前提，非原文“最迅速”的精确措辞）：** 若把第二个前提改成“所有快速增长均为倍比增长”，火的推理是否已获科学证明？  
**答：** 论式可成为有效链，但新前提是否真、是否说明适当原因仍需独立证据；不能把形式修复当作自然规律已经验证。

**题 4：** 一个反例能否既击破全称前提，又不足以建立替代理论？  
**答：** 能。B＝{0,1}、A＝{0} 中的 1 足以否定 B 包含于 A；它没有告诉我们所有对象的原因分类。不能因此说该反例无效。

**题 5：** 两个前提都写“圆”，程序为何仍应要求词义 ID？  
**答：** 几何圆与文学循环可能同名不同义。链的传递要求同一中项；词义 ID 可显式暴露假设，但 ID 本身也要人工核实。

**题 6：** H→C 与 C 已知，缺少什么才能据此得到 H？  
**答：** 缺少 C→H 或其他独立支持 H 的前提。定义有时提供双向关系，但不是每一个导出结果的推理都等价。

**题 7：** 512 个有限图全部与 oracle 一致，证明了什么？  
**答：** 证明本次实现对这些被枚举输入与该 oracle 输出相符；不能单凭这一事实证明任意规模正确。还需读代码、验证 oracle 独立性并给出路径归纳论证。

**题 8：** 为什么 Owen 的边注勘误影响阅读，却不等于原作者改变了定理？  
**答：** 它订正译本对一个论证的分类标题，帮助读者不把无效论式当有效；正文论证的归属与版本层次必须分别记录。
