# 欧几里得《几何原本》VII.16：不预设交换律，怎样证明三次七等于七次三？

> AI 数学与形式推理前史补读。约公元前 300 年的古代算术，实读 1908／2008 版；这是从现代论文主线回跳的案例，不是 AI 论文，也不声称穷尽前史。

## 1. 书目与问题

- Euclid, *Elements*, VII.16。[Clay 希英对照与第 136 叶手稿入口](https://www.claymath.org/library/historical/euclid/files/elem.7.16.html)。T. L. Heath, *The Thirteen Books of Euclid’s Elements*, 卷 II（1908），印刷页 316–317；题述、图和原证在 316，评注续至 317。
- Richard Fitzpatrick, *Euclid’s Elements of Geometry*（2008 修订），[希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=208)，页 208。[Joyce 在线本](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII16.html)也完整给出结论。参见[原典核对](../../reproduction/euclid-elements-vii16/source-review.zh-CN.md)。

三次七与七次三，看起来只是把两个因子的次序调换。可是按欧几里得的定义，第一次加的是七，第二次加的是三，连加的轮数也不同，不能只说“加法里交换相邻两项就行”。本命题把[上一命题 VII.15](euclid-elements-vii15.zh-CN.md)关于量尽次数的转换，用在两个分别按定义构造的积上。

## 2. 角色与定义：谁给次数，谁被加？

| 英文／希文 | 角色 | 教学记号 |
|---|---|---|
| A／Α | 在第一种构造中给次数，在第二种中被重复 | $`A=nu`$ |
| B／Β | 在第一种构造中被重复，在第二种中给次数 | $`B=mu`$ |
| C／Γ | 把 B 加 n 次所得 | $`C=\sum_{i=1}^{n}B`$ |
| D／Δ | 把 A 加 m 次所得 | $`D=\sum_{j=1}^{m}A`$ |
| E／Ε | 单位，不是与 A、B 同类的给定的数 | $`E=u`$ |

[卷 VII 定义 15](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII15.html)规定，“A 乘 B”就是按 A 所含的单位数反复加 B。为避免把现代式中的因子顺序当成无需声明的惯例，本篇沿用 Heath 页 316 的约定：记 $`AB`$ 为 n 次 B。单位 E 在现代整数模型中取 1；卷 VII 的[定义 1–2](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII1.html)仍区分单位与由单位组成的数。图上 C、D 已画成同样长，那是在示意要证的关系，不可代替证明。

## 3. 原证：先把 C 和 D 都改用 A 量尽

1. **第一种构造。** 依定义 15，B 量尽 C 的次数是 A 中的单位数 n。E 量尽 A 也是 n 次。这里只推出第一对同次数，还没比较两个积。
2. **一次调用 VII.15。** 将“E 量 A、B 量 C 同次”换成“E 量 B、A 量 C 同次”。因此 C 改由 A 量尽，次数等于 B 中的单位数 m。这里不是把乘法写成交换后的形式后再算，而是从早先的量尽规则读出一个新见证。
3. **第二种构造。** D 按定义就是 m 次 A，所以 A 量尽 D 也是 m 次。此处不需要第二次使用 VII.15。
4. **同块同次。** C、D 都由同一个 A 恰好装 m 次，因此 C=D。只知道 A 分别整除 C 和 D 并不够，必须核对次数相同而且都无余数。

以正数量的商表示次数，可将证明骨架写成下式。长箭头使用 VII.15，右端关于 D 的等式来自 D 的独立构造。

$$
\frac{A}{E}=\frac{C}{B}=n \quad\Longrightarrow\quad
\frac{B}{E}=\frac{C}{A}=m,\qquad \frac{D}{A}=\frac{B}{E}=m .
$$

**版本差异。** 已核 Clay 在线英栏确实包含 VII.15 的换量尽步骤，也到达“A 量 C、D 同次数”，但到此截止；希文、Heath、Fitzpatrick 与 Joyce 还有最后的 C=D。Heath 页 316 还说明题述中希腊文“由它们产生”的指代在译法上有不清处，释为从原来的两个数得到积；这不改变证明次序。Heath 页 317 用定义 20 和 VII.13 写出自己的比例式重述，并明确区分正文：正文说的是量尽，用的是 VII.15，而不是直接援引 VII.13。

## 4. 现代重建：等长单位格，两种遍历

令 A 含 n 个单位、B 含 m 个单位。从第一种构造取 n 行，每行 m 个单位格。行遍历对应把 B 加 n 次；列遍历对应把 A 加 m 次。在坐标对 $`(i,j)`$ 中，固定 i 逐个枚举 j 是按行，固定 j 枚举 i 是按列。每个格在两种遍历中都恰出现一次。因此两次加总都是整个有限格集合的单位数：

$$
C=\sum_{i=1}^{n}\left(\sum_{j=1}^{m}u\right)
=\sum_{j=1}^{m}\left(\sum_{i=1}^{n}u\right)=D .
$$

这里的等号来自同一组格子被各数一次，不预先使用乘法交换。它是现代教学证明，不宣称原稿画了矩形数组。原证明用的是 VII.15 的量尽次数转换，而不是交换有限求和的现代记号。也不把这个特定的重复相加模型推广给任意二元运算。

## 5. 算例与不能省掉的条件

| 输入与操作 | 观察 | 是否是 VII.16 的对应证据 |
|---|---|---|
| A=3、B=7；C=7+7+7 | B 量 C 三次，VII.15 转为 A 量 C 七次 | 是，第一种构造 |
| B=7、A=3；D=3+3+3+3+3+3+3 | A 量 D 七次 | 是，与 C 共用 A 和次数 |
| 人为把 D 改为 18 | 3 仍恰量尽 18，但只量六次 | 不是，D 已不是第二种定义构造 |
| 人为把 D 改为 22 | 以 3 作块，添七块仍余 1 | 不是，商的整数部分相同也不够 |
| 交换矩阵因子而不换别的 | 例如两个二阶矩阵，取只有左上角为 1 的 P、只有右上角为 1 的 Q，则 PQ=Q、QP=零矩阵 | 不是，所用运算并非此处由单位次数定义的数乘法 |

现代整数中，把 A 或 B 取 1 时仍可交换；若定义零次和为空和，也可推得与 0 相乘的边界。这是现代扩展，不是给欧氏原命题增添了单位和零作为数的用例。对于负整数还需要符号规则，本篇不以有限格计数直接证明它。

## 6. 原证位置与后文用途

| 主张 | 证据位置 | 可复核细节 |
|---|---|---|
| A 决定 B 相加的次数 | 定义 15；Heath 316 证首及注 | 不把 A 当第一次被加的项 |
| 只对 C 的量尽关系做一次换位 | Heath 316／Fitzpatrick 208 证中 | B 量 C → A 量 C；共同次数改为 B 的单位数 |
| 分别构造后以同块同次比较 | 同页后段，Clay 希栏末 | D 的次数来自定义，结尾才认定 C=D |
| 后文需要交换因子的角色 | [VII.18 正文](https://www.claymath.org/library/historical/euclid/files/elem.7.18.html) | 对 A 乘 C、B 乘 C 的两个积分别换位，C 于是成为两个式子里同一个给次数的因子，再按适用的比例规则比较 |

合理延伸：用“一份输入、两条独立构造、同一量尽见证”检查实现，比只比较结果更容易发现把次数或块长拿反的错误。不过两个构造可以返回同一个数而仍分错组，单看最终相等不能保证途中角色记录正确。这个例子是现代测试方法的类比，不是对古书直接影响当代 AI 的断言。

## 8. 复盘与练习（含答案）

记忆链：**定义各建一次 → 对第一积换量法 → 比同块同次数**。

1. **题：** A=4、B=9，C 和 D 分别怎么按定义构造？  
   **答：** C 是四个 9 的和，D 是九个 4 的和，均为 36。原证用 VII.15 说明 4 可量 C 九次，不是从 C 与 D 已相等倒推。
2. **题：** VII.15 换了什么，什么没变？  
   **答：** C 的度量块由 B 变为 A，次数由 A 所含单位数变为 B 所含单位数；被量的 C 没变。
3. **题：** C=36、D=32 都可用 A=4 量尽，能判等吗？  
   **答：** 不能，次数是 9 与 8。D 不满足 B=9 决定的构造次数。
4. **题：** “C、D 同由 4 量九次”，为何排除了 37？  
   **答：** 37 虽能放下九个 4，但还有余数 1，不符合量尽。
5. **题：** 为什么两次重复相加不是偷偷假定交换律？  
   **答：** 两个积分别由定义建立。VII.15 已独立把第一积的量尽见证换到 A；第二积本来就由 A 构成。只在确认同块同次后才说两个总量相等。
