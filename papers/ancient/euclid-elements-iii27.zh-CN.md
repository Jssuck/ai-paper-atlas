# 《几何原本》III.27 精读：等弧为什么能反推出等角？

> 前史补读，非现代 AI 论文。卷三命题号说明编排与证明依赖，不说明发现的先后。本文选读一个可定位原文的推理案例，不代表穷尽古代数学或自动推理前史。

III.26 已经给出“等圆中，同类等角对等弧”。III.27 调转输入和输出，却没有把箭头直接倒过来。它先在较大的角里复制一个较小的角，再用已证的正向定理，把角的严格大小差异转化成弧的严格包含关系。这样才排除了“角不等、所对的弧却相等”的可能。

## 1. 读哪个版本

主读 [Fitzpatrick 2008 修订版，希英对照](https://sidoli.w.waseda.jp/Fitzpatrick_Euclid_Elements.pdf)，卷三印刷第 96 页；已核对该页的命题、图与证明。另读 [Joyce 网页版 III.27](https://mathcs.clarku.edu/~djoyce/elements/bookIII/propIII27.html)。Joyce 的正文在复制角之后描述“等圆心角对等弧”，却把该处边注写成并链接到 **I.26**。实际是 **III.26**，Fitzpatrick 页 96 也标作 3.26。这里纠正的是此页的交叉引用，不是改动原文。另对照 [Heath 译注本，卷 II，第 58–59 页](https://www.wilbourhall.org/pdfs/heath_euclid_ii.pdf#page=71)，该步也标 III.26。Heath 在第 59 页结论之后指出，这是前一命题的逆命题，前一命题涉及的不同角形情形也适用于这里。第 58 页前置的锐、直、钝角讨论属于 Heath 的 III.26 注释；它帮助识别图示范围，不是 III.27 证明正文，也不是作者勘误。没有做手稿校勘，不能推断所有版本都没有勘误。

## 2. 原文提出的问题

设圆 ABC、DEF 相等，圆心分别为 G、H。指定两条相等的弧 BC、EF。圆心角 BGC 和 EHF 分别以它们为底；圆周角 BAC 和 EDF 也各对同一条指定弧。所求是前一对相等，后一对也相等，不是说 BGC 和 BAC 相等。

两个端点并不总能独自识别一条弧。按图，BC 指经过 K 的那一段，而不是经过 A 的补弧；EF 也取不经过 D 的那段。以现代符号写成 $\gamma_1,\gamma_2$ 比把 BC 一会儿当弧、一会儿又读作弦更不容易混淆。图画在较大角内添 K，正是为了指出所用的是哪条弧。

## 3. 按原文顺序重建

1. **圆心角比较。** 若两个圆心角不等，则一个大于另一个。不失一般性取 $\angle BGC>\angle EHF$。交换两圆只改变记号，不改变等圆和等弧前提。
2. **复制。** I.23 给出在指定起始线和顶点复制角的构造。以 G 为顶点、GB 为始边，指定与 GC 同一侧复制这个较小角，得到位于所比较扇区内部的射线，使 $\angle BGK=\angle EHF$。K 是这条射线在第一圆上的交点。严格不等与内侧放置使 K 不在 B 或 C。原文以构造和图给出位置；这里明确写出“扇区内”是教学补叙。
3. **先得到另一条等弧。** 两圆相等，复制出的圆心角与 EHF 相等。用 III.26 从等角得到弧 BK 等于 EF，不能在这里反用正在证明的 III.27。
4. **部分不可能等于全体。** 给定 EF 与 BC 等，故 BK 与 BC 等。但 BK 是 BC 的真子弧，BC 还包含非空的一段 KC。此处的矛盾用的是弧的严格部分关系，与全体大于部分相应，不依靠小数近似，也不通过肉眼比较两幅图的长短。由此圆心角只能相等。
5. **最后才转到圆周角。** III.20 把同一弧的圆周角和相应圆心扫角联系起来。两个中心量相同，取其一半仍相同，故 BAC 与 EDF 相等。

证明依赖可写成：I.23 保证能复制，III.26 把复制等角换成等弧，全体大于部分排除大小差异，最后由 III.20 处理另一类角。第一到第四步并未调用圆周角半倍关系。反过来，如果只知道某映射保等，譬如两个对象颜色相同则标签都为“样品”，不能说标签相同就保证颜色相同。III.27 真正补上的正是排除这种合并的机制。

## 4. 现代度量模型（不是原证）

记 $r>0$ 为半径，$t$ 为所选弧扫过的转数，限定 $0<t<1$。$\theta=2\pi t$ 为对应扫角的弧度量，所截弧长写成

$$
s=r\theta=2\pi rt.
$$

若两半径相同且两弧长相同，则

$$
r\theta_1=r\theta_2\quad\Longrightarrow\quad
\theta_1=\theta_2\quad\Longrightarrow\quad
\frac{\theta_1}{2}=\frac{\theta_2}{2}.
$$

这里使用现代弧长关系和同弧半倍关系，计算比原证短，却不是古代作者的论证。原图中的普通圆心角对应不超过半周的扇区；要扩展到大弧，应显式允许所选扫角超过半周。不能一边选大弧，一边把两条射线间的较小夹角当作它的完整扫角。例如圆周顶点在余下的小弧上时，所截 $270^\circ$ 大弧对应 $135^\circ$ 的圆周角，而不是 $90^\circ/2$。

在现代数值例中，取 $r=2$、$t=1/6$，从不同的起始方向扫同一转数，两弧长度都为 $2\pi/3$；两圆心扫角各 $60^\circ$，所对圆周角各 $30^\circ$。转动摆放不改变长度或角度。再看反证里的复制步骤：若较大的扫角是 $120^\circ$、小的是 $60^\circ$，复制得到的前段只占较大弧的一半。这个例子展示严格包含，不是假设这两条不同弧同时满足原命题的等弧前提。

### 前提不能删

- **不等圆。** $r_1=1,\theta_1=\pi/2$ 与 $r_2=2,\theta_2=\pi/4$ 都给弧长 $\pi/2$，但圆心扫角相差一倍。若同弧圆周角各减半，仍不相等。
- **同端点不代表同弧。** 单位圆上一对相距四分之一周的端点给出 $90^\circ$ 小弧和 $270^\circ$ 大弧。两条弧共用同一条弦，长度却不相等。如果端点直径相对，两条弧都是半圆、相等但仍非同一条弧。
- **不同角类不能混比。** 同一条 $60^\circ$ 弧明确给出 $60^\circ$ 圆心扫角和 $30^\circ$ 圆周角。同类结论不能转成中心角等于圆周角。
- **边界不是图证的默认输入。** 首尾同一点需要额外区分零弧和整周，复制构造也不再产生这里要求的正常三点配置。

## 5. 此段史料能支持什么

| 主张 | 证据或性质 |
| --- | --- |
| 等圆中等弧推出两对同类等角 | Fitzpatrick 印刷第 96 页，命题及结句 |
| 先构造较小等角，以较短弧等于较长弧反证 | 同页，图及正文中段 |
| 圆周角结论最后由半倍关系取得 | 同页，结句前；明确标 III.20 |
| 扫角用转数、弧长用 $2\pi rt$，参数覆盖大弧 | 现代教学建模，不是原词义的全面替换 |
| 形式推理中应显式登记选弧、严格包含与构造前提 | 教学分析；并非欧几里得创立现代证明检查器的历史主张 |

III.26 与 III.27 成为配对的正逆结果，但中间用了构造，而不是一条普适的逻辑倒换规则。在符号证明检查中，可以把“在较大扇区内”和“所选弧”作为构造产物的约束显式记录。潜在价值是发现缺前提的步骤，不是为现代证明器声称一条从古代直接传承的谱系。

## 6. 最小教学复现

[源码、运行命令、Notebook 与实跑日志](../../reproduction/euclid-elements-iii27/README.md)。

用 Python 标准库的有理数记录半径、起始方向和终止方向，并将方向差对一周取模。从起点逆时针选弧，先据模型关系独立计算两边的归一化弧长（实际弧长除以 $2\pi$），再按输入比较扫角；较大一边需复制时，用较小扫角计算子弧端点、检查严格包含并比较长度。圆周角不从平面点构造，而是直接按所选弧扫角减半。

通过普通、`-O`、`-OO` 三种模式实跑，每种模式通过 8 项测试、覆盖 2,904 个等半径网格配置，其中 264 个扫角相等，2,640 个触发复制较小扫角。边界例另外覆盖跨零方向、互补弧、异半径等弧长及退化输入。网格是教学选择，不是来自古代数据；模式之间是同源运行，不是三个独立定理证明。

随附 Notebook 复用同一模型。当前环境没有可用的 Jupyter 执行组件，三个代码单元已逐格编译、执行并留存日志，未在 Jupyter 内核或前端验证。

测试没有独立验证弧长公式、III.20 或尺规可构造性。它能检查有理数模型的参数关系及程序中的严格子弧约束，却不能替代一般证明。特别是同半径时，等长与等扫角在模型内已由 $rt$ 的定义相连；若把它冒充独立复现，就会循环论证。

## 7. 复盘练习（附答案）

1. 如果把 K 放到起始射线的另一侧，哪个证据链最先断？  
   **答：** 等角仍可能成立，但所选 BK 不一定是 BC 的真子弧；因此全体与部分的矛盾没有依据。
2. 若给出半径 1、2，两个弧长都为 $\pi/3$，求所选圆周角。  
   **答：** 圆心扫角为 $\pi/3,\pi/6$，相应圆周角为 $\pi/6,\pi/12$；不符合等圆假设。
3. 付给程序相同的一对端点，能推出两条弧重合吗？  
   **答：** 不能，还要给定起点与方向，或单独指定弧经过的一点。直径处即便两半圆等长也不重合。
4. 若只保存 III.26，形式系统能直接将其当作双条件吗？  
   **答：** 不能。要另证逆向，或显式引用 III.27。此处的反证依赖复制角和弧的严格大小关系。
