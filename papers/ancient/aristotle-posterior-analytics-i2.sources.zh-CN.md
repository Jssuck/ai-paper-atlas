# 《后分析篇》I.2：原始来源与章界台账

对应[中文深读](aristotle-posterior-analytics-i2.zh-CN.md)。只公开书目链接及原创核读说明；扫描、OCR和原文全文不进入公开附件。

## 阅读范围与年代

Aristotle，*Analytica Posteriora / Posterior Analytics*，I.2，**71b9–72b4**。以Bekker1831扫描的章号及行号核实：71b9起章2，72b5起章3。本次覆盖开头的严格知识、证明条件、中部原则分类，直至章末确信与相反错误的限制，而非只摘六个形容词。

作品置于公元前四世纪思想背景，单章精确写作年及两部《分析篇》真实写作先后未核。按传本文集顺序接读I.1，不把该次序当年代证据。它是AI思想前史的书籍章节，不是现代AI论文，也不表示前史已穷尽。此处后分析篇I.2不等于仍暂缓的前分析篇I.2。

## S1：Bekker1831希腊扫描

Immanuel Bekker编，*Aristotelis Opera*，vol.I，Berlin，1831。[卷本](https://archive.org/details/aristotelisopera01arisrich)；[印71](https://archive.org/download/aristotelisopera01arisrich/page/n86.jpg)；[印72](https://archive.org/download/aristotelisopera01arisrich/page/n87.jpg)。实际逐页看图，核71b右栏第9行至栏末、72a全栏及72b前4行，并看页下相关校记。

71页右栏校记涉及13、14、20、21、24、25、30等行；72页左栏涉及6、12、16、17、18、20、21、30、31、32、33、35等行。装置记录词序、连接词、词形及增删异文，不是作者正式勘误。本单元不声称重校全部手稿，也不把校记中的某个读法自动改成正文唯一正确解释。

## S2：标为Bekker1837的希腊转录

[Graeco-Arabic Studies正文及版本说明](https://www.graeco-arabic-studies.org/view/arist.analytpost-orig-gr1)。页面Source标为Bekker，*Aristotelis Opera*，Oxford，1837，I，182–257。实际读章号2至3之间全部希腊转录，与1831扫描核对术语与段序。此转录不等于另一份独立古代手稿。

六条件是“真实、首要、直接、较可知、在先、结论的原因”；“较可知/在先”有相对于我们与无条件的不同序；“定义某物是什么”和“断言它存在”明确区分。末段原文保留“全部或某些”首要前提的说法，不能静默改成每一个前提都具有同一数值概率优势。

## S3：Owen1853英译、页下注及ERRATA

Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol.I，London: Henry G. Bohn，1853。[全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)。实际读**印246章II标题起至印250章III标题前；本地所用PDF第265–269页（1起算）**。印246脚注仍承I.1，不误归本章；本章相关脚注为247注1–3、248注1–4、249注1、250注1–2。

重要分层：

- 247注1援Taylor解释原因与结果，注2借后世逻辑文献说明首要、直接以及复合证明的基础。它允许理解为根本依赖最终落实于首要原则，不能据此把本章写成“任一中间已证命题都永远不可用于证明”。注3谈回溯，是译注解释，不表示已完成I.3。
- **248注2**把普遍者优先解释为赞同柏拉图、灵魂本具形式，援Proclus及后世学者。这是译注层强解释，不是本章正文已经论证灵魂本有全部知识。本篇不采用此推论作为古代作者的已证主张。
- 249注1讨论公理地位并援Mansel等；250注2给出共同原则/特殊原则、公理/设定/定义/假设的表，属于译者教学图，不冒称作者原图。
- 250章末英译关于“原则的相反者”的句法很拗口，其注2又说明避免把相反于真原则的东西当真。解释时应与希腊句及Mure末段合读，不能读成“应比真原则更相信相反原则”。

实际看卷首ERRATA整页：列印219章题、273边注、594章题三项，**未列246–250**。故未发现该表适用于本章的正式修正；这不等于保证本章不存在其他误印、异读或解释争议。

## S4：Mure英译电子转录

[MIT Internet Classics Archive，Book I，Part2](https://classics.mit.edu/Aristotle/posterior.1.i.html)，署G.R.G.Mure。实际读Part2全段，以Part3为结束界标；页面所据印次未从该页扫描核实，不附会某一印年，也不采用网页“350BCE”为单章精确日期。

Mure采用“科学知识”“证明”等术语，Owen有“单纯地/单独地知道”等较生硬措辞；本篇用“严格意义的知识”指向其限定，避免把古代epistēmē直接等同现代实验科学全部实践。Mure末段与希腊共同支持：不能让导向相反错误的材料，比原则更可信或更可知；不是现实中任何反证都应拒绝的劝告。

## 原文位置与教学边界

| 位置 | 本章主张 | 不可偷换 |
| --- | --- | --- |
| 71b9–16；Owen246–247 | 严格知识涉及知道原因及其不可另样 | 自以为知道与实际知道不同；不能以自信代替真 |
| 71b16–25；Owen247 | 证明是产生知识的三段论；列六条件 | 形式有效不自动为证明；另一种知道暂留后文 |
| 71b25–33；Owen247–248 | 真、首要不可证、原因与先知事实的理由 | “不可证”不是任意猜测免审；意义与事实分开 |
| 71b33–72a5；Owen248 | 对我们较先与无条件较先两序 | 发现次序不等于解释根据次序 |
| 72a5–14；Owen248–249 | 直接原则、前提、断言、矛盾、肯否定 | 辩证选择与证明选定真一方不同 |
| 72a14–24；Owen249 | 公理、设定、假设、定义；单位例 | 定义不自动承诺实例存在；现代统计假设非同义 |
| 72a25–37；Owen249–250 | 原则较先知且更确信，全部或某些；所爱类比 | 不是贝叶斯公式或经验心理定律 |
| 72a37–72b4；Owen250 | 相反错误材料不能压过原则；稳定知识 | 不能把它写成现代科学永不修订信念 |
