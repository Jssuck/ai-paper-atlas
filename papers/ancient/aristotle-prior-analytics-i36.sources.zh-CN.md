# 《前分析篇》I.36：来源台账与解释边界

## 1. 阅读单元与版本

本单元是古代推理与关系表示的前史补读：完整第一卷第36章，**Bekker 48a40–49a5**。作品属公元前四世纪的年代范围；实际所读印本是1831、1853年版本，另以Jenkinson英译电子转录对校。它不是现代期刊论文，不是“第一篇AI论文”，也不表示年代目录已穷尽。本章与I.35相接，不把I.37及全书算入完成。

定位区间有相邻句交叠，因为同一印刷行可能含前句结尾及后句开头；它们是核读导航，不声称每条均有独立整行。

## 3. 已发现的版本与编辑差异

### 3.1 智慧例的结尾不能默改

Bekker48b14的相关否定以“知识／科学”的希腊词为谓项；Jenkinson亦说善不是知识。Owen印161却在对应位置写成善不是智慧，然后重申智慧是知识。本文应以Bekker正文并参照Jenkinson解释，同时如实保留Owen的差异。它不在所读Owen正式勘误表内，故只能叫**译文差异／疑点**，不能捏造“1853勘误已改正”。

这里的“不是”也不应未经论证变为现代集合的全称不交规则。原文正在说明直接谓述与斜格关系并非同一形式；教学模型若把善作为一个对象、智慧作为一类知识，须明确这是类型化重构而非唯一古代语义。

### 3.2 相反者例的标点与补词

Bekker48b7在“相反者”之后有逗号。Jenkinson注180明确采用Al.和Waitz的处理而删去该逗号。Owen161注1说Waitz加入αὐτῶν；注2另说他加入ἐπιστήμη。它们是所读译注记录的编辑处理，不等于本文亲核了Waitz版本或相关手稿。Bekker印48页底还可见48a40、48b6、7、12–13、20、41附近的简校记；本单元核其存在和涉及位置，不据这些缩写宣称已完成手稿谱系考证。

### 3.3 否定例及神例的解释层次

Owen在快乐例中以括号补出运动与生成，而Jenkinson把关于快乐的前提表为生成；本文不得把译者括补当作希腊原文逐字内容。可以选择“生成”作为现代教学实例，但要保留原章同时提到运动与生成。

Owen162注1和Jenkinson注181都把相邻反驳例联系到第二格，并说明中项可以是斜格关系而非严格直接谓述。Owen162注2则把神的例子判为第三格，中项为神。本文接受它作为所读注释对结构的提示，不把注释当作原文章号内的新增定理。

原文“机会不是适宜时间”可用来反驳两者无差别的界定或给出不全称结论；从“对神有机会而无适宜时间”最多得到一个见证差异，不能在现代集合模型中自动升级为“没有任何机会是适宜时间”。“无物对神有用”是例子给出的思想前提，不是本项目对神学事实的裁决。

## 4. 历史定位与比较的限度

I.32要求先确定前提再拆出项；I.33警告忽略量的覆盖；I.34检查状态与承载者；I.35允许复合表达。本章继续追问：同一个基本名称进入不同命题时，是否保留了关系角色。这个内部相邻脉络可由原典章节直接核实；不能据此断言现代关系数据库、类型系统或谓词逻辑由本章直接发明。

Owen160注8援引《解释篇》第2章，作为名称与斜格的比较入口；本单元只核这条译注，不声称该转引已代表整章独立精读。Owen所引Waitz、Buhle等后世说明也同理。没有核实到明确的前驱作者、同期文本或直接传承链时，应保留缺口，而不是给某个现代术语安排古代发明者。

现代教学使用一元分类谓词、二元关系、存在量词以及反模型，是为了清楚演示角色保存、见证保持和结论强度。它们不是本章原有符号。有限枚举只能核对这些自有模型及实现，不能证明古代全部推理体系正确或完成一般定理。
