## 3. 三个必须显式处理的文本问题

### 3.1 56a34：不能一面取“全 C 属于 A”，一面说“某 C 属于 A”为假

Bekker 第56页左栏约第34行、Owen 印188上部、Jenkinson 第三章末段均保留将 A 与 B、C 两项作全关系的正文。接着设定 E(A,B) 与 I(A,C)，却称两前提皆假；在本文采用的非空项解释下，前述全 C 属于 A 会使 I(A,C) 真，因而不满足该段宣称的“两假”。这不是改变推理有效式能解决的问题。

Jenkinson 注18明确提出，句意需要类似 Boethius 译本所暗示的读法：A 全属于 B，而全不属于 C。本文若采用这一配置，必须标明**据注释所报校读重建**，不能静默把修订文本当作各版本共同字面。此次没有独立读取 Boethius 译本或相关手稿，因此这里只报告 Jenkinson 的校读依据，不宣告手稿学定论。有限模型可以证明两个读法对真假分类的不同，却不能裁定文本传承。

### 3.2 56a15：否定读法及其支持程度

Jenkinson 注16指出该处句意需要否定，并注明手稿支持有限。Bekker 第56页左栏可见该行及页下相关异读；Owen 印187有前后措辞不完全顺畅的动物／白色例，但后半明确给出动物不属于某些白色事物的说法。正文应把所用模型写清为存在白色而非动物者，避免把含糊翻译当作唯一证据。Owen 该页边注说 Taylor 遗漏一个分句，不应误记成“Bekker 漏了否定词”的注。

### 3.3 55b33–35：否定作用域

Owen 印186的措辞容易被现代读者理解为“并非全部 C 属于 A”，但其紧随的沥青例要求 A 与 C 全不相交。Jenkinson 注15也明确将相应句子解释为不属于任何 C。因此教学模型采用 E(A,C)，不能仅取 O(A,C) 来充当那个真全称否定前提。

## 4. 枚举和编辑材料的边界

Jenkinson 注13讨论开头列举的重复以及 Waitz 的删改意见，并提醒实际论述未展开所有组合。本文的完整真假分类表若比原文列举更系统，应归为教学重构；不能借“in every way”的概述声称原文逐项证明了现代程序输出的每个格子。注14解释把否定前提换到另一位置；注17只是词语参照，并非新增证明。

Owen 的边注、Ex. 1–13三行式和拉丁式名是译者说明层；原文有项例，不等于原文使用相同排版或后世式名。印188底部关于 Taylor、Waitz、Buhle、Averroes 的注1属于紧随的第四章，**不能算作本章自己的校读证据**。

## 5. 历史与复现的可支持范围

篇内直接前驱是第一卷 I.5 对第二格的有效式研究；紧邻 II.2 研究第一格中真假配置，II.3把问题转到第二格，II.4接着处理第三格。这是著作内部结构，不等于各章独立发表的年代顺序。白色乌鸦、黑白互斥、属种与有足者等只能按原文例项配置讨论，不作为现代动物学或测量数据。

有限集合、枚举程序、回归测试、最小见证和 AI 类比属于现代原创教学层。它们不声称复原全部古代项逻辑，也不能单凭小域无反例证明任意域定理。现代一般证明与文本校勘分别承担不同责任；现代可靠性类比也不构成历史直接影响链的证据。
