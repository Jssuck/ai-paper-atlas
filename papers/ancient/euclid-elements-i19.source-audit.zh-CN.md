# Euclid I.19 独立来源审查

## 结论与绑定

**通过。** 本报告针对最终正文SHA-256：`c26d15cd99706aa2ed43aea1703397ea9952bdf95c24dc682ed5a23c7568503a`。若正文修改，须重新检查相关内容并更新绑定，不能沿用此结论认证另一稿。

审查实际重读Heath1908第一卷印284–286上（PDF305–307）、Fitzpatrick2008印/PDF22下–23上、Heath卷前ERRATA（PDF16），并核对[TCD I.19转录](https://www.maths.tcd.ie/~dwilkins/Courses/MA232A/Euclid_ETexts/EuclidBookI_Heath1908/EuclidBookIProp19_Heath1908.php)。扫描来源、页界及公开范围见[来源台账](euclid-elements-i19.sources.zh-CN.md)。原始PDF及扫描未作为公开附件上传。

## 逐项核查

| 检查项 | 结果 |
|---|---|
| 题设与结论的方向 | 已知B角大于C角，目标AC大于AB，顶点和对边匹配正确；与I.18互逆但不自动倒置。 |
| 两个反证分支 | 等长以I.5推出等角；较短以交换标签后的I.18推出反向角序，均保留原先严格角题设。 |
| 结尾穷尽性 | 显式说明长度三分与角序不相容；现代“全序”名称未冒充原文列明的序公理。 |
| De Morgan评论 | 引述位于Heath284下–285上；1847年书第25页是Heath所给书目，不冒称另核原书。两组恰一真模式与局部目标的较弱充分条件被区分。 |
| Proclus及直接证明 | 印285–286评论与原证明确分层；an-Nairīzī归Heron是转述归属而非确定首创权。排分支的exhaustion未混同面积逼近。 |
| 替代引理与应用 | SAS、I.6、角平分与线段顺序展开无错配。现代参数2t/(s+t)保证G在AC内部；BF落点等条件没有仅凭图冒称全形式证明。 |
| 现代模型 | 余切比较与边平方恒等式标为现代欧氏坐标重构，不倒写为原作者方法，也不循环把I.19当原证前提。 |
| 反例与范围 | 正方形/菱形、不可比偏序、结果重叠和缺失等号桥梁反例针对不同推理条件，不声称驳倒原定理。 |
| 历史与AI定位 | 约前300年是作品年代估计；古代推理前史不冒充现代AI论文，不声称穷尽或直接技术传承。 |
| 勘误和版本 | 所查Heath表无284–286条目，结论限定于该表；Fitzpatrick现代排印不当作新古代手稿。 |
