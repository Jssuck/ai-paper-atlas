## 实际阅读与核验

实际目视Heath 1908卷一印刷255–258页（所用扫描PDF第276–279页），包含完整I.6及相关评论；目视本卷附带勘误页（PDF第16页）；目视Fitzpatrick 2008版第12–13页的希英对照I.6与脚注。不是只据OCR、搜索摘要或后世定理表核查。来源链接、页码和版本限制详见[来源台账](euclid-elements-i6.sources.zh-CN.md)。

| 核查项目 | 结果与依据 |
|---|---|
| 作品、版本与年代 | 约公元前300年是作品时代估计；1908、2008是所读现代版本；888年是所引抄本日期。未混同为命题精确写作年。 |
| 反设与截取 | 原文取AB较大，在其上从B截出DB=AC并连DC。正文保留这一构造，不将AD误当对应边。 |
| I.4的对应 | DBC与ACB，D→A、B→C、C→B；DB=AC、BC=CB及夹角相等，结论含DC=AB及三角形相等。正文没有只凭DC=AB宣告矛盾。 |
| 严格部分与整体 | Heath第256页明确提醒隐含位置背景。正文先说明D严格内点和非共线，再交代分割/真部分；不声称共同概念5自行证明全部位置关系。 |
| 相等的含义 | 原证明由I.4取得三角形相等；正文没有将任意同面积推成全等。面积行列式被标为现代证书。 |
| 逻辑约定 | Fitzpatrick第13页关于“不不等”推相等的说明被正确归为现代编者脚注，未冒充古代另列公设。 |
| 逆命题与依赖 | I.5不是可自动倒置的逻辑规则；I.3、I.4为原路线依赖。I.26替代路线被注明为后续定理，须另查依赖。 |
| 历史归属 | 没有把I.5的发现传述移植给I.6；没有把Heath所说书内首个归谬夸大为人类史首次反证。 |
| 原文与教学分层 | 另一大小分支、作用域、坐标、内积、行列式与代数因子等均明确标为教学展开或现代模型，未伪装成原文术语。 |
| 勘误与异文 | 已查所用卷首勘误，未见针对相关页的条目；正文结论限于此次所查勘误，不声称所有版本不存在异文。 |

最终补充的重心坐标权重说明仍属于现代模型，不改变原文归属。有限实跑的数目与日志不由本来源审查独立认证；正文已将其与一般证明分开，由技术审查处理。
