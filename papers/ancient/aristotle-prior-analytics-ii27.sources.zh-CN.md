# II.27：章界、来源与证据台账

对应[原创中文深读](aristotle-prior-analytics-ii27.zh-CN.md)。公开内容限原创解析、必要书目信息与定位；扫描、PDF和转录全文不进入发布包。

## 1. 单元及范围

Aristotle，*Analytica Priora / Prior Analytics*，第二卷第二十七章，**70a3–70b38**。这是公元前四世纪逻辑与论辩思想的前史补读，亦为本书卷末章；版本出版年不得当成单章创作年。上一章止70a2。本单元读到卷末不表示全书所有单元已完成，I.2、II.25仍暂缓，不计入完成。收录不声称穷尽早期迹象推理，也不以它或图灵样稿作为“第一篇 AI 论文”。

## 2. 实读见证

### S1：Bekker1831希腊文与校记

Immanuel Bekker编，*Aristotelis Opera*，vol.I，Berlin，1831，印70左栏第3行至右栏末行。

- [全卷](https://archive.org/details/aristotelisopera01arisrich)
- [印70原图](https://archive.org/download/aristotelisopera01arisrich/page/n85.jpg)

实际查看印70全图，包括27章号、三格例、70b相面条件段和页底两栏校记，末行为70b38。校记记录70a7、10、11、15–18、23–26、29、33、38及70b1、3–5、8–9、12–13、15、19–21、24、28、30–32、36等位置的异文/省略。这里报告所见校记范围，不声称穷尽手稿或建立新校本。

70a10校记有含ἀτελής（不完全）措辞的读法；不能仅据该读法把本章恩梯墨玛定义成省略前提。70b30分离个体的句子未明写主语，需结合前后文与译本解释；本篇不把Jenkinson补出的man谎称为希腊原句中的明文。

### S2：Owen1853英译、长注及正式勘误

Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol.I，London: Henry G. Bohn，1853。

- [全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)
- 实际阅读印 **238–243**，即PDF第257–262页（1起算），含正文、边注、页脚及跨页长注。
- 印238章题是通常性、迹象、恩梯墨玛；238–239的长注讨论eikos译词、迹象作命题/论证的不同用法，以及不宜将恩梯墨玛只按省略形式界定。引Pacius、Hamilton、Whately、Hessey等属于后世解释史。
- 印239–240分别列出有乳、Pittacus、苍白三个原例与教学排列。Pittacus个例支持存在命题而非全称；印240边注把第三格所求全称例标为paralogism，并把第二格失败限定为双肯定。
- 印241讨论tekmērion以及从身心共同变化进入相面论的条件。注1将确证性迹象联系到第一格，并指出仍可攻击前提；不能把“无可反驳”写成无条件真实。
- 印242列一一迹象与可知特性假设，讨论两个特性共同出现的识别困难。注2牵涉十九世纪颅相学并承认标记—特性对应若未充分证明则论证失败；本文只将该注作为解释史，不认可颅相学或身体人格推断。
- **印243译差：** 开头分离个体写“a (lion)”，而Jenkinson写man，希腊70b30无显式主语。若同时采纳整个狮类具有勇敢和慷慨的设定，取“不慷慨的狮”会冲突。本篇显式记录差异，并按另类个体解释识别步骤，而不声称已校定所有版本。
- 印243末段明说大项与中项可换位，中项宽于末项；末尾教学排列又示某个人的特称应用。这不授权从外形判断现实人的品性。
- **ERRATA：** 实际查看正式勘误页，仅列印219章题、273边注、594章题三项，未列238–243。这是有限检索结果，不是“本章无错误”的保证。

### S3：Jenkinson转录、注107–108与版本标记

A.J. Jenkinson译，*Analytica Priora*，收入 *The Works of Aristotle Translated into English*，vol.I。实际阅读全文第27节至卷末、注107和108，并以第26节末交叉确定边界。

- [Book II](https://en.wikisource.org/wiki/The_Works_of_Aristotle/Prior_Analytics/Book_II)
- [固定修订15924675](https://en.wikisource.org/w/index.php?title=The_Works_of_Aristotle/Prior_Analytics/Book_II&oldid=15924675)
- [Source索引](https://en.wikisource.org/wiki/Index:Works_of_Aristotle_-_vol._1,_ed._Ross_-_1928_%28djvu,_worksofaristotle01arisuoft%29.djvu)

实际打开Source索引，Year为 **1928**，编辑W.D.Ross，Oxford: Clarendon Press；本篇只据此报告当前电子转录所标底本，不声称亲见1913印本或核定全部印次沿革。

注107说明“中项”指第一格承担联结的真正中项，不是第二格。注108在70b32建议τῷ代τῶν，列相应抄本与Waitz支持。这是译注校读，本文不把它当作已独立建立的新定本。Jenkinson的分离例补明man；此补足与Owen的(lion)不同，必须保留。

### S4：同作者关联原典《修辞学》I.2

Aristotle，*Rhetoric*，I.2；W.Rhys Roberts英译的[章节转录](https://kairos.technorhetoric.net/stasis/2017/honeycutt/aristotle/rhet1-2.html)。实际阅读章节全文，重点比对1357a–1357b。

1357a讨论听众补足熟悉前提、恩梯墨玛的简短表达和通常材料；1357b区分一般迹象与可构成完整证明的迹象，并给贤者单例与身体征候例。泌乳例在此指最近生育，而II.27说怀孕；不能借此悄悄改写本章原例，亦不据两处例子向现代读者提供生理诊断。该文本用于同作者概念比较，不推定写作先后或直接传承线路。

## 3. 原文—解析对应

| 原文位置 | 需要保存的主张 | 教学处理 |
|---|---|---|
| 70a3–11 | 通常命题与迹象不相同，恩梯墨玛由这些材料构成 | 不偷换成数值概率，也不只按省略定义 |
| 70a11–16 | 第一格以迹象为中项 | 给一般包含链证明，真前提与有效形式分开 |
| 70a16–19、29–33 | 共同个例不能覆盖全体 | 保留存在结论，给两对象全称反模型 |
| 70a19–24、33–38 | 第二格双肯定不能保证归属 | 给三项非空反模型，不否定第二格所有式 |
| 70a24–28 | 补出隐含前提 | 补出不等于证真，也不等于形式自动有效 |
| 70b1–6 | 两种tekmērion命名安排 | 说明第一格中项，不与第二格混淆 |
| 70b7–26 | 身心同变、专属迹象、可获得特性等条件 | 视为未实证的条件，不为相面背书 |
| 70b26–32 | 两特性/标记共同出现的辨别问题 | 区分限定候选的排除与全域规律的证明 |
| 70b32–38 | 大项中项可换位，中项宽于末项 | 相等和严格较广均强于单次包含推导的最低需要 |

## 4. 前史与覆盖边界

本篇把I.4–6、I.32、II.23–24、II.26作为可定位的书内背景，把《修辞学》I.2作为关联原典；后世注家仅列为接受史。没有为增加作者数量而声称不可核实的直接前驱或同期影响。现代集合、反模型、候选匹配与布尔测试属于教学重构，不能归到古人名下；本篇没有原始实验数据、现代测量量表或人格判别证据。
