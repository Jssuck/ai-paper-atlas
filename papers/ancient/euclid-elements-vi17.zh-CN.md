# 欧几里得《几何原本》VI.17 深读：为什么均比例线恰好是等积正方形的边？

**前史补读 · 约公元前 300 年 · 数学构造与形式推理。** 这不是 AI 论文，而是一例如何把三项关系改写成既有四项定理可以处理的形式。弄清「复制中项」这一个动作，就能看到连续比例和面积之间的双向联系。这里只追踪可以定位的原典和书内用法，不声称穷尽几何平均的历史。

## 1. 原典与读本

- 欧几里得，*Elements*，第 VI 卷命题 17。[Clay 希腊文与英译](https://www.claymath.org/library/historical/euclid/files/elem.6.17.html)。希腊文首尾均有双向陈述；网页英译从指定 A、B、C 的开题开始，止于最后一次恢复比例，省略一般性开头与结语。
- Richard Fitzpatrick，*Euclid's Elements*（2008），[双语第 173 页起](https://sidoli.w.waseda.jp/Fitzpatrick_Euclid_Elements.pdf#page=173)。第 173 页有图、希腊全文、几乎全部英译，英文最后一词在第 174 页。希腊 Α、Β、Γ、Δ 对应 A、B、C、D；四个字母指线段，不是某同一图形四个顶点。
- T. L. Heath，*The Thirteen Books of Euclid's Elements*（1908），卷 II，[印刷页 228–229，扫描页 241–242](https://www.wilbourhall.org/pdfs/heath_euclid_ii.pdf#page=241)。末注直接将本命题定位为 VI.16 的特例。
- [Joyce 逐段文本](https://mathcs.clarku.edu/~djoyce/elements/bookVI/propVI17.html)标出 I.3、V.7、V.11 等用于复制和比例替换的链接。它们是阅读时定位依赖的依据，不是希腊正文印出的引文。几种读本的构造、比例项次与证明方向一致。

## 2. 三个输入，两种问题

令 A、B、C 是给定正线段，现代记为 a、b、c。这里「连续成比例」不是三项排得整齐，也不是相邻差相等，而是同一个中项 B 同时作为第一比的后项与第二比的前项。若把以 X、Y 为邻边的矩形记作 R(X,Y)，以 X 为边的正方形记作 S(X)，命题就是：

$$
A:B=B:C \iff R(A,C)=S(B).
$$

等号在右侧表示**等积**，不表示两块全等或具有同样边长。VI.17 给的是检验条件的等价性。若只给两个外项、要从无到有找到中项，原书已有 [VI.13](euclid-elements-vi13.zh-CN.md) 的半圆作图；不把这里的判定说成那条构造。

## 3. 原证：同一条中项，两次出现

1. **造一个等长副本。** 令 D 等于 B。[I.3](euclid-elements-i3.zh-CN.md) 是截取相等长度的构造依据。D 有新记号，却没有新增独立的自由长度；A、B、D、C 是四个位置，两个中间位置要求相等。保留这个区别有助于读清内外项：外项是 A 与 C，内项是 B 与 D。
2. **从连续比例到等积。** 若 A:B=B:C，用 D 代换第二比前项 B，[V.7](euclid-elements-v7.zh-CN.md) 与 [V.11](euclid-elements-v11.zh-CN.md) 解释这一步的等量替换及同比传递。于是 A:B=D:C。由 [VI.16](euclid-elements-vi16.zh-CN.md) 的正向，外项矩形 R(A,C) 与内项矩形 R(B,D) 等积。因为 D 等于 B，后者就是边 B 所确定的正方形。
3. **从等积到连续比例。** 同样复制 D，不把所求比例偷作前提。由已知 R(A,C) 与 S(B) 等积，又知 R(B,D) 是边 B 的正方形，得 R(A,C) 与 R(B,D) 等积。VI.16 的逆向给 A:B=D:C；将 D 换回 B 即完成。注意所得比例不是 A:C=B:D，后者会把等长内项放进同一个比里。

这不是先把四项当数相乘；中间比较的是长度比与面积相等。VI.16 负责把一种判断转为另一种判断。若 D 未复制准确，虽还能套 VI.16，却不一定得到正方形：例如 A、B、D、C 分别为 2、3、4、6，四项成比例且两块矩形等积为 12，但边 3 的正方形面积为 9。

## 4. 现代独立重建

给定正实数 a、b、c，固定长度单位。可将外项矩形在坐标平面中表示为从原点出发、边向量 (a,0)、(0,c) 的四边形；以 (s,t) 为另一个起点取边 (b,0)、(0,b) 就得到中项正方形。取边行列式的绝对值，面积分别是 ac 与 b 的平方。独立的分式消元给：

$$
\frac{a}{b}-\frac{b}{c}=\frac{ac-b^2}{bc}.
$$

bc 为正，比例差为零当且仅当面积差为零。正长度还保证：固定 a 与 c 时，解是平方根的**正支**，并且唯一；若把 b 当任意实数，负根虽平方相同，却不是线段长。外项相等时中项就等于它们；外项不等时，乘积在两个外项各自的平方之间，故正根落在外项之间。这是现代推论，不是原文多加的步骤。

| 算例或边界 | 面积与比例证书 |
| --- | --- |
| a,b,c 依次为 9,12,16 | 两面积都是 144，两个比都是 3/4 |
| a,b,c 依次为 1/2,1,2 | 两面积都是 1，两个比都是 1/2 |
| 误用算术平均 | a=9、c=16 时，算术中点 25/2 的平方是 625/4，不等于 144；相邻差相等不是连续比例 |
| b 不一定有理 | a=1、c=2 时，面积证书是 2，唯一正长度是根号 2。没有有理根不等于没有几何解 |
| b=c=0、a 为正 | 两个形式面积均为零，但两个比都无定义，且图形退化 |
| 对调输入位置 | 16,12,9 仍满足，两个比都倒成 4/3；只把 9 和 12 对调则不保证中项平方等于外项乘积 |

有理数中存在精确正根的判据也可单独核查：将正乘积约成互素正整数的分数；它的正根有理，当且仅当分子与分母都为完全平方数。理由是把假设的根写成最简分数后，分子分母各自平方仍互素，等式两侧的最简表示必须一致。这个判据适用于教学程序的数据类型，不替代对不可公度线段的几何论证。

## 5. 证据位置与历史关系

| 位置 | 可核实的证据 | 边界 |
| --- | --- | --- |
| VI.17 两段主体 | 第一步复制 D；正向由外项与内项等积识别正方形，逆向用同一复制恢复四项比例 | 不是直接用数字的平方来证明原文 |
| [VI.16](euclid-elements-vi16.zh-CN.md) 与 [VI.14](euclid-elements-vi14.zh-CN.md) | 前者把四项比例与两矩形等积相联，直接供 VI.17 调用；前者再依赖后者的等角反向边比 | VI.17 没有把更晚的结果当作前提 |
| [VI.13](euclid-elements-vi13.zh-CN.md) 与 [II.14](euclid-elements-ii14.zh-CN.md) | VI.13 用半圆找到均比例线；II.14 用面积证明得到与给定直线形等积的正方形，包含相近的半圆构造 | VI.17 解释两个目标为何对应，不是 II.14 或 VI.13 原证的依据 |
| [X.27](https://www.claymath.org/euclid_index/classification-of-incommensurables/?chapter=27) | 原文先取 A、B 的均比例项 C，随后把 A、B 所围矩形认作 C 上正方形，来转移面积类别 | 第 X 卷的类别依附参考线与可公度性，不等同于现代数值有理性；更不能从小实验推导整卷分类 |
| [X.54 附引理](https://www.claymath.org/library/historical/euclid/files/elem.10.54.html) | 由 AG、GE 所围矩形等积于 EF 上的正方形，恢复 AG:EF=FE:EG | 这是书内可以核实的逆向用例，前提是先有面积相等 |

**复盘。** 本条的关键是为现成的四项规则补上缺的一个位置，并加等长约束。若先记「比差为零推出面积差为零」，可能漏掉同样重要的逆向；若只记「复制一项」，又可能复制错位置。对形式推理任务，值得保留的是这两条可核查义务：复用前要满足规则的输入条件，复用后要回到原问题的类型和对象。

## 6. 练习（含答案）

1. 外项为 4 与 25，分别用面积和比例核查中项 10。答：外项矩形与正方形面积同为 100，两比同为 2/5。
2. 只知道 a=3、b=6，第三项取多少才成立？答：12；令外项乘积等于 36，得 c=12，再验 3:6=6:12。
3. 在四项规则中若把 D 插到 C 后面，能否得到原命题？答：不能。顺序 A、B、C、D 会让 A、D 变成外项，B、C 变成内项，不能把内项直接认作正方形。
4. 为什么两块面积相同不等于两个矩形全等？答：9×16 和 12×12 都有面积 144，但第一块两条邻边不等，另一块相等。
5. 正乘积为 18/8 时，是否有有理中项？答：有。先约成 9/4，分子分母均为完全平方数，唯一正根为 3/2；用未约分的 18 和 8 直接判会误报无解。
