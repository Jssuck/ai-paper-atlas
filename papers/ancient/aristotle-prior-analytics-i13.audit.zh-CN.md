# I.13：独立论证核验

## 范围与结论

本轮独立逐节阅读正文、来源账本及来源审查，重建正文的定义、一般证明、反例和二十道答案，并编写不导入主教学程序的独立检查器。来源层核验以[来源审查](aristotle-prior-analytics-i13.source-audit.zh-CN.md)的已读底本记录为依据；本报告不冒称另做了一轮希腊手稿考证。结论：下列修订已落实后，正文在所明示的现代经典二值、固定论域语义下成立；没有发现把有限执行当作一般定理证明的断言。此结论不是对所有古代模态解释的裁决。

## 查出的问题及回验

1. 初稿§4.2未显式写出对象与集合的类型限制。已要求并回验加入 `x∈D`、`S⊆D`、每个 `A_w⊆D`。这不是纯排版：若允许D外对象，逐世界相对于D取补与逐点否定不能无条件相同。
2. 初稿§6.2只展示一种含混前提，虽已声明不是完整反例，仍不够便于核验。已回验替换为固定实际主项的完整反模型：C实际含甲，B实际为空而另一世界含甲，A恒空。于是U(C0,B)真，U(B0,A)空真，U(C0,A)假；文中明确此反例依赖允许空实际中项，换成可能B或要求实际B非空后不能继续使用。

后续来源精定位与说明修订亦已回验：科学论述定位改为32b18–22；§5保留两类可能性在转换解释上的区别；§6明确并集主项使用广义P，包含必然B而不是只含双向偶然B。后者尤其避免将B0包含于可能B错误套在狭义偶然集上。数学检查的定义无需变更。

## 逐项论证检查

| 位置 | 独立重建与结果 |
|---|---|
| §3.1—3.3 | 非空W与二值语义明确。P(p)=非N(非p)、非N(p)=P(非p)来自经典量词否定；C同时要求真、假见证。恒假命题确实反驳“非必然推出可能”。三分表在非空W上穷尽且互斥。空W导致全称空真，不是正文允许的输入。 |
| §4.1 | C的内层补交换两个合取项；模态外否定不具有同一性质。总真与混合真假这两个反例分别有效。没有把“尚未证明必然”偷换成语义上的非必然。 |
| §4.2 | 在修订后的类型限制下，对每个x补属性交换真、假见证，从而U与T均保持。这是一般逐点证明，不依赖有限枚举。 |
| §4.3 | 甲乙轮流为A时每个对象都有两类见证，但没有共同全正或全负世界；总甲、可变乙时整句全称偶然而甲不偶然。因此正文所述两方向蕴涵均有合法反例。 |
| §4.4—4.5 | 从U选出T的见证需要S非空；空S确实区分二者。项位交换例中甲恒为B、乙恒非B，反向U为假，即使正向U为真。 |
| §5 | 两套严格正且总和为1的权重支持相同的真假可能性，却给出不同概率；不能从C读出二分之一、频率或原因。正文没有把这些权重说成古代定义。 |
| §6.1 | w0∈W保证实际B包含于各世界B并集。U由大范围推出小范围，T方向相反。正文的U反向反例两个主项非空；独立检查另验T反向失败：只有乙对A偶然，实际B仅甲，可能B为甲乙。 |
| §6.2 | 新完整反模型两前提在同一固定语义中同时成立，结论失败。存在政策、历史解释与加条件版本的限制已明示。没有跨世界拼接出未证明的传递定理。 |
| §0—2、§7—8、§10 | 以古代书籍章节／前史补读定位，版本年不冒充创作年，I.2暂缓不计完成；现代模型、原文、工程类比与运行证据分层。章节覆盖不声称穷尽历史目录。 |

## 二十道答案逐题核验

1：古代作品与1831/1853版本年区分正确。2：非空W下N蕴涵P正确。3：C排除N正确。4：否定位置正确。5：恒假反例正确。6：合取交换证明正确。7：总真反例正确。8：混合真假反例正确。9：空W理由正确，所述是模型选择而非矛盾律。10：允许各对象不同见证正确。11：两个交错单元素世界无共同覆盖正确。12：恒甲、可变乙反例正确。13：非空S为一般U→T补足存在条件正确。14：质量改变不同于项位交换正确。15：不推出等概率正确。16：通常不等于必然，未虚构历史阈值。17：实际世界属于W的前提已给出。18：U范围单调方向正确。19：T方向正确。20：有限枚举不是任意W定理证明；合法反例足以否定普遍命题正确。

## 独立执行证据与限制

检查器位于[argument-review/check_arguments.py](../../reproduction/aristotle-prior-analytics-i13/argument-review/check_arguments.py)，只用Python标准库，不导入主教学实现；检测使用显式条件及异常，不依赖可被优化关闭的assert。分别以普通、`-O`、`-OO`模式实跑，均退出0，记录见[run.log](../../reproduction/aristotle-prior-analytics-i13/argument-review/run.log)、[run-O.log](../../reproduction/aristotle-prior-analytics-i13/argument-review/run-O.log)、[run-OO.log](../../reproduction/aristotle-prior-analytics-i13/argument-review/run-OO.log)。

覆盖126个非空世界真假向量（1至6世界）、682个属性模型（1至3对象，1至3世界）、8736个带指定实际世界的A/B模型（1至3对象，2世界），以及显式反例与概率归一条件，共74968项检查。实际环境Python 3.12.14。数字是列明循环中的输入计数，不是全部可能模型数，也不是独立随机试验次数。

复跑命令（从附件的argument-review目录执行）：

```sh
python3 check_arguments.py
python3 -O check_arguments.py
python3 -OO check_arguments.py
```

审查输入及脚本的SHA-256见[review-inputs.json](../../reproduction/aristotle-prior-analytics-i13/argument-review/review-inputs.json)。摘要仅绑定本轮读过的版本；以后正文修改需重审，不能沿用本报告充当无限期批准。主程序边界测试与软件审查另见附件的独立代码报告。本次没有实测历史自然过程，没有证明任何无限模型结论，也没有声称现代语义与古代体系等价。
