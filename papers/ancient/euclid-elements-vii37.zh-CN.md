# 《几何原本》VII.37：3 能量尽 12，为什么 12 的三分之一是 4？

**AI 数学前史补读 · 深读 v2。** 这不是 AI 论文，也不是古代数学目录的穷尽。承接 [VII.36 的共同度量构造](euclid-elements-vii36.zh-CN.md)，本篇关注从整除关系到可构造的单位分数部分：已知按一种块长恰好分完，怎样给出按指定份数平分的每份大小？

## 1. 文献和校读

- 欧几里得，《几何原本》卷 VII 命题 37，作品通常置于约公元前 300 年；不能把现代印本的出版年当作命题写作年。
- T. L. Heath 译注，*The Thirteen Books of Euclid's Elements*，卷 II，Cambridge University Press，1908，[印刷页 341–342](https://archive.org/details/thirteenbookseu01heibgoog)。扫描物理页 354–355；p.341 有起题、图和构造，p.342 完成交换和结论，其后的代数说明是 Heath 自己的评注。
- Richard Fitzpatrick 希英本（2008 修订），[印刷页 224](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=224)，题面、图、证明、结论都在该页。
- [Clay 希英栏](https://www.claymath.org/library/historical/euclid/files/elem.7.37.html)与 [Joyce 正文和导读](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII37.html)用于横向核读。Clay 英栏停在对应“同一份额”处，没有继续明说如何命名和得出结论；希栏、两印本和 Joyce 都保留这部分。未发现要求改动算术关系的独立勘误。[原典核对](../../reproduction/euclid-elements-vii37/source-review.zh-CN.md)。

## 2. 当时的问题：一个量作两种角色

12 可以排成四组、每组三个单位；也可以排成三组、每组四个单位。若要的是“第三部分”，应读成“三个等份中的一份”，不是“每组三个单位”。前一种排法的 3 是块长；后一种排法的 3 是块数，4 才是每块大小。“同名”指部分的名称由原来的量度数确定，不是说那一部分就**等于**量度数。

卷 VII 的[定义 1–2](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII1.html)区分单位与数；[定义 3–5](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII3.html)区分单一份额、若干部分和倍数。本命题用 [VII.15](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII15.html)交换等次度量中的位置，得到一个带有明确含义的份额见证。此处核对的是卷内的文本依赖，不从中推断失传前驱或同时期文本，也不把现代约束求解的术语归给欧几里得。

## 3. 符号与假设

| 原文（希栏→英栏） | 角色 | 现代记法 |
| --- | --- | --- |
| Α → A | 被量的整体 | $`a`$ |
| Β → B | 量度数，也是所求部分名称的来源 | $`b`$ |
| Γ → C | 用 B 量 A 的次数，由单位数构造；交换后是所求部分 | $`c=a/b`$ |
| Δ → D | 一个单位，不是任意除数 | $`1`$ |

“X 度量 Y”表示 X 的若干个整倍恰好组成 Y。本文用正整数表示量和次数，用 $`b\mid a`$ 表示有正整数 $`k`$ 使 $`a=bk`$。古文的“部分”带有小于整体的要求；现代教学中输入 $`b=1`$ 得整个量，不能据此把“第一部分”等同于古文真部分。若 $`a=b`$，则 $`c=1`$，它的确是现代整数模型中严格小于整体的份额（若 $`b>1`$），但此时原文所称的 C 数值上退化为单位，须另标边界。下文不对古代实践作额外假定。

## 4. 原文的证明：交换量度次数，再转移名称

1. **设 B 量尽 A。** 取 C，使 C 所含的单位个数等于 B 量 A 的次数。此时得到的是整数次数，尚未把 C 当成原要求的部分。
2. **引入单位 D。** D 每次贡献一个单位，所以 D 量 C 的次数等于 C 所含单位数，也就等于 B 量 A 的次数。
3. **用 VII.15 换位。** 从“D 量 C 与 B 量 A 等次”变成“D 量 B 与 C 量 A 等次”。因为 D 为单位，D 量 B 恰好是 B 所含单位数；所以 C 量 A 也是这么多次。现代称为交换同一整积的两个因子，不把 VII.15 本身改称乘法交换律命题：VII.16 才把交换乘法另立为题。
4. **将名称从单位迁到新部分。** D 是 B 的 B 分之一，理由是把 B 分成 B 个单位；C 与 A 的关系有同样的计数，因此 C 是 A 的 B 分之一。这个结尾是 Clay 英栏恰好缺失的部分。

用 12 作 A、3 作 B：B 量 A 四次，故 C 是 4。单位 D 也量 C 四次。换位后 D 量 B 三次，C 量 A 也三次，故一份是 4 而非 3。把 3×4 陈列出来是现代教学画法，不是把原图当成矩形面积证明。

## 5. 现代重构：整数见证，精确而非取整

在整数模型中，从 $`b\mid a`$ 选出唯一正整数 $`c`$ 满足 $`a=bc`$。从乘法换位即可确认以 C 为块长也恰好量尽 A；两次度量共享同一整体，次数分别是 c 和 b，除非两者恰好相等：

$$
a=b\cdot c=c\cdot b,\qquad
\frac{a}{b}=c,\qquad \frac{a}{c}=b .
$$

独立读出命名规则：单位 D 在 B 中是 $`1/b`$；若 C 在 A 中也是这个份额，需满足 $`c/a=1/b`$。上式保证它，且 $`b>0`$ 允许在 $`bc_1=bc_2`$ 时消去 b，故整数见证唯一。唯一性是现代模型的简短补充，不是原命题另立的主张。

【分析延伸】在现代模型中可用有理数表示 $`a/b`$，只要 b 非零；原命题关心的是每份是否能由**整数个给定单位**构成。若把一个原单位改成若干子单位，变更的是表示尺度，不是原来的整除事实。VII.37 证明“整除 ⇒ 存在同名整数部分”；逆向在 VII.38 单列。现代等式让逆向读起来直接，但不应把逆向冒充本命题的原文。

## 6. 算例、反例和可辨误读

| 整体 | 名称来源 | 试取部分 | 检查 | 结论 |
| ---: | ---: | ---: | --- | --- |
| 12 | 3 | 4 | $`3\cdot4=12`$ | 4 是第三部分 |
| 12 | 4 | 3 | $`4\cdot3=12`$ | 3 是第四部分 |
| 9 | 3 | 3 | $`3\cdot3=9`$ | 此例恰巧名称和大小相同，不能泛化 |
| 14 | 3 | 4 | $`3\cdot4=12`$，余 2 | 4 是整数商，不是精确的第三部分 |
| 7 | 7 | 1 | $`7\cdot1=7`$ | 现代：C 为单位，另列边界 |
| 7 | 1 | 7 | $`1\cdot7=7`$ | 现代：整个量，不是古文真部分 |

14 对照说明失败的不是有理数值，而是固定单位下的整数见证。整数搜索中 4 太小，5 太大；等份不能取成一个较粗的近似。另一个错误是拿存在某种份额代替指定份额：12 既有第三部分又有第四部分，验证其中一个不能认证另一个商的值。

## 7. 证据定位与后续作用

| 主张 | 证据位置 |
| --- | --- |
| 由 B 量 A 的次数构造 C | Heath p.341 题面下及随附图；Fitzpatrick p.224 证明前半 |
| 单位 D 引入同次数，再换成 C 量 A | Heath pp.341–342 跨页；Clay 希栏、Joyce 正文 VII.15 标记 |
| C 的部分名称来自 B 而非 C 自身 | Heath p.342 正文下半；Fitzpatrick p.224 结尾 |
| 现代代数法中每份为整数商 | Heath p.342 正文后短评；Joyce Guide 给 12 和 3 的例子 |
| 从整除见证推到多个指定份额 | [VII.39 正文](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII39.html)先构造共同度量目标，再借 VII.37 得到各部分 |

VII.39 借这一条从“几个数都能量尽某一整体”过渡到“整体有几个指定名字的部分”。它并不要求指定部分相加正好成为整体。这里只定位后续使用，不增开下一篇。

## 9. 练习与答案

1. **哪一个量是名称？** B=5 量 A=35 时，C 是多少？它是什么部分？  
   **答：** C=7。7 量 35 恰好五次，因此是第五部分，不是第七部分。
2. **何时交换不会改变数值？** 设 B 量 A 的次数也恰为 B，A 有何形式？  
   **答：** A 是 B 的平方。此时部分大小恰好也等于 B，身份仍不同。
3. **整数商能充当见证吗？** 17 除以 4 的整数商是 4，能否称它为 17 的第四部分？  
   **答：** 不能；四个 4 得 16，留下一个原单位。现代有理数的精确部分是 $`17/4`$，不在原单位整数模型中。
4. **单位替换改变了什么？** 把 14 个大单位各拆成 3 个小单位，能否写出其第三部分？这能证明 3 整除 14 吗？  
   **答：** 42 个小单位的第三部分是 14 个小单位，即 $`14/3`$ 个大单位。不能推出 3 整除 14；变化的是计量单位，不是数 14 的因子。

复盘：交换块长和块数，把“B 量尽 A”的倍数证据变成“C 是 A 的 B 分之一”的份额证据。
