# II.18 独立数学与代码审查

审查日期：2026-10-24。结论：下列绑定版本通过本次审查；这不是对任意程序或全部古代逻辑体系的形式化认证。

## 审查对象与方法

审查者独立阅读Owen印页221的XVIII章及注2、3，并交叉阅读Jenkinson电子转录Chapter18；核查范围为本章的两前提保真论证及向上游命题的追溯。版本定位与异读另见[来源台账](aristotle-prior-analytics-ii18.sources.zh-CN.md)。逐项核对[正文](aristotle-prior-analytics-ii18.zh-CN.md)的符号、假设、证明、三组集合解释和12道练习答案，并阅读全部生产源码和测试。

独立实现没有复制生产程序的递归遍历：它按另一变量顺序作笛卡尔积枚举，直接检查三个局部约束，再检查预先列出的四条根叶路径；逐项比对生产程序的全部128个记录、违反条件的步骤、路径与去重假叶。另检验长度1至4的链以及6项边界条件。源码与真实日志见[独立oracle](../../reproduction/aristotle-prior-analytics-ii18/audit/independent_oracle.py)、[运行记录](../../reproduction/aristotle-prior-analytics-ii18/audit/run.log)。

## 数学核验

- 两前提结论成立：若P、Q保真推出R且R假，全真P/Q将迫使R真，故至少一个前提假。不存在“恰有一个”“两个都假”或唯一因果责任的结论。
- 七节点教学配对D/E→A、F/G→B、A/B→C明确为重构。C假时至少一个假父节点，继续下降得到至少一个假叶。要求每一步有效、解释一致、前提齐全；仅某赋值不违反局部条件不能认证规则在所有解释中有效。
- 第8节按高度归纳的有限树证明成立；有限DAG可采用拓扑高度。共享节点不导致假事实数量等于路径数量。对循环、无限结构和空前提步骤的限制已说明。
- 三组集合模型逐项重算，按A/B/C/D/E/F/G顺序分别为：假真假假真真真；假真假真假假假；真真真假假假假。例二有三个假输入，但只有C→A→E这条全假节点路径；F、G藏在真B上游，不应被冒充为该路径的终点。
- 12道练习答案与上述条件一致；尤其真结论不保证真前提、发现假前提不保证假结论、有限枚举不代替一般归纳、规则可靠性改为待诊断对象必须重新建模。

## 实跑核验与结果解释

独立oracle在普通、`-O`、`-OO`三模式均正常结束，输出逐字一致；其检查使用显式异常而非可被优化删除的裸`assert`。生产15项unittest亦独立重跑通过。

| 核验项 | 独立结果 |
| --- | --- |
| 固定七节点赋值 | 128，全部与生产输出逐项一致 |
| 满足三个具体赋值局部条件 | 82，不称为82个有效证明 |
| 上述82中C假 | 33，全部有假叶路径 |
| 33中路径数1/2/3/4 | 16/12/4/1 |
| 上述82中C真且至少一假输入 | 48；正文和README已明确此分母 |
| 长度1/2/3/4链满足局部条件 | 7/24/82/280 |
| 对应链假根赋值 | 3/10/34/116 |

固定树与长度3的链不是同一图，故33和34并不矛盾。六项边界检查覆盖真中间节点遮断全假路径、共享假叶去重、循环拒绝、缺失真值、非布尔值及未知目标。路径存在性、路径条数与假输入总数是不同量。

这只是低成本有限核验。它不证明每个抽象布尔记录都有古代类项模型，不自动辨认真正的事实错误，不证明任意长度程序实现正确；一般存在命题的依据仍是正文第8节的数学证明。
