# II.23：来源、章界与证据台账

服务于[原创中文深读](aristotle-prior-analytics-ii23.zh-CN.md)。只公开书目、必要定位和原创说明；未公开原典扫描、PDF、全文翻译、私人记录或账户信息。

## 1. 年代与收录边界

Aristotle，*Analytica Priora / Prior Analytics*，第二卷第二十三章，**68b8–37**。本次是公元前四世纪逻辑思想的前史补读，不是现代AI期刊论文。1831、1853及转录页面标示的1928是版本年，不给单章强加一个未经证明的写作年。本章接续II.22，下一章II.24仅为定界兼读，不计完成；目录不是穷尽清单。

## 2. 亲读来源与范围

### S1. Bekker1831原典印本

Immanuel Bekker编，*Aristotelis Opera*，vol.I，Berlin，1831，印68，右栏。

- [整卷扫描](https://archive.org/details/aristotelisopera01arisrich)
- [印68图像](https://archive.org/download/aristotelisopera01arisrich/page/n83.jpg)

亲看完整该页，II.23章号在68b8，II.24章号在68b38，因此本章止37；核对章内A/B/Γ项位置、全体列举段及末尾两种认识次序，也看页下注异文栏。此为针对章界、论证和术语的印本核读，不声称独立穷尽手稿或建立新定本。现代集合证明由本文承担，不以一张扫描替代希腊语校勘研究。

### S2. Owen1853英译扫描、边注、脚注、勘误

Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol.I，London: Henry G. Bohn，1853。

- [全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)
- 实读印 **230–231** 正文、边注及全部本章脚注；印230长注续至231，印231最后一注续至印232页底注区开头。PDF页序249–251（1起算）。另读下一章标题，确认II.23正文在印231结束。
- 印230章题 *Of Induction*；印230注2提苏格拉底归纳与定义，注3说明此处“归纳的三段论”不是狭义普通三段论，并提完备列举难题。这些解释属于Owen与其引述注家，不能当亚里士多德逐字主张。
- 印231边注呈现第三格转第一格；脚注示意把“无胆者都在人马骡范围内”放入覆盖前提。该脚注帮助确认转移方向，但不是动物学调查资料。
- 印231末注与232续注指向《后分析篇》、修辞学、伦理学等认识次序讨论。本次记录这些交叉指引，不冒称已经完整精读全部被引章节。
- **正式ERRATA：** 亲看全卷勘误页，列印219章题、273边注、594章题三项，无印230–231本章条目。只报告此页检索结果，不扩张为没有任何版本问题。

### S4. 前驱关联的原典核查（不是另完成一篇）

Aristotle，*Metaphysics* XIII.4，1078b相关段；W.D. Ross英译，Internet Classics Archive [Book XIII / Part4](https://classics.mit.edu/Aristotle/metaphysics.13.xiii.html)。实际读Part4开头关于理念论起源与苏格拉底归纳、普遍定义的段落。它支持“亚里士多德把两项贡献归于苏格拉底”的有限表述，不能独立确证苏格拉底的全部实践，也不能据网站给出的整部作品单一年份推定本单元日期。

Owen印230注2采用旧卷次写作 *Metaph. xii.4,5*；正文采用现代通行XIII.4并用原典段落核查，不把旧卷次不加说明地复制成当前定位。译注所列Mansel、Whately等是后世解释背景，不是古代同期工作。

## 3. 版本、语义与经验风险

| 位置 | 可见问题 | 本文处理 |
| --- | --- | --- |
| 68b8–9回顾句 | Bekker/Jenkinson属II.23；Owen列II.22末 | 完整阅读并纳入本章范围，说明差异 |
| Jenkinson注97，68b9 | 给比较词次序的校读及版本依据 | 记录校读存在，不说“无勘误”；不影响覆盖定理 |
| 68b23范围措辞 | Owen字面“不超过中项”承接C；Jenkinson说中项不更宽 | 不把Owen短句单独等同于B⊆C；以共同明说的可换位及全体列举条件重构同延 |
| 68b21附近动物句 | 两英译都出现以无胆者长寿说明所列项长寿的表述 | 原句若被当作目标证明的根据会循环；显式把独立性质证据列为教学重构要求，不擅自宣布传抄错误 |
| 68b20个别项 | 例为人、马、骡，不是具名个体样本 | 说明类别并集与具体个体层级差异，不能凭代表个体保证全种 |
| 68b30“无中项” | 第一直接前提与形式重构仍用C易混淆 | 区分解释根据和推导中的形式位置，不宣称解决全部认识论 |
| 动物学内容 | 无可重跑数据、定义与完整清单 | 不把古例认证为现代经验定律；只用人工对象作教学复现 |
