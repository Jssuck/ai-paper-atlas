## 主张—证据对应

| 主张 | 位置 | 限定 |
|---|---|---|
| 已知角ABC大于BCA，求AC大于AB | Heath284题面/设定；Fitzpatrick22下 | 从角序到对边序，与I.18反向。AC对B，AB对C，不能按字母顺序错配。 |
| 如果目标不成立，AC等于或小于AB | Heath284证明起句；Fitzpatrick23上 | 原证实际使用长度比较的穷尽性；现代术语“全序/三分律”是教学显式化，不是说原文列出一套序公理。 |
| 等长分支导出等角，与严格角前提冲突 | Heath284首段，标I.5；Fitzpatrick23 | I.5是等腰底角定理。不能用I.6倒置后冒充原文依赖，也不能只排除等长就结束。 |
| 较短分支导出反向角序，与前提冲突 | Heath284第二段，标I.18；Fitzpatrick23 | 用AB大于AC重新应用I.18，得到C角大于B角；不是无条件倒转I.18。 |
| 两个错误分支均排除，留下较长分支 | Heath284末段；Fitzpatrick23 | 依赖相等、较小、较大分类穷尽及角严格序不相容；不是有限数值枚举。 |
| 三分对应允许逆向推理的一般逻辑框架 | Heath284下–285上 | Heath引用De Morgan, *Formal Logic* (1847), p.25；两组命题各自“恰一真”且逐一对应蕴涵。此处只实读Heath转引，不宣称独立核读De Morgan原书或认为欧几里得已写现代符号模式。 |
| 分情况排除的历史解释 | Heath285中，转述Proclus318.16–23 | “exhaustion”在这里是排尽相斥假设，不应混同面积逼近或现代有限模型穷举。 |
| 历史直接证明与引理 | Heath285下–286上，转述Proclus319–321及an-Nairizi归Heron | 这是评论中的另一条证明路线，不是I.19原证明；归属是Heath报告的传承归属，不是已核实的首创权。 |

## 历史替代方案读到哪里

Heath先给引理：三角形顶角平分线把底边分成不等两段时，接较长底边段的邻边也较长。其证明以延长平分线、截取相等底边段、SAS和等角对等边（I.6）构成比较，不要求把现代角平分线比例定理作为前提。

印286的I.19替代证明先取BC中点D，延长AD到E使DE=AD，连接BE。SAS得到BE=AC且角DBE等于C角。由给定B角更大，B处角平分线BF在该图布置下交AE于A与D之间，从而EF大于FA；用引理得BE大于BA，再换成AC大于AB。这里BF的存在、与AE相交及落点顺序需要几何位置条件；本单元将其作为历史方案和教学分析，不据图像就冒称所有隐藏步骤已经形式化，也不把主复现包当作该替代方案的完整机器验证。

## 公开与推论边界

- 三分关系表、精确点积角比较、坐标、证书及异常输入检查均属现代教学重构。
- 独立比较角序和边序能核查具体输入及代码，不自动认证一般几何定理、原典全部语义或历史首创者。
- 原证无须求角度、用正弦定理或余弦定理；这些现代检验不能倒写为古代证明步骤。
- 本单元不完成I.20、全书或AI前史。阅读扫描、PDF仅用于内部研究，公开只留原创说明和必要书目链接，不附原件或全文翻译。
