## 主张、位置和解释边界

| 主张 | 原始定位 | 必须保留的边界 |
|---|---|---|
| 一边延长后的外角等于两个不相邻内角之和；三内角等于两直角 | Heath316末命题、317证明；Fitzpatrick34–35 | 两项结论分别陈述，后者由前者加相邻内角及I.13取得 |
| BC经过C延长至D | Heath316设定及317图；Fitzpatrick34 | 明确B、C、D次序，不能把D放在CB射线上或取D=C |
| 经C作CE平行AB | Heath317第一句，边注I.31；Fitzpatrick34 | 原文说完整直线，图及角和使用要求选CE射线落在外角ACD内部；严格内部性是应展开的图形位置义务 |
| BAC与ACE相等，ECD与ABC相等 | Heath317两次I.29边注；Fitzpatrick34 | 第一次是AC截线的内错角，第二次是BD截线的外角与内对角；不可删去射线角色 |
| 外角ACD分成ACE、ECD | Heath317“whole angle”处；Fitzpatrick34跨35 | 角量相加依赖非重叠且严格内部的分角，不仅是两条等角式 |
| 给外角等式两边加ACB，并由I.13得两直角 | Heath317后半；Fitzpatrick35上 | 不预先使用待证三角形角和；ACB与BCA是同一普通无向角的反向命名 |
| 早期发现的历史材料来自Eutocius、Proclus转述Geminus、Eudemus等 | Heath317–320 | 本次读的是Heath的材料汇编，未直接读这些古代著作；不得将其转述伪作独立原始考据 |
| 不能可靠超出Eudemus所归Pythagoreans的发现与证明 | Heath320“On the whole”段 | Heath自身判断；Thales、埃及铺砌及逐类三角形发展链包含推测，不宜写成无争议年表 |

## 适用勘误与版本差异

Heath卷前ERRATA没有列出316–322页；Fitzpatrick I.32处未见专属校正脚注。两版原证基本相同，Fitzpatrick用括号明确“和”等补足词。Fitzpatrick35页下方的勘误标记属于I.33，不能误归给I.32。希腊Δ、Ε对应英文D、E。上述只是本次检查范围，不能推出所有版本或手稿均无误。

## 有来源的年代与依赖目录

- Euclid作品约公元前300年的传统定位采用Fitzpatrick导论；作品年代与1908译注、2008修订版年代分列，不为I.32编造精确发表年。
- 书内前驱：I.31提供平行线存在；I.29从平行推出两个角等式，其证明使用第五公设；I.13处理直线上的邻角。I.32原证对第五公设的依赖不能由I.31构造本身不需要它而抹去。
- 历史前驱线索依Heath317–321：Geminus、Eudemus、Proclus、Eutocius与Aristotle；本次未独立实读这些著作。Thales等早期归属保留争议，不以作者声望替代证据强度。
- 后世证明讨论：Heath321列Thibaut、Schumacher和Gauss；本次只读Heath转述，不声称已独立核读书信或Thibaut原书。此目录展示可核实的直接关系，绝非穷尽。
