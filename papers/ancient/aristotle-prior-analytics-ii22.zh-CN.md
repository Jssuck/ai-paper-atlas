# 《前分析篇》II.22：什么时候能倒过来推？从词项换位到偏好比较

## 1. 书目、历史问题与阅读范围

Aristotle，*Analytica Priora / Prior Analytics*，第二卷第二十二章。实际阅读范围包括 Jenkinson 英译电子转录全章及注 90–96、Owen 1853 第一卷印页 228–230 的正文和注释；版本边界与扫描核对见来源台账。本文不是原文全译。

II.21 讨论知道前提却未实际合用的问题；II.22 返回词项关系，汇集若干能使方向逆转的条件，随后转入较可欲与较应避免的比较。它并非现代意义上一篇题目、方法和实验统一的研究论文。Owen 所加章题突出第一格两端换位，但不足以概括后半的分类和欲求论证。

最可核实的前人关系首先在本书内部：I.2 建立否定命题等换位规则；第一格的包含链提供这里的演算基础；本章 68a21–25 的共同属性与换位条件，又被下一章 II.23 的归纳论证明确调用。提及 I.2 是书目性回指，不代表本项目已发布或恢复其暂缓单元。对外部前驱，Owen 印页 230 的脚注将爱情例与柏拉图《会饮篇》联系，这是十九世纪译者的类比，而不是本章正文点名的引文；不能据此断言直接借用，更不据此添加未经核实的同时代影响链。

## 3. 符号和语义：先别把所有 conversion 都写成等号

【教学重构】固定论域 U；A、B、C、D 是 U 的子集，表示对象具有的属性。本文先采用普通二值外延语义，允许空集合；原文并未因此被解释成一套完整的现代集合论。

- “A 属于所有 B”： $`B\subseteq A`$ 。方向由主词 B 指向谓词 A。
- “A 不属于任何 B”： $`A\cap B=\varnothing`$ 。
- 肯定的双向全称述谓： $`A=B`$ ，须有两个包含方向。
- 否定命题的换位：由 $`A\cap B=\varnothing`$ 得 $`B\cap A=\varnothing`$ ，仍只是不交。
- U 中严格二分： $`A\cup B=U`$ 且 $`A\cap B=\varnothing`$ 。两条一起才有 $`B=U\setminus A`$ 。

尤其不能由“不相交”直接写“互为补集”：若 U 有三个对象而 A、B 各占一个，第三个对象可能两者都不属。也不能由否定的“互换”写成 A=B。下面每次倒转都指出所用的规则。

## 4. 肯定链的夹逼：两端相同，中间为何逃不出去？

【原文，67b27–32】A 通过中项 B 述谓 C；若两端 A、C 可互换，则 B 也能与两端互换。

【教学重构】前提是：

$$
C\subseteq B\subseteq A,\qquad A\subseteq C.
$$

逐步证明，而不是只说“显然相等”：

1. 任取 x 属 A，由反向前提 x 属 C，再由 C 包含于 B 得 x 属 B，故 $`A\subseteq B`$ 。
2. 原有 $`B\subseteq A`$ ，合得 A=B。第一步以 C 为中项。
3. 任取 x 属 B，由 B 包含于 A，再由 A 包含于 C，得 x 属 C，故 $`B\subseteq C`$ 。
4. 原有 $`C\subseteq B`$ ，合得 B=C。第三步以 A 为中项。

于是 A=B=C。这里是两次普通全称传递，加上反向包含，不是从一个肯定命题无条件全称换位。

**算例：** U={1,2,3}，A=B=C={1,2}，条件全真；空集三者相等也通过本教学语义。证明无需选择某个保证存在的成员，因此不依赖非空性。

**缺条件的反例：** A={1,2,3}、B={1,2}、C={1} 保留完整正向链，却没有两端反向包含；三个集合严格不同。只增加 A、C 有共同成员也无济于事。不能把“相交”偷换成“可互换”。

## 5. 否定段：对称排斥不等于两端相同

【原文，67b32–68a3】从 B 属于所有 C、A 不属于任何 B 出发，A 也不属于任何 C。随后交换否定项、或把肯定小前提反向，再说明可恢复哪些否定关系。这一小段涉及译者校读，不能只看英文 convertible 一词就套用上一节的等号。

设：

$$
C\subseteq B,\qquad A\cap B=\varnothing.
$$

取任意 x 属 C，得到 x 属 B，故 x 不属 A；所以 $`C\cap A=\varnothing`$ 。否定关系可对称写成 $`A\cap C=\varnothing`$ 。同理原大前提可写成 $`B\cap A=\varnothing`$ 。

**恢复较大类的否定需要什么？** 单从 A 与 C 不交，不能推出 A 与 B 不交，因为 B 可能比 C 大。若另给 $`B\subseteq C`$ ，则取 x 属 B 得 x 属 C，故 x 不属 A；得 $`A\cap B=\varnothing`$ 。这一步用的是肯定小前提的反向包含，不是仅把否定结论换个主谓次序。

对应三条可检查的路径：

| 已有或补入 | 推出的关系 | 作用 |
| --- | --- | --- |
| C 包含于 B，A 与 B 不交 | A 与 C 不交 | 否定向子类传递 |
| A 与 B 不交 | B 与 A 不交 | 全称否定的对称换位 |
| A 与 C 不交，B 包含于 C | A 与 B 不交 | 用反向小前提，从结论恢复大前提 |

末条说明为什么原文区分“从结论出发”的情形；而若一开始仍保留原大前提，恢复它当然在逻辑上冗余。研究目标是展示推导路线的可逆条件，不是把已知事实重新宣布为新发现。

**反例：** U={1,2,3}，A={1}、B={1,2}、C={2}。有 C 包含于 B 且 A 与 C 不交，但 A 与 B 相交。所以不能省略反向小前提。另一方面 A={1}、B={2}、C={2} 可满足整个否定推导，却 A 不等于 B；这直接阻止“所有 convertible 都是等号”的误读。

## 6. 两个严格二分：为什么另一半也随之相同？

68a3–10 先讨论对应词项互换时，二择一结构如何保留。【教学重构】若 A=B、C=D，且 A、C 构成 U 的严格二分，则 B、D 当然也覆盖 U 且互不相交：任一对象原来恰属 A、C 中一个，将两项分别换为相等集合即可。这里“或”后面的“不同时”不可漏读为普通兼容析取。

68a10–16 的更有用结论是：

$$
A\cup B=U,\quad A\cap B=\varnothing,\quad
C\cup D=U,\quad C\cap D=\varnothing,\quad A=C
\quad\Longrightarrow\quad B=D.
$$

原文用反证写出一向；Owen 印页 229 注 1 指出另一向省略，本文完整补足。

**先证 D 包含于 B。** 任取 x 属 D。假设 x 不属 B，由 A、B 覆盖 U 得 x 属 A；由 A=C 得 x 属 C。这与 C、D 不交冲突。因此 x 属 B。

**再证 B 包含于 D。** 任取 x 属 B。假设 x 不属 D，由 C、D 覆盖 U 得 x 属 C；由 A=C 得 x 属 A。这与 A、B 不交冲突。因此 x 属 D。两向合得 B=D。

**具体算例：** U={1,2,3,4}，A=C={1,3}，B=D={2,4}。这不是因为另一半“长得像”，而是每个对象没有第三种去处。

**删除覆盖条件：** U={1,2,3}，A=C={1}、B={2}、D={3}。两对各自不交，A=C，但 B≠D；对象2、3的去处未由两对分割共同约束。

**删除不交条件：** U={1,2}，A=C={1}、B={1,2}、D={2}。两对都覆盖 U，A=C，仍 B≠D；允许重叠就不能认定余项是唯一的补集。

原文“未生成—不毁灭／生成—可毁灭”例应作为**在其对立划分与等值假设下**的应用理解。这里没有通过集合程序证明物理宇宙必然满足这些命题，也不把“可毁灭”未经解释就等同于所有日常意义的“不永恒”。

## 7. “只有 B 和 C”：穷尽性、层次与一个不能静默删掉的短语

68a16–21 说 A 述谓 B、C 而不述谓其他，B 又述谓 C，因而 A、B 可互换；结尾保留“除 A 自身”。这个说法在词项述谓层次上讨论，不能原封不动说成三个普通对象集合之间没有任何解释问题。

【明确限定的教学重构】把“仅 B 和 C”解释为对象范围由两类穷尽，即：

$$
A=B\cup C,\qquad C\subseteq B.
$$

由并集定义，任取 x 属 A，则 x 属 B 或 C；后一情形又得 x 属 B，所以 A 包含于 B。反向由 B 包含于 B∪C=A 得出，故 A=B。

**不是原文逐字形式化：** 原文提到一个词项述谓自身，并把 A 自身列作例外；上述一阶对象集合模型把谓词和对象分型，没有把谓词 A 当成 U 中的一个对象来讨论“它属于自己”。因此它只抽取穷尽分类的外延核心，并未解决文本的自述谓问题。若要研究“所有可被 A 述谓的词项”这一更高层范围，必须另定义词项论域及述谓关系，不能把 U 和其幂集不加区分地混用。

**为何穷尽性不可少？** A={1,2,3}、B={1,2}、C={1} 时，B、C 都包含于 A 且 C 包含于 B，却 A≠B；对象3正是“没有其他”所禁止的剩余部分。

## 8. 从共同属性到全称规则：给下一章归纳留下的桥

68a21–25 的前提是 A、B 都述谓全部 C，且 C 与 B 可互换。教学写法为：

$$
C\subseteq A,\qquad C\subseteq B,\qquad B\subseteq C.
$$

任取 x 属 B，由补入的反向包含得 x 属 C，再得 x 属 A，因此 $`B\subseteq A`$ 。原来的 C 包含于 B 对这两步证明不是必需，但它说明为什么这里说 C 与 B“可互换”，而不只是新添一个孤立包含关系。

**反例：** A=C={1}、B={1,2}。A、B 在 C 上完全共现，却对象2属于 B 不属于 A。因此“共同出现在一些或一类对象中”不能升级为“所有 B 都是 A”。

下一章 II.23 直接调用本段，用穷尽的个别集合建立反向涵盖。本文只说明这一文本连接，不提前把下一单元算作完成，也不把它等同于现代从有限样本学习任意总体的统计归纳。

## 9. 偏好段：结论有效，靠的不是三个大小号而已

68a25 起转向两对相反项：A 相对于 B 较可欲，D 相对于 C 较可欲，而组合 AC 比 BD 较可欲，欲推出 A 比 D 较可欲。原文随后诉诸相反项的欲求与避免程度对应，并排除 A、D 等优及 D 优于 A 两种情况。

【分析】这已经不只是集合包含。至少需要解释：相反项的强弱如何反向对应；同优替换是否保持组合评价；较大的好处加较小的坏处为何严格胜过反方向组合；以及比较是否穷尽。若只保留 A>B、D>C、AC>BD 三句，结论不自动成立。

**原论证结构的重建：**

1. 假设 A 与 D 同等可欲；相反项的程度对应使 B、C 同等应避免。若组合保持这种替换，AC 与 BD 同优，和前提冲突。
2. 假设 D 优于 A；程度反向对应使 B 比 C 较少应避免。若组合对这两方面单调，BD 兼有更大的好处与更小的坏处，应优于 AC，又与前提冲突。
3. 若 A、D 的比较是完备的，只剩 A 优于 D。若允许不可比，还不能仅靠上述两次排除得到严格优势。

【教学重构，不是原文效用理论】选一个足够强而易于检查的数值模型：A、D 的效用分别为正数 a、d（所以也满足 A 优于 B、D 优于 C）；各自相反项 B、C 的效用为 −a、−d；组合效用可加。

$$
u(A)=a,\quad u(B)=-a,\quad u(D)=d,\quad u(C)=-d,
\qquad u(AC)=a-d,\quad u(BD)=d-a.
$$

所以：

$$
u(AC)>u(BD)
\iff a-d>d-a
\iff 2(a-d)>0
\iff a>d.
$$

这里可加性和零点对称是**充分的教学假设**，比原文的定性说明更具体；不是说亚里士多德发明了这一效用函数，也不说只有数值可加才能重建其推理。例取 a=3、d=2，AC 的效用为1，BD为−1，得到 A 优于 D。

**拆掉对称性即可失败，即使仍可加：** 令 u(A)=3、u(B)=0、u(D)=4、u(C)=2。A>B、D>C，且 AC=5>BD=4，却 A<D。若希望两项“坏处”确为负数，可取 A=3、B=−2、D=4、C=−0.5，则 AC=2.5>BD=2，仍 A<D。名称叫“相反”而没有强度规则，不足以排除这些模型。非加性情境还可能存在组合协同或冲突，不能无条件沿用上述代数。

## 10. 爱情例与目的：哪些是应用，哪些不是已证明的普遍事实？

68a39–68b7 把四项用于被爱者的情感倾向及是否实际给予亲密满足，并据组合偏好判断被爱本身较重要，再转到目的与手段。理解此例要区分三层：

- **条件性的偏好输入：** 某种恋爱中的选择者更喜欢“有相应情感倾向但未实际满足”而非“实际满足却无该倾向”的组合。这是原文的设定，不是本项目调查得出的所有人的偏好。
- **比较推理：** 在上一节所需结构成立时，比较组合可帮助判断哪一方面更值得追求。不能从少数选择行为直接识别全部个人效用。
- **目的论结论：** 从更重视某方面进而说它是目的，另有关于欲求与行为目的的解释承诺；集合包含证明或数值穷举都未验证该承诺。

译文对情感倾向、取悦、亲密行为的措辞不完全一致。本文保留论证角色，不利用古代例子建立现代人际规范，不把“不实际满足”美化成操纵他人的策略，也不将这一段当作现代心理实验。它的价值在于暴露：从形式比较走向实际解释时，新的实质性前提已经加入。

## 11. 最小复现：检查什么，不检查什么

**【真实实跑】** 普通、`-O`、`-OO` 三模式各9项单测通过，三份生产 JSON 逐字一致；正式集合枚举在1、2、3对象域共4368个四词项世界，七条规则的满足前提模型均无结论违规。偏好整数四元组枚举2401组，175组满足简化前提，其中70组不满足结论；对称正数模型25组中10组满足前提，无违规。独立布尔审计另含空域，共4369世界、30583对规则结果交叉比对通过。详见原始日志，不将手算冒充执行。 本文第4–9节的例子标为教学计算，不声称是原作数据。有限模型无反例不是一般定理的证明；一般论证在正文的任取元素、反证和代数步骤中。程序也不能裁定希腊文校读、宇宙论事实、人类爱情或目的论是否为真。没有数据集、模型训练或现代统计基线，不能硬套实验论文的指标，也不声称完整复现古代人的认知。

## 12. 局限、合理延伸与复盘

本章可以启发今天的规则审计：记录一条边是包含、等值、排斥还是互补；倒推时检索缺失的反向边；把穷尽分类标志和经验样本严格分开。偏好段则提示，观测组合排序与识别组成因素的价值不是同一任务。这些是现代分析推论，并非已证实的古今技术传承。

三项局限尤其重要：第一，集合语义淡化了词项述谓自身的层次问题；第二，否定段的字母与补文存在版本问题，程序不能替代校勘；第三，偏好与目的论需要实质性结构，不能靠三段论术语自动获得。下一步合理的研究是分别扩大模型和核对文本，而不是把一段顺手的形式化宣布为全文唯一正确解释。

复盘时可问：我是否写出了每个“互换”的两个方向？否定的方向改变是否被偷换成相等？“或”是否还要求互斥？“只有”是给定穷尽条件还是有限观测？数值模型是解释工具还是被冒充原文？如果这五项没有逐一回答，所谓倒推很可能只是隐藏前提。

## 13. 带答案练习

1. **已知 C 包含于 B、B 包含于 A，再给 A 包含于 C。分别用谁作中项推出 A 包含于 B 与 B 包含于 C？**
   答：第一项用 C，第二项用 A。与原方向合并，三集合相等。
2. **A 与 C 不交、C 包含于 B，是否推出 A 与 B 不交？**
   答：否。A={1}、B={1,2}、C={2} 即反例。加 B 包含于 C 才能按本章路线恢复。
3. **两个二分共享同一前半部，为何证明后半部相同需要两向？**
   答：仅 D 包含于 B 允许 B 更大。再互换两对分割的角色证明 B 包含于 D，才得等号。
4. **若 U={1,2}，A=C={1}、B={1,2}、D={2}，互补等值推理哪条假设失效？**
   答：A 与 B 不交失效；两对覆盖和 A=C 仍成立。
5. **“A 述谓 B、C，且 C 包含于 B”哪里还缺条件？**
   答：不能排除 A 中另有对象；教学外延重构需 A=B∪C。原文自述谓短语另有层次问题，不能由这条补充声称已全部解释。
6. **C 同时包含于 A、B，为什么不能从 C 的共现直接推广到所有 B？**
   答：B 可能超出 C。取 A=C={1}、B={1,2}。添加 B 包含于 C 才排除额外对象。
7. **在对称加性模型 a=2、d=5 下，两个组合怎样排序？**
   答：AC=−3、BD=3，所以 BD 优于 AC；不满足原设定 AC 优于 BD，没有矛盾。
8. **是否仅凭 AC 优于 BD 就证明所有恋爱者都更重视被爱而非亲密行为？**
   答：否。尚需确认个体的组合偏好、相反项结构、组合比较条件及目的论解释；本单元没有这样的经验调查。
