## 3 独立数学核验

### 3.1 四与六是在数不同的东西

在允许空项但论域非空的现代模型中，正向有效式恰为AAA、EAE、AII、EIO。在三项均非空模型中另有AAI、EAO，共六式；生产前提对仍只有AA、EA、AI、EI。

AAI与EAO的最低附加存在条件均可取S非空。在AA前提下，S非空已经迫使M、P非空，故此时它与三项非空等价；在EA前提下P仍可为空，三项非空政策才额外加强了P的存在。最终主文对这一差异表述准确。

### 3.2 十二类失败的完整性

独立逐个代入G1–G4：

- G1同时覆盖AE、IE、AO、IO。
- G2同时覆盖EE、OE、EO、OO。
- G3覆盖IA、II。
- G4覆盖OA、OI。

每组两个模型均保持指定两前提为真，且P、M、S全非空。第一模型S全在P内，使E和O为假；第二模型S与P分离，使A和I为假。由此，对十二类中任一前提对、任一候选正向结论，都确有反模型。此处量词顺序是“对每个结论存在反模型”，不是一个模型让四个结论同时为假。

四个成功前提对的额外候选也全部排除：AA的非空相等模型排除E/O，空S排除I；EA的非空分离模型排除A/I，空S排除O；AI与EI的混合S模型分别阻止全称升级，另用纯包含或纯分离模型排除不受保证的另一特称。加上四条直接证明，16对分类在两种政策下闭合。

### 3.3 反向检查没有偷换问题

反向结论只交换结论槽位为(P,S)，不改变两前提。完整核得：

| 前提对 | 允许空项的反向结论 | 三项非空的反向结论 |
|---|---|---|
| AA | 无 | I |
| AE | 无 | O |
| AI | I | I |
| EA | E | E、O |
| IE | O | O |
| 其余11对 | 无 | 无 |

IE的存在见证同时在M、P内，且因E(S,M)而不在S，直接给出O(P,S)。AE需要M非空才能使用同一路径；M为空、P=S={a}即反例。I.7开头提供相应邻章文本支持，但现代推导本身不依赖把全称命题偷偷赋予存在承诺。

### 3.4 八类型论证的充分性与必要性

任意模型中每个对象映射到其PMS成员类型，实际出现类型构成非空支持T。全称真值只看有无违反类型，特称真值只看有无见证类型；压缩因此同时保持前提和候选结论的真假。每个词项非空亦由相应位是否出现决定，所以两种模型政策均保持。

反过来，每个非空T直接构成合法模型。故若存在任意大小的反模型，便有至多八对象的规范反模型；若规范枚举中找到反例，它本身就是原语义反例。这里不是仅证明从小模型到大模型的一侧。

非空支持共2⁸−1=255。三项均非空的支持数用容斥为256−3×16+3×4−2=218。空支持已在后者中排除，不再减1。类型000必须保留以表示论域非空而三项皆空。词项名称不同不要求外延彼此不同。

这些结论只针对已声明的语言；支持压缩不保留同类型对象重数。无显式计数算子不意味着某些前提不会间接要求多个对象，最终主文没有保留这种过强断言。

### 3.5 “最小反例”的范围

实现按支持基数、再按类型字典序排序。若存在对象数更少的任意反模型，将其压缩不会增加对象数，所得规范反例应先被枚举。因此返回值在所选语义下确为最小论域基数；它不是自动最小化词项总大小或任何其他目标。README与WALKTHROUGH中的论证足以支持这一声明。
