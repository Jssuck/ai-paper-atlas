# 欧几里得《几何原本》VII.18：两个乘数作用于同一个数，为什么两积保持乘数之比？

> AI 数学与形式推理前史补读。此处从现代论文主线回看约公元前 300 年的古代算术，实读 1908／2008 版。不是 AI 论文，也不是穷尽式目录。

## 1. 书目与问题

- Euclid, *Elements*, VII.18。[Clay 希英对照与第 137 叶手稿入口](https://www.claymath.org/library/historical/euclid/files/elem.7.18.html)。T. L. Heath, *The Thirteen Books of Euclid’s Elements*, 卷 II（1908），印刷页 318，题述、图、原证和评注同页。
- Richard Fitzpatrick, *Euclid’s Elements of Geometry*（2008 修订），[希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=209)，页 209。[Joyce 在线本](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII18.html)提供完整证明。参见[原典核对](../../reproduction/euclid-elements-vii18/source-review.zh-CN.md)。

取六份 4 与九份 4，为什么两份总量之比等于六对九？从现代算式看，只要约掉共同的 4。原书却把这一事实与 [VII.17](euclid-elements-vii17.zh-CN.md) 分开证明：前一命题固定的是**取多少次**，本篇的起始构造固定的是**每次取哪一个数**。两条命题结论形状相似，但共同因子的角色不同。

## 2. 标号、定义与输入

| 英文／希文 | 原始角色 | 交换后角色 |
|---|---|---|
| A／Α | 规定取 C 的次数，计数为 a | 被重复的一块 |
| B／Β | 规定取 C 的次数，计数为 b | 被重复的另一块 |
| C／Γ | 两次构造中都被重复，块长为 c | 规定共同的重复次数 |
| D／Δ | a 个 C 构成的第一积 | 仍是第一积，不与 E 对调 |
| E／Ε | b 个 C 构成的第二积 | 仍是第二积 |

据[卷 VII 定义 15](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII15.html)，A 乘 C 的意思是按 A 的单位数去累加 C。本文记前一项为给次数的乘数，后一项为被乘数。Joyce 英文开头的被动式容易让读者把 C 读成原先的给次数者，但紧随的原证先从 A 乘 C 出发，再换成 C 乘 A；Clay、Heath、Fitzpatrick 的设例也明确了方向。这里没有一条另设的单位线；重复次数来自数所含的单位，单位和原题给定的数仍有区别。

## 3. 原证：交换两次，把共同项移到同一位置

1. **固定两个积。** 先以 A 乘 C 构造 D，以 B 乘 C 构造 E。两个积不是相等的假设，题目要求的是它们的比例。
2. **分别交换。** 用 [VII.16](euclid-elements-vii16.zh-CN.md)，A 乘 C 与 C 乘 A 生成同一个 D。按同一理由，B 乘 C 与 C 乘 B 生成同一个 E。交换发生在每一积的内部，不是把 D、E 调换。
3. **调用 VII.17。** 现在 D 与 E 都可由同一个 C 给次数，分别重复 A 与 B。这个共同因子在正确的位置，方可直接用 VII.17，得 A:B=D:E。

$$
D=AC=CA,\qquad E=BC=CB
\quad\Longrightarrow\quad A:B=CA:CB=D:E .
$$

Clay 在线英栏停在认定 C 是共同乘数处；希腊栏、Heath、Fitzpatrick 和 Joyce 都继续写出最终的比例。Fitzpatrick 在第一次换位标 VII.16，第二次写同理由，最后标 VII.17；不是证明只检查了一个积。Heath 页 318 的符号评注也把两个换位分别写出。

## 4. 现代重建与独立核验

取非单位正整数 a、b、c 表示 A、B、C 里的单位个数。按定义，先构造 $`d=\sum_{i=1}^{a}c`$、$`e=\sum_{i=1}^{b}c`$。现代教学可按两份有序格子核对交换：第一份有 a 行、c 列，一种数法得 a 个 c，另一种数法得 c 个 a；第二份以同样方式由 b 个 c 改数成 c 个 b。这两份各自计数，不要求格子集合相同或大小相等。原证直接援用 VII.16，不画这两个矩形。

换位后，d 以 a 作块量尽，e 以 b 作块量尽，都是 c 次。于是：

$$
\frac{a}{d}=\frac{1}{c}=\frac{b}{e}
\quad\Longrightarrow\quad
\frac{a}{b}=\frac{d}{e}.
$$

左段是 VII.17 所用的共同辅助比，右段是其交互结果。现代检验可另从 $`d=ac`$、$`e=bc`$ 得 $`d/e=(ac)/(bc)=a/b`$；此处依赖 c 非零。把两个比放入等式后交叉相乘，也能独立查验 $`ae=bd`$。这些是现代核验，不是把后面的 VII.19 当成本篇前提。

## 5. 算例与反例

| 给定 A、B、C 或操作 | 所得 D、E | 检查 |
|---|---|---|
| 6、9、4 | 24、36 | 先取六个／九个 4，再各取四个 6／9；比为 2/3 |
| 9、6、4 | 36、24 | 一起交换两路的输入与输出，比反向为 3/2 |
| 6、6、4 | 24、24 | 现代相等情形；比为 1 |
| 两路原数仍为 6、9，但各用 4、5 | 24、45 | 两边都能按其因子累加，然而共同 C 的前提失效，比为 8/15 |
| 给定 6、9、4，却呈交 30、45 | 30、45 | 比碰巧仍为 2/3，但每次取的是 5，不是指定的 4 |

最后一行区分了**结论正确**与**证明见证正确**：同一原比可以由不止一个缩放量保持，不能从比值倒推出一定用了给定的 C。若 C=1，现代模型是原样复制；若 C=0，两积都是 0，后项为 0 的分数没有定义。这两个现代边界不计入古书的非单位数模型，负数或其他运算也不属这里的重复相加论证。

## 6. 证据、后文与限度

| 主张 | 原典位置 | 怎样核实 |
|---|---|---|
| A、B 是原先给次数的一方 | Heath 318、Fitzpatrick 209 的题述和设例 | 各自作用于共同的 C |
| 经两个换位，D、E 的身份都不变 | 同页原证中段 | 从 A 乘 C 到 C 乘 A，从 B 乘 C 到 C 乘 B |
| 得到共同乘数后才用 VII.17 | 同页证末；Clay 希文完整 | C 同时给出两份重复的次数 |
| VII.19 直接使用这一侧的保比 | [VII.19 正文](https://www.claymath.org/library/historical/euclid/files/elem.7.19.html) | 在那一篇的标号中，A 乘 C 得 G，B 乘 C 得 F；共用被乘数 C，于是 A:B=G:F |

现代类比：把两份样本都复制相同次数，样本数的比不变；若既要保证比例又要保证用了预先指定的复制次数，额外检查两个输出相对于各自输入的倍数。这里只说明这种验证结构可以怎样用，不把论文或软件的设计追溯为欧几里得的直接影响。

## 8. 复盘与练习（含答案）

要点：**共同的是每次取的数 → 分别交换两个积内部的角色 → 共同的是次数 → 调用 VII.17。**

1. **题：** A=8、B=12、C=5，换位前后第一积的组块分别是什么？  
   **答：** 先是八块 5，后是五块 8；都是 D=40。第二积同理为 E=60，D:E=2:3。
2. **题：** 若 D、E 误记为 48、72，能用结果比证明依然用了 C=5 吗？  
   **答：** 不能，二者仍是 2:3，但分别是 8、12 的六倍，不是五倍。
3. **题：** 只交换第一积内部的 A 与 C 就能直接引用 VII.17 吗？  
   **答：** 按此证明路线不能。第二积还没写成由 C 给次数，必须把两条构造都转成 VII.17 的形式。
4. **题：** 辅助比 A:D 与目标比 A:B 一定相同吗？  
   **答：** 不一定。上例辅助比为 1/5，目标比为 2/3；前者是换位后的共同缩放见证。
5. **题：** 令共同的 C=0，会得到两个相等的积，为什么不是保比反例？  
   **答：** 它不满足古题的数域，现代比式中的 D:E 也成为未定义的 0:0；积相等不等于比存在。
