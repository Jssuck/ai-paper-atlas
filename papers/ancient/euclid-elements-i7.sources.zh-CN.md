## 主张—位置—证据性质

| 主张 | 精确位置 | 证据性质及注意事项 |
|---|---|---|
| 固定基底、同一侧、另一个顶点、两端分别对应的相等边共同构成命题条件 | Heath 258–259；Fitzpatrick 13 | 原命题。不能把“分别对应”改成无序的长度集合；不能删除同侧条件。Heath 的部分括号文字是译者为使省略句法明白而补入。 |
| 连结两个假设顶点，分别对以 A、B 为顶点的等腰三角形使用 I.5 | Heath 259；Fitzpatrick 13–14 | 原证明；连接使用公设 1，角相等使用 I.5。 |
| 角的严格大小关系与另一组角相等构成矛盾 | Heath 259；Fitzpatrick 13–14 | 原图形下的证明链。角的“整体大于真部分”依赖射线位置，不能把图画当成对所有位置情况的穷尽证明。 |
| 原文只处理一个图形情况；角的包含关系还需要空间位置依据 | Heath 260 | Heath 评论。其指出可补写被省略的不等式，并讨论位置公设；应区别于 Euclid 原文已经显式列出的论证。 |
| 一个顶点位于另一三角形内部的第二种情况，借助延长线及 I.5 的底边下角处理 | Heath 260 | Heath 转述的 Proclus 补充及 Simson 等版本的处理，不是上述传世原证明正文。延长 AC 至 E、AD 至 F，得到 ECD 与 FDC 相等，再结合角的包含关系导出矛盾。 |
| 顶点落在 AC 或 BC 上是另外的边界位置 | Heath 260 末尾 | Heath 称此情况无需证明；若正文补用真子线段短于整体，应标为教学补充，并说明顶点与端点相异。 |
| I.7 不仅服务于 I.8，也给先前构造提供同侧唯一性信息 | Heath 261 | 译注中的用途分析；不能因此把 I.7 改写为任意边长都有解的存在性定理。 |
| I.8 的原证明调用 I.7 | Fitzpatrick 14，I.8 证明；亦见 Heath 261 的讨论 | 后续命题依赖关系。以 I.8／SSS 作为 I.7 原证明的依据会形成循环。 |
| 平方距离相减、坐标或两圆交点解释 | 不在上述 I.7 原证明中 | 只能作为明确标注的现代教学重构，不可归为 Euclid 的符号或证明方法。 |

## 引用与解释纪律

1. 原命题的否定对象是：在固定非退化基底的同一侧，存在两个**相异**顶点，且到基底两个端点的长度逐端分别相等。结论是条件性唯一性，不保证给定长度可构造。
2. 异侧镜像用于说明同侧条件不可删，并不反驳原命题。共线顶点、重合端点以及零长度不自动属于原文的非退化三角形范围。
3. 同一侧的两个候选位置仍可能产生不同图形关系。正文应区分原图、评论补充的内含图形、边界位置，以及现代重构如何覆盖其声明的范围。
4. Heath 提及的其他古代作者、后来的构造解释和应用属于评论者提供的历史关联；不能仅凭这些评论宣称 Euclid 直接依赖某作者，或给 I.7 指定确切发现年份。
5. 本台账核查两个指定版本及所附勘误表，不宣称穷尽手稿谱系、所有译本或全部古代前驱。有限算例和计算机枚举只是教学检查，不是一般几何定理的证明。
