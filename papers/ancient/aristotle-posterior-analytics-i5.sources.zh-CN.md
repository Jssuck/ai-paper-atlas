# 《后分析篇》I.5：来源台账与解释边界

对应[中文深读](aristotle-posterior-analytics-i5.zh-CN.md)。只公开核读说明和书目，不收入扫描件、OCR或全文翻译。

## 阅读范围与年代

Aristotle，*Analytica Posteriora / Posterior Analytics*，**I.5，74a4–74b4**。Bekker1831印74左栏第4行起章5，右栏第5行起章6；Owen1853印256章V标题至印258开头三行与之对应。本章完整包括普遍证明误判的几种来源、平行线、只存在等腰三角形的假设、比例交换、分种证明和铜制等腰三角形的抽去限定检验。

作品年代仅标公元前四世纪范围，不由传本排列推出单章写作先后。这里是AI知识与解释的思想前史补读，不称现代AI论文，不声称已穷尽古代论证传统。

## S1：Bekker1831扫描与校记

Immanuel Bekker编，*Aristotelis Opera*，vol.I，Berlin，1831。[卷本](https://archive.org/details/aristotelisopera01arisrich)，[印74图像](https://archive.org/download/aristotelisopera01arisrich/page/n89.jpg)。实际查看本页两栏、章号及底部校记。本章相关校记列左栏7、8、9、16、17、19、21、26、27、33、36、37行，以及右栏3行；包括词形、词序、删省等。此处记录所见版本证据，不据此声称完成手稿谱系校勘或所有异读的裁决。

末段的“抽去”不能不加说明地改成破坏实物的操作：论证关注所凭的规定与属性为何归属。图形和界限不能被彻底消掉，尚不等于它们就是该属性首要而恰当的说明主体。

## S2：Bekker1837希腊电子转录

[Graeco-Arabic Studies全文与版本说明](https://www.graeco-arabic-studies.org/view/arist.analytpost-orig-gr1)，页面标Bekker，*Aristotelis Opera*，Oxford，1837，I，182–257。实际读章号5至6之间全文，对照1831印74。它是另一印本的电子转录，不是独立古代手稿。原文的“按数”与“按种/形式”差别，支持本章区分逐类覆盖与作为三角形本身的共同根据；它不取消现代逻辑中合法的穷尽分类讨论。

## S3：Owen1853译文、注释与ERRATA

Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol.I，London: Henry G. Bohn，1853。[全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)。实际读印256–258（本地PDF第275–277页），本章止印258前三行；258章VI标题以下及其脚注属于后章，未算本章阅读成果。

- 印256正文列出三种误判情形；同页脚注把错误原因重新分作四种，还引Locke、Dugald Stewart、Whately及Waitz。脚注是后世解释层，不能说亚里士多德本人引用这些人，也不能把脚注四项冒充正文原有的四项。
- 印256平行线例的英文表述容易误读为任意两条直线不相交。对照希腊文角相等的论述和Mure的明确表述，应按同一直线的垂线这一特殊情形来解释；使结论成立的几何关系不局限于直角。具体平面、角位置及非重合条件在现代展开中应显式说明。
- 印257比例交换例列数、线、立体与时间，并说共同者原先缺少一个名称。本章没有点名某位发现者，也没有给出完整比例理论；不能据“如今”直接补出精确发现日期或作者。现代实数交叉乘法只可作有限教学类比，不能冒充古代一般量论的原证。
- 印257等边、不等边、等腰三类分证，即使穷尽，仍不自动具有作者要求的作为三角形本身的知识。脚注1阐释“按数”；脚注2说明Taylor、Buhle用“普遍地/无条件地”互释；脚注3再次强调分种证明与三角形本身的普遍属性之别。正文说可用同一或不同证明，不应把错误仅限于“用了三份不同证明”。
- 印257末至258开头的铜制等腰例，应保留“铜”“等腰”“图形/界限”“三角形”几个层次。去掉无关限定后属性仍成立，是寻找恰当说明主体的检查，不是单靠外延极大化便决定本质或因果。

实际查看卷首ERRATA整页，只有印219章题、273边注、594章题三项，**未列256–258**。这只是该表的覆盖范围，不保证本章不存在其他印刷、翻译或解释问题。

## S4：Mure英译转录

[MIT Internet Classics Archive，Book I，Part5](https://classics.mit.edu/Aristotle/posterior.1.i.html)，页面署G.R.G.Mure。实际读Part5至Part6前，对照Owen和希腊段序。该页的350BCE不作为单章精确定年，网页本身不用于断定英译印次。

Mure把平行例明确为同一直线的垂线，把末段解释为逐步去掉低层限定；这些澄清有助于避免对Owen含混短句的机械直译，但并非另一个古代作者的独立实验或史料。

## 主张与证据位置

| 位置 | 内容 | 必须保留的边界 |
| --- | --- | --- |
| 74a4–12；Owen256 | 普遍/首要误判、三种来源 | 真覆盖不自动满足首要解释；正文三项不混入脚注四项 |
| 74a12–17；Owen256 | 平行线与只存在等腰的假设 | 角关系/几何条件须明示；外延重合不必是定义相同 |
| 74a17–25；Owen257 | 不同领域的比例交换 | 无共同名称不表示无共同结构；不补造发现者或年代 |
| 74a25–32；Owen257 | 三角形分种证明与按数/按种 | 穷尽证明可保真，但不自动给出作者的共同说明根据 |
| 74a32–37；Owen257 | 何时知普遍、同一所是与首要性 | 本质同一不是观察样本相同 |
| 74a37–74b4；Owen257–258 | 铜制等腰三角形的限定抽去 | 无关限定可去，太宽的图形/界限不是首要主体 |

## 历史关系与后续比较

[I.4](aristotle-posterior-analytics-i4.zh-CN.md)已经规定每个、本身、作为自身及首要主体；I.5专门处理把局部成功误当恰当普遍的诊断。[I.2](aristotle-posterior-analytics-i2.zh-CN.md)的适当原则和原因要求是相邻理论背景。这是传本的概念承接，不当作已证实的写作年代链。

Owen的Locke等引注只证明1853注释如何把文本放入后世抽象与概括讨论，未实际完整核读这些被引著作，不能标为本轮完成。现代测试覆盖、特征消融、类型抽象可与本章比较，但应说明结构相似不证明历史直接影响；它们也不能替代独立的科学或因果证据。后分析篇I.6不计本单元完成，前分析篇I.2及II.25仍暂缓。
