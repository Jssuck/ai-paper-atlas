# 证明为什么能换一种走法：亚里士多德《前分析篇》I.7 深读

> 本篇是古代逻辑前史的明确补读，不是“第一篇 AI 论文”，也不意味着已连续覆盖全部早期文献。完整阅读单位为 Bekker 29a19–29b28；实际核对1831希腊印本与Owen1853英译印页98–100。章号不证明精确写作次序，十九世纪版本年不是古代作品写作年。I.2仍另行暂缓，本篇不计它完成。

## 1. 这一章真正要解决什么

前面三章分别问：中项处在三种位置时，哪些前提组合能够推出指定方向的结论？I.7换了问题：这些不同外形的证明，能否转换成少量共同的证明路线？有些前提不能推出“P关于S”的结论，却能推出“S关于P”的结论；有些证明看起来必须直接使用特称推理，却能先假设相反命题，再只用全称规则制造矛盾。

这不是把所有命题改写成全称命题。它是**改变证明组织方式，同时保留原前提与结论之间的必然关系**。特称前提中的存在见证没有消失，归谬中仍需要它来形成真正的冲突。

本章有四层工作：补充逆向端项结论；说明不定肯定可在当前推理位置替代特称肯定；把不完善推论完成为第一格；再把第一格特称路线及其他格路线归约到第一格全称路线。结尾收束的是当前直言、非模态的讨论；下一章才转向必然性。不能将这里的“所有”扩张成一切数学、模态逻辑或自然语言论证。

## 2. 书目、原文层次与阅读边界

作者为Aristotle；作品为 *Analytica priora*，第一卷第七章，独立书籍章节而非现代期刊论文。公元前四世纪只是作品历史定位，本次没有核定此章独立成文日。

实际底本：Immanuel Bekker编1831年柏林印本第29页；Octavius Freire Owen译1853年伦敦Henry G. Bohn版第一卷，印98页章题起至100页章VIII前的三行。必要扫描、页界、脚注及装置见[来源账本](aristotle-prior-analytics-i7.sources.zh-CN.md)与[独立来源复核](aristotle-prior-analytics-i7.source-audit.zh-CN.md)。

尤其要注意首句版本差异：Owen括入“and particular”，并在p98脚注2说Waitz省略这些词。Bekker1831正文不含该词组，页底装置记录相关异读。本文不把Owen括入当作所有底本一致的原文，也不自行宣判哪一古代读法绝对正确。下面的现代检验分别说明规则的适用域，不能靠一个可疑词组抹平范围问题。

Owen本章三个编号脚注属于译编层：p98的版本注、较长的直接证明/归谬术语及后世评论注，以及p99的归谬解释。p98顶部的脚注1属于上一章。译注提到的学者与归属说法仅作为Owen的注释报告，没有把所有所引著作独立读完，更不把它们当成亚里士多德本人自述。

## 3. 原文问题与前人关系：这里的“前人”主要是已建立的规则

本章直接依赖本书前面的换位规则与三格分析。I.4提供第一格，I.5提供第二格，I.6提供第三格；I.7利用这些既有结论解释格与格之间的关系。不能因此把全书看成按现代程序模块编写，也不能从这种组织方式推导出已核实的计算机科学直接传承链。

“完善”指论证的必然性已由当前明确陈述的结构显现；“不完善”需要补充换位结果或假设推导。它不是正确/错误的二分。不完善的推论可以完全有效，完成它是在补足展示过程，而不是修补一个错误结论。

后世拉丁式名Barbara、Celarent、Darii等仅用作今天定位模式的标签，不倒署为原章命名。现代集合、代码证书与有限支持模型也均为本篇教学重构。

## 4. 符号必须先定向

本文统一写A(X,Y)表示“每个X是Y”，主项在前。不要与原文“A属于每个B”的字母次序混淆：后者在本记号下是A(B,A)。E、I、O相同。

| 记号 | 含义 | 集合条件 | 是否自带见证 |
|---|---|---|---|
| A(X,Y) | 每个X是Y | X包含于Y | 否 |
| E(X,Y) | 没有X是Y | X与Y不相交 | 否 |
| I(X,Y) | 有X是Y | X与Y有共同成员 | 是 |
| O(X,Y) | 有X不是Y | X有成员不在Y | 是 |

现代论域非空，但词项允许空或全部非空，是两套明确区分的政策。A和E在空主项上同时为真；因此它们不是无条件矛盾命题。真正互为否定的是A/O和E/I：

```math
\neg A(X,Y)\iff O(X,Y),\qquad \neg E(X,Y)\iff I(X,Y).
```

上式使用经典集合语义。I(X,X)表示X非空。E和I可以简单换位；A(X,Y)不能简单换为A(Y,X)。若X非空，才可由A(X,Y)得到I(Y,X)。O一般不能换位。

**两项具体反例。** X为空、Y含一个对象时，A(X,Y)真而I(Y,X)假。X含甲乙、Y仅含甲时，O(X,Y)真而O(Y,X)假。后面每一次换位都应注明究竟用了哪条规则。

## 5. 无正向结论，不等于没有逆向结论

### 5.1 原章例子：共同中项给谁提供见证

原章29a19以后举出“A属于每个或某个B，B不属于任何C”。改用主项优先记号，即A(B,A)或I(B,A)，另有E(C,B)。要推出的是O(A,C)：有A不是C。

若前提为I(B,A)，逐步做：

1. 取前提保证的对象b，b同时属于B与A。
2. E(C,B)说明任何B对象都不在C，因为交集为空。
3. 所以b属于A而不属于C。
4. 得O(A,C)。原证明可经E与I换位进入第一格；这里直接展示同一见证。

若前提为A(B,A)，步骤1不能凭全称句单独完成，必须另有B非空。从B中取b，剩余步骤相同。并不是需要A、B、C全都非空，**这条证明只需B有见证**。

具体例子：B是某批已登记的铜件，A是导电件，C是非金属件。若至少有一件该批铜件，且该批铜件都是导电件、没有非金属件属于这批，则至少有导电件不属于C。这里把实际物理知识视为给定前提，不宣称逻辑本身证明材料属性。

### 5.2 空中项为何打破结论

令论域仅有u，B为空，A=C={u}。A(B,A)与E(C,B)都真，却没有A在C以外，O(A,C)假。这不是原章“被程序推翻”，而是告诉我们：把原来的存在背景改成现代空项政策后，必须公开标出补充条件。

### 5.3 结论的方向不可偷换

令B={b}、A={b,c}、C={c}。原前提真，O(A,C)真；但A(C,A)也真，O(C,A)假。由“有A不是C”不能倒转成“有C不是A”。

更一般地，“某格不成推论”的早先讨论针对指定端项方向。I.7补充反方向，并不是说此前错误分类现在变正确，也不是两前提可以任意交换主谓。附带的分类程序同时检查S关于P与P关于S，避免把方向丢掉。

### 5.4 首句的量化范围

原章先限定“不产生所讨论推论”的情形，再区分两前提同质与异质。不能删掉前置限定，误说“两肯定永远不能推出结论”：Barbara就是直接反例。也不能把“不产生必然端项结论”理解成没有任何逻辑后果，前提自身当然仍是后果。

对异质且否定全称的补充，应保留此前格与方向的上下文，并注明全称肯定分支的存在要求。本文代码给出三格固定三项、AEIO、双向结论的完整有限语义分类；它不是对所有可能自然语言句式的历史释义判决。

这里也不把“负前提全称时可有逆向结论”升格成唯一必要条件。例如第二格O(P,M)、A(S,M)中，取P里不在M的对象；它必不在S，所以O(P,S)。第三格A(M,P)、O(M,S)中，取M里不在S的对象，它在P中，仍得O(P,S)。两例的负前提都是特称。它们说明充分条件不能偷换为充要条件，不是声称原章逐一列出了这两个现代展开。

## 6. 不定肯定代替特称肯定，究竟保留了什么

29a末段说，不定肯定置于特称肯定的位置，会产生相同推论。不定句未明说“每个”或“有些”；本文不把任意自然语言裸复数句都强行解释成存在命题。

在本章论证位置，若把不定肯定规范化为I(X,Y)，证明只用到共同成员，不用到数量比例，更不用到“有些但不是全部”。所以“有些X是Y”容许全部X都是Y；添加“有些不是Y”就是新的O前提，会改变推论集合。

例如I(S,M)、A(M,P)只需要一个共同见证，就可得I(S,P)。若误把“有些”读为“并非全部”，会在所有S恰好都属于M的合法模型中错判前提为假。代码不解析自然语言；它只接收已经明确的AEIO命题，不冒称自动解决不定句语用。

## 7. 第一层归约：把不完善推论完成为第一格

### 7.1 直接路线与假设路线

原章29a30以后区分两类完成：直接用换位得到第一格，或先作与结论相反的假设，通过第一格导出不可能。两种都需要记录新增命题来自何处：换位所得不是额外独立事实，反设也不是最终保留的前提。

第一格的两个全称基本路线，在现代集合语义中为：

```math
A(M,P),A(S,M)\Rightarrow A(S,P),\qquad
E(M,P),A(S,M)\Rightarrow E(S,P).
```

前者是包含的传递，后者是包含到一个与P不交的集合。两条都不需要词项非空。分别称Barbara与Celarent。

### 7.2 原章Darapti归谬逐行重建

给定A(C,A)、A(C,B)，想得I(B,A)。这里先另列C非空。

1. 反设E(B,A)，即否定所求I(B,A)。
2. E(B,A)与A(C,B)通过Celarent得E(C,A)。
3. 原前提A(C,A)和C非空保证一个c属于C与A。
4. E(C,A)禁止这个共同成员，矛盾。
5. 反设不可能，故I(B,A)。

第3步不可省。仅仅把A(C,A)和E(C,A)写在一起，在C为空时无矛盾。程序将存在条件显式记成I(C,C)，不靠“看起来肯定与否定冲突”闭合分支。

也可直接从C取c，同时属于A与B。这是同一结论的另一条证明，不意味着两种证明在长度、解释清晰度上完全相同。

## 8. 第二层归约：连第一格特称式也不必当原始规则

本章更强的主张是：可以把所讨论的推论归约到第一格全称路线。关键不是从全称前提凭空产生见证，而是把已有特称前提保留到归谬终点。

### 8.1 Darii：全称肯定加特称肯定

前提A(B,A)、I(C,B)，目标I(C,A)。原章先用第二格说明，再把第二格展开。

1. 假设E(C,A)。
2. E换位得E(A,C)。
3. E(A,C)与A(B,A)用Celarent得E(B,C)。
4. E换位得E(C,B)。
5. 与既有I(C,B)构成E/I矛盾。
6. 排除反设，得I(C,A)。

这里没有调用Darii去证明Darii。步骤2–4就是第二格全称否定路线的展开；特称前提只在步骤5提供冲突见证。空项允许也不妨碍此证明，因为I(C,B)已保证所需成员。

### 8.2 Ferio：全称否定加特称肯定

前提E(B,A)、I(C,B)，目标O(C,A)。

1. 反设A(C,A)，它正是O(C,A)的经典否定。
2. E(B,A)换位为E(A,B)。
3. E(A,B)与A(C,A)用Celarent得E(C,B)。
4. 与I(C,B)矛盾。
5. 得O(C,A)。

如果错误反设E(C,A)，那是否定I而非否定O，证明目标已经被偷换。若反设I(C,A)，它也不是O的否定：同一个集合可以有成员在A中，也有成员不在A中，两特称可同时真。

### 8.3 两条第二格特称式

Festino：E(P,M)、I(S,M)得O(S,P)。先把E换位，进入Ferio，再把Ferio按上节展开，最终只剩全称规则、E换位和E/I冲突。

Baroco：A(P,M)、O(S,M)得O(S,P)。反设A(S,P)，与A(P,M)经Barbara得A(S,M)，与原O(S,M)矛盾。这里不能随意换位O；归谬正好绕开不可靠的特称否定换位。

## 9. 十四条标准路线的依赖图，而非循环证明

下表是现代核对索引，排列的是前文三格的十四个基本模式。表中A/E/I/O依次是大前提、小前提、结论；结论都以S为主项、P为谓项。第一格前提位置为(M,P)、(S,M)，第二格为(P,M)、(S,M)，第三格为(M,P)、(M,S)。

| 格与模式 | 名称（后世标签） | 归约说明 | 额外存在条件 |
|---|---|---|---|
| 1 AAA | Barbara | 全称基本路线 | 无 |
| 1 EAE | Celarent | 全称基本路线 | 无 |
| 1 AII | Darii | 假设E结论，经E换位和Celarent与I冲突 | 无 |
| 1 EIO | Ferio | 假设A结论，经E换位和Celarent与I冲突 | 无 |
| 2 EAE | Cesare | 大前提E换位，再Celarent | 无 |
| 2 AEE | Camestres | 小前提E换位、Celarent、结论E换位 | 无 |
| 2 EIO | Festino | E换位后Ferio，随后展开Ferio | 无 |
| 2 AOO | Baroco | 假设A结论，Barbara与O冲突 | 无 |
| 3 AAI | Darapti | 假设E结论，Celarent与共同中项见证冲突 | M非空 |
| 3 EAO | Felapton | 假设A结论，Barbara与E及中项见证冲突 | M非空 |
| 3 IAI | Disamis | I换位、Darii、I结论换位，再展开Darii | 无 |
| 3 AII | Datisi | 小前提I换位，再Darii并展开 | 无 |
| 3 OAO | Bocardo | 假设A结论，Barbara与O冲突 | 无 |
| 3 EIO | Ferison | 小前提I换位，再Ferio并展开 | 无 |

Felapton的展开值得单独检查：给E(M,P)、A(M,S)，反设A(S,P)，Barbara得A(M,P)。M非空提供m；原E(M,P)禁止m属于P，新A(M,P)要求它属于P，冲突。去掉M非空则M为空、S=P={u}就是反例。

Bocardo的展开相似但不需外加存在：给O(M,P)、A(M,S)，反设A(S,P)，Barbara得A(M,P)，与O(M,P)直接矛盾。见证来自原特称否定，不是另补的假设。

表中的箭头组成可终止的展开顺序：先固定Barbara/Celarent；再用它们证明第二格全称和Darii/Ferio的展开；再替换其他模式中的已证明节点。即使叙述上先说“Darii经第二格”，也不必让该第二格证明再调用Darii，因而不存在实质循环。**名字之间画一条双向箭头，不能代替检查展开后的基础依赖。**

## 10. 一个小证明核怎样工作

[代码与使用说明](../../reproduction/aristotle-prior-analytics-i7/README.md)实现现代教学证书，不声称复原亚里士多德的写作过程或一套完整自动定理证明器。

命题有明确量词、主项、谓项。证书记录原前提、反设、规则、依赖行、结论和冲突。可检查的局部规则包括E/I换位、Barbara/Celarent，以及显式存在背景下的冲突闭合。实际API、检查集合与运行计数以附件为准；本文不把手写证明数量充作程序覆盖数量。

为什么小核有意义？若每条规则都保持真，并且反设与原前提最终推出一个不可能同时满足的条件，那么不存在同时满足原前提和反设的解释。在经典语义中，原前提便蕴涵目标。证明核负责检查具体证书是否遵守这些规则，有限语义枚举负责从另一条路检验具体模式。两者不能相互假冒独立数学证明。

**一般可靠性论证。** E/I换位由交集交换律成立；Barbara由包含传递成立；Celarent由包含与不交成立。对证书行数归纳：初始行在假定解释中真；若依赖行真，合法规则的新行也真。若闭合行要求同一命题及其经典否定都真，则没有这样的解释。于是排除反设。归纳的结论不限于测试过的有限集合，也不意味着程序实现绝无缺陷。

存在条件是证明上下文的一部分，不能藏进函数默认值后在报告中省略。检查器接受一个带M非空的Darapti证书，不等于证明了无条件Darapti。

## 11. 为什么八个成员类型足以检查这些命题

对三个一元词项P、S、M，每个对象按属于或不属于三项归入八种布尔成员类型。只保留哪些类型出现过，而不保留各类型出现几次，就得到支持集合。

```math
T(D)=\{(1_P(x),1_S(x),1_M(x)):x\in D\}\subseteq\{0,1\}^3.
```

每个AEIO命题只问某些类型是否存在或被禁止：A禁止X真Y假的类型；E禁止二者真；I要求二者真的类型至少一个；O要求X真Y假的类型至少一个。因此同一支持的两个解释，对全部固定三项AEIO命题有相同真值。

给任意可能无限的解释，为每种实际出现的类型选一个代表，至多八个对象，所有这些命题及词项非空条件都保持。反过来，任意非空类型支持用其类型本身作对象即可实现。所以枚举255个非空支持，足以判定这个**有限语汇片段**的语义后承。一般保持性证明在这里；程序只是对这些支持进行真实检查。

这不适用于含“至少两个”、二元关系、时态或模态的扩展：成员重数或世界关系会携带额外信息。也不能从覆盖这255个支持推导出自然语言推理的一般完备性。

## 12. 实跑、独立核验与证据分工

## 14. 局限与可以合理延伸的问题

1. **版本限制**：本次核两个十九世纪印本及有界装置，不建立所有手稿的校勘谱系；Owen的括注不默认为唯一原文。
2. **存在限制**：现代空项政策是分析工具；不能将它无声替换原章背景，再把条件差异宣称成历史作者简单算错。
3. **基础限制**：归约依赖换位、经典反设和矛盾关闭。不能仅列Barbara/Celarent就宣称其他逻辑原则完全不需要。
4. **效率限制**：能归约不等于归约后的证明最短。Darii直接取见证更直观，展开为归谬反而增加步骤。
5. **范围限制**：只处理三项直言片段。模态、关系推理、数量词、概率和非经典逻辑未由本篇解决。
6. **历史限制**：可把证明证书与当代可检查推理作教学比较，但未核实一条从本章到现代AI工程的直接影响链。

合理下一步是比较不同证明路线的长度与可解释性、为证书加机器可检查的假设作用域、或扩展多项并明确何时八类型压缩不再足够。上述是研究建议，不是本轮已经做过的实验。

## 15. 二十道练习与答案

### 1. A属于每个B如何翻成本篇记号？
答：A(B,A)。第一个位置是主项，第二个是谓项；不要因原文字母顺序而写反。

### 2. A(X,Y)的经典否定是什么？
答：O(X,Y)，即至少一个X不属于Y，不是E(X,Y)。

### 3. E(X,Y)的经典否定是什么？
答：I(X,Y)，存在共同成员。

### 4. 为什么A(X,Y)和E(X,Y)可同时真？
答：X为空时，包含和不交都成立。若要以二者闭合矛盾，需另有X非空。

### 5. 原章逆向结论的A分支需要哪个集合非空？
答：B；从B取见证，经B包含于A及B与C不交，得到A中不在C的成员。

### 6. 给出上述规则无存在条件时的反例。
答：B为空、A=C={u}。两全称前提真而O(A,C)假。

### 7. O(A,C)能否换为O(C,A)？
答：不能。A={b,c}、C={c}时前者真后者假。

### 8. 两肯定前提是否永远不能推论？
答：不是。Barbara两全称肯定能推出全称肯定；原章首句有“不成所讨论推论”的范围限定。

### 9. “有些X是Y”是否含“有些X不是Y”？
答：不含。所有X都是Y也满足前句；后句是新的O前提。

### 10. Darapti归谬为何要明确C非空？
答：反设只能导出E(C,A)，它与A(C,A)在C为空时兼容；C见证才使两者真正冲突。

### 11. Darii反设应选E还是O？
答：E，因为目标是I；E/I互为否定。

### 12. 展开Darii时用哪条全称基本规则？
答：Celarent；配合E换位，把E(C,A)和A(B,A)转为E(C,B)，与I(C,B)冲突。

### 13. Ferio为何反设A(C,A)？
答：目标O(C,A)的否定是A(C,A)；假设I不能排除部分成员在A外。

### 14. Baroco为何不换位O？
答：O换位不可靠。反设A(S,P)后用Barbara得到与原O(S,M)冲突的A(S,M)。

### 15. Felapton与Bocardo的存在来源有何区别？
答：Felapton两全称前提需另列M非空；Bocardo的O(M,P)已经给M见证。

### 16. “归到全称式”是否删除了特称前提？
答：没有；特称仍用于闭合矛盾，归约改变的是证明结构而非任意删除信息。

### 17. 怎样避免Darii与第二格互相依赖的循环？
答：把所用第二格全称路线进一步展开为Celarent和换位，最终证书不以Darii为基本规则。

### 18. 为什么最多八个代表足够？
答：三个一元词项有八种成员类型，AEIO只关心类型是否出现。每种实际类型保留一个代表保持全部相关命题真值。

### 19. 若增加“至少两个X”，八类型支持还够吗？
答：单纯支持不够，因为一个与两个同类型对象有同一支持却不同计数；必须保留额外重数信息。

### 20. 本篇可以宣称证明了什么，不可以宣称什么？
答：可给出明确语义下各归约规则的可靠性证明，并用有限支持完整检查固定三项AEIO片段的具体后承；不可因此宣称全部历史逻辑、所有自然语言或现代AI推理都已被验证。

## 16. 复盘

本章的核心不是又增加几条式子，而是教我们把“推出了什么”与“用哪条路线推出”分开。方向、见证、假设作用域与规则依赖是归约中不能丢的信息。真正可靠的简化不是把证明写短，而是让每一步都能说明：它用了哪些已知条件，新增命题从哪里来，最后的矛盾是否确实矛盾。
