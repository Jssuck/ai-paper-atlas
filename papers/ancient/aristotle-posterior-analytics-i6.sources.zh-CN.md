# 《后分析篇》I.6：来源台账与解释边界

对应[中文深读](aristotle-posterior-analytics-i6.zh-CN.md)。只公开核读说明与书目，不收入原书扫描、OCR或全文翻译。

## 书目与实际阅读范围

Aristotle，*Analytica Posteriora / Posterior Analytics*，I.6，**74b5–75a37**。Bekker1831印74右栏第5行起章6，印75左栏第38行起章7；Owen1853印258章VI标题至印261章VII标题前。范围包括必要原则、本身归属、可消失中项、前提与结论的必要性方向、非本身偶性、论辩中的必随以及末段的迹象/原因区别。

作品年代只标公元前四世纪范围，印本、译本年代另列。传本章节相邻不证明先后写作日期。本单元属于AI认识论与解释思想前史补读，不称现代AI论文，也不声称穷尽古代知识传统。

## S1：Bekker1831希腊扫描与校记

Immanuel Bekker编，*Aristotelis Opera*，vol.I，Berlin，1831。[卷本](https://archive.org/details/aristotelisopera01arisrich)、[印74](https://archive.org/download/aristotelisopera01arisrich/page/n89.jpg)、[印75](https://archive.org/download/aristotelisopera01arisrich/page/n90.jpg)。实际查看两页正文、章号、行号及底部校记。

相关校记在74b10、13、24–25、34–37及75a2、5、21–22、35等行记录词序、删省或读法；这里不据一份印本宣布完成手稿谱系校勘。75a5–11的字母推导同时使用A对B、B对C的必要关系；结论非必要所排除的是两项必要条件的合取，不是逐项断言每个前提都不必要。

## S2：Bekker1837电子转录

[Graeco-Arabic Studies希腊正文及版本说明](https://www.graeco-arabic-studies.org/view/arist.analytpost-orig-gr1)。页面标Bekker，*Aristotelis Opera*，Oxford，1837，I，182–257。实际读章号6至7前全文，对照1831扫描；这是另一印本的数字转录，不是独立古代手稿。

重点核对通行意见与领域首要原则、结论必要与路线必要、承认前提后必须承认结论与结论自身不可能另样的区别。章末即使联系恒常成立，若不属本身、不给出原因，仍不足以构成作者要求的知道为何。

## S3：Owen1853英译、注释与ERRATA

Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol.I，London: Henry G. Bohn，1853。[全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)。实际读印258–261正文及本章脚注，对应PDF第277–280页。印261虽页眉标VII，页内章VII标题前仍是I.6末段，不能按页眉截断。

1. 印258脚注1借Taylor说明可借换位重写为Barbara。这是译注解释，不是原文逐步列出的证明；不能仅由本身者必要逆推出所有必要者本身。正文另有本身/偶性的分类和偶性不必要的限定。
2. 印258–259跨页脚注把知道/拥有知识的诡辩归于Protagoras并列扩展论式。正文仅称智者而未具名；不能把注者归属写成正文自证的身份。
3. 印259中项可能消失段保留认识者、对象及记忆。Waitz注释和Whately参照属于后世解释层；此段不是现代心理实验，也不能泛化成任何知识一旦论据变化便从未成立。
4. 印260脚注1概括四项模态关系，第二项复数简写易诱发过强读法。正文实际假设两条关系均必要而推出矛盾，故教学展开应写不能两条均必要，不写每条都非必要。
5. 印260关于知道事实、知道为何、经中项与直接前提的结尾，Owen英语连接较含混。对照希腊转录和Mure，不把一份译文句法当唯一无争议解释；共同要点是缺必要解释中项时不能由形式推得便宣布掌握必要原因。
6. 印261脚注1区分普通偶性和可列于第二种per se的固有属性；正文也明说这里讨论非本身偶性。不能把一切现代意义属性都排除于科学知识外。脚注3将恒常性指向前提始终为真；末段仍指出恒真迹象路线不自动提供原因。

实际查看卷首ERRATA整页，只列印219、273、594三处，**未列258–261**。这仅是该表范围，不保证本章没有其他印刷、翻译或解释问题。

## S4：Mure英译转录

[MIT Internet Classics Archive，Book I，Part6](https://classics.mit.edu/Aristotle/posterior.1.i.html)。页面署G.R.G.Mure；实际读Part6至Part7前，对照Owen和希腊段序。页面350BCE不作为单章精确定年，网页本身不用于确定英译印次。

Mure把Owen的probable对应为通行、受认可的意见，此处不是统计概率阈值；它把必要中项展开为与两端的必要联系，并保留必要结论可由非必要前提推得的让步。章首必要前提便是证明的强语句应连同本章恰当性、原因要求及I.2整体定义阅读，不独立升级成任意必要真句足以产生科学知识的现代定理。

## 主张与证据定位

| 位置 | 核读内容 | 解释限制 |
| --- | --- | --- |
| 74b5–12；Owen258 | 必要原则、本身与偶性 | 对立属性一者或另一者必在，不是两者分别必在 |
| 74b13–26；Owen258–259 | 必要性要求、通行真句与恰当原则 | 不删去领域、本身及原因条件 |
| 74b26–39；Owen259 | A/C结论必要、B中项可失 | 保留人、对象、记忆，非心理学实证 |
| 75a1–11；Owen259–260 | 必要前提推出必要结论，反向不成立 | 非必要结论只排除两前提共同必要 |
| 75a12–17；Owen260 | 缺必要中项时的信念/知识区别 | 译文连接含混，不取消所有事实知识 |
| 75a18–27；Owen260–261 | 非本身偶性与论辩条件性必随 | 承诺必须跟随不等于对象必然如此 |
| 75a28–37；Owen261 | 恒常迹象与本身因果中项 | 相关、恒常、模型保真均不认证原因 |

## 前驱、承接与延伸的证据等级

I.2规定科学知识与原因、恰当原则；I.4讨论本身归属；I.5讨论恰当普遍主项。这是传本文内承接。Owen259脚注引《前分析篇》II.2–4，说明可由不真的前提出真结论的类比背景；这里核其引用，不把这些章节算作本轮新完成成果。

现代模态模型、证明证书、相关特征和机制解释可用于比较，但结构相似不证明直接历史影响。有限世界中全真只相对于预定模型集合，外部声明原因也不是程序证实原因。后分析篇I.7不计本单元完成；前分析篇I.2和II.25仍暂缓。
