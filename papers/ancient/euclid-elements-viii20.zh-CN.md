# 欧几里得《几何原本》VIII.20：知道一个整数中项，怎样找回两对相似的边？

**年代跳转 · 数学与证明方法前史补读 · 深读 v1。** 作品通常约定在公元前 300 年前后。本篇只读第八卷命题 20，作为数学证明方法的前史，不是 AI 论文，也不主张存在一条从欧几里得到现代 AI 的直接传承链。这里的“平面数”是由两整数因子相乘得到、可以用两条边来表述的数，不是带长度单位的现代平面图形。

## 1. 把有中项的条件转成一个找因子的办法

[上一条相关命题 VIII.18](euclid-elements-viii18.zh-CN.md) 已知两组边成比例，从两端各取一条对应合适的边相乘，就能造出整数中项。VIII.20 倒过来：只给两个端点和一个整数中项，不给边，仍能找出两组比例相同的边。它只倒转 VIII.18 的存在结论，不要求恢复当初的边，也没有把 VIII.18 的二重比结论作为另一个独立前提。[VIII.19](euclid-elements-viii19.zh-CN.md) 处理立体数的正向构造，不应把它的两个中项混进这里。

例如，给 $`A=18,\ C=30,\ B=50`$。两个相邻比都是 $`3:5`$。把第一段写成 $`(18,30)=6(3,5)`$，第二段写成 $`(30,50)=10(3,5)`$。中项 $`30`$ 在左段是 $`6\cdot5`$，在右段是 $`10\cdot3`$。这次让 $`30`$ 在两个位置同时出现，就得到端点的两组边 $`(3,6)`$ 和 $`(5,10)`$。这个过程中，真正要证明的是两次缩放量都是整数，而且它们自身又成 $`3:5`$。

**书目与版本。** 欧几里得，《几何原本》卷 VIII，命题 20。查读 [Heath 1908，卷 II，印页 375–377](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)、[Fitzpatrick 希英对照，pp.246–247](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)、[Clay 希英网页](https://www.claymath.org/library/historical/euclid/files/elem.8.20.html) 和 [Joyce 正文及 Guide](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII20.html)。证据位置和转录差异见[版本核对](../../reproduction/euclid-elements-viii20/source-review.zh-CN.md)。原命题没有实验数据或性能主张。

## 2. 跟着原典做两次同样的除法

| 角色 | 记号 | 约定 |
| --- | --- | --- |
| 两端和中项 | $`A,C,B`$ | 正整数，顺序不能混；$`A:C=C:B`$，等价于 $`C^2=AB`$ |
| 共同的最小比 | $`D,E`$ | $`D:E=A:C`$，现代写法为 $`D=A/\gcd(A,C),\ E=C/\gcd(A,C)`$ |
| 两次缩放量 | $`F,G`$ | 原文希文分别用 Ζ、Η；$`F=A/D`$，$`G=B/E`$ |
| 要找的两组边 | $`(D,F),(E,G)`$ | 乘积分别为 $`A,B`$，要证 $`D:F=E:G`$ |

1. **约为最小比。** 据 [VII.33](https://www.claymath.org/library/historical/euclid/files/elem.7.33.html)，先取与 $`A:C`$ 同比的最小数对 $`D,E`$；因为有中项，第二段 $`C:B`$ 不需要另选数对。现代模型中最小数对互素。因为 $`D,E`$ 互素，任意整数比对 $`X:Y=D:E`$ 满足 $`EX=DY`$，从而 $`D`$ 整除 $`X`$，$`E`$ 整除 $`Y`$，并且两个商相同。这是 [VII.20](https://www.claymath.org/library/historical/euclid/files/elem.7.20.html) 所用结论的现代推导，不是原证明的译文。
2. **第一次量尽：** $`D`$ 量尽 $`A`$ 和 $`E`$ 量尽 $`C`$ 的次数相同。记这个次数为 $`F`$，则 $`A=DF`$，**同时** $`C=EF`$。后一句虽未在原文第一次引入 $`F`$ 时单独写出，却来自同一句“次数相同”，并不需要额外假设。
3. **第二次量尽：** $`D`$ 量尽 $`C`$ 和 $`E`$ 量尽 $`B`$ 的次数相同。记为 $`G`$，则 $`C=DG`$，$`B=EG`$。已构造出两端的因子；但仅有两项乘积对，还未得到相似性。
4. **对照中项并换比。** 因为 $`C=EF`$、$`B=EG`$，按 [VII.17](euclid-elements-vii17.zh-CN.md)，有 $`F:G=C:B=D:E`$。原文还用第一次的两个乘积说明 $`D:E=A:C`$；这一步重申了选取 $`D,E`$ 时已知的比例。最后按 [VII.13](euclid-elements-vii13.zh-CN.md) 交替，得 $`D:F=E:G`$，正是所需的边比例。现代也可直接从 $`EF=DG`$ 交叉核算。用 [VII.18](euclid-elements-vii18.zh-CN.md) 表述两个乘数乘同一因子也能得到同一比，别把两个记号习惯当成不同定理。

## 3. 这份构造证书唯一吗？

**教学重构。** 从 $`EF=DG`$ 且 $`\gcd(D,E)=1`$ 得 $`D`$ 整除 $`F`$；写成 $`F=kD`$，代回得 $`G=kE`$。于是任何符合已给条件的正整数链都可写为

$$
(A,C,B)=k(D^2,DE,E^2),\qquad k,D,E\in\mathbb Z_{>0},\quad \gcd(D,E)=1 .
$$

反过来，这个式子给出的链两段比例相等。最小数对由第一段固定，$`k`$ 也由 $`A`$ 固定；但把 $`k`$ 全放在第二条边上只是原典的选择。若 $`k=uv`$，则 $`(uD,vD)`$ 与 $`(uE,vE)`$ 也是相似分解。反之，若找到了任意有相同对应次序的相似分解，两项对应边之比的平方就是 $`A/B=(D/E)^2`$，正值性保证每对对应边的比为 $`D:E`$，互素性使每对边分别是它的整数倍。因此这个分配也描述了所有正整数有序表示，不是原命题另外证明的唯一性定理。比如 $`k=4,D=2,E=3`$ 时，$`16,24,36`$ 既可用 $`(2,8),(3,12)`$，也可用 $`(4,4),(6,6)`$ 表示。

| 输入 | 构造或检验 | 能说明什么 |
| --- | --- | --- |
| $`(18,30,50)`$ | $`(D,E,F,G)=(3,5,6,10)`$ | $`30`$ 同时是 $`5\cdot6`$ 与 $`3\cdot10`$；两边内比都是 $`1:2`$ |
| $`(50,30,18)`$ | $`(5,3,10,6)`$ | 两端可倒转，边随之交换，不须把两段重新定义成递增 |
| $`(18,29,50)`$ | $`29^2=841\ne900`$ | 端点确有中项，但错误的见证必须被拒绝 |
| $`(6,\,?,\,10)`$ | $`7^2\lt60\lt8^2`$ | 实数中项存在，整数中项不存在；近似开方不能充当认证 |
| $`(2,4,8)`$ | $`(1,2),(2,4)`$ | 现代正整数模型允许单位因子；若另要求边都大于 1，素端点 $`2`$ 使结论不成立 |

相等端点的现代扩展只给链 $`(A,A,A)`$；它不满足严格的“落在两数之间”，故不拿来反推欧几里得如何处理等比 $`1:1`$。第七卷开头在文字上区分单位与数；这里不以现代测试替代古典语义。上表素端点例也不是反驳原典：它指明现代推广的约定不能与严格的非单位要求混用。

## 4. 怎样证实复现不是把同一个程序跑两次

- **原文证据：** Heath p.375 下半取最小数对并定义 $`F`$；p.376 上半定义 $`G`$、下半闭合相似性，校注解释为何要补出 $`EF=C`$；p.377 顶部续前页的现代化提纲。Fitzpatrick p.247 有同类脚注。Joyce 的 Guide 两处公式与其正确正文冲突，不能直接依照 Guide 给代码写预期值。
- **教学检查：** [源码、Notebook 和真实日志](../../reproduction/euclid-elements-viii20/README.md) 对给定三元组做精确整数构造，并在同一有限范围内用端点乘积的整数平方根单独判定是否存在中项。构造返回的中项证书另查乘积和交叉相乘，不用浮点近似，无外部数据或速度比较。在 10,000 对有序端点中，整数平方根基线检出 310 个整数中项，另外 9,690 个向下取整候选全部被拒。程序获得的有限证据不能推出不限范围的定理；它能捕捉把两个商倒写或把原先给定的分解误当唯一的具体问题。[独立技术核对](../../reproduction/euclid-elements-viii20/technical-review.zh-CN.md) 分开核查推导和运行。
- **现代启发：** 比例的最小代表可作为两段资料的公共参照；真正能拼接的不仅是两个标签相等，还要展示共享的量由哪两个乘积得到。用现代词汇说，这是可检查的构造证书，不是说古典文本使用了程序语言或现代自动证明。

## 5. 练习与答案

1. 对 $`(12,18,27)`$ 写出两组边。  
   答：$`D:E=2:3,\ F=6,\ G=9`$，两组边为 $`(2,6)`$ 与 $`(3,9)`$，边内比均为 $`1:3`$。
2. 在 $`(18,30,50)`$ 中，若把 $`G`$ 写成 $`D/C`$，错误出现在哪里？  
   答：$`G`$ 是 $`D`$ 量尽 $`C`$ 的次数，所以是 $`C/D=10`$，亦为 $`B/E`$；$`D/C=1/10`$ 不能是量尽次数。
3. 约得 $`D:E`$ 后，为什么不能就宣布相似？  
   答：还没构造第二条边。需先由两次量尽得到 $`F,G`$，再用 $`EF=DG`$ 得到边比例。
4. $`(8,12,18)`$ 有相似的两组整数边吗？一定是方形吗？  
   答：有，$`D:E=2:3`$，$`k=2`$，例如 $`(2,4),(3,6)`$；两组对应同倍率，不意味着每一组自身的两边相等。
5. 已知 $`16,24,36`$，有人说验证 $`24^2=16\cdot36`$ 就能证明指定的 $`(2,8),(4,9)`$ 相似。对吗？  
   答：不对，两组边的内比分别是 $`1:4`$ 和 $`4:9`$。存在整中项保证**某对**分解相似，不保证任给分解满足前提。

**复盘：** 约出同一个最小比，用它分别量尽两段；中项得到的两种乘积写法，把存在性结论变成了可以逐项验证的边。
