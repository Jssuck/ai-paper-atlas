# I.27 来源台账：不是只有证明规则，还要准备前提

## 1. 书目与实读范围

- Aristotle，*Prior Analytics*（《前分析篇》）卷一第27章；作品年代为公元前四世纪这一范围，不将某个现代印本年当成写作年。它是古代逻辑著作中的有界章节，收录为AI推理前史补读，非现代AI论文、非“第一篇AI论文”。
- Immanuel Bekker编，*Aristoteles Graece*，Volumen Prius，Berlin：Georgius Reimer，1831。本章完整为 **43a20–43b38**，全在[印43页图](https://archive.org/download/aristotelisopera01arisrich/page/n58.jpg)。左栏章号27在a20，右栏章号28在b39。43a1–19属于I.26；43b39以后的I.28不计完成。实际查看了本章正文及页底简校记。
- Octavius Freire Owen，*The Organon, or Logical Treatises, of Aristotle*，Vol.I，London：Henry G. Bohn，1853。[原扫描PDF](https://archive.org/download/Aristotles_Organon_vol_01_1853/Aristotles_Organon_vol_01_1853.pdf)。实读PDF第163–165页，即印 **144–146** 的I.27正文及本章全部十条数字注；另实看PDF第10页题名与第18页正式ERRATA。

本台账提供原创定位摘要，不是全文翻译。原PDF、扫描与OCR只供核验，不放进公开附件。未认证全手稿谱系、全部译本或唯一古代解释。

## 2. 主张—位置对照

| 原文位置 | 内容与论证任务 | 不应添加的主张 |
| --- | --- | --- |
| 43a20–24；Owen144章首 | 从“知道推理如何形成”转向“能够为问题获得前提并形成推理” | 没有现代自动证明系统、完备性或复杂度定理 |
| 43a25–32；Owen144中 | 区分不普遍谓述别者的个体、谓述他者而无更先谓词者、两向皆可的中间项 | 不把单称项等同特称量词；不从分类直接推出现代类型系统 |
| 43a32–39；Owen144末至145首 | 感性个体偶然充当谓词的日常句例；向上追溯停止在此暂作假定，证明另说 | 本章未证明所有概念层次必有限；不能把假定写成已证终止定理 |
| 43a39–43；Owen145首 | 论证与考察主要围绕可同时居主项和谓项的中间项 | “几乎/主要”不是禁止所有其他论证 |
| 43b1–6；Owen145上 | 先置主题、定义与固有材料，收集后随项、前随项及不相容项；否定可换位而不必重复收集反方向 | 否定换位须保留全称否定范围，不能把特称否定或“未知”对称化 |
| 43b7–11；Owen145中 | 分开本质性谓述、固有属性、偶性，以及依意见与依真实；材料多有利于发现，真材料有利于证明 | 不是条目越多运行时间必短，也不是来源标签本身证明内容为真 |
| 43b11–17；Owen145中 | 搜集对整个主项成立的后随关系及整个前随项；不定量表达不能保证全称 | 不是从观察一个人推广所有人；本段强调全称材料不等于把所有三段论前提都说成全称 |
| 43b17–23；Owen145下 | 全称标记附主项，不把谓项也全称化；人/动物、音乐/科学、正义/善的例子 | “所有人是动物”不等于“所有动物是人”，也不等于两类外延相等 |
| 43b23–29；Owen145末至146上 | 主题已被上位类包含时，上位类已有的肯定/否定材料可继承，不必同样重抄；仍须收集种特有材料 | 这是知识组织策略，不是可以抹除推导根据或把种特有属性提升到属 |
| 43b29–32；Owen146中 | 属包含种、种包含其前随项，相关前随材料更适合在种的条目下组织 | 不应误写成这些材料对属在逻辑上无效；原文恰说明属亦随后随之 |
| 43b33–36；Owen146中下 | 同时收集通常/多数情况下成立的前随与后随材料；此类问题的前提及结论保持相应性质 | 原词不是严格全称；没有给出现代概率乘法或阈值演算 |
| 43b36–38；Owen146章末 | 不选择对一切都后随的共同谓项，不能仅靠这类材料组成所需推理；理由留待后文 | 不能推广为“任何含普遍谓词的推理都无效”，更不能计后章已读完成 |

## 3. 十条数字注及边注

Owen注号每页重置，应按实际所属章计数：

1. **印144注2**，章标题注：Averrois的旧分段及第二节题名。这是译者报告的后世结构线索，不表示本次已独立读完Averroes。
2. **印144注3**，单称项注：提及Wallis逻辑附论对单称谓项的讨论。未据此作对Wallis全文的判断。
3. **印145注1**：Owen批评Taylor把单称译为particular，并提Averrois的singularia。这里只核实Owen的注记，未全面对校Taylor。
4. **印145注2**：称前随关系分句被Taylor省去。仍是译注报告，不冒称独立完成该译本校勘。
5. **印145注3**：讨论idion与可换位、共外延及第四可谓述项，提Porphyry。正文中的固有/特有材料须看语境，不能让译注替代本章所有用法。
6. **印145注4**：解释如所形成的命题那样；附在谓项不额外全称化段。
7. **印145注5**：解释带全称符号的谓项。
8. **印146注1**：解释被一个全称谓词所包摄。
9. **印146注2**：解释人被谓述的那些项，辅助辨清前随关系方向。
10. **印146注3**：说人的主项材料应按自身条目选择，并引Whately等逻辑书。未视为Aristotle本人的引书，更未计这些书已读完成。

印144注1是I.26的计数总结，排除；印146注4已附于I.28，排除。实际看见I.27的五组编号边注（144两组、145两组、146一组），另有144《后分析篇》I.19及以后、146 Aldrich/Hill的非数字边旁书目提示。这些后世辅助标记与原章正文分开。

## 4. 勘误、校记与译义风险

- Owen正式ERRATA列印219、273、594页，没有144–146条目。仅可说这张所查正式表未列本章，不能证明全网或所有版次不存在勘误。
- Bekker印43页底简校记涉及省略、读法等，本次目视核了与本章相交的a34–35、a43及b10–13。未重新校订手稿、裁定全部异读或凭现代模型改动希腊原文。
- **最重要的译义区分**：43b33–36的ὡς ἐπὶ τὸ πολύ，指通常/多数情况。Owen在146页用generally，不宜在中文中不加说明地译成与43b11–17同义的“全称”。严格包含规则和通常规则须分轨；本章没有给通常规则配置具体概率。
- Owen145页“syllogism consists of universal propositions”若脱离本章材料搜集语境，会与此前特称推理冲突。希腊43b14的用语同样突出全称前提的作用；这不是允许删去已经讨论过的特称前提，正文应明确限定。
- “不相容项”的反向条目可省，是以否定换位为理由。不得泛化为不成立、未观察到、没有数据库记录都等于全称排斥。

## 5. 历史位置及收录边界

I.26问既有三格有哪些证明路线，I.27开始准备可供路线使用的前提材料；I.28将给具体选中项办法。本次只读I.28标题/起始以确定边界，不计其内容已完成。前文I.4–7的方向、全称否定换位、I.23–26的结构与搜索问题提供直接书内前置关系；年代更早的具体影响源，不能仅凭相似处宣布已证。
