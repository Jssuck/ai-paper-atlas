# Euclid《几何原本》I.15：来源、版本与证据台账

对应[中文深读](euclid-elements-i15.zh-CN.md)。范围为I.15及紧邻的历史、推论评论；属于几何与推理前史补读，不称现代AI论文。约公元前300年是作品传统年代，不是命题的可确定发现日期。书内依赖顺序不等于历史发现顺序，也不表示前史文献已穷尽。

## 主张和位置

| 主张 | 定位 | 限定 |
|---|---|---|
| 两条直线相交，分别形成两组相等对顶角 | Heath277题面和设图；Fitzpatrick19底–20首 | 不是任意四条射线或任意相等角；相反射线及共同顶点是关系前提。 |
| AE立于CD上，CEA与AED合为两直角 | Heath277末，I.13边注；Fitzpatrick20第一推理 | 第一组补角关系。 |
| DE立于AB上，AED与DEB合为两直角 | Heath278首，I.13边注；Fitzpatrick20 | 第二组补角关系，公共角是同一AED。 |
| 两组角和相等 | Heath278第15行附近，Post.4及C.N.1边注 | 公设4保证不同直角可作共同量；Fitzpatrick对应处只印C.N.1，不能声称两本边注完全相同。 |
| 同减AED，得CEA与BED相等 | Heath278第19–20行，C.N.3边注；Fitzpatrick20 | BED与DEB是同一普通无向角，不是有向旋转相等的自动规则。 |
| 第二对CEB与DEA也相等 | Heath278第21行附近；Fitzpatrick20 | 原文简写为同理；正文若展开是教学补全，不是额外原文。 |
| 交点四角合为四直角 | Heath278方括号Porism，第25行起 | 方括号与传本疑点应保留；Fitzpatrick此处不列该段。数学可导出性与文本作者归属是两类问题。 |
| 推论真实性的传本判断 | Heath278末部 | Heath说手稿证据的总体倾向不利于其真实性，但Proclus和Psellus都有。不是本文独立校勘所有手稿的结论。 |
| Thales发现、Euclid给出科学证明的说法 | Heath278评论，标Proclus299,3–6并称据Eudemus | 本次直接读取的是Heath转述，不是Eudemus或Thales原作；不据此断言唯一首创。 |
| 相等“对顶”角的逆向辨识须异侧等条件 | Heath278评论中的Proclus逆命题 | 不能从任意两角数值相等直接推出其边形成两直线。 |
| 任意多条直线同点相交的四直角和 | Heath279上部末段 | Heath转述Proclus的进一步推论，需按不重叠相邻扇区理解；不把所有两两夹角相加。 |
| I.16使用I.15 | Heath279后半I.16的I.15边注；Fitzpatrick20后半 | 只说明后续依赖，本篇不宣称完成I.16。 |

## 历史、术语和数学层次

Heath印278说明对顶角与相邻角的区别：延长相交的一条线后，交点周围形成两组相对的角。英文vertical在这里指共享顶点的对面位置，不是“竖直方向”，也不表示直角。现代点积、行列式、反向比例、旋转对以及180度/360度读数都属于教学重构，不能替换原证的两次I.13和同减步骤。

Heath印279还讨论正多边形围绕一点的例子。本单元不据该段扩展声称已经证明平面铺砌分类，更不把三种正多边形的同形铺砌说成所有可能混合铺砌。涉及早期发现者的材料均保留转述层级，不通过“著名人物”自动提高证据等级。
