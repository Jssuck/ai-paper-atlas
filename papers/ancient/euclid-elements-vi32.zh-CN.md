# 欧几里得《几何原本》VI.32：相似三角形怎样接成一条直线？

> AI 数学与形式推理前史补读。作品约公元前 300 年，实读 1908 / 2008 版。这是古典证明和几何约束的年代回填，不是 AI 论文，也不声称覆盖全部前史。

## 1. 来源与历史问题

- Euclid, *Elements*, VI.32。[Clay 希腊文与 Heath 英译](https://www.claymath.org/library/historical/euclid/files/elem.6.32.html)；T. L. Heath, *The Thirteen Books of Euclid’s Elements*, 卷 II（Cambridge University Press，1908），[正文、页影和校注入口](https://geometor.github.io/euclid/heath/volume_II/book_vi/propositions/32/)，印刷页 270–271 为正文、271–273 为校注；Richard Fitzpatrick, *Euclid’s Elements of Geometry*（2008 修订版），[希英对照 PDF](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=190)，页 190–191；[Joyce 教学读本](https://mathcs.clarku.edu/~djoyce/elements/bookVI/propVI32.html)。
- 输入是两个非退化三角形 ABC 与 DCE，它们在 C 相接；给出 $`AB:AC=DC:DE`$、$`AB\parallel DC`$、$`AC\parallel DE`$。按原图的方位摆放，结论是 **B、C、E 顺次在一条直线上**，不是仅有两条直线平行。问题的难处是从局部的比例和平行配置推出两段在公共点无折角地接上。
- 此处以 [VI.6](https://mathcs.clarku.edu/~djoyce/elements/bookVI/propVI6.html) 的夹角相等加夹边成比例为桥，最终用 [I.14](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI14.html) 的邻角判据落到全局结论。[XIII.17](https://mathcs.clarku.edu/~djoyce/elements/bookXIII/propXIII17.html) 在正十二面体的构造中实际使用本命题，以三角形 XPH 和 HTW 推得 X、H、W 共线。Heath 页 272 以此驳斥 Todhunter 对其用途的怀疑。页 272–273 也记录 Simson 把它联系到 [VI.26](euclid-elements-vi26.zh-CN.md) 的平行四边形对角线情形，但 Heath 认为第六卷的次序不支持把这种联系当作现存 VI.26 的证明来历。

## 2. 摆放条件：无向平行不等于有向对应

Heath 页 271 的图将 ABC 画于左、DCE 画于右。Fitzpatrick 页 190 的希腊和英文图同样如此。图上 A、D 在分列于 C 两侧的两个三角形的上方；**不能在推理开始就把 B、C、E 画成水平线然后把水平当成前提**。实际要用的是两对方向：A→B 与 D→C 同向，A→C 与 D→E 同向。

原题「拼在一个角处」没有用现代向量量化这两项。证明末尾却明说，就直线 AC 而言，射线 CB 和 CE 不在同侧，才用 I.14；Joyce 的 Guide 则明示两对对应边方向一致。Heath 页 271–272 指出题述若仅按字面接受无向平行和长度比例，会允许补角配置；一般的互补夹角并不相等，不能据此使用 VI.6。以下保留原图允许的拼法，并用符号把它明确化，而不把补明的有向假设说成题面本来已逐字写出。原图方向既保证最后异侧，也保证待相加的两个角真能拼成一个角。

校读：Heath 印本与 Fitzpatrick 的证明链一致，Clay 希腊文保留最后的异侧条件和命题重述；不要把英语题述单独当作完整证明。BA、AB 作为**长度**无差别；现代写向量时 AB 的方向不能换成 BA。这是需标明的解释差别，不是声称存在正式勘误。

## 3. 原证重建：传角，再证相邻角互补

1. **两次利用平行线。** 由 $`AB\parallel DC`$，截线 AC 给内错角 $`\angle BAC=\angle ACD`$（[I.29](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI29.html)）。再因 $`AC\parallel DE`$，以 CD 作截线，在该摆放中得 $`\angle ACD=\angle CDE`$。所以 A、D 处夹角相等。每次都要选对射线和内错角，不能把同侧内角误作相等。
2. **按正确的边对应传到 C。** 在相等夹角旁，BA 对 DC、AC 对 DE，且两边成比例。VI.6 因此给两三角形等角，对应顶点 $`(A,B,C)\mapsto(D,C,E)`$。由此 $`\angle ABC=\angle DCE`$。尤其第一个三角形的 B 角对应第二个的 C 角，不是对应 E 角。
3. **确保角真的是相邻的。** 原图中 CD 射线在 CA 和 CE 夹成的内角里，故 $`\angle ACE=\angle ACD+\angle DCE`$。上一节的方位条件已经指定这种内部分割；第 4 节给独立坐标检查，不以预期的直线作为理由。换入前两步得 $`\angle ACE=\angle BAC+\angle ABC`$。同加 $`\angle ACB`$，由 [I.32](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI32.html) 的三角形内角和得 $`\angle ACE+\angle ACB=180^\circ`$（原典表述为两直角）。
4. **由两直角得到顺接。** 射线 CE 和 CB 位于直线 AC 两侧，邻角满足 I.14，故两射线反向共线。C 位于 B 与 E 之间，两个闭线段仅在 C 相接。单独检查两个角的数值和为两直角，却不检查是不是异侧邻角，不能推出这一步。

## 4. 教学重构：把两种「平行」分开编码

令非共线向量 $`u=B-A`$、$`v=C-A`$。因长度为正且比例一致，有公共的正线尺度 $`k=|DC|/|AB|=|DE|/|AC|`$。在原图所需方位下，

$$
C-D=k u,\qquad E-D=k v,\qquad E-C=k(v-u)=k(C-B).
$$

最后一式同时给共线和点序：方向与 B→C 相同且长度非零，所以 E 在从 B 经过 C 的延长线上。等价地，从有限坐标做检查可以验 $`\det(C-B,E-C)=0`$，再验 $`(C-B)\cdot(E-C)>0`$；单独只验行列式不排除折返重合。

原角拼接的严格位置也可直接核对，不先把 B、C、E 假定为直线：$`D-C=-ku`$，$`A-C=-v`$，$`E-C=-ku+kv`$，因而 $`D-C=(E-C)+k(A-C)`$。两个边界向量独立，且系数均正，CD 在它们成的较小夹角内部。另一方面，将 CB、CE 分别与沿 AC 的向量 $`v`$ 作行列式，有 $`\det(v,B-C)=\det(v,u)`$、$`\det(v,E-C)=-k\det(v,u)`$，确为异侧。古证说的是角与直线，这个核对用的是现代有向面积。

还可做一个更锋利的分类。只保留无向平行和长度比例，写 $`C-D=\sigma k u`$、$`E-D=\tau k v`$，其中 $`\sigma,\tau`$ 各取正负一。因 $`u,v`$ 线性独立，

$$
E-C=k(\tau v-\sigma u),\qquad
\det(C-B,E-C)=k(\sigma-\tau)\det(u,v).
$$

- 两个符号都正：原题图式，得到顺接。
- 两个都负：行列式仍为零，但 CE 与 BC 反向，也即 CE 与 CB 同向，两个线段在离 C 的一段正长度上重叠；不满足原证最后的异侧条件。
- 一正一负：行列式非零，不共线。是否在 AC 两侧单独不能决定结论。这给了对 Heath 所指出题述缺口的现代完整分类，不是传本写过的符号表。

## 5. 算例和反例

设 $`A=(0,0),B=(0,2),C=(3,0)`$。下列都令 $`|DC|=4,|DE|=6`$，满足夹边长度比例 $`2:3=4:6`$；若没有特别说明也保持对应直线无向平行。

| D 与 E 的选取 | CE 与 BC 的关系 | 说明 |
| --- | --- | --- |
| $`D=(3,-4),E=(9,-4)`$ | $`CE=(6,-4)=2(3,-2)`$ | 两段顺接；C 的确在 B 与 E 之间 |
| 镜像第二三角形：$`D=(3,4),E=(9,4)`$ | $`\det((3,-2),(6,4))=24`$ | 即使夹角恰巧同为直角、两三角形相似，也不能仅由无向平行推出共线 |
| 只使另一边反向：$`D=(3,-4),E=(-3,-4)`$ | 行列式 −24 | CB、CE 仍在 AC 两侧，但对应方向不全对，不能跳到 I.14 |
| 两对应边均反向：$`D=(3,4),E=(-3,4)`$ | $`CE=-2(3,-2)`$ | 三点共线，但这里是 C–B–E，BC 和 CE 重叠 |

表中 CE、BC 的坐标写的是有向向量。如果连平行也不要，例如把第一个合法的第二三角形绕 C 整体旋转四分之一圈，则长度不变，但新的 CE 成 $`(4,6)`$，和 BC 的行列式为 26；两组长度比例没有控制朝向。

## 6. 局限与复盘

原证不是从三点观测拟合直线，也不解决误差下的近似平行。现代复现用精确有理坐标检验方位、行列式和点序，测试中有反向和不共线的配置。其有限枚举不能代替一般向量证明，更不是复现古代图面的精确尺寸。共线向量、重合点、零边都不在非退化假设以内。

核心教训：**约束的方向是输入的一部分，点序是输出的一部分。** 边长比只给尺度，平行加同向才给有向关系。检查时不仅应问最后的式子过不过，还要问式子是否表达了正确的几何命题。用这一点讲现代几何求解是教学类比，不主张原典直接影响了当代 AI。

## 7. 练习与答案

1. **为何 $`\angle ABC`$ 对 $`\angle DCE`$？** 对应为 A→D，AB 对 DC，所以 B→C；第二个三角形的 C 角正是 DCE。
2. **为何角和为两直角还必须看异侧？** 两条同侧射线也可能各与 CA 成直角或出现重叠；I.14 用的是隔着公共边的两个邻角，不是两个任意角的数值之和。
3. **合法算例的比例尺度为多少？** $`k=4/2=6/3=2`$。BC 的长度为 $`\sqrt{13}`$，CE 为 $`2\sqrt{13}`$，BE 为 $`3\sqrt{13}`$。
4. **若行列式为零且点积为负，是否满足原题？** 不满足顺接；CE 与 BC 反向，CE 与 CB 同向，两个闭线段不只在 C 相接。
5. **如果比例成立但两组平行都不指定方向，是否至少一定共线？** 不。不同号的情形给非零行列式，表中镜像只翻转一组对应便是反例。
