# 欧几里得《几何原本》VI.7：不是夹角，也能判相似吗？

> 数学与形式推理前史补读。原作通常系于约公元前 300 年。本篇回填年代目录，不是现代 AI 论文，也不宣称穷尽前史。

[VI.6](euclid-elements-vi6.zh-CN.md) 的等角必须夹在两条同比边之间。VI.7 则把等角放在别处，另加一条信息：两图的第三个对应角要么都锐，要么都不锐。这个条件不告诉你角有多大，却能排除另一种形状。欧几里得通过反证把不等的两角变成一个等腰三角形；现代坐标解里，同一个障碍表现为射线至多两次交圆。

## 1. 原典与校注

| [Heath 英译评注，1908，第 II 卷](https://www.wilbourhall.org/pdfs/heath_euclid_ii.pdf#page=219) | 印刷 pp.206–208（扫描 219–221）为命题、两图和结尾；pp.208–209 的评注另谈 Walker、Todhunter 与 Simson 的表述。注意区分古证与后世建议。 |
| [Clay 希腊文与 Heath 英译](https://www.claymath.org/library/historical/euclid/files/elem.6.7.html)；[Joyce 全文与导读](https://mathcs.clarku.edu/~djoyce/elements/bookVI/propVI7.html) | 与书版核对正文章节；都保留锐角、不锐角两个分支。对读未见需要改写核心古证的独立勘误。 |

Heath p.208 转述 Walker 和 Todhunter：若只读总述，最好明确一开始那两个等角的**对边也要对应**。正文其实已经固定了顺序：A 对 D，故 A 的对边 BC 对 D 的对边 EF。pp.208–209 还记录一条较强的表述：第三角不是相等就是互补；Simson 另列其中一个恰是直角的情形。下面分别说明这些细节，不把它们倒填进古证。可核查的书内关系是：VI.6 给出夹角版本；VI.7 证明中实际援引的是 [VI.4](euclid-elements-vi4.zh-CN.md) 的等角推出成比例，不是直接用 VI.6。这里不据命题序号推断最初发现的先后。

## 2. 输入、对应与结论

两图是非退化欧氏三角形，边长为正，角为无向内角。固定 A↔D、B↔E、C↔F。用 $\sim$ 表示两比相等，原题给出

$$
\angle BAC=\angle EDF,\qquad AB:BC\sim DE:EF.
$$

另要求 C 与 F 的角都小于直角，或都不小于直角。直角归后者；要检查的是 C 与 F，不是夹在比例边间的 B 与 E。待证的是 $\angle ABC=\angle DEF$ 以及 $\angle ACB=\angle DFE$ 。再用 VI.4 才得所有对应边同比。

## 3. 按原文重建两支反证

**先作辅助三角形。** 若 B 与 E 的角不等，交换整组三角形的名字后，可假定 B 的角更大；两分支的假设都关于 C 和 F 对称，因此允许交换。在 B 按 [I.23](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI23.html) 复制 E 的角，令 $\angle ABG=\angle DEF$ 。教学补足：将射线 BG 选在 BA 与 BC 之间，它与线段 AC 的内部相交；在现代平面中，内射线方向是 BA、BC 两方向的严格正线性组合，重新缩放两系数使其和为一即可得到该交点。于是点序是 A–G–C，不是 G 在边的延长线上。此时 A 的角没有变；[I.32](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI32.html) 赋予第三角 $\angle AGB=\angle DFE$ 。等角的是 ABG 和 DEF，目标 ABC 尚未证明。

**再把比例转成等腰条件。** 对辅助三角形和 DEF 用 VI.4，接上原题比式（[V.11](euclid-elements-v11.zh-CN.md)）：

$$
AB:BG\sim DE:EF\sim AB:BC.
$$

这次共用的是前项 AB，不同于 VI.6 共用的后项；[V.9](euclid-elements-v9.zh-CN.md) 也能据此给出 $BG=BC$ 。按 [I.5](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI5.html)，等腰三角形 BGC 的两个底角相等。由于 G 在 AC 内部，C 处的射线 CG 和 CA 同向，G 处的 GA 与 GC 反向。于是

$$
\angle BGC=\angle BCA,\qquad
\angle AGB+\angle BGC=180^\circ.
$$

**分别排除两种可能。** 若 C、F 都锐，C 的等角 BGC 也锐，[I.13](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI13.html) 使邻角 AGB 钝，但 AGB 正等于 F 的锐角，矛盾。若 C、F 都不锐，BGC 的两个底角就都至少为直角，违背 [I.17](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI17.html) 的两内角和严格小于两个直角。假设 B、E 不同无法成立。A、D 已等，再用 I.32 得 C、F 相等。

**后世的统一观察，不是原文的分支写法。** 若夹角 B、E 不等，上述等腰、邻角与辅助三角形的对应直接给 C、F 互补，且等腰三角形的底角 C 必须锐；这时 F 钝。若有一个第三角恰是直角，互补只可能给另一个直角，因此也不能产生不同形状。这是 Heath 引述的 Todhunter 与 Simson 所强调的边界。“都不锐”包括两个分别涉及直角与钝角的输入标签，但若其余精确前提成立，同一个直角不可能配一个钝角。

## 4. 独立的现代模型：射线与圆的交点

把每图平移、旋转或反射，并按其首条边缩放，使 A 成为原点，AC 沿正横轴，AB 长为 1，B 位于上半平面。第二个三角形同样处理；A 与 D 的共同角使两图的 B、E 重合为 $(x,y)$ ，其中 $y\gt0$ 。记 $r=BC/AB=EF/DE$ ，C 及 F 的归一化位置都形如 $(t,0)$ 且 $t\gt0$ 。圆心 B 与 C 的距离为 r，因此

$$
(t-x)^2=r^2-y^2,\qquad
(A-C)\cdot(B-C)=t(t-x).
$$

在 $t\gt0$ 时，点积的符号正是 $t-x$ 的符号。故锐角选 $t\gt x$ 的根，不锐角选 $t\le x$ 的根。给定同一个分支，至多一个根；判别为零时两根重合，对应直角，仍须检查交点在正射线上。判别为负无实交点；两条实根也未必都为正，不能一律宣布存在二解。这是一般代数推导，和下面有限的代码核对不是一回事。

## 5. 算例、反例与直角边界

取 A=(0,0)、B=(3,4)、C=(5,0)。有 AB=5、BC=√20、点积为 10，故 C 为锐角。令 D=(10,0)、E=(16,8)、F=(20,0)，是放大两倍后平移；初始对应角相等，DE=10、EF=2√20，F 仍锐角。把 C 换成 (1,0)、F 换成 (12,0)，则初始角、同比仍成立，新的一对第三角都钝，结论照样成立。

**不限制第三角时的反例。** 同取 A=(0,0)、B=(3,4)，比较 C=(5,0) 与 C′=(1,0)。AB=5 不变，BC=BC′=√20，在 A 的角相等，但 AC=5、AC′=1，形状不同。两处点积为 10 和 −2；分别是锐角与钝角。不是题设反例，而是删去分支条件以后的反例。VI.6 文末的非夹角反例也是同一机制，只是点的标号不同。

**恰好直角。** 在同一骨架上若给 BC=4，则唯一交点 C=(3,0)，点积为零。这个例子说明第三角的直角边界确有实例，并不是因为非退化假设被禁止。第三角若在 C 与 F 一为直角、一为钝角，不能靠四舍五入把它们当作精确兼容的输入。

## 7. 带答案的练习

1. 已知角是 A、D，为什么比例边并不夹住这个角？答：AB 与 BC 在 B 相交，DE 与 EF 在 E 相交；A 的另一条边 AC 没在所给比中。
2. 为什么 V.9 在这里比较的是 BC 和 BG？答：同一个正长度 AB 分别对 BC、BG 有相同的比，故两个后项相等。
3. 若画成 A–C–G，等腰三角形的哪个步骤会变？答：G 处的 GA 与 GC 同向而非反向，AGB 与 BGC 不再是所需的邻补角；原证要求 G 落在 AC 内。
4. 用未归一化的 A=(0,0)、B=(3,4)，若 BC=√20，两个候选横坐标是多少？答： $(t-3)^2=4$ ，故为 1 与 5；点积分别为 −2 与 10，只有后者是锐角支。
5. 为什么点积恰为零不是“缺一个选择”的情形？答：此时根恰在圆心的垂直投影处，两候选合一；只要它仍在正射线上且三角形非退化，形状是唯一的。
