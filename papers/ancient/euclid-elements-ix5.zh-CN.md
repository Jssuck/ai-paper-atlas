# 《几何原本》IX.5 深读：已知因子和乘积都是立方，怎样找回另一个立方？

$`216`$ 和 $`8`$ 都是立方数，且 $`216\div8=27`$。这种情况不是碰巧。欧几里得先在另外两个已知立方之间找到整数中项，再将这两个中项迁回原来的因子对，才认出 $`27`$ 是立方。现代算法直接相除两条立方边，但有一个条件不能省：为什么这个边长之商也是整数？

> **年代和范围**：约公元前 300 年是《几何原本》的作品年代范围。本篇是 AI 数学前史补读，不是 AI 论文，不把形式上的相似看成直接影响，也不声称穷尽古代相关工作。

## 1. 所据版本与前后关系

Euclid, *Elements*, Book IX, Proposition 5。实读 Thomas L. Heath 1908 年 [英译注释卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf) 印页 387 底至 388 上（PDF 第 400–401 页），以及 Richard Fitzpatrick [希英本印页 256](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=256)。对读 [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.5.html) 和 [Joyce 正文及导读](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX5.html)。Clay 的英译止于中项迁移，结论在希文和两本整本译文里均可核对。详细定位见[原典记录](../../reproduction/euclid-elements-ix5/source-review.zh-CN.md)。

[IX.4](euclid-elements-ix4.zh-CN.md) 从两个**因子**都是立方推出**乘积**是立方；IX.5 固定第一个因子为立方，将另一个因子的性质和乘积的性质互换为待证与已知。两篇都从 [IX.3](euclid-elements-ix3.zh-CN.md) 得到辅助立方，但转移中项的方向相反。IX.5 并不是把 IX.4 的推理箭头倒写，更不是断言立方乘积的每个因子都是立方。

## 2. 前提和符号

| 符号或结构 | 已知或待证 | 现代教学解释 |
| --- | --- | --- |
| $`A=a^3`$ | 已知立方因子 | $`a`$ 是其正整数边 |
| $`C=c^3=AB`$ | 已知立方积；希文 $`\Gamma`$ | 原文给出整数 $`B`$，因而 $`A`$ 整除 $`C`$ |
| $`D=A^2`$ | 辅助立方；希文 $`\Delta`$ | 边为 $`a^2`$，不能与 $`A`$ 的边混淆 |
| $`B`$ | 已知为整数，待证是立方 | 若程序只收 $`A,C`$，需先精确检查 $`B=C/A`$ 是整数 |
| 四项连比 | $`x:u=u:v=v:y`$ | 相邻比按“前项除以后项”读；整数校验为 $`u^2=xv`$、$`v^2=uy`$ |

原文的数与单位有别。以下正整数模型能处理 $`1`$，但把它当因子或商的退化例必须另标现代扩展。相等端点也应区分常数链和严格处于端点之间的数。

## 3. 原文逐步重建

1. **建造辅助立方。** 令 $`D=A\cdot A`$。[IX.3](euclid-elements-ix3.zh-CN.md) 已证明立方数自乘仍是立方。因此 $`D`$ 是立方，理由不是 $`C`$ 已知为立方。
2. **保住端点比。** 同一个 $`A`$ 乘 $`A`$ 得 $`D`$，乘 $`B`$ 得 $`C`$；[VII.17](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII17.html) 给出 $`A:B=D:C`$。现代交叉相乘可验 $`AC=BD`$。这条等式只联系两对端点，还没提供中项。
3. **从已知的一对取见证。** $`D,C`$ 均为立方，边分别全相等，所以是相似立体数。由 [VIII.19](euclid-elements-viii19.zh-CN.md)，两者之间存在两个整数中项。此处不能先说 $`A,B`$ 是相似立体数，否则已经暗中使用了要证的 $`B`$ 为立方。
4. **反向迁移，不倒置比值。** 依据 [VIII.8](euclid-elements-viii8.zh-CN.md)，将“有两个整数中项”从 $`(D,C)`$ 迁回同比的 $`(A,B)`$。“反向”指从乘过 $`A`$ 的对回到原对，仍是 $`D:C=A:B`$，不是 $`C:D=A:B`$。
5. **用首项传递性质。** [VIII.23](euclid-elements-viii23.zh-CN.md) 说明四数连比时，首项若是立方，末项也是立方。目标链首项为 $`A`$，给定是立方，故末项 $`B`$ 是立方。若 $`A=B`$，结论直接由已知 $`A`$ 为立方得到，无须要求相等端点有严格中项。

## 4. 现代教学重构：先证中项可整除，再写出新边

源链的两端分别由边 $`a^2`$ 与 $`c`$ 生成。把三条边逐一从 $`a^2`$ 换成 $`c`$，得 $`a^6,a^4c,a^2c^2,c^3`$。形式上每项除 $`A=a^3`$，会得到 $`a^3,ac,c^2/a,c^3/a^3`$。**端点可整除也不意味着任意整数列的中项可整除。** 在这里要利用立方根之间的关系，而不是把 $`B`$ 是立方当成前提。

令 $`g=\gcd(a,c)`$，约成 $`a=gu,c=gv`$，其中 $`u,v`$ 互质。由 $`A\mid C`$，有 $`u^3\mid v^3`$。若 $`u`$ 有任一素因子，则也整除 $`v^3`$、因此整除 $`v`$，与互质矛盾。故 $`u=1`$，从而 $`a\mid c`$。写 $`c=ak`$，得到全部整数见证：

$$
(D,a^4c,a^2c^2,C)
\xrightarrow{\ \div A\ }
(a^3,a^2k,ak^2,k^3).
$$

这里 $`B`$ 的立方边是 $`k=c/a`$。两条链的生成倍率都是 $`k/a=c/a^2`$，不要求它本身是整数。这个约分论证已经足够作现代简证：$`(c/a)^3=B`$ 且 $`c/a`$ 为整数。它也说明为什么本题可以把原链逐项除以 $`A`$；这不是宣称原文先做了欧几里得算法或写出了 $`k`$。

| 证据位置 | 能核实的内容 |
| --- | --- |
| Heath 387 底、Fitzpatrick 256 起讲 | 以任意因子 $`B`$ 为待判对象；建立 $`D`$ |
| Heath 388 首半、Fitzpatrick 256 中段 | VII.17 的比例；VIII.19 的供给方向；VIII.8 的迁移方向 |
| Heath 388 正文末、Fitzpatrick 256 在 IX.6 前 | A 是立方，借 VIII.23 得 B 是立方 |
| 本节约分和显式边长 | 教学推论，不归给原文；无需引入浮点立方根 |

## 5. 算例与失去前提后的反例

- **递增**：取 $`A=8,C=216`$，则 $`a=2,c=6,D=64`$。源链 $`(64,96,144,216)`$，各项除以 $`8`$ 得 $`(8,12,18,27)`$，新边 $`k=3`$。手核 $`12^2=8\cdot18`$、$`18^2=12\cdot27`$。
- **递减**：同样的 $`C=216`$，取 $`A=27`$（边 $`3`$）。$`D=729`$，源链 $`(729,486,324,216)`$，各项除以 $`27`$ 得 $`(27,18,12,8)`$。顺序仍从 $`D`$ 到 $`C`$、从 $`A`$ 到 $`B`$，生成倍率为 $`2/3`$；商的边是 $`2`$。
- **两数都是立方而商非整数**：$`A=8,C=27`$，有理数商是 $`(3/2)^3`$，并不是整数立方，也没有原命题要求的整数 $`B`$。辅助链 $`(64,48,36,27)`$ 虽全为整数，除以 $`8`$ 后第二中项为 $`9/2`$，所以不能当作整数比例链。
- **任缺一个立方前提都不行**：若积为立方但已知因子不是，$`2\cdot4=8`$ 的商 $`4`$ 不是立方；若只有因子为立方，$`8\cdot2=16`$ 并不能找回一个立方商。对比这两种失败与“两个都是立方但不可整除”，它们缺少不同前提。
- **现代延伸**：若正整数 $`a^n`$ 整除 $`c^n`$，用同样的互质论证可得 $`a\mid c`$，再得商为 $`n`$ 次幂。这里 $`n`$ 是任意正整数；并非扩张对 IX.5 文本本身的断言，也不涉负数和零。

## 7. 复盘与答案

1. **$`A=64,C=1728`$。写出源链、目标链及待证立方的边。**  
   **答**：$`a=4,c=12`$。源链 $`(4096,3072,2304,1728)`$，目标链 $`(64,48,36,27)`$，边是 $`3`$。
2. **$`A=8,C=64`$，如果比例链四项都相等，是否推翻命题？**  
   **答**：否。$`D=64=C`$ 且 $`B=8=A`$。已知 $`A`$ 立方，便立即得到 $`B`$ 立方；无需声称存在严格介于两端的数。
3. **“如果 $`c/a`$ 不是整数，它的立方还是可能为整数”能用来质疑本命题吗？**  
   **答**：不能。将 $`c/a`$ 化为互质的 $`v/u`$，其立方仍是既约分数 $`v^3/u^3`$；若立方为整数，分母只能是 $`1`$。这种现代证明与原文的整数中项迁移达到同一结论，但调用的工具不同。
