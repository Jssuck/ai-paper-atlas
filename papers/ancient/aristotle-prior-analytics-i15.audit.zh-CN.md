# I.15：独立论证核验

## 核验对象与结论

独立阅读本篇正文第0–16节、20道练习及答案，并对照本次Owen印112–118章内论证顺序；历史位置和希腊否定范围另见[独立来源审查](aristotle-prior-analytics-i15.source-audit.zh-CN.md)。对[教学模型](../../reproduction/aristotle-prior-analytics-i15/model.py)、[演示](../../reproduction/aristotle-prior-analytics-i15/demo.py)及其说明，另写不复用作者模态计算的集合语义检查。**在明确限定的现代语义下，正文一般证明、反模型和练习答案通过本次论证核验。** 这不是对古代模态体系唯一解释、整体可靠性或完备性的认证。

## 逐项审核

1. **直接范围转移。** 实际C包含于实际B，保证同一对象属于大前提所覆盖范围；特称小前提提供一个实际共同见证。正文没有把该见证改成任意C，也没有对空C作全称到特称的非法降量。
2. **可能性保存。** 一般证明以同一世界应用后承，世界集合无需有限；必要性保存在另一条件下说明。命题p表示联合前提，不被误认为单一词项或每个前提的分别可能。
3. **假不保假。** 两世界p假真、q恒真是有效反例；正文不把后果可能误写成后果假。希腊文的“假”措辞由来源核验处理，本审查独立确认推理不能支持保假。
4. **背景相容。** Γ实际真与h可能不足以给出Γ∧h可能；保留背景的条件没有在现代证明中隐去。原文无时间限定不被直接定义为现代全世界必然性。
5. **稳定桥强度。** B在各世界包含于A只传正向见证，不交只传反向见证；A恒真或恒假的反例表明均不足一般保证双向偶然。正文只将稳定桥称为现代充分条件。
6. **强桥。** 额外相反A见证与稳定桥给的见证属于同一个实际C对象；特称情形没有拼接两个人的两侧见证。正文也承认这一附加条件不是历史公理或已证最弱条件。
7. **量词次序。** 两对象分别成为B不意味着一起成为B；逐对象全称可能与全句共同实现严格区分。程序的`jointly_possible`和`modal`分别检查它们。
8. **否定范围。** 否认必要A只是可能非A，非必然非A；正文又区分全称量词与必要算子的位置。乌鸦与运动例的任务是分别排除强偶然和普遍必要性，不被当作现代经验事实。
9. **小前提为否定。** 偶然内部改质不交换项，实然否定不得照搬该规则；雪／沥青以及自造两对象反模型说明覆盖断裂。原文“不直接显出”与现代“无逻辑后承”没有混同。
10. **特称与结尾总结。** 主文保留特称大前提的覆盖缺口、不同存在见证以及全称大前提总结的例外条件。未把压缩总结误写成无条件一般规则。
11. **20题。** 逐题核查方向、数量、空项条件、可能性、否定、背景与见证；答案均与正文所定义语义相符。第20题明确有限检查不等于完整历史形式化。

## 独立实跑

脚本：[check_arguments.py](../../reproduction/aristotle-prior-analytics-i15/argument-review/check_arguments.py)。它自行用Python集合表示每世界外延、选择世界和对象见证，与作者位掩码语义交叉对照；并独立判断现代桥定理的前提和结论。没有使用可被优化模式删除的裸`assert`。

在附件`argument-review`目录运行：

```sh
python check_arguments.py > run.log
python -O check_arguments.py > run-O.log
python -OO check_arguments.py > run-OO.log
```

[normal](../../reproduction/aristotle-prior-analytics-i15/argument-review/run.log)、[-O](../../reproduction/aristotle-prior-analytics-i15/argument-review/run-O.log)、[-OO](../../reproduction/aristotle-prior-analytics-i15/argument-review/run-OO.log)均真实完成且通过。每模式检查9,864个模型／实际索引配置，来源为1对象1、2、3世界与2对象2世界全部赋值。实际索引与重复同构均计数，不视为统计样本。

每模式765,285次显式判定，包括：532,656个独立模态值；177,552个共同实现值；39,456个同对象强桥值；4,786个直接范围定理实例；6,406个稳定弱桥实例；4,358个额外见证强桥实例。另有65个4世界命题可能性保存实例、1个必要性保存实例，以及假不保假、分别可能不联合、背景失效、全实际项非空的当前关系失败、逐对象不共同等各1个边界检查。不同定理前提可重叠，不能把计数当作独立有效率。

## 证据边界与版本绑定

输入摘要见[review-inputs.json](../../reproduction/aristotle-prior-analytics-i15/argument-review/review-inputs.json)。它绑定实际核读的主文、来源账本、模型、演示、测试和附件说明；来源账本的语义表述经此核对，具体古文图像校读另由来源审查负责。后续修改这些文件时，原摘要只能证明旧版本；必须复核变化后更新，不可无检查迁移通过结论。

有限枚举用于检查实现及有限反例，不替代正文对任意论域和世界集合的证明；本脚本也不是独立古希腊语言学审稿或完整历史证明器。代码输入异常、变异测试等实现层问题另由独立代码审查负责。未执行的工具、无限模型、现实生物及AI指标不计入结论。
