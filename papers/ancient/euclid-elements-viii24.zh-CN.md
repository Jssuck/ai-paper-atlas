# 欧几里得《几何原本》VIII.24：相同的平方比，怎样传递平方性？

**年代跳转 · 数学与证明方法前史补读 · 深读 v1。** 《几何原本》约为公元前 300 年前后的作品。本篇精读卷 VIII 命题 24，不是现代 AI 论文，也不声称存在直接技术传承。

## 1. 已知的是两对数的比，不是中项

给出 $`A:B=4:9`$，又有两个平方见证 $`C:D=16:36`$。平方见证之间的中项是 $`24`$；目标对的中项却是 $`6`$。它们恰好相差一个分数倍率 $`1/4`$。原证明要保证的是**中项存在这件事**可以传递到相同端点比，而不是把 $`24`$ 原封不动搬到目标对，或误要求两对数之间的缩放量是整数。

[前面的 VIII.22](euclid-elements-viii22.zh-CN.md) 从已经给出的整数中项传递平方性；VIII.24 的新问题是只给比，怎样先重造中项。此前 [VIII.18](euclid-elements-viii18.zh-CN.md) 从两对相似的边造中项，[VIII.8](https://www.claymath.org/library/historical/euclid/files/elem.8.8.html) 则负责在两个同比例的端点对之间传递整数中项的存在。

**书目。** 欧几里得，《几何原本》卷 VIII 命题 24：[Heath 1908 卷 II，印页 380](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)、[Fitzpatrick 希英对照 pp.249–250](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)、[Clay 希英网页](https://www.claymath.org/library/historical/euclid/files/elem.8.24.html) 和 [Joyce 正文](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII24.html)。转引差异见[原典核对](../../reproduction/euclid-elements-viii24/source-review.zh-CN.md)。

## 2. 先构造，再转移，最后闭合

| 符号 | 约定 |
| --- | --- |
| $`A,B`$ | 目标端点，正整数，已知 $`A=s^2`$ |
| $`C,D`$ | 平方见证，$`C=x^2,\ D=y^2`$，且 $`A:B=C:D`$ |
| $`M,m`$ | 分别为见证对、目标对的正整数中项 |
| $`p,q`$ | 把根比 $`x:y`$ 约到最简后的正互素代表 |

1. **造见证中项。** 平方的两条边取成相等因子，所以 $`(x,x)`$ 和 $`(y,y)`$ 对应成比例。依 VIII.18，在 $`C,D`$ 之间构造中项。现代写成 $`M=xy`$，核对 $`x^2:xy=xy:y^2`$。
2. **传递整数见证。** 因 $`A:B=C:D`$，VIII.8 给出 $`A,B`$ 之间也有一个整数中项 $`m`$。其关键是最小链的端点能以相同的整数次数量尽新端点；这里的整数次数不是 $`A/C`$。
3. **使用已知的平方端点。** 有了正整数连续比例 $`A,m,B`$ 和平方数 $`A`$，VIII.22 给出 $`B`$ 也是平方。Heath 把这三条依赖分别标为 VIII.18、VIII.8、VIII.22；Fitzpatrick 同。Joyce 在“传递”附近重复链到 VIII.18；从各命题的内容可知不能把它当成传递步的依据。

## 3. 把转移的整数性写出来

**教学重构。** 令 $`g=\gcd(x,y)`$，$`p=x/g,\ q=y/g`$。见证链等于 $`g^2(p^2,pq,q^2)`$，其最小端点 $`p^2,q^2`$ 互素。因为 $`Aq^2=Bp^2`$，由互素性得 $`p^2`$ 整除 $`A`$，且 $`q^2`$ 整除 $`B`$，对应商相同。于是取 $`k=A/p^2=B/q^2`$，由两段交叉相乘证实：

$$
(A,m,B)=k(p^2,pq,q^2),\qquad k\in\mathbb Z_{>0}.
$$

这个 $`m`$ 等于 $`M`$ 乘 $`A/C`$，但能证明积为整数的是约化，不是分数倍率本身。若已知 $`A=s^2`$，因 $`p^2\mid s^2`$，得到 $`p\mid s`$，再取 $`t=(s/p)q`$；于是 $`B=t^2`$，并可用 $`m=st`$ 检查两种构造是否一致。这里 $`p^2\mid s^2`$ 推 $`p\mid s`$，可对每个素数比较指数，也可用最简分数平方若为整数则分母为 1 的引理。

用相同机制可得到**现代推广**：一对正整数具有平方比，当且仅当两数可以写成共同的无平方因子部分乘各自的平方。理由是对每个素数，端点中的指数差为偶数，故剩余的奇偶部分一致。若 $`A`$ 已是平方，共同的剩余部分便是 1。反过来，两端同为非平方也完全可能；不能看见比是平方比就省去一个平方端点的前提。

| 目标对；见证对 | 计算 | 结论或边界 |
| --- | --- | --- |
| $`(4,9);(16,36)`$ | $`M=24,\ m=6,\ k=1`$ | 见证到目标的倍率 $`1/4`$ 不妨碍整数性 |
| $`(144,324);(16,36)`$ | $`M=24,\ m=216,\ k=36`$ | 目标的根是 $`12,18`$；两种中项计算一致 |
| $`(9,4);(36,16)`$ | 约化比 $`9:4`$，$`m=6`$ | 两组同时倒序可用，单组倒序一般会改比 |
| $`(8,18);(16,36)`$ | $`k=2,\ m=12`$ | 平方比仍有整数中项，但两端都不是平方 |
| $`(4,8);(16,36)`$ | $`4\cdot36\ne8\cdot16`$ | 首项平方、见证也为平方，但没通过同比检查 |

单位及等端点只在现代正整数模型中讨论。等端点的中项等于端点，并不严格落在两者之间。若允许非整数目标，则结论也不是“整数平方”：例如 $`4:(16/9)=9:4`$，但 $`16/9`$ 只是一有理平方。

## 4. 可复核的证据

- **原典。** Heath p.380 的命题正文及紧随的代数化短注都保留了 VIII.8 的作用；Fitzpatrick p.249 开头、p.250 完成。Clay 希文有结论，所列英译停在获得目标中项处。Joyce 正文保留结论，引用锚点在传递步重复 VIII.18。
- **教学小实验。** [源码、Notebook、实跑日志](../../reproduction/euclid-elements-viii24/README.md) 验证平方前提、同比、最小链和整数中项；独立的有界对照不复用该移植步骤。在 640,000 组输入中，200 组通过，1,008 组同比但首项非平方，638,792 组不同比。算例边界与复现都经[独立技术核对](../../reproduction/euclid-elements-viii24/technical-review.zh-CN.md)。没有历史数据集、性能基准或作者实验；有限检查不能证明一般定理。
- **阅读方法。** 分清可以随比例传递的结论、中间见证的具体值，以及算法要维持的整除条件。这三个对象若只写成一个“同比”，容易把正确的原典论证实现成错误的取整程序。

## 5. 练习与答案

1. 见证端点 $`25,100`$；目标首项 $`9`$。求目标末项和中项。  
   答：最小根比 $`1:2`$，目标链为 $`9(1,2,4)=(9,18,36)`$。
2. 见证对 $`(16,36)`$ 的中项 $`24`$ 除以 $`4`$，为什么不算任意四舍五入？  
   答：这里确切的目标倍率为 $`1/4`$；一般情况用原始链 $`(p^2,pq,q^2)`$ 和目标整数倍 $`k`$ 证明乘积恰为整数。
3. 若只知道 $`A:B=4:9`$，是否可说两端必为平方？  
   答：不可。例如 $`8,18`$ 同比而都不是平方。中项存在与平方端点存在是不同的命题。
4. $`A=100,\ C=45,\ D=20`$ 可以用于 VIII.24 吗？  
   答：给定见证 $`45,20`$ 不是平方，不能直接当原命题的平方见证；但 $`45:20=9:4`$，可换成平方见证 $`(9,4)`$，算得同比所要求的 $`B=400/9`$ 不是整数，故没有这样的正整数目标对。这里须在计算时先检查目标整数域，不能宣称整数平方结论。
5. 为什么 VIII.18 不能单独替代 VIII.8？  
   答：VIII.18 需要现成的相似边，先给见证对造中项；VIII.8 只靠端点同比保证目标对也有整数中项，目标的边并未在这一阶段给出。

**复盘：** 见证对供给中项，最小整数链把存在性传到目标对，再用已知的平方首项闭合。关键不是避免分数，关键是证明最后取到的是整数。
