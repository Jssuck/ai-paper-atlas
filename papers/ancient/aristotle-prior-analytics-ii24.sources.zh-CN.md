# II.24：来源、章界与证据台账

服务于[原创中文深读](aristotle-prior-analytics-ii24.zh-CN.md)。只公开书目链接、必要定位与原创分析，不公开扫描、PDF或全文翻译。

## 1. 书目与范围

Aristotle，*Analytica Priora / Prior Analytics*，第二卷第二十四章，**68b38–69a19**。本次是公元前四世纪逻辑与说服思想的前史补读；版本年代不等于单章写作年。接续II.23，II.25只看开头定界，不计完成；不声称年代目录穷尽。

## 2. 亲读见证

### S1. Bekker1831希腊文扫描

Immanuel Bekker编，*Aristotelis Opera*，vol.I，Berlin，1831，印68右栏末与69左栏上段。

- [全卷](https://archive.org/details/aristotelisopera01arisrich)
- [印68图像](https://archive.org/download/aristotelisopera01arisrich/page/n83.jpg)
- [印69图像](https://archive.org/download/aristotelisopera01arisrich/page/n84.jpg)

实际查看两页图像，章24始于68b38，章25始于69a20。核对政治例A/B/Γ/Δ项位、69a10–13的一例/多例、末段部分到部分与归纳比较；同时查看页底校记。68b39–40有文字异文，69a11–15亦见记录。本次是针对所读印本的核对，不声称穷尽手稿或建立独立希腊文定本。对未能凭本次见证裁决的异文不自行替原文改字。

### S2. Owen1853英译扫描、边注、脚注与ERRATA

Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol.I，London: Henry G. Bohn，1853。

- [全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)
- 实际阅读印 **232–233** 本章全部正文、边注与脚注；PDF页序251–252（1起算）。印232顶端页底续注属于前章，不能误记为章24注1。
- 印232章题 *Of Example*；注1区分不完备归纳与随后的演绎应用，引用Mill、Mansel、Hill、Whately、Hessey。这些是译注解释背景，不是原文时代前驱。
- 印232注2–4说明大项、小项及相似项；印233注1用部分到部分说明整个路线，但其A为整体、B为部分的配置不能作为独立证明一般规则的根据。
- 印233注2称C/D在共同A之下，而正文共同分类项是B。正文指出该表述张力，不把注中配置当成已经取得C有A的证据，不擅自宣布原典错误。
- 印233注3–4解释归纳不在该比较形式中继续应用于目标，而举例会继续应用且不取全部来源。印233注5开始属于章25，不作为本章结论。
- **ERRATA：** 实际查看全卷正式勘误页，列印219标题、273边注、594标题三项，没有印232–233条目。这只是该页的检索结果，不等于没有异读或解释问题。

### S4. 同作者关联原典：《修辞学》I.2

Aristotle，*Rhetoric*，I.2；W. Rhys Roberts英译，Internet Classics Archive [Book I / Part2](https://classics.mit.edu/Aristotle/rhetoric.1.i.html)。实际阅读Part2关于例证与省略前提、偶然事项、例证的部分到部分关系，以及Dionysius/Peisistratus/Theagenes先例和共同原则的段落。

这支持同作者内部论题关联以及更熟悉案例向较不熟悉案例的结构，不证明两作品各段的成文先后，也不独立认证所举政治事件。网站为整部作品列的单一年份不用于给本章定年。Owen还指向《修辞学》II.20、II.24、III.17；本单元不因看过这些引用就冒称已经完整亲读被引章，正文只使用实际核查的I.2。

## 3. 主张—位置—责任边界

| 主张 | 见证位置 | 本文承担的额外工作 |
| --- | --- | --- |
| 举例借相似第三项支持大项与中项 | 68b38–40；Owen232开头 | 把“已知关系”和“桥的根据”分开 |
| 目标、共同类和已知先例 | 68b40–69a10；Owen232 | 论域选行动、统一评价主体；不作战争史定律 |
| 可用多个相似案例 | 69a10–13；Owen232–233 | 并集重构及未覆盖反模型 |
| 整体部分到部分 | 69a13–16；Owen233 | 区分整体方向与局部一般应用 |
| 非全体来源与继续应用 | 69a16–19；Jenkinson注100 | 与II.23比较但不泛化到所有归纳理论 |
| “不完备/无形式逻辑力量” | Owen232注1 | 明确译注评价而非亚里士多德原话 |

| 有限世界检查 | 自有源码、日志与技术独审 | 真实运行，不是历史算法或经验置信度 |

## 4. 不确定性与公开边界

原文使用的“坏/有害”与“不利”没有给出可重跑指标；例子的历史细节、机制及语境不能由集合代码核证。本文不将同属一类视为对任何属性充分的相似性，更不把Owen注语与原文混为一谈。所见异文和译注差异已经记录，但本次研究不是完整版本学调查。公开成果只含原创解释、必要书目链接、自有教学代码和检查后的运行证据。
