## 章界、注释与勘误

1. **完整范围为 66a16–24**；下一章 II.19 从 66a25 开始。正文没有将本章九行当作整部《前分析篇》，也没有把前章 II.17 的反证论述归入本章。
2. Owen 印页 221 的脚注 2 将上层命题解释为 D、E、F、G；脚注 3 指向假结论 C，并附后世逻辑教材参照。脚注 1 属 II.17，脚注 4、5 属 II.19。作者没有据这些参照虚称已阅读 Aldrich 或 Huyshe。
3. Jenkinson 注 76 回指 53b11–25，支持将本章与本卷此前对真假前提、结论的讨论相连；不是本章独立勘误。
4. Owen 所读 ERRATA 列有印页 219、273、594 的改正，没有印页 221 或 II.18 条目。印页 219 的标题修订属于前章，不能移植至本章；“此表未列”也不等于“所有版本无讹误”。
5. Bekker 校勘栏相关条目为 66a16 `πρῶτον om B`、66a17 `ἔσται C`、66a21 `δὲ om BC`、66a23 `περαίνεται C`。正文与台账把它们限定为编辑本报告的异读，不声称亲见手稿。尤其“第一／首先”的用词有省略异读，不应据此制造唯一、时间最早的错误定位规则。
