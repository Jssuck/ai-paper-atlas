## 实读位置

1. Heath：印刷 261–262／PDF 282–283，I.8 命题和证明；印刷 262–264／PDF 283–285，结论范围、Aristotle 关联、Philo 替代证明评论；PDF 16 卷首勘误。
2. Fitzpatrick：印刷／PDF 14–15，完整 I.8；第 15 页 I.9 对 I.8 的引用只用于依赖定位。
3. Clay 历史入口：区分作品约公元前 300 年与 D’Orville 301 抄本公元 888 年。

扫描只作阅读核验，不作为公开附件；公开内容为原创分析与必要链接。

## 核查结果

| 项目 | 结果 |
|---|---|
| 书目、页码、跨页范围 | 两版本可定位；Fitzpatrick 英文 I.8 的末尾确实跨至第 15 页。 |
| 三边对应 | AB 对 DE、AC 对 DF、BC 对 EF 与两版一致；没有把无序边长集合当作指定对应。 |
| 原始结论 | 仅直接断言 BAC 与 EDF 相等；其余角和三角形比较注明可再调用 I.4，符合 Heath 262 的评论。 |
| 叠合与 I.7 | 保留 B 到 E、C 到 F 的方向；同侧安排明确标为教学补显，没有假称 I.7 能证明刚体运动合法性。 |
| 镜像 | 正确区分异侧反例对 I.7 无同侧版本的作用与 I.8 角相等的有效性。 |
| 替代证法归属 | 明确为 Heath 经 Proclus 记载的 Philo 证明，不混入 Euclid 原证；避开 I.7 不等于避开叠合。 |
| 历史关系 | Aristotle 段落是经 Heath 转述的线索，不声称独立校读或确定发现史；不将 Proclus 的注释年代当成 Euclid 的同期工作。 |
| 勘误范围 | Heath 扫描 PDF 16 所列条目不涉及 I.8 或印刷 261–264 页；未扩大为所有版本绝无勘误。 |
| 现代工具 | 内积、Gram 矩阵、正交证书均标为现代教学重构，不归于古代原文。 |
| 实跑与定理 | 有限检查不冒充一般证明；数值与代码正确性由另行技术审查核验。 |
| 隐私与版权 | 正文与来源文件不包含私人对话、账户资料、扫描全文或译注全文翻译。 |

## 修订意见

初审建议将“经 Heath 确认的前驱线索”改为“由 Heath 转述的前驱线索”，避免将转述升级为本单元的独立确认。该意见已在最终稿落实；其他关键来源主张未发现阻断性错误。

本审查仅支持所列阅读范围和主张，不认证所有古代文献的作者归属、最早发现年代或全部手稿差异，也不替代独立技术审查及发布后的远端内容验证。
