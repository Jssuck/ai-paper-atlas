# II.26：来源、章界与证据台账

服务于[原创中文深读](aristotle-prior-analytics-ii26.zh-CN.md)。只公开必要书目链接、定位和原创分析；扫描、PDF与转录全文不进入发布包。

## 1. 单元与年代

Aristotle，*Analytica Priora / Prior Analytics*，第二卷第二十六章，**69a37–70a2**。这是公元前四世纪逻辑与论辩思想的前史补读；不能把编辑、翻译或转录年代当作单章写作年。章25止于69a36；章27从70a3开始。本次不计相邻章节完成，不声称早期文献已穷尽，也不把古代逻辑直接命名为现代AI研究论文。

## 2. 实际阅读的见证

### S1：Bekker1831希腊文、页底校记

Immanuel Bekker编，*Aristotelis Opera*，vol.I，Berlin，1831，印69左栏末、右栏全部以及印70左栏首两行。

- [全卷](https://archive.org/details/aristotelisopera01arisrich)
- [印69图](https://archive.org/download/aristotelisopera01arisrich/page/n84.jpg)
- [印70图](https://archive.org/download/aristotelisopera01arisrich/page/n85.jpg)

实际查看两页图像。69a37的章号26与开头定义、69b的全称/特称分路、两个方向的知识例、第二格讨论和末段待议事项均核对；70a3的章号27和新主题用于关闭范围。印69页底校记对本章记录69b1、3、6、9、15–20、28、30–32、38等处的异文或省略；印70所列a栏校记从第7行开始，已在下一章范围。校记说明传本文字并非没有差异，但本单元没有建立新的希腊文定本，也不声称穷尽手稿。

重要核对：Bekker正文把“可知与不可知”列为相反项；本次不擅自改作其他对立类别。章末确实保留第一格特称、第二格否定异议是否可行的待议问题，不能因其与前文断言紧张而从正文删除。

### S2：Owen1853英译、边注、脚注和正式勘误

Octavius Freire Owen译，*The Organon, or Logical Treatises, of Aristotle*，vol.I，London: Henry G. Bohn，1853。

- [全卷扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)
- 实读印 **234–237**，PDF第253–256页（1起算）；印234前半为上章，章26从该页下半章题 *Of Objection* 开始。
- 印234注3延续到235：区分针对前提与针对结论的反驳，讨论较广/较狭中项，并引Hessey、Pacius、Whately、Waitz等。这些是后世解释史材料，不是Aristotle时代的前驱。
- 印235列出三个教学排列；其中例2的结论未显式写出“某些”，孤立阅读易被理解为全称。正文印236明确以第三格特称路线说明该例，因此本篇不把这个排列表述升级为全称结论。印236边注标Celarent、Felapton、Barbara、Darapti；这些式名是后世教学标签，不是原文自己的命名。
- 印236正文称“已知与未知”为相反项，另一例译为有益健康与有害健康；Jenkinson则用可知/不可知和健康/患病。教学集合不得凭词面把这些争议对象的分类真实性当成已证明。
- 印237正文完整保留第二格不产生肯定结论、额外前提应立即清楚、符号论证和末段待议事项。注1承认该段解释困难，借Pacius和Waitz说明广项；注2将第二格考虑限定于原命题为肯定时，注3解释另一个前提是被理解的原命题，注4指向下一章，注5回指Hessey表V。本篇区分这些解释与原文断言，不把它们当成已经消除全部张力的校定。
- **ERRATA：** 实际查看正式勘误页，其列印219章题、273边注、594章题三项，未列234–237。这个有限检索结果不是“本章没有文本问题”的证明。

- [固定修订版15924675](https://en.wikisource.org/w/index.php?title=The_Works_of_Aristotle/Prior_Analytics/Book_II&oldid=15924675)

注103建议调整69b22逗号；注104补出第二格的两前提；注105提出符号句可能为插注或位置有误；注106提出末句可能是熟悉《修辞学》相关讨论者所加。后两项是译注猜测，不是已被本次独立证实的删改结论。正文保留原段并明示解释限度。

实际打开Source索引，所列Year为 **1928**，编辑W.D.Ross，Oxford: Clarendon Press，译者包括Jenkinson。本篇据此仅报告当前转录所标底本，不声称已亲读整卷1928扫描或核定所有初刊、重印沿革；不沿用未经此次核明的1913说法。

### S4：关联原典《修辞学》II.25

Aristotle，*Rhetoric*，II.25，1402a29–1403a15；W.Rhys Roberts英译的[章节转录](https://kairos.technorhetoric.net/stasis/2017/honeycutt/aristotle/rhet2-25.html)。实际阅读该章全文。其开头把反论证与提出异议分开，列四种异议来路；后段特别提醒：反例可否定必然性，却未必否定“通常如此”。这支持本文区分严格全称命题与概率材料的适用范围，不能由单个反例宣布统计判断已全败。

该关联是同作者著作间的文本比较，不据章号推定写作先后。

## 3. 论证—位置索引

| 位置 | 要核的主张 | 本篇处理 |
|---|---|---|
| 69a37–69b5 | 异议、特称可能性、两方式两格 | 定义是论辩功能，不把所有前提排除为非特称 |
| 69b5–14 | 反对全称肯定的全称/特称否定 | 广类排斥与狭类见证分开；见证存在显式化 |
| 69b14–19 | 反对全称否定的肯定路线 | 同一知识例只作原文材料，不核证其认识论事实 |
| 69b19–28 | 广中项第一格、狭中项第三格 | 项包含方向明确，不把狭类误当普遍覆盖 |
| 69b28–37 | 第二格限制、额外说明与符号句 | 区分表达能力、即时可接受性、形式有效性 |
| 69b38–70a2 | 其他异议及两项待议问题 | 保留开放结尾和译注猜测，不假装原文已完成讨论 |

## 4. 前史、同期与后续的证据边界

本章的直接理论前提是同一著作I.4–6的三格和II.20的反驳结构；这些是内部依赖，不据排列宣称精确写作时间。《修辞学》II.25提供同作者的另一讨论环境。Owen的Hessey、Pacius、Whately和Waitz引用只记录所见解释史链，不假装已经独立通读这些被引著作；不从引用数量或作者声望决定质量标准。将广类/狭类异议重构为集合证书、反模型与有限测试，是本项目自己的教学延伸，不是古代计算机实验，也不是所有异议方式的完整分类。
