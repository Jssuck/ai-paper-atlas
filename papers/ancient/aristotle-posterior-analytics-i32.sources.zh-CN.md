# 《后分析篇》I.32：来源、译差与证据定位

## 1. 收录范围与实读版本

本篇对象为 Aristotle, *Analytica posteriora*（《后分析篇》）第一卷第32章，**88a18–88b29**。下一章始于88b30。这是公元前4世纪逻辑与知识论前史补读，不是现代AI论文；现代版本年份不是古代章节的写作年份。以下仅记录实际核看的材料，不声称穷尽传本、古代知识传统或现代研究。

- [Boyer 希腊文与 Mure 英译对读页](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-32)：页面注明希腊文据 W. D. Ross, *Aristotelis analytica priora et posteriora*, Oxford, 1964，英译 G. R. G. Mure, Oxford, 1928。实读整章及前后边界。所读是数字转录，**不是 Ross 纸本校勘栏**。
- [Bekker 1831 卷一原版扫描](https://archive.org/details/aristotelisopera01arisrich)：实看[印页88](https://archive.org/download/aristotelisopera01arisrich/page/n103.jpg)左右栏正文和页脚校勘栏。章32从左栏中部开始，跨到右栏，章33在右栏下部另起。正文、页脚异文和后世解释分别处理。
- [Octavius Freire Owen, *The Organon*, vol.I, 1853 扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)：实看印页**310–312**（PDF第329–331页），包括章节首尾、脚注和边注；312下半另起章33。另实看本卷 ERRATA（PDF第18页），所列更正针对印219、273、594，不含310–312。**仅该表未列本章，不等于本章或全部版本无误。**

原书扫描、原文和全文译本仅用于核验，不随原创解析上传。

## 2. 原文论证地图

| 位置 | 论证动作 | 阅读与建模边界 |
|---|---|---|
| 88a18–25 | 从真假推理及真结论由假前提推出的情形讨论原理差异；再向前提追溯中项 | 不能读成“结论真便保证前提真”；假中项不是对象本身有真假，而是相应述谓关系不成立 |
| 88a26–30 | 不同假说也可能彼此相反、不能同时成立 | 不能不加条件推广到现代任意不一致前提集；经典爆炸逻辑会使这种推广失败 |
| 88a30–36 | 真证明的原理亦有属的差别；单位与点有无位置不同，术语须能接入三段论结构 | 不是声称单位与点永无任何映射；未经说明的替换与有桥接前提的解释不同 |
| 88a36–88b3 | 共同原理不足以独力证明全部领域内容；量、质各有相关属性 | 共同规则、共同公理、特定领域的内容不能混成一层 |
| 88b3–10 | 从增加端项或插入中项、原理与结论数量，以及必然／可然原理提出进一步理由 | 有限原理与无限结论的段落需要保留困难，不能宣称它已经证明现代形式系统不能有限公理化 |
| 88b10–15 | “各学科各有这些原理”以及每组与自身相同，并不能建立跨学科原理同一 | 自同一不是跨对象的同一 |
| 88b15–21 | 反对把“同一原理”解释为每个结论都使用全部原理；讨论直接前提和追加直接前提 | 足够前提集、实际使用的前提、最小支持集需分开；正文的支持集是现代重构 |
| 88b21–29 | 再排除所有原理同属、仅选不同子集的解释；末尾区分“从何出发”与“关于什么” | 末句不宜压成“所有原理都不共通”：它明确保留共同者，同时区分数、量等专属对象 |

## 3. 必须显式保留的译差与校勘范围

1. **88a21 的 ἅπαξ。** Mure 用 *once only*，Owen 印310用 *rarely*。后者容易使人误读为经验频率，前者容易使人误读为全世界只能发生一次。本文不据任何一个英语词推出次数定理，而把局部论证放回“再证明两个假前提”这一向前追溯结构中。该解释是分析重构，不冒称已解决所有文本争论。
2. **88a25 的真假方向。** 原文前面已经允许假前提得真结论；这一句不可被抽成其逆命题。现代健全性只保证有效形式中全真前提不导出假结论；反向检查假结论时只能保证至少有一个假前提，不能保证每个前提都假。
3. **88b6–7 的“项”。** 希腊文为 ὅροι；Owen 印311译为项，Mure 增添了“中”这一解释。不能把后者当作希腊原文逐字已有的限定。原理数、命题数、术语数和可生成公式数也不是同一种计数。
4. **88b9 附近的异文。** Bekker 印88右栏页脚在行9列出含 εἶναι、ἢ、πεπερασμένας 的读法记录；本次只核看所印正文及校勘条目，不重新构建抄本谱系，不对字母符号补造手稿身份。正文对此处数量论证保留限定，而不是宣布它无文本问题。
5. **88b12 的学科名称。** Owen 印311边注列有 λογισμῶν 与 ἀριθμῶν 的版本差别。因此可用“计算／算术”概括，但不据这一处词形差别杜撰不同学科制度。
6. **88b20–21 的“一”。** 两份英译都保留每属中“一”的说法。不能据此宣布几何、医学等每门科学恰好只有一个现代意义公理；这里直接前提、最初直接前提和属的关系仍须在亚里士多德自己的分析框架下阅读。

Owen 印310的石头／动物／人例、印311的三格解释、印312对公理和章节的转引均是**译者所附说明**，不能改称亚里士多德在I.32正文中逐字给出的例子。石头／动物／人的相应例子确实可另在《前分析篇》II.2找到，但两处证据应分别注明。

## 4. 实读的前驱、内部背景与同代问题

- [《前分析篇》II.2–4](https://aristotle.johnhboyer.com/APr/book/2/#ch-2-2)：本轮针对性重读II.2 **53b4–35**，包括全真不能推出假、假前提可得事实而非所以然，以及石头／动物／人例；重读II.3 **55b3–20**与II.4 **56b4–20**的各格假前提得真结论例。这是相关段落实读，不冒称本轮重新完成三章全部细节。它们直接约束I.32开头的解释，不能说作者不知道假前提可能导真。
- [《后分析篇》I.2](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-2)，**71b19–33、72a5–22**：论证性知识的前提须有真、直接、先在、原因等条件；无这些条件的推理仍可能是三段论。这是“形式有效”与“知识性证明”不可混同的内部依据。
- [I.7](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-7)，**75a38–75b20**：重读整章的跨属限制与从属例外，特别是75b14–17的光学／几何、和声／算术。I.32不能被解释成彻底禁止跨学科关系；有从属结构的关联须单独说明。
- [I.10](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-10)，**76a31–76b22**：重读专属者、按类比共同者和证明三要素。共同公理在具体属内使用，与对象存在及属性含义并非同一种前提。
- [Plato, *Republic*, VI，Jowett英译](https://www.gutenberg.org/files/1497/1497-h/1497-h.htm)：实读卷六末尾分线段讨论数学假设与向原理上升的正文段落（510c–511b附近），不是仅取译者导论。这提供“数学从假设起步、原理怎样被追问”的前驱问题背景；**本章未直接点名该段，不据主题相似断言它逐句反驳柏拉图或确立唯一影响链**。

这里的章节先后是阅读和论证关系，不能独立确定成文先后。几何、计算、医学是I.32自身举出的领域；这足以说明它关心多个知识领域，却不足以替每一领域补造作者、机构、精确年代或影响力排名。本次不声称穷尽早期逻辑、数学或其他文化中的前史。

## 5. 现代重构的限度

集合包含、真值表、Horn闭包、最小支持集、显式标签和桥接规则属于原创教学模型。它们可以把论证中的区别变得可检验，却不是原文算法。有限域穷举只能覆盖声明的有限配置；程序不证明全部亚里士多德科学观。用有限前提产生无界句法族的例子，是反对把原文数量论证无限制现代化，不是宣称古代原文意在讨论现代公理系统。更不能由本章推导“通用AI不可能”或“统一数学基础不可能”。
