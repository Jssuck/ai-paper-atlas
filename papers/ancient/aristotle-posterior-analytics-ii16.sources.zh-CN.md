## 主张定位与阅读警戒

| 位置 | 原文论证步骤 | 解析必须保留的限制 |
|---|---|---|
| 98a35–98b5 | 以落叶、月食发问：果在时因是否也在，因在时果是否也在？ | 疑难的提出不是已经证明所有因果都双向蕴含；“阔叶”在此是候选解释。 |
| 98b5–10 | A=落叶，B=阔叶，Γ=葡萄藤；经B推出A属于Γ。 | 这是原文的假定植物例，不是现代植物学采样结论。 |
| 98b10–16 | Δ=阔叶，E=落叶，Z=葡萄藤；更换中项可反向推出阔叶。 | 反向论证另用了“凡落叶者皆阔叶”的前提，不能只由正向包含关系擅自换位。 |
| 98b16–24 | 原因优先于结果；月食不造成地球居间。经原因知“为什么”，反向可知“是如此”。 | 推理方向与解释方向不同。“优先”不能无条件缩减为钟表时间先后；地球居间进入月食的说明。 |
| 98b25–31 | 假设A先属于B、另先属于Γ，后者分别属于Δ、E；提出同一结果的多因问题。 | 因出现则果出现；果出现不要求每个候选因都出现。这里是论证分支，不宜抹去或直接说作者否定多因。 |
| 98b32–38 | 转问普遍问题及整体范围；在这种情形，中项与结果要等范围、可换位；以液体凝结和落叶示范。 | 末句明确不是任意物中的凝结，而是树中的凝结。须保留对象域与“如果确由此”的设定，不得推出瓶中液体凝结也落叶。 |

## 译词、校记与勘误核对

1. **98b31的“某个原因，不是所有原因”。** Bekker正文与Owen译文都保留这一对照。Mure的后半句使用“whole cause”的解释性表达；本项目不据此引入现代“一个原因由多个必要部件组成”的理论。其直接论证是B、Γ分别解释不同承载者，而非每一结果实例同时具备全部中项。
2. **98b32起的语气与普遍性。** Owen保留反问/另一个解法的语气，Mure添加了“commensurate”的解释；中文以“转而在普遍且范围相称的设定下讨论”呈现，不伪称原文已建立无条件的双条件定理。Owen349页脚注回指第一卷第4章的普遍性用法；脚注是译者说明，不是亚里士多德正文。
3. **98b37的凝结。** 希腊正文为液体/湿物的凝结，Owen译作“concretion of moisture”，Mure译作树液凝结。可用“树中液体（树液）凝结”帮助理解，但不得把古代模型包装成现代落叶机制的实证核验。
4. **版面核对。** Bekker98页正文及下方校记实际可见；本次用于核实章界、符号顺序、限定语及两段论证的转折，不声称完成全部抄本谱系或穷尽异文研究。
5. **Owen勘误表。** 已实际目视该PDF的ERRATA页，三项涉及印本219、273、594页；未列本次347–349页。结论仅为“此表未列本章勘误”，不等于本章不存在任何版本或解释争议。
