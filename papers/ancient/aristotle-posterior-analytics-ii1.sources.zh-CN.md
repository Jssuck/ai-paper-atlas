# 《后分析篇》II.1：来源、边界与证据台账

## 1. 本次完整阅读单元

Aristotle，*Analytica posteriora*（《后分析篇》）第二卷第一章，**89b23–35**。这是公元前四世纪作品的推理与认识论前史补读，非现代AI论文。版本年不等于古代成文年；本章完成不表示第二卷或全书完成。

- [Bekker, *Aristotelis opera*, vol.I, 1831](https://archive.org/details/aristotelisopera01arisrich)，实看[印页89扫描](https://archive.org/download/aristotelisopera01arisrich/page/n104.jpg)右栏卷Β标题、章1全文和页脚异文。第一卷I.34在89b20结束；卷二II.1从89b23开始，到89b35“人是什么”之问结束。章2的数字标记在89b36。不能把90a1–7的中项归约偷偷并入本章。
- [O. F. Owen, *The Organon*, vol.I, 1853](https://archive.org/details/Aristotles_Organon_vol_01_1853)，实看印316（PDF第335页）章I全部正文、边注和页底说明；同页章II开头用于核边界。另实看卷首ERRATA（PDF第18页）：所列印219、273、594，无316。只可说此表未列本页，不可声称所有传本没有讹误。
- [Boyer希英对读II.1](https://aristotle.johnhboyer.com/APo/book/2/#ch-2-1)，实读希文与英译完整89b23–35，并核下一章标题。网站标示希文据Ross（Oxford, 1964）、英译据G. R. G. Mure（Oxford, 1928）；本次使用数字转录，不冒充直接阅读Ross纸本全部校勘装置。

研究扫描只保留于工作底稿，不作公开附件；本仓内容是原创分析，不是整章全文翻译。

## 2. 原文证据地图

| 位置 | 实读内容与论证功能 | 边界 |
|---|---|---|
| 89b23–25 | 所求与所知相应，列事实、原因、是否存在、是什么四类 | 属本书知识研究的问题分类，未给现代自然语言所有疑问句的穷尽证明 |
| 89b25–28 | 以太阳是否受食说明事实之问；确认后停止追问同一事实 | 不是结束全部研究，更不是宣称观察不可修正 |
| 89b28–31 | 已知日食或大地震动，再问其原因 | “事实已知”不是从事实自动推出具体原因 |
| 89b31–33 | 以半人马或神是否存在为无附加限定的存在之问，区别于是否白 | 列出询问对象不等于证明对象存在；两种问题不可只按汉语“是”字分类 |
| 89b33–35 | 在已知存在后问是什么，例为神与人 | 本章没有提供这些对象的本质定义，也没有证明存在事实唯一决定本质 |

## 3. 译差与编辑层

1. **四问标签**：Owen用that/why/if/what；Mure展开为属性联结是否事实、联结原因、对象存在和本性。中文宜保留“事实／所以然／是否存在／是什么”并注明对象层次，不能把第一问也简单译成对象存在。
2. **εἰς ἀριθμὸν θέντες（89b25）**：Owen较直译为关于数目，其边注解释为对多项的注意；Mure解释为对象与属性的复合。该解释差应保留，不将希文归为现代概率、枚举或编码算法。
3. **κινεῖται ἡ γῆ（89b30）**：字面为大地运动，两英译均用地震语境。不能借此声称本章主张地球绕太阳运行。
4. **ἁπλῶς（89b33）**：此处将单纯存在与带“白”等限定的谓述相区别。现代用存在量词与一元谓词表示是教学选择，不是原文已给出形式语义。
5. **章末异分**：Owen在“人是什么”后注明Bekker和Waitz在此结束，Taylor和Buhle把下一章首句接入本章。本篇采用Bekker及所核对读页的89b23–35边界，并披露该差别；不把译者所述版本当成本次亲读全部版本。
6. **Bekker页脚**：对应b24有εἰ、τί前增冠词的异文记录；b25、b28、b29亦有词形／词序异文。这里仅报告实际见到记录，不擅解缩写为完整抄本谱系或宣布解决传本问题。四问区分不以本篇另立校订为前提。
7. **Owen编辑文字**：章题、边注及页底对Trendelenburg、Kühn、Aldrich、Mansel的提及属于十九世纪解释层，不是古代原文，也不算本次已完整阅读这些著作。

## 4. 前驱与同作者问题背景

实读[Jowett译柏拉图《美诺篇》](https://classics.mit.edu/Plato/meno.html)开头通常定位70a–71b的“美德能否教／美德是什么”对话，以及80d–81a的探究困难：不知对象时如何寻找，找到后如何认出。用它说明定义、属性与探究的前驱问题；不能把苏格拉底角色的话直接当作亚里士多德引文，也不能断言II.1逐句回应该段或接受回忆说。此处使用定位区间而非该网页不提供的逐行号。

实读同书[I.1的71a11–17](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-1)：先行理解词义与先行知道存在／事实有区别，不同对象要求不同。这使“II.1先知存在再问是什么”不应被夸张成在询问存在前连名称意义都不能理解。又核读II.2开头89b36–90a7仅作边界比较：把诸问归约到中项是否存在／中项是什么，是下一章展开的论证，不算本单元的已完成内容。

另核读[I.13的78a22–30](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-13)开头：知道事实与知道所以然不同，直接性与通过原因解释均有关。实看Bekker印89右栏[I.34的89b10–20](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-34)：敏捷把握中项并以月亮例展开。它们支持正文对前卷背景的概括，但不证明各章成文先后。

上述选择依据问题相关性，而非作者声望、地区或机构；不是全球古代思想传统的穷尽目录，不据未列入判定其他传统没有贡献。本次未建立从此章直达现代AI的历史传承链；程序中的问答路由、证据状态与类型检查均为现代教学类比。

## 5. 对复现与解析的约束

可以用有限状态和显式查询类型演示“先核事实再问原因”“对象存在与属性真值不混淆”，但应明确：这是现代规范化重构，不是从古文恢复出的算法。未知不等于否定，定义字符串不等于真实存在，存在证据不自动给出本质，事实记录不自动认证因果解释。有限测试只核验程序所声明规则，不证明四问穷尽、古代本体论、真实因果关系或一般知识定理。
