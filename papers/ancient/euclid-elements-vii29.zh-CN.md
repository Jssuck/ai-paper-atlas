# 欧几里得《几何原本》VII.29：素数不整除另一个数，为什么就与它互素？

> AI 数学与形式推理前史补读。约公元前 300 年的古代算术，实读 1908／2008 版。从现代论文主线回看形式推理前史；这不是 AI 论文，也不声称穷尽前史。

## 1. 书目与要解的问题

- Euclid, *Elements*, VII.29。T. L. Heath, *The Thirteen Books of Euclid’s Elements*, vol. II, Cambridge University Press, 1908，[印刷页 330–331](https://archive.org/details/thirteenbookseu01heibgoog)。330 页有题句、图和矛盾，331 页首有结论和短评。
- Richard Fitzpatrick, *Euclid’s Elements of Geometry*（2008 修订），[印刷页 217–218，希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=217)。另读 [Clay 希英本](https://www.claymath.org/library/historical/euclid/files/elem.7.29.html)与 [Joyce 正文及导读](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII29.html)。版本差异见[原典核对](../../reproduction/euclid-elements-vii29/source-review.zh-CN.md)。

7 不整除 15，两者没有非单位公因数。6 也不整除 15，却和 15 共享公因数 3。两例的区别是 7 自身是素数，不能有一个比它小又大于 1 的约数。本命题说明**什么时候可以把“不整除”升级成“互素”**。这与 [VII.28](euclid-elements-vii28.zh-CN.md)搬运共同度量的办法不同：这里不换比较对象，而是用素数的结构封住候选共同度量。

## 2. 三个角色和两个“素”

| 原文标号 | 教学记号 | 作用 |
|---|---|---|
| A／Α | $`p`$ | 给定的素数；它不度量 B |
| B／Β | $`b`$ | 被比较的给定数；不要求自身为素数 |
| C／Γ | $`d`$ | 为反证假设的非单位共同度量 |

古书[卷七定义 1、2](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII1.html)区分单位与数，[定义 11、12](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII11.html)分别讲一个数的素性与两个数的互素。用现代说法：素性约束 p 的真约数，只允许 1；互素约束 p 和 b 的**共同**约数，只允许 1。原书的图用三条线段标号，不从图的长短得出 p 或 b 的数值，更不把图中比例当作可整除性的证据。

## 3. 原证：同一候选必须既等于 A，又不等于 A

1. **假设结论不成立。** 若 A 与 B 不互素，便可取数 C 同时度量 B、A。它不是单位；否则无论两数是否互素都存在这个平凡见证。
2. **先看 B。** C 能度量 B，A 却不能。如果 C 就是 A，两句便相互矛盾。所以 C 不等于 A。
3. **再看 A。** C 也度量 A。它大于单位，又不是 A 本身，因此是 A 的一个非单位真约数，与 A 的素性冲突。
4. **收束。** 不存在这样的 C。按互素的定义，A、B 互素。这里只排除非单位共同度量，单位仍度量二者。

| 主张 | 可核查位置 |
|---|---|
| A 是素数且不度量 B；引入共同度量 C | Heath 330 页下部题句和图旁；Fitzpatrick 217 页下部 |
| 由 C 度量 B 而 A 不度量 B 得 C 不是 A | 两印本的中段；Clay 希英栏均有 |
| C 是 A 的非单位真约数导致矛盾 | Heath 330 页末；Fitzpatrick 217 页近末 |
| 否定共同度量，由定义回到互素 | Heath 331 页首；Fitzpatrick 217 页末，结束语跨至 218 页；Clay 希栏保留 |

Clay 英栏在否定共同度量后停止；不能把希栏和两印本的结论就此删除。Joyce 的卷七定义交叉引注有助于区分素性、互素；不必把网页的引注摆位理解成原本另有一条前提。

## 4. 教学重构：看清两项假设分别排除了什么

用 $`d\mid x`$ 记整除。古书的输入数用现代大于 1 的整数模拟；现代分析可另允许 $`b=1`$，但仍不把 1 当作素数。若 d 是共同约数，则它属于 p 的约数集合，也必须能整除 b。

$$
\begin{aligned}
d>1,\quad d\mid p &\Longrightarrow d=p \qquad (p\text{ 为素数}),\\
d\mid b,\quad p\nmid b &\Longrightarrow d\ne p,\\
p\text{ 为素数}:\qquad
\gcd(p,b)&=
\begin{cases}
p,&p\mid b,\\
1,&p\nmid b.
\end{cases}
\end{aligned}
$$

前两行用现代符号并排陈述冲突，书上的次序是先检查 B。最后一行是**现代补全**，覆盖原证外的另一分支：若 $`p\mid b`$，p 自己是共同约数，而任何共同约数都不超过 p。这不是说 VII.29 原文证明了显式分段公式，也没有用后面的素数整除积的规则。

| 教学输入 $`(p,b)`$ | 核算 | 判断 |
|---|---|---|
| (7,15) | 15 除 7 余 1；7 唯一非单位约数是 7 | 两个前提都真，互素 |
| (7,14) | 7 整除 14，两数最大公因数 7 | 只保留素性不够 |
| (6,9) | 6 不整除 9，但 3 同时整除二者 | 去掉素性，推理无效 |
| (8,15) | 8 不整除 15，且最大公因数仍为 1 | 合数也可能与某个数互素；这不能证明 8 是素数 |
| (7,1) | 7 不整除 1，最大公因数为 1 | 现代单位边界，不改变原书范围 |

## 5. 后续用途、局限和实跑

[紧接的 VII.30](https://www.claymath.org/library/historical/euclid/files/elem.7.30.html)让素数 D 度量积，若 D 不度量第一因数 A，便**先用本命题**得到 D 与 A 互素。后续还要用比例及最简数对的性质，才得到 D 度量另一因数。VII.29 提供的是前提转换，并未单独证明素数整除积的结论；用后者倒过来证明本条会丢掉原书的依赖顺序。

**现代延伸。** 对整数 $`n>1`$，只要对所有 $`b>1`$ 都满足“不被 n 整除就与 n 互素”，n 就是素数。若 n 为合数，选其任一非单位真约数 d 当 b；因为 d 比 n 小，n 不整除 d，却有 $`\gcd(n,d)=d>1`$。这里的关键是“对所有 b”，不是用一次互素成功鉴定素数；选择真约数也没有说需要把 n 完全分解。

[源码、Notebook、运行命令与实跑日志](../../reproduction/euclid-elements-vii29/README.md)分别核查素性、不整除和非单位共同约数的见证；见[独立技术核对](../../reproduction/euclid-elements-vii29/technical-review.zh-CN.md)。现代程序用最大公因数找候选，再以独立因数枚举核对；它不是对古代操作的逐行模拟。两项各取 2 至 30 的网格有 841 对，247 对满足前提，另核对素数整除另一数的 43 对。三种 Python 模式各过 5 项，Notebook 三个代码格通过标准库实际回放，未运行 Jupyter 内核。有限教学检验没有历史实验数据、训练或性能指标；它验证实现与算例，不代替原证。复盘时问：哪一个条件规定候选 d 只能等于 p？哪一个条件禁止等号？

## 6. 带答案练习

1. **11 不整除 35。用原证排除 C。** 答：若 C 同时度量 11、35，且不是单位，必须是 11；这又会使 11 度量 35，矛盾。
2. **13 是素数，与 26 是否互素？** 答：否。13 整除 26，正是原命题跳过的情形；最大公因数为 13。
3. **为什么选 b=3 就能反驳“9 不整除 b 就与 b 互素”的全称断言？** 答：9 不整除 3，而 3 是二者的非单位公因数。
4. **11 和 22 都能被 11 度量。能用这个例子否定 VII.29 吗？** 答：不能，前提要求 11 不度量另一数；这是一个前提不满足的控制例。
5. **VII.30 的开头为什么先分 D 是否度量 A？** 答：若度量，所求已得；若不度量，结合 D 的素性，用 VII.29 换得后续比例论证所需的互素条件，不是立即得出 D 度量 B。
