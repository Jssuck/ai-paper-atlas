## 数学逐项审查

| 证明义务 | 独立审查结果 |
|---|---|
| 非退化输入 | A≠B 明确；等边构造给 C 不在 AB 上。现代模型中的 u=A−C、v=B−C 因此线性无关，长度 r>0。没有把零线段作为正常构造吞掉。 |
| 输出的位置条件 | D=A+t(B−A)、0<t<1 与 AD=DB 是分别核验的条件；A≠D≠B 不被单独误当作介于关系。P=(3,4) 对 A=(0,0)、B=(6,0) 等距，但不满足位置条件。 |
| 内角平分方向 | 等长 u、v 的和 w=u+v 是两方向的严格正系数组合，位于非退化凸角内部且非零。u·w=v·w，加上相同正归一化分母和余弦在 [0,π] 的单调性，给出等角。没有将不等长向量直接相加当成通用角平分公式。 |
| 交点存在、内部与唯一 | 解 C+λ(u+v)=C+(1−t)u+tv；线性无关给 λ=1−t=t，故 λ=t=1/2。此解存在、射线参数为正、线段参数严格内部、且唯一，四项都有依据，不靠图形或预置中点。 |
| 反向与外角 | 反向射线要求参数 −1/2，故不能到达 D；等长情形的外角方向 u−v=A−B 与底边平行，C 又不在底边上，故无交点。等角判据与内部性不能相互代替。 |
| I.9 展开与异侧 F | 两个等边候选位于 AB 两侧；因 CA=CB，可取 A、B 为等距截点。选择与 C 异侧的 F 才产生非零内部方向。此特殊构形有 F−C=u+v，故第 5 节 λ 与第 6 节 s 恰好相同；正文没有把参数值误写成缩放不变量。 |
| I.4 对应与非循环性 | A↔B、C↔C、D↔D；CA=CB、CD 公共、C 处夹角相等，确为 SAS 而非 SSA。AD=BD 是对应底边结论，未预先放入全等前提。两比较三角形非退化。 |
| 中点唯一及辅助两支 | 另一内部等距点的参数 q 满足 q=1−q，故为同一中点；C 的两种合法选择不改变输出唯一性。 |
| 有限可分量词 | “每个给定有限 n 可作有限次二等分”与“有限时间完成所有层级”明确不同。任意有限步保持正长并可继续平分；该分析限于现代模型，不是物理连续性的实验结论。 |

正文第 4.1 节补明 I.9 辅助有限段必要时沿同方向延长，避免把其任意辅助终点直接叫作中点。正文、README 与 Notebook 也将 I.1、I.9、I.4 理解为本构造的调用顺序，而非发现年代或命题间的单向依赖链。I.1 解析实现中使用平均坐标描述圆交点中心，是公开标明的现代建模；不能据此声称实现了不借现代算术的物理尺规器。

## 源码契约与精确性

逐行检查 `geometry.py` 后，关键路径符合正文所述：

1. `Q3` 保存两个有理系数，拒绝隐式浮点、布尔和字符串；非零元素除法以共轭和有理分母计算。符号判定只用有理比较。对异号非零有理系数，平方比较不会因 √3 的有理表示而产生伪零。
2. `construct` 拒绝重合或非有理端点及无效分支；`i9_vertex` 检查等长正截线及非退化，再以严格异侧选 F。
3. 一般求交器从行列式计算 s、t；检查方向与边非零、分母非零以及 s>0、0<t<1 后，返回 C+s(F−C)。没有将最终 D 直接赋为平均数。独立非中点求交例进一步检验了这一点。
4. 角谓词除了平方余弦的交叉相等，还检查点积符号，防止误收补角；叉积内部性另行检查，防止误收反向等角射线。
5. 证书由调用方提供的端点重新核算，不信任预存“通过”标签。22 项事实同时检查构造、方向、两个交点表达、点序、SAS 前提与长度结论。公共 CD 是同一个向量对象关系，另核正长与三角形非退化。
6. 检查器验证的是几何一致性，不是数字签名、安全反序列化器或来源认证。生成器与检查器仍共享精确算术和部分谓词，所以本次增加独立预期值与区间符号 oracle，而不声称实现间完全独立。
