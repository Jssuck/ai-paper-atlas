# 《后分析篇》I.31：来源、译差与证据定位

## 1. 收录范围与书目

本篇读 Aristotle, *Analytica posteriora*（《后分析篇》）第一卷第31章，完整范围 **87b28–88a17**；下一章始于88a18。它是公元前4世纪逻辑与知识论前史补读，不是现代AI论文，也不据现代印本年份推定古代写作年份。这里记录已实际核看的材料，不声称穷尽传本或研究文献。

- [Boyer 希腊文与 Mure 英译对读页](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-31)：页面标明希腊文据 W. D. Ross, *Aristotelis analytica priora et posteriora*, Oxford, 1964；英译 G. R. G. Mure, Oxford, 1928。实读本章全文及其相邻章节边界。访问的是数字转录，**不等于查看 Ross 纸本校勘栏**。
- [Graeco-Arabic Studies 希腊文](https://www.graeco-arabic-studies.org/view/arist.analytpost-orig-gr1)：页面书目为 Immanuel Bekker, *Aristotelis Opera*, Oxford, 1837, vol.I, pp.182–257。实读第31章完整段落；这是1837版的数字文本，不冒称1831版扫描。
- [Bekker 1831 卷一原版扫描](https://archive.org/details/aristotelisopera01arisrich)：实看印页87右栏下部、88左栏上部及两页页脚校勘栏。直达图：[印87](https://archive.org/download/aristotelisopera01arisrich/page/n102.jpg)、[印88](https://archive.org/download/aristotelisopera01arisrich/page/n103.jpg)。章31从87b28开始，88a17结束，章32随后开始。正文与校勘栏分开处理，不把校勘符号当成亚里士多德正文。
- [Octavius Freire Owen, *The Organon*, vol.I, 1853 扫描](https://archive.org/details/Aristotles_Organon_vol_01_1853)：实看印页308末至310上部（PDF第327–329页），包含整章、脚注及章32起点。另实看本卷 ERRATA 页，所列改正针对印页219、273、594，没有列出308–310。此结论仅限该勘误表，**不是宣告本章所有版本无误**。

扫描与来源全文仅用于阅读核验，不随公开解析上传。公开内容是原创概括、必要短术语和书目链接。

## 2. 主张与位置

| 位置 | 本文所据内容 | 必须保留的限定 |
|---|---|---|
| 87b28–35 | 实际感觉指向此物、此时、此地；证明针对全称，因此不能把感觉本身等同论证性知识 | 不等于所有知识都与感官无关 |
| 87b35–39 | 即使感知某三角形角和，也仍会追寻证明 | 原文是假设性例子，不是实测报告 |
| 87b39–88a2 | 假想身处月球看到地球遮挡，仍须区别当前月食事实与一般原因 | 不能把看见遮挡说成自动具备完整解释 |
| 88a2–5 | 多次观察可帮助追踪全称、形成证明 | 没有给出保证正确的样本数量、统计阈值或现代归纳算法 |
| 88a5–8 | 全称之可贵在于揭示原因；原因异于被解释项时有相应比较 | 第一原理另有论述，不能宣布证明无条件高于一切直观 |
| 88a9–11 | 对可证明项，单凭感觉不构成知识；除非把证明知识也改称感觉 | 这是术语边界，不是禁止观察 |
| 88a11–17 | 有的问题来自观察缺失；视觉可帮助把握全称。玻璃、孔隙、光的例子说明这个补充 | 不把古代例子认作现代光学结论或本项目真实物理复现 |

## 3. 末例的译文与校勘风险

本处尤其不能只抄一份英译：Owen 印310写的是玻璃有孔、光经过，并用 **illuminates**；Mure 用 **kindling**。所读两份数字希腊文和 Bekker 1831 排印正文在88a16均有 **καίει**。本文按该排印正文处理“燃烧／引燃”的例意，同时显式保留 Owen 的译法差异，**不将透光、照明和引燃当成同一个已获证实的物理机制**。

Bekker 印88页脚在左栏行16列有此词的校勘记录（包括 καίει、καὶ ἀεὶ 等读法及版本符号）；因此不能声称本处不存在异文。本次没有重新整理全部抄本关系，也不为缩写符号补造来源。另见两份数字希腊文本的细小差别，例如88a9附近的形式及玻璃词形；本篇不是新校勘本，论证不依赖把这些差别强行消除。

Owen 印309脚注对感觉与科学的区别、直观／把握作了译者解释，印310脚注提到 Philoponus 的说明；这些均须标为**译注**，不能移作亚里士多德原句或声称本次直接读了 Philoponus 原著。

## 4. 前后关系与不越界原则

同卷 I.1 的先有认识与学习问题、I.2 的原因与论证知识、I.13 的“事实／所以然”区别、I.18 的感官与归纳，构成本章可直接比较的内部背景。这里的章节次序是阅读关系，不能单凭次序确定各章实际成文先后。I.31 的第一原理保留项使 II.19 成为后续可查方向，而不意味着本篇已经完成 II.19 的独立深读。

本项目的有限布尔假设空间、反模型、观察等价机制均是**现代教学重构**；原文没有这些集合、计数公式或程序。实验只能检验明定模型内的主张，不能证明亚里士多德全部知识论，不能把有限域全覆盖升级为无限域规律或原因知识。
