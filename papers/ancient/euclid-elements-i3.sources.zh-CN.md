# Euclid《几何原本》I.3：来源与版本台账

## 范围与方法

本单元实际核对第一卷命题3全文及其必要基础，I.2仅作为前置结果回查。核对包括可检索文字与真实页面渲染，不把OCR或图中比例当作数学证据。以下页码首先指**印刷页码**；PDF页号另行注明。核验日期：2026-10-26。

这是原创中文教学解析，不是整段现代译文的翻译或再发布。源PDF与扫描截图仅用于私人核查，不在发布目录内；读者通过原始托管链接查阅。

## 1. Heath 1908第一版，卷I

Thomas L. Heath, *The Thirteen Books of Euclid’s Elements*, vol. I, Cambridge University Press, 1908。[扫描与书目](https://archive.org/details/thirteenbookseu02heibgoog)。

独立实读并查看图像：

- **246—247页**：I.3正文。246页为题面和构造，247页为等长证明、完成句与Heath评论。本次使用的449页PDF按1起算对应第267—268页。
- **153—155页**：定义15、16、公设3、共同概念1；同时检查其他相关条目，避免把圆定义或等量相等当作位置存在公理。
- **245—246页**：与I.2有关的点位、操作范围及后世圆规解释；不得将这段评论直接归为I.3正文。
- **导论第1页**：Heath转述Proclus关于整理前驱成果的见证，并提醒其生平知识有限。只支撑一般传承背景，不确定I.3发明者。
- **所附ERRATA叶**：本PDF第16页。卷I条目涉及19、105、106、182、415页，没有246—247页。这仅报告该份表的检查结果，不声称全部版本勘误或手稿异文都已排除。

原文先用I.2在A处置AD=C，再以A为中心、AD为距离画圆DEF。证明从AE=AD出发，用C=AD与共同概念1得到AE=C，没有重新使用I.2的等量相减。E在AB上的交点及严格内部位置没有独立推导段；图形和完成句包含这些条件。本文把它们显式展开，并将现代补强与古代文本分开。

247页关于多情形的讨论属于Heath：Proclus的多图实质上重展开前一命题，而把I.2作为已知结果便无需这样分类。本篇没有声称读过Proclus完整原著。246页的圆规离纸合拢比喻来自Heath引用De Morgan1849的讨论，是后世操作解释，不是古代器具的考古结论。

## 2. Fitzpatrick 2008修订订正本

Richard Fitzpatrick, *Euclid’s Elements of Geometry*，2007初版、2008修订订正；希腊文据J. L. Heiberg 1883—1885校本重排，附现代英译。[大学托管PDF](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf) · [作者的版本说明](https://farside.ph.utexas.edu/Books/Euclid/Euclid.html)。

独立核对版本页、印刷**9—10页**的I.3希英对照与图形，以及**6—7页**的定义、公设和共同概念。该PDF这几处的印刷页与按1起算的PDF页号相同。I.3的构造与证明和Heath一致：I.2、Post.3、Def.1.15、C.N.1。

给定线段的希腊Γ对应英文C，Δ对应D，Ζ对应F；C不是平面点。第9页上方关于多情形的脚注属于I.2，不能误说成I.3专属脚注。本文未将现代英译称作古代原稿或Heiberg校本影印，也没有把Fitzpatrick的现代编辑意见冒充欧几里得正文。

## 3. 作品年代与传抄本

[Clay Mathematics Institute历史档案](https://www.claymath.org/library/historical/euclid/index.html)标示作品约公元前300年，并说明所展示的Bodleian MS D’Orville 301由Stephen the Clerk在888年为Arethas抄写。

本篇仅据此区分作品时代与具体抄本年代。没有编造I.3精确写作年，没有把888年抄本认作作者手稿，也没有完成全部传本史、早期几何作者目录或同期研究综述。

## 4. 现代形式化对照

Michael Beeson, Julien Narboux, Freek Wiedijk, *Proof-checking Euclid*, arXiv:1710.00787v2，版本日期2018-10-18。[全文](https://arxiv.org/html/1710.00787v2)。

本轮实读§6.2、6.9—6.11及相关段，作为区分介于关系、画圆与交点存在义务的现代对照。该论文有自己的公理选择；本文不声称它逐字判定I.3必须补入某一种唯一公理。网页另示的2026年HTML生成日期不替代v2日期。本文没有运行其HOL Light或Coq工程，自写Python检查器也不是该工程的复现。

## 5. 主要主张定位与原创边界

| 主张 | 实读位置 | 限制 |
|---|---|---|
| 输入是不等的两条线段，AB为较长者 | Heath246；Fitzpatrick9 | 正长度和严格内部性在现代规格中写明 |
| 在A处由I.2取得AD=C，再画圆 | 同上构造段 | 不擅加I.2保证方向的说法 |
| 圆周半径相等，再用同一中间量传递 | Heath247；Fitzpatrick10；Def.15、C.N.1 | 等式链不单独证明共线、方向或点序 |
| E在AB上、A—E—B | 两版I.3图与完成句 | 本文显式补写相交/位置义务，不伪称原文另有现代式证明 |
| 重展开I.2会增加图形配置 | Heath247评论 | 区分Heath、Proclus和欧几里得 |
| 圆规离纸合拢解释 | Heath246引De Morgan | 后世操作模型，不是器具实证 |
| 现代几何应明确点序和交点条件 | 现代研究§6.2、6.9—6.11 | 各体系公理选择不同，未复跑外部证明工程 |
| 显式点E、唯一性、余段、叉积/内积检查 | 正文第4节 | 本文实数模型内的原创推导 |
| 候选反例、表示限制、生成与检查区分 | 正文第4—7节及复现附件 | 教学分析，不由史料为程序统计背书 |
