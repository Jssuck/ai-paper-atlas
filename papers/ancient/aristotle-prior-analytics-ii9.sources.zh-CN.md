# 《前分析篇》II.9：来源台账

## 单元、年代与收录范围

完整单元为亚里士多德《前分析篇》第二卷第九章，**Bekker 60a15–60b5**。第二卷第十章自60b6开始，不计入本篇完成。作品置于公元前四世纪的年代范围；本章不是能单独确定首刊年份的现代研究论文。此处是AI推理前史回填，不称第一篇AI论文，也不声称穷尽古代推理研究。

本章直接接续II.8的结论替换定义，把分析转向第二格；I.5是第二格原式的前驱，I.4、I.6提供替换后第一格与第三格的推导工具，II.2提供真前提不推出假结论的背景。II.5–7讨论相互证明，问题不同于这里的前提反驳。没有从所查章节建立某位古代同期作者与本章的具体竞争关系；不能为了年代目录而编造。1831、1853和1913分别是所用编辑、译本年代，不是原作年代；形式相似也不证明亚里士多德直接导致某一现代AI算法。

## 勘误、注释与转录核验

1. **正式ERRATA：** 本次实看卷首三条，分别针对印219、273、594；无印201–202条目。仅说明所见自带勘误不涉及本章，不证明本章无误。
2. **Owen印201注6的contrary：** 注6把本段大前提AB的反驳解释为反对式，但正文所得是“A不属于某B”，原前提是“A属于所有B”，这是一对矛盾命题。Jenkinson注36明确解释为contradictory。正文采用矛盾反驳，并公开指出该脚注与正文不合；这不是正式ERRATA所列更正。
3. **Owen印201注7、8的式名角色：** 注7附于“B属于某C、A不属于任何C，故A不属于某B”一段，却标Darii反驳小前提；注8附于“B属于某C、A属于所有B，故A属于某C”一段，却标Ferison反驳大前提。两标签与所附推导对调。印202注1恰明确Darii反驳小前提、Ferison反驳大前提，与推导一致。本文按实际项位及202注1解释，不照抄201的标签位置。拉丁式名来自后世注释，不是古希腊原文的名称。
4. **Wikisource转录缺字：** 60a40对应句在所见电子文本为“Again if belongs to some C…”，缺B；Bekker原行有B，Owen印202也有B。本篇按两印本核为B，不把转录遗漏归罪于未亲见的1913印本。
5. **特称见证措辞：** Owen印202说某个个体可有且可无相应属性，脱离语境易误读成同一对象同时有且没有。Bekker连续两个τινί及Jenkinson的some C须结合量化理解：可以存在属于A的C，也存在不属于A的C，不要求同一见证。现代集合的两个对象例为教学澄清，不当作原文给出的例子。
6. **校记范围：** Bekker印60页底60a30有词形读法记录；本次没有据此另造正文。Jenkinson注35回指I.6，注36解释矛盾反驳，注37回指II.8；未见本章新的校订命令。II.10注39的60b19校订不属于II.9，不混列为本篇成果。
