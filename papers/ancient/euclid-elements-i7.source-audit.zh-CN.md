# Euclid I.7：独立来源审查

**结论：通过本次来源范围审查，未发现阻断发布的来源归属或历史证明表述错误。** 这不是对所有传世版本的校勘，也不是独立技术实跑的替代。

## 审查对象与版本绑定

- 正文：[euclid-elements-i7.zh-CN.md](euclid-elements-i7.zh-CN.md)
- 正文 SHA-256：`7a0e7a284ff146860fb49ae837e546fdd1898b0a566f1e6df009957416f7be57`
- 方法：由独立来源审查任务完整阅读正文，对照 Heath 1908 卷一印刷 258–261 页、Fitzpatrick 2008 第 13–14 页；目视扫描页面而非只检查文本提取结果；另检查 Heath 所附勘误表及 Clay 历史档案入口。
- [来源台账](euclid-elements-i7.sources.zh-CN.md)提供版本链接和逐项定位。正文若有改动，本审查结论不自动覆盖新字节版本。

## 逐项核对

| 检查项 | 结果与依据 |
|---|---|
| 年代定位 | 通过。Clay 入口将作品置于约公元前 300 年，并明确所展示 D’Orville 301 抄本抄于公元 888 年。正文没有把抄本年代当作品年代，也没有赋予 I.7 确切发现年份。 |
| 命题条件 | 通过。固定不同 A、B，C、D 位于基线同一严格侧，长度逐端对应；相异候选的反设与 C=D 的现代逻辑结论相容。没有把无序长度集合当成对应关系。 |
| 原文证明 | 通过。Heath 259 与 Fitzpatrick 13–14 均以连接 CD、两次 I.5 和角的严格大小／相等矛盾为骨架。正文将图示射线次序列为条件，没有把共同概念 5 当作射线位置定理。 |
| 原图角链 | 通过。角 CDB 大于角 ADC，后者等于角 ACD，再大于角 DCB；同时角 CDB 等于角 DCB。交换角名中的两端字母没有改变所指无向角。 |
| 第二情况的归属 | 通过。Heath 260 明说第二情况不在原文所给证明中，联系 Proclus 的补充和 Simson 等后世处理。正文没有把这段补充倒写为原作者正文。 |
| 内嵌情况的角链 | 通过。AC 越过 C 延至 E，AD 越过 D 延至 F；I.5 的底边下角给 ECD=FDC。补充图中的 BDC 大于 FDC、ECD 大于 BCD，和 BC=BD 所给 BDC=BCD 矛盾。正文保留了图形位置限制。 |
| 边界与退化 | 通过。真子线段／延长线的长度检查被置于教学说明；共线候选、重合锚点不被偷偷代入原角证明。正文没有声称已完成所有古典射线排列的形式化穷尽。 |
| 非循环依赖 | 通过。I.8 后续调用 I.7，正文不反借 I.8 或 SSS 充当 I.7 的历史证明。现代坐标证明另立实数欧氏平面背景。 |
| 存在性与反例 | 通过。命题是条件性唯一性，不保证任意半径有交点。异侧镜像、交换对应、三维情形与带容差条件都未冒充满足原命题全部前提的反例。 |
| 原文与现代重构 | 通过。平方距离相减、内积／叉积恒等式和程序检查均明确为现代教学工作；未声称 Euclid 使用这些符号。 |
| 实跑证据的边界 | 通过来源表述检查。正文明确有限有理枚举不证明全体实数结论，标准库执行 Notebook 不等于 Jupyter 内核认证；运行数值由独立技术审查负责复核。 |
| 勘误范围 | 通过。实际检查的 Heath 卷首勘误表未列印刷 258–261 页修正；正文没有夸大为“所有版本均无勘误”。 |
| 公开内容边界 | 通过。正文与来源文件为原创解析、必要书目链接和审查结论，没有公开所读扫描页面、PDF 或原文全文翻译。 |

## 仍需保留的限度

原文简短图证与现代形式化证明不是同一种交付。本次确认的是指定版本、可定位的命题及评论、正文的忠实区分与推理范围；未核验全部希腊手稿异文，也不凭后世评论断定发现优先权或直接历史传承。数学实现及真实运行结果另见[独立技术审查](../../reproduction/euclid-elements-i7/technical-review.zh-CN.md)。
