## 3. 需要特别纠正的读法

### 3.1 一个等号不能替代三个层次

1. $`X\equiv Y`$ 是元层“同一Etwas”的记号约定，含定义性同一。
2. $`(X=Y)\equiv QXY`$ 定义对象层等式表达式。
3. $`\vdash X=Y`$ 表示这个等式表达式被断言为Formel。

实验另行引入的 $`\to`$ 是四条计算行为的**定向教学读法**。原文Reg.B/C/W/K给的是带断言的等式，不是只准向右执行的程序规范。

### 3.2 原文扫描中可定位的排印疑点

- **533页II.B.4 Satz3证明首行**：扫描左端印作 $`X\cdot(Y\cdot Z)`$，而紧跟的 $`B(X\cdot Y)Z`$ 依Def.1对应 $`(X\cdot Y)\cdot Z`$。后续三步最终又得到 $`X\cdot(Y\cdot Z)`$。本解读显式改写首端为 $`(X\cdot Y)\cdot Z`$，使证明链成立；不把该修复冒充作者正式勘误。
- **534页II.B.4 Satz7参数范围**：公式使用 $`m,n,p`$，括号内扫描却有重复 $`n`$ 的排印。按公式及下一行脚注的 $`p=0`$ 解释为 $`m,n,p\ge0`$；不影响本篇核心推导。
- 原文I₁公理的脚注说其可由其他公理推出，并把证明指向II.D.2 Satz6。这里保留它在第一部分公理表中的身份，不声称本轮已核该冗余性证明。

### 3.3 Ax.(BW)的括号：以534页明确重写为准

521页原始公理行按扫描中可见括号及本文的左结合约定读为：

```math
BBW=B(B(B(B(BW)W)(BC))B(BB))B.
```

但534页同一公理被作者重写为：

```math
B_1\cdot W_1=W_2\cdot W_1\cdot C_2\cdot(B_2B)\cdot B.
```

其中点乘左结合。这一形式展开并化简定义后应为：

```math
BBW=B(B(B(B(BW)W)(BC))(B(BB)))B.
```

关键是将 $`B(BB)`$ 作为一个整体参数。字面521页版本与534页版本不是同一应用树。分别再应用三个新鲜符号 $`x_0,x_1,x_2`$，四条定向行为规则给出：

```math
(BBW)x_0x_1x_2\to^*x_0(x_1x_2)(x_1x_2),
```

而521页字面右端给出：

```math
x_0(x_1(Bx_0))(x_1x_2).
```

独立读图与符号复算均发现该差异。实验采用534页明确点乘版本，并保留字面521页失败用例。这是**可定位的疑似括号排印错误及本解读采用的版本选择**，没有取得作者正式勘误，不声称作者曾发布以上修正。更不据这处字面公理与计算行为不一致就宣称已经证明整个1930理论逻辑不一致。

## 4. 可复核阅读路线

先读509、512–514确认问题；接520–525核对象/元层与等式基础；再读526–528看“将来要证明什么”；最后529–536逐式核序列、公理组织与第一部分的止点。若只读到528便宣布“组合逻辑表示完备性已证毕”，恰好漏掉了本轮最重要的范围限制。
