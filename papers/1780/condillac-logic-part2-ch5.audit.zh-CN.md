## 3 必要条件不能被形式模型改造成充分条件

设 $`R`$ 为进行了某种推理，$`K`$ 为具有属种分类，$`A`$ 为具有抽象观念，$`N`$ 为具有名称。只为检查推论方向，原文的连续否定条件可写成：

```math
\neg N\Rightarrow\neg A,\qquad
\neg A\Rightarrow\neg K,\qquad
\neg K\Rightarrow\neg R.
```

经典命题逻辑下，能够得到：

```math
R\Rightarrow K\Rightarrow A\Rightarrow N.
```

这不推出 $`N\Rightarrow R`$，更不推出“名称构造良好便保证每次推理正确”。令四个命题都真，再让某次推理的结论错误，仍可满足这条必要条件链。因而即使暂时承认每项心理学前提，正确性的充分条件也没有凭此获得。

不能把“好语言”故意压缩成拼写清楚，再声称已经驳倒原作者全部方法。自引背景表明，作者的“好”含有分析、内容形成、生成追溯和关系安排。相应地，若把准确前提与可靠步骤全收进“好”的定义，就必须分别论证这些要求如何满足，不能靠定义省略工作。

现代模型的定理从“每条边已经外延有效”出发。这是额外的语义前提，既没有从名称的存在推出，也没有从必要条件链推出。因此它澄清一个可靠的有限情形，并未修复原章全部强结论。正文第4.2节、第9.4节与结尾明确维持这项区别。

## 4 定义的类型和输入前提

令 $`U`$ 为对象集合，$`L`$ 为名称集合，$`E:L\to\mathcal P(U)`$ 为完整外延解释，$`G\subseteq L\times L`$ 为显式有向边。这四类对象的类型一致。成员关系 $`u\in E(a)`$、集合包含 $`E(a)\subseteq E(b)`$、显式边 $`(a,b)\in G`$ 和可达关系 $`a\preceq_G b`$ 没有互相替代。

模型文件额外保存对象、名称及边的固定枚举顺序。这些顺序用于决定首个反见证、同长路径的平局及输出排列，不改变集合论真值。模型把带枚举的有限集合写成元组，是实现约定；其中取幂集和包含时使用其对象集合，而不是把整个元组当成一个不可分对象。

以下前提已经明确：

- $`E(a)`$ 必须是已声明 $`U`$ 的子集；未知对象不能被默认为新的成员。
- 每个名称必须有恰当位置的外延；未知名称不能被当作空类。
- 边端点必须属于 $`L`$。对象标识与类名即使使用相同字符串，仍处在不同类型的位置。
- 可执行系统至少有一个名称，但可以没有对象；标识必须是非空字符串。空字符串不是“空类”的表达方法。
- 不要求外延两两不交，也不要求一个名称只有一个直接上级。一般模型不是分类树。
- 同外延名称可以保留不同身份；给定有限世界中的等外延不能自动提升为自然语言同义。

没有发现利用非法输入使一个证明看似成立的情况。拒绝非法输入、拒绝含坏边图和合法查询返回无路径，是三种不同结果。

## 5 外延包含 反见证与路径可靠性

定义 $`a\preceq_E b`$ 当且仅当 $`E(a)\subseteq E(b)`$。差集

```math
W(a,b)=E(a)\setminus E(b)
```

为空，当且仅当包含成立。这一等价不限于有限集合；有限性使本程序能够用完整成员表逐一决定它。空差集没有说明现实观察已经穷尽全部相关对象。

一条证书 $`a_0,\ldots,a_k`$ 要求每个相邻对是显式边，长度为 $`k`$。正文使用允许重复名称的有限路径定义，更严格的图论术语可称有向游走；这不影响可达性、串接或可靠性。BFS返回的最短证书不会有重复名称，因为发现记录只保留第一次访问。零边证书只含起点名称，不要求显式自环。

模型的较强表述是：

```math
G\subseteq\preceq_E
\quad\Longleftrightarrow\quad
\preceq_G\subseteq\preceq_E.
```

正向证明完整：对任意路径的任一起点成员，逐条包含关系将成员保留到下一外延，有限次后到达终点。起点外延为空时，任意成员的条件真空成立；长度为零时使用包含自反性。反向也成立，因为每条显式边本身就是一条长度为1的路径。

这一证明实际上不要求 $`U`$ 有限，也不要求所有可能路径的总数有限；它只使用所取路径长度有限。对无限成员表作自动有效性判定则是另一个问题，本程序没有实现。正文正确地没有以两个或四个对象的测试规模代替一般证明。

坏边也不能反向推出“经过它的每一条路径，其端点关系都假”。例如 $`E(A)=\{x\}`$、$`E(B)=\varnothing`$、$`E(C)=\{x\}`$，路径 $`A\to B\to C`$ 含坏边，但 $`E(A)\subseteq E(C)`$ 仍真。这条路径没有合格的逐边证明保证，尽管其端点结论偶然为真。模型已保留这个区别。

## 6 不完备 全图门槛与三种查询结果

图可靠与图完备相对于同一个固定解释定义：

```math
\text{可靠：}\quad\preceq_G\subseteq\preceq_E,
\qquad
\text{完备：}\quad\preceq_E\subseteq\preceq_G.
```

两者都满足，才有关系相等。把所有真实包含对写为边足以获得完备可靠图，但不是唯一方式。自环可以由零边路径承担，某些边可以由其他路径生成。

正文的无边反例有效：令两个不同名称的外延分别为 $`\{u\}`$ 和 $`\{u,v\}`$，语义包含真而图无对应路径。没有路径只说明指定证明系统未给出证书，不等于差集非空。

在全图有效的前提下，三分结果完整且互斥：

| 图中证书 | 语义包含 | 反见证 | 判断 |
|---|---|---|---|
| 有 | 真 | 无 | 有已认证证明 |
| 无 | 真 | 无 | 真关系没有被现有图推出 |
| 无 | 假 | 有 | 有限解释提供具体反驳 |

第四种“已认证证明存在而包含假”被可靠性排除。对坏图则必须另列拒绝状态，而非强塞进此表。

`prove` 检查所有显式边，再调用图搜索。因此完全无关的坏边也可阻止一个局部正确查询，连自反查询也不能绕过门槛。这是接口的保守准入约定，不是新逻辑定律。拒绝全图不会改变对象关系，更没有证明查询命题为假。正文、模型、走查及第23题一致地解释了这一点。

有限解释本来允许直接决定语义包含，图路径仍有教学意义：它显示已经记录哪些前提、如何连接中间项及证书是否可回查。这里的“无图证明”不是整个有限模型不知道答案，也不是不可判定性。

## 7 两种预序 商结构及修正后的充分条件

图可达关系对任何图都是预序。零边路径给出自反性，串接有限路径给出传递性。语义关系同样因集合包含的自反性和传递性成为预序。不同名称可以具有相同外延，因此语义关系在名称集合上未必反对称。

令

```math
a\sim_G b\quad\Longleftrightarrow\quad
(a\preceq_G b\ \text{且}\ b\preceq_G a),
\qquad
a\sim_E b\quad\Longleftrightarrow\quad E(a)=E(b).
```

两者都是等价关系。前者的等价类是强连通分量；后者的等价类是同外延名称组。

### 商关系为什么与代表元无关

在图商集上，定义 $`[a]_G\leq_G[b]_G`$ 当且仅当 $`a\preceq_G b`$。若换成相同组内的 $`a'`$ 和 $`b'`$，就可串接 $`a'\preceq_G a\preceq_G b\preceq_G b'`$，故关系不依赖代表元。自反、传递继承下来；若两组互达，其代表本来等价，故两组相同，反对称性成立。

语义商集上，代表元换成同外延名称并不改变集合；按包含定义关系也良定义并满足偏序。因此两个商偏序都成立。这个论证没有将“强连通分量”与“相同外延”预先认作同一个概念。

### 有效图只保证一个方向的细化

可靠性给出 $`a\sim_G b\Rightarrow a\sim_E b`$。所以映射 $`[a]_G\mapsto[a]_E`$ 良定义、满射且保序。但它未必单射：同外延名称可以没有互达路径。

在有效图中，两种等价分组相同的确切条件是：

```math
\forall a,b\in L,\quad E(a)=E(b)\Rightarrow a\sim_G b.
```

全语义完备足以保证这个条件，却不是必要条件。例如 $`E(A)=E(B)=\{x\}`$、$`E(C)=\{x,y\}`$，图只有 $`A\to B`$ 和 $`B\to A`$。两种分组都为 $`\{A,B\}`$ 与 $`\{C\}`$，但缺少前一组到后一组的真实包含路径。

这个反例还提醒读者：分组相同，不等于组间偏序已经相同。若要求以上自然对应既保序又反映全部语义顺序，即商偏序在该对应下同构，则需要把遗漏的语义包含也补上；对于有效图，这相当于完整性。正文与模型的修订只声称“分组一致”的较弱条件，没有再将它误作整个顺序相同。

## 8 双射换名的全部不变量

设 $`\pi:L\to L'`$ 是双射，定义

```math
E'(\pi(a))=E(a),\qquad
G'=\{(\pi(a),\pi(b)):(a,b)\in G\}.
```

首先，新解释良定义，因为每个新名恰有一个旧名来源。其次，外延集合不变，所以每一对包含的真假及全部反见证集合不变；对象宇宙也不变。再者，路径逐名应用 $`\pi`$ 得到同长新路径，逆映射可恢复任一新路径，因而可达性和最短边数都不变。双向可达也对应，所以强连通分量仅改标签。

“第一个反见证”和“BFS究竟选哪条同长证书”比真假及最短长度多依赖顺序。模型已经明确对象枚举顺序、名称位置和边输入顺序一起保持，且BFS不按新名字重新排序，因此这两个确定性输出也保持。如果另一个实现按标签字典序重排邻居，仍会保持可达性及最短长度，却未必返回逐字换名后的同一条平局证书；不能无条件推广当前实现的更强结论。

非双射合并不满足定理前提。若两个不同外延被压在一个新名上，新解释会冲突；即使二者外延相同，图结构和路径信息也可能改变。只改显示名称而错配外延，同样属于改变解释。定理不证明自然语言之间存在逐词双射，也不衡量记忆、词源、语境或学习成本。

## 9 BFS的终止 最短性与成本

BFS以起点为已发现名称，维护队列和前驱。每个新名称仅首次发现时入队，已发现者跳过。因此有限名称集合使入队和出队次数有限，自环和更长的环都不会导致无限循环。目标与起点相同直接返回零边证书；未知端点先拒绝，不会产生伪自反答案。

队列按非递减距离层处理。归纳假设当前出队名称的首次发现距离已经最短，由其一条出边首次发现的新名称距离增加1。若目标首次被发现于第 $`k`$ 层，却有短于 $`k`$ 的路径，沿较短路径的倒数第二个名称应已在更早层处理并发现目标，矛盾。因此首次发现目标即可返回，无需等它出队。前驱形成严格由晚发现到早发现的链，必回到起点，不能含环。

这里最短指边数。没有权重、证明可信度、计算成本或心理难度的最优化。图中若有多条相同边数的路径，固定邻边输入顺序只决定选哪一条，不改变最短长度。

为避免正文和附件用同一字母表达不同计数，以下统一记名称数 $`n=\lvert L\rvert`$、边数 $`q=\lvert G\rvert`$、对象数 $`s=\lvert U\rvert`$。

| 操作 | 审计后的上界 | 条件及范围 |
|---|---|---|
| 已有邻接表上的BFS核心 | 时间 $`O(n+q)`$，额外搜索空间 $`O(n)`$ | 集合和字典按通常平均常数成本；不含预先存图 |
| 当前 `find_path` | 时间及辅助空间 $`O(n+q)`$ | 含构造邻接表和线性标签定位，不含创建整个实例 |
| `includes` 与 `witness` | 时间 $`O(n+s)`$ | 标签定位线性，成员及子集判断按有限集合成本计 |
| `violations` | 时间 $`O(q(n+s))`$ | 每条边独立定位标签并检查外延，坏边另取见证 |
| `prove` | 时间 $`O(q(n+s)+n+q)`$ | 每次重新进行全图核验，没有认证缓存 |
| 当前 `components` | 时间 $`O(n^2(n+q))`$ | 最多作 $`2n^2`$ 次路径查询，不是线性SCC专用算法 |

将正文的计数换成本节记号后，$`O(qs)`$ 是朴素的逐边逐对象成员检查数，不能当成当前实现包括标签查找的全部运行时间；它已将全图认证与图搜索分开，附件进一步给出实现级成本。空宇宙使成员检查可以为零，却不消除标签查找和遍历边的开销。

这里均为通常数据结构成本模型下的粗略上界。字符串长度、哈希最坏情形、创建及校验实例的成本不由这些公式自动消失；材料没有将上界冒称为跨环境实测性能。若另行排序邻居，排序预处理须另计。

## 10 边界情形逐项审计

| 情形 | 正确结果 | 材料是否区分 |
|---|---|---|
| 某一类外延为空 | 包含于每个类；没有该类的存在见证 | 是，正文及走查均有专节 |
| 全对象宇宙为空 | 所有外延都空，所有语义包含为真；图仍可不完备 | 是，模型明说，程序允许 |
| 名称集合为空 | 数学上只有空关系、无合法名称查询；程序明确拒绝 | 修订后已区分 |
| 一个名称但无边 | 自反路径长度0；包含自反为真 | 定义与BFS均涵盖 |
| 显式自环 | 语义必有效，不增加新的自反可达结论 | 允许；单项测试与穷举范围分开 |
| 不同名称但同外延 | 语义双向包含；图不自动互达 | 是 |
| 重叠但互不包含 | 两方向均可能有反见证 | 红色与三角形例明确 |
| 互达且图有效 | 外延相同；名称仍可不同 | 是 |
| 环中存在坏边 | 原始搜索仍可达；认证拒绝全图 | 是，不把所有环本身判为矛盾 |
| 一条与查询无关的坏边 | 全图接口拒绝，即使局部查询可安全证明 | 是 |
| 非空单元素前件 | 合法代表检查可决定该前件的包含 | 走查练习五及模型明确 |
| 空前件选代表 | 没有合法代表，不能用任意对象代替 | 明确拒绝 |
| 空字符串作标识 | 非法输入，不等于空类或空宇宙 | 输入约定明确 |
| 越界对象或未知名称 | 输入错误，不应静默补充解释 | 明确拒绝 |
| 重复名称或边 | 程序拒绝，避免位置与次序歧义 | 与数学集合不含重复的定义相容 |

“所有空类成员都是红色”只给出全称包含，不能单独推出空类非空，也不能单独推出存在红色对象。特别是在空宇宙中，两个存在断言都假而包含仍真。这是现代集合语义的选择，未被反向归给孔狄亚克的历史逻辑。

## 11 两套逐步示例的手工复算

### 正文的三角与圆

正文第11节先明确说是独立手算例。对象为红三角 $`x`$、蓝三角 $`y`$、红圆 $`z`$、蓝圆 $`w`$。三角与多边形外延均为 $`\{x,y\}`$，图形为全部四个对象，红色为 $`\{x,z\}`$。

- 三角到多边形、再到图形的两条边都有效；证书长度2。
- 三角包含于红色是假，差集为 $`\{y\}`$。
- 红色包含于三角也是假，差集为 $`\{z\}`$；两类交集为 $`\{x\}`$。
- 只检查红三角 $`x`$ 会得到正例，不能排除 $`y`$。即使再看一个红三角，也不能在开放对象域上排除其他蓝三角。
- 绿三角的外延为空，包含关系不提供存在见证。
- 在只保留原来另一条边的情况下，删去三角到多边形会使三角到图形失去路径，外延包含却不变。

所有计算正确。圆不是多边形，所以这个小世界中三角和多边形恰好同外延；正文已经警告，不能把这件事推广为现实概念同义。
