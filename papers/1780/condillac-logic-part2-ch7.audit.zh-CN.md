## 2. 全章论证不可压缩成一个答案

### 2.1 数学家、发现与教学

152–154页以Clairaut、Euler、La Grange的实践支持分析法，同时断言分析既是发明的方法，也应是讲授的方法。需保留两个限制：作者明说不知道Euler和La Grange是否公开表达相应教学主张，是由他们的实践作推断；赞美Euler代数教材《Élémens》时也批评方程理论有时过于简略。把这些数学家列为权威，不能证明所有学生、目标与课程条件下同一种编排最优。发现的历史过程、结果的证明结构与学习者的起点也不是同一个对象。

### 2.2 简洁、精确与充分证据

155–157页把分析的清楚精确归于语言的清楚精确，并把所有科学的证明问题主要归咎于语言制作。此处至少要分开：表达有没有确定意义；推导有没有保持真值；前提是否有根据；经验测量能有多精确。语言改进可能帮助前两项，却不能只凭改写产生新的观察事实或抹去测量不确定性。

159页从缩短表达推出观念更靠近、更易把握全部关系，是认知效果的论断。本文的字符数、代数长度或运行步骤不能代替人的理解实验。给整套问题取一个单字母代号可以让可见字符串极短；如果没有其字典，读者反而失去可解释性。有字典时仍有学习、检索与记忆成本。简洁必须相对于给定符号系统和使用者来讨论。

### 2.3 两个转移、括号与回代

157–162页的问题有同一初态的两个替代条件，不是连续动作。令初始右、左手数量为 $`R,L`$，得

```math
R-1=L+1,\qquad R+1=2(L-1).
```

第二式的括号关乎意义，不能写成 $`2L-1`$。原文“两个左手，各减一”将两个减一合为减二。由第一式得 $`R=L+2`$，由第二式得 $`R=2L-3`$，故 $`L+2=2L-3`$，即 $`L=5`$；再回代得 $`R=7`$。两个替代情景为 $`(6,6)`$ 与 $`(8,4)`$，都满足原条件。若误作顺序转移，第二条件变为 $`R=2L`$，与第一条件合起来解成 $`(4,2)`$。这说明漂亮的算术答案也可能源于错误问题语义。

### 2.4 164页的印字与校读

实际图像明确显示中间一行为 $`x+2=2y-3`$。其上文是令两个右成员相等，162页文字解法也给“左手加二等于两个左手减三”，下一行又消掉一个 $`y`$，故校读为 $`y+2=2y-3`$ 有很强上下文依据。外交转录应保留印字，数学重构应明确声明采用校读；不能把 $`y`$ 静默冒充所见印字，更不能将这里的差异只归咎于OCR。

把最终解 $`x=7,y=5`$ 代入实际印式，得到 $`9=7`$，直接不成立。这足以证明该行与本题已给出的关系及答案不相容，不足以独立确认错误在作者、排字工或哪次版次中首次出现。

### 2.5 同一、蕴含与全部科学

165页以判断的“同一”解释推理明证，166页把它延伸到心灵能力与感觉的关系、所有科学的精确性。现代重构可以证明明确系统的解集保持，却不能因此证明作者的一切“同一”都等于现代逻辑等价。字符串相同、表达式在给定解释下等值、方程组解集相同和某结论由前提推出，是不同关系。

尤其原系统推出 $`L=5`$，但 $`L=5`$ 单独不推出原系统：$`(R,L)=(0,5)`$ 是反例。保留 $`R=L+2`$ 才得到完整的等价系统。另一种严格操作是对原系统作存在量化，投影到左手坐标；那是在改变自由变量集合，须明说重建右手的条件。原文162、164页实际回代了右手数量，不应把它说成完全忘记了原条件；问题在于一般的“每一步都同一”修辞需要更细的语义说明。

166页“全部能力与感觉同一”是作者的哲学主张，不由筹码解题证明。167–169页进一步说代数本身就是语言、科学进步仅取决于语言进步，推理和计算都归结为组合与分解。这些主张没有因一个线性问题求解成功而获得普遍证明。167页的局部可互译示例，与168页关于代数能展开其他语言无法翻译的推理的说法，应分开讨论，不能把前者放大成所有语言无条件互译。

## 3. 精确仿射系统的独立证明

### 3.1 语法与语义

一个表达式由有理数三元组 $`(a,b,c)`$ 表示，解释为 $`aR+bL+c`$。单行方程意味着该表达式等于零；有限行列表是这些等式的合取。空列表约束所有有理数点，而不是没有任何解。程序不解析自然语言；其输入已经是现代读者完成语义选择后的结构。

系数和赋值均在 $`\mathbb Q`$ 内。两个线性表达式之差仍仿射，标量乘法封闭。一般变量乘变量不在此语法中；因此本模型的保证不覆盖任意代数方程或所有科学语言。

### 3.2 可逆行操作

交换两行的逆为再次交换；乘非零有理数 $`s`$ 的逆为乘 $`1/s`$；将另一行的 $`s`$ 倍加到当前行的逆为减去这另一行的 $`s`$ 倍。最后一步要求两行不同，保证作为参照的行不被自身改变。每项操作及其逆都保持所有方程同时成立，故保持完整解集；有限复合也保持。

不允许零倍缩放是实质条件。$`R=0`$ 乘零成为 $`0=0`$，原来不满足的点由此被接纳。仅保留两行相减的结果同样丢失约束；可逆消元应保留另一行。模型的证书执行器只允许这些明确操作，不代表自动判断任意自然语言证明。

### 3.3 规范形与解集

算法按两变量列和常数列寻找主元。每次归一和消去都是可逆行操作；此前主元所在列在之后候选行已为零，后续消元不会破坏已建主元结构。有限行、三列保证终止。

若出现只有常数非零的一行，则无解。所有不相容系统解集均为空，可以统一返回 $`1=0`$；这是一项语义约定，不等于声称它们原来的增广行空间相同。相容时系数秩只能为0、1、2，分别给整个平面、一条仿射直线或唯一点，所以程序的无限／唯一分类成立。

对相容系统，规范形为何也足以比较解集？这里可给一个专门针对二维的完整证明，避免只援引一般线性代数定理。若解集为平面，每一原行都必须恒零，规范形为空。若解集为直线，所有非零约束必有同一法向方向与同一常数比例；否则两条非平行线交于一点，或平行不同线无交。以首个非零变量系数归一，唯一得到同一行。若解集为唯一点 $`(r,l)`$，相容秩2规范形必为 $`R-r=0,L-l=0`$，也唯一。因此两个相容系统有同解集当且仅当其规范形相同；加上空解集统一约定，覆盖全部有限二维有理仿射系统。

一般证明不依赖下节有界枚举。它也不保证浮点近似、非线性约束、有限域或现实测量条件下保持相同结论。

## 4. 一般转移、退化与物理域

设两个独立转移量为 $`a,b`$，第二情景倍率为 $`k`$。代数前提为

```math
R-a=L+a,\qquad R+b=k(L-b).
```

第一式等于 $`R-L=2a`$。代入第二式得

```math
(k-1)L=2a+(k+1)b.
```

于是 $`k\ne1`$ 时存在唯一有理解

```math
L=\frac{2a+(k+1)b}{k-1},\qquad R=L+2a.
```

$`k=1`$ 时化为 $`0=2(a+b)`$：若 $`a+b\ne0`$ 则无解；若 $`a+b=0`$ 则只剩 $`R-L=2a`$，有无穷多个有理解。额外要求转移量为非负整数时，后者迫使 $`a=b=0`$，物理可行解为全部非负整数 $`(n,n)`$。

不可分筹码还要求 $`R,L,a,b`$ 都为非负整数，且各自初始供给足够：$`R\ge a,L\ge b`$。程序的可行性函数只检查这些条件，并不检查方程，因此必须与原方程同时使用。它也不是顺序模型的供给检查器。倍率若有额外物理限制，应另明示；代码的代数倍率可为任意有理数。

当 $`a=b=1,k=4`$，唯一有理解为 $`(13/3,7/3)`$，不可能解释为不可分筹码。即使在任意有限整数正方形中搜不到解，“全体整数上无解”仍应由唯一有理解的分母推出，而不是把有限搜索冒充无限域的证明。

## 5. 独立有界实现检查

另写[独立检查脚本](../../reproduction/condillac-1780-part2-ch7/independent_argument_checks.py)，不导入原单元测试。对任意输入行，独立判准先找非平行法向量的两行，用克莱姆法则求交点，再把该点代入所有原行；若全部法向量平行，则比较整条增广行的比例。常数矛盾、恒真空约束分别分类。该判准不调用被测消元器来生成预期分类或坐标。

实际覆盖：

- 系数各在−2至2的全部125种行，取全部有序二行系统，共15,625组。
- 系数各在−1至1的全部27种行，取全部有序三行系统，共19,683组。
- 合计35,308组，独立核查无解／无限解／唯一解分类、唯一点、规范形与语义类别的双向对应；每组再作五种交换、非零分数缩放或加行，共176,540次操作，以独立判准确认全解集类别及参数未变。
- 空组、单个恒真、单个矛盾、单变量分数约束另作边界检查，不计入上述组数。
- $`a,b,k\in\{-2,-1,0,1,2,3\}`$ 的216组推广，比较直接展开式、分式通解与退化分支。
- $`R,L,a,b`$ 各取六个含负数、零、半数和正整数的值，共1,296组，独立核查不可分筹码及两种供给约束。
- 八项拒绝输入，包括布尔系数与布尔减法、零缩放及来源目标相同行；另核原题、印字异常、顺序误读、丢失条件及非整数解反例。
