# Schönfinkel 1924：变量可以消失，依赖关系不能消失

## 从命题逻辑的一根竖线，到没有绑定变量的函数表达式

**一个公式里的字母，究竟在提供什么信息？** 如果同一个变量出现在三个位置，它把三个位置接到了同一个输入；如果一个变量没有出现，公式就丢弃那个输入；如果交换两个变量的位置，输入流向就改变了。Schönfinkel 的突破，是把这些原先由字母及其作用域表达的关系，变成可以组合的固定函数。变量并非凭空被删除，而是被编译成表达式的结构。

这是一篇关于逻辑表达形式的论文，不是一篇已有程序、数据集和运行时间的计算机论文。它的目标是减少数学逻辑的基本概念：先减少联结词，再把多元函数改写成逐次一元应用，最后用少数固定函数吸收变量的工作。其思想后来可以成为计算模型和编译技术的材料，但不能把后来的术语、定理及实现倒写成 1924 年已经完成的结果。

本篇围绕三个问题展开：为什么少到两个组合子就能处理函数项里的变量？为什么这并不等于用两个符号解释了全部逻辑？我们如何把原文的等式变成一台可以实跑、可以发现错误、又不会冒充一致性证明的教学机器？

## 1 “积木”问题：缩减什么，保留什么

### 1.1 基本概念的数量也是一种复杂度

原文第 305 页从公理化方法出发：除了减少公理，还可以减少那些不再解释、直接作为出发点的概念。这个目标并不自动要求每块积木都直观简单。有时把复杂性集中到一个略显奇怪的原始操作，反而能使整个语言的基础更统一。

先看命题联结词。取“非且”作为二元运算，本文记为 $`a\mid b=\neg(a\land b)`$。只要它可用，否定、析取、合取都能重建：

```math
\neg a=a\mid a,\qquad
 a\lor b=(a\mid a)\mid(b\mid b),\qquad
 a\land b=(a\mid b)\mid(a\mid b).
```

这一步的意义不是三个公式突然比一个更短，而是可以把语言的原始联结词缩成一种。原文第 306 页明确把这一方向联系到 Sheffer，并引用其 1913 年论文。这里是原文的历史归属；本轮没有继续精读 Sheffer 全文，因而不根据这一脚注作更广泛的独立发现或优先权裁决。

### 1.2 下一步为什么比非且更困难

命题逻辑里的 $`a`$ 可以直接看成一句完整陈述，但 $`f(x)`$ 还依赖对象。要说“每个对象都满足它”，必须说明哪个位置由量词约束。仅仅减少真值联结词，并没有消除变量、函数应用和量化。

原文把非且推广为含量化的关系。本文为了容易排版，把原来的带上标竖线写成：

```math
A\mid^{x}B\;:=\;\forall x\,\neg(A\land B).
```

这里 $`x`$ 绑定的是左右两个表达式中的自由出现；它不是第三个普通参数。普通 $`a\mid b`$ 与带绑定作用的 $`A\mid^{x}B`$ 因此不是同一种语法操作。若不分清，后面“消除变量”的成果就会被提前藏进定义里。

第 306 页表明，这个推广可以吸收否定、析取以及全称和存在量化。不过，把不含 $`x`$ 的陈述 $`a`$ 写成 $`a\mid^{x}a`$ 并理解为 $`\neg a`$，在现代通常采用的语义下依赖量化域非空：空域上的全称式恒真。本篇实验明确使用非空有限域；原文的表达习惯不能自动充当对所有空域约定的处理。

### 1.3 变量的工作是标识连接

原文第 307 页把变量描述成标示某些参数位置和操作归属的辅助符号。可以把这个观察转成一个今天很有用的提问：如果我们不允许在最终表达式里写绑定字母，有没有固定函数能接管“重复使用”“不使用”“交换顺序”“嵌套应用”这些工作？

注意，这不等于以后永远不能写 $`x`$。定义组合子时仍然要用元语言变量说明它的行为；构造过程中仍可出现开放项。最终对象语言没有某个绑定符号，与说明这种语言时完全不用变量，是不同要求。任何教程声称自己在第一页“彻底摆脱了所有变量”，却又用 $`S f g x`$ 解释规则，至少需要讲清这两层。

## 2 先改变函数观：输出也可以是函数

### 2.1 一次只接受一个参数

原文第 307–309 页扩展函数的考虑范围，使函数既能作为输入，也能作为输出。对于二元函数 $`F(x,y)`$，先固定 $`x`$，所得不是最终数值，而是一元函数；把这个一元函数作为新的函数 $`f`$ 在 $`x`$ 处的值，便有：

```math
F(x,y)=(f x)y=f x y.
```

这就是今天常称为“柯里化”的安排，但在这里应首先承认它出现在 Schönfinkel 的原文中。我们使用现代名称是为了检索与交流，不是在按名称分配发明权。

第 308 页用减法说明区别：先给定 $`a`$，得到“从 $`a`$ 减去输入”的函数；再输入 $`b`$，才得到 $`a-b`$。若把“输入两个数”当成一个不可分的原子动作，就看不到中间那个可以被传递和组合的函数值。

### 2.2 结合方向决定计算对象

本篇与原文一样约定应用左结合：$`f x y`$ 是 $`(f x)y`$，不是 $`f(xy)`$。最后一种写法把 $`xy`$ 作为一个参数传给 $`f`$，通常是另一棵树、另一个程序。

教学重构把项写成三种数据：变量、固定组合子和二元应用节点。一个应用节点保存“谁作用于谁”；所以即使打印时省掉左括号，树结构并没有丢失。所谓“无变量”也从来不等于“无结构”：名称被消掉，括号、应用顺序与常项仍须承担区别表达式的责任。

### 2.3 原文的函数直觉并非现成的无类型集合模型

第 307 页说每个输入至多对应一个输出，第 310 页解释 $`T`$ 时又限定在右侧表达式有意义的参数值上。它的叙述允许讨论意义范围，不能直接理解成“取所有集合函数组成一个集合，每个函数都能安全地作用于任何函数”。后者需要额外的模型构造，且随便取所有集合函数会有基础困难。

本篇程序选择一个更清楚、也更有限的承诺：项是有限语法树；重写规则对匹配的树起作用。我们不借此承诺每棵树都对应一个普通数学总函数，更不承诺每次求值都结束。这一区分在自应用和发散例子处尤其重要。

## 3 五个原始角色，先不要急着写成 SK

### 3.1 符号对照：最容易误读的一处

原文第 309–311 页依次使用 $`I,C,T,Z,S`$。其中 $`C`$ 是常值函数生成器，今天通常记作 $`K`$；原文 $`T`$ 的交换功能，今天常记作 $`C`$；原文 $`Z`$ 的复合功能，今天常记作 $`B`$。因此把原文中的每个字母 C 都按今天组合逻辑教材的 C 解释，会把整个论证读错。

本篇以原符号为主，明确给出行为：

```math
I x=x,
\qquad C x y=x,
\qquad T f x y=f y x,
\qquad Z f g x=f(g x),
\qquad S f g x=(f x)(g x).
```

这里只定义充分应用后的行为。$`C a`$ 是一个尚待输入的常值函数；$`S f`$ 和 $`S f g`$ 也都是可以合法保留的部分应用项。不要看见它们没有立即产生一个数值，就把它们判成语法错误。

### 3.2 I：把输入原样交回

$`I`$ 的功能最小，却恰好补上“表达式就是被消去的变量自身”这一特殊情形。若要为 $`x`$ 找一个不含 $`x`$ 的函数 $`F`$，使 $`F x=x`$，答案就是 $`I`$。

原文第 309 页特别解释等号：这里不是命题演算里的逻辑等价联结词，而是在说左右表达式指称同一个东西。这是概念性说明。代码则进一步选择把等式从左往右用作重写步骤；这种方向化和特定求值策略属于教学实现，不应冒充原刊原样规定的操作系统。

### 3.3 C：把不用的输入也接到接口上

若 $`a`$ 与 $`x`$ 无关，仍想把 $`a`$ 写成一个关于 $`x`$ 的函数值，就用 $`C a x=a`$。C 的工作是忽略后一个参数，而不是把所有参数变成常量。它本身先接受 $`a`$，然后生成那个恒为 $`a`$ 的函数。

这个角色以后会处理量词两侧依赖不一致的问题。例如左侧是 $`f x`$，右侧却是 $`g y`$。右侧没有 $`x`$，但可写为 $`C(g y)x`$，使双方都具有“某函数作用于 x”的外形。统一外形以后，才方便把绑定 x 的操作改写成一个接受函数的算子。

### 3.4 T 与 Z：交换和嵌套不是自由的代数定律

$`T`$ 可以交换后两个输入，但这不意味着应用满足交换律。$`f x y`$ 与 $`f y x`$ 一般不同；必须显式插入 T 才能改变输入安排。同样，Z 处理复合，却不意味着应用满足结合律：$`f(gx)`$ 不是 $`(fg)x`$。

原文第 310 页说 Z 可以移动内部括号，并特别提示括号没有在意义上被消灭。今天读这段，最实用的练习是每次变形都先画清应用树，而不是把相邻的字母当作可随意交换、合并的乘法因子。

### 3.5 S：把一个输入分给两个分支

S 是整个构造的中心。$`S f g x`$ 先把同一个 x 交给 f 与 g，再把所得的两个结果做一次应用。这不是把结果相加，也不是同时返回一对结果，而是让 $`f x`$ 作用于 $`g x`$。

原文第 311 页用对数举例：若 $`f x y`$ 表示以 x 为底的 y 的对数，$`g x=1+x`$，则 S 把它们组成以 x 为底的 $`1+x`$ 的对数。这里通常的对数定义域条件仍然存在；S 并不会让所有实数输入都突然合法。

从语法看，右侧有两次 x，左侧只有一次 x。这个“融合”消除了书写上的重复依赖；若从左向右运行规则，又会展开成两个 x。这也解释了为什么变量消除不必然带来更少的运行工作：紧凑的输入接口可能在执行时复制大型参数。

## 4 从五种函数到两种：逐行核对，而不是背口诀

### 4.1 I 为什么等于 SCC

原文第 312 页给出：

```math
S C C x=(C x)(C x)=x.
```

第一个等号用 S，第二个用 C。注意最后一个 C 只是为被丢弃的参数提供一个合法表达式：在有意义范围允许时，换成别的函数也可以。原文脚注 4 对这种替换附有“对每个 x 都有意义”的条件。现代纯语法里即使被丢弃的参数不能归约到结果，正常序仍可能直接把它丢掉；这属于另一层操作语义，不能默默抹去原文的限定。

原文脚注 3 还把此简化归给 Boskowitz，并提到 Bernays 先前给过另一个表达式。这个脚注使“这 12 页里出现的每一条等式都由作者单独首创”成为不准确的叙事。

### 4.2 Z 为什么等于 S(CS)C

把候选作用于三个参数，逐步算：

```math
S(CS)C f g x
\longrightarrow (CS f)(C f)g x
\longrightarrow S(C f)g x
\longrightarrow (C f x)(g x)
\longrightarrow f(g x).
```

原式 $`CS f`$ 读作 $`(C S)f`$，所以结果是 S；它不读成 $`C(Sf)`$。这一点若错，后面的每步都可能看似合理却算的是另一项。

### 4.3 T 的稍长表达式

原刊给出 $`T=S(ZZS)(CC)`$，其中 $`ZZS`$ 仍为左结合。令 $`Q=S(ZZS)(CC)`$，可核验：

```math
Q f x y
\longrightarrow (ZZS f)(CC f)x y
\longrightarrow^{*} (Z(S f))C x y
\longrightarrow S f(Cx)y
\longrightarrow (f y)(Cx y)
\longrightarrow f y x.
```

这段推导仍以 Z 为便利缩写；再把 Z 替成 $`S(CS)C`$，就只剩 C 和 S。这里的“等于”是在给定足够参数后行为相同的意义上说明的。一个纯重写器中的裸项 I 和 SCC 都可能已经没有可归约处，却不是同一个语法树；不要用“它们没有共同的裸项打印结果”反驳刚才的逐点等式，也不要用逐点计算自动推出自己实现了完整外延等式判定。

### 4.4 充分不等于最优

两种组合子足够承担这些行为，不意味着每个编译后的项都最短，或运行最快。保留 I、T、Z 作为可直接执行的指令，往往能使表达式更短、更容易看懂。原论文已经同时使用“为理解准备五种工具”和“原则上缩成两种基础”这两层；它并不要求读者在每一行都展开成巨大 C/S 串。

## 5 教学重构：把“消变量”写成真正的算法

原文第 313 页明确表示不完整展开一般证明，而是解释各个固定函数在归约中的作用。以下递归算法因此标为现代教学重构：它忠实展示原文核心机制，但不是把一段后来的标准证明误称为原文逐字给出的定理。

### 5.1 输入、输出和正确性承诺

输入是仅由变量、常项及应用组成的有限项 E，以及一个待消去的变量 x。输出记作 $`[x]E`$，目标是满足两点：输出中没有自由 x；把输出应用于任意项 A 后，其计算对应于把 E 中的 x 替换成 A。

本节的项还没有绑定算子，所以替换只是递归替换相应变量叶。若输入语言含 λ、量词或其他绑定结构，不能把这个简单替换器直接套上去；必须先处理作用域与变量捕获，或者逐层编译绑定节点。

规则如下，按列出的顺序选用：

```math
[x]x=I;\qquad
[x]E=C E\quad\text{若 }x\notin FV(E);\qquad
[x](P Q)=S([x]P)([x]Q)\quad\text{其余情形}.
```

$`FV(E)`$ 在此只是项内出现的变量集合。最后一个规则把大项变成两个严格更小的子项问题，所以构造过程结束。编译结束不等于编译出的程序求值结束；这两个终止性问题不可混淆。

### 5.2 正确性证明只需三个情况

若 E 就是 x，则 $`([x]x)A=IA\to A`$，正好是替换结果。

若 x 不出现，则 $`([x]E)A=(CE)A\to E`$，而替换本来也不改变 E。

若 E 是 PQ，则先展开 S：

```math
([x](PQ))A
=S([x]P)([x]Q)A
\longrightarrow (([x]P)A)(([x]Q)A)
\longrightarrow^{*}P[x:=A]\,Q[x:=A]
=(PQ)[x:=A].
```

中间两部分用对子项的归纳假设。更精确地说，这证明存在一条允许在应用内部归约的有限路径，通向替换后的原始项；它不要求该原始项继续归约后一定有正规形，也不声称一个任意选择的归约策略都能找到相同的终点。

证明输出不含 x 也按同一结构归纳：I 不含 x；第二种情况的 E 已经不含 x；第三种情况的两个抽象结果按假设均不含 x。这样，消元算法的功能与其边界就都有了可检验的表述。

### 5.3 第一个例子：消去 fx 中的 x

直接使用通用规则：

```math
[x](fx)=S(Cf)I.
```

将它作用于 a：$`S(Cf)Ia\to(Cfa)(Ia)\to^{*} fa`$。如果只要求外延上实现相同的一元行为，当然可以直接使用 f。这相当于一种额外简化；本文的基础算法没有偷偷加入这一条，因此读者看到较长输出时不应以为算法错误。算法强调简单且可证明的覆盖性，不强调最小化。

### 5.4 第二个例子：同一个输入用于自己

令 $`D=[x](xx)=SII`$。那么 $`D a\to (Ia)(Ia)\to^{*} aa`$。这个例子把“重复使用同一个参数”的机制展示得最清楚，也为发散例子埋下伏笔。

D 本身是闭项，没有变量，没有缺失定义，却可以应用于自己。$`DD`$ 会重复产生自应用结构。这说明没有自由变量并不保证计算停止；绑定问题与终止问题属于不同维度。

### 5.5 第三个例子：既嵌套又重复

考虑 $`f(gx)x`$，并假定 f、g 与 x 无关。先分解为 $`(f(gx))x`$：

```math
[x](f(gx)x)
=S\bigl(S(Cf)(S(Cg)I)\bigr)I.
```

作用于 a 后，最外层 S 得到“左分支作用于 a”的结果，再应用到 $`Ia`$；左分支依次产生 $`f(ga)`$，于是结果是 $`f(ga)a`$。也可用原来的 Z 简写成 $`S(Zfg)I`$。两个表达式长度差别很大，但目标行为一样；这正好给实验一个非平凡的交叉检查。

### 5.6 多个绑定必须从内向外消去

现代 λ 记法里的 $`\lambda x.\lambda y.x`$ 表示先收 x 再收 y。用本文规则，应先做 $`[y]x=Cx`$，再做 $`[x](Cx)=S(CC)I`$。把所得项作用于 a 和 b，得到 a，与直接使用 C 的行为相符。

若反过来消元，就在编译另一个参数次序。这里不是无关紧要的实现选择：次序决定调用接口。对包含遮蔽的绑定，比如 $`\lambda x.\lambda x.x`$，还必须按作用域识别两个不同的绑定位置；本篇基础项 AST 不提供这样的输入语法，因此不宣称它已经是完整的 λ 编译器。

## 6 变量到底去了哪里：一个结构成本的账本

### 6.1 删除名称不是删除信息

想象表达式里有三条线：第一条把输入接到 f，第二条接到 g，第三条把两个输出接成应用。用同一字母 x 两次，隐式表达前两条线；用 S，则把线路模式提炼成可复用的固定零件。表达仍然要区分左支、右支与应用方向，所以结构复杂度不会因为少了一个字母而凭空消失。

这也能解释 C 的必要性：一个输入可以没有被使用，这个事实必须有所表达。C 的“忽略”并非无意义的空操作，而是一个明确的数据依赖模式。T 表达置换，Z 表达串接，S 表达共享输入。无变量语言把这些模式从名称约定中搬到了显式项结构里。

### 6.2 空间膨胀与重复求值

朴素括号抽象在仍依赖待消变量的应用节点上引入 S，并在不依赖输入的分支加入 C。多次抽象时，会反复遍历已经扩大的表达式，产生很长的项。这里不把某个未经证明的全局复杂度界安到原文身上；仅从具体展开例子就足以看到“原始符号更少”并不等于“输出文件更小”。

进一步，$`SfgA`$ 展开后包含两份 A。树重写会在结构上复制它；如果两个分支分别求值，还可能重复做相同工作。后来的图归约可以用共享节点改善某些重复，但图、共享、更新策略以及效果的处理都是新增工程设计，不能只凭 S 这一个等式自动获得。

### 6.3 为什么消除捕获仍不代表没有编译错误

一旦得到完全没有绑定节点的组合子项，就不再会发生“把一个自由变量塞进某个同名绑定下面”的变量捕获问题。可是编译前错误地判定自由变量、错误处理遮蔽、错误排列参数，仍会编译出错误程序。目标语言简化了某类风险，不能替代源语言作用域分析的正确性。

对于自动推理或由模型生成程序的工作流，这个区别很实际：一个输出通过了语法检查，只证明它是一棵可解析的树；通过少量实例，只证明这些实例的行为吻合；保持语义的通用证明，则还需要类似上一节的归纳论证与明确前提。

## 7 U：逻辑内容并没有被纯组合子吞掉

### 7.1 传入的是谓词，不是一个尚未绑定的变量

原文第 313 页引入不相容函数 U：

```math
U f g=\forall x\,\neg(fx\land gx).
```

U 接受两个谓词，返回它们在所考虑域上是否处处不同时为真。将 $`fx\mid^{x}gx`$ 改成 $`Ufg`$ 后，绑定字母 x 从对象表达式中消失；量化的语义责任移到了 U 的解释里。

所以“把逻辑公式写成 C、S、U 的表达式”不等于“只用纯 C/S 重写就算出了所有逻辑真值”。纯组合子负责组织依赖；U 负责逻辑性的全称不相容判断。对于无限域、任意谓词，不能默认这个判断有一个能在有限时间内完成的普通计算过程。

### 7.2 用 C 补齐没有出现的参数

第 313 页的第一类情形是 $`fx\mid^{x}gy`$。右侧不依赖 x，先变为 $`C(gy)x`$，然后得到：

```math
fx\mid^{x}gy=U f\bigl(C(gy)\bigr).
```

这里 y 仍是自由参数，并没有因为消去了 x 就神秘消失。若最终目标还要消去 y，必须继续抽象，或者在原逻辑中先明确它的量化角色。把一部分绑定消除后的开放项宣传成“已经得到不含变量的最终句子”，会漏掉这一步。

### 7.3 用 T 改变变量的位置

对 $`fx\mid^{x}gxy`$，右侧 x 在 g 的第一个输入位置；为了让 x 出现在整个谓词的最后应用位置，原文写成 $`Tgyx`$，于是：

```math
fx\mid^{x}gxy=U f(Tgy).
```

核验很直接：$`Tgyx=gxy`$。这里 T 的角色不是让两个量词交换，而是重排一个谓词的参数。量词次序在更复杂公式中依然可能改变意义，不应把参数置换工具误当作任意交换量词的逻辑公理。

### 7.4 嵌套量化怎样逐层编译

原文第 314 页考虑两边各有一个内层绑定：左边是 $`fxy\mid^{y}gxy`$，右边是 $`hxz\mid^{z}kxz`$，再对 x 做带量化非且。先消除内层 y、z，得到关于 x 的两项：$`U(fx)(gx)`$ 与 $`U(hx)(kx)`$。

令 $`L=S(ZUf)g`$、$`R=S(ZUh)k`$。依照组合子等式，$`Lx=U(fx)(gx)`$，$`Rx=U(hx)(kx)`$。整个表达式因此成为 $`ULR`$：

```math
\bigl(fxy\mid^{y}gxy\bigr)\mid^{x}
\bigl(hxz\mid^{z}kxz\bigr)
=U\bigl(S(ZUf)g\bigr)\bigl(S(ZUh)k\bigr).
```

这个例子比一句“变量都可以去掉”更能说明机制：从最内层绑定开始，把依赖于外层 x 的函数值保留下来；再对这一层的函数值使用 S，把重复 x 融合；最后交给 U。它也是本文递归重构与原文具体步骤的接点。

## 8 原文完整例子：每个谓词都有一个与它不相容的谓词

第 314–315 页的命题，在现代符号中写作：

```math
\forall f\,\exists g\,\forall x\,\neg(fx\land gx).
```

这里 f、g 本身也是被量化的对象，因此不能把例子简单说成“普通一阶个体量词的演示”。需要区分个体域、谓词域以及 U 在相应层次上的解释。原文使用统一函数语言展示结构；本篇有限语义实验会显式枚举谓词，避免把类型层次藏起来。

### 8.1 先处理最内层的不相容

最内层是 $`Ufg`$。固定 f 后，把 $`Uf`$ 看成关于 g 的谓词。于是 $`U(Uf)(Uf)`$ 表达：

```math
\forall g\,\neg(Ufg\land Ufg)
\quad\text{即}\quad \forall g\,\neg Ufg.
```

它说“没有一个 g 与 f 不相容”，恰好是所需存在陈述的否定。设 $`Hf=U(Uf)(Uf)`$，目标句便可写为 $`\forall f\neg Hf`$，再用 U 得 $`UHH`$。

这里每个 U 都具有同一个“不相容”的模式，却可能在不同种类的输入上解释：最内层扫描个体，外层扫描谓词。把所有层都塞给只知道一个固定个体列表的 Python 函数，是一种类型错误，不是历史上量词已经被神奇消除的证据。

### 8.2 把 H 本身的 f 消掉

利用 Z 与 S：

```math
S(ZUU)U f
\longrightarrow (ZUU f)(Uf)
\longrightarrow U(Uf)(Uf).
```

所以可取 $`H=S(ZUU)U`$，最后获得原刊第 315 页的无变量表达式：

```math
U\bigl(S(ZUU)U\bigr)\bigl(S(ZUU)U\bigr).
```

再展开 Z 就只剩 C、S、U。这个结果确实消除了原先的三个绑定字母，可它仍然依赖 U 的语义以及函数能在什么范围有意义。句子“表达式没有变量”不是句子“逻辑已经没有任何解释条件”。

### 8.3 真值与表达能力是两个问题

在经典非空有限个体域 D、全部布尔谓词组成的谓词域 $`\{0,1\}^{D}`$ 中，给任何 f 选择恒假谓词 g，就能使 $`Ufg`$ 为真。也可以选 f 的补谓词。有限实验会验证这一点。

但是若谓词域被限制成只含恒真谓词，并令个体域非空，便没有所需见证；句子为假。这说明编码保留了一个句子的结构，不负责让句子在任意解释里为真。原文是在举逻辑表达的转换例子；我们不把这个例子夸大为对任意受限模型都成立的元定理。

## 9 结尾最容易被压扁的三层限制

### 9.1 三个符号到一个 J，作者自己也觉得勉强

第 315 页先说自然的缩减停在 C、S、U；随后给出一个形式上的打包办法：定义 J，使 $`JC=U`$、$`JS=C`$，其余输入的值为 S。依靠 J 与 C、S 的区别，可以写 $`JJ=S`$、$`J(JJ)=C`$、$`J(J(JJ))=U`$。

这是一种把现有常项藏进选择函数的编码方法。原文马上指出其任意性，使这种缩减缺乏实质意义。本篇不把它宣传成一个与 C/S 同等自然、已有完备操作语义的一指令通用编程语言；它还依赖对特殊对象的判别，不能只凭字符串中剩一个字母就认为基础负担消失了。

### 9.2 把 U 提出来，不等于从逻辑中定义出 U

紧接着的另一条路径，把某个含 U 的公式改写为 $`F U`$，其中 F 不再含 U。把这个约定的尾部参数省略，纸面上便能只写 C 和 S。它与现代抽象一个自由参数的思想相通，但逻辑算子依然作为隐含参数被提供。

原刊脚注 5 写在这段起始处，说明“以下考虑”出自整理者。因此第 315 页后半开始的这一路讨论及后续结尾，需要标明 Behmann 的编辑贡献，不能无差别归作 Schönfinkel 1920 年演讲的逐字内容。

原文随后还讨论借助 C、Z、S 避免括号，并用三进制数字串表征。本文报告这个方向，不补写一段未经原文逐步验证的全算法，也不把它称作已经完成的 Gödel 算术化：把表达式编码成数，与在算术内部表达证明关系并构造不可判定句子，是不同层次的任务。

### 9.3 第 316 页没有声称任意逻辑等价都能机械判定

最后一页先承认纯符号表示不会唯一，因为新旧公式都能有多种变形；然后在更受限的意义下讨论对应。其“等值”围绕不使用逻辑公理的定义性转换，以及变量类型差别展开。不能把这里改写成“任意两个意义相同的公式都会编译成完全相同的字符串”。

尤其不能从它推导出逻辑判定算法：一个表达式的构造性翻译，与判断任意表达式是否为真，是两种算法任务。原文强调这种还原独立于逻辑公理，也不等于证明了所涉及逻辑公理的一致性、完备性或可判定性。

### 9.4 本轮没有完成的历史问题

本篇完成了这 12 页原文的阅读和主要公式核验；没有顺带完成 Curry 1930 两部分、Curry 1931 量词论文或 Church 1933 续篇全文。因此也不在这里裁决后来各体系的全部一致性问题。可以比较“表达组织”这条连续线，却必须把各篇的语法、公理、类型限制与证明目标分别研究。

## 10 可执行复现：我们实际做了哪一种机器

配套文件位于 [reproduction/schonfinkel-1924](../../reproduction/schonfinkel-1924/README.md)。它是现代 Python 标准库教学重构，原论文没有软件、训练数据或实验日志。本篇并未寻找一个不存在的“作者原版代码”。

实现把变量、组合子与应用分开存储。它按最左最外策略逐步应用 I、C、T、Z、S 的定义，保留未获得足够参数的部分应用，并实现第 5 节的括号抽象。现代 K 只作为原文 C 的明确别名，不与现代交换组合子 C 混淆。

### 10.1 为什么不用 Python 函数直接冒充符号计算

直接定义几个高阶 Python 函数当然也能展示组合行为，但会把宿主语言的求值次序、调用栈和异常机制混入问题。用显式 AST 与单步重写，我们能数清每一步、观察哪个子项被复制，也能给出明确的步数预算。

例如 $`Ca\Omega`$，若 $`\Omega`$ 是发散自应用项，最左最外规则可先用 C 直接返回 a；一种先算完所有参数的实现却会陷在 $`\Omega`$。这不是 C 的数学定义忽然改变，而是求值策略决定是否先计算一个最终不用的参数。代码和日志明确展示预算与策略，不把任何超时都写成“已经证明发散”。

### 10.2 测试能确认什么

实验检查三类内容：定义性例子与充分应用后的导出组合子行为；对一个明确有限的项族检验抽象后的自由变量和替换结果；对非空有限域枚举谓词，检查 U 的解释及第 8 节命题的量化结构。

有限枚举是实现层面的回归检查，不能代替第 5 节的结构归纳证明。某次预算耗尽仅表示这一策略在这次资源限额内没有得到正规形；对于自应用，我们另用数学展开解释它为什么持续回到同类结构，而不是让程序的停止报告承担通用不可终止判定器的工作。

U 的有限语义测试与纯项重写分开。程序没有给纯 C/S 系统加入一个能检查任意无限域的真值神谕，也没有声称实现了第 316 页全部等值关系。它是一份尽可能小、可读、能被重新运行的机制演示。

### 10.3 本次实跑结果

CPython 3.12.14 下，11 个测试方法全部通过；Notebook 的 8 个普通 Python 单元全部实际执行并保存输出。替换性质覆盖 280 个小项乘以 5 种替换，共 1,400 例；个体域 `{0,1,2}` 上 8 个布尔谓词的 64 个有序对全部检查通过。

三个导出组合子补足新鲜变量参数后的结果分别为：I 得 x，展开侧 2 步；Z 得 `f(gx)`，4 步；T 得 `fyx`，6 步。这里的步数包含保留为原语的 I/C/T/Z/S 规则，尤其 T 的构造仍使用原语 Z；不是把所有项完全展开成仅 C/S 后的统一成本比较。

复杂项 `fx(gx)` 的机械抽象应用到 y 后，7 步得到 `fy(gy)`。自应用项在 25 步预算处被停止；同一策略计算 `CxΩ` 只用 1 步得到 x。高阶 U 的编码与直接量化枚举在全部 8 个谓词域上都为 True，在仅含恒真谓词的域上都为 False。

## 11 放回人工智能前史：有用的联系与不该有的捷径

### 11.1 从逻辑表达转向计算表示

这篇论文重要的桥梁，不是说 1924 年已经有了现代 AI，而是让函数的组织结构可以成为显式可变换的对象。一旦抽象、应用和依赖关系能够被有限规则处理，人们就有可能研究表达式之间的转换、程序的编码、通用解释器和机械化推理。

与 Gödel 的联系在于“符号及变换本身可成为数学对象”；与 Church 的联系在于函数表达和绑定；与 Turing 的联系在于后来可以用机器来执行这些有限规则。但三条联系不把三篇论文的目标合并成同一个目标，也不让本篇自动拥有后来的通用性、不可判定性或完备性定理。

### 11.2 编译器视角是一种现代读法

把 $`[x]E`$ 看成编译过程很自然：源形式有变量依赖，目标形式用固定组合子表达，正确性是应用后的行为保持。今天在代码生成中，最重要的不是目标串看起来多么精巧，而是编译器有无明确输入范围、每条规则是否保持意义、异常情况是否被测试。

由模型生成一个很长的 C/S 串，并不能凭外观判定它正确。更可靠的办法是保留可读源表达式，提供逐步推导，并用独立实现或有限样本交叉验证。本文为同一行为同时给出原文的短构造与机械抽象的长构造，就是为了让检查不依赖单一路径。

### 11.3 类型、资源与效果不能靠删变量解决

现代类型系统可以限制哪些应用有意义；资源敏感系统会特别关注重复与丢弃；带状态或其他效果的语言则必须明确重复求值会不会改变行为。这些问题在 S 的复制和 C 的丢弃处都有直观入口，但完整的现代理论不是原文已经写完的隐含附录。

尤其不要把“高阶函数”“自应用”“无变量”三个词连起来就宣布系统既安全、又终止、又能表示任何任务。表达能力强与受控行为之间往往存在设计取舍。本篇最值得保留的习惯，是每次缩减符号时追问：原来由这个符号承担的责任，究竟搬到哪里了？

## 12 练习与参考答案

### 练习 1：先检查括号

展开 $`S C C a b`$；再说明它与 $`S C(Ca)b`$ 是否一样。

**答案。** 前者先按 $`SCCa\to a`$，所以结果是 $`ab`$。后者按 S 得 $`Cb((Ca)b)`$，再由 C 得 b。一般而言 $`ab`$ 与 b 不同。邻接表示应用，不是可以随意重新结合的乘法。

### 练习 2：无依赖并不是空白

假设 x 不在 $`gy`$ 中出现，计算 $`[x](gy)`$，并解释为什么结果还可以含 y。

**答案。** 结果是 $`C(gy)`$，应用到 a 后得 $`gy`$。算法只消除指定的 x；y 是另一个依赖，不能被无授权地删除。若再要消 y，应继续做 $`[y](C(gy))`$。

### 练习 3：复合与融合

分别为 $`f(gx)`$ 和 $`fx(gx)`$ 写一个关于 x 的无变量函数，假定 f、g 不含 x。

**答案。** 短表达式分别是 $`Zfg`$ 与 $`Sfg`$。前者把 g 的输出交给固定 f；后者先用 x 得到一个函数 $`fx`$，再把 $`gx`$ 交给这个函数。一般不同。机械抽象可能得到更长但等行为的结果。

### 练习 4：两个消元次序

比较 $`[x]([y]x)`$ 与 $`[y]([x]x)`$ 的行为，各自作用于 a、b 后输出什么？

**答案。** 第一个对应先收 x 再收 y，输出 a。第二个内层为 I，外层因为 y 不出现而为 $`CI`$；作用于 a、b 后得 $`Ib=b`$。消元次序决定参数接口。

### 练习 5：对裸项作什么比较

为什么不能要求正规化函数把裸 I 和裸 SCC 都打印成同一个字符串，才能承认它们实现同一个一元行为？

**答案。** 若系统只实现消去式重写，裸 I 没有参数，裸 SCC 也未给 S 足够参数，二者都是这种规则下的不可再约项。逐点行为相同是把它们应用于任意参数后比较的主张；要在裸项层面加入外延等式，是额外设计，不能假装基础归约器已经完成。

### 练习 6：U 不是逐点非且

令 D 为两个元素，f 只在第一个元素为真，g 只在第二个为真。$`Ufg`$ 是真还是假？若把 g 改成 f 呢？

**答案。** 第一种为真，因为没有元素使二者同时为真；第二种为假，因为第一个元素就是反例。U 返回整个域上的判断，而不是返回一张逐点非且的真值列表。

### 练习 7：寻找量化域的隐藏条件

若个体域为空，$`a\mid^{x}a`$ 还能无条件表示 $`\neg a`$ 吗？

**答案。** 不能。在通常空域语义下，左侧全称量化恒真；若 a 为真，右侧为假。这是为何本篇把第 306 页相关重写放在非空域背景下理解，有限实验也显式拒绝把空域测试当作原式的普通实例。

### 练习 8：有限测试与一般证明

若对一千个项都验证了括号抽象正确，可否宣布它对全部项正确？怎样补上缺口？

**答案。** 不可。有限测试可能错过另一个形状或更深的项。一般结论由三种构造情况的结构归纳证明获得；测试用于确认实现遵守规则。还须检查具体代码的变量判定、树构造和重写位置是否与证明一致。

### 练习 9：存在见证取决于模型

第 8 节命题在全部布尔谓词域上为什么为真？若谓词域只有恒真谓词且个体域非空，结果怎样？

**答案。** 全部谓词域包含恒假谓词，它与任意 f 不相容。限制后的域只有一个恒真候选，与恒真 f 在每个个体上都同时为真，所以存在量词失败。无变量编码可以同时表示这两种模型下的同一句子，不替模型选择真值。

### 练习 10：删除一个看似多余的参数

设 $`\Omega=DD`$，$`D=SII`$。为什么正常序计算 $`Ca\Omega`$ 可得到 a，却不能据此说 $`\Omega`$ 有正规形？

**答案。** C 的规则可以直接丢掉第二个参数，不需要先计算它。整个项的正规化不要求每个子项都能正规化。这也提示，使用宿主语言急切求值直接调用高阶函数，可能展示出与符号正常序不同的行为。
