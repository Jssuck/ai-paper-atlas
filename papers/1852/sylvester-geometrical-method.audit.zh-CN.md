# Sylvester 1852 数学与原刊字形审计

本审计覆盖原刊 366–369 页的两个几何证明、比例分角线公式、参数域及圆弦例子；De Morgan 435–438 页与 Drach 479 页只作有界回应核查。结论是：原来的内部角平分线定理成立，两个几何论证都可补足；负参数必须说明射线方向，368 页特殊公式存在可辨字形与数学关系不一致，原文关于每个给定角差都存在解的说法也不能照字面普遍使用。本文不把数学重构当成原刊原话，不推断不一致由作者、排字还是扫描造成。

## 2 原刊字形与数学校核必须分列

### 2.1 第 366 页字母

Smith 证明末段扫描可辨出类似 `FBA` 与 `FB` 的字形；但前文定义、图中点位及比较三角形要求相应位置为 $`EBA`$ 与 $`EB`$。可以用数学意义确定教学重构应比较 $`AD`$ 和 $`BE`$，不能据此断言历史上究竟哪个环节造成字形差异。引用原文时保留原字形并作注；重写证明时明说采用一致的点号。

### 2.2 第 368 页特殊公式

扫描中两个特殊式右端均可辨为 $`1`$。第二式分子呈现 $`(3\alpha-\beta)/2`$，不是清楚排出的 $`3(\alpha-\beta)/2`$。依据 367 页通式计算，一致的数学形式应为

```math
n=\tfrac12:\quad
\frac{\tan(3(\alpha+\beta)/2)}{\tan((\alpha+\beta)/2)}=-1,
\qquad
n=-\tfrac12:\quad
\frac{\tan(3(\alpha-\beta)/2)}{\tan((\alpha-\beta)/2)}=-1.
```

原文紧接着给的 $`\alpha+\beta=90^\circ`$ 与 $`\alpha-\beta=\pm90^\circ`$ 也支持这一校核：$`\tan135^\circ/\tan45^\circ=-1`$。这些是**从通式导出的校核式**，不是声称发现了正式勘误；不应静默替换后再称为逐字转录。

### 2.3 第 369 页圆弦公式

原印为 $`x^2+ax=b^2`$；逆向情形是 $`a(a+x)=b^2`$。逆式右端不是零。两式的变量角色不同，后文第 7 节说明其几何意义。

## 3 Smith 证明的完整检查

只在本节和下一节令 $`p=A/2,q=B/2`$，以免和边长混淆。假设 $`p\gt q`$ 且 $`AD=BE=L`$，两者均为内部角平分线，因此 $`0\lt q\lt p\lt \pi/2`$。

1. 到底边的垂距为 $`L\sin p`$ 和 $`L\sin q`$，故 $`D`$ 高于 $`E`$。
2. 作 $`DF\parallel EG\parallel AB`$，其中 $`F\in AC,G\in BC`$。平行截线随高度增大而缩短，故 $`DF\lt EG`$。
3. 由角平分与平行线内错角，$`AF=DF`$、$`BG=EG`$。
4. 两等腰三角形的顶角为 $`\pi-2p`$、$`\pi-2q`$。前者腰短且顶角小；用欧氏三角形比较可得前者底边短。等价的教学计算是

```math
AD=2DF\cos p\lt 2EG\cos q=BE.
```

这与保留的等长假设矛盾。交换两底角排除另一方向，故 $`A=B`$。

这里的高度论证已经使用等长假设，因此这份展开稿本身是归谬证明，不能仅因结尾出现“不等角导致不等长”就改称为一份完全未用归谬的直接逆否证明。De Morgan 对逆否转换的分类另见第 8 节。三角函数计算是对原刊所引 Euclid 比较法的教学补全，并非作者印出的公式。

## 4 Sylvester 第二证明的完整补足

本节仍只证明 $`n=2`$ 的原问题。作者声称其证明可作比例分角推广，但以下内心面积计算不能不加改变地用于一般 $`n`$。

### 4.1 证明原文省略的比值

记边长 $`a_0=BC,b_0=CA,c=AB`$，周长 $`P=a_0+b_0+c`$，内心 $`H=AD\cap BE`$，内切圆半径为 $`r`$。由面积分解 $`[ABC]=rP/2`$。以 $`BC`$ 为底的高是 $`rP/a_0`$，而 $`H`$ 到此底的距离为 $`r`$；由于 $`H\in AD`$，

```math
\frac{HD}{AD}=\frac{a_0}{P},\qquad
\frac{HE}{BE}=\frac{b_0}{P}.
```

于是

```math
\frac{AH}{BH}
=\frac{AD}{BE}\frac{b_0+c}{a_0+c}.
```

角平分线定理又给出

```math
CE=\frac{a_0b_0}{a_0+c},\qquad
CD=\frac{a_0b_0}{b_0+c}.
```

所以在 $`AD=BE`$ 的假设下，确有原文的 $`AH/BH=CE/CD`$。这个比值并非任意三角形、任意两条交叉线段都自动满足的恒等式。

### 4.2 角关系与点的顺序

假设 $`p\gt q`$。三角形 $`ABH`$ 给出 $`AH\lt BH`$，故由上式 $`CE\lt CD`$。第一证明中的高度关系仍成立。设 $`K=DE\cap AB`$，按原图顺序有 $`K,A,B`$ 与 $`K,E,D`$。

点序也可明确核查。取 $`A=(0,0),B=(c,0)`$，则 $`D=L(\cos p,\sin p)`$、$`E=(c-L\cos q,L\sin q)`$。由于 $`H`$ 位于两内部角平分线中间，三角形 $`ABH`$ 给出

```math
c=AH\cos p+BH\cos q\lt L(\cos p+\cos q),
\qquad
BH=\frac{c\sin p}{\sin(p+q)}\lt L.
```

第一式使 $`D-E`$ 的横坐标为正；$`p\gt q`$ 使纵坐标为正。第二式使直线 $`DE`$ 与横轴的交点在 $`A`$ 左方。因此 $`k=\angle AKD\gt 0`$，所用点序成立。

在三角形 $`CED`$ 中，$`CE\lt CD`$ 给出 $`\angle CED\gt \angle CDE`$。按上述点序，两角分别为 $`2p-k`$ 与 $`2q+k`$，所以

```math
t:=p-k\gt q,
\qquad p\gt q+k.
```

特别地 $`t,q,p,q+k`$ 都在 $`(0,\pi/2)`$，以下正弦比较才合法。

### 4.3 补足“垂距关系容易证明为不可能”

原文得到从 $`A`$ 到 $`DE`$ 的垂距大于从 $`E`$ 到 $`AB`$ 的垂距，但没有展开最后的矛盾。**任意两条相交直线上的这类垂距并无固定大小关系**，不能只凭图形把它判为不可能。下面给出保留全部条件的补足。

在三角形 $`KAD`$ 和 $`KBE`$ 中，$`AD=BE`$ 且 $`K`$ 处角同为 $`k`$。由正弦定理，

```math
\frac{KA}{KE}=\frac{\sin t}{\sin q}\gt 1,
\qquad
\frac{KD}{KB}=\frac{\sin p}{\sin(q+k)}\gt 1.
```

另一方面，对三角形 $`KBD`$ 的横截线 $`A,E,C`$ 用 Menelaus 定理：

```math
\frac{KA}{AB}\frac{BC}{CD}\frac{DE}{EK}=1.
```

$`C`$ 在 $`BD`$ 越过 $`D`$ 的延长线上，故 $`BC/CD\gt 1`$。于是 $`KA\,DE\lt AB\,KE`$。两侧加上 $`KA\,KE`$，利用 $`KD=KE+DE`$ 与 $`KB=KA+AB`$，得到

```math
KA\cdot KD\lt KB\cdot KE.
```

这与前述两个比值都大于 1 矛盾。第二证明因此可以严格完成；这里的面积计算、Menelaus 次序引理和正弦比较是**本次补足**，不是宣称恢复了作者未刊出的唯一原始证明。

## 5 比例分角模型和精确定义域

### 5.1 必须先固定射线和符号

令 $`A\gt 0,B\gt 0,A+B\lt \pi,c\gt 0,n\ne0`$。指定从 $`A`$ 出发的单位方向角为 $`A/n`$，从 $`B`$ 出发的方向角为 $`\pi-B/n`$。这里若允许任意实参数，角是带明确分支的实数角；较小 $`|n|`$ 可产生大于一周或反向的转角。

与对边所在直线相交的带符号参数为

```math
t_A=\frac{c\sin B}{\sin(B+A/n)},\qquad
t_B=\frac{c\sin A}{\sin(A+B/n)}.
```

由两条直线的交点方程即可得到这些公式。分母须非零；分母为零时不得把交叉乘积方程的形式解当成有限线段。两个分子均严格正，所以正向射线的**精确条件**为两个分母均正。无向整直线模型的长度则是 $`|t_A|,|t_B|`$，它多出 $`t_A=-t_B`$ 分支。

- $`n\gt 1`$：指定射线在底角内部，交点位于对边边段，两个分母自动正。
- $`n=1`$：两交点都为 $`C`$，等长恰为 $`AC=BC`$。
- $`n=-v\lt -1`$：两分母的角都在 $`(-\pi,\pi)`$，故正向射线条件精确化为 $`A/v\lt B\lt vA`$；交点在底边外侧的相应延长线上。
- $`n=-1`$：正向条件同时要求 $`B\gt A`$ 与 $`A\gt B`$，所以空域；等腰时两条相交方程的分母为零。
- $`0\lt |n|\lt 1`$：不能把正弦号简化成单一线性区间，须保留两个正弦分母的符号及明确的转角分支。
- $`n=0`$：不定义，不能包含在“全部实参数”的定理中。

### 5.2 从长度等式到无除法形式

令 $`A=2n\alpha,B=2n\beta`$，$`s=\alpha+\beta,d=\alpha-\beta`$。在交点有限时，$`t_A=t_B`$ 等价于

```math
F=\sin(2n\alpha+2\beta)\sin(2n\beta)
 -\sin(2n\beta+2\alpha)\sin(2n\alpha)=0.
```

有两种方便的等价展开：

```math
F=-\sin s\sin((2n-1)d)-\sin((2n+1)s)\sin d,
```

以及

```math
F=2\bigl[
\cos((n+1)s)\sin((n-1)d)\sin(ns)\cos(nd)
-\sin((n+1)s)\cos((n-1)d)\cos(ns)\sin(nd)
\bigr].
```

只有在所除因子非零时，第二式才化为原刊的正切商

```math
\frac{\tan((n-1)d)}{\tan(nd)}
=\frac{\tan((n+1)s)}{\tan(ns)}.
```

$`d=0`$ 是被该商式除掉的等腰情形，须回到 $`F`$；但 $`F=0`$ 仍不能替代交点存在及方向检查。

### 5.3 正参数的无不等角解证明

对 $`n\gt 1,d\ne0`$，

```math
0\lt |d|\lt s\lt \frac{\pi}{2n}.
```

因此左侧正切商在 $`(0,1)`$。右侧有三种情形：

1. $`(n+1)s\lt \pi/2`$ 时，它大于 1。
2. $`\pi/2\lt (n+1)s\lt \pi`$ 时，它为负；上界来自 $`n\gt 1`$ 与上述三角形角域。
3. $`(n+1)s=\pi/2`$ 时，商式有极点，但 $`F`$ 展开中的第二项非零，第一项为零，故仍非解。

所以不存在不等角解。$`n=1`$ 另按几何直接处理即可。

### 5.4 负参数正向域的完整比较

对 $`n=-v\lt -1`$，改用正角 $`u=A/(2v),w=B/(2v)`$，记 $`S=u+w,D=u-w`$。相应商式为

```math
\frac{\tan((v+1)D)}{\tan(vD)}
=\frac{\tan((v-1)S)}{\tan(vS)}.
```

若 $`D\ne0`$，由正向条件 $`A/v\lt B\lt vA`$ 得到

```math
\frac{|D|}{S}\lt \frac{v-1}{v+1},
\qquad
(v+1)|D|\lt (v-1)S\lt vS\lt \frac\pi2.
```

所以左侧严格大于 1，右侧严格在 0 与 1 之间，矛盾。这个版本避免了负参数分支中的隐含正切极点；若放弃正向条件，则应另行分区，而不能直接重复这组不等式。

### 5.5 遗漏方向约束的精确反例

取 $`n=-2,c=1,A=96^\circ,B=24^\circ`$，第三角为 $`60^\circ`$，三角形不等腰。此时

```math
t_A=\frac{\sin24^\circ}{\sin(24^\circ-48^\circ)}=-1,
\qquad
t_B=\frac{\sin96^\circ}{\sin(96^\circ-12^\circ)}=1.
```

因为 $`\sin96^\circ=\sin84^\circ`$，这是精确等式，不是数值近似。故无向长度相等，但 $`D`$ 在指定射线背后。它反驳的是把原推广无条件解释成“所有延长直线上的无向等长”，不反驳内部角平分线定理或前述正向射线定理。

## 6 小参数例子和原文过强的存在断言

对 $`n=1/2`$，$`\alpha=A,\beta=B`$，所以 $`0\lt s\lt \pi`$、$`|d|\lt s`$。无除法形式化为

```math
F=-\sin(2s)\sin d.
```

非等腰时 $`d\ne0`$，因此唯一可用角和是 $`s=\pi/2`$。取 $`A=30^\circ,B=60^\circ,c=1`$ 即得 $`t_A=t_B=1`$，交点在对边延长线上。

对 $`n=-1/2`$，$`\alpha=-A,\beta=-B`$，$`-\pi\lt s\lt 0`$，且

```math
F=\sin s\sin(2d).
```

非等腰解要求 $`d=\pm\pi/2`$。取 $`A=15^\circ,B=105^\circ,c=1`$，得到 $`t_A=t_B=1`$。但此时指定的 $`\phi=B/n=-210^\circ`$ 是有明确分支的转角；若只准使用大小小于 $`180^\circ`$ 的普通外角，这个例子不在该较小模型中。

**368 页“任给角差总能找到角和”的话不能照字面普遍成立。** 在 $`n=1/2`$ 时，若固定 $`|d|\ge90^\circ`$，则唯一候选 $`s=90^\circ`$ 不满足 $`s\gt |d|`$；没有非退化解。在 $`n=-1/2`$ 时，除 $`d=0,\pm90^\circ`$ 外更是没有任何角和可使 $`F=0`$。例如固定 $`d=30^\circ`$ 就已经排除了所有解。这是解析反例，不依赖有限网格采样。

故应把原文的存在说法标成条件不足的断言；其根数询问和倒数区间脚注没有完成可容许根的统一分类。不能以两个有效例子证明每个小参数、每个角差都可行，也不能把周期函数的所有代数零点都算作不同几何配置。

关于轨迹，取底边端点为 $`(0,0),(c,0)`$、顶点为 $`(X,Y)`$ 且 $`Y\gt 0`$，则相等底角给出 $`X=c/2`$，另外两个条件给出

```math
A+B=90^\circ:\quad (X-c/2)^2+Y^2=c^2/4,
\qquad
|A-B|=90^\circ:\quad (X-c/2)^2-Y^2=c^2/4.
```

可分别令 $`\cos(A+B)`$ 与 $`\cos(A-B)`$ 为零推得。后者渐近线斜率为 $`\pm1`$，因此互相垂直，确为等边双曲线。原文脚注所说整条曲线仍需按非退化、有限交点和射线方向裁剪，不能整体等同于可容许点集。尤其 $`n=-1/2,A=B`$ 时 $`t_A=t_B=-c`$，等腰直线分支全部不在正向射线域；$`n=1/2,A=B`$ 时，正向分支仅有 $`0\lt A\lt 60^\circ`$，$`A=60^\circ`$ 交点方程退化，$`60^\circ\lt A\lt 90^\circ`$ 在反向。

368 页另一脚注说，当参数的绝对值位于 $`1/(2k+1)`$ 与 $`1/(2k-1)`$ 之间，相关根数的上界至少为正整数 $`k`$。这里统一使用 $`k`$ 表示原脚注的整数记号；“上界至少为”不是“每个角差至少有”。原文没有明确完成端点和给定角差的适用域分析。鉴于上述存在断言的反例，本审计只核对其印出内容，不把脚注升级为完整可容许根计数定理。

## 7 圆弦模型和逆式

令 $`M`$ 是弧 $`UV`$ 的中点，所以 $`MU=MV=b`$。从 $`M`$ 发出的弦在 $`P`$ 穿过弦 $`UV`$，再于 $`Q`$ 交圆，点序为 $`M,P,Q`$。弦 $`UV`$ 的端点不可与这些交点混同。记 $`MP=x\gt 0,PQ=a\gt 0`$。

由圆周角与 $`MU=MV`$，三角形 $`MUP`$ 与 $`MQU`$ 相似，对应为 $`M\leftrightarrow M,U\leftrightarrow Q,P\leftrightarrow U`$。因此

```math
\frac{MU}{MQ}=\frac{MP}{MU},
\qquad MP\cdot MQ=MU^2,
\qquad x(x+a)=b^2.
```

在临界的端点/共线情形，应取极限或另行处理退化三角形；这里讨论远近两段严格为正的普通配置。

二次方程的两个根为

```math
x_+=\frac{-a+\sqrt{a^2+4b^2}}2\gt 0,
\qquad
x_-=\frac{-a-\sqrt{a^2+4b^2}}2\lt 0.
```

它有两个实根而非“没有实根”；只有一个正长度代数候选。对于题设中已经存在的弦，该候选就是其近段。若反过来任意给定数字并要求构造，还须检查下述固定圆弧的范围。不同弦若远段同为 $`a`$，近段只能同为 $`x_+`$。也可不用求根：$`x(x+a)=y(y+a)`$ 给出 $`(x-y)(x+y+a)=0`$，而第二因子严格正。

逆向问题把近段给定为 $`a`$、远段记为未知 $`x`$，因此

```math
a(a+x)=b^2,
\qquad x=\frac{b^2}{a}-a.
```

$`0\lt a\lt b`$ 保证远段的代数值正；$`a=b`$ 远段为零，$`a\gt b`$ 则不符合所选点序。不过，**正性不单独保证固定圆弧中的构造存在**。设 $`h=\mathrm{dist}(M,UV)\gt 0`$，穿过弦段 $`UV`$ 的近段范围实际是 $`h\le MP\lt b`$。所以逆向固定近段的完整范围为 $`h\le a\lt b`$，正向固定远段则需 $`0\lt a\le b^2/h-h`$。圆弧中点轴线给出下端近段 $`h`$，靠近弧端点给出上端极限 $`b`$。原定理从已存在的弦出发，不需另证任意数字的可构造性；代码或教学示例若反过来构造则必须保留这一层检查。一次或二次之别来自哪个量给定、哪个量未知，并不是两套无关的几何关系。

De Morgan 所提的逆否方向也可清楚表达：对任意两条弦，远段函数为 $`r(x)=b^2/x-x`$。若 $`x_1\gt x_2\gt 0`$，则 $`b^2/x_1\lt b^2/x_2`$，从而 $`r(x_1)\lt r(x_2)`$。这证明近段不等导致远段不等。这里的函数式是现代解释；De Morgan 原文只给出其逆否论证的意图，没有印出这个计算。

## 8 同时代回应和证明方法结论

De Morgan 435 页将直接肯定、直接逆否、正面归谬、逆否归谬区分开；436–437 页论证通常所谓间接步骤有时只是从逆否命题返回肯定命题的逻辑转换。437 页明确把近段不等推出远段不等作为圆弦命题的逆否方向，并承认 Sylvester 可能不接受其直接性标准。438 页继续说明该分歧，并非宣布推翻几何结论。应按其经典逻辑语境读“同义”；不能把逆否等价无条件推广到所有现代非经典逻辑系统。

Drach 479 页的表达可重写为 $`a+b i+f-c i=(a+f)+(b-c)i`$；$`b=c`$ 时虚部消失。这只是类比性评论。它没有给出将任意几何的不等假设统一映射为这些系数的证明，也没有定义或穷尽全部可能的证明，因此既非正式勘误，也不能验证 Sylvester 的普遍方法判据。

原文 368 页提出“某类不可容许根情形使间接几何证明必要”，369 页进一步提出肯定性命题何时才需要这种方法。两者都是方法论猜想。一个解析表示需要排除某根，不足以证明所有纯几何推导都必须使用归谬。若不规定公理、可用引理、辅助构造与直接证明的语法，这个跨越不能仅凭例题补足。比如在 $`x\gt 0`$ 的域内，$`x=1`$ 与 $`x^2=1`$ 语义等价，却只有后一个表示显出额外负根；这是关于表示依赖的现代反思，不冒充原文或某套形式系统中的完整不可能性定理。

## 9 审计边界

本次已逐项核查主要公式、两个几何链条及其缺省条件，给出精确反例和无需除法的校核式；同时检查了主文的相似三角形对应及代数展开。没有把数值实验当作普遍定理证明，也没有声称完成全部 $`|n|\lt 1`$ 的根数分类、所有历史版本对勘或后世直接证明史。原文发现、教学补全、可辨字形和现代批判应继续分层保留。
