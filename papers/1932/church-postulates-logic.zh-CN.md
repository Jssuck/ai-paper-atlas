# Church 1932：函数、替换与一场未完成的逻辑基础实验

## AI 前史中的 1932 年节点回填

**计算的起点，可以不是一台机器，而是一条替换规则：把函数中的参数换成给定表达式，再继续处理得到的表达式。** Church 这篇论文把函数应用、函数抽象和符号变换放到形式系统的中心；它也提醒我们，能构造表达式、能进行计算、能把表达式当作有意义的命题，以及能建立一致的逻辑，是四件不同的事。

本文不把 1932 年论文包装成已经完成的现代 λ 演算教材。原文的主要目标是给逻辑与数学提供基础，既有函数表达式，也有量化、存在、否定、合取、描述和抽象的逻辑常项；它有五条操作规则和三十七条形式公设。后来留下来的计算核心，与这套完整逻辑的命运不同。特别重要的是，原文的函数收缩规则不允许直接抹掉一个根本没有被使用的参数。这个条件若被略去，若干现代教材里最熟悉的例子就会被错误地安放到 1932 年。

阅读目标是能亲手回答：自由变量怎样被意外捕获？为什么“函数作用于自己”在语法上合法？为什么有限运行没有结果不等于不可计算？原文最后那个长达数页的定理到底想把哪种推理改写成闭公式？以及为何一个数学基础方案失败，不代表它包含的每一种计算装置都失败？

## 1 这篇论文要解决的究竟是什么

### 1.1 一个公式为什么还依赖外面的说明

**原文，第 346–347 页。** Church 从类似分配律的表达式开始：写下 $`a(b+c)=ab+ac`$，并没有把所要表达的命题完全确定下来。变量可以取实数、复数，也可能各有不同范围。如果这些条件只在自然语言里口头补充，符号串本身就没有承担全部表达任务。

这不是说分配律神秘，也不是说数学不许使用字母，而是关于“一个形式命题是否必须把适用范围写在自身之内”的设计选择。我们可以把范围条件和量化显式写出，例如在现代记法中使用

```math
\forall a\forall b\forall c\bigl((R(a)\land R(b)\land R(c))\to a(b+c)=ab+ac\bigr).
```

此式只是帮助说明目的的现代一阶写法；原文使用自己的受限蕴涵记号，不能把两者未经解释就逐字符等同。其关键变化是：每一个原先需要外部交代的变量，都受到公式内部结构的约束。

Church 想避免把自由变量直接作为最终命题的一部分，但他的**语法仍然允许自由变量**。表达式 $`x`$、$`f x`$ 和中间开放表达式必须存在，才能解释替换和抽象。原文第 352 页说最终可证明的公式将没有自由变量；第 357 页又为了研究“作为假设的后承”，明确容许临时加入含自由变量的公式。若把开头读成“该语言没有自由变量”，后面的整个证明就无法理解。

### 1.2 避开悖论的策略：让某些应用不表达命题

原文不想简单照搬类型论或集合论的限制方案，尝试给命题函数保留有限制的定义范围。对某些输入，$`F(X)`$ 可以既不代表真命题，也不代表假命题，而是没有所期待的意义。这里的“未定义”是关于原文预期解释的说明，不是后来编程语言里的异常对象，更不是自动指定了一个带第三个真值的完整语义模型。

为什么这似乎有吸引力？设想“某对象不适用于自身”一类自指表达式。经典两值的直观推理容易在“真”和“假”之间产生冲突。如果允许这个具体应用不表达一个命题，就不能未经检查套用所有只对命题有效的真值规则。

但“我打算把危险应用理解为未定义”不是一致性证明。必须查看全部公设和规则会不会重新强迫它具有真或假，或者通过另一条路径推出矛盾。原文第 348 页坦言，系统是否足以发展数学、是否完全无矛盾，都尚未解决；对 Burali-Forti 型问题也保留开放态度。它提出的是一个需要通过推导检验的研究方案。

### 1.3 为什么它不是换了名字的直觉主义

原文第 348 页专门作了区分：两种方案限制排中律的方式不同；本系统保留双重否定方面的规则，却不能普遍保留“若一个陈述导出矛盾，就断言它为假”的使用方式。Church 还提出一种关于存在命题可得见证的预期性质，但措辞不是已经完成全部证明的现代元定理。

因此，本文不从“没有无条件排中律”推出“它就是直觉主义”，也不画一个自创的三值真值表声称复现原文。这两个捷径都会把需要检验的逻辑设计偷换成另一种已经熟悉的系统。

## 2 先搭出符号机器，再谈解释

### 2.1 元语言与对象语言不是同一层

原文第 349–351 页强调：公设系统中的符号可以先当作没有指定意义的对象来处理；证明必须凭明确规则，而不能临时诉诸“这个符号本来就应该是什么意思”。可是定义规则又必须使用我们已理解的语言，例如“出现”“替换”“同一个符号”“由有限次组合得到”。

这不意味着形式化失败，而是标出工作的层次。用 Python 写一个表达式检查器时，检查器内部的数据是对象语言；解释 Python 程序为什么忠实实现规则的论证是在元语言里。即使再给 Python 一个形式语义，说明和信任的边界也只是向外移动，不能以一句“全都符号化了”消失。

原文假设我们能识别字符串、复制子公式、区别相同符号的不同出现、逐次替换，并作关于有限构造的归纳。与 Gödel 的算术化相接的地方就在这里：这些原本属于说明层的有限符号操作，可以进一步被编码成可研究的数学对象。但两篇论文的任务不同，Church 1932 并未在这里重做不完备性证明。

### 2.2 归纳语法与树

**原文，第 351–353 页。** 基本成分包括变量，应用 $`\{M\}(N)`$，抽象 $`\lambda x[M]`$，以及逻辑常项 $`\Pi,\Sigma,\&,\sim,\iota,A`$。所有良构公式由有限次应用与抽象构成。

**教学重构。** 用现代左结合记法写成：

```math
t ::= x\mid c\mid(t\ t)\mid\lambda x.t,
\qquad c\in\{\Pi,\Sigma,\&,\sim,\iota,A\}.
```

这里 $`::=`$ 表示构造规则，不是论文中的一个逻辑等式。表达式是有限树：变量或常项是叶子；应用节点有函数和参数两个孩子；抽象节点保存一个绑定名称与一个函数体。有限树可以表示会无限计算的过程，树的有限性不等于执行的有限性。

例如 $`(\lambda x.x)\,y`$ 的根是应用，左支是一个抽象，右支是自由变量 $`y`$。而 $`\lambda x.(x\,y)`$ 的根是抽象。两者使用近似相同的字符，却是不同树，所以括号和作用域不能当作排版细节。

约定应用左结合：$`f\,a\,b=(f\,a)\,b`$。抽象体尽量向右延伸：$`\lambda x.x\,y=\lambda x.(x\,y)`$。这些是本文的现代阅读约定；原文第 354 页采用自己的省括号和点号规则，其中省去方括号的范围规则并不完全相同。阅读原页时必须回到原书约定，不能机械套用本文的习惯。

### 2.3 一个输入也足以表达多个输入

原文第 352 页明确归功于 Schönfinkel：二元函数可改写成返回函数的一元函数。现代例子是

```math
\mathrm{add}=\lambda a.\lambda b.(a+b).
```

先把 $`a`$ 换成 2，得到“等待一个 $`b`$，然后加上 2”的函数；再给它 3，才得到 5。这里加号和整数只是帮助理解的外部示意，尚未说明如何在纯 λ 语法中编码数。

从树上看，$`\mathrm{add}\,2\,3`$ 的两次应用绝不等于一次把有序对传入的操作。两种接口能相互编译，但表达式和步骤数不同。本文后面的数编码才完全消去作为内建算术操作的加号。

## 3 最容易被现代知识覆盖掉的历史细节

### 3.1 语法允许的抽象，不一定有现代 β 行为

今天常写函数收缩规则：

```math
(\lambda x.M)\,N\longrightarrow_\beta M[x:=N].
```

这允许 $`x`$ 在 $`M`$ 中不出现。例如 $`(\lambda x.y)\,N\to y`$，无论 $`N`$ 怎样，整个参数被扔掉了。

但原文第 355 页 Rule II 明写：$`x`$ 必须在 $`M`$ 中出现，而且 $`M`$ 中的绑定变量不能是 $`x`$，也不能与 $`N`$ 中的自由变量重名。由这两个条件合起来，相关出现是可替换的自由出现。Rule III 的反向扩张也带同样限制。本文把这称为**非擦除收缩限制**，只是便于区分的教学名称。

因此，$`\lambda x.y`$ 按原文归纳语法仍良构，却不能直接用 Rule II 得到 $`(\lambda x.y)N\to y`$。不要把“良构”和“可以做这一收缩”混同。也不要说本文的受限模式已经模拟了完整历史系统：它只在现代捕获避免实现上加入这一侧条件，未实现全部逻辑公设和证明判定。

### 3.2 三种规则与两种推理

原文的五条操作规则，按作用分成两层：

1. Rule I：在规定条件下改绑定变量的名字。
2. Rule II：满足侧条件的函数应用收缩。
3. Rule III：同样条件下反向扩张。
4. Rule IV：由 $`F(A)`$ 得 $`\Sigma(F)`$。
5. Rule V：由 $`\Pi(F,G)`$ 与 $`F(A)`$ 得 $`G(A)`$。

前三条服务于表达式的变换；后两条承担逻辑推理。原文称经前三条得到的变换为 conversion。它是可以向两个方向转换的关系，不是只向前执行的求值策略。

同时，原文把这些规则写为“若 $`J`$ 已可断言，则替换其中某个特定出现后仍可断言”，而不是现代教科书先独立定义一个任意项上的操作语义。本文的解释器抽出可操作部分，让读者观察表达式变化；这是一种有意缩小的教学重构。

### 3.3 一个能证明的自由变量不变式

对于现代捕获避免替换，若 $`x\in\mathrm{FV}(M)`$，则

```math
\mathrm{FV}(M[x:=N])
=(\mathrm{FV}(M)\setminus\{x\})\cup\mathrm{FV}(N).
```

收缩前，应用项的自由变量也正是右侧这个集合，因此**非擦除 β 收缩保持自由变量集合**。绑定变量改名不改变集合，反向扩张也不改变。这里集合等式不是只说“不会增加奇怪变量”，而是连作为参数出现的自由变量也不会被凭空删除。

如果移去 $`x\in\mathrm{FV}(M)`$ 条件，反例立刻出现：$`(\lambda x.y)\,z`$ 的自由变量为 $`\{y,z\}`$，现代 β 收缩后 $`y`$ 的集合只有 $`\{y\}`$。

这个差别影响后面的元证明。原文第 358 页在定理 I 的零步情形使用“由含 $`x`$ 的 $`M`$ 经 conversion 得到的 $`N`$ 仍含 $`x`$”。现代允许擦除的 β 规则下，这句话不能直接照搬。它不是历史小注，而是证明依赖的一部分。

## 4 替换必须尊重绑定关系

### 4.1 自由变量的递归定义

用现代树语法定义：

```math
\mathrm{FV}(x)=\{x\},\quad \mathrm{FV}(c)=\varnothing,
```

```math
\mathrm{FV}(M\,N)=\mathrm{FV}(M)\cup\mathrm{FV}(N),\qquad
\mathrm{FV}(\lambda x.M)=\mathrm{FV}(M)\setminus\{x\}.
```

一个名字可以在同一个大表达式里同时有自由出现和绑定出现。例如 $`x\,(\lambda x.x)`$ 的第一个 $`x`$ 是自由的，第二、第三个字符位置属于绑定结构。程序若只收集“出现过的字母”，就会丢失关键信息。

从作用域看，$`\lambda x.\lambda y.x`$ 的函数体引用外层参数，而 $`\lambda x.\lambda y.y`$ 引用内层参数。改名字之后，前者可写成 $`\lambda a.\lambda b.a`$，却不能写成 $`\lambda a.\lambda b.b`$。相同的字符数量或相同的绑定变量集合都不足以判断函数结构相同。

### 4.2 捕获反例逐步做

考虑

```math
(\lambda x.\lambda y.x)\,y.
```

如果把体内所有字符 $`x`$ 直接替换为 $`y`$，会得到 $`\lambda y.y`$。这错误地把输入中原本自由的 $`y`$ 绑住了。正确过程先改名：

```math
\lambda x.\lambda y.x\equiv_\alpha\lambda x.\lambda z.x,
```

```math
(\lambda x.\lambda z.x)\,y\longrightarrow_\beta\lambda z.y.
```

$`z`$ 要新鲜，不能与相关自由变量冲突。结果是一个返回外部 $`y`$ 的函数，而不是恒等函数。这里内层参数没有被使用，但外层被收缩的参数 $`x`$ 确实出现，所以这个具体收缩符合非擦除侧条件；不要因式子中含有一个常值函数就误判所有收缩都不历史兼容。

可以再用一个新参数 $`a`$ 检查两种结果在现代演算里的差异：错误结果 $`(\lambda y.y)a\to a`$；正确结果 $`(\lambda z.y)a\to y`$。这个第二步是现代擦除规则的示意，不能反过来声称原文 Rule II 也会做它。

### 4.3 捕获避免替换的递归配方

**教学重构。** 定义 $`M[x:=N]`$：

- 在叶子处，$`x`$ 换成 $`N`$，其他变量不变。
- 在应用处，分别进入左右两个子项。
- 遇到 $`\lambda x.P`$，停止：内层绑定遮蔽了要替换的外层名字。
- 遇到 $`\lambda y.P`$ 且 $`y\ne x`$，若 $`y\notin\mathrm{FV}(N)`$，可递归进入。
- 若 $`y\in\mathrm{FV}(N)`$，先把这个绑定及它控制的出现改成新鲜 $`z`$，再递归。

最后一条也可以在 $`x`$ 根本不自由出现于 $`P`$ 时跳过整个替换，避免无意义改名。选择哪一个新鲜名字不影响 α 等价类，但会影响打印出来的字符串，所以测试不该脆弱地要求某个特定字母。

怎样证明该配方终止？每次真正递归替换都进入有限树的严格子树；改名也是对有限树的扫描。怎样证明不捕获？关键是不把 $`N`$ 中的自由变量移到同名绑定之下；冲突时改用新鲜变量，恰好保证这一条件。完整证明可按树结构归纳，而不是靠跑过几个例子。

### 4.4 去掉名字的比较方式

为了独立检查 α 等价，附件把绑定引用换成到对应绑定者的距离，自由名字仍保留。这是后来的 de Bruijn 式结构比较思想，不是 1932 年的记号。

例如从最近一层绑定算距离 0：$`\lambda x.\lambda y.x`$ 对应两个抽象节点后引用距离 1；$`\lambda a.\lambda b.a`$ 相同；$`\lambda a.\lambda b.b`$ 引用距离 0，所以不同。开放项 $`\lambda x.y`$ 必须仍保留自由名字 $`y`$，不能把所有未绑定叶子统一涂成一种颜色。

这种比较建立的是有限语法对象的 α 等价判断，不是一般的 β 可转换判定器。能够忽略绑定名字的无关差异，不表示已经能判定所有程序是否计算相同结果。

## 5 从几次手算看见计算能力，也看见边界

### 5.1 恒等与复合

定义 $`I=\lambda x.x`$。于是 $`I\,a\to a`$。这看起来太简单，却已把“按照函数体指定的位置替换参数”完整表达出来。

再定义复合项

```math
B=\lambda f.\lambda g.\lambda x.f(gx).
```

逐步作用于三个表达式 $`F,G,A`$，必要时先把绑定变量改成不冲突的名字：

```math
B\,F\,G\,A
\to(\lambda g.\lambda x.F(gx))\,G\,A
\to(\lambda x.F(Gx))\,A
\to F(GA).
```

三次收缩对应三个参数的位置，不需要计算机内建一个“复合”指令。对有冲突的开放项，以上式子应理解为 α 改名后的等价结果，不能直接当作允许捕获的文字替换。

这些例子是教学构造，不是声称原文逐项列出了 $`I,B`$ 的现代定义。它们解释原文应用与抽象的机制。原文完整系统还有逻辑常项，不是这些组合子的一个简写列表。

### 5.2 自应用在语法上没有禁令

令

```math
\Delta=\lambda x.x\,x,\qquad\Omega=\Delta\,\Delta.
```

一次收缩给出

```math
(\lambda x.x\,x)\,\Delta\to\Delta\,\Delta=\Omega.
```

这里 $`x`$ 在函数体出现两次，所以并没有使用擦除。表达式有一个可收缩的子式，而收缩结果恰好与自身相同。解释器若用“新字符串等于旧字符串”判断没有可做的步骤，就会错把 $`\Omega`$ 标成正常形；应由“是否找到合法 redex”来判断。

对这个特定项，可以给出真正的非终止论证：$`\Delta`$ 内部没有 β redex，$`\Omega`$ 唯一可收缩位置在根；每次根收缩都返回同一项。因此不存在有限次收缩到正常形的序列。运行一百步只是显示这一模式；以上结构论证才排除了全部有限长度。

自应用也不等于矛盾。$`\Omega`$ 是计算项；若没有给它一个命题解释和相应推理规则，不能从“它返回自己”推出“任何命题都可证”。把不终止与逻辑不一致混为一谈，是阅读这段历史时最常见的类别错误之一。

### 5.3 顺序可以决定你能不能看到答案

**现代延伸。** 在允许擦除的现代 β 演算中，取

```math
T=(\lambda x.y)\,\Omega.
```

若先收缩外层，立刻得到 $`y`$。若先处理参数，就反复在 $`\Omega`$ 里打转。为避免与程序语言里的弱求值混淆，附件比较的是整棵项树上的最左最外和最左最内归约，允许进入抽象体；它不是逐字模拟某个具体语言的运行时。

这个例子不能拿来证明原文 Rule II 的策略性质，因为原规则恰好禁止外层擦除。受限模式中，外层不是合法 redex，仍能不断处理内层 $`\Omega`$。实验的目的正是把两种模式摆在一起，让历史条件可见。

在现代 λ 演算里，关于最左最外策略找到正常形、不同收缩路径能汇合的结论都有额外的数学证明，不能由这一例得出。本文不提供完整标准化或 Church–Rosser 定理证明，更不会把有限测试说成证明了它们。

### 5.4 数不是内建对象，而是重复操作的接口

**现代教学重构，不声称是 1932 正文的算术发展。** 定义

```math
\overline n=\lambda f.\lambda x.f^n(x).
```

$`f^0(x)=x`$，$`f^{n+1}(x)=f(f^n(x))`$。于是 $`\overline2=\lambda f.\lambda x.f(fx)`$。它不是十进制字符串“2”，而是一个“把给定操作做两遍”的行为接口。

定义

```math
\mathrm{PLUS}=\lambda m.\lambda n.\lambda f.\lambda x.mf(nfx),
```

```math
\mathrm{TIMES}=\lambda m.\lambda n.\lambda f.m(nf).
```

把 $`\mathrm{PLUS}\,\overline2\,\overline3`$ 作用到任意 $`f,x`$：内层 $`\overline3fx`$ 产生 $`f^3(x)`$，外层 $`\overline2f`$ 再作用两次，所以得到 $`f^2(f^3(x))=f^5(x)`$。抽象回去即与 $`\overline5`$ α 等价。

乘法中，$`\overline3f`$ 本身是一项“做三次 $`f`$”的操作，$`\overline2`$ 重复这一操作两遍，因而

```math
\mathrm{TIMES}\,\overline2\,\overline3
\longrightarrow_\beta^*\lambda f.\lambda x.f^6(x).
```

要把这个论证推广到所有自然数，可以分别对迭代次数作归纳。实验只检查若干具体输入，其结果不会替代这个一般性证明。

特别注意零：$`\overline0=\lambda f.\lambda x.x`$ 的外层绑定 $`f`$ 没有被使用。它语法上没有问题，但某些现代 β 算术计算会需要原文禁止的擦除步骤。因此不能用一个包含零的现代数编码测试集，声称已复现 1932 全部数学基础。数编码、归约规则和所讨论的数域必须一起说明。

## 6 逻辑常项为什么不是可有可无的装饰

### 6.1 Π 的“受限全称”用途

原文第 353 页把 $`\Pi(F,G)`$ 的预期含义解释为：在所有 $`F`$ 真正为真的输入上，$`G`$ 也为真。这与不加说明地写“对任意 $`x`$，$`F(x)\to G(x)`$”不同，因为后者容易把全部输入都当成已有命题意义的场合。

原文给它的关键用法是 Rule V：

```math
\frac{\Pi(F,G)\qquad F(A)}{G(A)}.
```

没有 $`F(A)`$，就不能仅凭 $`\Pi(F,G)`$ 断言这个输入上的命题关系已具备一切常规意义。把 Π 只译作现代材料蕴涵，会擦去系统试图管理定义范围的地方。

本文使用一个便于阅读的缩写：

```math
[M]\supset_x[N] :=\ \Pi(\lambda x.M,\lambda x.N).
```

这对应原文第 354 页的缩写，而不是普通材料蕴涵 $`M\to N`$。它把含 $`x`$ 的两个表达式分别变成函数，再陈述二者的受限关系。下标 $`x`$ 承担绑定作用，不能省掉之后假装公式意义不变。

### 6.2 Σ 给出见证方向

原文的 $`\Sigma(F)`$ 预期表示有某个输入使 $`F`$ 为真。Rule IV 是

```math
\frac{F(A)}{\Sigma(F)}.
```

从具体实例到存在断言，在直觉上很自然。但逆向不能随意选定任意一个 $`A`$，由 $`\Sigma(F)`$ 推出 $`F(A)`$。存在的见证不等于你手边每一个对象。

可以把 $`\Sigma x.M`$ 读作 $`\Sigma(\lambda x.M)`$。这一区别在扫描 OCR 中尤其危险：印刷 Σ 常被识别成 λ。定理 I 的关键假设是“$`\Sigma x.M`$ 可证”，不是“$`\lambda x.M`$ 可证”。前者是非空性的存在断言，后者只是抽象项，两者在论证中绝不能替换。

### 6.3 其余常项与三十七条公设

$`\&`$ 处理合取，$`\sim`$ 处理否定；$`\iota`$ 是描述性常项；$`A`$ 用于原文所谓相对于某关系的抽象。第 355 页再定义析取、材料蕴涵、函数等价、存在性等缩写，并用 $`K=A(Q)`$ 引入类的记法。

这里的 $`K`$ 是原文的类构造缩写，不是现代组合子教材中的常值组合子 $`\lambda x.\lambda y.x`$。同一个字母在不同文献里经常承担不同角色，不能看到 K 就自动联想后者。

本文不把三十七条复杂公设逐条转录为一份声称已形式核查的公理库。第 356–357 页的印刷数学公式需要逐项语法恢复；附带代码也不实现它们。本文把焦点放在前十三条支撑最后三项元定理的用途，以及替换规则的精确侧条件。公设总表存在且已经阅读，不等于代码已经验证完整公设系统。

## 7 论文最后的主工作：把假设推理变成闭公式

### 7.1 “由 M 可证 N”是在说什么

原文第 357 页定义：若把 $`M`$ 临时加为第三十八条形式公设，就能证明 $`N`$，则称 $`N`$ 可作为 $`M`$ 的后承而证明。这里 $`M,N`$ 可以含自由变量。临时开放的推理，怎样回到系统要求的闭式表达，正是第 358–366 页研究的问题。

为避免层次混乱，本文用 $`\vdash N`$ 表示在原公设系统中可证，用 $`M\vdash N`$ 表示加上这个假设后的可证。这个转写是元语言记号，原文并未把“可证”本身加入对象语言成为一个谓词。

### 7.2 定理 I 的两条出口

**原文，第 358 页；现代排版。** 设 $`x\in\mathrm{FV}(M)`$，$`\vdash\Sigma x.M`$，且 $`M\vdash N`$。那么：

- 如果 $`x\in\mathrm{FV}(N)`$，可以证明 $`[M]\supset_x N`$。
- 如果 $`x\notin\mathrm{FV}(N)`$，可以直接证明 $`N`$。

第二条为何不是“从任意假设都能证明任意后果”？因为存在前提要求 $`M`$ 不是一个无见证的虚空条件。用现代普通逻辑作类比：若确知有一个满足 $`M(x)`$ 的对象，又已证明对任何这样的对象都能推出不依赖于 $`x`$ 的 $`N`$，便能推出 $`N`$。如果没有存在性，可以在空的前提类别上得到空泛的条件关系，却不能得到无条件结论。

这只是语义直觉，不代替原系统证明；原系统不能无条件使用现代一阶逻辑的全部推理规则，所以 Church 花了多页把这个转换实现出来。

### 7.3 为什么归纳的“步数”不是字符串重写次数

原文把 IV 或 V 的使用算作证明步骤，I–III 的 conversion 不算在这项计数里。若某个中间结论后来被使用多次，先前证明步骤要按使用次数展开计算。直观地说，数的是展开后的证明树，而不是把共享子证明只存一次的图节点数。

为什么有用？Rule V 有两个前提。若最后一步是 V，把前提各自的证明树取出来，步数都严格小于整棵树，于是能对两个前提应用归纳假设。不能拿解释器输出的 β 步数替代这个量：那是在数完全不同的对象。

这个设计也提示自动证明工程：一个算法若说“对证明长度归纳”，先要交代证明表示是树还是共享图，哪些转换计费，重复使用是否重复计算。否则所谓长度下降可能只是纸面印象。

### 7.4 零步情形的完整主线

先看 $`N`$ 是从 $`M`$ 经 conversion 得到的情形。根据第 3 节的不变式，它仍含自由 $`x`$。需要得到 $`[M]\supset_x N`$。

原文第 358 页使用公设 1，把已知 $`\Sigma(\lambda x.M)`$ 转到可应用 Rule V 的形式，先推出

```math
\Pi(\lambda x.M,\lambda x.M),
```

亦即 $`[M]\supset_x M`$，再在右侧作 conversion 得到所需结果。用现代元语言概括其依赖是：

```math
\vdash\Sigma F\quad\Longrightarrow\quad\vdash\Pi(F,F),
\qquad F=\lambda x.M.
```

这条箭头描述通过公设 1 和操作规则得到的实例，不是把任意现代逻辑的自反律偷偷加入系统。原文逐行写出把 $`\Sigma F`$ 扩张成函数应用、使用公设、再收缩的细节，正是为了显示闭公式怎样承载看似容易的代入。

如果 $`N`$ 原本就是已可证公式，直接使用已有证明即可；核心困难是那些依赖新增假设而获得的行。把这一平凡支路说清楚，比把“零逻辑步骤”一概口述成“必从 M 转换而来”更适合现代证明树重构。

### 7.5 最后一步是 Rule V：先走一个可看清的情形

原文 Case 1 假设最后推理为

```math
\Pi(F,G),\quad F(x)\quad\Longrightarrow\quad G(x),
```

其中 $`F,G`$ 本身没有自由 $`x`$。归纳假设分别提供：

```math
\vdash\Pi(F,G),\qquad\vdash[M]\supset_x F(x).
```

为什么第一个前提不带 $`[M]\supset_x`$？因为它不再依赖自由 $`x`$，正好进入定理的第二条出口。不是作者随意丢掉假设，而是归纳条件决定了能采用哪个结论。

原文利用公设 3、$`\Sigma x.M`$ 和 conversion，得到一个允许把上述两项合起来的受限复合关系。设 $`H=\lambda x.M`$，结构可读作：若 $`H`$ 的真值输入都落入 $`F`$，且 $`F`$ 的真值输入都落入 $`G`$，则 $`H`$ 的真值输入都落入 $`G`$。在本次实例化下，结果是

```math
\vdash[M]\supset_x G(x).
```

原文第 358–359 页 A1–A14 通过抽象、应用、Rule V 和 conversion 完成这一点。这里提供的是那段证明的依赖重构，而不是声称仅凭集合包含的口头比喻就证明了它。尤其不能把“Π 与真值输入集的包含相像”升级成已构造了整个逻辑的集合模型。

### 7.6 为什么余下十五种情况不能一句“类似”带过

Rule IV 中函数 $`F`$ 和参数 $`A`$ 是否含 $`x`$ 有不同组合；Rule V 中 $`F,G,A`$ 各自是否含 $`x`$ 又产生更多情况，$`A`$ 恰为 $`x`$ 还需要单独处理。原文总共分十六种情形，而不是简单列八个布尔组合。

例如 Case 15 中 Rule V 的三个对象都不含自由 $`x`$，归纳后两个前提已经无条件可证，再用一次 V 就结束。Case 16 对 Rule IV 同理。它们很短，因其依赖结构简单。

相反，若 $`F`$ 含 $`x`$ 而结论 $`G(A)`$ 不含，必须从带参数的中间函数关系中消去依赖；若 $`G`$ 也含 $`x`$，就要把它包装为 $`\lambda x.G`$ 传给前面已经建立的情形。Case 10、11 等反复进行这类抽象化。公设 2–13 的安排，与这些变量依赖的搬运有密切关系。

下面把分支覆盖列全，方便读者回原页，而不把未展开的推导伪装成已完成的形式证明。“有/无”都指是否有自由 $`x`$；“一般有”在本表专指不单独按 $`A=x`$ 处理的分支。

另一个容易从现代教材偷渡的规则是 η。在 $`x\notin\mathrm{FV}(F)`$ 且允许 η 的系统中，可以讨论 $`\lambda x.Fx`$ 与 $`F`$ 的外延对应，但 1932 的 I–III 不是一份含 η 规则的列表。Case 1 里的 $`\Pi(\lambda x.M,\lambda x.Fx)`$ 不能仅靠随手去掉 $`\lambda x`$ 就改写；原文通过公设实例和显式应用完成所需搬运。附件同样不实现 η 归约。

这解释了原文为何显得冗长：它不是在优化计算程序，而是在把自然语言里看似自动的“泛取一个 x 推理，再把 x 绑定起来”变成闭公式系统内有凭据的变换。本篇详细重构零步和 Case 1、交代其余情形的分支依赖；并未逐行形式认证全部十六段推导。扫描中个别公式还存在难读或疑似排印问题，不能用现代常識替换后声称已验证原式。

### 7.7 定理 II 和 III：长证明最后买到了什么

**原文，第 366 页。** 定理 II：若 $`\Sigma(F)`$ 可证，$`G`$ 不含自由 $`x`$，并且从 $`F(x)`$ 可证明 $`G(x)`$，则 $`\Pi(F,G)`$ 可证。

证明的三层依赖是：公设 12 把 $`\Sigma(F)`$ 转成 $`\Sigma x.F(x)`$；定理 I 产生 $`[F(x)]\supset_xG(x)`$；公设 13 再把这一具体抽象关系转回 $`\Pi(F,G)`$。在原文正式可证性的闭式背景里使用这些对象，不能任意引入额外未绑定参数而仍照搬结论。

定理 III：若 $`\Sigma(F)`$ 可证，从 $`F(x)`$ 能证明一个不含自由 $`x`$ 的 $`N`$，则 $`N`$ 可证。这里公设 12 配合定理 I 的第二条出口就足够。

所以最后三项定理是关于**如何安全地恢复假设推理与变量管理的便利**。它们不是不可判定性定理，不是 λ 演算与图灵机等价定理，也不是系统的一致性证明。若只在读后感里写“Church 发明了函数式编程”，就错过了论文大半的技术劳动。

## 8 自指为什么有时只是计算，有时会破坏逻辑

### 8.1 固定点方程不等于求得一个数值

**现代延伸。** 定义著名的固定点构造

```math
Y=\lambda f.(\lambda x.f(xx))(\lambda x.f(xx)).
```

对某项 $`F`$，必要时先作 α 改名，选择 $`x\notin\mathrm{FV}(F)`$，再令 $`W=\lambda x.F(xx)`$。于是

```math
YF\to WW\to F(WW).
```

严格说，这里立即出现的是 $`F(WW)`$；由于 $`YF`$ 也收缩到 $`WW`$，可以得出 $`YF=_\beta F(YF)`$ 的可转换等式。不要把所有可转换等式都伪装成“左边恰好单步缩成右边”。

方程表示递归展开的接口：某个对象可以被改写成把自身再交给 $`F`$。它不保证有正常形，不保证唯一性，也不保证在指定策略下终止。若 $`F=I`$，反复展开不会凭空产生一个完成的答案。

这段推导从抽象、应用和替换直接算出，却仍标为现代教学扩展：本文没有在 1932 正文中找到这一项以此名称与用途出现，不能用后来约定俗成的名字替作者补写历史。

### 8.2 一个逻辑危险的缩小模型

下面不是 Kleene–Rosser 原证，而是说明“自指加上太强的逻辑规则”为何危险的现代条件论证。假设某个逻辑能形成 $`D`$，并能使用

```math
D\leftrightarrow(D\to P)
```

的两个方向；还允许普通条件证明与 modus ponens，并允许同一假设重复使用。则：

1. 暂时假设 $`D`$。
2. 由一个方向得到 $`D\to P`$。
3. 再用刚才的 $`D`$ 得到 $`P`$。
4. 解除假设，得到 $`D\to P`$。
5. 由另一个方向得到 $`D`$。
6. 两者合起来得到 $`P`$。

若 $`P`$ 任意，系统就失去区分可证与不可证命题的能力。每一条假设都重要：只在纸上有一个自引用表达式不够；还需把它当成可使用的命题等价，允许条件证明和重复使用假设。原文 Π 的受限机制不能未经证明替换为此处普通箭头。

这段简短演示的价值是隔离危险接口，不是替代七页历史论文，更不是宣称“任何递归程序都会使逻辑不一致”。一种程序演算完全可以容许自应用和不终止，却没有这样的逻辑断言规则。

### 8.3 与 Gödel 的对比必须放在假设上

Gödel 1931 的典型结论是在适当一致性假设下出现系统不能决定的句子；这里讨论的逻辑崩塌则是规则过强，导致系统可以证明太多东西。它们都能用到编码和自指，但结果方向不同。

若一种系统已经不一致，再用它“证明”一个句子，不会给出我们想要的可靠数学知识。不完备性研究中的一致性条件因此不是可随手删掉的装饰。反过来，也不能为了避免矛盾就要求任何有用计算都必须终止；终止性、一致性、表达能力之间要通过指定模型的定理建立关系。

## 9 后续文献、修订与本篇没有声称完成的工作

### 9.1 1933 不是 1932 的同一份印刷稿

Church 的第二篇同名论文发表于 *Annals of Mathematics* 34(4)，1933 年 10 月，第 839–864 页，[原刊记录](https://www.jstor.org/stable/1968702)。1932 与 1933 应作为两个版本节点保存，不能从后者抄一条规则后标作前者原文。

本次除了核对书目，还在 [ENS Paris-Saclay 课件第 8 页](https://lsv.ens-paris-saclay.fr/~goubault/Lambda/lambda-agreg-1_compressed.pdf#page=8) 中找到并目视读取了嵌入的 1933 原刊首面影像。§1 标题即是修订形式公设列表；Church 承认原来的公设集需要修改才能避开矛盾，并具体指出公设 19 含有足够强的归谬原则，导致一种改写的 Russell 悖论。首面记收到日期 1933 年 1 月 3 日。这里依据的是嵌入的原页影像，不采信课件对后续年份的概括。

但第 840 页以后未取得可逐页核验的完整扫描。首面能证明作者承认与修订原方案的错误，不能代替整个续篇。因此本篇不列一份假装已读过的完整勘误与替换公设清单，也不声称已把原文三十七条公设全部替换成修订版。1932 原页个别难读公式和疑似排印问题保留为复核边界，而不是静默修好后冒充原文。

### 9.2 1935 的结论打击的是逻辑系统

Kleene 与 Rosser 的 *The Inconsistency of Certain Formal Logics*，*Annals* 36(3)，1935 年 7 月，第 630–636 页，给出这条后续路线的决定性负面结果。[原文扫描](https://www.cis.upenn.edu/~cis5110/Kleene-InconsistencyCertainFormal-1935.pdf)

第 631 页定理 A 指明：满足所列操作规则及一组指定公设的逻辑，能证明每个无自由变量的良构公式。其脚注 6 明确将规则解释为 1932 规则经过 Kleene 1934 §1 修订后的版本；不能把这句话改写成“我们已经逐字形式验证原始扫描中的每条规则”。

原文第 630–632 页的主线是内部编码、可证明函数的枚举和 Richard 式对角构造。教学性骨架是：若系统把一列函数 $`U(1),U(2),\ldots`$ 的适当总性都内部化，又构造

```math
Q(n)=1+U(n)(n),
```

并使 $`Q`$ 也落入这列函数，就会在其自身位置发生冲突。实际证明还需要算术理论、语法表示和解码能力；仅写这个方程没有重现全部证明。

### 9.3 失败的基础方案与保留下来的计算核心

“完整逻辑太强”与“纯函数表达式的等式理论所有项都相等”不是同一结论。删除逻辑断言与公设，只研究应用、抽象和转换，研究对象已经改变。后来的计算理论工作正需要认真区分这些层次。

## 11 与现代 AI 的联系：有用，但不能倒写历史

### 11.1 程序生成需要把绑定结构当成数据

### 11.2 搜索策略与验证器的权限边界

最左最外与最左最内对同一项表现不同，提示搜索策略会影响能否在预算内找到结果。但验证器回答的是给定一步是否符合规则，搜索器回答的是下一步试哪里。这两种组件可以共享数据结构，却承担不同保证。

### 11.3 类型与限制不是简单的能力损失表

我们可以限制自应用、约束哪些项可当成命题、或者区分计算项与证明对象，以获得所需性质。但具体限制换来什么，需要在相应系统中证明。本文没有证明“加类型就绝无错误”，也没有证明“没有类型就一定不一致”。

## 12 练习与答案

### 练习 1：自由变量

求 $`\mathrm{FV}(\lambda x.(x\,y)\,(\lambda y.z))`$，并说明两个 $`y`$ 的角色。

**答案。** 自由变量为 $`\{y,z\}`$。第一个 $`y`$ 不在内层 $`\lambda y`$ 的作用域中，故自由；内层绑定名没有任何被它绑定的体内出现，不能把外面的同名自由变量一起绑定。外层 $`x`$ 的出现被删除出自由变量集合。

### 练习 2：捕获与 α 等价

把 $`(\lambda x.\lambda y.x\,y)\,y`$ 正确收缩一次。结果为何不是 $`\lambda y.y\,y`$？

**答案。** 先将内层绑定名改成新鲜 $`z`$，得到 $`\lambda z.y\,z`$。输入的自由 $`y`$ 必须继续自由；错误结果把它捕获了。这里外层 $`x`$ 出现于函数体，非擦除限制没有阻止这次收缩。

### 练习 3：良构不等于可收缩

$`(\lambda x.y)z`$ 在 1932 的语法中是否良构？可以直接用 Rule II 变成 $`y`$ 吗？

**答案。** 良构，因为归纳语法允许变量、应用和任意绑定的抽象。不能直接这样收缩，因为 $`x`$ 未在函数体 $`y`$ 中出现。现代 β 可以做，两个判断必须分开。

### 练习 4：自由变量不变式的必要条件

证明非擦除 β 保持自由变量集合，并给一个允许擦除后不保持的例子。

**答案。** 由捕获避免替换的结构归纳公式，在 $`x\in\mathrm{FV}(M)`$ 下，替换结果的自由变量正是 $`(\mathrm{FV}(M)\setminus\{x\})\cup\mathrm{FV}(N)`$，与应用项相同。反例 $`(\lambda x.y)z\to y`$ 抹掉自由 $`z`$。若没有出现条件，只能使用更弱的一般关系，不能直接套用该集合等式。

### 练习 5：循环与正常形

解释器发现 $`\Omega`$ 收缩前后完全相同，为什么不能宣布已经正常结束？

**答案。** 正常形指没有合法 redex，而不是某个选定收缩恰好保持字符串。$`\Omega`$ 的根始终是合法 redex；它的唯一收缩又返回原项。状态循环与不存在可做步骤不同。

### 练习 6：存在前提为什么不能删

用普通一阶逻辑的类比，解释为什么“从 $`M(x)`$ 可推出不含 $`x`$ 的 $`N`$”不足以单独推出 $`N`$。

**答案。** $`M`$ 的满足者可能为空。例如 $`M(x)`$ 取 $`x\ne x`$，其下可以在经典逻辑中推出任意结论，但不能无条件宣布任意结论成立。定理 I 另外要求 $`\Sigma x.M`$ 可证。这里用的是类比，不把经典爆炸律强加回 Church 原系统。

### 练习 7：数编码手算

不调用 Python，解释 $`\mathrm{TIMES}\,\overline3\,\overline2`$ 为什么与 $`\overline6`$ 相符。再指出零编码的历史陷阱。

**答案。** $`\overline2 f`$ 代表二次操作，$`\overline3`$ 把这个二次操作复合三遍，得到六次 $`f`$。零编码 $`\lambda f.\lambda x.x`$ 含未用的 $`f`$，现代计算涉及的擦除不一定获原文 Rule II 许可，所以该算术编码实验不是原逻辑的完整复现。

### 练习 8：自指与矛盾

为什么 $`YF=_\beta F(YF)`$ 不能单独推出任意命题 $`P`$？

**答案。** 它是计算项的可转换关系，尚未声明这些项是命题，也未给出普通蕴涵、条件证明或可用于自指命题的逻辑等价规则。第 8.2 节的崩塌依赖那整套额外能力。删去其中一些假设，就不能照搬六步证明。

### 练习 9：一个审稿练习

有人说：“程序测了一万项都没有产生矛盾，所以 Church 的公设应当一致。”至少指出三处问题。

**答案。** 本程序没有实现全部逻辑公设，因而根本没有在搜索该系统的矛盾；有限测试不能覆盖全部证明；正常化结果与逻辑可证明性是不同对象。此外，后续历史原文已经给出相关修订系统的不一致性定理，不能以一个不相关的有限实验推翻它。
