# 德摩根第二篇三段论论文的概率与证言数学审计

本文依据[完整原刊扫描](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf)核对原刊第111至127页，重点为第六节的证言概率论，也包括第114至116页的1850年7月1日替换文字，以及第126至127页、署1850年7月3日的附记。所有页码均指原刊印刷页码；所给49页论文摘本中，PDF第33页对应原刊第111页。

**核心结论：** 第120页的证言公式是正确的条件概率更新。其解释力来自同时规定“事实如何发生”和“证人如何报告”，尤其是误报会落到哪个具体说法上。它并不支持仅凭证人的总体正确率、事件稀有程度或赞同人数，就算出可信度。第125页的多证人乘积还需条件独立假设。关系逻辑部分同样须保留非空性、关系方向和对补类的约束，不能把作者在特定体系中的结论当作任意二元关系的定理。

下文的矩阵、条件独立记号、图模型式解释和数值反例是本附录的现代重构，不是对原文符号的原样转写，也不据此主张作者已经提出完整的现代概率学习或人工智能理论。

## 二 第111至113页 从系词到二元关系

[原刊第111页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=127)。

### 1 复合关系不必仍是原来的关系

第111页用“玫瑰是红的，红是美的”说明，两个“是”可能分别连接对象与感觉、感觉与判断。现代重写可设：

```math
R(a,b)=\text{对象 }a\text{ 以颜色 }b\text{ 呈现},\qquad
S(b,c)=\text{颜色 }b\text{ 得到评价 }c.
```

结论使用的是复合关系

```math
T(a,c)\iff\exists b\,[R(a,b)\land S(b,c)].
```

这说明可以消去中项，但没有证明 $`T=R`$、$`T=S`$，更没有证明任意两个同写作“是”的系词都可互换。原文的重要方法要求是保留系词的差别，而非让自然语言的同形词掩盖关系类型。

### 2 第113页四对量化形式的现代读法

在该页局部采用的关系解释中，令 $`R\subseteq X\times Y`$。四对矛盾式可以写为：

| 原文意义 | 现代重写 | 矛盾命题 |
|---|---|---|
| 每个X都与每个Y相关 | $`\forall x\in X\,\forall y\in Y\,R(x,y)`$ | $`\exists x\in X\,\exists y\in Y\,\neg R(x,y)`$ |
| 每个X都与至少一个Y相关 | $`\forall x\in X\,\exists y\in Y\,R(x,y)`$ | $`\exists x\in X\,\forall y\in Y\,\neg R(x,y)`$ |
| 一些X合起来关联到所有Y | $`\forall y\in Y\,\exists x\in X\,R(x,y)`$ | $`\exists y\in Y\,\forall x\in X\,\neg R(x,y)`$ |
| 没有X与任何Y相关 | $`\forall x\in X\,\forall y\in Y\,\neg R(x,y)`$ | $`\exists x\in X\,\exists y\in Y\,R(x,y)`$ |

第三行的“合起来”必须保留。它不等于 $`\exists x\forall y\,R(x,y)`$。例如，甲只会英语、乙只会法语，则两人合起来覆盖这两种语言，但没有一人同时会两种。

若用允许空类的现代语义，表中全称量词可能空真；原文“some”所暗含的存在承诺则须另行处理。例如 $`Y=\varnothing`$ 时第三行的现代重写自动为真，却不能据此保证至少有一个X。因此，不能在不交代空类约定的情况下，把整套传统推理直接换成这张表。

还应注意符号的局部改义：第113页把 $`X)(Y`$ 解释为每个X与每个Y相关；第115页转回作者的补类体系，并明说其等价式按普通体系解释。第115页又把相应形式解释为“有些情形中两者都不……”。同一括号串跨越这两种讨论，不宜机械维持第113页的含义。

### 3 第112页的计数断言是正确而且可达的

设共有 $`\xi`$ 个X、$`\eta`$ 个Y，至少有 $`m`$ 个X各与至少 $`n`$ 个Y相关。令总关系数为 $`E`$，与全部X相关的Y有 $`t`$ 个。则

```math
E\ge mn,\qquad
E\le t\xi+(\eta-t)(\xi-1)=(\xi-1)\eta+t.
```

所以

```math
t\ge \max\{0,mn-(\xi-1)\eta\}.
```

这就是第112页方括号内的论证。若 $`mn>(\xi-1)\eta`$，由 $`m\le\xi`$、$`n\le\eta`$ 可知必须有 $`m=\xi`$；随后条件化为

```math
n>\eta-\frac{\eta}{\xi}.
```

这里应取 $`\xi\ge1`$、$`\eta\ge1`$，并把 $`m,n`$ 视为整数。

**可达例：** 三个X、五个Y，每个X关联四个Y。三个X分别漏掉不同的Y，则恰有两个Y被全部X关联；下界为 $`3\times4-2\times5=2`$。

**严格不等号不能删：** 三个X、三个Y，每个X关联两个Y，关联集合分别为 $`\{a,b\},\{b,c\},\{a,c\}`$。此时 $`n=\eta-\eta/\xi=2`$，却没有任何Y关联到全部X。

## 三 第114至116页 修订论证的假设边界

[原刊第114页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=130)。

### 1 逆关系和否定关系不同

若 $`R`$ 传递，则逆关系 $`R^{-1}`$ 也传递：由 $`bRa`$ 与 $`cRb`$ 得 $`cRa`$。这是第114页所说的相关关系也具有传递性的现代形式。

它没有说关系的否定也传递，更没有说 $`R=R^{-1}`$。例如“小于”与“大于”互逆，都传递，但方向不能混用。朋友关系的逆关系仍是朋友关系，却通常不传递；“不是朋友”也通常不传递。

### 2 全覆盖与补类约束不是传递性的结果

原文给“给予／接受”设定了额外条件：有关实例必须有给予者或接受者；同一个实例不能同时与一个词项和它的补类发生被禁止的混合联系；关系还可延伸到词项的补类。第115页明确借助这些条件推出等价式，第116页用补类作反证。

因此，“每个X都给某个Y”本身并不推出“没有X给非Y”。反例是一个人同时给甲和乙，其中甲属于Y、乙不属于Y。使这一步有效的是原文另设的排除混合联系条件，而不是存在量词或传递性。

同样，现代数学中任何关系都可定义逆关系；这不保证每个对象同时有前驱与后继。把“逆关系在数学上可定义”当作原文“直接及倒置关系总是存在”的全部内容，会把实质的存在假设漏掉。

### 3 顺向链与逆向链不可混同

令 $`R`$ 传递。以下顺向链有效：

```math
\forall x\in X\,\exists y\in Y\,R(x,y),\quad
\forall y\in Y\,\exists z\in Z\,R(y,z)
\Longrightarrow
\forall x\in X\,\exists z\in Z\,R(x,z).
```

但若第一前提改成每个X“从某个Y接受”，即 $`R(y,x)`$，一般就不能推出X向Z给予。

**反例：** 用实数上的小于关系，取 $`Y=\{0\}`$、$`X=\{2\}`$、$`Z=\{1\}`$。有 $`0<2`$ 与 $`0<1`$，却没有 $`2<1`$。这一反例并不直接否定原文的强约束体系；它说明第116页的补类论证不能省略为“这只是传递性”。

### 4 存在性尤其要检查补类

第115页示例通过非Y的给予和接受，推出涉及非X与非Z的特称结论。这样的见证推理需要相关补类确有实例。普通集合语义下，若 $`X=Y=Z=U`$，则 $`X\subseteq Y`$ 与 $`Z\subseteq Y`$ 都成立，却不存在既非X又非Z的对象。

因此，在解读作者从全称前提得到此类特称结论时，应明确记录其存在承诺。不能只保留正项非空，却让参与论证的补项为空。

## 四 第116至119页 初始分配不是逻辑形式自动给定的概率

[原刊第116页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=132)。

第117页把初始分配称为心理活动，并区分数学运算与分配本身是否适当。其抽球例说明：即使知道白球、黑球各100个，若抽取机制不对每个球等机会，仅凭数量也不能保证下一次抽白球的概率为二分之一。

关于“所有X都是Y”比“有些X不是Y”更不可能，原文提供的是对随机选取词项和人类判断的主张，不是由全称与特称的逻辑形式推出的定理。必须先给出如何随机选择词项或如何分配个体属性的模型。

设有 $`N`$ 个X：

- 若各个X独立地以二分之一概率属于Y，则全称命题概率为 $`2^{-N}`$。
- 若“属于Y的X的数量”为 $`0,1,\ldots,N`$，且这些数量等概率，则全称命题概率为 $`1/(N+1)`$。
- 若X为空，按现代空真语义，全称命题为真，概率可为1。

当 $`N=10`$ 时，前两种分配给出 $`1/1024`$ 与 $`1/11`$，差距很大。第122页采用的是后一种按数量分组的假设，而非从逻辑中导出的唯一先验。

原文还说，不等概率的案例仿佛可再细分成等概率案例。有限的精确细分适用于有理概率；一般实数概率则需要近似或更一般的概率空间。“仿佛”这一措辞不宜改写成对所有概率都成立的有限计数构造。

## 五 第120页 核心证言公式的完整推导

[原刊第120页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=136)。

### 1 统一符号

令互斥且穷尽的真实状态为 $`H\in\{1,\ldots,n\}`$，证人的报告为 $`J\in\{1,\ldots,n\}`$。定义

```math
v_s=P(H=s),\qquad C_{js}=P(J=j\mid H=s),
```

其中 $`v_s\ge0`$、$`\sum_s v_s=1`$，且每个固定s满足 $`\sum_j C_{js}=1`$。本文与主文均采用“行是报告、列是真相”的列随机矩阵。可运行附件为了按真实状态查表，存储“行是真相、列是报告”的行随机矩阵；两者互为转置，即代码中的 reports[s][j] 等于本文的 $`C_{js}`$。原文以 $`p_q`$ 表示“真相为q却报告p”的概率；本附录写作 $`C_{pq}`$，避免把字母p同时当作下标和数值参数。

总体正确率为

```math
\mu=P(J=H)=\sum_s v_s C_{ss}.
```

听见报告k的边际概率为

```math
D_k=P(J=k)=\sum_s v_s C_{ks}.
```

因此，在 $`D_k>0`$ 时，具体报告的可信度为

**式（1）**

```math
P_k=P(H=k\mid J=k)
=\frac{v_k C_{kk}}{\sum_s v_s C_{ks}}.
```

分子是“事实确为k且报告为k”；分母还包括一切事实不是k却报告为k的路径。公式正确，且并不需要各个真实状态独立，因为它们是互斥的备选状态。

### 2 三种不同的比较不可混为一谈

- $`\mu`$：尚未知道具体报告时的总体正确率。
- $`C_{kk}`$：如果k为真，报告k的概率。
- $`P_k`$：已经听到报告k后，k为真的概率。

原文称听到报告以后证人的“信用”可能升降，主要在比较 $`P_k`$ 与 $`C_{kk}`$。当 $`C_{kk}>0`$ 时，

```math
P_k\gtreqless C_{kk}\iff v_k\gtreqless D_k.
```

若要比较 $`P_k`$ 与总体的 $`\mu`$，则条件是 $`v_kC_{kk}\gtreqless\mu D_k`$，不能直接使用前一条件。

若要比较 $`P_k`$ 与先验 $`v_k`$，则对 $`0<v_k<1`$，令

```math
f_k=P(J=k\mid H\ne k),
```

有

```math
P_k\gtreqless v_k\iff C_{kk}\gtreqless f_k.
```

**数值例：** 两种状态，$`v_1=0.1`$、$`C_{11}=0.99`$、$`C_{22}=0.8`$。总体正确率为 $`\mu=0.819`$，而

```math
P_1=\frac{0.1\times0.99}{0.1\times0.99+0.9\times0.2}
\approx0.35484.
```

听到报告1以后，它比原先的0.1更可信，却仍低于证人的0.819总体正确率和0.99的该项真阳性率。三个判断完全相容。

公式没有另设未知的“证人能力”参数及其先验，因此这里不应自动解释成已经完成对证人长期可靠性的贝叶斯学习。

### 3 总体准确率不够确定后验

设三个真实状态等概率，每项正确率均为0.8。如果每种错误各分0.1，则报告任一状态的后验正确率都是0.8。若条件概率矩阵改为

```math
C=\begin{pmatrix}
0.8&0.2&0.2\\
0.2&0.8&0\\
0&0&0.8
\end{pmatrix},
```

各列仍和为1，所有对角元仍为0.8，总体正确率仍为0.8；但报告状态1时，后验为

```math
\frac{0.8}{0.8+0.2+0.2}=\frac23.
```

区别来自两种错误都偏向报告1。这正是第120页一般化符号所能表达，而单一“信用分数”不能表达的内容。

### 4 发言选择不能悄悄忽略

第120页在介绍一般可信度时附有“如果他作任何陈述”的限定。若沉默的概率依事实而异，需要明确：要么所有概率已条件化于证人发言，要么模型包含发言选择。

设 $`S`$ 表示发言，$`\alpha_s=P(S\mid H=s)`$，而 $`C_{ks}=P(J=k\mid H=s,S)`$。若 $`v_s`$ 是发言前先验，则

```math
P(H=k\mid S,J=k)
=\frac{v_k\alpha_k C_{kk}}
{\sum_s v_s\alpha_s C_{ks}}.
```

例如 $`v_1=0.1`$，发言后的二分类正确率为0.9；状态1时总会发言，状态2时仅有0.01概率发言。听见报告1的后验约为0.99010。忽略选择机制则会算成0.5。这个差别不是贝叶斯公式失效，而是条件事件未写完整。

## 六 第119至122页 罕见事件与错误报告的分配

[原刊第119页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=135)。

### 1 对称误报模型

第121页额外假定

```math
C_{ss}=\mu,\qquad
C_{js}=\frac{1-\mu}{n-1}\quad(j\ne s).
```

代入式（1）得

**式（2）**

```math
P_k=\frac{v_k\mu}
{v_k\mu+(1-v_k)(1-\mu)/(n-1)}.
```

当 $`0<\mu<1`$ 时，

```math
P_k\gtreqless\mu\iff v_k\gtreqless\frac1n.
```

“没有特定错误偏向”在这里是具体的均匀条件概率假设，不能仅凭未发现偏见便认定成立。

### 2 同样稀有的事件可以有不同的证言价值

**报出一张具体牌：** 52张牌等概率，证人有0.9概率报对；错误均匀落到其余51张。听到“黑桃七”，后验仍为0.9。

**只回答黑桃七与非黑桃七：** 若改用二分类报告，并假定两类各有0.9正确率，听到“黑桃七”，则

```math
\frac{0.9}{0.9+51\times0.1}=0.15.
```

两个模型的目标事件先验都是 $`1/52`$，差别在假阳性率：前者为 $`0.1/51`$，后者为0.1。因而这不是同一个模型经不同说法得到互相冲突的答案。

若只是把第一个模型的51个非目标报告合并，目标假阳性率仍须为 $`0.1/51`$，不能忽然改成0.1。**一致地粗粒化同一个联合分布不会改变目标事件的后验。** 改写标签或任意细分“其他情况”本身不能提高可信度。

### 3 n很大时趋近1的适用范围

固定 $`v_k>0`$、$`\mu>0`$，式（2）确实随 $`n\to\infty`$ 趋近1。但若 $`v_k=1/n`$，后验始终等于 $`\mu`$。若 $`v_k=c/n`$，则

```math
P_k\longrightarrow\frac{c\mu}{c\mu+1-\mu}.
```

所以“大量备选状态使差证人近乎无误”不是无条件结论。它依赖目标先验不与备选数量同时降得太快，并依赖新增状态稀释了误报目标的概率。

第122页按“有多少X属于Y”分成n种等概率情况时，全称命题的先验恰为 $`1/n`$，因此在均匀误报假设下，报告全称命题的可信度恰为 $`\mu`$。这个解释同时使用了先验分组与误报机制，不能只留下分组。

### 4 一个稀有事件计算

若目标先验为0.001，真阳性率为0.99，假阳性率为0.01，则

```math
P_k=\frac{0.001\times0.99}
{0.001\times0.99+0.999\times0.01}
\approx0.09016.
```

同样的先验和真阳性率，若假阳性率降到百万分之一，后验约为0.99899。应调查的是具体误报路径，而不是把“事件很稀有”或“证人很可靠”当成单独充分的理由。

## 七 第122页 投币例的数值与极限

[原刊第122页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=138)。

“第一次正面迟于第十五次投掷”要求前十五次均为反面，单轮概率为 $`2^{-15}`$。若每轮独立，则N轮中至少发生一次的概率为

```math
1-(1-2^{-15})^N.
```

要达到二分之一，需要

```math
N\ge\left\lceil\frac{\log(1/2)}{\log(1-2^{-15})}\right\rceil=22713.
```

因此原文“超过22,000轮”的数量判断正确。2048轮中至少出现一次的概率约为0.06059，确属不常见，但远非不可能。“恰在第十六次首次出现正面”的概率是 $`2^{-16}`$，与“迟于第十五次”必须区分。

原文说重复试验能产生任何稀有事件，应按有正概率、适当独立重复的模型理解：发生概率趋于1，不表示任意有限次数已经保证发生，也不表示每条无限样本路径都会发生。若所有试验完全复制第一次结果，重复并不会提高机会。

第122页关于“显著性相近”的结果分组，是对人类注意和意外感的解释性设想。事先指定的100次全正面与事后才描述出的某一串结果虽然单串概率相同，报告和选择机制却不同；不能仅凭单串概率小就宣布异常，也不能据此宣布所有异常检验无效。

## 八 第123页 否认证言的公式及其隐含协议

[原刊第123页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=139)。

若“否认k”恰为“报告不是k”，则

**式（3）**

```math
P(H=k\mid J\ne k)
=\frac{v_k(1-C_{kk})}{1-D_k},
```

而

```math
P(H\ne k\mid J\ne k)
=\frac{1-v_k-\sum_{s\ne k}v_sC_{ks}}{1-D_k}.
```

两式相加为1，与第123页印式相符，且需要 $`D_k<1`$。

但不肯断言k、选择沉默、明确否认k，是三个可能不同的行为。若证人可说“不知道”，或受提问措辞影响，应另设 $`P(\text{明确否认k}\mid H=s)`$，不能直接拿 $`1-C_{ks}`$ 代替。

否认k使k的概率下降，还需要证言有正确方向。由式（3），对非退化情况，

```math
P(H=k\mid J\ne k)\lt v_k\iff C_{kk}\gt D_k
\iff C_{kk}\gt P(J=k\mid H\ne k).
```

**反例：** 两个状态等概率，一个总会反着说的证人有 $`C_{11}=C_{22}=0`$。他否认状态1，恰恰证明状态1为真。原文的“一般会更加不可能”不能读成对任意证人的数学定理。

## 九 第123至124页 按证人预期分配错误

[原刊第123页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=139)。

设接收者认为证人自己给各状态的先验权重为 $`\lambda_s`$，其中 $`\sum_s\lambda_s=1`$。记该状态的正确报告率为 $`c_s=C_{ss}`$。原文模型对 $`j\ne s`$ 规定

```math
C_{js}=\lambda_j\frac{1-c_s}{1-\lambda_s}.
```

它把“已经出错”时的报告，按证人的预期权重分配到其余状态。假定 $`\lambda_s<1`$，可核对每列总和为1。于是

**式（4）**

```math
P_k=\frac{v_kc_k}
{v_kc_k+\lambda_k\sum_{s\ne k}v_s\frac{1-c_s}{1-\lambda_s}}.
```

### 1 何时报告完全无信息

若 $`c_s=\lambda_s`$，则连同对角元在内，所有列都满足 $`C_{js}=\lambda_j`$。报告的分布与真实状态完全无关，所以 $`P_k=v_k`$。这给出了第123页“证言不偏向任何一方”的简单现代证明。

这一结果也解释了为何“不愿说自己认为不可能的事”不足以证明证人优秀：他可能只依照既有期待说话，根本没有利用观察。

### 2 比较静态必须说明什么保持不变

第123页说，证人自己越认为某事件不可信，接收者反而越有理由相信他的报告。在式（4）中，若其余误报背景项保持不变，降低 $`\lambda_k`$ 确能提高后验；若把其余 $`\lambda_s`$ 按固定比例重新归一化，也有对应的单调性。

但 $`\lambda`$ 在概率单纯形上，不能一面改变一个分量、一面假定其余所有分量均不变。任意重新分配其余权重时，结论未必成立。

**反例：** 固定 $`v=(0.1,0.89,0.01)`$、$`c=(0.9,0.5,0.5)`$，目标为1。把 $`\lambda`$ 从 $`(0.2,0.1,0.7)`$ 改为 $`(0.1,0.89,0.01)`$，目标在证人心中的先验从0.2降至0.1，但式（4）的后验约从0.46821降至0.18180。原因是其余预期的重新集中显著改变了误报目标的概率。故原文的直观说法应作为有控制条件的比较，而非全局无条件单调定理。

### 3 第124页两个参数化模型

若 $`c_s=\theta\lambda_s`$，原文给出 $`P_k=v_k`$ 的条件

```math
\theta=\theta v_k+\sum_{s\ne k}v_s\frac{1-\theta\lambda_s}{1-\lambda_s}.
```

利用

```math
\frac{1-\theta\lambda_s}{1-\lambda_s}
=\theta+\frac{1-\theta}{1-\lambda_s},
```

在 $`0<v_k<1`$、$`0<\lambda_k<1`$ 等非退化条件下，该式简化为 $`\theta=1`$。此外必须确保 $`0\le\theta\lambda_s\le1`$。

若改为 $`1-c_s=\theta(1-\lambda_s)`$，则

```math
C_{js}=\theta\lambda_j\ (j\ne s),\qquad
c_s=1-\theta+\theta\lambda_s,
```

且

**式（5）**

```math
P_k=\frac{v_k(1-\theta+\theta\lambda_k)}
{(1-\theta)v_k+\theta\lambda_k}.
```

在参数使各概率合法且分母为正时，

```math
P_k-v_k=\frac{(1-\theta)v_k(1-v_k)}
{(1-\theta)v_k+\theta\lambda_k}.
```

所以 $`\theta=1`$ 时报告无信息；$`\theta<1`$ 时报告k支持k；合法的 $`\theta>1`$ 情形则可能使报告k反而反对k。第124页的代数可核对，但参数可行域不可省略。

## 十 第124页 判断误差与故意虚假陈述的两阶段模型

[原刊第124页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=140)。

令B为证人心中认定的状态，设

```math
C_{bs}=P(B=b\mid H=s),\qquad
L_{jb}=P(J=j\mid B=b).
```

在报告只通过B依赖真实状态的假设下，

```math
T_{js}=P(J=j\mid H=s)=\sum_b L_{jb}C_{bs},
```

于是

**式（6）**

```math
P(H=k\mid J=k)
=\frac{v_k\sum_b C_{bk}L_{kb}}
{\sum_s v_s\sum_b C_{bs}L_{kb}}.
```

这正是原文对真实状态和中间判断作双重求和的现代形式。所谓“错上加错可能报对”，就是 $`b\ne k`$ 的路径仍可能以报告k结束。

这里隐含 $`J\perp H\mid B`$。如果陈述还依赖未纳入B的线索、压力、利益或知情程度，则须使用 $`P(J=j\mid B=b,H=s)`$ 或增加相应变量，不能把只依赖B的矩阵当作无条件的普遍分解。

若两个阶段分别以a、b的概率正确，所有错误均匀分到其余 $`n-1`$ 项，且真实状态均匀分布，则

**式（7）**

```math
P_k=ab+\frac{(1-a)(1-b)}{n-1}.
```

第一项为两个阶段都正确；第二项为两个阶段都错误、最终恰好回到真相。n=2时，第二次错误必然把第一次错误翻回真相；n较大时，还须选中原来的正确状态。

例如 $`n=3`$、$`a=0.8`$、$`b=0.9`$，得 $`P_k=0.72+0.01=0.73`$。全体均匀先验和对称通道使每种报告的边际概率仍是 $`1/n`$，这才让条件后的可信度等于合成通道的正确率。

第119页称p为诚实度、r为判断力；第124页按此前定义给无撇与有撇矩阵分别赋p、r，两个角色的标签顺序发生了交换。式（7）对a、b对称，数值结果不受影响；逐字转写时仍应避免把角色混淆。

## 十一 第125页 定向说谎模型

[原刊第125页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=141)。

设证人判断为目标k时总报告k；判断为其他状态时，以概率 $`\kappa`$ 改口报告k，否则如实报告自己的判断。这里原文“只有k可能被虚假报告”的零元素限制，应作用于错误的非对角项，不能连其他状态的诚实报告对角项也删掉。

若 $`c_k=C_{kk}`$，并令 $`D_k=\sum_s v_sC_{ks}`$ 是不考虑此类说谎时判断为k的概率，则

**式（8）**

```math
P_k(\kappa)
=\frac{(1-\kappa)v_kc_k+\kappa v_k}
{(1-\kappa)D_k+\kappa}.
```

对 $`D_k>0`$，可写成

```math
P_k(\kappa)=w\,P_k(0)+(1-w)v_k,\qquad
w=\frac{(1-\kappa)D_k}{(1-\kappa)D_k+\kappa}.
```

因此原文所说它位于原先后验与先验之间，是正确的：这种一律向k的报告偏向，把证言推向无信息状态。$`\kappa=1`$ 时总报k，后验恰为先验。

若判断完全准确，则

```math
P_k=\frac{v_k}{(1-\kappa)v_k+\kappa}
=\frac{v_k}{v_k+\kappa(1-v_k)}.
```

例如 $`v_k=0.01`$、$`\kappa=0.1`$，即使没有观察错误，报告k的可信度也只有约0.09174。这个结果直接区分了判断准确与报告诚实。

## 十二 第125页 多证人乘积的独立性审计

[原刊第125页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=141)。

对证人 $`i=1,\ldots,m`$，令合成报告通道为

```math
T^{(i)}_{j_i s}=\sum_b L^{(i)}_{j_i b}C^{(i)}_{bs}.
```

如果各证人的报告在给定真实状态后相互独立，则

**式（9）**

```math
P(H=t\mid J_1=j_1,\ldots,J_m=j_m)
=\frac{v_t\prod_i T^{(i)}_{j_i t}}
{\sum_s v_s\prod_i T^{(i)}_{j_i s}}.
```

展开各个中间判断b的求和，就得到原文第125页的乘积与求和结构。若证人通道相同且全都报告k，则似然是 $`(T_{ks})^m`$。

但“各证人性格完全一样”不等于“给定真相后独立”。如果他们共用一个消息来源、相互抄录、共同受一件误导材料影响，或者准确率本身有共同未知原因，式（9）就需要修改。

**最小反例：** 两种状态先验各二分之一。一个证人正确率0.9，报告状态1。

- 一个证人，后验为0.9。
- 两个条件独立、同等可靠的证人一致报告1，后验为 $`0.9^2/(0.9^2+0.1^2)=81/82\approx0.98780`$。
- 第二人逐字复制第一人的报告，则两个一致报告仍只带来0.9的后验。

十个独立同类报告给出 $`9^{10}/(9^{10}+1)\approx0.99999999971`$；十次复制仍为0.9。这是乘积模型的实质边界。它适用于今日对重复网页、同源报道或模型答案的一致性判断，但这种应用是本附录的现代延伸，不是对作者历史影响的断言。

一般的正确公式是以完整联合似然

```math
P(J_1=j_1,\ldots,J_m=j_m\mid H=s)
```

替代乘积；只有满足相应条件独立性，才可进一步因式分解。

## 十三 第125页 补入其他事件还需补入其报告机制

[原刊第125页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=141)。

原文指出，若列举的事件并不穷尽，可增加“以上皆非”这一状态，赋概率 $`1-\sum_s v_s`$。这个做法正确，前提是原有事件互斥，并且其概率和不超过1。

但增加余项的先验仍不够；还需规定其报告似然 $`P(J=k\mid H=\text{其他})`$。一个包含多种异质情形的余项，其似然通常是内部各情形的条件加权平均。

例如三个状态的先验为 $`(0.1,0.4,0.5)`$，报告目标1的似然分别为 $`(0.9,0.01,0.5)`$，则正确后验为

```math
\frac{0.09}{0.09+0.004+0.25}\approx0.26163.
```

漏掉“其他”一项便会得到 $`0.09/(0.09+0.004)\approx0.95745`$。这说明“封闭世界”假设的影响可能远大于公式计算误差。

## 十四 第126至127页 附记中的形式与材料

[原刊第126页起](https://archive.org/download/transactionsofca09camb/transactionsofca09camb.pdf#page=142)。

### 1 类包含和不相交的复合

第126页的例子在集合语言中是

```math
X\subseteq Y,\qquad Y\cap Z=\varnothing
\Longrightarrow X\cap Z=\varnothing.
```

若把“是……的种”视为集合间的包含关系，把“外于……”视为不相交关系，就能说明普通三段论本身也使用关系复合。它并不因此变成任意关系都可复合后保持同一结论关系的原则；这里需证明“包含后接不相交”保留不相交。

### 2 加入普遍原则并未消灭其应用步骤

第127页把“与同一物相等者彼此相等”的普遍原则加入等式链。若已采用标准相等关系，传递性和对称性足以得到结论；把原则作为大前提写出，只是改变了论证的表达层级，仍须把具体对象代入该原则并使用推理规则。

作者由此质疑：为什么普通三段论可以直接使用其形式，而其他关系的推理必须因补入原则才算逻辑？本附录不据此给出“所有推理都能化为某个单一演算”的结论。附记提供的是对形式范围的论辩和实例，不是完整性定理。

### 3 父与子要区分关系方向和词义条件

原文以Philip是Alexander的父亲、因而Alexander是Philip的儿子为例。严格重写为：

```math
\mathrm{Father}(p,a)\Rightarrow\mathrm{ChildOf}(a,p).
```

若要得到 $`\mathrm{SonOf}(a,p)`$，还需a是男性这一词义条件。“父亲”的逆关系在不限制论域时是“某位父亲的孩子”，不是对所有对象无条件等同于“儿子”。这个细分符合原文把关系的具体知识与关系换向的形式用法分开的意图。

### 4 应当如此不等于事实上如此

第127页批评把“是”译成“应当是”后继续照常推理。设 $`T(a)`$ 为某对象属某类，$`G(a)`$ 为实际具有某性质，$`O G(a)`$ 为应当具有此性质。

```math
T(a)\Rightarrow O G(a),\qquad\neg G(a)
```

不能推出 $`\neg T(a)`$。一个仍然是学生的人可以没有完成他应当完成的作业。若第一前提是 $`T(a)\Rightarrow G(a)`$，才可由反证或逆否推出 $`\neg T(a)`$。原文强调系词差异，在这里有明确的形式理由。

## 十五 对正文解读的建议

可据原文稳妥建立的判断是：作者把证言可信度明确写成由事件先验与报告机制共同决定的量，容许不同事件有不同误报倾向；又以判断和陈述的两阶段结构、以及多证人路径求和，扩展了模型的表达能力。第111至116页和附记则要求把关系方向、量化范围和系词性质纳入形式分析。

应避免的过强表述包括：

1. “只要事件很罕见，证人就不可信”，或其相反说法“具体报告无论多罕见都可信”。两者都漏掉假阳性机制。
2. “选择更多备选事件即可提高后验”。一致的重分组不会改变同一个联合模型的结果。
3. “证人越多，一致性就按人数指数增加可信度”。这需要条件独立，不能用于重复来源。
4. “凡传递关系都可随意换向，并沿用全部三段论”。逆关系、补类延伸、非空性和原文附加限制必须逐项检查。
5. “脑是概率计算机器”已经得到本文公式的实验证明。第118页的相关话语是有保留的推测；数学模型没有测量脑机制，也没有校准人的心理权重。

最适合据此提出的阅读问题是：这个推论除了运算规则，还承诺了哪些对象存在、哪些状态彼此排斥、哪些错误等可能、哪些报告相互独立？本论文值得细读之处，恰在它既推进形式化，也留下了这些必须进一步检查的模型选择。
