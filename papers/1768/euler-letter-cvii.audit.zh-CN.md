# 欧拉第 CVII 信：独立数学审计

## 1. 底本与结论

本审计逐页核看 1768 年第二卷原印第 134 页下部至第 139 页的图像（扫描序号 155–160），止于「le 3 Mars 1761」。第 134 页上部的十九式总结与 1761 年 2 月 28 日署日属于前信；第 139 页下部 CVIII 标题以后的内容不属于本信。出版年 1768 与本信署日 1761 年 3 月 3 日须分别记录。本文是现代形式重构，不能归作欧拉原文中的集合论、模型论或算法。

核查结论：

1. I–V 对经典固定三项、两前提、AEIO 结论的三段论给出必要限制；它们不是充分判据，也不是对任意逻辑语言中「一切可能结论」的禁令。
2. 两全称前提推出特称结论涉及存在性。第三格 AAI 至少需中项非空；第四格 AAI 至少需大项非空。不得仅用非空论域代替相应项非空。
3. VI–IX 的核心是主项外延是否被整体论及，不是对象数量的大小。单称主项只有一个对象，整体论及它仍可按全称式处理。
4. VIII 的措辞有「仅涉及一部分」的表述，但柏林例没有追加「其余居民不富有」。应区分断言范围未覆盖全部与明确断言并非全部；不宜把现代特称真值条件改成「有些但非全部」。
5. 伏尔泰例的有效性来自同一个有指称个体同时满足两个谓词。把两次出现的个体换成互不相关的存在见证会丢失信息。
6. 十个编号段不是十条相互独立的演绎公理：VI 引入问题，VII 转述他人意见，VIII–IX 反驳并提出分类，X 限定讨论范围。

## 2. 明确语义和适用边界

令论域为 $`D`$，结论主项为 $`P`$，谓项为 $`Q`$，中项为 $`M`$。三者在基本审计中为非空子集；它们可以重合，并不要求三个外延互异。项字母在形式上不同，也不允许另加有关三项关系的背景公理。

```math
\begin{aligned}
A(X,Y)&\iff X\subseteq Y,\\
E(X,Y)&\iff X\cap Y=\varnothing,\\
I(X,Y)&\iff X\cap Y\ne\varnothing,\\
O(X,Y)&\iff X\setminus Y\ne\varnothing.
\end{aligned}
```

以上全称命题本身不编码存在；存在要求单列。若改为允许空项，则某些传统式失效，见第 6 节。把非空条件写出，是为检验历史推理需要什么，不是声称原信已经明确建立这套现代语义。

四格均以 $`P`$ 为结论主项、$`Q`$ 为结论谓项：

- 第一格：$`M\!-\!Q,\;P\!-\!M\;\therefore P\!-\!Q`$。
- 第二格：$`Q\!-\!M,\;P\!-\!M\;\therefore P\!-\!Q`$。
- 第三格：$`M\!-\!Q,\;M\!-\!P\;\therefore P\!-\!Q`$。
- 第四格：$`Q\!-\!M,\;M\!-\!P\;\therefore P\!-\!Q`$。

「无结论」在本语境表示：不存在仅凭这两个前提、在所有容许解释中成立的指定端项间 AEIO 结论。它不否认可推出某个前提本身、两个前提的合取、重言式，或携带中项的其他句子。X 明言此前只讨论由两个概念构成的简单命题，并说复合命题另需规则，正好支持这一范围限定。

例如，两个否定前提当然蕴涵它们的合取；否定前提与另一个肯定前提也蕴涵后者。将 I 或 III 改写成一般命题逻辑定理便会错误。

## 3. I：两个否定前提不能联结两个端项

原印第 135 页以高卢人、凯尔特人与罗马人为例：都不是罗马人，不能据此确定前两类相容还是不相容。历史例只用来表示前提形式，不以现代历史分类替代逻辑检验。

### 对所有格及 E/O 组合的统一反模型证明

设 $`a\ne b\ne c`$ 且三者两两不同。

- 模型甲：$`Q=\{a\},P=\{b\},M=\{c\}`$。任何两项之间无论哪个方向，E 与 O 都真；但结论 $`A(P,Q)`$、$`I(P,Q)`$ 都假。
- 模型乙：$`Q=P=\{a\},M=\{b\}`$。每个端项同中项之间无论哪个方向，E 与 O 都真；但结论 $`E(P,Q)`$、$`O(P,Q)`$ 都假。

每个前提总是连接中项和一个端项，所以甲、乙适用于四格全部两个否定前提的组合。对每种可能结论都有前提真而结论假的模型。这是一般证明，不只是一个图例。

原文「全部或部分在中项之外」适合其直观讲法；现代严格化时尤其要注意 O 不可换位：$`O(M,Q)`$ 表示有中项成员不属 Q，不能直接改成有 Q 成员不属 M。

## 4. II–V：必要规则、证明与不能反推的地方

### II：两个特称前提

原印第 136 页：「有些学者贫穷」「有些学者爱说坏话」不能确定贫穷者与爱说坏话者的关系。令 $`M`$ 为学者，$`Q,P`$ 为两个谓词的外延：

```math
\exists x(Mx\land Px),\quad
\exists y(My\land Qy)
\quad\not\models\quad
\exists z(Pz\land Qz).
```

不能令 $`x=y`$；两项存在断言没有提供此等式。具体两模型为：

- $`M=\{a,b\},Q=\{a\},P=\{b\}`$：两个 I 前提真，A、I 结论假。
- $`M=Q=P=\{a\}`$：两个 I 前提真，E、O 结论假。

这两模型直接覆盖 II 型肯定特称组合。包含 O 的所有特称组合，由下列周延计数和第 9 节完整语义检验覆盖；不应误以为仅举 II 的例子已证明 IO、OI、OO。

### III：有否定前提时，有效结论也须否定

先排除 I 所说的两个否定前提。剩下恰一个肯定、一个否定前提。令肯定前提连接的那个端项与 M 同为 $`\{a\}`$，另一个端项为 $`\{b\}`$。这样肯定前提无论 A/I、无论方向都成立；否定前提无论 E/O、无论方向也成立。两个端项却不相交，所以 A、I 结论均假。这给出全体格与此类前提的统一反模型。

规则不是「一有否定前提，就一定推出某个否定结论」。第二格两个否定前提已经说明此推理不成立；其他不满足有效性条件的组合也不产生结论。

### IV：有特称前提时，有效结论也须特称

直观的「只谈一些，因此只能谈一些」不能单独代替一般证明。可用标准周延必要条件组织检查：

- A 周延主项，E 周延两项，I 不周延任何项，O 周延谓项。
- 中项至少在一个前提周延。
- 结论中的周延项必须在相应前提中周延。

这两条必要条件有以下直接证明，无须先信任教科书规则或程序结果。

**中项至少周延一次的证明。** 若 M 两次都未周延，则前提只可能是 A(X,M)、I(X,M)、I(M,X) 或 O(M,X)，其中 X 为相应端项。E 的两个位置和 A 的主项、O 的谓项均已被排除。

- 若两个前提都肯定，按第 4 节 V 的独立反模型论证，有效结论只能肯定。取 $`P=\{a\},Q=\{b\},M=\{a,b\}`$：所有允许的 A/I 前提成立，但 A(P,Q)、I(P,Q)都假。
- 若恰一个前提否定，只可能是 O(M,X)。按 III 的独立证明，有效结论只能否定。取 $`P=Q=\{a\},M=\{a,b\}`$：O 前提由 b 见证，另一允许的 A/I 前提成立，但 E(P,Q)、O(P,Q)都假。
- 若两个前提都否定，已由 I 的统一反模型排除。

因此在所有情况下，不周延中项都不能得到有效结论。这一证明只依赖已独立证明的 I、III、V，不循环使用 II 或 IV。

**结论周延项须在前提周延的证明。** 假设端项 X 在其唯一所在前提中未周延。该前提只可能是 A(Y,X)、I(X,Y)、I(Y,X) 或 O(X,Y)。把 X 的外延扩大不会破坏其中任何一句真前提；另一前提没有 X，也不受影响。所有前提对均有全项非空模型：固定 M={a}，每个端项独立取 {a} 可满足其 A/I 前提，独立取 {b} 可满足其 E/O 前提，无论方向。

从一个真前提模型出发，考虑 X 在结论被周延的三种情形：

- 结论为 A(X,Z)：添一个新对象 t，只让它属于 X 而不属于其余项。两个前提仍真，但 t 推翻 A(X,Z)。新对象在其余项皆为假，因而不会破坏另一前提。
- 结论为 E(X,Z) 或 E(Z,X)：Z 非空，取其中一个对象并把它加入 X。两前提仍真，E 结论变假。
- 结论为 O(Z,X)：把 X 扩大成整个论域。两前提仍真，而 Z 外于 X 的差集为空，O 结论为假。

这穷尽结论中的周延位置，故得到所需必要条件。非空项前提在 E 情形的选取中明确使用；它与本审计的主要历史重构背景一致。第 9 节代码另作交叉检查，但不是上述两证明的依据。

II 的计数：两个 I 没有周延位置，不能周延中项；I/O 只有一个周延位置，而 III 要求否定结论，其谓项与中项至少需要两个不同周延位置；两个 O 被 I 排除。

IV 的计数：排除两个特称或两个否定后，只须考察一全称、一特称。

- A/I 共有一个周延位置。由 V，结论若有效须肯定；全称肯定结论的主项加上中项至少要两个位置，因此不能是 A。
- A/O 或 E/I 共有两个周延位置。由 III，结论须否定；若为全称否定 E，两个端项加上中项至少要三个位置，因此不能是 E。
- E/O 两前提均否定，已排除。

因此有结论时只能是 I 或 O。计数说明必要性；不能把「位置数足够」当作充分条件，因为这些周延位置还必须落在正确的项上。

两个具体反模型可防止不当全称化：

```math
M=Q=\{a\},\quad P=\{a,b\}:
\quad A(M,Q),I(P,M),I(P,Q),\neg A(P,Q).
```

```math
M=\{a\},\quad Q=\{b\},\quad P=\{a,b\}:
\quad E(M,Q),I(P,M),O(P,Q),\neg E(P,Q).
```

### V：两个肯定前提不推出否定结论

取 $`Q=P=M=\{a\}`$。任何方向的 A 或 I 前提都真，而 E、O 结论都假。这同时覆盖四格和全部肯定前提组合。

两个全称前提却可能仅足以推出特称结论。这里「仅」须联系该式指定方向的结论；不能理解为两全称前提绝不可能蕴涵其他方向的全称命题。

### 五条必要规则并不充分

第二格的 AAA 通过 I–V 的质量、数量限制，但一般无效：

```math
Q=\{a\},\quad P=\{b\},\quad M=\{a,b\}.
```

此时 $`A(Q,M)`$ 与 $`A(P,M)`$ 真，$`A(P,Q)`$ 假；中项两次都未周延。故不能写成「凡遵守 I–V 者均有效」，更不能称它们为完整自动推理算法。

## 5. 第三、第四格的 AAI：完整重构

原印第 137 页 V 指第三格、第四格各自第一式；第 139 页明确把伏尔泰例归为第三格第一式 AAI。

### 第三格 AAI

```math
M\subseteq Q,\quad M\subseteq P,\quad M\ne\varnothing
\quad\Longrightarrow\quad P\cap Q\ne\varnothing.
```

取 $`m\in M`$，两包含关系分别给出 $`m\in Q`$ 与 $`m\in P`$，所以 m 是结论见证。

它不能一般加强为 $`P\subseteq Q`$：令 $`M=Q=\{a\},P=\{a,b\}`$ 即为反例。

### 第四格 AAI

```math
Q\subseteq M,\quad M\subseteq P,\quad Q\ne\varnothing
\quad\Longrightarrow\quad P\cap Q\ne\varnothing.
```

取 $`q\in Q`$，由传递性得 $`q\in P`$，故存在既为 P 又为 Q 的对象。这里最小存在条件是 Q 非空，仅有 M 或 P 非空不够。

两包含实际还给出 $`Q\subseteq P`$；但指定结论方向为 $`P\!-\!Q`$，不能把逆向全称 $`A(Q,P)`$ 误当此式的 $`A(P,Q)`$。令 $`Q=M=\{a\},P=\{a,b\}`$，指定方向的 A 结论即为假。

## 6. 空项与存在承诺

非空论域不等于每个概念的外延非空。若容许空项：

- 第三格：令 $`D=\{a,b\},M=\varnothing,Q=\{a\},P=\{b\}`$。两 A 前提真，I 结论假，即使两个端项各自非空仍然无效。
- 第四格：令 $`D=\{a\},Q=\varnothing,M=P=\{a\}`$。两 A 前提真，I 结论假，即使中项和小项非空仍然无效。

这些是改变存在约定后的反例，不是欧拉在相同历史约定下自相矛盾的证据。须把「所需存在条件」与「作者是否明说此条件」分开。

## 7. VI–IX：单称、柏林与「有些」的范围

VI 用「维吉尔是一位伟大的诗人」说明单称命题；VII 转述某些作者因「一个比一些更少」而将单称归入特称的理由。VIII–IX 明确反对这一理由：判断标准是主项概念在命题中是否按整个外延使用，不是计算谈到的对象多少。

### 柏林例不宜形式化为「有些而非全部」

VIII 的「Quelques habitants de Berlin sont riches」及说明确有「不谈及全体」「只涉及一部分」措辞。严谨编辑应保留这种历史表述，同时注明现代重构所作区分：

```math
\text{未断言所有居民富有}
\quad\ne\quad
\text{断言并非所有居民富有}.
```

在通常 AEIO 语义中，该句为 $`I(B,R)`$，并非 $`I(B,R)\land O(B,R)`$。若所有柏林居民都富有且居民非空，I 仍真；它不携带额外的不富有见证。

把「只取一部分来断言」解释为断言力度或主项使用范围，最能与本章 AAI 和历史三段论的上下文协调。单凭本段无法证明欧拉已作出完整的现代语义／语用区分；反过来，也不能据「une partie」几个字替他增添一个 O 真值条件。建议正文写成：「欧拉强调特称不就整个主项外延作断言；本文以存在量化重构，不额外读入『并非全部』。」

### 单元素类的全称与特称可以真值重合

设名字 v 确实指称论域中的对象，且 $`V=\{v\}`$。则对任何谓词外延 T：

```math
\begin{aligned}
A(V,T)&\iff v\in T\iff I(V,T),\\
E(V,T)&\iff v\notin T\iff O(V,T).
\end{aligned}
```

因此「按全称方式处理单称」是可保全结构的表示选择，并不表示在单元素域上 A 与 I 必有不同真值。对象数量为一不妨碍主项外延被整体论及；也不能因为 I 等价于该单称断言，就抹去单元素限制以后再用无约束一般类的规则判断。

若名字不指称，这组等价不能直接照搬。把无指称名字模拟为空类时 A、E 会空真，I、O 为假；而不同自由逻辑对原子句的处理也不完全相同。经典一阶逻辑的常项通常要求指称；欧拉关于真实个人的例子不能直接解决虚构或无指称名字的逻辑。

## 8. 伏尔泰：同一见证与量词依赖

原印第 139 页的原例是：伏尔泰是哲学家；伏尔泰是诗人；所以某位诗人是哲学家。令 v 指伏尔泰，Q 为哲学家、P 为诗人：

```math
Q(v),\quad P(v)
\quad\Longrightarrow\quad
Q(v)\land P(v)
\quad\Longrightarrow\quad
\exists x\,(P(x)\land Q(x)).
```

在集合表示中令 $`M=\{v\}`$，便得 $`A(M,Q),A(M,P)`$，并用已知 $`M\ne\varnothing`$ 应用第三格 AAI。

这里共同的名字不是两次任意取样。以下较弱信息一般不足：

```math
\exists x(Mx\land Px),\quad\exists y(My\land Qy).
```

反例是 $`M=\{a,b\},Q=\{a\},P=\{b\}`$。如果另外保留 $`M=\{v\}`$，那么两个存在见证都只能等于 v，此时两 I 前提也足够。这不推翻 II：II 针对项外延可独立变化的一般三段论，未附加「中项恰有一个成员」的额外条件。

不可写成「两特称从来不能推出结论，所以单称绝不能用存在式表示」。准确说法是：将两个单称前提仅抽象成无约束的两个特称类命题，会丢失共同指称及唯一性信息；欧拉的全称分类是一种避免这一信息损失的方法。

## 9. 有限模型检查为何在这里是完整检验

此处的有限枚举并非随意检查若干小集合。对于三个一元项，每个对象有 8 种成员签名；签名 000 在三项之外，不影响任何 AEIO 真值。其余 7 个区域，每个只需记录空或非空：AEIO 不区分某一区域有一个还是无穷多个对象。

对任意模型，在每个非空成员区域选一个代表，便得到至多 7 个相关对象的模型，所有 AEIO 命题真值不变。若三项均空且需保留非空论域，可另添一个 000 对象。因此区域压缩证明覆盖任意基数模型；它与只试有限范围而无缩约证明的实验有本质差别。

7 区域共有 $`2^7=128`$ 个非空性模式。要求三项非空后，容许模式数为：

```math
128-3\cdot 8+3\cdot 2-1=109.
```

### 与主稿 255／218 支持数的对应

主稿保留 000 类型，要求论域非空，因此共有 $`2^8-1=255`$ 个完整支持；三项非空时为 218 个。本文忽略 000 类型，形成按 AEIO 真值等价的商：

- 任一非空的 7 区域支持，都可配上「没有 000」或「有 000」两种完整支持，二者 AEIO 真值相同。
- 7 区域支持为空时，为保证论域非空，完整支持只能取 {000}，不能取全空支持。
- 因此允许空项时有 $`127\cdot2+1=255`$ 个完整支持，约化后为128类。
- 三项非空时，109个约化支持全都非空，每个恰对应两种完整支持，所以 $`109\cdot2=218`$。

109和218不是不一致的模型定义；前者删除无关的域外成员位，后者保留它。以下独立脚本实际生成两种支持系统，验证每个投影纤维的大小，并比较全项非空与允许空项两种背景下的所有有效式集合。允许空项背景得到15个有效式，非空项背景得到24个；这两个数量不能互换。

逐格检验 $`4^3=64`$ 个式，共 256 个格／式组合，得到 24 个有效组合。全部满足 I–V。24 包括从有效全称结论弱化所得的五个附加式：第一格 AAI、EAO；第二格 AEO、EAO；第四格 AEO。它不是原文十九式的另一种抄读，更不说明前信算术错误；两种计数采用不同的列举约定。

以下代码块是本次实际运行脚本的逐字核心节选，不是完整脚本；已核对它与所链接脚本中的对应部分完全一致。完整独立脚本另存于[独立数学验证脚本](../../reproduction/euler-1768-cvii/independent_mathematics_audit.py)，实际输出见[独立运行日志](../../reproduction/euler-1768-cvii/independent-mathematics-audit.log)。脚本另外核对 000 类型的商约化与具体反例；没有导入生产验证器，亦无外部依赖。

```python
from itertools import product

def holds(kind, x, y):
    return {
        'A': not (x - y),
        'E': not (x & y),
        'I': bool(x & y),
        'O': bool(x - y),
    }[kind]

models = []
for bits in range(128):
    cells = {i for i in range(1, 8) if bits >> (i - 1) & 1}
    q = {i for i in cells if i & 1}
    p = {i for i in cells if i & 2}
    m = {i for i in cells if i & 4}
    if q and p and m:
        models.append((q, p, m))

valid = []
for figure in range(4):
    for a, b, c in product('AEIO', repeat=3):
        good = True
        for q, p, m in models:
            edges = [
                ((m, q), (p, m)),
                ((q, m), (p, m)),
                ((m, q), (m, p)),
                ((q, m), (m, p)),
            ][figure]
            if (holds(a, *edges[0]) and holds(b, *edges[1])
                    and not holds(c, p, q)):
                good = False
                break
        if good:
            valid.append((figure + 1, a + b + c))

assert len(models) == 109
assert len(valid) == 24
for figure, mood in valid:
    a, b, c = mood
    assert not (a in 'EO' and b in 'EO')
    assert not (a in 'IO' and b in 'IO')
    assert not ((a in 'EO' or b in 'EO') and c not in 'EO')
    assert not ((a in 'IO' or b in 'IO') and c not in 'IO')
    assert not ((a in 'AI' and b in 'AI') and c not in 'AI')

# 独立核验上文使用的两条周延必要条件。
def distributed(kind, subject, predicate):
    return {'A': {subject}, 'E': {subject, predicate},
            'I': set(), 'O': {predicate}}[kind]

for figure, mood in valid:
    a, b, c = mood
    edges = [
        (('M', 'Q'), ('P', 'M')),
        (('Q', 'M'), ('P', 'M')),
        (('M', 'Q'), ('M', 'P')),
        (('Q', 'M'), ('M', 'P')),
    ][figure - 1]
    dp = distributed(a, *edges[0]) | distributed(b, *edges[1])
    assert 'M' in dp
    assert distributed(c, 'P', 'Q') <= dp

print('109 models; 24 valid moods; all necessary conditions passed.')
```

这里的完整性仅限三个独立一元项、四格和 AEIO 命题。它不证明复合命题的一般规则，不处理关系谓词、模态、时态或无指称名字；也不是声称欧拉已经具有现代有限模型判定法。
