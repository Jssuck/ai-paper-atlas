# 欧拉第 CVIII 封信：逻辑与数学审计

## 审计对象与结论

本审计直接核对 1768 年版书页 139 下半至 144 上半的第 CVIII 封信；书末落款为 1761 年 3 月 7 日。139 页上半属于 CVII，144 页下半已经是 CIX，均不纳入本信论证。

审计结论：本信两种肯定有效的条件推理，可以用现代经典命题逻辑给出一般有效性证明；两种被否定的形式确实各有“前提全真而结论假”的反例。末尾物体／精神例子的第一种推理需要分类覆盖，第二种需要类别互斥，二者不可混为一个未经解释的“或”。这些是形式关系的审计，不证明报纸报道、和平局势或实体二分等实质前提为真。

下文严格区分：

- **原文主张**：欧拉写出的句子、形式与论述范围，附印本页码。
- **现代教学重建**：用赋值、语义后承、集合或谓词表达的分析工具。符号、证明及反模型不冒充欧拉已经提出的现代语义学。

## 一、逐页论证定位

1. **139 下半—140 页**：从此前“简单命题”的三段论转向复合命题，介绍假言／条件命题；以“如果报纸所说属实，那么和平不远”为例。原文解释后件是前件的“必要后果”，前件不能真而后件不真。
2. **141 页**：单有条件关系没有进一步断定两部分各自的真假；加上肯定前件或否定后件，得到两种有效形式。
3. **142—143 页**：列出否定前件、肯定后件两种错误形式；说明即便报纸不可靠，和平仍可能临近；即使和平确实临近，也不能因此断定报纸可靠或从不撒谎。
4. **143 页**：命名前件与后件，重述“承认前件就须承认后件”“否定后件就须否定前件”；随后转向另一种复合命题。
5. **144 上半**：“每一实体或是物体、或是精神”；由某实体不是物体推其是精神，由某实体是物体推其不是精神。此处第二式揭示其分类实际按排斥理解使用。

原文以“包含两个概念”描述简单命题，以“包含更多概念”描述复合命题。这是其历史术语框架，不应改写为现代命题逻辑给出的严格句法定义。

## 二、条件命题的现代重建及其适用边界

### 2.1 原子命题与一致的解释范围

用 $`P`$ 表示所谈报纸在约定报道范围内都说真话，该范围包括和平将近这一报道，也允许其他报道；用 $`Q`$ 表示和平临近。则条件关系重建为 $`P\to Q`$。这是明确的现代教学约定：和平报道可以正确而其他报道错误，因此允许 $`P=0,Q=1`$。若把 $`P`$ 缩成仅仅“和平临近这一句话为真”，它便可能与 $`Q`$ 同义，不能再用二者展示倒推谬误。

必须固定 $`P`$ 的范围。某一报道属实、这些报纸相关报道属实、这些报纸一向可靠、所有报纸永不撒谎，不是同一个命题。原文在自然语言中有修辞性的扩大；教学形式化应声明固定读法，不能在推导途中换义。

原文形式中的“$`A`$ 是 $`B`$”被整体视为一个命题，不能未经交代把 $`A,B,C,D`$ 全当四个命题变元。本重建将“$`A`$ 是 $`B`$”整体记为 $`P`$，“$`C`$ 是 $`D`$”整体记为 $`Q`$。“$`A`$ 不是 $`B`$”相应解释为对同一命题的否定。

这里不偷偷引入类别量词。如果“$`A`$ 是 $`B`$”被另行解释为“所有 $`A`$ 都是 $`B`$”，其否定是“并非所有 $`A`$ 都是 $`B`$”，不等于“没有 $`A`$ 是 $`B`$”。前一信有关全称／特称与空类的问题，不可不加说明地搬入本信命题层面的否定。

“和平尚很遥远”在原文用作否定“和平临近”。现代严格模型把后者的否定统一记为 $`\neg Q`$；自然语言“遥远”与“不临近”是否完全互补，取决于划分标准，不能由符号本身保证。

### 2.2 一次赋值上的材料蕴含

**现代教学重建。** 在经典二值语义中，赋值 $`v`$ 给每个原子命题真或假；材料蕴含的定义是：

```math
v(P\to Q)=0\quad\text{当且仅当}\quad v(P)=1\ \text{且}\ v(Q)=0.
```

因此，单次赋值中前件假就足以使材料蕴含为真，不要求前后件存在因果、解释、证据或概念上的联系。这是现代连接词的语义定义，不能说欧拉在本信已经提出了这张真值表或接受了其全部哲学解释。

### 2.3 “必要后果”要求跨情形的保证

令 $`W`$ 是讨论所允许的赋值／情形集合。相对于这些情形的后承可定义为：

```math
P\models_W Q
\quad\Longleftrightarrow\quad
\text{对每个 }v\in W,\ v(P)=1\text{ 时都有 }v(Q)=1.
```

它等价于材料蕴含在 **每个允许情形** 都为真，而非只在当前情形为真。允许情形可由背景假设限制；选取哪些情形须另行解释。若取全部经典赋值，则得到通常的逻辑后承。

例如允许 $`v_0(P)=0,v_0(Q)=1`$ 与 $`v_1(P)=1,v_1(Q)=0`$ 两个情形。材料蕴含在 $`v_0`$ 中为真，但由于 $`v_1`$ 这个反例，$`P\not\models_W Q`$。故“当前条件句在材料语义中为真”不能自行升级为“后件必然随前件而来”。

即使没有允许情形使前件为真，上述后承也会空真；所以它仍不能证明前件可能、相关或能解释后件。若 $`W`$ 为空，所有后承都空真，模型完全失去区分力。教学时宜选择非空且说明背景的 $`W`$；这不是对欧拉原文强加现代模态系统。

## 三、两种有效条件推理：任意公式的一般证明

### 3.1 肯定前件（现代名称：modus ponens，MP）

```math
P\to Q,\quad P\quad\models\quad Q.
```

任取使两个前提都真的赋值 $`v`$。第二前提给出 $`v(P)=1`$。若结论假，即 $`v(Q)=0`$，则条件前提按定义为假，与前提全真矛盾。因此结论必真。

证明未使用 $`P,Q`$ 的内部结构，也未限定其原子数量；用任意复合公式代入同样成立。在 $`P\models_W Q`$ 的必要后果读法下，任一允许情形中的 $`P`$ 成立也依定义保证 $`Q`$ 成立。

### 3.2 否定后件（现代名称：modus tollens，MT）

```math
P\to Q,\quad\neg Q\quad\models\quad\neg P.
```

任取使两个前提都真的赋值。由第二前提，$`Q`$ 假。如果 $`P`$ 真，条件前提就会假，故 $`P`$ 必假，$`\neg P`$ 必真。跨允许情形的版本同理：若允许情形中后件假而前件真，就直接违反后承条件。

以上一般证明足以覆盖任意代入，毋须靠有限随机测试支持。有限真值表可以验证两个原子的所有组合，但只有说明公式语义及任意代入性，才清楚说明结论的范围。

### 3.3 “不会导致错误”的前提

有效性是保真：前提全真时结论不能假，不是无条件生产真结论。即使条件关系真，补入的“报纸属实”或“和平并不临近”若是假，也不能保证结论真。原文 p.143 特别强调条件命题必须真；现代审计还应明确另一前提也须真。

## 四、两种无效形式：一个反模型、两次独立核验

### 4.1 否定前件

```math
P\to Q,\quad\neg P\quad\not\models\quad\neg Q.
```

取 $`P=0,Q=1`$。条件前提真，否定前件真，结论 $`\neg Q`$ 假，正好满足反模型要求。这不是“找不到证明”，而是已经证明该形式不普遍保真。

### 4.2 肯定后件

```math
P\to Q,\quad Q\quad\not\models\quad P.
```

同样取 $`P=0,Q=1`$。条件前提与 $`Q`$ 都真，而结论 $`P`$ 假，故该形式无效。

无效不表示每个实例的结论都假，只表示这些前提不足以保证它真。如果另外给出逆向条件 $`Q\to P`$，肯定后件可借 MP 得到 $`P`$，否定前件可借 MT 得到 $`\neg Q`$；这依赖新增前提，不能倒算为原形式有效。

这两个反例也不只是利用了“材料蕴含空真”的怪现象。取允许情形集合为 $`W=\{(0,0),(0,1),(1,1)\}`$，则 $`P\models_W Q`$ 成立，且前件确有可能为真；然而允许情形 $`(0,1)`$ 仍同时反驳上述两种倒推。

## 五、单有条件句，究竟能与不能推出什么

原文 p.141 的“除此条件之外不再断言什么”，宜理解为没有单独断言前件或后件。不能夸张为“条件句不能推出任何东西”：它当然蕴涵自身，在经典逻辑中也蕴涵其等值式 $`\neg P\lor Q`$。

对无额外限制的原子命题，下列四个直接断言都不由条件句单独保证：

- 不保证 $`P`$：反例 $`(P,Q)=(0,0)`$。
- 不保证 $`\neg P`$：反例 $`(P,Q)=(1,1)`$。
- 不保证 $`Q`$：反例 $`(P,Q)=(0,0)`$。
- 不保证 $`\neg Q`$：反例 $`(P,Q)=(1,1)`$。

所列各反例都使条件句为真。上述允许情形集合 $`W`$ 包含这些情形，因而即使把条件关系理解为跨情形保证，单凭关系仍不选定当前前件／后件的真假。特定背景可能另行固定其中一项，此时须把背景算入前提。

原文“只有这两种方式正确”应限于此处逐项肯定或否定前件、后件的四种直接形式，不能写成“现代逻辑中只有 MP、MT 两种有效推理”。

## 六、物体／精神例子：覆盖与排斥不可合并省略

### 6.1 明确论域与三种谓词

**原文主张（p.144）**：每一实体或是物体、或是精神；给出否定物体推出精神、肯定物体推出非精神两个推理。

**现代教学重建**：取对象论域 $`U`$，用 $`S(x)`$ 表示实体、$`B(x)`$ 表示物体、$`E(x)`$ 表示精神。“每一实体至少属于两类之一”的覆盖前提是：

```math
\forall x\bigl(S(x)\to(B(x)\lor E(x))\bigr).
```

“每一实体不能同时属于两类”的排斥前提是：

```math
\forall x\bigl(S(x)\to\neg(B(x)\land E(x))\bigr).
```

两式合用才表达实体范围内的恰好二选一。不能仅因法文写了“ou”就断言一切自然语言“或”都是排他的；但原文给出的第二推理，足以表明此例确实依赖排斥读法或相应背景。

### 6.2 第一推理只需覆盖

已知覆盖前提、$`S(a)`$ 与 $`\neg B(a)`$。对全称前提实例化并利用 $`S(a)`$，得到 $`B(a)\lor E(a)`$。第一支被否定，故 $`E(a)`$ 成立。此证明不使用排斥；即使其他实体兼具两类，证明仍有效。

### 6.3 第二推理只需排斥

已知排斥前提、$`S(a)`$ 与 $`B(a)`$。若 $`E(a)`$ 也真，则 $`B(a)\land E(a)`$ 真，与排斥前提矛盾，所以 $`\neg E(a)`$。此证明不使用覆盖；即使另有实体两类都不属于，推理仍有效。

### 6.4 覆盖不能代替排斥：最小反模型

取一个对象 $`a`$，使 $`S(a),B(a),E(a)`$ 都真。覆盖前提真，$`a`$ 是物体也真，但“$`a`$ 不是精神”是假。因此仅从包含或的分类与肯定一支，不能否定另一支。

反方向也独立：若 $`S(a)`$ 真而 $`B(a),E(a)`$ 都假，则排斥成立，但覆盖失败；“不是物体”不能仅凭排斥推出“是精神”。

### 6.5 论域归属不能遗漏

若论域本来就只含实体，可把 $`S`$ 的限制吸收到论域中；否则必须补出 $`S(a)`$。原文“这样的某一实体”已经在自然语言中携带这种归属，现代符号不能把它漏掉。

覆盖推理若省略 $`S(a)`$，取 $`S(a)=B(a)=E(a)=0`$ 即为反例：限定实体的全称前提空真，$`\neg B(a)`$ 真，但 $`E(a)`$ 假。排斥推理若省略 $`S(a)`$，取 $`S(a)=0,B(a)=E(a)=1`$：限定实体的排斥前提真，$`B(a)`$ 真，而 $`\neg E(a)`$ 假。

### 6.6 非空、存在与哲学真实性

标准经典一阶逻辑通常规定 $`U`$ 非空且名称 $`a`$ 有指称；但这不保证实体类非空，更不保证物体类或精神类各自非空。若用实体作为整个论域，标准非空论域约定就等于另外假设至少有一个实体，须明说。

限定实体的两个全称前提，在实体类为空时可以同时空真。即使实体类非空，所有实体都为物体、没有精神，或反过来，都与“覆盖且互斥”相容。故分类本身不证明精神存在，也不证明物体存在。只有在给出具体实体 $`S(a)`$ 及相应小前提之后，才有相应实例与存在结论。

欧拉此处没有证明“所有实体恰好分成物体与精神”这项哲学分类。逻辑审计只说明：如果接受所需分类前提，并对指定实体给出真小前提，相应结论被形式所保证。不能借审计替二元论背书，也不能仅凭现代包含或的惯例就宣布原文第二式必然是逻辑失误；准确结论是它需要原文实际采用的排斥解释。

## 七、发布前检查标准

- MP、MT 都写出条件大前提与小前提；“有效”与“实质前提真实”分开。
- 两个谬误都展示前提全真、结论假的明确反模型，不把“无效”说成“结论必假”。

### 8.2 复杂度表达的确切范围

主文使用 $`O(2^nL)`$ 表示对 $`n`$ 个不同原子枚举赋值，并对总语法树大小为 $`L`$ 的前提与结论递归求值的工作量，此界成立，条件是每个节点的连接词操作和原子取值按常数代价计，且 $`n`$ 指输入公式实际出现的不同原子。

理由：恰有 $`2^n`$ 个赋值；单个赋值下，每个语法树节点访问有常数工作，所有前提与结论总计至多 $`O(L)`$。即便朴素赋值构造另需 $`O(n)`$，因为不同原子的出现数不超过总节点数，$`n\le L`$，仍被同一界吸收。若实现保存全部长度为 $`n`$ 的模型，还可能需要 $`O(n2^n)`$ 的输出空间；若逐个输出或只保留一个反模型，空间行为不同。主文没有把时间界伪称为最优下界，也没有声称所有逻辑推理都须枚举，边界合适。
