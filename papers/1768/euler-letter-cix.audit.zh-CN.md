# 欧拉《致德国公主书简》CIX：概念与论证独立审查

## 0. 范围、证据与读法

本审查处理1768年第二卷原刊第144–148页的第CIX信，信末日期为 **1761年3月10日**。已逐页核对原版图像，以文字识别协助定位，不以识别结果代替原刊。阅读必须延续到第148页恶的段落与署日，不能在“上帝也不能剥夺精神……”处截断。第144页开头的身体／精神析取与“7 Mars 1761”属于前一信；第148页的“LETTRE CX”及其后文字属于下一信，不能并入CIX。

原文定位：[1768原刊第144页](https://archive.org/download/lettresuneprinc01eulegoog/lettresuneprinc01eulegoog.pdf#page=165)、[第145页](https://archive.org/download/lettresuneprinc01eulegoog/lettresuneprinc01eulegoog.pdf#page=166)、[第146页](https://archive.org/download/lettresuneprinc01eulegoog/lettresuneprinc01eulegoog.pdf#page=167)、[第147页](https://archive.org/download/lettresuneprinc01eulegoog/lettresuneprinc01eulegoog.pdf#page=168)、[第148页](https://archive.org/download/lettresuneprinc01eulegoog/lettresuneprinc01eulegoog.pdf#page=169)。版本、日期与边界的详细证据见[来源账本](euler-letter-cix.sources.zh-CN.md)；完整教学阅读见[正文](euler-letter-cix.zh-CN.md)。

以下使用五种明确区分的层次：

1. **原文主张**：欧拉确实在本信说了什么。
2. **推理桥梁**：若要从其观察走到结论，还需要什么前提。桥梁未必在本信明说。
3. **形式重构**：本审查者为了检验有效性而另加的定义、符号、模型或证明；不是欧拉的公式。
4. **现代功能类比**：当代系统能够被要求完成的任务；不是历史影响关系，也不自动等于人的心理经验。
5. **形而上学结论**：灵魂、物质、体验、自由等究竟是什么。一个功能模型通常不足以裁定这一层。

总评：本信提出了有价值的解释要求，但其对某种简单“印痕说”的反驳，不能直接提升为对一切物质性解释的反证。反过来，给出一个能完成相似功能的有限状态机，也不能直接证明物理主义，或证明该机器具有欧拉所说的感受、判断和自由。

## 1. 原文实际区分了哪些现象？

### 1.1 感觉、观念与快感／不快不是同一个词

第144–145页说：最初的观念来自作用于感官的实在对象；感官不仅呈现对象，也使灵魂确信对象在我们之外存在。感觉总伴随程度不同的快乐或不快。对象不再作用于感官时，当下感觉消失，而观念可以保存。

应忠实写成“欧拉认为所有感觉均伴有快感或不快”，而不是把它当作本审查已经验证的普遍心理定律。此处的 plaisir／déplaisir 是感受性的愉快／不愉快，不宜不加说明便改写成当代强化学习的奖励标量。奖励信号是形式量；具有奖励信号并不自行证明系统有享乐或痛苦。

### 1.2 保存不等于当下持续想到

第145页明确否认保存的观念须一直在场，或灵魂须不断思考它。保存表现为能重新唤起、召回。欧拉把这种召回既有观念的能力称为 réminiscence 与 imagination，并说它含有记忆的源泉。

这里的 imagination 不能径直缩成现代日常汉语的“虚构幻想”。它在这一段首先承担再现先前观念的功能；“想象”一词应配合说明，而不要据词形补入生成新图像、新概念的完整理论。

“随意召回”的强措辞在第145页出现，但第146页随即承认人经常遗忘。最妥当的读法是：他描述这种能力及其典型用法，继而讨论能力失败时的现象。不能抽取前一句就归给他“任何已获得观念永远可以随意完美检索”的一贯理论；也不能把这层张力悄悄删去。

### 1.3 想起火灾不等于相信眼前有火灾

第146页的实例是：曾见过一次火灾的人，可以再现该观念，却不因此想象现在真的有一场火灾。长时间没有想到火灾，也不一定丧失再现能力。

第145页末的法文表面写的是回忆不伴随“那些观念真实存在”的确信；结合相邻的外物存在句以及紧接的火灾实例，解释性中文可以说明这里关心的是所表象对象的现实在场。严谨排版宜保留原文措辞与解释之间的区别，不擅自声称欧拉已精确提出某种现代“来源监控理论”。

最低限度的现代类比是：内容相近的表征，可以带有不同的来源标记、时间标记或现实性判断。“输入来自正在感知的场景”与“输入来自检索”需要可区别。但给机器加一个来源字段，不等于证明它具有主观意识、现实感或人的记忆经验。

### 1.4 忘了与从未知道不同

第146页先说我们会把既往观念“几乎全忘了”，随后说遗忘的观念与完全未知、从未拥有的观念有明显差别：对象重现时，前者更容易被把握，还会认出它正是自己先前遗忘的观念。

原文合并讨论了两个可分别检验的现象：

- 再次获得更容易；
- 能认出“我先前有过它”。

两者不能在现代重构里当作完全同一件事：反应变快不必然伴随正确的有意识再认，正确再认也不由速度单独证明。文中“几乎完全忘记”尤其不能偷换成“整个系统中所有与经历有关的因果信息都已完全清除”。

## 2. 第一反驳：为何残存印痕就必须使观念持续在场？

### 2.1 原文的靶子

第146–147页中，欧拉转述一群没有点名的“唯物主义者”：灵魂是一种精细物质；外物通过感官在其上留下印痕；印痕就是对象的观念；印痕持续则记忆保存，印痕全消则遗忘。

不要替这群人补上本信未给出的姓名、派别、著作或因果影响链。“欧拉在此转述的印痕说”比“一切唯物主义”更精确。本信也没有把“凡属物质都遵从决定论”正式写成一条论证前提。

### 2.2 论证重构

把物质印痕存在写作 $`M`$，把观念当下呈现写作 $`A`$，把日后仍可召回写作 $`R`$。欧拉第一反驳可以重构为：

1. 对手以持续的物质印痕解释记忆保存；在本次重构中，可召回意味着相应印痕仍在：$`R\Rightarrow M`$。
2. 如果印痕持续，那么观念就必须持续呈现：$`M\Rightarrow A`$。
3. 实际上，人可能仍能召回，却很久不想到该观念：$`R\land\neg A`$。
4. 因此，所转述的解释无法说明这种情形。

问题在第2步。由“观念与某个物质过程同一”本身，还推不出“被保存的结构在没有读出时也必定构成当下意识内容”。必须进一步把**保存的痕迹**与**正在呈现的观念**完全不加区分，或假定印痕无需激活即可持续生成现前经验。这个桥梁在本信没有独立论证。

若一个理论确实明说“痕迹存在当且仅当相应观念正在呈现”，反驳便对它有效；但物质性记忆模型没有逻辑义务采取这条规定。

### 2.3 可逐步检查的最小反模型

这是本审查者的功能模型，不是欧拉的模型，也不是关于意识的模型。

系统具有两个二值状态：$`m`$ 表示某一固定内容的痕迹是否保存；$`g`$ 表示当前是否打开该内容的读出通道。输出规则为：

```math
y=m\times g.
```

1. 学到内容后，设 $`m=1`$。
2. 一段没有召回的时期，保持 $`m=1`$，令 $`g=0`$，于是 $`y=0`$。
3. 收到召回指令或适当线索后，令 $`g=1`$，于是 $`y=1`$。
4. 读出完成，再令 $`g=0`$；$`m`$ 可以仍为1。

在第2步，保存状态存在而当前读出不存在。因此，$`M\Rightarrow A`$ 在把 $`A`$ 操作化为“正在读出”时不是逻辑必然关系。若器件以物质方式实现上述状态与门控，它就是一种物质性的保存／读出分离方案。

**模型能说明什么**：某种物质痕迹不必一直变成系统当前输出；能保存而未读出，在逻辑上不矛盾。

**模型不能说明什么**：$`y=1`$ 是否伴随某种体验；真实人的记忆是否采用这个实现；意识能否完全由物质构成；欧拉关于精神实体的整个理论是否错误。把 $`A`$ 直接改名为“意识”不会额外证明任何事情。

**与正文符号的关系**：这里的 $`g`$ 是读出开关，不是已经读出的内容；空存储时也可以发出读出请求，但输出仍为空。正文第7节直接记录保留与实际活跃两项。令 $`r=m`$、$`a=y=mg`$，就得到正文的约束 $`a\le r`$ 及三个状态。二者是不同粒度的同一反例；不要把开关、访问权限和实际注意都因字母相近而视为同一量。可执行附件又明确增加了集合式访问权限与感官输入，见[逐步教学](../../reproduction/euler-1768-cix/WALKTHROUGH.zh-CN.md)。

## 3. 第二反驳：既然彻底抹掉，何以认出曾经有过？

### 3.1 原文与其中有效的洞见

第147页问：如果印痕已被抹掉，那么当物质再次接收它时，怎么能够记得自己曾有过这种印痕？

这比第一反驳更接近一个明确的信息约束：若过去经历没有在任何当前可利用的地方造成差别，而未来输入也完全相同，那么系统不能依据已不存在的差别去区分两种过去。不过这要求“彻底抹掉”具有很强的含义。

### 3.2 未知与暂时不可提取的反模型

仍只对某个固定内容建立玩具模型。状态为 $`(h,a)`$：$`h`$ 表示是否保留“曾经遇过”的标记；$`a`$ 表示当前是否可主动读出该内容。模型使用三种状态：

- 从未遇过 $`U=(0,0)`$；
- 遇过但主动检索失败 $`L=(1,0)`$；
- 遇过且当前可检索 $`A=(1,1)`$。

主动召回的成功条件设为 $`h\times a=1`$。于是 $`U`$ 与 $`L`$ 都可能表现为“现在想不起来”。当同一个对象再次作为线索到来，按以下顺序操作：

1. 先读取更新前的 $`h`$，输出“旧／新”判断 $`r=h`$。
2. 再将 $`h`$ 设为1，将 $`a`$ 设为1。

$`U`$ 对本次对象输出“新”；$`L`$ 输出“旧”。两者在没有线索时同样不能主动召回，在对象重现时却表现不同。可见，检索失败不必等于所有相关信息消失。

顺序很重要。若先把 $`h`$ 更新为1再判断，首次遇到的对象也会被错误判为“旧”。这说明一个有用的功能模型需要明确更新时点，不能只画“存储 → 检索”箭头便算解释完毕。

此模型只把一个具体对象的区分任务压缩为两个比特，未提供开放世界中的对象识别、相似性匹配、来源核验或体验理论。$`h`$ 也未必是现实系统中的显式单一比特；相关信息可以分布在多处。只要任何可利用的历史差异仍在，“彻底抹除一切相关信息”就没有发生。

### 3.3 可以严格证明的条件命题：完整状态不可区分定理

**下述定理是现代重构，不是欧拉已经给出的数学定理。**

设两个系统在同一时刻 $`t`$ 具有完整因果状态 $`x_t`$ 与 $`x^{\prime}_t`$；完整意味着：所有能够影响未来反应的历史差别都已包含在该状态及随后明确列出的输入中。两个系统具有相同的确定性转移规则 $`F`$、输出规则 $`G`$，且收到相同的未来输入序列 $`u_t,u_{t+1},\ldots`$：

```math
x_{k+1}=F(x_k,u_k),\qquad y_k=G(x_k,u_k).
```

假设 $`x_t=x^{\prime}_t`$。那么两个系统的所有未来状态和输出均相同。

**证明**：

1. 时刻 $`t`$ 的状态相同、输入相同，故由同一 $`G`$ 得到 $`y_t=y^{\prime}_t`$。
2. 由同一 $`F`$ 得到 $`x_{t+1}=x^{\prime}_{t+1}`$。
3. 在 $`t+1`$ 重复步骤1、2。
4. 对时间步归纳，即得到一切未来状态与输出相等。

**再认任务的推论**：设过去历史 $`H_1`$ 中曾遇过目标，$`H_0`$ 中从未遇过；正确答案分别应为“旧”和“新”。若二者在询问前已汇合为同一完整状态，且之后输入相同，则系统必给出相同答案。因为正确标签不同，所以它不可能同时正确区分这两个历史。

注意，结论不是“它再也不能说出‘旧’”，而是“它不能可靠地根据那段已经不留下任何可用差异的过去，把两种情况区分开”。它可以在两种情况下都说“旧”；那只会在一种历史中碰巧正确。

### 3.4 适用条件不能省略

- **完整状态**不等于某一枚指定印痕。主痕迹消失，其他连接、标记、身体反应、记录、环境线索仍可保留历史差异。
- **相同未来输入**要求后来提供的旧照片、日志、证言等线索也一致；若它们使两个系统获得不同的过去信息，便不满足同一输入条件。外部记录属于因果可用信息，不能一面忽略，一面声称从“完全消失”恢复了记忆。
- **同一规则**也属于条件。若两个系统具有不同参数或规则，差别本身可能保存历史。
- **状态观察相同**不等于完整状态相同。只测到同样的行为或某个局部信号，不能替代定理的强假设。
- **本定理采用决定性转移，不表示物质主义等于决定论。** 若改用相同的随机转移／输出机制并假定同一状态包含全部历史依赖，则能推出相同的未来输出分布，而不是每次随机结果必相同。随机性本身也不能凭空恢复已无任何可用痕迹的特定过去。

因此，可以肯定欧拉的一个条件性问题：“真正无差别的系统如何识别不同过去？”不能直接接受另一个未经证明的等同：“日常所说的忘记就是所有可用历史差异被彻底清除”。

## 4. 脑变化、感受和判断：正面二元论论证在哪一步成立？

### 4.1 原文并不否认脑中变化

第147页承认：对象作用于感官确实在脑中造成变化。随后断言，这种变化与由其引起的观念极其不同；快乐／不快的感受以及对造成印痕的对象所作判断，都需要一种完全不同于物质、具有另一种性质的存在。

因此，不能写成“欧拉以为大脑与思想无关”。争点是脑变化是否足以构成或解释心理活动，以及两者是否属于同类实体。

### 4.2 有效形式与有争议前提要分开

一种强重构是：

1. 任何纯粹物质存在都不可能具有感受性或判断能力。
2. 我们确实具有感受性和判断能力。
3. 因此，我们的这些能力必须属于非物质的存在。

只要接受前提1，这个排除形式可以成立。困难在于，本信用“极其不同”“显然要求”等强断语表达前提1，未在本信内给出独立的充分论证。

“两种描述很不同”不是“必有两种实体”的充分条件。一个对象可以具有不同层次、不同视角的描述；另一方面，这个逻辑可能性也不证明心理体验事实上就等同于某个物理过程。审查者需要同时保留两条限制：**描述差异尚不足以推出实体二元论；物质状态能够产生相应输出也尚不足以推出体验已被解释。**

不能把本段都降格为“记忆功能尚未做好”的技术抱怨。欧拉提出的感受与判断具有第一人称和语义／评价方面的要求；即使记忆工程问题被解决，这些问题也不自动消失。

## 5. 抽象：非物体的所指，是否必须由非物质主体来把握？

第147页接着说，召回的观念经抽象可以形成容纳许多个别观念的一般观念；我们还形成关于性质与属性的抽象观念，其中没有相应的有形物体，例如德性与智慧。这里的 accidens 是传统意义的属性／偶性，不是日常意义的事故。

从这里到“抽象能力只能属于非物质主体”，至少需要一条额外桥梁：

**待论证桥梁：若一个表征具有非物体的或一般性的内容，那么承载、处理它的存在就不能是物质的。**

这条桥梁不是逻辑真理。必须区分：

1. 载体：纸上的墨迹、某个器件的状态；
2. 内容：它表达的概念或命题；
3. 所指：它是否对应一个具体物体、多个个体、某种性质，或根本没有实际对象；
4. 主体：谁或什么在理解、运用这份内容。

“德性”一词可以具有有形的书写载体，而德性不是那块墨迹，也不必是一件可拿起的物体。这足以说明不能仅凭所指的性质，直接判定表达载体的本性。它仍不足以证明墨迹、计算机或任何特定物质系统具有真正理解德性的能力。

现代分类、概括、符号操作可以作为“怎样把多个个例置于一般表示之下”的功能类比；它们不能单凭分类成功，就证明规范性、理解或精神实体问题已经解决。更不能把本信说成机器学习的训练规则，或依据今日类比补造欧拉影响人工智能的传播链。

## 6. 意志与自由：理由、强迫、因果决定是三个问题

### 6.1 原文的层级转换

第147页先将上述认识活动归于 entendement（知性／理解能力），再转向另一大类能力：volonté 与 liberté（意志与自由），一切决心和行动依赖它们。第148页说，灵魂经过成熟审议仍自由地确定自己的行动；它考虑动机，却不受动机强迫。

这不是把“记忆检索”平铺成“行动选择”的同一种机械功能。欧拉在这里明确转入自由行动者的形而上学。

### 6.2 “考虑动机而不受迫”本身没有完成不决定性的证明

须分别问：

- 行动是否对理由／动机有反应？
- 是否存在外部强制、威胁或其他特定意义的强迫？
- 在完全相同的总状态和全部先行条件下，行动是否仍可能不同？

前两个答案不自动决定第三个。作为纯形式示例，一个选择器可以依据内部规则比较行动的评价值，并依规则选取最高者。它可对输入理由发生系统响应，也可没有外加威胁；但给定完整状态与规则后仍只有一个输出。

这仅表明“对理由有反应、没有外部胁迫”的一种功能描述与决定性计算可以共存。它不证明这种选择器在欧拉的意义上自由，更不允许把欧拉直接列为现代相容论者。原文的“强迫”也可能承载更强的必然性排除意味，应由上下文解释，不宜悄悄改写成只有狭义外部胁迫。

两条常见偷换必须防止：

- 系统因为新信息、训练或反思而修改决策策略，意味着相关状态改变；这不是“同一完整状态下仍可另作选择”的证明。
- 加入随机性使结果不唯一，也没有证明结果属于主体的自由控制，更没有自动产生责任。

### 6.3 “自由之于精神，如广延之于物体”是本质断言

欧拉说，自由对于灵魂和一切精神是如此本质，以至于不能设想一个没有自由的精神，正如不能设想一个没有广延的物体；连上帝也不能剥夺精神的这一性质。

可以把其形式写为：必然地，凡精神皆自由；必然地，凡物体皆具有广延。这标示概念的本质条件，不能单独证明现实中存在某种精神，也不能单独证明有广延者不可能同时自由。后一个排除需要另加“物质中没有与自由有关的性质”等前提；本信确实断言了这种排除，但不能把类比本身误写成它的证明。

“上帝不能剥夺”在本段的逻辑是：若剥夺本质属性，该存在便不再是原义的精神。不要把它扩写成未经文本支持的一般神学结论，也不要把它翻译为一种可以用外部行为测验直接证实的心理规律。

## 7. 恶与罪：末段提出了什么，又没有证明什么？

第148页末说，据此很容易解决恶的起源、罪被容许以及世界遭受一切祸患的问题，并称人的自由是它们的唯一来源。本段措辞很广，不宜为了让论证更顺而悄悄缩成“人有时自由地做坏事”。也不能把CX随后对恶的展开倒填为CIX已经完成的论证。

应分开三项命题：

1. 自由是精神不可剥夺的本质属性。
2. 自由行动者可能作恶。
3. 一切实际发生的恶及祸患，只能来自人的自由。

命题1不单独推出命题2；命题2也不推出命题3。“可能”不是“必然实际发生”，某类恶的可能来源也不是所有恶的唯一来源。

一个只用于检验蕴涵关系的反模型是：设想世界中存在自由者，他们选择行善；同时存在一个并非由这些选择引起的有害事件。只要不另添有关所有有害事件的来源规定，这个设想并不违反“精神本质上自由”，却违反“全部祸患仅由人的自由造成”。因此，第一命题不足以推出第三命题。这里没有用这个模型否定欧拉整个神学体系；它只标出本信末段尚未展开的桥梁。

同样，“不能在保留精神本质的同时剥夺其自由”不自行回答：为何允许具体伤害、为何受害者承担后果、能否存在始终自由行善的行动者，以及不同类型祸患的因果解释。这些是后续论证的负担，不是本信一两句本质断言已经逐项完成的结果。

## 8. 放入人工智能前史时，最稳妥的定位

本信适合作为一份**关于机械解释必须说明哪些差别，以及功能解释何时不足以支持本体结论的历史文本**。可以借它训练下列区分：

- 保存与当前激活；
- 自主召回、线索诱发再认与再次学习；
- 过去经历的残留信息与经历被完全擦除；
- 表征内容与对象当下实存的判断；
- 感受、评价信号和行动输出；
- 一般概念、物质载体与抽象所指；
- 理由响应、外部强迫、因果决定、随机性与自由。

其历史意义在于问题结构，而不是已发明现代存储器、神经网络、来源监控模块、强化学习或自主代理。若无独立传播证据，不应称这些现代系统受本信直接影响。

最精确的一句总结可以是：

欧拉利用保存而未想到、遗忘后仍可再认等现象，反对把心理活动简单等同于静态物质印痕；这些现象要求解释者区分保存、激活和历史信息，但它们本身尚不能证明记忆必须依托非物质灵魂。随后关于感受、抽象和自由的二元论主张，又增加了不能由一个记忆功能模型独自裁定的形而上学前提。
