# VIII.5：逐次替换两个因数

现代正整数教学重构，不是古代实跑或一般命题的计算证明。将两个平面数写成带顺序的因数对 (a,b)、(c,d)。从 ab 开始，先替换 a 为 c，得到 cb；再把 b 换成 d，得到 cd。两个相邻比较依次为 a:c、b:d。把三项统一除以最大公度得到最小的同比三项，与 VIII.4 的最小链背景相应；这一步是现代整数算法，不是原文算法逐字重演。

(6,10)、(9,14) 先给出 (60,90,126)，公度 6，归一为 (10,15,21)。若只交换第二组因数，端点仍为 60 和 126，中项变为 140，两个相邻比变了。若同时交换两组因数的槽位，两个替换比只是调换顺序，最小三项为 (10,14,21)，首末仍是 10:21。另有首末相同但中项不同的模型样例 (2,6)、(3,4)，得到最小三项 (2,3,2)；不是等比三项。默认所有输入因数大于 1，现代开关另允许单位。

独立测试从首项 1 起用 Fraction 逐项生成并搜索第一组全整数三项。原始首项 ab 是必然可行的搜索上界。测试亦用精确比较核对首末大小。
