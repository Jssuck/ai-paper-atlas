# 《几何原本》VI.3 教学复现

[中文精读](../../papers/ancient/euclid-elements-vi3.zh-CN.md)。这是独立的坐标检验，不是古证、历史实测或一般性证明。标准库求值只探测可精确归一化的坐标：点坐标、有理参数及两腰长度均取有理数；底边长度不必有理。

## 比较的两条计算路径

- 用底边仿射参数 t 表示截点：无向段比由 abs(t)/abs(1−t) 得到，直接与 AB/AC 对比。
- 独立角度判据：AD 与 AB、AC 两个单位向量作内积，两余弦具有同一个 AD 长度作分母。检查它们的分子是否相等，并另外检查 D 在底边内部。无浮点、反余弦或容差。
- 第三条交叉检查从行列式构造 CE 与 AB 延长线的交点，验证共线、平行以及 AE=AC 是否恰在正确分点成立；不把目标比例当成交点构造的输入。
- 3 种平移 × 3 对单位方向（直角、锐角、钝角）× 5 对正整数边长，共 45 个三角形配置。枚举分母 2 至 9 的所有不同内点参数，补入正确分点（如集合已含则不重复），实际共 1224 个探针；45 个同时等比及平分，1179 个同时不等比且不平分。分别按预期的正确参数检查，不只检查两个布尔值互相相等。

主例 A=(0,0)、B=(21,0)、C=(0,28)。D=(12,12) 给出 15:20=21:28，且构造 E=(−28,0)。倒置分点 Q=(9,16) 给出 20:15，两个内积的差为 −7。P=(84,−84) 给出 105:140 且在外角平分线所在直线上，却在 B 外，不是内角平分射线的截点。脚本还拒绝共线三角形、端点和不在底边直线的输入。
