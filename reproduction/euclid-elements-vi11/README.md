# 《几何原本》VI.11：作第三比例项

配套[中文深读](../../papers/ancient/euclid-elements-vi11.zh-CN.md)。这是现代有理坐标教学模型，不是原尺规过程的机器重演，也不是一般定理的形式证明。

给定正长度 a=AB、b=AC，沿 AB 延伸至 D，使 BD=b；过 D 作与 BC 平行的线，与 AC 延长线交于 E。构造函数用行列式求交，而不在求交时直接代入 b²/a。验证器另检查点序 A–B–D、A–C–E，平行方向以及线段长平方，用无开方的方式核对给定边与复制边，并以 b²/a 核对 CE；在正长度条件下，这也验证 VI.2 的两比相等。用平方不丢失信息，是因为这些长度都是正数。该程序使用有理单位方向，仅覆盖有理坐标中的有限样本。

原向量算例 a=4、b=6 给 D=(10,0)、E=(0,15)，CE=9 而非 AE=15。负例错抄为 BD=4 时，平行条件仍成立，E=(0,12)、CE=6；AB:BD 和 AC:CE 依然同为 1:1，却不同于原题要求的 4:6。等长、交换顺序、整体反射和非法输入另列测试。

## 环境与执行

Python 3.12.14，标准库，无外部数据和依赖。进入本目录运行：

```sh
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B replay_notebook.py
```

[普通](normal.log)、[-O](O.log)、[-OO](OO.log) 各通过 8 项测试，每次扫描 576 个精确构形，其中 288 个反射构形。组合取 16 对长度、3 种旋转、3 种夹角、2 种手性、2 个原点。[Notebook](euclid-vi11.ipynb) 中 3 个代码格用标准库在共享命名空间真实执行，见[回放日志](notebook-replay.log)；不是 Jupyter 内核运行，Notebook 不预嵌运行输出。实跑可发现错抄及点序错误，不能由有限样本证明命题。
