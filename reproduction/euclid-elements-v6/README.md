# 《几何原本》卷 V 命题 6：在固定基量上扣除整批

[回到中文精读](../../papers/ancient/euclid-elements-v6.zh-CN.md)。

## 现代模型、原证重构与对照

两列各自固定基量，并先统一该列计量单位；两列可以不同量类。如第一列以长度为量类，第二列以面积为量类，代码不会把两列量值相加。标签并不转换单位。所有输入用正有理数精确表示；整体共同次数 m 和被扣部分共同次数 n 均至少为 2，且 m>n。这个严格倍量约定将结果的一份与多份分开。代码读取有理坐标的商来验证输入见证，并不声称古代原证采用除法。

从输入见证取 k=m−n，将各列基量复制 k 次，作为辅助候选。原文对一份情形显式构造右列候选，多份情形留作同理；这里把两列候选统一实现，并记录两条分支。将候选加回各列被扣部分重建整体，再用整体扣除原被扣量交叉核对余量。全流程不需要将一个给定的余量任意等分。有限网格另用直接乘法核对候选结果。

例如基量 2/3 长度单位与 5/4 面积单位，共取四份、删去三份时，各余一份；共取七份、删去三份时，余下 8/3 与 5，分别为自己基量的四倍。反例：基量 (2,3)，整体 (10,18)，被扣部分 (6,12)。余量 (4,6) 的次数都是 2，但整体次数 (5,6) 和被扣次数 (3,4) 均不在两列共享，故不能用结论替代前提。

## 环境与实跑

Python 3.12.14，只需标准库。在本目录运行：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python difference_counts.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

三种模式各通过 11 项测试。网格取三种基量坐标组成九对、整体次数 3–8 和每个更小且至少为 2 的被扣次数。54 个合法输入余一份，135 个余多份；对全部 189 个合法输入，另在右列的整体及被扣部分同时加入一份右列基量，构造余量不变的错配输入，全部被拒绝。日志仅归一化 unittest 耗时。Notebook 的三个代码单元已用标准库顺序编译执行；未启动 Jupyter 内核或前端。有限网格验证实现，不代替一般证明。
