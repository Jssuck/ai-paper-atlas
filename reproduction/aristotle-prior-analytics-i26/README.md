# I.26 最小教学复现：路线计数不是运行时间

本目录只复现有明确范围的现代 AEIO 模型和一个候选路线扫描器，不复现全部古代逻辑或实际认知难度。原文、一般证明和历史说明见[中文深读](../../papers/ancient/aristotle-prior-analytics-i26.zh-CN.md)。源码完全使用 Python 标准库，无第三方包、数据集或训练。

## 模型和计数口径

`model.py` 将 S、P、M 三个一元项的八种成员类型标为0至7：S为最低位、P为次低位、M为第三位。整数模型1至255选择哪些类型实际出现。每个出现的类型用一个对象代表；0模型排除，因此论域始终非空。这里没有‘所有对象都不存在’的模型，但允许某个项为空。AEIO分别定义为子集、不相交、交集非空、差集非空。

- 允许空项：255个类型模型。
- S、P、M都非空：218个类型模型。
- 三格各64种前提/结论组合，共192种候选式。
- 允许空项得到12个有效式；三项非空得到18个。
- `CANONICAL` 明确列出原章计数对应的14个典型式。结论A/E/I/O数目为1/3/4/6。它是声明的历史计数对象，不是代码从原文自行发现的事实。

三项非空时多出的四式是第一格AAI、EAO，第二格EAO、AEO：它们把相应全称结论弱化为特称，因此不能再冒充原章新增的独立方式。允许空项时第三格AAI、EAO不成立。本复现没有第四格，也不混入模态命题。类型压缩的一般理由须在正文证明，255次枚举本身不是一般证明。

## 可重跑命令

从本目录运行：

```sh
python3 -m unittest -v test_model
python3 run_examples.py
python3 -O -m unittest -v test_model
python3 -O run_examples.py
python3 -OO -m unittest -v test_model
python3 -OO run_examples.py
```

每模式真实输出保存在 `logs/tests-{normal,O,OO}.log` 和 `logs/examples-{normal,O,OO}.json`。测试日志含实际命令、测试名称、耗时与退出码；三模式例子JSON逐字相同。环境见 `environment.json`。`author-manifest.json` 绑定作者源码、README、环境和执行证据，不包含自身，也不包含后来由独立审查者创建的文件。

## 结果与解释

每模式18项测试通过，192种候选式在两种存在政策下均重新分类；1020次矛盾对检查、480次非空主项下弱化检查通过。

1. 对任意模型，A与O、E与I恰一真。这是反驳方向的精确对应。
2. S非空时A推出I、E推出O；S为空时A、E同真而I、O同假。故用E强反驳A、或用A强反驳E需要存在前提，不能遗漏。
3. `search` 仅扫描某结论的典型路线，输入是已经拥有的路线证书。例一A在一次检查命中、O在第六次命中，尽管O候选路线较多。例二A找不到、O第一次命中。

扫描器不推导前提、不发现中项、不验证输入证书，也不计算真实运行时间。`inspections` 是明确定义的候选检查次数，不能叫神经模型延迟、实际人类难度或一般复杂度。两个例子展示‘路线总数’与‘给定知识下的搜索工作’是不同量，并不否定原章在其语境中的启发式比较。

## 接口边界

命题类型必须是大写A/E/I/O，项名必须是S/P/M。模型和格数要求严格整数，不接受bool、浮点或字符串。存在政策要求bool。搜索输入要求无重复的典型路线元组，拒绝弱化路线、非法格数和错误形状。所有校验用异常而非会被 `-O` 删除的 `assert`；测试使用unittest断言。
