# I.26 独立代码核验

结论：通过下述有限范围核验。审查者未修改作者源码或作者日志。正文第11节曾将程序称为前提匹配；已反馈并在作者修订后复读：现在正确说明它仅扫描已给定的路线标签，不匹配前提或验证证书，第9节知识库例属手算。不存在以扫描失败证明目标为假的实跑主张。

## 独立性与方法

`independent-review/check.py` 的 oracle 从笛卡尔布尔向量构造普通 Python 集合，以子集、交集和不相交判定AEIO。它不调用作者truth、premises、term_nonempty或classifications来定义期望结果；作者函数仅作被测系统。两套代码共享本篇明示的数学问题规格，因而不是两套独立历史文献。典型14式和顺序显式声明，不能借代码认证其历史归属。

错误语义变体包括错误给A/E附加主项存在、将E解释为非A、把I解释为A或‘有些但不是全部’、把O解释为E或颠倒主谓。它们是显式写出的错误语义函数，而非自动改写作者源码的完整mutation-testing框架；见证模型编号保存在结果JSON。不可将七个变体的检出率泛化为任意软件故障检出率。

## 具体语义复核

255个非空类型集合与三项非空的218个集合一致；两政策的192种候选反模型不只是计数相等，而是逐个模型编号相等。第三格AAI、EAO的存在依赖与正文一致。矛盾对A/O、E/I不需主项非空；全称弱化和A/E互斥需要主项存在。正文给出的空主项及I/O同真反例与集合定义一致。

`search`枚举固定典型库，检查可用标签的存在；候选检查次数由目标专属顺序定义。其输入标签可包含不同目标，函数只寻找指定目标。不验证证书、前提真假、中项发现或语义蕴含。穷尽标签子集检查不等于穷尽知识库证明搜索。README与修订正文已披露此范围。

输入核验覆盖bool冒充整数、范围/类型错误、大小写、项名、方式长度、政策类型、非典型路线、重复路线和错误容器/形状。所有核验在优化模式保留。三模式并非三份独立数学证明。
