# I.10：六个不靠空实际类的手算检查

对象为x、y，实际世界为w0，另一个可考虑世界为w1。以下所有实际A、B、C都非空。表中的数字掩码1、2、3分别表示{x}、{y}、{x,y}。这是现代教学构造，不是原文的自然类事实。

## 1. Cesare局部路线成立，强对称结论不随之而来

```text
w0: A=1 B=2 C=1
w1: A=1 B=2 C=3
```

A的可能并集是{x}，B的是{y}，两者不交；实际C包含于实际A。实际C的x确实在所有世界都不是B，因此单向锚定“没有实际C会成为B”成立。然而C在w1新增y，C的可能并集与B相交，强对称结论不成立。加入“可能的C都可能是A”会排除此例，但这是额外条件。

## 2. Camestres路线得到反向结论，不准默默再换位

```text
w0: A=1 B=1 C=2
w1: A=1 B=3 C=2
```

A与C的可能并集不交，实际B包含于实际A。因此实际B中的x永远不是C。可是实际C中的y在w1成为B；反向的锚定结论失败。这恰好说明单向锚定E不是原文所使用的可换位必要E的完整解释。

## 3. 必要肯定与普通全称否定

```text
w0: A=1 B=1 C=2
w1: A=3 B=3 C=2
```

实际B只有x，而x在所有世界都是A，所以锚定必要肯定成立；实际A与实际C不交。实际B与C也不交，这是普通三段论的必然后承。但实际C中的y在w1成为B，故锚定必要否定结论不成立。“若前提为真则结论为真”不同于“实际为真的结论在另一情景仍真”。

## 4. 同一模型给必要肯定与普通特称否定的失败

沿用上一表。实际C的y不是A，所以特称否定前提成立；普通Baroco结论“某C不是B”成立。可是y在w1成为B，没有另一个实际C见证，因此固定见证的必要O结论失败。

## 5. 只把特称否定变为必要仍不足

```text
w0: A=1 B=1 C=2
w1: A=1 B=3 C=2
```

实际B包含于A。实际C的y在所有世界均不是A，满足固定见证必要O。但y会成为B，无法保证固定见证必要O结论。原因不是否定不够“强烈”，而是普通B到A的包含只约束实际世界。

## 6. 锚定E换位失败的直接检查

```text
w0: A=1 B=2 C=1
w1: A=1 B=3 C=1
```

实际B的y永远不是A，所以anchored(E,A,B)为真；实际A的x却在w1成为B，所以anchored(E,B,A)为假。API始终先写谓项、后写主项，不要把这两次调用读反。

## 固定见证成功例与换位范围

取两个世界都A={x}、B={y}、C={x,y}。A与B可能外延不交，实际A和C有共同见证x；这个x永远不属于B，故固定见证的特称必要否定成立。证明所用的是同一个对象，不能把各世界不同的见证偷换成一个固定见证。

所有这些表都可直接放进Model构造器；六个失败例在test_modal.py中有命名测试，主枚举结果另在results.json。程序结果为这些明确语义服务，不以“成功拟合”替代历史解释。
