# 《几何原本》III.30：从弦的垂线选出指定弧的平分点

教学模型输入圆心及两个有理坐标的圆周端点，还要给出从第一个端点到第二个端点的方向（逆时针 `+1`，顺时针 `-1`）。只给端点不足以指定弧，尤其不能靠「取较短那一段」区分两个半圆。历史证明见[中文精读](../../papers/ancient/euclid-elements-iii30.zh-CN.md)。代码显式使用圆心与坐标，不是对原文尺规作图过程的直接执行。

## 数据、对照与边界

- 用有理数检查输入端点到圆心的距离平方确实相等，并精确算弦的中点。圆心到两端等距，故圆心位于弦的垂直平分线；归一化弦的法向量，算出该直线与圆的两交点，近似值用 Python 浮点表示。
- 若弦由第一个端点指向第二个端点，则逆时针经过的弧位于弦的右侧，顺时针的弧位于左侧。这条规则不要求选定弧是短弧。程序按方向选取交点，而不是按「到两端距离相等」选：两个交点都满足后者。
- 两个网格测试反复使用**同一批** 2,808 个有向输入：3 个半径 × 18 个形状参数 × 13 个旋转 × 2 种端点顺序 × 2 种方向（1,326 个短弧、156 个半圆、1,326 个长弧）。圆心、端点及作为一个对照的预期平分点由有理圆上点和已知反射轴生成。按弦法向量构造的浮点交点用三种信息复核：几何距离与弦侧、生成时已知的有理平分点坐标、另从实际端点和交点的极角直接量出的扫角。相关测试使用绝对误差阈值 `2e-12`，几何量与角度分别按各自的单位比较，不以此声称一般误差上界。
- 例如，一条过 `(3,-4)` 与 `(3,4)` 的弦把半径为 5、圆心为原点的圆切成两弧。两射线分别给出 `(5,0)` 与 `(-5,0)`。前者至两端点的距离平方都为 20，后者都为 80。逆时针指定短弧时只有前者在指定弧内；沿指定方向经过后者会使两段扫角总和多出整周。给出直径两端时程序保留方向，分别选中两个半圆各自的中点；重合端点、方向或半径条件不合法时不进入浮点计算。
- 这是有限教学验证，使用三角函数量化角度也不等于验证古代公理或证明一般命题。极短弦、超大平移及极端数值范围可能有浮点消差或溢出，不在测试覆盖内。
