# VI.17 教学复现：中项正方形与外项矩形

[中文深读](../../papers/ancient/euclid-elements-vi17.zh-CN.md)

给定三个正长度 a、b、c，复制中项 b 作为第四个线段；比较确切的 a:b 与 b:c。同时在不同坐标位置构造外项矩形 a×c 和两条邻边同为 b 的正方形，按实际顶点用鞋带公式求面积。代码是现代有理坐标教学重构，不是原典证明或尺规操作的重演。

## 验算速览与边界

- 9、12、16：两比都是 3/4，外项矩形与中项正方形面积都是 144。互换外项得到两个 4/3，互换中项与外项则一般破坏命题条件。
- 只把中项改成算术平均 25/2：外项面积仍为 144，中项正方形面积却是 625/4。
- 取外项 2/3 与 3/8，则乘积 1/4 的正根恰是有理数 1/2。
- 对正有理量，乘积约成最简分数后，只有分子和分母均为完全平方数才有有理的正根。外项为 1 与 2 时，函数返回 `None`，仅表示不能用 `Fraction` 表示该根，几何平均仍存在。
- 比较函数的输入限于正整数和正有理数；零或负数不是原命题的非退化长度。有限实算不能证明一般几何定理。
