# I.3 模态换位：两个明示语义的最小检查

对应[原创中文深读](../../papers/ancient/aristotle-prior-analytics-i3.zh-CN.md)。这里只重建可检查的现代教学语义，不声称完整复现亚里士多德的模态逻辑，也不以有限枚举代替一般证明。

## 1. 两种合同必须分开

每个模型有固定非空对象域、非空有序情形列表。所有列出的情形都参与模态判断；第0个是实际情形。S与P在每个情形中各有一个外延；对象身份固定，词项外延可以变化。没有概率、未知真值、时间因果或现实数据。

- **dc（整句 / de dicto）**：先在每个情形计算A（S包含于P）、E（两集合不交）、I（交非空）、O（差非空），再对整句真值应用N（全真）、P（至少一真）、C（有真有假）。
- **dr（实际主项 / de re）**：先从实际S中选对象。A/E要求每个对象，I/O要求至少一个对象；再对该固定对象的谓项成员关系应用N/P/C。E/O对谓项取否定。故dr特称N中的见证是同一对象，不能每个情形换一个。
- `reverse()`只交换两个词项的全部外延序列，实际情形仍为0。它不是对原命题取否定。

dc中的C作用于整句，dr中的C作用于逐个对象。这两个C不等价。dr的C-A与C-E相同，C-I与C-O相同；这是双向可能定义导致的改质，不是词项换位。若实际S为空，dr的C-A与C-E因全称量词空真而为真，即使所有情形解释固定；因此不能把它们等同于整句“有真有假”。

**历史边界。** I.3自然/通常意义的偶然否定不按普通否定换位；本实验dc-C-E反而始终对称，dr-C-O又有反向失败。因此二者都不能冒充该段全部规则的唯一历史解释。这些失配用于揭示形式化需要额外选择，不是据此宣判古文矛盾。I.13/I.17也只作为有界语义比较，不重新计完成。

## 3. 枚举的精确口径

对象数取1、2、3；情形数取1、2。每个情形的S/P外延都从全部子集取值，包含空项。模型总数为4+16+16+256+64+4096=4452。情形有标签且允许重复：同一语义结构的重命名、重复世界仍可能多次出现，不把计数称为同构类数。

每模型有2种语义×3模态×5规则=30条候选记录。五规则是A→反向I、加“每世界S非空”守卫的A→反向I、E→反向E、I→反向I、O→反向O。先检查守卫，再检查前提，仅前提真时评估是否反例；JSON中的premise_models是相应有效前提数，不是所有模型数。总共评估133560个规则槽位，带守卫的槽位可能被跳过。

独立oracle不调用生产categorical/modal函数，而将位掩码展开为布尔矩阵并计数。对4452模型×3模态×4式型×2语义共106848个结果逐一比较。18项测试在normal、-O、-OO三种模式各自通过；每模式106848次比较零差异，三份规则结果逐字节相同。此oracle仍属于本教学包，不能据此称为独立历史解释；另见[独立数学代码审查](../../papers/ancient/aristotle-prior-analytics-i3.technical-review.zh-CN.md)，其核查范围和结果以报告为准。

## 5. 逐个可以手算的见证

集合中的0、1只是对象编号，括号中依次给出世界0和世界1。

1. **空项破坏A→I**：D={0}，S=P=(空集)。dc-N-A与dc-P-A真，反向I没有见证。
2. **实际存在不保证必要存在**：S=P=({0},空集)。dc-N-A真，但第二情形没有交点，dc-N-I假。
3. **每世界一个见证不等于固定一个见证**：D={0,1}，S=P=({0},{1})。dc-N-I真；dr-N-I假，因为实际对象0不在第二世界的P中。
4. **dr必要否定换位失败，实际两项均非空**：D={0,1}，S=({0},{0,1})，P=({1},{1})。原实际S只有0，它始终非P；反向实际主项含1，而1在第二世界是S，所以反向dr-N-E假。
5. **dr必要肯定特称换位失败**：D={0}，S=({0},空集)，P=({0},{0})。0是实际S且始终P；反向需0始终S，不成立。
6. **可能否定不是不可能肯定**：S=({0},{0})，P=({0},空集)。dc-P-E真，同时dc-P-I也真，所以“非dc-P-I”为假。
7. **dr偶然O换位失败，实际两项均非空**：S=({0},{0})，P=({0},空集)。实际S中的0对P有真有假，原dr-C-O真；反向实际P中的0始终为S，反向dr-C-O假。这正说明本dr模型不完整实现原章的偶然特称换位规则。
8. **整句严格偶然不能随意弱化**：D={0,1}，S=({0},{0,1})，P=({0},{0})。A整句有真有假，所以dc-C-A真；交集始终含0，反向I始终真，所以dc-C-I假。每世界S均非空，失败不是空项造成的。

## 6. 范围与后续

模型没有刻画自然倾向、概率权重、词项本质或古代完整解释体系。它没有估计人的推理表现或AI可靠性。可以另行加入刚性词项、个体必要身份或其他古代语义方案，再明确验证其所支持规则，但本包没有完成这些延伸。

文中的反例足以否定对应现代合同下的无条件蕴涵；它们不否定所有加条件规则，也不证实或证伪原作者的一整套哲学理论。一般有效性依赖正文证明和清楚的语义合同，有限运行只提供可查的实跑证据。
