# 独立技术复核的运行证据

这是对 I.3 教学代码的第二实现核验，不是新的一篇论文，也不是对古代唯一语义的认证。

- [independent_oracle.py](independent_oracle.py) 逐对象枚举跨世界成员历史，用 Python 集合的包含/不交关系计算命题，再按真值计数计算模态；不导入生产模型、枚举器或语义函数。
- 它从生产 JSON 读取待核数字，但独立重算全部 4452 个模型、30 个规则的 60 个计数字段，另外重验其中 22 个首反例，均无差异。
- [test_oracle.py](test_oracle.py) 包含 5 项测试，检查枚举口径、跨世界见证、固定解释的模态退化、否定对偶及全部计数/反例。实际主项为空时，de re 全称 C 式空真；固定解释的 C 不一定一律为假。
- [run.sh](run.sh) 在 normal、-O、-OO 三模式各运行 5 项测试及独立统计，输出真实[测试日志](tests-normal.log)、[优化日志](tests-O.log)、[双优化日志](tests-OO.log)与三份[结果](results-normal.json)。[比较记录](comparison.log)确认结果逐字节一致。
- 审查另在三模式重跑生产的 18 项测试，见[normal](production-tests-normal.log)、[-O](production-tests-O.log)、[-OO](production-tests-OO.log)。每模式包含生产测试自带的 106848 次布尔矩阵比较；这与本目录的独立逐对象枚举是两层核验。

审查早期一项测试曾错误地把“固定解释下整句 C 恒假”推广到空实际主项的 de re 全称式。该测试假设已修正；生产代码无须改变。现有日志是修正后的真实运行结果，不将先前失败说成通过。

运行：在本目录执行 `sh run.sh`。仅 Python 标准库，脚本覆盖本目录内自身日志/结果。有限运行不能替代一般证明，计数不是同构类数，也不是现实人类推理或机器学习评测。
