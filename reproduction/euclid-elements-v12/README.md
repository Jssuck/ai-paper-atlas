# 《几何原本》V.12 教学复现：同比怎样传到合计

回到[中文精读](../../papers/ancient/euclid-elements-v12.zh-CN.md)。这是原创的正有理数教学模型。它区分逐项比较、总量比较与精确数值检查，不是欧几里得的一般量证明，也不是历史软件重现。

## 检查过程

- `probe_sum` 对每一组比使用同一个正整数对 (m,n)，比较 m·前项 与 n·后项，记录 −1、0、+1，再单独计算总量的符号。输入用正整数或精确 Fraction，并需在共同单位下表达，代码不做单位换算。单位标签同时检查比的两项和进入同一和式的项；长度比与面积比可能同比，但不能据此把两种量相加。
- `exact_sum` 用精确交叉乘积比较每组比与第一组比，输出逐项有理商、合计比和前提真假。对 (2:3,4:6,6:9)，合计为 12:18；探针 (1,1)、(3,2)、(2,1) 分别得到逐项和合计都为 −1、0、+1。精确有理数检查与有限搜索不是一个算法。
- 对 (1:2,3:3,6:5)，合计比为 1，等于中间比，但逐项不同比。探针 (1,1) 得到 (−1,0,+1)，总符号为 0；这是不同符号的差额抵消，不是同比的证据。合计比以各后项占后项总和的份额加权，本例权重为 2/10、3/10、5/10；简单平均则为 9/10。
- 对 (101:100,102:100,103:100)，窗口 1 至 20 没看到逐项符号分歧，扩大至 40，按先 m 后 n 的顺序在 (34,35) 首次发现 (−1,−1,+1)，合计为 −1。精确数值检查直接确定前提不成立。None 仅表示窗口内未找到反例，不能据此判定同比。
- 三种解释器模式各通过 10 项测试。有限网格取 16 个有序整数比、4,096 个有序三组比和每组 9 个探针，共 36,864 次签名比对；其中 88 个三组比满足精确前提。测试用逐项有理商与阈值 n/m 独立计算预期符号，另检查空集合、多个集合大小、输入边界、类型约束及有界漏判。这些样例没有训练数据或模型评测，有限网格也不能证明一般定理。
