# 《后分析篇》II.4：包含链、完整定义标签与前提承担

本目录是原创现代教学重构，不是古代认识论的完整复现；不认证人的本质、灵魂理论或本质发现能力。原章对象为91a12–91b11；对应[深读正文](../../papers/ancient/aristotle-posterior-analytics-ii4.zh-CN.md)。

## 1. 原文问题与模型边界

原文追问通过中项证明“是什么”时，是否已在小前提接受了另一种完整本质说明。普通属性传递与定义资格必须区分。本模型将其分解为两种可审计检查：

- 外延层：C包含于B，B包含于A，故C包含于A。只有再给A=C，才能夹逼得到三者相等；这不是从普通链自动推出互谓。
- 声明层：`attribute`仅属性；`essential_part`表示作者声明的本质组成条件而非完整定义；`full_definition`表示作者声明的完整定义。角色不是程序从集合中发现的事实。此三层是教学分类，不声称是原文已形式化的三值演算。

`compose`采用显式约定：组合结果取两条角色中较弱者。双完整定义才能保留完整定义标签；它同时报告小前提已经声明了主项的完整定义。`full_definition`必须至少满足此有限域外延相等，然而通过该最低检查仍不证明真实本质。`essential_part`只作包含检查，不把“动物”之类组成条件误作“人”的完整定义。

支持来源取两前提标签并集。包含指定目标标签便报告显式目标依赖；未包含不等于独立，更不能识别未登记的同义改写、暗含前提或所有乞题。程序不使用图上有环等同认识上循环的捷径。

## 2. 可以手算的例子

C={0}、B={0,1}、A={0,1,2}给出严格包含链，结论成立但三者不同。把三者改为{0}，外延相等；然而双`attribute`输入仍只得到属性角色，双`essential_part`仍不是完整定义，双`full_definition`则保留原来已声明的定义承担。即使最后一种，`actual_essence_certified`始终为false。

夹逼的一般证明无需程序：任取B中对象，它属于A，再由A=C属于C；已有C包含于B，故B=C=A。有限枚举只检查实现，不能用样本代替这个一般证明，也不能从集合等同跳到本质同一。

## 4. 枚举口径、预期计数与限制

对n=0,1,2,3,4分别取有标号的n元素论域，独立遍历A、B、C所有子集，包含空论域、空项。总计4681组三集合，其中341条包含链、220条C非空的链；端点相等的链31条，其中26条C非空；310条有效链端点不等。传递与夹逼违例均为0。独立oracle按每对象的三个成员位逐一检查，而非调用集合分类函数，两者输出应完全相等。

计数也可由组合分析核对：每对象有8种任意成员模式；符合C⊆B⊆A的模式有4种；端点相等的合法模式只剩全不属于或全属于两种。因此总数分别为各n的8^n、4^n、2^n之和；C非空的链扣除3^n，非空同外延链扣除1。空模型的形式真值不承担现实存在。

同外延证书遍历9种角色组合，只有双full_definition输出该角色；4种组合至少双essential_part而达到组成条件或更强角色，剩余5种只是attribute。所有9例均不认证真实本质。输出角色反映程序约定，不构成对原典本质传递原则的独立实验证据。

## 5. 小练习

1. 仅已知C⊆B⊆A，能否得到A⊆C？不能；第2节严格链是反例。
2. full_definition大前提配attribute小前提能推出定义吗？本模型输出attribute；只增强一边不够。
3. 目标标签没出现在支持列表，能否宣布没有乞题？不能；检查只覆盖登记的显式标签。
4. 真正想证明该模型超越小样本，应补什么？形式传递与夹逼给一般元素证明；角色规则则是定义好的程序约定，不能由更多样本把它变成真实本质理论。
