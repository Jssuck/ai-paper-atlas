# I.13 独立技术核验

本目录保存独立审查者实际重新执行的代码与日志。没有外部依赖或网络请求。

在上一级复现目录运行：

```sh
python test_geometry.py
python -O test_geometry.py
python -OO test_geometry.py
python independent/check.py
```

[commands.json](commands.json)记录四条命令的真实开始时间、返回码、时长与Python版本，全部返回0。三模式各28项测试通过。附加核查不只是调用生产证书验证器判真：

- 360组任意有理向量/两方向符号，独立展开复数乘积恒等式，并对照生产乘法。
- 36组额外有理平移、斜基线、不等长反向射线、两侧与三个位置分支。独立算旋转对、同侧垂线与预期分支。
- 324次数值字段篡改或独立输入变更；保留字段结构，只改有理值，同样必须拒绝。
- 30个额外有理周数输入，独立算三个相邻扇区并检查非负性与总量。
- Notebook 6个代码格在新共享命名空间重新compile/exec，不改写原notebook；捕获输出逐字与已保存输出比较，全部一致。未使用Jupyter kernel，不宣称浏览器呈现核验。

范围：这些是有限回归证据，不能替代一般恒等式证明或原典论证。检查器从独立输入重算证书，是一致性验证，不是可信证明内核，也不针对恶意自定义Python对象。
