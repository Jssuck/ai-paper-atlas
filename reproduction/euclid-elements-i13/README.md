# I.13 的精确教学核验

本目录是原创的现代教学模型，不是古代程序复原或完整形式化证明；不复制原典。原文讨论直线上的相邻角等于两直角，本模型显式检查点序、半平面和普通角范围。

## 文件与运行

Python 3，仅标准库；不联网、不安装依赖、不读取秘密。

```sh
python run_all.py
```

该命令顺序执行普通、`-O`、`-OO` 三种模式的 `test_geometry.py` 与 `run_examples.py`，随后创建并执行教学 Notebook。八条真实子命令、时间、退出码和日志路径见 [run-summary.json](run-summary.json)，环境见 [environment.json](environment.json)。重跑会刷新这些生成证据。

- [geometry.py](geometry.py)：有理向量证书与独立角度分拆模型。
- [cases.py](cases.py)：360 个正证书、16 个负证书及 66 个角度分拆输入。
- [test_geometry.py](test_geometry.py)：28 项测试，覆盖反射、输入绑定、共线但同向、零向量、退化角、浮点/布尔值拒绝。
- [逐步走查](WALKTHROUGH.md)：模型、公理依赖、一般代数论证和反例。
- [教学 Notebook](teaching.zh-CN.ipynb)：6 个代码格。
- [校验清单](SHA256SUMS.json)：除自身和缓存外的公开文件 SHA-256。

## 两层模型不可混淆

向量层直接用任意有理坐标，不计算角度小数，也不假定有理向量的夹角是有理周数。旋转对的正虚部说明两个角均为普通角；乘积为负实数，结合角度合成的现代解释才导出半周。

角度层另外输入有理周数，预先采用普通角和可加测度，用来展示辅助垂线前后两种分拆。`1/2-t` 是这层对补角的定义，不能循环论证原几何定理。

证书验证器从独立传入的 B/C/D/A 重算全部字段，额外字段、漏项、篡改都拒绝。这是一个小型回归检查器，不是可信证明内核，也不宣称防御恶意 Python 对象。
