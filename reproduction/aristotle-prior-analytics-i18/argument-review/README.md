# I.18 独立论证核验

这是独立于作者 `model.py` 的集合实现；没有导入作者函数。只核本篇明确声明的现代教学语义，不将有限枚举当作亚里士多德模态理论的完备解释。

## 一般证明重建

令实际点为0，所有量词主项均取实际外延。对每个实际C对象x，严格偶然A给出某世界w使x属于A_w，也给出某世界v使x不属于A_v。若所有世界满足A_w与B_w互斥，则第一见证w必使x不属于B_w。因此每个实际C对象都可能非B。将“每个”改为“存在一个”可用同一见证证明特称版。这里只用了偶然的正向可能部分；实际E(A,B)单独不能替代全世界互斥假设。

第二个见证v只保证非A，不能保证B。因此不能把弱可能非B升级为严格偶然非B。w也不必等于实际点，不能自动推出实际非B。上述证明不依赖域或世界有限。

交换B和C时，相同证明给出B对象可能非C，不能自动交换结论的主谓。在全称偶然前提且B、C均刚性时，若有对象实际属于B∩C，其成为A的见证世界因C刚性而违反A/C持续互斥。因此B/C全称互斥；两者刚性再给出必要互斥。这是额外桥接的教学定理，不是古代原文隐含假设的认证。

**特称不能沿用这一全称换位。** 反例：域{0,1}，两世界B均为{0,1}、C均为{0}；A由空集变为{1}。存在B对象偶然A，A/C始终互斥；但没有实际C对象可能非B。原文数量/位置规则必须与这一单独的现代反例区分。

## 有界独立实跑

执行目录为本文件所在目录：

```sh
python check_arguments.py > normal.json
python -O check_arguments.py > O.json
python -OO check_arguments.py > OO.json
```

三个模式均实际运行；核验条件使用显式异常而非可能被优化移除的`assert`。每模式枚举1和2对象、两世界、实际点固定0，共4160配置。另核49920次严格偶然改质等价、24960次实然E换位；满足前件的直接全称/特称桥接分别702/520例，反向原方向分别702/520例，刚性反向全称56例。空主项允许全称空真，特称要求见证；这些数量不能当作非空前提的计数。

日志保存七种缺口反模型：无持续互斥时全称/特称失败、严格结论全称/特称失败、反向全称/特称换位失败、即使刚性仍失败的反向特称。自动挑选的某些最小反例含空主项；最后一个特称反例B和C均非空，不能归因于空真。

还为实然A/I/O × 偶然A/E/I/O × 两个前提位置共24个布局，各找出端项非空且刚性的重合模型和分离模型。它们只证明这些现代布局不确定端项肯否关系，不能证明原语言全部不定命题的处理或每个亚里士多德判准。

本记录的脚本、环境与三模式输出均公开；原文扫描不打包。
