# I.18 独立代码核验

## 核验对象与方法

独立核读 `model.py`、`demo.py`、`test_model.py`、复现README、环境与作者输出。审查不把原作者模型当作唯一历史解释；只检查它是否实现公开约定的实际主项、逐对象模态、量质、持续排斥与刚性。

独立程序[check_code.py](code-review/check_code.py)将掩码经整数除法另行解码，按对象的真假次数定义四种模态，不调用作者 `extension` 来形成期望值。所有9个谓主项组合、4种量质、4种模态逐一比较；另独立检查外延、持续互斥、刚性以及全体对象同一世界的可能性。范围包括对象数1、2的全部两世界赋值和两个实际点，以及固定种子产生的128组三对象三世界赋值的三个实际点。后者是样本，非完整枚举；重复世界和同构模型均未去重。

所有失败判定使用显式异常，不依赖可被优化移除的 `assert`。同时重跑作者13项测试、全部demo，并将Python元组经JSON序列化归一后与保存输出比较。审查器开发时曾直接比较内存元组与JSON数组而误报不一致；已修正此序列化比较问题，再完整重跑三模式。此为审查器问题，不是作者真值模型错误。

## 结果

普通、`-O`、`-OO`模式的独立结果见[普通](code-review/normal.json)、[-O](code-review/O.json)、[-OO](code-review/OO.json)。三模式内容一致。每模式：

- 8704个配置（8320完全枚举配置，加384个三世界样本配置）；
- 1253376次命题真值比较；
- 53376次外延、78336次持续互斥、26112次刚性、156672次共同可能性比较；
- 93个非法输入探针均拒绝；
- 9类有意注入的语义错误均被独立oracle检出，包括M/N交换、Q误弱化、数量错误、忽略实际索引、否定符号、持续性错误、刚性错误和共同世界量词错误。

另对8个命名模型再次进行全方法比较；这些额外比较不计入上面计数。重跑作者输出吻合：8320配置、149760次Q肯否比较、4888正向桥、224反向全称强桥、8320实然E换位；24失败布局均由作者程序再次实际求值。原始作者测试重跑日志：[普通](code-review/author-tests-normal.log)、[-O](code-review/author-tests-O.log)、[-OO](code-review/author-tests-OO.log)。

输入检查覆盖空或畸形世界、越界掩码、未知项／量质／模态、错误实际点、布尔值冒充整数、生成器参数及共同可能性标志。并不宣称覆盖任意恶意Python对象、资源耗尽、并发或完整安全审计。

## 结论与范围

在所公开语义及所列测试范围内，未发现阻止发布的实现缺陷。普通／优化模式结果一致；全称空真没有被误当存在，严格偶然未被偷换为弱可能，反向刚性桥只对全称偶然前提检查，没有错误推广到特称。一般桥接定理的理由仍是正文与README中的逐见证证明，不是这125万次有限比较。

没有运行古代体系完备性证明、无限模型判定、真实数据实验、性能基准或GitHub CI；上述结果不是这些未做工作的通过声明。数学与原典审查独立另记。最终审查版本的SHA-256见[绑定记录](code-review/reviewed-hashes.json)。
