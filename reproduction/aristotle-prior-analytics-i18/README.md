# I.18 最小教学复现：桥接条件，而非古代体系的自动验证

本目录配合[中文深读](../../papers/ancient/aristotle-prior-analytics-i18.zh-CN.md)。它是原创、有限、可复跑的现代模型诊断；**不是**亚里士多德写过的程序，也不宣称这一语义唯一忠实或完整。原文 I.18 的阅读、译本和校勘责任由正文与来源台账承担。

## 模型约定

对象域为 `0..n-1`，非空。每个世界以 `(A,B,C)` 三个二进制掩码给出三个项的外延。世界序列非空，`actual` 显式选择其中一个；所有列出的世界都参与模态评估，不添加隐藏的可达关系。谓项外延可以变化。**主项量词范围固定在实际世界外延**，不随评估世界变动。这一约定尤其不能直接继承普通全称否定的模态换位。

`categorical(predicate, subject, form, mode)` 的顺序总是谓项在前。`A/E` 对全部实际主项对象求值，`I/O` 对至少一个实际主项对象求值；`A/I` 肯定、`E/O` 否定。每个对象的 `actual` 取实际真假，`possible` 至少一个世界为真，`necessary` 所有世界为真，`contingent` 至少一个真且至少一个假。以下简称四种方式为实然、M、N、Q。

因此 Q 的肯否逐对象等价；M 不等于 Q，N 否定可满足 M 否定而不满足 Q 否定。空主项上全称真、特称假，程序不偷偷施加传统存在预设。`jointly_possible` 另行检查所有实际对象能否在**同一个世界**满足肯定或否定，不与逐对象 M 混淆。

## 两条一般教学命题及边界

### 正向桥接

假设每个世界的 A、B 外延互斥，且每个实际 C 对象都严格偶然地为 A。任取实际 C 对象 x，由 Q 可选一个 x 属于 A 的世界 w；该世界互斥，所以 x 不属于 B。因此每个实际 C 对象都 M 不为 B。若 Q 前提只是特称，取其给出的同一个对象即可得到 M 特称否定。这是任意非空世界集上的逐见证证明，**不是**由两世界枚举推出来的一般定理。

程序另外保留实际 E(A,B) 前提，以匹配源文形状；持续互斥已蕴涵这个实际前提，故这一教学桥是更强的充分条件，不自称从古代句子中读出的隐藏公理。Q 否定也适用，因为它包含可肯定的一支。结论只有弱 M，既不一般是实然，也不一般是严格 Q。

### 反向全称的强桥接

把实际否定放到 A/C，严格偶然全称放到 A/B。在持续 A/C 互斥且 B、C 外延刚性的条件下，任取实际 B 对象 x，Q 给出 x 为 A 的世界；若 x 属于实际 C，C 刚性令它在那里仍为 C，与互斥矛盾。故实际 B 与 C 互斥，换位得实际 E(B,C)，进而得 M E(B,C)。这里 B 刚性甚至比这一步证明实际需要的更强，仍保留以清晰表达“两外项都刚性”的充分方案；不宣称最弱条件。

**该证明只针对 Q 全称，不扩张到 Q 特称。** 特称至多给出某个 B 不为 C，不能换位得到某个 C 不为 B。实际外项互斥这个较强结果也提示：这是一种现代教学修补，不能把它当成 I.18 本身已经断言实然结论。

## 八个命名模型

掩码中最低位代表对象 0。全部原始世界和结论真值在[实跑 JSON](results/demo.json)中保存。

|名字|作用|
|---|---|
|`missing_persistence`|一个对象始终 B、C，只在另一世界 A；实际 E(A,B) 与 Q A(C) 成立，却无 M 非B(C)。裸前提不够。|
|`bridge_without_actual_conclusion`|另一个世界对象离开 B 并进入 A；持续互斥保 M 否定，但实际否定仍假。|
|`bridge_without_strict_conclusion`|C 对象始终非B；它可A可非A。桥与源形前提成立，结论 N 否定、M 否定真，Q 否定假。|
|`possible_negative_not_convertible`|同一实际对象始终 B，后来非C；M 非C(B) 真，但 M 非B(C) 假。|
|`objectwise_not_joint`|两个 C 对象轮流属于 B；各自可非B，却不存在两者一起非B的世界。|
|`stable_overlap`|稳定的 C 包含于 B，A 在全部对象／空集间变化；用于原文失败布局的包含端。|
|`stable_separation`|稳定的 B/C 分离，A 同样变化；用于失败布局的排斥端。|
|`empty_subject`|核对空主项下全称空真不能提供特称见证。|

此外，24 个失败布局的配对：实然前提在 B 或 C 一侧，实然量质为 A、I 或 O，另一侧 Q 为 A/E/I/O；每种布局分别造稳定包含与分离模型，两个模型都满足同形前提，端项却有相反的 N 全称关系。每次都实际计算前提，不仅打印预设结论。实际肯定用 A0 为全域，实际 O 用 A0 为空集，另一世界翻转 A；两个外项均非空。程序没有为“不定”另造第五种语法，也不把这24组冒称原文全部可表达式。

## 环境、命令和真实结果

仅 Python 标准库，无第三方安装、付费服务、密钥或网络调用。环境记录见 [environment.json](environment.json)。在此目录运行：

```sh
python -m unittest -v test_model
python demo.py
python -O -m unittest -v test_model
python -O demo.py
python -OO -m unittest -v test_model
python -OO demo.py
```

保存的日志分别为 [普通](results/tests-normal.log)、[-O](results/tests-O.log)、[-OO](results/tests-OO.log)，以及 [普通 JSON](results/demo.json)、[-O JSON](results/demo-O.json)、[-OO JSON](results/demo-OO.json)。三个 JSON 逐字节相同；测试不靠会在优化模式消失的 `assert` 语句执行模型校验。

每种模式：13 个 unittest 测试通过；枚举 n=1、2，两标号世界及两种实际位置，共 **8320 个配置**（不是同构类个数）。统计为：

- 149760 次严格偶然肯否等价比较；
- 4888 次满足正向桥和前提的量质配置；
- 224 次满足反向全称强桥和前提的量质配置；
- 8320 次实然全称否定换位比较；上述三类合计 `checks=13432`；
- 1008 个未经桥接的正向规则失败配置（按前提量质计数，不是不同模型个数）；
- 24 个失败布局配对，另含 144 次前提/端项断言，不混入 `checks` 数字；
- 八个命名模型的全量可读真值。

自动测试还覆盖非空世界／对象限制、错误掩码、未知项、未知量质或方式、错误实际索引、布尔值假扮整数、冻结数据结构、空项与生成器边界。真值模型不含对象自然本性、时间因果或学习数据；没有古代逻辑的完整性证明、性能基准、真实 AI 实验或无限模型自动验证。一般命题的责任在上面的证明，而非有限测试规模。
