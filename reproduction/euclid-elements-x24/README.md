# 《几何原本》X.24：可公度的中项边所成矩形

以 `u>0` 为参考长度，令 `q=(x/u)^4` 为正有理非平方数，令 `h=y/x` 为正有理数。`form_rectangle(q,h)` 返回相对矩形面积的平方 `h²q`、边长 `x` 的正方形与该矩形的面积比 `1/h`，以及等面积正方形的边长相对 `u` 的四次幂 `h²q`。等面积边长是后一量的正四次根。因为 `h²q` 与 `q` 属于同一非平凡平方类，两面积均不与参考平方可公度，但互相可公度。

例如 `q=6,h=2` 得相对面积平方 24、面积比 `1/2`；`q=16/15,h=9/4` 分别得 `27/5,4/9`。仅平方可公度的两边未必产生中项面积，例如取 `q=2,h=√2` 会给面积平方 4；这里 `h` 不是有理数，不是函数的合法输入，也不反驳命题。代码不用浮点近似，不判定任意实数。

独立基线用试除求既约分数的平方自由签名，并核对交换两边不改变面积。在 `q,h` 的原分子、分母都在 1–8 的 4,096 个有序代表中，3,328 个接受且保持平方类，768 个是平方前提之外的对照（未去除重代表）。有限校验不能代替一般性证明。
