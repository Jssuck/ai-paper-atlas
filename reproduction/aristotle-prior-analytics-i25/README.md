# I.25：项、命题边、推理步与证明出现次数

本目录为原创教学重构，不是亚里士多德原记号的执行器，也不主张这是本章计数语言的唯一历史解释。仅用 Python 标准库；无数据下载、第三方依赖或密钥。建议 Python 3.10+；实际环境见 [environment.txt](logs/environment.txt)。

## 语义及可检验边界

边 `(a,b)` 表示“每个 a 都是 b”，即集合包含；允许空类。规则只实现传递性：从 `(a,m)` 与 `(m,b)` 得 `(a,b)`。因此一般集合语义中的自反包含虽永真，程序不会无条件补上；`closure` 计算**正长度有向可达关系**，环可以导出自反边。这是规则闭包，不是所有语义后承的完整判定。

`chain_report(terms)` 只接受至少两个互不相同的非空字符串项，初始前提恰为相邻项的有向边。记录区分：

* 不同项数 n；不同初始前提边数 n−1；
* 所有可达有序项对 n(n−1)/2；
* 扣去初始相邻边后，不同非邻接结论数 (n−1)(n−2)/2；
* 产生这些结论的一份证书里的规则使用次数，不是所有可能证明的数量；
* 单独证明首项包含于末项的二元树所需推理步 n−2，不等于全部可推出结论数。

一般计数的**数学论证**是：线性链仅有 i<j 可达；距离至少 2 的有序对数为 (n−2)+(n−3)+…+1。不是因为程序枚举了有限多个 n，所以一般公式成立。

向原 n 项链末端增一项，新非邻接结论有 n−1 个，邻接边是新增前提而不计为结论。内部插入也令非邻接结论总数增加 n−1，但含义不同：原来跨过插入位置的**直接前提边**现在被归类为非邻接结论。例如 `A→B→C` 插入 X 为 `A→B→X→C`：新增计入的结论为 `A→X` 和 `B→C`；后者没有新端项，且从旧前提清单移到结论清单。不能把这个差值直接说成“全是涉及新项的新命题”。

`proof_tree_stats(tree)` 的叶 `('given',a,b)` 是假设出现；内节点 `('via',left,right)` 必须具有同一中项才能组合。对 k 个内节点的满二叉证明树：边数既是 2k，又是总节点数减 1，故叶出现 k+1，总节点出现 2k+1，前提槽 2k。k=0 是只有一个假设的退化树。这里“前提槽”是每一步两个输入位置，并非不同前提命题数。函数逐节点验证组合并统计，深度超过 200 抛出异常（实现保护，不是逻辑限制）。

共享子证明会被按出现展开。例如先由 `A→B,B→A` 得 `A→A`，再将同一个子证明同时作为两个输入，树展开有 3 次推理、4 个叶出现、7 个节点；DAG 中只有 2 个不同推理对象及 4 个不同节点对象。重复项、环与 DAG 不能直接套用“不同项”的线性链公式。

## API 与证书

* `closure(edges)`：去重后的正长度闭包；一般有限有向图均可输入。
* `chain_report(terms)`：前提、结论、项数及按距离递增构造的三元组证书。
* `verify_certificate(edges, steps, target)`：每个步骤 `(a,m,b)` 检查两条前提均已存在，然后加入结论。禁止依赖未来步骤；目标必须实际作为某个合法步骤结论出现，不能只在初始前提中。容许冗余步骤，不检查最短性。格式错误抛 `ValueError`；格式正确但推理无效返回 `False`。
* `proof_tree_stats(tree)`：检查二元树中项及统计出现次数；叶假设不对照外部前提数据库。

边用二元 tuple/list，标签必须是无首尾空白的非空 str。链输入必须 list/tuple 且无重复标签；证书步骤是 iterable 中的三元 tuple/list。所有安全检查和测试均不用可被优化移除的 `assert`。

## 重跑

在本目录执行：

```sh
python3 -m unittest -v test_model
python3 run_examples.py
python3 -O -m unittest -v test_model
python3 -O run_examples.py
python3 -OO -m unittest -v test_model
python3 -OO run_examples.py
```

三种模式的原始输出见 `logs/tests-{normal,O,OO}.log` 和 `logs/results-{normal,O,OO}.json`；后者应逐字相同。实际执行命令见 [commands.txt](logs/commands.txt)。`run_examples.py` 用显式异常执行检查，不依赖 `assert`：检查 n=2…30 的链、每个非邻接结论的证书、各位置插入、单目标证明树；并对三个标签上含自环的全部 512 个简单有向图，比较关系组合闭包和独立编写的逐起点遍历。

分支 `A→B,A→C` 有三个不同项、两个不同前提却没有非邻接传递结论，不能套线性链公式。两项环 `A→B,B→A` 有四个可达有序对，包括两条自反边，也不满足线性链前提。以上是有限见证，并非普遍计数证明、完整传统三段论实现、或对原书所有解释的实验裁决。
