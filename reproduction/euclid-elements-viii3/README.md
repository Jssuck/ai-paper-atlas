# VIII.3：最小等比数列的端点互素

现代正整数教学重构，不是古代实跑记录或一般命题的计算证明。先确认每对相邻项的前项比后项有同一精确比值。以互素的比对 a:b 生成给定长度的基本链，再和输入逐项比较。程序单独核对：输入若已最小，两端必须互素。有限搜索另从首项 1 开始、按反向增长因子逐项精确生成，找到首个全整数候选；端点最大公度也由公因数枚举复核。

(8,12,18,27) 的前后项比为 2:3，已最小且端点互素；(16,24,36,54) 虽同比，却是前者的两倍，端点公度为 2。默认程序采用最小比对的两项都大于 1 的模型。显式现代模式可检验一端是单位的 (1,3,9,27) 与 (27,9,3,1)，皆最小；(9,27,81) 虽然给定项都大于 1，按现代含单位的模型可缩至 (1,3,9)。此限制不是判定原文如何定义单位；常数列也仅在现代模式运行。
