# 《几何原本》卷 V 定义 1–7：整数倍比较的可复验模型

[回到精读正文](../../papers/ancient/euclid-elements-v-definitions-1-7.zh-CN.md)。本目录用现代数域示范「度量整除」「倍数可超越」「两个比的逐项比较」等不同问题，不把任何一种操作当成其余操作，也不声称穷尽古代量的理论。

## 对象和实现范围

- 量取正数，表示成有理数系数的 a+b√2，拒绝零、负数和浮点输入。每个比内部两个量标为同种；比较两个合法比时，不强制它们同为长度比或同为面积比。类型标签是教学保护，不是可以验证输入物理单位的系统。先在每一种类中统一计量单位。
- V.Def.1–2：若「部分」严格较小且能以正整数个不剩地度量整体，代码返回乘数；相等、非整数商或无法整数度量则不返回乘数。这不等于禁止形成非整数比。
- V.Def.3–4：检查同种；对这套正数模型，用反复倍增实际找到两个严格超过的乘数。两方向各自搜索，不要求共享或最小的乘数。这只展示给定模型中的实例，不从有限测试建立通用量公理。
- V.Def.5–6：给同一对正整数 m,n，用同一个 m 乘两前项、同一个 n 乘两后项；两次比较的符号（−1、0、1）必须对每一对 m,n 一致。V.Def.7 使用存在见证：前一比较严格大于，后一比较不大于，等号算在后一分支内。
- 精确符号：a、b 同号或一项为零时直接处理；异号时比较 a² 与 2b²，再乘 a 的符号。只比较非负绝对项的平方，不对未知符号的表达式随意平方。
- 搜索范围是 1≤m,n≤N 的方格，不是无限量词。找到一个差异即可否定同比；找到 V.Def.7 型见证即可认证相应方向的较大比。没找到只说明扫描范围内未见，不是证明同比或没有较大关系。这里不实现任意实数量的判定器。

## 实跑实例

| 左比、右比 | 旧上限内 | 扩展上限后 |
| --- | --- | --- |
| √2:1、7:5（示范两对各自同种即可） | N=6，未发现三态符号差异 | N=7，(m,n)=(5,7)，符号 (+,0)，同时是 V.Def.5 的反例及 V.Def.7 的见证 |
| 101:100、102:101 | N=100，未发现三态符号差异 | N=101，(100,101) 的符号为 (0,−)，可否定同比却不是该方向的 V.Def.7 见证；N=102，(101,102) 给 (+,0)，才得到该方向见证 |

反过来，√2:1 与 2:√2 的同比分别比较 m√2 与 n、2m 与 n√2。后一对是把前一对同乘正数 √2，所以无限范围的同号来自推导，不来自有限搜索。

## 环境、命令与证据

在本目录运行；只需 Python 3.12.14 标准库。

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python ratio.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```
