## 核验与限制

- 两个比须同为最简 m/n，且 1<m<n。分别用最大共同量数作为组件大小 g、h。两个较小项来自前 m 对组件；两个整体来自全部 n 对组件。每对合并为 g+h，相当于重复应用 VII.5 的同份见证。以 8/12、10/15 为例，组件 4、5 均大于 1，m=2、n=3；两部分与完整整体分别配为 18、27。
- 50 个最简真分数（分母 3 至 14，分子至少 2）与各自组件大小 1 至 11 的两个选择组合成 6,050 例。检查 m 个配对确是 n 个配对的前缀，逐项求和还原两部分、两整体及两者合并值，再用独立的标准库分数计算核对。
- 输入的四个古代数都大于一；但模型可用区分于数的单位 1 作为某一侧的组件，例如 2/3 配 10/15。这不把单位本身扩充为古代的数；它是分块中的计量边界。程序为演示而显式创建组件序列，并不追求最少内存。
- 分子不同、分母不同以及两边同为单位分数的输入都拒绝生成见证。最后一种正是 VII.5 的范围，不表示相加会破坏相同的单位分数。有限实跑不证明一般命题。
