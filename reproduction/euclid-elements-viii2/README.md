# VIII.2：按给定比构造最小等比链

现代整数教学重构，不是古代实跑记录或一般定理的计算证明。给定前项与后项之比 a:b，先按 VII.33 的现代方式取互素的最小对 x:y。三项由 x²、xy、y² 得出；把旧项依次乘 x，最后补上旧末项乘 y，就得到四项 x³、x²y、xy²、y³。程序将同样的构造循环推广到任意整数长度 n≥2，并核对相邻交叉积和端点互素。后者通向 VIII.1 的最小性检验。

2:3 的三项、四项结果分别为 (4,6,9) 和 (8,12,18,27)。若不约分 4:6，就会得到三项 (16,24,36)，虽同比却不是最小。程序默认要求给定数和约分基数均大于 1；现代开关显式允许相等比或含单位的情形，如 2:4 构成 (1,2,4)。不把这类现代模型边界当作原文对单位的称呼。

测试另用 Fraction 从首项 1 起搜索第一条全整数链，并与幂公式及相邻比核对。上界 a 的 n−1 次幂来自一定可行的原始幂链。
