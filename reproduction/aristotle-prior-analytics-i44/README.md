# I.44：约定桥、临时假设与有限语义核验

本目录是《前分析篇》I.44的**现代教学重构**，不是古代三段论算法的复原。解释和一般证明见[中文深读](../../papers/ancient/aristotle-prior-analytics-i44.zh-CN.md)。

## 检查什么

- 设S、P为两个命题。由S蕴涵P与非P，可推出非S；删除桥接前提，或者把它换成反向P蕴涵S，推理便不成立。两者都有P假、S真的反赋值。
- 设Γ为背景、H为临时假设。Γ与H没有共同满足赋值，当且仅当Γ蕴涵非H。归谬记录应把H放在临时作用域，结论精确为非H。
- 一个作用域标签不得同时作为背景和临时假设，重复背景标签也拒绝。**标签只表达调用者声明的来源**，程序不认证背景事实、自然语言材料或隐藏的推导历史；把同一公式改名重新作为背景，仍是调用者实际提交的额外前提，不会被程序神奇地消除。
- 不一致背景会使结论在经典语义下空真，核验器允许并明确测试这一点；通过不等于背景可满足，更不等于背景真实。
- 整数平方奇偶性和1至64范围的既约分数检查，仅作一般反证的具体算例，不把没有找到平方根2的有理表示当成无理性证明。

现代命题蕴涵不是原章“假设”的唯一历史释义。“不能按给定前提归入三格”也不等于现代意义上的无效或不能形式化。

## 文件与接口

`model.py`用一个有序原子表和真值行集合表示有限命题语义。最多8个不同原子，是明确的低成本实现限制，不是逻辑限制。`Space(())`有一个空赋值；空前提没有限制这个空间。`Formula`的真值行必须为范围内的整数，布尔值不视为整数；先验证所有输入，再去重。

- `entails`与`counterexample`计算有限空间中的蕴涵及首个反例。可接受一次性生成器，不在前提已经不满足时跳过后续输入校验。
- `ReductioCertificate`冻结背景记录和临时记录；`verify_reductio`检查精确的否定结论、作用域标签约束，以及内部上下文无满足赋值。它是**有限语义证书核验**，不包含逐行三段论推导，不是任意公式系统的证明搜索器。
- `test_model.py`有18项测试，涵盖缺桥、反桥、归谬、错误结论、作用域标签、空原子表、不一致背景、跨空间输入、生成器、布尔数值陷阱等。
- `run_experiment.py`枚举两原子的16个真值集合，比较全部背景／假设组合及结论证书；另外实查整数奇偶与有限分数。

## 环境与复跑

Python 3，只有标准库；实际版本和命令见[环境日志](logs/environment.txt)。在本目录执行：

```sh
python3 -m unittest -v test_model.py
python3 run_experiment.py
python3 -O -m unittest -v test_model.py
python3 -O run_experiment.py
python3 -OO -m unittest -v test_model.py
python3 -OO run_experiment.py
```

关键校验使用显式异常，不用会被优化模式移除的assert语句。unittest的断言方法不受此影响。

## 真实实跑

三模式各18项测试通过。每模式两原子共4赋值、16个真值集合；256背景／假设组合中81组内部不相容；4096份带精确结论的候选证书中81份通过。81也可独立由每行“只在背景、只在假设、都不在”三个选择得到3的4次方，但这并不代替执行日志。

另有513个整数（−256至256）的奇偶检查，4096个正分子／分母组合中2519组互素，没有平方等式p²=2q²解。范围外不作实验结论，一般无理性由数学证明处理。上述计数是不同检查口径，不能相加包装成“验证了更多模型”。

## 局限

程序没有解析希腊文或英语，不认证科学／能力的经验关系，不决定约定是否合理，也不实现完整古代假设论证分类。有限真值枚举可穷尽**声明的两原子布尔模型**，不能由此宣称穷尽任意语言、一般数学定理或原章的历史解释。整数实验也没有完成任意整数上的证明。
