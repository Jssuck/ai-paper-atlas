# 《几何原本》IX.21：偶数相加仍为偶数

`even_sum(terms)` 接受有限、非空的正偶整数列，逐项取半，再把各项的一半分别放入两组，核对总和确为两组相等整数之和。例：$`(2,4,6)`$ 的逐项一半是 $`(1,2,3)`$，合计 $`6`$，故原总和为 $`6+6=12`$。即使给定项为 $`2`$，其半数也允许为单位 $`1`$。

本命题不要求反过来成立：$`3+5=8`$、$`2+3+5=10`$ 都不是全偶数输入。$`2+3=5`$ 说明仅有一个偶数也不足以保证偶数和。程序特意拒绝空列、零及负数，以保留非空正数模型；现代偶数的定义可包含零和负数，空和也可定义为零。

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v

```
