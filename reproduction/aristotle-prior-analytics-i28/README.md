# I.28：从六类前提索引寻找同一个中项

这是 **原创教学重构**，不是 Aristotle 的程序，也不是全章逻辑系统的完整复现。原文定位、异读与证据风险见[中文深读](../../papers/ancient/aristotle-prior-analytics-i28.zh-CN.md)。本实验只实现 I.28 六种明确的相同中项配对，并把若干失败规则转成反例测试；不将有疑点的章末字母归约硬编码为定理。

## 1. 模型与可运行范围

设要讨论的是“谓项 A 对主项 E 成立”。程序的 `all(x,y)` 表示 **x 是 y 的子集**；因此 `all(E,A)` 才是“所有 E 是 A”。这与用谓项写在前面的历史记号不能混用。

| 索引 | 存入中项 M 的显式前提 |
| --- | --- |
| B | `all(A,M)`：A 的后随项/超类 |
| C | `all(M,A)`：A 的前随项/子类 |
| D | `none(M,A)`：与 A 排斥 |
| F | `all(E,M)`：E 的后随项/超类 |
| G | `all(M,E)`：E 的前随项/子类 |
| H | `none(M,E)`：与 E 排斥 |

`none` 表示交集为空，并将两端名称排序，利用全称否定对称性。未知、缺项、尚未观察到不是 `none`。`nonempty(M)` 是额外显式的非空前提，不由全称陈述自动生成。所有对象类在语义中允许为空；特别结论才检查见证前提。

| 配对 | 已检查的前提 | 目标结论 |
| --- | --- | --- |
| CF | M⊆A，E⊆M | 所有 E 是 A |
| CG | M⊆A，M⊆E，M 非空 | 有 E 是 A |
| DF | M∩A 为空，E⊆M | 没有 E 是 A |
| BH | A⊆M，M∩E 为空 | 没有 E 是 A |
| DG | M∩A 为空，M⊆E，M 非空 | 有 E 不是 A |
| BG | A⊆M，M⊆E，A 非空 | 有 E 是 A；**不是**所有 E 是 A |

BG 先支持反方向“所有 A 是 E”，再由 A 的非空得到共同实例。程序只输出表内特称目标，测试另核反方向全称与错误正方向全称之间的区别。

证书保存规则、目标主谓项、中项名称、规范化前提列表和结论。`verify` 重建该规则所需前提，核对它们均在输入知识集中，并拒绝篡改中项、结论、规则或前提列表。它检查**前提如果成立时的形式推理实例**；不认证输入命题在现实中为真。`true_fact` 是独立集合语义入口；`facts_from_model` 仅供穷举测试生成完整的有限模型真值材料，不是知识搜索器的现实资料搜集机制。

不同名称不会因两个集合在某个模型中恰好相同而自动合并。项名必须为非空字符串；两个端项须不同，否则搜索明确抛出 ValueError。中项须不同于两个端项；不搜索退化端项替代。`search` 只连接显式输入，没有传递闭包、否定继承或别名推理。因此空结果只意味着“这批材料中没有这些模式的证书”，不意味着目标为假或不可证明。

## 2. 一般推理与有限实验的区别

六规则的健全性依赖一般集合论证明，不依赖穷举次数：CF 取任意 E 的元素，经 M 进入 A；CG 取非空 M 的元素，它同时属于 A 和 E；DF 若 E 的元素属于 A，则因它属于 M 与排斥条件矛盾；BH 同理以 A 的元素进入 M 再与 E 排斥；DG 取非空 M 的元素，它属于 E 而不能属于 A；BG 取非空 A 的元素，经 M 进入 E。各步可以在任意论域执行。这里是现代外延模型的证明，不宣称已解决古代存在预设的全部解释问题。

有限检查仅检查论域大小 **0、1、2、3、4** 的全部三集合 A、E、M 赋值，共 **4681** 组；对每组，用真实有限模型产生显式真前提，再搜索/验书，并另用集合语义判断结论。共检查 **2123** 份证书：CF 341、CG 440、DF 341、BH 341、DG 440、BG 220。还检查每个核心规则的前提实际为真时没有被搜索器漏掉。这只是**六规则相对于该显式索引的有限覆盖检查**，不是三段论全体、全部推理或任意知识库的完备性证明。

## 3. 反例与文献风险

- BF、CH、DH 三种配对不能保证目标方向“ A 对 E ”的 A/E/I/O 四种结论。`run_demo.py` 为每种配对、每种目标输出非空三集合反模型，共 12 个反例记录。**这不说 CH 完全没有两端关系**：若 M 非空，M⊆A 且 M 与 E 排斥，确可推出反方向“有 A 不是 E”。实验只否认表明的目标方向四型必然性。
- 部分交叠不能替代中项同一：A={0}、E={1}、M1={0}、M2={0,1}。M1⊆A、E⊆M2、M1 与 M2 相交，仍不保证 E⊆A。
- 属层查询失败不能排除种层成功：K={0,1}、F=E=A={0}。K 不被 A 包含，但 F 被 A 包含并可支持 CF。未实现复杂启发式优先队列，不声称性能比较。
- Owen 印149末至150首的 B/G 排斥段在字母归约上有需保留的风险。取 A=B={1}、G={0}、E={0,1}，则 A⊆B、G⊆E、B 与 G 排斥且 G 非空；确实有 E 非 A，但 **B 不与整个 E 排斥**，所以不能由这些前提直接把 B 当成 H。有效现代归约是先推出 G 与 A 排斥，再用 DG。测试保留这一反例，不以程序替古代文本作无声明改字；来源/版本讨论由正文负责。

## 4. 环境、命令和真实记录

无第三方依赖，Python 3.12.14 / CPython / Linux x86_64 实跑。代码只使用标准库。请在本目录执行：

```bash
python3 -B run_evidence.py
```

它依次运行普通 unittest、有限 demo、`-O` 优化模式 unittest、`-I` 隔离模式 unittest，并保存各自 stdout、stderr、退出码及源文件 SHA-256。隔离模式只显式加入当前项目目录；不依赖环境 PYTHONPATH。`-O` 不会删除 unittest 的断言；穷举 demo 使用显式异常而不是会被优化移除的 `assert`。

本次普通、优化、隔离模式均 **29 项测试通过**，demo 退出码为 0。[evidence.json](evidence.json) 给出环境、规范化命令、真实退出码、源文件哈希；操作系统分配的解释器绝对路径仅在命令记录中标准化为 `python3`，原始 stdout/stderr 不作清洗或重写：

- [普通测试 stdout](logs/tests.stdout.txt)、[stderr](logs/tests.stderr.txt)
- [有限模型与反例 JSON stdout](logs/demo.stdout.txt)、[stderr](logs/demo.stderr.txt)
- [优化测试 stdout](logs/optimized.stdout.txt)、[stderr](logs/optimized.stderr.txt)
