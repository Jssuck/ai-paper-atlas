# 《后分析篇》II.8：事实证书与原因角色的最小教学实验

对应93a1–93b20。全部代码为原创现代教学重构，不是原典的历史实现，也不是完整复现。原文以月食的征兆与地球遮挡、以云中熄火解释雷声；这里仅检查论证结构。云中熄火不是本实验认可的现代雷声理论。源码不含天文或气象观测数据。

## 1. 假设与接口

- `subsets(n)`：给定有限域 `{0,...,n-1}` 的所有子集，包括空集。
- `chain(C,B,A)`：分别检查 `C <= B`、`B <= A`、`C <= A`。这是外延包含，不是原因识别。
- `candidate_middles(C,A,candidates)`：返回给定命名字典内满足 `C <= B <= A` 的全部名字，按名字排序。没有遍历未提供的词汇或现实原因；同延而不同名也分别保留。
- `DeclaredRole(role, immediate_premises, source)`：保存外部给出的征兆/原因/未知标签、直接前提声明、非空来源文字。来源文字只是一项标签，不是文件真实性或引文充分性的检验。
- `report(...)`：合并形式检查与外部声明。无论标签为何，`causal_truth_verified` 和 `essence_verified` 都为False。这里的False表示程序没有认证，不等于它已证明非因果或非本质。
- `binary_world(kind,U,do_b)`：求解两套明定的二元结构方程。`directed` 为 B=U、A=B；`common` 为 B=U、A=U。可选择用指定常数替换B的方程。没有概率估计、参数学习或现实实验。

这些接口有不同职责：集合检查器验证给定扩展，报告器不升级知识地位，结构模型只计算给定方程的后果。原文的“直接前提”不等于软件中没有递归，也不等于模型图边数少。

## 2. 一般证明与必要的反例

### 2.1 前向传递

假定C包含于B，B包含于A。任取x属于C，由第一前提得x属于B，再由第二前提得x属于A；所以C包含于A。若C为空，结论仍真，但没有提供任何存在见证。这是适用于任意集合的一般证明；有限穷举只检验实现。

### 2.2 从结论倒推中项不唯一

取C={0}，A={0,1,2}，B1={0,1}，B2={0,2}。两条包含链都成立，B1与B2却不同且互不包含。已知C包含于A不能唯一确定中项，也不能自动选择一个为真实原因。更强地，从A(x)及B包含于A，不能推出B(x)：取A={0,1}，B={0}，x=1即可反驳。

### 2.3 更换角色不改变外延真值

对完全同一组三集合分别贴“征兆”“原因”标签，四项布尔检查完全相同。形式检查不读取自然机制；声明前提直接也不添加外部证据。若想完成原典意义的所以然说明，必须另行承担中项确为相关原因、前提可靠等责任，而不是把报告中字符串改为cause。

### 2.4 相同观察表不足以区分所给两模型

在无干预时，两模型均返回(U,U)，所以U=0时为(0,0)，U=1时为(1,1)。在U=1且把B方程替换为常数0时，directed返回(0,0)，common返回(0,1)。观察表相同，干预结果不同。逐式代入即完成这一特定反例的证明。

本反例不是现代因果识别一般不可能定理，更不证明亚里士多德已经提出结构因果模型。干预语义是本教学额外假设。实际天文或雷声研究需独立领域证据，不能把这里的变量名当作测量。

## 4. 计数口径和结果

- 每个域大小n有8^n组三集合（每个元素有8种成员组合），n=0..4共4681组。
- 满足C包含于B包含于A时，每元素仅允许4种顺序成员组合，所以共1+4+16+64+256=341条有效链。
- 对上述4681组，逐成员oracle与集合包含实现比较；传递违例与oracle差异均为0。
- 候选例返回cause、sign两个名字，不认证任一为真原因。
- 二元模型比较4个(U,do(B))组合，2个组合的输出不同；两个自然观察行完全一致。
- 30项测试在normal、-O、-OO三模式分别运行；4个Notebook代码单元依次运行。详见对应日志，不把一次运行称为性能基准。

### 复杂度与复现条件

枚举三集合的候选数为8^n，逐成员oracle每组O(n)，指数增长；上限4是低成本教学选择。单次子集操作成本随集合规模增长，不能因小样本耗时短便声称任意规模常数时间。候选名字排序和有限字典遍历也只覆盖输入词表。无随机性、训练集、测试集划分或外部网络需求。

## 5. 练习与答案

1. C为空能否由包含链证明有C？不能，空集是反例。
2. `candidate_middles`返回空元组是否证明现实中没有原因？不能，只否定给定候选字典中的合格扩展。
3. B1与B2同延但名称不同，函数是否合并？不会；这也不证明它们本质相同。
4. 为什么改role不应改变包含结果？角色属外部证据层，不是成员关系。
5. 令C={1}、B={0}、A={0,1}，结论真能否证明两个前提真？不能，小前提假。
6. 从A(x)及所有B是A推B(x)缺什么？需额外A包含于B等足够条件；不能自动逆推。
7. 两模型U=0且do(B=1)分别如何？directed=(1,1)，common=(1,0)。
8. 当干预设置恰等于U时能区分吗？不能，这两个模型该行结果相同。
9. `immediate_premises=True`是原典直接性的证明吗？不是，仅保存使用者声明。
10. 为何有限枚举不能代替§2一般证明？枚举只含n≤4；逐元素证明没有域大小限制。
11. 零oracle差异能证明雷声古代解释正确吗？不能，oracle仅核形式实现。
12. 本实验验证了什么未验证什么？验证给定有限结构的蕴涵、候选和方程计算；未认证真实因果、本质或科学知识。
