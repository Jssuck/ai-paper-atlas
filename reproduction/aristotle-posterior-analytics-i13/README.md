# 《后分析篇》I.13：事实推理不等于原因认证

这是原创、低成本的有限教学模型，不是原文算法，也不声称复现古代自然科学。目标是把三个容易混淆的问题分开：**结论是否随前提成立、逆推需要什么桥梁、外延相同是否决定因果方向**。

## 1. 有限集合：事实链与逆向桥梁

宇宙固定为 `U={0,1,2}`。整数 mask 的第 i 位表示 i 是否属于该集合；例如 `1={0}`、`2={1}`、`3={0,1}`、`7=U`。`included(a,b)` 检查 `a⊆b`，`disjoint(a,b)` 检查 `a∩b=∅`。集合是人为给定的完整外延，不是从数据学习出来的普遍律。

令 S 为当前主项集合，E 为作为线索的性质，C 为候选解释性质。变量名 `cause` 只方便对照，不代表程序已发现原因。

### 有效事实链

若 `S⊆E` 且 `E⊆C`，则 `S⊆C`。一般理由是：任取 x∈S，先由第一前提得 x∈E，再由第二前提得 x∈C。这只确立外延关系，不认证 `E` 或 `C` 哪个是现实原因。

### 正向包含不能自行倒转

若只知 `C⊆E` 和 `S⊆E`，不足以推出 `S⊆C`。非空反例：

```text
S={1}, C={0}, E={0,1}
```

两个前提真，但 S 中的 1 不属于 C。要让每个 E 对象都可这样逆推，需要补上 `E⊆C`；已知 `C⊆E` 时，双向桥相当于 `C=E`。

这里的量词必须说清：**双向包含是对全部 E 对象有效的充分桥梁，不是任意一次局部逆推的必要条件**。例如 `S=C={0}`、`E={0,1}`，对这个 S 的结论仍真，尽管 `E⊄C`。程序单独测试了此情形。可互换的外延也不意味着因果解释可互换，见下一节。

本实验采用现代集合语义：空宇宙、空主项允许，全称包含不暗含存在。这不是对所有古代存在承担解释的裁定；结果也单列全部相关集合非空时的反模型，避免把失败全归为空集。

## 2. 相同观测，不同干预：两个明确规定的模型

规定外生变量 `U∈{0,1}`，且 `P(U=0)=P(U=1)=1/2`。内生变量 X、Y 也只有 0/1。模型方程是**输入假设**：

| 模型 | 方程 | 输入中指定的方向 |
| --- | --- | --- |
| `X_to_Y` | `X=U; Y=X` | X→Y |
| `Y_to_X` | `Y=U; X=Y` | Y→X |

不干预时两个模型都只生成 `(X,Y)=(0,0)` 和 `(1,1)`，各占 1/2。因此它们的**完整观测联合分布相同**，不仅是某次小样本恰好相似。以外生状态为宇宙，性质 `X=1` 和 `Y=1` 的外延也相同，均为 `{U=1}`。

本模型将 `do(X=0)` 定义为：用常数赋值 `X=0` 替换 X 原来的结构方程，Y 的方程及 U 的分布不变。它不是挑出观测中 `X=0` 的行：

| 条件 | `X_to_Y` 的结果 | `Y_to_X` 的结果 |
| --- | --- | --- |
| 无干预 | `00:1/2, 11:1/2` | `00:1/2, 11:1/2` |
| `do(X=0)` | `00:1` | `00:1/2, 01:1/2` |
| `do(Y=1)` | `01:1/2, 11:1/2` | `11:1` |

其余状态概率为零；JSON 保留全部四个状态，以分数字符串精确存储概率，避免浮点误差。程序检查两个变量各有“不干预/置0/置1”的全部九种组合，包括同时替换两条方程。

**这对模型给出一个具体反例**：仅凭这个观测分布，不能在这两个候选结构中选择方向。这个结论可由上面的方程直接算出；它不是用36次程序计算证明一条普遍因果识别定理，更不是说因果方向永远不能通过其他假设或实验确定。程序没有真实干预数据，不会挑出哪个模型符合现实，尤其不能把集合相等或程序输出当作“真实近因认证”。

## 3. 否定结论有效，中项仍可过宽

用抽象标签重构墙例的关系，不把标签当作现代生物学分类：

```text
W={0}       当前待考察类别
A={1,2}     一个较宽类别
B={2}       A 的较窄子类
```

于是 `B⊆A`、`W∩A=∅`，必有 `W∩B=∅`。证明：假若某 x 同时属于 W 和 B，由 `B⊆A` 得 x 也属于 A，与 `W∩A=∅` 矛盾。

但 `A⊆B` 为假，元素1就是反例。因此不能把“所有 B 都是 A”变成“是 A 就足以具有 B”。否定结论的形式有效性并未赋予 A 一个充分或适当的解释地位。这是**中项外延过宽的逻辑检查**，不是对直接/间接原因的自动分类器；程序没有时间、机制、肺、生命或近因变量。

也不把“否定某原因导致无结果，则肯定它必导致结果”写成通用现代因果规则。集合反例仅指出给定外延桥梁允许和不允许的推断。

## 输入与数学边界

- 集合函数参数 `size` 必须是原生 `int`，范围0至8；mask 必须是原生 `int`，满足 `0≤mask<2**size`。`bool`、浮点、字符串、越界值均拒绝。8只是接口资源上限，不是数学定理限制；本次完整三元组枚举只用 size=3。
- 结构模型名只能为 `X_to_Y` 或 `Y_to_X`。U 和干预值必须是原生整数0或1；拒绝 `True`/`False` 以防 Python 布尔/整数混用。
- 干预必须为普通 `dict` 或 `None`；只接受字符串键 X/Y，不接受对外生变量 U 的干预、不静默忽略未知键。`None` 和 `{}` 都表示无干预，输入字典不会被修改。
- 所有模型都有限、无环、确定性（给定 U 后）；随机性只来自指定的 U 分布。不处理隐含额外变量、循环模型、噪声学习、有限样本统计误差或真实因果发现。
