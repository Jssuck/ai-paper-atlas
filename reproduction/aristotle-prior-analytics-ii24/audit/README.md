# II.24 独立复核代码与实跑

本目录是独立技术核验：`independent_oracle.py` 不导入生产源码，用集合、组合枚举和逐元素成员检查；生产程序使用位掩码。`compare.py` 只读取双方的 JSON 输出，并独立重算八份证书的谓词。它不把生产程序的同一函数再调用一遍当作独立证据。

从本复现目录执行：

```sh
sh audit/run.sh
```

脚本实际分别运行正常、`-O`、`-OO`，保存 oracle、生产输出、比较结果和测试输出。每种模式独立核对69905个四集合世界汇总、341个对全部性质扩张量化的配对、8份例证；17项生产测试也在三模式重新执行。优化模式的检查通过显式异常和 `unittest`，不依赖会被删除的裸 `assert`。

## 不同于穷举的计数交叉核验

每个论域元素对A、B、C、D有16种成员模式。观察约束允许8种，其中D不含该元素允许6种；故n元素域的观察世界数为8的n次方，非空D世界数为8的n次方减6的n次方。

在观察约束中再要求目标C包含于A，允许7种模式；再令D为空则允许5种。因此非空D目标失败世界数为8的n次方减6的n次方减7的n次方加5的n次方。在观察约束中再要求全B包含于A，允许6种模式；再令D为空允许4种，故非空D全称失败数为8的n次方减2倍6的n次方加4的n次方。对n从0到4求和，分别得到1106和1912，与独立枚举及生产输出相符。

演绎桥统计保留自由D，覆盖桥统计保留自由C；这两个4681是四集合世界计数，不是4681个互不重复的三集合实例。341配对对每一对(C,D)检查所有可能A，而不是只检查某一个已给A。八份证书包括空项边界、删假设失败、目标覆盖但全类不覆盖及两例仍未覆盖；它们不是八个都满足完整前提的反例。

有限枚举不是一般证明。正文的任意元素论证与取A等于证据集合的反向构造承担一般结论；本实验也不验证历史战争、因果或古代唯一语义。源文件与结果摘要由[独立技术审查](../../../papers/ancient/aristotle-prior-analytics-ii24.technical-review.zh-CN.md)绑定。
