# Posterior Analytics II.13：定义搜索的有限外延检查

## 范围与证据层级

本目录配合[中文深读](../../papers/ancient/aristotle-posterior-analytics-ii13.zh-CN.md)，针对《后分析篇》II.13，96a20–97b39。原文提出搜集较广的属性、使其合取对应所定义者，并讨论分割、排列与同名对象的共同处。原文可读：[MIT / G. R. G. Mure 英译，Book II，Part 13](https://classics.mit.edu/Aristotle/posterior.2.ii.html)。

**本目录是原创现代教学重构，不是古代文本的算法复刻。** 将对象编码为有限集合、把属性变为集合交集、以贪心删除研究冗余，以及下述枚举范围均是本项目设计。交集恰等目标，只是给定有限宇宙内的外延吻合；不能判定本质、自然属、科学定义或未来对象。没有把“最少属性数”归给亚里士多德。未复刻全部古代数论或三数定义。

## 模型/API

- `intersection(U, features)`：属性集合的交；空属性表的交约定为 `U`。
- `describe(U,T,features)`：分别返回 `sound`（每项含 T）、`exact`（交恰为 T）、`severally_wider`（每项严格含 T）、`irredundant`（准确且删任一项不再准确）。空表对 `T=U` 的不可删性为真，是数学约定而非科学定义评价。
- `greedy_reduce(U,T,features,order)`：只接受起始交准确的列表，按索引排列尝试删除仍能保持准确的项；输出原索引。它不是最小基数求解器。
- `split_check(parent,left,right,target)`：检查覆盖、互斥及目标整体归支。各集合必须在 parent 内。`nonempty_unique_branch` 另要求目标非空且完整包含在且仅在一支。
- `common_features(rows)`：已观察样本属性的交；没有观察则拒绝。交为空不表示真实对象无共同本质；交非空也不说明未观察样本满足。

所有集合项需可哈希；超出指定宇宙的输入抛出 `ValueError`。不接受宇宙外元素后默默截断。只处理二分，不提供分类树、本质判别器或自然语言解析器。

## 一般证明（不是由小实验推出）

令有限属性表为 F₁,…,Fₖ，目标为 T，宇宙为 U，所有集合均为 U 的子集。设 I 为这些属性的交。

1. 若每个 Fᵢ 都包含 T，则任取 x∈T，x 属于每个 Fᵢ，故 x∈I，得到 T⊆I。
2. 若不存在 U∖T 中同时满足全部属性的元素，则任取 x∈I，x 不可能在 U∖T，所以 x∈T，得到 I⊆T。
3. 两条件合起来恰给出 I=T。反过来 I=T 蕴含这两条件。每项**严格**宽于 T 不是准确交的必要条件，而是更强的筛选。

贪心删除的不变量是当前交始终等于 T，因为仅在试删后的交仍等于 T 时删除。一旦第 i 项试删失败，就存在一个目标外见证 w，它满足当时其余全部属性。随后只删别的属性，剩下的限制更少，w 仍满足它们，因此第 i 项最终仍不可删。有限项表保证终止，结果准确且不可删。证明不保证最小基数；输入准确是前提。上述集合证明不要求 U 有限，但实际实现与运行使用有限集合。

## 手算例与反例

### 较广的两项可以精确合取

U={0,1,2,3,4}，T={0}；F={0,1,2}，G={0,3,4}。F、G 都严格宽于 T，交却是 T。若改 G={0,1,3}，交变成 {0,1}，必要属性仍不足；若把 F 改成 {1,2}，则连目标 0 都被排除。

### 不可删、最少与顺序

仍用同一 U、T，五个属性为：

| 索引 | 属性集合 | 被它排除的目标外元素 |
|---|---|---|
| 0 | {0,4} | {1,2,3} |
| 1 | {0,1,2,3} | {4} |
| 2 | {0,2,3} | {1,4} |
| 3 | {0,1,3,4} | {2} |
| 4 | {0,1,2,4} | {3} |

按 0→4 尝试删除，留下 [2,3,4]：各自排除的 {1,4}、{2}、{3} 都不可缺。按反序删除，留下 [0,1]，也不可删。没有单项等于 T，所以后者两项达到最小；前三项的不可删解并非最小。属性交换不改变交，但这不证明属差排列在定义论上可随意交换：本模型根本没有“先属后差”的语义结构。

### 分割检查不能替代知识

parent={0,1,2}，left={0}，right={1} 有遗漏 2；left={0,1}、right={1,2} 有重叠 1。即使 parent={0,1} 已由 {0} 和 {1} 分成完整互斥两支，目标 {0,1} 仍跨支；目标为空则在两支内都成立。分割结构正确不自动告诉我们目标是什么、应落哪支。输入目标归属来自外部知识，不是从覆盖推导。

同名样本属性 {a,b}、{a,c} 的共同处为 {a}；补入第三样本 {b} 后共同处为空。不能把前两例的交当作所有同名对象的定义。

## 练习与答案

1. “每个特征比 T 广”是否足以得出交等于 T？**否。** T={0}，两个特征都为 {0,1}，交仍含 1。
2. 准确交是否要求每个特征严格更广？**否。** 一个特征已为 T，也可准确；但不能据此断言本质定义合格。
3. 三项不可删，是否至少要三项才能定义目标？**否。** 上面的 [2,3,4] 与 [0,1] 是明确反例。
4. 完整互斥分割为何不能单独证明归支？**覆盖针对每个元素，不保证整个目标类只在一支；** 非空跨支 T={0,1} 即反例。
5. 删除更早判定不可删的项，后来会不会变成可删？**在这里只删限制且起始准确的条件下不会。** 原先见证对象仍满足更少的其余限制，故依然阻止该项被删。
6. 所有示例都共有属性 a，能否推出 a 是该名词的本质？**不能。** 样本外覆盖、本质与偶然属性的区分都未由有限交认证。
