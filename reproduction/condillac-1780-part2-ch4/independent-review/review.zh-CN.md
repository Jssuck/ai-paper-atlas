# 有限语言教学模型：独立代码复核

## 结论与范围

2026-10-12，独立检查未发现交付实现偏离已声明数学语义的行为缺陷。普通、`-O`、`-OO` 三种模式均真实运行，实际优化级别、退出码、输出及输入散列见本目录的 [verification.json](verification.json) 和三份 `audit-*.txt`。这不是所有可能输入上的正确性证明，也不是历史主张、心理学理论或泛化能力的实验验证。

复核对象为 `finite_language.py` 及其示例、专门测试、作者验证器和证据记录器；规格对照[主文第8至10节](../../../papers/1780/condillac-logic-part2-ch4.zh-CN.md)、[MODEL.zh-CN.md](../MODEL.zh-CN.md) 与[逐步手算](../WALKTHROUGH.zh-CN.md)。未更改生产实现，未重新获取扫描件，未安装依赖，未进行远程写入。独立检查只使用标准库。

本次发现并协调修正了一项证据包装问题：原作者运行清单含绝对工作区／解释器路径。最终记录改为可移植显示命令和相对目录，并明确实际子进程使用启动记录器的解释器；同时增加运行前后输入散列一致性检查。没有将这个包装问题称为数学或拟合缺陷。

## 规格逐项对照

- `h(r(u))` 是预测；`empirical_loss` 按记录次数累计不符，`truth_errors` 按对象计错。拟合不读取真值。正确但覆盖不全的记录可使经验损失 `1→0`、真错误 `1→2`；重复错误记录可使经验损失 `10→0`、真错误 `0→1`。
- 正计数平局按声明的答案次序处理，不能按字符串排序，也不保留并列旧值。检查采用非字典顺序 `("z", "a", "m")`。整个标签没有证据时才保留旧解码；已使用但全零的标签、未使用标签均包括在内。
- 不要求表示满射。所有标签都有解码，空单元不影响最低损失；它们的无证据处理仍受检查。
- `rename` 按标签枚举顺序联合传递表示与解码。新旧名称相互重叠、置换旧字符串、采用中文或不透明字符串均不改变逐对象预测；逆换名恢复原问题，拟合与换名可交换。
- `refine` 检查 `q∘s=r`，并以 `h∘q` 传递解码。父映射也可不满射。传递保持实际预测、经验损失和真错误；细化比较的是两个表示各自可达到的最小值。自定义错误细解码可使实际经验损失 `2→5`，同时最小值 `2→0`。复用同名标签时照抄旧字典的损失 `0→1`，正确传递保持为0。
- “表示足够当且仅当真值在非空单元内恒定”在独立小域中以直接枚举全部解码器核验。生产程序没有独立的表示充分性 API；`minimum_empirical_loss` 也不是最小真错误函数。
- 主文以非空对象集展开；程序允许空对象集是明确写出的边界扩展。空预测、零损失、零真错误以及保留全部旧解码均核验；标签和答案仍须非空。
- 主文手算与 `demo.py` 有刻意的数据差异，手算文档现已明示。独立检查另外执行主文第10.1节四对象例：用同构字符串重命名答案后，经验损失与真错误均 `3→1`。没有将作者的七组示例日志冒称为主文所有手算例的日志。

## 独立预期值怎样产生

`check_language.py` 不导入作者的测试、`verify.py` 或 `examples.py`。候选解码器以整数元组直接列出；参考损失逐对象逐答案累计不符的整数次数，参考真错误逐对象计数。最优值取全部候选中的最小值，不调用待测聚合器或拟合器来产生期望值。

多数拟合的确定性答案另从最优候选中选取：先限制零证据标签保持旧值，再取声明答案次序下的第一个候选。这同时检验最优值、平局规则和零证据特例，而不只检验“返回了某个最优解”。

| 检查 | 有限域或关系 | 次数 |

| 细化真值上下文 | 每个结构9个真值函数 | 648 |

四个细化观察矩阵为全零、两个不同答案各观察一次、不同答案分别观察2与3次，以及每个对象的三个答案各观察一次。这里没有声称枚举全部整数矩阵。

这些数字区分上下文、候选计算和输入检查。不同检查有重叠，不能相加包装为独立样本数；三种优化模式也不是三倍数学覆盖。另有针对性的边界检查，覆盖单答案、`10**100` 级精确整数、不可变对象、真值不参与拟合、未见对象及噪声反例等，不将每条条件包装成额外实验。

## 输入拒绝与失败语义

98个手选拒绝例分为：名称域30例、空标签／答案域2例、映射27例、计数14例、换名9例、细化16例。检查错误容器、重复／空名称、域外映射、长度不符、错误矩阵形状、负数／浮点数／字符串／空值计数、布尔值，以及不满足细化关系的映射。必须明确抛出 `ValueError`；意外异常不计为成功拒绝。

计数中的 `True` 与 `False` 都被拒绝。公开 API 使用字符串域元素，并没有整数索引参数；在名称或映射位置传整数、布尔值属于错误类型，同样拒绝，不作 Python 布尔值等于0／1的索引解释。该检查集覆盖公开校验的主要类别，不是对无限多种 Python 对象的穷尽防御声明。

独立检查不用 Python `assert`。显式失败路径控制在每个模式中确认假条件抛出指定异常。未开展变异测试，因此没有“检出全部变异”等结论；导入、语法、环境或运行器失败也不会被冒充为行为错误检出。

## 重跑与散列绑定

从模型目录运行：

```bash
python3 -B independent-review/check_language.py
python3 -B -O independent-review/check_language.py
python3 -B -OO independent-review/check_language.py
python3 -B independent-review/record_review.py
```

最后一个命令重建三份日志和本目录清单。它先核对作者六份日志及其源码散列，再运行独立检查，并核对运行前后输入与作者证据没有变化。作者测试仍为24个方法；表示充分性的小域复核在独立检查中单列，不改写作者原来的测试计数。

本目录清单绑定生产源码／模型文档、独立脚本／本复核报告、作者证据及独立运行日志。主文只绑定第8节标题起至第11节标题前的UTF-8文本，清单明确记录提取边界；主文其他历史段落不属于本代码审计的散列范围。SHA-256仅绑定所检查的具体版本，不是第三方签名、永久可信认证或通用正确性证明。后续相关改动必须重跑，不能沿用旧清单声称新版本已通过。
