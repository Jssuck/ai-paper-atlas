# 语言习惯、观察与判断：一个有限教学模型

## 1. 历史参照和不能跨越的边界

本单元对读 Condillac《La Logique》第二部分第四章，采用 1798 年印本的正文页码 125–130。底本见 [IA／Wellcome 扫描，PDF 133–138 页](https://archive.org/download/b28772581_0022/b28772581_0022.pdf#page=133)；版本与完整历史论证见[主文](../../papers/1780/condillac-logic-part2-ch4.zh-CN.md)。下列对应关系用于提出问题，不把原文改写成现代定理。

| 原文位置 | 阅读中的问题 | 本模型的有限回应 |
| --- | --- | --- |
| pp. 125–126 | 语言习惯影响判断；语言不完善却仍可能推理正确 | 区分表征与沿用的解码习惯；允许某些对象判断正确、另一些错误 |
| p. 126 | 日常／科学语言的身份不自动保证正确；代数的例外在此被断言而未获证明 | 不设置“科学”“代数”或“日常”名称的正确性特权；不据此证明代数的历史主张 |
| pp. 127–129 | 词汇来历透明的理想，以及对混杂语言的批评 | 检查名称来历能否单独决定正确性；不把语言混合模拟成错误率 |
| pp. 129–130 | 更好的观察及相应精确的语言有助于改进推理 | 把观察记录、分类粒度、判断习惯分别显式化，并说明改进需要哪些条件 |

这是本单元原创的现代、离散、可执行教学构造。Condillac 没有在这些页中提出本文的计数矩阵、多数规则、经验风险最小化、有限映射或测试程序。模型不是他的算法复原，也不是关于认知、儿童学习、自然语言优劣、文化或语言借用的心理学验证。代码不声称解释完整的自然语言语义。

“词源透明”“借来的符号”等说法只作为虚构示例的说明文字；程序既不识别真实词源，也不生成或模拟语言起源。历史论证的支持与局限，要从原文及历史分析判断，不能由程序运行成功倒推。

## 2. 完整定义与假设

### 2.1 有限世界、标签、答案

- $`U`$：有限对象集合。主文以非空对象集为教学任务；可执行程序额外允许空对象集作为总函数边界情形，预测为空、两个错误数皆为零。本附件的公式和证明也涵盖此空情形，不增加认知结论。代码以 `objects` 的无重复字符串元组枚举。
- $`L`$：非空有限标签集合。标签可以未被任何对象使用；不要求表征满射。
- $`A=(a_1,\ldots,a_k)`$：非空有限答案集合，$`k=\lvert A\rvert`$ 为正整数，并声明固定全序 $`a_1\prec\cdots\prec a_k`$。这一全序只用于打破平局，不表示答案价值或可信度。
- $`f:U\to A`$：教学者为这个封闭任务给定的真值函数。这里不研究如何发现或证明真值。
- $`r:U\to L`$：对象的表征。共用一个标签的对象形成一个分类单元。
- $`h_0:L\to A`$：沿用的确定性判断解码器。初始预测为 $`h_0(r(u))`$。

对象、标签和答案的字符串在各自域内无重复。它们只是域元素名称；不同域允许使用同名字符串。解码器不能看见对象标识或其他特征，只能看见 $`r(u)`$。如果同一标签内的真实答案不相同，任何这样的确定性解码器都无法把该单元全部答对。

### 2.2 有限观察记录

对每个 $`(u,a)\in U\times A`$，给定非负整数 $`n(u,a)`$，表示把对象 $`u`$ 记录为答案 $`a`$ 的次数。总观察次数是

```math
N=\sum_{u\in U}\sum_{a\in A}n(u,a).
```

这些次数允许偏置、重复、噪声和互相冲突的答案；也允许全零。没有独立同分布、随机抽样、观测正确、均匀覆盖或因果关系的假设。一次也没被观察的对象满足 $`\sum_a n(u,a)=0`$。整数次数既可以看作多重集中的重复记录，也可看作整数权重；不是概率。

记号对照：附件的 $`n,C_{\ell,a},h_0,h^\star,E_f,D_n`$ 分别对应主文的 $`w,N_{\ell,a},h,h_w,E,D_w`$；只是符号不同。程序以 `counts[i][j]` 保存 $`n(u_i,a_j)`$。必须是精确的非负整数；布尔值、浮点数、负数和不规则矩阵均被拒绝。拟合不使用 $`f`$。真值仅用于事后的封闭世界评估。

### 2.3 两个必须分开的误差

经验观察损失（原始次数，不归一化）为

```math
D_n(r,h)=\sum_{u\in U}\sum_{a\in A}n(u,a)\,\mathbf{1}\{h(r(u))\ne a\}.
```

它统计与已记录答案不一致的次数。程序接口为 `empirical_loss`。观察错了，赞同错误记录反而会降低它。

有限宇宙真值错误数为

```math
E_f(r,h)=\sum_{u\in U}\mathbf{1}\{h(r(u))\ne f(u)\}.
```

它对每个对象只计一次，与观察次数无关。程序接口为 `truth_errors`。即使对象没被观察，仍包含在 $`E_f`$ 中。这里的“未见对象”仍属于已经声明的有限集合 $`U`$，不是代码能够接受域外新对象的承诺。

只有在 $`N>0`$ 时，$`D_n/N`$ 才是可定义的经验错误率；只有在 $`U`$ 非空时，$`E_f/\lvert U\rvert`$ 才是可定义的宇宙错误率。本代码返回计数，不暗中为零分母约定错误率。

## 3. 确定性拟合规则

每个标签的答案计数和总次数为

```math
C_{\ell,a}=\sum_{u:r(u)=\ell}n(u,a),\qquad
T_\ell=\sum_{a\in A}C_{\ell,a}.
```

如果 $`T_\ell=0`$，保留沿用的 $`h_0(\ell)`$。否则选择最大计数所对应答案；若多个答案并列，选择声明的答案顺序中最先出现的一个：

```math
h^\star(\ell)=
\begin{cases}
h_0(\ell),&T_\ell=0,\\
a_j\text{，其中 }j=\min\{i:C_{\ell,a_i}=\max_{a\in A}C_{\ell,a}\},&T_\ell>0.
\end{cases}
```

这不是按字符串的字典顺序排序。例如答案顺序为 `("z", "a", "m")`，计数为 `(2, 2, 1)` 时选择 `"z"`。正计数平局时，即使旧答案也是并列最佳之一，仍按固定顺序选择；零证据时才特别保留旧答案。

零证据标签与零证据对象不能混同。某个未见对象的标签可能被别的对象观察过；该标签的解码就可能改变，从而改变未见对象的预测。相反，整个标签的 $`T_\ell=0`$ 时，本规则绝不改动它。

## 4. 定理一：逐单元最优与精确残差

对任意上述有限域、计数、表征及沿用解码器，拟合规则获得所有确定性解码器中的全局最小经验损失，而且

```math
D_n(r,h^\star)=\min_{h:L\to A}D_n(r,h)
=\sum_{\ell\in L}\left(T_\ell-\max_{a\in A}C_{\ell,a}\right).
```

证明：按标签重新分组，不改变任何计数，得到

```math
D_n(r,h)=\sum_{\ell\in L}\left(T_\ell-C_{\ell,h(\ell)}\right).
```

每个求和项只依赖一个 $`h(\ell)`$。因为每个标签的答案可独立选择，最小化该项等价于最大化 $`C_{\ell,h(\ell)}`$。非空有限答案集合保证最大值存在。若总次数为零，该项对所有答案均为零，保留旧答案同样最优。规则在所有有证据的标签选择一个最大值，所以每项同时达到其最小值；相加即得公式。平局只决定采用哪个最优解，不改变最小损失。证毕。

推论：对同一组 $`r,n`$，$`D_n(r,h^\star)\le D_n(r,h_0)`$。再次拟合不会改变结果：有证据单元仍选择同一个固定次序最大值，零证据单元保留第一次结果。因此 `fit` 幂等。以上不是渐近结论，也不需要概率假设。

残差可能来自不同对象被合并，也可能来自同一对象被记录成不同答案。把所有对象分开仍不能消除同一对象内部的矛盾记录。

## 5. 定理二：细化降低的是可达到的最小经验损失

设更细表征为 $`r':U\to L'`$，其中 $`L'`$ 非空有限。必须存在给定的映射 $`q:L'\to L`$，满足

```math
q\circ r'=r.
```

也就是说，一个细标签内的对象不能跨越两个旧标签。未使用标签也给出 $`q`$，但不要求 $`q`$ 满射。观察记录 $`n`$ 与对象宇宙必须保持相同。

对任意旧解码器 $`g:L\to A`$，定义传递后的细解码器 $`g'=g\circ q`$。于是每个对象满足

```math
g'(r'(u))=g(q(r'(u)))=g(r(u)).
```

所以逐对象预测、经验损失和真值错误数全部相同。特别地，将一个粗表征的最优解这样传递，就是细表征中的可行解，因此

```math
\min_{h':L'\to A}D_n(r',h')\le\min_{h:L\to A}D_n(r,h).
```

这证明的是最小可达损失，不是任意解码器的损失。`refine` 先检查 $`q\circ r'=r`$，并采用 $`h_0\circ q`$，故该函数单独运行时不会改变预测。接着 `fit` 才得到细表征的经验最优解。

三个边界不能省略：

1. 若随意给细标签配置坏解码器，实际经验损失可以变大，即使最小值变小。
2. 即使新旧标签恰好同名，原封不动地保留整张旧字典，也不一定等于正确传递 $`h_0\circ q`$。原本未使用的旧标签一旦接收对象，可能带来错误。例 6 展示 0 → 1。
3. 重新拟合降低经验损失，不保证未见对象或整个宇宙的真值错误数下降。例 3 展示经验损失 3 → 0、宇宙错误 1 → 2。该反例仅靠重新拟合即可出现，无须细化。

如果修改了观察记录，两个损失函数本身也改变了。不能把基于不同记录的数值简单相减，宣称同一个优化目标得到了改进。

## 6. 定理三：联合传递的双射改名不改变正确性

设 $`\pi:L\to\widetilde L`$ 为双射，并同时定义

```math
\widetilde r=\pi\circ r,\qquad
\widetilde h=h\circ\pi^{-1}.
```

则对每个 $`u\in U`$，有

```math
\widetilde h(\widetilde r(u))=h(\pi^{-1}(\pi(r(u))))=h(r(u)).
```

因此逐对象预测、$`D_n`$、$`E_f`$ 及可达到的最小经验损失全部保持不变。若初始解码器也这样传递、答案顺序不变，则拟合与改名可交换：对应标签有相同答案计数，正计数平局选择相同答案，零证据标签保留相同旧答案。

这里要求双射并联合传递 $`r,h`$。只改输入标签但不改对应解释，不属于这个定理。把多个标签合并也不是双射改名。

## 7. 词源说明与形式准确率没有逻辑蕴含关系

取非空描述集合 $`M`$（例如非空字符串的集合），可以给标签另附任意说明 $`m:L\to M`$，比如“示例作者宣称来历透明”“外来风格名称”“不透明记号”。这些说明不进入 $`f,r,h,n`$ 或误差定义。对同一个 $`f,r,h,n`$ 任意改写说明，预测及两个误差数均不变。这是本模型选择的形式独立性，不是关于现实社会中的统计独立性的实证发现。

例 1 的“red-origin”表示命名者以红色作为来历的虚构说明，但继承的解码器反而输出蓝色；同样可以用不透明记号正确解码。名称的来历和当前使用规则是两个不同输入。这个有限反例拒绝“只要词源透明就必然正确”以及“只要借用名称就必然错误”的逻辑保证；它没有测量词源透明对真实使用者学习难度的作用。

为避免制造一个无意义的“词源评分器”，代码没有元数据评分或混合语言惩罚项。

## 8. 何时经验改善才对应真值改善？

如果每个对象恰好被正确观察一次，即 $`n(u,f(u))=1`$，其他答案次数皆为零，那么对所有解码器都有 $`D_n=E_f`$，于是定理一、二也给出相应的宇宙真值保证。若每个对象都被正确观察相同的正整数次，则 $`D_n`$ 是 $`E_f`$ 的相同比例倍数，结论仍成立。

这些是额外假设，而非默认前提。仅仅“所有记录都正确”仍不足以推出不加权的宇宙错误下降：若一个真值为 1 的对象被观察 10 次，两个真值为 0 的对象各被观察 1 次，而三者共享标签，则旧解码 0 的经验损失为 10、宇宙错误为 1；多数解码 1 的经验损失为 2、宇宙错误为 2。

另一项与观察无关的性质：存在零宇宙错误的解码器，当且仅当 $`f`$ 在每个非空表征单元内为常数。必要性来自同一标签只能输出一个答案；充分性来自把该单元的共同真值指定给标签，空单元任意指定。更一般地，定义

```math
B_{\ell,a}=\sum_{u:r(u)=\ell}\mathbf{1}\{f(u)=a\},
```

便有

```math
\min_h E_f(r,h)=\sum_{\ell\in L}\left(\sum_{a\in A}B_{\ell,a}-\max_{a\in A}B_{\ell,a}\right).
```

证明与定理一的逐单元分解相同，但 $`B`$ 是宇宙真值计数，不能偷换成观察计数 $`C`$。代码的拟合器从不计算或使用这个真值最优解。“表示充分”是上述一般性命题，本程序没有另设自动返回充分性的独立 API；不要把 `minimum_empirical_loss` 误当作最小真值错误函数。

## 9. 可执行验证的范围

一般性保证来自上面的证明。程序测试只检查实现是否符合这些定义：24 个专门测试方法，外加明确限定的小域穷举。小域使用两个对象、两个标签、两个答案，逐对象逐答案次数各取 0、1、2。它覆盖零证据、噪声、正计数平局、未使用标签及各种映射，但不声称穷举所有有限宇宙。

穷举参考值直接枚举所有候选解码器并计算逐条记录的损失，不调用拟合或标签汇总函数来产生期望最优解。一个显式失败路径控制确认校验条件为假时确实抛错。没有把故意破坏导入、语法或执行环境的失败记成“行为错误已检出”，也没有开展变异测试覆盖率评估。

`-O` 和 `-OO` 真正运行同样的验证。生产输入校验与穷举校验使用显式条件和异常；专门测试使用 `unittest` 的运行时检查，均不依赖可能被优化删除的 Python `assert` 语句。完整命令、精确域大小与实际输出见 [README](README.md) 和 `evidence/`。
