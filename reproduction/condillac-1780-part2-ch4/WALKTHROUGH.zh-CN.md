# 从语言习惯到有限判断：逐步手算

以下数据全是为教学发明的有限例子。它们不是历史人物的实验记录，也不是自然语言的经验数据。请先区别：经验损失计算与观察答案不符的次数；宇宙真值错误对每个对象只计一次。

运行 `python3 -B demo.py` 可以得到各步骤的完整预测、解码器、经验损失、最小经验损失及真值错误。对应数据在 `examples.py`，完整理论在 [MODEL.zh-CN.md](MODEL.zh-CN.md)。

正文手算和程序示例讲的是同一组区别，但不是逐例相同的数据：

- 正文 §10.1 的四对象例是主文手算，不在本次 `demo.py` 输出中；本附件例 2 用两个对象及 3、2 次权重展示相关区别。
- 正文 §10.2 只观察一个对象 1 次；本附件例 3 观察它 3 次，所以经验损失分别为 1 → 0、3 → 0。
- 正文 §10.3 从 1 条错误记录讲起，并讨论重复错误；本附件例 5 实际使用 4 条错误记录，所以旧经验损失为 4。
- 本附件后续所有输出对应 `examples.py` 中的数据；不能把这些日志称作正文全部手算例子的执行记录。

## 1. 名称来历清楚，解码仍可能错误

对象依次是 `red-object` 和 `blue-object`，真值是 `red`、`blue`。每个对象被正确观察一次。表征标签分别为 `red-origin`、`blue-origin`；这些标签的来历透明性只是假定的示例说明。

1. 沿用习惯把 `red-origin` 解码成 `blue`，把 `blue-origin` 解码成 `red`。
2. 预测为 `(blue, red)`，两个观察都不符，两个对象都答错：经验损失 2，宇宙错误 2。
3. 换一套使用 `xi` 和 `borrowed-symbol` 的表征，分别解码成 `red`、`blue`。
4. 预测为 `(red, blue)`：经验损失 0，宇宙错误 0。

第 3 步同时采用正确解码器，并非声称“只要改名就能纠错”。原来的透明标签也完全可以正确解码。不透明或借来风格的字符串不阻止正确性，名称来历清楚也不替代正确使用。

## 2. 粗分类的冲突与精确残差

有两个对象：真值为 `hot` 的对象被正确记录 3 次；真值为 `cold` 的对象被正确记录 2 次。二者都用标签 `same`。声明的答案顺序为 `(cold, hot)`。

1. 沿用解码为 `cold`：预测 `(cold, cold)`，经验损失 3，宇宙错误 1。
2. `same` 的计数为 `(2, 3)`，总次数为 5。多数解码选择 `hot`。
3. 新预测 `(hot, hot)`，经验损失 2，宇宙错误仍为 1。精确最小残差为 $`5-\max(2,3)=2`$。
4. 把表征细化成 `one`、`two`，各指一个对象；两个细标签都映回旧标签 `same`。
5. 先正确传递旧的已拟合解码，两个细标签都输出 `hot`。预测与实际经验损失仍为 2，但细表征的可达到最小损失已是 0。
6. 再拟合：`one` 计数 `(0, 3)`，选择 `hot`；`two` 计数 `(2, 0)`，选择 `cold`。经验损失 0，宇宙错误 0。
7. 若故意把细解码器写反为 `(cold, hot)`，经验损失会升为 5，宇宙错误为 2。

| 阶段 | 实际经验损失 | 此表征的最小经验损失 | 宇宙错误 |
| --- | ---: | ---: | ---: |
| 原有粗解码 | 3 | 2 | 1 |
| 粗表征拟合后 | 2 | 2 | 1 |
| 细化且传递解码后 | 2 | 0 | 1 |
| 细表征拟合后 | 0 | 0 | 0 |
| 细表征搭配坏解码器 | 5 | 0 | 2 |

这就是“最小可达损失”与“目前实际损失”的区别。

## 3. 经验损失变好，未见对象及宇宙真值变坏

对象为 `(seen, unseen-1, unseen-2)`，真值为 `(1, 0, 0)`，都共享标签 `shared`。答案顺序 `(0, 1)`，观察矩阵为

```text
seen       (0, 3)
unseen-1   (0, 0)
unseen-2   (0, 0)
```

1. 旧解码为 0，预测 `(0, 0, 0)`：与 3 次观察都冲突，经验损失 3；只有第一个对象答错，宇宙错误 1。
2. 标签累计观察为 `(0, 3)`，拟合选择 1。
3. 新预测 `(1, 1, 1)`：经验损失 0；两个未见对象都答错，宇宙错误 2。

主文 §10.2 使用同样真值与分类，但仅观察 `seen` 一次；本例用 3 次，因此经验损失是 3 → 0，而主文是 1 → 0。两者的宇宙错误都为 1 → 2。

没有任何标签是“零证据标签”：`shared` 有 3 次证据。两个对象未见，并不意味着它们共享的解码会保持不变。不存在保证泛化的抽样假设，因而不能将这次经验改善当作认知可靠性的证据。

## 4. 平局和零证据各走哪条规则？

对象为 `(left, right, unseen)`，真值为 `(0, 1, 1)`。前两个对象用标签 `tied`，最后一个用 `empty`。观察矩阵为 `((1, 0), (0, 1), (0, 0))`。旧解码依标签顺序为 `(1, 1)`，答案顺序为 `(0, 1)`。

1. `tied` 累计 `(1, 1)`：正计数平局，按答案顺序选 0，不因为旧值为 1 而保留它。
2. `empty` 累计 `(0, 0)`：无证据，保留旧值 1，不强行选第一答案 0。
3. 解码从 `(1, 1)` 变为 `(0, 1)`；逐对象预测从 `(1, 1, 1)` 变为 `(0, 0, 1)`。
4. 经验损失与宇宙错误都保持为 1，只是两个已见对象中答错的是另一个。

程序另有固定次序 `(z, a, m)` 与计数 `(2, 2, 1)` 的测试，确认选择 `z`，而不是按字典排序选择 `a`。未被任何对象使用的标签，以及整个空宇宙也单独测试。

## 5. 观察错误会强化错误判断

只有一个对象，真值 `no`。旧解码为 `no`，但观察记录 4 次都是 `yes`，即计数 `(0, 4)`。

1. 旧解码：经验损失 4，宇宙错误 0。
2. 拟合选择 `yes`：经验损失 0，宇宙错误 1。
3. 若教学者把观察纠正为 `(4, 0)`，再拟合才会选择 `no`：相对纠正后的记录，经验损失 0，宇宙错误 0。

第 3 步改变了数据。它不是同一个经验目标上的又一次下降，也不是拟合器自行鉴别出了真伪。模型里提供真值的是教学者；拟合器并无查验世界的额外通道。

即使把所有对象拆为独立标签，一个对象若既被记录 `no` 又被记录 `yes`，一个确定性答案仍不能吻合全部记录。这是残差公式中的另一种冲突来源。

## 6. “字典不变”不等于正确传递习惯

两个对象 `(u, v)` 的真值都是 `no`，都被正确观察一次。旧标签集为 `(left, right)`，旧表征为 `(left, left)`，旧解码字典为 `left→no, right→yes`。`right` 起初没有对象。

1. 旧预测 `(no, no)`：经验损失 0，宇宙错误 0。
2. 将表征细化成 `(left, right)`，但照抄旧字典不改：预测 `(no, yes)`，经验损失 1，宇宙错误 1。
3. 此细化的映回函数是 `q(left)=left, q(right)=left`。正确传递应让两个细标签都继承旧 `left` 的 `no`。
4. 使用正确传递，或对新表征重新拟合，均得到 `(no, no)`，损失 0。

第 2 步是真实的表征细化，却没有采用定理证明中的传递解码。它说明“表征更精确”本身不是任意行为改善的保证。

## 7. 真正的双射改名什么都不改变

取例 2 已拟合的粗表征，把唯一标签 `same` 改为 `foreign-looking-token`，同时把解码 `hot` 绑定到新名称。

- 改名前后逐对象预测都是 `(hot, hot)`
- 经验损失都是 2
- 最小经验损失都是 2
- 宇宙错误都是 1

这次只改变名称及其对应键，没有改变分类边界或输出。名称看起来像外语，不会自动让形式任务的准确率下降。

## 8. 从程序结果返回历史阅读

这个模型帮助分别追问：对象怎样被划分？标签带着什么既有判断？观察记录是否可靠、是否偏置？更精确的分类是否配套更新了使用规则？它没有证明某种自然语言、词源政策或历史理论优于另一种。

可以用它检验一个现代说法是否把“观察吻合”“世界中的正确”“词的名称”和“词的使用习惯”混在一起；不能拿一次运行的输出替代对 Condillac 历史论证的解释。
