# 《几何原本》X.29：由有理线段构造平方差

以 `u>0` 为参考长度，令 `h=(H/u)^2` 是正有理数，取严格有序的正整数 `n>m`，要求 `n²−m²` 不是整数平方。函数 `construct(h,n,m)` 输出 `(L/u)^2=h(n²−m²)/n²`、`(G/u)^2=hm²/n²` 以及 `G/H=m/n`。因此 `H²−L²=G²`，差平方的边 `G` 与原线段 `H` 长度可公度；所构造的 `L` 与 `H` 只在平方上可公度。这里的「有理线段」采取第十卷的参考平方条件，并不要求 `H/u` 为有理数。代码不近似根式，也不执行尺规操作。

例如 `h=1,n=3,m=2` 得输出 `5/9,4/9,2/3`；把 `h` 换成非平方的 2 则是 `10/9,8/9,2/3`。对照 `n=5,m=3` 的整数差平方为 16，会令 `L/H` 为有理数，故拒绝；相等、反序、零与非精确类型也拒绝。

独立基线枚举整数第三边来核对勾股条件，不调用整数平方根。对 `1≤m<n≤64` 的 2,016 个严格有序整数对，1,962 个有效、54 个因平方差前提被拒。检查输出的差平方恒等式、尺度和有理比值。有限校验不替代证明。
