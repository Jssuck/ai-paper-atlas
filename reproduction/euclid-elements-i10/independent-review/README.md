# Euclid I.10 独立技术复核实跑

本目录由与正文和主复现编写者分开的 AI 技术审查代理制作。它检查作者的精确实现，不是第二套完整几何实现，不构成人类专家认证或形式证明。

在本目录运行：

```sh
python3 run_audit.py
```

`run_audit.py` 在普通、`-O`、`-OO` 三种模式中运行 `independent_checks.py`，保存真实标准输出、错误输出、退出码、时间及结果；不改写作者的测试、Notebook 或主运行记录。三个模式除自身优化级别字段外结果相同。

每模式的新增检查口径如下，不能把这些不同类型的计数相加后称为同一种“测试数”：

- 512 份新有理输入证书：256 组固定种子端点，各取两支；预期中点用独立 `Fraction` 坐标运算计算。
- 120 个非中点的一般射线交点：先独立指定严格内部参数及正射线参数，再核对求交器结果。
- 1881 个符号例：用整数平方根得到 √3 的严格有理上下界，独立对照精确符号；含 100 对 Pell 近抵消输入。
- 200 对域元素：分别核对乘法与可定义的除法系数。
- 16 份拒绝证书：15 份改动/畸形对象，另加一份改绑可信端点的证书。
- 4 项角符号和方向检查；8 条显式拒绝路径。
- 检查 Notebook 六代码格的保存状态、输出与非内核元数据；这里不声称执行过 Jupyter kernel 或浏览器渲染。

全部作者顶层 Python 源码与 Notebook 代码格还接受 AST 检查，确认没有会在优化模式中消失的裸 `assert`。执行门禁为显式异常，不依赖 `assert`。
