# VII.16：交换乘数次序

现代整数上的教学重构，不是古代运行记录或一般命题的计算证明。这里按卷七定义 15，用所谓「A 乘 B」表示取 A 个 B，用「B 乘 A」表示取 B 个 A。这两次累加彼此独立。先确认 B 量度第一组和 A 次；按 VII.15 的位置交换量度角色，核对 A 量度该和 B 次。第二组和按定义也由 A 量度 B 次。同一个度量块 A 和同一次数给出同一总数。

例如 A=3、B=4，分别得到 4+4+4 和 3+3+3+3；第一组和 12 被 4 量度 3 次，换成 3 后量度 4 次。用 3 量度 13 不整除；量度 15 虽然整除，次数却不是 4。测试独立枚举有限网格的格点，再交换坐标核对两种计数。

历史重构仅接受大于 1 的给定整数。modern 函数另展示 1 的恒等行为和 0 的空和，不声称 VII.15 的量度转移包含除以零。
