# II.12 教学复现：第二格内部归谬与目标强度

本目录配套[中文深读](../../papers/ancient/aristotle-prior-analytics-ii12.zh-CN.md)，是原创、低成本的现代集合教学模型，不是古代程序的复制或完整自然语言证明器。原文实读范围及译本问题见[来源台账](../../papers/ancient/aristotle-prior-analytics-ii12.sources.zh-CN.md)。这里的候选语言、数字、模型政策和程序均是教学重构，不冒称原文已有算法。

## 语义与有限范围

谓项在前：`U(P,S)`意为每个S是P；`E(P,S)`意为没有S是P；`I(P,S)`意为有S是P；`O(P,S)`意为有S不是P。整句矛盾是U/O和E/I。I与O可以同真，不能互相当作否定。

论域非空，A、B、C可空。对象的三个成员位压缩为0–7的类型，bit0=A、bit1=B、bit2=C。每个非空类型支持集恰取一个代表，得到255模型；过滤A、B、C均非空得到218模型。单独要求B非空有240模型。重复同型对象不影响这里无等号、无计数的一元四型命题。这给出枚举范围的理由，但真实跑完仍不替代正文的一般证明，更不扩展到模态、关系、数量或现实事实。

## 候选如何产生

固定目标`Q(A,B)`，假设其整句矛盾`H(A,B)`。内部只容许一个第二格步骤：`H(A,B)`和`X(A,C)`推出`R(C,B)`，A是共同谓项。Q、X、R各四种，因此每种政策64个候选。不先换位，不增加中项，不作任意多步推导。

每条记录分别检查：
1. 内部前提可满足，并保真地推出R。
2. 独立已知背景X与R的整句矛盾可满足。
3. 独立背景推出目标Q。

三项通过才记`certificate=true`。这是教学标签，不是通用证明助理内核证书。内部有效和外部目标成立分开记录；不能用背景另有证明反推某个错误内部步骤有效。

反模型按支持集基数、再按升序类型元组的字典序选择最小者。这里的最小是明示支持集顺序下最小，不包含自然语言例子的认知复杂度比较。

## 实际结果

|存在政策|模型|候选|U有效路线|E有效路线|I有效路线|O有效路线|
|---|---:|---:|---:|---:|---:|---:|
|允许空项|255|64|1|1|1|1|
|A、B、C全非空|218|64|1|1|2|2|

新增两条来自全称否定内部结果弱化为特称否定所需的存在条件，不是原文宣布了两个新三段论式。全项非空仅为敏感性对照，不断言古文唯一语义。原文四条标准路线可取以下独立背景，全部在允许空项语义有效：

- U目标：`U(A,C), U(C,B)`。
- I目标：`U(A,C), I(C,B)`。
- E目标：`E(A,C), U(C,B)`。
- O目标：`E(A,C), I(C,B)`。

11个具名检查另检验：
- I/O路线若把存在背景I(C,B)换成U(C,B)，B为空时都失败，最小反模型为类型集`[0]`；单独加B非空足够恢复，不必要求所有项存在。
- 用E假设来证明U时，否定E只得到I。具名强度反例明确采用较弱背景`U(A,C), I(C,B)`，反模型`[2,7]`。若保留原`U(A,C), U(C,B)`，背景本身仍推出U，不能谎称该原背景有反模型；错误的是把排除E的局部结束步骤当作直接证明U。
- `非U→E`、`非E→U`均失败；三项非空反模型同为`[2,7]`。
- 类型`[2,7]`对应A=C={7}、B={2,7}，I(A,B)和O(A,B)共真。
