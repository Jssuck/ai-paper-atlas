# 独立核验说明

`oracle.py` 不导入生产代码的模型、真值函数或枚举器。使用显式集合解释 U/E/I/O，先遍历1–3个有标号对象的所有三谓词赋值，再独立遍历八个布尔三元类型的占用与否。第二轮覆盖非空域下全部255个类型支持集，并可限制三项非空或B非空。

第一轮是独立的有界交叉检查，不凭其有限范围宣称一般完备。第二轮逐条比对生产的内部/外部关系有效性、前提满足模型数、反模型数和按基数再字典序选取的最小反模型；它检验的是已声明的一元集合教学语义，不裁定古代唯一语义。

在本目录运行：

```sh
python oracle.py > normal.log 2>&1
python -O oracle.py > optimized.log 2>&1
python -OO oracle.py > double-optimized.log 2>&1
```

实际结果：每模式6项独立测试通过；有标号模型584/371，各64候选；两个存在政策共256条内部/外部记录及11项具名检查与生产结果一致。成功路线数4/6。日志为真实运行；无外部依赖，程序不访问网络。`oracle-results.json`记录第一轮逐条结果，第二轮比较生产 `../evidence/results-normal.json`。
