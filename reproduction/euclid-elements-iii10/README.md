# Euclid III.10：两圆交点的精确有理数教学模型

这是《几何原本》III.10 的**现代坐标教学重构**，不是原文算法复原、形式化证明器或几何图像识别器。已阅读 [Joyce 原文与导读](https://mathcs.clarku.edu/~djoyce/elements/bookIII/propIII10.html)：原文以两条公共弦的垂直平分线确定两圆同心，再由 III.5 得矛盾。这里的减圆方程与判别量是另行构造的现代解释，不冒充欧几里得符号。

## 输入、输出与例外

所有坐标及**平方半径**只接受整数、有理数字符串或 `fractions.Fraction`；拒绝布尔值、浮点数、坏分母、非法点形状和非正平方半径。圆是欧氏平面中给定圆心、正半径的圆周，不是填充圆盘。`classify(o1,r1,o2,r2)` 的 `r1,r2` 是平方半径，不是半径。

- 圆心不同：`count` 精确返回0、1或2；分别为相离、相切、相交。
- 圆心相同、平方半径不同：0个公共点。
- 圆心相同、平方半径相同：圆周重合；`count=None` 表示无限多个公共点，**不是零个、未知或恰好两个**。因此“不同圆”的假设不可删除。
- `rational_intersections` 返回精确有理交点元组；相离返回空元组。若交点无理或圆周重合，则返回 `None`，须结合 `classify` 的结果区分这两种情况；不会把无理坐标四舍五入伪装为精确值。
- `same_circle_from_three` 验证给定三个非共线点确实同时在两个已提供参数的圆上，然后报告中心和平方半径相等。重复点、共线点、不共圆均拒绝。这是对给定对象的有限检查，不是从像素认证未知圆周，也不是独立一般证明。

## 根轴与判别量如何得出

记第一圆心为 a，第二为 b，平方半径 R、S，v=b−a，D=v·v。D=0 必须先单独处理，不能除以零。D>0 时，令 X=a+u，两圆条件为 u·u=R 和 (u−v)·(u−v)=S。相减消去二次项，得到 2v·u=T，其中 T=R−S+D。

根轴上的垂足 h=a+Tv/(2D)，令 w=(−v_y,v_x)，则 w 与 v 垂直且 w·w=D。根轴上任意点唯一写成 X=h+λw。代回第一圆得到 λ²=N/(4D²)，其中 N=4DR−T²。因此 N<0 无实交点，N=0 一个交点，N>0 两个交点；两个圆方程的公共点必须在这条直线上，且代回第一圆与根轴条件已保证第二圆条件。一般结论来自这些恒等式和实二次方程根数，不来自枚举。

N 是有理数，但平方根不一定有理。源码用整数平方根分别核查分子分母是否完全平方：只有二者都是平方时才返回有理坐标。这不影响交点**个数**的精确判定。

示例 a=(0,0)、b=(6,0)、R=S=25：D=36、T=36、N=2304，h=(3,0)，交点是 (3,4)、(3,−4)。示例 R=S=1、b=(1,0) 则 N=3，两个交点无理，程序仍精确报告2。

## 三点为何迫使两圆重合

若三个互异公共点不共线，减圆方程会要求它们都落在同一条根轴上；非共线性排除圆心不同的分支。圆心相同后，一个公共点已足够推出半径相同。因此两个不同圆最多有两个公共点。源码要求非共线三点；“圆周上三互异点必不共线”的几何事实由直线代圆得到最高二次方程解释，不依赖测试清单。

## 真实运行

在本目录执行：

```sh
python run_all.py
```

运行器真实运行六条命令并保存 stdout、stderr、退出码：

```sh
python -m unittest -v test_geometry
python -O -m unittest -v test_geometry
python -OO -m unittest -v test_geometry
python run_examples.py
python create_notebook.py
python verify_notebook.py
```

本次 CPython 3.12.14，标准库，无第三方安装。**21项测试在普通、-O、-OO模式各通过一次，六个子进程均退出0。** 每个模式的一个测试方法含600个精确实例（25种平移×4种正有理缩放×6种中心差方向），每例核验两个不同交点到两圆心的平方距离。600例不是600条测试方法，也不是一般证明。

测试另覆盖内外相离、内外相切、水平/竖直根轴、重合、同心不等半径、无理交点、接近相切的精确有理扰动、极小尺度、三点约束、坏输入。接近相切的例子用2±10⁻¹⁸作为中心距，结果精确为2或0，不使用浮点容差。六个算例包括有理/无理两交点、内外相切、相离和重合。

## 边界与不声称的内容

此实现只接收有理圆心和有理平方半径；可精确判断无理交点存在，但不输出一般代数数对象。有限测试不覆盖全部实圆，也不验证古代版本史；原创SVG仅画合法两交点例子，不把原文反证假设中的四公共点画成两条真正的圆周。独立审查另行保存；测试日志不含私人对话、账户、主机路径或秘密。
