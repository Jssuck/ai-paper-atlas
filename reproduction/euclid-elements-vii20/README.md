# VII.20：最小的同比例数怎样量度其他数

这是现代正整数教学重构，不是古代实跑记录或一般定理的计算证明。受限的候选检查只接受大于 1 的给定数和基本块，并选择前项小于后项、候选低于目标的方向。先用最大公度还原基本块和两个倍数，再按倍数逐份累加。这里用现代算法算出基本块；不把它当作欧几里得原证明的计算顺序。原证明区分候选相对于目标的一份与若干份，必须先约分倍数之比才能判分支。代码另给出该约分比；对若干份分支还给出历史切块（原目标除以约分分母），它可能是现代基本块的倍数。

例如目标 (16,24)，候选 (10,15)，两边候选分别是目标的 5/8。候选可以拆成五对 (2,3)；逐对汇总一直保持 2:3，符合 VII.12 使用的同率求和结构。单对 (2,3) 更小，是候选不最小的见证。实际最小对 (2,3) 分别量度目标两项，各 8 次。如果候选改成 (8,12)，原始倍数 4:8 应约为 1:2，它处于历史的一份分支，虽仍不通过现代最小性检验。目标 (20,30)、候选 (12,18) 则是 3:5，历史切块 (4,6) 不同于现代基本块 (2,3)。另一个可核对的算例是 91:143=7:11，量度次数为 13。

独立穷举用 Fraction 逐对检查，在有限范围内找到最先匹配的对。允许单位时 3:6 的最小对为 1:2；人为排除单位后穷举给出 2:4，但 2、4 并不分别整除 3、6。这个算例区分现代含单位约分与仅排除单位的天真移植，不能把后者当作原命题的解释。
