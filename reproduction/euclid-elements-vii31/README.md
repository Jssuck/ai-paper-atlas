# VII.31：合数有质因数

现代整数教学重构，不是古代实跑记录或一般命题的计算证明。设给定合数为 N。每个合数节点都选大于 1 且严格小于它的因数。相邻节点满足整除，其后每一步也都整除原数。正整数不能无限严格下降，终止节点没有非单位真因数，因此是量度原数的质数。命题寻找一个质因数，不要求列出全部质因数。

程序以整平方根内的试除寻找最小真因数，用互补因数找到最大真因数；还提供一个按顺序选中间真因数的演示。原文不规定这些策略。84 的最大路径为 84→42→21→7，最小路径为 84→2，中间路径为 84→12→4→2。终点不必相同。独立测试用完整真因数枚举核对每一步和终点，并检查终点及中间节点整除原数。单位和已是质数的起点都不符合此处的合数前提。
