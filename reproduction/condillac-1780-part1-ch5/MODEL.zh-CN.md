# 模型、假设与证明

## 0. 史料与模型的边界

本例阅读依据是 1798 年版《La Logique》第一部第五章，印刷页 49–53（扫描 PDF 57–61）。它从以下段落提出教学问题，但数学对象、程序接口、具体数据、反例和证明**全部由本教学单元现代设定**：

| 底本定位 | 段落关切 | 本例如何使用 | 不作的归属 |
|---|---|---|---|
| p.49 / PDF57 | 从可见效果谈不可见原因；把运动的原因称为 force，并不因此更认识它 | 区分存在、数目、身份和属性；名称不改观测 | 不把有限集合或识别判据归给孔狄亚克 |
| p.50 / PDF58 | 测量的结果是关系；有名称不保证已有相应认识 | 单位、校准与相对量的现代例子 | 不把响应式称为原文公式或牛顿定律 |
| p.51 / PDF59 | 观察现象及因果关联，扩展对自然部分系统的认识；开始转向宇宙原因 | 区分新观测与新前提；说明有限可知 | 不声称新增观测总能解决一切问题 |
| pp.52–53 / PDF60–61 | 第一因及其属性的推演 | 提醒读者逐步区分所观察的内容与所加入的前提 | 不编码、证明或否证上帝、第一因及其属性 |

历史作者在这些页中的具体论证，不等同于本模型中的假设。尤其，下面的“属性 red/blue”只是无历史负载的标签，不对应神学属性。源文不是程序输入，程序输出也不是源文主张为真的证据。

## 1. 有限、确定、无噪声的观测模型

### 1.1 定义

- $`H`$：有限假设集。一个 $`h`$ 描述一个允许的世界；它不是观测。主文通常取非空集；本实现另允许空集以测试筛选后的边界情形。
- $`O:H\to Y`$：观测映射。程序以整数元组作为观测签名，例如 `(1,7)`。
- $`h\sim h'`$ 当且仅当 $`O(h)=O(h')`$：观测等价。
- $`F_y=\{h\in H:O(h)=y\}`$：给定观测 $`y`$ 的相容集合，也叫观测纤维。
- $`q:H\to V`$：待回答的问题，例如原因是否存在、原因个数、身份、某项属性。

对当前观测 $`y`$：

- $`F_y`$ 为空：`inconsistent`。数据与这个模型不相容，不可利用空集上的逻辑真空声称已经识别。
- $`F_y`$ 非空且 $`q(F_y)`$ 只有一个值：`identified`。
- $`q(F_y)`$ 有至少两个值：`ambiguous`。

这是**模型内、精确数据下的识别**，不是概率置信度，也不保证真实世界属于 $`H`$。所有推断都以“真实世界属于 $`H`$，$`O`$ 的预测正确，观测无误”为条件。

### 1.2 基本判据与证明

$`q`$ 全局可识别，当且仅当它在 $`O`$ 的每个非空纤维上恒定；等价地，存在 $`d:O(H)\to V`$，使 $`q=d\circ O`$。

必要性：若 $`q=d\circ O`$，任何 $`O(h)=O(h')`$ 都给出：

```math
q(h)=d(O(h))=d(O(h'))=q(h').
```

充分性：对任意已实现的签名 $`y`$，取其纤维内的任一 $`h`$，定义 $`d(y)=q(h)`$。纤维内恒定保证取谁都相同，故定义良好，且对全部 $`h`$ 都有 $`q(h)=d(O(h))`$。

如果同一纤维内有 $`h`$ 和 $`h'`$ 的 $`q`$ 值不同，只读取 $`O`$ 的任何确定性程序都得到同一个输入，不能在两个世界同时答对。因此这不是“换个更聪明的分类器就能解决”的问题。随机输出也不能在两个世界都保证正确；本例不引入先验概率。

程序的 `globally_identifiable` 判定全域性质。$`H`$ 为空时此普遍命题真空为真；但 `answer` 对任何当前观测均为 `inconsistent`。这两个接口有意区分。

### 1.3 存在、唯一、身份、属性并不相同

教学假设如下。数字 0/1 只是观察类别，不是物理强度。

| 假设 $`h`$ | $`O(h)`$ | 原因存在 | 原因数目 | 身份描述 | 属性标签 |
|---|---:|---|---:|---|---|
| none | (0,) | 否 | 0 | none | absent |
| A | (1,) | 是 | 1 | A | red |
| B | (1,) | 是 | 1 | B | blue |
| A+B | (1,) | 是 | 2 | A+B | red |

观测 `(1,)` 的纤维是 `{A,B,A+B}`。存在问题恒为真；原因数目取 1 或 2；身份有三种；属性有两种。因此“存在”“恰好一个”“是哪一个”“具有什么属性”不能互相替换。`number_of_causes` 的两个值已经给出“是否恰好一个”不可识别的证据。

**因果前提反例**：加入 spontaneous，令其观测签名为 `(1,)`、`cause_exists=False`。相同观测现在也与无所指原因的世界相容，存在性不再可识别。这不是对实际自然或原文因果原则的反驳，而是证明原来的结论使用了 $`H`$ 中已编码的限制。模型没有从感官材料凭空推出因果公理。

### 1.4 命名与信息

`with_labels` 只改变语言元数据，$`h`$ 的标识和 $`O`$ 都不变，故 $`F_y`$、$`q`$ 的识别结果均不变。即使为每个假设配上不同名称，也不能因此得知哪个假设是真的。

更一般地，若附加记录 $`N=f\circ O`$，即新字段完全由旧观测计算，则 $`O'(h)=(O(h),N(h))`$ 与 $`O`$ 拥有完全相同的纤维：

- $`O(h)=O(h')`$ 蕴含 $`f(O(h))=f(O(h'))`$，故 $`O'(h)=O'(h')`$。
- $`O'(h)=O'(h')`$ 的第一分量已蕴含 $`O(h)=O(h')`$。

这不主张语言在思考或交流中毫无价值，也不否认有独立证据支持的名称可以传达知识。这里只断言：没有引入任何新事实的重命名或重编码不能提供新的经验区分。

### 1.5 新观测、筛选前提与扩大学说

新增真实可用的观测 $`R:H\to Z`$，令 $`O'=(O,R)`$。固定新观测 $`(y,z)`$ 时，

```math
F'_{(y,z)}=F_y\cap R^{-1}(z).
```

所以每个新纤维包含于一个旧纤维。新分区细化旧分区；旧有可识别问题继续全局可识别。要判断指定问题 $`q`$ 是否获得新的识别，须考察 $`R`$ 是否消除了 $`q`$ 在各新纤维内的取值分歧；仅拆开某个旧纤维未必足够。重复旧记录不会分开旧纤维。

程序的 `refines(other)` 只比较**相同的假设集**上的分区，允许记录顺序不同。不同 $`H`$ 时拒绝比较，避免把删假设包装成新增信息。

新增前提 $`A\subseteq H`$ 则改用 $`H_A=A`$、$`O_A=O|_A`$，相容集合成为 $`F_y\cap A`$；观测列保持不变。若 $`A`$ 去掉所有相容假设，答案为不相容。若 $`A`$ 恰好只保留一个，则可能获得条件性的唯一答案；这不表明观察设备提供了更多信息。若错误前提排除了真实世界，还会产生错误的确定感。

反过来扩展 $`H`$ 可能令原本恒定的 $`q`$ 变得不恒定。所有“可识别”结论必须伴随模型边界，不能跨假设空间无条件搬运。

## 2. 比例、校准与隐藏参数

### 2.1 现代响应式的全部假设

另设正有理数 $`k>0`$（待研究系数）、$`g>0`$（仪器增益），输入 $`u\in\mathbb{Q}`$，输出 $`y\in\mathbb{Q}`$，规定：

```math
y=gku.
```

这是为了易于手算而选的**现代比例响应式**，不是原文公式，不是 force 的定义，不是 $`F=ma`$，也没有从“运动更大”推出任何特定物理规律。输入坐标已知且校准；数据精确、同步、无截距、无噪声，$`g`$ 与 $`k`$ 在测量期间保持不变。若改变这些假设，需要另建模型。

使用 `fractions.Fraction`；不接收浮点数，以免把舍入误差误当模型不相容。负输入允许，正乘积会给出同号输出。$`g,k`$ 严格为正是一项设定，故非零输入对应零输出也判为不相容；本例不覆盖 $`k=0`$ 的系统。

### 2.2 乘积与校准

一次 $`u\ne0`$ 的观测给出 $`p=y/u=gk`$；多次观测必须得到相同的正 $`p`$。若 $`u=0`$，模型只允许 $`y=0`$，此测量不限制 $`p`$。全部输入为零时，结果为 `uninformative`，不能把 $`0/0`$ 当作系数。

若 $`g`$ 已知且非零，$`k=p/g`$ 唯一。例：$`u=(1,2,3)`$，$`y=(6,12,18)`$，得到 $`p=6`$；若 $`g=2`$，$`k=3`$；若 $`g=1`$，$`k=6`$。这些是不同校准前提下的推断，不是两种同样的绝对测量。

### 2.3 未知增益下的不可识别性：对全部输入的证明

对于任意正有理数 $`c`$，变换 $`(k,g)\mapsto(ck,g/c)`$ 后：

```math
\frac{g}{c}(ck)u=gku.
```

所以这两个参数世界对**每个** $`u`$ 的输出均相同，不只在例子选用的三个输入上相同。取 $`c\ne1`$ 就得到不同 $`k,g`$。任意增加同类输入实验都无法独立识别 $`k`$ 或 $`g`$；它们的乘积 $`p`$ 可以识别。有限参数网格上的搜索容易因为网格边界删掉等价解而造成虚假的唯一性，因此本例用一般代数证明，而不把有限网格当完整参数空间。

校准或额外测量 $`g`$ 能打破这个对称性；单纯声称 $`g=1`$ 只是选择前提，不是观测发现。

### 2.4 共同增益下的相对量

若两个系统共享同一个增益 $`g`$，响应乘积 $`p_A=gk_A`$、$`p_B=gk_B`$，则：

```math
\frac{p_A}{p_B}=\frac{gk_A}{gk_B}=\frac{k_A}{k_B}.
```

此比值不依赖未知共同增益。例：$`p_A=6`$、$`p_B=10`$，比例为 $`3/5`$。若仪器增益不同，$`p_A/p_B=(g_A/g_B)(k_A/k_B)`$，就不能这样解释。程序 `relative_coefficient` 计算比值，但**无法从输入数据自行证明共同增益前提**，调用者必须保证它。反例：$`k_A=3,g_A=2`$；$`k_B=5,g_B=3`$；观测乘积比为 $`6/15=2/5`$，而真正系数比为 $`3/5`$。

这把“关系可得、隐藏本性未必可得”变成一个可核算的现代例子，而不把“所有现实测量都只如此”当作程序已证结论。

## 3. 实现契约和证明之外的检查

`FiniteModel` 保存不可变元组；状态和列名唯一；观测为整数元组；问题映射、标签映射及新观测映射的键必须恰好覆盖 $`H`$。标签不参与匹配。`answer` 返回状态、相容假设及可能答案，避免用一个布尔值掩盖不相容与不确定的差别。

问题的取值应使用具备正常相等语义的不可变值，例如 `bool`、`int`、`str`、`Fraction` 或由这类值组成的元组。数学判据要求相等关系自反、对称、传递，且相等值具有一致的哈希值。运行时的 `Hashable` 检查并不完整验证这些定律；`NaN` 和自定义病态相等／哈希对象不在本定理及接口的使用契约内。观测输入本身被限制为精确整数，不接受浮点数。

穷举检查独立枚举 $`d:\{0,1\}^2\to\{0,1\}`$ 的全部 16 种解码器，比较“是否有一个 $`d`$ 满足 $`q=d\circ O`$”和实际全局识别结果，并逐个检查当前答案。它还用独立的成对判据检查新增观测是否真正细分旧分区。完整范围为 $`|H|\in\{0,1,2,3,4\}`$；每个状态可以任取四种二位签名；$`q`$ 和新增列可以任取二值。各类 4,681 案例来自 $`\sum_{n=0}^4 4^n 2^n`$；五种测试观测带来 23,405 次当前答案检查。

单元测试同时覆盖零列观测、空假设集、错误键域、不合法输入、不同记录顺序、比例冲突、零输入、错误增益前提与可重现示例。九个独立语义变异只修改临时副本；原源文件与测试不变。完整测试输出保留（本地绝对路径规范为相对路径），不以导入错误冒充被测试发现的逻辑错误。

这些检查支持“实现与写出的现代定义一致”这一有限结论。它们不是独立历史审查，不提供哲学命题的经验验证，也不能取代一般性证明。
