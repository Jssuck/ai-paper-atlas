# 从看得见的效果到可识别的问题：现代教学模型

本目录是原创、低成本、可运行的**现代形式化教学演示**，用于细读孔狄亚克《逻辑》第一部第五章。它不是历史算法复原，不是作者的计算模型，不是牛顿力学模拟，也不检验人的心理机制或神学命题。

底本是 1798 年《Œuvres de Condillac》第二十二卷中的《La Logique》，原书第 49–53 页，对应本项目扫描 PDF 第 57–61 页。目录名中的 1780 是作品一版的书目年份，不认证最早版次，也不能当成本扫描印本的年代。页码和解释的历史证据由主文及源文审计提供；这里的程序没有把源文转成可执行规则。

## 与主文的对应方式

主文使用 h0、ha、hb、hc 及运动／仪器读数；程序使用 none、A、B、A+B。它们是两组分别设定的虚构教学例子，共享“按观测纤维检查问题是否恒定”的形式方法，数值、假设身份与实验条件不能逐项混用。程序增加 A+B，是为了单独检验“是否恰好一个原因”。

主文的基础理论以非空假设集 $`H`$ 为通常前提；实现额外允许空 $`H`$，用于检验筛选前提把候选全部删光的边界情形。此时全局普遍性质真空成立，但对任何当前观测都必须返回 `inconsistent`，不作事实识别。

## 一分钟运行

需要 Python 3.10 或更新版本；实际验证版本见 `logs/environment.json`。无第三方包、无下载、无账户、无模型调用、无 GPU、无随机训练。

在本目录运行：

```sh
python3 demo.py
python3 verify.py
```

第一条打印逐步例子的 JSON，精确有理数以字符串显示；第二条运行全部检查，并更新本目录 `logs/`。不要使用 `-O` 或 `-OO`；有限穷举依赖断言，入口会拒绝关闭断言的运行。

也可分别运行：

```sh
python3 -m unittest discover -s tests -v
python3 finite_oracle.py
python3 mutation_check.py
```

## 要学会的四个区别

1. **某类原因存在、原因只有一个、原因身份、原因属性**是不同问题。相同观测可以只回答其中一部分。
2. **给未知对象命名**可以方便交流；在本模型中，名称本身不改变哪些假设与观测相容。
3. **增加观测**与**增加前提**可能都缩小候选集，但前者增加数据，后者删去允许的世界。不能把两者的依据混为一谈。
4. **可测的比例或组合量**不等于全部隐藏参数。在指定的响应式中，未知仪器增益与隐藏系数可以彼此补偿。

同时，程序直接展示反例：只要扩大学说允许的假设空间，原先“存在原因”的识别结论就可能消失。模型从不把“观察到效果”无条件升级成因果证明。

## 文件路线

- `MODEL.zh-CN.md`：明确假设、定义、证明、源文对应关系和不可得出的结论
- `WALKTHROUGH.zh-CN.md`：逐行推算的例子、反例和输出字段说明
- `finite_model.py`：有限假设、观测等价类、问题识别、命名、观测扩充、假设筛选
- `ratios.py`：精确有理数响应、校准、参数混淆、共同增益下的比例
- `demo.py`：全部教学例子及机器可读输出
- `tests/test_model.py`：23 个单元测试，含错误输入和边界情形
- `finite_oracle.py`：用独立的“枚举解码器”定义核对有限范围内的实现
- `mutation_check.py`：将九个语义错误真正写入临时副本，用原测试检查能否发现错误
- `verify.py`：一键运行、记录实际环境、逐阶段命令、退出码、用时和源文件 SHA-256
- `logs/`：真实执行结果。`mutation-details.txt` 包含被故意破坏的程序的预期失败详情

## 怎样解读验证

单元测试检查指定行为；穷举覆盖 0–4 个假设、两列二值观测、全部布尔问题，以及一列二值新增观测。它检查 4,681 个全局识别问题、23,405 个当前观测答案、4,681 个观测扩充情形。更大模型的结论须依据 `MODEL.zh-CN.md` 的证明，不能由这个有限边界外推为“穷尽验证”。

变异检查分别破坏“一致才能识别”、空候选集处理、命名隔离、旧观测保留、校准、参数对称性、零输入处理、冲突检测和比例方向。只有程序完成测试、出现断言失败且没有测试错误，才记为 `KILLED`。九个针对性变异全被发现仍不证明没有其他缺陷。

`verify.py` 返回 0 且 `logs/verification.json` 为 `PASS`，只说明本次所列检查通过。它不宣称独立审稿，也不验证历史解释。独立审查须由另一位审查者另行完成。

## 成本和限制

默认例子很小，全部检查通常数秒即可结束；确切用时以本次日志为准。日志中的工作目录和回溯路径已规范为相对于本目录的路径，解释器命令使用实际解释器的文件名；运行版本、时间、退出码与用时保留原值。穷举器的状态数上限固定为 4，不是可任意扩大的高性能工具。模型没有噪声、概率、近似相等、测量误差或经验数据；不能直接用于科学仪器标定或现实因果推断。
