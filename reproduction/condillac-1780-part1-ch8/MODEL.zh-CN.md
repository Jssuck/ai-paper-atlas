# 从匮缺到希望与意志：模型、假设和证明

## 1. 对象、版本与方法边界

本项目对应孔狄亚克《逻辑》第一部第八章。1780仅为本次核定的一版书目年；这里实际逐页阅读的是1798年《全集》第22卷，印刷页67—71，Internet Archive扫描PDF第75—79页。章题为“Continuation du même sujet”。[所据扫描本](https://archive.org/details/b28772581_0022)。不要把文件夹中的1780当作扫描本的出版年。

这是原创、低成本、可运行的现代教学重构，使用布尔条件、有限可能世界和显式输入标签。原文没有给出可能世界语义、概率算法、效用最大化、学习阈值或Python程序。运行成功只能表明代码符合下列约定；不能验证孔狄亚克的心理发生论，更不能证明一切能力由感觉转化而成。

只观察一个主体、一个对象、一个当前时刻，以及该对象随后能否获得的一个情境。输入由读者标注，没有行为数据拟合。除下文显式列出的不变量之外，代码不强制情感、习惯、判断各层的完整心理连贯性；某些输入刻意只用于接口独立性检查。本章较宽的“意志”和更宽的“思想”保留为术语分类，不编码成单一布尔变量。

## 2. 原文依据与明确省略

- 印67—68页区分“缺少”和“被剥夺”。仅缺少某物，甚至不知其为何物，都不自动构成这里的需要。被剥夺涉及认识该物，惯常享用它，或至少惯常想象享用所许诺的快乐。此前真正享用过并非必要条件。
- 印68页把这类被剥夺导致的受苦称为需要，讨论其较弱形态、不安以及遇阻碍时的增强。本模型仅取“由这种剥夺而受苦”的定性连接；不把所有痛苦等同需要，不量化程度，不给不安设强度函数，也不制造一套阈值把不适划为痛苦。
- 印68—69页把身体与心灵能力朝向所需对象称为欲望。代码中的方向标签是输入记录，没有实现回忆、反思、想象和身体动作的完整因果链。
- 印69页称习惯化欲望为激情，并允许其暂停后因轻微契机重新发生。因此代码区分习惯倾向与当前激活，不能由当前没有欲望推出没有激情。
- 同页将希望联系于欲望及“将会获得”的判断，将狭义意志联系于欲望及经验养成的“不会遇到障碍”的习惯判断。代码将两种判断分开；没有擅自将一种定义为另一种的高概率版本。
- 印70页扩展“意志”和“思想”的涵盖范围；印70—71页总结能力由感觉转化而来，并转向下一章。这里不为绝望、恐惧、自信或自负另造判断阈值。

## 3. 符号表与输入不变量

各布尔量取0或1；代码必须接收真正的bool，拒绝把1、字符串等默认为真。

| 符号 | 代码 | 含义 |
|---|---|---|
| $`L`$ | `lacking` | 当前客观上缺少该对象或其享用 |
| $`K`$ | `known` | 对象已被认识 |
| $`E`$ | `habitual_enjoyment` | 已有惯常享用的背景 |
| $`I`$ | `habitual_imagination` | 惯常想象该对象所许诺的快乐 |
| $`F`$ | `faculties_directed` | 已记录原文所述能力朝向该对象的状态 |
| $`P`$ | `desire_habit` | 欲望习惯仍作为倾向存在 |
| $`D`$ | `deprivation` | 本重构中的被剥夺 |
| $`N`$ | `need` | 因该剥夺而受苦的需要 |
| $`d`$ | `desire` | 当前欲望 |
| $`h`$ | `experience_backed` | 习惯已建立且标注为来自经验 |
| $`\Omega`$ | `worlds` | 有限、非空的情境全集，名称唯一 |
| $`B`$ | `support` | 主体尚保留的非空候选情境集合 |
| $`a`$ | `actual` | 实际情境，属于全集；不必属于候选集 |
| $`G(w)`$ | `obtains` | 在情境w中将获得对象 |
| $`O(w)`$ | `obstacle_free` | 在情境w中不会遇到阻碍 |
| $`J_B(Q)`$ | `judges(Q)` | 所保留情境全都满足Q的定性判断 |
| $`H`$ | `hope` | 本模型中的希望 |
| $`W`$ | `narrow_will` | 本模型中的狭义意志 |

$`I`$保留原文“惯常享有，或至少想象其乐”的习惯语境，不设形成习惯所需的次数、时长或强化率。它不意味着曾经真的享用。$`h`$的“来自经验”只是来源标签，不保证经验正确、充分或合理，也不保证本次判断为真。

输入必须满足：

```math
(E\lor I)\Rightarrow K,\qquad
\varnothing\ne B\subseteq\Omega,\qquad a\in\Omega.
```

代码拒绝不符合这些不变量的输入，而不是猜测修补。特别是，$`a\in B`$是额外事实，不是构造器默许的公理。

当前的$`L`$与未来的$`G(a)`$处于不同时间位置，故“现在缺少、随后获得”完全一致。这里没有一个暗藏的式子把当前缺少定义为未来不能获得。

## 4. 情感层的操作化

```math
D=L\land K\land(E\lor I),\qquad
N=D,\qquad d=N\land F.
```

$`D`$的等式是有限模型的充分、必要条件约定，不是声称“凡现实中认识且缺少的事物都会使人受苦”。它还要求享用或想象快乐的背景。$`N=D`$以原文的因果说法为模型假设：这里的被剥夺产生该种受苦。程序没有从数据推断这个连接，也没有测量受苦强度。

允许$`N=1,F=0`$的输入，意指需要为真而定向输入为假；false并非未知或尚未记录。这样的输入并不宣称符合原文全部心理因果链；程序没有执行原文需要藉能力定向而扰乱安宁的因果连接。若研究者要使记录始终符合该完整连接，应额外限制输入，而不能把本程序现有的允许范围当作历史主张。

激情作两个标签处理：

```math
\text{passion disposition}=P,\qquad
\text{passion active}=P\land d.
```

因此$`P=1,d=0`$可以是暂停中的激情。$`E`$与$`P`$不同，惯常享用不由代码自动转为欲望习惯。原文关于习惯形成和轻微契机再现的解释，在此仅以倾向/激活的区别保留；没有实现触发动力学，也不保证任意线索都会激活。

## 5. 判断层：没有概率的支持集语义

对两个可用命题之一$`Q`$：

```math
J_B(Q)=1\quad\Longleftrightarrow\quad
\forall w\in B,\; Q(w)=1.
```

这是现代的全称候选集约定，选来把“主体作出判断”和“事情实际上如此”分开。原文“判断”并不因此被还原成作者主张的逻辑必然性。这里不给各世界概率，不使用“概率等于1”来定义意志，不将未知判断当作已断言其反面。

```math
h=\text{established}\land\text{from experience},
\qquad H=d\land J_B(G),
\qquad W=d\land h\land J_B(O).
```

代码将原文“不会遇到任何障碍”的部分以$`O`$表达。“一切都应协同”在日常理解中可能包含更强的成功条件；本项目不悄悄给$`O`$加上这些条件。若读者选择较强理解，应明示添加下面的桥接假设，届时结论会相应变化。

非空$`B`$至关重要：空集上的全称命题会空真，但主体没有任何候选情境不应被这个程序报成同时充满希望与意志。空输入或清空支持集的限制操作均抛出ValueError；代码没有提供矛盾后的修复算法。

## 6. 一般命题与证明

以下论证对任何满足上述不变量的有限域成立，不是从四世界运行结果归纳而来。

### 命题一：缺少不蕴涵需要，实际享用也不是需要的必要条件

取$`L=1,K=0,E=I=0`$，则$`D=N=0`$，尽管$`L=1`$。反之，取$`L=K=I=1,E=0`$，满足一致性约束，且$`D=N=1`$。所以在这套定义中，无须先前真正享用即可构成需要。证明仅由布尔代入完成；不构成对现实人的实验断言。

### 命题二：限制候选集保留已成立的判断

若$`\varnothing\ne B'\subseteq B`$且$`J_B(Q)=1`$，则$`J_{B'}(Q)=1`$。

证明：任取$`w\in B'`$，由包含关系有$`w\in B`$。原判断给出$`Q(w)=1`$。因此新候选集的每一元素均满足Q。证毕。

固定情感状态和习惯输入时，此命题也保留已成立的H和W。这里固定$`G,O`$的赋值；不能一边删候选世界、一边悄悄改世界的命题真值。反方向不成立：从含有成功和失败的候选集删掉失败世界可以新生获得判断。这种删减不保证合理或更接近事实；如果实际世界就是被删者，可以产生错误确信。

### 命题三：判断并不一般蕴涵事实

取两个世界$`u,v`$，$`B=\{u\}`$，$`a=v`$，且$`G(u)=O(u)=1`$、$`G(v)=O(v)=0`$。取$`d=h=1`$。则H与W均为1，实际获得和实际无障碍均为0。故希望和狭义意志都不保证实际成功或实际无阻碍。

若额外知道$`a\in B`$，则$`J_B(Q)\Rightarrow Q(a)`$。证明：将全称命题实例化到$`a`$即可。$`a\in B`$是这里的充分条件，不是单个判断正确的必要条件；即便实际世界不在候选集，也可能偶然判断正确。

### 命题四：希望与狭义意志没有无条件的线性嵌套

两者都蕴涵d，由各自的合取定义立即成立。但H不必蕴涵W：令唯一候选世界满足$`G=1,O=0`$，取$`d=h=1`$。此时H=1、W=0。可以用“最终克服障碍而得到”理解这种赋值。

W也不必蕴涵H：令唯一候选世界满足$`G=0,O=1`$，仍取$`d=h=1`$。此时W=1、H=0。这个反模型刻意测试形式系统中两谓词未设桥梁的结果，不能拿来声称孔狄亚克赞同“所有条件协同却仍不成功”；它只说明，要排除这种赋值，必须写出额外的成功条件。

此外，即使$`G=O=1`$，只要$`h=0`$，也会出现H=1、W=0。因此仅合并命题内容仍不足以消除经验习惯这项区别。

### 命题五：显式桥梁给出有条件的嵌套

假定支持集上的桥接条件：

```math
C_B:\quad \forall w\in B,\quad O(w)\Rightarrow G(w).
```

则$`W\Rightarrow H`$。证明：W给出d和$`J_B(O)`$。对任一$`w\in B`$，由$`O(w)`$及桥梁推出$`G(w)`$。因此$`J_B(G)`$，与d合取得H。证毕。

这只需桥梁在B成立，不需要在整个全集成立。程序输出`bridge_holds_on_support`检查的正是这个局部条件。桥梁单独为真不等于存在意志或希望；例如B中每个世界都满足$`O=0`$，桥梁也可以空真，而W仍为0。

若另有反向桥梁$`G\Rightarrow O`$在B上成立，且$`h=1`$，则可推出$`H\Rightarrow W`$。这里给出充分条件，不声称它们是任一固定状态中该蕴涵成立的必要条件。若在B上两个命题等价且$`h=1`$，则H与W等价。所有这些条件都是显示给读者的现代假设，不是从原文偷偷导入的必然关系。

### 命题六：候选集为空不能当作得到所有判断的捷径

全称式在空集会真，因此如果不维护非空不变量，就会出现无候选世界却$`J_B(G)=J_B(O)=1`$。本模型通过构造器拒绝空B而排除它。`restrict`复用同一构造器，故任何被接纳的限制结果继续满足非空不变量。这是代码域的设计证明，不是对人类矛盾信念的心理解释。

## 7. 程序成本、试验范围和验证层次

模型只用Python标准库。一次`evaluate`对世界列表进行固定次数扫描，因此对于n个世界，时间为O(n)，返回固定大小字典；存放模型需要O(n)级空间。没有搜索树、数值优化、训练或外部调用。测试四种$`(G,O)`$赋值，所有15个非空支持集、4个实际世界，以及选定的情感/习惯组合。

三层证据务必分开：

1. 本文第6节是一般的集合论和布尔证明。
2. `test_model.py`的27个测试方法中，有480个分类组合、64个有实际世界在支持集内的命题检查、130个非空限制下的命题检查、15个桥梁支持集检查。它们是明确有限范围的实现检查，不是任意规模穷举。
3. `mutation_check.py`分别植入11个语义错误。行为断言失败才记为检出；语法错误、超时、未完成测试、错误或跳过测试记为测试框架失败。真实语法错误对照必须被归到后者，不能拿来充数。

四种真值组合不是任意世界身份的完整表示。例如实际世界与候选世界可以是不同身份而有相同命题真值；把它们合并可能改变`actual_in_support`。因此这里不声称四世界枚举完整覆盖所有身份关系、动态更新或心理状态。一般证明不依赖这种压缩。

普通、`-O`和`-OO`模式都真正执行`unittest`的检查方法；没有会被优化删除的Python `assert`语句。变异子进程保持其调用者的优化级别，并报告实际级别。`results/`保存本次实际运行，环境文件记录解释器版本与源代码哈希，不能据此宣称所有Python版本都已验证。

## 8. 这次重构能教什么

读者可以追踪“客观缺少—有快乐背景的剥夺—需要—定向欲望”的不同条件，看到暂停中的激情为何不能被删掉，再将欲望与两种不同判断组合。最重要的练习是每增加一个推论，都问它来自定义、原文的因果主张、输入事实，还是新增的桥接假设。

它不输出治疗建议、理性决策方案或自动行动，也不把“希望”“意志”作为临床心理量表。本章的价值在于辨析感觉、评价、习惯和判断的角色；这段程序只是使这些角色的若干区别变得可检查。
