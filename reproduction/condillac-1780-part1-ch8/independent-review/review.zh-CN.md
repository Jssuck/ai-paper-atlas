# 第八章教学模型的独立代码审计

审计日期：2026-10-11。结论：下列有限范围全部通过。普通、`-O`、`-OO`结果一致；28种指定语义变异在每种模式均被行为检查检出，真实的语法错误、导入异常、运行异常及超时对照均被归为框架失败。未发现核心模型实现与公开定义不一致之处。

这套检查由实现作者之外的复核角色另写，未将作者测试改名作为独立证据。“独立”指本次实现与核查分工，不是外部学术同行评审，也不是另一个Python运行时或完全独立的公理基础。

人工复核实际查看了1798年版印刷页67—71的五页图像；1780是作品书目年，不是本次图像底本年。源文定位及版次说明以[来源账本](../../../papers/1780/condillac-logic-part1-ch8.sources.zh-CN.md)为准。

原文支持的概念区别与代码新增约定分开核对：

- 缺少不等于这里的剥夺。享用习惯和想象快乐分别保留，不强制曾经真实享用。
- 由这类剥夺而受苦被称为需要；代码把它作为明示假设，没有从布尔输入测得疼痛。
- 能力定向作为输入，不冒称已实现需要、回忆、反思、想象与身体运动的发生链。
- 激情习惯允许当前暂停，不能把倾向与当前欲望合并。
- 希望加入获得判断；狭义意志加入经验形成的无障碍判断。两谓词未暗设蕴涵。
- 广义意志和思想不被压成额外单个开关；未自行给原文只列名的绝望、恐惧等规定阈值。

有限可能世界、全称支持集判断、显式实际世界、限制支持集操作都是现代重构。代码运行不能证明原文的心理发生论；也未声称“无障碍”布尔值保留了原句全部模态或规范力量。

## 2. 独立预期值如何计算

[review_model.py](review_model.py)不调用生产属性来计算正确答案，不使用作者测试或作者演示作为oracle。

1. 将六个情感输入编码为0至63的整数，另行列出40个合法行、12个剥夺行、6个欲望行及3个活跃激情行。其余24行必须拒绝。倾向位独立于当前欲望。
2. 将两个习惯输入编码为四行，仅第3行是经验支持且已建立的判断习惯。
3. 将每个世界的两谓词编码为0至3；按独立的真值分类构造“反例所在世界”的位掩码。支持集中没有相应反例，才给肯定判断。未复用生产代码的`all`扫描公式。
4. 希望和狭义意志由独立真值表选行，实际标签只读取另给的实际世界编码；支持集不会自动补进实际世界。
5. 每次比较完整16标签字典，包括精确键集合与真正的布尔类型，避免只检查两个主要标签却漏掉其余接口。

两套实现仍共享定义、Python和数据协议。另一种计算方式与生产输出一致，是有限实现证据，不等于程序绝对正确性的证明。

## 3. 精确覆盖范围

每种优化模式均执行相同范围，不能把三次运行当成三个独立样本。

| 检查 | 每模式数量和边界 |
|---|---|
| 情感输入 | 40个合法行、24个拒绝行，覆盖六位输入全部64行 |
| 判断习惯 | 全部4行 |
| 四规范世界完整输出 | 40 × 4 × 15 × 4 = 9,600例，每例核对全部16标签 |
| 三命名世界全部真值赋值 | 64 × 7 × 3 × 40 × 4 = 215,040例，每例核对全部16标签 |
| 世界顺序不变性 | 24种排列 × 15支持集 × 4实际世界 = 1,440例 |
| 世界全集的非空子集 | 184例，实际世界须在该全集，但不必在支持集 |
| 合法非空限制 | 260组，逐一检查支持集、全集和实际世界保存 |
| 判断/希望/意志/桥梁单调性 | 上述260组各核5标签，共1,300项 |
| 拒绝扩张支持集 | 640次 |
| 拒绝清空支持集 | 60次 |
| 带实际世界成员条件的事实性 | 64个命题实例 |
| 有桥梁且意志为真的实例 | 4例，另有全输出枚举覆盖全部桥梁真假情况 |
| 定向反例 | 5个：错误确信、两个非包含方向、限制产生新判断、潜在激情 |
| 其他非法API输入 | 139项，包括严格布尔、容器、对象、重复名、域外世界和谓词限制 |
| 冻结记录 | 4种数据类的普通赋值均须拒绝 |

两个完整分类块合计224,640例。三世界块枚举全部64种谓词赋值，允许不同身份具有相同真值，从而额外检查四种规范真值类型无法独自覆盖的身份区别。世界名称有刻意误导性的英文名及中文名；预期结果不依据名称含义。

四世界块穷举该固定全集的全部非空支持集和全部实际世界。三世界块穷举三个命名世界的全部谓词赋值、非空支持集、实际世界及情感/习惯组合。它们都不是任意大小世界集合、任意Python对象或全部人类心理状态的穷举。

184个全集检查按全集大小分解为4 + 36 + 84 + 60。260个限制来自每个实际世界的65个非空嵌套支持集对。单调性检查固定情感、习惯和世界真值；没有一边删除世界一边改写谓词。

## 4. API和反例复核

- 情感、习惯及世界谓词要求真正的布尔量，整数1、字符串和其他真值对象不能悄悄替代。
- 世界集合要求元组，支持集要求不可变集合；名称必须是非空字符串且互不重复。名称规则是“非空”，不是额外的“去除空白后非空”规则。
- 未知世界、无世界、空支持、未知谓词和错误求值参数都被拒绝。仅接纳两个公开谓词，不能借属性名访问其他对象内容。
- `restrict`接收待保留的非空子集；它本身不是一般证据交集、贝叶斯更新或矛盾修复算法。
- 全称判断为假不等于肯定其否定。模型没有三值未知输入，不能将缺资料误写成已经确认的假。
- 实际世界不在支持集中可以产生错误确信；实际世界在支持集中提供事实性充分条件，但不是某次判断碰巧正确的必要条件。
- 希望真而狭义意志假、狭义意志真而希望假均有合法非空反例。只有明示支持集上无障碍蕴涵获得的桥梁，才支持相应方向的条件推论。
- 冻结数据类的检查只针对普通API赋值，不构成针对任意恶意Python代码的安全沙箱。

人工核对了[MODEL](../MODEL.zh-CN.md)中的六组命题、[逐步讲解](../WALKTHROUGH.zh-CN.md)的九个案例及支持集限制示例。一般证明来自定义和集合论；有限检查没有被当作无限域证明。

审计中推动并复核了两项表述修正：主文将实际世界在支持集中明确为事实性的充分条件；演示将实际获得的前值、后值及“是否不变”分别输出。修正后的限制示例是前值false、后值false、不变标记true。核心`model.py`无需修改。

## 5. 指定语义变异与框架失败

[mutation_review.py](mutation_review.py)在临时副本植入28种错误，运行上述独立oracle，不调用作者测试来判定检出。

- 情感条件：将缺少当剥夺、两种快乐背景误用合取、删掉想象分支、接纳未知对象的快乐背景、抹掉需要约定、忽略定向、只凭定向产生欲望
- 激情：删掉潜在激情、把享用习惯当激情、把全部倾向当当前激活
- 判断与事实：全称换存在、对整个全集判断、偷偷补进实际世界、从第一个世界取事实、声称实际世界永远在支持中
- 希望与意志：希望不需欲望、由事实代替判断、忽略经验来源、忽略习惯已建立、忽略当前无障碍判断、无桥梁强加希望条件、混同获得与无障碍、倒转桥梁
- 输入与更新：允许空支持、允许重复世界名、允许证据扩张、忽略限制操作、将严格布尔契约换成真值宽容

只有独立程序明确返回`SEMANTIC_FAILURE`且退出码为1，才算`detected_by_behavior`。语法错误、导入失败、运行异常、超时、不明退出或结构化报告无效，都记`harness_failure`，不计为成功检出。

每种模式还实际执行四个负对照：故意损坏语法、导入时抛错、求值时抛错、导入时睡眠并触发超时。四项全部被正确归为框架失败。预期输入拒绝是输入契约的一部分，与非预期崩溃不同。

[普通变异](logs/mutations-normal.json)、[-O变异](logs/mutations-O.json)、[-OO变异](logs/mutations-OO.json)分别28/28检出；三种模式合计84次指定变异运行及12次负对照。它们只针对这些错误，不声称检出全部可能缺陷。脚本运行前先验证同级别未改基线，并确认生产源码运行期间没有改变。

## 6. 实跑和复现

独立基线：[普通](logs/normal.json)、[-O](logs/O.json)、[-OO](logs/OO.json)。三份均为PASS，计数相同，实际优化级别分别为0、1、2。

另行重跑作者27个测试：[普通](logs/author-tests-normal.log)、[-O](logs/author-tests-O.log)、[-OO](logs/author-tests-OO.log)均通过。九个演示及支持集操作的独立重跑见[演示JSON](logs/demo.json)。作者11个语义变异与本报告28个变异为不同检查集，不合并成39种独立发现。

从上一层模型目录运行：

```sh
python -B independent-review/review_model.py
python -O -B independent-review/review_model.py
python -OO -B independent-review/review_model.py
python -B independent-review/mutation_review.py
python -O -B independent-review/mutation_review.py
python -OO -B independent-review/mutation_review.py
```

只用标准库，不安装、下载、联网或远程写入。默认核对相邻`model.py`；`review_model.py`可接收一个模型文件参数供变异脚本定位临时副本。独立oracle用显式检查函数，不依赖会被`-O`移除的`assert`。变异子进程使用调用者的实际优化级别。
