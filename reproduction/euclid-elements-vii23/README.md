# VII.23：因数继承互素性

现代正整数教学重构，不是古代实跑或定理的计算证明。给定彼此互素的 A、B，以及整除 A 的 C。若 D>1 同时量度 C 和 B，则 D|C|A 给出 D|A，和 D|B 一起违背互素。程序把两段精确整除的商相乘，并核对合成的商；独立测试枚举公因数，不借用程序的 gcd 判定输出。

35、12、5 满足前提：5 量度 35 共 7 次，5 和 12 互素。非互素数据 (A,B,C,D)=(12,9,6,3) 可亲手核对传递：12/6=2、6/3=2，所以 12/3=4，且 9/3=3。这不是符合互素前提的反例。逆向则不成立：12、9、4 中，4 量度 12 且与 9 互素，但 12 和 9 有公度 3。

程序的给定数都大于 1。现代延伸 C=1 时自然和任一正整数互素，代码另行用枚举核对，不冒充古文「数」。C=A 的现代边界保留一倍整除。
