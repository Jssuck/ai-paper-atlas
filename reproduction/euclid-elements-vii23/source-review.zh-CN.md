# VII.23 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.23.html)、Heath 1908 卷 II 印刷页 324–325（扫描物理页 337–338，图在 324，末步及短评在 325）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=213) 印刷页 213，以及 [Joyce VII.23](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII23.html)。

希文 Α、Β、Γ、Δ 对应英语 A、B、C、D。已知 A、B 互素，C 量尽 A；D 仅在反设 C、B 不互素时才引入。若 D 量尽 C，而 C 量尽 A，则 D 也量尽 A；D 又量尽 B，这才与原假设矛盾。整除的传递是原证直接使用的推论，不另列命题编号。现代教学可以用嵌套分组补足：A 由若干整块 C 组成，每块 C 又由若干整块 D 组成，所以所有 D 小块合起来正好是 A。没有必要假定 D 为素数、把它选为最大公因数，或将这一步写成调用现代算法。

第 VII 卷定义 12 意味着互素的两个数仅由单位共同量尽。这里反设的 D 是一个“数”，不是单位；否则从 D 同时量尽 A、B 并不能推出矛盾。希文在反设句中的不定代词 [τις] 有编辑括号，Fitzpatrick 对应写作 [some]，不改变 D 的作用。Clay 英文题句有单复数排字疏漏，并且证明英栏在否定 C、B 有共同的数能量尽后即止；希文、两印本和 Joyce 都保留读回互素的最后一句。Heath、Clay、Joyce 标出的定义 12 指向互素矛盾，不是整除传递的单独依据。

[VII.24](https://www.claymath.org/library/historical/euclid/files/elem.7.24.html) 直接使用本命题：该处的 C 与 A 互素，且 E 量尽 C，由此推出 A 与 E 互素。切勿把两个命题各自的字母角色照抄过去；VII.24 的乘积互素结论还依赖别的论证，并非 VII.23 的单独结论。

所核卷前与命题所在印页、Fitzpatrick 版该页以及两在线对读页，未见专改 VII.23 的正式勘误；并非所有印次的校勘。Fitzpatrick 否定句应结合随后的互素结论及希文读成“没有非单位的数同时量尽二者”，不能仅由“有某个数不能量尽”推出互素。
