# 《几何原本》IX.22：偶数个奇数的和

`even_count_odd_sum(terms)` 接受至少两项、项数为偶数、且每项为不小于 3 的奇整数。先从每项取出一个单位，将余下的偶数各分两半；再将取出的单位两两配对，每对贡献一个单位到总和的每一半。以 $`(3,5,7,9)`$ 为例，余量逐项半数为 $`(1,2,3,4)`$，取出的四个单位可组成两对，得到总半数 $`12`$。

程序特意不接受包含单位 1 的奇数列、空列或负数，以贴近这里的古代非单位正数模型；现代奇数可以是 1 或负数，空和也可定义为 0。正偶数输入 $`(2,4)`$ 虽同样得到偶数和，却不是本命题的见证。

在本目录运行，使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

有限基线遍历长度 1 至 4、各项 1 至 7 的有序列，查预先生成的奇数表和偶数总和表。对合规输入先配对原项，再查询每对和的半数，最后与移出单位的构造比较。有限核验不代替一般证明。Notebook 日志是标准库顺序执行三个代码单元的实际记录，并非 Jupyter 内核运行。
