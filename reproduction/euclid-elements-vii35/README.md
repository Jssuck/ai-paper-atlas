# VII.35：最小公倍数整除任一公倍数

现代正整数教学重构，不是古代运行证据或一般证明。公倍数 T 用公倍数 L 作步长时，余数是 T−qL。对任一给定因数 d，两个整除次数相减得到 T/d−q(L/d)，所以该余数仍由 d 量度。若 L 最小，假设存在严格介于 0 和 L 之间的余数就产生矛盾；并非实测找到了这样的反例。

以 12、18 为例，108 用最小步长 36 恰好量度 3 次。把步长故意改为非最小公倍数 72，余数 36 确实仍是公倍数；这不反驳原命题。把目标改为非公倍数 50，除以 36 得余数 14，但已经不具备公倍数前提。单位与目标等于最小值的情形按现代整数约定单独核对，零余数不是正公倍数。
