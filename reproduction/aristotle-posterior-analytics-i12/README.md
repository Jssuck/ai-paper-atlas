## 1. 共享属性为什么不够

固定宇宙 U={0,1,2}。每个整数 mask 的第 i 位表示 i 是否属于该集合，范围0至7。`included(A,B)`检查A是否包含于B；允许空主项的现代集合语义，不偷偷把存在承担混入全称句。

若A、B都包含于R，并不能推出A包含于B。明确非空反例是A={0}、B={1}、R={0,1}。两前提均真，而0属于A不属于B。对应程序：`shared_attribute(1,2,3)`为真，`included(1,2)`为假。这只是火与某种比例都“快速”这一错误结构的反例，不声称集合元素是实际火焰或比例。

有效替代路线A包含于B且B包含于R，则任取x属于A，先得x属于B，再得x属于R，所以A包含于R。程序在512个集合三元组中检验该一般证明的有限实例，而非用枚举代替一般证明。

## 2. 正向推得出，不许可反向推回去

A={0}包含于B={0,1}，但B不包含于A。若只掌握结论或结果B中的对象，不能因A会带来B就断定它属于A。只有另有B包含于A的桥梁，才有双向包含及集合相等。一般证明是两个方向逐元素推出，不来自计数。

三元组与集合对枚举分别报告全体反模型和A、B都非空的反模型。空集合不是失败结论的唯一来源。该集合重构与命题“肯定后件”的结构相似，但不把集合包含、命题蕴涵和古代解释关系说成同一概念。

## 3. 同一个词是否真是同一个中项

`same_middle((词面,意义ID),(词面,意义ID))`只比较外部给定的意义ID。词面都是circle而ID分别是几何圆与史诗组诗时，结果为假；词面circle与圆不同、意义ID相同时，结果为真。

这是人工标注的词义一致性检查，不会自动理解语词、图形或古文。将错误的相同ID赋给歧义词，程序就会接受错误标注。因此它只能暴露“词面相同不保证语义相同”的接口需求，不能认证前提无歧义。

## 4. 问题范围不是问题真值

`question_route(science, question_domain, role, bridges)`的`role`只允许：

- `derived`：在外部声明的范围内，可进入该学科说明任务；
- `principle`：范围内原则标为本任务不证明，不代表不可讨论或不需要其他层次的辩护；
- `foreign`：外部已标作不属于该任务范围。

不同域只有明确的有向桥声明才能进入范围。例如`('geometry','optics')`表示本模型明确允许几何任务处理光学方面相应的派生问题；反向不能凭此自动接受。桥只是人为声明，不是程序推导出的学科从属事实，也不表示所有光学命题都可用纯几何证明。

程序不会检查问题是否为真、是否有适当本己原则、桥接是否现实有效，也不把“范围内但错误”改成“外域”。“平行线相交”作为古代几何任务中的错误材料，与谈音乐的外域问题不同；此处不借这个例子否定现代非欧几何，而是强调需先声明体系。

## 5. 纵向与横向扩展

`closure(nodes,edges)`中的边(x,y)表示声明x包含于y。采用含自反边的传递闭包，算法为现代教学实现：

- 纵向：d→c→b→a得到d→a；
- 横向：c→b→a和e→d→a得到c→a、e→a，但不能得到c→e。

512张三节点有向图（包括自环）逐一比较矩阵式闭包与独立逐起点栈式可达性搜索oracle。循环边可以产生相互可达；这不表示独立科学根据已建立，更不证明对象或声明边真实。闭包不新增原始事实，也不模拟所有科学发展的机制。原文扩展讨论不等于此程序的算法复杂度结论。
