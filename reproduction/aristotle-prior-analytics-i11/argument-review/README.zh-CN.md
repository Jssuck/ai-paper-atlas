# I.11 独立论证检查

独立于教学实现，以Python集合和逐对象量化重写语义，没有导入或调用作者模型。

## 实际命令

在本目录运行：

```sh
python check_argument.py > normal.log
python -O check_argument.py > optimized.log
python -OO check_argument.py > double-optimized.log
```

三模式均真实通过，每模式4,096个两世界两对象外延赋值、63,659项显式检查。三个结果日志逐字相同。检查器用显式异常，不依赖优化模式会移除的assert。

检查：必要命题蕴含实际命题、双边稳定I对称、两条反向锚定见证路线、六式的12个单必要配置在锚定/句子两语义中的分类、正文两反模型、轮换见证与空中项。所有配置都有满足前提的模型，不用空真掩盖有效性。

锚定语义六种大前提必要配置无反例，六种小前提必要配置均有反例；句子必然性的12配置均有反例。结果仅限本检查的有限域，正文另给任意世界/域的一般证明。不是对原文所有模态规则的历史复现，更不证明作者正确或错误。

本次不检查作者实现的输入验证或故障注入；那属于独立代码审查。此文件不能替代来源核对。
