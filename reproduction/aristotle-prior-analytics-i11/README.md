# I.11：第三格混合模态的有限语义实验

本附件是原创现代教学重构，不是亚里士多德的程序，也不声称唯一还原原章模态逻辑。完整原典核验见[来源账本](../../papers/ancient/aristotle-prior-analytics-i11.sources.zh-CN.md)。此处以原章讨论的第三格形式为问题来源，专门检查：一个易于实现的现代解释，是否保留原文需要的换位与结论方向？答案并非总是。

## 定义与范围

固定非空有限对象域，至少一个世界，第一个世界为实际世界。A、B、C都是各世界可变的一元性质；同一对象编号跨世界保持身份。模型不包含时间、因果、事物本质、可达关系或自然种类理论。程序主报告固定两个对象、两个世界，完整列举4096种性质赋值。

用 S0 表示实际S对象，P∩表示各世界P的交集，P∪表示并集。实际AEIO为通常集合包含、不交、相交、差集非空。锚定必要定义为：

| 形式 | 本程序定义 |
|---|---|
| N_A(S,P) | S0 包含于 P∩ |
| N_E(S,P) | S0 与 P∪ 不交 |
| N_I(S,P) | S0 与 P∩ 相交 |
| N_O(S,P) | S0 减 P∪ 非空 |

这把主体选在实际世界，而只要求谓词性质保持。另一种句子必要解释则要求每个世界的同一AEIO句子都真；各世界特称句可以由不同对象作见证。这两套解释不混用。辅助函数 fixed_shared_witness 检查两个性质的稳定交集非空，是对称但更强的固定见证条件，不是第三套完整AEIO语义。

六种第三格形态的大前提都是 C→A，小前提 C→B，结论 B→A。Darapti=AAI，Felapton=EAO，Disamis=IAI，Datisi=AII，Bocardo=OAO，Ferison=EIO。报告每种形态的两个配置：将指定一条前提解释为必要，另一条仅按实际真值评价；这并不强迫后者必然为假。实际C非空是显式条件，即使某一特称前提已保证它也不重复计数。

## 实际执行结果

[完整报告](results.json)列出24种配置，每项包含满足前提的模型数、反模型数和按域大小1再2搜索的最小对象域反例。这里的“最小”只指两个世界范围内的对象数，不声称世界数、边数或历史反例的全局最小性。

- 锚定解释：六种形态的大前提必要均无反模型；小前提必要均有反模型。
- 句子必要解释：十二种混合配置都有反模型。
- 以上有限无反例不是一般证明。锚定大前提必要的六条一般见证证明见[逐步走查](WALKTHROUGH.md)。存在明确反例则足以否定相应现代语义下的无条件有效性。
- 重要失配：原章对两全称肯定的必要性位置可互换、并否定一些特称必要配置的普遍保证；本锚定模型却不对称，并使Disamis/Bocardo大前提必要有效。因此不能把计算表冒充原文“验证通过”。这正是实验要暴露的解释风险。

## 运行

在本目录使用已安装Python，无第三方依赖：

```text
python -m unittest -v test_modal
python -O -m unittest -v test_modal
python -OO -m unittest -v test_modal
python modal.py
python -O modal.py
python -OO modal.py
```

32项unittest测试在普通、-O、-OO模式各实际通过；测试使用unittest断言，不会因优化开关被删除。三份完整分类报告逐字节相同。测试含单世界退化、必要蕴含实际、六条有效路线、所有失败配置的单对象反例、换位缺口、稳定桥接、不同世界更换见证、非法输入及精确计数回归。
