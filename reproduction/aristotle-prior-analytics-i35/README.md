# I.35 的最小教学复现：有限词表、复合项与证明证书

这是原创现代教学代码，不是亚里士多德的程序、古希腊语解析器或完整几何定理证明器。对应[中文深读](../../papers/ancient/aristotle-prior-analytics-i35.zh-CN.md)。历史原章仅要求中项不必总是单个名称，并没有给出下面的 AST、核验算法或欧几里得辅助线证明。

## 一、运行与文件

无需安装包；仅用 Python 标准库。于本目录运行：

```bash
python3 model.py > results.json
python3 -m unittest -v test_model > test-default.log 2>&1
python3 -O -m unittest -v test_model > test-O.log 2>&1
python3 -OO -m unittest -v test_model > test-OO.log 2>&1
python3 -c "import sys,platform; print('Python:',sys.version); print('Platform:',platform.platform()); print('Dependencies: Python standard library only')" > environment.txt
```

- [model.py](model.py)：两个独立的小核验器及演示。
- [test_model.py](test_model.py)：12项回归测试；[默认](test-default.log)、[-O](test-O.log)、[-OO](test-OO.log) 均为实际运行。
- [results.json](results.json)：真实演示结果；[environment.txt](environment.txt)：实际解释器和平台。

`-O`、`-OO`仍通过，因为有效性检查显式抛出异常，不依赖可被优化关闭的 `assert`。这些通过结果不等于已发现全部程序错误。

## 二、输入语言与可信边界

|代码对象|数学解释|边界|
|---|---|---|
|`Atom(name)`|论域上的一元谓词|名字是标识符，不自动证明其含义|
|`And(P,Q)`|谓词交集|结构相同才视为相同；不自动进行交换律归一化|
|`Inclusion(P,Q)`|所有满足P的对象都满足Q|允许空类；不含存在结论|
|`facts`|已接受的全称包含假设|核验器不调查假设是否真的符合几何或历史|
|`Step`|带规则和先前节点引用的证书一步|引用只能向前已核的节点，不能自证或前向引用|
|`goal`|需匹配的末节点|中间推导正确不能代替目标完成|

设论域为任意集合，赋值将每一原子项解释为其子集；复合项解释为交集。核验器只检查包含关系如何由给定包含关系推出。它不把一句自然语言的语法正确当作该句真实。

## 三、规则及一般可靠性证明（不是测试所得结论）

核验器有五条规则：已给事实、传递、共同主项的合取引入、左右投影。分别是：

$$
P\subseteq Q,\quad Q\subseteq R\quad\Longrightarrow\quad P\subseteq R;
$$

$$
P\subseteq Q,\quad P\subseteq R\quad\Longrightarrow\quad P\subseteq(Q\cap R);
$$

$$
P\cap Q\subseteq P,\qquad P\cap Q\subseteq Q.
$$

**命题：**若所有 `facts` 在某一任意论域的解释中为真，证书被 `check` 接受，则末目标在该解释中为真。

**证明：**按证书节点序号归纳。`given`只能引用与本步结构完全相等的已接受事实，故真。传递步任取属于P的对象，由第一先前节点属于Q，再由第二属于R；相同的中间项是必要的。合取步任取属于共同主项P的对象，它同时属于Q和R，因而属于交集。投影步由交集定义成立。引用严格小于当前序号，所以归纳不形成循环。最终检查最后节点等于目标，故目标成立。此论证适用于任意大小论域，不依赖有限枚举；它是我们对现代核验器规则的教学证明，而非原章给出的证明。

**不声称完备：**核验器没有自动搜索全部证书，也没有处理否定、量词嵌套、存在、模态或任意逻辑等价；它可以拒绝语义上真的目标，只因没有提供它支持的证书。

## 四、有限名词表为何会漏掉复合中项

演示使用四个原子标记：T为三角形，R为平行辅助构造，S为平角排列，A为角和180度。复合项M是同时具有R与S的构造描述。这些只是演示中的符号，不是声称原章给出了这些名称。

明确作为输入的三条桥接假设为：T包含于R、T包含于S，以及M包含于A。第三条不是从一个新名字的出现而自动取得的事实。给定这三条假设，五步证书为：

1. 取第一已给事实。
2. 取第二已给事实。
3. 由共同主项合取，得到T包含于M。
4. 取第三已给事实。
5. 经同一M传递，得到T包含于A。

为公平区分**词表问题**而不是少做推导，比较两种检索时都先加入第3步已经证成的包含关系。词表只含T、R、S、A时，两边均有直接包含边的中项数量为0；加入M后为1。故同一知识库已经有该中项，只是受限索引没有列它。结果见 `named_middle_count=0`、`expanded_middle_count=1`。

一般地，若有限词表V中不存在所需结构M，检索V失败只得到“V中未检出”，不是“全部允许表达式中不存在”。即便V含有一个新名m，也必须提供m与该描述的定义联系及推理根据；单纯改名字不能创造证明。

## 五、几何解释与精确线性证书

第二核验器与包含核验器**彼此独立**。它展示一个欧氏教学重构的代数收尾，并不从第一个核验器的原子字符串推导几何事实，也不是几何构造的自动验证。

在欧氏平面中取非退化三角形；在适当顶点作一条与对边平行的直线。将与两底角相等的辅助角分别记u、v，原三角形角记alpha、beta、gamma。正确的直线、位置与相邻关系给出：

$$
\alpha-u=0,\qquad \beta-v=0,\qquad u+\gamma+v-180=0.
$$

前两式依赖平行线角关系；第三式依赖三个角按正确顺序拼成平角。代码不是从坐标、入射关系或第五公设证明这些几何事实，而是将它们及所需条件登记为显式可信输入。

证书给三式各乘系数1并相加：u与v的系数消去，得到

$$
\alpha+\beta+\gamma-180=0.
$$

代码按固定基底 `alpha,beta,gamma,u,v,constant`核验向量和恰好为 `[1,1,1,0,0,-180]`；计算使用精确有理数 `Fraction`，不使用浮点容差。允许有理系数不意味着角度本身只能是有理数；恒等式适用于任何满足输入等式的实数角。

**线性核的可靠性：**设输入等式的左侧为线性形式L1至Ln，某个赋值使每一Li为0。若核验器精确检查目标线性形式等于它们的有理线性组合，则在该赋值上目标值也是这些0的同一线性组合，因此为0。这里不需要枚举角度，也不依赖一个特定三角形。几何假设的正确性在这一定理的前提中，而非其结论中。

手算例：alpha=50，beta=60，gamma=70，u=50，v=60，三条等式均满足，和为180。反之只取三角为90、90、90而没有满足平行辅助构造的等式时，不能应用此证书；不能先把欧氏桥接等式加入非欧背景再宣称证明了普遍角和。程序的条件标签检查仅能防止**漏声明条件**，无法辨认调用者虚假声明的欧氏条件。

## 六、拒绝案例与实跑结果

12项测试覆盖：有限词表漏检与扩展成功；传递中项不一致；反转给定包含方向；自引用、前向、负引用及布尔值伪装索引；缺失或冒充事实；合取缺共同主项；投影及末目标不匹配；8种单对象真值赋值下的局部规则回归；精确线性等式；漏几何条件；未知等式、浮点系数、错误系数与空证书；演示负例。

`results.json`实际保存四项拒绝：缺欧氏条件、错误线性系数、循环引用、新名字冒充已给事实。默认、`-O`、`-OO`各运行12测试并通过。

对包含反向的手工反模型：P为空、Q含一个对象，则P包含于Q为真，而Q包含于P为假。对错误的合取，令P、R为互不重合的非空集合，分别包含于Q、S；不能由此推得P包含于Q与S的交集。测试只核接口行为，本文构造解释为什么规则的方向和共同主项必要。

## 七、范围与可行扩展

本包没有证明欧氏几何、公理独立性、原章语义唯一正确或所有自然语言“语句中项”可归约为交集。复合项只覆盖一种易验证表达；原文的logos并不因此被定义为本程序的 `And`。

进一步可以加入定义展开的保守性检查、带位置关系的几何小核、或结构表达式的索引。但任何扩展都必须说明新可信假设和可靠性证明；增加搜索次数、改标签或扩大有限样本不能代替这些工作。
