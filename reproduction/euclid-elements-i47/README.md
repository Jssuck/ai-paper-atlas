# I.47：全等三角形、两次倍积与斜边正方形分割

[中文深读](../../papers/ancient/euclid-elements-i47.zh-CN.md) · [来源审查](source-review.zh-CN.md) · [独立技术审查](technical-review.md)

## 原证与现代模型

原文在直角顶点A的三角形ABC三边上作外正方形BDEC、ABFG、ACKH。连接AD、FC，以及对称一侧AE、BK；由I.4得到ABD与FBC等积、ACE与KCB等积，再用I.41的倍积关系把两直角边正方形对应到斜边正方形的两块矩形。M是本教学模型新增的BC上分割点标签，L沿AL在DE上；不能误当M也是原文点名。

本程序以Python Fraction实现有理坐标模型，不模拟实际尺规器具。输入只要求A、B、C为精确整数/有理数坐标，两条腿非零且点积为零。**不输入斜边长度，不要求整数勾股三元组，不以所证平方和恒等式筛选输入。** 正方形使用90度向量旋转构造；现代欧氏坐标度量已经包含相应结构，不能把这个模型称为独立公理化证明。

设u=B−A、v=C−A、s为det(u,v)的符号，J(x,y)=(−y,x)。AB外方形使用−sJu，AC外方形使用sJv，BC外方形使用−sJ(C−B)。M=B+t(C−B)，其中t=((A−B)·(C−B))/((C−B)·(C−B))；这里用点积求交点，不用平方和结论。L=M+(D−B)。模型覆盖镜像、平移、非水平腿和非整数有理坐标。

verify不调用construct或用重建结果比较，而直接验证：三个正方形四边等长四角直及凸顺序、全部外侧、M严格在BC内、L在DE上、分割线平行、I.14所需共线、两对SAS条件和行列式面积。随后检查四个倍积关系、两块矩形不跨越端点及面积相加。SAS用平方边长和夹角点积比较，没有反三角函数数值误差。面积由鞋带公式独立计算。平方和是最终输出中可观察的关系，不是入口假设。

## 实际执行

无需安装依赖，从本目录运行：

```bash
python run_all.py
```

[run-summary.json](run-summary.json)记录每条命令、退出码和日志位置；[environment.json](environment.json)记录解释器版本，不记录主机、私有路径或环境变量。

- 21单元测试，normal、-O、-OO三模式均通过。
- 72合法例：3种平移×4种非零方向×3种正有理腿比例×2种取向。
- 12非法输入在construct入口直接抛ValueError，含零腿、非直角/共线、布尔或浮点坐标、维度错误、字符串和空对象。
- 证书攻击包含每个点的篡改、遗漏/额外标签、F/G和H/K交换、内侧正方形、足点落端点、错误输入三角形、布尔/浮点坐标。几何和类型检查使用显式条件，不依赖可被-O移除的assert。

[结果](results.json)：A=(0,0)、B=(3,0)、C=(0,4)，三个正方形面积分别为9、16、25；左侧全等三角形面积均9/2，右侧均8；BDLM=9、MLEC=16。M=(48/25,36/25)，L=(148/25,111/25)。这些是实际运行输出，不是一般证明。

## 范围与限制

程序没有证明全部实数输入，也没有验证古代作者归属、原文史实或每条公理依赖。它对有限有理输入核对构造及局部面积链，拒绝非直角输入，并不覆盖I.48逆命题或一般斜三角形。现代坐标表示的点积、旋转和面积公式须与正文的综合几何证明分开理解。
