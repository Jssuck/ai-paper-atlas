# V.17 教学复现：从合比到余比

[中文精读](../../papers/ancient/euclid-elements-v17.zh-CN.md) · [源码](ratio_separation.py) · [测试](test_ratio_separation.py) · [Notebook](euclid-v17.ipynb)

这是用正有理数重放欧几里得命题 V.17 的比较步骤，不是古代程序或一般定理的计算证明。输入是四个正整数或精确 Fraction 及两个独立的正整数倍数。每组的两项同类才能相加、求比；两组彼此不限于同类。例如长度组和面积组可以比较各自的无量纲比例，但绝不直接比较长度和面积，也不在组间消去量。每组数值须预先用组内一致的单位，无自动换算。

## 执行的步骤

1. 由两个组内的加法构成整比，用精确分数商核验整比相等。这是现代正有理数模型的预检，不是穷尽第五卷定义 5 的所有探针。
2. 给余比任取探针 `(p,q)`，为整比构造 `(p,p+q)`。对每组 `(a,b)`，依据 V.1 与 V.2，展开被比较的 `p(a+b)` 与 `(p+q)b`，核对它们等于 `pa+pb` 与 `pb+qb`。
3. 检查两个组的整比探针比较同号；只在各组内部消去两侧共享的 `pb`，再比较 `pa` 与 `qb`，核对小于、等于、大于的结果均与该组原比较一致。用余比的精确分数商和阈值 `q/p` 再做独立计算。缩放倍数可以相等，无须强制不同；“独立”意为可任意选择。
4. CLI 的混合类型样例以 2、3 作为长度，以 4、6 作为面积。目标探针 `(1,1)`、`(3,2)`、`(2,1)` 分别触发两组同时小于、等于、大于。等号一例在第一组消去 9、第二组消去 18，动作相同，消去的量不必相等。测试同时覆盖组内类型错误、整比不等、非正量、不合法倍数、错误消去等负例。

## 怎么重跑

在本目录用 Python 3.12.14 及标准库（`dataclasses`、`fractions`、`itertools`、`unittest`、`json`、`pathlib`）；不需要数据下载或第三方库：

```sh
python -V
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B ratio_separation.py
python -B replay_notebook.py
```

普通、`-O`、`-OO` 各通过 9 项测试；详见 [normal](normal.log)、[-O](O.log) 和 [-OO](OO.log)。由 `(x,y,z,w)=(us,vs,ut,vt)` 生成同比样例，`u,v,s,t,p,q` 各遍历 1 至 4，共 4096 个带参数的配置。两组在整比和余比上的符号均与独立的整数比较 `up` 对 `vq` 一致：小于 1792、等于 512、大于 1792。此处计数的是参数配置，重复数值的配置不去重。网格是确定性的有界检查，不提供对所有整数探针、不可公度量或一般古典量理论的证据保证；一般结论依赖正文中的任意倍数证明。

当前环境未安装 Jupyter 命令。依次执行了 Notebook 的三个自有代码单元，以同一 Python 命名空间用标准库重放，不声称使用 Jupyter 内核；输出见 [Notebook 实跑日志](notebook-replay.log)。重放器直接执行 Notebook 中的 Python，只用于本仓的可信代码，不应照用来运行陌生文件。
