# 《后分析篇》I.3：循环是否自己提供起点？

这是原创、低成本、标准库教学实验，不是古代文本的逐句形式翻译，不是认知实验，也不声称完整复现亚里士多德的科学知识理论。正文的历史主张须回到原文证据；这里仅核查明示的现代有限模型。

## 1. 三个不同的问题

1. **规则闭包**：给定已经接受的原子事实和正 Horn 规则，可以有限步推出什么？
2. **解释顺序**：哪些前提比结论更适合解释它？本程序不自动回答。
3. **知识为真**：起点是否真实、已知、直接或第一？本程序没有现实证据接口，不认证这些属性。

把环检测结果直接写成“知识无效”，或把闭包结果写成“已获得科学知识”，都超出了实验。

## 2. 模型与一般论证

原子集合有限；每条规则由非空前提集合和一个结论构成。种子是额外输入，不由系统自己凭空宣称。禁止空前提规则只是为了清晰地区分“规则”和“起点”；另一套编码可以将事实写成空前提规则，但必须承认那已经添加事实。

closure 从种子开始，在每轮用上一轮已到达集合触发规则，直到不再增加。rank 是首次获得的轮数，不是置信度、历史时间或解释优先性。witness 保存一条实际使用的规则。

一般有限论证：每个新增原子最多加入一次，所以至多原子总数次严格扩张后停止。种子属于每个满足种子和规则的赋值；归纳地，每轮新结论也属于每个这样的赋值，因此闭包包含于所有模型的交集。另一方面，停止后的闭包自身包含种子且满足全部规则，因此也是一个模型，交集包含于它。故闭包等于所有模型的交集。这个证明依赖有限原子和正 Horn 规则，不是由下面枚举得到的普遍定理。

在无种子且无空前提规则时，第一轮没有可触发规则；以后仍没有，故空集是闭包。环不能改变这一点。但有外部种子时环可以是无害的冗余关系，并非任何含环知识库都无效。

certificate_ok 检查一个已提供的推导子集是否有严格下降至种子的 rank 见证；它不单独检查闭包完整性，也不要求 rank 恰为最短轮数。完整闭包正确性由 closure 与 truth_oracle 的比较另行检查。循环证书在有限严格下降的排名下不能自我支撑。

## 3. 可手算的例子

- A 推 B，B 推 A，无种子：闭包为空。语义模型恰有“二者皆假”“二者皆真”，所以规则并不单独蕴涵 A 或 B。
- 同样两规则，添加种子 A：得到 A、B，排名为 A:0、B:1。结果来自外部 A，不是来自环的自我奠基。
- A 与 B 共同推出 C，只给 A：不能得到 C。不能把合取前提误做任选一个前提。
- 三集合满足 A 包含于 B、B 包含于 C、C 包含于 A 时三者相等。集合相等允许扩展意义上的相互替换，却不自动给出谁在认识上优先。这里允许空集合，不暗中添加古代项的存在政策。
- 长度 n 的有限链 p(n-1) 推……推 p0：无种子没有结论；把末端设为种子就得到全链。这仅比较两种不同边界条件，绝不能据 n≤32 的试验断言无穷链已被证明不可知。

## 4. 真实运行和精确范围

Python 3 标准库，无第三方依赖。进入本目录执行：

```sh
python -m unittest -v test_model
python -O -m unittest -v test_model
python -OO -m unittest -v test_model
python exhaustive.py
python -O exhaustive.py
python -OO exhaustive.py
```

20 项测试在三种模式下全部通过；测试使用 unittest 的运行时检查，枚举错误使用显式异常，不依赖优化模式会删除的裸 assert。

每种模式独立枚举：

- 三原子全部 512 个有向一元规则图（包含自环）乘 8 种种子，共 4096 例。
- 两原子三个非空前提集合乘两个结论，六条候选规则的全部 64 个子集乘 4 种种子，共 256 例。覆盖真正的合取前提。
- 三元素域的全部 512 个集合三元组，其中 8 个包含环均为三集合相等。
- 长度 1–32 的链，各比较有种子/无种子，共 64 例；较长链不枚举指数数量的真值赋值。
- 4352 个规则/种子例以全赋值模型交集为独立语义 oracle，同时检查生成见证。差异为 0。

## 5. 局限和延伸

这里只处理单调正规则，没有否定、撤销、概率、时间变化或现实因果证据；证明见证不是解释质量证书。无限对象、无限规则和无限证明路径均未实跑。若扩展为带否定规则，需要重建语义，不能沿用正 Horn 的所有模型交集论证。

可自行删去例子中的外部种子，观察可导集合变化；再加入一个独立起点，区分“某条循环支持路径存在”和“所有有效支持都循环”。这可帮助理解依赖结构，但不替代原文对科学知识和直接原则的哲学论证。
