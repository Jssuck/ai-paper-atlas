# 《几何原本》卷 V 命题 3：两阶段倍量

[回到中文精读](../../papers/ancient/euclid-elements-v3.zh-CN.md)。两列分别以自己的基量为单位，第一阶段各取 n 倍做成中间块，第二阶段各取 m 块。程序先分别核验两阶段，再展平成各列基量的 mn 倍。

## 模型及对照

- 使用正有理坐标和量类标签。同一列的基量、中间量、终量必须同类，单位要预先统一。两列可用不同量类，因为从不跨列相加。这是现代模型处理类型的方式，不把传世图的线段说成面积。
- 按卷 V 定义 1–2 的严格量尽语义，每阶段整数倍数至少为 2。倍数 1 的恒等情形是算术扩张，不计入此模型。代码用精确除法读取份数，古证并不用先求数值商。
- 每列从自己的基量构建 n 个副本组成的块，重复 m 块后展平并核对终量。正例的基量坐标为 3/2、5/2；先各取 2 倍，再各取 3 倍，得到 9、15，均为各自基量的 6 倍。
- 反向不成立：基量均为 1 时，一列先 2 后 3、另一列先 3 后 2，都得到 6，却没有共同的阶段计数。若只从末端求商，便会把两阶段错配漏掉。
- 一般同比也不等于整数倍：以 (2,4) 为基量，(4,8) 为中间量，(10,20) 为终量，末端是 5 倍，但外阶段同为 5/2 倍，不能分成整数个中间块。

## 环境与实跑

在本目录运行，仅用 Python 3.12.14 标准库：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python nested_multiples.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

普通、-O、-OO 各通过 10 项测试。网格以三种基量坐标组成九对，每阶段试 2–5 倍，共 144 个合法嵌套，用直接乘法对照展平。另对两阶段计数不同的正例，只交换右列的两阶段计数，保留两列最终量，得到 108 个拒绝例。阶段计数相等时交换无变化，不计入错配。日志只统一 unittest 显示的耗时。

环境没有 Notebook 模板脚本或可用 Jupyter 命令。Notebook 按教程结构生成，三个代码单元实际由标准库顺序编译执行，未运行 Jupyter 内核或前端。有限检验只用于核验实现，不替代原命题的一般证明。
