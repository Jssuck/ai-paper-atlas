# VII.27 原典核对

对读 [Heath 1908 卷 II](https://archive.org/details/thirteenbookseu01heibgoog) 印刷页 328–329（扫描物理页 341–342）、[Fitzpatrick 2008](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=216) 印刷页 216 的希英对栏及脚注、[Clay 希英本](https://www.claymath.org/library/historical/euclid/files/elem.7.27.html)（链接第 141 叶）与 [Joyce](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII27.html)。核对图标和版面，不从线长读出数值。所核 Heath 卷前及命题页、Fitzpatrick 命题页和对读文本未见此命题的单独正式勘误，不声称校遍各印次。

- 希文 Α、Β、Γ、Δ、Ε、Ζ 对应 A、B、C、D、E、F。原证按 C–B、C–E、A–E 的次序展现三次 VII.25；第二、三次均平方 B，但固定项不同。Heath 与 Clay 首次标 VII.25、后两次同引，Fitzpatrick 分三次明标，Joyce 将该引用置于这段之前。其后四条跨组关系齐备，方可应用 VII.26。
- Clay 英栏止在 D、F 与对应乘积的认同，希栏、Heath 与 Fitzpatrick 仍有 D、F 互素的明示收束；Joyce 同样写出结论。这个差别限于所对读的页面，不推定希文本缺句。
- Heath 328 页底至 329 页上记录了 Heiberg 对末端产物夹注的疑问及插入语判断，并报告 Campanus 的不同处理。Fitzpatrick 与 Clay 保留方括号，Joyce 将一般幂放在导读而非题句；Fitzpatrick 脚注的概括并不补写一般情形的证明。因此将平方、立方和教学推广分开标注。
- [VIII.2](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII2.html) 的 C、E 及 F、K 是平方／立方端点，取得互素后再援 VIII.1。[VIII.3](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII3.html) 对应 G、K 和 L、O，再用同一比下的最小链相等识别端点。两处图文演示的长度，不等于证明已经逐一展示任意长度。
