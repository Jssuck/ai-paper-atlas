# VII.27：平方与立方保持互素

现代整数教学重构，不是古代实跑记录或一般定理的计算证明。给定大于 1 的互素整数 A、B。按 VII.25 的原证明顺序，先取 A 的平方 Γ 比较 B，再取 B 的平方 E 比较 Γ，最后用同一个 E 比较 A。三步得到 Γ 与 B、Γ 与 E、A 与 E 互素。连同前提 A 与 B，四项正好是 VII.26 对组 (A,Γ)、(B,E) 所需的交叉条件。结论是平方对和立方对分别互素。

(8,15) 的三个见证依次是 (64,15)、(64,225)、(8,225)，两个立方是 512 与 3375。(6,15) 不满足前提，两个立方还有公度 27。程序的见证用标准库 gcd 核对；测试另外用逐个枚举非单位公因数及独立的二进制最大公度法复核。这里检验有限输入，未把原命题的推广说成计算证明。程序不含单位、零和负数。
