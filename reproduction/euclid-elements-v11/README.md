## 三种检查及其边界

- `probe_chain` 对每组比使用同一对正整数 m,n，分别比较 m·前项 与 n·后项，记录三个符号 −1、0、+1。只有前两符号相等且后两符号相等时，当前探针才能由这两个前提推出首尾符号相等。原证需要把这个推理用于任意探针。若三组各用不同倍数，符号相等不构成同一个前提。例如用 (2,1)、(3,1)、(4,1) 测 (1:2,1:3,1:4) 各得等号，但改成同一个 (2,1) 后得到 (0,−1,−1)。
- `exact_chain` 是另一个功能：只在正有理数模型中以精确交叉乘积判断两个同比前提是否都成立，不靠有界搜索。这些乘积只是以各量类内部共同单位表达后的数值运算，不把不同种类的物理量直接相比。每一组比要求前后项同类；不同组可以异类。用长度 2:3、面积 4:6、质量 6:9 得到符号三元组 (−1,−1,−1)、(0,0,0)、(+1,+1,+1)。
- `bounded_mismatch` 找到违背任一前提的第一个探针就返回；None 只表示窗口未见反例。在 (101:100,102:100,103:100) 中，窗口 20 未找到不一致，扩大到 40 则在 (34,35) 找到 (−1,−1,+1)；精确检查确定两个前提都不成立。某一探针未区分左、中，不意味着别的探针也不能。
- 三种解释器模式各通过 11 项测试。网格取 16 个有序整数比分量组合、4,096 条三比链和每条 9 个探针对，共 36,864 次探针检查；88 条链满足模型的精确前提。测试逐个对照有理商及阈值 n/m，另外检查跨组异类、组内混类拒绝、等号及有界漏判。有限网格检查实现，不证明一般量的定理。
