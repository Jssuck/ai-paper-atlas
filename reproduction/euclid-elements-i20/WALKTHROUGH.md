# 逐步走查

## 1. 把和改写成一段长

原典 I.20（实读 Fitzpatrick 2008 印23–24）把 BA 越过 A 延到 D，并令 AD=AC，连接 CD。现代向量记 u=B−A、v=C−A，t=|v|/|u|>0，D=A−t u。由于三角形非共线，u不为零，构造合法。

D−A=−t u，所以AD=AC；B、A、D共线且A在中间。于是DB=AB+AD=AB+AC。这里加法成立依赖点序，不是任意三点距离都可相加。

## 2. 谁保证射线在角里面

令 CB=u−v、CD=−t u−v，直接代入可得

`CA = [t/(1+t)] CB + [1/(1+t)] CD`。

两系数严格为正，且CB、CD不共线。因此CA严格位于普通角BCD的内部。原典图示中的内部关系在现代坐标里得到显式说明；不是通过看图决定。

## 3. 相等桥梁与严格链

原典的DAC等腰，故∠ADC=∠ACD（I.5）。CA严格在BCD内，使∠BCD>∠ACD。D处DA和DB同射线，所以∠BDC=∠ADC。三者合并为∠BCD>∠BDC。对三角形DCB应用I.19，DB>BC，串接得AB+AC>BC。轮换顶点得另两组。

代码的 `base_angles_equal_modern_check` 和其他角布尔项以点积再次核查这些量值；不会把“I.5”标签当公理引擎。一般推导在上面，有限运行只是核查实现和样例。

## 4. 手算样例

A=(0,0)、B=(3,0)、C=(0,4)。t=4/3，D=(-4,0)。AB=3，AC=4，BC=5，DB=7，所以7>5。CA=(0,-4)，CB=(3,-4)，CD=(-4,-4)，以4/7和3/7的正系数组合得到CA。

取A=(0,0)、B=(1,0)、C=(1,1)，t=√2，D=(-√2,0)。这不是有理点，但仍在一个二次域内，不需要浮点近似。测试还含平移后的有理分数坐标。

## 5. 长度平方不等式核验

平方长度U,V,W非负。因为原来的两个根式表达式都非负，`sqrt(U)+sqrt(V)>sqrt(W)`等价于`U+V−W+2sqrt(UV)>0`。比较后者符号只需一个根号。分别替换三种U,V,W即可核对全部边和。这里不混合不同二次域，避免不合法的代数简化。

## 6. 边界与反例

A=(0,0)、B=(1,0)、C=(3,0)有AB+BC=AC，不严格。代码拒绝该几何输入，独立平方长度比较也返回False。把非共线前提删掉会破坏严格性；这不是原命题的反例。

普通欧氏距离下成立的事实不能自动搬到其他范数：L1范数下(0,0)、(1,0)、(1,1)虽非共线，仍有两段长度和等于第三段。代码只建模欧氏点积，不将其结论推广至所有度量。

证书把True替换为1，或换成另一三角形输入时，验证必须拒绝。对极细三角形，精确有理/根式比较仍无舍入误差；但成功运行并不消除模型选择和原典依赖的审查责任。
