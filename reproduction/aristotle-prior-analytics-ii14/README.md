# II.14：同项的直接证明与归谬互换

这是原创、低成本、标准库教学复现，不是对古代文本的机器翻译或原作者实验复跑。原文为《前分析篇》II.14，62b29–63b21；解释与校勘见[正文](../../papers/ancient/aristotle-prior-analytics-ii14.zh-CN.md)和[来源台账](../../papers/ancient/aristotle-prior-analytics-ii14.sources.zh-CN.md)。

## 范围与记号

U(P,S)表示所有S都是P，E表示无S是P，I表示某S是P，O表示某S不是P。允许项为空，论域不空，采用现代经典集合语义。程序将原章分支教学展开为15条具名路线：内部第一格7、第二格4、第三格4。这不是全部合法三段论或全部证明转换的穷尽枚举。

每条固定记录含目标T、矛盾假设H、保留前提P、已知背景K和内部结果R。分别验证：

1. P与H是否推出R；
2. P与K是否直接推出T；
3. R与K能否同真；
4. P与H是否推出K的精确矛盾命题，即由直接证明反向构造反驳。

第4项是语义检查，不承诺程序自动产生合法单步句法证明。记录的格号是按正文项位人工标注，不是程序发现的唯一格。I/E换位和重新选择保留前提可能给出其他格，测试包含经I换位的III→III路线。因此不可将原章的主要映射理解为不可例外的唯一异格表。

`Route`仅承载审核过的内部常量，不是任意输入证书的安全验证器。`Proposition`和模型入口检查所用语法/域；程序不处理自然语言、不认证背景事实。

## 模型与存在条件

一个对象仅有A/B/C三个布尔成员资格，共8类型。整数1–255的每位标记相应类型是否出现；保留类型0（不属于任何项）保证非空论域可与三个空项共存。每类型一个代表即可检查这组无数目约束的一元命题；这种压缩适用性须由正文一般论证解释，程序输出本身不是一般定理证明。

- empty_allowed：255个非空类型子集；
- all_terms_nonempty：218个A、B、C均非空的子集；
- C_nonempty：240个C非空子集，显示无需把所有项都强制非空。

15个内部推导在三政策均有效。空项政策仅14个直接目标、反向反驳和R/K冲突成立；唯一失败是第一格内部对应的双全称肯定直接Darapti：U(A,C)、U(B,C)并不保证I(A,B)。增加C非空后均为15。最小反例为论域仅类型0、三项皆空；测试另用A、B不空而C空的反例，避免误以为只需A/B存在。

R不一定是K的精确矛盾：双U分支中的E(A,C)与U(A,C)只是反对关系，缺C存在时可同真。不能删除背景K、把两个不同存在见证合为一个，或把I和O当作矛盾。

## 实跑

需要Python 3.10或以上，仅标准库；无需联网或安装包。

```sh
sh run.sh
```

脚本在normal、-O、-OO三模式各执行13个unittest测试，再生成45条路线/政策结果，检查三个结果文件逐字一致。测试使用unittest方法而不是会被优化删除的裸assert。真实版本、时间、退出码及结果哈希见[环境与运行记录](evidence/environment-and-run.json)；[普通日志](evidence/tests-normal.log)、[-O日志](evidence/tests-optimized.log)、[-OO日志](evidence/tests-double_optimized.log)和[详细结果](evidence/results-normal.json)均保留。独立审查另有独立实现，不拿生产代码自测充当独立审查。

结果提供每一蕴涵前提满足模型数、反模型数和按对象数/掩码选出的最小反例；R/K冲突提供同真数。仅记录有效而不记录前提可满足性会掩盖空洞成立，所以两者同时输出。文件哈希见SHA256SUMS，重新运行会更新运行时间与测试时长，相应清单须重新生成。
