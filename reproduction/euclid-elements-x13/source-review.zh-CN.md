# X.13 原典核对

- [Heath 1908 卷 III](https://www.wilbourhall.org/pdfs/Heath_Euclid_III.pdf)印页 36 是完整本题及三线图。反设 B、C 可公度，和 A、B 已可公度合用 X.12，则 A、C 应可公度，和题设矛盾。末尾略写重述。该页紧接的半圆构造引理另有题头和独立论证，延续至印页 37；其评注不属于 X.13 的三量反证。
- [Fitzpatrick 希英对照本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=293)印页 293 本题含图，英栏括注指向 X.12；古希文给同一个推理但无现代编号。该页下方另起的引理续至 294，页脚以平方差、平方和说明其题意；不是本题的校勘或缺步。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.10.13.html)两栏均收 X.13 的略写重述，随后收另题引理；英栏未录引理第二构造的收束句。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookX/propX13.html)展开 X.13 重述并给证毕，导读说是前一题的逻辑变式，后用始见 X.18。以上边界差异不是可公度命题的不同版本结论。
- 原证正边固定为 A 与 B，负边为 A 与 C；推出的负边是 B 与 C。替换正边等价类代表的说法是教学重构，不主张不可公度关系本身传递。证明不以另题的勾股构造为前提。
