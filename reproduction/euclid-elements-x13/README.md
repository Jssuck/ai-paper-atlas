# 《几何原本》X.13：从一组可公度关系传递不可公度

用正有理平方坐标 `a,b,c` 表示长度 `A=√a,B=√b,C=√c`。函数 `ratio(a,b)` 在既约平方比的两项都是整数平方时返回有理长度比，否则返回 `None`。`transfer(a,b,c)` 检验 `A/B` 有理、`A/C` 无理这两个前提，然后独立计算 `B/C`，结果应为 `None`。它不是任意实长度的判定器，也不使用浮点近似。因为三项的平方坐标全是有理数，这些模型输入的平方总可公度；分类针对长度。

例：平方坐标 `(2,8,3)` 给出 `A/B=1/2`，`A/C`、`B/C` 均无有理见证。同乘正有理的平方坐标缩放因子不改变这一结论。反过来不能把两条不可公度关系串联：长度 `1,√2,2` 的两个相邻比均无理，而两端成比 `1/2`。此模型只复现命题本身，不模拟附列的平方差构造。

独立基线用试除消去整数平方因子，比较剩余平方自由部分；它不调用 `isqrt`，也不约分来判定该部分的相等。对 `a,b,c∈1..24` 的 13,824 个有序三元组，1,026 个满足前提，其余 12,798 个被拒，符合基线。这个有限校验不是一般性证明。
