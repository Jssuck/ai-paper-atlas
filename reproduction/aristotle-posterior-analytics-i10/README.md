# 《后分析篇》I.10：定义、存在与前提角色的最小教学复现

这是自有 Python 标准库教学代码，不是亚里士多德完整科学理论的复现，也不认证任何现实知识。对应正文讨论的几个区别，分别建模而不混成一个“科学证明判定器”。

在本目录执行 `bash run.sh`。无第三方依赖、网络、随机数据或密钥。环境见[environment.txt](logs/environment.txt)。脚本以普通、`-O`、`-OO` 三种模式运行相同 `unittest` 和枚举，比较三份结果一致后保存[results.json](results.json)。真实日志：[普通](logs/tests-normal.log)、[-O](logs/tests-O.log)、[-OO](logs/tests-OO.log)。测试使用 `unittest`，不是会被优化移除的裸 `assert`。

文件：[模型](model.py)、[测试](test_model.py)、[运行脚本](run.sh)、[校验和](SHA256SUMS)。只读这些文件即可复查，无需下载古籍扫描件。

## 模型及输入约束

1. **定义不是存在断言。** 取大小1至4的非空有限宇宙，两个位掩码分别表示新谓词P和条件Q的扩展。`definition_holds` 检查两扩展相等，即选定的外延双条件。`has_instance` 单独检查非空。宇宙本身非空仍允许P与Q都为空。这个双条件是现代教学选择，不能把古代本质定义等同外延相等。通用函数允许大小1至8，越界、负掩码、布尔冒充整数等会显式拒绝。
2. **共同规则分类型使用。** `Quantity` 仅有number与magnitude两个标签。number在此用非负整数；magnitude用非负精确有理数代理。`subtract_equals` 要求四个量同类、两整体相等、两移除部分相等且部分不超过整体，返回余量。它不自动把相同数值的不同属混合。返回的零余量是现代约定，不宣称古代数与量都纳零。该代理不涵盖不可通约量，类型相同亦不充分认证本己科学关联。
3. **学生相关的未证采用。** `learner_status` 接收meaning-only definition或proposition、可证明声明、已证明声明和学生accept/neutral/reject。在“可证明而尚未证明”的声明条件下，接受标作相对假设；中立或反对标作相对要求接受。学生态度不改变命题真值。`declared_proved` 只说明输入声称已证，不检查证明；`outside_relative_classification` 不是公理认证。定义输入不能夹带存在断言，因而有证明标记时拒绝。
4. **画线与理想对象分离。** `diagram_gap` 只求精确长度差，如999/1000与1差1/1000。它既不以画线误差推翻理想定理，也不验证具体图的映射、理想化合理性或几何证明。程序并无一般图形识别器。

## 推导与反例

对任一非空宇宙，令P和Q扩展同时为空，所有个体上P与Q同真值，因此双条件成立，但P没有实例。这是一般反例构造；下面枚举只是检查实现与小规模算例。若另给一个满足Q的见证，由双条件得到该见证满足P，才可推出P有实例。

在整数或有理数教学域中，若a=b且c=d，减法对等式两边相同操作，所以a-c=b-d。非负域还需c≤a、d≤b确保操作留在所选域。删除这些前提会被程序拒绝，而非随意输出“证明成功”。同样数值不自动给出跨类型的桥梁。

学生甲接受一条尚未证明但声明可证明的命题，学生乙没有意见；对二人的教学角色标签不同。该变化只改变教学接受状态，不能算作命题真值、可证明性或客观证据的改变。

## 实跑结果

- 21个生产测试在三种模式各通过，输出完全一致。
- 宇宙大小1、2、3、4分别检查4、16、64、256对扩展，总计340对；满足双条件的数量为2、4、8、16，共30，其中每个宇宙大小各有一个空扩展定义，共4个。
- number与magnitude各检查1296个四元组，各21个满足等量与可移除条件；所有接受结果余量相等，与直接算术oracle零差异。
- 分类与999/1000画线差算例记录在results.json。分类仅对上述政策分支验证，不作为古代释义的独立证据。

枚举有限、模型刻意简化；它们不证明一般本质、科学公理必然性或历史心理机制。一般反例与等式论证在上节给出，不能以测试数量代替。
