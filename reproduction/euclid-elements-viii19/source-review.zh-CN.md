# VIII.19 · 原典与版本核对

- [Heath 1908 卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)，印 pp.373–375 / 扫描物理 pp.386–388。p.373 完成平面链，p.374 是对应比及三段立体链，p.375 完成 V.定义 10、结论与 Q.E.D.，然后是小写字母评注；VIII.20 另起。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)，pp.245–246。希文和英译的括号 ἄρα / [thus] 出现在从前两边推相似平面数处，未改变推理。希文第二个立体中项 Ξ，三个英译见证用 O。中间段注 VII.18，两侧共享因子注 VII.17；末段是 Def. 5.10，英译脚注说明 triple 的字面意思，数学义为立方比。
- [Clay](https://www.claymath.org/library/historical/euclid/files/elem.8.19.html) 希文直到结语，英译在 A:N 与相应边相同处停止；[Joyce](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII19.html) 正文保留最后结论和重述，其 Guide 用小写乘积写第二中项 fge，与原构造 dfh 因 DH=GE 等值。将现代讲解与译正文分开；正文个别网页打字问题不影响依赖。
- 核对限上述见证；未识别出适用于证明的正式勘误，不作全部抄本校勘。发布物不含扫描或全文翻译。
