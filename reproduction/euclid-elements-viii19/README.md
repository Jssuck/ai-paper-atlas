# 《几何原本》VIII.19：相似立体数的两个比例中项

这是正整数的现代教学重构，不是古代计算工具的复刻。给定按位置对应的三因子 $(C,D,E)$ 和 $(F,G,H)$。先用整数的交叉乘积核验相似，再构造 $K=CD,M=DF,L=FG$，以及 $A=EK,N=EM,O=HM,B=HL$。后者的第三项记为 $O$（希腊字母 Ξ）。两条链往右的相邻乘率都是 $F/C$；若写原文方向的前项比后项，则相邻比是 $C:F$，端点比是其三重比。

输入 $(2,4,6),(3,6,9)$ 时，辅助链为 $(8,12,18)$，主链为 $(48,72,108,162)$，公比为 $3/2$。倒序仍成立，公比变成 $2/3$。给定因素 $(2,4,6),(2,9,9)$ 不能通过相似条件，尽管端点仍为 $48,162$，而且确有这两个整数中项。这里检验的是**指定的**有序因子，不是搜索是否存在另一组相似因子。含 $1$ 的因子以及比值 $1$ 的齐项作为现代边界单测，不据此解释古代的单位及数的区别。

## 运行

在本目录使用 Python 3.9+，无第三方依赖。测试直接用标准库 `Fraction` 按比率幂生成两条链，对照按原文乘积步骤生成的链。六个因子各取 1 到 6（含），独立用三个约分后分数是否相等判定相似。有限精确枚举并不证明一般定理。

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```
