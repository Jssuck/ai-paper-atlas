# VIII.18：相似平面数之间的等比中项

现代整数教学重构，不是古代实跑或一般定理的计算证明。令两平面数为 A=CD、B=EF，所给的有序因数对相似，即 C:D=E:F。取原证明的 G=DE；由交叉乘积也有 G=CF。增长因子 t=E/C=F/D，于是 G/A=B/G=t，B/A=t²。程序保留 G 的原构造和替代积，并检查精确比。默认不同且非单位的相似因数组；显式现代模式另纳入单位与等组。

(4,6)、(6,9) 给出 (24,36,54)，增长因子为 3/2；倒序给出 (54,36,24)。指定的分解 (2,8)、(4,9) 不相似：端点虽有整数中项 24，但 DE=32、CF=18，原构造不能用在这两组因数上。这不是 VIII.18 的反例；相同端点还可以用另一对相似分解 (4,4)、(6,6) 表示。

独立测试以 Fraction 识别相似性，并用整数平方根从端点乘积另外求中项。
