## 方法和边界

- 地位相同的顶点由两套零起始标签给出；从共同参照 C 到 A、B 的对应分别允许按周界循环移位及反向。先求对应的复合 C→B ∘ (C→A)⁻¹，再用一组边定候选平方尺度，并对所有已标记点对独立计算欧氏距离平方验证，而非只看边长。不是从任意重复或乱序顶点自动恢复对应的算法，也不负责验证输入多边形是否简单。
- 工作例的 C→A 标签为 (1,2,0)，C→B 为 (0,2,1)，A→B 为 (1,0,2)。变换 C→A 为 (10−2y,1+2x)，C→B 为 (−3+x/2,5−y/2)，因此长度比 B/A 是 1/4，平方比是 1/16。在此已知变换的算例中，也直接核对复合坐标式 (−3+(y−1)/4,5+(x−10)/4)。
- 网格为三角形、四边形、五边形，各自遍历两组起始偏移、三组尺度对以及第二组周界方向。共 (3²+4²+5²)×3×2=300 个受控配置，含 150 个第二组周界反向且坐标反射的配置。全部使用整数或有理数对照，不采用浮点容差。
- 反例：不等边三角形虽相似，固定的错误标签会使所有对应距离无法共用一个平方尺度；两矩形各角相等但对应边不统一成比例；正方形和非正方形菱形各边相等，却有不同的角（以两条邻边的点积区分直角与非直角）。有限测试不证明一般命题。
