[中文精读](../../papers/ancient/euclid-elements-vi22.zh-CN.md)讨论古代量比与作图。这里用精确有理坐标及交叉乘积核验例子，不把有限测试当成一般证明。

## 对照与边界

- 第一对取边长 2、3 的正方形，第二对取直角腿 4、6 的等腰直角三角形。面积由鞋带公式算出 4、9、8、18；两对图形之间不必为同一形状。正向检查第三比例线 9/2 和 9，以各比的交叉乘积检验。反向现代模型按前三条长度作第四底 6，用构造图形的实算面积检验；改取 5 或 7 则失败。
- 270 个受控配置：第一、第二对各有 3 种形状（正方形、等腰直角三角形、3–4–5 比例直角三角形），3 组首项、5 个尺度、2 种反射选择。使用旋转和平移变换；底边平方由实际坐标和标记边求出，面积由行列式求出，比例比较用精确交叉乘积。模型只处理正有理长度，不探索古代任意不可通约量，也不是任意多边形的相似性求解器。
- 在第二对的 3–4–5 型三角形中把较大三角形的斜边 10 错当作与直角腿 4 对应的边，实算的面积比例没有改变，错取的底却不成比例。对内相似不可省：正方形与窄矩形可有按比例的底却无所需面积比例；面积为 12、27 的斜平行四边形与矩形对，能配合 4、9 的正方形对给出相等的面积比例，但它们的底比 4:9 并非第一对的 2:3。
