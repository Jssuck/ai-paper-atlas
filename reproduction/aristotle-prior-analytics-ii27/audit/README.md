# II.27：独立逐对象核验

本目录是独立审查者编写的第二实现，不导入 `../signs.py`。生产实现使用整数位掩码；这里枚举布尔向量，并逐对象用全称/存在量词计算七条路线。

运行：

```sh
cd reproduction/aristotle-prior-analytics-ii27
sh audit/run.sh
```

实际运行 normal、`-O`、`-OO` 三模式：每模式独立枚举大小0–4的4681个带标号模型，重算32767条路线。与对应生产JSON比对七条路线的28个聚合/首反例字段（反例对象字段也整体精确比对），以及多数模型和两特征—两性质识别模型的全部指定字段。三份独立输出逐字一致。

**比较粒度：** 生产JSON未提供逐世界布尔证书，因此这里是独立逐世界重算后的完整聚合与首反例比对，不声称逐项比对生产实现的32767条中间输出。它不能排除恰好保持所有聚合字段的抵消错误；另以代码审查、显式反例和单元测试降低这一风险。

每模式另跑5项独立单元测试，其中一项检验正确日志并故意修改反模型计数、首反例、候选映射、观测行及多数结论，共5个损坏结果，确认全部被拒。优化模式保留显式异常与 `unittest` 判定，不依赖可删除的 `assert`。

`oracle-*.json`、`tests-*.log` 和 `comparison.log` 是本次真实运行保存的证据。有限枚举不是一般定理证明；空论域是边界压力测试，不声称古代作者允许空世界。该实现只检验指定形式重构及合成数据，不检验任何身体特征与人格关系的经验真实性。
