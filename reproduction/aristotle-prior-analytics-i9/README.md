# I.9：必然性加在哪一个前提上？

这是现代、有限、可检查的教学重构，不是亚里士多德完整模态逻辑的实现，也不宣称给出唯一历史解释。原典与一般证明见[中文深读](../../papers/ancient/aristotle-prior-analytics-i9.zh-CN.md)。

## 模型与语义

`Model(n, worlds)` 使用固定的非空对象域和至少一个世界。世界0是实际世界；每个世界是三个集合位掩码，顺序固定为 `(P, M, S)`。位0表示对象0、位1表示对象1。允许某个词项在实际世界或其他世界为空；这不等于对象域为空。

- T：在实际世界评价通常的A（所有S是P）、E（没有S是P）、I（某些S是P）、O（某些S不是P）。
- N：先固定实际的S对象，再看这些对象在全部世界中的P性质。A/E要求每个实际S永久是/不是P；I/O要求某一个实际S永久是/不是P。
- D：在每个世界分别评价整个AEIO命题；主体集合随世界变化，特称见证也可变化。

N不是简单地给完整T命题外面加一个方框。特别是N的特称命题需要同一个实际对象，而D的特称命题不要求同一个对象。另一方面，N不要求该对象在别的世界仍属于S，所以两者一般不可互推。代码同时保留二者，以防把语义选择伪装成已经证明的历史事实。

`evaluate(m, mode, q, subject, predicate)` 的项参数是索引，**主项在前，谓项在后**。第一格大前提为M→P（1,0），小前提为S→M（2,1），结论为S→P（2,0）。

## 范围与风险

零反例只说明此有限域搜索未发现反例；任意域的一般有效性须由正文的逐对象证明支持。一个正确反模型足以反驳该明确语义下的普遍有效式，却不能直接推翻不同语义下的历史论证。

代码没有实现模态换位、混合式第二/三格、可能命题、变域、可达关系或本质论。实际主体锚定的N_E并不一般对称，因此不能把本模型的结果无条件搬到I.3或后续章节。报告中的故障注入只是列出的故障被检出，不意味着没有软件缺陷。
