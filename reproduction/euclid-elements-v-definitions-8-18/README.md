# 《几何原本》卷 V 定义 8–18：精确比式和连接

[回到精读正文](../../papers/ancient/euclid-elements-v-definitions-8-18.zh-CN.md)。本模型用标准库 Fraction 检查正有理量。商是现代、已约定单位后的算术表示，不是卷 V 原始定义，也不覆盖不可公度的量或证明卷 V 的各项命题。

## 输入和语义

- 定义 8–10：以共享中项表示三项连续比例；逐对检查相邻比相等，再读取首末比。支持三、四项以示二重比与三重比。比如基比 3/2 得 9/4、27/8，而 3/2 的普通双倍为 3。
- 定义 11–12：对应两前项和两后项；交替比 (a:c, b:d) 需要跨组配成的每个新比自身都同种。允许长度比和面积比同比，不表示可把长度对面积形成交替比。程序只提取两个新比，不把原比不等的输入假装变成同比。
- 定义 13–16：输入 3:2，倒比 2:3，并比 5:2，分比 1:2，反成比 3:1。分比和反成比都要求前项严格大于后项，在零差和负差时拒绝。
- 定义 17–18：按链的中项连接位置找局部同比。对齐示例为 (12,6,2) 对 (18,9,3)，两链依次基比 2、3；换序示例为 (12,6,2) 对 (18,6,3)，右链依次基比 3、2。两种端点比都相等（6），但在这两例把配对方式对调会因不满足前提被拒绝。右链按 V.23 端点次序 D,E,F 记号，即 A:B 对 E:F、B:C 对 D:E；Fitzpatrick 在定义 18 的 p.131 脚注改用右链 F,D,E 的字母排列。若两个局部比恰相同，两种配对都可能成立，不能强称互斥。网格允许两链各自同种、两链之间异种，这是现代数值商模型的性质；不据此声称 V.23 原证跨种类可用：其换序论证借助 V.16 的交替比，需要跨链组成的比合法。

## 环境与证据

在本目录运行：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python ratio_ops.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

仅需 Python 3.12.14 标准库。普通、-O 和 -OO 各通过 11 项测试。网格包括 4×4 对局部比和 2×2 组尺度；每组验证两种连接，共 128 个有效连接，并有 56 个局部比不同的错配拒绝。端点检查另用交叉乘积对照。还检验错种、差量边界、长度不匹配和连续比例被中断。有限样本检验实现，不代替一般证明。

环境无可执行的 Jupyter 命令和模板脚本；Notebook 按教程结构生成，实际用标准库逐个编译执行三个代码单元，不宣称已运行 Jupyter 内核或前端。日志仅将 unittest 计时归一化为 `<elapsed>`。
