# 从相反射线到对顶角：逐步走查

## 1. 先验条件不是结论

取E=(0,0)，A=(1,0)，B=(−1,0)，C=(0,1)，D=(0,−1)。`opposite_scale`先证B−E=−k(A−E)、D−E=−l(C−E)，其中k=l=1；非零行列式排除两条重合线。这些条件对应两条相交直线形成四个普通角。点的命名本身不保证E位于两端之间。

在非直角例取A=(2,1)、B=(−4,−2)、C=(1,3)、D=(−3,−9)。反向比例是2与3。CEA的点积为5、行列式绝对值为5，角描述为(1/2,1/2)。DEB两向量同时反向并缩放，点积与绝对行列式同乘6，描述仍为(1/2,1/2)。AED及BEC同为(−1/2,1/2)，保留钝角与锐角之分。这里没有说角度值等于1/2直角；描述的两个分量不是角度。

## 2. 一般恒等式与运行证据分开

令b=−ku、d=−lv，k,l正，则d·b=kl(v·u)，|det(d,b)|=kl|det(v,u)|。共同正因子在归一化时消去，所以两组对顶角描述相同。另一对同理。它是现代向量推导，不是原文使用向量。

代码对135个配置真实验证以上结构，覆盖平移、有理坐标、方向变化及不同k,l。这不证明所有输入，更不代替正文中一般推导。

## 3. 原证的同减结构单独运行

输入x=2/3、y=4/3、z=2/3，以一直角为单位。两次I.13对应x+y=2及y+z=2；同减公共y得到x=z。四个相邻角按x,y,x,y排列，总和4。这是带既定前提的代数账本，不是对上述坐标计算角度。

若仅知道x+y=2而没有第二个等式，不能推出x=z。`angle_ledger('2/3','4/3','1/2')`拒绝缺失前提。若允许0或2退化角，几何构型不再满足这里的交叉射线条件，函数也拒绝。

## 4. 失败例有不同意义

- 把B移到A同一侧：反向关系失败，不能称对顶。
- 把C也放在AB支撑线上：行列式为零，四角构型退化。
- 只改输入的比例而复用旧证书：角量可能仍相同，但证书不能冒充当前输入，验证失败。
- 把证书schema_version的1改True，或把结果True改1：一般Python相等可能放行，本实现严格JSON比较拒绝。
- 更改角描述、删字段、加字段、塞入NaN：证书不匹配或不是允许的数据树，拒绝。

这些拒绝是本实现的契约测试，不证明一般攻击安全性。正例通过只说明所列输入及检查路径；没有运行的配置不计覆盖。

## 5. 自己复盘

1. 为什么两端必须是负比例而不是任意共线？答：正比例只给同一射线，不形成对顶关系。
2. 为什么分母不会为零？答：非零二维向量同时dot=0与det=0不可能；几何输入还有det非零。
3. 为什么不只比较dot平方？答：它丢失锐/钝的符号；本描述保留dot的正负。
4. 为什么证书存规范化坐标？答：绑定数学输入且便于精确比较，不保存无关文本拼写。
5. 为什么三种优化模式都跑？答：检查正确性关卡不依赖被-O删除的裸assert；不是证明Python解释器绝无错误。
6. 运行Notebook是否就是Jupyter kernel复现？答：不是，本次只有标准库顺序compile/exec及真实输出。
