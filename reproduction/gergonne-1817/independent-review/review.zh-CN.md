## 2. 复核如何避免循环论证

1. 逐行阅读核心实现，特别检查严格包含、X 的三个非空区域、固定关系坐标 (M,G)/(P,M)/(P,G)、旋转符号及作者 figure 编号。源码中的 §59 分类器没有调用语义判定器；四个反证证书也没有调用“该式有效”的枚举结论来验证自身。
2. 独立程序以布尔成员三元组和组合生成占用模式，而非调用实现的 mask 枚举器。另以区域存在性重新计算关系和命题真值。
3. 另写一个见证约束判定器：全称命题禁止某些对象成员类型，特称命题要求至少一个允许的类型作见证；非空语义再增加三条存在义务。对“前提加结论的否定”作可满足性检查。这个判定器不调用实现的模型生成、命题求值或有效性函数，不穷举 109 个占用模型；它在两种语义下逐一核对全部 512 个候选，并独立求得最小见证数。
4. 再枚举四对象论域的 4096 个具体类三元组，其中 3375 个三类均非空，以另一条真值计算路径交叉检查。这个小论域实验只是交叉检查，不被冒充为任意论域的完备性证明。
5. 从原版页面检查源表和关键方向。第 213、219 页的预期集合直接写入独立脚本，而非读取程序生成结果充作标准答案。第 216 页同时保存原版和校正版预期。

`PROOF.md` 的七原子压缩证明有效：该语言只能分辨相关区域的空/非空；每个非空区域取一个代表保留所有命题真值。外部 000 区域不影响本语言。空类实验中，全部内部区域为空仍可加一个外部对象，因而不依赖允许空论域的约定。

## 3. 审查发现与修正

### 3.1 原版第 216 页的 CH/DH 差异

[原文扫描](https://www.numdam.org/item/AMPA_1816-1817__7__189_0.pdf)印刷第 216 页 §55，N 行为 HI、HC、IH、CH。已从原 PDF 放大核对字形；同表 n 行的反向 C 可作比较。


这一 CH 不能保证 N(P,G)。反例：M={m}，P={p}，G={m,p}。M 严格包含于 G，P 与 M 不交，因此前两关系为 CH；但 P 属于 G，N(P,G) 为假。程序的 Model(48) 是同一反例的原子编号表示，关系三元组为 CHC。

第 217 页 §56 将这组关系重新排列时，右下角明确印成“反向 C H”。这既有同文后续段落作证，也与第 213 页兼容表及第 214 页 §52 的例子相符。


本篇相关的[同卷正式勘误第 386 页](https://www.numdam.org/item/AMPA_1816-1817__7__386_0.pdf)列出第 213、221、222 页三项，没有列第 216 页这一项。因此本包把 CH→DH 标作有充分内部证据的建议校正，不假称它属于作者正式发布的勘误。核心算法无须改变；需要修正的是“源表原样无误”或“DH 为直接原版转录”的说法。

### 3.2 §§51–52 的原例方向

初稿将原文 N(M,P) 简单换位为 N(P,M)，有效性虽不变，却不再是原展示句的逐字方向。最终版本已恢复：

- §51：A(G,M)、N(M,P)，作者 figure II。
- §52：A(M,G)、N(M,P)，作者 figure IV。

独立测试检查具体有序命题，避免仅比较真假结果而漏掉转录差异。第 213 页 IG→IH 则按正式勘误处理，与上面的第 216 页校正区别记录。

## 4. 可复跑方法与限制

从复现包根目录执行：

```sh
python run_checks.py
python independent-review/run_review.py
```

后一命令重新执行主套件、独立套件和导览，覆盖本目录的复核日志与环境记录。只运行独立逻辑检查可用：

```sh
python independent-review/audit_checks.py
```

检查仅使用 Python 标准库，无安装和联网步骤。原版字形通过已有 PDF 的局部放大核对；发布包提供原文链接与页码，不包含扫描图片。

本次实测环境是 CPython 3.12.14/Linux。Python 3.10+ 的兼容性符合所用语法和标准库接口，但没有在每个版本、操作系统上实际重跑。不声称这些测试验证了作者全部哲学主张、历史优先权、对后世 AI 的直接影响或实际存在论。非空类语义、七原子证明、约束判定器和自动反例都是明确标记的现代重建。
