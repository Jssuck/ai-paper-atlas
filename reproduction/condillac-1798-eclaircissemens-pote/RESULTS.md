# 实际运行与结果

在当前环境执行了以下命令，退出码均为 0：

```sh
python test_model.py > logs/test-normal.txt
python -O test_model.py > logs/test-O.txt
python -OO test_model.py > logs/test-OO.txt
python demo.py > logs/demo.txt
```

环境实录见 `logs/environment.txt`。无外部数据、依赖、随机数或网络请求。

三种测试模式的结果相同：

- 2,904 个轨迹—映射组合：三个状态、长度 1–5 的所有非空轨迹，共 363 条；乘以 8 个二值观测映射。检查压缩、变化数上界、相等的充要条件和潜在停顿不变性。
- 256 个有限纤维例子：四位置的 16 个二值观测词 × 16 个二值目标词，检查判据与解码器重建。
- 54 个事件表：内部候选坐标为 1/4、1/2、3/4，各子集可取；每段赋二值标签，包含相邻重复。穷举 2,916 个有序表对，检查切点并集、完整覆盖、中点标签和投影压缩保持。
- 3 个固定反例回归：同长度隐藏变化、联合观测区分、边际日志无法确定联合顺序。
- 20 个无效输入测试：覆盖词类型/空值/标签、映射类型/缺失/非法项、纤维长度、同步外层/空表、非零起点、整数/浮点坐标、重复/越界坐标和坏事件结构。

这些数值是模型输入组合数，并非历史样本数或心理实验数量。没有将每一个内部布尔比较叠加为虚高“测试数”。

## 反例的实际输出

- 单个 a 与 a,b,a,b 的潜在变化数为 0、3；压缩观测同为 still。
- 联合映射 a↦(0,0)、b↦(0,1)、c↦(1,0) 可区分三个状态，两个边际各自不能。
- 两种共同轴输入的中间联合标签分别为 (1,0)、(0,1)，两个边际压缩词均为 (0,1)。

## 结论边界

有限测试未覆盖任意长度或任意数值，不能独自证明一般命题；一般证明见 MODEL。模型的非识别性依赖信息丢失条件。同步的成功依赖输入已具有共同坐标。结果不量化主观持续，不证明历史文本为经验定律，也不证明或否定宗教、形而上学或绝对时间主张。
