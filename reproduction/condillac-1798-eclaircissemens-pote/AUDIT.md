# 独立代码与数学审计

## 结论

本次审计未发现实现与所列数学命题不一致的缺陷。`model.py` 无需算法修复。所有验证均在本目录实际执行，正常、`-O`、`-OO` 三种模式均以退出码 0 完成，各模式对应输出逐字节一致；命令、解释器、退出码记录于 `logs/audit-run.txt`。这不是对无限输入空间、历史解释或心理机制的实验验证。

## 数学逐项核对

- 观测词保留每个位置；压缩只删除相邻重复，不删除 a,b,a 中第二次出现的 a。两种信息损失分开处理。
- 观测变化位置是潜在变化位置的子集。更精确地，潜在变化数减观测变化数，等于被映射合并的实际相邻变化数。因此上界与逐次可见的充要条件成立，无需全域单射。
- 压缩潜在停顿再观测、压缩，不改变最终观测词。隐藏变化反例可取同长度轨迹，故并不只依赖长度不同。
- 纤维判据在提供的有限定义域上成立，成功解码器只在观测像上定义；未声称能推广到新输入。空域在数学上可处理，但 API 明确限制非空，不应误读为一般数学障碍。
- 共同细分只处理已经给定的共享有理坐标。实现将事件时刻及终点 1 合并，按观察者输入次序返回标签；事件在左端点立即生效，终点 1 不属于定义区间。
- 联合观测可比单一边际更可辨识，但分开压缩后的日志不提供逐位置对齐。演示代码与这项限制相符。

## 独立参考程序与覆盖范围

`audit_model.py` 没有调用原测试的辅助函数，没有把生产函数结果当作另一生产函数的正确答案。它检查：

1. 1,134 个轨迹—映射组合：二状态、长度 1–6，三个观测标签的全部映射。参考压缩用标准库 `groupby`；独立逐边计数检验隐藏变化的精确差额、压缩次序和停顿不变性，并检查映射不被修改。
2. 1,554 个有限纤维实例：域大小 1–4，三值观测和二值目标。直接枚举观测像上所有可能解码器，比较存在性和唯一的像上解码器，避免复写生产代码的字典一致性算法。
3. 18 张事件表的全部 5,832 个有序三观察者组合：内部候选坐标为 1/3、3/5，允许冗余同标签事件。参考语义通过原始事件区间的成员关系寻找标签，同时在每段左端点和中点验证；另检查精确分割、观察者次序、投影压缩保持。
4. 50 个非法输入案例：精确异常类型必须匹配。覆盖 tuple/str/dict/Fraction 子类、生成器、只读映射、空词/空表/空外层、缺失及非法额外映射项、bool、NaN、无穷浮点、整数坐标、端点 1、负坐标、非零起点、重复与逆序事件、坏事件结构等。另验证合法额外映射键与单表单事件。

上述数字按完整输入实例计算，不将内部布尔检查堆叠成虚高测试量；不同套件不合并宣称为互不重复的总量。严格类型拒绝是接口设计，不是数学要求。所有检查使用显式异常而非 `assert`，优化开关不会使检查消失。
