# I.34：状态、承载者与可能性——最小教学复现

本目录是原创的**现代教学重构**，不是古代程序的复现，不是亚里士多德模态三段论的完整形式化，也不是医学模型。研究对象是[《前分析篇》I.34](../../papers/ancient/aristotle-prior-analytics-i34.zh-CN.md)中不能在不检查词项含义的情况下套用形式的警告。原文与版本见[来源记录](../../papers/ancient/aristotle-prior-analytics-i34.sources.zh-CN.md)。

## 模型的明确约定

- `Person` 是状态承载者；`Condition` 是状态名称，预设为 `HEALTH`、`DISEASE`。`holds(condition, person, world)` 只接受这两类不同位置的参数。拿 `DISEASE` 当第二个参数将抛出 `TypeError`，而不是把“健康属于疾病”强行当成普通人的谓词关系。
- 固定有限人物域 $`D`$，固定非空备选情景集合 $`W`$。所有情景都是**一个固定评价点**的备选；没有定义世界之间的可达关系，没有嵌套模态，也没有声称古代文本使用 S5。
- 每个人在每情景只能取三种状态之一：`0` 两者皆非；`1` 健康；`2` 患病。互斥是本模型为阐释“相反状态”设的约定，并非真实医疗状态的充分分类。
- `from_cells(n, cells)` 按情景优先编码：前 $`n`$ 格为 `w0`，后 $`n`$ 格为 `w1`。例如 `(1,2,2,1)` 表示两个承载者在两情景交换状态。
- 情景可用来思考备选情况；代码没有时间演化、转移概率或病程预测。不要把情景变化自动解释为原文所说的必然康复。

| API | 数学含义 |
|---|---|
| `possible(P,x)` | $`\exists w\in W\;P(x,w)`$ |
| `all_possibly(P)` | $`\forall x\in D\;\exists w\in W\;P(x,w)`$ |
| `possibly_all(P)` | $`\exists w\in W\;\forall x\in D\;P(x,w)`$ |
| `possibly_none(P)` | $`\exists w\in W\;\forall x\in D\;\neg P(x,w)`$ |
| `necessarily_none(P)` | $`\forall w\in W\;\forall x\in D\;\neg P(x,w)`$ |
| `joint_possible(P,Q,x)` | $`\exists w\in W\;(P(x,w)\land Q(x,w))`$ |

这些函数针对模型已声明的两个状态及域内人物使用。各谓词 API 入口先验证所有状态和涉及的人物，即便空域或布尔短路也不跳过；`holds` 另检查情景；构造器检查域、完整赋值和互斥性。空人物域允许，空情景集合禁止；空域只是揭示全称命题的现代真值约定，不据此断言古代词项均允许空外延。

## 手算与实跑如何对应

一人模型 `[1,2]`：人物在 `w0` 健康，`w1` 患病。因而分别可能健康、患病，都是真；同一情景同时两者是假；“可能患病”没有使 `w0` 的实际患病变真。`possibly_no_health=true` 与 `necessarily_no_health=false` 并不矛盾：一个是存在见证，另一个要求所有情景。

两人模型 `[1,2,2,1]`：每人都有患病情景，但没有所有人一起患病的情景；也没有所有人均不健康的情景。因此 $`\forall x\Diamond P(x)`$ 不能仅凭量词外形变成 $`\Diamond\forall xP(x)`$。这一额外反例用于限制现代重构，**不声称原文 I.34 明确提出了该量词交换问题**；尤其不能拿这个反例声称驳倒亚里士多德的整套模态规则。

`survey` 枚举两情景、$`n=0,1,2`$ 人的全部三态赋值，恰有 $`3^{2n}`$ 个。`all_possibly_diseased` 是每人至少在一个情景患病的模型数；`counterexamples_to_necessarily_no_health` 是该前提真但“任何情景都没有人健康”假的模型数。

| 人数 | 模型总数 | 每人可能患病 | 其中反驳必不健康 | 全称/可能性交换缺口 |
|---|---:|---:|---:|---:|
| 0 | 1 | 1 | 0 | 0 |
| 1 | 9 | 5 | 2 | 0 |
| 2 | 81 | 25 | 16 | 8 |

可独立手算：单人的两格中至少一个 `2` 共 $`9-4=5`$ 种；其中同时出现 `1` 和 `2` 有 2 种。因此两人满足前提共 $`5^2=25`$，其中没人能健康为 $`3^2=9`$，反例共 $`25-9=16`$。两人各有患病见证却没有共同患病情景：他们的患病情景集合必须分别是单例 `{w0}` 和 `{w1}`，有2种分配，每个人另一格各有2种选择，共 $`2\cdot2^2=8`$。

`celarent_survey` 另枚举 $`n=0,1,2,3`$ 的全部 $`A,B,C`$ 子集组合，共1、8、64、512组，前提真分别1、4、16、64组，失败均0。

**这些零失败不是一般定理的证明。**

一般证明另行给出：若 $`A\cap B=\varnothing`$ 且 $`C\subseteq B`$，任取 $`x\in A\cap C`$，即有 $`x\in A\cap B`$，矛盾，所以 $`A\cap C=\varnothing`$。本章不能被误读成普通 Celarent 失效。

## 可复跑命令

标准库，无第三方依赖，不需下载或密钥。在本目录执行：

```sh
python3 model.py > results.json
python3 -m unittest -v test_model > test-default.log 2>&1
python3 -O -m unittest -v test_model > test-O.log 2>&1
python3 -OO -m unittest -v test_model > test-OO.log 2>&1
```

[环境](environment.txt)、[结构化结果](results.json)、[普通测试](test-default.log)、[`-O`](test-O.log)、[`-OO`](test-OO.log) 是2026-10-22实跑保存的输出。每种模式10项测试通过；运行耗时可能不同。判断使用 `unittest`，不依赖会被优化移除的裸 `assert`。测试覆盖分离可能/共同可能、量词范围、全病模型、空域、类型拒绝与输入验证、空域与短路漏检回归、有限全枚举。

## 限制

代码只建立一个透明的教学语义，不验证健康/疾病作为抽象状态的全部古代本体论；没有完整实现三格模态组合、必然性与双侧偶然性的古义区分；模型的 `possible` 只表示至少一个列出情景，不能与原文所有“可能/偶然”逐字等同。状态名与承载者的程序类型区分是防错示范，不是对原文的一次无损编译。实验不能替代原文释读或一般数学证明。
