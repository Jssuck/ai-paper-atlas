# 独立坐标核验

从复现主目录运行：

```sh
python3 independent-review/check.py
```

检查器不调用生产实现的 `dot`、`cross`、`sub`，不以证书 `checks` 字段作为几何真值。它独立实现有理数对 `(a,b)` 表示 `a+b√d` 的加减乘法，从 F/G 的证书坐标重算三组平方距离，要求根式系数为零，并与输入源点的平方距离比较。再重算有向面积、确认目标正射线及正根。

实际遍历源臂两个坐标分量均在 -2 到 2 的非零、不共线向量组合，取 3 个不同目标位置/方向及两个侧向，共 2976 组。另拒绝 21 份字段篡改证书和 2 次外部输入重绑定。结果与命令退出码分别见 `result.json` 和 `run.log`。

这与生产 `verify` 的重算比较不同，但仍是有限范围的独立程序检查，不是一般定理证明、第三方安全审计或证明助理认证。两者都使用 Python 标准库有理数；系统环境及解释器缺陷不在本次认证范围内。公开脚本为本单元原创，未包含原文 PDF 或全文翻译。
