# 一次复制角的证书解剖

## 1. 源点到目标点

取 C=(0,0)、D=(2,0)、E=(1,2)，目标 A=(3,-1)、B=(4,0)。有 U=4、V=5、W=2、T=2、X=det(CE,CD)=-4。side=1 时 d=5/2、p=2/5、q=4/5，w=(1,1)、Jw=(-1,1)。于是 G=A+√(5/2)(1,1)，F=A+√(5/2)(-2/5,6/5)。

AG²=(5/2)×2=5；AF²=(5/2)×(4/25+36/25)=4；FG²=(5/2)×(49/25+1/25)=5。AF·AG=2，det(AG,AF)=4。因此三边分别对应 CD、CE、DE，可以在原证的框架下调用 I.8，得到 FAG=DCE。这里坐标公式只是现代求出满足条件的三角形，不是把旋转或三角函数当作欧几里得证明。

## 2. 一般恒等式（教学推导）

二维行列式恒等式给出 UV=T²+X²。由于 V、W 正且 X 非零，d=V/W>0，q 非零；p²+q²=(T²+X²)/V²=U/V。w 与 Jw 垂直且平方长度均为 W。

故 AG²=dW=V；AF²=dW(p²+q²)=U；AF·AG=dWp=T。于是 FG²=AF²+AG²−2AF·AG=U+V−2T=|u−v|²。叉积为 dWq=side×|X|，所以选择哪一侧不是数值舍入的偶然结果。输出严格非退化且 G 落在正向 AB 上。

## 3. 镜像与错误输入

side=-1 时仅 q 变号，三边及点积不变，叉积变成 -4。在本例源 cross(CE,CD)=-4，因此右侧分支保持该有向约定，左侧分支反向；二者复制的普通内角均正确。若需求指定目标侧，就不能任意返回另一分支。

D=C 或 E=C 时射线截点消失；D、C、E 共线时角退化；A=B 时目标方向未定义。这些均明确报错而不发布“成功”证书。坐标中的浮点数和布尔值被拒绝，以免伪精确或类型混淆。

## 4. 什么被验证，什么没有

运行日志证明这份代码在记录环境下执行了列出的测试。校验器重新计算规范 JSON，拒绝改过的输入、side、根式、长度和布尔/整数混淆。它与构造器共享算法，故并非独立形式证明器；测试也不是一般定理的证明。一般等式来自第 2 节推导及独立技术审查，而古代直尺圆规构造及 I.22 所需存在性则必须回到原典解释。
