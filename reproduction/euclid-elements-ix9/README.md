# 《几何原本》IX.9：第一非单位项的幂性质向后传播

教学重构以单位为隐含的第零指数项，输入整数乘率 $q\ge2$，返回第一非单位项 $q$ 起的指定长度。平方支先给出 $q,q^2$，后面隔两项乘 $q^2$；立方支用 $q,q^2,q^3$ 起步，后面隔三项乘 $q^3$。各支同时生成并核对相应整数根。测试包含链比正确而起始项不是所需幂的情况；若丢掉从单位出发的条件，则例如 $(4,8,16)$ 不保平方，$(8,16,32)$ 不保立方。单位本身按现代定义是平方和立方，但不接受它作为这里的非单位底数。

在本目录使用 Python 3.9+ 标准库运行：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线先用正整数幂表判定底数是否符合前提，再直接以幂算整条链与根链；测试覆盖 $q=2,\ldots,512$、长度 1 至 10、两种次数。有限算例不替代一般证明。Notebook 日志记录标准库实际回放三个代码单元，不是 Jupyter 内核实跑。
