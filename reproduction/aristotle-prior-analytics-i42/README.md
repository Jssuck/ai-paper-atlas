# I.42：从结论类型筛选格，逐步识别证明

本目录是[中文深读](../../papers/ancient/aristotle-prior-analytics-i42.zh-CN.md)的原创教学代码。古文没有这套程序、集合穷举算法或输入格式；本程序不认证历史唯一语义，不解析自然语言，也不是完整证明助手。

## 语义、参数与计数口径

论域非空，S、M、P为一元谓词的外延。命题按“主项、谓项”记录：

- A(S,P)：S包含于P。
- E(S,P)：S与P不交。
- I(S,P)：S与P相交非空。
- O(S,P)：S中存在不属于P的对象。

三格位置固定为：第一格大前提(M,P)、小前提(S,M)；第二格(P,M)、(S,M)；第三格(M,P)、(M,S)。结论始终(S,P)。式名的三个字母依次是大前提、小前提、结论的类型。只覆盖这三种位置，未实现第四格、模态或关系推理。

存在政策是显式参数，不写进A的默认定义：

- `nonempty_terms=False`：允许S、M、P为空，但论域不空。
- `nonempty_terms=True`：额外要求S、M、P全都非空。它不是每种有效式所需的最弱存在条件。

每格有4×4×4=64个类型组合，三格共192个。统计包括有效全称式的特称弱化式，不能直接冒充某种传统“基本式”数量。返回有效，含义是在声明的集合语义和存在政策下没有反模型，不代表前提在现实中为真。

## 为什么检查七种非零类型

这是独立于程序的现代数学论证：任一对象对于S、M、P各有真/假两种成员身份，因此最多八种成员类型。A、E、I、O的真值仅依赖相关类型是否有人占据，不依赖每种类型有多少对象。

对任意模型，从每个已占据的非零类型选一个代表。这样的代表最多七个。删除所有000类型对象不会改变三个项的非空性、相交、差集和包含关系；这些对象不属于任何主项，不能成为I/O的见证或A/E的反例。如果三个项全空，则另保留一个000对象，确保论域仍非空。于是所有有关命题的真值保持不变，任何反模型都可压缩成最多七个对象的规范模型。

所以程序枚举七个非零类型的全部支持集，共128个；全空支持用单个000对象实现。各项非空时保留109个支持。109也可用容斥核算：128−3×8+3×2−1=109。类型使用S=4、M=2、P=1的位编码，对象编号就是其类型。

这段真值保持论证才解释有限覆盖为何充分；仅打印128/109个模型及测试通过，本身不能证明一般定理。结论也仅限上述无关系、无模态的一元集合语言，不自动推广为古代三段论的完整解释。

## 两步推理和可手算边界

先用M包含于P、S包含于M推出S包含于P，是第一格AAA。再用Q与P不交、S包含于P推出S与Q不交：把Q视为大项、S为小项、P为中项，按记录位置是第二格EAE。若先将Q与P不交换位为P与Q不交，同一后果也有第一格EAE的证明。格取决于这条具体记录的项位，不是给整份多步证明贴一个永久标签。

`classify_step`只看位置，不保证式有效。例如第一格IAA会被识别为第一格，但可能无效。取S={0}、M={0,1}、P={1}，某个M是P、所有S是M为真，所有S是P为假。由结论A筛出第一格只是搜索约束，不是证明证书。

空项例：S={0}、M为空、P={1}，第三格AAI的两个全称前提均真，但I结论为假；要求M非空便可取同一M见证，推出某个S是P。程序的全项非空政策比此处必要的M非空更强，不混淆二者。

## 接口与防误用

- `Model`：一次性冻结可迭代的论域与项外延；对象编号要求非负整数，拒绝布尔值、空论域和越域成员。
- `evaluate`：返回大前提、小前提、结论三个布尔值，不自动把“已评价”当作“证明成功”。
- `countermodel`：返回首个前提真且结论假的规范模型；无此模型返回None。
- `valid_moods`、`candidate_figures`：计算当前存在政策下有效式及某种结论可能出现的格。
- `classify_step`：输入三个(类型,主项名,谓项名)元组。要求恰有三个不同的非空名称；返回1/2/3或None。None仅表示未匹配本程序三格位置，不是一般无效判定。质量字母不会改变位置标签。
- `mixed_proof`：提供上述两节点的教学记录。它不是任意图的依赖检查器，不验证节点编号或循环。

输入检查使用显式异常，不依赖会被`-O`移除的assert。调用者仍应满足上述结构契约；程序不提供用户界面或不可信网络输入服务。

## 复跑命令与真实结果

只使用Python 3.10以上标准库，未安装额外包。[实际环境](logs/environment.txt)。

```bash
cd reproduction/aristotle-prior-analytics-i42
python3 -m unittest -v test_model
python3 run_experiment.py
python3 -O -m unittest -v test_model
python3 -O run_experiment.py
python3 -OO -m unittest -v test_model
python3 -OO run_experiment.py
```

三种模式均通过16项测试。每模式完整评价24576个允许空项的模型-式组合、20928个全项非空组合，共45504次。另检查固定三对象论域中四项的4096种赋值，125种满足混合证明原始前提，两个中间/末尾后果均无失败。

有效式如下。字母顺序和存在政策必须与上文一起读。

|政策|第一格|第二格|第三格|
|---|---|---|---|
|允许空项|AAA, AII, EAE, EIO|AEE, AOO, EAE, EIO|AII, EIO, IAI, OAO|
|全项非空|AAA, AAI, AII, EAE, EAO, EIO|AEE, AEO, AOO, EAE, EAO, EIO|AAI, AII, EAO, EIO, IAI, OAO|

两种政策的类型候选格相同：A仅第一格；E第一或第二格；I第一或第三格；O三格均可。实际式的有效性则会因存在政策变化，不能仅保留候选格表而丢弃条件。
