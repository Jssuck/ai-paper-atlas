# 《几何原本》X.20：沿有理底边配置有理面积

以参考长度 `u>0` 表示面积。输入 `a=底边²/u²` 和 `r=矩形面积/u²`，均为精确正有理数。函数 `apply_area(a,r)` 返回宽与底边的比 `r/a`、相对宽平方 `r²/a`，以及最简整数公度计数。若宽与底边之比为 `m/n`，共同长度量为底边的 `1/n`；依次量出宽和底边 `m,n` 次。无需以浮点数近似开根。

例如 `(a,r)=(4,6)` 得底边 `2u`、宽 `3u`；`(2,3/2)` 则得底边 `√2u`，宽为底边的 `3/4`，宽平方相对 `u²` 为 `9/8`。后一对仍在长度上彼此可公度，但与参考长度 `u` 只在平方上可公度。同时把两项面积坐标乘以相同的正有理数，宽与底边的比不变。模型不接收任意实数，也不是尺规实现。

独立测试从整数铺格出发：若底边由 `n` 个等长小格组成，底边平方有 `n²` 个小格；宽有 `m` 格的矩形面积便是 `mn` 格，宽平方是 `m²` 格。在每个 `a=p/q` 上传入按铺格得到的面积，核对输出的比例、宽平方与公度计数。`p,q,m,n∈1..8` 的全部 4,096 组输入（不去重）中，1,280 组宽底比为整数，2,816 组为非整数有理数。有限校验不是一般性证明。
