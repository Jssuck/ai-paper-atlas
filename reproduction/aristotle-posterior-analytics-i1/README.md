# 《后分析篇》I.1：普遍规则、个体识别与实际应用

这是围绕71a1–71b8制作的**原创现代教学模型**，不是复原古代认知过程，也不测量人的学习表现。对应[中文深读](../../papers/ancient/aristotle-posterior-analytics-i1.zh-CN.md)。原文阅读定位见[来源台账](../../papers/ancient/aristotle-posterior-analytics-i1.sources.zh-CN.md)。

## 1. 为什么不把“知道”直接写成真假函数

客观上所有P都是Q，并不意味着一个主体已逐一识别每个P，或已经实际应用规则得到每个Q。本实验保留以下不同层：

- World：客观论域、P外延、Q外延；仅用于事后核验。
- meanings：主体已登记理解的谓词符号。本程序只检查登记，不声称验证了真实理解。
- accepts_rule：主体是否持有“所有P都是Q”。持有不自动保证为真。
- registered：主体已登记存在的对象ID。登记也可能错误。
- recognizes_p：主体记录为P的对象ID。记录不自动保证识别准确。
- derived_q：主体真正执行一步应用后写下的Q结论。不会自动填充逻辑闭包。

这些字段是为拆分混淆所作的教学选择，不是原文列出的六项心理学理论。原文区分预知事实、词义及两者，并未规定每一学习任务必须具有相同字段。这里要求两谓词登记，是此极简程序的接口检查，不能推回为亚里士多德的普遍必要条件。

P/Q没有绑定真实三角形几何；几何例只帮助理解任务结构。程序不证明三角形内角和或任何数论定理。它也不试图解决所有意义的“存在”。

## 2. 一步证书与两种核验

模型只使用一条规则：对于任意对象x，如果P(x)，则Q(x)。

操作前提为：P与Q的词义登记齐全、持有规则、对象存在登记、该对象的P识别记录。derive读账本，不读取World，返回新账本与绑定同一对象ID的证书。

syntactic_check核验**形式支持齐全**；semantic_check再要求全称规则客观为真、该对象确实存在且是P，并核对结果是Q。后者只是此模型的真值审计，不是完整的科学知识定义；它没有审查原因说明、证据可靠性或认知主体是否真正理解。

证书只检查当前账本的形式支持，不是历史执行的密码学证明；手工构造同字段证书也可通过。实际执行记录另见日志。

因此，错误识别可能产生形式上合格而客观为假的Q输出。不能把这种输出叫作知识。相反，即使个别结论碰巧真，若一般规则假，真值支持审计也不通过；这不是宣称所有具有假前提的论证结论都假。

### 一般保真推导，不依赖枚举

设任意论域D，P、Q都是D的子集，且P包含于Q。取任意对象a。若a属于P，那么由子集定义a属于Q。因此：**全称规则真且个体P识别真时，一步应用的Q结论真**。

这条证明的任意性不受三对象实验限制。程序中“词义已登记”“持有规则”等操作条件决定程序何时执行，不能代替上述真值前提，也不能从事实为真推出主体已知。

### 为什么把规则限于已识别对象会变弱

用R代表已识别/选择的对象集合。“所有P都是Q”要求P包含于Q；只检查已识别部分则要求P与R的交集包含于Q。前者蕴涵后者，逆向不成立。

反例：D={a,b}，P={a,b}，Q={a}，R={a}。已识别部分全部通过，但b使原全称失败。这个反例说明两个断言不等价，不是断言原文偶数定理本身为假。若R覆盖P，两种检查在此模型中才等价。

## 3. 可逐步查看的学习场景

开始：账本已登记P/Q、持有规则；derived_q为空。仅因规则客观真，不会给每个对象自动写结论。

1. 若尚未登记a，derive拒绝。
2. 登记a后，若未识别P(a)，仍拒绝。
3. 识别P(a)后，执行derive才把a写入derived_q。
4. 若原规则及P(a)都真，真值审计通过。若识别错误，形式证书可以通过但真值审计失败。

因而“先已掌握普遍规则”与“后来获得这个个体的结论”可以同时描述同一过程，无需把学习压成“完全无知或已知道一切”。这里只展示该区分的一种一致实现，不证明它是唯一古文解释。

## 4. 文件及命令

Python标准库即可，无第三方依赖，无网络、随机性或外部数据。

- [model.py](model.py)：不可变账本、一步应用、形式与真值核验。
- [test_model.py](test_model.py)：16项单元测试。
- [exhaustive.py](exhaustive.py)：生产集合运算与独立位运算/布尔oracle逐项比较。
- [results.json](results.json)：实际枚举结果。
- [environment.json](environment.json)：运行环境，不含个人目录或主机标识。
- [SHA256SUMS](SHA256SUMS)：本复现源码与说明的冻结校验值。

在此目录运行：

```sh
python3 -m unittest -v test_model
python3 -O -m unittest -v test_model
python3 -OO -m unittest -v test_model
python3 exhaustive.py
python3 -O exhaustive.py
python3 -OO exhaustive.py
```

测试使用unittest断言，枚举使用显式异常检查，不依赖可被-O删除的Python assert语句。-OO删除文档串不会取消检查。各模式均真实执行，日志不是复制出来的“通过”模板。

## 5. 本次真实结果与计数口径

每个模式均通过16项测试。枚举固定三个对象，P、Q各8种外延，形成64个世界；识别集合8种，登记集合8种，持有规则2种，两个词义登记4种，共32768个账本-世界状态，逐对象检查98304次。

- 形式上可应用：3072次。
- 全称规则和个体识别均有真值支持：432次，均输出真Q。
- 缺乏真实前提支持并产生假Q：1536次。程序**有意允许不可靠输入**，这不是保真性漏洞；审计拒绝这些输出。
- 在64世界×8选择集合的512组合中，限制子域断言真而完整全称假的组合：127。
- 生产实现与独立oracle不一致：0。

其余有形式应用但真值审计未过的输出中，也存在碰巧为真的结论，故“审计失败”不等于“结论假”。counts不是统计估计、性能基准或认知正确率。

## 6. 覆盖与局限

测试包括缺规则、缺存在登记、缺识别、缺词义、误识别、虚构对象、同名不同ID、真结论与假规则、已知子域弱化、未知不是假、空P的空泛全称、证书篡改及重复应用幂等性。

此程序不学习普遍规则，不解决归纳正当性，不模拟感知误差分布，不实现认识逻辑中的完整知识算子，也不把账本字段称作古代概念的唯一对应。有限枚举检验这份代码在有限域上的一致性；一般保真论证另由上面的逐步证明承担。对原文中最末个体可在学习时同时被识别的讨论，本模型只表达输入登记与应用的先后依赖，不把它强制解释为必有时间间隔。
