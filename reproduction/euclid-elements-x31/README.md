# 《几何原本》X.31：保留差平方的公度类别

取参考长度 `u>0`。输入 `a=(A/u)^2>b=(B/u)^2>0` 为正有理数，要求 `k=b/a` 不是有理平方，对应两输入线段只在平方上可公度。函数 `construct(a,b)` 输出相对四次幂 `ab,b³/a`、相对矩形面积 `b`、输出边比的平方 `k`、归一化差平方 `1−k`，以及差平方对应的边是否与所在对的较长边在长度上可公度。输入对和输出对的归一化差平方均为 `1−k`，因此类别相同。这里不是直接拿两个差平方的边彼此作比较。

例：`a=25,b=21` 时归一化差平方为 `4/25`，其边与较长边之比为 `2/5`；`a=2,b=1` 时为 `1/2`，其边与较长边的比无理。若 `a=4,b=1`，两输入边已在长度上可公度，不满足前提；相等或反序也拒绝。函数只处理精确有理平方坐标，不近似根式，不模拟尺规。

独立基线不调用整数开根。对整数样本，用 `ab` 是否为整数平方判断输入是否满足前提，并用 `a(a−b)` 是否为整数平方核对差平方类别：两者分别比对应的有理平方比多乘了整数平方 `a²`。枚举 `1≤b<a≤64` 的 2,016 对，54 对的差边与较长边在长度上可公度，1,904 对不可公度，58 对不满足前提。有限样本不能代替证明。
