## 范围与边界

本目录是原创的现代教学重构，对应 I.30（87b19–27）关于偶然、必要与通常的论证。**不把原文“通常”定义为概率大于 1/2，也不宣称复现了亚里士多德的模态或知识理论。** 有限枚举不能证明一般定理，更不能把“可能但非必要”直接等同于原文的偶然分类。

## 三组模型

### 1. 改变条件总体时，简单多数不能直接传递

均匀有限总体 U={0,…,9}，C={0,1,2,3,4}，B={0,1,2,5,6,7,8,9}，A={5,6,7,8,9}。

- P(B|C)=3/5，P(A|B)=5/8，两者都严格超过一半。
- P(A|C)=0；P(A|B∩C)=0。

这诊断的是一种现代“简单多数”的机械读法，不是对原文“通常”所有解释的反驳。

### 2. 同一条件 C 下的嵌套条件下界

当 C 与 B∩C 非空时：

`P(B|C) × P(A|B∩C) = |A∩B∩C| / |C| ≤ |A∩C| / |C| = P(A|C)`。

分母消去和集合包含已给出一般论证；代码只做有限核查。**无独立性假设**。因此，若两个条件频率分别至少为 1−ε₁、1−ε₂，且 ε₁、ε₂∈[0,1]，结论至少为 (1−ε₁)(1−ε₂)。这并不必然超过一半，例如 (3/5)²=9/25。

`frequency(event, condition)` 要求输入支持交集与长度的有限集合；空条件返回 `None`，绝不以 0 代替。`bound_values` 遇到未定义因子也返回 `None` 下界。B∩C 为空时交集频率可为 0，但那个条件频率本身仍未定义；程序单独统计这些情形。

### 3. 全称包含、真空成立与样本频率

C⊆B⊆A 蕴含 C⊆A；这是有限外延模型，不是模态必要性语义的完整实现。C 为空时包含关系仍可能成立，条件频率却未定义。两个预设可能世界的例子还显示：在观测世界中频率为 1，不保证每个预设世界所有对象都满足性质。

16 个 `unittest` 测试在普通、`-O`、`-OO` 三种模式均通过。它们覆盖空条件、精确分数、反例、交集恒等式、非独立情形、阈值下界、全集枚举和跨世界反例。使用 `unittest` 检查而不是会被优化移除的裸 `assert`。
