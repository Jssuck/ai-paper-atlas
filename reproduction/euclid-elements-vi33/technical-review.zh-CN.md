# VI.33 独立技术核对

复核原典的正倍量判据、现代累计模型、各算例和练习，并重新运行复现。

- **两列比较。** 两列需要独立选取正整数倍数；各自把同一倍数用于该列的弧与角。比较时，每一侧始终是同类量相减，三种符号均须一致。等圆弧的严格次序由共同起点、同一方向和严格包含说明，不能把它当成 III.27 等弧命题逐字所述。圆周角必须对应同一截弧，顶点不在所选弧内；大弧的现代圆周角读法不意味着古文已经处理普通角大于平角的情形。
- **现代重构。** 同半径的共同整圈长、旋转保长度及路径可加性给有理圈数线性关系，再由严格单调性夹逼到任意实数圈数。半圈后的主角折返和满圈取模丢失都是表示错误；核对了 270° 对 180° 的次序反转、450° 对 90° 的终点相同、等半径正例和不等半径的两种反例。圆周角的二分是比较模型采用的关系，不是测试推出的。
- **独立运行。** 普通、`-O`、`-OO` 三种模式各通过 6 项测试；各次网格均为相同的 15,552 组精确比较，正、零、负号各为 7,533、486、7,533 次。所有 3 个 Notebook 代码单元均通过纯 Python 回放，未调用 Jupyter 内核。检查的是教学模型的实现，不以有限有理网格代替普遍证明。
