# 《几何原本》X.14：等比的两对线段保留平方差分类

`classify(A,B,C,D)` 接收正有理边长，要求 `A>B`、`C>D` 且 `A:B=C:D`。两组平方差所对应的长度分别和各自较大的边长作比。它们的比值平方同为 `q=(A²−B²)/A²`，故只需检查一次：若既约 `q` 的两项都是整数平方，两组比值同为一个正有理数；否则两组都不可公度。函数返回精确 `q` 及该有理比值或 `None`。这不比较两组平方差长度彼此之间是否可公度。

`(5,3)` 与 `(15/2,9/2)` 的平方差长度与较大边长都成 `4:5`；`(3,2)` 与 `(9/2,3)` 均无有理根。现代符号核对：若同比放大因子为 `√2`，两个平方同时乘 2，归一化平方差不变。函数不直接接收这些无理边长。

独立整数基线枚举 `1,…,A−1` 的平方，查找 `A²−B²`；其完整性来自有理数若平方为整数，则自身是整数。对 `1≤B<A≤32` 和整数同比因子 `1≤k≤8`，有限样本不能代替证明。实跑 3,968 个组合，其中 176 个两组都可公度，3,792 个两组均不可公度。
