# 《后分析篇》I.20：有限区间、链深度与候选宽度

这是配合[正文](../../papers/ancient/aristotle-posterior-analytics-i20.zh-CN.md)的原创教学代码，不是古代科学谓述的完整形式化。目标是让三个不同检查可重复：一条全序区间中的中项数量、一般偏序的候选宽度，以及相邻前缀之后仍可继续细分的有限数值前缀。

## 模型与接口

`StrictOrder(n, edges)`的节点是0到n−1；输入任意编号的有向边，计算Floyd–Warshall传递闭包，并拒绝自环和环。模型关系的方向是从低端到高端。它只检查严格序关系，不判断哪条边是真实科学原因、自然谓述或本质归属。`middle(lower, upper)`返回严格位于端点之间的节点；`interval`还返回区间是否全序及其中最长链的边数。端点不严格可比时直接拒绝，而不是冒充空区间。

最长链由有限无环关系上的记忆化递归计算；全序检查逐对检查可比性。对于有限全序区间，把所有内部项按顺序排在两端之间，就得到一条最长链，因而“内部项数=最长边数−1”。这是普通有限序的教学性质，不能由它推出古代所有证明必须终止。

节点数限制为0至128；固定拓扑序枚举的n限制为0至5；菱形m限制为1至126；有理插入次数限制为0至256。这些是程序资源边界，不是原文的哲学界限。

## 实际结果与分母

在固定顺序0<1<2<3下，6条可能正向边共有64种子集，即64个原始DAG；其中只有40种不同传递闭包。**它们不是全部任意标签偏序的枚举。** 同一闭包可能出现多次；按64个原始DAG累计得到223个严格可比端点区间出现次数，其中221个全序区间、2个非全序区间。全序区间的上述计数等式失败为0。重复闭包有意保留在223/221/2的分母中，未伪称独立模型数量。

构造底点0、中点1至m、顶点m+1，只连接底点到中点和中点到顶点。m=1、2、8、32时，中点数分别为1、2、8、32，而最长链总是两条边；m大于1时区间并非全序。这不反驳本章条件论证，而是说明**把一条串联链偷换成所有不可比较候选，会改变问题**。由有限m的运行记录也不声称已经实例化无限集合；任意m的一般结构由构造本身说明。

有理例把允许的有序域明示为{-1}与[0,1]内所有有理数的并集。-1与0在这个域中相邻，0到1之间却仍可取中点。程序只保存一个有限前缀：8次插入后最后插入255/256，距1有1/256；下一中点是511/512。程序不会遍历全部有理数，也没有通过有限运行证明无限性。一般可继续性需要正文中的平均数构造与代数证明。

三种Python模式各13项测试通过，Notebook4个单元实际完成。结果来自合成结构，不设真实数据基线、准确率或科学解释正确率；这些指标在本实验中没有相应测量对象。

## 复盘与局限

- 无环不是无穷域上无无限链；有限图搜索的结束不等于科学根据回归已解决。
- 中间候选多不等于同一条链长；全序条件不能悄悄删除。
- 某段相邻并不表示后面没有可继续细分的部分。
- 同外延、自然/偶然方向、模态与解释优先性都不在这个纯序模型里。
- 本实验只支持检查明示的有限结构与有限数值前缀；不宣称古代全文形式验证、一般无限定理的实验性证明或完整AI推理系统复现。
