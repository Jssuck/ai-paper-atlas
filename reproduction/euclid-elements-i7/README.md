# Euclid I.7：同侧双距离唯一性的精确教学核验

对应[中文深读](../../papers/ancient/euclid-elements-i7.zh-CN.md)。本包是原创现代有理坐标模型，**不是古代程序、尺规操作引擎、证明助理或全部欧氏公理的模型**。一般结论由正文的明确论证承担；有限枚举不能证明一般定理，也不能补齐原文所有图形分情况。

## 1 接口、前提与非空真检查

坐标仅接受整数和Python标准库Fraction；拒绝浮点、布尔值、错误维度。A与B必须不同。C、D允许被提交在基线上，以便返回“命题域前提不成立”，不是把退化情况悄悄删掉。

`certificate(A,B,C,D)`分开报告：

- `equal_a`：AC²=AD²；`equal_b`：BC²=BD²。这两个是固定端点的**对应**距离相等，不能交换对应。
- `same_side`：cross(B-A,C-A)乘cross(B-A,D-A)严格大于零，故C、D都不在基线上且严格同侧。
- `premises`：上述两距离与严格同侧同时成立。
- `conclusion`：C=D；`distinct`：C≠D。I.7排除的是满足相应条件的第二个不同顶点，并不是排除原顶点本身。
- `implication`：前提不成立或结论成立。异侧镜像的蕴涵为真，仅是空真，**不代表镜像通过了命题前提检查**。
- `verify_claim`同时要求前提与结论成立，专用于避免把空真当成有效证书。

若A=B，接口直接报错。若C=A或C=B，或C、D共处基线，`same_side`为假；它们不被记为原命题域内正例。C=D且在同侧是有效正例。没有制造“不同顶点却同时满足全部前提”的欧氏正例，因为该组合正是待排除的情况。

## 2 解析证书各步

设u=B-A、v=C-A、w=D-A、q=u·u，s=u·v、t=u·w，h=cross(u,v)、k=cross(u,w)。程序逐项检查距离差恒等式、二维内积/叉积恒等式及坐标重建式。

1. 两对应距离相等，可由平方距离相减得到s=t。
2. q|v|²=s²+h²，q|w|²=t²+k²；又|v|²=|w|²，得到h²=k²。
3. 严格同侧给hk>0，排除h=-k，故h=k。
4. q>0，且qv=(s*u_x-h*u_y, s*u_y+h*u_x)，同样重建w，推出v=w。

以上是内积坐标模型中的教学证明思路，不声称欧几里得原文使用了向量或平方距离，也不借用后续I.8。恒等式可在前提不成立的输入上检查，但恒等式正确不会自动让输入满足前提。

`reflect(A,B,C)`提供关于直线AB的精确有理镜像，公式使用q作分母。它是现代解析生成器，不是古代尺规程序。镜像保留两对应距离并反转叉积符号；不在基线的点与其镜像属于异侧，故不是I.7反例。基线上镜像不变，但严格同侧前提仍不成立。

## 4 手算例与负例

固定A=(0,0)、B=(4,0)、C=(1,2)。

1. D=C：两对应距离均相等，叉积均为8，前提和结论成立。
2. D=(1,-2)：AC²=AD²=5，BC²=BD²=13，但叉积为8和-8。它展示删除同侧条件后唯一性失败，不反驳原命题。
3. D=(-1,2)：两点严格同侧，AC²=AD²=5，但BC²=13、BD²=29；只给一个距离不够。
4. D=(3,2)：AC²=BD²=5、BC²=AD²=13，距离成对交换，却不满足固定对应要求。
5. D=(1,0)：基线候选被命题前提排除。C=D=(1,0)也不会因结论为真而通过严格域前提。
6. A=B=(0,0)时，到两个“端点”的条件重复；(1,0)和(0,1)都距它1。同侧本身失去基线含义，接口直接拒绝，不能把零分母当计算技巧问题。

## 6 解释限制

有理坐标不能枚举所有实数点；解析证书核验也不检查原文角比较步骤是否完整。程序不将“同侧”“距离对应”和“点相异”融合为一个含糊的布尔值，不用浮点容差替换精确相等。理论中同侧正负分支和q非零条件是逻辑要件，不是有限实验自动发现的规律。
