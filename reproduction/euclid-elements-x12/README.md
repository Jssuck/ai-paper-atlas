# 《几何原本》X.12：两项相邻比例给出三个量的同一公度单位

教学模型 `combine(A/C,C/B,C)` 接收正有理的两个相邻比及中间量（在共同外部单位下的坐标）。分别化为既约正整数比 `d:e` 和 `f:g` 后，构造 `H:K:L=df:ef:eg`。同一单位 `C/K` 量出三个量，整数次数依序为 `H,K,L`。这是一种乘积构造，不等于声称原文选择了这组整数；VIII.4 支持匹配相邻比例的整数形式。现代补充：除去三项的最大公因数，计数变为最简，同时公度单位乘上该公因数。

例如比例 `2/3` 和 `9/4` 给出 `18:27:12`，最简为 `6:9:4`。取中间量 27 时两种单位分别为 1 和 3；取中间量 `9/2` 时分别是 `1/6` 和 `1/2`。倒转顺序时同时倒转相邻比并取倒数，不能只交换两项。输入比例已被假定有理，因此不是判定任意实线段可公度的工具；模型用坐标表示尺度，不是尺规复原。

独立基线枚举正整数中间计数，从 1 到输入原代表的 `ef`，找到第一个令两端计数均为整数的值。原代表不必既约；即便不约分，`df:ef:eg` 仍给出上界。对 `d,e,f,g∈1..8` 的全部 4,096 个有序代表组合，两段输入比先各自约分，再构造乘积三元组；实跑检验其中 3,422 组无需再约分，674 组需要再约分。重复表示不去重，有限检验不代替证明。
