# VII.12：同率对应项分别求和

现代正整数上的教学重构，不是古代实跑或一般命题的计算证明。输入是至少两对按次序对应的整数 (a,b)，每对均须满足 1<a<b 且具有相同约分计数 m:n。共度可以为 1，即使给定的数本身不能是单位。

将定义 20 的同一份或若干份写成相同约分计数：m=1 逐对走 VII.5，m>1 逐对走 VII.6。代码累加每一对并检查每步的计数；输出包含各前缀和与最终合计。测试用原始列分开求和，并直接构造 Fraction 核对，不借用该计数的输出。

- (4,12)、(5,15)、(7,21)：单位份，合计 (16,48)，比为 1/3。
- (2,3)、(6,9)、(8,12)：若干份，合计 (16,24)，比为 2/3。
- (4,8)、(6,12) 若重新错配为 (4,12)、(6,8)，合计仍为 (10,20)，但局部比变成 1/3 和 3/4；程序拒绝。对整对联合重排则保留合计。
- 相等或每对统一倒置仍能导出现代分数等式，限于原证明方向的程序不接受。单对时现代等式只是恒等式，不属于此多对模型。
