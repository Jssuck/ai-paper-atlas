# Drach–Sylvester 短札：精确算术教学演示

这是针对 Drach 1852 年第 479 页短札中公式的**现代教学演示**。短札讨论的表达式为

```math
a+b\sqrt{-1}+f-c\sqrt{-1}.
```

这里不把程序或这些数值例子说成历史原文中的实验，也不声称重建了 Drach 或 Sylvester 的计算过程。原文、署名关系及历史语义的判断应以本项目的文献核验材料为准。

## 数学解释与边界

1. **实数参数假设。** 当 $`a,b,f,c\in\mathbb R`$ 时，令 $`i^2=-1`$，表达式就是 $`(a+f)+(b-c)i`$。由复数实部、虚部表示的唯一性，它为实数当且仅当 $`b=c`$。这一推导是代数论证；程序只用有理数实例检查实现。
2. **正负差确实不同。** $`5-3=2`$、$`3-5=-2`$、$`3-3=0`$。固定 $`a=2,f=3`$，取 $`(b,c)=(5,3),(3,5),(3,3)`$，结果分别为 $`5+2i,5-2i,5`$。虚部系数可以为正、负或零；这不意味着复数具有实数意义上的大小顺序。
3. **拆分不唯一。** $`(2+5i)+(3-3i)`$ 与 $`(1+9i)+(4-7i)`$ 都等于 $`5+2i`$。更一般地，同时把 $`a,f`$ 改成 $`a+t,f-t`$，或把 $`b,c`$ 改成 $`b+s,c+s`$，不会改变结果。因此 $`(a,f,b,c)`$ 的拆分不唯一，但复数的实部、虚部仍然唯一。
4. **非实中间量可产生实数结果。** $`(2+3i)+(3-3i)=5`$，且 $`(1+i)(1-i)=2`$。这些例子只说明中间出现非实数不妨碍最后得到实数，不代表某种几何构造已经成立。
5. **几何约束与“非实根”不能混为一谈。** $`x^2+3x=4`$ 因式分解为 $`(x-1)(x+4)=0`$，根为实数 $`1,-4`$。如果 $`x`$ 表示普通长度并要求 $`x\gt 0`$，只有 $`1`$ 合格；$`-4`$ 被排除的原因是违反定义域约束，而不是非实。该例反驳“凡不合几何条件的代数根都是非实根”的宽泛等同，并不说明整个几何问题无解，也不是尺规可作性的判据。
6. **撤掉实数参数假设后，$`b=c`$ 不再是充要条件。** 即便只让 $`a,f`$ 可为复数，实际条件已是 $`\mathrm{Im}(a)+\mathrm{Im}(f)+b-c=0`$。例如 $`a=i,f=0,b=c=1`$ 时结果为 $`i`$，说明 $`b=c`$ 不充分；$`a=-i,f=0,b=2,c=1`$ 时结果为 $`0`$，说明 $`b=c`$ 不必要。这里不是声称原文有意让这些参数取复数，而是在标明现代解释所依赖的假设。

## 运行

需要 Python 3.10 或更新版本；仅使用标准库，无须安装依赖或联网。

在本目录运行：

```sh
python3 reproduce.py
```

也可以单独查看与检验：

```sh
python3 demo.py
python3 -m unittest -v test_demo
```

`Pair` 用两个 `fractions.Fraction` 表示实部和虚部；不使用浮点运算，拒绝浮点输入。输入可为整数、分数字符串或 `Fraction`。JSON 中的有理数保存为字符串，以免读取工具自动转成浮点数。

## 文件与实际验证

- `demo.py`：复数对及教学例子。
- `test_demo.py`：8 个测试方法，覆盖分数精度、基本运算、正负差、实数性条件、拆分不唯一、消去、长度约束与复参数反例。
- `reproduce.py`：实际执行测试和演示，并记录输出。
- `results.json`：演示的实际输出。
- `tests.log`：测试运行输出；含实参数五点网格的 $`5^4=625`$ 组检查。625 组为一个测试方法内的子测试，不是 625 个独立测试方法。
- `environment.json`：本次运行的 Python/平台信息及时间。
- `commands.log`：执行命令和实际退出码。

有限实例和测试既不能取代一般证明，也不能决定十九世纪术语的历史含义。本目录只提供与短札篇幅相称、可独立运行的代数教学材料；没有添加机器学习基准、性能比较或虚构的历史实验。
