## 数学与实现

- `Pair` 用两个 `Fraction` 保存实部和虚部；加、减、乘的公式正确。整数、分数字符串和 `Fraction` 输入保持精确；浮点数及布尔值被拒绝。输出中的有理数为 JSON 字符串。
- 对实参数，`remark(a,b,f,c)` 实现 `(a+f)+(b-c)i`。因此结果为实数当且仅当 `b=c`。一般结论来自代数恒等式与实部、虚部表示的唯一性；有理数测试只是实现检查。
- 两种拆分均得到 `5+2i`，且同时平移 `a,f` 或 `b,c` 的不变性正确。非实加数消去和共轭相乘的例子分别得到 `5` 和 `2`。
- 当仅允许 `a,f` 为复数、仍令 `b,c` 为实数时，虚部是 `Im(a)+Im(f)+b-c`。两例分别给出 `b=c` 而结果为 `i`，以及 `b≠c` 而结果为 `0`，确实分别否定充分性与必要性。`unrestricted_remark` 的适用范围是这里的有限放宽，不能据函数名称理解为任意类型输入。
- `x²+3x−4=(x−1)(x+4)` 的全部根为 `1,−4`，代回残差均为零；在明确规定 `x>0` 后，仅 `1` 合格。`−4` 仍是实根。**这是代数根与正长度约束的示例，不是几何模拟、尺规作图证明，也不能据此断言整个几何问题无解。**
