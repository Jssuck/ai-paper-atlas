# 《后分析篇》II.5：覆盖、选择与定义的最小教学实验

对应91b12–92a5；这是原创现代集合模型，不是对古代全体系、自然分类或本质知识的完整复现。它只检验几项可精确定义的推理条件，并展示有限词表与外延的边界。

## 1 假设、API与逻辑目标

所有集合来自同一个有限论域。P为父集合，L/R为左右分支，H为待分类目标类，不默认为单个对象。允许空H；此时包含结论真是空真，不是证明对象存在。

- `division(P,L,R)`分别检查分支在父类内、覆盖、互斥。覆盖采用L∪R=P；互斥不是覆盖的同义词。
- `elimination(H,P,L,R)`检查覆盖、H⊆P、H∩R=∅这三条件及H⊆L结论。互斥不是这条规则的必要条件。
- `check_path(H,root,steps)`逐层核查给定左右分割、选支后目标包含；记录选择与来源标签。它直接核对已给外延，不发现或证明这些外延。assumption、observation、supplied_proof都只是标签，不验证来源、证明正文或科学认识。
- `conjunction(U,predicates)`计算候选说明的外延交集；不能认证本质成分、完整定义或自然统一性。
- `relative_atom(cell,vocabulary)`仅判断非空cell不被任何已给谓词真切分割；空cell返回False。相对旧词表的“不可再分”可能被新增谓词打破，不等于自然种。

## 2 一般推导与最小反例

**排除规则证明。** 任取x∈H。由H⊆P得x∈P；由P=L∪R得x∈L或x∈R；H∩R=∅排除后者，故x∈L。对任意x成立，得到H⊆L。这个逐元素论证适用于任意集合，不依赖下面的有限枚举；也不需要L、R互斥。

**覆盖不能独自选支。** P={0,1}，L={0}，R={1}，H={1}。这是完好的二分且H在P内，但H不在L内。列出分支没有为H选择分支。

**不能删除覆盖。** P={0,1}，L={0}，R=∅，H={1}。H在P内且排除了R，却落入覆盖空缺，不能进入L。不能把“排除一个已经列出的选项”误当作“剩余选项已经穷尽”。

**路径并不证明本质。** 演示U={0,1,2,3}，先选{0,1}再选{0}，目标H={0}。路径全部外延条件可核对；来源分别标作观察和假设。程序仍返回essence_certified=False，这表示本工具不认证本质，绝不表示它证明了该说明不是本质。

**遗漏和冗余是不同错误。** 给三个谓词{0,1,2}、{0,1}、{0,2}，全交集是{0}；漏掉末项得到{0,1}，跳过中项得到{0,2}。另加入{0,3}，全交集保持{0}，但这个外延冗余并不告诉我们它是偶性还是解释性成分。这只是可手算例子，不声称每次漏项都会改变外延。

每个元素对四集合有16种成员位，故总数1+16+256+4096=4369。有效分割且H在父类内时每元素有5态：父类外1态、左支2态、右支2态，所以1+5+25+125=156；再要求H在左支，每元素只有4态，计1+4+16+64=85，失败数156−85=71。排除规则前提每元素也是5态：父类外1态、仅左支2态、仅右支且不属H为1态、双支且不属H为1态，故也156。空H固定，其余三集合每元素8态，总1+8+64+512=585。

oracle用逐元素布尔成员条件重算覆盖、前提、结论，不调用待测集合包含函数。它是独立实现的有限交叉检查，仍受共同建模假设限制。

## 5 带答案练习

1. 若H=∅，H⊆L能说明H存在吗？不能，空真与存在分开。
2. 排除规则需要左右互斥吗？不需要；见第2节逐元素证明。
3. 分支覆盖且对象不在右支，但对象未被证明在P内，能选左支吗？不能，可能在P外。
4. 路径每一步都是观察标签，是否得到本质定义？没有，标签及外延不认证本质。
5. 加入一个不改变交集的属性，是否证明该属性不属于本质？没有，只证明此模型中交集外延未变。
6. 旧词表不可分的cell为何会再次可分？新谓词可能在cell中取真于部分元素；本例加入{0}切开{0,1}。
