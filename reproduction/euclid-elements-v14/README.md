## 模型、检查及结果

- 正整数或 Fraction 精确输入。对内同类且共用单位，才可比较整倍。同比函数可比较两对分别同类的比；V.14 的对应次序比较则要求四个量同类同单位。标签只做相等检查，不识别或换算不同单位；数据输入方负责使用共同单位。
- `order_transport(A,B,C,D)` 验证有理数等比前提，输出 A 对 C、B 对 D 的比较符号（−1/0/+1）。严格分支把较大的前项放左边，保留成对顺序，选择 n/m 等于 C/B，复现 V.8 中以 B 为共同后项的比序证据。探针符号按 A:B、C:B、C:D 排列：严格大于、等于、严格大于。V.13 传递严格符号，再由 V.10 所用的夹式 nD < mC ≤ nB 推出 B>D。等号分支用现代正有理数乘积消去，不冒称逐句复原古代省略的论证。
- (9,6,6,4)、(6,4,9,6)、(6,4,6,4) 分别得到 (+1,+1)、(−1,−1)、(0,0)。前两次同一有向严格分支使用探针 (1,1)，夹式是 4 < 6 ≤ 6。非同比 (51,50,52,50) 的原量次序是 (−1,0)：上限 20 的有限整倍比较找不到分歧，上限 26 内第一个分歧在 (25,26)，符号为 (−1,0)。
- 三种解释器模式各通过 10 项测试。独立的有理数商检查从 4,096 个有序四元组中选出 160 个等比四元组，分别含 48 个大于、64 个等于、48 个小于的情况；直接比较两列，核对输出，另检查不合格前提、类型和单位标签、精确分数及有限窗口的遗漏。样例和枚举都是有限教学检查；没有训练或测量数据，不能证明所有正实数或一般量的命题。
