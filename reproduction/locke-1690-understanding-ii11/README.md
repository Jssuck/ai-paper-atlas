# 洛克 II.XI：三个有限教学模型的复现说明

这份附件是 John Locke《人类理解论》第二卷第十一章的现代数学伴读。1690是所选首版题名页的印年。它不是从原书恢复的历史算法、经验实验的重复，也不是心灵实现。洛克提供辨别、比较、组合、增加与抽象这些哲学问题；下面的有限表、商关系判准、交换幺半群与版本空间，均由本项目另行构造。

本附件把问题限定为：一个已经选定的表示，何时保留区别、比较、重复次数或预测所需的信息，何时丢掉这些信息？策略例子只使用具名彩色卡片和合成响应表，没有医疗案例或动物实验，不据此判断任何个人或物种的能力。

所选首版全章为印页68–72、§§1–17，起于[扫描叶84](https://en.wikisource.org/wiki/Page:An_Essay_Concerning_Humane_Understanding_-_Locke_%281690%29.djvu/84)。页级定位与适用勘误见[中文正文](../../papers/1690/locke-understanding-ii11.zh-CN.md)及[来源账本](../../papers/1690/locke-understanding-ii11.sources.zh-CN.md)。这些属于来源主张；本附件的形式构造属于现代解释。

## 一 有向对象对与关系下降

### 1.1 现代定义

设 $`X`$ 为明确给定的有限对象域，$`r:X\to A`$ 为每个对象指定表示，$`I=r(X)`$ 为实际出现的标签集合。布尔关系是一张完整表 $`R:X\times X\to\{0,1\}`$；代码使用严格的 Python 布尔值，整数0或1不能冒充输入布尔值。

所求的商关系为 $`Q:I\times I\to\{0,1\}`$，要求：

```math
R(x,y)=Q(r(x),r(y))\qquad\text{对每个 }x,y\in X.
```

每个标签 $`a\in I`$ 的表示纤维为 $`F_a=\{x\in X:r(x)=a\}`$。这里要检查的是两个纤维的笛卡尔积 $`F_a\times F_b`$，不是单独检查某一个纤维。输入为有向对象对；模型不预设对称性、传递性或自反性。

### 1.2 一般定理与证明，和有限测试分开

商关系存在，当且仅当 $`R`$ 在每个非空纤维矩形 $`F_a\times F_b`$ 上恒定。若商关系的域为实际像集 $`I\times I`$，它还必定唯一。

必要性：若 $`r(x)=r(x')=a`$ 且 $`r(y)=r(y')=b`$，商关系给出 $`R(x,y)=Q(a,b)=R(x',y')`$。同一个矩形内的所有值因此相同。

充分性：假设每个矩形恒定。对每个 $`(a,b)\in I\times I`$，相应矩形非空，把它唯一的布尔值定义为 $`Q(a,b)`$。恒定性保证换用别的对象代表不改变结果，也立即得到所要求的等式。任何另一个商关系在这个非空矩形上都只能取同一值，所以商关系唯一。

这个证明并不限于测试中的小规模；对任意明确给定表示与关系的集合也成立。实现则只接收有限输入，不声称能判定无限表。若对象域为空，实际像集与商关系表都为空，空表是成功且唯一的结果。若改为在一个含未出现标签的外部集合上定义商关系，存在性不变，但空矩形上的值没有约束。因此唯一性主张有意只针对实际像集。

实现检查每个给定有向对象对，并从每个冲突矩形返回一对真见证和一对假见证。读者可直接核对：它们的表示输入相同而输出相反，因而不存在满足要求的商关系。失败返回 `None`，绝不返回残缺或任意选出的表。全假商关系与空商关系均属于成功。

### 1.3 颜色保留了，编号先后可能丢失

取三个明确对象：`white_1`、`white_2` 与 `blue_3`。颜色依次为白、白、蓝，编号依次为 $`1,2,3`$。表示只保留颜色。

- 一元谓词“是白色”可以下降：两张白卡都为真，蓝卡为假
- 二元关系“与另一张卡同色”也可以下降；抽象并不自动破坏所有关系
- 二元关系“编号严格小于另一张卡”不能下降：在白对白的矩形中，`white_1` 对 `white_2` 为真，`white_1` 对自身为假。同一表示输入需要不同输出。把第一对反向也能得到有效假见证；实现确定性地返回先遇到的那一对

一元下降的条件是每个单独纤维上的谓词值恒定。不能因为一个被保留的一元性质可以计算，就推断任意二元比较也可计算。反过来，单射表示总能保留给定关系，但它可能没有进行任何压缩。

### 1.4 有限核验范围

关系检查枚举对象数 $`0,1,2,3`$、到两个可用表示标签的全部赋值，以及每张可能的布尔关系表。对象数为 $`n`$ 时共有 $`2^n2^{n^2}`$ 个案例，包括空域案例。总数为 $`1+4+64+4096=4165`$。

独立判定方法直接枚举实际像集平方上的全部布尔表，数出其中满足分解等式的候选；它不把被测程序的“纤维矩形恒定”算法重新当成自己的存在性判据。检查还会核对程序返回的每个冲突见证。另行枚举一元谓词，共 $`1+4+16+64=85`$ 例。它们是有限实现检查，既不代替一般证明，也不是认知测量。

## 二 用保留次数的组合解释一打与增加

### 2.1 现代定义

固定有限原子表 $`A`$。多重集为函数 $`m:A\to\mathbb N_0`$，支持集为 $`\{a:m(a)\ne0\}`$。因为原子表有限，所有允许输入都具有有限支持。相加表示组合次数，乘以非负整数表示重复：

```math
(m+n)(a)=m(a)+n(a),\qquad (k m)(a)=k\,m(a).
```

零向量为单位元。每个坐标上的自然数加法证明结合律与交换律，因而这些多重集形成交换幺半群。模型有意只处理无序的加法组合，不表示时间次序、空间排列、语义角色绑定、视觉图像或主观的增加体验。

一个单位和一打单位在原子 `unit` 上的次数分别为 $`1`$ 与 $`12`$，因此不同。包含十二次相同 `unit` 的普通集合只有 $`1`$ 个元素。集合并集无法代替本模型的计数组合。

输入规则如下：原子表内不允许重复名字；重复的 `(atom, count)` 条目则将次数相加；明确写出的零次数不进入支持集；负数、冒充整数的布尔值以及未知原子均被拒绝。每一条次数都必须非负，不能靠正负抵消蒙混过关。空原子表、空输入列表、零多重集与乘以零均有效。原子表次序会规范化，因此输入排列不影响相等判断。

### 2.2 一般同态证明与信息损失

给定重命名 $`h:A\to B`$，把取得同一新名字的次数累加，定义推送映射：

```math
(h_*m)(b)=\sum_{a\in A:\,h(a)=b}m(a).
```

对每个目标原子 $`b`$，有限求和的分配律给出：

```math
(h_*(m+n))(b)
=\sum_{a:\,h(a)=b}(m(a)+n(a))
=(h_*m)(b)+(h_*n)(b).
```

所以重命名保留加法与零。它也保留总次数，因为各个原像纤维构成源原子表的划分。但它未必保留原子的身份区别。如果两个不同原子得到同一个新名字，各自只有一次的两个单位多重集原本不同，输出却相同。反过来，若重命名为单射，每个原子原有的次数都能从其独占的目标名字读回。因此，推送映射在全部允许多重集上为单射，当且仅当原子重命名为单射。

给定保留子表 $`K\subseteq A`$，投影 $`P_K`$ 只是限制计数向量的坐标。逐坐标计算得到 $`P_K(m+n)=P_K(m)+P_K(n)`$，并且零被保留。丢掉一个原子会丢掉其次数，也可能降低总次数。投影在全部多重集上为单射，当且仅当 $`K=A`$：若丢掉一个原子，它的单位向量和零都会投影为零。

例子把红、蓝都改名为 `token`：红2蓝1与红1蓝2都成为单位3。另一个例子只保留红色，因而不同的蓝色次数消失。“保留加法”说的是一个操作的相容性，不能改写成“保留全部信息”。

### 2.3 有限核验范围

输入范围含两个原子，每个坐标次数取 $`0,1,2`$，共九个输入多重集与81个有序输入对。检查到两个目标原子的全部四个重命名，以及全部四个保留子表。因此有324次重命名检查、324次投影检查，并分别对照独立计算的坐标和。全部729个有序三元组检查结合律；倍数 $`0,1,2,3`$ 给出324次分配检查。相加及倍乘的输出可以超过输入上界，不会被截断。

## 三 有限观察、允许的策略与有条件的一致预测

### 3.1 现代定义

设 $`S`$ 为有限具名刺激域，$`B`$ 为非空有限响应集合，$`H\subseteq B^S`$ 为明确允许的完整确定性策略类。观察为部分函数 $`o:D\to B`$，其中 $`D\subseteq S`$。版本空间为：

```math
V(o)=\{h\in H:\ \forall s\in D,\ h(s)=o(s)\}.
```

查询刺激 $`q`$ 的可能预测集合为 $`\{h(q):h\in V(o)\}`$。恰好一个可能响应表示一致；多个可能响应表示尚未确定。空版本空间单独报告，不算空泛的一致预测。

重复的相同观察不会增加约束。同一刺激的矛盾输出会被拒绝，因为它违反当前模型的确定性假设。策略与观察都不得越出指定刺激和响应域。允许空观察、空候选类；刺激域为空而响应集合非空时，恰有一张完整空表。

须区分数学定义与接口验证：上面的 $`o`$ 已经是无矛盾的部分函数。若把任意记录列表直接代入“满足每条记录”的约束，矛盾记录在数学上会产生空版本空间；本接口选择在筛选前拒绝这种非法输入。合法且无矛盾的记录仍可能与受限制的候选类不相容，此时接口正常返回 `empty_version_space`。

数学计数中的策略按外延函数区分，即完整输入输出表不同才是不同函数。接口还允许保留名字不同、输出表相同的候选描述，用来展示行为无法区分实现；这类重复描述不会增加可能预测，不能算作不同外延函数。`enumerate_policies` 的输出不含重复表，以下全部函数计数均使用这个不重复口径。

### 3.2 一般论证，和有限测试分开

对任意允许的策略类，只要版本空间非空，给定观察与假设所能保证的响应，恰好对应预测集合为单元素的情形。这里的假设是：真实策略属于允许的策略类，而且观察无误。

充分性：真实策略必定仍在版本空间中；既然所有相容策略都给同一响应，它也给这一响应。必要性：如果有两个相容策略在查询处不同，两者都仍符合假设与已有观察；任何单一答案至少在一个允许情形中失败。这是有条件的保证，并不意味着已经从数据无条件发现了真实策略类。

若允许全部策略，即 $`H=B^S`$，记 $`|B|=b`$、$`|S|=n`$、$`|D|=d`$。每个未见刺激可独立选择任一响应，所以 $`|V(o)|=b^{n-d}`$。若 $`b\ge2`$ 且 $`q\in S\setminus D`$，在查询处取两个不同响应，分别扩充已见表，就得到两个解释全部观察但在查询处不同的策略。因此观察本身不能迫使该预测唯一。受限制的候选类可以得到唯一预测，但结论此时还依赖这个限制。

这是一条关于所选有限行为模型的可识别性结论，不证明被观察者拥有或缺乏某种心理能力。即使观察完整表，也只确定指定有限域上的行为；不同内部机制可能实现同一张表。代码明确测试：名字不同而完整行为相同的两个策略，仍不能靠这些观察区分。

### 3.3 可以手算的合成例子

刺激为 `white_circle`、`white_square`、`blue_circle` 与 `blue_square`。响应标签使用字符串 `"0"`、`"1"`。观察白圆输出1、蓝圆输出0。

1. 一般颜色规则对白卡输出1、蓝卡输出0，因此对未见白方预测1。
2. 查表候选记住两项观察，对其余刺激默认输出0，因此对白方预测0。
3. 两者解释全部观察。16张不受限的完整策略表中，恰有四张相容，因为两张方卡的响应都未观察。
4. 若事先只允许颜色规则，白方预测就一致为1；该一致性有赖于候选限制。
5. 再观察白方输出1，可以区分上面两个具名候选。但若允许全部16张表，仍留下两张，因为蓝方尚未观察。这不证明唯一内部机制，也不保证未建模的更大域上具有同样能力。

原章对心灵操作及其能力归属的讨论，启发我们提出这个问题。模型中的逻辑审慎属于现代批判性伴读，不背书历史群体划分，也不声称已经检验那些划分。

### 3.4 有限核验范围

对刺激数 $`0,1,2,3`$ 与两个响应标签，枚举每张可能的真实表和每个已观察子集，共85种真实表／观察子集情形，以及228项逐点预测检查。候选数与预测集合对照上面独立的自由坐标计数论证。另有单元测试覆盖受限类、空类、矛盾输入与完整行为等价。

## 边界与解释纪律

- 有限表示及允许的策略是人为给定的输入，不是学习得到或从历史中复原的机制。
- 所有域与表均明确给出。穷举在这里便宜，是因为教学域很小；独立布尔位置增加时，枚举量呈指数增长。
- 一般证明说明在什么假设下数学结论成立，运行日志说明本实现真正执行了什么。两者都不是关于心灵的经验证据。
- 没有使用个人数据、医疗记录、动物行为数据或私人来源。
- 合成输出不支持速度、准确率、样本效率或历史优先权方面的额外主张。
