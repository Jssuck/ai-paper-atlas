# I.36：保留关系槽位的最小教学核验

这是原创现代教学程序，不是希腊语解析器、古代三段论完整实现或对原典唯一语义的认证。正文见[本章深读](../../papers/ancient/aristotle-prior-analytics-i36.zh-CN.md)。源材料为Owen1853印160末–162第36章；原文区分直述与斜格表达，本附件以显式二元关系演示该区别，不声称原作者采用集合语义或存在量词。

## 模型和输入

非空有限论域 $`U`$；原子项解释为 $`U`$ 的任意子集（允许空项），关系 $`R\subseteq U\times U`$，有序对 $`R(u,x)`$ 的第一槽是来源，第二槽是对象。定义现代存在投影：

$$
E_R(P)=\lbrace x\in U:\exists u\in U\;(u\in P\land R(u,x))\rbrace.
$$

例如来源是某种学问、对象是善时，$`E_R(Science)`$ 表示“有某门科学研究它”的对象，不是科学自身；这不重构原文“一门科学研究相反者”的共同性／唯一性主张。固定关系与槽位之后才可把投影当作一元类。

Python表达式用 `('atom','P')` 和 `('some','of',('atom','P'))`；后者可嵌套。`member/notmember` 是带具体对象的事实，`subset/disjoint/not_subset` 是类间断言，`edge` 保留有序关系。所有名称是非空ASCII字母数字／下划线字符串。该名称限制只为小程序输入规范，不是古代项理论。

## 受限证书规则

|规则|两项输入|输出|
|---|---|---|
|project|$`u\in P`$；$`R(u,x)`$|$`x\in E_R(P)`$|
|instantiate|$`P\subseteq Q`$；$`x\in P`$|$`x\in Q`$|
|transitive|$`P\subseteq Q`$；$`Q\subseteq G`$|$`P\subseteq G`$|
|exclude|$`P\cap Q=\varnothing`$；$`x\in P`$|$`x\notin Q`$|
|difference|$`x\in P`$；$`x\notin Q`$|$`P\nsubseteq Q`$|

`check`逐步检查规则名、准确表达式、相同见证及只指向先前事实的整数引用；布尔值不能冒充整数引用。每步必须恰好有`rule/refs/conclusion`三个字段，结论由规则独立算出并与声明比对。它**信任给定前提**，不核历史真实性，也不保证前提相容；拒绝一个证书不等于否定其结论在任何系统都可证。规则只支持表列顺序，不自动交换输入，也不是完备搜索器。

“善有一个属”可用 $`E_R(Genus)`$，“善本身是属”可用 $`Genus`$；这两个目标只能由不同的包含前提得到。快乐／生成、笑／标记的负例，要先明确统一的投影和排斥前提。神的例子在本模型仅用于“某对象在一类而不在另一类”的差集见证：它不能推出两类完全不交。以上均是教学解释，不把古例的哲学前提当作本程序已证事实。

## 文件与命令

- [model.py](model.py)：表达式、模型、五条规则及证书检查器。
- [test_model.py](test_model.py)：13项单元测试，覆盖正常规则、伪造结论、错见证、反向／越界／布尔引用、格式、缺失解释及空类。
- [verify.py](verify.py)：另一套直接量词oracle，不调用`Model.extension/true`来计算期望值；枚举并对照模型语义、规则实例与五个故意错误的反模型。
- [run_checks.py](run_checks.py)：保存真实环境和正常、`-O`、`-OO`三模式完整命令输出；任一步非零即停止。

需要Python3.10或更新版本，仅标准库；无网络、密钥、付费服务、第三方依赖。进入本目录执行：

```sh
python3 -m unittest -v
python3 verify.py
python3 run_checks.py
```

最后一条会更新`logs/`；这是本地运行证据，不是静态预填结果。当前真实记录：[环境](logs/environment.json)、[正常](logs/normal.txt)、[优化](logs/optimized.txt)、[双优化](logs/double-optimized.txt)。

## 实跑结果与边界

本次三模式均13项测试通过、所有命令退出码0。固定两个命名对象、三个任意原子类、一个任意二元关系，总计 $`4^3\times16=1024`$ 个解释；共139264次语义对照。真前提规则实例数：project6336、instantiate18240、transitive98604、exclude10176、difference13248，全部结论在独立oracle下为真。枚举使用三个原子及各自的一层投影；project输出可能是二层投影，但未穷举任意深度语法或更大论域。模型数含有空类解释，不等于1024个历史例子。

五个反模型分别展示：存在投影不等于原类、有序关系不必对称、逐对象见证不必是统一见证、非包含不等于不交、“有一个属”不等于“是属”。前两项可用 $`U=\lbrace a,b\rbrace`$、$`P=\lbrace a\rbrace`$、$`R=\lbrace(a,b)\rbrace`$；量词交换反例用对角关系；非包含但相交用 $`P=U,Q=\lbrace b\rbrace`$。这都是自设的小模型，不是原文具体对象的经验事实。

有限检查不是五条规则的一般证明，更不能证明亚里士多德全理论、自然语言归约完备性或历史解释唯一性。一般保真性需逐规则证明：存在引入保留同一见证；包含实例化／传递逐元素；排斥消去使用同一元素；非包含只需一个差集见证。正文承担这些推导。本附件oracle与实现虽分离，仍由本次作者编写，应另由独立审查者核查。
