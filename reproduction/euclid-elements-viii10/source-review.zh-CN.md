# VIII.10 原文与版本核查

- [Clay 希腊文与英译](https://www.claymath.org/library/historical/euclid/files/elem.8.10.html)：希腊文在第二次使用 C:D 时将表示单位的 `μονὰς` 置于方括号，Fitzpatrick 英栏相应作带括号的 `unit`。这不改变 C 的身份，前文已经设 C 为单位。Clay 英文保留至 A、K、L、B 连续成比例，未显示原文随后重述中项数的结语及证毕语；不能据此推断古本缺文。
- [Heath 1908 年英译第二卷](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)，印本 360–362 页（所核 PDF 第 373–375 页）：360 页陈述，361 页设定、图及前半证明，362 页余文及编者的幂式说明。Heath 特别辨明，原文说同理可得 H:G=D:F，此处实际用的是 VII.18，而非上一句用于 E:H=D:F 的 VII.17。
- [Fitzpatrick 希英对照](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)，印本 237–239 页：237 页陈述及设定，238 页图与英文证明全部，希腊证毕语的最后一字续至 239 页。希腊 Α、Β、Γ、Δ、Ε、Ζ、Η、Θ、Κ、Λ 对应英文 A、B、C、D、E、F、G、H、K、L。文中的比例定理编号为英译的编辑标注，不是希腊正文自注。
- [Joyce 释读版](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII10.html)保存完整构造，其题句开头略去了“各自”，但后半句、正文及导读仍明确分别对两个端点用单位链，而非一条同时包含三者的链。

## 原证对应与范围

同一个单位 C 在两列重复画出。以现代数值表示，已知链按位置是 C、D、E、A 和 C、F、G、B。图中的额外量 H、K、L 对应 DF、DH、FH；H 是辅助量，不能错作 A、B 之间的中项。由重复量度和 VII.Def.20，E=D²、A=D³、G=F²、B=F³。先得 E:H=D:F（VII.17，固定乘者 D），再得 H:G=D:F（VII.18，固定被乘数 F）；继而按 VII.17、VII.18、VII.17 分别传到 A:K、K:L、L:B。三对的前项比后项都是 D:F；若改说后项除以前项的现代公比，则是 F/D。

原文在图上取各有两个中项的两条单位链；一般陈述要求各自在单位和端点之间有同样数目的中项，才配对反向取项相乘。无须互素条件；从 VIII.9 的结论回推到存在原列可以援引 VIII.10，但不能由此回推 VIII.9 的互素前提。Joyce 以平方、立方说明紧邻命题的专题关系，这不等于已经核实其正文直接引 VIII.10，也不推出各命题的独立成文时间。
