# VIII.10：从两条单位链拼出混合比例链

现代整数教学重构，不是古代实跑记录或一般命题的计算证明。输入两条从 1 开始、长度相同的正整数等比链，至少各有一个中项。令第一、第二链的增长倍数分别为 a、b，用第一链倒序、第二链正序逐项相乘：第 i 项含 n−i 个 a、i 个 b，得到从 a 的 n 次幂到 b 的 n 次幂的整数链，相邻增长比为 b/a。

以 a=4、b=6、n=3 为例，输入 (1,4,16,64)、(1,6,36,216)，输出 (64,96,144,216)，端点公度为 8，不要求互素。换序结果正好反向。默认要求两增长倍数大于 1 且端点不等；现代模式显式包括单位底数及相等端点，属于程序模型的范围选择。输入链长度不同、起点并非单位或不恒比均拒绝。

独立测试从首端开始用 Fraction 逐次乘增长比，不使用倒序逐项相乘来作对照。另检查端点最大公度和非法输入。
