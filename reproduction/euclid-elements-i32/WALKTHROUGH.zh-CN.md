# I.32 的精确角对：教学重构与实跑边界

## 1. 不计算反三角函数

对非零向量 u、v，普通无向角属于[0,π]。记录角对 `(u·v, |det(u,v)|)`，其正比例方向表示 `(cosθ,sinθ)`；比例是两向量长度之积，始终为正。比较两个角对是否正比例即可比较角度，不必求平方根。

两个角对按复数乘法相乘，即 `(x,y)*(r,s)=(xr−ys,xs+yr)`，表示角和的正比例方向。所有坐标为分数，点积、行列式和乘法均精确。必须解释角的范围，不能仅凭乘积负实数就无条件宣称角和等于π：一般角度还能差整周。

## 2. 为什么这里排除整周歧义

三角形非共线，三个内角各严格在0与π之间。CE严格在ACD内部，所以两分角之和就是该外角，不发生绕行。两迁移角之和在0与2π之间，外角在0与π之间；若角对正比例，它们不可能相差2π，只能相等。

三个内角和在0与3π之间。乘积是负实数代表模2π等于π，在该开区间内只有π，不包括端点3π。代码显式检查非退化及正方向，数学上的区间理由在此说明，不把分数乘法本身当成全部几何证明。

## 3. 手算

取A=(0,1)、B=(0,0)、C=(2,0)、D=(4,0)、E=(2,1)。CD=BC，CE=BA；CA=(-2,1)，CE=(0,1)，CD=(2,0)。CA到CD的外角内含CE。

三个内角的角对依次为 A:(1,2)、B:(0,2)、C:(4,2)。两分角ACE:(1,2)、ECD:(0,2)，外角ACD:(−4,2)。于是：

- A与B的乘积为(−4,2)，恰是外角角对。
- 再乘C得到(−20,0)，为负实数。
- 同时两分角的位置和角度迁移通过检查。

## 4. 方向反例与证书反例

只把E改成(2,−1)，CE所在直线仍平行AB，却向下而不在外角内。不能只检查行列式为零就接受；构造函数直接拒绝其负比例。把D改为(1,0)，它在线BC上却不在越过C的延长方向，也直接拒绝。

把正确证书借给A=(0,2)的新输入，即便新输入也有自己的合法见证，旧证书仍不能通过完整输入绑定。改变证书中的布尔值为整数1、schema为True、任一乘积或添加字段也拒绝。JSON严格类型比较避免Python中True==1的漏洞。
