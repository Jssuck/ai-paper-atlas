# 《几何原本》VI.7：为什么要区分锐角支与非锐角支？

对应[中文深读](../../papers/ancient/euclid-elements-vi7.zh-CN.md)。这是现代有理坐标教学模型，不是尺规证明的机器复原，也不是原命题证明的替代品。

## 模型与证据

把给定的角放在 A，把 B 放在横轴正半轴，固定 C 所在射线。因为 AB 已固定，AB:BC 给出一条以 B 为心的圆。C 必须是射线与圆的交点，且射线参数严格为正。二次式直接对照这种可能性：两正根关于投影参数对称；靠近 A 的交点对应钝角 C，远处交点对应锐角 C；相切点只有一根，对应直角 C。如果投影在反向延长线上，切根无效；若半径恰为 AB，零根也不算三角形。

程序通过判别式和根的和、积判断根数，不近似求根。另算有理坐标给出的三个无向角余切（点积除以行列式绝对值）、三个边长平方以及它们是否同比。这两种计算互作核对，但不是彼此独立的数学证明。平移、旋转、正比例缩放和反射用有理变换生成；不能借有限样本断言所有实坐标的输出。

反例取 A=(3,0)、B=(0,0)、C=(1,2) 或 C′=(2,1)。A 角均为 45°，AB²=9、BC²=5 不变，AC² 却从 8 到 2。C 角余切分别为 1/3 和 −1/3，表明分支条件失效。正例是同支缩放；直角用 A=(0,0)、B=(4,0)、C=(2,2)。固定同一射线方向，若 BC²=4，则无交点，不能声称得到一个非锐角三角形。

## 实跑

Python 3.12.14 标准库即可。在本目录执行：

```sh
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B replay_notebook.py
```

[普通](normal.log)、[-O](O.log)、[-OO](OO.log) 各有八项通过。扫掠用三个底长、四条射线、七个投影倍数、三个缩放倍率、两种取向，生成 504 个同支比较（含 72 个直角比较），另由配对根产生 432 个异支比较；另检验 12 个判别式为负的参数输入。专项测试还覆盖零根排除、仅一正根和退化输入。

[Notebook](euclid-vi7.ipynb) 有三个代码格，使用共享命名空间由标准库顺序编译执行，见[回放日志](notebook-replay.log)。不是 Jupyter 内核运行；Notebook 保留未执行状态，便于读者重跑。
