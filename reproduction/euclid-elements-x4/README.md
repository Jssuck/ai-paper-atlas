# 《几何原本》X.4：三个量的最大公度量

`greatest_common_measure(a,b,c)` 接受三个正有理量。先求前两量的最大公度量 $`d`$。若 $`d`$ 度量第三量，直接返回 $`d`$；否则再求 $`d`$ 与第三量的最大公度量。返回对象保留第一次结果、最终结果、分支及三个度量次数。因为任意公度量必度量 $`d`$，第二次计算不会遗漏原来的共同度量。

例如 $`(21/10,9/10,6/10)`$ 直接保留 $`d=3/10`$，而将末项换成 $`4/10`$ 则需第二次计算，得到 $`1/10`$。$`(6,10,15)`$ 每一对都有非单位公因子，但三者只有单位公因子；六种排列会改变中间量，不改变最终结果。程序只接受整数与精确分数，不是一般实量的判定器。

在此目录运行，使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线将三个量通分，再枚举到最小整数坐标的所有候选因子。输入由分子 1 至 8、分母 1 至 3 生成，去重后组成有序三元组。有限核验不替代一般证明。Notebook 日志来自标准库实跑三个代码单元，不是 Jupyter 内核运行。
