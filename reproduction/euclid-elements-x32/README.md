# 《几何原本》X.32：中项矩形的无理面积与差平方类别

令 `a,b,c` 为 `A,B,C` 相对于同一参考长度 `u` 的平方。函数 `construct(a,b,c)` 要求三项正有理、`a>c` 且三对平方比都不是有理平方。根据 `D²=AB` 和 `D:E=A:C`，计算 `D,E` 的相对四次幂 `ab,bc²/a`，矩形相对面积的平方 `bc`，以及输出边比的平方 `k=c/a`。归一化差平方为 `1−k`，它与输入对 `A,C` 的归一化差平方相同。检查它是否为有理平方，就能报告差平方的边与所在对较长边是否长度可公度。两个比较各用自身的较长边；不是直接比较输入与输出的差平方边。

例如 `(25,3,21)` 的差平方比为 `4/25`（有理平方），`(2,3,1)` 的差平方比为 `1/2`（非有理平方）。两组输出矩形的面积都与参考平方不可公度，但这和差平方边的分类不同。模型保持精确分数，不近似根式，也不模拟尺规操作。

独立整数基线不调用整数开根：`ab,ac,bc` 是否为整数平方可判定各自输入比的有理平方性，`a(a−c)` 是否为整数平方可判定差平方比的有理平方性。乘入的尺度均为整数平方。在三项都取 1–16 的 4,096 个有序三元组中，86 个有效且差平方边长度可公度，1,282 个有效但不可公度，2,728 个不满足前提。有限校验不能代替一般性证明。
