## 发现并修正的实质问题

初稿称把“等积”误译为“全等”会使 I.39 成为错误且更强的命题。由于这里等积是**前提**，改为全等会强化前提、缩窄适用范围，所得定理仍为真；真正错误的是由等积反推全等。已向作者反馈，终稿第 7 节准确区分。来源审查者亦独立发现这一点。复现核心未发现需修复的正确性漏洞，未改动其源码。

## 数学核验

1. I.31 保证过 A 的平行线存在，I.37 给出中介三角形 EBC 与 ABC 等积；题设与共同概念 1 推出 EBC 与 DBC 等积。此链没有使用本命题或后章比例公式作为前提。
2. BD 与辅助平行线相交及交点在正射线 BD 上需要欧氏相交/点序背景；正文已标为教学补显而非古文逐字内容。现代参数 a/d 同号为正另作模型解释，不替代原证。
3. E 在线段 BD 内时 EBC 为 DBC 真部分；E 在 D 外时相反。C 不在 BD 上保证余片非退化，严格大小与等积确实矛盾。E=D 则辅助线通过 A、D，直接给出平行。
4. E=A 不破坏构造比较，辅助线用 m 或 A+λ(C−B) 命名；A=D 则目标直线 AD 无定义。代码和正文正确区分。A=D 的支持线版本仍成立，接口拒绝不是对古命题的反例。
5. 同侧是从绝对面积相等得到有向面积相等的必要附加信息。正文异侧反例面积均 6、AD 过自身中点 (3,0)，而非 BC 中点，计算正确。
6. 有向二倍面积 a、d，求交参数 t=a/d、行列式 d−a 均正确。零底、零高、零方向的排除明确；正例与非等积反证分支没有混计。
7. 正文手算表、非全等边长平方、练习答案一致。有限程序结果不被用来证明一般几何定理。

## 输入与证书信任边界

输入精确类型检查拒绝 bool 与 int 子类、float、NaN、非规范有理字符串等；坐标只接受严格整数或规范字符串。证书只含字符串/list/object，完整规范化输入和全部派生字段重新生成后比较，因此避免 Python `True == 1` 型漏洞，并拒绝未知/漏失字段。整数 `1` 与规范字符串 `"1"` 有意表示同一坐标；它不是输入原始文本的数字签名。

这些是有限测试与代码审读支持的实现结论，不保证任意资源耗尽攻击均被抵御，不证明所有 Python 对象上的安全性，也不替代一般定理或完整几何公理化。核验器重算同一模型，不是独立证明内核；独立脚本增加不同生成方式和预期计算，仍不改变这一限制。
