# II.20：三段论成立不等于反驳了指定论题

这是《前分析篇》II.20 的**现代集合语义教学重构**，不是古代程序、辩论行为实验或历史语义的完整复现。原文：[Jenkinson 1913 英译，Book II 第 20 节](https://en.wikisource.org/wiki/The_Works_of_Aristotle/Prior_Analytics/Book_II)。章内讨论反驳与三段论的关系、肯定与混合前提的可能性、全否定及无全称前提的限制；版本及证据位置见[中文深读](../../papers/ancient/aristotle-prior-analytics-ii20.zh-CN.md)。

## 范围与符号

三个不同词项 S、M、P 分别是小项、中项、大项；结论和待反驳论题均以 S 为主词、P 为谓词。A 为“所有 S 是 P”，E 为“没有 S 是 P”，I 为“有 S 是 P”，O 为“有 S 不是 P”。默认令三个词项都非空，作为本实验明确选定的存在预设；这不是宣称古代所有语境都使用同一存在解释。

三格的 `(主词,谓词)` 前提位置：

| 格 | 大前提 | 小前提 |
|---|---|---|
| 1 | M,P | S,M |
| 2 | P,M | S,M |
| 3 | M,P | M,S |

`mood="EAE"` 的前三个字母依次指定大前提、小前提、结论类型。四个类型的所有组合给出每格 64 个候选，共 192 个；不是 192 个有效式。不包括第四格、模态、关系谓词、重合词项、任意数量前提或整个辩论系统。

## 七种成员类型与一般解释

一个对象是否属于 S、M、P 可以用三位编码；代码规定 S=1、M=2、P=4。类型 3 表示属于 S 和 M 而不属于 P。A/E/I/O 只关心相关成员类型是否有对象，不关心数量。000 类型不影响这些公式，故只枚举 1 至 7 各类型是否占用，共 128 种支持集；其中 109 种使每个词项非空。空支持集不强迫论域空：可以令论域含一个 000 对象。默认的非空词项筛选不允许该模型。

这个表示法有一个**限制在本模型内的一般证明**：任意集合解释按三词成员关系分为八类，每个非空的相关类型留一个代表即可保留所有 A/E/I/O 真值；反向则每个占用类型设置一个对象。因此对于这里固定的三词直言语法，支持集覆盖所有相关真值配置。此论证解释枚举范围为何足够，不把有限测试本身当作一般逻辑定理或古代语义的证明。

A 与 O、E 与 I 才是精确矛盾对；即使允许空项，它们的真值也始终相反。A 与 E 并非精确矛盾：主词空时可以同真，主词兼有 P 和非 P 成员时可以同假。

`check` 返回前提模型数量、有效性、反模型数量及首个反模型。`refutes(f,premises,thesis)` **不把 thesis 加入前提**，而是检测原有两前提是否蕴涵 thesis 的精确矛盾式。它不把任何与论题无关的有效结论标成反驳，也不检测对方是否真正接受了这些前提、是否发生歧义等实际辩论条件。

## 一般推导和反模型

- AAA 第一格：任取 S 中对象，由 S⊆M 与 M⊆P 可知它属于 P，所以 S⊆P。它反驳 O 型论题，却不是对 A 型论题的反驳。
- EAE 第一格：任取 S 中对象，由 S⊆M 与 M∩P=∅ 可知它不属于 P，故 S∩P=∅，反驳 I 型论题。
- “两前提都肯定”不充分：AAA 第二格只给 P⊆M、S⊆M。令 S={x}、M={x,y}、P={y}，两前提真而 S⊆P 假。程序编码这个模型为 `[3,6]`。
- 存在预设会改变结果：AAI 第三格在 M 非空时，取 M 中对象便得到同时属于 S 和 P 的见证；允许 M 空时此步不成立。程序中允许空项后确有反模型。不能无说明混用两种解释。

“两负”指两个前提类型都在 E/O 中，“两特称”指都在 I/O 中；不是把受问者的沉默、拒答或不合作翻译成某个集合事实。下述枚举只检验固定三格和范围，原文论证仍须结合它调用的三段论理论阅读。

## 实际运行与证据

仅用 Python 标准库，无第三方安装。命令：

```sh
cd reproduction/aristotle-prior-analytics-ii20
sh run.sh
sha256sum -c SHA256SUMS
```

`run.sh` 分别运行正常、`-O`、`-OO` 的 `unittest` 与主程序，逐字比较三个 JSON。所有检查使用 `unittest` 方法或显式异常，不依赖会被优化移除的裸 `assert`。运行环境见 `results/environment.txt`；原始日志为 `results/tests-{normal,O,OO}.log`，结果为 `results/output-{normal,O,OO}.json`，比较证据见 `results/verification.txt`。重新运行耗时会变，测试日志的哈希可能因此改变。

已真实完成三模式各 8 个测试方法：128 支持集的计数和 109 非空词项筛选、集合运算真值交叉检查（128×6 有向词对×4 类型=3072 次）、矛盾对检查、有效式清单、两负/两特称限制、174 个返回反模型的证书验证、论题与存在边界、非法输入。

| 检查 | 实跑结果 |
|---|---|
| 总候选 | 192 |
| 有效 | 18，每格 6；包括全称结论的特称弱化 |
| 无效并返回反模型 | 174 |
| 两负前提候选 | 48，全部无效 |
| 两特称前提候选 | 48，全部无效 |
| AAA 第一格 | 有效；4 个前提模型 |
| EAE 第一格 | 有效；2 个前提模型 |
| AAA 第二格 | 无效；10 个前提模型中 6 个反模型 |
| AA 第一格反驳 O / 反驳 A | 前者成立，后者不成立 |
| AAI 第三格 | 三词非空时有效；允许空项时无效 |

两负与两特称的候选集合在 OO 前提处重叠，不能把 48+48 当作 96 个不同候选。18 也不是“历史标准式总数”的宣称：统计口径包括弱化结论且只取三格。

## 复盘

本实验分开三个问题：前提有没有满足模型、前提是否蕴涵指定结论、该结论是否否定了指定论题。此处所有 48 组“格＋两前提类型”均可满足，所以有效结果不是从矛盾前提空洞推出。有限支持集模型无从检验心理接受、语言歧义、论题身份漂移，或现代 AI 系统的可靠性；这些不是本次实跑的结论。
