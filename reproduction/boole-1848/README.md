# Boole 1848：选择函数的现代教学模型

这组代码是针对《The Calculus of Logic》的**原创现代重构**，不是布尔的程序，不是对全部历史逻辑体系或心理学主张的复现。只使用 Python 标准库。原文与版本问题见[正文](../../papers/1848/boole-calculus-logic.zh-CN.md)；这里不附原刊 PDF 或全文翻译。

## 怎样运行

在本目录运行：

```sh
python run_checks.py
```

它依次执行六条命令，保存各次真实 stdout/stderr 和退出码：

```sh
python test_model.py
python demo.py
python -O test_model.py
python -O demo.py
python -OO test_model.py
python -OO demo.py
```

测试使用 `unittest` 方法而不是可被 `-O` 删除的裸 `assert`。运行器在失败时非零退出；完整环境、UTC 时间、输入 SHA-256、命令、日志散列在 [run-manifest.json](logs/run-manifest.json)。演示 JSON 的三模式字节一致性另作检查，不拿它代替测试。无第三方库、Notebook、Jupyter 内核、证明助手或 CI 通过声明。

## 文件

## 模型约定与边界

1. 论域是有限整数集合；每个类是其子集。函数对单个对象的 0/1 成员值作精确有理运算。允许空类，测试也包含空论域这个软件边界；这不认定历史作者允许空论域。
2. 乘法对应交集，`1-x` 对应补集。普通加法不是一般集合并；只有相加类互斥时才直接对应并。代码不会把 `1+1` 改成 `1`。
3. 成分表描述每种成员类型的系数。方程要求**逐对象**为零，不是全论域求和为零。不同对象上的正负值不能抵消。
4. 输出变量通过两个端点是否为零来选择。`0/0` 不作为 Python 数运算；它只提示两种成员状态都容许。两端都非零则该输入类型不得有对象。
5. 一个“任意类”可以在同一输入成分内部选一部分对象；不能简化成每个成分统一选择一个常数位。
6. `Y = V ∩ X` 中固定的 V 受到方程约束。“存在合适 V”与“所有 V 都可用”不同。特称命题还需非空见证，仅有两个选择结果相等并不够。
7. `solve_last_class` 枚举所有有限输出子集，最坏指数规模，只用于透明教学。一般证明在走查中，不由有限测试代替。
8. 本代码未实现原文全部三段论规则分类、任意自然语言翻译、假言逻辑的完整系统、全部历史勘误判断或人类认知实验。

## 实际覆盖

每种优化模式有 22 个测试方法。它们检查：

- 0 至 3 个对象上，共 85 对 X/Y 的恒等例；船舶例也有 85 对固定 X/Y，直接逐个检查的候选 Z 共 585 个。
- 81 个二元有理值表的成分展开；通用求解另用 81 个取值为 −1/0/1 的二元表，在二对象论域逐一与直接求值对照。
- 36 对有理端点，包括相同非零值、异号值和分数；不使用浮点近似。
- 85 对固定 V/Y 的补类参数解，空类/非空见证、逆否与条件式。
- Ex.3 直接消元：16 个成员比特配置，以及二对象论域 256 组 V/V′/X/Z。裸消元等式不足，加入 X⊆V 与 Z⊆V′ 后，才与“存在 Y 满足两原方程”的投影一致。

这些是限定输入族上的执行结果，不是“穷尽历史逻辑”、证明程序无缺陷或一般定理的实验认证。
