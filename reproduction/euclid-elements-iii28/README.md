# 《几何原本》III.28：两条弧的教学复现

**对象：** 两个同半径的圆，各给一条弦，由弦端点分别得到两条圆弧。普通弦按短对短、长对长配对；直径对应两条半圆，不再区分严格的大小。本目录是现代坐标教学，不是原文复跑，也没有用有限样本代替证明。

## 文件与运行

- [chords.py](chords.py)：从圆心及两端点计算弦和弧；生成等弦样本和不等半径反例。
- [test_chords.py](test_chords.py)：几何精确量、端点扫角、弧折线、错配、不等半径、直径、非法端点共七个测试。
- [euclid-iii28.ipynb](euclid-iii28.ipynb)：依次演示等弦、折线估计、反例和边界。可在本地 Notebook 前端从头运行。
- [replay_notebook.py](replay_notebook.py)：不依赖 Jupyter，把 Notebook 的纯 Python 单元按顺序在同一命名空间编译、运行；不验证 Jupyter 内核、前端或 Notebook 渲染。

在本目录使用 Python 3.9 或更高版本（仅标准库，无外部数据）：

```sh
python -B -m unittest -v
python -B -O -m unittest -v
python -B -OO -m unittest -v
python -B replay_notebook.py
```

实跑见 [常规](normal.log)、[`-O`](O.log)、[`-OO`](OO.log)、[Notebook 单元回放](notebook-replay.log)。没有安装或启动 Jupyter；回放日志不冒充 Jupyter 执行。

## 数据、比较路径与局限

- 用有理参数生成精确圆上点。每个网格有 3 种半径 × 20 种参数 × 13 种第二弦旋转 × 2 种镜像方向 = 1,560 对；第二圆平移且其弦端点顺序反向。两个网格测试**重复检查同一批配对**。对照检查是各自端点的弦长平方、圆心到弦中点距离平方和余弦恒等式，运算使用有理数而非浮点容差。
- 弧的比较另从各自原始端点相对圆心的极角差求扫角，不拿同一个弦长换算结果分别赋给两边。再以弦长平方给出的余弦关系作交叉检查，角和余弦在对应测试里采用绝对误差阈值 `3e-14`。半径相同时，可由扫角比较相应弧长；另对一组弦的两条实际路径，比较 8、32、128 段内接折线的数值收敛。折线没有被当作弧长的精确值。
- 误配测试把一条短弧与另一条长弧比较；两条弧在该例中明显不同。跨圆反例用半径 13、15，圆心均置于原点，端点分别取 `(5, ±12)` 和 `(9, ±12)`；弦长都为 24，但短短、长长的弧长都不同。
- 生成方式有意只给出有限的、按构造全等的样本。测试比较的是两条计算路径，既不验证合成几何的公设，也不独立证明一般命题。不覆盖任意坐标尺度、浮点极端条件或极近于重合或对径的非退化弦。直径用精确条件识别，扫角并列为 π，只是此现代模型对退化分类的明确约定。
