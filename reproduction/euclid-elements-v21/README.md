# V.21 教学复现：错配相邻比，比较首尾量

[中文精读](../../papers/ancient/euclid-elements-v21.zh-CN.md) · [源码](ratio_chains.py) · [测试](test_ratio_chains.py) · [Notebook](euclid-v21.ipynb)

给定两组三量 `(A,B,C)`、`(D,E,F)`，先核验 V.21 的错序对应：`A:B = E:F`、`B:C = D:E`。比较左端点 `A,C` 的大小，等价于比较同后项的 `A:B, C:B`。第二组比例两边同时取倒比，所以右侧对应比较的是同前项的 `E:F, E:D`。若第一个比更大，它的后项 `F` 反而较小；输出的是 `D` 对 `F` 的次序，不是 `F` 对 `D` 的次序。程序把三种情形统一为三向比较，是用正有理数商重构，不是对原文省写分支的翻译，也不把相邻比相乘。

同组量须同类并采用统一单位；`kind` 检查量类，不换算单位。两组可以跨量类，例如左为长度 `(6,4,3)`、右为面积 `(8,6,4)`。两组首尾均为大于；比例 `A:B` 对应 `E:F`，而不是 `D:E`。

- 右组改为 `(3,6,4)` 或 `(8,6,10)`，分别只保留第一对或第二对错序比例；两例中右组首尾均翻为小于。
- 右组若为 `(12,8,6)`，符合 V.20 的顺次配对而不符合 V.21。它不反驳 V.21 的首尾结论：在正有理数模型中，两种完整配对都使首尾比值相等，只是具体的边匹配条件不同。

## 重跑与结果

实跑环境：Python 3.12.14，只用标准库，不依赖历史数据或第三方软件。在本目录执行：

```sh
python -V
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B ratio_chains.py
python -B replay_notebook.py
```

[普通模式及示例](normal.log)、[-O](O.log)、[-OO](OO.log) 每种模式均通过 9 项测试。对 4,096 组构造的分数输入核查端点次序，小于、等于、大于分别为 1,792、512、1,792。另穷举每项取 1 到 5 的 15,625 个整数六元组，用独立的整数乘积条件 `A*F == B*E == C*D` 筛查：103 组通过，对比右端点的直接整数序；15,522 组违反前提，全部被拒。还检查单边缺失、量类混用、非正值及不精确输入。
