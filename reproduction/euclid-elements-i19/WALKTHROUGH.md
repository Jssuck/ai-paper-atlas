# I.19 逐步走查

## 1. 输入、符号和范围

A、B、C是有理坐标的非共线点。β表示ABC处的普通角，γ表示BCA处的普通角；`side_relation` 比较 AC² 与 AB²。由于长度正，平方保持大小。`angle_relation=1` 表示β较大，`0`相等，`-1`较小。角不带方向，反射图形不改变比较。

设 u=A−B，v=C−B，w=A−C，z=B−C。四向量非零且两个叉积均非零。对范围 (0,π) 的普通角，余切是严格递减函数，且可写为点积除以叉积绝对值。所以比较β、γ时，先比较 dot(u,v)/abs(cross(u,v)) 与 dot(w,z)/abs(cross(w,z))，再反转大小号。两个分母严格正，交叉相乘不会改变符号。这是现代角比较算法，并不是声称欧几里得使用了余切。

## 2. 3–4–5例的真实计算路径

取A=(0,0)，B=(3,0)，C=(0,4)。

- AB²=9，AC²=16。
- β的点积为9、叉积绝对值为12，因此余切3/4。
- γ的点积为16、叉积绝对值为12，因此余切4/3。
- 因3/4<4/3而余切递减，β>γ。
- 假设AC=AB，I.5要求β=γ，与严格题设冲突。
- 假设AC<AB，I.18在交换两边位置后要求β<γ，也冲突。
- 线段长的三分性排尽后仅剩AC>AB。

运行结果中记录完整输入、平方长度、点积、两种独立关系及排除依赖，见 `results-normal.json`。手算说明与实际输出分开保存；手算不是运行日志。

## 3. 不把结论偷偷写进输入

`angle_compare` 只读形成角的四个向量，不读边序结论。`inspect_triangle` 另算两条边平方，再记录一致性。可以用恒等式理解二者为何相容：令 A 为原点，B=b，C=c，β点积为 |b|²−b·c，γ点积为 |c|²−b·c。因此 γ点积−β点积=|c|²−|b|²；两个角的叉积绝对值相同。代码记录此恒等式的精确残差，有限网格测试核查其为零。

这条现代恒等式与原文证明不同：它借助欧氏内积，不是 I.5/I.18 的形式证明。证书重建只核查记录的一致性，不能作为独立于生成器的一般正确性证明。

## 4. 三分性为何必需

抽象表中，已知β>γ；相等边分支预测角相等，较短边分支预测角较小。删去两分支后，在全序表中只剩`greater`。若人为加入`incomparable`，它不由两条依赖排除，所以剩余两个分支。删去等长保等角规则时，`equal`也不能排除；删去反序保反角规则时，`less`也不能排除。

这展示“一个命题成立，因此逆命题自动成立”是错误推理。I.19成功依赖的不是形式取逆操作，而是相等支、反序支与三分排尽。有限关系表假定这些规则，不负责证明其几何真实性。

## 5. 负例与类型陷阱

共线、重复点、零角、平角被拒绝，因为不在本模型定义域；角相等或相反序的三角形可由`inspect_triangle`描述，但不能被`build_certificate`当成 I.19 的正题设。布尔坐标、浮点坐标、NaN、分母零、错误维数也被拒绝。

Python `True == 1` 为真，不能直接用字典相等认证有类型含义的证书。检查器限制为规定JSON类型后比较规范序列化文本，因此把schema的整数1改成布尔true或浮点1.0都失败；篡改预测、加入字段、删除字段、换输入亦失败。

## 6. 练习与答案

1. 把C换成(0,3)能否生成I.19证书？答：不能，β=γ，严格题设不成立；可观察等角等边。
2. 把C换成(0,2)而B仍为(3,0)如何？答：β<γ，AC<AB；交换B、C后才满足所选方向的题设。
3. 为什么不能直接把两点积平方再比较？答：钝角点积为负，平方丢失符号。这里先用带符号余切和正分母，直接有理比较，无此损失。
4. 精确运行87例是否证明全体三角形？答：否，任意域的一般论证需独立证明，有限案例仅核查实现与所选边界。
5. 全序表删去equal和less后得到greater，是否适用于任意偏序？答：否，不可比较支可能仍存在。
6. 独立重跑Notebook是否使用Jupyter kernel？答：本包没有。它是六个普通Python代码单元的共享命名空间compile/exec，元数据明确记载这一限制。
