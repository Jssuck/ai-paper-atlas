# I.19 独立技术核验

独立审查脚本 `check.py` 与被审生产代码分开撰写。命令、真实时间与退出码见 `commands.json`，标准输出/错误见各 `.log`。本目录不含研究PDF、私有信息或完整翻译。

## 实际执行

- 原有 unittest 在普通、`-O`、`-OO` 三模式各34测试通过。
- 独立生成330个平移有理三角形，直接用边平方和点积代数式检查排序；126个满足严格题设的构型产生有效证书。
- 1134次证书篡改或输入绑定负检查全部拒绝，覆盖布尔/整数混淆、浮点、字符串、缺失分支、边平方及结论改写。
- 400对普通角与独立 `atan2` 数值诊断一致；此诊断只在非共线离散方向使用，不是裁决器或一般证明。
- 168个有理构型核对正文7.1引理的交点参数：AC参数2t/(s+t)，EF延长参数2s/(s+t)，其中s>t>0。
- 8种抽象假设旗标组合的剩余候选表一致。
- 独立顺序执行Notebook六个代码格，标准输出/错误与已保存输出逐字匹配，不改写原Notebook。没有启动Jupyter kernel。

## 数学解释

普通非退化角的余切为点积除以叉积绝对值，分母严格正，余切在(0,π)严格递减，故交叉相乘后反转比较符号。三角形B角和C角两分母相等；两点积差与对边平方差恰相反。该恒等式提供现代坐标核查，不替代原证I.5、I.18及长度三分性。

证书重建是一致性检查，不是独立形式证明器。有限分支标签程序把历史依赖当明示假设；移除全序时保留不可比候选是教学反模型。有限测试和精确算术均不能证明一切古代或现代几何模型的有效性。
