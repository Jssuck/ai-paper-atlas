# IX.28 原典核对

- [Heath 1908 英译卷 II](https://www.wilbourhall.org/pdfs/Heath_Euclid_II.pdf#page=429)印页 416、扫描页 429，位于 IX.27 和 IX.29 之间，命题、三个数段和证明完整。A 中有多少单位，积 C 就由多少份 B 相加得到；先引 VII.定义 15，再引 IX.21。
- [Fitzpatrick 希英对照本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=273)印页 273 末为命题题句，印页 274 首从 Α、Β、Γ 三个数段起，给题设、证明和结语。两栏相同地以 A 为计数、B 为被重复的偶数。核对所列读本的相关页，未见需要另行应用的正式勘误。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.28.html)希文有 C 为偶和证毕；英栏截于援引 IX.21 的偶数和引理，没有列出随后单独的结论语。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX28.html)保留结语，导读也指出 A 为奇的假设未在证明中用到，即有限正个偶数相加无需检查项数奇偶。
- [VII.定义 15](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII15.html)明确乘法的重复加法方向，[IX.21](../../papers/ancient/euclid-elements-ix21.zh-CN.md)提供偶数求和结论；[VII.16](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII16.html)是调换两个因数时可用的另外一个命题，不是 IX.28 传世正文所引依据。Joyce 导读以 IX.31 对奇数的因子必为奇数作为后续用途；不把这种改写和本题的直接引证混为一谈。
