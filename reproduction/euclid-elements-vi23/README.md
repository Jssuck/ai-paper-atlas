# 《几何原本》VI.23：换一条边，再换另一条边

用正有理长度和坐标面积演示复合比。[中文精读](../../papers/ancient/euclid-elements-vi23.zh-CN.md)区分古代量比、面积中介及现代乘积表达。这里不形式化证明欧多克索斯比例论。

## 对照与限制

- 固定一条边水平、另一条边沿单位方向，以三组边长 (a,b)、(c,b)、(c,d) 分别构造 P、T、Q。用鞋带公式求面积，再以相邻边向量的行列式作对照。工作例单位方向为 (3/5,4/5)，边长为 (6,2)、(4,2)、(4,5)，三面积为 48/5、32/5、16。两步面积比为 3/2、2/5，首尾为 3/5。取 K=6 作得 L=4、M=10，代表的仍是相同两个比。
- 共 128 个面积配置：4 组第一边 × 4 组另一边 × 4 个基本单位方向 × 2 个纵坐标符号。每例用 5 个正首项验证 K:L:M，共 640 个比链。只以有理方向与有限边长测试正长度及非退化面积，不主张枚举全部角或任意不可通约量。
- 目标方向改为 (5/13,12/13) 时，边长不变而 P/Q 从 3/5 变为 13/25。若改为 (−3/5,4/5)，夹角成互补角但正弦相同，面积比仍是 3/5；这是现代的相同绝对正弦条件，不改写古命题的等角假设。若长度非正、方向不归一或两边平行，模型拒绝构造。
