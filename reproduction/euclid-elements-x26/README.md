# 《几何原本》X.26：中项面积差不可能是有理面积

取参考长度 `u>0`。较小面积相对于参考平方为 `√q`，其中 `q` 为正有理非平方数。假设面积差相对于参考平方是正有理数 `r`，再选取相对底边平方为 `b>0` 的有理底边。函数 `contradiction(q,r,b)` 将较大矩形的相对宽平方精确写为 `(q+r²)/b+(2r/b)√q`。第二项的系数严格为正，这与较大面积为中项面积时按 X.22 应得到有理的宽平方冲突。该函数输出符号证书，不枚举所有有理数或近似根式。

另一条现代校验路径 `difference_squared(p,q)` 接收较大与较小中项面积的平方 `p>q>0`，返回差平方 `p+q−2√(pq)`。若 `pq` 是有理平方，差平方可写为正有理非平方数；否则保留无理根式。例：`p=8,q=2` 时差平方为 2；`p=3,q=2` 时差平方为 `5−2√6`。这两种情形的原始面积差都不是有理数。相等、反序、非正量、平方输入或不准确的浮点输入不在模型范围内。

独立校验使用手列平方或枚举整数平方比，不调用生产路径中的整数平方根。证书网格核对 192 个正根式系数；从 (1–16) 的分子分母代表约分去重后取 148 个正非平方有理数，核对 10,878 个严格有序对，其中 370 个得到有理非平方差平方、10,508 个保留无理差平方。有限校验不能代替一般性证明。
