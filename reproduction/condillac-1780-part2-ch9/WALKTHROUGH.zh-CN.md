# 从猜想到区分实验：一次小型练习

运行 python examples.py 之前，先写下你预计每个布尔结果是什么，然后按印刷页回读。这不是在测孔狄亚克是否“通过”现代测试。

1. 因果逆推（183–184 页）。三个候选为 both、alternate、neither。原因 C 为真只出现在 both；结果 E 在 both 与 alternate 都为真。全体候选中 C→E 成立。观察 E 后留下两个候选，因此 C 未被确定。若要排除 alternate，须增加能够区分的观察或公开提出额外规则；不能把“E 已见”当作排除理由。
2. 相似类比（182–183 页）。similar_inhabited 与 similar_empty 同样满足所选相似特征。匹配后仍不能保证有居民。增加同样不能区分它们的特征不会有帮助。原文手段—目的类比较强的评价并不被这个结果否定；这里没有模拟其全部前提。
3. 金的例子（178–179 页）。两候选都支持已观察的可锻性，但在未观察性质上不同。输出已观察性质确定、未观察性质不确定。已观察事实不是对材料本质的完全知识。
4. 选择实验（180–181 页的现代延伸）。四候选 00、01、10、11。测第一位或第二位分别分成 2+2，预期剩余 2。只问是否 11 分成 3+1，预期剩余 (9+1)/4=5/2。因此均匀权重下前两种单次实验更能减少候选数。第一位与第二位组成最小的两项固定区分集合；任一单项均不能区分四个候选。若权重、实验成本或测量噪声变化，这个选择标准需要变化。
5. 不一致。对同一确定性测试同时观察 True 和 False 得空集合。certain((),{}) 返回 False。应检查记录、测试规则或候选空间，而不是宣告任意结论得到证明。
6. 可选：现代条件概率。两个正似然候选中，把 alternative 先验设零，得到 target 后验为 1，而结构确定性仍为 False。双方先验相同、似然分别 3/4 与 1/4，则后验分别 3/4 与 1/4。若 alternative 似然确实为零，且至少一候选似然为正，才可在这个似然模型内排除它。模型中的零似然需要依据；一次没看到并不自动等于不可能。
