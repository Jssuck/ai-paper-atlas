# 模型契约与历史边界

## 1. 这是什么

这是一套现代、有限、确定性的教学类比，不是孔狄亚克的原始算法，不是其论证的形式化证明，也不是其历史天文学推断的数值重演。文本依据为《逻辑》第二部第九章，1798 年版本印刷页 177–191；目录名称保留作品的 1780 年标识，实际逐页阅读依据是 1798 年文本。源 OCR 含前一章末尾、192 页起《Éclaircissemens》及更后材料；这些均不属于本模型的章内证据。OCR 只用来定位，排字和标点须回看影像。

代码只模拟一件事：在明确写出的候选与观测规则中，哪些结论已经被全部剩余候选支持，以及还需做什么区分。它不模拟“情感明证”的第一人称经验，也不把三种明证排列成概率刻度。

## 2. 数据与 API

H 是非空、无重复的有限假设名序列；每个名字是非空 str。所有输入表必须恰好覆盖 H。确定性测试 t:H→Y 必须是全定义的。结果标签只接受精确类型 str、bool、int、Fraction；禁止 float、NaN、自定义对象、可变标签。比较采用 Python 的精确相等关系，因此 True、1 和 Fraction(1) 代表同一个结果标签。不同意义的标签请用不同字符串。谓词 Q:H→{False,True} 只接受真正 bool。API 不修改输入。

- consistent(H, tests, observations)：S={h∈H | 对每个(t,y)，t(h)=y}，保留 H 顺序。没有观测时 S=H；冲突或不可能观测返回空元组。未知测试或不完整表报 ValueError。一次也没用到的测试仍需完整有效。
- certain(S,Q)：S≠∅ 且对所有 h∈S，Q(h)=True。Q 必须恰好覆盖 S。空证据状态不产生“确定”。这是一种非空支持判据，与空模型集上全称量化的空真惯例有意区分。
- partition(S,t)：按结果分割 S，保留首次出现顺序。空 S 被拒绝。
- expected_ambiguity(S,t)：假定 S 上均匀权重，结果 y 的概率是 |S_y|/|S|；观察后剩余候选数期望为 Σ_y |S_y|²/|S|。返回精确 Fraction，不是熵，不保证最少自适应测量次数，也不计成本和噪声。
- minimal_separating(S,tests)：枚举测试子集，找每对候选至少有一个不同结果的最小基数集合；同大小按输入测试顺序决胜。单候选返回空元组，无解返回 None。返回的是固定、非自适应测试集合，指数复杂度，仅用于小模型。这里只实现完整状态识别，不实现仅区分目标 Q 真假的最小测试集；后者只要求 Q 值不同的候选对可分，是可能更便宜的扩展。

对模型内逻辑条件的检验使用 H；观测后的经验条件检验使用 S。二者使用同一个量词操作，不代表历史上两种“明证”没有差异。尤其 H 的穷尽性、观测准确性、测试规则在现实中成立，都是模型外条件。删除一个真实可能性能制造虚假的模型内确定性。

## 3. 可选的现代贝叶斯插图

这部分不是原文中的数值概率学说。先验权重 w_h≥0 可不归一化；似然 ℓ_h=P(e|h)∈[0,1]；只接受 int 或 Fraction，拒绝 bool、float 和负值。

Z=Σ_h w_hℓ_h；当 Z>0 时，posterior(h)=w_hℓ_h/Z；当 Z=0 时抛出 ValueError，不造一个均匀后验。likelihood 表仅描述一个指定证据事件，不声称给出了完整结果空间。代码也没有把多次似然相乘并暗中假定条件独立。

structural_certainty(H,likelihood,Q) 检查非空 L={h:ℓ_h>0} 上 Q 是否处处成立，故保留了先验为零但似然为正的候选。两个候选 Q 与非 Q 若都有正似然，给非 Q 零先验可使后验 P(Q|e)=1，却没有结构确定性。若所有候选的先验严格为正且 Z>0，则有限和中的非负项给出 P(Q|e)=1 当且仅当所有似然为正的候选满足 Q。这是给定有限模型的数学推导；有限测试只检查实现，没有证明关于现实世界的普遍归纳法。

## 4. 原文连接与不连接之处

- 177–179 页：三角形定义与金的已观察性质不同。金的教学表保留两种未测性质相反的候选：已测“可锻”不能自行推出全部本质或别的性质。它不是金的化学模型。
- 179 页：évidence de sentiment 是对自身现象的认识来源。程序没有第一人称经验，不能以布尔变量“复现”它。
- 180–181 页：观察、实验、猜想各有作用。猜想指导去观察什么；实验设计表演示这一实践方向，不提供历史作者的效用函数。
- 182–183 页：相似、手段与目的、因果关系的类比不同。相似性匹配仍可保留“有居民”和“无居民”；程序没有替目的论设定概率增益，也没有断言目的类比在现代统计上必然较强。
- 183–184 页：C→E 与观察 E 并不单独给出 C。原文明确说类比假定相同结果有相同原因，并要求新类比和新观察确认。代码的 alternate 候选使逆推漏洞可见；这不是把原文简化成毫无附加说明的逻辑错误。
- 186–191 页：反复阅读、复述、返回原文、熟悉规则使方法成为习惯。下面的练习以预测、运行、复述为序；代码的显式检查不是原文所说熟练者的心理过程。

未建立：候选集合来自何处、开放世界中的充分性、观测噪声、自然规律之真实性、因果干预识别、目的论、主观感受。加入这些需另订模型，不能靠增加几行权重掩盖。
