## 已检查的模型契约

- 假设构成有限、有序的集合；各假设彼此不同，均为非空字符串，类型必须恰好是 Python 的字符串类型。基础假设集不能为空；处理证据状态的 `certain` 操作则有意允许空集。
- 测试必须恰好以该假设集为定义域，对其中每个假设给出一个结果。支持的结果标签，其类型必须恰好是 `str`、`bool`、`int` 或 `Fraction`。标签是否相同按 Python 的相等关系判断，因此 `True`、`1` 和 `Fraction(1)` 表示同一个结果。若希望表达不同含义，须改用不同的字符串加以区分。
- 确定性观测通过取交集保留所有与证据相容的世界，同时保持假设的原有顺序。重复加入相同证据不会改变结果，即具有幂等性；相互矛盾的证据不会留下任何世界；观测到测试值域之外的结果，也不会留下任何世界。
- 命题的值必须是真正的布尔值。确定性指命题在**非空**的剩余世界集合中处处成立；不相容的证据不能使任意命题获得确定性。传给 `certain` 的命题映射必须恰好覆盖传入的状态，不能仍覆盖尚未缩减的更大定义域。
- 划分所采用的相等关系与观测筛选一致。预期歧义度是在均匀先验下，剩余假设数量的精确期望值。区分测试的搜索遍历所有非自适应测试子集，返回测试数量最少的解；如有并列，按插入顺序取第一个。只有一个假设时返回 `()`；无法区分时返回 `None`。
- 贝叶斯计算使用非负的精确整数或有理数先验权重，以及位于 `[0,1]` 内的似然。归一化采用精确运算；证据总权重为零时报告错误。结构性确定性要求命题在所有似然为正的假设上成立，不论这些假设的先验权重是多少。因此，由零先验造成的后验概率为一，并不意味着结构性确定性。

## 发现的问题及修复

**已解决：不满足自反性的可哈希结果，破坏了确定性观测的一致性。** 初始 `model.py` 版本的 SHA-256 为 `8c5e8fbb646ab9da96dd42e365849d682e16a9a3e2955e2d2bd8a5a101c04f78`，该版本接受任意可哈希结果。设 `nan = float('nan')`，假设集为 `('a', 'b')`，测试为 `{'a': nan, 'b': 'ordinary'}`，则：

- `partition` 返回两个各含一个元素的划分单元，`minimal_separating` 也会选中该测试。
- 但是，即使观测的正是假设 `'a'` 所存储的那个结果，`consistent` 仍返回 `()`，因为 NaN 与自身不相等。

这违反了确定性全定义测试应当满足的不变量：产生某项观测结果的世界，不应被该观测本身排除。作者将表中的值和观测结果同时限制为受支持的精确符号类型，从而排除了 NaN、浮点数、容器，以及任意具有用户自定义相等关系的对象。审计者核验了修正后的源文件及相关边界回归检查；审计者未对 `model.py` 或 `examples.py` 作任何修改。

## 局限与解释范围

- 有限测试不等于对所有输入规模的证明。本次也按模型契约阅读核验了代码；穷举有意限制在很小的情形。
- 调用者必须提供有限可迭代对象和普通、稳定的映射。资源限制、无限生成器、并发修改、带有恶意行为的映射实现，以及格式不合要求的观测容器，均不在这一教学模型的契约范围内。不受支持的数据结构可能引发普通 Python 异常，而非统一的输入验证异常。
- 穷举区分测试的复杂度呈指数增长。它既不是高效的大规模实验规划器，也不是自适应、考虑成本、处理含噪测试或按后验权重进行设计的算法。
- 均匀先验下的预期歧义度，与非自适应区分测试集的最小基数，是两个不同的目标。实现没有将二者混为一谈，也不声称解决其中一个目标就等于解决另一个。
- 逻辑确定性始终相对于声明的假设集、观测表和命题而言。遗漏现实中的可能性，会人为造成模型内部的确定性。运行这些示意性示例，不能推出关于行星、黄金或物理因果关系的经验结论。
- 精确有理数运算并不能证明所选似然或先验合理。尤其是，后验概率质量为零，可能只是先验已经排除了某个假设，而非证据表明它不可能。
- 本次没有审计历史资料、配套论述、外部依赖、发布流程或作者编写的测试套件。
