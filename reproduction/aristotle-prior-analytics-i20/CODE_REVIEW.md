# I.20 独立代码审查

## 结论与范围

在所列有限配置、边界输入及具名检查范围内通过，未发现阻断错误。审核者没有修改作者源码、测试或原日志。本结论只针对明确的现代教学实现，不证明古代唯一语义，也不把程序中故意保存的归约失配当成需要掩去的错误。

## 独立方法

`independent-review/oracle.py` 不调用作者方法来产生语义期望值：它以普通集合和逐对象/逐世界量词独立计算 D/P/N/C/BOX。作者的 `Model.holds` 只作为待比较对象。自行枚举 `(n,w)` = `(1,1),(1,2),(1,3),(2,1),(2,2)`；每个配置对五模态、四数量、九项对全部比对。

- C要求同一个实际主项对象的谓项在世界中真过也假过，不是弱可能P。
- N锚定实际主项；BOX逐世界重新取主项，特称见证可随世界变化。
- 全称允许空主项；特称不允许以空主项产生见证。
- 对象数和掩码不把bool当整数；构造及API的非法项、世界、模态、数量须显式拒绝。

作者枚举报告还重新实跑并和保存JSON全结构比对；这一步是可重复性核查，不称为第二套独立枚举算法。独立语义oracle与独立数学审核分别提供另一层检查。

## 实际执行结果

Python 3.12.14，正常、`-O`、`-OO` 每种模式：

- 4744个配置，853920次独立语义查询比对，无不一致。
- 68个非法输入全部以ValueError拒绝。
- 9个作者具名实例经过对象反序置换、复制世界、保持实际世界的其余世界反序，共4860次变形比较保持真值。
- 9类明确语义错误变体均找到区别见证：C误作P、C误作D、N/BOX混用两方向、P误作N、谓项主项交换、全称特称交换、正负极性交换、误把最后世界当实际。每类首个见证保存在报告。这不是任意源码变异的完全覆盖。
- 主稿§7、§8.1、§8.2、§11包含/排斥及非空扩充共六个具体实例单独核验。它们与作者具名实例不全相同，不能仅凭作者例名宣布覆盖；独立脚本显式给出各自模型。
- 作者16项单元测试重新执行通过；三份作者JSON一致，重新执行的报告与保存报告相同。
- 作者manifest的14文件哈希逐项吻合。

主稿的数学证明仍应由论证审查独立判断；代码穷举只能检查有限实现。本文没有声称测试是一般证明、无穷规模验证、自然词事实认证或现代AI实测。
