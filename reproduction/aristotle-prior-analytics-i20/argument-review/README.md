# I.20 独立论证检查

本目录与作者模型分别实现。`independent_argument.py`不导入作者模块，以两世界位掩码实现偶然条件，再用逐对象集合逻辑交叉检查。

运行：`python independent_argument.py`、`python -O independent_argument.py`、`python -OO independent_argument.py`。仅Python标准库。实际Python版本及每次命令和退出状态见`execution.log`，完整结果见`normal.json`、`O.json`、`OO.json`。

## 范围

穷举1、2、3个对象的所有两世界A/B/C解释，包括空项，实际世界固定为0。每模式266304个配置、1597824次点式交叉比较。验证三种带明确桥接条件的推论，并计数在每个世界三项都非空时的换位/第三格失败。另核六个具名配置，含四对象自然词结构的成对例；主稿第8.1、8.2及11节另有五个显式配置分别核验。

位掩码第i位表示对象i属于该项。例如15={0,1,2,3}，11={0,1,3}。`flip(X)=X0 xor X1`仅因本脚本恰有两个世界；作者模型若支持更多世界，不能照抄xor定义。

## 解释限度

记录的是现代实际主项模型的性质，不是亚里士多德的完整历史语义。该模型确实不保持本章所有原文归约，失败保留为结果，而非隐藏或改成“原文已证伪”。一般性桥接结论由独立审查稿的任意对象证明承担；穷举不能替代证明。未验证三个以上对象的所有配置、两个以上世界，或不定命题的全部历史解释。
