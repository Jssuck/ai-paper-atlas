# VIII.21 原典与版本核对

- [Heath 1908，卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)，印页 377–379，PDF 第 390–392 页。正文始于 p.377，p.378 得出相似性；末句与希文同样列作 O、L、M，而前面仍按 L、M、O 对应；其后至 p.379 顶部是 Heath 的小写字母提纲。他把命题视为 VIII.19 的逆向结论，并在提纲中明确从 VIII.20 的证明读取相邻比。
- [Fitzpatrick 希英本 pp.247–249](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)：p.247 取三项最小比并引出平面子问题，p.248 完成两个缩放与第三边的比例，p.249 有终结与脚注。希文 Θ、Κ、Λ、Μ、Ν、Ξ 分别对应 H、K、L、M、N、O；在末尾列出第二组三边时希文写 Ξ、Λ、Μ，Fitzpatrick 英译改为 L、M、O，注为次序错误。它不改因子乘积；正文前面已确定依次配对。
- [Clay](https://www.claymath.org/library/historical/euclid/files/elem.8.21.html) 希文有最后的相似结论与终止句。网页英译在最后列边处结束，未显示结论句，并保留 O、L、M 的顺序。[Joyce](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII21.html) 正文也保留那一排列，且有完整结论；Guide 称为 VIII.19 的部分逆命题。
- 依赖对应：[VII.33](https://www.claymath.org/library/historical/euclid/files/elem.7.33.html) 或 [VIII.2](https://www.claymath.org/library/historical/euclid/files/elem.8.2.html) 建立最小同比链，[VIII.3](https://www.claymath.org/library/historical/euclid/files/elem.8.3.html) 保证最小链端点互素，[VIII.20](https://www.claymath.org/library/historical/euclid/files/elem.8.20.html) 由中项恢复平面相似，[VII.14](https://www.claymath.org/library/historical/euclid/files/elem.7.14.html) 传递跨度一致的比例，[VII.21](https://www.claymath.org/library/historical/euclid/files/elem.7.21.html) 与 [VII.20](https://www.claymath.org/library/historical/euclid/files/elem.7.20.html) 保证依最小比整除，[VII.18](https://www.claymath.org/library/historical/euclid/files/elem.7.18.html) 消去公共乘数。引用 VIII.18 给任意平面相似分解的中项核算是教学解释；不是把正文的“前面命题”擅改为 VIII.18。
