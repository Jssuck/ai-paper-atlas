# I.41：全称范围与有名类覆盖的最小教学核验

这是《前分析篇》I.41中文深读的**原创教学代码**，不是古代原文的唯一语义，不是自然语言解析器，也不是完整三段论证明器。[返回深读](../../papers/ancient/aristotle-prior-analytics-i41.zh-CN.md)。

## 实现的对象

取非空有限论域D，以非负整数给对象编号；A、B、C是D的子集。`Model`将可迭代输入一次性冻结，拒绝布尔值、非整数、负编号、空论域和越域项。属性名称`a`、`b`只表示外延，不认证自然语言内容或事实。

- `strong()`：B包含于A，即每个B对象都是A对象。
- `weak()`：对于**显式提供的有名类表F**中的每个X，只要X包含于B，就要求X包含于A。
- `eligible_union()`：将F中包含于B的那些X取并集，记为U。
- `covers_b()`：检查U是否等于B。它是输入类表的覆盖性质，不是默认事实。
- `all_chain(C)`：只在B包含于A、C包含于B时接受，返回C包含于A的核验结果；前提不满足抛出`ValueError`。
- `some_chain_witness(C)`：只在B包含于A且C与B有共同对象时接受，返回最小编号的同一见证。返回值是对象编号，不是布尔值；编号0也是真实见证，调用方不得用`bool(witness)`判成功。

**F是教学重构引入的参数，原文没有给出这个有限集合模型。** 穷举所有F是为了检查实现跨输入行为，不是说历史论证实际量化所有对象子集。若把F固定为幂集，单元素类自动覆盖B，此时弱式与强式等价；不能用这个特殊选择掩盖一般有名类表可能覆盖不全的问题。

## 一般论证与实验的分工

一般集合论证明如下，无需D有限：若B包含于A，则任何包含于B的X都包含于A，所以强式推出弱式。若弱式真，每个合格X中的对象均在A，于是U包含于A；反过来，若U包含于A，每个合格X包含于U，故弱式真。因此弱式等价于U包含于A。最后若U=B，弱式就等价于强式。程序只是对有限输入检查这套明确约定的实现，**穷举本身不证明一般定理**。

同理，对任取的C对象x，若x在C且C包含于B，则x在B；B包含于A再给出x在A。这证明全称链。若只知存在一个C且B的见证w，只能把这个w传到A，并不能断言其他C对象属于A。`some_chain_witness`保留同一见证，不作这种量词升级。

## 可手算的反例

取D={0,1,2}，A={0}，B={0,1}，F=[{0},{1,2}]。其中只有{0}包含于B，故U={0}，弱式真；但1在B不在A，强式假。令C={1,2}，C与B相交，却与A不交。这里不是“推不出A”就证明“非A”，而是给出一个满足指定弱条件且A完全缺席于C的模型。

另取D={0,1}，A=B={0}，C={0,1}。强式真，C与B有见证0，所以某个C是A；但1不是A，所有C是A为假。再取A={0}、B={0,1}、C={1}，可见仅“某个B是A”即使配合“所有C是B”，也不能确保某个C是A。
