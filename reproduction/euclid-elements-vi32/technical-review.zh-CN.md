# VI.32 独立技术核对

复核原典的角序、中文精读中的方位约束、符号分类及各算例，并重新执行教学代码。

- **角与方位。** 平行线把 BAC 传到 ACD 与 CDE；VI.6 的对应是 A→D、B→C、C→E，故 ABC 对 DCE。角的相加需要 CD 射线在 ACE 内部；应用 I.14 之前，还须保证 CB 与 CE 在 AC 异侧。现代向量的正系数组合与两个相反号的行列式分别给出这两个检查，不以已知共线为前提。Fitzpatrick、Clay 证明都明确保留末步的异侧条件；XIII.17 的实际用例是证 XH 与 HW 顺接。
- **符号和算例。** 独立展开 det(BC,CE) 得到稿中符号；两组同向则沿 BC 方向前进，两组皆反向则同射线折返，异号则不共线。核对了表中两个非零行列式 24、−24，取消平行后得到的 26、反向重叠时的点序及五道练习。只检验行列式为零会漏掉点序错误；只检验异侧仍不足以证共线。
- **独立运行。** 普通、`-O`、`-OO` 三种模式各通过 6 项测试；正尺度有理网格为 60 个合法配置，另检查反向、只保留比例及退化案例。标准库逐格回放全部 3 个 Notebook 代码单元，未调用 Jupyter 内核。有限测试用于核查代码和例子，不替代一般证明。
