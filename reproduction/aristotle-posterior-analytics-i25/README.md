# 《后分析篇》I.25：极性树与前提计数教学复现

对应[正文](../../papers/ancient/aristotle-posterior-analytics-i25.zh-CN.md)，原典范围86a31–86b39。本目录只公开原创代码和真实运行记录；不上传原文PDF或全文翻译。

## 复现的是什么

这不是原典实验的重复：理论原典没有提供这些程序。我们把“展开时只有一条负前提、肯定前提增多”的特定结构变成可运行教学模型，并分别检验集合规则和前提成本的限制。实验不检验真实人类认识速度、不认证科学原因，也不证明“肯定证明在所有意义上优于否定证明”。

### 1. 极性树：计叶，不重复计内部结论

`A`在程序中表示全称肯定命题类型，`E`表示全称否定命题类型，不是原文项名A、E。树叶为暂不继续分解的前提；一个内部节点把两条前提组成一步推理。唯一允许的局部极性规则：

- `A,A -> A`
- `E,A -> E` 或 `A,E -> E`

这是极性层证书，不检查具体项的排列、分布或意义；任意AA极性组合未必是有效三段论。具体项位的有效性另由下述Celarent模型检验。`validate()`会拒绝双负分支、单子节点和不一致的结论极性；不会把任意二叉树宣称为科学证明。

结构归纳给出精确边界：A叶有0负叶，E叶有1负叶。若A节点有两棵A子树，负叶数仍0；若E节点恰有一棵E和一棵A子树，负叶数相加仍1。每新增一个二叉分解，叶数增1。因而内部节点数为n时叶数n+1，负根树有1负叶、n个肯定叶。多个内部负结论只是同一负依赖向上传递，不能再当新增原始负前提。这里给出一般结构证明；有限枚举只是程序核验。

`shapes(n)`生成全部有序满二叉树形；`label`分别赋全肯定或指定唯一负叶，再向上计算极性。测试范围n=0…6：197棵肯定树、1275棵负树，共1472个带极性树，全部叶数/负叶数不变量违规0。包含n=0单叶基例，不称其单独构成一次三段论。两种E子节点顺序是抽象极性模型的对称处理，不等于原文每一具体项位都可任意换序。

### 2. Celarent与正文的双侧展开

集合采用位掩码，允许空集合。本处只有全称A/E规则，结论不需要偷偷添加存在条件：

- 直接：A与B不相交，C包含于B，所以A与C不相交。
- 展开：A与D不相交，B包含于D，项E包含于B，C包含于项E，所以A与C不相交。

最后一条同时展开原文两条前提，叶前提共4条，负叶仍1。程序参数`e_term`明确表示项名，不是负命题类型E。集合模型只检查外延有效性，不能由某集合关系“真”推出它是原典的适当科学原因。

真实结果：

| 检查 | 枚举域 | 总赋值 | 满足全部前提 | 反例 |
|---|---|---:|---:|---:|
| 直接Celarent | 论域大小0…4，三个集合任取 | 4681 | 341 | 0 |
| 双侧展开 | 论域大小0…3，五个集合任取 | 33825 | 259 | 0 |

论域大小0纳入边界测试；不同大小的同构赋值未去重，数字是带标签赋值次数而非非同构模型数。枚举并不能替代任意论域的包含/不相交证明。

### 3. 反例与条件不能删

- 两负前提：A=C={0}、B={1}，A与B不相交、B与C不相交均真，但A与C不相交为假。这反驳把两个负关系直接串起来的具体错误推理；不是程序穷尽所有逻辑系统的结论。
- 冗余假设：有效Celarent证书外再列一个未使用的负假设，列出的负假设数可为2。它不破坏原结论，却不属于这里的精简推导树，不能把原典命题读成“一个论证上下文只允许有一个否定句”。
- 声明成本：等单位成本时两条前提成本2、三条成本3；若短路线每条成本10、长路线每条成本1，则20大于3。它只显示其他条件相同是必要限定，不是人类耗时测量，更没有把原典“同样熟知”完全定义为一个数值。把任意长证明包装为单一黑箱前提也不能自动获得认识上的优越性。
