# I.15：混合模态推理的现代教学附件

此附件不是亚里士多德全部模态系统的形式化，也不是历史有效性的实验证明。目标是把正文的**现代重构**做成可检查的语义：原文的实然与不加时间限定之关系，不被偷偷等同于任意可能世界的必然性。

## 环境与命令

仅 Python 3 标准库；不需安装依赖，不调用网络，不使用付费服务。运行环境见 [environment.json](environment.json)。在本目录执行：

```sh
python -m unittest -v > results/tests-normal.log 2>&1
python -O -m unittest -v > results/tests-O.log 2>&1
python -OO -m unittest -v > results/tests-OO.log 2>&1
python demo.py > results/demo.json
```

测试使用 `unittest` 检查，而演示的全枚举用显式条件抛异常；不会因 `-O` 去除断言而失去检查。实跑28项测试在 normal、`-O`、`-OO` 各通过。真实日志：[normal](results/tests-normal.log)、[-O](results/tests-O.log)、[-OO](results/tests-OO.log)。没有 Jupyter 内核执行或 Notebook 渲染的声明。

## 模型契约

[model.py](model.py) 中 `Model(n, worlds, actual)` 固定非空有限论域，世界为非空元组，每世界一个 `(A,B,C)` 位掩码元组；`actual` 指定实际世界。位 `1 << x` 表示对象 x 属于该词项。所有世界彼此可及，词项可随世界改变。

- `categorical(P,S,'A'/'E'/'I'/'O')` 分别检查实际主项 S 的全肯、全否、特肯、特否；可给明确世界索引。
- `modal(P,S,'K','all'/'some')` 先固定实际 S 对象，再检查每个／某个对象是否**分别**有 P 与非 P 的世界见证。
- `M+` 只要求 P 的世界，`M-` 只要求非 P 的世界。两者不同于 `K`，也不声称它们就是原文所有位置的唯一译义。
- `stable(P,S,negative)` 在**每个世界**检查 S 被 P 包含／与 P 不交。这是现代额外充分条件，不由实际大前提推出。
- `reverse_strong_guard(A,B,C,negative,quantity)` 是强结论的额外见证条件：选定 C 对象须有双向 B 可能，且在肯定桥情形另有非 A 世界，在否定桥情形另有 A 世界。特称分支必须是**同一个对象**满足条件，不能拼接两个见证。
- `jointly_possible` 要求同一世界实现所有实际主项对象的同符号属性；不能用逐对象 `modal(...,'all')` 替代。
- 空实际主项使全称式空真、特称式假；不暗含存在输入。输入验证拒绝越界、未知词项／模式，以及把布尔值当成整数的参数。

## 代码所核的现代定理

1. **直接转移。** K(A,B) 加实际 C⊆B，任取实际 C 对象即是实际 B 对象，获得正反 A 见证。若只有实际 B∩C 非空，就选择该见证，得到特称 K(A,C)。K 的“肯定／否定”两种表述在此现代定义中是同一个双向条件，并不是换位 B、A。
2. **逆向弱桥。** 若各世界 B⊆A，且某实际 C 对象有 B 世界，该世界就是 A 见证；若各世界 B 与 A 不交，该世界就是非 A 见证。全称／特称分别保持原对象量词。它只给 M+／M-，并不给 K。
3. **逆向强桥。** 在第2步的同一个对象上补相反 A 见证，才可合成 K。全称逐对象补，特称保留同一个见证。代码的 guard 是充分条件，不声称最弱条件或古代隐含公设。
4. **可能性保存。** `entails(P,Q)` 要求所有世界 P→Q；`possible(P)` 选一个 P 世界，该世界也满足 Q。P 必须打包所有前提。固定背景 R 时，要有可能的 P∧R，或者已另证背景在有关世界保持；实际 R 与单独可能 P 不够。

这些任意论域／世界的论证独立于有限枚举；枚举只是检查代码与给出边界反模型。

## 实跑范围与读数

[demo.py](demo.py) 遍历1、2个对象、2世界的全部三个词项赋值，并分别选择两个实际索引，共 **8,320** 个配置（不是8,320个互不等价模型）。空词项允许，因此同构、世界排列和空真都计入；不宣称全模态逻辑完备。

[结果](results/demo.json) 中：

| 条件分支 | 满足前提的检查数 | 结果 |
|---|---:|---|
| 直接全称 / 特称 | 2,112 / 1,424 | K结论全部成立 |
| 稳定肯定大前提＋全称 / 特称 K 小前提 | 1,404 / 1,040 | M+全部成立；K分别失败392 / 424次 |
| 稳定否定大前提＋全称 / 特称 K 小前提 | 1,404 / 1,040 | M-全部成立；K分别失败392 / 424次 |
| 强见证桥肯定分支，全称 / 特称 | 1,012 / 552 | K全部成立 |
| 强见证桥否定分支，全称 / 特称 | 1,012 / 552 | K全部成立 |
| 仅实际大前提，肯定 / 否定逆向弱结论失败 | 284 / 284 | 说明稳定桥不能省略 |

另外枚举1–4世界的340对布尔真值向量，90个“必要后承＋可能前提”实例均保存可能性；联合背景的1,246个满足前提实例也全部通过。不同分支不是互斥统计，不能相加当作独立样本或有效率。

## 尖锐边界例

结果文件保存确切掩码与实际索引；以下均为自造教学反例，非历史经验事实。

- `stable_positive_not_strong`：A总真，B变动，正向稳定桥只支持M+，不支持双向偶然。
- `stable_negative_not_strong`：A总假，B变动，负向稳定桥可产生必然否定；这不使所有此类结论都必然否定。
- `weak_negative_not_actual`：A与B互补变动，实际A真，仍有非A世界。因此M-既不等于实际否定，也不等于必要否定。
- `nonempty_time_slice_positive` / `negative`：三个实际词项均非空，依然有逆向弱结论失败。失败并非只靠空真。
- `pointwise_not_joint`：两个对象轮流有A，各自都双向可能，却不存在二者同时有A或同时无A的世界。逐对象全称不能取代整个全称前提的共同实现。
- `negative_minor_necessary_positive` / `negative`：实际小前提否定，无法把C对象接到B上的偶然大前提；相同前提形式容许相反的固定端项关系。
- 布尔真值向量 `false_premise_true_conclusion`：实际假而可能的前提可有实际真且必要的后承，不能从假前提传递“假”。
- `separately_possible_not_joint` 与 `background_not_preserved` 展示分别可能和相容实现的差别；`necessary_implication_not_necessary_conclusion` 区分推理的必然性与结论命题本身的必然性。

## 未实现范围

不实现完整古代证明演算、自然／偶发可能的全部解释、全部三格混合式分类、无限模型搜索、时间与可能世界关系的历史裁定。没有生物学、心理学或现代AI训练数据。源文第三格反证与全称前提替换由正文逐步分析，程序不伪装成其自动化证明器。
