# 《几何原本》X.34：有理面积与无理的平方坐标之和

设参考长度为 `u>0`，令 `R=HL/u²>0` 为有理数，`k=(L/H)²` 为满足 `0<k<1` 的有理数。函数 `construct(R,k)` 要求 `k,1−k` 都不是有理平方。用 `c=√center_squared` 和 `t=√offset_squared` 表示正根，两条输出直角边的平方坐标为 `c+t,c−t`，因为 `c²>t²`，后者仍为正。其和的平方为 `R²/k`；其乘积为 `c²−t²=R²/4`，所以两条输出直角边围成的正矩形相对面积为 `R/2`。

例：`R=2,k=1/2` 时平方坐标为 `√2±1`；取 `R=2,k=2/5` 时则为 `√(5/2)±√(3/2)`，两种面积都为 1。两例区分了偏移 `t` 的有理与无理。不要把它与展开 `(c±t)²` 时的交叉乘积 `2ct` 混同：后者与 `√(1−k)` 相差一个正有理因子，在有效域内恒无理。程序保存精确坐标，不近似开根或模拟尺规。

独立基线显式枚举整数平方，核对 `hl,h(h−l),l(h−l)` 的平方性，分别给出 `k=l/h`、`1−k`、偏移平方的分类。对 `1≤l<h≤64` 的 2,016 对整数，1,904 对接受，112 对被拒；接受者有 104 对给出有理偏移，1,800 对给出无理偏移。有限校验不能代替一般性证明。
