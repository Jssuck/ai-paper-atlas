# X.34 独立技术核对

复核 X.31 末尾给出的中项输入、VI.28 的贴附、X.18 后方向、X.11 的不公度传递、III.31 与 I.47，以及 X.6 所给面积公度。投影引理的高平方公式补上正文从半辅助线过渡到高的等长关系；Fitzpatrick 第 320 页脚注若按斜边归一，两个系数的平方和确实不等于 1，正文的几何结论不受影响。

独立计算得到，两条直角边的归一化平方坐标为 c±d，其中 c²=R²/(4k)，d²=c²(1−k)。因此其和的平方为 R²/k，乘积为 R²/4，且两坐标之比有理当且仅当 d/c 有理。核对了四组表例、四道练习及逆向判据；有理偏移并不保证平方比有理。原证与现代逆向结论在文中分开。

普通、优化、双优化三种 Python 模式均重跑通过，各 3 项测试；三格 Notebook 的标准库回放与留存的标准输出逐行一致。分别按既约分数的分子和分母判定平方，独立重算 2,016 对输入，其中 112 对被拒；合格组 1,904 对分为偏移有理 104 对、无理 1,800 对。有限检查不替代一般证明，也不执行实体尺规作图。
