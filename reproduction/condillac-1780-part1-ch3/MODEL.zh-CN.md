# 形式模型、证明与解释边界

## 1. 与原文的关系

文本限于 Condillac《逻辑》第一部第三章，1798 年 Ch. Houel 版《Œuvres de Condillac》卷 XXII，实际印页 25–31；[公开扫描](https://archive.org/download/b28772581_0022/b28772581_0022.pdf#page=33)的 PDF 页 33–39。

印页 25–26 将感觉及其记忆作为表象／观念的来源，并把分析所得观念的秩序与清晰表达联系起来；印页 27 用机器说明：分别认识部分，并能把它们按原先的秩序放回，才形成对机器的完整观念。印页 28 的制衣例子把拆开和重做用于实际学习。印页 29–31 继续提出自然、正误心智和分析法的广泛主张。

本模型只取“分解时哪些信息必须留下，才能按指定标准重建”这一窄问题。以下都是现代作者的明确选择，原文没有给出它们：整数叶子、二叉树、ADD／SUB、左右次序、括号结构、类型化前缀、解析器、等价关系及穷举程序。把“机器”形式化为表达式语法，只是教学类比；没有机械部件、材料、连接强度、因果运动或时间过程的物理模型。

本模型既不声称思想本来就是表达式树，也不证明分析是唯一学习方法、所有发明都来自分析，或按序表达就足以保证认识真实。没有历史实验、受试者或经验数据。

## 2. 所有形式假设

1. 对象是有限、非空、有根、有序的满二叉表达式树。每个内部节点恰有两个孩子，明确区分左与右；没有环、缺失孩子或可变元数。
2. 叶子的标签属于数学整数集。操作标签仅为 ADD 和 SUB；标签本身是结构信息。
3. 一个表达式由其节点种类、叶值、操作、左右位置及嵌套关系确定。内存地址、对象身份和子对象共享不是结构的一部分；共享引用按出现位置展开成树。
4. 解释使用精确整数算术，无溢出、舍入、副作用、异常算子或非确定性；SUB 表示左值减右值。
5. 前缀输入是有限 token 序列。每个 token 恰为 `("LEAF", integer)`、`("ADD",)` 或 `("SUB",)`；容器和 token 在实现中必须是精确的 `tuple` 类型，标签必须是精确的 `str` 类型，整数必须是精确的 `int` 类型。特别排除 Python 的 `bool` 及自定义子类，不进行隐式转换。
6. 编码协议、操作含义和叶值意义由发送方／接收方事先共同约定；本任务不解决符号如何获得意义、观念是否准确代表外物或不同人的理解是否相同。
7. “无损”只相对于第 3 条的结构同一标准；“任务等价”必须另外指明观察函数。得到相同整数输出不自动等于保存了原结构。
8. 数学证明针对上述抽象有限对象。执行结论以足够资源、未并发篡改输入及正常 Python 运行时为条件。`frozen=True` 防止通常赋值，不是安全沙箱；核心入口仍重验节点字段及环，但不承诺抵御恶意运行时代码。

Python 的不可变 dataclass `Leaf(value)` 和 `Branch(op, left, right)` 实现这些节点。树的语法定义为：

```math
T ::= L(z) \mid B(o,T,T), \quad z\in\mathbb{Z},\quad o\in\{ADD,SUB\}.
```

结构相等递归定义：两叶子当且仅当值相等；两分支当且仅当操作、左子树、右子树分别相等；叶子永不等于分支。

与主文记号对应：主文的 A(l,r) 是此处 B(ADD,l,r)，主文的 S(l,r) 是此处 B(SUB,l,r)；两者都是构造器缩写。完整编码统一记 C，整数输出统一记 V，避免把减法构造器 S 与编码函数混淆。

## 3. 四个表示／观察函数

令 $`\Vert`$ 表示序列拼接，$`[x]`$ 表示单元素序列。

### 完整前缀 C

```math
C(L(z))=[(LEAF,z)].
```

```math
C(B(o,l,r))=[(o)]\Vert C(l)\Vert C(r).
```

操作 token 已含“需要两个孩子”的元数信息。因此没有显式右括号，仍保留全部括号关系；它不是去掉括号的中缀记号。

### 有序叶序列 Q

```math
Q(L(z))=[z],\qquad Q(B(o,l,r))=Q(l)\Vert Q(r).
```

Q 保留叶值和左右遍历次序，但删除操作与分组。

### 叶多重集 M

$`M(t)=sort(Q(t))`$。实现使用排序后的元组表示多重集，重复值计数仍在；它不是去重集合。

### 整数输出 V

```math
V(L(z))=z.
```

```math
V(B(ADD,l,r))=V(l)+V(r),\qquad V(B(SUB,l,r))=V(l)-V(r).
```

V 是给定解释下的一次确定性求值。这里没有输入变量，所以“输出相等”不是关于未知输入上的函数等价，更不是程序行为或物理机器的全面等价。

## 4. 严格解码 P

先完整验证外层类型及每个 token 的类型、标签、长度和负载。任何不符协议的 token 被拒绝，即使它位于一个看似完整表达式之后。

然后从右至左扫描：

1. 遇叶 token，就把对应的 L 压栈。
2. 遇 ADD／SUB，栈中必须至少有两棵树。先弹出的是左子树，再弹出的是右子树；把新分支压栈。
3. 扫描结束时必须恰有一棵树。空输入、孩子不足以及多余完整表达式均被拒绝。

此 P 是部分函数：合法输入返回唯一树，非法输入报错。所谓“全部消费”指一个 token 都不能被忽略，且不能把两个并列表达式当成一个。

主文用从左向右、按元数递归消费两个孩子的方式解释同一前缀语法；实际代码采用上面的逆向栈实现。二者消费方向不同，但都以该语法的唯一树为结果。下面的程序正确性证明明确针对实际逆向栈，不把概念解码过程冒充代码执行轨迹。

## 5. 一般性往返证明

### 定理 1：P(C(t)) = t

对有限树的构造做结构归纳，证明更强命题：在任意已有栈 R 上，从右至左处理 C(t)，恰把 t 放到 R 顶部，R 的其他成员不变，不会缺少操作数。

- 基础情形：t 是 L(z)。C(t) 只有一个叶 token，扫描器把 L(z) 压到 R 顶部，命题成立。
- 归纳步骤：t 是 B(o,l,r)，并假设命题分别对 l、r 成立。C(t) 的逆扫描顺序是先 C(r) 的逆序，再 C(l) 的逆序，最后操作 token。由归纳假设，第一段把 r 压入 R，第二段把 l 压在 r 上；操作 token 先弹出 l，再弹出 r，创建 B(o,l,r)。因此既保留操作，也保留左右位置和所有递归嵌套；R 保持不变。

对初始空栈取此命题，末栈恰含 t，最终检查通过。因此对全部满足假设的有限树成立，并非只对 3477 棵测试树成立。

### 定理 2：P 接受 s 时，C(P(s)) = s

扫描不变量：已处理的后缀，等于当前栈“从栈顶到栈底”各树完整前缀的拼接。

- 初始时后缀与栈均为空，成立。
- 读到叶 token 时，所读 token 等于新叶子的前缀；把它放在原后缀前面，对应把叶子压到栈顶，不变量保持。
- 读到操作 token 时，合法执行要求至少两棵树。若栈顶依次是 l、r，则此前后缀的前两段是 C(l)、C(r)。新分支的前缀恰为操作 token 后接这两段；替换后不变量保持。

若执行结束且只剩 t，则不变量给出 s=C(t)，而 P(s)=t，所证即得。若报错，则没有宣称它属于合法编码域。结合定理 1，可知“被 P 接受”与“存在 t 使 s=C(t)”等价。

### 推论：唯一、无损、结构完整

若 C(a)=C(b)，两边施加 P，由定理 1 得 a=b，故 C 是单射。若同一 s 能解码为两棵树，则它们的 C 都等于 s，因单射而相等。这也证明括号结构无歧义。

由 P(C(t))=t，所有确定的结构观察量都保留，特别是 Q、M 和 V。这是语法同一的推论，不是通过求得相同输出倒推结构同一。

### 长度引理

设叶数为 N(t)，token 数为 K(t)。对树归纳得 $`K(t)=2N(t)-1`$。

叶子时 1=2×1−1；分支时，归纳假设给出 $`K(t)=1+(2N(l)-1)+(2N(r)-1)=2(N(l)+N(r))-1`$。这个长度检查仅是必要条件，不代替解析；相同长度仍可能有错误标签、截断或多余子式。

## 6. 等价关系与信息损失

对任意观察函数 f，在同一树域上定义 $`a\sim_f b`$ 当且仅当 $`f(a)=f(b)`$。普通相等的自反、对称、传递性，立即给出这是等价关系。

C 等价就是结构同一。C 等价蕴含 Q 等价，Q 等价蕴含 M 等价；C 等价也蕴含 V 等价。不能把这四个表示按“从好到坏”排列成一条链：

- Q 相同不保证 V 相同：`(0 + 1)` 与 `(0 - 1)` 的有序叶都是 `(0,1)`，输出分别为 1、−1。
- M 相同不保证 Q 或 V 相同：`(0 - 1)` 与 `(1 - 0)` 的多重集相同，叶次序和输出不同。
- V 相同不保证 Q 或 M 相同：`0` 与 `(1 - 1)` 的输出均为 0，但有序叶、多重集均不同。
- 因而 Q 与 V、M 与 V 均不可比较：两个方向的蕴含都不成立。

对 Q、M 或 V，存在不同树共享同一结果，故不存在能对全域准确恢复原树的单值逆函数。反证非常直接：逆函数接收同一个输入，却被要求同时返回两个不同输出。

损失判断依赖任务。如果任务只是整数求值，那么用 V 的等价类区分结果正好够用；如果任务是列出零件数目和数值，M 可以够用；如果任务是重建此处定义的原表达式，C 才满足本模型的完整恢复标准。此处没有证明 C 是所有可能无损编码中最短的编码。

## 7. 反例最小性

“最小”需要先规定尺度。穷举报告按以下字典序取结构碰撞的第一对：两树最大叶数、叶数总和、较小树的秩、较大树的秩；树秩为“叶数、完整 typed prefix”，一对树按该秩先排序。这个约定只用于有限域 `{0,1,2}` 的报告。

三个丢失投影 Q、M、V 的最小结构碰撞都出现在最大叶数 2：

- Q、M 的第一对：`(0 + 0)` 和 `(0 - 0)`。两棵均 2 叶，结构不同，输出恰好相同。结构损失不要求输出必定变化。
- V 的第一对：`0` 和 `(0 + 0)`。最大叶数 2、总叶数 3。
- 最大叶数为 1 时，域中只有三个叶对象，各自值不同，Q、M、V 都能区分，因而不可能更小。

若想分别看清哪一种信息丢失造成输出改变，应使用以下“控制其他因素”的反例。它们是按叶数的最小反例，不宣称都是上述字典序的第一对：

1. 只改操作：`(0 + 1)` 与 `(0 - 1)`，2 叶。单叶没有操作，不能更小。
2. 只换左右位置：`(0 - 1)` 与 `(1 - 0)`，2 叶。单叶没有两个位置，不能更小。
3. 只改括号：`((0 - 0) - 1)` 与 `(0 - (0 - 1))`，3 叶，操作均为减法、叶次序均为 `(0,0,1)`，输出 −1 与 1。1 叶无分支；2 叶只有一种满二叉形状，故不能更小。

这些例子只否定相应投影在整个所定领域内的无损性。加法等特定子域可能对某些置换或重括号保持输出，这不反驳结构损失。

## 8. 穷举完整性和独立计数

有限检查域：叶数 1–4，叶标签恰在 `{0,1,2}`，每个内部节点可独立取 ADD／SUB，有序满二叉形状全部保留；不把交换律、结合律或相同输出的表达式合并。

`generate_trees(n)` 把左子树叶数 k 从 1 遍历到 n−1，分别遍历全部 k 叶左子树及 n−k 叶右子树，并取两个操作。

对 n 作归纳即可证明枚举完备且不重复：n=1 时三个叶值各出现一次。n>1 时，任何合法树都有唯一根操作、唯一左叶数 k 和唯一左右子树；由归纳假设各子树恰出现一次，因此该组合会且只会被生成一次。反过来每个生成组合都满足树定义。

令 $`a_n`$ 为 n 叶树数。独立于实际生成对象的整数递推为：

```math
a_1=3,\qquad a_n=2\sum_{k=1}^{n-1}a_k a_{n-k}.
```

另用满有序二叉树的 Catalan 形状数作闭式计数：

```math
a_n=\frac{1}{n}\binom{2n-2}{n-1}\,2^{n-1}\,3^n.
```

形状数在 n=1,2,3,4 时分别为 1,1,2,5；每棵形状有 n−1 个内部节点、n 个叶子。与每个内部节点的两种操作、每个叶子的三种数值独立相乘，得到 3、18、216、3240；总和 3477。程序分别计算实际生成数量、上述整数递推、上述闭式，检查三者一致，再核对前缀唯一性和两个方向的往返。

“独立计数”指不依赖生成结果本身的组合公式；它不是“独立人员代码审计”。作者程序和作者测试仍共享代码，另行审阅才是独立检查。

## 9. 实际有限结果

完整实测见 `validation/census.json`。本节为便于阅读列出结果：

| 表示 | 等价类数 | 单元素类 | 碰撞类 | 不同树的碰撞无序对数 | 最大类大小 |
|---|---:|---:|---:|---:|---:|
| 完整前缀 C | 3477 | 3477 | 0 | 0 | 1 |
| 有序叶 Q | 120 | 3 | 117 | 63945 | 40 |
| 叶多重集 M | 34 | 3 | 31 | 512469 | 480 |
| 整数输出 V | 15 | 0 | 15 | 711386 | 565 |

“碰撞类”指大小至少 2 的等价类；一个大小为 k 的类贡献 k(k−1)/2 个不同树的无序对，既不把自身算碰撞，也不把一对算两次。输出类可跨叶数，Q、M 类因长度固定而不能跨叶数。

Q 的类数为 3+9+27+81=120，各 n 叶类大小分别为 1、2、8、40。M 的类数为 3+6+10+15=34；数值出现次数为 a、b、c 且 a+b+c=n 的类，大小为 $`n!/(a!b!c!)`$ 乘该 n 的形状数及操作标签数。V 的实际可达输出为 −6 至 8 的全部 15 个整数，频数在 JSON 中逐一列出。

有限结果既不代替第 5 节的一般证明，也不扩张到未定义的运算、无限树、浮点数、自然语言、学习者或历史实践。
