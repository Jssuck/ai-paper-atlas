# I.19：实际主项与逐世界主项的教学模型

这是《前分析篇》I.19的**现代、有限、常域教学实验**。目的不是复原作者的全部模态体系，而是显式检查：某种现代定义支持哪些推论，以及它在哪些地方不再符合原章的例证。只需 Python 3 标准库，无第三方依赖、数据集、密钥或付费服务。

## 原典与实验边界

[I.19深读](../../papers/ancient/aristotle-prior-analytics-i19.zh-CN.md)与[来源台账](../../papers/ancient/aristotle-prior-analytics-i19.sources.zh-CN.md)负责历史证据；本目录的代码、世界集合和布尔结果都是现代教学重构。Owen1853印128页的“运动—清醒—动物”例说明：把所有必要命题机械翻译成“实际对象永远有该性质”，会过度限制可用模型。本实验直接呈现这种失配，**不称它驳倒古代原文，也不称另一种现代语义已经解决古代全部问题**。

## API、假设和符号

`Model(domain, worlds, actual=0)`接收非空整数论域、非空世界list/tuple及实际世界索引。布尔值不是对象编号或世界索引；允许各项外延为空。每个世界必须恰有A/B/C三个键，每个值是论域的子集。输入被复制为不可变集合和只读映射，以免调用方随后修改源集合改变计算。非空论域和非空世界是本模型约定，不是本实验为所有历史解释作的断言。

`model.eval(mode, form, predicate, subject)`中谓项在前、主项在后。例如`eval('D','a','A','B')`意为“所有实际B是A”，不是其逆。形式`a/e/i/o`依次为全称肯定/全称否定/特称肯定/特称否定。`as_dict()`给出可公开检查的整数集合，不输出环境路径或身份信息。

设实际世界为r：

- D：只在r计算普通集合命题。
- N：固定主项集合为S(r)，对其中每个（a/e）或某个（i/o）对象检查它在**全部世界**是否满足谓项的肯定/否定性质。
- P：同样固定S(r)，把“全部世界”改成“某个世界”。全称P允许不同对象有不同见证世界，不宣称存在使整句同时成立的单一世界。
- C：固定S(r)，每个或某个对象都既有属于谓项的世界，也有不属于谓项的世界。故C_a=C_e、C_i=C_o；这是肯否改质，不是交换主谓。
- Box：每个世界重新计算该世界的主项外延并检查整句a/e/i/o。Box_i/o允许存在见证跨世界变化；N_i/o要求同一个实际主项见证始终满足属性。

所有列出的世界都可及，实际世界也在其中。这保证N推出D、D推出P；本目录不实现任意可及关系，也不为非反身模态逻辑作这些断言。

## 一般推导与枚举的分工

数学推导必须读正文；实验只检查有限情况。例如N_e(A,B)与C_a(A,C)成立时，若实际对象x同时为B和C，前者要求x在所有世界都不是A，后者却给出x是A的一个世界，矛盾。因此实际B与C不交。换成C_i时，只能对该实际C见证推出D_o(B,C)，不能把“某个”升级为“所有”。

当必要否定落在C一侧时，同样论证首先给D_o(C,B)，**不能将特称否定随意换位成D_o(B,C)**。全称否定则确实对称。

这里的N_e本身不保证模态换位：实际B永不为A，不能排除一个实际A以后成为B。古代原章采用必要否定换位，这说明本模型不是其完整语义，只是用来隔离某个推导机制。

N_a(A,C)与C_a(A,B)在此锚定模型也推出实际不交：若同一个实际对象兼为B/C，便被要求既始终为A又在某世界非A。这同原章“清醒者属于动物”的可相交例不合。改用Box_a(A,C)可让C随世界变化，允许相交；但不能因此不说明地把其他证明中的N也一并换成Box。

## 八个实跑实例

1. `weak_not_necessary`：两前提N_e(A,B)、C_a(A,C)及D_e/P_e(B,C)为真，N_e(B,C)为假。用三个世界使实际C在后来属于B；这没有违反关于**实际B**的前提。
2. `weak_not_strong`：同两前提及D_e/P_e为真，C_e(B,C)为假，因为实际C从不属于B。弱可能否定不等于强双向偶然。
3. `conversion_fails`：N_e(A,B)真而N_e(B,A)假，展示锚定必要否定不自动对称。
4. `awake`：Box_a(A,C)、C_a(A,B)、D_a(B,C)真，但N_a(A,C)和D_e(B,C)假。A/B/C可分别作运动/动物/清醒的形式标签，**不是动物行为实证数据**。
5. `anchored_affirmative`：N_a(A,C)、C_a(A,B)、D_e(B,C)都真，演示锚定定义的额外排斥。
6. `reverse_particular`：N_e(A,C)、C_i(A,B)、D_o(C,B)真，D_o(B,C)假。见证方向不能随符号排列丢失。
7. `particular_negative`：N_o(A,B)、C_a(A,C)真，但D_e和D_o(B,C)都假。必要否定仅特称不足以代替全称否定。
8. `box_negative`：Box_e(A,B)、C_a(A,C)真，但N_e(A,B)、D_e(B,C)假。逐世界B可变化，故不能悄悄用Box_e代替第一个定理中的N_e。

报告列出每个模型的所有世界、实际世界和被检查命题，读者无需信任自然语言名称。

## 有界枚举覆盖

枚举所有A/B/C外延及每个可指定的实际世界：对象数/世界数为(1,1)、(1,2)、(1,3)、(2,1)、(2,2)，分别为8、128、1536、64、8192个指定配置，总计9928。包括空项及非零实际世界；其中3692个配置的三个实际项都非空。

每个配置检查C肯否改质、所有项对的N⇒D⇒P以及五个有条件结论：全称/特称必要否定路线、其端项互换路线、锚定必要肯定与双向偶然的排斥。实际满足各前提的数量保存在日志，避免仅凭全真空蕴涵说“验证成功”。八个例子另以单元测试确保预期真/假。

正常、-O、-OO模式分别运行17项单元测试和9928个配置，均通过。数字是有限计算规模，不是一般逻辑完备性证明。没有模拟全部古代不定命题、自然倾向可能性、所有译本、任意模态框架或实际AI性能，也没有声称完整复现亚里士多德全部理论。
