## 独立 oracle 与覆盖

[独立核验源码](independent-review/audit_code.py)不调用作者 `eval` 来生成期望真值。它将每一项外延编码为位掩码，用谓项跨世界的并集与交集构造“合格对象集合”，再以集合包含/相交判断全称或特称。Box 则逐世界检查整个直言式。作者实现采用逐对象、逐世界 `all/any`，二者计算路径不同。

每模式覆盖对象/世界规模 (1,1)、(1,2)、(1,3)、(2,1)、(2,2)，包括全部项外延和每个实际世界索引，共 **9,928** 个指定配置。对每配置的5种语义×4种形式×9个有序项对进行比较，共 **1,787,040** 次逐项一致。包括空主项、空谓项、自项关系、单世界、非零实际索引、必要特称同一见证与 Box 特称跨世界不同见证等边界。

另外69个非法输入案例实际检查异常类型，覆盖空论域、非整数/布尔对象编号、非法世界容器和键、域外外延、非法实际索引、查询参数类型和未知值；检查复制隔离及只读世界映射。

[边界核验源码](independent-review/boundaries.py)每模式另做 **540** 次变形检查：整数编号重标为负数/非连续值、世界排列并同步实际索引、重复世界而不改变可及情形集合。还检查 tuple/list/frozenset、重复编号归一化、`as_dict` 返回值与模型隔离及外延不可变。[三模式边界报告](independent-review/boundaries-normal.json)分别使用相同脚本生成。

## 变异敏感性

穷举同时找到9类错误语义的区别见证：实际索引固定为0、主谓颠倒、N换为Box、Box换为N、P换为N、C换为P、e换为a、o换为i、i换为a。每个首次区别的世界、实际索引、查询和两个真值完整保存在报告中。这是**显式语义变异敏感性检查**，不是声称进行了任意源代码变异工具的全覆盖，也不代表能杀死所有实现错误。

## 数学和接口核对

- N/P 固定实际主项；N_i/N_o 的存在对象先于全世界量词，符合正文；Box_i/o允许对象见证随世界改变。
- C 的正负形式同真值只表示双向变化，不表示主谓换位。空实际主项的全称真、特称假是公开声明的现代约定。
- P全称的世界见证可以逐对象不同；程序没有误实现为整句共享一个可能世界。
- 所有世界可及并包含实际世界，故本模型内 N⇒D⇒P；没有冒称任意模态框架同样成立。
- 必要否定换位失败、锚定必要肯定导致排斥、Box_e不能代替N_e的实例均与正文的语义失配说明一致。
- 输入集合和世界映射被复制并冻结；这不是对使用者故意重写下划线私有属性的安全沙箱或整个 Python 对象绝对不可变承诺。

## 重跑和限制

```sh
cd reproduction/aristotle-prior-analytics-i19/independent-review
sh run_audit.sh > execution.log 2>&1
```

命令会替换本独立审核目录的生成报告；不会修改作者日志、安装依赖或联网。检查失败抛出显式异常，不依赖优化模式会删除的 `assert`。报告中的单元测试耗时可能随重跑变化。

有限枚举不是一般定理证明；一般推导须另读正文及数学审查。程序不处理无限域、任意可及关系、古代自然倾向语义或全部三段论体系。语义变异只是明确列出的9类。未运行性能基准，也不作现实AI效果主张。
