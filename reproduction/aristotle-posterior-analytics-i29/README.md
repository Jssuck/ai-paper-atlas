## 1 模型及明确边界

设有限宇宙的元素按位编号，整数掩码的第i位表示元素i是否在集合中。`subset(x,y)`检验X包含于Y。`middle(a,b,d)`严格对应两条件：B包含于D且D包含于A。因此从任意x属于B，先得x属于D，再得x属于A。两条路线分别经D与H，并不要求这两个中项有包含关系。

例A={0,1,2}、B={0}、D={0,1}、H={0,2}，掩码依次7、1、3、5。D和H交集非空，但互不包含。若B为空，取D={0}、H={1}、A={0,1}，两路线都满足全称包含，而D和H不交。因此“共享非空主项保证相交”必须把非空条件明列；不能从共享主项推出全称互谓或任一包含方向。

固定B包含于A时，任一合格中项唯一写成B与S之并，其中S任取A减B的子集。因此候选数是2的|A减B|次方。B不包含于A时无候选。此计数允许D=B或D=A，亦允许不同名称同外延，**不是适当的、直接的或因果性科学中项数**。特别是测试中的equal类别计数不声称新增一份独立证明。

## 2 同一链切点与不同路线

给定链B→C→D→Z→A有一个完整简单路径；C、D、Z是三个可选切点。由链段的传递推导可分别以它们作中项。菱形B→D→A与B→H→A有两个给定路径。两例分别保存在results.json。

`paths`只枚举给定有限有向图中的简单路径，重复边去重，遇环避免重复节点。它不证明所有真实解释已列全；图里没有D→H边不能被解释成集合D不包含于H，更不能作为经验因果独立性。有限图路径多样性也不是统计独立证据数量。

## 3 其他格教学补充

原章末尾提出考察其他格，本程序只补两条合法全称否定路线，不冒称原章已列出或我们已穷尽诸式：

- Celarent（第一格）：A与D不交，B包含于D，推出A与B不交。
- Cesare（第二格）：H与A不交，B包含于H，推出A与B不交。

两者固定结论E(A,B)，中项、前提位置和前提内容可以不同。反向不成立：结论为真不保证指定前提为真。没有从第三格特称结论偷升为全称。本程序明确允许空项；这两条全称否定规则在此模型不需额外存在假设。
