# II.5 独立技术复核的实跑证据

本目录由非正文、非主程序作者的审查者编写。`audit.py` 用逐对象布尔量词重新表达命题，不导入主程序的模型或谓词实现。

在上一级复现目录运行：

```sh
python3 independent-audit/run_audit.py
```

`run_audit.py` 实际执行独立审查、作者测试与作者枚举，将命令、环境、退出状态写入 `run.log`。作者结果必须逐字节一致，否则失败；测试日志用时可能因环境而变。

检查内容：

- 重新生成255种非空占用模式及218种全项非空模式，逐项比对作者8有效、6无效模式的前提满足数与反例数。
- 实际复核作者输出的12个反模型，不依赖其标签；全项非空域额外检查存在条件。
- 另用1–4个带标签对象枚举4680个模型，允许成员类型重复，与压缩域不是同一种遍历。
- 独立检查10个有效模式：作者8个加正文两个特称正向推导；6个无效模式均找到反例。
- 直接检查正文六个全项非空反例。
- 单独重建正文六关系账本中V的假设依赖，结果为P、R、V；与主程序另一个C⊆A短环不混同。

输出 `results.json` 给出具体计数，`author-results.json` 是作者程序本次独立重跑的输出，`author-tests.log` 是作者测试的本次独立执行记录。独立枚举仍是有限检查；一般证明依赖正文逐对象推导，依赖集合演示不构成通用逻辑证明器，亦不裁定古代文本异读。
