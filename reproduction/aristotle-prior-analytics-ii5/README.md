# 《前分析篇》II.5：互证条件与循环依赖的最小检查

这是原创、现代集合语义下的教学重构，不是对古代文本的机器翻译、一般证明器，也不是整个亚里士多德逻辑的复现。对应 [中文深读](../../papers/ancient/aristotle-prior-analytics-ii5.zh-CN.md)。原文出处与版本问题见深读。

## 环境与重跑

只用 Python 3 标准库，无网络、无第三方依赖。实际版本及运行 UTC 时间见 `run.log`。

```sh
python3 run.py
```

在本目录运行；`run.py` 实际调用 `python3 check.py` 与 `python3 -m unittest -v test_check.py`，分别刷新 `results.json` 与 `tests.log`，并记录真实退出状态。失败时立即非零退出。`run.log` 不含用户名、主机名或私有目录。作者单元测试不冒充独立审查。

## 语义与枚举域

`A, B, C` 是共同非空论域 `U` 的子集。原文“A 属于所有 B”写作 `B <= A`；全称否定是交集为空；特称肯定是交集非空；“A 不属于某些 C”是 `C - A` 非空。全称命题在此不自带存在承诺。

整数 0–7 的三个位分别表示 A（4）、B（2）、C（1）成员资格。枚举八种成员型的所有非空占用集合，共 255 个模型，每种已占用成员型放一个代表。000 型保留，因为补集必须相对于整个 U。第二域过滤 A、B、C 都非空，剩 218 个模型。

这不是枚举“任意八个元素的所有赋值”，也不检查成员型内的基数、模态或本质谓述。代码在该压缩域内穷举，论文中的一般推导须另行检查；这些小模型运行结果自身不构成对原文所有定理的证明。

## 检查内容

八个有效模式分别检查：肯定链；用反向小前提恢复大前提；用反向大前提恢复小前提；否定链；恢复否定大前提；借助 `U-A <= B` 恢复小前提；肯定特称恢复；否定特称恢复。每种模式在两个域中均有满足前提的模型，避免空测例导致的假通过。

六种无效增强均自动寻找最小反模型（先最小论域，再按成员型排序）：

1. 结论加原小前提不足以恢复原大前提。
2. 结论加原大前提不足以恢复原小前提。
3. E 命题简单换位不等于 `U-A <= B` 这一补集覆盖条件。
4. `C-A` 和 `B-A` 各自非空，不保证两者共享同一个见证，更不保证 `C & B` 非空。
5. 特称肯定结论加换位后的特称小前提不保证全称大前提。
6. 特称否定结论加换位后的特称小前提不保证全称否定大前提。

第 4 点的全项非空反例：`U={0,1,2}, A={0}, B={1}, C={2}`。这里存在两个不同的“不属于 A”的对象，但没有同时属于 B 和 C 的对象。第 3 点也可用此反例，显示 `B <= U-A` 与反方向不能混淆。第 8 个有效模式使用明确的**全称补集桥**作为充分条件，不宣称这是原文末句的唯一解释。

## 实际结果与边界

- 255 个非空论域占用模式；其中 218 个三项都非空。
- 8 个有效模式 × 2 个域：全部无反例；各模式满足前提的模型数见 `results.json`。
- 6 个无效增强在两个域中都有反例，均输出具体集合。
- 按两个域分别计数共 6,622 次模型/模式检查，其中两域有重叠，并非 6,622 个不同模型。
- 7 项作者测试通过。细分测试和真实用时见 `tests.log`。

依赖演示把 `C<=A` 作为假设，用 `A<=B` 得 `C<=B`，再用 `B<=A` 得回 `C<=A`；输出依赖集仍含原假设，不算独立证明。若把假设节点改为递归指向目标，依赖遍历明确拒绝环。该函数仅审计依赖边，不检验每条边是否合法；示例边的逻辑正确性由集合传递性说明，不能称为通用证明验证器。
