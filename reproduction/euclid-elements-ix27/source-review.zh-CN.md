# IX.27 原典核对

- [Heath 1908 英译卷 II](https://www.wilbourhall.org/pdfs/Heath_Euclid_II.pdf#page=429)印页 416、扫描页 429 上部；IX.27 的论证与图完整。A、D、C、B 按图排列，从奇数整段 AB 的 A 端去掉单位 AD，留下偶段 DB；减数 BC 仍为偶，故依 IX.24 剩下 CD 为偶，原余段 CA 是 CD 加一个单位，依 VII.定义 7 为奇。扫描在题设及后续均为 BC；若 OCR 给出 AC，是转录误识，不是扫描异文。
- [Fitzpatrick 希英对照本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=273)印页及扫描页 273，IX.26 后、IX.28 前。希文和英栏分别以 [γὰρ] 与 [For] 标记去单位步骤的连接词；英栏还用圆括号显式补出该单位取自 AB。Heath 不在对应句印带括号的连接词。括号差异不改变数段关系，也不据此推断传本先后。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.27.html)希文保留方括连接词和完整结语，英栏止于 CD 为偶。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX27.html)保留最终推出 CA 为奇，并称本题是四种奇偶减法的末一种。
- VII.定义 7 两次使用的方向不同；原文在去单位处没有展开其现代带余除法依据。图中 D 严格位于 C 左侧，保证能在正数域内应用 IX.24。若 AB 仅比 BC 长一个单位，则 D 与 C 重合，CD 为零；现代整数结论仍成立，但不能把零当作原图中的正余段。正文未单列此边界。
