# 《后分析篇》I.28：类型、根支持与推导证书

## 范围与身份

这是本仓原创的现代教学重构。它用有限正 Horn 规则帮助区分“共享推理规则”“共享具体起点”“标签同类”和“存在合格推导”。它不是Aristotle的原始算法，也不自动识别自然之类、第一原理、科学之间的真正身份或优越性。本章原文见[中文深读](../../papers/ancient/aristotle-posterior-analytics-i28.zh-CN.md)。

## 规格及证明义务

原子是字符串；一条规则由非空有限前件集合和一个结论原子构成。不包含否定、函数符号或量词实例化。初始事实集合 F 与规则集合 R 分开提供，空前件规则被拒绝，避免暗中把规则当作事实。derive 不断添加所有已满足前件的结论，记录每个新原子的首次推导证书。

1. **终止。** 只出现输入种子及规则中的有限原子。每次变化严格增加已知集，因此至多添加该有限全集中尚未知的原子数。
2. **最小性。** 归纳地，每个新增原子都被所有包含 F、对 R 封闭的集合包含；终止时结果自身封闭，因而是最小闭包。
3. **证书。** 每步须属于输入 R，前件已知且结论尚未出现。检查器拒绝逆序、不存在规则、重复结论；它验证给定证书而非证书的解释正确性。
4. **单调性与幂等。** 增加初始事实不会减少闭包；已封闭集再次闭包不变。这是正 Horn 语法性质，不是所有非单调科学推理的性质。
5. **最小支持。** minimal_supports 枚举声明根集合的子集，返回足以推出目标的所有包含最小子集。不是唯一真实原因，不是基数最小，更不是关于无限科学理论的搜索。

代码允许同类型规则；跨类型规则必须出现在完全匹配的 bridges 清单内。缺类型即拒绝，桥也不能补缺类型。类型和桥由建模者声明，类型检查不是对其真实性的认证。此例只检规则的局部签名，不把现代类型制度强加给古代原文。

## 手算例与反例

令规则为 p→u、q→v、u与v→w。以 p、q 为根，先得u/v，再得w；w的唯一包含最小根支持为{p,q}。只有p时缺q/v，不得w；没有根时即使共享全部规则也什么都推不出。

声明p/u属于N，q/v/w属于G：第三规则跨类，默认被拒。显式声明它为桥后，w重新可导出。这只说明输入证书改变，不说明实际科学中的桥已经得到辩护。未给出的桥或规则不能自动被认定不存在；“不可导出”总是相对于这里完整声明的有限规则集。

同标签a、b且只给事实a，不提供a→b，就不能得b。同标签不是证明。反过来，根交叠也不是同一学科的等价关系：A={p}，B={p,q}，C={q}，AB、BC有交集而AC无交集。这个反例反驳一种简单教学算法，并非反驳原典的完整科学统一性主张。
