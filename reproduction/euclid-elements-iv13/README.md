# 《几何原本》IV.13：从两个角平分线到五边形的内切圆

[回到正文](../../papers/ancient/euclid-elements-iv13.zh-CN.md)。本目录用现代精确坐标核验构造的几个关键条件。正例的输入是已经生成的正五边形，程序不把已知生成中心偷偷交给构造函数，而是实际求顶点 C、D 的两条内部角平分射线之交。不是逐工具模拟尺规操作，也不是一般性证明。

## 算法与证书

- 横坐标和纵坐标系数用有理数对表示 a+b√5。以 U=cos72°=(√5−1)/4，V=1−U²，实际点坐标为 (x,y√V)。点积须用 xx′+Vyy′；行列式可忽略恒正的 √V 因子，求交时该因子也消去。
- 输入必须保持五个不同点的严格凸边界次序。两条相邻边等长时，顶点指向两邻点的向量和在内部角平分线上；在 C、D 处各构造一条。用行列式求两条直线交点，再要求两个射线参数都严格为正，并核实交点严格在全部边的内侧。
- 对有向边 A→B，垂足参数为 t=(F−A)·(B−A)/|B−A|²。验证 0<t<1、正交、五个距离平方为同一个正值。正例的五个垂足还都是边中点；已知外接半径 R 的独立期望是内切半径平方 R²(3+√5)/8。
- 两个反例族都保留正的边内垂足和垂直关系。向外推 A 的反例仍有原 C、D 的内角和同一交点，且与 BC、CD、DE 等距，却不与其余两边等距。另一个反例固定正五边形，仅小幅平移圆心，也会破坏五边等距。检查正交或检查两条平分线都不等于检查五条边共同相切。

## 结果和适用范围

48 个有理外接半径各取正反绕行，得到 96 个正例、96 个只推 A 的反例与 96 个只移动圆心的反例；坐标样本含非零平移。普通、`-O`、`-OO` 模式各通过 8 项具名测试，其中包括错误次序、重复顶点、点数不足、非法半径或方向以及落在线段外的垂足。有限样本用于发现方向、符号或实现错误，不是对所有正五边形的证明。坐标域和等长邻边约束是本教学实现的限制，不是判定任意不规则五边形是否存在某个内切圆的通用算法。
