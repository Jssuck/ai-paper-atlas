# 《几何原本》X.3：求最大公度量

正有理量教学模型。输入 $`a\ge b>0`$，以整商合并相减。最后一个非零余量 $`d`$（直接整除时就是 $`b`$）是公度量：从 $`d,0`$ 的计数 1、0 开始，用每行的商逆推各量包含多少份 $`d`$。任何公度量在每一步都继续度量下一余量，因而必度量 $`d`$；全部公度量可写成 $`d/n`$，其中 $`n`$ 为正整数。

例：$`21/10,9/10`$ 的商为 2、3，余量为 $`3/10,0`$；原量分别包含 7、3 份 $`3/10`$。等量输入按现代一步终止处理。程序不是任意实数量的可公度判定器，也不使用浮点数。

独立基线将有理量通分后枚举公因子，再查较细网格上的候选公度量，比对候选能否分别整除两个初始量。网格由分子 1 至 12、分母 1 至 4 生成，去重后取降序或等量配对。有限校验不是一般证明。
