## 接口与范围

`construct(payload)` 输入恰为 `A/B/C/D` 四键字典，各点是长度为 2 的 JSON 列表。坐标可用整数或有理数字符串，如 `"1/3"`；拒绝浮点数、布尔、非法分数及非列表点。A、B、C 不共线，且 D 在 B→C 越过 C 的延长线上。`verify(payload, certificate)` 重新从输入构造并严格比较规范 JSON，区别 `True` 与 `1`、字符串与整数、元组与列表；额外/缺失字段和坐标篡改不接受。等价数值输入会标准化为相同有理值，不是保留原字符串拼写的签名。

证书包含两组辅助点、长度/夹角/内射线检查及两个外角不等式。第一组 E=(A+C)/2、F=A+C−B；第二组 M=(B+C)/2、N=B+C−A、G=2C−A。全部检查用 `fractions.Fraction`，没有浮点角度、平方根或三角函数。

`same_angle` 由点积符号和余弦平方交叉相乘检验普通角相等；符号检查不能省略，否则锐角和补角会混淆。`strict_inside` 通过行列式证明向量位于两独立射线张成的小于平角的扇区内部。内射线加非退化给严格大小关系；程序未假装直接计算古代“角量”。

## 覆盖与局限

180 正例包括两种定向、顶点在底边投影外部、不同边长和延长量；测试另含有理数、极大尺度、极扁三角形、平移/旋转/反射。16 非法输入覆盖共线、重复顶点、延长方向错误、离线、类型和字段错误。12 种证书篡改回归覆盖点、系数、输入、真假、模式号、结论等。

有限输入不证明全部有理数，更不证明所有实数；一般恒等式与点序证明见正文。程序假定欧氏坐标、普通无向角和精确算术，不论证这些概念在古代公理系统中已完备，也不适用于球面。验证器与构造器共享实现，仍需独立审查；单靠重算不能排除共享逻辑缺陷。
