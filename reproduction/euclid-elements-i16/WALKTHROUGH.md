# 两次中点构造：逐步走查与边界

示例 A=(1,2)、B=(0,0)、C=(3,0)、D=(5,0)。输入给出外角 ACD，不把外角定义成“两内对角和”，也不调用后面的三角形角和定理。

## 1. 首构造

E=(2,1)，F=(4,2)。E 同时平分 AC 与 BF，故 AE=EC、BE=EF；两夹角是对顶角。原证明借 I.4 的 SAS 对应得到 BAC=ECF；实现另用长度平方和精确普通角检查这些关系，不能把计算替代原文的推理来源。

从 C 出发，CA=(-2,2)、CD=(2,0)、CF=(1,2)，于是 CF=CA+(3/2)CD。两个系数严格为正，且 CA、CD 不共线；因此 CF 不是边界，而是外角扇区内射线。EC 与 CA 同向，所以小角 ECF 是 ACD 的真部分。其余小角不为零，得到严格 `ACD > BAC`，而非大于等于。

## 2. 第二构造

M=(3/2,0)，N=(2,-2)，G=(5,-2)。M 平分 BC 和 AN；另一次 SAS 得 ABC=MCN。CB=(-3,0)、CG=(2,-2)、CN=(-1,-2)，且 CN=CB+CG；从而 CN 严格在 BCG 内。最后 BCG 与 ACD 的两对边分别反向，普通对顶角相等，因此 ACD>ABC。

这是把“同理”的另一条路径明确补齐的现代坐标教学展开；没有把首个不等式复制成第二个，也不声称所有辅助点字母都来自原文。

## 3. 一般形式而非小实验推定

写 CD=λ(C−B)，λ>0，则 CF=(A−C)+(C−B)=CA+CD/λ。第二构造恒有 CN=(B−C)+(C−A)=CB+CG。只要原三角形非退化，两个构成扇区的向量独立。正系数内分说明为何补充点序条件可靠。代码对这两条恒等式的系数做证书记录，具体运行不是证明这条一般代数论证。

## 4. 反例与验证器练习

1. 把 D 改成 (2,0)：D 回到底边内部，程序必须拒绝，而非仍给外角结论。
2. 把 D 改成 (3,0)：外角一边退化为零向量，必须拒绝。
3. 把 A 改成 (1,0)：三角形共线，扇区不再严格，必须拒绝。
4. 把证书 `schema=1` 改成 `True`：虽然 Python 原生比较认为相等，严格 JSON 规范比较拒绝。
5. 把 F 改成 (4,3)：不再是要求的倍长点，输入绑定重算拒绝。
6. 仅把输入 D 从 (5,0) 改成 (6,0)，沿用旧证书：几何结论仍成立，但旧证书不描述当前输入，必须拒绝，重新构造才通过。

以上均由真实测试或 Notebook 检查。负例不是对欧几里得命题的反驳，而是展示前提和实现契约的必要性。

## 5. 复盘

原文论证的关键不只是等边等角，还包括辅助射线处于所需角的内部。坐标重构补全了这个次序环节，但也加入欧氏平面坐标的现代背景。不能据有限平面样本声称证明一般公理独立性、球面失败机制或古代所有隐含前提。
