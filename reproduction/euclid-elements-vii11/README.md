# VII.11：交叉扣除后比较余数

用现代正整数手工重建，不是古代计算记录或一般命题的计算证明。输入次序 AB、CD、AE、CF；程序要求四个给定量大于 1，AB<CD，两边都有严格、非零的扣除，且 AB/CD=AE/CF。零扣除、全扣除、给定量含单位、方向反过来或相等均不进入此重构。余数为单位则可以精确计算，属于现代模型边界。

用同一组互素计数 m,n 表示 AB=m·u、CD=n·u、AE=m·v、CF=n·v，u>v。在 VII.7/VII.8 中，把 AB、AE 视为 CD、CF 相同的份或若干份，作差得到 EB 相对于 FD 的份数。分支由横比 AB/CD=AE/CF=m/n 决定：m=1 进入 VII.7，m>1 进入 VII.8。纵向扣除比例 AE/AB=CF/CD=v/u 仅为现代附带核对，不决定分支。余量 EB、FD 都保持  m:n。代码用约分计数表达定义 20 中同一「份或若干份」和同一比较关系之间的转换。Fraction 检查直接从原始量及余数另算，不借用该计数的输出。

- (12,36,4,12)：横比 1/3，VII.7，余数 (8,24)。
- (18,30,6,10)：横比 3/5，VII.8，余数 (12,20)。此例与上一例的纵向扣除比例同为 1/3，却走不同分支。
- (3,6,2,4)：余数 (1,2)，现代模型保留单位。
- (12,18,4,8)：扣除量之比 1/2 不等于原比 2/3，余数比变为 4/5。
