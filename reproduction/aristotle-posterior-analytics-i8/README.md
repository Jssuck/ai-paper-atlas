# 《后分析篇》I.8：全时关系、暂时事实与事件条件律

这是原创教学程序，不是古代天文复原或现代天文数据实验。原文范围参见[深读](../../papers/ancient/aristotle-posterior-analytics-i8.zh-CN.md)与[来源台账](../../papers/ancient/aristotle-posterior-analytics-i8.sources.zh-CN.md)。实读Mure Part8与Owen印263后，取三处论证边界作最小核验；没有把古代“普遍且永恒”定义成现代有限模型的`all`。

## 模型、输入与输出

- `Slice(a,b,c)`表示一个时刻的三个谓词外延。固定对象集，不模拟对象出生死亡；“易灭”只用谓词关系会随时间失效来作局部教学类比。
- `relation`依次给出B包含于A、C包含于B、C包含于A。`summarize`只检查输入的非空有限时域，返回各前提/结论失效时刻。
- 大前提和小前提在每个时刻都真，结论就在每个时刻真。逐对象逐时刻的传递证明见正文；枚举是实现检查，不是该一般结论的证明。
- 若某时刻结论假，该时刻至少一条前提假；不同失效时刻可以由不同前提承担。并不推出某一固定前提在所有时刻皆假，也不推出两条都假。
- `event_summary`把“触发时发生事件”“始终发生事件”“至少发生一次”分别计算。事件序列只是三位布尔数组，没有观测月食或拟合天文参数。
- `continuation(prefix,future,t)`表示一个明确定义的无限序列在有限索引处的值。前缀相同、尾部全真与全假可不同；代码只抽查若干索引。一般“任何有限观测前缀不能单独强制唯一未来”的证明是构造两条延伸，而不是跑完无限时间。

定义与证明的三个位置关系属于原文哲学论述，本程序不把它们压成未经论证的计算判定；不认证真实因果、本质、恰当普遍性或亚里士多德全部科学观。

## 实跑结果与基线

两个对象的子集有4种，每个时刻三谓词有64种状态，两个时刻共4096条轨迹。集合包含实现与逐对象布尔蕴涵oracle比较，差异0。

- 两条前提全时成立的轨迹256条；其中结论全时失败0条。
- 结论不是全时成立的轨迹2800条；其中两条前提仍全时成立0条。
- 首时刻两前提皆真但结论不是全时成立448条，直接反驳把快照证明升格为全时证明。
- 三时刻触发/事件布尔序列64组；条件律与“不存在触发为真而事件为假的时刻”的独立表达比对差异0。

oracle只是另一种计算表达，不是独立历史证据。4096轨迹包含空谓词，不添加原文未明说的存在预设；针对存在的事件例另列，不以条件真推出事件存在。

## 可手算边界例

1. 时刻0取A=B=C={0}；时刻1取A为空、B=C={0}。快照成立，全时结论失败。
2. 时刻0取A为空、B=C={0}，只有大前提假；时刻1取A=B为空、C={0}，只有小前提假。两次结论都假，失败责任可换。
3. 触发与事件同为(假、真、假)：条件律始终真，事件不是始终真。
4. 两者同为(假、假、假)：条件律真，但没有事件。需要实际触发信息才能应用规则。
5. 同一个全真有限前缀之后可以接全真尾部或全假尾部。实验不会选择哪条是真实未来。

所有结果仅针对公开代码的明确输入域；不声称完整复现原著、不替代一般证明、不因月食例而否定现代对个别事件的预测与解释。
