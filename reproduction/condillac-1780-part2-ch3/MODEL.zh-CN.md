# 模型与证明：观察纠错、推导闭包与词义对齐

## 1. 阅读对象与模型身份

本附件对应孔狄亚克《逻辑学》第二部第三章，原题 *Comment les langues sont des méthodes analytiques. Imperfection de ces méthodes*。实际阅读底本是1798年《Œuvres de Condillac》卷XXII，印页118–124，IA PDF126–132；目录路径中的1780是作品初版书目年。[从实际底本118页开始核对](https://archive.org/download/b28772581_0022/b28772581_0022.pdf#page=126)。这里不把1798措辞冒充1780初版，不收录整章扫描或全译。

## 2. 模型一：经验究竟能排除什么

### 2.1 全部对象与假设

- $`X=(x_1,\ldots,x_n)`$ 是非空有限观测位置表，各位置名称互异；$`n`$ 是位置数。
- $`Y`$ 是结果符号的集合。每条实际输入只含有限多个非空字符串；程序不要求预先列尽 $`Y`$，允许观察到所有候选均未预测的结果。
- $`H`$ 是非空有限候选名称集。每个 $`h\in H`$ 对应完整预测函数 $`p_h:X\to Y`$。不同名称可以有完全相同的预测函数；“候选不同”不强行意味着可被数据区分。
- $`D=((u_1,y_1),\ldots,(u_k,y_k))`$ 是长度为 $`k`$ 的有限观察序列，$`u_i\in X`$、$`y_i\in Y`$。重复观察分别计数；同一位置出现相互冲突的结果也合法。
- $`b\in\{0,1,2,\ldots\}`$ 是事先给定的错误预算。比较观察前缀时保持同一预算，不在看到结果后悄悄更改。

定义不一致次数及候选集：

```math
E_D(h)=\sum_{i=1}^{k}\mathbf 1[p_h(u_i)\ne y_i],
\qquad H_D^{(b)}=\{h\in H:E_D(h)\le b\}.
```

其中 $`\mathbf 1[P]`$ 在命题 $`P`$ 成立时为1，否则为0。$`b=0`$ 是精确过滤。`HypothesisSpace.candidates(D, max_errors=b)`实现这一集合；不估计概率，不排名，也不把唯一剩余者自动叫作“事实真相”。

附件固定例子使用true=(0,0,1)、twin=(0,0,0)、other=(1,1,1)，位置为x、y、z。这与正文A=(0,0,0)、B=(0,0,1)、C=(1,0,1)的例表不同；它们检验同一组定义，但附件噪声数值不是正文例表的执行实录。

### 命题1：追加观察使候选单调不增

若 $`D'`$ 由 $`D`$ 追加若干观察得到，则每个 $`h`$ 的不一致次数只会增加或不变，所以 $`E_D(h)\le E_{D'}(h)`$。若 $`h\in H_{D'}^{(b)}`$，立即有 $`E_D(h)\le b`$，故

```math
H_{D'}^{(b)}\subseteq H_D^{(b)}.
```

它不保证严格缩小，也不保证非空；增加预算则可能重新接纳候选，不属于本命题。

### 命题2：保留真实候选需要两个前提

假设真实预测机制在类内，即存在指定 $`h^*\in H`$；并且观察与 $`p_{h^*}`$ 的不一致次数至多为 $`b`$。依定义 $`E_D(h^*)\le b`$，于是 $`h^*\in H_D^{(b)}`$。特别地，无噪声且真实机制在类内时，精确过滤不会删除它。

没有这两个前提，唯一剩余者也可能错。类内只有预测(0,0)的候选，而真实机制预测(0,1)，仅观察第一位置0时便只剩一个错误候选；再观察第二位置1会得到空集。另一个反例是类内确有真实候选，但把其第一位置0误录成1，就可能只留下另一错误候选。空集只表示当前类、记录与预算无法同时相容，不能单凭空集断定究竟是仪器噪声、真相不在类内，还是其他假设错误。

### 命题3：检测一个错误不等于唯一识别

在无噪声且真实候选为 $`h^*`$ 时，错误候选 $`h`$ 被排除，当且仅当至少存在一次观察满足 $`p_h(u_i)\ne p_{h^*}(u_i)`$。

证明：无噪声给出 $`y_i=p_{h^*}(u_i)`$；精确排除等价于 $`E_D(h)>0`$，而有限非负指示量之和大于零恰等价于其中至少一个为1。

因此某些错误能被检出，不意味着其余候选彼此可分。完全同预测的不同候选名称永远不能靠本模型中的观察区分。经验可纠错的主张若要提升成“总能到达唯一真相”，必须补充可观测性与可识别性条件。

### 命题4：全类可识别的充要条件

令 $`Q\subseteq X`$ 是选定的不同观测位置集。限制映射 $`\rho_Q`$ 把候选 $`h`$ 映为它在 $`Q`$ 上的预测函数。`distinguishes(Q)`检验 $`\rho_Q`$ 是否单射。

对于“每个可能的真实候选，在无噪声地观察全部 $`Q`$ 后，都成为唯一剩余候选”，$`\rho_Q`$ 单射是充要条件。充分性：真实候选保留，而其他候选的限制函数不同，必有一位置使其排除。必要性：若有两个不同候选在全部 $`Q`$ 上同预测，以其中任意一个为真，它们都会保留，无法唯一识别。$`Q`$ 为空时，只有单一候选的类满足此条件。

某次观察唯一识别某个特定候选，比“整个类可识别”弱；不能用一次成功声称所有候选都可区分。

### 2.2 噪声预算有什么作用，又没有什么作用

有界错误模型保留所有不一致次数不超过 $`b`$ 的候选。它不是从数据估计的统计噪声模型，也不保证谁更可信。观察越多且预算固定时，仍满足命题1；重复同一错误记录会重复消耗预算。

还可得到一个有用的充分条件。对固定观测位置序列 $`(u_1,\ldots,u_k)`$，定义两个候选预测向量之间的Hamming距离：

```math
\delta(h,g)=|\{i:p_h(u_i)\ne p_g(u_i)\}|.
```

若任意不同候选都有 $`\delta(h,g)>2b`$，则任意记录 $`D`$ 至多容纳一个预算内候选。否则若 $`h,g`$ 都容纳，每个二者预测不同的位置至少使其中一者不同于记录，因此

```math
\delta(h,g)\le E_D(h)+E_D(g)\le 2b,
```

矛盾。再加命题2的类内真相与有界噪声条件，便恰剩真实候选。这里给出充分条件，不把它当作程序已实现的误差校正码或实际语言学习机制；程序只逐项计数过滤。

## 3. 模型二：连贯推理怎样继续传播错误

### 3.1 全部对象

$`U`$ 是有限命题原子集，允许为空。$`R`$ 是有限正Horn规则集，每条具互异名称的规则记为 $`r=(A_r,b_r)`$，其中 $`A_r\subseteq U`$ 是前提集合，$`b_r\in U`$ 是结论。规则含义是“所有前提成立时可加入结论”；不是“任一前提成立即可”。$`A_r=\varnothing`$ 允许无条件规则。没有否定、默认推断、置信度或概率。

给定种子 $`S\subseteq U`$，定义一步算子：

```math
F_R(K)=K\cup\{b_r:r\in R,\ A_r\subseteq K\},\qquad K\subseteq U.
```

$`K`$ 为规则闭合，当且仅当 $`F_R(K)=K`$。从 $`S`$ 出发反复应用直到不再增加，所得最小闭合集记为 $`\mathrm{Cl}_R(S)`$。`HornSystem.close(S)`按给定规则顺序扫描，并允许同一轮新添原子立即触发后面的规则；程序轨迹与同步轮次不一定相同，最终集合相同。

### 命题5：有限终止与最小闭包

每次成功推导只加入一个此前没有的原子。因此最多有 $`|U|-|S|`$ 次成功添加；每个非终止扫描至少添加一个原子，故最多 $`|U|-|S|+1`$ 轮扫描（最后一轮确认不再变化）。规则数有限，每轮结束，所以程序终止。空宇宙及空规则集也在范围内。

终止时种子都在集合中，且每条前提已在集合中的规则都不能再添加新结论，故结果闭合。令 $`C`$ 为任意包含 $`S`$ 的闭合集。归纳每次添加：初始 $`S\subseteq C`$；若此前已知原子都在 $`C`$，触发规则的前提都在 $`C`$，由 $`C`$ 闭合，其结论也在 $`C`$。因而最终结果包含于每个这样的 $`C`$，即为唯一最小闭包。

这也证明闭包等于所有含种子的闭合集之交。全宇宙 $`U`$ 自身总闭合，所以待交的集合族非空。测试的穷举对照正使用这个交集定义，不照抄前向扫描。

### 命题6：扩张性、单调性、幂等性和顺序无关

扩张性 $`S\subseteq\mathrm{Cl}_R(S)`$ 已由构造给出。若 $`S\subseteq T`$，则 $`\mathrm{Cl}_R(T)`$ 是一个包含 $`S`$ 的闭合集，由最小性：

```math
\mathrm{Cl}_R(S)\subseteq\mathrm{Cl}_R(T).
```

$`\mathrm{Cl}_R(S)`$ 本已闭合，再以它为种子不会添加原子，因此

```math
\mathrm{Cl}_R(\mathrm{Cl}_R(S))=\mathrm{Cl}_R(S).
```

任一每轮完整扫描规则、只在前提齐备时加入结论并运行至无变化的次序，同样满足命题5的最小性，故最后集合相同；具体来源轨迹可以不同。幂等性说明既定种子和规则下已无新结果，**不说明种子正确，也不说明经验已充分**。

### 命题7：事实保真是有条件的

用 $`T\subseteq U`$ 表示实际为真的原子集合。把“所有规则在这一真值赋值下成立”精确定义为：对所有 $`r`$，若 $`A_r\subseteq T`$ 则 $`b_r\in T`$，也就是 $`T`$ 闭合。若再有全部种子为真，即 $`S\subseteq T`$，则最小性给出

```math
\mathrm{Cl}_R(S)\subseteq T.
```

反例：$`U=\{rain,wet,slip\}`$，规则为 $`rain\to wet`$、$`wet\to slip`$，真实集合取 $`T=\varnothing`$。两条材料蕴含在该赋值下都成立，因为前件均不真。却若错误加入种子 $`rain`$，闭包为三个原子，全部为假。推导的每一步都合规则，闭包也稳定，仍然没有得到真事实。

这些天气词只是三枚原子名称，不是天气学定律。正Horn系统没有显式否定，因此不能拿“没出现形式矛盾”当作事实可靠性的测试。

### 3.2 来源核查到底证明什么

`ClosureResult`保存原种子、按产生顺序记录的`Derivation`列表和最终原子集。每条记录包含规则名称、该规则的完整前提和结论。`verify_trace(result, seeds)`独立接收预期种子，检查：

1. 保存种子与外部给定种子一致；所有原子属于宇宙。
2. 规则名称存在，记录的前提、结论与这条规则完全相同。
3. 前提在此前已知集合中，结论尚未加入；随后加入该结论。
4. 逐条重放的集合恰等于报告集合，而且报告集合对所有规则闭合。

如果核查通过，逐条归纳说明报告集合中的非种子原子均可由种子导出，所以报告集合包含于真正闭包；它又是含种子的闭合集，按最小性真正闭包包含于报告集合，因此二者相等。来源核查既验证每步合法，又验证终点没有漏掉可触发规则。

核查仍只担保**这些种子经这些规则确实得到这些结论**，不担保种子是真，也不担保规则与现实吻合。虚假种子的完整来源可以全部通过检查。程序记录每个原子的一个首次来源，不枚举全部证明，也没有增量撤回功能；改正种子后应重新计算，不能把某条已知证明的后代一律删除，因为还可能有其他支持路径。

## 4. 模型三：重命名可逆，为什么仍可能误解

### 4.1 语义对齐与可逆性的不同条件

令 $`M`$ 为共同的有限意义原子集，$`W_A,W_B`$ 为两套有限词码集。两套理想化词表是双射 $`e_A:M\to W_A`$、$`e_B:M\to W_B`$；逆映射 $`d_A=e_A^{-1}`$、$`d_B=e_B^{-1}`$ 是解码。这些词表已排除一词多义和同义词，不能冒充自然语言全貌。正文关于一般解码函数、字典存在与意义像集覆盖的命题更宽；本程序只执行共同有限意义集上的双射词表这一严格子情形，不声称机器验证了一般非单射定理。

字典 $`\tau:W_A\to W_B`$ 是另给的函数。语义保持要求下列两条路径对于每个 $`w\in W_A`$ 给出同一意义：先翻译再解码 $`d_B(\tau(w))`$，或直接解码 $`d_A(w)`$。这就是语义交换图的等式形式：

```math
d_B\circ\tau=d_A.
```

由于两编码双射，上式当且仅当

```math
\tau=e_B\circ d_A.
```

证明：语义等式两侧左复合 $`e_B`$，利用 $`e_B\circ d_B`$ 为 $`W_B`$ 上恒等函数即可；反向代回则立即成立。`aligned_dictionary`构造唯一这张对齐字典，`translation_preserves`要求覆盖恰好全部源词、值落在目标词域，并逐项检查语义等式。

对一般函数 $`\tau:W_A\to W_B`$，若存在 $`\sigma:W_B\to W_A`$ 同时满足

```math
\sigma\circ\tau=\mathrm{id}_{W_A},\qquad
\tau\circ\sigma=\mathrm{id}_{W_B},
```

则 $`\tau`$ 必为双射：第一式使它单射，第二式使它满射。反之双射有唯一逆函数，满足两式。`inverse_dictionary`检查映射单射，返回到其**实际像集**的逆；它不接受指定目标词域，因此单独调用它不能证明字典覆盖某个外部目标词表。

即使字典确为全域双射，往返恢复也不保证 $`d_B\circ\tau=d_A`$。两个逆过程可以把同一个错误互相抵消。正确语义对齐才把“回来一样”提升成“过去也是同一个意义”。

### 4.2 规则闭包的另一个交换图

把函数逐元素作用于集合，记 $`\tau[S]=\{\tau(s):s\in S\}`$。若 $`\tau:U\to V`$ 是原子宇宙间双射，把规则 $`(A,b)`$ 改名为 $`(\tau[A],\tau(b))`$；全部改名后的规则集记为 $`\tau R`$。

对任意 $`A,K\subseteq U`$，双射（其实此处单射已足够）给出：

```math
A\subseteq K\quad\Longleftrightarrow\quad\tau[A]\subseteq\tau[K].
```

所以某规则在 $`K`$ 触发，当且仅当改名规则在 $`\tau[K]`$ 触发。逐轮归纳可得同步迭代的集合一一对应；由有限终止及最小闭包唯一性，同样适用于程序的扫描实现，得到：

```math
\tau[\mathrm{Cl}_R(S)]
=\mathrm{Cl}_{\tau R}(\tau[S]).
```

这是“先闭包再翻译”与“先翻译种子和规则再闭包”的形式交换图。**它只要求重命名保持规则结构，不自动要求词义正确。** 如果用一张错误但双射的字典把规则也一起错译，两边照样可能完全一致。只有另加语义对齐，且目标系统是同一意义规则集的正确编码，才能把该交换式解释成意义层面的推理保持。

非单射映射可能破坏等式。取规则 $`a\to b`$、$`c\to d`$，种子 $`\{a\}`$，映射 $`a,c\mapsto x`$、$`b\mapsto y`$、$`d\mapsto z`$。源闭包是 $`\{a,b\}`$，其像为 $`\{x,y\}`$；目标规则却成了 $`x\to y`$、$`x\to z`$，目标闭包为 $`\{x,y,z\}`$。合并原子制造了额外触发。这不说明每个非单射实例都会失败，只说明不能一般性地省掉单射条件。

### 4.3 正确接触与错误字典的并排例子

共同意义是 rain、wet、dry。词表A用相同英语词码，词表B分别用 lluvia、mojado、seco。正确字典按意义对应，编码同一条 $`rain\to wet`$ 规则后，两边从雨这个种子都得到雨与湿。

错误字典保留 rain→lluvia，却把 wet→seco、dry→mojado 交换。它仍有完美的双向逆，但“wet”翻过去被目标解为“dry”。将源闭包错误翻译得到 {lluvia,seco}；目标真正的规则 lluvia→mojado 从相同种子得到 {lluvia,mojado}，两者不同。若把目标规则也照错误字典写成 lluvia→seco，形式闭包图又会交换，却共同保留了误解。

因而本模型的失败条件是具体的词义错配、合并或规则不一致，不能归罪于语言之间发生接触这件事本身。正确对齐是直接的成功反例。它也不评价真实多语言社群的历史或能力。

## 5. 小模型：任务精确性不等于词数

令 $`\Omega`$ 是非空有限世界集，$`L:\Omega\to V`$ 为标签函数，$`q:\Omega\to A`$ 为当前任务答案函数。$`V`$ 是标签集合，$`A`$ 是答案集合。这里“词汇广度”只数已使用标签 $`|L[\Omega]|`$，不冒充自然语言全部词汇量。

称 $`L`$ 对 $`q`$ 精确，当且仅当存在函数 $`g:L[\Omega]\to A`$，使 $`q=g\circ L`$。换句话说，看到标签便能确定任务答案。`task_exact`检查这一条件的等价形式：

```math
L(\omega)=L(\omega')\ \Longrightarrow\ q(\omega)=q(\omega')
\qquad(\omega,\omega'\in\Omega).
```

必要性：相同标签输入 $`g`$ 得到相同答案。充分性：对任一已使用标签选一个产生它的世界，用该世界的答案定义 $`g`$；蕴含条件保证不因选哪个世界而改变结果，所以 $`g`$ 良定义。

由 $`L`$ 引出的分区是同标签世界组成的块。条件等价于标签分区细化答案分区。若标签函数 $`L'`$ 的分区进一步细化 $`L`$，而 $`L`$ 已对任务精确，则 $`L'`$ 仍精确：同 $`L'`$ 标签先推出同 $`L`$ 标签，再推出同答案。但**仅仅块数更多不意味着细化**。

四个世界的任务答案为 (safe,safe,unsafe,unsafe)。标签 (A,A,B,B) 只用两个标签而精确；标签 (X,Y,X,Z) 用三个，却把第一与第三世界都叫X，混淆任务答案。这个例子是任务相对的：换一个任务，哪种标签精确也可能改变。它支持“数量不足以保证精确”的有限结论，不给历史语言作高低排名。

## 6. 实现契约、规模与测试边界

核心模型复制通常的有限Python输入容器为元组、冻结集合或局部字典。名称均为非空字符串。非空约束、未知位置、未知原子、缺漏预测、重复候选/规则名及不完整词表等用显式`ValueError`拒绝；`bool`不当作错误预算整数。观察会全部验证后再筛选，不因早先矛盾而跳过后面的非法输入。无限迭代器、恶意对象、通过底层接口修改冻结对象、并发篡改输入及任意故障恢复不在契约内。

令 $`h=|H|`$、$`k=|D|`$、$`n=|X|`$。当前实现用元组成员检查验证位置，单次候选查询保守为 $`O(kn+hk+n)`$ 时间与 $`O(k+n+h)`$ 额外空间；存储完整假设表本身为 $`O(hn)`$。这些界以固定有限字符串比较/散列为单位成本，并采用Python dict/set平均或摊还常数时间访问假设；不声称散列碰撞最坏情况下仍是常数。实际长字符串处理成本另计。

Horn部分令 $`N=|U|`$、$`r=|R|`$、$`a=\max(\{1\}\cup\{|A_r|:r\in R\})`$，设 $`L=N-|S|`$，$`k_S`$ 为原始种子输入序列长度（可有重复，故可能大于 $`|S|`$）。集合包含判断按前提个数计，闭包最多 $`L+1`$ 轮，每轮扫 $`r`$ 条；首次来源对前提排序。保守时间为 $`O(N+k_S+(L+1)ra+La\log(a+1))`$，包含原始种子解析暂存与轨迹的额外空间 $`O(k_S+N+La)`$；不是高性能推理引擎主张。所有源规则及宇宙的输入存储另计。

字典和任务模型是有限表查找，所用字典构造及单次完整语义比较为线性规模；`Vocabulary.meanings/words`每次访问重新构造冻结集合，因此复杂表达式会有额外常数次扫描。测试中的穷举故意很小，不能当作可扩展到真实语言的性能结果。

作者验证在正常、`-O`、`-OO`下各运行24个unittest方法，包含32,895个过滤/预算案例、2,408个Horn系统/种子案例、216个词表/字典案例和729个标签/答案函数对。每个模式另运行10个人工行为突变、10个原版哨兵基线及11个故障控制。仅指定哨兵完整执行且发生测试断言失败才计为`killed`；通过为`survived`；语法/导入失败、提前退出、超时、测试运行异常、非法JSON和缺字段/非对象/bool计数/负计数/不相容计数报告等为`harness_failure`，不能伪报成检出。

突变分类以列明的十个不伪造终止报告的实现替换为范围。同一子进程没有对输出作身份认证；恶意程序可以打印结构合法的假终止报告误导分类，故这里不是任意恶意代码的隔离或认证框架。
