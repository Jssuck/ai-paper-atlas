# I.31 坐标教学复盘

## 1. 对象与边界

原文先给线外点A与直线BC，在线上取D，连接AD，用I.23在A复制角ADC成为角DAE，再把EA延长至F，使用I.27得到EF平行BC。这里给出的是结果证书核验，不记录I.23内部画圆、交点选择或操作历史。D≠C为角ADC非退化所需；D可以在BC段外。BC端点只是直线的表示，并不限制整条线范围。

输入为有理坐标。给定v=C−D、w=A−D；A在线外保证v和w不共线。模型要求E与C在AD两侧，并要求无向角EAD=ADC；F在AE反向射线上。角等式不是只比较点积平方：还要比较点积的正负，否则锐角和补角会混淆。

## 2. 一般模型推导（教学重构，不是原书代数）

把DA的单位方向记为e，并选垂直单位向量n使v在n方向的分量为正。于是v/|v|=cosθ e+sinθ n，0<θ<π。AD方向为−e。与AD成角θ的两个单位射线方向分别为−cosθ e±sinθ n。侧向条件选择负n分量，因此AE/|AE|=−cosθ e−sinθ n=−v/|v|。所以存在t>0使AE=−t v。反向延长再给出AF=u v（u>0）。由此EF方向与BC相同，且A不在BC上，两条线互异而不相交。

这是声明的欧氏内积坐标模型中对一般条件的论证，使用角的单位方向表述；程序本身不用三角函数或浮点数。程序等角判据以两点积符号一致及平方归一化相等实现。由于各向量非零且角非退化，该判据无补角歧义。独立审查可对其他精确输入重复核验，但有限测试仍不是该论证的替代。

## 3. 手算

取B=(−1,0)、D=(0,0)、C=(1,0)、A=(0,1)、E=(−1,1)、F=(1,1)。角EAD与ADC均为直角，两点积均0。以AD=(0,−1)为方向，E和C的有向面积分别−1和1，乘积−1；AE=−DC、AF=DC，t=u=1。EF是y=1，BC是y=0；平行且互异。

换成E=(1,1)，仍为直角且支撑线仍平行，但E和C位于AD同侧。这是“平行输出”真、所声明角复制侧向证书不合格的案例，不应把拒绝说成几何输出一定错误。F同样必须取E的反向，不能仅随意选平行线上的点。

## 4. 非直角错侧反例

取D=(0,0)、C=(1,0)、A=(1,1)。正确AE方向是(−1,0)。把此方向关于AD的支撑线反射得到(0,−1)，故错误E=(1,0)。它仍与AD构成相同无向角，但位于C同侧；所得直线x=1与BC在C相交。侧向不是可以省略的装饰。

## 5. 存在与唯一

对任意有理A、D、C满足上述条件，可直接选E=A−(C−D)、F=A+(C−D)，得到模型内存在的见证。换正比例t,u可改变E、F而保持同一输出直线；辅助点变化与输出唯一性不是同一问题。原I.31构造与I.27论证给存在性；另一个证明若从平行推出相应角关系使用I.29，则间接使用第五公设。不能因为本欧氏坐标模型输出唯一，就声称已在不含第五公设的公理系统证明唯一。

## 6. 复盘问答

1. 为什么平方归一化还不够？答：cosθ和−cosθ平方相同，必须保留点积符号。
2. D一定要在B、C中间吗？答：本模型不需要，仅需在线上且不等于C；程序有段外测试。
3. E、F距离改变是否得到不同平行线？答：正比例只改变在线上的标记点，不改变A处方向。
4. 接受平行输出是否足以认证I.23操作完成？答：不够，本程序连古代操作序列都未编码；它检查的是明确列出的坐标条件。
5. 1008样例可以证明所有构造吗？答：不能，只能帮助发现实现、绑定和边界错误；一般论证与原文依赖需另外阅读。
