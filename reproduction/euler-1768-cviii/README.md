# 欧拉第 CVIII 封信：条件推理的最小可运行实验

这是原创、仅使用 Python 标准库的教学性重建，不是欧拉留下的程序，也不声称复原其完整逻辑语义。阅读范围仅为 1768 年版第 CVIII 封信：印刷页 139 下部至 144 上部，信末日期为 1761 年 3 月 7 日。页 139 上部及其 3 月 3 日日期属于前一封信；页 144 的 CIX 标题之后不在本实验范围内。

## 先运行

需要 Python 3.10 或更新版本，无第三方依赖、无需联网或安装。实际执行环境见 `logs/environment.txt`。

在本目录运行：

```sh
python main.py demo
python main.py check example.json
python -m unittest discover -s tests -v
```

完整重跑并记录结果：

```sh
sh reproduce.sh
```

该脚本仅在本目录内更新 `logs/`。`logs/demo.json` 是真实程序输出，不是手工填写的答案；`logs/tests.txt` 是真实测试记录。连续两次演示输出必须逐字节相同。`logs/verification.txt` 记录这项检查及案例数量。

## 你会看见什么

21 个案例，以及 31 个测试方法：

- 肯定前件（MP）、否定后件（MT）有效，且前提确有满足模型。
- 否定前件、肯定后件无效，二者都有反例 $`p=\bot,\ q=\top`$。
- 单独给出 $`p\to q`$，不能断定 $`p`$、$`q`$，也不能断定它们各自的否定。
- 一个赋值上蕴涵为真，不等于在允许的所有情形中 $`p`$ 都保证 $`q`$。
- 穷尽性支持“非物体，所以精神”；互斥性支持“物体，所以非精神”。两项分别检查，不能偷换。
- 前提不相容或整个理论无模型时，经典语义蕴涵真值虽为真，输出同时明确标记空真及其原因。

这里 `valid` 的精确含义是：在指定理论允许的赋值中，不存在“所有前提真而结论假”的赋值。它不保证前提符合现实。请同时阅读 `theory_consistent`、`premises_consistent`、`warning`。

## 原文与编码之间的桥梁

| 原文位置 | 阅读要点 | 现代实验表示 |
|---|---|---|
| 139 下部—140 | 从简单命题转向复合、假言命题 | 完整命题用原子 $`p`$、$`q`$ 表示 |
| 140—141 | 报纸真实与和平临近；仅说条件不再断言其他事实 | `implies` 与 `conditional_alone_*` |
| 141 | 两个正确条件推理形式 | `modus_ponens`、`modus_tollens` |
| 142—143 | 两个错误形式及其说明 | `denying_antecedent`、`affirming_consequent` |
| 143 | “$`A`$ 是 $`B`$”叫前件；“$`C`$ 是 $`D`$”叫后件 | $`p`$ 是整句“$`A`$ 是 $`B`$”，不是项 $`A`$ |
| 143—144 上部 | 物体／精神的两个推论 | 穷尽性、互斥性分开施加 |

报纸例中，$`p`$ 表示“报纸在当前约定范围内的报道全部属实”，其中包括和平消息，也允许有其他报道；$`q`$ 表示“和平临近”。不能把 $`p`$ 缩窄为和平这一条消息属实，否则可能使它与 $`q`$ 同义，掩盖原文针对推理形式的区分。

重要限制：原文说后件是前件的“必要结果”。本实现的 `implies` 首先只是现代经典材料蕴涵的真值运算。`Theory` 再用允许世界和约束表示“在所选情形中没有 $`p`$ 真、$`q`$ 假的反例”。这可帮助区分单次真值与受约束的后承关系，但不是对欧拉的“必要性”给出完整的模态、因果或认识论解释。

代码不会由报纸内容判断真实世界的和平，也不会证明实体只能是物体或精神。这些示例只是原文论证结构的抽象。本文不提出欧拉与后世 AI 系统之间的历史因果关系。

## 自己输入一个论证

`main.py check` 读取 JSON 文件，必须有 `atoms`、`premises`、`conclusion`；可选 `constraints`、`allowed_worlds`。

```json
{
  "atoms": ["p", "q"],
  "constraints": [["implies", "p", "q"]],
  "premises": ["p"],
  "conclusion": "q"
}
```

表达式支持布尔常量、已声明原子、`["not", f]`、`["and", f, g]`、`["or", f, g]`、`["implies", f, g]`。`or` 是包含式“或”。没有隐含的排他性。没有自然语言解析，也不使用 Python `eval`。

`allowed_worlds` 可列出完整赋值字典；不提供或给 `null` 表示枚举全部赋值，给 `[]` 则表示零个世界。约束再与这些世界取交集。世界自动去重、排序；每个世界必须恰好给所有原子赋布尔值，不接受 0、1 代替布尔值。

原子名符合 `[A-Za-z][A-Za-z0-9_]*`，最多 12 个，不许重名。表达式树深度不超过 64（根的深度为 0）。未知原子、操作符、字段、重复 JSON 键以及参数数目错误会被拒绝。输入文件错误退出码为 2；计算出一个无效论证仍属成功计算，退出码为 0，须检查结果中的 `valid`。

本工具是小规模、经典二值、命题层的穷举模型检查器。复杂度随原子数呈指数增长，因此设置 12 原子上限；它不是通用定理证明器，也没有重建范畴命题中主词／谓词的内部结构。无需 Notebook：全部步骤可从终端或阅读 JSON 结果完成。
