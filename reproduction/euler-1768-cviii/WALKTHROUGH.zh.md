# 从阅读到实验

## 1. 先确定形式化的单位

欧拉写的是“如果 $`A`$ 是 $`B`$，那么 $`C`$ 是 $`D`$”。前件是整句“$`A`$ 是 $`B`$”，不是其中的项 $`A`$。令 $`p`$ 表示前件整句，$`q`$ 表示后件整句。此处只研究命题之间的连接，不试图在 Python 中重做前几封信的项逻辑。

报纸例也同样：$`p`$ 表示“报纸在当前约定范围内的报道全部属实”，其中包括和平消息，也允许有其他报道；$`q`$ 表示“和平临近”。不能把 $`p`$ 缩窄为和平这一条消息属实，否则可能使它与 $`q`$ 同义。我们不把新闻报道的事实真伪写进程序。

## 2. 一个四行实验

以 $`\bot`$ 表示假、$`\top`$ 表示真，赋值顺序为 $`(p,q)`$。`Theory(["p", "q"])` 枚举 $`(\bot,\bot)`$、$`(\bot,\top)`$、$`(\top,\bot)`$、$`(\top,\top)`$ 四个赋值。材料蕴涵只在第三行，即 $`p`$ 真而 $`q`$ 假时为假。

MP 的前提为 $`\{p\to q,p\}`$，唯一满足前提的行是 $`(\top,\top)`$，所以结论 $`q`$ 为真。

MT 的前提为 $`\{p\to q,\neg q\}`$，唯一满足前提的行是 $`(\bot,\bot)`$，所以结论 $`\neg p`$ 为真。

否定前件的拟议后承 $`\{p\to q,\neg p\}\models\neg q`$ 则失败：$`(\bot,\top)`$ 满足两个前提，但 $`\neg q`$ 假。肯定后件的拟议后承 $`\{p\to q,q\}\models p`$ 也被同一行反驳。

`demo` 为这两个无效形式返回实际反例字典，而不是只贴上“无效”标签。

## 3. “仅说条件”没有断言组成命题

满足 $`p\to q`$ 的有三行。两者全假这一行反驳了从条件单独推出 $`p`$ 或 $`q`$ 的企图；两者全真这一行反驳了从条件单独推出 $`\neg p`$ 或 $`\neg q`$ 的企图。

所以“条件不单独断言前后件”不表示它没有内容：它排除了 $`p`$ 真、$`q`$ 假的组合。也不表示在额外理论约束下永远不能得出任何组成命题。

## 4. 单点真值与受约束后承不同

`evaluate(["implies", "p", "q"], {"p": False, "q": True})` 为真。但在不受约束的四个世界里，$`p`$ 并不蕴涵 $`q`$，因为 $`(\top,\bot)`$ 仍然被允许。

若明确把 $`p\to q`$ 作为理论约束，`Theory(["p", "q"], constraints=[["implies", "p", "q"]])` 只留下三个允许世界，此时 $`p`$ 在该理论中蕴涵 $`q`$。直接列出同样三个允许世界会给出完全相同的结果。

这项比较区分“某次赋值使公式为真”与“所选理论支持这个推论”。约束来自建模者的明确假设，程序没有从单次观察自动学到约束，更没有证明其事实根据。它也不是一个足以解释欧拉全部‘必要结果’含义的历史语义理论。

## 5. 将末尾的‘或’拆成两个条件

取一个固定且已假定为实体的对象。令 $`\mathsf{body}`$ 表示它是物体，$`\mathsf{spirit}`$ 表示它是精神，对应源码原子名 `body`、`spirit`。原文的全称“所有实体”在这里通过任取一个实体考察其命题结构；程序并不证明该形而上学分类本身。

- 穷尽性 $`E`$：$`\mathsf{body}\lor\mathsf{spirit}`$，至少一个成立。
- 互斥性 $`X`$：$`\neg(\mathsf{body}\land\mathsf{spirit})`$，至多一个成立。

四组理论各检查两个推论，表中后承均相对于该行理论：

| 理论 | $`\neg\mathsf{body}\models\mathsf{spirit}`$ | $`\mathsf{body}\models\neg\mathsf{spirit}`$ |
|---|---|---|
| 无 $`E`$、无 $`X`$ | 无效 | 无效 |
| 仅 $`E`$ | 有效 | 无效 |
| 仅 $`X`$ | 无效 | 有效 |
| $`E`$ 与 $`X`$ | 有效 | 有效 |

仅 $`E`$ 时，$`\mathsf{body}=\top,\ \mathsf{spirit}=\top`$ 仍可出现，故不能由 $`\mathsf{body}`$ 推出 $`\neg\mathsf{spirit}`$。仅 $`X`$ 时，$`\mathsf{body}=\bot,\ \mathsf{spirit}=\bot`$ 仍可出现，故不能由 $`\neg\mathsf{body}`$ 推出 $`\mathsf{spirit}`$。

`example.json` 专门演示“仅 $`E`$”不足以支持第二个推论。它应输出 `valid=false` 和两者全真的反例。

这说明要使原文列出的两个推论都成立，现代重建需要两项性质；并不声称欧拉本人以现代包含式析取为先，再偷偷添加了一个前提。原文的‘或’及分类背景可能本来就承载两项性质。实验目的在于把逻辑负担显明化。

## 6. 不要把空真当作可靠的事实推断

前提 $`p`$ 与 $`\neg p`$ 同时给出时，没有任何经典赋值能满足前提。因而找不到前提真、结论假的反例，`valid=true`。但 `premises_consistent=false`，并给出 `inconsistent premises ... validity is vacuous` 警告。

如果冲突发生在理论约束中，连允许世界都没有了，`theory_consistent=false`，警告改为 `empty theory ...`。这种情况下，“任何结论都有效”只是本模型的经典后承定义所致，不能拿来确认一个现实结论。

## 7. 一般论证与本次有限检查分开

上述 21 项输出是特定有限模型的检查结果。下面才是一般结构说明：

1. 对任意经典命题 $`P`$、$`Q`$，在任意满足 $`P\to Q`$ 且 $`P`$ 的赋值中，$`Q`$ 不可能为假，否则 $`P\to Q`$ 就为假。因此 MP 对任意命题替换都成立。
2. 在任意满足 $`P\to Q`$ 且 $`\neg Q`$ 的赋值中，$`P`$ 不可能为真，否则同样违反条件。因此 MT 也具有任意命题替换的有效性。
3. 令 $`P`$ 假、$`Q`$ 真，便得到否定前件及肯定后件的共同反例。一个反例足以推翻这两个形式的普遍有效性；不表示它们在每个有额外限制的理论中都失败。
4. 对任意对象，若至少属于物体、精神中之一又不属物体，则必属精神；无需互斥性。若至多属其中之一又属物体，则不属精神；无需穷尽性。

本工具对每个输入的有限原子集穷举全部允许赋值，因而对所指定的二值有限语义给出完整检查，不是随机抽样。但这不能外推为无限域的一阶证明、自然语言条件句的一般解释、现实前提的真实性证明，或欧拉对现代逻辑／AI 的历史影响证据。

测试中的嵌套替换实验另将 $`p`$ 替换为 $`a\land b`$、$`q`$ 替换为 $`c\lor d`$，检查四个原子的 16 个赋值。这是额外实例验证；一般证明仍以上述逐赋值论证为依据。
