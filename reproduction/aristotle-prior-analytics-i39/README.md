# I.39：显式定义展开与保真替换

服务于[《前分析篇》I.39中文深读](../../papers/ancient/aristotle-prior-analytics-i39.zh-CN.md)的原创现代教学重构。原章49b3–9讨论同义表达的替换和列项简化；以下集合、表达式树与程序不是古代算法原样复刻，也不是自然语言同义识别器。“不是属”的原文例没有被程序擅自翻译为集合不交。程序仅运行自有人工例。

## 输入与约定

只用Python标准库。论域是有限整数集合，可为空；重复输入按集合处理，布尔值不当作整数对象。每个原子名称对应显式给定的论域子集。

|接口|含义|
|---|---|
|`Atom('P')`|原子谓词P；其外延来自模型|
|`Ref('ready')`|引用已声明的定义，而非另一种原子写法|
|`And(left, right)`|两项外延交集|
|`Not(child)`|相对于当前论域的补集|
|`Definitions(dict)`|保存并检查所有定义；未定义引用或任意循环均拒绝，包括未被查询的定义|
|`defs.expand(term)`|递归展开引用，保留原子及复合结构|
|`defs.equivalent_by_definition(a,b)`|仅比较展开后的结构是否完全相同|
|`Model(domain, extensions)`|保存论域及原子外延；外延越出论域报错|
|`model.extension(term,defs)`|计算项外延；缺失原子报错，不把未知解释为假|
|`model.proposition(kind,s,p,defs)`|判断A/E/I/O四类现代集合命题|

A表示主项外延包含于谓项；E表示二者不交；I表示交集非空；O表示主项减去谓项非空。空论域或空主项使A/E真、I/O假。这是明确的现代教学语义选择，不冒充原章的存在承担政策。

`Atom`与`Ref`属于两个显式命名空间；`Atom('ready')`不自动指向`Ref('ready')`。程序不会凭相同文字猜测意图，不允许循环定义，也不求循环方程的最小或最大不动点。输入定义是人为指定的约定，并非程序从语料认证出的自然语言事实。用户应使用通常构造接口，不通过反射篡改对象内部状态。

## 一个可追踪的自有例

将P理解为“设备已充电”，Q理解为“设备已登记”。定义`ready := And(P,Q)`，再定义`available := Ref('ready')`。在论域`{0,1}`中取P外延为`{0,1}`，Q为`{1}`，两名称展开后都表示交集`{1}`。以该定义项为主项或谓项时，A/E/I/O真值均与直接写交集一致。

命名不会产生原来没有的内容。若“可用设备”在实际业务里还要求安全检查，那么上述定义只是错误或不完整的建模选择；程序成功不认证业务正确。定义的外部根据仍须人工论证。

## 一般论证与程序检查的区别

对有限无环定义依赖图，可按依赖次序先解释原子、再解释定义。引用项的外延按其定义右侧解释；And取交、Not取补。对项结构归纳：原子不变；引用替换为定义右侧按约定不变；若子项外延保持，则它们的交集和补集保持。因此展开保留外延；包含、不交及非空性只依赖这些外延，所以AEIO在主项或谓项位置的替换保留真值。此论证不限制论域有限，也不由下面的有限枚举来证明。

程序直接使用展开来实现定义语义；主检查脚本中的展开前后比较是实现回归，不应被宣传为两个独立语义算法的一致性验证。独立审查需另外建立oracle及逐对象语义检查。

结构相同是**充分而非必要**证书。例如`And(P,Q)`和`And(Q,P)`外延总相同，但本程序拒绝为它们签发该结构证书。拒绝不表示不同义、不等价或论证无效；只是这一个受限检查器没有给出证明。单个模型中P与Q碰巧同外延更不足以获得定义证书。

## 反例

1. **单向包含不够。** P=`{0}`，Q=`{0,1}`，R=`{0}`。P包含于Q且P包含于R，但Q不包含于R。因此，不能仅凭“所有P是Q”就把任意语境中的P改为Q；这里展示的是主项扩张失败，不声称所有单向替换方向都失败。
2. **一次同外延不等于一般同义。** 在单对象模型取P=Q=`{0}`，二者外延相同；另取上述双对象模型，P与Q即分开。定义环境没有P/Q同义约定，故不会把偶合当作证书。
3. **同字不同义不能充当同一中项。** C=M1=`{0}`，M2=A=`{1}`。C包含于M1和M2包含于A都真，C包含于A假。把M1、M2印成同一个词不能补上缺少的桥接。

这些例子均为现代教学模型，不是对古例的历史解释定论。
