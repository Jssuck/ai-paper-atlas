# 《几何原本》VI.1：同高图形的底边、面积和倍量

这是 [VI.1 中文深读](../../papers/ancient/euclid-elements-vi1.zh-CN.md) 的教学复现。三角形的有理坐标面积由行列式绝对值的一半求出；平行四边形取相邻边向量的行列式绝对值。现代数值公式只用于检查，不是欧几里得的证明或古代运行记录。

`fan` 从公共底点沿底线拼接给定数量的等长小底边，给每一段连接同一个顶点。它独立求每片三角形和整块三角形，并用可剪切的平行四边形核对面积倍数。基线长度、高度必须为正，倍数必须为正整数。有理坐标输入用 Python 整数或 `Fraction`，不接受浮点近似。返回的比较顺序是：延长底边、整块三角形、平行四边形；−1、0、+1 分别表示小于、等于、大于。

- 同高算例：两底 2、3，高均为 4。用 (1,1)、(3,2)、(4,2) 分别得到三个同时为小于、等于、大于的分支。在 (3,2)，两延长底均为 6，两块三角形面积均为 12，两平行四边形均为 24；左三块小三角形各为 4，右两块各为 6。
- 去掉同高：仍取两底 2、3，但高度变成 4、2。在 (1,1)，底边比较为小于，却分别得到三角形面积 4、3，平行四边形面积 8、6，两种面积比较都为大于。
- 不可公度：底边 1、√2，高度 2。三角面积是 1、√2，平行四边形面积是 2、2√2。对正量比较可等价比较平方，探针因此全用整数运算。底边比较化为比较 m² 与 2n²；平行四边形化为比较 4m² 与 8n²。这里并未实现一般代数数或以有限探针证明卷 V 的全称条件。
- 另遍历 1–4 组成的 1,024 个同高五元组，直接整数乘积作独立参照；检查非整数倍及零高等非法输入。无历史实验数据。
