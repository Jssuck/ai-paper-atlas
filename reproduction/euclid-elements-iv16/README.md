# 《几何原本》IV.16：用同向弧差构作正十五边形

[回到正文](../../papers/ancient/euclid-elements-iv16.zh-CN.md)。本目录用现代代数复现主命题的弧差、平分、逐弦步进与验收；不从画面测量角度，不模拟完整尺规原语，也没有复现原文末尾的三种类比构作。

## 精确模型

- 在同一个单位圆，从公共点 A 沿同一方向标五边形相邻点 B、三角形相邻点 C。弧 AB、AC 各是整圈的 1/5、1/3，差 BC 为 2/15；弧中点 E 给出 1/15 步幅。取任意圆心与正半径只作相似变换：模型中的弦长平方和内积都乘半径平方，等式与边界顺序不变。
- 构造端用有理转数求差和折半。比较端用十五次本原单位根 z=exp(2πi/15) 表示点，并以 Φ₁₅(x)=x⁸−x⁷+x⁵−x⁴+x³−x+1 的余数（八个整系数）给出精确代数证据。弦长平方为 (zᵃ−zᵇ)(z⁻ᵃ−z⁻ᵇ)；两条同起点边向量 u、v 的双倍内积为 u·conj(v)+conj(u)·v。无三角函数近似参与比较。顶点共圆在表示中成立，不是从任意点集侦测共圆。
- 步进序列一共十六项：前十五项是候选顶点，末项单独检验是否正确返回首点。正则证书同时要求闭合、十五点互异、所有步沿同一方向接续相邻弧、非零等弦和等角。等角子检查本身只比较内积，等边与凸边界结合起来才推出内角相等；不把自交多边形上的较小夹角当作凸多边形内角。
- 错侧控制：B 在负向第五圈、C 在正向第三圈时，沿正向取 BC 得 8/15，折半得 4/15。因 4 与 15 互素，轨道也闭合且采齐十五点，弦长和局部夹角仍各自相同，但跳过相邻点而自交。同侧误取大弧则给 13/30 步幅，分数模一检查显示首次在第 30 步返回；十五次单位根表示明确拒绝该分支，不伪造三十边形的精确几何结果。
- 另测试步幅 5/15 导致的过早闭合、逐次交换相邻顶点错序，以及保留十五点却不给正确闭合终点。正则性验收和“是否走回起点”是不同问题。

## 环境与复跑

在本目录执行以下命令。仅需 Python 3.12.14 标准库；日志只归一化 unittest 计时。

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python polygon15.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

十五个起点乘两种方向，精确验证 30 组正例、30 组错侧反例和 30 组缺闭合反例；普通、-O、-OO 模式各通过 9 项单元测试。环境无可执行 Jupyter 命令、内核和模板辅助脚本；按教程结构生成 Notebook，实际用标准库 compile/exec 顺序重放三个代码单元，并保留日志，不声称运行 Jupyter 内核或前端。此有限试验仅检验上述实现，不能替代构作的一般证明。
