# 《几何原本》X.30：两个差平方边都不与原线段长度可公度

取参考长度 `u>0`。输入 `h=(H/u)^2` 是正有理数，整数 `m,n` 均为正且允许相等，要求 `N=m²+n²` 不是整数平方。`construct(h,m,n)` 返回相对平方 `l=hm²/N,g=hn²/N` 及长度比 `L/H,G/H` 的平方 `m²/N,n²/N`。所以 `H²−L²=G²`；两个长度比皆无理，然而对应的平方比均有理。与 X.29 的不同在于，此次差平方的边 `G` 也不与 `H` 在长度上可公度。代码保持精确分数，不近似根式，不模拟尺规。

例如 `h=1,m=1,n=2` 得两个相对平方 `1/5,4/5`。也可令 `m=n=1`，此时两段相等，但与原线段的比皆无理；`m=3,n=4` 的平方和是 25，会使两个比例有理，因此被拒。

独立基线生成整数 `1..90` 的平方，不调用整数平方根。对 `1≤m,n≤64`，(N≤8192)，而 `91²>8192`，所以枚举覆盖所有可能的整数平方和，以及归约后的比平方分子与分母。实跑 4,096 个有序整数对，其中接受 4,022 个、拒绝 74 个；验证相对平方相加为 `h`，并独立检验两个比平方均不是有理数的平方。有限校验不是一般性证明。

python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
