# I.13 教学模型：独立代码审查

结论：在下列明确范围内通过。审查者不是模型与原测试的作者；未将原作者的运行报告直接当作独立结果。

## 检查与发现

阅读了 `model.py`、`test_model.py`、`demo.py`、保存结果、环境、README、WALKTHROUGH，并与正文的 N/P/C、逐对象 U/T、固定主项和可能主项定义对照。模型是固定非空有限论域、非空世界集合的现代教学语义；不声称实现亚里士多德原章的唯一解释。

- 使用与集合实现不同的整数位掩码 oracle，对二对象的一、二、三世界模型分别穷举16、256、4096个，总计 **4368个模型、17472个固定主项对、69888个句子真值向量**；核对U/T、实际与可能主项、四种整句真值及偶然性，并直接核对补集与换项外延。
- 独立重跑 normal、`-O`、`-OO`：每模式 **22个测试方法通过**；三份 demo 输出均与保存的 `results.json` 逐字一致。未以 Python `assert` 承担独立 oracle 的检查，因此优化模式不会取消检查。
- 审查输入拒绝范围、空主项真值、非必然但不可能反例、逐对象与整句量词差别、补谓词与交换项位的区别、零权重概率1不等于必然的边界。未发现实现与所声明定义不符。
- 进行了8个隔离 mutation：将C改为P、U改为存在、T改为全称、可能主项改为实际主项、all改some、none改notall、补集改原样、允许空真值列。

初轮中7个被原20项测试捕获，**补集改原样的 mutation 存活**。这暴露的是测试覆盖缺口，不是生产实现错误：只检验偶然性对补集不变，无法验证程序真的取补集。作者增加了直接补集及换项外延检查（含空、全、部分外延、三世界、原模型不变及两次操作复原），总数升至22项。复审后 **8个 mutation 全被捕获**，且失败摘要是测试断言失败，不是导入或语法错误。保留[初轮报告](code-review/report-before-coverage-fix.json)而未抹去发现过程。
