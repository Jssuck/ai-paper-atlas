# II.21：从可导结论到实际合用前提——有限教学实验

本目录为原创现代教学重构，不是古代算法、完整认识论形式化、心理实验或生物学验证。实读依据：Jenkinson（1913），《前分析篇》II.21，66b18–67b26；[Book II 全章与译注](https://en.wikisource.org/w/index.php?title=The_Works_of_Aristotle/Prior_Analytics/Book_II&oldid=15924675)。对应双中项讨论、三角形的普遍与个别、骡例的前提持有与实际合用。章末善恶实质同一的语义问题没有编码；不以集合相等替代其哲学问题。

## 1. 两个独立模块，不混淆“世界”与“相信”

`premises(world)` 返回四个命题在集合世界中的**真值**，不是主体持有状态：

- p1：B ⊆ A；p2：D ⊆ B。
- p3：A ∩ C = ∅；p4：D ⊆ C。

原文的真实背景可令 A 同时属于 B、C；p3 则是主体的错误意见。程序不把 p3 叫作知识；此模块专门检查四项说法能否共同为真，不声称它们都是原文世界的事实。由 p1、p2 可推出 D ⊆ A；由 p3、p4 可推出 D 与 A 不交。因此若 D 非空，四项不可能同真。D 为空时没有这个矛盾；这用于显式暴露现代空类语义的差异，不能把它当作原文已采用空类语义的证据。

删除 p4 后可一致。例如 A=B=D={0}、C=∅。若希望所有术语均非空，可在二元域中令 A=B=D={0}、C={1}；同样满足 p1、p2、p3 而不满足 p4。因此缺桥而未合成双路径，不等同于已经正面持有相反结论。程序不模拟人的实际注意力。

`RecognitionState` 使用另一个**固定真世界**：某个个体 c 属于 B，也属于 A，而且所有 B 都属于 A。`universal_stored` 与 `recognition_stored` 分别是已持有这两个真前提的记录；false 只代表未在本模型中持有，不代表持有其否定。`negative_opinion` 则是错误地认为 c 不属于 A 的记录，永远不计为知识。`acquire_verified` 另作输入防线：只有世界中真实的个别归属可进入知识侧记录。

- `available = universal_stored and recognition_stored`：给定两项都在，推论可供执行。
- 初始 `exercised=False`，即使两项都持有也不偷偷做逻辑闭包。
- 只有显式调用 `.exercise()` 才形成新状态，标记已实际合用；缺前提则报错。
- `explicit_conflict` 仅在已合用并且保留否定意见时为真。它是冲突报警，不是允许矛盾知识，也不说明心理上能够稳定维持这种状态。程序保留意见以显示待解决的冲突，**没有自动撤回、说服或修复规则**。

这三个存储旗与一次调用只是教学接口；不是把原文“知道”的三义直接等同于三个互斥布尔位。模型不把“不知 p”改写成“知非 p”，不把持有真前提强制替换为已实际知道结论。骡例仅提供历史问题动机；固定真世界中的 A、B 没有声称现实中所有骡都满足无例外生物学规则。

## 2. 有限穷举及可以独立手算的校验

`worlds(n)` 枚举固定标号域 {0,…,n−1} 上四个集合的全部取值。每个个体有 16 种四术语隶属型，故总数是 16 的 n 次方；不按同构合并，不抽样。

| n | 世界数 | 四前提 + D 非空 | 四前提 + D 为空 | 仅 p1,p2,p3 + D 非空 | 正路径 + D 非空 | 负路径 + D 非空 |
|---|---:|---:|---:|---:|---:|---:|
| 1 | 16 | 0 | 4 | 1 | 2 | 2 |
| 2 | 256 | 0 | 16 | 9 | 28 | 28 |
| 3 | 4096 | 0 | 64 | 61 | 296 | 296 |

共检查 4368 个带标号集合世界。四前提要求每个个体 D=0，余下 (A,B,C) 有四种合法型，所以 D 为空的计数为 4 的 n 次方。缺 p4 时多出一种 D=1 的合法型，非空计数为 5 的 n 次方减去 4 的 n 次方。单独正路径/负路径分别有八种局部型，其中六种 D=0，非空计数均为 8 的 n 次方减去 6 的 n 次方。这些手算解释可核对输出，有限实跑本身不证明任意基数的定理；上述集合包含/交集推导才给出一般理由。

认知记录模块列出 u/r/o 的全部 8 种初态：2 种具备合用条件，6 种因缺前提不调用（JSON `null` 意为未调用，不是 false）；可调用的两种中，1 种调用后报警，另 1 种不报警。所有初态均尚未实际调用。这是接口定义与枚举的结果，不是人类认知状态分布。

## 3. 运行与证据

只用 Python 3 标准库，无安装、网络、随机数、私有数据或密钥。

```sh
cd reproduction/aristotle-prior-analytics-ii21
sh run.sh
sha256sum -c SHA256SUMS
```

`run.sh` 对同一源码真实执行 normal、`-O`、`-OO` 三模式，分别跑 12 个 `unittest` 用例及 JSON 枚举。测试使用 `self.assert*` 和显式异常，不依赖会被优化删除的裸 `assert`。三份 JSON 已用 `cmp` 核验逐字一致。实际版本与平台见 `results/environment.txt`，完整测试命令和结果见 `results/*-tests.log`，枚举见 `results/*-results.json`。

`SHA256SUMS` 绑定已保存的源码、说明、命令与实跑证据；它不包含自身。重跑会更新测试耗时等日志，需重新生成清单才能验证新日志，不能拿新跑的时间文本冒充原日志。输入范围限 n=1,2,3；布尔值不能冒充整数规模，集合扩展必须用非负整数的 `frozenset`；状态旗必须是真布尔，非法预置“已合用”状态被拒绝。

## 4. 局限与教学复盘

不形式化立即归属/本性、存在的认识、记忆时间、所有三段论式、善恶实质同一、意见的完整闭包与心灵因果。真值模块与认知模块刻意分开，不能从有限记录推断真世界，也不能从世界中的蕴涵推断已完成心理操作。练习：为什么删掉 p4 时无冲突？答：负路径从 C 到 D 的桥不存在，不能推出 D 与 A 不交。为什么 u=r=true 而未 exercise 时仍不报警？答：报警特指实际合用后与保留意见冲突，不否认错误意见在客观上早已为假。
