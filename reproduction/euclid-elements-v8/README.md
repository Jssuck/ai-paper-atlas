原典分析见[中文精读](../../papers/ancient/euclid-elements-v8.zh-CN.md)。本目录是现代正有理数量的原创教学模型，不是古代文本、几何图版或通用实数推理器。

## 检查了什么

- 同类量 a > b，共同项 c；差量 d = a − b。m 取使 m·min(d,b) > c 的最小正整数，n 取使 n·c > m·max(d,b) 的最小正整数。用整数除法构造倍数，不做近似商。d = b 的第三个分支是教学补明。三个实跑示例所得夹逼分别为 15 < 21 < 24、10 < 14 < 20、9 < 28 < 30。
- 前项比较使用 (m,n)，共同前项的后项比较改用 (n,m)，并交换大小排列；两者的符号均为 (+1,−1)。单独的 V.Def.7 检查允许第二项取等；例 (3,2,2) 的 (1,1) 正向有效、反向无效。
- (102,101,100) 的正向比较在双倍数上界为 20 时找不到见证；上界为 52 时找到 (51,52)。构造不要求得到所有可能见证中最小的一对。找不到见证时程序只返回 None，不判定等比。
- 11 个测试检查 19 个不同正有理数形成的 3,249 个有序合格三元组、三种差量分支、等号边界、严格取下一倍数、不同类量与非法输入。V.Def.7 的通用检查允许两组比各自同类而彼此不同类；V.8 三项因共用 c 必须同类。
- 有限网格和有理数模型只帮助检验实现；不能证明欧几里得对一般量的命题，也未模拟非阿基米德量。
