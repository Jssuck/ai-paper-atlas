# VII.26：两组的交叉互素性传递到乘积

现代正整数教学重构，不是古代实跑记录或一般定理的计算证明。A、B 各自与 C、D 各自互素，共四个交叉条件。第一次用 VII.24 得 E=A×B 与 C 互素；第二次得同一个 E 与 D 互素；第三次让 C、D 分别对 E 应用 VII.24，得 F=C×D 与 E 互素。程序逐步生成这三个证书，测试用因数枚举与现代整数乘法独立核对。
