# VII.26 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.26.html)、Heath 1908 卷 II 印刷页 327（扫描物理页 340，含图、完整证明及评注）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=215) 印刷页 215 和 [Joyce VII.26](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII26.html)。

希文 Α、Β、Γ、Δ、Ε、Ζ 对应英文 A、B、C、D、E、F。E 是 A 乘 B 的积，F 是 C 乘 D 的积。题设的“二者各对每一个”给出 A 与 C、A 与 D、B 与 C、B 与 D 四条跨组互素，不给出 A 与 B 或 C 与 D 的组内互素。

[VII.24](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII24.html) 在证明里实际有三次实例化。先由 A、B 各与 C 互素得到 E 与 C 互素；同理把 C 换成 D，得到 E 与 D 互素。最后利用互素关系的对称性，让 C、D 各自与 E 互素，再由同一命题得它们的积 F 与 E 互素。Heath、Fitzpatrick、Clay 和 Joyce 的证明只在展开写出的首、末两步标出 VII.24，中间一次缩写成“同理”。所以区分两处可见引文和三次具体使用。Clay 英栏止于 C、D 的积是 F；希栏、两印本和 Joyce 都明确写出 E 与 F 互素。

Joyce 导读的案例有一个乘积写错：45×75=3375 正确，26×77 应为 2002，不是 1144。用现代最大公因数核算，3375 与 2002 互素，3375 与误写的 1144 也恰好互素；后一点只说明误数偶然保持了结论，不能令其成为 26×77 的正确算例。此例属于导读，不是希文或印本的勘误。

[VII.27](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII27.html) 直接应用本命题：前面已得到 A、A² 分别与 B、B² 的四个跨组互素条件，再将两组分别相乘得到两个立方互素。本命题正文没有陈述任意长度的因子列表或任意幂次；若推广，应另给迭代或归纳论证。

所核 Heath 1908 扫描卷前及命题页、Fitzpatrick 命题页与公开对读文本未见针对 VII.26 的正式勘误；不声称校遍所有印次。
