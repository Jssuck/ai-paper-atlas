# VIII.9：同数目的单位端点链

这是现代整数教学重构，并非古代运行记录或一般命题的计算证明。设给定链有 n 步，相邻后项／前项的既约比为 p/q。以 h 为整体整数倍数，第 i 项就是 h·q^(n−i)·p^i，两端的最大公度为 h。原命题要求给定端点互素，于是 h=1，两条从单位出发的链分别为 1,q,…,q^n 与 1,p,…,p^n，有相同的 n−1 个中项。这里是现代整数模型，不把单位当作古文的给定「数」；含单位的给定链或恒等比必须显式选择现代模式。

(8,12,18,27) 得单位链 (1,2,4,8) 与 (1,3,9,27)。若给定链整体乘 2，两端 16、54 均不是立方，不能保证存在同数目的单位链；若整体乘 8，两端 64、216 都是立方，却依然在互素前提之外。程序对这些非互素输入都不提供原命题见证，不表示一般判定无解。

测试按 Fraction 另行试探精确整数根，并直接枚举端点公因数、检查单位链的相邻比。有限核对不替代原命题的证明。
