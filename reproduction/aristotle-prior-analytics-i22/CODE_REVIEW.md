# I.22 独立代码核验

审查对象：作者 `model.py`、枚举器、十八项单测、十二显式配置、正文 §3—7 的教学语义和数字模型。独立审查不改作者源码或原日志；实际执行见 [commands.json](independent-review/commands.json)，版本绑定见 [bindings.json](independent-review/bindings.json)。

## 方法及结果

[独立检查源码](independent-review/check.py) 不调用作者位运算量化函数求预期值，而是逐对象、逐情形重建谓项成员关系及量词。D/N/P/C 固定实际主项；BOX 每情形重取主项；N 的特称见证在情形全称量词之外；双向偶然同时要求正、负情形。穷举维度 (对象数, 情形数) 为 (1,1)、(1,2)、(1,3)、(2,1)、(2,2)。

正常、`-O`、`-OO` 每模式分别通过：

- 4744 配置 × 5 模式 × 4 量词 × 9 有序项对 = 853920 次 oracle 比较。
- 35640 次变形比较：情形重复、对象重标号、三词项一致改名。重复世界不能改变任何既定量词语义。
- 48 个非法输入检查，涵盖非法维度、形状、空情形、越界掩码、布尔冒充整数、非法模式/量词/词项/情形索引；不依赖可被优化移除的 `assert`。
- 十二作者配置额外 2160 次全查询 oracle 比较。
- 六个正文原样数字模型的 22 条明确真假主张，由 oracle 和实现分别确认。睡马正文二对象与作者三对象、双特称正文见证与作者配置并非逐字相同，故单独核验而未强制替换。空中项政策另由穷举和作者配置覆盖。
- 九类定向语义变异都发现区别见证：D→P、N→BOX、P→N、C→P、全称→特称、交换项位、否定→肯定、C→非N、N特称把情形量词移至对象量词外。完整见证保存在结果 JSON。这是语义替换测试，不冒称对任意源码突变的全面 mutation coverage。

三模式独立结果分别见 [正常](independent-review/result-normal.json)、[-O](independent-review/result-O.json)、[-OO](independent-review/result-OO.json)。另以三模式重新执行作者单测和枚举器，均为十八测试、4744 配置、七类枚举检查通过，重跑枚举 JSON 与作者已保存结果逐结构相同。作者 manifest 的全部 14 个文件 SHA256 逐一核对相符，原日志未覆盖。

## 结论与边界

未发现所审有限域的实现/定义差异，所列正文数字模型可复核；未发现优化模式使检查失效。独立 oracle 与作者程序有不同计算路径，但仍在同一明确教学定义下，不是独立历史语义证据。有限实跑不证明一般定理，不排除更大域或未覆盖输入问题，也不证明原典所有推理在这套 N/C/BOX 语义中有效。一般见证证明及原典译文分歧分别由数学和来源审查处理。
