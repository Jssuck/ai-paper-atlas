# 《几何原本》I.3：精确有理数教学复现

**这是原创、低成本的解析见证与证书检查器，不是尺规作图引擎。**
目标是在较长线段 `AB` 上截取 `AE`，使其等于给定较短长度。
本项目把目标记为 **平方长度 `C`**，不是长度本身：

$$
 A,B\in\mathbb Q^2,\qquad 0<C<\lVert B-A\rVert^2.
$$

只使用 Python 标准库；不安装任何依赖。实际验证环境见 `evidence/environment.json`。

## 2. 检查的是什么？

证书包含半径端点 `D` 和候选截点 `E`。令 `v=B-A`、`w=E-A`，检查器要求：

1. 严格输入域成立：`0 < C < dot(v,v)`；
2. 外部提供的 `D` 符合长度条件：`|AD|² = C`；
3. `E` 在以 `A` 为圆心、`AD` 为半径的圆上：`|AE|² = |AD|²`；
4. 线上关联：`cross(v,w) = 0`；
5. 严格点积界：`0 < dot(v,w) < dot(v,v)`；
6. 最终目标复核：`|AE|² = C`。

第 6 项在前面等式成立时可推得，仍保留以便教学和定位错误。
**第 5 项单独不表示点在开线段上；必须与第 4 项共线性联合使用。**
全部运算使用 `fractions.Fraction`，没有浮点容差。接口拒绝浮点数、布尔值和字符串；
例如应写 `Fraction(1, 10)`，不要先把 `0.1` 转成分数来假装精确的十分之一。

### I.2 的边界必须保留

`D` 是已给定的长度转移结果。程序可以检查 `|AD|²=C`，但这种结果相等：

- 不证明 I.2；
- 不说明 `D` 曾由允许的尺规操作构成；
- 不验证构造的历史、步骤或前提。

未提供 `D` 时，解析见证生成器直接设置 `D=A+(0,r)`。这只是一个方便的坐标见证，
**不能把它称为执行了 I.2**。本模型也没有编码原先那条较短线段的两个端点；它只接收其平方长度。

## 3. 解析见证与一般定理不是同一层

对 `L=|AB|` 和 `r=√C` 都是有理数的子族，生成器使用：

$$
 E=A+\frac rL(B-A).
$$

实现用整数平方根确认分子、分母都是完全平方数；遇到无理根明确抛出
`RationalWitnessUnavailable`，不会偷偷换成浮点近似。
这不是圆与直线求交器，也不是合法尺规操作序列的解释器。

**解析论证（不是“测试已证明”）：** 在实数欧氏平面中，若 `0<C<L²`，则
`t=√C/L` 满足 `0<t<1`，所以 `E=A+t(B-A)` 在开线段内且 `|AE|²=C`。
反过来，共线性和 `A≠B` 给出 `w=t v`；严格点积界给出 `0<t<1`；长度等式给出
`t²L²=C`。正根唯一，因此这样的截点唯一。这是坐标模型中的数学论证，
并非本项目提供的机器形式证明，也不替代尺规步骤的可执行性说明。

程序的**生成范围**比上述实数结论窄；**检查范围**又比生成器宽。例如：

```python
from fractions import Fraction as F
from euclid_i3 import Point, Certificate, verify
A, B = Point(0, 0), Point(1, 1)
E = D = Point(F(1, 2), F(1, 2))
print(verify(A, B, F(1, 2), Certificate(D, E)).valid)  # True
```

这里 `|AB|=√2`、目标长度 `√(1/2)` 都无理，但 `D,E` 的坐标有理，检查器无需开方即可接受。
生成器会拒绝此例，因为它刻意只覆盖两条长度分别有理的子族。
若真正的 `E` 有无理坐标，本项目没有代数数表示；不输出证书不等于原命题不成立。

## 4. 边界策略与反例

所有非严格输入都拒绝，不悄悄扩展命题：

| 输入 | 分类 | 几何解释／实现策略 |
|---|---|---|
| `0<C<|AB|²`，`A≠B` | `strict_cut` | 合法严格截取 |
| `C=|AB|²` | `equal_target` | 延伸任务可取 `E=B`，但不是本任务的严格截取 |
| `C>|AB|²` | `longer_target` | 开线段内不存在这样的目标长度 |
| `C=0` | `zero_target` | `E=A` 为零长，排除 |
| `C<0` | `negative_squared_length` | 无效平方长度 |
| `A=B` | `degenerate_segment` | 退化基线，优先拒绝 |

用 `A=(0,0)`、`B=(5,0)`、`C=4`、`D=(0,2)`：

| 候选／修改 | 能骗过什么？ | 失败条件 |
|---|---|---|
| `E=(2,0)` | 正确证书 | 全部通过 |
| `E=(-2,0)`，圆的另一个直线交点 | 长度与共线性都通过 | 仅严格点积界失败 |
| `E=(6/5,8/5)`，离线但同距离 | 长度与严格点积界都通过 | 仅线上关联失败 |
| `E=(10,0)`，超出 `B` | 共线性通过 | 严格点积界及长度失败 |
| 保持正确 `E`，改成 `D=(0,4)` | 最终目标长度仍通过 | 已给半径长度、圆关联失败 |
| `D=E=(0,0)` 且 `A=B,C=0` | 若只查距离等式会空泛通过 | 输入域及严格点积界失败 |

这说明：**只看“数值长度算对了”会漏掉方向、线上关联、线段位置和依赖输入。**

## 5. 实际证据与计数口径

已实际运行 **33 个有意义的 unittest 方法**，在普通、`-O`、`-OO` 下各通过一次。
不是 99 种独立测试；三次是同一套测试在不同优化模式下复跑。
实现及测试均不使用会被优化删掉的 Python `assert` 语句；测试用 `unittest` 检查方法，
实验循环使用显式条件和异常。

确定性子族覆盖：

- 8 个有理单位方向：横纵正负方向及非轴向毕达哥拉斯方向；
- 3 个原点位置：零、整数平移、分数平移；
- 5 个有理长度：`1, 5/2, 13/7, 10¹², 10⁻¹²`；
- 5 个严格比例：`1/10, 1/3, 1/2, 2/3, 9/10`。

因此 `8×3×5×5 = 600` 个合法证书全部接受。每例生成四种有结构的无效变体，
共 **2,400 个全部拒绝**，逐类均为 600。它们是有限的确定性样本，不是随机总体统计。
测试另外检查极小 `10⁻¹⁰⁰`、极大平移 `10¹⁰⁰`、极接近端点但仍严格的有理点、
无理长度的范围边界、非法类型和退化输入。这些检查没有声称代码行覆盖率百分比。

## 6. 不应从这些结果推断什么

- 600 个正例和 2,400 个反例不能证明一个普遍几何定理。
- 精确坐标证书通过，不表示找到或检查了古典尺规作图过程。
- AD 的距离复核，不表示证明了 I.2 或核查了其操作来源。
- 本项目不是任何历史 AI 系统的忠实实现，也没有提供历史实验性能对照。
- `-O` 与 `-OO` 通过说明这些检查没有依赖被删去的 `assert`；不等于无缺陷证明。

本目录用于把“存在性论证、解析生成、证书检查、有限测试、作图操作”五层明确拆开。
