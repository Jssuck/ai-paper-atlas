# III.15：直径最大与弦长、垂距的反向次序

本目录是自有标准库教学代码，不是尺规作图引擎、古典证明助理或完整复现。它检验同一圆中有效弦的有限精确坐标证书；一般定理仍依赖正文证明。

## 输入与输出

`Circle(center, radius)`接受两个坐标与严格正半径，各为`int`或`Fraction`，拒绝浮点及布尔。`chord(c,a,b)`要求不同端点都在该圆周上。它先由直线投影计算参数和垂足，随后给出长度平方、垂距平方、半弦平方及直径标记，不把垂足中点或平方恒等式作为输入。

`compare(c,a,b,d,e)`独立计算两条弦，输出`length_order`和`distance_order`（第一条较小/相同/较大分别−1/0/+1）、反向次序是否成立、各自是否不超过直径。长度和距离非负，平方保持大小次序，所以无需浮点开方。相等分支返回0/0；任意两条直径都并列最大，严格不等只适用于非直径弦。

`validate`严格检查证书字段、类型，并根据端点重算；不是一般证明认证器。实际圆周坐标由有理参数化产生，再枚举任意不同点对，未按待证结论过滤。完整实数圆上的无理坐标不属于这个有限实现接口。
