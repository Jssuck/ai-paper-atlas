# VIII.7：首项量度末项时，也量度第二项

现代正整数教学重构，不是古代实跑记录或一般命题的计算证明。假设相邻后项与前项的比都等于约分后的 v/u，首末相隔 k 步。末项与首项之比就是 (v/u) 的 k 次幂，它的约分分母为 u 的 k 次幂。若首项整除末项，该分母只能为 1，于是 u=1，首项也整除第二项。反过来，若 u=1 而各项恒比，首项整除末项。这是另行核查的现代反向推论，不是把原文命题改写成双向。

(5,15,45,135) 两个方向条件都真。递减 (24,12,6,3) 的末项可反向整除首项，但首项不整除末项。(8,12,18,27) 的公比是 3/2，按原方向两条件都假。(2,3,6) 虽然首项整除末项，却不整除第二项；它不恒比，不能反驳命题。默认要求至少三项、给定数均大于 1；相等和单位只进入显式现代模式。
