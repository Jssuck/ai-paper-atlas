# 三个有限模型：定义、可表示性与学习次序

## 0. 历史解释与模型地位

本附录为《逻辑》第二部第六章的阅读新写了三个现代教学模型。阅读单元采用 1798 年版印刷页 141–151；目录中的 `1780` 仅作已核版的书目归年，不能当作所引页码的版本年份，也不是对最早版本史的穷尽认证。

这里的布尔语义、保守扩张、观察纤维与有限规则闭包均为现代重构工具，不是孔狄亚克提出的数学，也不是其感知心理学的计算复现。模型只帮助分开三个问题：

1. 给已经有意义的关系加一个新名称，会不会自动增加关于旧对象的事实？
2. 已有的区分能力是否足够表达一个目标？
3. 按指定规则学习时，某一步的前提是否已经可用？

孔狄亚克对“定义是唯一补救”“定义应当作起始原则”及综合法的批评，须依据历史文本解读。以下定理不能证明“人的观念实际上这样发生”，也不能从一个失败的反向次序推出“一切综合、演绎或教材编排都无效”。定义可以简化表达和计算，教学也可以改变起点、引入新的前提；模型没有排除这些用途。

## 1. 共通约定与符号

| 符号 | 意义与限制 |
| --- | --- |
| $`\mathbb B=\{0,1\}`$ | 二值真值；代码严格使用 `False` 与 `True`，不接受整数代替 |
| $`P`$ | 有限原始名称集合；名称互异且非空 |
| $`\Omega_P=\mathbb B^P`$ | 给每个原始名称赋值的全部世界；$`P=\varnothing`$ 时恰有一个空世界 |
| $`w`$ | 一个全赋值世界；同一批输入世界必须具有相同词汇 |
| $`\varphi`$ | 由常量、变量、否定、合取、析取构成的有限表达式 |
| $`[\![\varphi]\!]_w`$ | 表达式在世界 $`w`$ 中的布尔值 |
| $`\mathrm{Vars}(\varphi)`$ | 表达式实际引用的名称集合 |
| $`W`$ | 指定的有限可能世界集；允许为空，也可以只是全部世界的子集 |
| $`K_0`$ | 规则模型的初始可用名称集合，不自动表示已经证实的事实 |

表达式采用通常的二值语义。求值要求全部自由名称都有赋值，包括被短路的分支；例如 `False and missing` 不被当作合法的已绑定表达式。函数复制世界后工作，不修改输入字典。

## 2. 模型一：显式定义的唯一保守扩张

### 2.1 假设

给定有限原始词汇 $`P`$ 和定义列表

```math
D=\{d_i:=\varphi_i\mid 1\le i\le m\}.
```

满足以下全部条件：

- 新名称 $`d_1,\ldots,d_m`$ 互异，且都不在 $`P`$ 中。
- 每个 $`\varphi_i`$ 只引用 $`P\cup\{d_1,\ldots,d_m\}`$ 内的名称。
- 若 $`\varphi_i`$ 引用了 $`d_j`$，画一条从 $`d_j`$ 到 $`d_i`$ 的依赖边；该有限图无环。
- 表达式是总的、确定的布尔函数，不包含随机、未定义、异常或副作用语义。

代码允许乱序输入定义，先按依赖进行拓扑排序。无环是方便检查的充分条件，不声称是一切唯一可解方程系统的必要条件。

### 2.2 定理一：每个旧世界有且仅有一个扩张

对任意 $`w\in\Omega_P`$，恰有一个扩张世界 $`E_D(w)`$，其在 $`P`$ 上等于 $`w`$，并满足所有等式 $`d_i=\varphi_i`$。

证明：有限无环图存在拓扑次序，重编号使每个右式只引用原始名称或先前定义名称。先令 $`E_D(w)`$ 在 $`P`$ 上等于 $`w`$；随后依次把 $`d_i`$ 赋为其右式的值。每一步输入已确定，右式总且确定，因此构造存在，并满足全部等式。

再取任意另一个满足等式的扩张 $`v`$。两者在原始名称上一致。归纳假设两者在前 $`i-1`$ 个新名称上一致，则第 $`i`$ 个右式引用的全部值一致，其求值也一致，等式迫使 $`v(d_i)=E_D(w)(d_i)`$。有限归纳得到两扩张相同。证毕。

### 2.3 定理二：关于旧词汇的保守性

设 $`\Gamma`$ 为任意原始词汇公式集合，$`\psi`$ 为任意原始词汇公式。把定义看作扩张语言中的等式约束，则：

```math
\Gamma\models\psi
\quad\Longleftrightarrow\quad
\Gamma\cup D\models\psi.
```

这里两侧分别量化原始世界与满足定义的扩张世界，不能误读成“把任意句子标为定义都安全”。

证明：先对原始公式的结构归纳。变量值未改变，常量固定，各连接词作用于相同的子式值，所以

```math
[\![\psi]\!]_{E_D(w)}=[\![\psi]\!]_w.
```

由定理一，扩张与限制到 $`P`$ 是满足相关约束的世界之间互逆的映射。若左侧成立，任取满足 $`\Gamma\cup D`$ 的扩张世界，限制后满足 $`\Gamma`$，因此满足 $`\psi`$，再由结构归纳保留真值，得到右侧。若左侧不成立，有一个满足 $`\Gamma`$ 却使 $`\psi`$ 为假的原始世界；其唯一扩张仍是右侧的反例。证毕。

等价地，任何 $`W\subseteq\Omega_P`$ 经扩张后，与 $`W`$ 一一对应，旧世界没有丢失。若 $`W`$ 原本为空，结论仍成立，但空集上的全称蕴涵是空真，不能当作获得了可靠经验知识。

### 2.4 定义与证据为什么分开

`DefinitionSystem.worlds()` 扩张全部原始世界。`filter_evidence(worlds, evidence)` 则保留证据为真的那些世界；后者可以排除旧世界。

例如 $`d:=p\land q`$ 本身保留全部四个原始世界，而再要求 $`d=1`$ 只留下 $`p=q=1`$。定义建立名称的意义；“此名称在现实中适用”的断言增加了约束。二者不可合并。

### 2.5 假设失效的反例

- 环形方程 $`d=\neg d`$：零个解。
- 环形方程 $`d=d`$：两个解，分别取 0 和 1。
- 环形方程 $`d=d\land0`$：恰有一个解 0。故“有环”不等于“一定无解或多解”；代码为明确的显式定义语言而拒绝全部依赖环。
- 旧名复用 $`p:=1`$：作为等式，它排除 $`p=0`$ 的原始世界。这是额外约束，不是上述的新名称保守扩张。
- 对不存在的名称作引用：表达式不满足总赋值前提，不能进入定理。

`satisfying_extensions` 是刻意放宽“新鲜、无环”限制的有限方程求解器。它固定旧世界，穷举新名称的值，检查全部等式。旧名称绝不会被它偷偷覆盖；每个左式名称仍须唯一，未绑定的右式名称仍被拒绝。

## 3. 模型二：可表示性恰是观察纤维上的常值性

### 3.1 设定

在共同词汇的有限世界集 $`W`$ 上，给定 $`k\ge0`$ 个布尔特征 $`f_1,\ldots,f_k`$ 和布尔目标 $`t`$。特征和目标在每个世界上都有定义。目标及其各世界真值是调用者预先给定的输入；这里检查可表示性，不从未知目标数据学习标签。定义观察映射

```math
O:W\longrightarrow\mathbb B^k,
\qquad O(w)=(f_1(w),\ldots,f_k(w)).
```

两世界观察等价，指 $`O(w)=O(v)`$。某个观察值 $`b`$ 的纤维是所有映射到 $`b`$ 的世界。这里“观察”只表示模型中允许使用的区分，不假装模拟视觉、注意、记忆或实际测量误差。

### 3.2 定理三：三个等价条件

以下三个条件等价：

1. 存在一个总函数 $`h:\mathbb B^k\to\mathbb B`$，使每个 $`w\in W`$ 都满足 $`t(w)=h(O(w))`$。
2. 对任意 $`w,v\in W`$，若 $`O(w)=O(v)`$，则 $`t(w)=t(v)`$。
3. 存在一个仅使用观察坐标变量 $`x_1,\ldots,x_k`$ 的布尔公式，在全部 $`W`$ 上表达目标 $`t`$。

证明：1 推出 2，因为同一函数在相同输入上输出相同。2 推出 1：在实际出现的每个观察值 $`b\in O(W)`$ 上，令 $`h(b)`$ 等于该纤维的目标值；条件 2 保证选择哪个世界都一样。未出现的观察值统一指定为 0，由此得到总函数。1 推出 3：布尔输入只有有限个，取真值表中输出为 1 的行作析取范式；每行以每个坐标或其否定的合取精确描述。3 推出 1：把公式的求值函数作为 $`h`$。证毕。

代码 `analyze_observations` 遍历实际世界：成功时返回实际出现的观察值及其目标值；失败时返回观察相同、目标相反的两个见证世界。`observed_formula` 根据成功表生成析取范式，默认未出现的观察值输出 0。这个默认只是总函数的一个补全选择，不是对未见世界的经验预测。生成式中的坐标名属于合成的观察输入词汇，调用时须把第 $`j`$ 个名称绑定为 $`f_j(w)`$ 的值；它不自动代表原始世界中的同名量。API 只要求坐标名彼此不同，并不追踪原始名称空间；建议显式使用 `x0`、`x1` 等坐标名。

### 3.3 构造公式与边界情形

令 $`B_+=\{b\in O(W):h(b)=1\}`$。构造：

```math
H(x_1,\ldots,x_k)
=\bigvee_{b\in B_+}\ \bigwedge_{j=1}^{k}\ell_{b,j},
\qquad
\ell_{b,j}=\begin{cases}x_j,&b_j=1,\\\neg x_j,&b_j=0.\end{cases}
```

约定空合取为真、空析取为假。

- 零个特征且 $`W\ne\varnothing`$：所有世界的观察都是空元组，所以仅常值目标可表示。
- 空世界集：三个条件都空真，成功表为空；生成常假公式只是补全约定。
- 世界子集：相对于子集可表示，不保证在更多世界上仍可表示。删去反例世界可能改变结论；因此必须交代 $`W`$ 的来源。
- 重复特征或重复列出的世界不改变是否可表示。代码容许重复世界记录，数学上仍按同一世界集理解。

### 3.4 反例与推论

只观察 $`p`$，目标为 $`q`$，且 $`W=\Omega_{\{p,q\}}`$。世界 $`(p,q)=(0,0)`$ 与 $`(0,1)`$ 的观察相同，目标相反，所以不存在只从 $`p`$ 得到 $`q`$ 的布尔公式。给 $`q`$ 另起名字并不改变这两个世界的不可区分性。

如果增加的新观察恰为旧观察的函数 $`g(O(w))`$，则新观察映射 $`O'(w)=(O(w),g(O(w)))`$ 与 $`O`$ 产生相同的划分。证明：旧观察相同必使新坐标相同；新观察相同又直接包含旧坐标相同。两方向合并得到等价关系相同。

这个推论只覆盖“由当前可观察信息计算出的新特征”。若定义引用了尚未观察的原始量，并且后来真的测得了它，信息可能增加；增加来源是新的观察，而不是命名行为自身。

## 4. 模型三：给定规则下的前提可用性

### 4.1 规则不是世界中的真理

令 $`U`$ 是初始名称及规则中出现名称的有限并集，$`K_0\subseteq U`$。一条规则写成 $`A\to c`$，其中前提集 $`A\subseteq U`$，结论 $`c\in U`$。只有当 $`A\subseteq K`$ 时，才允许把 $`c`$ 加到当前可用集合 $`K`$。空前提规则无条件可用；同一结论可以有多条替代规则。

规则是任务预先声明的操作资格。名称“已知”在代码里仅表示已经给定或规则可导出，不自动断言它在现实中为真。规则 $`\{p\}\to q`$ 可以使 $`q`$ 可导出，而某个另给的世界仍可能有 $`p=1,q=0`$；这意味着该规则在那个世界并不保真。

### 4.2 定理四：闭包、终止与最小性

定义单调迭代：

```math
K_{n+1}=K_n\cup\{c:\text{存在规则 }A\to c\text{ 且 }A\subseteq K_n\}.
```

该迭代有限步停止，所得 $`C`$ 是包含 $`K_0`$ 的最小规则闭合集。

证明：集合只增加，且始终包含于有限集 $`U`$；每个严格增加的轮次至少加入一个新名称，因此严格增加不超过 $`|U\setminus K_0|`$ 轮。停止时全部已启用规则的结论已在集合内，所以闭合。任取包含 $`K_0`$ 的闭合集 $`L`$；归纳证明每个 $`K_n\subseteq L`$：初始成立，若前提在 $`K_n`$，也在 $`L`$，闭合性迫使结论在 $`L`$。因此 $`C\subseteq L`$，证明最小性。证毕。

`forward_closure` 按上述轮次实现。`plan_learning` 每次选择输入顺序中第一条全部前提已知且结论尚新的规则，并记录其结论。

### 4.3 定理五：顺序计划的正确性与完整性

`plan_learning` 终止，其输出是逐步合法的，且最终已知集恰为定理四的闭包 $`C`$。

证明：每步只加入一个新名称，所以最多进行 $`|U\setminus K_0|`$ 步；每次选择都检查全部前提，故输出逐步合法。所得集合包含 $`K_0`$。停止意味着不存在结论尚新的已启用规则，所以所得集合闭合；最小性给出 $`C`$ 包含于所得集合。反向包含由归纳成立：初始已在 $`C`$；每个新增结论由 $`C`$ 中的前提及其闭合性得到。因此两集合相等。证毕。

`verify_order` 独立逐项检查一个提议次序；重复加入、加入已经给定的名称或没有任何全部前提已知的规则都失败。合法次序可以只是一个前缀，故 `valid=True` 不表示已经导出了整个闭包。

### 4.4 DAG 是特例；环与种子不能混淆

若知识节点的全部前提构成一个无环依赖图，则在正确给定起始节点的前提下，拓扑次序可提供合法计划。实现不要求整个规则图无环，以免把“存在环”误写成“永远学不到”。

- $`a\to b`$、$`b\to a`$，初始集合为空：无步骤可启动。
- 同样两条规则，初始集合为 $`\{a\}`$：立即可得 $`b`$。
- 链 $`a\to b`$、$`b\to c`$，初始为 $`\{a\}`$：顺序 $`b,c`$ 合法，反序 $`c,b`$ 在第一步失败。
- 若规则改为 $`a\to b`$、$`a\to c`$，则 $`b,c`$ 与 $`c,b`$ 都合法。

因此“某条学习链倒序失败”只证明那个起点和规则下那个次序不合法，既不证明所有反序都失败，更不证明一切名为综合法的历史或现代方法都错误。

### 4.5 可选保真性条件

另外给定一个世界 $`w`$，若所有初始名称在 $`w`$ 中为真，并且每条规则在 $`w`$ 中都满足“前提全部为真则结论为真”，那么闭包中每个名称都在 $`w`$ 中为真。证明是对合法计划长度的归纳：初始真；下一步的前提已真，规则保真条件使新结论真。

这个额外条件并不由规则语法或调度算法提供。算法输出可导出集，不能自行担保经验正确性。

## 5. 计算与证据边界

- 程序使用递归表达式树；极深表达式受 Python 递归深度和机器资源限制。一般定理没有把此实现限制当作数学边界。
- 全世界枚举需要 $`2^{|P|}`$ 行。方程穷举器对每个固定旧世界枚举 $`2^r`$ 个新名赋值，其中 $`r`$ 是未固定的左式名称数。
- 观察检查对给定世界逐个求值并检查纤维冲突；DNF 最坏随特征数指数增长。代码追求可审计，未作工业规模优化。
- 规则算法在有限名称上单调增加；仅受有限输入规模限制，没有把程序超时或查找失败当作数学不可导出的证据。
- 数学定理由上述一般证明支持。测试只检查明示的小规模边界；穷举测试通过不能替代一般证明。
- 测试与方程 oracle 共用表达式求值器，故还另用直接布尔真值和完整小真值表验证求值器。规则闭包 oracle 使用“全部闭合集的交”，没有调用闭包实现。
- 六个定向变异只说明六类已知错误会被检测，不能报告为整个程序的全面变异覆盖率。意外异常单独记作 `harness_error`，不算成功检测。
