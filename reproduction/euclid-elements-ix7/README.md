# 《几何原本》IX.7：合数与数相乘得到立体数

正整数教学重构；给定 $A,B>1$ 且 $A$ 为合数。程序寻找真因子 $D$，以整数除法取得 $E=A/D$，给出积 $C$ 的三个非单位因子 $(D,E,B)$。例如 $4\cdot3=2\cdot2\cdot3$ 是立体数但不是立方数，$4\cdot2=2^3$ 则两者皆是。立方诊断只是现代对照，不是证明步骤。

命题前提充分而非必要。$3\cdot4$ 的首因子并非合数，但积仍可写成 $3\cdot2\cdot2$；$2\cdot3=6$ 不是立体数。$B=1$ 不属于这里的历史输入范围，去掉该条件后 $4\cdot1=4$ 并非立体数。

只需要 Python 3.9+ 标准库。在本目录运行：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线枚举乘积不超过 1024 的所有有序非单位三因子，以其积归组，再逐一比较 $A,B$ 各取 2 至 32 的情况。由于其余两个因子都不小于 2，单个因子最多为 256，枚举不会遗漏这一范围的见证。有限算例不代替一般证明。Notebook 日志是标准库对三个代码单元的实际回放，并未启动 Jupyter 内核。
