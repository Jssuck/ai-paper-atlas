# II.15：对立前提、固定推理规则与空真

这是《前分析篇》II.15的原创现代教学模型，不是古代文本解释器，也不是完整逻辑系统。原文范围和异读以[中文深读](../../papers/ancient/aristotle-prior-analytics-ii15.zh-CN.md)及[来源台账](../../papers/ancient/aristotle-prior-analytics-ii15.sources.zh-CN.md)为准。

## 实际做什么

1. 将U/E/I/O(P,S)分别解释为S包含于P、两者不交、交非空、S减P非空。三格项位固定，P为大项、S为小项、M为中项。
2. 固定14个基本式的句法证书。第一格4个、第二格4个、第三格6个；第三格Darapti/Felapton明确需要M存在。程序不凭“不一致前提没有模型”接受任意公式，不含一般爆炸规则，不声称14式穷尽所有弱化结果。
3. 第二、第三格各列六个正负配对：UE/EU/UO/OU/IE/EI。某一配对无当前方向结论时交换两个极项，并在输出标出。此为12条教学路线，不是12个额外传统式。第一格在P=S后仍是P(M)、M(P)，不构成同一主谓项的直接对立；加换位会是额外步骤。
4. 将P=S作为“科学不属于科学”的背景，分别检查前提是否可共真、结论在背景中是否为假。U/E允许空主项时可能共真；第三格双全称若撤掉M存在，特称结果有反模型。
5. 单列医学包含于科学的背景。类名“医学”不是量词“某个”；背景包含和医学存在是两个不同条件。撤去包含时，第二格推理可以有真前提和真结果，不能再声称两个前提互相对立。
6. I/O可共真，不把两个存在见证合成一个。另演示经典语义空真与实际固定式证书不同。

## 本次真实结果及口径

三个一元集合有8种成员类型，程序枚举其中非空类型集，共255个模型；三个项均非空者218个。每种类型至多一个代表，只保留本模型的包含/交/差是否非空信息，并非枚举现实对象或全部历史语义。

14个固定基本式在声明的非空政策下均无反模型，且每个都有共同满足前提的模型。12条教学路线在原有不同项解释下均保真；当极项同一且三项非空，12组前提都无共同模型，而12个否定结果在各自背景中均为假。后一个事实不是有效式的证明，保真另由前一个检查和正文的一般推导说明。

仅对第二格UE/EU，将极项同一而允许空项时各有3个前提共同模型；结论E(P,P)在这些模型为真，因为P为空。第三格UE/EU若撤去M存在则特称结论无效，有明确反模型。这些现代空项结果限制“结论必假”的解释范围，不冒称替古文裁定唯一存在论。

包含例：无包含限制时255背景模型、15共同前提模型；加入S包含于P后63背景模型、7共同前提模型；再要求S存在后48背景模型、0共同前提模型，48个背景中结论都为假。完整对象集合和反模型在JSON内。

## 证据限度

有限检查不替代一般证明；不一致的联合模型数为0不证明任意句法推导合法。此代码不解析自然语言，不实现多结论/复合三段论，不检验现实中的科学、医学或善，也不裁定古希腊项逻辑的唯一解释。章末单个否定结论与同时断言正反两句的区分由正文讨论，不把本程序冒称完整复现该讨论。
