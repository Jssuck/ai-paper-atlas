# II.3：第二格的假前提与真结论

对应[中文深读](../../papers/ancient/aristotle-prior-analytics-ii3.zh-CN.md)。这是原创现代集合教学模型，不是古代文本的唯一语义，也不是原论文实验的复制。只用 Python 标准库；不安装依赖。

## 模型、项位与分类

论域非空，M 为中项，P 为大项，S 为小项，项集合允许为空。函数 `proposition(model, kind, predicate, subject)` 使用**谓项在前、主项在后**的顺序，与文中“A属于所有B”形式相符。它不同于某些先主项后谓项的 API。

|类型|`kind(X,Y)` 的含义|
|---|---|
|A|Y 包含于 X|
|E|Y 与 X 不相交|
|I|Y 与 X 有共同对象|
|O|Y 中存在不属于 X 的对象|

四个模式严格固定：

- Cesare：E(M,P)、A(M,S)，推出 E(P,S)。
- Camestres：A(M,P)、E(M,S)，推出 E(P,S)。
- Festino：E(M,P)、I(M,S)，推出 O(P,S)。
- Baroco：A(M,P)、O(M,S)，推出 O(P,S)。

全称前提非空主项上分为 `true`、`wholly_false`、`partly_false`。整假表示相反的全称命题成立，部分假表示主项中同时有满足和违反谓项的对象。部分假仍是二值逻辑中的假，不是概率或中间真值。空主项统一分类 `vacuous_true`，避免 A/E 同为空真时误判整假。特称命题仅分 `true`／`false`，不套用全称命题的“部分假”。

## 四式的一般保真证明

Cesare：若有对象同时属于 P 与 S，则 A(M,S) 使它属于 M，E(M,P) 却使它不属于 M，矛盾，所以 P、S 不交。Camestres 同理，把共同对象经 P 送入 M，经 S 排除于 M。Festino：I(M,S) 取一个同属 M、S 的见证；E(M,P) 排除它属于 P，因此它见证 O(P,S)。Baroco：O(M,S) 取 S 内而不在 M 的见证；若它属于 P，A(M,P) 使它属于 M，矛盾，所以它不属于 P。这些证明不依赖枚举、项的总体非空假设或论域有限性。

真结论不能倒推出真前提。例如 M={1}、P={1}、S={0}，Festino 的 E(M,P) 和 I(M,S) 均假，O(P,S) 为真。推理形式仍保真；实际前提是假的，不能凭真结论为它们背书。

## 为什么所有指定组合可有真结论

全称式：取互不相交的非空 P、S，各预备两个对象。针对每个前提独立安排相关对象是否属于 M：全部满足为真、全部违反为整假、一个满足一个违反为部分假。P、S 分离，因此两个安排不干扰；E(P,S) 始终为真。若 M 暂为空，可额外加入一个不在 P、S 中的 M 对象。于是两个全称式的3×3状态组合都有非空各项的真结论见证。

特称式：同样先取 P、S 分离，用 P 中对象实现全称大前提的三个状态。Festino 的 I(M,S) 要真时给 S 一个 M 对象，要假时使 S 全在 M 外；Baroco 的 O(M,S) 要真时给 S 一个非 M 对象，要假时使 S 全在 M 内。O(P,S) 始终为真。必要时加一个不在 P、S 中的 M 对象。因此每个特称式的3×2状态组合均可实现。这里只是构造这些组合**存在**的模型，并非说任何有假前提的实例都产生真结论。

## 八类型压缩与计数

每个对象由属于 M/P/S 的三个布尔值决定类型。位权 M=4、P=2、S=1，类型0也允许：它在论域中但不属于三个项。保留每个非空类型的一个代表，删除同类型的多余对象。A/E 的反例、I/O 的见证、各项非空和真假分类只依赖相应类型是否存在，因此压缩保持全部检查性质，任意无限论域也适用。这是一般论证；有限程序是它在声明片段上的核验，不代替证明，也不处理多元关系、模态、计数约束或历史解释争议。

非空八类型子集共有255个。要求**M、P、S三个项均非空**时有218个：从255减去3×15个单项空情形，加回3×3个双项空情形，再减去三项都空的1种。228不是本程序的全项非空计数，不能混用不同存在条件。

每个模式按前提分类和结论真假记录计数。`witnesses.json` 保存全部可行组合及最小类型模型见证。枚举按论域基数递增，等基数按类型字典序，因此“最小”指本片段按对象数最少；不指自然语言中最简单或历史上唯一的例子。压缩论证保证重复同类型对象不会产生新的组合。

## 实际运行与复核

执行命令：`bash run.sh`。脚本生成环境记录、21项作者测试和模型普查的 normal／-O／-OO 三种模式日志，以及完整见证文件。无需设置密钥、联网或安装包。

- 每模式255个允许空项的模型，四式共1020次评价。
- 每模式218个全项非空模型，四式共872次评价。
- 两个全称式分别覆盖9个真结论前提状态组合；两个特称式分别覆盖6个。
- 三模式全部通过，保真违例0；完整报告 SHA-256 在模型日志中输出，供核对三模式结果一致。
- 测试还覆盖空主项、参数方向、整假/部分假、非法项名、非法类型、布尔对象、最小见证和文本校读风险。

`test_jenkinson_literal_does_not_give_two_false` 仅验证一个数学事实：在 M 包含非空 P、S 时，E(M,P) 假而 I(M,S) 真，因此不能同时称两前提假。它不以程序裁决原文；版本问题应见正文和来源台账。
