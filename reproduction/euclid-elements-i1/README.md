# 欧几里得《几何原本》I.1：精确构造的最小教学复现

本目录是原创现代坐标教学实验，不是古希腊原程序、不自动判定《几何原本》全部公设，也不是完整几何证明器。正文的一般证明与这里的有限实跑分开。

## 1. 数学对象与输入合同

输入 A、B 是两个不同的有理坐标点。Python 接口只接受 `int` 或 `fractions.Fraction`；拒绝浮点、布尔、字符串和坐标数量错误，避免误把近似数当精确数。A=B 时构造抛出 `ValueError`。

`Q3(a,b)` 表示实数 a+b√3，a、b 为有理数。加法逐系数，乘法用 (a+b√3)(c+d√3)=(ac+3bd)+(ad+bc)√3。本实现只需要加、减、乘及有理倍数，不实现通用域除法。因为 √3 无理，系数配对是唯一表示。

设向量 v=B−A=(dx,dy)，中点 M=(A+B)/2。构造输出

C+ = M + (√3/2)(−dy,dx)，C− = M − (√3/2)(−dy,dx)。

这是对实欧氏坐标平面中 I.1 的教学重构，使用了实数/平方根模型，不声称从欧几里得列出的原始公设不加解释直接形式导出交点存在。

`certificate` 不调用 `construct`，而独立检查：基边两端不同、AC²=AB²、BC²=AB²、方向行列式不为零。它验证给定顶点，不搜索或认证任意原始几何图示。Q3 符号比较在两项异号时比较 a² 与 3b²；非零有理系数不能使二者相等，这依赖 √3 无理性。代码不使用浮点近似、误差容限或 Python 的可被 `-O` 删除的 `assert`。

## 2. 为什么一般构造成立（教学证明）

v 与 Jv=(−dy,dx) 的点积为零，二者长度平方均为 dx²+dy²。C±−A=v/2±√3 Jv/2，于是其长度平方为 (1/4+3/4)(dx²+dy²)=AB²。C±−B=−v/2±√3 Jv/2 同理。方向行列式为 ±√3(dx²+dy²)/2；A≠B 保证其非零，所以得到两个非共线顶点。这是对所有规定输入的代数证明；1200 次程序检查不是它的替代品。

## 4. 条件删除与有理平面边界

单位基边 A=(0,0)、B=(1,0)：

1. 仅在 A 圆上取 C=(0,1)：AC²=AB²=1，但 BC²=2，证书拒绝。一个等长条件不能替代两个圆的共同归属。
2. 任取 C=(0,2)：AC²=4、BC²=5，不是目标交点，拒绝。
3. 允许 A=B=C=(0,0)：三边平方虽均为0，`distinct_base` 与 `noncollinear` 都失败，拒绝。构造器也直接拒绝重合端点。

若坚持 C=(x,y) 只能取有理坐标，单位基边的两个圆方程相减得到 x=1/2，代回得 y²=3/4。于是 (2y)²=3，与 √3 无理矛盾。代码只报告这一精确约束，不以有限枚举冒充“所有有理数中不存在”的证明。有理平面例只展示这一坐标域的闭包不足，不声称它满足《几何原本》的全部原公设、全部连续性或所有构造要求。一般无理性论证见正文。
