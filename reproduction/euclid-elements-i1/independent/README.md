# 独立扩展核验

本目录由未参与构造器编写的技术审查者制作。与正文的600基边、1200三角形原实验分开。

`oracle.py` 调用被审查的构造器取得候选，但平方距离与行列式用独立有理系数对运算，不调用被审查模块的 Q3 算术方法、distance2 或 orientation。它也枚举候选点并比较证书结论，另用明确的有理上下界夹住 √3 来独立检查符号函数。无浮点近似。

运行：

```sh
python independent/oracle.py > independent/results.json
```

实际结果：6480整数有序基边的12960个三角形，2352分数有序基边的4704个三角形；625个候选点组合中恰好接受单位底边的两个真实交点；67个不同有理系数产生4489个符号核验，零不一致。保存的 results.json 是此公开脚本真实重运行输出，和审查阶段结果逐字一致。

这些有限核验用于寻找实现错误，不证明全部输入正确，也不检验古代文本解释、欧几里得全部公设或解释器正确性。两组输入的数学构造依据仍是正文的一般代数证明。
