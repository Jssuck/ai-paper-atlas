# I.23 独立代码审核

结论：在下列明确有限范围内通过。审核者未修改作者实现或作者运行日志；不是仅重跑作者测试。完整源码、正文与审核证据的 SHA-256 绑定见 [独立清单](independent-review/review-manifest.json)。本文不替代原典来源审核或一般数学证明。

## 发现与修正

发现正文最初把接口例子写成小写 `holds("a","A","B")`，而实现严格要求大写 AEIO。已由正文作者改为 `holds("A","A","B")`，与正文主项优先的 `a(B,A)` 对应。复查现存正文明确说明两个顺序；小写非法输入也被独立测试拒绝。另将容易误读的“三项256模型结论”改为“三项有限代表模型结论”。上述两处修正未改变作者源码，因此作者原始运行记录仍适用。

## 独立方法与结果

独立 oracle 从布尔成员向量及 `all`/`any` 量化定义建立真值，而不调用作者 `extension` 或 `holds` 来确定预期值。作者集合运算与此 oracle 对照。

每个解释器模式均实际完成：

- 255 个非空论域三项占位模型上的 9,180 个 AEIO 查询；另行核得全项非空模型为 218 个。
- 18,360 个改名、矛盾互补与 E/I 对称变形检查。
- 四种有向连接输入、两前提和结论的全部质量组合，在空项允许／全项非空两策略下共 512 个后承配置；连同首个反模型掩码与独立 oracle 相符。
- 65,535 个四项模型中的链前提、结论分别对照 oracle；其中 31 个满足三条链前提，未出现前提真而结论假的模型。
- 7,776 个归谬记录检查，包含非矛盾配对、不同项位置及真假组合。始终确认 `outer_discharge_verified` 为 False，不能用配对记录代替推导验证。
- 78 个非法输入均抛出 `ValueError`；含布尔值伪装整数、零论域、未知项、小写质量、错误结构、非法上限。审核检查本身使用显式异常，不依赖可被优化去掉的 `assert`。
- 独立以固定对象 x、y 的集合解释验证自由 B 样例：掩码 129 与 24 对应的 AEIO 真值全部反转，固定 A=C={x}；不把变化的原子编号错当成必须固定的对象标识。
- 奇偶检查在上限 1、2、17、100 下符合有限计数与否认一般证明的返回字段。

有限敏感性检查：对 A 主谓倒置、O 主谓倒置、给 A 偷加非空、把 E 当非 A、把 I 当 A、把 O 当 E 六种显式语义变体，全部找到区分见证，保存在结果 JSON。另检查反向链不得合并为原方向、RAA 不得宣称完成卸除。这不是对任意源码变异的穷尽变异测试。

## 边界与结论强度

非空域不等于所有项非空；掩码 1 保留项全空、论域有对象的情形。有限成员类型压缩的数学理由见正文，不由这些实跑数量证明。`entails` 只覆盖所声明的三项 AEIO 集合语义。四项链成功不是所有多中项证明可归约的证明。RAA 函数不核验内层派生关系，也不执行外层卸除；有限整数扫描不是不可通约的一般证明。无 CI 或 Notebook 执行声明。本次未发现剩余实现错误；该结论只适用于清单绑定版本和这些已实际执行的检查。
