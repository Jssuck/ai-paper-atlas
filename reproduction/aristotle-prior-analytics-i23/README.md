# I.23：项图、共同见证与归谬分层的教学代码

本附件是原创现代教学重构，不是亚里士多德原有算法，也不认证其全部证明论。只用 Python 标准库；无需安装第三方包。代码与[中文主稿](../../papers/ancient/aristotle-prior-analytics-i23.zh-CN.md)配合阅读。

## 1. 模型、符号与明确边界

`Model(terms, occupied_mask)` 给每个非空成员原子保留一个代表。三项默认顺序为 `(P,M,S)`，原子号的第0、1、2位分别表示是否属于P、M、S；占位掩码的第a位表示原子a有代表。至少一个原子存在，所以论域非空；0掩码被拒绝。三项有255个占位模型，不是256个非空模型。允许项为空；另一个策略要求每个项都非空，剩218模型。

`holds(q,predicate,subject)` 的顺序为谓项、主项。A是主项集合包含于谓项，E是二者不交，I是交集非空，O是主项有成员不在谓项。空主项使A和E真、I和O假。`entails` 仅检验三项AEIO片段，不接收其他项名，也不是任意一阶逻辑求解器。

为什么这类有限模型适合教学？给任意非空论域中的对象按其对固定有限项的成员关系分类；只保留非空类别各一代表，就保持各AEIO句子的真值。这是需要单独给出的压缩论证，不是“代码跑完所以数学成立”。代码的有限运行核验的是所写实现；它不验证全部古代语义、量化关系逻辑或模态体系。

## 2. 图形只给结构，不自动给有效性

`skeleton(edges)` 接收两条主项到谓项的有向边，识别：

- S→M→P：正向链。
- P→M→S：反向链。
- S→M←P：共同谓项。
- S←M→P：共同主项。

反向链只有在交换端项角色以后才能与正向链归为同一连接形状。固定S到P的结论方向时，不可直接把它称为普通第一格，也不可忽略后来所谓第四格的区别。函数不读取AEIO量或质，更不从图形推出有效式。

例：全部P是M、全部S是M，不推出全部S是P。实跑返回全项非空反模型72：占位原子3和6，即P={3}、M={3,6}、S={6}。图连接而结论为假。相比之下，Barbara在所有255模型中无反例，但一般有效性须从任意S成员逐步进入M、P的证明理解。

## 3. 独立变化B与多中项

自由B示例使用项顺序 `(A,C,B)`，两个固定对象x、y，固定A=C={x}。B={x}时占位掩码129；B={y}时掩码24。原子代表号会随成员状态改变，所对应的两个原始对象可以保持不变。二者都满足全部C是A，但A对B的四类AEIO结论分别翻转。这只说明这个前提集不足以约束B，不宣称每个“不提B”的前提集都能使任何结论自由翻转。例如若前提迫使A为空，某些结论已受限制；若前提不相容，经典后承会平凡化。

四项链S⊆C⊆M⊆P遍历65535非空占位模型，有31个模型满足全部三个包含前提，均满足S⊆P。这是实现检查。一般证明是连续三次集合包含，不需要枚举论域；本程序不宣称所有多中项论证都必然能无条件缩约。

## 4. 归谬：本程序到底没做什么

`raa_certificate` 名称表示教学配对记录，不是完整证明检查器。它只判断假设与派生句是否为同一主谓项上的A/O或E/I矛盾对，以及给定模型中各句真值。它不检查“派生句是否由前提和假设推出”，也不执行外层假设卸除。返回字段 `outer_discharge_verified` 始终为false，防止将这两步偷并。

完整归谬需要：内层在前提及反设下合法导出矛盾；外层依据所采用逻辑的规则，卸除反设并取得目标。本文没有把任意输入的矛盾配对当作这两步的证书。

整数诊断仅检查0到100的平方偶数蕴含底数偶数，以及1到100的正整数对中没有既约平方比为2的解。一般无理性证明应采用任意既约p/q，推出p和q都偶，违背互素；程序明确返回 `general_irrationality_proved: false`。它并不重建古代原文省略的每个算术步骤。

## 5. 运行

在本目录执行：

```sh
python test_model.py
python run_examples.py
python -O test_model.py
python -O run_examples.py
python -OO test_model.py
python -OO run_examples.py
```

[环境记录](environment.json)保存实际解释器版本和命令。三个模式各20项单元测试通过；结果JSON逐字内容相同。生产校验使用显式异常，不依赖可被优化删除的assert。测试包含布尔值充当整数、空域掩码、错误词项、错误形状和不适用的存在策略。

真实结果：255三项模型、218全项非空模型；4590个矛盾对查询；四项链65535模型/31前提成立模型；有限整数10000正对。不要把查询数或模型数当作数学证明强度。
