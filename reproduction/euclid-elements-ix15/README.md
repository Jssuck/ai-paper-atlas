# 《几何原本》IX.15：最小三项连比中的互素和

程序用互素正整数 $`a,b`$ 构造 $`(a^2,ab,b^2)`$，逐项求其余两项之和并核查互素。按余项 $`4,6,9`$ 排列，例 $`(4,6,9)`$ 的两项和为 $`15,13,10`$。输入 $`(8,12,18)`$ 可由现代适配器约去倍数 2，但原三项各与相应的和至少共享此因子。$`(3,4,5)`$ 不成连比，且 $`3`$ 与 $`4+5`$ 不互素。含单位的根值另标为现代扩展，尤其 $`a=b=1`$ 并不代表古代给定的数。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

基线遍历三个坐标各取 1 至 36 的有序三元组，用精确分数判断连比，并独立约去公因数、枚举约分后余项与两项和所可能共享的非单位因子。有限检查不替代一般证明。Notebook 日志记录标准库实跑三个代码单元，不是 Jupyter 内核运行。
