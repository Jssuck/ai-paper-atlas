# Euclid I.6：等角、对边与严格部分的最小教学复现

对应[中文深读](../../papers/ancient/euclid-elements-i6.zh-CN.md)。这里是原创现代有理坐标教学模型，**不是欧几里得原始尺规操作执行器、不是证明助理认证，也不是古代原程序的复现**。它检查原文分析所涉及的不同条件是否被程序混淆；一般结论由正文证明承担，有限枚举不能证明一般定理。

## 1 范围与数学口径

只依赖 Python 标准库。坐标使用 `int` 或 `fractions.Fraction`，拒绝浮点、布尔值及错误维度。三角形必须非共线；两个点重合也因此被拒绝。

- `angle_equal(u,v,w,z)` 比较两组非零射线所成的普通无向角，范围为0到180度。先比较点积符号，再交叉相乘比较归一化点积的平方。符号不能省略：45度和135度的余弦平方相同，但角不同。这个底层函数允许零度/平角；三角形接口另外排除共线退化。
- `triangle_certificate(A,B,C)` 比较B、C处底角以及对边AB、AC的平方长度，返回两个真假值和蕴涵检查。底角不等时蕴涵为真是逻辑上的空真，**不等于已证该三角形等腰**。
- `strict_cut_certificate(A,B,C,D)` 分开检查AB较长、D严格在AB内部、DB=AC。仅三项同时成立时 `valid_cut` 为真。它还报告两个三角形有向双面积之比及等底角是否成立。`proper_area` 仅表示面积比在0与1之间，不能单独代替点在线段内的证书。
- `cut_from_rational_ratio(A,B,C,r)` 要求给出可精确核验的有理数r=AC/AB，且严格在0和1之间，再计算D=A+(1-r)(B-A)。一般有理坐标的长度比可能无理，该函数没有声称覆盖它们。它生成解析见证，不认证已执行I.3尺规步骤。
- `factor_certificate(x,y,z)` 在正的有理边长、严格三角不等式下，令x=AC、y=AB、z=BC，核验清除正分母后的余弦等式左端 `x*(y*y+z*z-x*x)-y*(x*x+z*z-y*y)` 等于 `(y-x)*((x+y)**2-z*z)`。第二因子严格正，所以等角方程可推出x=y。一般展开、内积/余弦模型假设与严格三角不等式的依据见正文；这个代码仅检查有理实例，不声称就是原文反证。

原文反证假定AB较长且底角相等，再导出不可能。不能制造一个欧氏非退化三角形“同时满足这些矛盾假设”来作为正例。这里的220个截取实例只满足可实现的截取/严格部分条件，底角并不相等，`contradiction_premises_realized` 因而为0。

## 3 可手算对照

1. A=(0,3)、B=(-2,0)、C=(2,0)：AB²=AC²=13，两个底角相等。
2. A=(0,0)、B=(5,0)、C=(0,3)、D=(2,0)：DB=AC=3，D严格在AB内。ABC的双面积为15，DBC的双面积为9，比为3/5，是真部分；B、C角不相等。这不是满足矛盾前提的反证“成功样本”。
3. 上例改D=(8,0)：仍有DB=3，但D在线段外、方向错误，`valid_cut` 为假。改D=(5,3)也有DB=3，却不共线，仍不通过。
4. 取射线(1,0)与(1,1)，另一组(1,0)与(-1,1)：平方比较会丢掉正负，实际角比较返回假。
5. x=y=5,z=6：第二因子为100-36=64，等角方程成立；x=3,y=5,z=4：第二因子为64-16=48，左端96，等角方程不成立。
6. x=1,y=2,z=3会使严格正因子消失，但三角形退化，接口拒绝，不能作为I.6的反例。
