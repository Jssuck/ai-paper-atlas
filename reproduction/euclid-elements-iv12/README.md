## 数学模型与独立检查

圆心在原点，半径 R 为正有理数。以 u = (√5−1)/4 = cos 72°、V = 1−u² 建立精确模型：坐标对 (x,y) 表示实际坐标 (x,y√V)，其中 x、y 是 a+b√5 形式的数。点积需将纵坐标系数乘积乘 V；叉积在判号时可去掉共同正因子 √V。没有浮点阈值。

接触点 p 设定切线 p·x = R²。相邻线性方程用行列式解出顶点；再独立比较各顶点是否满足两条直线的等式。每条边还验证切点严格位于两端之间，并要求所有顶点在各切线含圆心的闭半平面内。严格转向一致、不重复顶点、无非邻边严格交叉，与半平面判定共同检验凸边界。角证书同时检查余弦的符号和平方，不会把补角混成同一个角。

在正常构造中，每边长平方为 4R²(1−u)/(1+u)，各顶点与圆心距离平方为 2R²/(1+u)；另以单位圆的根式值交叉检查。未把这些等式当作校验切性或边界的替代品。

## 已验证范围

- 48 个正有理半径各取两个镜像方向，产生 96 个精确正例，各项切性、凸性、等边、等角及 108° 判据成立。
- 96 个星形对照沿同一组切点重新配对，形成 5 处严格交叉，且顶点不全在各切线的圆心侧。它们仍满足切线、切点位于线段内、等边和相等的普通顶角，说明这些局部条件不能单独验收。
- 96 个不等距切点对照用有理参数把 B 沿同一圆移到 A 与原 B 之间，仍是凸的有切外接多边形，但不等边也不等角。
- 普通、`-O`、`-OO` 各通过 8 个具名测试，另含非法半径与方向、重复和离圆切点以及相邻切线平行的拒绝检查。不接受给定任意中心或浮点测量输入。

这些是有限教学案例，不是全空间遍历或历史复现实验。文件中的数字只代表所描述的运行。
