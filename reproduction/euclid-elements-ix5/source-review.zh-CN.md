# IX.5 原典与交叉引用

- [Heath 1908，卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)：印页 387 底至 388 上（PDF 第 400–401 页）。387 有命题、符号图和取辅助立方；388 承接等比、中项及结论。正文引用 IX.3、VII.17、VIII.19、VIII.8、VIII.23，末段下方另列译者符号提要。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=256)：印页 256 自 IX.5 标题至 IX.6 之前完整。希文 Γ 对应积 C，Δ 对应辅助量 D；两者立方性来源不同。此次对读未见改变证明的适用正式勘误，非全面校勘。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.5.html)：希文包括将目标 B 判为立方及证毕；英译栏停在 VIII.8 推出 A、B 有两个中项。此为该网页英栏的范围，不应把它当作正文不同结论。
- [Joyce](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX5.html) 正文保留 VIII.23 最后一步，Guide 将本命题与 IX.4 比较。源链由 [VIII.19](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII19.html) 提供，按 [VIII.8](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII8.html) 迁移。[VIII.21](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII21.html) 是 [VIII.23](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII23.html) 所用的前置结果，而非 IX.5 明列的最后一步。
- [对应深读](../../papers/ancient/euclid-elements-ix5.zh-CN.md) 中的根约分、混合项、反例与代码为现代教学重构；未公开原典扫描或全文翻译。
