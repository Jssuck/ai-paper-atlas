# 《几何原本》IX.5：立方数的整数商

正整数教学重构。给定立方数 $A=x^3$、$C=z^3$，还要求 $B=C/A$ 是整数。用首端 $D=A^2$ 的根 $x^2$ 和末端 $C$ 的根 $z$ 构造四项连比；把全部四项同时除以 $A$，得到以 $A,B$ 为端点的连比。程序分别核查四项整除和 $z/x$ 为整数，并验证其立方为 $B$。

输入 $(8,216)$，原链 $(64,96,144,216)$，除以 $8$ 后得到 $(8,12,18,27)$，商的立方根为 $3$。$(27,216)$ 得递减链，$(8,64)$ 得齐项。$(8,27)$ 虽然两者皆为立方数，却没有整数商。给定项或商为单位的情况标为现代正整数扩展。

在此目录运行，需 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线查预先枚举的立方表，并以精确分数按乘率幂核对两条链。给定端点各取 1 至 216；有限核验不代替一般证明。Notebook 日志来自标准库实跑三个代码单元，不是 Jupyter 内核运行。
