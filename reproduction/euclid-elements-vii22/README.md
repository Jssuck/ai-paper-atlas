# VII.22：最小数对必互素

现代正整数上的教学重构，不是古代实跑记录或一般命题的计算证明。假设给定比的最小对 A、B 有共同非单位公度 C。沿 VII.17 的思路，把 A、B 分别写成 C 个 D、C 个 E，可得 D:E=A:B；且 D<A、E<B，和最小性矛盾。C 不必是最大公度。

18:30 取 C=2 得 9:15，已足以否定原对最小；取 C=6 得 3:5，也可以否定原对最小。8 和 15 各是合数，但彼此互素。程序另设使用 gcd 的现代诊断；反证步骤不依赖它。测试独立枚举比值候选和全部公因数，并用 Fraction 核对缩小所得的同比。

给定数按历史用语限制为大于 1。现代模型允许 3:6 的最小对为 1:2；含单位的商不进入这里的历史「数」见证，不能用代码排除它来判断原文对单位的处理。
