# VII.22 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.22.html)、Heath 1908 卷 II 印刷页 323–324（扫描物理页 336–337；图在 323，完整推论和评注在 324）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=212) 印刷页 212–213，以及 [Joyce VII.22](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII22.html)。

希文 Α、Β、Γ、Δ、Ε 对应英语 A、B、C、D、E。A、B 假定为同比中的最小对；C 是反设存在的、严格超过一单位的公量；D、E 分别以单位数记录 C 量尽 A 和 B 的次数。因为公量超过一单位，次数严格小于相应的原数。希文与两印本接着写 C 分别乘 D、E 而生成 A、B，由 [VII.17](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII17.html) 得到 D:E=A:B，与最小性矛盾。

Heath 与 Fitzpatrick 在乘法行旁标定义 15，在等比行旁标 VII.17。说得更细，定义 15 的动作方向是由先说的乘数指定第二数的份数：“C 量 A 共 D 次”立即给出 D 乘 C 生成 A；原证写的是换位后的 C 乘 D。可将这个方向转换显式补作 VII.16；若保留 D 乘 C、E 乘 C 的次序，则用 VII.18 而非 VII.17。Heath 324 页的代数评注也指出可用 VII.17 或 VII.18。原文并未在这一行直接列出 VII.16 编号。

这一反证在现代正整数域也覆盖 D 或 E 等于 1 的情况；古文区分单位与数，不宜不加说明就称该边界由 VII.17 的“两数”假设覆盖。现代教学中可直接承认一单位可以作比项，并用正整数分数说明同比性。若反而把所有同比候选的两项一律限制为至少 2，则 2:4 已是该受限候选中的最小对却不互素，不能拿这种约定概括本命题的现代效力。

Clay 英栏于没有共同的“数”能量尽 A、B 处截断，未将这句话再读回互素；其希栏、Heath、Fitzpatrick 和 Joyce 都补足末步。Joyce 网页在图示两侧重复了 D、E 的计数构造句，两次写的是同一构造，不是另一组商。与 VII.21 合读可见互素与最小的双向关系，但 VII.22 的反证没有把 VII.21 当作前提。[VIII.2](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII2.html) 直接由本命题将给定的最小数对 A、B 判为互素，再讨论连比列端项的互素及整列最小性；这些后两步不是 VII.22 单独给出的。

在所核 1908 扫描卷前及命题所在页、Fitzpatrick 同命题版本和两在线对读页中，未见针对 VII.22 的正式勘误。这是所见材料的范围，不等于校完所有印次。Fitzpatrick 213 页否定句按希文和上下文作“没有数同时量尽两项”理解，不把翻译措辞另立为数学命题。
