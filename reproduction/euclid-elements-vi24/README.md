## 构造、检查与边界

- 用不共线的向量 u、v 表示平行四边形的两条边，四个顶点为 0、u、u+v、v。参数 t 在 0 与 1 之间，两组平行线在 t(u+v) 交会。起角与对角的两格相对于整图分别沿两轴等比缩放 t、1−t；另一对两轴比例一般不同。
- 例 u=(6,0)、v=(2,4)、t=1/3，整图面积 24，起角与对角格分别为 8/3、32/3，剩下两格各 16/3。两条边长度比较使用实际坐标算边长平方；计算面积时用鞋带公式，并与从邻边行列式得到的面积独立核对。面积数值是现代说明，不作为 VI.24 原命题的附加声称。
- 共 28 个配置：4 对边向量（包含斜形、矩形、有理向量和反向取向）与 7 个内部切分。检查交点在对角线上、两格相似倍率、四格面积和、非对角格的对应边平方比。切分为中点时四格同以 1/2 缩放。其他 t 值的非相似测试只针对标记的方向对应，不排除其他顶点重标。
- 在同一例中让 u、v 两方向的切分参数分别为 1/3、1/2，交点变为 (3,2)，离开对角线；起角与对角格均失去原来的按轴等比。共线或零边向量，以及边界切分不是这里的合法输入。
