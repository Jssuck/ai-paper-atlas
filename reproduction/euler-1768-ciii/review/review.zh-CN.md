# Euler CIII：独立代码与数学语义复核

## 结论

**通过；未发现需要修正的语义求值、候选枚举、形式匹配或反例报告错误。**
本复核针对本目录中的现代集合论复现，不代替原版图像、法文转写及历史解释的文献复核。

独立量词／集合 oracle 得到：

- 允许项为空时，九式中的八式有效；A5 无效。
- A5 的前提为 `A ⊆ B ⊆ C`，故其结论 `C ∩ A ≠ ∅` 在前提下恰好等价于 `A ≠ ∅`。仅假定 B、C 非空不足以修复。
- 加入 A 非空，或加入全部三项非空后，九式均有效。
- `A ⊆ B`、`A ⊆ C` 推出 `I(C,B)` 需要 A 存在；在指定的两种匹配约定下均未匹配九式。
- `A ⊆ B`、`O(A,C)` 推出 `O(B,C)` 不需要另加存在假定；其第二前提已提供见证，同样未匹配九式。
- 原始占位掩码共 256 个；掩码 0 添加项外见证后与掩码 1 重复，故有 255 个不同的标准占位模型。这里的“不同”指占位模型，不指公式真值等价类。

上述两个未匹配模式仅支持在明确现代匹配准则下的完备性疑问，不能单凭程序判定 Euler 历史上的“形式”分类错误。

## 独立性与方法

`independent_oracle.py` 用普通集合与直接量词定义 A/E/I/O 的真值：全称用 `all`，特称用 `any`。九式由本复核手工独立录入；模型、存在约束、256 候选式与 E/I 转换／项置换／前提交换的显式闭包均由复核程序独立生成。预测结果不调用被审实现的求值器、模型生成器、候选生成器或规范化／匹配器。

程序导入被审模块，只为把它的实际输出与独立预期作比较。这种导入不意味着复用被审逻辑来计算预期答案。量词求值还与另一套普通集合运算交叉比较。

审查同时阅读了 `PROOF.md` 的有限化证明。任意非空论域的元素按三个一元谓词的隶属向量分为八类；每个非空类保留一个代表即可保持四种范畴关系与项非空条件。因此枚举覆盖任意大小论域的反模型。额外枚举小论域只是代码交叉检验，不作为普遍有效性的证明。

### 必须保留的解释边界

1. A5 在允许空项时有 16 个满足前提的原始掩码，合 15 个不同占位模型；反例为 8 个原始掩码、7 个不同模型。原始反例是 `0, 1, 16, 17, 64, 65, 80, 81`，不能称为八个不同反模型。
2. `A ⊆ B` 且 `C ∩ A = ∅` 不推出任何一个固定的 C→B 范畴结论，但 A 非空时确实推出反向的 `O(B,C)`。“无推论”必须注明方向及候选语言。
3. `I(A,B)` 不推出 `O(A,B)`，即使三项均非空。通常存在意义的“某些”不排除“全部”。
4. 梨树与树的相等模型反驳从包含与存在直接推导严格包含；严格包含示例中非梨树见证属于额外前提，不能循环地当作已从原前提推得。
5. 已检验的是两类固定首前提、共享一项的第二前提及两端项间的结论。未声称穷尽全部首前提种类、更多前提或整套传统三段论。

## 实际运行与可重跑记录

从项目根目录执行：

```sh
bash review/run_review.sh
```

该脚本只使用 Python 标准库和常见本地 shell 工具，不安装软件，不访问网络，不更改生产环境或远端。它依次执行：

```sh
python3 --version
uname -s -m
python3 -m unittest discover -s tests -v
python3 reproduce.py --output review/reproduced
cmp results/report.json review/reproduced/report.json
cmp results/report.txt review/reproduced/report.txt
python3 review/independent_oracle.py
```

最终记录以同目录中的机器生成文件为准：

- `implementation_tests.log`：独立重跑原有 30 项测试的完整输出与解释器／平台摘要。
- `reproduction_run.log`：独立重跑 CLI、报告逐字节比较及成功标记。
- `independent_tests.log`：独立 oracle 的 8 个测试组及明细计数。
- `independent_results.json`：UTC 时间、Python／平台、各项结果和所审文件 SHA-256；只包含项目相对路径。
- `reproduced/`：本复核单独重建的 JSON、文本与运行环境记录。

审查的最终状态是 30 项原有测试通过、8 个独立测试组通过，确定性 JSON／文本报告逐字节相同。时间戳与测试耗时随重跑变化；逻辑结论与报告内容应保持一致。任何后续源文件改动都应重跑以上脚本，以更新哈希及日志；本报告不以旧日志担保新版本。
