# 《几何原本》X.1：余量降到给定量以下

教学模型以整数和精确分数表示正量。给定阈值 $x$ 与起始量 $y>x$，选择最小整数 $N$ 使 $Nx>y$。从初始余量 $r_0=y$ 开始，每一步要求 $0<r_{i+1}<r_i/2$，并核对线性参照梯 $(N-i)x$ 及现代界 $r_i\le y/2^i$。可选择启用“至少削去一半”的现代统一模式（恰取半已见原证附句）；程序要求严格低于阈值才认定越界，等于阈值时仍需下一步。例：阈值 5，余量 12、5、2，在两步后越界。仅严格单调递减不足，例如 $5+2^{-i}$ 始终不低于 5。

输入必须给出到越界为止的有限证据，程序不从有限前缀推断任意未来，也不模拟无理量。测试独立地逐项查找第一次越界及两个上界，取初始量 2 至 32、阈值为更小正整数，分别用乘率 $1/3,2/5,1/2$ 构造余量。有限验证不代替一般证明。
