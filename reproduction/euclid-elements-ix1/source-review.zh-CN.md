# IX.1 原典与链接核对

- [Heath 1908 卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)：PDF 第 397 页《BOOK IX》标题下，页未标印页码，依后页 385 定位为 384。扫描核题头、四字母线段图、正文、证毕与译者小写代数简述。后者不属于原证明希文。编辑标注顺序是 VII.17、VIII.18、VIII.8、VIII.22。
- [Fitzpatrick 希英本 p.254](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=254)：完整命题在第二命题题头之前。希文与英文同样由希文 Γ 的对应 C 承载目标积，Δ 的对应 D 承载平方。英译编号与 Heath 一致。本次对读未识别适用的正式勘误，不宣称校遍各版。
- [Clay 希英在线版](https://www.claymath.org/library/historical/euclid/files/elem.9.1.html) 的英译结束于说明 D、C 间存在一个中项，希文还包含已知 D 为平方到 C 为平方的闭合。[Joyce 本文](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX1.html) 保留闭合且在转移段明确使用 VIII.8；Guide 的提纲改链 VIII.1，不据此改动原证明路线。
- [VII.17](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII17.html) 同乘保持端点比；[VIII.18](https://www.claymath.org/library/historical/euclid/files/elem.8.18.html) 相似到整数中项；[VIII.8](https://www.claymath.org/library/historical/euclid/files/elem.8.8.html) 同比转移；[VIII.22](https://www.claymath.org/library/historical/euclid/files/elem.8.22.html) 由整数中项和首端平方得末端平方。[IX.2](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX2.html) 和 [X.29 第一引理](https://mathcs.clarku.edu/~djoyce/elements/bookX/propX29.html) 只核逆向题头和使用位置，不作新增读完项。
- [深读正文](../../papers/ancient/euclid-elements-ix1.zh-CN.md) 的混合积、两个中项的具体计算、素数指数和有限代码是现代教学重构。此处只给书目和核查结论，不附扫描或全文翻译。
