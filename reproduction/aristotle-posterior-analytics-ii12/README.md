# II.12 教学复现：时间方向与推理方向

本目录是原创的现代有限模型，不是古代实验复刻，不把模型中的事件标签认证为现实原因。对应《后分析篇》II.12（95a10–96a19）：后事回溯必要先件、事件与过程的时间划分、循环生成、通常性。

## 1. 模型的四层

1. **必要条件图**：边 `(a,b)` 表示“a 成立要求 b 成立”，不是“a 引起 b”。例：房屋→地基→石块。只检查显式给出的规则，不认证规则本身。
2. **有时刻的有限轨迹**：`None` 表示在整个被建模轨迹中不发生，不是现实中的未知；整数是完成时刻。仅本实验要求必要先件严格早于后件，不能把它套到章首同时原因的例子。`completed` 是时刻不晚于观察点的事件集合，不是持续过程的完整语义。
3. **稠密与循环示意**：精确有理数中点示范可插入时刻；循环表仅按给定四类依次列出时间 token，不模拟气象动力学。类型相同不表示同一次事件重复造成自身。
4. **通常性替代模型**：严格多数定义为非空主项中超过一半的成员落入谓项。这是为暴露推理危险选的现代定义，绝不声称等于原文“通常”的唯一解释或概率定律。

## 2. 一般证明，不靠枚举替代

### 闭包为何可靠且在本语言完备

设有限事件集 V、基底 S、单前件规则 a→b。算法从 S 起，只加入某条已满足前件规则的后件。归纳可知，每次加入的事件都在任一满足 S 和全部规则的赋值中为真，因此算法可靠。至多 |V| 次真正增添后停止。终止集合 K 包含 S 且对所有规则闭合，所以 K 本身就是一个满足赋值；任何不在 K 的事件在这个赋值中为假，故不是逻辑后承。这证明完备性，仅限该正单前件规则语言，不是因果发现、一般自然语言推理或无限系统的完备性。

`truth_oracle` 独立枚举全部赋值，取满足赋值的交集，不调用闭包算法。本语言的全真赋值总满足规则，故交集对象集合非空。

### 必要先件为何可回溯

若每条边 a→b 满足“a 发生就有 b，且 t(b)<t(a)”，那么已完成 a 时，b 也必已完成。沿有限链重复应用即可。对于房屋 H→地基 F→石块 S，H 已完成推出 F、S 已完成；方向是认识上的回溯，时间仍 S 在前、H 在后。反向不成立：S 在0完成而 F、H 均不发生，是符合规则的模型。

即使最终都有发生，S=0、F=1、H=2，在观察点1仍不能说H“已经完成”。没有额外完成保证时，S已完成也不蕴涵H将完成。程序不是检验古代所有时态推理的完整系统。

### 无相邻时刻与直接解释是两件事

任意有理数 a<b，m=(a+b)/2 满足 m−a=(b−a)/2>0 与 b−m=(b−a)/2>0。因此区间内总有另一个有理点。这是一般代数证明；21个数对只是实现测试。它不证明现实时间必为有理数或实数，不保证每个中间时刻都有另一个解释中项，也不证明不存在直接前提。

### 全称传递与多数失效

若 C⊆B 且 B⊆A，任取 x∈C，先得 x∈B，再得 x∈A，故 C⊆A。若换成严格多数，这个推导第一步就不能对任意x使用。取C={0}、B={0,1,2}、A={1,2}：C的全部成员在B中，B中2/3在A中，但C没有成员在A中。不能把两个“通常”机械串成结论“通常”，更不能无独立性和同一总体条件直接相乘。

## 5. 带答案练习

1. 房屋→地基是因果箭头吗？答：不是，是本模型中的必要条件蕴涵，箭头与通常生成次序相反。
2. 石块在0完成，能否推出房屋在2完成？答：不能，None后件是合法反模型。
3. 已知房屋2完成，能否证明某个特定石块0完成？答：规则只涉及给定标签，现实对象身份与具体时刻仍须独立证据；程序不能从抽象规则推出0。
4. 全无轨迹是否合法？答：是，蕴涵前件全假，不能因此推出现实什么都没有。
5. 图中H→S→H而无基底能推出H吗？答：不能，空赋值满足两规则，最小闭包为空。
6. 为什么同一循环类型可以再出现但不是自因？答：如(0,wet_ground)和(4,wet_ground)是两个不同token。
7. 中点是否必须成为新的原因？答：否，时间坐标密度与解释结构之间没有给定桥接规则。
8. 多数反例为何可用单元素C？答：多数的分母是各自主项；更换条件总体正是传递失败的来源之一。
9. 有限枚举能证明任意事件集闭包正确吗？答：不能，一般证明见第2节；枚举检查的是实现与有界实例。
10. 优化模式测试通过意味着Jupyter运行通过吗？答：不意味着，命令与执行层次不同。

## 6. 不主张的结果

不认证房屋建造的所有技术、气象循环的现实机制、时间本体论、所有“通常”论证或无限因果链终止。现有程序不自动发现科学原因，不裁定原文唯一解释，不把后件推先件当成逆时间作用。
