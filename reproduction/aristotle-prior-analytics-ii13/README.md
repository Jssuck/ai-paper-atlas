# II.13 教学复现：第三格内部推理与归谬目标

配套[中文深读](../../papers/ancient/aristotle-prior-analytics-ii13.zh-CN.md)及[来源台账](../../papers/ancient/aristotle-prior-analytics-ii13.sources.zh-CN.md)。这是原创标准库教学程序，实读单元为62b5–28；不是古代算法复制、自然语言证明器或完整亚里士多德逻辑复现。沿用前篇明示的类型支持枚举方法，但改为本章共同主项B、结果A/C及不同见证检查。

## 语义、模型与范围

谓项在前：U(P,S)为所有S是P，E(P,S)为没有S是P，I(P,S)为有S是P，O(P,S)为有S不是P。整句矛盾配对为U/O与E/I，不是U/E或I/O。

论域非空而项可空。成员类型0–7的bit0=A、bit1=B、bit2=C；每个非空类型支持集取一代表，得到255模型。三项均非空的过滤子集为218；只要求B非空为240。模型排序为支持集基数、再按升序类型元组字典序。对这个无等号、无计数的一元语言，重复同型对象不改变四型真值；此约化理由与正文的一般证明是理论说明，运行日志自身不是一般定理的证明。

## 内部步骤不能与外部结论混同

固定目标Q(A,B)，临时假设H=NEG(Q)(A,B)。程序限定一个第三格步骤：H(A,B)与X(C,B)推出R(A,C)，B为共同主项。已知背景另含K=NEG(R)(A,C)。Q、X、R各四型，形成每政策64候选；不先换位、不增加中项、不搜索任意多步证明。

每候选分别记录：
1. 内部前提H、X有多少模型、是否推出R、失败时多少反模型及最小反模型。
2. 独立背景X、K有多少模型、是否推出Q、失败时反模型。
3. 只有内部与外部均有效且各自前提可满足，才标certificate=true。这是本程序的教学标签，不是通用证明内核认证。

原文四条路线在允许空项政策全部有效：

|目标|假设H(A,B)|X(C,B)|内部R(A,C)|独立K(A,C)|
|---|---|---|---|---|
|U|O|U|O|U|
|I|E|I|O|U|
|E|I|U|I|E|
|O|U|I|I|E|

前两路K将原文“结果不可能”的背景显式补齐，属于教学重构；后两路E背景有原文明确表述或回指。第三格内部只出特称，不妨碍整个归谬撤除假设后得全称U/E。

## 实跑结果与17项专门检查

|政策|模型|候选|U路线|E路线|I路线|O路线|
|---|---:|---:|---:|---:|---:|---:|
|允许空项|255|64|1|1|1|1|
|三项全非空|218|64|1|1|2|2|

额外两条来自第三格双全称前提推出特称结果所需存在条件，不是把原文说成宣布两个新式。17个具名检查包括四标准外部推导、I/O路线用全称背景替代存在背景的失败与单独B存在修复、错误否定强度及本章特有内部存在问题：

- I或O的存在背景I(C,B)若改U(C,B)，B空时失败，最小反模型[0]；单独B非空即修复。
- E(A,B)+U(C,B)并不无条件推出O(A,C)；U(A,B)+U(C,B)也不无条件推出I(A,C)。两者空B反例最小[0]，单独B存在足够。故本章“错误反对假设仍有三段论”须说明传统存在背景。
- 排除E只直接给I，不给U。具名弱背景U(A,C)+I(C,B)并不推出U(A,B)，反例[2,7]。完整原U路线背景仍可另证U，不把错误局部撤除步骤冒充整个背景失效。
- O目标背景I(C,B)+E(A,C)不排除I(A,B)，反例[3,6]；I和O可共真。
- I(A,B)+I(C,B)不保证I(A,C)，三项非空最小反模型[3,6]。两个存在前提可能由不同B对象满足，不能合并成一个见证。

结果内保留全部候选及反模型，便于独立实现复核。有限搜索不能证明任意自然语言推理不可证，也不能裁定古代唯一存在语义或现实背景真假。
