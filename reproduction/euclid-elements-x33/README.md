# 《几何原本》X.33：用二次共轭精确表示输出边平方

以 `u>0` 为参考长度，输入相对平方 `h=AB²/u²`、`l=BC²/u²`，要求 `h>l>0` 且 `k=l/h`、`1−k` 均非有理平方。`construct(h,l)` 返回两条输出直角边的**平方**坐标的精确表示：中心 `h/2`，根式系数 `h/2`，被开方数 `1−k`，分别取正负号。两条直角边长是两个正平方坐标的正平方根。平方坐标之和为 `h`，乘积为 `hl/4=(xy/u²)²`。严格范围保证两个平方坐标都为正。代码不近似根式，不实现尺规操作。

例如 `h=9,l=2` 时平方坐标为 `(9/2)(1±√(7/9))`，相对矩形面积平方为 `9/2`。`(4,1)` 仅令 `k` 成平方，`(4,3)` 仅令 `1−k` 成平方，`(25,9)` 两者都成平方；三组都被拒。零、相等、反序、非精确类型也被拒。

整数基线枚举整数平方：`hl` 与 `h(h−l)` 分别与两个比例相差有理平方因子 `h²`。对 `1≤l<h≤64` 的 2,016 对输入，1,904 对接受，54 对仅 `k` 成平方，54 对仅 `1−k` 成平方，4 对二者都成平方。对有效输入用共轭相乘独立核对输出矩形的面积条件。有限校验不能代替一般性证明。
