# 《几何原本》X.25：中项边矩形的两类面积

取参考线段 `u>0`，设输入 `q=(x/u)^4`、`k=(y/x)^2`、`b=(底边/u)^2`。三项必须为正有理数，前两项不能是有理平方。函数 `construct(q,k,b)` 返回三个宽平方的相对值 `(q/b,kq/b,k²q/b)`、矩形相对面积的平方 `kq`，及相对面积是否为有理数。判别使用既约分数的分子、分母的整数平方根，不以浮点数近似长度。矩形面积 `xy` 与两端正方形面积 `x²,y²` 相对于同一底边所用的三个宽构成等比；检验平方后的中项仍成立。

例如 `q=k=2,b=1` 得三个宽平方 `2,4,8`、相对面积 2；`q=2,k=3,b=2` 得三个宽平方 `1,3,9`、相对面积 `√6`。若 `q` 是平方，则 `x` 不满足中项前提；若 `k` 是平方，两边已在长度上可公度，均不属于本命题模型。模型不处理任意实数或模拟尺规操作。

独立校验直接生成有理平方集合，不调用整数平方根。原始三项的分子分母均在 1–4，故 `kq` 的既约两项至多为 16，其有理根若存在，既约两项都不超过 4。实跑 4,096 个有序输入代表（不去重）：576 个有理面积、1,024 个无理面积、2,496 个前提之外。有限校验不能代替定理证明。
