# I.46：否定作用域的最小教学核验

本目录是原创、标准库实现的现代教学模型，不是古代文本的唯一语义，也不是完整自然语言解释器。与[中文深读](../../papers/ancient/aristotle-prior-analytics-i46.zh-CN.md)配套；一般证明见正文，以下有限实跑仅检查实现和实例。

## 模型与限制

1. 取有限论域 U、适用域 T、正项 P，要求 P ⊆ T ⊆ U。定义 A=P、B=U−P、C=T−P、D=U−C。检查 C⊆B、A⊆D、A∩C=∅、B∩D=U−T，及 T=U 恰使两种否定同外延。T 是明确添加的教学参数，不宣称原文拥有集合论定义；论域外指称、真实的善恶和非存在对象没有被建模。
2. 另取 C⊆A，B=U−A、D=U−C。检查逆否方向 B⊆D、严格性等价及 A∩D=A−C。这里的字母另行重置，不和第一模型混用。
3. 检查全称命题的否定等于存在反例，而不等于全称否定。允许空主项，保留空集的边界行为。
4. 检查“既非A又非B”的外延 U−(A∪B)。当 A/B 互补时它是空集，并非通常的 U−A；不把这个布尔模型当作对末段所有历史解释的裁决。
5. 在明示的有限可达情境序列上，can_walk=存在真值True，can_not_walk=存在False，not_can_walk=无True。该模型只展示作用域差别，不模拟人体能力、知识或古代完整模态理论。允许零情境以检测边界：两个可能性都假，not_can_walk为真；不能默默假设可达性非空。

## 文件与运行

- `model.py`：五类核验接口和严格输入校验。
- `test_model.py`：22项原创单元测试；覆盖木块反例、空域/空适用域/空主项、生成器、重复项、不合法输入及模态边界。
- `run_experiment.py`：有限穷举，失败使用显式异常，不依赖会被 `-O` 删除的 assert。
- `logs/environment.txt`：真实运行环境；无需第三方包。
- `logs/test-*.log`、`logs/experiment-*.log`：三种模式的真实输出。

从本目录运行：

```sh
python3 -m unittest -v test_model
python3 run_experiment.py
python3 -O -m unittest -v test_model
python3 -O run_experiment.py
python3 -OO -m unittest -v test_model
python3 -OO run_experiment.py
```

API 的集合元素是非空字符串；容器可为集合、列表或一次性生成器，重复元素按集合语义合并。字符串自身不当作集合输入；不接受整数或布尔值作为元素。所有输入先完整物化校验，避免短路跳过非法值。模态输入只接受真正的 bool，不将整数1冒充True。集合包含条件失败会抛出 ValueError，类型错误抛出 TypeError。

## 真实结果与统计口径

正常、`-O`、`-OO` 均22项测试通过，穷举统计逐项相同。每个模式分别检查：

|检查|范围与数量|结果|
|---|---|---|
|适用域四项图|U大小0至5；364个(P,T)模型|全部关系通过；301个模型T≠U，显示两种否定可分离|
|补集逆序|U大小0至5；364个C⊆A模型|全部通过；301个严格包含模型，反向D⊆B失败|
|量词作用域|U大小0至5；1365组(S,P)|否定全称与存在反例全部一致；763组与全称否定不同|
|联合否定|U大小0至5；63个互补(A,B)模型|F均为空；57组不满足A∪F=U|
|可达情境|长度0至4的31个布尔序列|23组can_not_walk与not_can_walk不同；含零情境边界|

模型数包含空论域这个现代边界测试，不由此认定古代逻辑允许空论域。正整数n时，对每个对象的三种状态可得到3^n种适用域模型；这是统计枚举的解释，不是以测试数替代一般定理。

计数不按三种Python模式相加来冒称更多数学模型。没有训练数据、统计基线或精度指标；这是理论单元的有限核验，不是实验论文复现或完整定理证明器。不存在证明义务仅凭运行日志自动解决的情况。
