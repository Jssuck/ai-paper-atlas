# 《几何原本》VI.25：按指定面积重造相似图形

[中文精读](../../papers/ancient/euclid-elements-vi25.zh-CN.md)讨论 I.44、I.45 的面积转移和 VI.13、VI.18 的比例线与相似图形构造。此处以共高矩形作现代坐标模型，未把古代作图限于直角。模型不是原文尺规形式化。

仅依赖 Python 3.9+ 标准库：

```sh
python -B -m unittest -v
python -B -O -m unittest -v
python -B -OO -m unittest -v
python -B replay_notebook.py
```

[程序](equal_area.py)、[测试](test_equal_area.py)、[Notebook](euclid-vi25.ipynb)。实跑：[常规](normal.log)、[`-O`](O.log)、[`-OO`](OO.log)、[Notebook 回放](notebook-replay.log)。逐格编译执行 3 个纯 Python 单元，未调用 Jupyter 内核或验证前端渲染。

## 对照与限制

- 底长 6、原面积 12、目标面积 27。先取共高 2，把目标面积转移为底长 27/2 的矩形，再取几何平均得到新底 9。鞋带公式分别独立核对两矩形和按长度系数 3/2 缩放的三角形面积。
- 60 个设计好的有理数配置：4 个源底、3 个源三角形高、5 个长度尺度。缩小、不变、放大分别 24、12、24 个。通过实际坐标的面积和共高矩形的面积核对正根证书。构造拒绝非正底或面积。
- 目标改为 6，转移底是 3，输出底平方是 18，正根为 3√2。精确保留输出底平方及尺度平方 1/2；标准库的有理数类型并不表示这个无理根，示例不伪造相似三角形的有理坐标。该例验证平方证书，不声称对普遍无理长度作了精确坐标运算。
- 若把面积比 27/12 直接作为长度缩放系数，三角形面积反而成为 243/4。有限实测用于排查算法和方向错误，不是一般定理的证明。
