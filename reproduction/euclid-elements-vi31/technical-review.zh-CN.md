# VI.31 独立技术核对

独立复核两套印本文字及图示、中文精读中的比例证明、算例和练习，并重新运行教学代码。

- **对应关系。** 直角在 A，斜边为 BC。整体与左右小三角形分别给斜边、对应直角边和投影三项的连比，不能交换 BD 与 DC。三份相似图形在三边上使用模板的同一对应边；同形矩形若换一条边作底，即会改变面积系数。Fitzpatrick 页 189 与 Heath 页 269 的图有矩形轮廓，但正文不把一般命题限于矩形。
- **比例聚合。** VI.19 的推论把两组连比转成面积比。先反转两式，让共同的后项为斜边长度和斜边上图形面积，再按 V.24 合并两个前项；这一步不把长度与面积直接互比。回到斜边的两个线段相加等于全长，才取得面积等式。此证明不先用 I.47；现代共同面积系数只是另一个核验方法。
- **独立运行。** 普通、`-O`、`-OO` 三种模式各通过 5 项测试，精确网格有 216 个配置。坐标直接核验投影及腿到斜边的面积比例，并比较全部面积；复查了错形、非直角和退化输入。三道 Notebook 代码单元均能用标准库回放，未执行 Jupyter 内核。有限验证不替代一般证明。
