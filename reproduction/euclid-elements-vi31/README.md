# 《几何原本》VI.31：三边上的相似图形面积

[中文精读](../../papers/ancient/euclid-elements-vi31.zh-CN.md)说明欧几里得的比例证明。这里用鞋带公式和垂足的有理坐标进行独立面积、投影比检验，不是古代证明的形式化执行。

## 对照与限制

- 先生成有理坐标的直角三角形。以点积求垂足及沿斜边的投影比例；在每条边上把模板的标记单位底映射到实际边端点，侧向方向由直角旋转并可选反射，从真正的多边形坐标计算无向面积。核对两腿图形与斜边图形的面积比、两段投影比及面积相加。反射用于现代无向面积的鲁棒性检查，不宣称原文把所有图形摆法视为等同。
- 3–4–5 例的垂足为 (9/5,0)，正方形面积 9、16、25。另取单位模板面积 51/80 的非正方形四边形，实算三面积 459/80、51/5、255/16，面积比 9/25 和 16/25。模板应为非退化简单多边形，且有指定的水平单位底；代码不自动判定任意模板相似关系或简单性。
- 216 个精确配置：6 组生成三角形的参数 × 3 种缩放 × 3 种旋转 × 2 种摆放方向 × 2 个模板。点积检查直角及垂足，再比较由距离平方得到的比和独立鞋带面积；有限实跑不能证明一般定理。
- 若只把斜边上的正方形改成以该边为腿的等腰直角三角形，则其面积 25/2 不再等于两腿上正方形之和 25。若保留同模板，却把三角形顶点换为 (1,1)、(0,0)、(4,0)，则前者不是直角，腿上面积和 153/20 不等于对边面积 51/5。
