## 1 两种本身关系不能混成一个包含箭头

`definition_link(subject,predicate,1)`输出主项到谓词的定义依赖：谓词出现在主项的定义中。`kind=2`输出谓词到主项：主项出现在谓词的定义中。例如human→animal和odd→number。二者都约定箭头从“被解释项”指向“定义使用项”。这只记录输入者声明，不检查定义是否正确。

这个方向不是断言所有number都是odd，也不是自动把定义依赖当成类包含、原因关系或严格谓述顺序。后面的严格序模型另外提供边，另外检查无环；没有从上述两条书目相关示例推出那个假设。

## 2 严格秩与中项插入

给有限顶点集与有向边；若有自环或有向环，strict_ranks拒绝。否则以到终点的最长边数给秩：每沿一条边，秩至少下降1。方向约定为“向上推进”，数值秩则递减，两者不冲突。有限DAG本身是教学假设，不是从古代文本自动认证的事实。

order_closure计算严格传递闭包。对于固定端点a、b，只在已有相邻x、y之间存在x→z→y时插入z。每一步：

1. 起点和终点不变，不能在端点外追加项充当中项。
2. 严格无环保证新节点不等于链上已有节点。
3. 链长度增加1；若总节点数n，初始两端链最多插入n−2次。
4. 不能再插入时，相邻对都是当前有限序的cover，即无位于其间的给定词表项。

这给出一般的**有限输入条件下**终止理由。枚举只检查实现没有违背它，不替代证明。相同端点可有多条饱和链：菱形0→1→3和0→2→3中，1与2不可比较，不能合并成0→1→2→3。cover也只针对给定关系，不认证科学直接性。

## 3 两个边界实验

**类别有限不是秩。** 两节点都可以赋同一类别，边0→1与1→0仍构成循环；程序拒绝为它给严格秩。更强的数学边界是：所有自然数可以使用同一类别标签而按0→1→2→…推进。程序没有穷举该无限例。若允许任意边，有限范畴数本身不限制链长；原典限制还依赖本质、承载者、严格谓述及可定义性等条件，不能删掉。

**循环推导不是无前提知识。** 规则p→q、q→p、q→r在没有种子时，最小Horn闭包为空；输入种子p后，第一轮增加q，第二轮增加r。若给空前提规则，它本身就是外部提供的公理，当然可启动推导。此程序只计算语法可导性，不判断种子为真、不认证认识论上的更好把握，也不证明原典所有知识必须是这种算法所得。没有种子的有限循环与无限回归不是同一对象，此处只是结构对照。

Horn有限终止的理由是已知集合只增不减，每个非空轮增加至少一个尚未知原子，最多增加有限原子总数减种子数。这不代表现实证明搜索总能停止。

## 5 不能由实验得到什么

不能从这份代码推出所有定义有限、所有本身谓词可互换、所有科学前提均可发现、亚里士多德的无限回归论证无争议。也不能因某条路径已饱和就断言不存在词表外新中项。这里所能核验的是给定有限结构的秩与细化不变量，以及给定规则的最小语法闭包。
