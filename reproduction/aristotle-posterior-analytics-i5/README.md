# 《后分析篇》I.5：覆盖、解释层级与支持集的有限教学实验

这是原创现代教学代码，不是古代程序复原，也不是一般认识论定理的数值证明。配合[深读正文](../../papers/ancient/aristotle-posterior-analytics-i5.zh-CN.md)阅读。原文I.5关心：每个种分别成立，为什么仍可能没有识别属性恰当地属于哪个共同主项。

## 运行

仅需Python 3标准库与Bash，无第三方包、网络、密钥、随机种子或GPU。

```bash
bash run.sh
```

脚本在本目录执行23项unittest，分别使用正常、`-O`、`-OO`模式，再各自执行有限枚举。测试使用unittest断言方法，不依赖会被优化删除的`assert`语句。`logs/environment.log`记录实际环境；`logs/tests-*.log`和`logs/enumeration-*.log`是实跑标准输出/错误；`results.json`是正常模式结果，`SHA256SUMS`校验本目录文件。再次运行会更新真实日志及耗时，不应期待日志哈希与本次完全相同。

## 1. 外延覆盖检查，不等于说明根据

`coverage_report(target, property_mask, parts, size)`使用有限论域位掩码。目标T、满足属性的对象P和若干部分类S由调用者给定。它分别报告：

- T是否被各S的并集覆盖，以及遗漏对象。
- 并集中是否有不满足P的对象。
- T本身是否都满足P。
- 各部分之外与目标之外的对象；空类和重叠不会被偷偷删除。
- `extensional_certificate`仅表示覆盖和所有部分真同时成立，不表示发现了属性的原因、本质或首要主项。

一般集合论理由可直接写出：任取T中的x，覆盖给出某个含x的S；该S所有元素满足P，故x满足P。此论证不要求各S互斥，也不要求各S非空。因此原文批评不能解释成“覆盖各类永远无法逻辑推出全称”。它批评的是把按种分别掌握结果冒充作为共同主项的解释。

三个对象上，T、P、S1、S2各有8种取值，实跑4096组合。独立表示的逐对象set oracle核对覆盖、各部分真、目标真与证书四个布尔量，差异0；512个组合有证书，证书真而目标假为0。这个枚举只是检查实现，并不取代上述任意x的证明。

反例：T={0,1,2}、P={0,1}、S1={0}、S2={1}，两类各自成立却遗漏2。另一边界：T={0}、P={0}、S1={0,1}，目标已经真，但过大的供给类含反例1，所以当前证书不合格。证书失败不是目标为假的证明。

`extensional_candidates`只返回候选标签中外延全部满足P的类，包括空类。如果在受限样本里“所有三角形”和“等腰三角形”都是同一个掩码，它无法区分二者。程序故意没有“真正本质”输出；同外延不保证同定义或同解释。

## 2. 删除额外限定：只诊断所声明路线

`available_routes(routes, retained)`把每条路线看成调用者声明的充分支持集，返回仍被保留条件覆盖的路线编号。例如仅声明`{'triangle'}`，删除`bronze`与`isosceles`后路线仍在；删除`triangle`后仅留`figure`和`limit`不能支撑该声明路线。

这不是实际重新运行几何证明，也不自动验证“triangle”是充分根据；三角形标签只是经过教学假定的输入。没有保留路线只说明这些声明不可用，不证明属性为假或不存在别的证明。空支持集允许表示调用者直接接受的无条件路线，不把它包装成无前提发现。三个标签的8种必需集与8种保留集，共64组合，逐位oracle与集合包含结果差异0。

## 3. 没有共同名字时的受限比例示例

`alternation(a,b,c,d)`只接受正整数或正`fractions.Fraction`。它检查a/b=c/d和a/c=b/d。正数保证分母不为零；第一式乘bd得ad=bc，再除cd得第二式。这是现代有理数域的共同结构演示。它不把线、体积、时间简单视为同单位的整数，也不宣称恢复古希腊包含不可公度量的比例理论。浮点数、零、负数与布尔值明确拒绝，避免把计算近似或越界输入误当此示例的证据。

1至6的四元组共1296个，其中86个满足前提，结论反例0。另有非整数正有理数单元测试。无统计泛化、真实世界数据集、学习器或性能提升主张。

## 局限

论域有限而且属性表由外部提供；没有估计未知实例。支持集检查不读取证明语义、不判断因果、不判定本质。比例例只覆盖显式有理数输入。程序不能裁定文本异读、古代论域的唯一解释、或原文主张的历史正确性。它能做的是暴露覆盖遗漏、区分目标真假与证书可用性，并演示外延一致对解释层级的欠决定。
