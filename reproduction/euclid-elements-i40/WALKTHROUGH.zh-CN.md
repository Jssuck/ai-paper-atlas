# 看懂实际算例

默认输入 A=(1,2)、B=(0,0)、C=(3,0)、D=(5,2)、E=(4,0)、F=(7,0)。两底长均为3且共线，两三角形面积均为3；辅助 G=D，AD 水平。此处使用六点推广符号，与原文五点的映射见 README。

只把 D 高度改成4：t=1/2，G=(9/2,2)，G 在 ED 内部；DEF、GEF、GDF 的双面积分别为12、6、6。I.38 对应的 ABC 与 GEF 等积，但 GEF 是 DEF 的真部分，因此它不可能同时等于 DEF。这不是定理正例：原来的等积前提已失败。

把 D 高度改成1：t=2，G=(6,2)，G 在 ED 延长线上；DEF、GEF、GDF 双面积分别为3、6、3，整体与部分交换，仍不可能相等。

一般 t 是相对于同一公共底方向的两个有向高度分子之比。同侧使 t>0，非退化使分母非零。t<1、t=1、t>1 三分支穷尽正有理比例。双面积只是现代核验值；原文一般证明仍需构造交点和 I.38，不可把这张数值表当作证明。

练习：为什么两底反向不影响结果？答案：采用无向底长和绝对面积；侧向比较始终以 BC 的同一方向为准，不混用反向 EF 的符号。

练习：若 A=D，为什么证书不能仍写 AD 平行？答案：两个相同点不能确定一条直线。可以说存在过该共同顶点、平行底线的直线，但这是不同的命名表述。
