# 行动、习惯、意向与规范：现代教学模型

## 0. 历史定位及不可越过的边界

这是为孔狄亚克《逻辑》第一部第六章制作的原创数学教学装置。参照1798年《全集》第二十二卷印第54—57页；目录名中的1780是作品书目年，不是所用扫描本的年份，也不表示本项目已读到1780年初版本。程序中的递推、参数、表格、有限集合和数值例子全部是现代编者设定，绝非作者留下的算法。

原文与装置的对应分四步：

1. 第54—55页说，反复做使行动形成习惯；停止做使同样的行动不再一样容易。我们用一个标量递推把这两个方向显式化。原文没有学习率、指数衰减或量化标尺。
2. 第55页说，从可见身体行动判断不可见心灵行动，并诉诸自己欲求、恐惧时的经验。我们用已给定的“情境—意向—行动”表检查逆推的条件；原文没有提供这种表，也没有证明跨人迁移总成立。
3. 第55—56页把德行、恶习解释为好行动、坏行动的习惯。我们把“习惯程度”和“行动是否符合指定规范”拆开，防止把反复做直接当作道德根据。
4. 第56—57页把行动的道德性说成仅在于与法律相符合，并反驳“约定所以任意”：需要和能力既定，自然法则也随之规定，上帝才是真正的立法者。我们只检验在给定额外规范前提后能算出什么，既不删去这段自然法—神学论证，也不把它伪装成程序结论。

第54页开头还区分无生命物体和有生命身体的行动，并把行动联系于造成效果的运动。本模型没有力学、器官或物种参数，不能替代这部分的阅读。第55页关于自然语言的首要性、表现力与真实性也不是本程序的可检验命题。

以下证明只对明示假设成立；没有人类或动物数据，不证明心理机制、道德真理、自由意志或神学命题。不同于上一章“原因存在、身份与属性”的模型，本章把时间中的练习、情境中的行为解释、规则下的评价串联起来；也不把习惯退化成一次性的假设筛选。

## 1. 共同场景和记号

固定一个有限行动集合 $`A`$；示例为 `withdraw`（退避）、`stay`（停留）、`approach`（接近）。三层共用行动名字，但各自的输入不能混用：

- 习惯层：时间 $`t\in\{0,1,2,\ldots\}`$，指定跟踪行动 $`a_\star\in A`$，实际行动记录 $`a_0,a_1,\ldots`$；$`u_t=1`$ 当 $`a_t=a_\star`$，否则 $`u_t=0`$。
- 意向层：有限情境集 $`X`$、有限候选意向集 $`I`$，以及确定性表 $`\pi:I\times X\to A`$。
- 规范层：一个规范代码 $`C\subseteq A`$，表示此教学体系判为合规的行动；候选代码族 $`K\subseteq\mathcal P(A)`$。这里$`\mathcal P(A)`$表示 $`A`$ 的所有子集。

数学论证可在实数域中成立；本精确实现把参数 $`\alpha`$ 和状态 $`h_t`$ 限于有理数，$`0<\alpha<1`$，$`0\le h_0\le 1`$。$`h`$ 只是规定的“熟练／习惯指数”，不是观测概率、欲望强度、神经可塑性、自动性或道德价值。

意向层的多条观测被视为同一个固定候选意向在不同情境下的表现。它们可以是教学上的反事实探查；不能把一个人跨长时间变化的动机悄悄视为恒定。示例的练习时间线与意向辨别的三项探查是两个不同记录，因共用行动表而相连，不能逐项当成同一条时间线。

## 2. 习惯层：递推、闭式与顺序

### 2.1 设定

令 $`b=1-\alpha`$，于是 $`0<b<1`$。定义

```math
h_{t+1}=b h_t+\alpha u_t.
```

这是一种最小、可手算的指数加权装置。“未执行”统一用 $`u=0`$，模型不区分休息、受伤、转做相似任务等不同原因；使用同一个 $`\alpha`$ 同时规定获得与消退速率，也纯属简化。函数 `habit_trace` 返回含初始值的 $`n+1`$ 项序列。

### 2.2 闭式及证明

对长度为 $`n`$ 的输入 $`u_0,\ldots,u_{n-1}`$，

```math
h_n=b^n h_0+\alpha\sum_{k=0}^{n-1}b^{n-1-k}u_k.
```

$`n=0`$ 时，空和为0，右边为$`h_0`$。假设公式对$`n`$成立，乘$`b`$并加$`\alpha u_n`$，便将旧项的幂次增加1，并补上 $`k=n`$ 的新项。因此公式对$`n+1`$成立，归纳完成。`habit_closed_form` 直接计算此加权和。

因为每步是 $`h_t`$ 与 $`u_t`$ 的凸组合，$`h_t\in[0,1]`$ 蕴含 $`h_{t+1}\in[0,1]`$；由归纳知区间不变。两个不同初值、相同输入序列的差满足

```math
h_n-g_n=b^n(h_0-g_0).
```

这只说明在所设递推中初值的影响收缩，不能据此断言真实人的早期经历会被忘掉。

### 2.3 反复与停用

连续执行 $`n`$ 次，即所有 $`u_t=1`$：

```math
h_n=1-b^n(1-h_0),\qquad h_n\longrightarrow 1.
```

每步增量为 $`\alpha(1-h_t)\ge0`$；只要 $`h_t<1`$ 就严格增加。连续不执行 $`n`$ 次，即所有 $`u_t=0`$：

```math
h_n=b^n h_0,\qquad h_n\longrightarrow 0.
```

每步增量为 $`-\alpha h_t\le0`$；只要 $`h_t>0`$ 就严格下降。极限来自$`0<b<1`$，因此$`b^n\to0`$；有限枚举并不能验证无穷极限。$`h_0=0`$时停用始终为0，$`h_0=1`$时练习始终为1。其余情况下，有限步通常不会恰好达到端点，“习惯消退”不能在这里等同于有限时刻精确归零。

### 2.4 同次数不等于同状态

从同一 $`h_0`$ 出发，输入 $`(1,0)`$ 与 $`(0,1)`$分别得到

```math
h_2(10)=b^2h_0+\alpha b,\qquad h_2(01)=b^2h_0+\alpha.
```

相减为 $`h_2(01)-h_2(10)=\alpha^2>0`$。两条记录各执行一次，但最近一次执行的权重更大。因此单靠累计次数不能重建 $`h`$。

更一般地，在两个相邻位置交换$`10\to01`$，紧接交换后状态增加$`\alpha^2`$；若其后还有$`m`$步相同输入，末状态增加$`b^m\alpha^2>0`$。证明是先用上面的两步差，再用初值差收缩式。

补充反例：若持续输入 $`1,0,1,0,\ldots`$，两步映射为 $`z\mapsto b^2z+\alpha b`$。偶数时刻收敛到 $`b/(1+b)`$，奇数时刻收敛到$`1/(1+b)`$。$`\alpha=1/2`$时分别为$`1/3`$与$`2/3`$，完整状态序列没有单一极限。这个结论也不能从“执行频率恰为一半”替换为 $`h=1/2`$。

## 3. 意向层：行动何时足够区分候选

### 3.1 前提

计算相容集合只需提供合法的确定表 $`\pi`$ 和观测记录，不需要先断言真实意向属于候选集。若要把表内唯一候选解释为现实识别，则还需表格适用且稳定、观测无噪声、真实意向属于 $`I`$。把自身经验得到的表套给他人，还需他人与观察者共享相关映射。这些正确性前提不由“行动可见”保证。

给定观测序列 $`D=((x_1,a_1),\ldots,(x_m,a_m))`$，定义相容候选

```math
V(D)=\{i\in I:\pi(i,x_j)=a_j\text{ for every }j\}.
```

- $`V`$为空：表格、观测或候选范围至少一项不相容；不是认定“此人没有意向”。
- $`V`$含一个元素：只在上述前提下识别出此候选。
- $`V`$含多个元素：现有数据不能区分这些候选；不表示各候选等概率。

额外观测的候选集合等于旧集合再与一个条件相交，所以 $`V(D\text{ with new observations})\subseteq V(D)`$。相同观测重复不会改变集合；同一情境记录两种不同动作则给出空集。此结论依赖固定、确定的$`\pi`$；现实中的随机行为或变化的意向需要别的模型。

### 3.2 行为等价与细化

对选定情境子集 $`S\subseteq X`$，定义

```math
i\sim_S j\quad\Longleftrightarrow\quad\pi(i,x)=\pi(j,x)\text{ for every }x\in S.
```

自反、对称、传递分别来自等号的对应性质，所以这是等价关系。函数 `behavioral_classes` 返回其等价类，按候选原顺序列出；类的先后没有认识论意义。

若 $`S\subseteq T`$，则 $`i\sim_T j`$ 蕴含 $`i\sim_S j`$；新增情境只能细分等价类，不能合并。细化未必严格：若新列对旧类中的候选给出同样行动，就不增加区分能力。在所有情境上的行向量都相同的两个候选永远不能被这个表的行为记录分开。

若在$`S`$每个情境中观察到某一候选 $`i_\star`$ 的动作，$`V`$恰是 $`i_\star`$ 的$`\sim_S`$等价类。这只需把候选定义中的条件逐项改写。因而所有候选都可由$`S`$上的完整向量唯一识别，当且仅当映射 $`i\mapsto(\pi(i,x))_{x\in S}`$ 为单射。

$`I`$允许为空，用于边界检查。此时没有等价类，也没有可识别意向。$`I`$非空而$`S`$为空时，所有候选属于同一类。代码对未知情境、动作、重复标识和形状错误拒绝输入，不将它们误当作不相容证据。

### 3.3 跨人迁移反例

观察者表中 `fear_harm` 的动作向量为 (`withdraw`,`stay`,`approach`)，`desire_quiet` 为 (`withdraw`,`withdraw`,`withdraw`)。让另一个人的这两行互换。他真实处于 `desire_quiet` 时仍会产生前一个向量；观察者如果错误地沿用自己的表，会得到唯一候选 `fear_harm`。

因此“唯一候选”只意味着在所用表内部唯一；没有正确性前提，唯一也可以错。此反例揭示教学假设的作用，不能当作已经反驳孔狄亚克全部关于表达和自然语言的主张。

## 4. 规范层：合规计算需要哪些前提

### 4.1 定义及两个集合的区别

$`F\subseteq A`$ 记录本示例中已经出现、从而被假定为可能的动作。它是描述性记录。$`C\subseteq A`$ 是一套给定规范代码中的合规动作集合。这里不默认 $`C=F`$、$`C\subseteq F`$ 或 $`F\subseteq C`$；这些关系都需要单独论据。

对动作$`a`$和非空代码族$`K`$，考察全部命题 $`a\in C`$（$`C\in K`$）。`normative_status` 返回：

- `all_permit`：每套候选代码都包含$`a`$。
- `all_forbid`：每套候选代码都不包含$`a`$。
- `underdetermined`：至少一套包含$`a`$且至少一套不包含$`a`$。
- `inconsistent`：$`K`$为空。不能用空真把互相冲突的前提算成一致许可或一致禁止。

这些标签只是二值“符合某代码／不符合某代码”的教学记法，不代表现实法律中的许可、义务、豁免、正当理由或当事人责任。尤其不自动判定哪套代码正当。

### 4.2 可见行动不唯一指定代码：限定性反模型

在不附加规范桥梁的模型类中，$`K=\mathcal P(A)`$。对任意$`a\in A`$，空代码$`\varnothing`$与代码$`\{a\}`$都允许；它们可以共享同一$`F`$、同一行动记录、同一$`h`$、同一$`\pi`$，但对$`a`$判断相反。因此这些描述变量在本模型类中不唯一确定该判断。

这不是证明“任何需要、能力或事实都不可能与规范有关”，也没有预先驳倒自然法。它仅证明：我们给定的描述输入和未受限制的代码空间之间，没有偷偷出现唯一映射。如果作者的需要—能力—自然—上帝论证另有足够前提，必须把那些前提逐条列出并评估；本程序没有将它们形式化为已证事实。

即使另加 $`C\subseteq F`$，对任意$`a\in F`$，$`\varnothing`$和$`\{a\}`$仍给出反例；不过$`F`$外动作都被这个额外桥梁排除了。若要求代码非空或加入其他规则，结论须重新计算，不能沿用无条件说法。

### 4.3 显式桥梁与代码族计数

为了展示“给出前提后”的计算，任意指定 $`R\subseteq A`$ 为必须纳入的动作，$`Q\subseteq A`$ 为必须排除的动作，定义

```math
K(R,Q)=\{C\subseteq A:R\subseteq C,\ C\cap Q=\varnothing\}.
```

$`R`$、$`Q`$是调用者给定的额外规范约束，不是从观察中发现的自然法。

若 $`R\cap Q`$非空，则某动作同时须纳入与排除，$`K`$为空。反之，对 $`R\cup Q`$之外的每个动作都可独立选择纳入或排除，得到双射

```math
\mathcal P(A\setminus(R\cup Q))\longrightarrow K(R,Q),\qquad D\longmapsto R\cup D.
```

所以非冲突时 $`|K|=2^{|A|-|R\cup Q|}`$。并且：

1. $`a\in R`$ 时，该动作一致合规。
2. $`a\in Q`$ 时，该动作一致不合规。
3. $`a`$既不在$`R`$也不在$`Q`$时，$`R`$与$`R\cup\{a\}`$均在$`K`$而判断相反，因此不确定。

由此，整个代码唯一当且仅当 $`R\cup Q=A`$ 且 $`R\cap Q=\varnothing`$。但单个动作的判断可以在多套代码下已唯一，不能把“这一动作可判定”与“完整规范唯一”混为一谈。$`A`$为空时有唯一代码$`\varnothing`$；没有动作可供查询。

## 5. 为什么三个层次要连起来

共同跟踪动作 `withdraw`，前三次执行得到 $`h=7/8`$。相同的高$`h`$能同时与 $`C_1=\{\mathrm{stay}\}`$ 或 $`C_2=\{\mathrm{stay},\mathrm{withdraw}\}`$ 相容；前者把该动作判为不合规，后者判为合规。因此形成习惯本身没有给出“好”的标准。反过来，指定了规范也没有替我们测得真实人的习惯指数或动机。

这与原文“德行是好行动的习惯、恶习是坏行动的习惯”的阅读相连，但程序既不定义完整人格德性，也不设阈值把人分类。它只要求读者分别交代：什么行动被重复了？何种表格支持意向推断？何套规则支持评价？

## 6. 程序契约、验证和范围

仅使用Python标准库。所有数值计算使用`Fraction`或整数；拒绝`float`和`bool`型参数，也拒绝用`bool`冒充二值执行标记。$`\alpha`$严格处于 $`(0,1)`$，$`h_0`$处于 $`[0,1]`$。标识集合（情境、意向、动作宇宙及约束集合）中的标签须为非空且不重复的字符串；行动历史与观测记录可重复。所有集合型入口拒绝把单个`str`或`bytes`当作集合，空字符串也不例外。意向和情境允许空，表格形状须匹配。这是接口为检验边界而扩展的退化域，正文讲解可以另以非空域为前提。

27个unittest测试方法覆盖示例、错误输入、空集、观测冲突和跨人迁移。它们使用unittest的显式检查，不依赖会被优化移除的裸assert。verify.py还扫描Python源文件中的Assert节点，并实际运行普通、-O、-OO三种模式。

有限oracle的预期值不调用生产实现求得：习惯预期值用独立整数多项式交叉相乘，行为候选及等价关系用位掩码和成对比较，规范用位掩码枚举。它由同一作者编写，不能被称为独立审稿。精确范围：

- $`\alpha`$取$`1/4`$、$`1/3`$、$`1/2`$、$`2/3`$、$`3/4`$；$`h_0`$取0、$`1/4`$、$`1/2`$、$`3/4`$、1；二值历史长度0—7。共$`25\times255=6375`$条历史，包含44,825个前缀值；重复前缀不是独立实验。
- 3个意向、2个情境、2种动作的全部64张表；每个情境“未观察／动作0／动作1”共9种记录，所以576次候选查询；4个情境子集共256个分区；9个嵌套子集对共576次细化检查。
