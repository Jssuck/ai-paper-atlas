# 独立代码与数学对应复核

## 1. 结论和身份边界

本复核独立编写测试、预期值算法和变异脚本，没有导入或复制作者的有限 oracle 与单元测试来充当独立预期值。复跑作者检查单独列为作者检查。它是一份有限范围的代码复核，不是外部人类审稿、实际心理实验或对哲学论证的机器证明。

在所审有限范围内，未发现习惯递推／闭式、相容意向、分区细化、规范族或四种判断状态的计算错误。发现并促成修复了一组输入边界缺陷；修复后再运行检查，才冻结源码快照。最终执行状态及绑定哈希见第 7 节和[验证汇总](logs/verification.json)，不能以初轮日志代替。[复跑说明](README.md)提供全部命令与日志入口。

## 2. 发现、修复及回归

### 2.1 裸字符串被误当成动作记录

修复前，`action_inputs("withdraw", "withdraw")` 逐字符迭代，静默返回八个 0，而非拒绝一个误传的标量。若调用者误把单个动作名当作序列，这会把实际练习变成八次“没有练习”。它不改变正确输入下的数学结果，但具有实际教学误导风险。

同时发现空字符串在某些集合边界会被静默接受：习惯输入成为空历史，观测成为无证据，规范候选成为空族，而空形状的 `Policy.rows` 被接受为无行。原有 `_labels` 对裸字符串的拒绝与这些接口不一致；字节串还有被迭代为整数的风险。

作者现已统一拒绝标量 `str`／`bytes`：习惯输入、动作记录、标签集合、策略行的外层及内层、观测的外层及内层、规范候选的外层及每个代码。独立新增回归覆盖 14 个调用边界和 6 个标量值，合计 $`14\times6=84`$ 个拒绝检查；包括空串、非空串、空字节串及 `b"\x00\x01"`。正确的列表、元组和生成器继续可用；重复动作和重复观测仍保留合法语义。

### 2.2 文档输入范围

原来的“标签必须唯一”表述已收窄为标识集合与约束集合中的标签不重复。行动历史和观测允许重复，否则既违背本章“反复行动”的用途，也与程序行为冲突。[模型说明](../MODEL.zh-CN.md)已明确空意向集、空情境集和空动作宇宙的边界；这些边界用于程序检查，不是关于现实主体的主张。

## 3. 独立预期值路线

### 3.1 习惯：穷举重置过程，而非重写加权和

对长度 $`n`$ 的二值输入，独立 oracle 穷举全部 $`2^n`$ 条“保留／重置”路径：每步以形式权重 $`\alpha`$ 重置为本步输入，否则保留旧状态；最终状态由最后一次重置决定，没有重置则保留初值权重。对整个有限样本空间精确求和。

这段算法不迭代生产递推，也不使用作者 oracle 的整数多项式或指数权重交叉相乘。其均值满足相同递推，因此提供另一条可核对的计算路线。这里的随机表示仅为核验恒等式服务，不把文档中的 $`h`$ 改成实际观测概率。

另检查空历史、精确 Fraction 类型、区间不变性、连续练习与停用、端点、初值差收缩、互补输入、前后分段组合、顺序交换的差值，以及交替输入的偶数步闭式。无穷极限仍依靠数学证明，程序只检查精确有限恒等式。

### 3.2 意向：关系纤维交集与逐列分块

对每个“情境、动作”键，先建立能够产生它的意向集合；再逐条对观测取交集。生产实现是对每个候选检查全部观测，作者 oracle 是位掩码；独立预期值不调用二者。

分区预期值从一个大块开始，每增加一个情境，就按每种动作分裂旧块；它不复制生产实现的整行签名字典，也不使用作者 oracle 的成对等价关系算法。除完整覆盖且无重复外，还检查每个大情境集的块包含于小情境集的某一块，以及某候选在选定情境中的全部动作所定义的相容集恰好等于它的等价类。

重复观测、改变顺序的记录、同情境矛盾观测、空记录、空表、未知标签、重复标识和表格维度错误均进入检查。可变输入在构造后改动不会改变已建立的策略快照。

### 3.3 规范：递归自由选择与并集／交集

规范族预期值从必需动作集合出发，对每个尚未受约束的动作递归选择“加入／不加入”，不使用生产实现或作者 oracle 的位掩码筛选。另核对族大小公式及重叠约束的空族。

四状态不仅在 `admissible_norms` 生成的族上核验，还穷举三动作宇宙的所有任意规范族：以族的并集和交集判断一致许可、一致禁止和未决定，并专门先处理空族。族中代码顺序颠倒、重复代码和生成器输入不改变状态。空族与仅含空代码的族严格区分。

## 4. 精确有限覆盖范围

每种优化模式运行相同的 18 个独立测试方法，含 12 个快速回归方法与 6 个完整复核方法。内部计数按对象分别说明，不能相加冒充独立实验：

- 习惯参数：$`\alpha\in\{1/5,1/3,1/2,3/5,5/7\}`$；$`h_0\in\{0,1/5,1/2,4/5,1\}`$；二值历史长度 $`0\le n\le6`$。共 $`25\times127=3{,}175`$ 条习惯历史，积分 $`25\times(1+4+16+64+256+1024+4096)=136{,}525`$ 条重置路径。
- 补充习惯恒等式：$`\alpha\in\{1/101,3/7,100/101\}`$；$`n\in\{0,1,2,9,40\}`$，共 15 组。交替输入使用长度 $`2n`$，最长 80 步。
- 策略表：三个意向、三个情境和两种动作，全部 $`2^9=512`$ 张表。
- 每表穷举长度从零至三、由 6 个观测对组成的全部有序记录，包括重复及矛盾：$`512\times(1+6+36+216)=132{,}608`$ 次记录检查；另以生成器重复核验，未把它算成新的记录。
- 每表检查 8 个情境子集，合计 4,096 个分区；27 对嵌套情境集合，合计 13,824 次细化；每个子集对 3 个候选核验“相容集＝等价类”，共 12,288 次。
- 规范桥梁：动作宇宙大小从零至四，全部 $`R`$、$`Q`$ 组合，共 $`1+4+16+64+256=341`$ 对；动作状态查询共 1,252 次。
- 任意规范族：3 动作宇宙的 8 个代码共有 $`2^8=256`$ 个候选族，共 768 个基础状态查询；反转、重复、生成器形式另作不变性核验，不计为更多独立族。
- 文档演示：精确检查 $`11100`$ 的六项状态、$`10`$／$`01`$ 的顺序差、三个意向的逐步缩小、跨人换行迁移反例、8 套无约束代码及部分／完整／矛盾规范约束。

## 5. 优化模式与有效语义变异

普通、`-O`、`-OO` 均实际运行；不是只检查命令语法。独立测试摘要去掉优化标记后必须完全相同，演示 JSON 文本也必须逐字一致。生产代码、作者检查和独立检查的 AST 都被扫描；不允许裸 `assert` 节点。`unittest` 检查与显式异常在优化模式下仍然执行。

最终 23 个独立语义变异，每个在三个模式执行，共 69 次。范围包括：抹掉初值、错误衰减系数、遗漏 $`\alpha`$、闭式多衰减一步、额外基线、错误接纳布尔初值／二值输入、放开 $`\alpha`$ 端点、动作标记恒真、忽略意向行、只看末项观测、颠倒匹配、空记录无候选、只看最后情境、永不合并候选、把必需关系改为真子集、把禁止改为必需、冲突族变成单例、空族错误判断，以及把“有一个许可／禁止”错当成一致判断、接受重复标识。

只有源码解析和编译均合法、全部 12 个独立快速测试实际运行、至少一次检查失败且测试错误数为 0，才计为 `KILLED_BY_ASSERTION`。语法错误、导入错误、运行错误或未跑满测试均不算检出。每次退出码、失败数、错误数和完整回溯保存在日志。

初轮有一个更宽的“接纳所有布尔有理数”变异，把预期的 TypeError 改成 ValueError，引发测试错误而非断言失败；严格规则将其列为无效检出，没有计入通过。原始日志保留。随后将该变异收窄为“错误接纳布尔初值”，从而检验实际错误结果并获得有效断言失败。最终 23 项中的这一项与初轮不同，不能把两轮统计混为一个固定变异集。

## 6. 文档一致性与剩余限制

已人工对照[作者 README](../README.md)、[模型说明](../MODEL.zh-CN.md)、[中文走查](../WALKTHROUGH.zh-CN.md)与核心代码、演示数值和真实测试计数。习惯闭式、相邻交换差、收缩式、周期输入极限的有限闭式、候选集合单调性、等价类细化、规范族计数和四状态定义相符。示例动作序列和意向探查在文档中被明确区分；范例 $`\pi`$ 是人造设定，不是孔狄亚克提供的表。

没有把自写现代模型称为历史算法复现，也没有用通过测试认证哲学或神学结论。自然法结尾的历史证据、版本核对与全文论证另由来源和论证审查负责；本报告不替代它们。

剩余限制：

- 有限枚举不是所有有理数、任意长记录或任意大有限集合的穷尽证明；没有形式化证明器或符号执行认证。
- 标准库纯 Python 的实际执行环境仅本报告所列 CPython 版本；未在 README 所允许的每个 Python 版本或每种操作系统逐一运行。
- 规范族枚举随动作数指数增长；无限生成器会无法完成，超大整数或恶意自定义对象可能造成资源问题。本教学 API 不是面向不可信输入的沙箱或生产服务。
- 23 项定向变异不能构成全程序缺陷检出率；没有穷尽所有可能变异。
- 本次仅检查显式小模型及对应文档；不验证现实心理机制、动机识别可靠性、道德正当性或自然法前提。
