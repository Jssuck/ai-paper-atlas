# 《几何原本》X.11：等比下同时可公度或同时不可公度

教学模型将两对正长度的比值表示为精确平方比 `q1=(A/B)^2` 和 `q2=(C/D)^2`，并输入正有理参考长度 `B=b,D=d`。正长度的顺序与相等不会因平方而丢失，因此 `transfer(q1,q2,b,d)` 先拒绝两平方比不等的输入。若共同既约平方比的两项均为整数平方，则返回共同计数 `(m,n)` 以及各对分别使用的公度量 `b/n,d/n`。例如 `q1=9/4,q2=18/8,b=4,d=10`，两对为 `6:4,15:10`，都用计数 `3:2`，但函数给出各对的公度量 2 和 5。它们不是同一个见证；在这个例子中仍可以另外用单位 1 同时度量四项。

平方比同为 2 时，两对都没有整数计数见证。两对各自可公度也不足以满足等比前提，例如平方比 `9/4` 和 `25/4`。这个现代模型仅覆盖正有理平方比，并不以有限枚举证明命题或判定任意实际线段。

独立基线直接生成整数比平方，未调用被测的整数平方根。对 `p,q∈1..64` 的 4,096 个有序平方比代表（不去重），约分后分子、分母仍不超过 64，若存在整数平方根，则根不超过 8，基线因而覆盖这些输入的全部既约计数。实跑 180 对有公度见证、3,916 对两边都没有。

python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
