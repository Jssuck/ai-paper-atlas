# I.40 独立数学与代码核验

核验对象是[主稿](../../papers/ancient/aristotle-prior-analytics-i40.zh-CN.md)所声明的现代教学模型及本目录生产实现；不据此认证希腊原文唯一解释，不替代独立来源审查。审查者未编写生产`model.py`和`test_model.py`，另行编写[独立oracle](independent_audit.py)并实际运行。

## 发现、修复和复验

初审发现一项语义对齐错误：主稿U_G表示“至多一个G”，空外延也真；初版代码却用恰好一个G。两个带G(g)的桥接规则并未因此变成不可靠，但程序没有逐项实现主稿定义。已要求实现者修正为`AT_MOST_ONE_GOOD = 'at_most_one_G'`及`len(good) <= 1`，增加空G测试并重跑全部生产日志。当前版本普通、-O、-OO均15项通过。独立oracle以全称量词定义另核空G和非空G，而非重复长度判定。

主稿第6.1节现用G仅含g、p与g不同的反模型说明去掉身份前提后的失败；它不再误引用两个对象都属于G的例子来展示G(p)假。

## 一般论证核对

- 第4节明确D非空，p和g属于D，G是D子集；g的名字不自动增加G(g)。模型没有宣称定冠词恒等于个体常量。
- 第5.1节p与g不同而均在G中，G(p)、G(g)真且身份假，正确反驳没有唯一性的反向推断。
- 第5.2节p=g而这个元素不在G中，身份真且G(p)假；文中正确限定为无G(g)桥接的模型类，而非伦理结论。
- 第6.1节由等号和G(g)对同一元素代换，任意大小论域都成立；两项前提删去后的反模型均正确。
- 第6.2节U_G是至多唯一而不含存在。G(p)、G(g)提供两个成员资格，实例化U_G得到p=g。删掉G(g)的反例正确。G等于g的单元素集合时双向等价也正确。
- 第6.3节区分一次同真与全模型等价，表中三种背景的方向正确。12题答案与上述模型一致。

这些是数学论证的人工核对，有限枚举不是其证明。对许可规则的一般可靠性可分三种情形：目标不变时结论就是已真源命题；身份到性质时用等号与G(g)；性质到身份时用G(g)与至多唯一。任意附加假设不会破坏“所有前提真实时结论真实”的保证。

## 独立实现核验

独立脚本不调用生产`models`生成期望模型，不调用`holds`计算期望真值，而用长度n的布尔向量遍历所有G解释，再遍历p、g位置。G(p)、G(g)由向量位置直接取得，身份比较位置；至多唯一逐对检查“若x、y都为真，则x=y”。生产`holds`只用于待测输出。

普通、-O、-OO三种模式各自实际得到：

|检查|各模式结果|
|---|---|
|独立边界单测|10项通过|
|域大小1–4独立生成模型|346|
|四公式与oracle比较|1384次一致|
|对象编号反转的重命名不变性|1384次一致|
|所有16种声明假设子集及四种源/目标组合|22144组|
|许可、源命题真、全部声明假设真的实例|1790组，结论全真|
|空G且至多唯一真的模型|30|

真值对按G(p)、p=g顺序，00/01/10/11分别为124/49/124/49。身份且G(g)真的49例、G(p)且G(g)且至多唯一真的10例，与生产统计一致。独立脚本三种模式JSON逐字相同。

边界测试还查：空G不推出存在、多成员违反唯一性、假假设不认证结论、以目标作为已知假设仍可能被受限规则拒绝（不完备）、非法论域与越界解释、布尔值伪整数、非枚举公式、非frozenset假设、生成器在开始迭代时才验证输入、256个n=4模型无重复、拒绝超出survey规定上界。输入验证使用显式异常，独立枚举检查显式抛错，不依赖被优化模式移除的assert。
