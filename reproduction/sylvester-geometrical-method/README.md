## 1. 先规定几何域，后处理等式

置 A、B 为三角形在基边 AB 两端的内角，c=AB。要求

```math
0\lt A,\quad 0\lt B,\quad A+B\lt \pi,\quad c\gt 0,\quad n\ne0.
```

公共 Python 接口使用“度”，函数内部使用弧度。定义

```math
A=2n\alpha,\qquad B=2n\beta,\qquad
\theta=A/n=2\alpha,\quad\phi=B/n=2\beta.
```

负 n 时，α、β 也随之为负；不得一面令 n<0，一面仍未经说明地把 α、β 当作正内角。对于很小的 |n|，方向角可能多次绕转；程序只计算指定的有向支撑直线，不保证满足原作者未完全形式化的全部几何可容许性条件。

固定坐标 A=(0,0)、B=(c,0)，三角形顶点 C 在上半平面。两条分角方向为

```math
u_A=(\cos\theta,\sin\theta),\qquad
u_B=(-\cos\phi,\sin\phi).
```

交点 D=A+t_Au_A 位于直线 BC，E=B+t_Bu_B 位于直线 AC。由正弦定理或二维线性方程可得

```math
t_A=c\frac{\sin B}{\sin(B+A/n)},\qquad
t_B=c\frac{\sin A}{\sin(A+B/n)}.
```

分母必须不为零。实现把绝对值不大于 10⁻¹² 的正弦分母视为数值近退化并拒绝求交；这是实现阈值，不是精确数学边界。

- `t_A,t_B` 是相对于所选方向的**带符号参数**。
- 通常线段长是 `abs(t_A),abs(t_B)`。
- 两个参数都为正，才是两条所选**正向射线**上的交点。
- 交点还必须分别落在 BC、AC 的开线段内部，才是本包所称的两条**内部劈线**。

原 p. 367 的式子为

```math
\frac{\sin(2n\alpha+2\beta)}{\sin2n\alpha}
=
\frac{\sin(2n\beta+2\alpha)}{\sin2n\beta}.
```

在交点存在时，这对应 `t_A=t_B`。普通长度相等还有 `t_A=-t_B` 一支，不能把两者静默混同。也不能把正弦式成立当成交点存在的证据。

### 端点与奇点

- n=0：A/n、B/n 无定义，程序拒绝。
- n=1：两条分割线分别沿 AC、BC，交点都是 C；不再是开角内部的劈线。此时长度相等仍需 a=b。
- n=−1：A=B 时两个目标交点均退化为平行线，正弦式却为 0=0；A≠B 时两个有限参数符号相反。
- A=B 时，p. 367 的正切比第一项成为 0/0；正弦式仍有意义。不能因正切写法除零而删掉等腰解。
- 正切还可能在 cos=0 时出现极点。程序逐项检查，不把交叉相乘后的候选解全部收回。

## 2. n=2 的全域代数证明，不依赖有限抽样

令 a=BC、b=CA、c=AB，a,b,c>0 且满足全部严格三角不等式。内部角平分线满足

```math
\ell_A^2=bc\left(1-\frac{a^2}{(b+c)^2}\right),\qquad
\ell_B^2=ac\left(1-\frac{b^2}{(a+c)^2}\right).
```

这些式子可由角平分线定理、Stewart 定理推出，亦可由 `t_A,t_B` 在 n=2 时结合正弦/余弦定理推出。通分并收集项得到

```math
\ell_A^2-\ell_B^2=
\frac{(b-a)c(a+b+c)P(a,b,c)}{(a+c)^2(b+c)^2},
```

```math
P(a,b,c)=a^2b+ab^2+3abc+ac^2+bc^2+c^3.
```

### 可机械检查的恒等式证书

`polynomial_certificate.py` 不代入有限个数值，而用指数三元组到整数系数的映射，展开以下两端并比较**全部系数**：

```math
\begin{aligned}
&bc\big((b+c)^2-a^2\big)(a+c)^2\\
&\quad-ac\big((a+c)^2-b^2\big)(b+c)^2\\
&=(b-a)c(a+b+c)P(a,b,c).
\end{aligned}
```

残余非零系数数目为 0 是这一多项式恒等式的精确运算证据。对字典算法的实现仍应进行代码审阅；这不是外部形式证明内核签发的证明。

### 全域结论

由于 a,b,c>0，P 的每一项为正；c、a+b+c 以及分母也都为正。严格三角不等式保证上面的两个平方确实对应非退化三角形内的正长度。因此

```math
\ell_A=\ell_B\iff\ell_A^2=\ell_B^2\iff a=b.
```

这给出了 n=2 命题的现代代数论证。它没有把何谓“纯几何”“直接”或“可能的全部证明”形式化，故不能仅凭这个因式分解就宣布原作者关于几何证明方法的普遍猜想已被彻底裁决。

## 3. p. 368 的字形与重建式必须分开

p. 367 给出的正切等式是

```math
\frac{\tan((n-1)(\alpha-\beta))}{\tan(n(\alpha-\beta))}
=
\frac{\tan((n+1)(\alpha+\beta))}{\tan(n(\alpha+\beta))}.
```

在相关分母和正切均有定义时，代入 n=1/2 及 n=−1/2 应分别得到

```math
\frac{\tan(3(\alpha+\beta)/2)}{\tan((\alpha+\beta)/2)}=-1,
\qquad
\frac{\tan(3(\alpha-\beta)/2)}{\tan((\alpha-\beta)/2)}=-1.
```

扫描中两个右端可辨为 `=1`；第二式分子可辨为 `(3α−β)/2`，没有明确显示应有的 `3(α−β)/2` 分组。此处只记录可见字形与上式代入所得重建式不一致，不推定差异究竟由原稿、排印、扫描还是其他环节造成。不得把重建后的公式冒称逐字转录。

更稳健的校核是返回原正弦式。令

```math
F_n=\sin(A+B/n)\sin B-\sin(B+A/n)\sin A.
```

积化和差给出

```math
F_{1/2}=-\sin(2(A+B))\sin(A-B),\qquad
F_{-1/2}=\sin(2(A-B))\sin(A+B).
```

因此在非退化三角形、A≠B 的域内，正弦方程的两个非等腰特例分别是 A+B=90°、|A−B|=90°。再检查交点分母：

- n=1/2，A=30°、B=60°：t_A=t_B=1；D=(1/2,√3/2)、E=(3/2,√3/2)。两条射线都正向，但 D、E 在对边的延长线上。
- n=−1/2，A=15°、B=105°：t_A=t_B=1，同样不属于两条内部劈线。

p. 368 紧邻文字还对固定差值的可解性作了宽泛陈述；这里不把它当作已证明事实。例如 n=1/2 的非等腰支要求 α+β=90°，而三角形域给出 |α−β|<α+β；n=−1/2 的非等腰支更要求 α−β=±90°，并非任意给定差值都可用。这些域条件不能从结论中删去。

这两个实例支持原文紧随公式之后的角条件，却不支持把扫描中的两个右端 `1` 原样用于计算。

## 4. 反例候选必须说明反驳的范围

首先有一个无需数值求根的精确角度例子：n=−2、A=96°、B=24°、c=1。此时

```math
t_A=\frac{\sin24^\circ}{\sin(-24^\circ)}=-1,\qquad
t_B=\frac{\sin96^\circ}{\sin84^\circ}=1.
```

`exact_opposite_sign_example()` 实现这一例子；图中的坐标用浮点三角函数生成。另保留数值求根作为独立补充：`opposite_sign_example()` 对 A=90°、n=−2 的异号分支求数值根，得

```math
B\approx22.7350867996022^\circ,\quad
t_A\approx-1.02000954230287,\quad t_B\approx1.02000954230287.
```

这是不等腰且**普通线段长**相等的支撑直线配置；它不满足原式所编码的带符号相等，也不是两条正向射线同时取到的交点。它反驳的是一个不加说明的“把带符号等长推广成任意延长线段等长”的读法，不是已经证明对原文每一种几何解读都构成反例。

8 个 n 值各检查 595 个 5° 网格三角形，共 4,760 个样本。在 n=−2 的粗网格中没有发现这些不等腰普通等长实例，而精确角度构造和定向求根都找到了实例。这恰好说明：有限网格未检出，不能推出不存在；不同几何域的数目也不能直接互换。

## 5. p. 369 的弦段方程与正根域

设 P 是圆弧 UV 的中点，两条弦从 P 引出，和基弦 UV 相交；`x` 为 P 到交点的近段，`a` 为其后的远段，`b=PU=PV`。原文的方程是

```math
x^2+ax=b^2.
```

对于 a,b>0，两个实根为

```math
x_+=\frac{-a+\sqrt{a^2+4b^2}}2\gt 0,\qquad
x_-=\frac{-a-\sqrt{a^2+4b^2}}2\lt 0.
```

API 名 `half_chord` 指的是“半个给定圆弧所对的弦” b=PU=PV，不是“基弦 UV 的一半”；本图 b=1，而 UV/2=√3/2。

只有正根属于近段长度域。实现采用有理化并缩放的表达式，以降低相消误差。**代数正根**不自动满足某个固定圆与固定基弦的全部位置约束；本包的具体圆图另要求 |θ|<60°，因此近段满足 1/2≤x<1（一般写作 h≤x<b，其中 h 是 P 到基弦的距离）。逆命题在这个固定图形中同样需要 1/2≤a<1；仅有 0<a<b 只保证代数远段为正。

另一种不用求根公式的全域代数唯一性论证是：对 x,y>0，

```math
(x^2+ax)-(y^2+ay)=(x-y)(x+y+a).
```

若两者等于 b²，右端为零且 x+y+a>0，于是 x=y。这是正实数域上的单调性/唯一性论证；它同样不能独自决定是否存在一种满足历史术语要求的“直接纯几何”证明。

### 逆命题的符号重置

p. 369 随后改以 a 表示给定近段、x 表示远段，方程为

```math
a(a+x)=b^2,\qquad x=\frac{b^2-a^2}{a}.
```

右端是 **b²，不是 OCR 可能误出的 0**。远段为正还要求 0<a<b。不要把逆命题中的 a 和前一个二次式里的 a 当成同一类弦段。

## 6. 什么被证明、什么只被检查

- 精确系数运算核查了角平分线平方差的多项式恒等式；正文的正性论证给出 n=2 在非退化三角形全域上的结论。
- 弦段的正根唯一性来自解析论证，不依赖测试样本数量。
- 40 个单元测试和 4,760 个网格样本用于发现实现、符号、域与退化情形的错误。
- n=±1/2 的校核式来自代入与积化和差；扫描的可见字形另作记录。
- 没有用有限实验“证明”所有 |n|>1 的一般命题；也没有用它们证明或否定关于一切几何证明方法的普遍猜想。
- 浮点数允许近退化误差；零残差阈值是数值诊断，不是形式证明的等号判定。极端尺度下无法表示的平方长度或根会显式抛出 DomainError；这不改变精确代数命题的域。
