# I.24 独立论证核验

本核验不导入作者 `model.py` 或其他实现。对象直接使用 `(S,P,M)` 布尔元组，模型使用元组集合；全称通过逐对象检查，特称通过见证检查。运行材料只涉及原创现代实然模型。

## 真实运行

工作目录为本目录，依次执行：

```sh
python check_arguments.py > normal.json 2> normal.stderr
python -O check_arguments.py > O.json 2> O.stderr
python -OO check_arguments.py > OO.json 2> OO.stderr
cmp normal.json O.json
cmp normal.json OO.json
```

三次退出码均为 0，JSON 相同，标准错误均为空。所有检查使用显式异常，不依赖可能被优化删除的 `assert`。环境见 `environment.txt`。

三模式各覆盖：

- 两种项存在政策共 473 个政策模型（255 + 218）；每政策各 192 个式，共 90,816 次式—模型真值检查。
- 48 个两否定前提的反模型构造，48 个两特称前提的反模型构造，均保证三项非空。
- 唯一全称前提四种不同有向边 × A/E × 两种全称结论，共 16 个局部扩张选择。
- 1,792 次从真实前提模型出发的单对象扩张：保留一全称、一特称前提，同时反驳目标全称结论；项非空性保持。
- 音乐错见证、Darapti 的全称过强、空中项、精确减法与遗漏被减量相等，共 5 个显式检查。

有效式列表为允许空项 12 式、全项非空 18 式；包含弱化结论，不等同于历史十九式。

## 一般证明与计算的界限

独立有限检查用于核对赋值和代码实现，不自行证明无限模型结论。正文双否定模型、双特称逐前提见证构造、单全称新对象扩张，才是一般论证。八类型压缩通过保留全部出现的成员类型证明 AEIO 真值保持；这一步使所定义语言可由有限代表检验，不适用于计数谓词、二元关系、模态或证明的认识论独立性。
