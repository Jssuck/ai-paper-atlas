# I.24 独立代码核验

## 结论与边界

通过本报告列明的语义/实现核验；未发现阻止发布的代码缺陷。审查者另写 `independent-review/oracle.py`，不调用作者的命题求值函数产生预期值，也不复用作者的集合扩张实现：独立把占用类型解码为布尔行，以 `all`/`any` 的量化式解释 A/E/I/O。作者函数只作为被测对象调用。三格的项位置也独立列出。

这验证的是有限类型支持集上的实现以及正文指定的教学语义，不是原文的完整历史证明、古希腊曲线角概念或形式证明依赖。一般类型保持定理仍靠正文论证；有限实验不能证明一般数学定理。以下计数是每一模式的实际执行数量，不是三模式相加。

审查者另行重跑作者测试：三模式各 18 测试 `OK`；作者示例输出逐字节匹配留存文件。独立报告三模式也逐字节相同。原始输出在 `independent-review/author-tests-*.log`、`author-results-*.json`、`report-*.json`；汇总核对输出在 `verification.log`。程序不用会被优化删除的 `assert` 作核验门槛，失败抛出异常。

## 定义与正文对照

- 位序 S/P/M 与非空论域一致；空主项使 A/E 真、I/O 假。作者 API 严格排除 bool、浮点掩码等非整型表示。
- 全项非空政策确实要求三个扩张各非空，不是仅论域非空。正文已说明 AAI-3 最小需要的是中项非空；全项非空是更强的对比政策，未混称历史存在预设。
- 音乐实例占用类型掩码 96：`I(M,P)` 与 `A(S,M)` 真，`A(S,P)` 假。另检查 III-1/96、EEE-2/24、AAA-2/96、AAI-3/1、AAA-3/130 的前提真结论假；AAI-3 在全项非空政策有效。
- 正文算例 `180−75/2=285/2` 与作者示例 `9/2−1/3=25/6` 是不同输入，分别运行验证，不能把一个日志冒充另一个。也检查不等被减量、不同整体及零值；前提假时的蕴涵真不等于结论相等。
- README、正文、作者代码对三格方向、量词、精确数值类型及两个存在政策的定义一致。

## 语义变体与未覆盖项

9 个变体是审查者明确写出的对照解释：A 反向、A 偷加存在、E 当 O、I 当 A、O 反向、E 当非 A、I 要求全体对象同属、O 当 E、A 当特称。各自的首个区分掩码及正误真值见报告。这不是自动源代码变异测试，也不声称杀死任意程序缺陷。重复对象不变性是在独立语义层检查；作者表示本身不保留同类型对象的数量，不能用它检测计数逻辑。

未测试模态、关系谓词、证明树循环、推导来源依赖或所有可能的恶意 Python 对象。非法输入覆盖的是清单中明确列出的普通值；数学实数的一般减法法则不由这五个有理数实例证明。

## 重跑命令与绑定

在本复现目录运行：

```sh
python independent-review/oracle.py
python -O independent-review/oracle.py
python -OO independent-review/oracle.py
python -m unittest -v test_model
python -O -m unittest -v test_model
python -OO -m unittest -v test_model
python run_examples.py
python -O run_examples.py
python -OO run_examples.py
```

`independent-review/binding.json` 绑定本次正文、作者文件以及独立脚本/证据/本报告的 SHA-256；该文件不自哈希。正文或被审源码变化后应重新审查对应修改并刷新绑定，不能沿用旧绑定冒充终审。
