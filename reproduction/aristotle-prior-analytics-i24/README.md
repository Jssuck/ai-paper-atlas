# I.24：前提的质、量与结论范围——最小教学模型

这是原创标准库教学代码，不是古代原典程序、不模拟人的学习、也不是完整自动证明器。它把本章若干必要条件放到明确的现代外延语义下检验。一般论证与原文证据见[主稿](../../papers/ancient/aristotle-prior-analytics-i24.zh-CN.md)。

## 模型

论域非空；S、P、M分别为结论主项、谓项、中项。八个布尔原子编号0到7，编号的第0、1、2位分别表示属于S、P、M。一个1到255的占据掩码指定哪些原子非空；每个非空原子保留一个对象。这是255种不同占据形状，不是255个不同基数的一般论域，也不是所有任意大小结构逐个实跑。

AEIO依次解释为包含、不交、交非空、差非空。A/E在主项空时真，I/O假。两种政策分开报告：

- `allow_empty_terms`：255个非空域占据掩码；项可以为空。
- `all_terms_nonempty`：筛选S/P/M均非空后的218个掩码。这一附加政策不是把原典所有存在预设一概判定为已解决。

格定义：第一格大前提M→P、小前提S→M；第二格P→M与S→M；第三格M→P与M→S。结论都为S→P。每个箭头的AEIO由式的相应字符指定。每格4×4×4=64种式，共192种；没有第四格，也没有本章末段提及的模态及其他谓述方式的实现。

`classify`按选定有限模型返回前提真模型数、反模型数、有效布尔值和第一个反模型。`valid`只表示本次已定义模型范围的语义后承；不区分公理已知性与循环证明、没有证明树来源追踪。即使逻辑上由目标推出目标，也不能用这一语义检查替代非循环性审查。

## 执行

在本目录运行，Python 3.12.14，纯标准库，无安装和随机种子：

```sh
python -m unittest -v test_model
python run_examples.py
python -O -m unittest -v test_model
python -O run_examples.py
python -OO -m unittest -v test_model
python -OO run_examples.py
```

代码校验使用显式异常，不依赖可能被优化关闭的`assert`。`unittest`的断言方法在优化模式下仍执行。输入仅接受大写AEIO、S/P/M、严格整数掩码与格号（布尔值拒绝）。不会默默把小写或浮点纠正为有效输入。

## 真实结果与证据

三模式各18测试通过；[正常结果](logs/results-normal.json)、[正常测试](logs/tests-normal.log)、[-O结果](logs/results-O.json)、[-OO结果](logs/results-OO.json)及相应测试日志均保留。三份结果JSON逐字相同。环境见[environment.json](environment.json)，作者文件摘要见[author-manifest.json](author-manifest.json)。

每种模式：允许空项时12个有效式；三项均非空时18个（包括由全称弱化出的特称结论）。这些计数只有三格，不能拿来与含第四格、不同存在政策或省略弱化式的“十九式”直接比较。

所有检出的有效式都满足至少一肯定前提、至少一全称前提；若结论全称，则两个前提全称。这个检验没有把必要条件误当充分条件：AAA第二格有一肯定且有全称，仍无效。测试也逐个重放反模型，防止仅统计一个错误标签。

示例：

- III第一格：mask96，S={5}、P={6}、M={5,6}；两个特称可由不同对象满足，S与P仍不交。
- EEE第二格：mask24，S=P={3}、M={4}；两者都排除M并不能推出彼此排斥。
- AAA第二格：mask96；同属M不意味着S包含P。
- AAI第三格：允许空项时失败，首反例mask1；加三项非空政策后有效。真正见证步骤只需要M非空；程序使用较强的三项非空政策作对照，而不是声称三个非空都是该式的最小假设。
- AAA第三格：即使三项非空也失败，mask130，S={1,7}、P=M={7}；全称前提只能确保一个共同见证，不能覆盖S的额外对象。
- 音乐例使用mask96：“一些快乐可称许”与“音乐快乐是快乐”不推出所有音乐快乐可称许。原典例子的伦理断言只作为变量含义，不作真实价值判定。

## 等量相减与边界

`equal_remainders`只核查用户给出的一个精确算术实例。以9/2减1/3，两边剩余均为25/6。它不作几何图的重建或证成，不证明等腰三角形底角定理，不判断一般规则的知识来源。整数/Fraction接受，浮点与布尔拒绝；要求非负整体和不超过整体的部分。若输入整体不等，`implication`可以空真而`conclusion`为假，日志与测试明确区分这种情况。

有限结果不能代替正文中的一般证明。占据形状压缩为何足以保存当前纯一元AEIO判断，需要另行数学证明；程序没有把这一证明自动化。也未实现数值量化、模态规则、证明依赖图、历史几何中的曲线角语义或完整问答辩证法。
