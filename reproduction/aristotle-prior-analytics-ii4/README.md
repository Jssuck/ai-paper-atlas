# II.4：第三格、假前提与真结论的见证

对应[中文深读](../../papers/ancient/aristotle-prior-analytics-ii4.zh-CN.md)。这是原创现代集合语义教学复现，不是古代实验复制，也不声称重建全部古代语义。只用 Python 标准库，无安装、联网或密钥需求。

## 1. 输入与假设

论域非空，三个项 A、B、C 可为空；C 是中项。每个对象由三个成员资格确定类型，位权 A=4、B=2、C=1。类型0表示不属任何一项的论域对象，不能删除它后让论域误变为空。压缩模型是非空、无重复的整数类型序列，范围0至7；布尔值、越界、重复与空模型显式拒绝。

`proposition(model, kind, predicate, subject)` 谓项在前、主项在后。例如 A(A,C) 是“所有C都是A”，不是“所有A都是C”。

|kind|集合含义|
|---|---|
|A(X,Y)|Y包含于X|
|E(X,Y)|Y与X不相交|
|I(X,Y)|Y与X有共同对象|
|O(X,Y)|Y中存在不属于X的对象|

A/E 在空主项上均为空真，I/O 在空主项上均假。对非空主项，全称命题分 `true`、`wholly_false`、`partly_false`：整假意为相反的全称判断为真；部分假意为既有满足者又有违反者。部分假仍是二值逻辑的假，不是概率。空主项另记 `vacuous_true`，避免把两种空真全称误记为整假。特称只分真或假。

## 2. 六式与一般保真证明

|模式|大前提|小前提|结论|附加存在条件|
|---|---|---|---|---|
|Darapti|A(A,C)|A(B,C)|I(A,B)|C非空|
|Felapton|E(A,C)|A(B,C)|O(A,B)|C非空|
|Disamis|I(A,C)|A(B,C)|I(A,B)|无|
|Datisi|A(A,C)|I(B,C)|I(A,B)|无|
|Bocardo|O(A,C)|A(B,C)|O(A,B)|无|
|Ferison|E(A,C)|I(B,C)|O(A,B)|无|

逐式证明不依赖有限枚举：

1. Darapti：存在条件给出一个C对象；两个全称肯定使它同时在A和B，所以它是结论见证。
2. Felapton：取C对象，由小前提它在B，由大前提它不在A，所以它见证O(A,B)。
3. Disamis：大前提提供同属A和C的对象；小前提使该同一对象进入B。
4. Datisi：小前提提供同属B和C的对象；大前提使该对象进入A。
5. Bocardo：大前提提供C内而不在A的对象；小前提使它进入B。
6. Ferison：小前提提供同属B和C的对象；大前提排除它属于A。

前两式若无C非空条件，取论域={0}、A=B=C为空，两个前提都真而特称结论假。因此侧条件是逻辑输入，不能以程序习惯隐去。后四式的特称前提已给出所需见证。以上是任意域的一般证明；小实验本身不能证明一般定理。

## 3. 两个假前提并不妨碍结论在别处为真

取模型类型(1,6)：类型1只属C，类型6同属A、B而不属C。Darapti两条全称前提均整假，结论I(A,B)却由类型6见证。此见证**在C之外**，不能伪装成从真实中项前提合法传递来的证据。

否定例取(2,5)：类型2只属B，类型5同属A、C而不属B。Felapton的E(A,C)与A(B,C)均整假，O(A,B)由类型2见证。这不证明假前提可靠，更不意味着所有假前提实例都得到真结论。

所有指定前提分类均可搭配真结论，且有一般构造：先令C非空。对于两个全称前提，C中用四个代表承载A/B两种独立成员资格；按目标分类让每个属性全部满足、全部违反或两者都有。对于含一条特称的式，分别控制该属性的存在或不存在，再独立控制另一属性的全称分类。随后在C之外增加所需结论见证：肯定结论添一个同时属A、B的对象；否定结论添一个属B而不属A的对象。该添加不会改变以C为主项的前提分类。若要A、B都非空，再在C之外添入必要成员，也不改变这些分类。程序对前两式分别得到9种真结论分类对，后四式分别得到6种；这只是声明语义内的存在性，不是自然语言例项都可任意分配的证据。

## 4. 八类型压缩与有限普查

保留每种已出现类型的一个代表即可保持每个A/E反例、I/O见证、项非空与分类。反之，重复同类型对象不改变上述性质。此论证也适用于无限域，但不适用于计数约束、多元关系、模态或自然类的经验限制。

非空八类型子集共255个。全部三项非空的模型数为218：255减去3×15个单项空情形，加回3×3个双项空情形，再减去三项都空的1种。仅要求C非空则是240个模型。不要把这些不同侧条件的数量混为一谈。

`witnesses.json` 保存每个式的分类计数及最小见证。按对象数递增、再按类型字典序枚举，因而“最小”严格指该压缩片段中所需论域对象数最少，不是古代唯一例子或语言上最简单。文件也列出真前提/假结论但不满足侧条件的反例数。

## 5. 章末论断的现代逻辑边界

`ending_table()` 是现代材料蕴涵真值表，不是原文语义的翻译裁决。设P、Q为布尔命题，P蕴涵Q与非P蕴涵Q同时成立，当且仅当Q为真。这组条件本身**不矛盾**：例如Q是恒真命题，则P任取都成立。两条蕴涵会排除Q假的情形；只有再要求存在Q假的可能情形，才产生冲突。不能把“若非Q则Q”直接读成无条件矛盾，因为它恰好可推出Q，而不是推出任意假命题。

原文“必然推出”是否含有相关性、非平凡性或解释关系，必须由来源讨论承担。这个真值表只阻止把一种有争议的历史论断误称为材料蕴涵的一般定理，也不反过来断言原作者就是在谈现代材料蕴涵。

## 6. 真实运行

命令：`bash run.sh`。脚本保存环境记录、作者测试以及普查的normal、-O、-OO三种模式日志。全部22项测试在三模式通过，输入验证不用会被优化掉的assert。

每模式结果：

- 255模型×6式=1530次式评价；全项非空218模型对应1308次式评价。
- Darapti/Felapton各240个满足存在侧条件的模型；无条件统计各有7个反例，补上条件后均0违例。
- 另四式各255模型，均0保真违例。
- 真结论分类对依次9、9、6、6、6、6。
- 章末合取与Q等价检查通过；这不是“原文已被实验证明”。

`logs/model-*.txt`输出完整见证文件SHA-256，可比较三模式结果；`logs/tests-*.txt`是真实unittest输出。源码、测试、环境、命令和日志一同保存，无手填通过结果。独立核验应另写oracle，不应只再次调用同一函数来声称独立。
