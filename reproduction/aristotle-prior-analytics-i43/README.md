# I.43：局部定义目标的有限集合教学实验

这是《前分析篇》I.43（50a11–15）的**现代教学重构**，不是古代算法复原，不认证水的经验性质，也不裁定Owen与Jenkinson译法分歧。完整解释见[正文](../../papers/ancient/aristotle-prior-analytics-i43.zh-CN.md)。

## 模型与检查对象

用W表示研究对象类，L和P表示两个谓词，D为显式合取L且P。允许空类和空论域，以免把存在前提偷偷加入；这不声称古代逻辑允许空论域。

1. W包含于D，当且仅当W分别包含于L、P。
2. **以W包含于L为额外背景**时，剩余P义务与整个包含目标等价。
3. 单独证明P不能自动填补L，也不能证明D反向包含于W。
4. 反驳“每个W都是P”需要一个属于W而不属于P的同一对象。论域中随便一个非P对象不够。
5. 外延定义相等需要双向包含，而不仅是对象满足两个性质。即使双向包含也不证明自然语言中的本质定义。

这些结论的一般理由是集合交、包含和相等的定义；逐步证明在正文。枚举实跑只核查实现及有限实例，不能证明一般数学定理。

## 文件和API

- `model.py`：Atom、And、Or、Not构造公式；Model计算有限外延、包含、相等与反例。And/Or至少需两个成员；正文空成分列表的集合约定不由此AST实现。
- `project_component`：只展开顶层正向合取，不穿过Or或Not。整个Not(P)作为合取成员可以选，但不能将Not(L且P)剪成Not(L)或P。非合取式只允许选自身，不能选内部子式。
- `Certificate(subject,predicate)`：一个**有限模型目标记录**。`verify_certificate`同时检查精确目标匹配及该模型中的包含事实，不把记录当作一般演绎证明。
- `verify_components`：逐一核对显式合取叶子的证书；重复局部证书不能替代缺少的成分。公式和原子名必须有效；空前件不会隐藏未解释谓词。
- `test_model.py`：18项针对性测试，含空类、缺成分、反向缺口、错误剪裁、生成器证书和无效输入。
- `run_experiment.py`：枚举论域大小0至4的全部W/L/P外延。

## 环境与重跑

Python 3，只有标准库；实际版本见[环境日志](logs/environment.txt)。在此目录执行：

```sh
python3 -m unittest -v test_model.py
python3 run_experiment.py
python3 -O -m unittest -v test_model.py
python3 -O run_experiment.py
python3 -OO -m unittest -v test_model.py
python3 -OO run_experiment.py
```

`-O`和`-OO`不应取消输入与实验检查，故关键检查使用显式异常而非assert。unittest断言是测试方法调用，不是Python可删除的assert语句。

## 真实运行结果

三种模式各18项测试通过；每模式枚举4681个模型（各规模分别1、8、64、512、4096）。四类无条件检查各计4681次，背景归约条件成立的1555个模型单独检查；774个模型显示局部P成立却全目标失败，440个模型显示全称包含成立却定义相等失败。这些是不同外延赋值计数，不是独立语义类型数，也不是历史结论的统计概率。

## 具体反例和边界

取论域{0,1}：

- W=P={0}，L为空：局部可饮属性成立，整个“L且P”失败。
- W={0}，L=P={0,1}：W满足全部成分，但D还包含1，不是外延相等。
- W为空，L=P={0}：全称包含真，定义相等假；没有存在结论。
- W=L={0}，P为空：W包含于L或P，却不包含于P；不能把析取当合取投影。
- 同一赋值下W包含于非(L且P)，但不包含于非L；德摩根规则不允许随便选择一个否定成分。

实验没有解析自然语言、证明原文所有解释、归纳水的性质或建立自动定义系统。结构筛选与有限语义核对也不是任意前提集的证明搜索器。原文“减少长项干扰”的动机只能得到教学性说明，不从这次运行推出人类理解速度或AI性能改进。
