# VII.19：比例与交叉积

这是现代整数教学重构，不是古代实跑记录或一般命题的计算证明。四个给定数 A、B、C、D 均须是大于 1 的整数。独立按重复加法得到 G=A×C、E=A×D、F=B×C。按 VII.17 核对 C:D=G:E；按 VII.18 核对 A:B=G:F。

若原比相等，G:F 与 G:E 的约分计数相同；又因为分子 G 固定且为正，两对的缩放倍数相同，故 F=E。反向若 E=F，两个桥接比本是同一对整数，于是原比相等。测试直接用整数乘法和 Fraction 从原输入核对两个方向。

- (4,6,10,15)：G=40、E=F=60，原比和桥接比都是 2/3。
- (4,6,10,16)：G=40、E=64、F=60，原比 2/3 与 5/8 不同，交叉积也不同。
- 现代边界：4:0 与 6:0 的交叉积皆为零，但两个分数都无定义。固定分子若是零，也不能从 0:2=0:3 推回两个分母相等。这些不属于原模型。相等和反向的非零输入可由现代约分计数核对，而非以真份来命名。
