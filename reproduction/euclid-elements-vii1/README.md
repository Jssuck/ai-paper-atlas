## 测试与边界

- 每一段固定较小数，逐次从较大数减它，直到余数小于该数；记录段初两数、相减次数及余数。比较现代 `divmod` 成批法的完整轨迹。新余数 1 停在 `unit-remainder`，整除停在 `exact-division`；后者用于示范失败分支，不把 VII.2 的最大共同量数结论归给 VII.1。
- 例 (35,22) 的新余数依次 13、9、4、1；(42,18) 先得 6，下一段整除；(21,7) 第一段即整除。相等的初始数和输入含单位在古命题前提之外，代码作为现代特例给出对应标签。拒绝非正数、浮点数及布尔值。
- 从 1 至 64 全枚举 4,096 组有序对，并用遍历全部候选共同因子的朴素方法作独立核验。4 种终止情形分别是 2,392 个新余数 1、1,514 个整除、127 个初始单位和 63 个初始相等非单位。每步另核对除式；正余数步检查共同因子集合不变，零余数时核对最后除数是共同因子；有限测试不证明所有输入的结论。
- (10,001,2) 一段执行 5,000 次普通相减，成批实现只调一次带余除法就记录相同轨迹。操作计数不是硬件计时或任意精度整数的成本证明。
