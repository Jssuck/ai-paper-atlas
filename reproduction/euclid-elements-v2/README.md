# 《几何原本》卷 V 命题 2：两批倍量的相加

[回到中文精读](../../papers/ancient/euclid-elements-v2.zh-CN.md)。每一批各有一对量，各对按固定的两种基量计数。第一批共用整数倍数 m，第二批共用整数倍数 n，两批可不同；每列合计是自己的基量的 m+n 倍。程序先核对两批前提，再重建结论。

## 模型、证书和对照

- 使用正有理数与量类标签。同一列的两批量和该列基量都要同类，每类内事先统一单位；两列可不同类，因为从不跨列加法。这是现代类型化模型，不意味着传世插图画了面积。标签不自动换算不同物理单位。
- 按卷 V 定义 1–2 的严格量尽约定，整数倍数须至少为 2。一般算术等式也允许倍数 1，不把这个扩张算成古代正文的前提。实现用精确除法读取整倍数作为证书，原证明按复制数计量，不用预先求商。
- 正例：左基量 3/2、右基量 5/2，两批分别取 2、3 倍。证书给总倍数 5、两列总量 15/2 和 25/2，后两者仍各自属于本列量类。
- 补偿反例：基量都是 1，两批按行记为 (2,3)、(4,3)，两列总量都是 6，但左右的批次配对均错；不能倒推原前提。
- 数值比例反例：基量 (2,4)，两批 (3,6)、(5,10)，每批在数值上同比分别为 3/2 和 5/2，但不是整数倍，尽管相加后恰是各列基量的 4 倍。

## 环境与实跑

仅用 Python 3.12.14 标准库，在本目录执行：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python equimultiple_sum.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

三个 Python 模式各通过 10 项测试。网格以三种基量坐标组成九对，各取两批在 2–5 的倍数，共 144 个正例。用显式拼接两组副本作为结果对照。另在右列两批间转移一份、保持合计不变，得到 135 个错配拒绝；两批均为 2 倍时，无法保持总份数不变又使两个新倍数都至少为 2，故这九组只计正例。日志仅统一 unittest 显示的耗时。

环境没有 Notebook 模板脚本及可用的 Jupyter 命令；Notebook 按教学结构生成，三个代码单元实际由标准库顺序编译执行，未运行 Jupyter 内核或前端。有限测试仅检验实现，不取代一般证明。
