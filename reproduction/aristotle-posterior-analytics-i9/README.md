# I.9 教学复现：推出、前提支持与解释资格不是同一件事

这是原创有限模型，不是古代实验或亚里士多德知识定义的完整形式化。原文入口：[Mure 英译 Book I Part9](https://classics.mit.edu/Aristotle/posterior.1.i.html)；完整书目、校勘边界以[深读正文](../../papers/ancient/aristotle-posterior-analytics-i9.zh-CN.md)和来源台账为准。

## 本实验回答什么

给定一组明确列出的有限世界，前提是否排除了结论为假的世界？去掉一个具体前提后，是否重新出现反例？哪些前提子集在当前语义中已经足够？

它不回答：这些前提是否确实是某科学的本原、某中项是否为真实原因、作者或读者是否拥有科学知识。代码把后者放在外部声明里，而且故意允许完全相同的逻辑掩码得到不同的政策结果，以展示语义演算没有认证这些声明。

## 世界与逐步计算

世界编号0至7，是三个布尔变元x、y、z的全部赋值。最低位对应x，第二位y，第三位z。每个命题用8位掩码存储：第w位为1，表示在世界w为真。

- x 的掩码170，y为204，z为240；全集255。
- 蕴涵y→z的掩码为243。它排除y真z假的世界，但仍允许世界0与1；这两个世界的z都为假。因此只给这条通用推理关系，不足以得到z，反例掩码为3。
- 加入x与x→y，三个前提的交集仅剩世界7，掩码128；该世界z为真，因此在这个有限语义中推出z。
- 删掉x，世界0恢复，反例掩码1；删掉x→y，世界1恢复，反例掩码2。

这里把y→z称为“共同材料”、x及x→y称为“具体路线”，只是例子的指定角色。它们不是从希腊文逐字翻译出的命题，也不是声称任意材料蕴涵都等于古代共同公理。

`assess`用前提真值集合的交集求模型，再减去结论的真值集合。没有反例表示语义蕴涵；另报`consistent`，区分有模型的推导和不一致前提的空真。`certificate`的教学政策拒绝不一致前提，但并不改变经典逻辑中不一致前提蕴涵任意结论这一事实。

## 前提撤除与最小支持

`minimal_supports`返回所有按包含关系极小的、同时一致且足够的前提索引集，并不是只返回数量最少的一组。对前提序列[y, y→z, x, x→y]，输出为[0,1]及[1,2,3]。第二组更长，但删掉其中任一前提就不再足够，故仍是极小支持。

这种计算可以定位一个给定推导依赖的假设，却不能仅凭“不可再删”认定其为解释原因。两个极小支持可能分别是观测性桥梁和理论性桥梁；真值表本身不会给它们贴出真实的因果标签。甚至直接把目标z放进前提也会形成极小支持，但这显然不凭自身解决论证起点问题。

## 外部声明的边界

`Declarations`有五个布尔字段：恰当性声明、原因中项声明、同域声明、从属路线声明、桥接声明。政策接受需要：前提一致且蕴涵目标，前两项声明为真，并且同域，或同时声明了从属路线与桥接。

这只是人为设定的审查门槛，不是I.9全部主张的充要条件。只勾选字段即可改变结果，程序不会查证勾选者是否诚实或正确。测试中的“通过”仅表示声明满足政策，不表示科学解释通过了实质审查。跨域政策不禁止数学应用；它要求在本教学记录里显式提供从属和桥接声明，而非只用共同规则的名字冒充适用性证明。

## 运行

环境：Python3，全部依赖标准库。仓库根目录执行：

```bash
bash reproduction/aristotle-posterior-analytics-i9/run.sh
```

`run.sh`使用`set -euo pipefail`。任一步失败即以非零码退出，不会把后续结果写作成功。它在normal、`-O`、`-OO`三个模式各运行20项`unittest`测试，并在各模式重跑枚举。测试使用`unittest`检查而非会被优化删掉的裸`assert`。三份JSON必须逐字节一致，才复制normal为`results.json`。

## 已实跑结果

- 8个世界，256种前提模型集合乘256种目标集合，共65536对。
- 位运算判定与逐世界真值蕴涵oracle差异0。
- 一致且蕴涵的组合6305对；计数关系为3的8次方减256，减去的是空前提模型集与任意目标的组合。
- 两个上述极小支持均被返回。
- 相同语义模型在“未声明恰当/原因”时政策失败，在补上声明时政策通过。这直接展示政策不能自行发现解释资格。
- 声明上位路线但不声明桥接时失败；同时声明时可通过。前提不一致时即使所有声明齐全仍失败。

日志见[环境](logs/environment.txt)、[normal](logs/tests-normal.log)、[-O](logs/tests-O.log)、[-OO](logs/tests-OO.log)，各模式结果在同目录。源码校验见`SHA256SUMS`。这些是本次真实运行记录，不是预写期望日志。

## 局限与可复查练习

模型没有量词、模态、古代属的本体论或真实科学材料；真值赋值也不等于现实可实现状态。枚举穷尽的是这8个预设世界的集合，而不是所有科学理论。最小支持搜索随前提数量指数增长，本例只用四条前提。

1. 为什么有6305对一致蕴涵？每个世界可在前提集合内且目标内、前提外目标内、两者外；共3的8次方种。删除前提空集的256种，得到6305。
2. 最小支持必然是原因吗？否。极小性只关乎给定前提库的删减，程序并未获得因果或恰当性证据。
3. 只给z为前提会怎样？语义上推出z，最小支持为该单项；没有独立解释依据，因此不可据此宣称掌握科学知识。
4. 能用此模型证明没有普遍统摄科学吗？不能。它不包含所有科学，也没有形式化原文该论证的全部历史假设。
