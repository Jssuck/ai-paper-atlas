# VII.21：互素数是给定比中的最小对

现代整数的教学重构，不是古代实跑或一般命题的计算证明。假如互素的 A、B 不是给定比中的最小对，取对应的严格较小最小对 C、D。VII.20 给出相同的整除次数 k>1。VII.16 让 k 从重复次数变成共同的段长：原先是 k 个 C、k 个 D，换成 C 个 k、D 个 k。因此 k 同时整除 A、B，与互素前提矛盾。

程序分开呈现两部分：`divisor_count` 核对给定的较小对是否具备 VII.20 所保证的共同整除次数，再独立重复加法核对 VII.16 的转移；它本身不验证较小对最小。反例 (12,18) 的候选 (6,9) 也给出有效公度 2，却不是最小对。另一个函数 `analyze` 用现代最大公度求最小对作为诊断，不声称这就是原文证明。测试独立枚举同比数对与公因数核对诊断。

- 8 和 15 都是合数但彼此互素，原数对已最小。
- (16,30) 的严格较小最小对是 (8,15)，次数 2 成为共同非单位公度。
- (4,8) 的现代最小对 (1,2) 涉及单位。按历史非单位给定数设置的转移函数拒绝该输入，不把现代诊断变成古文语义结论。
