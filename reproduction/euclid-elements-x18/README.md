# 《几何原本》X.18：比值不可公度在加减关系中的传递

在精确有理坐标中令 `L=x+y`、`S²=4xy`、`x>y>0`，输入 `L>S>0`。差 `d=x−y` 满足 `d²=L²−S²`。`analyze(L,S)` 返回差平方；若其既约分子与分母均为完全平方数，还返回依次为 `x/y,L/y,L/(2y),L/d` 的四个有理比。否则四个比均无有理见证，返回 `ratios=None`，不是说没有实数分段。模型限定有理输入坐标，不是判定任意实长度的工具。

例如 `L=3,S=2` 给出 `d²=5`，四个比均无理；可公度对照 `L=5,S=4` 的比值为 `4,5,5/2,5/3`。统一缩放长度不改变分类；本程序只演示精确有理缩放，不以浮点数表示无理长度。

在整数输入上，独立基线枚举双倍的小段 `Y`，以 `X=2L−Y` 和 `XY=S²` 核对。若有有理解，因差平方是整数，差也是整数，故双倍坐标枚举总能找到它。实跑 `1≤S<L≤64` 的 2,016 个整数对，其中 54 对四个比均有理，1,962 对均无理。这是有限校验，不代替一般证明。
