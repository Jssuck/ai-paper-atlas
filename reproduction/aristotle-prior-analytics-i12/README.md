# I.12：前提标签、共同世界与结论强度

这是本文自有的**现代教学模型**，不是亚里士多德模态体系的完整实现，也不声称给出 I.12 唯一历史解释。历史正文与译注的争议见[来源账本](../../papers/ancient/aristotle-prior-analytics-i12.sources.zh-CN.md)，整体解读见[主文](../../papers/ancient/aristotle-prior-analytics-i12.zh-CN.md)。

## 模型及边界

非空固定论域 U；非空世界集合 W，实际世界为第0个。每一世界分别解释 A、B、C 三个一元谓词，谓词可以为空。程序的穷举固定 U={0,1}、W={0,1}，每个世界的三个谓词各用0至3的位掩码表示，因此有4的6次方即4096个模型。另报告所有世界所有谓词均非空的729模型子集；这是额外筛选，不是改变程序的默认语义。

直言命题的参数次序为“种类、主项、谓项”。A(X,Y)表示X包含于Y，E表示不交，I表示交集非空，O表示X减Y非空。A/E不额外断言主项存在；I/O明确需要见证。全称否定E不因空主项而假。

- D：命题在实际世界为真。
- N：命题在所有世界为真。
- P：至少一个世界为真，即包含必然性的可能。
- C：至少一世界真且至少一世界假，即本模型的双向可能/偶然。

这四个名称不应未经论证地代换原作者全部模态词用法。尤其C不是“未获得证据”，P也不是“不是必然”。本章历史总结是否为指定推理式的分类规则，不能由这个现代模型决定。

## 实现与文件

- [model.py](model.py)：严格输入检查、位掩码语义、独立逐元素参考求值器与配置报告。
- [test_model.py](test_model.py)：16个测试方法，其中一项做196608次生产/参考语义比较；并检查世界顺序、空项、错误参数、弱化和具体反模型。
- [results.json](results.json)：192配置的可满足模型数、反模型数、首个反模型及非空项子集计数。192=4式×4大前提标签×4小前提标签×3结论标签。
- [WALKTHROUGH.md](WALKTHROUGH.md)：手算与一般证明。
- [environment.json](environment.json)：实跑解释器及依赖范围。
- [normal测试](logs/tests-normal.txt)、[-O测试](logs/tests-O.txt)、[-OO测试](logs/tests-OO.txt)；[normal报告命令输出](logs/demo-normal.txt)、[-O输出](logs/demo-O.txt)、[-OO输出](logs/demo-OO.txt)。

四式依次为Barbara(AAA)、Celarent(EAE)、Darii(AII)、Ferio(EIO)。大前提主项B、谓项A；小前提主项C、谓项B；结论主项C、谓项A。代码没有检查任意三段论、其他格、任意自然语言或无限模型。

## 可重跑命令

在本目录使用现有Python运行，无额外依赖或安装：

```sh
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python model.py
python -O model.py
python -OO model.py
```

model.py会重写本目录results.json。此次三个模式均真实执行，三个报告逐字节一致；测试各通过16个方法。正常与优化模式都不依赖assert实施输入检查。测试日志只包含相对模块名与实际计时，无账户/设备路径。

## 已运行结果

全部192配置中52个在4096模型内无反例。这个计数是**有界执行事实**，不是192个一般命题都已证明，也不把未找到反例升级为任意论域有效。

| Barbara配置（大/小/结论） | 满足前提模型 | 反模型 | 全项非空子集的反模型 |
|---|---:|---:|---:|
| N/D/D | 576 | 0 | 0 |
| N/D/N | 576 | 176 | 28 |
| N/N/D | 256 | 0 | 0 |
| P/P/P | 2592 | 242 | 48 |
| C/C/D | 1056 | 536 | 94 |
| C/C/N | 1056 | 830 | 140 |

关于前几项的一般有效性与后几项的具体反例见走查，不用穷举代替证明。所有表项都有满足前提的模型，因此这些已列有效项不是由前提矛盾产生的空洞成立。
