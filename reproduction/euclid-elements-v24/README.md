# 《几何原本》V.24：相加前项而不动后项

这是 [V.24 中文精读](../../papers/ancient/euclid-elements-v24.zh-CN.md) 配套的现代精确数值模型，不是历史文献的全文或原程序。给定输入顺序 `u,v,w,x,y,z`，先分别检查 `u:v~w:x` 与 `y:v~z:x`，其中左侧共用后项 `v`、右侧共用 `x`。无量纲的有理数模型不区分长度、面积等类型，也不验证不可公度量。

以 `6,4,15,10,2,5` 为例，先翻转第二比例（V.7 推论），再用 V.22 连接到 `u:y~w:z`；V.18 把前项变成两量之和；再次用 V.22 恢复原后项。两侧的四步数值比依次都是 2、3、4、2。轨迹计算中间比的精确商便于核对，并不是卷 V 各条命题的抽象实现。

## 环境和命令

使用 Python 3.12 与标准库，不需要额外依赖。在本目录运行：

```sh
python -B -m unittest -v
python -B -O -m unittest -v
python -B -OO -m unittest -v
python -B replay_notebook.py
```

[正常模式](normal.log)、[O 模式](O.log)、[OO 模式](OO.log)各实际运行了 8 项测试；[Notebook 日志](notebook-replay.log)由标准库顺序执行 [Notebook](euclid-v24.ipynb) 的三个代码单元生成，未启动 Jupyter 内核。若本机已有 Jupyter，打开 Notebook 后可直接运行全部单元。

## 证据与边界

- 输入项各从 1 到 5，共 15,625 组六元组，其中 157 组满足两条前提。遍历覆盖所有候选：参照先用后项的最大公约数约成最简整数对，再按整倍检验前项，借此检验程序的前提接受与拒绝；另用整数交叉积验证端点比例，并以分子分母比较核对实际轨迹的末项。
- 测试包括正分数、分别缺失两项前提、把两个比例的后项各自换掉，以及零、负量、浮点数与布尔值。普通有理数中的穷举是有限检查，不是原命题的全称证明。
- 独立字典序模型的左组是 `u=(1,1), v=(1,0), y=(1,-1)`，右组是 `w=(1,2), x=(1,0), z=(1,-1)`，加法逐坐标。两个前提在倍数不等时由首坐标统一决定；倍数相等时第一对均大于、第二对均小于。两个和的首坐标都是 2，比较和与原后项，要在后项倍数等于前项倍数两倍时看第二坐标；左侧相等而右侧大于。对 144 对倍数的检查只用来核对这个推导。因为 `(0,1)` 的任意正整数倍都小于 `(1,0)`，模型不满足卷 V 通常使用的同类正量可比较条件。
