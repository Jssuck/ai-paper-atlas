# 《几何原本》X.28：三个平方坐标构造中项矩形

取参考长度 `u>0`，令 `a,b,c` 依次为 `A,B,C` 长度相对 `u` 的平方。函数 `construct(a,b,c)` 要求三者为正有理数，且任意两项之比都不是有理平方。由 `D²=AB` 和 `D:E=B:C`，输出相对四次幂 `ab,ac²/b`，比平方 `(E/D)²=c/b`，以及相对面积平方 `ac`。正面积本身是 `√(ac)·u²`，在有效域上不与参考平方可公度；代码不近似开根，也不模拟尺规。

例如 `(a,b,c)=(1,2,3)` 得到 `2,9/2,3/2,3`。逐一检验前提：`(1,4,2)` 仅违反 `A:B`，原公式会使 `D` 不再是中项；`(1,2,4)` 仅违反 `A:C`，会得到有理面积；`(2,1,4)` 仅违反 `B:C`，会使输出两边在长度上可公度。函数对三者分别拒绝。

用独立枚举的有理平方集合核对，未使用整数平方根。原分子、分母均在 1–4，定义式至多相乘四项，所以既约分子、分母均不超过 256；若为有理平方，既约根的两项都不超过 16。4,096 个有序代表（不去重）中，1,344 个有效，2,752 个不满足前提。输出同时核对两个四次幂的乘积等于相对面积的四次幂。有限样本不能代替证明。
