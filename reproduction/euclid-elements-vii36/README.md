# VII.36：三个数的最小公倍数

现代整数教学重构，不是古代实跑或一般定理的计算证明。先按 VII.34 构造前两个数 A、B 的最小公倍数 M；若 C 量度 M，则 M 就是结果。否则再次按 VII.34 构造 M、C 的最小公倍数 L。若 H 是 A、B、C 的公倍数，按 VII.35，M 一定量度 H；C 也量度 H，因此在第二分支 L 也量度 H。程序用现代最大公度实现两数子程序；独立测试直接搜索。

(12,18,9) 得 M=36，已被 9 整除。(6,10,14) 得 M=30，需要第二次构造，L=210；公倍数 420 分别由 M 和 L 量度 14 和 2 次。后例的两两最小公倍数最大值只有 70，且不是 6 的倍数；三项积除以三项最大公度给 420，是公倍数却不是最小。现代单位输入需要显式开启；零、负数不进入此正整数模型。
