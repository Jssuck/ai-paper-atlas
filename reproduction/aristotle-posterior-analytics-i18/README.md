# 《后分析篇》I.18：观察、背景与有限样本

## 原文联系与范围

实际对读 Owen 1853 印285–286章 XVIII 与 [Mure Book I Part18](https://classics.mit.edu/Aristotle/posterior.1.i.html)：证明从普遍材料出发，归纳涉及个别，连抽象对象的学习也不因此完全脱离取得材料的问题。本模型仅提出一个额外的现代信息依赖问题：**给定观察，目标是否已经被唯一决定？** 原文没有这里的函数、二值模型或枚举定理。

## 模型和一般论证

设有限可能世界集合 W；O 为观察函数，T 为待恢复目标。说目标“可恢复”，是指存在定义在观察像集上的函数 g，使每个 w 都满足 T(w)=g(O(w))。这只表示信息充分，不保证学习者已知道 g、算法高效、科学原因成立或知识正当化。

**命题（现代重构）：**这样的 g 存在，当且仅当 O 相同的任意两世界，其 T 也相同。

1. 必要性：若 O(w)=O(v)，函数 g 对同一输入给同一输出，于是 T(w)=g(O(w))=g(O(v))=T(v)。
2. 充分性：对每个实际出现的观察值 o，令 g(o) 为其观察类内共同的 T 值。类内恒定使定义良好；代回任一 w 即得等式。
3. 空域：像集也空，空函数就是解码器。代码用 `{}` 表示它，不能把空字典当作失败；失败专用 `None`。
4. 未出现的观察值无需指定。若要求延拓到更大的观察值域，还需有可选目标值；本代码二值目标非空，因此可任意延拓。独立测试枚举所有二值总解码器。

程序只实现 O、T 均取0/1的版本。向量下标是世界，长度须相同；元素须为整数0或1，布尔值、浮点数与字符串不默许转换。它不接受噪声、随机观察、无限域或实际传感器数据。

## 四个例子与一个反例

世界顺序为坐标对 (0,0)、(0,1)、(1,0)、(1,1)。

- **缺失通道：**只观察第一坐标 x，要恢复第二坐标 y。前两世界观察相同但目标相反，故不可能仅凭 x 解出 y。
- **替代通道：**改为观察 y，就能直接恢复 y；信息条件已改变，不能拿它反驳旧条件下的不可能性。
- **额外背景：**若限定世界满足 x=y，只剩两世界，x 便足够。背景必须另有根据；不是从原始观察自动推出它为真。
- **抽象：**把 x 当形状类别、y 当材料类别，目标只问形状；观察 x 可忽略材料。这说明“忽略某些属性”不同于“毫无材料依赖”，不证明古代数学抽象的完整学说。
- **样本反例：**两对象仅检查第0项为1，目标候选 (1,0) 与 (1,1) 都符合观察，却对“所有对象都是1”给出不同答案。增加更多相同正例也不能无条件排除尚未观察对象的反例。

## 有限枚举与真实结果

| 世界数 | O/T 映射对 | 可恢复 |
|---:|---:|---:|
| 0 | 1 | 1 |
| 1 | 4 | 4 |
| 2 | 16 | 12 |
| 3 | 64 | 28 |
| 4 | 256 | 60 |
| 合计 | 341 | 105 |

测试以独立判据搜索全部4个二值总解码器，与观察类实现逐对核对，并检查得到的解码器逐点正确。n>0时，两个常值观察各允许2个目标，其他 2^n−2 个观察各允许4个目标，所以可恢复数为 4+4(2^n−2)。空域单列。

另外，4对象的16种目标×16种样本子集，共256组合；240组合仍有多个相容目标，16个全覆盖样本才唯一。若样本含 k 个对象，每个未观察位置可自由取两值，所以相容目标有 2^(4−k) 个。这是指定有限域上的计数，不是普遍归纳的可靠性结论。

normal、`-O`、`-OO` 均实际执行8项 `unittest` 测试并通过；检验使用 `self.assert...` 方法而非会被优化删除的 Python `assert` 语句。测试还覆盖空域、非满射观察、非法类型/长度/重复样本下标。

## 复盘练习（附答案）

1. 解码器存在，是否表示不需要经验就能知道它？**否。**存在性不提供获得或验证解码器的认识路径。
2. 为什么不能用 `if decoder(...)` 判断可恢复？**空域返回空字典，逻辑上可恢复但在 Python 中是假值；应用 `is not None`。**
3. 一个观察通道不足时，是否所有目标都不可恢复？**否。**可恢复观察类内恒定的目标，例如常值或观察本身。
4. 样本覆盖了4个对象，是否证明所有可能对象的普遍规律？**否。**结论仅对已指定4对象域；扩域后须另论。
5. 为什么替代通道与背景限制必须分开？**前者增加可区分信息，后者删去可能世界；两者的证据责任不同。**
