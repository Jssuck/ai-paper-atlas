# VII.32：质数自身或合数的质因数

现代整数教学重构，不是古代实跑记录或一般命题的计算证明。给定整数 N>1。若 N 本身是质数，证书选 N，标签是 `prime-itself`。否则按 VII.31 沿严格递减的非单位真因数找到质数，证书记 `VII.31`，且终点整除 N。复现在本目录中自包含，仅加入 VII.31 所用的下降循环。现代程序在质数分支返回自身以便统一检查，不把它说成找到了真因数。

13 走质数分支，路径只有 13。84 走合数分支，选最大真因数时路径为 84→42→21→7，选最小时为 84→2。原文不规定选择法，也不要求枚举所有质因数。单位 1 不进入命题约定的「数」。
