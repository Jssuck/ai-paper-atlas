# 《几何原本》V.23：错位比例的最小教学复现

这是一份现代有理数教学模型，不是历史文本或其程序的复刻。[中文深读](../../papers/ancient/euclid-elements-v23.zh-CN.md)解释一般证明的前提。在代码中，两个三元组及所有可比较量都用同一种精确正有理数表示，不能检验物理量类型、不可公度量或非阿基米德量。

## 方法

输入满足 A:B 与 E:F 同比、B:C 与 D:E 同比。对任取的两个正整数 p、q，将 p 用于 A、B、D，将 q 用于 C、E、F。按原文记号，倍量依次是 G、H、K、L、M、N。输出 G 对 L 与 K 对 N 的比较符号（1 大于，0 等于，−1 小于）；这对应 V.21，但程序直接比较数值，不是独立实现 V.21 的抽象证明。

两份轨迹都先用等倍不改比，得到 G:H 与 M:N 同比。原文轨迹随后依 V.16 转到 B:D 与 C:E，再以 V.15 与 V.11 得 H:K 与 L:M 同比，最后用 V.16 换回 H:L 与 K:M。替代轨迹只改第二个配对：用 V.4 同时给两边的前项乘 p、两边的后项乘 q，直接得到 H:L 与 K:M。原文中间的 B:D 与 C:E 需要跨组同类；替代路线不形成这些跨组的比。代码只演示数值，不执行这一类型区别。

## 实跑方式

使用 Python 3.12 与标准库，无需安装依赖。从本目录运行：

```sh
python -B -m unittest -v
python -B -O -m unittest -v
python -B -OO -m unittest -v
python -B replay_notebook.py
```

四次实跑分别见 [正常模式](normal.log)、[O 模式](O.log)、[OO 模式](OO.log)及 [Notebook 代码单元](notebook-replay.log)。Notebook 三个代码单元按顺序共用命名空间，由标准库逐单元运行，未启动 Jupyter 内核；若本机已有 Jupyter，可直接打开 [Notebook](euclid-v23.ipynb) 后运行全部。为避免把终端日志误作内核结果，Notebook 本身不保存输出。

## 读数与边界

- (6,4,3) 与 (16,12,8)：固定 p=1，让 q 取 1、2、3，两组端点依次同时大于、同时等于、同时小于。
- 确定性穷举：每个量从 1 至 4 取值。4096 组六元组，70 组满足双前提；每组检查 16 对倍数，总计 1120 次。独立参照直接用整数交叉积筛选前提，并用整数差计算预期符号，不调用模型的比较函数。按乘积值统计有序数对的个数，再将各个数的立方求和，可独立复核 70 这个计数。
- 测试还分别撤掉一项前提，检验错用按位缩放的失败，拒绝非正量、不精确输入与非法倍数。
- 65:64 和 66:65 不同，却在 1 至 64 的方格内没有得到反证，直到 p=64、q=65。一处反例能否定同比；任何有界范围无反例，都不能代替 V.Def.5 对全部正整数倍数的要求。
