# Aristotle II.10：第三格结论替换的最小教学实验

这是原创的现代一元集合模型，不是古代原算法、古代唯一定义语义或整书复现。对应[中文深读](../../papers/ancient/aristotle-prior-analytics-ii10.zh-CN.md)。六式名称是后世标签；原文展开与教学补全的区别见正文及来源台账。代码与日志不包含原文全文或PDF。

## 实验问题与定义

第三格保留中项C：大前提是关于A与C的命题，小前提是关于B与C的命题，原结论关于A与B。每个原式分别取两类结论替换，再分别保留一个前提、把另一个作为反驳目标，共6×2×2=24个案例。

`P(kind, predicate, subject)` 固定为“谓项属于主项”的方向；A表示包含，E表示不交，I表示交集非空，O表示主项中存在不属于谓项的对象。`A`同时被用作项名和命题种类，仅由各自参数位置区分。`contrary`沿用本章对特称I/O互换的用语，不把它们当现代逻辑中不能同真的反对命题；`contradictory`则将I换成E、O换成A。

|原式|AC|BC|AB结论|矛盾替换后，保留BC所得AC|矛盾替换后，保留AC所得BC|
|---|---|---|---|---|---|
|Darapti|A|A|I|E|E|
|Disamis|I|A|I|E|O|
|Datisi|A|I|I|O|E|
|Felapton|E|A|O|A|E|
|Bocardo|O|A|O|A|O|
|Ferison|E|I|O|I|E|

这张表是可运行的教学补全，不声称古文逐式写出了全部六行。`result_countermodels` 检查表中**所得结果**；`refutation_countermodels` 检查替换命题、保留前提和目标前提能否共真。二者故意分开：一个有效的新结论不自动等于反驳。

## 有限表示、输入与边界

每个对象用三位类型表示其是否属于A/B/C，位权4/2/1；一个模型是8种类型的非空占据集合，以1至255的整数掩码表示。同一类型多个对象在本实验的四种命题中不可区分。枚举三种政策：

- `empty_allowed`：论域非空，但A/B/C各自可空，255模型；
- `C_nonempty`：只要求C非空，240模型；
- `all_nonempty`：三个项均非空，218模型。

允许“000”对象表示三项外对象；不把谓项空误当论域空。压缩不处理关系谓词、模态、数量阈值或因果知识。有限运行本身不证明一般命题；适用于任意集合的见证推导与类型压缩说明见正文。

`valid_target_pair_forms` 检查目标前提相同方向的四种形式；`valid_reverse_pair_forms` 单独检查反向形式。不能把目标方向没有必然命题写成完全没有语义后果，例如Darapti的某个反对替换背景可以推出反向O(C,B)。

## 环境与运行

标准库即可，无第三方安装、外部数据、API或随机数。实际运行环境为CPython 3.12.14，Linux x86_64；详细版本和UTC时间见[环境与运行日志](logs/environment-and-reproduction.log)。

在本目录运行：

```sh
sh run.sh
```

脚本重生成`results.json`及测试日志。分开执行：

```sh
python3 check.py > results.json
python3 -m unittest -v test_check
python3 -O -m unittest -v test_check
python3 -OO -m unittest -v test_check
```

测试用`unittest`的显式检查，不以被优化删除的裸`assert`作为验证。`model`拒绝0、256、负数、布尔、浮点等非法掩码；命题及政策接口也检查合法输入。

## 已实跑结果

2026-10-23本次运行：12项测试在normal、`-O`、`-OO`三种模式均通过。包括真值定义、矛盾互补、空项、六式保真、24案例覆盖、反例回放、独立存在见证及目标方向/反向后果区别。

- 3政策、72案例-政策检查，以及18原式-政策检查；每个背景模型数均非零，避免凭空前提宣称有效。
- 12条矛盾替换的表列结果，在三政策中均没有反模型。
- C非空或三项非空时，这12条均真正排除目标前提。
- 允许空项时，Darapti、Felapton各两个矛盾替换案例仍各有7个共存模型；原因是空C上全称肯定和全称否定可同时成立。两原式本身也各有7个空C反模型。其他四式原前提已有存在见证。
- 12条I/O反对替换在三政策下均有目标前提共存模型，故不能反驳；目标同方向AEIO均无必然结果。每条首个共存模型含占据类型与集合，并被测试回放。
