# 《几何原本》IX.11：较早项度量任一较晚项

正整数教学重构。以单位 $`1`$ 为指数 $`0`$，按整数比率 $`q\ge2`$ 连乘。对于严格有序的非单位指数 $`1\le i<j`$，较早项 $`q^i`$ 度量较晚项 $`q^j`$，次数为 $`q^{j-i}`$；相邻度量次数恒为 $`q`$。若按位置把单位计为第一项，则指数 $`i`$ 对应位置 $`i+1`$。例如 $`q=3`$，指数 2 的 $`9`$ 度量指数 5 的 $`243`$ 共 27 次。

仅要求各项为整数、而不要求从单位起步，不足以推出结论。整数链 $`(8,12,18,27)`$ 的相邻乘率恒为 $`3/2`$，但 $`8`$ 不能度量 $`12`$。若另知乘率为正整数，任何正整数首项都可保留整除；本程序不把这种现代扩展混进原命题输入。

仅用 Python 3.9+ 标准库。在本目录运行：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

对 $`q=2,\dots,64`$ 及 $`1\le i<j\le12`$，用直接幂运算和精确分数作独立对照。有限核验不替代证明。Notebook 日志记录标准库顺序回放三个代码单元，不是 Jupyter 内核运行。
