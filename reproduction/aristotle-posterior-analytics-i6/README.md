# 《后分析篇》I.6：必然结论与给定中项的有限教学核验

[正文](../../papers/ancient/aristotle-posterior-analytics-i6.zh-CN.md) · [来源台账](../../papers/ancient/aristotle-posterior-analytics-i6.sources.zh-CN.md) · [数学代码独立审查](../../papers/ancient/aristotle-posterior-analytics-i6.technical-review.zh-CN.md)

## 复现什么，不复现什么

原文阅读对象是《后分析篇》I.6。核读[Mure英译Part6](https://classics.mit.edu/Aristotle/posterior.1.i.html)中“必要前提”“非必要中项”“中项可能消失而事实与记忆不变”“必然结论可以经非必然路线得出”及章末迹象与原因的区别。程序只检验其中适合有限形式化的推理关系，不模拟人的知识、记忆或古代原因理论，也不是完整复现古代科学证明。

**现代教学约定：** 固定非空对象域D，有限非空情形族W，首个情形w0作为实际情形。每一情形给A、B、C三个集合；不同情形中的同名项允许外延变化。整句“每个C是A”在一个情形中表示C包含于A；程序的“必要”只表示在给定W中每个情形均满足这一整句。本模型没有必然性可达关系、个体本质谓词、解释因果边，也不穷尽真实可能情况。尤其不能把有限样本全真直接称作现实必然。

A为大项，B为中项，C为小项。`necessary_ab`为所有情形B包含于A；`necessary_bc`为所有情形C包含于B；`necessary_ac`为所有情形C包含于A。空主项按现代集合语义使全称句真；同时单列所有项在每个情形均非空的模型计数，避免把反例误归因于空项。不是逐对象模态和整句模态的等价证明，不裁定亚里士多德唯一语义。

## 一般推导与失败方向

对于任意给定情形w与任意x，若x属于C(w)，由小前提x属于B(w)，再由大前提x属于A(w)。因此每情形两包含前提均真时，每情形结论都真。这一逐情形、逐对象证明不依赖程序枚举的域大小。其逆命题不成立：结论的必要性不保证任意一条给定路线的中项连接必要。

非空反例：两个情形中A=C={0}始终不变，B在首情形为{0}、另一情形为{1}。实际情形两前提都真；第二情形B不包含于A，C也不包含于B，桥梁失效，而C包含于A仍真。这里“消失”指支撑关联失效，不是必须B集合变空，更不是结论变假。本例只展示事实与路线分离，不从布尔值判定一个人何时真正拥有知识。

必要双前提推出必要结论的逆否表述是：若结论不是必要的，则两前提不可能同时必要。它不是“若结论非必要，则每个前提都非必要”。例如代码`actual_only_route`中C始终包含于B，但A在第二情形为空，结论和大前提都失效。

两个情形外延完全相同的另一个例子，则连必要前提和必要结论都满足；程序仍返回“因果/本质状态未建模”。把外延保持误当真正原因，会超出输入能支持的结论。原文章末连恒常的迹象也不足以自动给出原因，正是需要保留的界线。

### 额外教学对照：两条全称否定不能代替合法路线

`negative_models`是补充形式对照，**不是宣称本章专门证明了双否定规则**。在三对象域上列举所有A、B、C集合，仅保留各项非空、A与B不相交、B与C不相交的情形；检查C对A的A/E/I/O四种直言命题。每一种结论都有满足和不满足的模型，所以这种双否定组合不能强制其中任何一种。它只检查这组项位；不声称任意负句集合在任意逻辑中都无结论。

## 运行

只需Python 3与bash，全部Python依赖为标准库；不下载数据、软件包或秘密。命令：

```sh
bash run.sh
```

`run.sh`分别执行normal、`-O`、`-OO`下的unittest及枚举，保存实际stdout/stderr到`logs/`，写`results.json`和`SHA256SUMS`。测试使用unittest的检查方法，不依赖优化模式会删除的裸assert。运行命令、版本与平台信息见[环境日志](logs/environment.log)；平台信息不包含主机名、用户账户、网络或凭据。

## 限制与复盘

1. 必然性取决于选定情形族；未观察到反例不是对所有真实可能情形的保证。
2. mask内的A/B/C名称不带定义或原因意义。该工具不认证原文“自身”“恰当原则”或现实科学知识。
3. 枚举证明的是这些有限输入与实现的一致性。一般保真已由上方逐情形证明给出，不由4096这个数字替代。
4. 两否定补充对照与原章核心不同，不能充作本章书目证据。模型未实现不完整信息、概率或认识主体。
5. 只有输入合法性检查；下层`all_of`和`none_of`供已验证mask内部调用，不是任意对象的通用类型接口。
6. 三模式和独立算法可以发现编码问题，不能检测未纳入模型的哲学假设错误。真实研究仍需辨别事实真、形式有效、必要联系与解释原因。
