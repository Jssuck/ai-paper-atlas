# 《几何原本》X.22：把中项面积配置在有理底边上

取参考长度 `u>0`。输入 `q=(中项边长/u)^4` 和 `b=(底边/u)^2`，两项均为正有理数，且 `q` 不是有理平方。函数 `apply_medial(q,b)` 返回相对宽平方 `q/b` 及宽底比的平方 `q/b²`。后者仍不是有理平方：除以有理平方不改变平方类别。因此宽与底边在长度上不可公度；两者的平方坐标都是有理数，所以仅平方可公度。等面积由精确恒等式 `b·(q/b)=q` 核对：左右都是相对面积的平方，面积为正。代码不对根式取浮点近似，也不是任意实输入或尺规作图的实现。

例如 `q=6,b=2` 时相对宽平方为 3，宽底比平方为 `3/2`；`q=16/15,b=2/3` 时分别为 `8/5,12/5`。对照 `q=9/16,b=3` 的面积相对于参考平方为有理数，故在中项专用函数中拒绝；非正数和非精确输入也拒绝。

独立基线不调用整数平方根。它用试除剥去平方因子，以既约分数分子与分母乘积的平方自由部分作为签名。对每项的原分子、分母均在 1–8 的 4,096 个有序输入代表（不去重），3,328 个成功构造且平方类别保持，768 个按平方前提拒绝。有限校验不能代替一般性证明。
