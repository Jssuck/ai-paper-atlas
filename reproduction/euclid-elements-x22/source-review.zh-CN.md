# X.22 原典核对

- [Heath 1908 卷 III，正文印页 51–52](https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/022/)：以 A 记中项线、BC 记指定有理底边、CD 记施作所得宽。BD 是底宽为 BC、CD 的矩形的图形名，不是对角线长度。X.21 的命名给出另一等面积矩形 GF，其边 EG、EF 是仅平方公度的有理线。
- **第一条证路：** BD、GF 等积且等角。VI.14 给 BC∶EG＝EF∶CD；VI.22 给对应的平方比；X.11 把 BC、EG 的平方公度传给 EF、CD 的平方。由于 EF 的平方有理，依 X.定义4 得 CD 平方有理，并判定 CD 是有理线。公度判定所用的参照始终是同一个标准平方。
- **第二条证路：** 先用前置比例引理和 X.11，把 EF 与 EG 的长度不公度转移成 EF 上平方与 EF、EG 所围矩形的面积不公度；用 X.13 把这两个比较量分别换成 CD 上平方及 DC、CB 所围矩形（前者按面积公度，后者等面积）；再用同一引理和 X.11，经面积比 CD²∶(DC·CB) 转回 DC∶CB 的长度不公度。正好证明“宽是有理线”和“宽与指定底边不按长公度”这两个不同断言。
- [Heath 评注印页 52–53](https://geometor.github.io/euclid/heath/volume_III/book_x/propositions/022/commentary.html)另用除法解释并重述原证的两条路径，不把根式代数作为原证。[Fitzpatrick 希英对照本](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf)印页 303–304：p. 303 题述、图和施作设定，p. 304 完成证明；两次调用的比例引理单列在 p. 303 本命题之前（X.21 之后）。
- [Clay 的希英并排页](https://www.claymath.org/library/historical/euclid/files/elem.10.22.html)：第二条证路第一次提到与辅助矩形等积的目标矩形时，网页希文写 ΑΓ、ΓΒ；随后同一图形却写 ΔΓ、ΓΒ。Fitzpatrick 此处希文两次均用 ΔΓ、ΓΒ；Heath、Clay 英译、Joyce 相应处用 DC、CB。按图和上下文应读为 ΔΓ、ΓΒ；Α 是中项线的独立标签，不是该矩形宽的端点。这里只能确定网页呈现的不同，不能据此追断原手稿、雕版或录入层面的成因。Clay 英译到实质的不公度推论结束，希文另重述两条结论并有结束语。
- [Joyce 命题、前置引理及 Guide](https://mathcs.clarku.edu/~djoyce/elements/bookX/propX22.html)：在同一页面的命题正文前完整给两线比例引理，正文两次回用；与 Fitzpatrick 的相邻排法不冲突。Guide 的单位制代数，与 Heath 评注同属现代解释。
