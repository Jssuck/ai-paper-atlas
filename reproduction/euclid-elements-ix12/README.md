# 《几何原本》IX.12：素因子沿连比回溯

正整数教学重构。给定底数 $`q\ge2`$、指数 $`k\ge1`$ 和候选素数 $`p`$，先核验 $`p\mid q^k`$。再从指数 $`k`$ 倒查到 1，记录各项及实际的整数商。程序执行证据核验；一般推理是用素数乘积引理，在 $`p\mid q^e=q\,q^{e-1}`$ 且假设 $`p\nmid q`$ 时，推出 $`p\mid q^{e-1}`$，最终矛盾。指数 1 的单项例是直接核验。

例如 $`q=12,k=3,p=3`$，三个商为 $`576,48,4`$。结论限于素因子是否出现，不保重数。$`4`$ 度量 $`6^2`$，却不度量 $`6`$；其中素数 $`2`$ 可回溯，但它在两项中的重数不同。单位不作为这里的底数。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立有限基线先筛出 2 至 64 的素数，再标记它们在底数 2 至 64 中的倍数，对指数 1 至 8 比对回溯结果。有限核验不替代一般证明。Notebook 日志记录标准库实跑三个代码单元，不是 Jupyter 内核运行。
