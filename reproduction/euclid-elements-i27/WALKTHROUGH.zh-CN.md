# 教学推导与手算（非原文公式）

取非零横截方向 t，将平面向量用 t 与其逆时针垂向 n 作基底。设 u=a t+b n、v=c t+d n。异侧条件等价 b、d 非零异号。由于 t、n 正交等长，两个角的余切分别是 a/|b| 与 −c/|d|。相等给出 c=−a|d|/|b|；异侧同时给 d=−b|d|/|b|。所以 v=−λu，其中 λ=|d|/|b|>0。这是现代坐标推导，不借 I.29。

两线若有共同点，则 E+s u=F+r v，因而 t=(s+rλ)u。两边与 u 作行列式得 cross(t,u)=0，与异侧前提冲突。参数 s、r 是任意实数，因此一次代数矛盾涵盖两方向和全部距离；不是“检查若干远处点都未相交”。

手算正例：E=(0,0)、F=(2,0)、A=(1,1)、D=(1,−1)。t=(2,0)、u=(1,1)、v=(−1,−1)。侧向行列式为2和−2，两个角指标均为1，方向行列式0，λ=1。两线方程分别 y=x 与 y=x−2，故无交点。

边界反例：将 D 改为(1,1)。角 AEF 与 EFD 的普通角指标仍均为1，但A、D同侧，且两线交于(1,1)；因此删去“内错”位置条件就会错误。将 D 改为(3,−1)，A、D虽异侧，但角指标为1与−1，两个角互补而不相等；平方指标将掩盖此错误，两线交于(1,1)。程序两者均拒绝。

练习：为何不能用“方向行列式为0”作为完整结论？答案：还须排除重合；cross(t,u)非零提供不同偏移。为何证书不能只核自己携带的input？答案：攻击者可替换为另一个合法输入并重算全部字段，必须与调用方预期输入重新绑定。
