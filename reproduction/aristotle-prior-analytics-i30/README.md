# I.30：材料标签与形式路径的最小教学模型

这是原创教学重构，不是原文算法、完整三段论系统或经验科学自动化。目标是把「提供领域材料」与「从材料作形式推演」分开。三个项都是任意谓词，不表示真实天体或生物事实。

## 文件与运行

- `model.py`：严格输入校验、有向包含路径、独立路径证书检查、有限解释与样本检查。
- `test_model.py`：23 个单元测试（其中含多组非法输入子用例）。
- `demo.py`：可重复教学实例及一个明确有界的枚举。
- `logs/environment.txt`：实际 Python 版本；只需标准库，无安装步骤。
- `logs/tests-{normal,O,OO}.txt` 与 `logs/demo-{normal,O,OO}.txt`：真实输出、命令及退出状态。运行时间可能随机器变化。

在此目录运行：

```sh
python3 -m unittest -v
python3 demo.py
python3 -O -m unittest -v
python3 -O demo.py
python3 -OO -m unittest -v
python3 -OO demo.py
```

源码不使用 `assert` 做输入校验或实验失败检测；优化模式不会取消这些检查。

## API 与语义边界

`Premise(id, subject, predicate, basis, source)` 表示声明的「所有 subject 是 predicate」。`id` 唯一；两个不同来源可用不同 ID 支持相同边，输入顺序决定等长路径的选取。`source` 保留出处描述，但程序不能验证出处真实性或可靠性。

`find_path(nodes, premises, start, goal, mode='truth')` 返回最短的边 ID 元组，找不到返回 `None`。节点须预先声明，不能把拼写错误默默当成无结果。`verify_path(...)` 根据原前提库逐边重查标签、起点、连接与终点；有类型但不成立的证书返回 `False`，结构非法输入抛 `ValueError`。它只验证路径，不验证材料真、首要、自明、非循环或适合某门科学。

- `truth` 模式只读取 **声明标记** `verified` 的边；名称绝不表示程序已证明它们为真。
- `dialectic` 模式只读取 `endoxon` 边；标签绝不认证真正的公认意见，亦不认证每位对话者接受它。
- 两种模式不自动互通。若一项材料要在两种教学库中使用，必须各给明确标签的条目；这种人工分库是教学约定，不是对亚里士多德理论的完整形式化。
- 同项查询返回空证书：只用集合包含的自反性，不表示发现任何经验事实。
- 环不导致无限搜索；空谓词外延允许。模型因此使用现代集合包含，不处理亚里士多德全套存在承诺、模态、否定与特称命题。
- `None` 是相对所给有限图及此路径规则的 unknown，不是结论为假，更不是原文意义的一般「自然不可证明」。缺桥、错误标签或遗漏领域材料都可能导致它。

`interpretation_holds` 只检验一个由调用者给出的非空有限论域及全部项外延；空项允许。`sample_support` 区分无主项观测、样本支持、样本反例；它不把支持提升为普遍真理。

## 实际实例与结果

1. 声明库 `S→M`（a）、`M→P`（b）得到 `('a', 'b')`；证书携带 ID，并通过库找到原来源。删去 b 则结果是 `None`。
2. 同一形状换名为 `L→Q→R`，仍得相同 ID 路径。证明方式不变不意味着跨领域的前提事实可以照搬。
3. 解释 `S={1}, M={2}, P={2}` 中，a 为假、b 为真，结论 `S⊆P` 为假；证书仍形式有效。这直接示范标签与真理、有效推演与健全论证的差别。
4. 论域 `{1,2,3}`、主项 `{1,2,3}`、谓项 `{1,2}`，只观察 `{1,2}`。样本完全支持，未观察的 3 却反驳普遍命题。除非另加覆盖或其他正当保证，样本支持不足以提供普遍前提。
5. 在固定二对象论域上枚举三个谓词的所有外延，共 `4^3=64` 种解释；上述两前提同时为真的有 16 种，结论违反数为 0。该计数是实跑结果，不能证明任意论域上的定理，也不能保证任何领域材料完备。

## 纸面论证：测试不能代替的部分

**条件健全性（教学重构）。** 给定路径 $`T_0\to T_1\to\cdots\to T_k`$，假设每条边在同一解释中均为真，即 $`T_i\subseteq T_{i+1}`$。任取 $`x\in T_0`$，逐边应用包含得到 $`x\in T_1,\ldots,x\in T_k`$；故 $`T_0\subseteq T_k`$。这对任意论域成立，理由是成员传递而非有限枚举。$`k=0`$ 使用自反包含。

**有限路径检索完备性（不是科学完备性）。** 队列先出长度较小的路径；每个首次发现的节点以一条真实选中边接到已有路径。若存在一条可达路径，沿路径归纳，每个后继节点要么已发现、要么会在前驱出队时入队。有限节点集与每节点至多入队一次保证终止；第一次发现节点时得到最短路径，最后未发现目标说明有限所选图中没有路径。此证明不涉及未提供的事实、其他推理规则或不可证明性。

原文的材料条件并没有由程序兑现：模型既不会发现「全部真实属性」，也不会把调查已结束判作知识已完备。形式路径只是用来暴露这一缺口。
