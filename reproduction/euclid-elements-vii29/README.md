# VII.29：质数若不整除一数，就与它互素

现代正整数教学重构，不是古代实跑或一般定理的计算证明。给定质数 P，且 P 不量度 N。若存在共同非单位公度 D，则 D 量度 P。质数没有非单位的真因数，因此 D=P，又因 D 量度 N，即 P 量度 N，与前提矛盾。程序将候选公度检查单独列出，用最大公度寻找候选；质数判定用整平方根内的试除，测试独立枚举完整正因数集合核对。

- (7,15) 满足前提，没有非单位公度。
- (7,14) 仍给了质数，但 7 量度 14 共两次，故不适用。
- (6,9) 不整除但共享公度 3；(8,15) 同样不整除，却互素。两者的首项均非质数。
- 模型只接受大于 1 的整数；单位不被算作质数，也不作为古文意义的给定「数」。
