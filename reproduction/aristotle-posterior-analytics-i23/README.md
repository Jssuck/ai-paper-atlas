# I.23：共同中项、相邻前提与负结论的最低复现

本附件是原创现代教学重构，对应《后分析篇》I.23完整84b3–85a12。不是古代程序，不认证本质、同属科学、真实原因或直观认识；有限实跑不证明一般无限终止定理。原典及异读定位见[来源台账](../../papers/ancient/aristotle-posterior-analytics-i23.sources.zh-CN.md)。

## 模型与语义

- `strict_closure`对有限有向无环图求严格传递闭包，边`(x,y)`表示教学关系x严格低于y，不自动等同真实因果或本质谓述。循环被拒绝。
- `common_middles`找同时严格在C、D上方并在A下方的词表内节点。端点不能充当新中项。C、D均指向A的三节点叉图没有这种中项；增加另一个节点及相应关系后可以有。没有找到仅对固定词表/关系成立，绝非现实中不存在解释的判决。
- `refinements`只向相邻有序项之间插入严格内部节点。每次增加一个未出现的节点，端点不变；有限n个节点最多组成n项链。所有相邻间隔均无内部节点时才是此模型的饱和链。
- 一条链的内部项数m、相邻命题数m+1、总项数m+2分别记录。只有饱和链的相邻命题才是本模型中直接的。84b20–28的元素/项计数有文本和解释困难，本代码既不宣布解决，也不把其静默改写成现代计数公式。
- 负结论使用有限集合S（主项）、P（谓项）、M（中项）。全称允许空集；特称要求见证。分别核Celarent（S包含于M、M与P不交）、Camestres（P包含于M、S与M不交）的全称否定；Baroco（P包含于M、S减M非空）、Felapton（M与P不交、M包含于S且M非空）、Bocardo（M减P非空、M包含于S）的特称否定。名称及集合语义是教学术语，不是原文逐字形式化或全三段论分类。

## 两个必须保留的反例

1. S={0,1}，P=M={0}满足Baroco的前提，S中1不是P，但0仍是P。因此特称否定不能提升为全称否定。85a8“非全”分支必须另保量词。
2. M为空、S=P={0}时，“M与P不交、M包含于S”都真，却没有S非P的见证。因此Felapton需要额外存在条件；原文未明写不等于现代程序可忽略。
