# Euclid I.14：相邻角和与相反射线的精确教学核验

这不是古代全文形式化，也不是一般定理的计算机证明。程序把普通角解释为两个非零向量之间0至半周内的角，用精确有理坐标、点积、行列式和旋转对乘法检查**异侧且角和等于半周**的输入，再输出两射线相反的比例见证。现代语义、代数恒等式和角范围论证须另行说明，不能归为欧氏原文。

## 使用

在本目录运行：

```sh
python3 run_all.py
```

只用Python标准库，不安装依赖、不联网。运行器依次启动普通、`-O`、`-OO`三组测试与样例，再生成Notebook并用标准库`compile/exec`顺序执行全部代码格。每次运行会覆盖本目录生成日志、结果、Notebook输出和哈希清单。保存的`run-summary.json`记录实际命令、时间、退出码和日志；`environment.json`给出真实环境，不复制旧任务结果。

## 文件

- `geometry.py`：检查两种前提、生成输入绑定证书、验证比例见证；单独的有理周数模型。
- `cases.py`、`test_geometry.py`：确定性正例、证书篡改/输入替换及退化输入回归。
- `run_examples.py`：生成结构化结果；`results-*.json`为真实三模式输出。
- `run_all.py`：运行8条命令并保存环境与日志；测试不使用优化模式可删除的裸assert。
- `teaching.zh-CN.ipynb`：中文六格教学Notebook；`create_notebook.py`可重建，`verify_notebook.py`实际执行并写入输出。
- `WALKTHROUGH.md`：符号、数学条件和反例的中文走查。
- `SHA256SUMS.json`：除自身和缓存外的文件哈希，修改后须重建。

## 边界

1. 两个普通角都严格在0和半周之间，排除共线公共射线及零向量。角量是现代模型，不以180°定义倒置原文证明。
2. `supplementary`由两个独立计算的普通角旋转对之积是否负实给出，**不调用结论的共线检测**。异侧由两个行列式的乘积为负给出。结论另查行列式为零、点积为负，输出正比例因子。
3. 任意有理坐标可输入，不是所有真实几何点均有理，也不是所有有理向量都有理角量。`angle_model`因此是独立示例，不把两模型无条件互换。
4. Notebook真实执行采用共享名字空间的标准库`compile/exec`，没有启动Jupyter kernel、nbclient或浏览器；这不证明所有Notebook前端表现相同。已阅读Notebook技能，当前执行器未找到可用模板助手，以标准库JSON构建且验证结构，不安装技能。
5. 同侧45°+135°给不共线反例，同侧90°+90°给重合而非相反反例。有理周数层另外包含60°+120°，并未用近似根号坐标伪装精确有理输入。
6. 有限通过不证明一般命题、不穷尽所有程序缺陷；证书重算验证也不是独立形式证明内核。

修复记录：独立审查发现Python字典相等会混淆布尔值True与整数1。现使用递归JSON类型校验及规范JSON比较，新增布尔/整数、元组与NaN三项回归；三模式各31测试已重新实跑。

真实统计以`run-summary.json`和`results-normal.json`为准；普通及两个优化模式结果应完全一致。
