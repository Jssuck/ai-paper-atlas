# 《几何原本》V.25：最大量与最小量相加

这是 [V.25 中文精读](../../papers/ancient/euclid-elements-v25.zh-CN.md) 的教学模型。输入是精确正有理数，顺序为 `a,b,c,d`；要求 `a:b ~ c:d` 且 `a` 严格大于两个中间项、`d` 严格小于两个中间项。允许两个中间项相等。无量纲的程序不区分长度和面积，不能验证实数不可公度量或历史文本全部前提。

## 两条核算路线

1. **原证的数值轨迹。** 大段中取走 `c`，另一整段中取走 `d`，余量为 `a-c, b-d`。按 V.19 二余量与原来的比相同；在定义 5 取一次量即可比出左余量较大。两边再各加同一量 `c+d`，所得即原不等式。输入 `12,6,8,4` 的余量是 `4,2`，分别加 `12` 得 `16,14`，差为 `2`。
2. **现代有理数参照。** 设正底量 `d`、尺度 `r=a/b=c/d`、`s=b/d`，则四元组为 `(r*s*d,s*d,r*d,d)`。差为 `(r-1)*(s-1)*d`，两因子都须为正；使其中一因子为零便得到等号。等中间项示例 `9,6,6,4` 的总和差为 `1`，折半即算术平均量比几何平均量多 `1/2`。有理数程序不借助浮点误差判别，也不试图计算所有无理几何平均量。

## 非阿基米德量为何要分开

[Joyce 的导读](https://mathcs.clarku.edu/~djoyce/elements/bookV/propV25.html) 给出无穷小反例。在现代的字典序整数对模型，把四量写作 `(1,5),(1,2),(1,4),(1,0)`，先比较第一坐标，再比较第二坐标。两组比例在倍数不等时同由首坐标比较决定；倍数相等时，左和右的前项均严格大于对应后项。按这个纯倍量比较，两比一致，但极端量之和 `(2,5)` 小于剩余量之和 `(2,6)`。此处被减后的正差首坐标为零，任何有限正整数倍都不能超过首坐标为一的量，而余量分别是 (0,1) 和 (0,2)，单位倍比较已与整量的比较不同；不能在这个模型里调用 V.19。程序检查 144 对倍数只用来验证这份教学算例。
