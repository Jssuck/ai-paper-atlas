# II.19：前提呈现顺序与逻辑后果的最小教学实验

这是 **现代教学重构**，不是亚里士多德的算法，也不是有关受骗、说服或记忆的人类实验。对应《前分析篇》II.19，66a25–66b3：[Jenkinson 1913 英译，Book II 第 19 节](https://en.wikisource.org/wiki/The_Works_of_Aristotle/Prior_Analytics/Book_II)。Owen 1853 印页 221–222 的章 XIX 可作对读。原文提出警惕重复中项、暂不说出前置推论的结论、打散相连前提的询问次序；本实验仅抽取第三点的全称肯定链例子。译词及历史语境以正文和来源表为准。

## 模型和边界

`(S,P)` 表示“所有 S 都是 P”，即集合包含 S⊆P。五条边为 B→A、C→B、D→C、E→D、F→E；目标是 F→A。`closure` 返回所有不同词项之间的可达对，包括已有前提，不计自反式。集合包含本来满足自反性；排除自反输出只是统计约定。允许空类，无存在承诺；否定、特称、模态及三格的完整历史语义不在模型内。

原文给出询问 AB、DE、BC 的前缀。代码 `SEPARATED` 采用 BA、ED、CB、FE、DC：**第四、第五步是为完成同一组五条边而作的现代补齐**，并非逐字原文。方向始终按主词→谓词存储。

- `witness` 用广度优先搜索给出最短证书，排序仅用于稳定输出。
- `profile` 计算相邻两条前提是否共享任一词项及每个前缀的非自反闭包大小。它不判别“真正的中项”，也不测量难度或欺骗效果。
- 重复词不充分：B⊆A、B⊆C 不推出 A⊆C 或 C⊆A。非空反模型为 B={0}、A={0,1}、C={0,2}。
- 不显示中间结论不等于中间结论不能推得；代码计算的是可推后果，而非受问者实际上注意到什么。

## 一般论证与有限测试的分工

全称肯定包含模型中，一条从 S 到 P 的路径由包含传递性保证 S⊆P。反过来，若没有该路径且 S≠P，可令一个元素属于 S 及 S 可达的所有词项，不属于其余词项：每条前提仍成立而该元素不属于 P。这是该模型下“可达当且仅当语义蕴涵”的反模型证明；测试枚举不是一般证明。前提的排列不改变边集，故不改变最终可达性；前缀边集不同则可能改变中途闭包。

## 实际运行

无第三方依赖。运行：

```sh
cd reproduction/aristotle-prior-analytics-ii19
sh run.sh
sha256sum -c SHA256SUMS
```

`run.sh` 实际分别调用 `python3`、`python3 -O`、`python3 -OO` 运行 `unittest` 和主程序，并用 `cmp` 比较 JSON。检查不用会被优化删掉的 Python `assert` 语句；单元测试使用 `unittest` 断言。环境在 `results/environment.txt`，三组原始测试输出在 `results/tests-{normal,O,OO}.log`，三组结果在 `results/output-{normal,O,OO}.json`，比较证据在 `results/verification.txt`。日志中的运行耗时可能因机器而不同，不应期望新跑测试日志哈希与存档相同。

已实跑 8 个测试方法：包含 120 个排列、64 个三词有向图的 384 个非自反查询与 8 种单元素成员赋值语义的交叉核查；还检查错误输入、生成器、重复前提、环、未知词、空图、最短证书、共享词反例。64 图语义枚举只是有限交叉检查，并不取代上述证明。

| 顺序 | 前缀闭包大小（含已有前提） | 相邻共享词对数 | 最终 F→A |
|---|---|---:|---|
| BA, CB, DC, ED, FE | 1, 3, 6, 10, 15 | 4 | 成立 |
| BA, ED, CB, FE, DC | 1, 2, 4, 6, 15 | 0 | 成立 |

120 个排列的最终闭包均含 15 对，均推出 F→A；所有排列中目标都只在第五条前提进入后才可推出。相邻共享词对数为 0、1、2、3、4 的排列分别有 14、40、48、16、2 个。只有一个中项的两条链前提，在两种顺序下闭包均为 3；这个粗指标没有重现原文对单中项情形的实际辩论效果，也不能证成或证伪该经验性建议。

## 复盘

这不是“打散次序使有效推理失效”：它只展示同一最终逻辑结构可以具有不同的中途呈现。零相邻共享词仍然可以在全局反复使用中项。把局部邻接数误当全局联系、把可推导误当被察觉、或把重复词误当有效格，都会错误扩大实验结论。

初次测试曾把第二种顺序的相邻共享词对数预期误写为 1；实际逐对检查为 0，已纠正预期并重跑三模式。最终日志记录修正后的真实成功运行，而不是把失败描述成成功。

## 独立技术交叉核验

独立审查者另写 `audit/independent_oracle.py`，不复用被测代码的遍历算法来计算期望值。真实三模式输出在 `audit/oracle-{normal,O,OO}.log`：4 词的 4096 个有向图、49152 个非自反查询及路径证书核查，以及 120 排列的 600 个前缀均通过。其检查使用显式异常，不受优化删除。复跑命令：

```sh
python3 audit/independent_oracle.py
python3 -O audit/independent_oracle.py
python3 -OO audit/independent_oracle.py
```

这增加的是该有限模型的独立实现一致性证据，不是关于所有历史三段论或实际人类心理的实验验证。
