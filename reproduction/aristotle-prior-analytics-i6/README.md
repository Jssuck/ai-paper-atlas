# 第三格：同一个中项成员怎样成为结论的见证

这是《前分析篇》I.6的现代集合教学模型，不是古代原算法、完整《工具论》形式化或现代AI效果测试。

## 运行

仅需 Python 3 的标准库。进入本目录运行：

```sh
python run_verification.py
```

脚本真实执行 normal、`-O`、`-OO` 三种模式的30项单元测试，比较完整分类报告，在 `logs/` 保存真实标准输出及环境摘要。没有使用 Jupyter 内核、第三方求解器或网络服务；不声称Notebook验收。最新结果见 [核验记录](logs/verification.json)、[完整分类](REPORT.md)和[JSON报告](report.json)。各运行耗时属实际运行记录，不保证重复执行时相同。

## 固定方向，不随自然语言阅读习惯颠倒

- 主前提：Q(M,P)。例如 A 表示每一个 M 都是 P。
- 次前提：R(M,S)。例如 I 表示至少一个 M 是 S。
- 结论：C(S,P)，不是 C(P,S)。
- A：X 是 Y 的子集；E：X 与 Y 的交集为空；I：交集非空；O：X 中存在不属于 Y 的对象。

A、E采用允许空主项的现代全称语义。存在要求由独立策略表达，不偷偷塞进全称命题中。所有策略的论域都非空：

| 策略 | 额外条件 | 支持数 |
|---|---|---|
| allow-empty | P、S、M均可为空 | 255 |
| middle-nonempty | 只强制 M 非空 | 240 |
| all-nonempty | P、S、M分别非空 | 218 |

把 M 非空和所有项非空分开，是为了显示 Darapti/Felapton 真正需要的见证条件，而不是把一个较强政策误称最弱条件。三种策略均不替代原典的历史解释。

## 八类型与一般压缩论证

每个对象按是否属于 P、S、M 得到三位标签。P位为4，S位为2，M位为1。例如类型3（二进制011）属于S与M而不属于P，类型7属于三项，类型0属于论域而不属于任何项。一个支持是实际出现的标签的非空集合，每种标签仅留一个代表。

对于任意原模型，不论有限或无限，一个对象是否在X∩Y或X\Y仅取决于标签。因此这些区域在原模型非空，当且仅当支持中有相应标签。I、O的真假保持，作为其否定的E、A也保持；每一项的非空条件同理保持。反过来，任何非空支持都能实现为一个有限模型，以标签本身作为对象。故本语言及指定存在条件下，有反模型就必有最多8个对象的支持反模型。这是对任意模型的数学证明，不是从255次实验外推出来的断言。

`countermodel`依对象数递增枚举支持，再按字典序取首项。任意具有n个对象的模型至多出现n种标签；压缩不会增加对象数。结合上面的保持性，首次找到的支持大小等于本语义下最小反模型的对象数。它不计算自然语言反例的最简单程度，不枚举无限对象的数值属性。

## 六条见证路线

后世名称只作索引，不署给原章。

| 名称 | 主、次、结论 | 见证如何取得 | 必要的额外存在条件 |
|---|---|---|---|
| Darapti | AAI | 从M取一员；主前提给P，次前提给S | M非空 |
| Felapton | EAO | 从M取一员；主前提给非P，次前提给S | M非空 |
| Disamis | IAI | 主前提给M且P的同一员；次前提给S | 无，I已给见证 |
| Datisi | AII | 次前提给M且S的同一员；主前提给P | 无，I已给见证 |
| Bocardo | OAO | 主前提给M且非P的同一员；次前提给S | 无，O已给见证 |
| Ferison | EIO | 次前提给M且S的同一员；主前提给非P | 无，I已给见证 |

`proof_witness`不随机各取一个人拼凑结论，而是返回贯穿两前提的同一成员标签。它是六条现代见证路线的实现，不是一般形式证明核。Darapti/Felapton在M为空时拒绝执行；反例见走查。

## 测试范围与局限

30个测试方法覆盖：三策略完整分类、192个前提对/结论/策略组合、所有找到反模型的真假与最小性、六路线的全部满足前提支持、独立集合语义对照、A/O与E/I矛盾对、E/I换位、P/S置换、压缩及重复对象、方向错误、不同见证陷阱和非法输入。

全项非空下恰有六种有效的前提对及结论；允许空项时只有四种。其余10种前提对没有任何A/E/I/O结论，但不是“前提不可能同时为真”。报告为每个无效结论给独立反模型。某条前提对的四个否定结论不应强求由同一个反模型同时满足，因A/O及E/I互为矛盾。

程序不含模态逻辑、时间、关系谓词、概率、因果或真实学习实验。有限测试不证明软件无缺陷，不代替上述一般数学论证，也不验证作者一切历史命题。
