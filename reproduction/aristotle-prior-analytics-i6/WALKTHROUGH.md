# 从见证到反模型：六个手算练习

所有例子均是现代教学重构。一个类型值代表一个对象，不是对象数量。类型位依次为P=4、S=2、M=1。

## 1. Darapti的缺项不是代数变形，而是存在

取支持(7)：唯一对象同时属于M、P、S。两条全称前提成立，也就有一个S属于P。改成(0)：M、P、S均空，两条全称仍真，但不存在S与P的共同对象。故AAI需要M非空。改成(6)：P和S非空但M为空，仍能使结论真；这说明M非空是保证所有模型有效的附加条件，而非每个结论真的模型都必须满足的条件。

更强的反例(2,4)中S与P各有一员且不相交，M为空；即便P、S非空，AAI仍不能成立。不能只检查外项存在。

## 2. Felapton不能从空中项取一个“它”

取(3,4)：类型3在M与S内且不在P内，类型4使P非空。M与P互斥、每个M都是S，类型3直接见证有S不是P。支持(6)则M为空、P=S非空，两前提仍真却没有S不是P，因此真正承载推理的是M成员。

## 3. Disamis与Datisi从不同前提获得见证

支持(3,7)满足“有M是P”和“每个M是S”。Disamis必须选类型7，不能选类型3后再另外找一个P。

支持(5,7)满足“每个M是P”和“有M是S”。Datisi从次前提选类型7。它不要求每个M都在S中，类型5正好表明该要求过强。

## 4. Bocardo与Ferison保持否定方向

支持(3,7)满足“有M不是P”和“每个M是S”，类型3见证有S不是P。但每个P都是S，因此“有P不是S”反而为假。这直接显示O不能简单换位。

支持(3,4)满足“没有M是P”和“有M是S”，Ferison仍由类型3给出有S不是P。此时不是先把O换位得到结论，而是把同一见证的成员信息合并。

## 5. 两个特称见证可以彼此不同

支持(3,5)中有M是P（类型5），也有M是S（类型3），但没有S是P。II不推出I。另取(7)又可满足II而使E为假。存在各自的反模型，说明II不保证I或E；不能把“没有必然结论”误读为“所有结论都假”。

## 6. 为什么即使有效式也不推出全称结论

AA前提在(2,7)中成立：所有M都为P和S，但类型2是S而不是P。所以结论只能保障某个S是P，不保障所有S是P。中项提供共同成员，不限制S在M之外的成员。

## 运行时核对

```python
from third_figure import premises, truth, proof_witness, countermodel
assert premises('O', 'A', (3,7))
assert proof_witness('Bocardo', (3,7)) == 3
assert truth('O', 'S', 'P', (3,7))
assert not truth('O', 'P', 'S', (3,7))
print(countermodel('I', 'I', 'I', 'all-nonempty'))
```

最后返回的支持按“最少对象数，然后类型字典序”决定。对结果逐一展开三项集合即可复核，不必相信式名或代码。
