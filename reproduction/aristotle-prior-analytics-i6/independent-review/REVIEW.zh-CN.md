# 第三格教学代码独立审计

结论：**PASS（有界范围）**。本报告核查现代集合教学模型，不认证全部古代文本解释，也不声称软件无缺陷。

## 独立性与方法

被审模型把每个对象编码为三位整数。审计器没有调用模型的位运算真假函数来制造期望答案，而是另建八种标签的显式成员清单，将其转为 Python 集合，以包含、交集和差集运算解释 A/E/I/O。期待反模型按所有支持的基数及字典序独立寻找，不复用作者的支持筛选或 `countermodel` 结果。

`audit_third_figure.py` 用显式抛出异常的检查器，而非可被优化移除的 `assert`。因此三种解释器模式都实际执行检查。作者单元测试也分别重新运行，不沿用已有日志作为新执行证据。

## 实际执行

在本复现目录运行：

```sh
python independent-review/run_review.py
```

该命令分别以普通、`-O`、`-OO` 模式运行作者的30个测试方法和独立审计器，共6次子进程，退出码全部为0。真实输出见本目录的 `author-*.log`、`independent-*.log` 与 `results-*.json`；环境摘要和逐次退出码见 [verification.json](verification.json)。三个独立 JSON 结果字节相同。

每个模式实际完成34,129次独立检查，含：

| 项目 | 每模式数量 | 检查意义 |
|---|---:|---|
| 全部支持、任意两项及四量词的集合真假 | 9,180 | 检查位编码实现与独立集合解释相同 |
| 存在策略判定 | 765 | 空项允许、仅M非空、全项非空 |
| 完整后承查询 | 192 | 三策略×16前提对×4结论 |
| 最小反模型比对 | 192 | 有效时均为None，无效时须等于独立首个反例 |
| 已找到反模型的前提/结论及基数最小性 | 各176 | 逐一检查，并排除所有更小支持 |
| 合法六式共享见证 | 160 | 返回的同一对象必须属于M、S且具有正确P极性 |
| 不满足路线前提的拒绝 | 1,370 | 不把不适用的输入冒充有效证明 |
| 最多3对象序列压缩保真 | 21,024 | 584个有序序列×任意两项×四量词 |
| 非法输入 | 125 | 支持、量词、项、策略、对象行、式名 |

此外核对三类支持的排序、展开、压缩和重复对象消除。完整逐项计数以机器结果为准；表中某些总检查类别有进一步拆分，不能把表中小项再次相加当作额外实验。

## 结果与语义边界

- 支持数为255、240、218。论域始终非空，空项政策不是空论域政策。
- 允许空项时恰有四个有效式；M非空或三项全非空时均为六式。AAI和EAO对空中项无效。
- 任何策略都不产生固定方向的全称结论。所有前提对均有模型，不靠不相容前提的空真后承计为有效。
- 176个无效查询各得到反模型；其最小性是这个三一元谓词语言中的对象数最小性，不是自然语言反例的认知难度最小。
- 路线函数返回一个共享成员标签，只是六个固定教学规则的实现，不是通用证明核。

一般的八类型压缩论证见复现README和正文。独立有限遍历检查实现是否符合该论证，但不能由“有限程序通过”替代一般证明，也不覆盖计数、关系谓词、模态与时态语言。

## 故障注入

真实临时替换实现中的函数并运行独立探针，共检出11种预设故障：A方向颠倒、O方向颠倒、E误作I、I误作A、A偷偷引入存在、O强读为“有些是且有些不是”、忽略存在政策、把全项非空降为仅M非空、总取第一个见证、总返错误极性见证、压缩抹去所有成员关系。

故障测试在 `finally` 中恢复原函数并清空相应缓存；没有把变异代码写回模型文件。检出这11种预设错误不等于检出所有可能软件缺陷。每模式的实际故障名称保存在结果JSON中。

## 输入与隐私检查

空支持、重复类型、布尔或浮点伪整数、越界类型、未知量词/项/策略、错误对象行和未知式名均按有界测试范围拒绝。审计接受TypeError或ValueError，不承诺所有接口在所有不合法对象上给出同一异常类型；Python缓存包装器可先拒绝不可哈希参数。

运行命令以可移植相对形式记录；环境摘要只含Python版本、实现、系统及架构，不包含用户名、主目录、主机名、账户、环境变量或秘密。源码通过运行时相对位置加载模型，不保存本机的绝对路径。当前成功日志没有异常堆栈或私人文件路径。
