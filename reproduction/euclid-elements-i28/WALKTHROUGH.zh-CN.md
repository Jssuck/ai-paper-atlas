# I.28 的现代精确模型与边界

## 原文与现代实现

原文把两种给定角关系化为 I.27 的内错角条件：第一案借 I.15 对顶角，第二案借 I.13 邻角和与相等量消去。本附件不编码这套古代公理推演，而使用现代二维内积模型。特别是坐标模型本来就具有欧氏平行结构，不能用这次运行证明平行公设独立性，或宣称 I.29 已由 I.28 在原书体系中推出。

## 一般模型推导

记 t=F−E、u=B−E、v=D−F，h=cross(t,u)、j=cross(t,v)。严格同侧 h*j>0 既保证 t、u、v非零，也排除角0或π和重合直线。定义 K(p,q)=dot(p,q)/|cross(p,q)|。这是普通角在(0,π)中的cot值；保留符号，且在该区间一一对应。无须计算任何反三角函数。

对应角案的指标是 K(−t,u)=−dot(t,u)/|h| 与 K(−t,v)=−dot(t,v)/|j|。相等直接给出 dot(t,u)/|h|=dot(t,v)/|j|。

同侧内角案的指标是 K(t,u) 与 K(−t,v)。两角互补当且仅当这两个指标互为相反数，因为 cot(π−θ)=−cotθ 且cot在(0,π)中单射。注意不是“cot值相加等于角值相加”。于是仍得到相同比值等式。

取 n=(-t_y,t_x)。u、v在基(t,n)中的系数分别为 a=dot(t,u)/dot(t,t)、b=h/dot(t,t) 与 c=dot(t,v)/dot(t,t)、d=j/dot(t,t)。同侧令b,d同号，比值等式推出a/b=c/d。因此v=(d/b)u，比例d/b>0。程序独立复核cross(u,v)=0、正比例和两坐标等式。

假设两条直线相交，则存在r,s使 E+r*u=F+s*v，因而t=(r−s*d/b)u，与cross(t,u)≠0矛盾。因此它们是不同且不相交的共面直线。这是一般代数论证；672次计算只检查有限输入实现，不取代论证。

## 手算

E=(0,0)、F=(2,0)、B=(1,1)、D=(3,1)。t=(2,0)、u=v=(1,1)，h=j=2。隐式G=(-2,0)。对应角GEB和EFD都是135度，指标[-1,-1]；同侧内角BEF和EFD为45度、135度，指标[1,-1]。比例为1，方向行列式为0，横截偏移非零，所以两条无限直线不重合而平行。

## 反例与失败条件

1. **只保留角数值、丢弃同侧位置**：把D改为(3,-1)。对应角GEB和EFD仍都是135度，同侧式所比较的两个数值仍为45度与135度，但B与D处于截线异侧。两线 y=x 与 y=−x+2 在(1,1)相交。两分支均必须在角检查前拒绝此配置。
2. **平方余弦混淆**：把D改为(1,1)，同侧仍成立；对应角一个135度，一个45度，平方余弦相等却角不等。内角和则为90度而非180度。有符号指标拒绝。
3. **近似平行不是平行**：D=(3000001/1000000,1)使方向有极小但非零差别。精确分数拒绝，不用容差。
4. **退化**：E=F、B=E或FD落在EF上均没有命题要求的两个严格角和横截结构。
5. **输入来源**：即使证书内部哈希正确，只要调用者期望输入不同、case不同，都必须拒绝。

## 复盘练习（含答案）

- 为什么要求同侧而不仅要求h、j非零？答：同侧把两个无向角的相等转成同一正比例方向；反例1表明去掉此项会把相交直线误认作平行。
- h、j同时变号会破坏结论吗？答：不会，整体反射仍保持同侧，绝对值角指标不变，比例仍正。
- 代码为什么还要检查偏移非零？答：平行方向不足以区分两条不同平行线和重合线；h≠0已经提供偏移证据。
- 运行成功能否证明所有古代几何模型都成立？答：不能。它只核查声明的有理二维模型，原书证明及其公理依赖需要单独阅读。
