## 构造与对照

- 总底长 L，缺块底 t，固定缺块的高宽系数 r 和水平偏移系数；故共同垂直高为 r·t。应用部分底为 L−t。用实际斜形坐标及鞋带公式核对面积 r·t·(L−t)；缺块面积为 r·t²。取 L=10、r=2 时，t=2、5、8 的应用面积为 32、50、32。
- 令 m=L/2，令 d=|t−m|。将各形状作同样的剪切以对齐共同方向后，可将面积差解作两条带面积之差：上条宽 m、高 r·d，边条宽 d、高 r·(m−d)。前者减后者剩角块 d×(r·d)。t=2 或 8 的两条带面积为 30、12，净损失 18。t>m 时先在现代模型交换 t 与 L−t，它们的应用面积相等。上条与边条的计算是现代等面积示范，不冒充原文各图块的命名或拆分。
- 405 个精确配置：3 种总底 × 3 个 r × 5 种切分比例 × 3 种偏斜 × 3 种旋转。分别检查面积、对称、损失、中点与缺块平方缩放的比例，拒绝非正高度系数和不在内部的切分。计算未使用浮点容差。
- 仅知道面积相等不能确保缺块同形：2×4 和 8×1 的面积同为 8，但长宽比不同。若去掉同形约束，应用部分底 8、高 7 时面积 56 大于固定 r=2 的中点面积 50。这不反驳 VI.27，而是另一个问题。
