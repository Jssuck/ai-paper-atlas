# 《几何原本》X.16：部分与整体的不可公度

令 `P,R>0` 是两个部分，`W=P+R` 是整体。教学模型用精确对 `(a,b)` 表示 `a+b√2`，只接收整数或 `Fraction` 系数。确定长度为正后，用两组系数的行列式是否非零来判断长度比是否无理。`analyze(part,remainder)` 返回整体的系数对和三个布尔值，依次对应 `P:R,P:W,R:W`，真表示不可公度。它不判定任意实长度，也不复现附列引理。

例如 `P=1+√2`、`R=2−√2`，整体为有理长度 3，三个比较仍都不可公度。反例控制：`2√2,3√2,5√2` 三个长度各自无理，但三个比例均有理，所以三对都可公度。无理性与不可公度不应混为一谈。

独立校验先用 `7/5<√2<10/7` 的有理区间筛出所有网格上的正长度，再通过乘共轭、除以分母的范数来提取比值中的根式系数。两条判别路径在 `−4..4` 的整数系数网格上相符：40 个正长度形成 1,600 个有序部分对，其中 1,504 对的三个比较均不可公度，96 对均可公度。有限校验不是一般性证明。
