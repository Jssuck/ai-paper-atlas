# 卷 IV 命题 7：外接正方形的精确教学复现

[返回中文深读](../../papers/ancient/euclid-elements-iv7.zh-CN.md)。

给定圆心 O 与非零半径向量 u，在法向量依次为 u、Ju、−u、−Ju 的四个点作切线。每个顶点由一对相邻切线的二元方程求得；程序用 Cramer 法则和 Python 标准库的 Fraction，不需要平方根、不用浮点误差容限。坐标只接受 int（不含布尔值）或 Fraction。输入不是仅有数值半径，还须给出半径向量来选定朝向。

输出逆时针排列，从 u 与 Ju 两条切线的交点起。验算按这一序列检查四边平方长、相邻边点积、对角线平方长、正的有向面积、切点是边中点、半径与边垂直，并用行列式重算圆心到实际边所在直线的距离。它不是对所有顶点排列都接受的无序正方形识别器。

主例以 (1/2, −1/3) 为圆心，半径向量为 (2, 1)，半径平方为 5，边长平方为 20，对角线平方为 40，面积为 20。负对照取圆心 (0, 0)、两条不垂直半径 (5, 0) 和 (3, 4)，另取两相反向量：四边平方长均为 625/4，但相邻有向边点积依次为 −375/4、375/4、−375/4、375/4。这是外切菱形，不是正方形。零半径、平行法向或不等长半径向量会被拒绝。
