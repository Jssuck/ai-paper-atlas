# 《后分析篇》II.2：有限中项搜索与反模型

这不是古代天文学、音乐学实验或亚里士多德完整知识论的复现。它是与[原创深读](../../papers/ancient/aristotle-posterior-analytics-ii2.zh-CN.md)配套的现代教学重构，旨在显出“找到形式中项”与“知道原因”的距离。

原文依据为完整89b36–90a34，实读[Boyer希英对读](https://aristotle.johnhboyer.com/APo/book/2/#ch-2-2)。原文90a6–11把所求原因与中项关联；90a15–23用月食与和谐讨论本质和原因；90a24–30讨论感知中项。这些论述激发模型，但原文没有本程序的集合搜索、计数定理、未知值语义或音比白名单。此处只核查属性推理的一个有限切片，**不把实体存在问题还原成空项处理**。

## 假设与一般论证

`U` 是有限域，演示中是整数0、1、2。`C,M,A` 是其子集；`C` 为被说明的主项外延，`M` 为候选中项外延，`A` 为谓词外延。所有数据是手工构造，不是采集数据。

1. 外延证书要求 `C ⊆ M ⊆ A`。任取 `x∈C`，由第一包含关系有 `x∈M`，再由第二关系有 `x∈A`，故 `C⊆A`。这是任意集合上的证明，不以512例枚举代替一般证明。
2. 若 `C⊈A`，存在 `x∈C\A`，任何M都无法同时满足两包含关系，候选为0。
3. 若 `C⊆A`，M必须包含C、不能含A外元素，其余只能自由选择A\C内元素。M与A\C的子集通过 `M=C∪S` 一一对应，所以候选数为 `2**len(A-C)`。模型枚举U全部子集，不表示科学上所有候选原因都已列出。
4. C为空时也能有形式证书，但不提供任何存在见证。统计另列非空C；不要由空真断言自然对象存在。
5. 即使M唯一，唯一的是该模型的一种外延，不是唯一解释或真实原因。不同描述可以在当前域共外延；代码根本没有因果认证字段。

## 算例与反例

- `U={0,1,2}, C={0}, A={0,1}` 有M=`{0}`与`{0,1}`。问题“有无候选”和“候选是哪一个”不同，且两者都未解决真实原因。
- 仅完整观察点0，得到M(0)、A(0)，其余点未知。每个未知点有四种(M,A)赋值；两点共16种扩展，其中每点三种满足蕴涵，所以9种满足 `M⊆A`，7种不满足。一个反例是 `M={0,1}, A={0}`。`completions`严格区分未观察与观察为否；观察集内的标签必须完整。
- 观察全域只能得到该有限域的外延结论，仍不能认证因果，也不能不加条件推广到域外。这不否认原文赋予感知的作用，而是明确现代模型没有自动给出通向科学普遍性的桥梁。
- `ratio_in_palette`对正整数计算准确的 `Fraction`，再核对作者**任意声明的教学白名单** `{2:1,3:2,4:3}`。440/220与330/220在内，221/220虽为有理数却不在内。白名单不是原文完整音律表，非听感判决，也非现代声学定律；不采用“有理数比即和谐”的过强实现。

## 测试覆盖和限制

覆盖有效链、两种前提各自失效、候选数0/1/2、空项和空域、越界元素、观察为否与未知、完整观察、错误样本标签、约分、有理非白名单、数比类型／符号检查和全枚举。输入对象按可排序的有限元素集合使用，演示统一整数；不提供任意无限域计算。

枚举成本指数增长：全部三元组为 `8**len(U)`，示例仅三点。`exhaustive_summary`把教学域大小限制在0至5；通用`powerset`函数不作为大规模生产搜索服务。没有训练数据、学习基线、预测指标或现代因果识别结论。本篇性质以数学证明重建和反模型教学为主，不为不存在的经验实验编造指标。

## 带答案练习

1. C={0}、A={0,1,2}有几个M？4个，两个自由元素各有两种选择。
2. 仅看0，U扩至四点，兼容扩展多少，普遍式真多少？64和27。
3. 若M1、M2同外延但描述不同，能自动认定同一个原因吗？不能；外延数据没有提供该判断依据。
4. 观察全域与证明原因一样吗？不是，有限全域覆盖仍只是外延信息。
5. 为什么不从测试全部通过宣布II.2理论获证？测试核验自设实现；一般包含定理由独立论证给出，古代知识论及科学解释还涉及模型以外的前提。
