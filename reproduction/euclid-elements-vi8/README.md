# 《几何原本》VI.8：高分出的两个相似三角形

对应[中文深读](../../papers/ancient/euclid-elements-vi8.zh-CN.md)。这是现代坐标教学模型，不是古代完整尺规构造的程序复原。全部输入为整数或有理数，无额外依赖。

从 A 向直线 BC 作正交投影得到 D。程序先检查 A 是非退化的直角顶点，再确认 D 严格落在 BC 内。在对齐顶点次序的 ABC、DBA、DAC 中，每一对三角形分别检查三对角、三条对应边的同比，不预先将“相似”当作输入。角用余弦平方及点积符号比较，避免混淆锐角与钝角；边长为正，故可比较平方后的比例，完全避免开方。三个平均比例恒等式 AD² = BD·DC、AB² = BC·BD、AC² = BC·DC 也以等式两端的平方精确比较。

正例 A=(0,0)、B=(15,0)、C=(0,20) 给 D=(48/5,36/5)，BD、AD、DC 分别为 9、12、16。反例 A=(0,0)、B=(3,0)、C=(2,4) 虽也有内部垂足 D=(48/17,12/17)，却有 AD²=144/17、BD·DC=42/17。这里撤掉的是 A 处直角，而不是垂直投影要求。

## 实际运行

在本目录用 Python 3.12.14 执行：

```sh
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B replay_notebook.py
```

[普通](normal.log)、[-O](O.log)、[-OO](OO.log) 各有七项测试。每次扫掠三处原点、四个轴向量、每条直角边三种正尺度及双取向，共 216 个构形（108 个反射方向），各检查三对相似及三个恒等式，共 648 相似对、648 恒等式核对；另外还有数值正反例、等腰与交换顶点、角符号及非法输入测试。构形由正交轴生成，检测使用坐标投影与余弦、平方长度，不是独立的古典证明。有限样本不代表任意实数坐标。

[Notebook](euclid-vi8.ipynb) 的三个代码格用标准库共享命名空间编译并执行，见[回放日志](notebook-replay.log)。未启动 Jupyter 内核；文件保留未执行状态，读者也可在 Notebook 环境从头运行。
