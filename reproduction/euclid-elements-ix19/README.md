# 《几何原本》IX.19：给定三项，求第四比例项

正整数教学重构。对有序 $`(A,B,C)`$，程序记录是否连比、端点是否互素，并对 $`BC`$ 除以 $`A`$：余数为零时，整数商 $`D`$ 是 $`A:B=C:D`$ 的唯一正整数见证。两项标记用于比较原文四类，并不代替整除检查。另记录原文设想的辅助量 $`E=C^2/A`$；它不是这一判据的额外前提；即使有理候选 D 不是整数，此字段也只记录有理数，不表示存在一对整数解。$`A,B,C=(2,4,3)`$ 就有 $`D=6`$，但 $`E=9/2`$，不能无条件当成整数。给定项的单位边界由现代接口接受；非单位接口仅限制给定三项，若得到单位见证也按现代算术解释。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线在给定项各取 2 至 18 时，用重复加 $`A`$ 检查是否恰好到达 $`BC`$，至超过即退出；因 $`A\ge1`$，至多 $`BC`$ 步。四类分别计数，有限核验不替代一般证明。Notebook 日志记录标准库实际回放三个代码单元，并未启动 Jupyter 内核。
