# IX.19 原典核对

- [Heath 1908 英译卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)：印页 409–410（扫描 422–423）保留四种情况。409 页用 IX.17 排除「连比、首尾互素」，再以双匕号标出「不连比、首尾互素」的有缺陷论证；该段在 410 页开头结束。410 页后半给出两个首尾不互素情形的整除检验，最后一支简述同理。印页 411–412（扫描 424–425）是译注，与正文区分：Heath 认为坏段有文本讹乱，说明该论证仅排除了辅助第四比例项；另记述删去坏段且改为两类的 Theon 路线，不据此断定哪个是作者原稿。411 页印出的 4、6、9 本身是连比，第四项为 27/2，不能直接充当「不连比、首尾互素而第四项为整数」的反例。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=269)：正文印页 269–270；题后结论的校勘说明从 270 页延续至 271 页。正文保留四类与有缺陷的推理，其现代脚注指出需要区分第四项的存在与辅助比例的可解性；肯定构造旁注引 VII.19。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.19.html)：希文完整到末一支的「同理」与证毕；英译保留错误段、用星号式符号标出，末一支仅给到令 B 与 C 相乘成 D，未收录希文末句。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX19.html)压缩为题目与方括编辑说明，不把现代判据冒充逐字正文；其 Guide 推导的是第四项，末尾的 “third proportional” 与前述方程不符。
- 错误段中，D 是待求第四项、E 是额外假定的辅助项，[VII.14](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII14.html) 的比例合并形式本身有效；错误在未证明辅助项也是「数」。后续有效段重新使用字母：D 是乘积 BC，E 是商与第四项。因此不能跨段把字母角色固定不变。两个方向的判据见 [VII.19](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII19.html)。本文使用明确反例，而不猜测 Heath 数例的原意。
