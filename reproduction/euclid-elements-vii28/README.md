# VII.28：和与两个加数的互素性

现代整数教学重构，不是古代实跑记录或一般命题的计算证明。若非单位公度 D 量度 A、B 各 i、j 次，它量度 A+B 共 i+j 次。若 D 量度 A 和 A+B，则按量度次数相减，D 也量度 B；交换加数同理。把两方向合看可得三个公因数集合相同，进而最大公度相同，这是本重构明确检查的现代推论。

(8,15) 的和为 23，(5,7) 的和为 12；尽管后一个和是合数，它仍与两个加数分别互素。(6,9) 的和为 15，三对都共享公因数 3；D=3 的次数按正向、两个反向分别是 5、3、2。仅量度一个加数不够，例如 2 量度 8 却不量度 23。给定数限定为大于 1，次数允许为 1；单位输入的现代情况另有测试，不把单位当作古文给定的「数」。
