# Euclid I.12 最小精确教学复现

本附件是原创现代坐标教学重构，不是古代尺规步骤的完整机械实现，也不把有限测试当一般定理的证明。原典位置：Fitzpatrick 2008《Elements》第一卷命题12，印17–18页；原文取异侧点 D，以 C 为圆心、CD 为半径作圆，在原直线上得 E、G，再依 I.10 平分 EG 得 H，依 I.8 及定义10论证 CH 垂直。这里直接解圆线二次方程并取算术中点，不声称重跑 I.10 的尺规子程序。

## 覆盖与边界

- 输入 A、B、C、D 均为有理坐标，A≠B、C 不在线上、D 严格位于 C 的异侧。
- 用分数及单一二次扩域 `a+b*sqrt(delta)` 精确计算交点，不使用浮点几何判断或数值容差。完全平方有理根归约为有理数。
- 同一构造内可处理任意正有理 delta；不同非平方 radicand 的表达不自动约分或互转，例如 `sqrt(8)` 与 `2*sqrt(2)` 不作跨表示识别。证书须使用同一扩域表示，不能把表达式拒绝解释成几何否定。
- 对任意真实数坐标、一般代数数与任意尺规表达树不提供覆盖；未形式化欧几里得几何公理、连续性或原文历史归属。
- 认证的是本次给定 A/B/C/D 的异侧构造，而不只认证“垂直”结论。同侧 D 有时也可产生割线，但不属于此输入约定。

## 命令及真实结果

在本目录运行，无需安装第三方依赖：

```bash
python run_all.py
```

该命令真实启动普通、`-O`、`-OO` 三种模式的测试及算例，然后创建并顺序执行 Notebook。日志、环境和命令记录分别见 `logs/`、`environment.json`、`run-summary.json`。

本次三模式各 **28 项测试、648 个正证书、16 个负证书** 通过，结果逐字结构一致。Notebook 的 **6 个代码格** 由标准库 `compile/exec` 在共享命名空间执行，**不是 Jupyter kernel 记录**；未验证 Notebook 浏览器显示。`notebook-check.json` 和 Notebook metadata 均标明此边界。

## 文件说明

- `geometry.py`：有理数/二次扩域、圆线交点构造、输入绑定证书检查器。
- `cases.py`：3个原点 × 4个方向 × 3个沿线位置 × 3个高度 × 3个辅助点偏移 × 2个深度，共648正例；另16负例。
- `test_geometry.py`：精确算术、几何、输入边界与篡改测试。
- `run_examples.py`：有限数据族与可复核示例。
- `teaching.zh-CN.ipynb`：六步短教学与已执行输出。
- `verify_notebook.py`：透明标准库执行器，不模拟 kernel 状态。
- `SHA256SUMS.json`：除自身和缓存外的文件哈希；核验报告新增后应刷新清单。

## 核验不是证明

检查器核对圆心与 C 绑定、半径平方与 CD 绑定、两交点在线上及指定圆上、交点相异、中点、严格介于、半弦相等、CH 非零、三角形非退化和现代点积垂直。最后一项是现代坐标校验，不应回写成欧几里得使用点积。

一般数学解释与原文证据请看正文；有限枚举只表明这些输入及程序路径没有暴露特定错误。
