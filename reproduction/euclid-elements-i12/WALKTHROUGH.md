# I.12 逐步走查与练习

## 1. 在坐标里重建圆与直线

设 u=B−A，q=u·u>0，X(t)=A+t u。圆条件为 |X(t)−C|²=|C−D|²。展开后除以 q，得到两个根 t=t₀±√δ，其中 t₀=((C−A)·u)/q，δ=(|C−D|²−|A−C|²)/q+t₀²。

这是现代代数重建，不是原典符号。程序先得到两个点，再计算 H=(E+G)/2。根的和消去根号，使 H=A+t₀u 为有理点。由 (C−H)·u=0 得现代垂直核验。

## 2. 异侧条件为什么够用

令 n 为 u 的单位法向量，仅作数学推导，不是程序数值近似。以线为高度零，C 与 D 的法向高度异号，因此 C−D 的法向分量绝对值严格大于 C 的高度绝对值。于是半径 CD 大于 C 到直线的距离，圆为真割线；δ>0。此段是欧氏坐标模型的一般分析，不是有限测试推出的结论，更不是声称原书明写了连续性证明。

## 3. 可手算的实例

A=(0,0)，B=(1,0)，C=(2,3)，D=(4,−1)。CD²=20，圆线方程 (x−2)²+9=20，故 E/G=(2±√11,0)，H=(2,0)。GH=HE，CG=CE，CH 共边，原文由 I.8 得 H 处邻角相等，再由定义10称为直角。现代点积给 (C−H)·(B−A)=0，但不能用它替换原文的历史证明说明。

H 超过 B 并非失败，命题的对象是无限直线，不是闭线段 AB。

## 4. 两个层次的反例

保持上例 C/H，将 E/G 伪造为(3,0)/(1,0)，中点和垂直性均成立，但 CE²=10 而非20，所以不能证明本次圆构造被正确执行。

若把 D 改成(2,2)，半径只有1，不交 y=0；若改成(12,2)，半径平方101仍可交线。两者同侧，都被此异侧算法约定拒绝，但“被拒绝”并不统一意味着几何上无解。

## 5. 练习与答案

1. 交换 A、B 后发生什么？答案：参数方向反转，E/G 命名交换，H 与支撑直线不变；测试真实检查此性质。
2. 改变异侧 D 是否改变垂足？答案：改变半径与交点间距，但两根的均值 t₀ 不变。
3. 为什么 E=G 时不能沿用直角定义的这一证明？答案：弦为零，H 处不再有两条反向非零射线，I.8 所需三角形亦退化。
4. 为什么普通模式通过还跑 -O 和 -OO？答案：防止关键验证只写在可被优化移除的裸 assert 中。这里用显式检查及 unittest 断言，另做 AST 扫描。
5. 正例有多少？答案：3×4×3×3×3×2=648；只是一组有限样本，不是遍历全部有理点。
6. 精确算术是否等于完整形式化证明？答案：不等于。它避免舍入误差，但程序实现、输入范围和几何公理仍有明确边界。
