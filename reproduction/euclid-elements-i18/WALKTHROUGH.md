# I.18 逐步走查

## 输入：A=(0,0)，B=(1,1)，C=(4,0)

AB²=2、AC²=16，故 t=√(1/8)，严格介于0和1。D=(√2,0)，AD²=2。二次域按有理系数和根式保存，打印未做小数舍入。

1. D 位于 AC 的内部，AD=AB。这对应截取步骤；坐标实现不冒充尺规演示。
2. BD=(1−t)BA+tBC。两个系数为正，且 BA、BC 不共线，所以 BD 严格位于角 ABC 内部，角 ABC>ABD。
3. 三角形 ABD 等腰：原证用 I.5 得 ABD=ADB。代码另外核查两角的点积描述相同。
4. DA 与 DC 为反向射线，ADB 是三角形 BCD 的外角：原证用 I.16 得 ADB>BCD。因 C、D、A 同向于 C 发出的射线上，BCD=BCA。
5. 传递得到 ABC>ABD=ADB>BCA。不要把 I.19 的逆命题偷偷用回来。

## 精确比较怎样避免数值误差

若角的点积为正、零、负，余弦分别为正、零、负。不同符号直接排序；同为正时比较 dot₁²·norm₂ 与 dot₂²·norm₁；同为负时反向。余弦在 [0,π] 严格递减，把余弦序转成角序。所有乘法、符号判定都在同一精确二次域完成。该解释属于现代教学重构而非原文术语。

## 反例与拒绝

- A=(0,0), B=(0,4), C=(4,0)：两边相等，不满足严格前提，拒绝，而不是谎报严格角序。
- B=(0,5)：AC<AB，拒绝；原命题方向不适用。
- 三点共线或重合：没有本单元要求的非退化三角形，拒绝。
- 改 D、改 t、换输入或把 true 改为 1：规范重放拒绝。重新构造一份自洽证书不是“伪造被识破”，而是另一个合法输入的证书；输入绑定才区分二者。

## 复盘与答案

**为什么不只核查最终角序？** 最终角序不能说明 D 确实实现截取和内部辅助构造；证书额外检查中间对象，但仍不是一般证明。

**为什么证书有 t 和 1−t？** 它们提供可核查的严格内部关系。图画“看起来里面”不够。

**两边相等是程序失败吗？** 不是，它在本函数的严格输入域之外；等边界由别的命题处理。

**普通/-O/-OO 相同说明什么？** 检查没有依赖裸 assert；不能由此推出所有实现均正确。

**为什么不称完整复现？** 这里只执行有限现代坐标重构，未形式化全部古代公设及图形推理，也未执行物理尺规实验。
