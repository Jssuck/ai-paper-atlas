# Euclid I.18 最小精确教学复现

本包是原创坐标教学重构，不是古代尺规操作的物理实验，也不是欧几里得公理系统的形式化证明器。原证路线：I.3 截取 AD=AB；I.5 底角相等；I.16 在 D 比较三角形 BCD 的外角；严格角部分和传递得 ABC>BCA。

## 环境与命令

仅 Python 3 标准库，无网络、无安装、无密钥。进入本目录运行：

```sh
python run_all.py
```

`environment.json` 保存真实解释器信息；`run-summary.json` 保存命令、UTC 时间、耗时、退出码；`logs/` 保存 stdout/stderr。普通、`-O`、`-OO` 各跑一次测试和样例，再创建并顺序执行 Notebook。测试使用 unittest，不依赖被优化删除的裸 assert。

Notebook 六个代码格由标准库 `compile/exec` 在共享命名空间真实执行，输出写回文件。**没有使用 Jupyter kernel、nbclient 或浏览器运行内核。** 已读取安装的 Notebook 技能；其脚手架文件未在此执行器提供，故用标准库生成 nbformat 4 结构并逐格验证，不安装第三方技能。

## 输入与数学范围

`point(x,y)` 接受整数或 Fraction，不接受 bool/float。`construct(A,B,C)` 接受任意有理坐标非共线三角形，且 AC>AB。令 r=AB²/AC²，t=√r，D=A+t(C−A)，所有值在单二次扩域 Q(√r) 中精确计算。完全平方根自动约为有理数；不混合不同非平方根扩域。

`quadratic.py` 的底层二次域运算改编自本仓 I.12 自有教学代码；本单元构造、角比较和证书由 I.18 重新设计。输出 `D`、截取参数、正锥系数和检查结果绑定原始输入。`accepted` 对规范 JSON 进行确定性重建比较；这只是可信程序内的重放式校验，不是独立证明检查器或密码学签名。字典键顺序无关，结构、字段及值类型严格；布尔 true 不能替换为数字 1。

`angle_cmp` 比较通常的无向角 [0,π]：点积符号先分类，再交叉比较点积平方与长度平方；负余弦区间反转平方比较。此算法是**现代向量核查**，没有把余弦定理、I.19 或三角形内角和冒充原文推理。未调用 acos 或浮点三角函数。原证的依赖关系仍须阅读正文。

## 文件与边界

- `geometry.py`：构造、精确角比较、严格 JSON 输入绑定。
- `quadratic.py`：单二次域、精确符号判断和向量运算。
- `cases.py`：有限正负输入。
- `test_geometry.py`：数学、退化、类型、篡改与边界测试。
- `teaching.zh-CN.ipynb`：逐步走查；`verify_notebook.py`：真实执行器。
- `results-*.json`：三种优化模式输出，要求完全相同。
- `SHA256SUMS.json`：公开文件字节摘要，排除自身及缓存；独立审查加入后须刷新。

有限样本不能证明一般定理，精确算术也不自动保证程序无错。本包不覆盖曲面几何、任意实数输入、跨二次扩域或机器浮点误差。样例的坐标选择不声称穷尽全部几何位置。
