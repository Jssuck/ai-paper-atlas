## 模型与判据

归一化后取 A=(0,0)、B=(1,0)、C=(t,0)，其中 t=AC/AB。欧几里得要求 AB×BC=AC²，即 1−t=t²；可行根为 (√5−1)/2。由 AD=AB、BD=AC 得 D 的横坐标 u=1−t²/2，纵坐标为 ±√v，其中 v=1−u²。所有内部纵坐标都以 √v 为单位保存，不计算浮点根式。横坐标及纵坐标系数均属于 Q(√5)，并以两项有理数精确表示。两点向量的点积需对纵坐标项乘 v，再对整体乘实际 AB 的平方。

圆 ACD 的圆心 O 的归一化横坐标为 t/2；由 OA=OD 得其纵坐标系数为 ±(1−tu)/(2v)。程序比较 OA²、OC²、OD²，检查 B 在圆外、B 的点幂等于 AB×BC，以及 OD 与 DB 的点积为零。最后用两个底角的余弦和顶角余弦的二倍角恒等式比较；顶角为锐角，故二倍顶角在 0 到 π 之间，余弦相同足以判定两个角相等。

## 已检查的案例

- 48 个正有理尺度分别取 D 的上下两个镜像分支，共 96 个正例；尺度和镜像不代表不同相似类。
- t 取 1/3、1/2、2/3、9/10 的两个分支，共 8 个错误内分对照。大圆的半径与弦长条件仍成立，圆 ACD 和 B 的点幂仍可计算，但分割等式、切线、三段等长和倍角条件不成立。
- 另检查负根不在 AB 内、零/负尺度、端点和区间外内分、错误分支标记，以及拒绝浮点输入。每种运行模式有 8 个具名测试，其中输入验证含多个子例。

这不是一套通用几何求解器：不输入任意直线、任意坐标或测量误差，不复现 II.11 的底层尺规步骤。有限测试只能发现这些例子上的偏差；相似、等角和可构造性的一般论证见主文。
