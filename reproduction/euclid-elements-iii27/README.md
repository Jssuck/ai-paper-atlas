# 《几何原本》III.27：选定圆弧的有理数教学模型

本程序不是古代尺规复现，也不以有限测试代替一般证明。它预先采用两个现代模型关系：弧长除以一整周的弧度数为半径乘转数，圆周角为它所截的选定弧对应圆心扫角的一半。因此无法借此独立证明这些前提，或称它是对原证的独立几何验证。

`Arc` 用 Fraction 表示半径、起点与终点方向；以逆时针选择两条互补圆弧中的一条。扫角是方向差对一周取模，跨过零方向不改变算法。同点首尾不区分空弧和整周，均拒绝。大弧使用明确的定向扫角，并非把欧几里得图中的普通角默认为反角。不论圆周顶点取在补弧何处，所截弧都保持一致；程序不独立构造或测量该顶点。

若圆心扫角不等，`copy_smaller` 在较大弧的起点复制较小扫角，并核查终点严格在较大弧内部。该初始子弧与较小圆弧等长，而它严格短于较大弧，展示了原证反证中的候选矛盾。程序由模型中的长度计算核查等长前提，而非假装接受任意两个不等弧为等长。

## 实跑

Python 标准库，无依赖。目录内执行：

```sh
python --version
python -B -m unittest -v
python -B -O -m unittest -v
python -B -OO -m unittest -v
```

三个日志记录各自版本和输出，各通过 8 项。网格每次覆盖 2 个半径、12 种起点配对、每对 121 种扫角组合，共 2,904 个等半径配置：264 等扫角、2,640 需复制较小角的不同扫角。另有跨零、异半径等弧长、同弦互补弧、异类角、退化输入以及非严格拷贝的定向测试。
