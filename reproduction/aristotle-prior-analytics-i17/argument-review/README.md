## 手工证明逐项复核

1. **对象层三分。** 对任意固定对象，否定“存在正例且存在反例”用经典德摩根律产生“无正例或无反例”，分别等于必要否定、必要肯定。非空世界集保证同一对象不能同时固定真与固定假。此论证不限有限域。
2. **全称否定。** 否定对实际主项的全称，再将存在量词分配到析取，得到“某个必要肯定见证或某个必要否定见证”。可以由不同对象同时给出两支；非互斥析取。空实际主项时两边皆假，等价仍成立。
3. **特称否定。** 否定存在偶然对象等于每个主项对象固定真或固定假，不等于全体统一固定真或全体统一固定假。正文已正确标记这一现代延伸。
4. **改质与换位。** 正负模态见证对换不改变双向偶然性，保持同一主项；交换主谓会换量词范围。正文两个非空换位反模型均成立；负分支单独版本确无必要肯定见证。
5. **第二格反模型。** 中项在两个世界从包含B∪C变为空，而B、C稳定非空，足以满足每条前提全部A/E/I/O。稳定分离反驳实际／必要／弱可能肯定结论，稳定重合反驳其否定结论，两者都反驳双向偶然结论。对16个有序前提对及16种候选结论各有显式反模型，即256个候选蕴涵。一般不有效性由明确构造和分类证明，非由有限枚举“没找出反例”推断。
6. **量词次序。** u与v在两个世界交替为P，各自可变但没有全体同时P或全体同时非P的世界。对象级可能不能替换为共同世界条件；必要特称亦固定同一对象。
7. **反证责任。** 一条归约路线失败不自动排除其他证明；正文随后另给反模型。反模型里的必要人马排斥也没有冒充由前提推出的新结论。
8. **范围声明。** “无三段论”限定端项范畴结论，不是没有任何逻辑后果。原章预告混合情况、所有古代语言、不定命题及其他现代语义没有被16型代码冒称穷尽。

## 独立有限检查

`check_arguments.py` 不导入作者模型或演示，通过谓项外延的并、交与补集另行构造语义，主要用于检查上述代数关系及手算反例。

从本目录执行：

```bash
python check_arguments.py > normal.json
python -O check_arguments.py > O.json
python -OO check_arguments.py > OO.json
cmp normal.json O.json
cmp normal.json OO.json
```

三种模式真实运行成功，三个JSON字节一致。明确抛出异常，不依赖优化时会移除的 `assert`。

- 对象数1–3，世界数1–3，全部谓项真值序列、全部实际主项子集及每个实际点：14,356个配置，272,764次检查。
- 其中384个配置同时有两种固定见证，1,378个配置满足逐对象偶然却无共同全肯世界，1,934个空主项配置。这些是已定义枚举中的计数，不是独立随机样本。
- 对象数1–4、任意两个非空稳定端项：284个端项对，2,272次前提检查，说明自由切换中项不约束端项的具体构造。
- 完整256候选推论反模型表，及11个针对正文负分支单独模型、量词次序和特称否定的手算检查。

这些检查与作者枚举覆盖有重叠，不相加冒充不重复样本。有限检查不是一般数学定理的证明，也不验证自然种类或古代心理学。实现级独立预言机、非法输入与变异测试由另一份代码审核负责。

确切解释器与命令见 [environment.json](environment.json)；记录：[普通](normal.json)、[-O](O.json)、[-OO](OO.json)；已读文件摘要见 [reviewed-hashes.json](reviewed-hashes.json)。
