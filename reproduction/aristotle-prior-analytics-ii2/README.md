# II.2：真假组合与前提失真的最小教学核验

这是原创的现代集合教学模型，不是古代术语的唯一语义，不是全文翻译，也不是解释性知识的自动判定器。对应正文 [II.2 深读](../../papers/ancient/aristotle-prior-analytics-ii2.zh-CN.md)。只使用 Python 标准库，没有安装依赖。

## 1. 模型和符号

`A` 是大项集合，`B` 是中项集合，`C` 是小项集合；非空论域中的对象用整数标识。`proposition(model, kind, subject, predicate)` 的后两项明确按**主项、谓项**排列：

| kind | 语义 |
|---|---|
| A | 主项包含于谓项，允许空主项 |
| E | 主项与谓项不相交，允许空主项 |
| I | 主项与谓项至少有一个共同对象 |
| O | 主项中至少有一个对象不在谓项中 |

四个有效式分别为 Barbara（全称肯定／全称肯定／全称肯定）、Celarent（全称否定／全称肯定／全称否定）、Darii（全称肯定／特称肯定／特称肯定）、Ferio（全称否定／特称肯定／特称否定）。每个签名依次表示大前提、小前提、结论的真假，T 为真，F 为假。不存在 TTF 是有效性的有限核验；存在 FFT、FTT 或 TFT 并不使有效式无效。

## 2. “整假”不等于普通假

对于非空主项的全称陈述，程序把反对的全称陈述为真称为 `wholly_false`：例如声称“所有 B 是 A”，实际 B 与 A 完全分离。若 B 同时有 A 与非 A 对象，则称 `partly_false`。这是一种明确的教学形式化：部分假在普通二值真值上仍是**假**，并不是半真值或概率。

空主项的 A、E 都为真，程序分类为 `vacuous_true`，绝不因为反对式也真就误列整假。I、O 只分类 `true` 或 `false`，不把全称命题的整假／部分假分类机械搬给它们。

## 3. 一般推理与有限实验的关系

Barbara 的一般证明：取任意 C 对象，由 C 包含于 B 得到它属于 B，再由 B 包含于 A 得到它属于 A。Celarent 用不相交条件作同样传递。Darii 与 Ferio 从小前提取一个存在见证，再由全称大前提传递该**同一见证**。这些论证不依赖有限枚举。

若大前提整假，小前提全称且为真，C 又非空，则 Barbara 的 C 全在 A 外，Celarent 的 C 全在 A 内，相应全称结论为假。C 非空不可省略：程序的两个 `empty_C_*_exception` 例子中，C 为空，结论仍空真。

对特称式，上述“必假”不成立。Darii 例子 A={0}、B={1}、C={0,1} 中，小前提见证是1，真结论见证是0，两者不同。Ferio 的对偶例子 A=B={1}、C={0,1} 中也一样。它们说明真实结论可以碰巧由**另一个对象**满足，并未修复假大前提。

### 八类型缩减为什么可用

任意对象由其是否属于 A、B、C 决定一个三位类型。每一非空类型保留一个代表，空类型不添对象。A/E 只取决于违例类型是否存在；I/O 只取决于见证类型是否存在。非空 B/C、整假以及部分假也完全由这些存在信息决定。因此任意非空论域上的这个一元三项片段，都能压缩到至多8个代表而保持本文所有被检查的真值与分类，包括原论域无限的情况。

这是缩减论证，不是由程序跑完就自动获得的一般数学定理。模型不处理关系谓词、模态、因果、证明的解释根据、自然语言分类真伪或古代全部三段论。

## 5. 结果能说什么，不能说什么

有效性是所有前提同时为真时的保真约束，不是说前提事实上都真；真结论也不能反向担保大、小前提正确。本实验不把“假前提推出真结论”解释为假前提能提供真实的因果或解释性知识，也不将一组材料蕴涵真值混同于亚里士多德所说的“为什么”。自然语言动物、石头等例子的事实真值仍需另外的知识；代码用整数集合，不伪装成实证生物学。
