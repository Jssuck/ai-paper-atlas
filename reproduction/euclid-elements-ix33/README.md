# 《几何原本》IX.33：一半为奇数的偶数

正整数教学重构。若偶数 $`N`$ 的一半 $`H`$ 为非单位奇数，则 $`H`$ 度量 $`N`$ 两次，给出一次有序见证 $`(H,2)`$。代码按（度量者，次数）保存；次数为偶、度量者为奇，对应卷 VII 定义 9 的偶次度量奇数方式，不能把元组位置读成文字标签的顺序。若存在偶度量者和偶次数，积会是四的倍数，半数也会是偶数，与前提矛盾。

例：$`18`$ 的一半是 $`9`$，有见证 $`(9,2)`$；$`12`$ 则有 $`(3,4)`$ 和 $`(2,6)`$ 两类见证，不能说它“仅”属混合类。$`2`$ 的一半是单位，排除在严格模型外；奇数输入同样不满足前提。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

在 2 至 256 的范围内，独立基线将非单位度量者和偶次数按乘积归组，与真因子和商的枚举比较。有限核验不替代一般证明。Notebook 日志记录标准库实跑三个代码单元，不是 Jupyter 内核运行。

实跑环境为 CPython 3.12.14：[普通](normal.log)、[-O](O.log)、[-OO](OO.log)；[Notebook](euclid-ix33.ipynb)及[回放日志](notebook-replay.log)。
