# 《后分析篇》I.15：直接否定与中项的有限模型教学

这是原创教学重构，不是古文程序的复现，也不把现代集合等同于亚里士多德的科学属概念。对应[深读正文](../../papers/ancient/aristotle-posterior-analytics-i15.zh-CN.md)；原文定位与译本差异见[来源核验](../../papers/ancient/aristotle-posterior-analytics-i15.sources.zh-CN.md)。

## 问题与表示

固定结论是“没有 B 是 A”。每一词项用论域的一个子集表示；`all_of(P, S)` 表示 S 包含于 P，`none_of(P, S)` 表示二者不交。中项 M 不要与主词 B 混淆。

|式|两前提|结论|
|---|---|---|
|Celarent（第一格）|没有 M 是 A；所有 B 是 M|没有 B 是 A|
|Cesare（第二格）|没有 A 是 M；所有 B 是 M|没有 B 是 A|
|Camestres（第二格）|所有 A 是 M；没有 B 是 M|没有 B 是 A|

前两式的否定前提在集合外延语义下等价，枚举计数因而相同；这不抹除其语法格位差别。

## 三个应亲自检查的结果

1. **上属不是充分条件。** A={0,1}，B={1,2}，C={0,1,3}。A 真包含于 C，B 却不包含于 C；但是 B 与 C 仍相交，A 与 B 也相交。因此“C 不是 B 的属”不能直接读作“没有 B 是 C”。测试还包含结论恰巧为真、但所需否定前提依然为假的另例，避免把正确结论反推为正确论证。
2. **第三格的范围。** A={0}，B={0,1}，M={1}。没有 M 是 A，所有 M 是 B；因此某个 B 不是 A，但并非没有 B 是 A。非空 M 是此特称结论的存在条件。
3. **词汇限制与直接性。** A={0}，B={1}，只提供 A、B 时，程序找不到允许的一步中项；增加补集 not_A={1,2,3} 后，两种格位可作为真前提见证。这里的“找不到”只相对于给定词汇和三种模板；不是发现原文意义的直接科学原则。

`witnesses` 排除与端项外延相等的候选，以免用端项重命名制造循环证明。这是明确的教学约定，不是从原文导出的属关系定义。只要允许任意补集，每个不相交的 A、B 都有形式上的 Celarent 前提；但补集可能与 B 相同，论证可能循环，也未提供本质性、因果性或独立已知的科学前提。于是“一阶集合上可分解”不能替代“科学证明中有合适中项”。

## 范围、未做之事及推广

有限枚举不会证明任意论域中的一般定理。三式的一般集合有效性须由逐元素证明建立（正文提供）；实验只核查实现和所列反例。代码没有实现属树、必然性、第一原因、可知次序、完整证明搜索或科学公理系统；也没有声称重建亚里士多德全部逻辑。找不到一个词汇中的单步见证不等于任何形式的多步不可证明性。

已检查当前环境无 `nbformat`、`nbclient`、`ipykernel`，且已安装技能所指默认 notebook 脚手架路径不可用；没有安装新依赖，也没有伪造 Notebook 执行输出。此低成本复现采用真正实跑、可独立复核的标准库命令行程序。

可自行扩展论域大小，或添加受约束的属关系，再比较哪些扩展改变见证集合。两项练习：①为什么两否定前提不足？取 A=B={0}、M={1} 即得前提真结论假。②为何不能把 `[]` 写成“直接性已证明”？因为它仅表示有限候选词汇内没有所列模板的合格单步见证；词汇、证明规则及科学解释都尚未穷尽。
