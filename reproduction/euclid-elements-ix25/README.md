# 《几何原本》IX.25：偶数减奇数

给定偶数 $`A`$ 与奇数 $`B`$，要求 $`A>B\ge3`$。先将 $`B`$ 去掉一个单位，得到偶数 $`B-1`$。再从 $`A`$ 中去掉 $`B-1`$，留下偶数 $`A-(B-1)`$；继续去掉一个单位就是 $`A-B`$。例如 $`(18,7)`$ 先得 $`12`$ 再得 $`11=5+5+1`$。输出为单位的情况另标：$`(4,3)`$ 得到 $`1`$，在现代模型可写作 $`0+0+1`$，这不是将零作为古代两半的数。

程序拒绝 $`B=1`$ 的输入、倒序及零、负输入；这里采用的是原典背景下严格正的非单位输入约定，现代整数的奇偶关系可以更广。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线用计数表判定两项类型，并从 $`B+1`$ 起每次加 2，数到 $`A`$，和原程序的去单位路线核对。两个输入各取 1 至 64；有限核验不是一般证明。Notebook 日志来自标准库实跑三个代码单元，不是 Jupyter 内核运行。
