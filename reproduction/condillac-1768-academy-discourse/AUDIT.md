# 独立代码与接口审计

## 结论及证据范围

这次独立自动化审计没有发现仍未解决的有限模型语义缺陷。审计包含单独的代码与接口复核、独立编写的参照算法和边界测试；它不是人类专家认证、证明助理认证、历史发现或心理学实验。作者回归测试与独立测试均在普通 Python、`-O`、`-OO` 下执行。实际运行记录及精确文件绑定见 [`audit/code_review.json`](audit/code_review.json)。

一般论证见 [`MODEL.md`](MODEL.md) 及正文第10–12节。程序测试只确立所记录的有限实例结果。这些模型不归于孔狄亚克，数值输出也不验证历史演说中的主张。

## 怎样重跑

进入本复现目录，仅用 Python 标准库执行：

```sh
python3 independent_checks.py
python3 -O independent_checks.py
python3 -OO independent_checks.py
python3 run_independent_audit.py
```

最后一条命令重新生成审计日志与审查 JSON，分别在三种模式下运行作者回归测试和独立测试，并将演示输出与预期 JSON 逐字节比较。它还在隔离子进程内执行四项故意注入错误的对照。只更新本目录 `logs/`、`audit/` 内的本地记录，不安装依赖，不联网，不使用凭据，也不写远程服务。

独立测试只导入模型的公开接口，不导入作者测试、演示夹具或预期 JSON。检查使用 `unittest` 方法与明确异常，在优化模式下仍然有效。运行器还检查生产文件和两份测试文件中没有会被优化删除的 Python `assert` 语句。

## 独立有限检查的实际范围

独立套件共有16个测试方法。下表记录方法内部实际枚举的实例，不能把每次循环都冒称一个单独发现的测试方法。

| 独立检查 | 确切有限范围 | 参照算法或判据 |
|---|---:|---|
| 树的编译与查询成本 | 368份树规格，2,944次输入求值 | 枚举并匹配叶子路径约束，而非再写一份沿分支求值的解释器 |
| 部分响应表 | 1,472份训练子集表 | 对独立算出的响应取直接限制；缺项查询必须失败 |
| 表示最优风险与任意解码器风险 | 3,510个有理权重总体，81,432个候选解码器 | 枚举完整的代码到标签赋值，逐对象直接加总错分质量 |
| 表示细化 | 972组旧、新总体比较 | 三对象划分的所有细化关系，交叉指定标签及权重目录 |
| 同步传播 | 16,384个图与初始集合实例 | 枚举简单有向路径并取最短长度，不使用传播递推或 Floyd–Warshall |
| 自环与内容改变 | 16,384组额外比较 | 添加全部自环，并改变说法与来源标识，检查接收快照不变 |
| 添加有向边 | 4,095组图比较 | 原接收者不更晚到达；稳定后延用终态，逐轮比较包含关系 |
| 非法构造规格 | 树29例、表示41例、图20例 | 必须抛出 `SchemaError`；另有非法查询、解码器及来源记录检查，未计入这三项数字 |

树目录包括叶子数从一到五的全部23种有序满二叉树形，交叉四种谓词赋值模式、四种标签模式和全部八个三位输入。重复谓词、在结构上存在但不会被给定输入访问的叶子也被覆盖。这并不是这些规模下所有谓词表与所有标签赋值的穷尽。

总体目录采用三个对象的全部五种划分、三种真实标签的全部27种赋值，以及各权重为零、三分之一或三分之二的全部26个非全零向量。候选预测包括三种标签和一个未出现标签。全零权重另作为非法输入测试。这与作者的四对象二元目录和按纤维取最大质量实现不同。

图目录采用四节点的全部4,096张无自环有向图，分别使用四个初始集合：空集、指定单节点、指定双节点、全体节点。这里没有枚举全部16个可能的初始集合。每张图还检查添加全部四个自环的结果。加边检查给每张非完全图添加固定顺序中第一条尚缺的边，没有穷尽所有可能的扩边方式。

## 接口与正文手算例子的复核

1. 树要求谓词为全域布尔表，根已经声明，非根节点恰有一个父节点，根没有父节点，所有节点在结构上都可从根到达。测试拒绝可达循环、断开循环、孤立节点、共享孩子、非布尔真值、未声明谓词和未知输入。求值与图结构校验采用迭代遍历；作者另外用深度1,500的树检查不依赖 Python 递归深度。
2. 空树输入域编译为一个空表，不能查询任何对象。根叶树查询零次谓词，成功查表按约定算一次抽象查找。这些成本约定都不构成真实耗时加速的测量。
3. 独立重建正文10.4节：异或标签依次为 `0, 1, 1, 0`，完整建表共作八次模型内谓词查询。把 `11` 的叶子改错后，编译仍保留该错误。两棵树可以在已观察的三个点上相同，在第四个点上不同。
4. 表示权重使用精确的非负整数或有理数字符串。浮点数、布尔权重、非法分数、空总体和总质量为零均被拒绝。零质量对象仍影响全域结构充分性；正权重支持集却可能充分，最低加权风险也可能为零。
5. 代码没有单独声明有限标签全集。`risk` 接受任意非空预测字符串，解码器的键必须恰好覆盖已出现代码。`best_decoder` 在每条纤维内实际出现的最大质量标签中，选择字典序最先者；完全零质量纤维也按此规则确定输出。允许更多预测字符串不能降低最低风险。正文用有限标签全集表述时，只要包含真实标签，最低风险相同。
6. 独立重建正文11.4–11.5节：标签 `0, 0, 1`、权重 `2, 1, 3` 形成并列，最低风险为 `1/2`；把最后对象分开，最低风险降为零。只保留第一位时，源任务风险为零，改判第二位后目标最低风险为 `1/2`。另外交换本来纯净纤维的标签，可使沿用解码器风险变成一，而目标仍充分且最佳风险为零。因此，解码器不相容与表示信息缺失被分别测试。
7. 独立重建正文12.4节时，准确只加从链首到第四节点的一条捷径，首次到达轮数变为 `0, 1, 2, 1`。这不同于演示中添加两条捷径、第一轮覆盖全部非孤立节点的补充例子。
8. 传播是同步、累积、有方向的。返回快照只省去最后一次不变的重复状态；以后各轮都等于末状态。可达循环会终止，孤立节点不会收到，空初始集合保留一份空快照。重复初始节点与重复边会被拒绝，不会悄悄去重。
9. 复制判断保留来源标识。重复同一标识不会扩大来源集合，即使说法字符串不同也一样；不同标识不能证明观察独立。传播假定全部初始节点持有同一判断，不推断其真假。
10. 输入字典和列表被复制，公开映射只读，普通属性重赋值与删除被拒绝。这是对日常误改的防护，不是针对同进程恶意反射的安全隔离。返回的数据类是结果容器；构造规格校验由已说明的模型入口负责。

## 故障对照与审查中已修正的问题

四项故障对照只在全新子进程内修改内存，不改写 `model.py`：

- 删除一个编译表项：独立异或检查会拒绝
- 谎报最低风险为零：含并列的加权例子会拒绝
- 混同全域充分性和正支持集充分性：零权重检查会拒绝
- 把多轮传播压成一跳：链上的首次到达检查会拒绝

预期发生的断言失败记录在 [`logs/independent-negative-controls.log`](logs/independent-negative-controls.log)。它们说明检查对这四种具体缺陷敏感，不表示穷尽所有可能的故障注入。

审查发现原验证元数据写入了绝对私有工作目录。作者随后改为发布相对工作目录和可移植命令标记，并重新生成日志。模型说明也补充了任意字符串预测与有限标签全集的接口区别，以及逐纤维的并列规则。这些问题不需要修补核心算法。
