# 模型定义、证明与边界

## 性质与范围

以下均为新建的有限数学教学模型，**不归于孔狄亚克本人**，不声称重现历史机制，也不作为人类认知的经验证据。历史解释仍须独立核对演说原文。程序输出检验具体有限例子，不能代替一般证明。

公式使用 GitHub 兼容的行内数学与数学围栏；实现标识使用代码格式。空集上的和为零。下文函数在各自声明的定义域上完整定义。标签是非空字符串；字典序只用于确定性地处理并列，不表示价值高低。

## A. 顺序判断与完整编译

### A1. 对象、谓词与树

令 $`X`$ 为有限命名输入集合，允许为空。每个已声明谓词 $`p`$ 都是从 $`X`$ 到布尔值的完整表。有限有根二叉树的节点，要么是带标签的叶子，要么是带谓词、假分支和真分支的内部节点。所有节点必须从根可达；根没有父节点，其他节点各有一个父节点。排除循环，也排除共享子节点的有向无环图。

递归定义树语义 $`F_t`$：标签为 $`y`$ 的叶子对每个输入返回 $`y`$；使用谓词 $`p`$ 的内部节点，按 $`p(x)`$ 的真假选择相应子树的结果。

定义 $`C_t(x)`$ 为执行的谓词测试数：叶子为零，内部节点为一加所选子树的测试数。`Tree.evaluate` 沿这一路径迭代执行，不依赖 Python 递归。规格校验保证查询的谓词条目和子节点存在；有限无环性保证终止。

### 命题 A1：求值正确且终止

对每棵合法树 $`t`$ 和每个 $`x\in X`$，求值终止，输出 $`F_t(x)`$，恰执行 $`C_t(x)`$ 次谓词测试。

**结构归纳证明。** 叶子立即返回标签，测试数为零，与定义相同。对内部节点，完整谓词表为给定输入提供唯一布尔值。求值器执行一次测试，进入递归定义指定的子树。该子树是更小的有限树，由归纳假设，它会终止并输出自身语义值，执行定义的测试数。加上当前一次测试，得到所需计数；所选子树的标签正是当前树的语义值。由结构归纳覆盖根。当 $`X`$ 为空时没有合法查询，全称命题是空真，不表示识别了任何对象。

### A2. 完整响应编译

编译枚举每个 $`x\in X`$，保存 `T[x] = Tree.evaluate(x).label`，即每个输入一个输出标签。对编译后字典的一次成功查询，**约定计为一次抽象查表**。

### 命题 A2：完整域上的语义保持

对每个 $`x\in X`$，编译表返回 $`F_t(x)`$。

**证明。** 命题 A1 保证每个枚举输入的存储标签等于 $`F_t(x)`$。编译遍历全部合法键，因此每次合法查询取回的就是该输入的原标签。这里没有推广步骤。空域得到空表，等价结论仍为空真。

若外部另给真标签函数 $`Y`$，树和表对每个输入的错误指示完全一致：都恰在 $`F_t(x)\ne Y(x)`$ 时出错。所以任何给定权重下，两者错误率相同。编译错误判断会保留错误判断。

**成本与存储边界。** 编译执行的模型内谓词测试数为 $`\sum_{x\in X}C_t(x)`$，并存储 $`|X|`$ 个标签条目。这里不包括校验、循环、键操作、分配等实现成本。一次查表的约定不是 CPU 基准，也不是 Python 字典最坏时间复杂度结论。深路径可以换成一次模型内查表；根叶树原本是零次谓词测试，因而不是改进。比较的是两类约定操作，不能把它们换算成相同耗时。

当前实现原本已保存完整有限谓词表。编译再材料化 $`|X|`$ 个标签，但这不保证所有实现的总内存必然增加：删除旧树或谓词表、压缩标签、以程序表示谓词都会改变比较。域很大时，即使树很小，完整查表也可能无法承担。本包不报告数值加速或内存基准。

### 命题 A3：只有训练响应，不能确定未见响应

只保留真子集 $`S\subsetneq X`$ 上的标签，允许至少两个不同标签，并且没有额外限制把其余输出与已观察数据联系起来。则任何只利用这些记录的方法，都不能保证对所有兼容完整标签函数，在每个未见输入上回答正确。

**证明。** 选未见输入 $`u`$，构造两个完整标签函数：它们在 $`S`$ 上一致，在 $`u`$ 上不同。只接收已保留记录的方法，在两种情况下收到相同数据。它在 $`u`$ 的单一回答不能等于两个不同标签。随机回答也不能同时对两种情况保证概率一正确。故观察记录本身没有无条件保证。

这不排除提供完整树、限制假设类或加入其他知识后的推断。回归测试给出两棵合法树：已观察 `d` 的答案相同，未观察 `c` 的答案不同。`train_lookup` 复制的是所选**原树输出**，不是外部真实训练标签；“train”不表示拟合参数。查询未记录的键时，它抛出 `UnknownInput`，而不补造答案。

## B. 表示、目标风险与迁移

### B1. 有限加权目标总体

这里 $`X`$ 非空且有限；$`r(x)`$ 为表示代码，$`Y(x)`$ 为真标签。每个对象有非负有理质量 $`w(x)`$，总质量 $`W=\sum_{x\in X}w(x)`$ 为正。省略权重时每个对象质量为一，即均匀分布。`2/3` 一类有理数字符串精确解析；拒绝浮点权重。

代码 $`z`$ 的纤维 $`F_z`$ 是所有满足 $`r(x)=z`$ 的对象。解码器 $`g`$ 为每个出现的代码指定标签。API 允许任何非空预测字符串，不要求声明有限标签集。总体实际出现的真标签像集 $`Y(X)`$ 有限，限制到这个集合仍可达到不受限的最优值。正文则显式规定包含所有真标签的有限标签集；最优公式相同。

目标风险为错分质量除以总质量：

```math
R(g)=\frac{1}{W}\sum_{x\in X}w(x)\,[\![g(r(x))\ne Y(x)]\!].
```

其中 $`[\![P]\!]`$ 在命题 $`P`$ 成立时为一，否则为零。

### 命题 B1：结构充分性的充要条件

存在一个对**全部对象**正确的解码器，当且仅当代码相同的任意两个对象都具有相同真标签。

**证明。** 必要性：解码器对一个代码只能给一个标签，同代码对象收到相同预测；要都正确，它们真标签必须相同。充分性：若每条纤维只有一个共同真标签，就给该代码指定这个标签。共同性保证定义不矛盾，而且每个对象都会被正确判断。该条件与权重无关。

`RepresentationDomain.sufficient()` 检查整个定义域；`sufficient(True)` 只检查正权重支持集。没有任何正权重对象的纤维，支持集条件空真。

### 命题 B2：最小风险的精确公式

令 $`M(z,y)`$ 为代码 $`z`$ 纤维中真标签为 $`y`$ 的总质量，$`M(z)`$ 为整条纤维总质量。在所有解码器中，最小错误质量为

```math
E_{\min}=\sum_{z\in r(X)}\left(M(z)-\max_{y\in Y(X)}M(z,y)\right).
```

最小风险为 $`E_{\min}/W`$。

**证明。** 若代码 $`z`$ 被解为 $`y`$，该纤维正确质量恰为 $`M(z,y)`$，错误质量恰为 $`M(z)-M(z,y)`$。选择最大质量标签即可使该项最小。不同代码的输出可以独立选择，因此各纤维最低错误质量能同时达到，相加便是全局最小值。除以固定正总质量得最小风险。预测一个未在正质量纤维出现的标签不会保住任何质量，不能改善最优值；全零质量纤维无论预测什么都贡献零。

实现从**该纤维出现的标签**中选择最大质量标签，并列时取字典序最小者。全零质量纤维也按此规则确定输出。这个约定决定返回哪一个最优解，但不改变最小风险。

### 推论 B2a：零风险与零质量例外

最小风险为零，当且仅当每条纤维的正权重对象具有共同真标签。

**证明。** 最小错误质量公式的每个加项都非负。某项为零，恰意味着该纤维全部正质量都落在一个标签上，即上述支持集条件。非负项的和为零，恰当且仅当每项均为零。零权重对象不约束风险。因此要从零最小风险推出全域充分，还需额外条件，例如每个对象权重都严格为正。

### 命题 B3：细化不会恶化可达到的最优风险

固定对象、真标签和权重。设新表示 $`r'`$ 决定旧表示 $`r`$，即存在 $`h`$ 满足 $`r=h\circ r'`$。不限制解码器复杂度，则新表示的最小风险不大于旧表示的最小风险。

**证明。** 对任一旧解码器 $`g`$，定义新解码器 $`g'=g\circ h`$。对每个对象都有 $`g'(r'(x))=g(h(r'(x)))=g(r(x))`$。新解码器逐点复制原预测，因而保留每个错误指示与加权风险。特别地，旧最优解可在新表示上重现；在所有新解码器中取最小值，不会差于这个可重现的选择。这是存在性结论，不保证训练算法能找到最优解，也不免除观察额外属性的成本。

正文三对象例的标签为 `0, 0, 1`，权重为 `2, 1, 3`。单代码最低风险为 `1/2`，分开最后对象后纤维纯净，最低风险为零。两者均在 `article_examples.weighted_tie_and_refinement` 中运行。

### B2. 迁移仍是另一个条件

源、目标总体可以共用表示代码字母表，而代码对应的真标签不同。本例只是把源解码器沿用于目标，没有训练算法或经验样本拟合。

源风险为零只约束源标签和质量，不约束独立指定的目标标签。即使两个领域各自结构充分，正确解码仍可以不同。示例将两个纯目标纤维的标签对调，使源解码器目标风险为一，正确目标解码器风险却为零。加权碰撞例则展示不可由任何解码器消除的目标错误，最小风险为 `3/8`。正文第一位表示用于第二位任务的均匀例单独运行，最小风险为 `1/2`；两者不是同一总体。

## C. 同源复制与确定性传播

这是第三个有限模型，通过区分来源、传播与正确性，与前面的表示迁移问题相联系。

### C1. 重复判断与记录的来源

一个 `Judgment` 保存固定断言和来源标识。复制保持二者不变。任意正数份精确副本的来源并集仍是同一个单元素集合；零份副本的来源集合为空。这是溯源陈述，不检验原来源是否可靠，也不检验其他来源是否独立。

条件概率可以说明对应的有限证据结论。令 $`E`$ 为原证据，$`D`$ 为其确定性副本。对正概率的条件事件 $`E=e`$，一致副本 $`D=d(e)`$ 必然成立。因此事件“$`E=e`$”与“$`E=e`$ 且 $`D=d(e)`$”完全相同。对任何命题 $`H`$，它们与 $`H`$ 的联合概率相同、分母的正概率相同，故给定两者得到的条件概率相同。知道原证据后，确定性复制不增加新证据。程序只记录来源，不估计这些概率。独立新观察、进一步核查、可靠性信息或选择性转发都需要另建模型。

### C2. 有向同步传播

令 $`G=(V,E)`$ 为有限有向图，$`S_0`$ 为初始持有者。所有初始持有者持有**同一判断**的副本。每轮所有已有持有者沿出边发送原判断，接收者永久保留。因此累计集合满足

```math
S_{t+1}=S_t\cup\{v\in V:\exists u\in S_t,\ (u,v)\in E\}.
```

允许自环、循环、空图和空种子集。重复边与未知端点是规格错误。模型不含真假、说服、遗忘、容量、拒收或竞争断言。

### 命题 C1：距离分层与可达性

对每个非负整数轮次 $`t`$，$`S_t`$ 恰为从某个初始持有者出发、有向路径长度至多为 $`t`$ 的顶点集合。因此顶点最终被达到，当且仅当它从种子集有向可达；首次到达轮次就是最短这样的路径长度。

**按轮次归纳。** 第零轮，零长度路径恰对应初始持有者。假设第 $`t`$ 轮结论成立。保留的持有者已有长度至多为 $`t`$ 的路径；新加入的出邻居是在这种路径末尾再加一边，因此路径长度至多为 $`t+1`$。反向地，长度至多为 $`t+1`$ 的路径，要么早已不超过 $`t`$，要么最后一边从第 $`t`$ 轮已到达顶点出发，其终点必加入下一轮。两方向合起来得到集合相等。对所有有限轮次取并集即得可达性；最早可达轮次就是最小路径长度。

种子集非空时，最短路径不会重复顶点，否则可删去重复段而缩短。若顶点数为 $`n`$，全部首次到达均不迟于第 $`n-1`$ 轮。种子集为空时，初始空快照已经稳定。代码返回初始快照和此后每个严格变化的快照，不重复保存终止后的同一集合；再往后的状态均可由最后快照恢复。

### 推论 C1a：此模型中加边不会延迟传播

顶点和种子固定时，加边保留所有旧路径，因此原已达到的顶点到达不会更晚；新顶点也可能变得可达。严格加速、最终覆盖不变都不是普遍保证，它们只同时成立于这里选取的捷径例。

### 推论 C1b：传播本身不检查真理

递推只用图与种子，不读断言内容。因此换成任何其他固定断言，每轮集合都不变。明显错误的 `2 + 2 = 5` 与正确的 `2 + 2 = 4` 会沿相同路径传播。这不否定现实交流可以改善知识，只表明该盲目复制规则没有真假检验操作。

## 程序检查与一般证明的区别

测试穷举：四个布尔输入、两个谓词、二元标签、深度至多二的202棵树；768个二元标签与代码的加权总体；全部4,096个三顶点有向图与种子集组合。树与独立的元组树求值器比较，最小风险与所有二元解码器枚举比较，传播与独立的全点对最短路径算法比较。错误输入测试覆盖规格和未知输入，深度1,500的树检验遍历不依赖 Python 递归。正文三个手算例另有精确断言。

这些检查规模小、开销低，不能量化覆盖所有更大树、标签集、权重或图。一般论证由上述命题提供；有限测试支持实现符合这些定义。它们都不能代替历史证据或心理实验。
