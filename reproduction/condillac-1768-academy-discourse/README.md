# 孔狄亚克演说辅助阅读：有限模型与复现

这是一组**现代教学模型**，不是孔狄亚克自己的数学，不是把其思想重建成算法，不是心理实验，也不构成历史证明。历史文本、版本和引文证据由配套文章提供。这里的对象、树、标签、权重和网络均为人为构造，不测量人的表现。

模型围绕两个问题展开：

1. 顺序完成的判断，能否变成直接响应而保持原来的答案？
2. 表示方便、迁移成功或流传更广，分别在什么条件下与正确性有关？

三个有限模型分别处理：完整决策树编译；表示充分性、跨领域解码迁移和精确加权风险；同源复制与有向传播。

## 运行

需要 Python 3.10 或更新版本；只用标准库。不需安装、网络、凭据、下载数据或远程写入。

在本目录执行：

```sh
python3 demo.py
python3 -m unittest -v test_model
python3 verify.py
```

最后一条命令以普通、`-O`、`-OO` 三种模式运行检查，将示例输出与 `examples/expected_results.json` 逐字节比较，解析生产代码检查是否出现 `assert`，并在 `logs/` 中保存实际输出和环境信息。它只更新本地日志。校验使用显式异常，在优化模式下仍生效；测试使用 `unittest` 检查方法，不依赖 Python 的 `assert` 语句。

公开日志把解释器命令显示为 `python3`、工作目录显示为 `.`，不包含私有机器路径。实际运行使用启动验证程序的同一解释器；版本、优化级别、平台和源码哈希均有记录。

## 文件

- `MODEL.md`：定义、假设、原创证明和适用边界
- `WALKTHROUGH.md`：从操作到结果的中文逐步讲解
- `RESULTS.md`：精确结果及其含义
- `model.py`：经过校验的有限模型
- `demo.py`：确定性示例
- `test_model.py`：错误输入、反例和有限穷举检查
- `verify.py`：三种解释器模式下的复现与日志采集
- `examples/expected_results.json`：固定的示例预期输出
- `logs/`：真实运行日志、环境信息和源码哈希

## 与正文的精确对应

`demo.py` 同时输出正文例子和补充变式，分别位于不同 JSON 键下：

- `article_examples.xor`：四个二进制输入，每个两次谓词测试，完整建表八次；改错 `11` 叶子后，树与表都保持 `1/4` 错误率
- `article_examples.first_bit_transfer`：源标签等于第一位，目标标签等于第二位；均匀目标风险和最低风险均为 `1/2`，细化表示后最低风险为零
- `article_examples.weighted_tie_and_refinement`：单纤维标签为 `0, 0, 1`，权重为 `2, 1, 3`；最低风险为 `1/2`，细化后为零
- `A_compilation` 与 `B_representation`：另外的非平衡树、非均匀总体变式；完整建表共六次谓词测试，目标风险为 `3/8`

独立纯数学检查可执行 `python3 audit/argument_oracle.py`。它不导入 `model.py`。它的有限检查与一般证明仍是两件事。

## 接口

`Tree(spec).evaluate(input)` 返回标签和谓词测试数。`Tree(spec).compile()` 创建完整 `Lookup`；`train_lookup(inputs)` 只复制原树在所选输入上的标签，不从外部真实训练标签学习。`Lookup.evaluate(input)` 返回标签及约定的一次抽象查表代价。未知输入抛出 `UnknownInput`，不合法规格抛出 `SchemaError`。

`RepresentationDomain(spec)` 接收对象、表示代码、真标签和可选精确权重。方法为 `risk(decoder)`、`sufficient()`、`sufficient(positive_support_only=True)`、`best_decoder()`。风险与错误质量均为 `fractions.Fraction`。预测标签允许任意非空字符串，不要求先声明标签集合；最优值仍能在有限的实际真标签中达到。解码器必须覆盖且只覆盖当前总体出现的代码。因此源、目标代码集合不一致时，调用者须先明确扩展或限制解码器，接口不会猜测缺失代码的含义。

`Judgment(claim, origin)`、`copy_judgment(judgment, count)`、`distinct_origins(copies)` 记录简单来源信息。`diffuse(graph, seeds, judgment)` 返回同步传播的累计快照、首次到达轮次及最终持有者。它不检查断言真假。

所有名字和标签必须是非空字符串。规格拒绝多余字段、缺失条目和错误类型。树、谓词、表示总体和查表数据会被复制成只读快照，防止普通调用者修改原字典而改变已经校验的模型；这不是对同一 Python 进程中恶意反射代码的安全隔离。

## 必须保留的边界

- 完整编译存下所有声明输入的原答案，不学习未见输入、不修复错误，也不测量 CPU 加速。
- 根本身为叶子时需要零次谓词测试，约定的一次查表反而更多。
- 编译允许空域。风险模型要求非空域及正总质量，但允许对象或整条纤维质量为零。
- 零加权错误约束的是正权重对象；有零权重时不等于全域充分。
- 源领域成功不保证目标领域成功，即使表示代码字母表相同。
- 同一判断的更多副本不会产生更多原始观察；来源标识不同也不自动证明统计独立。
- 增加边可以加快或扩大传播，但不提供真假检验。
- 有限测试检查实现和例子。一般结论依赖 `MODEL.md` 中的证明及其明确假设。
