# 中文导读：快判断、表示与传播，分别保证了什么？

这里是为了辅助阅读历史文本而新建的有限模型。**它不是孔狄亚克自己的数学，不是对其心理学的实验验证，也不构成历史论断的证据。** 历史解释、版本与引文请看配套文章；这里的对象、权重、树和网络都是人为构造。

## 1. 先运行，再区分三种问题

在本目录执行：

```sh
python3 demo.py
python3 -m unittest -v test_model
python3 verify.py
```

第一条输出精确结果。第二条运行测试。第三条分别以普通模式、`-O` 和 `-OO` 运行，保存真实日志与环境信息。只需 Python 3.10 或更新版本的标准库，没有安装、网络或远程写入步骤。

阅读结果时，始终分开问：答案有没有改变？答案是否正确？答案传播给了多少人？这三个问题的答案没有被预先设定成一样。

## 1.1 正文例子对应哪些输出？

同一个 `demo.py` 现在同时运行正文的精确例子和补充变式；它们不是同一组数值。

- `article_examples.xor` 对应正文四点异或树：`00, 01, 10, 11` 的真标签为 `0, 1, 1, 0`；每次两次谓词测试，完整建表共八次。把 `11` 的叶子改为 `1` 后，树和完整表都错一个输入，风险均为 `1/4`。
- `article_examples.first_bit_transfer` 对应正文只保存第一位的表示：源任务判断第一位，风险零；目标判断第二位，原解码器风险和最优风险均为 `1/2`。把完整二位保留为细化表示后，最优风险为零。
- `article_examples.weighted_tie_and_refinement` 对应正文标签 `0, 0, 1`、权重 `2, 1, 3` 的单纤维例子：总质量六，两个标签各占三，最优风险为 `1/2`。把最后一个对象分开后，最优风险为零。
- 下文第2–6节讲的是 `A_compilation` 和 `B_representation` 下的补充变式：非平衡树完整建表共六次谓词测试，非均匀目标总体的风险为 `3/8`。不要把这两个数当成正文四点例的运行值。

细化为什么不能使最优风险升高？若新表示能够恢复旧表示，就可以先恢复旧代码，再执行原解码器，逐点复制原预测。在同一对象、标签、权重且不限制解码器复杂度时，新的可选方案至少包含旧方案。这个结论只保证可达到的最优值，不保证实际训练器找到它，也不免除获取新属性的代价。

## 2. 从两次判断到一次查表

`demo.py` 的 `tree_spec()` 定义四个输入：`a`、`b`、`c`、`d`。这里的 `round` 和 `bright` 只是布尔谓词的名字；代码直接给出它们在整个有限输入域上的真假值，没有读取真实感官数据。

树先查 `round`。为假时输出 `drop`；为真时再查 `bright`，后者为真才输出 `keep`。于是：

- `a`：一次谓词测试，输出 `drop`
- `b`：一次谓词测试，输出 `drop`
- `c`：两次谓词测试，输出 `drop`
- `d`：两次谓词测试，输出 `keep`

`Tree.compile()` 对四个输入逐一执行原树，把结果完整存入表。再次查询时，只取对应键的标签。

这里所谓“一次查表”是人为规定的抽象代价，不是计时数据，也不是 Python 字典最坏时间复杂度的结论。它省略了编译、校验、散列、存储分配等成本。根节点已经是叶子的树需要零次谓词测试，不能据此宣布任何树都被加速。

为什么完整表与树逐点一致？先对树作结构归纳：叶子直接正确返回；分支进行一次完整定义的布尔判断，然后进入满足归纳假设的子树。编译又枚举每个合法输入，因此每个表项都保存了该输入原来的答案。完整证明在 `MODEL.md`。

## 3. 快一点，也可以错得一样

外部真标签被另外指定为：`a` 与 `b` 应为 `drop`，`c` 与 `d` 应为 `keep`。因此原树在 `c` 上出错。编译后的表仍把 `c` 判为 `drop`。

- 原来：两次谓词测试，错误答案
- 编译后：一次抽象查表，还是同一个错误答案
- 均匀分布下，两者错误率都是 `1/4`

这说明语义保持只保证“答案未变”，不保证“变得正确”。查表还须保存每个输入的答案；完整域很大时，材料化全部答案可能代价很高。当前实现原本就保存完整谓词表，所以不能仅凭示例断言总内存一定增加。

再看 `train_lookup(["b", "d"])`：它只保留原树在这两个已给输入上的输出；这里没有读取真训练标签，也没有拟合参数。遇到 `a` 或 `c`，程序抛出 `UnknownInput`，不会假装已经学会。测试还构造了两棵树：在观察到的 `d` 上相同，在未观察到的 `c` 上不同。只凭相同的观察结果，不能保证判断出二者哪一个是完整规则。这一结论明确排除了额外规则或背景知识，并不否定有条件的推广。

## 4. 表示是否保留了目标问题所需的信息？

`RepresentationDomain` 为每个有限对象提供三样东西：表示代码、真标签、非负有理权重。省略权重时，每个对象的权重都是一。总权重必须为正；单个对象和整组对象可以具有零权重。API允许预测标签为任意非空字符串，而正文显式给出有限标签集；最优解总可以在有限的实际真标签中达到，所以这个接口差别不改变最小风险公式。

所谓同一个表示的“纤维”，就是被映射到同一代码的对象组。一个解码器对同一代码只能给出一个标签。因此：

- 同代码对象的真标签全部一致时，可以构造逐点正确的解码器
- 同代码对象需要不同标签时，没有只看代码的解码器能全部答对

这叫整个输入域上的结构充分性，不是关于人类概念的实验证据。

目标例子有四个对象：

- `t0`：代码 `A`，真标签 `keep`，权重 3
- `t1`：代码 `A`，真标签 `drop`，权重 1
- `t2`：代码 `B`，真标签 `drop`，权重 2
- `t3`：代码 `B`，真标签 `keep`，权重 2

代码 `A` 最好选择 `keep`，仍须错掉权重 1。代码 `B` 两种选择都须错掉权重 2；实现按标签字典序选择 `drop`。最低错误质量是 `1 + 2 = 3`，总质量是 `8`，最低目标风险就是 `3/8`。

一般公式只是把每个纤维的“总质量减去最大单标签质量”相加，再除以总质量。每组独立选择自己的最优标签，所以逐组最优可以同时达到。这是本包给出的数学证明，不是由枚举几个例子得到的猜测。

## 5. 原领域全对，不意味着新领域全对

源领域只有 `sA` 与 `sB`：代码 `A` 对应 `keep`，代码 `B` 对应 `drop`。解码器 `A → keep`、`B → drop` 的源风险是零。

把同一解码器转用于上述四对象目标领域，目标风险却是 `3/8`。代码字母没有改变，但目标对象的标签分布改变了。

还有更强的反例：目标领域两组各自仍然标签纯净，只是正确对应变成 `A → drop`、`B → keep`。表示在两个领域都结构充分，源解码器的目标风险却达到 `1`；换成正确的目标解码器，风险可以是零。因此，“表示足够”和“沿用的解码器正确”也必须分开判断。

这个例子没有训练过程或抽样误差。源和目标真标签均被完整给定，风险通过有理数运算精确计算。

## 6. 零权重不能悄悄消失

零权重例子中，代码 `A` 下一个 `keep` 对象的权重是 `2/3`，一个 `drop` 对象权重为零。代码 `Z` 下两个标签冲突的对象权重也都是零。

结果是：整个域不充分；正权重支持集充分；最低加权风险为零。代码 `Z` 的最优标签按字典序选 `drop`，但它选什么都不影响风险。

因此“零风险”等价于正权重支持集上的条件，不自动等价于整个输入域上的标签一致。只有额外保证每个对象权重都严格为正，才能作后一推断。

## 7. 一百份副本与一百次独立观察不同

`Judgment` 存储固定断言与原始来源标识。把一份断言复制一百次，得到一百份记录，但来源标识集合仍只有一个元素。来源计数只是可追溯性记录：即使有两个不同标识，也不能仅凭标识断言统计独立。

若已经知道原始证据，确定性复制不会增加新的条件信息：给定原证据，副本的内容早已确定。`MODEL.md` 用有限事件的条件概率解释这点；程序本身没有估计置信度、可信度或人类信念。

## 8. 网络可以加快错误的流通

初始只有 `A` 持有断言 `2 + 2 = 5`。链为 `A → B → C → D`；另有一个孤立节点。

同步传播时，每轮所有持有者把原断言原样传给出邻居：

- 第 0 轮：`A`
- 第 1 轮：`A, B`
- 第 2 轮：`A, B, C`
- 第 3 轮：`A, B, C, D`

增加 `A → C`、`A → D` 后，第 1 轮就覆盖同样四个节点。孤立节点仍未收到。把断言换成 `2 + 2 = 4`，每轮持有者集合完全不变，因为算法没有读取真假。

归纳证明说明，第 `t` 轮恰好覆盖距初始持有者的最短有向路径长度至多为 `t` 的节点。最终覆盖所有且仅有可达节点。增加边不会延迟现有节点的到达时间，但不保证每次都严格加快；也可能扩大最终覆盖范围。示例专门选了最终覆盖相同、到达更早的情况。

这不意味着现实讨论不能纠错，只表明当前规则只有原样复制，没有证据核查、异议、修正或拒绝传播的操作。

## 9. 测试到底验证了多少？

20 项测试包含：202 棵小树、768 个加权表示总体、4,096 个三节点图与种子集合组合，以及缺字段、错类型、循环、未知输入、零质量、深树、真值改变和只读快照等检查。最优解与所有二元解码器枚举比较，传播与独立最短路径实现比较。

这些都是有限的程序检查。普通、`-O`、`-OO` 三种模式通过，说明本次运行在这些模式下得到预期结果，也检查了校验不依赖会被优化移除的 `assert`。一般命题仍依靠明示假设和证明，历史结论仍依靠文本证据。
