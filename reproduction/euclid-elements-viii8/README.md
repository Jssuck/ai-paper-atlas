# VIII.8：把已知等比链迁到同比的端点

现代正整数教学重构，不是古代实跑证据或一般定理的计算证明。给定至少三项的恒比链和一对同序同比的新端点。先将已知链除以整体最大公度，得到最小链；按照 VIII.3 检查其端点互素，再根据新首项恢复最小链的整数倍数，并用新末项核对。这样既保留项数，又保留相邻公比。新链相对旧链的缩放不一定是整数。

(16,24,36,54) 的最小链为 (8,12,18,27)，旧链与新链分别是它的 2 倍和 3 倍。新端点 24、81 对应新链 (24,36,54,81)，相对缩放 3/2。只调换新端点会改变有序比；若把新端点改成 24、62，差仍为 38，却已不同比。端点 4、64 可以来自 (4,16,64)，也可以来自 (4,8,16,32,64)，所以不省略原链指定的项数。默认给定数大于 1、非恒等比；单位输入及常数链以显式现代模式核对。

测试另直接按首项比用 Fraction 逐项缩放，不使用最小链或端点最大公度作为该路的计算条件。
