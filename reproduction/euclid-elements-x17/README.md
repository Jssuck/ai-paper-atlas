# 《几何原本》X.17：由矩形关系还原两段

在正有理长度坐标中，`divide(B,A)` 要求 `B>A>0`，用 `p+q=B`、`pq=A²/4` 还原两段。平方差 `B²−A²` 是两段之差的平方。程序检查它的既约分子、分母是否都是整数平方；如果是，返回精确的两段（从小到大），否则保留精确差平方并返回 `parts=None`。后者不是说没有正实解，只是没有有理长度坐标；不近似无理根。在模型内，部分与整体可公度恰好等价于部分坐标为有理数，因为整体 `B` 是正有理数。

例如 `B=5,A=4` 时两段为 1 和 4；`B=3,A=2` 时差平方为 5，实解是 `(3±√5)/2`。相等、反序及非正输入均被拒绝，严格条件排除等分、零段或无实解等边界。

独立基线在 `1≤A<B≤64` 枚举两段的双倍整数坐标 `u,v`，检验 `u+v=2B` 和 `uv=A²`。在整数输入上，若差平方有有理根，它必是整数，因此双倍坐标枚举覆盖所有有理解。实跑核对 2,016 对，其中 54 对存在有理长度坐标，1,962 对没有。有限实验不是一般性证明。
