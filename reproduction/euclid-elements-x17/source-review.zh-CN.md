# X.17 原典核对

- [Heath 1908 卷 III](https://www.wilbourhall.org/pdfs/Heath_Euclid_III.pdf)印页 41–43 收题与双向证明。第 43 页行注 45 说明省去平方差结论后重复使用技术词 δύναται 的等价说法；不是略掉新推理。随后评注延续到第 44 页，用现代二次式解释并提出有关古代数值动机的解释，这不等于原命题明写代数方程。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=297)印页 297 开题，298 有图与第一支及第二支前段，299 完成第二支和略写重述。题名匕首号在 299 页脚注解释二次式；该代数式不是正文。希文 Ζ 是英译 F，正文平方差处保有 δύναται 的重复说法。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.10.17.html)希栏保有末尾略写重述，英栏止于反向结论。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookX/propX17.html)保留重述；其重述中「四分之一减去正方形」易误导，希文是施作面积等于指定四分之一，而在给定基线上亏缺正方形。该导读的行内归一式还漏了根项系数的一半；应由面积方程重新验算。
- 按图取 B、F、E、D、C 的次序，E 为中点且 EF=ED，则 BF=DC、FD=2ED。II.5 对同一直线的等分与不等分给面积恒等式；乘四后 FD 的平方等于长短两整线的平方差。前提短线严格较短，故 D 不在中点；另一取向交换两部分但不改变 FD 长度和公度判断。
- 正向按 X.15 将两部分公度传到 BC 与 DC，X.6 用整数比 1:2 的倍量关系联结 DC 与 BF、DC 的和，X.12 传递后再用 X.15 取余 FD。逆向从 BC 与 FD 公度起，依 X.15 得余量与 BC 公度，再用 X.6、X.12 接到 DC，末用 X.15 得 BD 与 DC 公度。现代有理缩放捷径不等同原文引注顺序。
