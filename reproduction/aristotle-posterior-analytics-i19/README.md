# 《后分析篇》I.19：链、中项与词表边界的最小教学复现

## 定位与限制

这是**现代教学重构及真实实跑**，不是原文代码、古代心理实验或完整复现。原文 I.19 提出向上、向下、固定端点间继续插入中项的问题，涉及否定链与相互谓述；本章未完成这些无限性问题的全部证明。本实验只核查有限外延模型与精确有理数前缀，不能证明所有证明链终止，不能把有限词表的“找不到中项”认证为科学直接性。

集合包含只能表达某些外延关系，不能认证本质、原因、自然谓述或客观真理；同外延商类不判断原文末段自然/偶然方向差别。全部集合非空，这是显式教学域选择，不声称处理一切空项语义。

[原文参照：Mure，Book I Part 19](https://classics.mit.edu/Aristotle/posterior.1.i.html) · [中文深读](../../papers/ancient/aristotle-posterior-analytics-i19.zh-CN.md)

## 模型定义和逐步核查

### 1. 有限包含链

每个命名项是非空有限对象集。向上用严格包含；向下反转相同关系。`strict_chain`检查每相邻两步，返回步数及集合基数作为秩。固定有限对象域中每次严格上升基数至少增加1，所以严格链长度受域大小限制；这是有限条件下的一般论证，而不是输出本身证明的无限域结论。

示例C={0}、B={0,1}、A={0,1,2}具有秩1、2、3。若词表仅有C、A，`middles`返回空；新增B后返回B。前一种“空”只关于该词表，不是关系在所有候选概念下直接。

同外延别名B_alias加入后返回两个名字，但它们属于同一外延类；B到B_alias不是严格包含，不能冒充进了一层。该商结构是现代工具，不是把原文的可换位项讨论化约为集合论。

### 2. 两种桥接

肯定桥接前提为C包含于B、B包含于A，结论C包含于A：任取C中元素，经两次前提即可得到属于A。否定桥接前提为C包含于B、A与B不交，结论A与C不交：若有共同元素，它也属于B，违反A与B不交。源码对失败前提报错，不把它误报成结论反例。

穷举4对象的15个非空子集，检查15³=3375个有序三元组(C,B,A)：175组满足肯定前提、110组满足否定前提，均无结论失败。两类不要求穷尽所有三元组；其他配置并不满足所测前提。

计数独立复核：对肯定嵌套，每个对象有4种成员模式；除去C为空的3⁴种，得4⁴−3⁴=175。对否定前提也有4种成员模式；同时要求C与A非空，以容斥得4⁴−2·3⁴+2⁴=110；C非空自动使B非空。测试用这些公式核对枚举。

### 3. 固定端点不是自动有限

另取有理数序，不与有限对象集合模型混同。若有理数l<u，m=(l+u)/2仍是有理数，且m−l=u−m=(u−l)/2>0。因此任意给定两端间总可再插入一个精确中点。该不等式是一般构造论证；运行8次只是展示。

从0与1开始，每次细分最靠近1的区间，得到0、1/2、3/4、…、255/256、1，余隙1/256。对任意自然数n，有限前缀最后间隙为2的负n次幂，严格大于0。实现仅允许0至256次，作为资源边界，不把256当数学停止点。原文的自然谓述不已被证明等同有理稠密序，因此该模型是防止“端点固定所以中项有限”误推的教学对照，不是直接反驳原作者。

## 可复核结论

- 有限词表搜索可以找到中项，但“没有找到”依赖候选范围。
- 外延相同的重复名字不增加严格层级；这不解决自然/偶然谓述问题。
- 肯定与否定桥接在所述集合语义中保真，但不能由此认证所选中项科学恰当。
- 有限域秩界、有理序任意细分是不同条件下的数学结论。有限运行既不能证明无限链终止，也不能单靠列出8个点证明可无限继续。
