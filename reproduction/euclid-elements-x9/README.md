# 《几何原本》X.9：平方可公度不等于长度可公度

原创精确算术教学模型。`classify(area_a, area_b)` 接收同一面积单位下两个正有理平方量，先约分面积比，再用整数平方根判断既约比的分子、分母是否都是完全平方数。若两者都有精确整数平方根，返回既约边长比和共同边长单位的平方；否则边长比没有有理数见证。模型中平方总可公度，其共同面积量可取共同分母的倒数。它不是接受任意实数的判定器：两个各自不在此输入域的面积也可能有理成比，例如同为无理数的 `√2` 与 `4√2`，但它们的比例可在纸上化为 `1/4`。

平方量 `(2,1)` 的面积比为 2，边长 `(√2,1)` 不可公度；`(50,72)` 的面积比化为 `25/36`，边长比 `5/6`，共同边长为 `√2`。所以边长各自不必是所选外部长度单位的有理倍数。

独立基线直接生成整数比例的平方，不调用整数平方根。面积对两项均取 1–80（有序、不按比例去重）：如边长比存在且既约，其两个平方必等于既约面积比的两项，因此枚举边长比两项 1–9 已涵盖全部可能。本次实际为 6,400 个有序输入，其中 224 个边长可公度，6,176 个仅平方可公度。有限检验不是一般定理的证明。

python3 -B -OO -m unittest -v
