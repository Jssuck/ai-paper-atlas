# IX.31 原典核对

- [Heath 1908 英译卷 II](https://www.wilbourhall.org/pdfs/Heath_Euclid_II.pdf#page=430)印页 417–418、扫描页 430–431。417 页末设奇数 A 与 B 互素，C 是 B 的两倍，并反设 A、C 有共同量度；418 页取 D、断定其为奇、借 IX.30 让 D 量尽 C 的一半 B，抵触原假设。该页在结论和证毕之后另起 IX.32。
- [Fitzpatrick 希英对照本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=275)印页及扫描页 275。符号 C、D 对应希文 Γ、Δ。希文含三处方括记号，英译对应标注「也」、反设中的 A 与 C、以及量尽一半时的主词 D；Heath 在最后一处也用方括提示 D。两译本都明确标 IX.30；未见这段另需应用的正式勘误。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.31.html)希文保留反证后的重复结论及证毕，英文结束于第一次判定 A 必与 C 互素，并未缺失核心反证。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX31.html)完整保留收束，另以括注链接 IX.28 来解释奇数的因子为何必奇；Heath 和 Fitzpatrick 在该处未标 IX.28。若 D 为偶，则其任意正整数倍为偶；现代可以显式抽出因子 2，不需要预先假定另一因子为奇。
- [卷 VII 定义 1–2](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII1.html)区分单位与数，[定义 12–14](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII11.html)给出互素、合数等关系。在反设中 D 是非单位公因数，非任意选取的素数；「A 与 B 互素」也不要求 A 本身是素数。Joyce 导读另指向 VII.24 的一般结论，不能把一般化写成正文已经给出的证明。
