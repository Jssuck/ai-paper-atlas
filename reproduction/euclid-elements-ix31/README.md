# 《几何原本》IX.31：倍增保持与奇数的互素关系

给定奇数 $`A\ge3`$ 与整数 $`B\ge2`$，且二者互素。若非单位 $`D`$ 同时度量 $`A`$ 与 $`2B`$，因为 $`A`$ 为奇，$`D`$ 必奇；按 IX.30，$`D`$ 也度量 $`B`$，与互素前提矛盾。教学程序显式枚举非单位共同因子，并用份数减半核验该传递。反向从 $`D\mid B`$ 到 $`D\mid2B`$ 直接成立。两边非单位公因子集合相同（两边另都有单位）是现代的较强表述，即使 $`A,B`$ 不互素也成立。

例如 $`(15,8)`$ 倍增后为 $`(15,16)`$，仍互素。$`(45,30)`$ 非互素，三个非单位公因子 $`3,5,15`$ 在倍增后保持不变。去掉 $`A`$ 为奇的前提会失败：$`(4,3)`$ 互素，$`(4,6)`$ 则不互素。单位、零和负数不在命题接口内。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线以 `math.gcd` 比较倍增前后的最大公约数，并与逐个候选因子扫描交叉核验。网格取 $`A=3,5,\ldots,63`$、$`B=2,\ldots,64`$。枚举用于有限教学核验，不替代证明。Notebook 日志来自标准库实跑三个代码单元，不是 Jupyter 内核运行。

实际环境为 CPython 3.12.14：[普通](normal.log)、[-O](O.log)、[-OO](OO.log)；[Notebook](euclid-ix31.ipynb) 与[回放日志](notebook-replay.log)。
