# VII.14：从相邻比较到首末比较

这是现代正整数上的教学重构，不是历史运行记录或一般命题的计算证明。代码以两行等长数列为输入，至少三项；所有给定数是大于 1 的整数。为展示真份或若干份的直接方向，限制两行各自严格递增且第一行对应项严格小于第二行；这些是程序采用的范围，不是现代等式的必要条件。

每一步都先核对两行的相邻比，再按 VII.13 的换比思路检查对应两列的纵比。把相邻的纵比相等沿全序列传递，最后对首列和末列换回，检查两行的首末比。程序用最大公度后的互素计数比较；测试直接用原始数构造 Fraction，独立核对相邻、纵向和首末比。

三项例 (4,6,10) 对 (10,15,25) 的相邻比依次为 2/3、3/5，纵比均为 2/5，首末比也为 2/5（此处两类比相等只是数字巧合）。四项例分别追加 14、35，纵比仍为 2/5，首末比改为 2/7。若用 (10,16,25) 替换三项例的第二行，首末比仍为 2/5，但两个相邻比较的对应关系被破坏，程序拒绝。

一致倒序、重复项、两行相等也可能满足现代分数等式，单列同一对数可能有单位公度；这些都不改动本程序的直接方向限制。
