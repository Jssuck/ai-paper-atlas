# VII.33：任意多个数的最小同比表示

现代整数教学重构，不是古代实跑或一般定理的计算证明。给定至少两个大于 1 的整数，程序依次更新前缀最大公度。若全体最大公度为 1，当前数列已经最小；否则把每项除以同一公度，产生保持顺序的最小同比数列。返回前缀公度用于观察扩展输入时哪些公度保留下来。同率候选必须是该最小数列的同一正整数倍；代码检查首项倍数及每一对应位置。

18:30:45 的前缀公度是 18、6、3，最小表示为 6:10:15。后三数整体公度是 1，但任意两项仍有非单位公度。将其错序为 15:10:6 不保留有序比。输入仅有一项时缺少指定的多项比，程序拒绝；输入全相等时，现代扩展给出全 1，普通输入也可能产生某个单位项，例如 3:6→1:2。这些输出不把单位当作古文中的给定「数」。

独立有限预言机从候选首项 1 开始提高，按 Fraction 推出其他对应项，直到所有项都是整数；原输入保证有限上界。又独立枚举每个前缀的公因数，核对程序的最大公度轨迹。
