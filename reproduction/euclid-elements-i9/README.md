# Euclid《几何原本》I.9：角平分构造的精确教学核查

这是一组原创坐标教学代码，不是古代实验的复现，也不是通用尺规作图器。正文负责一般证明；此处只检查一个显式有限输入族及若干反例。未安装任何第三方依赖。

## 模型与证书

`geometry.py` 以两有理数表示 `a+b√3`。加减乘除及正负判定均为精确运算；符号判断在异号项时比较 `a²` 与 `3b²`，不通过浮点近似。测试中额外以 70 位 Decimal 对有限整数系数组做独立符号交叉检查；Decimal 不参与几何证书。

输入 A、D、E，要求 AD=AE>0，AD 与 AE 不共线。生成 DE 上两个等边三角形顶点：中点加或减 `√3/2` 倍的 DE 旋转向量。只选择与 A 分居直线 DE 两侧的 F。这是对 I.1 两个候选顶点的现代坐标建模，不是对 I.3 截长或圆交点存在性的程序证明；也没有用单位向量相加冒充古代尺规操作。

`certificate` 分别报告：非退化角、等距截取、等边三角形、A/F 异侧、非零输出射线、严格内部射线、相等夹角。最后两项不合并：

- 内部以两个有向叉积检测 F−A 是否处于 D−A、E−A 张成的开正锥；这里原角按小于平角的凸角解释。
- 相等夹角以点积同号及平方交叉乘积检测，避免仅比较平方而误认补角。
- 零向量不定义夹角。一般证书失败不表示每项都应失败；各项独立呈现。

## 分支反例为什么重要

设 A=(0,0)、D=(u,v)、E=(u,−v)，u,v>0。异侧候选为 F=(u+√3v,0)。同侧候选 F=(u−√3v,0) 的三种结果都保留：

| u,v | 同侧 F | 输出情况 |
|---|---|---|
| 2,1 | (2−√3,0) | 内向等角，但不符合这里固定的异侧构造证书 |
| √3,1 | (0,0) | F=A，无输出射线 |
| 1,1 | (1−√3,0) | 外向；两夹角相等仍不能推出内角平分 |

另有反向射线、不等距截取、重合截点、共线原角、任意错误顶点五份拒绝证书。反向的等角射线不是原凸角的内部射线；不要把这种情形不加限定地称为邻补角的外角平分线。

## 运行

在本目录执行：

```sh
python3 run_all.py
```

实际子命令完整保存在 `run-summary.json`，包括普通、`-O`、`-OO` 下各运行 `test_geometry.py`、`run_examples.py`，随后生成和执行 Notebook。每种模式有 **12 项 unittest 测试**，各模式的枚举结果完全相同；每种模式检查 **1536 份正例证书**，来自 8×8 组正有理参数、3 个平移、4 个直角旋转、2 种端点顺序。这个数字是变换后的测试输入数，不表示 1536 个不同角，也不构成对所有实数输入的覆盖。另核查 3 种同侧分支和 5 份其他失败证书。

- `environment.json`：实际 Python、系统和依赖范围。
- `logs/tests-*.log`：三模式单测真实标准输出/错误及退出码。
- `logs/examples-*.log`、`results-*.json`：三模式真实枚举与反例结果。
- `run-summary.json`：真实执行时间、命令、退出码及模式一致性。
- `teaching.zh-CN.ipynb`：4 个代码 cell 的中文教学 Notebook，含已执行输出。
- `create_notebook.py`：标准库构建 nbformat 4 Notebook；已阅读安装技能，但其本地 scaffold helper 不存在，附属资源也不可读取，故未使用该 helper，且未安装替代包。
- `verify_notebook.py`、`notebook-check.json`、`logs/notebook*.log`：按顺序共享 namespace 执行代码 cell 的真实记录。执行方式是标准 Python `compile/exec`，**不是 Jupyter kernel 或浏览器执行验证**。
- `SHA256SUMS.json`：本目录公开文件哈希，排除清单自身和缓存。重跑会改变计时/日志及相应哈希。

## 不覆盖什么

此数域不足以表达一般实数角的所有尺规中间量；有限族只用于程序检查。模型不实现直尺圆规的物理约束、不自动处理任意输入射线的等距截取、不验证 I.8 的一般几何定理，也没有自动填补《原本》的序关系与连续性前提。所有例子通过不能取代正文的证明重建；Notebook 的 Python 执行也不等于 GitHub 公式显示验证。
