# II.7 最小复现：有说明、有名字，不等于有对象

## 1. 本实验是什么

这是《后分析篇》II.7的**现代有限模型教学重构**，不是把古代全部论证写成程序，也不是验证现实对象或科学本质的工具。原文问题见[Mure第二卷Part 7](https://classics.mit.edu/Aristotle/posterior.2.ii.html)：名称含义、事物存在和本质知识不能不加区别；给定一种描述，还要说明它为何对应所声称的对象。下一章会重新审视疑难的结论，因此不把本章写成最终否定一切定义知识。

本实验只做三件窄事：

1. 检查两个有限谓词的外延相等，展示空外延也会相等。
2. 对给定解释检查一个对象是否为见证，并检查显式名称字典是否把名字绑定到指定公式。
3. 区分只在样本上相等与在整个有限域上相等。

现实存在、自然可能性、本质、命名惯例本身是否可靠，均不由程序认证。尤其是词表中的`inhabited`只指当前有限解释非空，不指实际世界已发现了这种事物。

## 2. 假设与接口

- `U`：有限、显式给定的可哈希对象集合。枚举包含空域作为现代边界测试；它不是宣称Aristotle接受空论域。
- `P,Q`：`U`的子集，表示一元谓词的当前外延；重复成员按集合处理。
- `S`：观察过的对象集合，必须包含于`U`。
- `w`：候选见证；在`U`外返回假；谓词或观察集本身越界则抛`ValueError`。
- `lexicon`：名字字符串到公式标识字符串的显式字典。`formulas`另将公式标识映射到外延。两层不能合并成“字符串出现所以对象存在”。

|接口|检查内容|不检查什么|
|---|---|---|
|`coextensive(U,P,Q)`|集合相等|相同意义或本质|
|`witness_valid(U,P,w)`|`w`属于给定`P`|现实世界的对象是否确实存在|
|`transfer_witness(U,P,Q,w)`|相等且`w`是`Q`见证|`Q`的证据是否来自可靠实验|
|`observations_agree(U,S,P,Q)`|`S`内所有对象成员状态相同|未观察对象或无限域|
|`binding_valid(lexicon,claim)`|字典明确记录了相应名称—公式关系|命名惯例是否真实、公式是否本质定义|
|`named_witness(U,formulas,lexicon,claim,w)`|上述绑定和成员见证同时成立|任何现代/古代完整定义理论|

`NameClaim`包含`name`与`formula_id`两个字符串字段。词典未登记该名字、登记到另一公式、或公式表缺该公式时，命名见证检查返回假。这是证书失败，不是宣告对象不可能存在。

## 3. 手算与一般证明

### 3.1 同延不推出非空

令`U={0}`，`P=Q=∅`。对每个`x∈U`，“x属于P当且仅当x属于Q”成立，但没有任何`P`见证。非空论域内已足够给出反例，不依赖空域。

反例推翻的是“任意P,Q若同延则P存在对象”这一形式推断，不推翻有额外存在前提的论证。

### 3.2 补入见证后的转移

给定任意集合`U`及其子集`P,Q`，若`P=Q`且有`w∈Q`，则由集合相等的定义立即得`w∈P`。所以可推出`P`非空。这个证明不要求`U`有限；实现和枚举只是核查有限实例。

代码`transfer_witness`返回的是两项前提同时满足，不创造新对象。其正确性义务是每次返回真时`witness_valid(U,P,w)`也真。检查失败不代表P为空，例如P={0}、Q={0,1}时同延前提失败，但P仍有见证。

### 3.3 字典绑定不是成员事实

假设公式表`equidistant→{0}`，词典只记录`circle→equidistant`。见证0使公式非空；`circle`对应声明被接受，改称`mountain_copper`则被拒，因为词典没有该绑定。把词典改为另一个名字会改变绑定检查，不改变集合成员事实。这不是拒绝更名，只是要求更名作为另一个显式输入。

两个公式即使有完全相同的外延，也不会被代码当成相同公式标识。这种保守策略避免从外延巧合自动发明语义同一；代价是合法同义别名必须另行登记。

### 3.4 样本一致不推出全域一致

令`U={0,1}`，`S={0}`，`P={0}`，`Q={0,1}`。样本上两者都包含0，因此一致；在未观察对象1上却不同。一般地，只要`S`遗漏某个`u∈U`，就可选P与Q仅在u上不同，构造同类反例。

反之，若`S=U`且样本一致，则定义直接给出`P=Q`。这仍只认证外延，不认证本质；有限全域枚举和现实抽样也不可混同。

## 6. 限制与复盘

本程序没有给出从词义自动发现对象的算法，没有解决“存在不是属”的全部形上学论证，也没有裁定归纳如何把握本质。样本反例只说明无附加条件时的外延推广失败，不可用来替代II.7对本质说明的论证。字典真实性、公式取义、观察可靠性均为模型外输入。不存在从这些布尔函数自动生成“真实本质已知”的接口。

### 练习与答案

1. U非空能否阻止空谓词？不能，U={0}、P=∅即反例。
2. P=Q能否推出两者都存在见证？不能；加入Q的见证w后才可转移。
3. 转移检查返回假是否说明P空？否，P={0}、Q={0,1}仍非空。
4. 字典绑定通过、公式为空，命名见证通过吗？不通过，因为成员证据缺失。
5. 有公式见证、字典无名字，命名见证通过吗？不通过；补入对应命名声明是额外输入，不是从成员事实演绎出来。
6. 两公式外延相同就有同样含义吗？本程序不给出此结论，公式标识独立检查。
7. 样本S为空时一致能说明什么？仅说明没有观察到不同，对全域没有约束。
8. 若S=U，外延相等是否认证本质？仍不能；它只解决有限解释的成员关系。
9. 341为什么不是4×2^4？n依次取0..4，每个n对应4^n对谓词，应求和。
10. 为什么零违例不能替代一般证明？枚举只到n=4，一般证明必须覆盖任意集合；这里的见证转移由相等定义直接证明。
