# 《几何原本》X.8：平方比的整数平方证书

这是原创的精确算术教学模型，不是对任意实数的判定器，也不是古代几何作图复现。给定正的有理平方比 `q=(A/B)^2` 和正的有理参考量 `B`（默认为 1），`classify(q,b)` 先用 `Fraction` 化简 `q=p/d`，再对两个整数分别取平方根下取整。若二者都是完全平方数，输出精确的 `A/B` 与 `A`；否则至少一个整数严格夹在相邻整数平方之间，正的比值没有有理数见证。严格夹逼不是对根的浮点近似。`B` 为有理数只用于输出具体长度；判据只依赖平方比。

例如 `3/2` 无有理根；`25/36` 与 `50/72` 都给出 `5/6`；`4/9` 给出 `2/3`。等比 `1` 作为现代输入也接收。浮点数、布尔值和非正量均拒绝。

测试用另一条路线生成分子、分母都在 1–64 的全部候选有理数之平方，比较 4,096 个输入平方比（按有序输入对计，不去重），其中 180 个有理根。该候选界在此网格上完备：一旦根写成互素的 `m/n`，平方仍为既约的 `m²/n²`，因此网格内若有根，其两个整数都不超过 64。它不依赖 `isqrt`，但这个有界实验不是一般性证明。

Python 3.10+，只用标准库。在本目录运行：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```
