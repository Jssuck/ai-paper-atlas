# 《几何原本》X.27：仅平方可公度的中项边围出有理面积

相对于参考长度 `u>0`，输入两个正有理平方坐标 `a=(A/u)^2`、`b=(B/u)^2`，且 `k=b/a` 不是有理数的平方。函数 `construct(a,b)` 输出两条中项边 `C,D` 的相对四次幂 `ab,b³/a`，两边比的平方 `(D/C)^2=k`，及矩形相对面积 `CD/u²=b`。两边取正四次根，不作浮点近似。四次幂均属 `k` 的平方类（分别乘有理平方 `a²,b²`），所以两边皆为中项；矩形面积却与参考平方可公度。

例：`a=2,b=3` 时输出四次幂 `6,27/2`，比平方 `3/2`，相对面积 3。倒转两输入得到四次幂 `6,8/3`、比平方 `2/3`、面积 2；这里倒转输入不等同于在同一矩形上交换两边。若 `a=2,b=8`，比平方为 4，不满足命题前提。模型仅处理正有理平方坐标，不是一般实数判定器或尺规作图的实现。

独立基线枚举有理平方的既约根候选，不调用整数开根。原分子、分母均在 1–8 时，比和两个四次幂的既约项均不超过 4,096，因此枚举根项 1–64 完备。实跑核对 4,096 个有序代表（不去重），3,640 个成功构造，456 个平方对照被拒。以正量的四次幂核对面积，并校验比值。有限样本不能代替证明。

```sh
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v

```
