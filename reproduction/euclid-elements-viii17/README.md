# VIII.17：立方数与边长的非量度

现代整数教学重构，不是古代实跑或一般证明。字段按立方、边长的顺序记录。第一支：若 A=C³ 不量度 B=D³，则 C 不量度 D，这是 VIII.15「边长量度推出立方量度」的逆否。第二支：若 C 不量度 D，则 A 不量度 B，这是 VIII.15 反向推理的逆否。程序核对两个前提是否触发，不把前提不成立标成反例。若 D/C 的约分分母为 q，立方比的约分分母就是 q³；这不表示立方余数等于边长余数的立方。

(6,9) 的立方余数 81、边长余数 3，两支都触发；(4,12) 两支都不触发，交换为 (12,4) 两支都触发。(6,10) 的立方余数为 136，边长余数为 4，而 4³=64。默认给定边长是不同的非单位正整数，单位和相等只在显式现代模式使用。测试另用 Fraction 和 divmod 核对精确比值、余数与触发条件。
