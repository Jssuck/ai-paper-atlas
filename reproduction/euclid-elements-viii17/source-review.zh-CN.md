# VIII.17 · 原典与版本核对

- [Heath 1908，卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)，印刷 pp.370–371 / 扫描物理 pp.383–384。p.370 后半出现题头及 A、B、C、D 四条示意线、第一段完整及第二段的设题；p.371 顶部第二次 VIII.15、矛盾、结论和 Q.E.D.；下一段为译注，明言用 VIII.15 归谬。VIII.18 已另起标题，不是结语的一部分。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf)，pp.243–244。p.243 底部是双陈述，p.244 顶端为图及完整两段。希文用 A、B、Γ、Δ；英译用 A、B、C、D。两处 VIII.15 是英译的参照编号，不能当作希文正文自带编号。未见像 VIII.16 次段连接词那样的同类方括号补入；不据此主张所有版本无异读。
- [Clay 希英网页](https://www.claymath.org/library/historical/euclid/files/elem.8.17.html)：希文在末行有第二段的原题、否定结论和收束；英译在第二次援引 VIII.15 后停止。以扫描本及 [Joyce](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII17.html) 互验。Joyce 的 Guide 概称 VIII.15 的逆否，正文各自调用相反方向；其额外重述和文学引语不当作原文。
- 所见差异不改变两论证的方向；未识别出需要改写推导的本命题正式勘误。这是限定于所读版本的结论，不是手稿谱系研究。发布只含原创论述、书目链接，不含扫描或完整翻译。
