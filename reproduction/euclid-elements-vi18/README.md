# VI.18 教学复现：复制对角线两侧的角

[中文深读](../../papers/ancient/euclid-elements-vi18.zh-CN.md)

输入凸四边形 C-D-E-F 和有序目标边 AB；第一步把三角形 CDF 放到 AB 上，得到 G；第二步用共享边 DF→BG 放置三角形 DFE，得到 H。程序只做**保向相似**，不提供镜像选项。它没有实现任意多边形的分解、凸性检测或真实尺规操作；重拼的教学解释要求输入凸四边形且两三角形在共享对角线两侧。

- 全局算法以源基线 u=D−C、目标基线 v=B−A 求缩放旋转矩阵；对任一点先减去 C，再变换，最后加 A。
- 局部算法不应用全局矩阵。每一步从旧基线和旧射线的点积、行列式得到沿线、横线分量，在新基线坐标下只复制方向，然后以两条正向射线的交点求点。第二次计算以第一次的 G 为输入。
- 例：C=(0,0)、D=(4,0)、E=(3,2)、F=(1,3)，A=(1,1)、B=(1,7)。得到 G=(−7/2,5/2)、H=(−2,11/2)，两种算法结果相同。目标边 AB 对应源边 CD，次序对调会改变输出。把 G 关于 AB 镜像则保留到 A 的距离，却翻转有向面积，不是保向解。

python3 -m unittest -v
