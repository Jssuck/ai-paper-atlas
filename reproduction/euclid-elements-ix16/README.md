# 《几何原本》IX.16：互素两项不能续接整数比例项

程序以现代正整数模型计算唯一的有理候选 $`k=b^2/a`$。原命题范围为 $`a,b\ge2`$ 且互素：此时候选的约分分母仍是 $`a`$，故不可能为整数。现代接口允许单位：$`a=1`$ 时有整数解 $`b^2`$；若 $`b=1`$ 且 $`a>1`$，则无。非互素也不保证可续接，例如 $`(4,6)`$ 可续接 $`9`$，而 $`(6,4)`$ 只能续接 $`8/3`$。

在本目录用 Python 3.9+ 标准库执行：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立候选法在 $`a,b`$ 各取 1 至 32 时，逐个扫描整数 $`1\le k\le b^2`$，检查 $`ak=b^2`$。若有整数解，$`a\ge1`$ 保证不会超出此界。有限检查不替代一般证明。Notebook 日志记录标准库实跑三个代码单元，不是 Jupyter 内核运行。
