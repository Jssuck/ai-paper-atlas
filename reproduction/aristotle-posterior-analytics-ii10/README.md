# 《后分析篇》II.10：记录重排与解释信息的最小教学实验

这是围绕93b29–94a19设计的原创现代教学模型，不是古代自然学实验复现，不是定义的自动发现器。对应[中文深读](../../papers/ancient/aristotle-posterior-analytics-ii10.zh-CN.md)。不把云中火熄灭的古代雷声解释当作现代物理事实。

## 要回答的问题

1. 已给定中项及两项前提来源，证明式记录能否改写成含因定义式记录，并完整还原？
2. 只留下主项和谓项，能否唯一还原中项及来源？
3. 集合包含链的形式有效、主项存在、现实原因和本质认识是否同一件事？

本实验只回答显式记录和有限集合的结构问题。名义、含因、结论式、直接等是阅读角色，不是代码认证的互斥完备分类。尤其没有实现“本质统一判定”，也不把文本拼接当作内在统一。

## 文件与输入契约

- `model.py`：不可变记录、双向字段重排、结论投影、集合证书、名义查询和枚举。
- `test_model.py`：28项测试，包含反例、输入错误及独立成员级oracle。
- `tutorial.ipynb`：四个短代码单元和对应说明，八个稳定唯一cell id。
- `run_notebook.py`：标准库按序exec代码单元并保存真实stdout。不是Jupyter内核；未验证交互式前端。
- `run_all.py`：执行三种优化模式、实验与Notebook，记录环境、日志和SHA256。
- `environment.json`、`logs/`、`sha256.json`：实跑证据；散列清单不含自身和缓存目录。

`Proof(subject,middle,predicate,major_source,minor_source)`的字段必须是非空字符串。来源只是标识，允许两前提来源同名；词项也允许重合。它的构造不证明其前提真。`CausalDefinition`按主项、谓项、中项、次前提来源、大前提来源保存同样五项。`to_definition`、`to_proof`严格检查记录类型。

`chain_report`要求每个被引用词项都有外延，且外延包含于显式有限域。以S、M、A记三外延，返回S⊆M、M⊆A、S⊆A及S是否非空。若标签重复，字典同一键就是同一外延。`nominal_lookup`仅查给定词典，不从短语产生存在见证。

## 一般论证，不能用小实验替代

**字段重排可逆。** 设记录为(s,m,a,u,v)。正向映射依次保存(s,a,m,v,u)，逆向依次取第1、3、2、5、4项。因此合成逐项恢复原记录；反向合成同理。此证明对任意满足输入契约的字符串成立。它只证明本程序设计的重排不丢信息，不证明自然语言任意改写保持意义，更不证明来源真实。

**结论投影不是单射。** 记录(s,m,a,u,v)与(s,n,a,u,v)，只要m≠n就不同，但都投影到(s,a)。所以没有仅凭这一投影唯一还原原记录的函数；额外背景可以缩小候选，但那是新增信息。即使中项一样，来源不同也会被投影抹去。原文的“结论式定义”不等于这对字符串，投影只是教学类比。

**集合链传递。** 任取x∈S，第一前提给x∈M，第二前提给x∈A，故S⊆A。这个证明不要求S非空。因而合法链可以没有实例，形式保真不能单独证明对象存在。要获得一个实例须额外给出并核验x∈S。前提真也不等于中项是现实原因；集合模型没有刻画因果机制。

## 手算算例与反例

域{0,1}，S={0}，M={0}，A={0,1}是一条合法链。把M换为{0,1}仍合法，同一S⊆A结论不能辨别哪个M被使用。两个集合链的合法性不赋予两中项同等科学解释资格。

删大前提：S=M={0}、A=∅，次前提真而结论假。删次前提：S={0}、M=A=∅，大前提真而结论假。反过来，S={0}、M={0,1}、A={0}结论真而大前提假，所以结论也不能反证原推导的正确性。

空域三外延皆空，两前提及结论真，但`subject_exists`为False。词典可登记“羊鹿”的短语解释而不提供任何羊鹿实例。程序中的名称可理解性也仅是字典命中，不是人类真的理解了一个本质。

## 实跑范围与计数推导

实跑精确结果见`logs/experiments.json`，测试见三份`tests*.log`。

| 项目 | 数量/结果 |
|---|---:|
| n=0..4全部三集合组合 | 4681 |
| 两前提均真的合法链 | 341 |
| 合法链中S为空 | 121 |
| 传递违例 | 0 |
| 集合实现与独立逐成员oracle差异 | 0 |
| 五字段有限记录 | 108 |
| 结论投影种类 | 9 |
| 每结论原像记录数 | 12 |
| 记录往返错误 | 0 |

每元素有8种(S,M,A)成员模式，故总数Σ8^n=4681。合法链逐元素只允许000、001、011、111四种，Σ4^n=341。另要求S空时允许前三种，Σ3^n=121。记录枚举三个词项各从3个标签取值，两来源各从2个标签取值，3³×2²=108；结论3²=9，每结论保留3×2²=12种被丢信息。这不是全语言统计，也不是现实解释数量估计。

## 运行与重验

只需Python标准库，没有安装依赖。在本目录执行：

```sh
python3 run_all.py
python3 -m unittest -v test_model
python3 -O -m unittest -v test_model
python3 -OO -m unittest -v test_model
python3 model.py
python3 run_notebook.py
```

测试断言使用unittest方法，输入契约使用显式异常，不依赖会被`-O`删除的Python assert。重跑会更新运行时间、耗时、Notebook输出及散列，这是预期变化。Notebook脚手架helper在本环境未找到，因此按既有合法结构生成并核验id、单元顺序和真实输出；这不是技能安装或内核执行记录。

## 带答案练习

1. 改写时删除major_source，还能保证五字段往返吗？不能；不同来源会合并。
2. 三字段名称相同，来源不同，是同一个Proof吗？不是；记录保留证据来源差别。
3. 同一结论有两个中项，说明两个都是真实原因吗？不说明，投影只展示信息不足。
4. S为空，包含链是否失效？不失效，但无法给出S的实例。
5. 为何28项测试通过不等于证明一般可逆性？测试只覆盖有限输入，一般性来自逐字段合成证明。
6. 能否把来源字符串改成“已证明”获得科学知识？不能，它仍只是未验证标签。
7. 合法链的341如何计算？每元素4种合法模式，n=0..4求和。
8. 去掉中项后如何找回原解释？需要额外资料或候选约束，仅投影无唯一逆。
9. 两段文字串联成一个字段是否已实现原文“本质统一”？没有，本程序不检测这一哲学条件。
10. 该模型是否穷尽II.10全部定义用法？没有，只隔离信息保持、信息丢失和存在承担三项问题。
