# 《后分析篇》I.4：每一实例、属内必择与恰当主项

原创、低成本的标准库教学复现。本章是古代科学证明思想的阅读单元，不是可按现代实验协议重跑的模型论文。本附件不声称复现亚里士多德的全部认识论；只核查明示的有限布尔与集合模型。它尤其不能从共现数据自动识别本质、原因或必然性。

## 1. 三层必须分开

- **外延检查**：输入的有限对象/时间位置中，有没有主项成立而属性不成立的位置？
- **语义声明**：谁出现在谁的定义中、谁不依附另一承载者、哪个事件是哪个结果的原因？本程序只读取外部声明，不为其真伪背书。
- **恰当解释主项**：本章要求不是仅对任一实例为真，还要就其自身、且首先属于相应主项。有限候选集合中的最大覆盖类仅是诊断工具，不等价于这个解释要求。

例如样本中所有等腰三角形均满足某性质，并不说明该性质因等腰而成立。缺少非等腰三角形、没有更广类别、或把两个概念在样本中做成同一集合，都会妨碍仅靠外延识别恰当主项。

## 2. 编码与一般正确性理由

### 对象与时间

`objects = n`、`times = k`，位序 `i = t*n+x` 代表对象 x 在时间 t 的位置。subject 和 predicate 是长度 `n*k` 的布尔表，整数位图只为紧凑存储，不赋予古代文本机器表示。

every_instance 返回 subject 的所有置位是否也在 predicate 中置位。counterexample 返回最早的违例位置（按先时间后对象），无违例返回 None。主项随时间变化也允许：当某对象在该时刻不属于主项时，不要求它在该时刻具属性。这比假定对象永远属于同一类更明确。

一般论证：subject & ~predicate 的某位置为1，当且仅当该位置主项为真而属性为假；该数为0恰好表示没有违例。若非0，最低置位确实是一个违例，除以n与取余恢复时间和对象。这个有限编码论证不把“检查了两时刻”提升为“所有真实时刻必然如此”。空主项使全称蕴涵空真；因此下面候选主项诊断另行排除空类。此处没有自动加入历史上的存在条件。

### 属内两个互斥选择

relative_partition(genus, left, right) 检查属中的每一对象恰在两个属性之一中。它不要求属外对象也被如此划分。原理是每个属内位置的两个布尔值不同，因此其析取真而合取假。只有整个析取受必择条件约束，不能从它推出每个对象必定属于左支，或每个对象必定属于右支。

奇数/偶数是属内示例。代码接受通用布尔输入，不凭标签检查数论定义；实际正整数的奇偶划分仍须独立定义和证明。本实验不是形而上必然性检查器，只有给定属与输入表上的完备、互斥检查。

### 有限候选类层级

broadest_adequate(classes, predicate, width) 先筛选非空且完全满足属性的候选类，再保留其中没有严格更大合格候选类包含它的类名。包含指集合包含，不是字面标签或名义层级。

这是有限偏序的极大元素筛选：输出者一定合格且不被另一合格类严格包含；任一被剔除的合格类确实有一个更大候选。有限集保证非空合格族至少有一个极大者，但未必唯一。相同外延的不同名字都会保留，不把外延相同当定义相同，也不把极大当全体候选中的唯一最大。

这个函数不能找出未提供的类，不能证实候选清单覆盖全部概念，也不检查“就其自身”的解释关系。它不是亚里士多德“首先主项”的充分判定。只有在候选层级完整、性质与类型事实准确且解释根据已另行给定的课堂案例中，才可用它演示“等腰太窄、图形太宽、三角形层级合适”的外延部分。

### 四种 per se 用法的声明账本

PerSeDeclarations 的两类定义关系分别保存“属性进入主项定义”和“主项进入属性定义”；第三类是某主项的独立存在/不依附承载者声明，**不是任意属性都本质地属于它**；第四类是明确给出的原因声明。senses 返回这些声明的标签，不能用其输出推出任何未提供的事实。

其中 subsistence-3 只检查 subject，因此对该 subject 传入任意 attribute 都返回该标签；这表示分类谈的是主体，不表示那个 attribute 受认证。它与前三个二元关系使用相同查询接口仅为教学展示，不表示四种用法有同一逻辑类型。即便 walking 与 lightning 两列完全相同，没有外部原因声明也不会出现 causal-4。反过来，输入 causal-4 标签本身也不是可靠的原因证据。

## 3. 手算案例

1. 三对象、两时刻：subject=9（二进制001001）表示对象0在两个时刻属于主项；predicate=1仅在第一时刻有属性。违例是对象0、时间1。只看第一时刻会漏检。
2. 属包含四对象，left=5、right=10，即两侧分别占第0/2位和第1/3位。属内恰好必择，但两侧都不覆盖全属，所以“必有其一”不推出“必定是这一侧”。
3. 四个课堂图形编号：0、1为等腰三角形，2为非等腰三角形，3为正方形；figure=15、triangle=7、isosceles=3。把“内角和为两直角”的输入属性表设为7，则figure不合格（正方形反例），两个三角形类都合格，但等腰被三角形严格包含，返回triangle。几何真值在此为教学输入，程序未证明平面几何定理，更未主张非欧几何也相同。
4. 只提供isosceles候选仍返回isosceles。加入triangle后改变结果，直接展示“不完整类别目录”的风险。
5. a={0,1}、b={0,2}、属性={0,1,2}时返回a和b两个不可比极大类。若a、b都为{0,1}也返回两名，不能由样本同外延决定本质名称。

## 4. 真实运行

环境见[environment.json](environment.json)，Python 3 标准库，无第三方依赖。进入本目录运行：

```sh
python -m unittest -v test_model
python -O -m unittest -v test_model
python -OO -m unittest -v test_model
python exhaustive.py
python -O exhaustive.py
python -OO exhaustive.py
```

24项单元测试三模式实际通过。unittest检查与显式RuntimeError不会因-O/-OO移除。每模式独立枚举：

- 三对象×两时刻，两张6位表的4096种组合；逐位置布尔列表oracle同时检查全称真值与首个违例。
- 三元素域，属、左支、右支全部512组，其中216组满足属内恰好一侧条件（允许空属）；oracle用逐对象异或检查。
- 三元素域、三个有名候选类和属性表全部4096组；oracle用显式Python集合及严格包含检查极大候选，不复用位图筛选实现。
- 全部oracle差异0。枚举仅支持所列有限输入范围，不能作为一般定理证明。

## 5. 可复盘的失败方式

把所有时间压成一次快照会漏掉时间1反例；把析取必择当某一支全称必有会在奇偶案例失败；只留下最窄的合格类会误选等腰；只挑一个极大类会掩盖不可比情形；将共现当原因、同外延当同定义都超出实现的证据。最小复现故意保留这些边界，而不是生成一个声称自动判定科学本质的分类器。
