# 欧拉第 CVII 封信：五条限制到底筛掉了什么？

这是一份原创、零第三方依赖的教学复现。阅读定位是 1768 年版第 CVII 封信，书页 134 下部至 139，信末日期为 1761 年 3 月 3 日。这里没有重印书页、扫描件或逐字翻译；也没有声称欧拉使用了 Python、位掩码或现代模型论。历史解释见[同一教学单元的主文](../../papers/1768/euler-letter-cvii.zh-CN.md)。

## 要回答的问题

对普通三项直言三段论，以下是必要限制，不是充分条件：

1. 两个否定前提不能构成有效式。
2. 两个特称前提不能构成有效式。
3. 有否定前提的**有效论证**，结论必须是否定的。
4. 有特称前提的**有效论证**，结论必须是特称的。
5. 两个肯定前提的**有效论证**，结论必须是肯定的。

后面三条的“有效论证”不能省去。它们不表示任意一组这样的前提，都能推出某个符合所需语气的结论。所有五条都通过，也仍可能无效。

## 固定语义与记号

论域非空。P、Q、M 是三个独立的一元谓词符号；“独立”不要求三个外延不同、互斥或非空，而是没有预先规定它们之间的关系。沿用欧拉与主文的记号，P 是小项／结论主项，Q 是大项／结论谓项。

| 字母 | 现代集合语义 |
|---|---|
| A(S,T) | S ⊆ T |
| E(S,T) | S ∩ T = ∅ |
| I(S,T) | S ∩ T ≠ ∅ |
| O(S,T) | S \ T ≠ ∅ |

A 和 E 在主项为空时为真。I 和 O 有存在要求。第二种比较语义另外要求 P、Q、M 三个外延都非空；这只是明确指定的一种存在预设，不能把它当作所有历史逻辑传统唯一的语义。

四个格的大前提／小前提项序依次是：

- 第 1 格：M–Q，P–M
- 第 2 格：Q–M，P–M
- 第 3 格：M–Q，M–P
- 第 4 格：Q–M，M–P

例如 AAA2 表示 A(Q,M)、A(P,M)，所以 A(P,Q)。前三个字母依次是大前提、小前提、结论，末位是格号。总共 4³ × 4 = 256 个式。

## 为什么只需 255 个模型代表？

每个人只需记录是否属于 P、Q、M，得到 8 种成员类型。类型编号的位权是 P=1、Q=2、M=4。占据支持 support 是另一层位掩码：第 t 位为 1，表示类型 t 至少有一个人。例如 support=32 只占据类型 5，即 P、M 真而 Q 假。

这里有一个数学归约，不能与“程序跑过了”混为一谈：

1. 在任意非空论域中，按三项成员资格把人分类。
2. 每个非空类型只保留一个代表，得到至多 8 个人的模型。
3. A/E 的真假只取决于某种违例类型是否存在；I/O 的真假只取决于某种见证类型是否存在。因此这四类命题的真假都保持。
4. 反过来，任何非空占据支持都能用每类一个人的有限模型实现。

所以，对这套**仅含三项 AEIO 命题**的语言，255 个非空支持覆盖了任意大小论域的反例可能性。每个支持的最小人数等于其占据类型数。这不是对任意一阶逻辑、任意多项或带基数约束语言的有限完备性断言，也不是程序已经形式化证明了上述归约。

若三项都要求非空，可用容斥计数：256 − 3×16 + 3×4 − 2 = 218；这里先从包括空支持的 256 种掩码计起。支持 1 不是空论域：它有一个不属于任何项的人。

## 实际结果

| 语义 | 支持数 | 有效式 | 五条全部通过 | 通过但无效 |
|---|---:|---:|---:|---:|
| 现代语义，可有空项 | 255 | 15 | 48 | 33 |
| 三项都非空 | 218 | 24 | 48 | 24 |

各条被违反的式数依次为 64、64、96、96、32。违反任何一条而仍有效的式数，在两种语义下都为 0。不同规则的违反集合有重叠，不能把这些数字相加当作被排除式数。第三、四条代码使用“至少一个”否定／特称前提；两个这类前提本来已经由第一、二条排除，因此对有效性条件没有差别，但统计违反数时必须说明这个口径。

一个最简单的“规则不充分”实例是 AAA2：Q ⊆ M、P ⊆ M 并不保证 P ⊆ Q。现代语义的最小反例只有一个人，P=M={0}、Q=∅。三项非空时的最小反例有两个人，P={0}、Q={1}、M={0,1}。

`results.json` 逐一列出两种语义下的有效式，以及所有通过筛选却无效的式的最小反模型。搜索先按人数，再按支持整数排序，结果可重复。这里“最小”指论域人数最少；它不表示历史上最自然或视觉上最直观。

## 单称命题为什么需要另开一层？

普通模型不预设 M 是单元素集。若说“同一个确定的人 a 是 P，a 是 Q”，这已经加入了指称条件：两个 a 必须指向**同一个存在的对象**。集合编码是 N={a}，即 |N|=1。

在这个约束下：

- A(N,P) 与 I(N,P) 等价，因为都等价于 a∈P。
- E(N,P) 与 O(N,P) 等价，因为都等价于 a∉P。
- a∈P 且 a∈Q，直接以 a 为见证，得到 I(P,Q)。

这段逐元素论证对任意非空论域成立。`singleton_counts` 另用显式 n 人论域穷举 n=1、2、3、4，只提供实现核验，不能以这四个有限实验替代一般证明。

如果换成两个不相同的存在见证，结论就不成立：M={0,1}、P={0}、Q={1} 使 I(M,Q) 与 I(M,P) 都真，却没有 P 与 Q 的共同成员。这正是无效式 III3 的实例。

还必须避免“没有指称对象的名字”漏洞。在一人论域 {0} 中令 N=P=Q=∅，A(N,P) 与 A(N,Q) 都空真，但 I(P,Q) 为假。单靠“名字”这个字面标签不提供存在性。|N|≤1 仍允许空集；|N|=1 才完整编码一个有指称的单称项。对于两个全称前提推出共同成员这一个推论，较弱的 |N|≥1 已足够；但它不能保证 A/I、E/O 的单称等价。

因此，三项一般规则与共享单个指称对象的推理不能混作同一个无条件论断。三项支持商模型不会保留原来每个类型的人数，不能被直接拿来判定任意基数约束。

## 运行环境与命令

- Python 3.10 或更新版本；仅用标准库
- 不需要下载数据、安装包、联网、付费 API、GPU 或 notebook
- 本次实际环境版本和完整测试输出保存在 `test-log.txt`

在本目录执行：

```sh
python --version
python euler_cvii.py > regenerated-results.json
python -m unittest -v
```

`results.json` 是随包交付的实际运行结果。测试会将再次计算的报告与它比较。若想验证另存的文件字节也相同：

```sh
python -c "from pathlib import Path; assert Path('results.json').read_bytes() == Path('regenerated-results.json').read_bytes(); print('identical')"
```

没有随机种子，因为没有随机步骤。主报告通常不到数秒；完整测试会重复枚举，以独立集合语义交叉检查，所以稍慢。不同机器用时不同。

## 小型 API

- `holds(support, mood, subject, predicate)`：支持模型上的 AEIO 真值。
- `all_forms()`：固定顺序的全部 256 式。
- `supports(all_terms_nonempty=False)`：按最少人数排序的全部合法支持。
- `argument_truth(support, form)`：大前提、小前提、结论的三个布尔值。
- `violations(form)`：违反的必要规则名称；空元组不表示有效。
- `minimum_countermodel(form, all_terms_nonempty=False)`：最小反例支持；不存在时为 `None`。
- `countermodel_record(support)`：将支持转成可阅读的成员外延。
- `native_holds(n, mood, subject, predicate)`：显式 n 人论域的项外延位掩码；此处参数不是占据支持。
- `singleton_counts(n)`：共享一个有指称的名字的穷举计数，n 限 1–4。
- `report()`：完整的确定性报告字典。

非法格式、未知项、超界掩码、空论域或用布尔值冒充整数，均抛出 `ValueError`。`native_holds` 的 n 范围限于 1–16，是防止误用的工程界限，不是逻辑定理。

## 测试覆盖与边界

另有[独立代码复核](independent-review/review.zh-CN.md)，以独立的集合语义实现检查两种语义下全部 512 次有效性判定与 473 个无效式反例的最小人数；该目录含复核脚本、运行日志和结果文件。

`test_euler_cvii.py` 检查：255／218 支持数、256 式、精确的 15／24 有效式清单、每个无效式反例及其最小性、五条筛选的违反计数、空项语义、共享单称项、两个独立见证、非指称名字、格式守卫，以及报告确定性。

另外，它在 n≤3 的每个带标签论域上枚举三项所有外延，用 Python 集合关系独立计算真值，与支持算法逐项对照。本次所有无效式都已经在这些 n≤3 原生模型中找到反例；这是特定 256 式的核验结果，不是先验声称所有更广语言的反例只需三人。共享单称部分穷举至 n=4，并与 n×4ⁿ 个赋值、n×4ⁿ⁻¹ 个真前提赋值等初等计数核对。

有限穷举可以有程序错误。独立语义核对和守卫测试降低这个风险；它们不构成经过证明助手核验的程序正确性证明，也不替代历史材料的文本审读。
