# VII.30 独立技术核对

- **原证。** 复核 Fitzpatrick 希英对栏印刷页 218。D 不度量 A 时，VII.29 给出 D、A 互素。E 是 D 度量 C 的次数；DE=AB 的外项 D、E 与内项 A、B 对应有序比例 D:A=B:E。VII.21 取得最小数对，VII.20 给出相同整数尺度，因此 D 对应 B、A 对应 E。交换原因数可得另一方向，结论是至少一个而非恰好一个。
