# VII.30：质数整除乘积

现代正整数教学重构，不是古代实跑记录或一般命题的计算证明。函数依次接收质数 D 与因数 A、B，三个给定数均大于 1。先构造 C=A×B，并要求 D 整除 C。设 E=C/D；若 D 不量度 A，则由 VII.29 得 D 与 A 互素。等积 D×E=A×B 按 VII.19 给出 D:A=B:E，VII.21 将 (D,A) 判为最小对，VII.20 把同一整数倍数传给两个对应项，因而 D 量度 B。另一分支交换 A、B；若两者都能被 D 量度，结论仍成立。

(7,15,14) 中 C=210、E=30，7:15=14:30，倍数为 2。交换两个因数产生另一单边分支；(7,14,21) 两边都可整除。若 D=6，A=4、B=9，则 D 整除 36 却不整除任一因数，这说明不能省略质数条件。相同的最小对可以有倍数 1，例如 D=7、A=15、B=7；这不是把单位作为给定的「数」。
