# Euclid I.5：精确有理教学证书

本目录是原创教学实现。它核查等腰三角形及辅助延长点的坐标条件、两个三角形比较的若干等式、底角和底边下方角。它不是原文算法的逐指令复制，不是尺规操作引擎，不认证点的实际构造历史，也不是证明助理。一般证明须阅读[正文](../../papers/ancient/euclid-elements-i5.zh-CN.md)；有限实跑不能证明一般定理。

## 1 对象与范围

输入为五个二维有理点 A、B、C、F、G。每个坐标只能是整数或 Python Fraction；浮点、布尔值、缺失坐标拒绝。核查以下前提：

1. ABC 非共线。
2. AB 与 AC 等长。
3. A、B、F 同线，且 B 严格在 A 与 F 之间。
4. A、C、G 同线，且 C 严格在 A 与 G 之间。
5. AF 与 AG 等长。

距离均用平方比较，不开平方。向外次序用叉积为零和内积严格大于 AB 的平方判断。前提失败时返回 accepted=false，不对零射线求角。

一般证书核验允许任意符合要求的有理坐标。生成器仅覆盖较窄的对称规范族：A=(0,h)、B=(-b,0)、C=(b,0)，其中 b、h 正有理；F、G 分别为沿 AB、AC 射线使用同一个有理参数 t>1 的点。允许有理正交变换、反射与平移。它通过坐标公式生成证据，不搜索欧几里得原文中任选 F 和通过 I.3 截取 G 的操作。因此它不能证明所有合法几何输入都有本实现可生成的有理表示。

## 2 角相等不使用近似

取两角的射线向量 u、v 及 w、z，点积分别为 d、e，平方范数积分别为 n、m。在 n 和 m 均为正时，无向角取值在闭区间 [0, π]。精确相等须同时满足：d、e 同号，以及 d²m=e²n。

只比较第二项会把锐角与其补角混同；例如45度和135度有相同余弦平方。测试和Notebook包含这一反例。直角的点积为零单独由同号条件正确处理。零射线没有定义角，抛出 ValueError。

## 3 对应关系和核验层次

第一组比较是 AFC 对 AGB，即 A↔A、F↔G、C↔B。记录夹角 FAC=GAB、FC=GB、AFC=AGB、ACF=ABG。

在 AF=AG 与 AB=AC 下，原文用等量减等量取得 BF=CG；代码独立检查这个等式。第二组是 BFC 对 CGB，即 B↔C、F↔G、C↔B。记录 BFC=CGB、FBC=GCB、FCB=GBC。

最后的内角结论是 ABC=ACB，外角结论是 FBC=GCB。代码还记录 CB 位于 ACF 内部和 BC 位于 ABG 内部的两个叉积同号检查，用来提示等角相减所需的平面点序。它们仅在全部前提已成立的本构造下使用，不作为任意射线组合的独立角包含判定器。

所有 step 字段都是坐标模型中独立计算的等式或次序检查，不能据此声称程序验证了欧氏公理推理合法性。尤其是“结果等长”不说明调用过 I.3，“三角形对应等式成立”不说明重演了叠合。

## 4 可手算的例子

令 A=(0,4)、B=(-3,0)、C=(3,0)、F=(-6,-4)、G=(6,-4)。此时 t=2。

- AB²=AC²=25，AF²=AG²=100。
- BF²=CG²=25，FC²=GB²=97。
- ABC 与 ACB 的点积为18、平方范数积为900，余弦为3/5。
- FBC 与 GCB 的点积为−18、平方范数积为900，余弦为−3/5。

内角与相应外角不是同一个角；它们的余弦符号相反。Notebook可以直接查看全部前提、比较步骤和两项结论。
