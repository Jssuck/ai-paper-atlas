# 独立技术复核证据

从本目录运行 `python3 audit.py`，或在复现根目录运行 `python3 independent-review/audit.py`。仅需 Python 3 标准库；会重写本目录的检查结果和日志，不改正文、原实现或原 Notebook。工作目录不影响导入。

`audit.py` 的独立角 oracle 用平面向量 `(点积, 叉积绝对值)` 的同向性，而不是复制被测实现的余弦平方交叉乘式。两者表示相同通常角的理由是 `atan2(叉积绝对值, 点积)` 在上半平面的角值；代码不调用浮点 atan2。另用非零坐标分量的精确比值检验外点比例，不复用被测 `outward`。

- 24 个非零整数向量组成 576 个角，再两两核对 331776 次。
- 从坐标各在 −4 到 4 的等长不平行整数腰，取 3 个延长比例及有理平移，取得 1056 个非规范正例和 4224 个负例。
- 对固定三角形，遍历 −3 到 3 的整数方格中的两辅助点，共 2401 对，核对接受值是否等于独立前提判据。
- 另重跑作者的普通、`-O`、`-OO` 单元测试及枚举，保存6份日志。每模式34项测试通过、1200正例通过及4800错误变体拒绝；模式间结果一致。
- 5个 Notebook 代码单元在新的共享命名空间顺序 compile/exec，逐单元比对已存储 stdout；不更改 Notebook，也不称为 Jupyter 内核执行。

全部判断使用显式异常而不是会被优化模式删除的 assert。有限范围的一致性不是一般定理、形式化验证或完整尺规复现。正文的一般证明仍须单独审核；记录见 [独立技术审查](../../../papers/ancient/euclid-elements-i5.technical-review.zh-CN.md)。
