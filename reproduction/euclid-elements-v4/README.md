# 《几何原本》卷 V 命题 4：同比保持与换标

[回到中文精读](../../papers/ancient/euclid-elements-v4.zh-CN.md)。本附件以有理量做精确核验，区分两组比之间的相等关系、单一比值、以及同一编号下的比较结果。

## 现代模型及对照

- 输入为严格正有理坐标。每对比内部须同类、先统一计量单位；两对各自同类即可，彼此可用不同量类。交叉乘积只在现代数值坐标中作精确同比判据，不是把古代长度和面积相乘的历史解释。
- 两个前项共同取 u 倍、两个后项共同取 v 倍。变换后在 (p,q) 比较的符号，等于变换前在 (up,vq) 比较的符号；左右两端均执行此映射。比较保留大于、等于、小于三态。程序的缩放与探针都取正整数，包含 1 的恒等情形；不靠将 1 说成严格的大量倍小量。
- 例如 3:2 与 6:4，取 u=2、v=1 后比值共同从 3/2 变成 3。原比在 (1,2) 给负号，变换后在同一编号给正号，但原比在对应 (2,2) 也给正号。保持的是同比关系，而非某个比的数值，也非原探针表在原编号下的原样保留。
- 若只对左前项取 2 倍，(1,2) 给左右符号 (+,−)。不同的四个缩放倍数并非一定破坏同比：在正有理坐标中，若两边的前项倍数与后项倍数之商相同，仍能保持同比。此为现代扩张，不是 V.4 的文字前提。
- 有限窗口反例：101:100 和 102:101 不同比，但在 1≤p,q≤100 内找不到反例；窗口到 101 才有 (p,q)=(100,101) 的 (0,−)。在这里交叉乘积先给精确对照，无需将未发现反例误读成相等。

## 环境及实跑

在本目录执行，仅需 Python 3.12.14 标准库：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python scaled_ratios.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

三种 Python 模式各通过 11 项测试。网格取 3 个公共比、3×3 对后项坐标与 4×4 对缩放倍数，组成 432 例；每例取 4×4 个探针，核对 6912 次四个符号的相等，并用交叉乘积检测变换前后同比。日志只将 unittest 耗时归一化。有限实例用于查验实现，不代替对任意探针的一般证明，也不覆盖原理论允许的所有不可公度量。

环境无可用 Jupyter 命令及 Notebook 模板脚本。按教程结构生成 Notebook，其中三个代码单元已用标准库实际顺序编译执行；未运行 Jupyter 内核或前端。
