# 《后分析篇》I.21：三格否定与混合路径的最小教学实验

这是原创 Python 标准库教学模型，配合[深读正文](../../papers/ancient/aristotle-posterior-analytics-i21.zh-CN.md)。不是原典演算完整实现，也不以有限枚举证明一般无限命题。对应完整阅读范围82a36–82b36；科学谓述链为何应上下终止仍是本章条件而非实验所得事实。

## 1. 集合语义：先固定项的方向

用非负整数的二进制位代表有限集合，最低位代表对象0。`All(P,S)` 表示 S 是 P 的子集；`E(P,S)` 表示 P 与 S 无交；`O(P,S)` 表示 S 减去 P 非空。参数第一位是谓词，第二位是主项，不能与日常“所有P是S”的字面次序混淆。有限论域下允许空项：All和E在空主项上真，O在空主项上假。

真实枚举论域大小0、1、2、3、4，每个大小各枚举所有三项集合赋值，合计4681组。跨论域大小分别计数，不声称是4681种不重复同构模型。

| 规则 | 前提满足数 | 结论失败数 |
| --- | ---: | ---: |
| 第一格：E(A,B) 与 All(B,C)，推出 E(A,C) | 341 | 0 |
| 第二格：All(B,A) 与 E(B,C)，推出 E(A,C) | 341 | 0 |
| 第三格：All(A,B) 与 O(C,B)，推出 O(C,A) | 774 | 0 |

第三格的结论是“至少一个A不是C”，不是“没有A是C”。A={0,1}、B={0}、C={1}就满足第三格前提及特否结论，却不满足全否结论。O前提自身已提供存在见证，不需要从空集合凭空取对象。

另枚举全部两项集合：E(P,S)加主项S非空时，90个前提实例均支持O(P,S)。去掉非空条件，P={0}、S=空集给出反例。O不能反推E：P={0}、S={0,1}时O真而E假。

这些计数来自 `results.json`。三条规则的一般正确性应分别用子集传递、无交继承、同一存在见证重建；有限测试仅检验本程序的有限实例。

## 2. 终止模型：是逆向找前提，不是向前推出结论

状态为(q,p,s)，q为E或O，p、s为两个端点的秩，范围0至H。秩越大表示朝较普遍端移动。两坐标只是独立的有限进展参数，不表示两个端点必须属于同一条真实集合链，不认证负命题真值、科学因果或原典所有规则。

仅允许下列逆向展开：

- E目标：谓词端或主项端严格上移。新全否前提若真，可沿相应肯定包含关系推出旧目标。
- O目标：谓词端严格上移，或主项端严格下移。新特否前提保留足以推出旧目标的见证。
- 有单独主项非空证据时，可由O目标转去证明同端点的E前提。这是向前 E⇒O 弱化的逆向搜索，不是由O前提推E结论。
- 不允许E目标转成O前提；不加入同项反复、等价项互换或其他不下降步骤。模型也不展开肯定支路，肯定支路终止须另外作为本章的条件处理。

定义自然数测度：E状态取( H−p )+( H−s )；O状态取2H+1+( H−p )+s。对于同模式移动，上述严格变化至少令测度减1。对于O→E换模式，任意O测度至少2H+1，任意E测度至多2H，因此也严格减小。非负整数不可能无限严格下降，所以**这套声明的受限逆向规则**没有无限路径。这是教学模型的数学证明，不是从一次测试归纳得到的无限结论。

真实运行H=4时有50个状态、225条逆向边，严格下降违规0，最大初始测度17，实际最长路径13步。状态图枚举在计算最长路径时允许非空证据，因此是“证据已给定时允许的结构移动”测试；不声称自动找到了每个E/O命题的真实非空证据。关闭证据参数会去掉O→E边。

## 3. 混合路径为何不能只数格的种类

R只含u→v，S只含v→u。单独重复R或S都不能无限走；合并后可以u、v来回走。程序检查R无环、S无环而其并有环。这个两点反例针对“有限种分别终止的方法，其任意交替必终止”的一般化，不是直接宣布原典论证错误。上节统一下降测度就是本模型为混合路径补上的共同约束。

同理，同一状态重复、等价项来回改名虽不增加“格种类”，却可能使搜索器循环；本文明确排除它们，不把去重软件技巧冒称原文已给出的论证。

## 4. 实际测试及环境

`test_model.py`有17项测试，分别在普通、`-O`、`-OO`三个Python模式通过。使用unittest断言方法，不依赖会被优化关闭的裸assert。包含空项、谓词方向、存在见证、量词升级反例、每条秩下降边、零高度、非法输入和切换循环。

## 5. 重跑

在本目录运行：

```sh
python model.py > results.json
python -m unittest -v test_model > logs/tests-normal.log 2>&1
python -O -m unittest -v test_model > logs/tests-O.log 2>&1
python -OO -m unittest -v test_model > logs/tests-OO.log 2>&1
python verify_notebook.py > logs/notebook.log
```

- `model.py`：集合判断、枚举、逆向秩模型及切换反例。
- `test_model.py`：17项测试。
- `results.json`：真实运行结果；更改程序或参数后必须重新生成。
- `i21_teaching.ipynb` 与 `verify_notebook.py`：教程及上述标准库执行方式。
- `logs/`：三模式测试及Notebook真实日志。
- `environment.json`、`commands.txt`：环境边界及命令。

练习：把H改为0与1，手算测度和最长路径；取消非空证据，解释O→E边为何不可用；将第一格All(B,C)误写为All(C,B)，找一个反模型。答案：H=0只有有证据时一次O→E移动；H=1最长4步。无非空证据时全否命题可能只是空主项真，不能保证O。误写方向可取A={0}、B={1}、C={0,1}：E(A,B)和All(C,B)都真，但E(A,C)假。
