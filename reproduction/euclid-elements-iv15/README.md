# 《几何原本》IV.15：用两圆交点构作内接正六边形

[回到正文](../../papers/ancient/euclid-elements-iv15.zh-CN.md)。给定正半径圆，选其上一点 D，以 D 为圆心、GD 为半径作辅助圆。程序以精确坐标重做交点和过 G 延长的步骤，再逐项验算；不模拟尺规动作，也不以测试代替一般证明。

## 模型及验收

以原圆心 G 为原点，令 u 为 GD 向量，J 为逆时针 90° 旋转。系数对 (x,y) 代表物理位移 x·u + √3·y·J(u)。在计算中只存有理数对；长度平方为 R²(x²+3y²)，其中 R²=u·u。若嵌回平移后的任意圆心，只需统一加上该圆心，不改变下面的约束；程序不运行图形界面，也不测试坐标平移。

辅助半径平方与原半径平方之比记为 q。主圆与辅助圆的方程分别为 x²+3y²=1 与 (x−1)²+3y²=q；相减得 x=1−q/2。q=1 时 E=(1/2,1/2)、C=(1/2,−1/2)，A=−D、B=−E、F=−C。证书明确把「六点都在圆上」「顶点互异」「按给定字母顺序逆时针相邻」「边长平方为 R²」「每个顶点的邻边点积为 −R²/2（结合边长等价于内角 120°）」分开；构造和验收不是同一行方程。

## 可复跑证据

进本目录，仅需 Python 3.12.14 标准库：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python hexagon.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

48 个有理参数各取两个不同方向，共 96 组精确正例、96 组错误辅助半径、96 组交换两顶点顺序。q=12/19 时六点仍都在圆周上，但边长平方除以 R² 依次为 (12/19, 676/361, 12/19) 重复两次。q=3 时六点集合甚至与正例相同，但按命题规定连线的次序和边长检查均失败。q≤0、q≥4 不产生两个不同的实交点；原半径为零也拒绝。q=2 的两个实交点需要 y=±1/√3，不在这份有理系数模型内；它在数学上仍有交点，继续取对径点只会得到四个不同的点。另单独检查了重复顶点证书。
