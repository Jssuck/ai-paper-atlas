# 二十分钟教学演示：从图解到可检查的语义

这是一组受《书信 CIV》启发的现代集合语义练习。原文转录、解释性修补、现代
建模选择分别标明，避免用一个程序抹去三者的差别。

## 1．先读一条规则，再运行程序

I 是 `AAB, ACA => ACB`：所有 A 都是 B；所有 C 都是 A；所以所有 C 都是 B。
任取一个 C 中的对象，它必先属于 A，再属于 B。这里无需先找到一个 C 的成员：
即使 C 为空，全称结论也成立。

II 是 `AAB, ICA => ICB`。第二前提已经提供一个同时属于 C 与 A 的见证对象，
第一前提把它放进 B。因此这里能推出特称结论，原因是见证来自特称前提。

## 2．VI 的见证从哪里来？

VI 是 `AAB, ABC => ICA`：A 包含于 B，B 包含于 C，所以有些 C 是 A。
两个包含关系本身能产生一个 A 的对象吗？

在允许空项的语义中，答案是否定的。最小反例是论域 `{x0}`，A=B=C=空。
两个全称前提都真，特称结论却假。若另外假定 A 非空，就可选一个 A 的成员，
沿两个包含关系将它放进 C，推理随即成立。

只要求 B、C 非空仍不足够：令 A=空，B=C=`{x6}`，结论仍假。因此“最少要求
A 非空”与“一律要求三项非空”是不同强度的假设。

```sh
python3 - <<'PY'
from euler_civ import REPAIRED_FORMS, check, minimal_nonempty_assumptions
rule = REPAIRED_FORMS['VI']
print(rule.as_dict())
print(check(rule).as_dict(rule))
print(check(rule, 'BC').as_dict(rule))
print(minimal_nonempty_assumptions(rule))
PY
```

把 VI 改成 XVIII、XIX、XX，重复实验。三者最少需要的非空项依次为 A、B、A。
其余汇总式在此语义下无需额外的项存在假设。

## 3．把印刷 XVI 留在读者面前

印刷式 `OAB, ACB => OAB` 直接重复第一前提，因此当然有效。印刷页 116 的
前一段推导却以 `OAC` 作结论。分别测试教学修补式 `OAB, ACB => OAC`：
取 A 中但不属于 B 的见证；由于 C 包含于 B，这一对象也不可能属于 C。

讨论：为什么不能在转录时默默把最后一个 B 改成 C？忠实记录印刷文本与提出
有根据的数学修补，依旧是两项不同的工作。

## 4．一个模型如何编码，255 又是怎样来的？

一个属于 A、C 而不属于 B 的对象，其成员元组 `(A,B,C)` 为 `(1,0,1)`。
按 A=1、B=2、C=4 的位权，区域编号是 5。仅有该对象的模型，其占据掩码为
`1 << 5`，即 32。**区域编号和模型掩码不是同一个数。**

```sh
python3 - <<'PY'
from euler_civ import Model, Statement
model = Model(32)
print(model.describe())
for code in ('IAC', 'OAB', 'OAC', 'ACB'):
    print(code, Statement.parse(code).holds(model))
PY
```

四个命题的结果依次为真、真、假、假。这也展示了 XVI 的第二前提为何必要：
只有第一前提时，修补结论可能是假。

README 中的有限商定理说明：每个被占据的成员关系区域只留一个对象，就能
保存此语言的全部命题真值。**是这个定理，而非“检查了许多小例子”这一事实，
赋予有限搜索以完备性。** 这里不关心一个区域有多少对象；若语言能数对象，
这种压缩就可能失效。

## 5．三种计数问题不要混为一谈

先数**印刷条目**：二十条。

只允许项名整体置换、交换前提，不允许 E/I 换位时，修补后的条目有**十九个
句法类**：只有 V 与 XVI 合并。

再允许 E/I 两项换位时，同一份修补后的数据有**九个结构类**。例如 II 与 XVII
此时合并，因为“有些 C 是 A”和“有些 A 是 C”都在说同一交集非空。

最后，数**另行固定的现代候选空间**：四格各有 64 个命题种类组合，共 256 个。
程序算得允许空项时 15 个有效，三项非空时 24 个有效。它们不是二十或十九，
因为计数对象已经改变。先比较同一种对象，才谈是否遗漏或重复。

不允许 E/I 换位的对照留下五个未覆盖格—式；允许换位的对照留下四个，分属
两个结构类。VI 只有把 I 结论换位后，才能另代表 AAI-1。

## 6．两个特称前提可以由不同对象作证

试验 `IAB, IAC => IBC`。第一前提可能由 A 中某个 B 对象作证，第二前提则由
另一个 C 对象作证。令 A=`{x3,x5}`、B=`{x3}`、C=`{x5}`，两个前提都真，
三个项都非空，但 B、C 没有交。因此这个论式在较强的存在制度下仍无效。

```sh
python3 - <<'PY'
from euler_civ import Argument, check
rule = Argument.parse('IAB', 'IAC', 'IBC')
print(check(rule, 'ABC').as_dict(rule))
PY
```

程序给出的反例有两个对象；这是最小可能的对象数。

首前提特称的候选清查检查其明确规定的全部 256 个组合；十个有效编码在两种
存在制度中都形成四个结构类。这不是“所有以‘有些’开头的任意逻辑论证”的
完整分类，必须连同候选空间的定义一起阅读。
