# 欧拉《书信 CIV》（1768）：可执行的教学性重构

本目录以 **Python 标准库**重构原书印刷页 116–117 的二十条汇总式，并与几个
**预先界定的现代候选空间**比较。所有代码为本次原创；这不是欧拉的程序，也不
声称复原其心理过程、发现正式勘误或穷尽一切逻辑推理。转录时直接查看了原页
图像，尤其保留了 XVI 的印刷差异。简短课堂演示见 [TEACHING.md](TEACHING.md)。

## 一、运行方法

需要 Python **3.10 或更新版本**；不安装依赖，不联网。实际测试环境记录在
`outputs/environment.json`。在本目录运行：

```sh
python3 report.py --check outputs/report.json
python3 -m unittest discover -s tests -v
```

重新生成确定性的完整报告：

```sh
python3 report.py --output outputs/report.json
```

重新核验报告、执行测试、保存实际日志及环境信息：

```sh
python3 run_checks.py
```

`run_checks.py` 先将重新计算的报告与保存版本逐字节比较，再执行测试；两条
命令只要一条失败，就返回非零退出码。它不会把变化后的结果悄悄接受为新基线。
确实要修改语义或报告时，应先审阅差异，再显式重新生成 JSON，最后重新测试。
报告内容及 JSON 排序是确定的；日志耗时、Python 路径和操作系统信息因环境而异。

## 二、程序计算的究竟是什么

`AAB` 是三个字符：第一个 `A` 是**命题种类**，后两个 `A`、`B` 是**项名**。
不要把命题种类和项名混为一谈。项名只有 A、B、C；每个命题使用两个不同的项：

| 编码 | 中文读法 | 本程序采用的集合语义 |
|---|---|---|
| `Axy` | 所有 x 都是 y | x 包含于 y |
| `Exy` | 没有 x 是 y | x 与 y 的交为空 |
| `Ixy` | 有些 x 是 y | x 与 y 的交非空 |
| `Oxy` | 有些 x 不是 y | x 中有对象不属于 y |

在这一明确指定的现代语义中，全称命题**不自带存在承诺**。E、I 的两个项可以
交换，A、O 通常不行。程序把“某项非空”作为额外假设添加，以免把词语含义和
存在前提混在一起。这是教学模型的选择，不是对欧拉语义的无条件归属。

所有模型的**论域非空**。“允许空项”意指 A、B、C 分别可以为空；“三项均非空”
要求每个项至少有一个成员，并不要求有三个不同对象。每条汇总式还检查了
`{A,B,C}` 的全部八个子集作为非空假设，报告其中按集合包含关系最小的充分
假设集。结果 `[[]]` 表示无需额外存在假设；结果 `[]` 表示八种假设都不足以
使该式有效。这两种结果不同。

## 三、为什么只需 255 个模型：有限商定理

这不是“抽样试了几个小图，所以推测成立”。设非空论域 D 上有任意三个集合
A、B、C，论域可以无限。按一个对象是否属于 A、B、C，把 D 划分为最多八个
成员关系区域，编号为 0 至 7。编号的位权是 **A=1、B=2、C=4**；区域 0 在
三项之外，区域 7 在三项之内。

令 Q 为被占据的区域编号组成的集合，在 Q 上用相应成员位解释 A、B、C。那么：

1. `Ixy` 在 D 中成立，当且仅当存在一个已占据区域同时具有 x 位和 y 位；
   所以它在 Q 中也成立，反之亦然。
2. `Oxy` 成立，当且仅当存在一个已占据区域具有 x 位而没有 y 位。
3. `Axy` 成立，当且仅当不存在具有 x 位而没有 y 位的已占据区域。
4. `Exy` 成立，当且仅当不存在同时具有 x 位和 y 位的已占据区域。
5. 某项非空，当且仅当至少一个已占据区域具有该项对应的位。

因此，该商映射保存每个命题、两个前提、结论以及所有非空假设的真值。反向地，
任意非空区域编号集合 Q，都能由“每个被占据区域恰放一个对象”的具体模型实现。
于是：**任意非空论域上存在反例，当且仅当 2^8−1=255 种区域占据配置中存在
反例。** 这一数学论证加上正确的枚举实现，才能把有限检查提升为指定语言的
完备判定；它不是仅凭实验宣称证明。

实现保留区域 0。若 A、B、C 全为空，非空论域仍须有一个三项之外的对象。
若删除区域 0 却不单独处理这个情况，就会漏掉最简单的存在性反例。程序不含
空论域；即使允许空论域，本例各式的有效性也不改变，因为“三项全空、只有一个
外部对象”的模型已经具有与空论域相同的所有命题真值。

边界也要说清：这里没有二元关系、对象数量约束、同一性限制、第四个谓词或
模态。程序有测试，但没有经过证明助手的机器形式化验证。

### 区域编号不等于模型掩码

成员关系写成 `(A,B,C)=(1,0,1)` 时，区域编号为 `1+4=5`。整数通常二进制的
高到低顺序则是 C、B、A；不能把通常二进制的读法与 `(A,B,C)` 元组混同。
若模型仅占据区域 5，其**占据掩码**是 `1 << 5 = 32`，不是 5。JSON 同时保存
区域编号、各项成员列表和占据掩码，避免只凭一个整数猜图。

## 四、XVI：印刷文本与教学修补分别保存

印刷页 117 的 XVI，编码为：

`OAB, ACB => OAB`

结论重复了第一前提。它确实有效，但第二前提没有作用，结论也没有连接尚未
使用的项对。紧接汇总表之前、印刷页 116 的规则却以“有些 A 不是 C”作结论：

`OAB, ACB => OAC`

程序同时保存印刷版和这一**解释性的教学修补**。原页差异为修补提供依据，但
本项目不把它说成已经查明的正式勘误。两套二十条数据之间只改变 XVI。

## 五、实际重新计算的结果

下表数值来自枚举，不是写给判定器的预设答案。测试另以预期数值作回归断言，
用于发现未来改动。

| 范围 | 候选数 | 允许空项时有效 | 三项均非空时有效 |
|---|---:|---:|---:|
| 印刷汇总表 | 20 | 16 | 20 |
| 仅对 XVI 作教学修补 | 20 | 16 | 20 |
| 现代四格候选 | 256 | 15 | 24 |
| 明确定义的欧拉式候选空间 | 512 | 30 | 48 |
| 其中首前提为特称的切片 | 256 | 10 | 10 |

需要额外存在假设的四条及各自最小要求：

| 条目 | 最小非空项 |
|---|---|
| VI | A |
| XVIII | A |
| XIX | B |
| XX | A |

其余印刷式或修补式无需额外存在假设。这四条在允许空项时都有同一个最小反例：
一个对象的论域，A、B、C 都为空。完整报告还为每种失败的非空假设组合给出
最小反例，统计前提成立的模型数，避免把“前提不可能同时成立导致的真空有效”
藏起来。汇总表每条的前提在两种主要制度中都可满足。

## 六、候选空间先固定，才谈覆盖

1. **现代四格的 256 式。** 令 S=C、P=B、M=A。第 1–4 格的大前提/小前提
   项对分别为 `(AB,CA)`、`(BA,CA)`、`(AB,AC)`、`(BA,AC)`；结论统一为 CB。
   每格枚举 A/E/I/O 的全部 4^3 个命题种类组合。
2. **欧拉式的 512 候选。** 第一前提固定为 qAB；第二前提项对取 AC、CA、
   BC、CB；结论用尚未出现的无序项对，并可取两个方向。三个 q 独立取 A/E/I/O。
   共 `4 × (4 × 4) × (4 × 2)=512` 个不同的原始三命题组合，每式恰使用三个
   不同的项对。
3. **首前提特称的 256 候选。** 与上一空间相同，只将第一个 q 限为 I/O。
   十个有效和 246 个无效编码全部得到分类；三项均非空不会新增有效编码。
   十个有效编码中包括四个“将 Ferio 型特称前提移到第一位”的等价写法。
   此处限制的是前提顺序，不是历史名称。

修补后的二十条全部位于 512 空间内；印刷 XVI 不在其中。这些结论只涉及明确
声明的候选范围，不等于一般逻辑的完备性。`outputs/report.json` 保存每个
候选的编号、公式、等价类、汇总表覆盖关系与两种有效性结果，而不只给出计数。

## 七、两种等价关系，必须分别计数

### 模式 1：项名同时重命名＋前提交换，不作 E/I 换位

这是较细的**句法归并**。E/I 的两个项仍保持原有方向。印刷二十条有 20 类；
修补后二十条有 **19 类**，唯一合并的是 V 与 XVI。这为历史十九之数提供一种
清楚且数值相符的读法，但数值一致本身不能证明欧拉的全部计数约定，也不能
证明存在正式勘误。

用同一模式对照现代四格，修补后的汇总表覆盖三项均非空时 24 个有效格—式中的
19 个。未覆盖的五个为 **AAI-1、EAO-1、AEO-2、EAO-2、AEO-4**。结论方向在
此模式中不能随意改变：VI 经重命名和前提交换可成为 AAI-4；只有允许 I 结论
换位后，它才也能成为 AAI-1。

### 模式 2：再允许 E/I 的两个项交换

这是较粗的**结构归并**。允许的操作恰为：

- 对整个论式的 A、B、C 同时作一个置换
- 交换两个前提
- 交换任一 E 或 I 命题的两个项

不允许把结论换成前提，不暗中将全称结论弱化为特称，也不把任意真值表一致的
公式归为一类。它尤其不是按“两个前提蕴涵结论”的布尔真值表计数，否则所有
有效蕴涵都成了重言式，问题将失去原先的结构意义。

按此关系，修补后二十条形成 **9 类**：

- I
- II、XIII、XIV、XVII
- III、IV、VII、VIII
- V、XVI（修补版）
- VI
- IX、X、XI、XII
- XV
- XVIII、XIX
- XX

印刷版有 10 类，因为重复前提的 XVI 单独成类。现代允许空项时的 15 个有效
格—式形成 6 类，汇总表全部代表。现代三项均非空时的 24 个有效格—式形成
**11 类**，汇总表代表其中 9 类。未代表的两个类可分别写成：

- `AAB, EBC => OAC`，最少需要 A 非空
- `AAB, EBC => OCA`，最少需要 C 非空

两式都可由 `AAB, EBC => EAC` 的不相交结论加上适当存在假设得到，但 O 结论
的方向和所需见证不同，因此这里的结构等价不把它们合并。现代格—式成员分别
为 EAO-1/EAO-2 与 AEO-2/AEO-4。

较大的 512 候选空间也产生同样的 6 或 11 个有效结构类；其首前提特称切片在
两种制度中都有 4 类。较粗模式覆盖 24 式中的 20 式，而非较细模式的 19 式，
因为 VI 此时还能代表 AAI-1。**这是等价关系改变造成的计数差异**，不能混用。
代码没有为了凑数而删除条目；所有归并都来自明确声明的变换。

## 八、文件与核验范围

- `euler_civ.py`：模型语义、二十条转录、单独的 XVI 修补、见证推理、候选生成、
  非空假设分析和两种归并
- `report.py`：确定性的完整 JSON 及简明文本摘要
- `tests/test_euler_civ.py`：23 个 unittest 测试方法，覆盖全部二十条、XVI 两种
  读法、全部 255 模型和 24 种基本命题编码；另用普通集合运算实现核对器；
  检查四对象的全部 4,096 种成员关系配置、全部 512 候选、非法输入、结果确定性
  与覆盖/等价计数回归
- `run_checks.py`：子进程核验器，保存环境信息与散列值
- `outputs/report.json`：完整机器可读结果
- `outputs/run.log`：实际命令、输出和退出状态
- `outputs/environment.json`：Python/平台信息及代码、报告的 SHA-256
- `TEACHING.md`：逐步演示与讨论问题

测试中的普通集合核对器与位掩码算法是分开实现的，但不能因此声称已经经过
独立人工审查。本次另行完成的独立审查及其证据见 [独立审查报告](review/review.zh-CN.md)。
文件散列使实际测试的输入和报告可核查。整个目录不会安装软件，
也不会进行远程写入。
