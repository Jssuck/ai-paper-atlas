# VII.37：取以给定因数命名的一份

现代整数教学重构，不是古代实跑证据或一般命题的计算证明。给定 A 与量度 A 的 B，取商 C。B 量度 A 恰 C 次；原文借 VII.15 交换等次量度（现代用交换乘数表达），C 又量度 A 恰 B 次。因此 C 是 A 的 B 分之一。程序以整除求 C，再另做 B 次重复加法验证交换后的总和。

12 可被 3 量度四次，也可被 4 量度三次，所以 4 是 12 的三分之一；14 除以 3 有余数 2，不满足前提。默认将给定数与商限制为大于 1，避免把单位作为原文中给出的「数」；现代模式允许 12÷12=1 或 12÷1=12 等边界。
