# VII.37 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.37.html)、Heath 1908 卷 II 印刷页 341–342（扫描物理页 354–355，图在 341，末段与评注在 342）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=224) 印刷页 224 与 [Joyce VII.37](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII37.html)。

希文 Α、Β、Γ、Δ 对应英语 A、B、C、D。B 量尽 A，取 C 的单位个数等于其测量次数，D 是单位。D 量 C 的次数等于 B 量 A 的次数；由 [VII.15](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII15.html) 交换对应角色，得到 D 量 B 的次数等于 C 量 A 的次数。因而 D 在 B 中占的单位分数，恰与 C 在 A 中所占相同。D 是 B 的 B 分之一，所以 C 是 A 的 B 分之一。“同名”指单位分数以 B 为分母，不是 C 和 B 数值相同，也不是原文已引入通用的有理数除法。Heath 342 页评注用整数部分明确说明此义，Fitzpatrick 用括号解释 B 分之一。

Clay 英栏在“同一部分”的比较后即止，省略希文中将该部分具体命名并识别为 C 的后续句；Heath、Fitzpatrick、Joyce 均保留。图上的四条线是对象标签，不替代证明。以现代正整数写，若 B 整除 A，C=A/B 是整数；当 A=B，C=1。原文却在构造后称 C 为“数”，而第 VII 卷区别单位和数；不宜声称古证显式处理这个值域边界，也无需否定现代解释的合法性。

[VII.39](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII39.html) 直接根据本命题，从整除 G 的 D、E、F 得到 G 具有相应名称的三个单位分数部分。[VII.38](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII38.html) 是逆向关系；其证明另用 VII.15，不是直接引用 VII.37。
