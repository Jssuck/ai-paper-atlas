# IX.17 原典核对

- [Heath 1908 英译卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)：印页 406–407，扫描物理页 419–420。406 起题并到交互比例，407 给完整整除传播。证毕后的等比列和第四比例项是译者代数概括，不是正文记号。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=267)：印页及扫描页 267–268。命题句跨页，续项字母 E；给定列的首尾为 A、D，而不是 A、B。正文给四项示范，命题陈述不限于四项。没有在所读版本发现需另应用的正式勘误。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.17.html)英译止于矛盾，希文有明确排除与证毕；[Joyce 读本](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX17.html)英译包括收束，Guide 把本题与 IX.16 的两项情形相联系。
- [VII.13](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII13.html)把 A:B=D:E 改为 A:D=B:E；[VII.21](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII21.html)与 [VII.20](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII20.html)从最简端点得到 A 量尽 B。Fitzpatrick 将连续比例中的两处整除传播引到卷 VII 定义 20。Heath 译者按语也在传播时给出该定义，不把传播本身当作对每一对相邻项套用最简定理。
- [中文深读](../../papers/ancient/euclid-elements-ix17.zh-CN.md)按原典的比例路线重建证明；单位边界、缩放参数和精确续项是现代分析。[教学复现](README.md)为有限检查，不发布扫描或逐句译文。
