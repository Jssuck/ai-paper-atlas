# 《几何原本》卷 V 命题 1：相同倍数与分组

[回到精读正文](../../papers/ancient/euclid-elements-v1.zh-CN.md)。本附件用正有理数重建「每组拆成同样多份，再按份重组」的论证。坐标先统一同类量的单位；代码精确拒绝浮点数、零与负量。

## 输入、证书与反例

- 输入是两列非空等长量，每一个较大量与对应基量必须同类。按卷 V 定义 1–2 的严格「小量度量大量」使用整数倍数至少为 2；等量乘以 1 是现代等式的平凡扩张，不在此复现的验证域内。
- 程序从各对的精确商读出倍数，拒绝非整数商或彼此不同的整数倍数。古证按份分割，并不用先除法计算商；除法在此只是读取输入的倍数证书。
- 把每个较大量分成一行同样长的基量副本，再逐列读出一整套基量。若所有项同类，则列内求和、再跨列求和，与逐行求和相等；同一小量不必在不同对中等值。
- 当不同对各自同类却彼此不同类时，程序允许看作保留类型的分量元组，重复计数而不成单个标量和。这是现代模型的分层边界，不主张原证把不同类量做加法。标签只是教学保护，不校验物理单位。
- 反例：(3,5) 和 (1,1) 的总量之比为 4:1，但逐组倍数为 3、5；总倍数不能倒推出各对共享倍数。

## 环境与实跑

在本目录运行，仅需 Python 3.12.14 标准库：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python equimultiples.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

普通、-O、-OO 各通过 9 项测试。网格取三种基量坐标的所有三项组合与 6 种倍数，共 162 个合法分组和 162 个仅改末对倍数的拒绝例。全部精确，无浮点误差或计时结论。日志仅将 unittest 耗时归一化为 `<elapsed>`。

环境无可执行 Jupyter 命令和模板脚本；Notebook 按教程结构生成，三个 Python 单元实际由标准库顺序编译并执行，未运行 Jupyter 内核或前端。有限测试可核验实现，不代替文中的一般论证，也不复现未列入本单元的卷 V 命题。
