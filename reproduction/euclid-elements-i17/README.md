# I.17 最小复现：任两内角和的严格上界

这是原创现代教学重构，不是欧几里得原文代码或完整形式化几何。对应[中文深读](../../papers/ancient/euclid-elements-i17.zh-CN.md)。没有第三方运行依赖或网络调用，所有数值计算使用 Python 标准库 Fraction 精确有理数。

## 运行

在本目录以 Python 3 运行 `python run_all.py`。这将执行普通、`-O`、`-OO` 三种模式，每种包括测试和示例，再生成并顺序执行 Notebook。真实命令、开始时间、耗时、退出码保存在 `run-summary.json`；环境在 `environment.json`，原始输出在 `logs/`。汇总 JSON 和 `SHA256SUMS.json` 可以交叉检查。无裸 assert 守卫，优化模式不应移除有效性检查。

Notebook 是六个代码格的标准库 compile/exec 顺序执行，共享命名空间；不是 Jupyter kernel、nbclient 或浏览器执行。输出保存在 `teaching.zh-CN.ipynb`，具体执行方式在其 metadata 与 `notebook-check.json`。本环境没有技能提供的 scaffold helper，因此使用手工标准 nbformat4 结构；没有安装新技能或依赖。

## 两个独立层次

1. `construct` 输入三个不共线有理平面点。每个内角用 `(点积, 叉积绝对值)` 表示，不求角度、不调用反三角函数。比较一个顶点的内角与另一个顶点的外角，检查严格正分子，并计算对应两内角和的正弦分子。
2. `ledger` 输入抽象有理角量 a、b、e、R，要求 a<e、b+e=2R、R>0 和正性。由同加得到 a+b<2R，严格差为 e−a。这里不判断这些角量是否可以同时实现为同一三角形。

第一层不通过三角内角和等式推出结论；它在坐标模型内核对外角比较和补角关系对应的代数。原证依赖 I.16 与 I.13，模型的点积、叉积、正弦加法则是现代解释工具。一般论证须另读正文；120个三角形不是对无限集合的穷尽证明。

## 输入、证书和覆盖

坐标接受整数或有理数字符串；拒绝浮点、布尔、无穷/NaN、退化点、额外键等。证书包含规范输入、方向面积和三对角证据。`verify` 重新构造并严格比较 JSON 类型，不能用 `True==1` 冒充模式号。它是当前实现的一致性检查，不是独立证明内核；另有独立技术审查。

最终实跑每模式34测试、120正证书（360对角）、12非法输入和63有理角量账本。模式间结果逐字结构一致。测试含旋转次序/反向、平移、不同输入绑定、字段删除/增加、类型替换、修改数字与虚假前提；样本范围有限，不覆盖浮点数值算法或非欧氏模型。
