# I.37：谓述限定与否定作用域的最小教学模型

这是本项目原创的现代重构，不是古代文本翻译，不是 Aristotle 的可执行算法。原章（Bekker 49a6–10）只提示谓述类别、某方面／无条件、简单／结合以及否定也要分别检查，并以进一步考察的要求收束。Owen1853印162注3–5给出牙齿与天鹅例；本程序不把注释例升级成原文定理，不判断人的群体属性，也不认证生物事实。

对应[深读正文](../../papers/ancient/aristotle-prior-analytics-i37.zh-CN.md)和[来源台账](../../papers/ancient/aristotle-prior-analytics-i37.sources.zh-CN.md)。

## 文件与运行

- `model.py`：显式谓词键、语法树、有限外延求值、受限包含链证书。
- `test_model.py`：18项单元测试，含拒绝路径和输入变更隔离。

## 1. 输入与语义

`Atom(name, category, aspect)` 是完整身份。三个非空字符串须完全相同才是同一原子。例如 `B/quality/teeth` 与 `B/quality/whole` 不是同一个谓词。`category`只是保留类别的标签，不实现古代十范畴的本体理论；`aspect`也不自动拥有“整体比部分强”等语义关系。

模型给定有限论域及每个原子的外延。`And(P,Q)`的外延是交集；`Not(P)`的外延是论域内补集。`includes(C,B)`是C外延包含于B；`some(P)`表示P有见证。外延必须在论域内，缺失原子抛出KeyError，**不是默认其外延为空**。字符串不是表达式，不做自然语言解析。

`And`仅用于用户已明确选择的外延相交读法。“白且是动物”可作这种教学输入；“假医生”“前任校长”作为不透明原子另给外延，不从文字拆出医生或现任校长。程序不知道这些词真实含义。

## 2. 一般证明与有限检查的区别

### 完整项保持的传递

若C包含于B且B包含于A，任取C中的对象，它先属于B，再属于A，所以C包含于A。证明对任何集合成立，并不依赖有限枚举。`chain_certificate((C,B),(B,A),(C,A))`仅检查此证书结构，**不认证两条前提真实**；须另外由模型或外部证据确认。

若第二条使用另一个方面的B，原有证书不能匹配，但这只表示这一个证明模板不接受，不表示结论在任何模型中都假。额外桥接前提可能使结论成立；本核验器不搜索它。

### 合取与见证

同一对象满足P且Q，它就属于两者交集；故交集包含于各分量。这一步依赖“同一对象”，不能把“存在P对象”和“存在Q对象”的两个不同见证合成。

### 否定的范围

一个对象不同时属于P、Q，当且仅当它至少不属于其中一个。因此“非(P且Q)”是两个补集的并集，而“非P且非Q”是两个补集的交集。后者蕴含前者，反向不成立。上述论证使用经典二值语义，不从原章短段推出 Aristotle 已表述现代德摩根定律。

## 3. 可手算反例

|错误步骤|完整赋值|核验|
|---|---|---|
|删除方面|论域只有0，B_other含0而B为空|B_other不包含于B。|
|跨方面串链|论域0、1；C和B_other都只含0；B和A都只含1|C包含于B_other，B包含于A，但C不包含于A；四项都非空。|
|把整体否定变为两个否定|论域只有0；P含0，Q为空|0满足非(P且Q)，但不满足非P且非Q。|
|拼接不同见证|论域0、1；P只含0，Q只含1|两者分别非空，交集为空。|
|把不透明修饰拆为交集|论域只有0；former-A含0，A为空|没有额外公理时former-A不包含于A；不是在判断具体自然语言事实。|

## 4. 实跑结果及计数口径

- 18项单元测试通过。
- 论域大小0至3，三个谓词的所有赋值共585个；其中85个满足两条包含前提，结论均成立。空论域单独纳入，不靠存在假设偷换全称规则。
- 同一范围两个谓词共85个模型，合取投影、双重否定、德摩根等式及较强否定到较弱否定的包含均通过。70个模型区分两个否定表达式；14个模型展示两个存在见证不可直接合并。
- 论域大小0至2，A/B/C/B_other共273个完整赋值，其中116个不允许删除方面，18个满足跨方面两前提而结论失败。116按四谓词完整赋值计数，包含对该项反例无关的A/C取值，不是116种独立历史错误。
- 同样大小0至2，不透明谓词与A的两谓词赋值共21个，其中8个不满足前者包含于后者。这是独立两谓词计数。

有限核验检查的是代码在列举范围内与声明语义一致，不证明上述一般集合定理，不证明原典体系完整，也不证明所有自然语言复合都透明。没有实验数据集、学习基线或预测指标；这里的“复现”仅指可重跑的教学算例和反模型。

## 5. 保守边界

该实现没有量词语言解析、模态逻辑、范畴类型推断、关于整体与部分的真实桥接、本体事实、所有推理路线搜索或古代文本自动理解。空集允许，存在需单独检查。任意方面可单独给值是刻意的弱模型：如需加入时间持续、部分到整体等关系，必须先给出相应公理与证据，不能以同名为由默加。Python的类、映射与结构化证书均为现代教学工具，不是对古代技术术语的同一化。

## 6. 独立审查与优化模式修正

独立审查指出初版回归脚本使用Python `assert`，优化模式会移除这些检查。已改为显式 `check` 与异常分支；正常、`-O`、`-OO` 三模式重跑均通过，三份结果JSON逐字一致，18项单元测试亦分别通过。`logs/optimization.txt`真实检查三模式中的`check(False)`均拒绝；这是执行检查不被优化移除的证据，不是语义完备性证明。
