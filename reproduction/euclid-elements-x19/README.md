# 《几何原本》X.19：公度的边围出有理面积

固定参考线段 `u>0`，将两边写成 `u√a,u√b`，其中 `a,b` 为正有理数。`classify(a,b)` 分别精确判断 `√(a/b)` 和 `√(ab)` 是否有有理值，返回边长比与相对于参考平方 `u²` 的面积比（无有理值时返回 `None`）。若面积比为既约 `m/n`，公度面积取 `u²/n`，恰好量出矩形 `m` 次、参考平方 `n` 次。此为相对参考平方的定义；代码不以绝对坐标近似根式。

例如 `(a,b)=(2,8)` 得边长比 `1/2`、面积比 `4`；`(2,3)` 的两种比均无有理值。更换参考线段时，按同一个实际矩形重新计算 `a,b`：由 `u` 换成 `2u` 时，原来的 `a,b` 均除以 4，边长比不变而面积比缩为原来的四分之一。模型不接受任意实数输入；若相对于新参考线段的平方坐标不再是有理数，即超出输入域。

命题的方向是从边长可公度推出有理面积。在所设的模型内，也可用 `√(ab)=b√(a/b)` 得到反向，但不把这点归为本命题的主张。

独立校验：对既约 `a=p/q`，用试除将整数 `pq` 化为平方自由部分。不调用整数平方根；仅比较两项的平方自由部分是否一致。基线核对了每项分子和分母均在 1–12 的全部 20,736 个有序输入对（未去除同值分数的重复代表）；1,696 对两种比均有理，19,040 对两种比均无理。有限校验不是一般性证明。
