# 从特殊图形到可检查的一般步骤

本文完整说明程序中的对象、记号和推导。模型是在今天构造的教学工具；它们说明某种区分如何被精确表达，不表明 Berkeley 具有这些数据结构或算法。

## 一、线性证书：某个细节究竟参与了证明吗？

### 变量与几何解释

设一个非退化的欧氏平面三角形的三个内角为 $`a,b,c`$，单位为度。通过内角 $`b`$ 所在顶点作与对边平行的直线。在这条直线上，$`u`$、$`b`$、$`v`$ 构成一个平角；交错内角关系分别给出 $`a=u`$ 和 $`c=v`$。

这些几何关系作为输入前提提供。程序不绘图、不计算反三角函数、不从坐标证明平行线关系。使用 `Fraction` 是为了精确检查线性等式，不是声称任意实际三角形的角度都必定为有理数。系数证书检验通过后，同一加法与数乘推导对实数角值也成立。

变量顺序固定为 $`(a,b,c,u,v)`$。一条 `Equation` 由变量名元组、同维度系数元组和右端常数组成。例如系数 $`(1,0,0,-1,0)`$、右端 $`0`$ 表示 $`a-u=0`$。

一般前提是：

```math
P_1:\quad a-u=0
```

```math
P_2:\quad c-v=0
```

```math
P_3:\quad u+b+v=180
```

目标是：

```math
T:\quad a+b+c=180
```

`Premise` 给等式加一个标签，`Certificate` 只保存按前提顺序排列的精确权重。检查器逐项计算：

```math
\sum_{i=1}^{n} w_i L_i = \sum_{i=1}^{n} w_i r_i
```

其中 $`L_i`$ 是第 $`i`$ 个前提的左端线性形式，$`r_i`$ 是右端常数，$`w_i`$ 是对应权重，$`n`$ 是前提数量。只有所得全部系数和右端都与目标一致，证书才有效。

对前三行取权重 $`(1,1,1)`$，直接相加：

```math
(a-u)+(c-v)+(u+b+v)=0+0+180
```

$`u`$ 和 $`v`$ 抵消，得到目标。这里是可检查的有理线性运算，既不靠变量名称暗示，也不靠“没有提到某个细节”的文字陈述。

### 把图中偶然性质加入，再删去

额外加入两条可用于一幅直角等腰特殊图形的事实：

```math
P_4:\quad b=90
```

```math
P_5:\quad a-c=0
```

五条前提对应的证书为 $`(1,1,1,0,0)`$。`Verification.dependencies` 因而恰好列出 `alternate_a`、`alternate_c`、`straight_angle`。零权重行不计入依赖。

`restrict_certificate` 做三步：

1. 直接重算并检查原证书有效。
2. 确认被删前提没有非零权重。
3. 构造缩减后的前提和权重，再次直接检查目标。

因此删除特殊图形事实后得到的是一份再次通过检查的证书，而不是未经验证的“可推广”声明。

### 一份不能迁移的证书

若目标改为 $`b=90`$，权重 $`(0,0,0,1,0)`$ 证明它时明确依赖 $`P_4`$。删除 $`P_4`$ 后，这份证书不能迁移；把剩余权重置零也只能推出 $`0=0`$，不能推出 $`b=90`$。

不过，“这一份证书失败”本身还不能证明“没有其他证明”。为此测试另外给出反模型：

```math
(a,b,c,u,v)=(60,60,60,60,60)
```

它满足 $`P_1,P_2,P_3`$，而且保留 $`a=c`$，却不满足 $`b=90`$。这才排除了由这些一般线性前提蕴含直角结论。三个内角都是正数且和为 $`180`$；这里无需把某一幅具体图的直角属性推广到所有图形。

### 依赖集的精确含义

依赖表示“这份给定证书用了哪些非零权重行”。如果同一条等式出现两次，权重分别为 $`1`$ 和 $`-1`$，它们虽然相互抵消，仍都记录为依赖。程序没有寻找最小前提集，没有证明唯一性，也不声称移去一项非零依赖后不存在别的证书。

检查器拒绝错维度、重复标签、不同变量顺序、浮点数和布尔数；不把 `True` 当作整数 $`1`$。合法输入下，错误权重或错误目标会得到 `valid=False`；结构不合法则抛出明确异常。

## 二、有限词项外延：一般性不等于一张混合图像

### 数据与直角判据

`Triangle` 的输入是三个二维整点，各点之间以直线段相连。三个点的叉积不为零才接受，因此重复点和共线点被拒绝。对于点 $`P=(p_x,p_y)`$ 和 $`Q=(q_x,q_y)`$，边长平方是：

```math
d^2(P,Q)=(p_x-q_x)^2+(p_y-q_y)^2
```

程序不用浮点平方根。把三个平方值排为 $`s_1 \leq s_2 \leq s_3`$ 后，由欧氏几何中勾股定理及其逆定理，直角条件等价于 $`s_1+s_2=s_3`$。这项几何事实是模型采用的数学背景，不是在代码里重新证明的定理。

演示的三个案例是：

- $`T_1`$：$`(0,0),(3,0),(0,4)`$，平方边长 $`(9,16,25)`$，是直角三角形
- $`T_2`$：$`(0,0),(2,0),(1,2)`$，平方边长 $`(4,5,5)`$，不是直角三角形
- $`T_3`$：$`(0,0),(4,0),(1,1)`$，平方边长 $`(2,10,16)`$，不是直角三角形

它们是独立的集合示例，不要求 $`T_1`$ 同时具有上一节可选图形的等腰性质。Python 对象按给定顶点元组区分案例；改变顶点排列会改变编码对象，但不改变边长平方或直角判断。这里没有实现模掉平移、旋转或顶点重排的几何同构分类。

### 定义范围与选取代表

声明有限论域 $`D=\{T_1,T_2,T_3\}`$。一个 `FiniteSign` 保存名称、论域和该词项的外延。称它在此论域上具有完整三角形范围，严格指外延恰好等于 $`D`$。

```math
\mathrm{denotation}(\text{triangle})=D
```

这里的集合外延是现代语义模型，不是把 Berkeley 的原话替换成一套集合论。它让人清楚区分两件事：给一个词声明整类对象的适用范围；从中取出一个具体案例供观察或演示。

如果某标记只指称 $`\{T_1\}`$，它便没有覆盖三个案例。检查 $`T_1`$ 是直角不够；若声称全部被该一般词项指称的对象都是直角，`first_counterexample` 会按论域声明顺序返回 $`T_2`$。

一个词项可以同时适用于直角和非直角三角形；这并不要求造出一个具体三角形，同时满足“是直角”和“不是直角”。程序没有实现心像，也没有从集合覆盖率推断一个人能想象什么。

另一个必要区分是空外延：它没有反例，但不覆盖这个非空论域。因此 `first_counterexample` 返回 `None` 不等于一般性成立，必须另查 `covers_domain()`。反例搜索证明的也只是在给定外延中有没有违例。

所有覆盖与反例结论都相对于有限 $`D`$。把论域改成单个案例，会改变覆盖判断的含义；这些测试不承担所有欧氏三角形的普遍量化。

## 三、多项式：符号结构怎样保证所有代入一致？

### 语言及规范形

表达式只有四种构造：

- `Const(q)`：有理常数 $`q`$，存为 `Fraction`
- `Var(name)`：变量
- `Add(P, Q)`：加法
- `Mul(P, Q)`：乘法

没有除法构造。负数可以作为常数，所以能表达相消；有理系数并不意味着支持带变量分母的有理函数。

单项式用按名字排序的正整数幂元组表示。例如 $`x^2y`$ 对应 `(('x', 2), ('y', 1))`；空元组表示常数单项式 $`1`$。多项式是按单项式排序的非零系数项元组。重复单项式合并，相消到零的项删除；零多项式是空项元组。

例如两个表达式：

```math
E_1=x(y+z),\qquad E_2=xy+xz
```

规范化后都是：

```python
Polynomial((
    ((('x', 1), ('y', 1)), Fraction(1)),
    ((('x', 1), ('z', 1)), Fraction(1)),
))
```

### 为什么不只是在少数数值上碰巧相等？

用指数向量 $`\alpha`$ 表示一个单项式的变量幂，用 $`p_\alpha`$ 表示系数。规范形可以看作只有有限个非零项的映射 $`\alpha\mapsto p_\alpha`$。

加法逐项加系数；乘法把单项式的指数相加，再合并系数。因此乘积在指数 $`\gamma`$ 处的系数为：

```math
(pq)_\gamma=\sum_{\alpha+\beta=\gamma}p_\alpha q_\beta
```

对三个任意有限支持有理系数多项式 $`p,q,r`$，有：

```math
\begin{aligned}
(p(q+r))_\gamma
&=\sum_{\alpha+\beta=\gamma}p_\alpha(q_\beta+r_\beta)\\
&=\sum_{\alpha+\beta=\gamma}p_\alpha q_\beta
 +\sum_{\alpha+\beta=\gamma}p_\alpha r_\beta\\
&=(pq+pr)_\gamma.
\end{aligned}
```

这些都是有限和，第二步使用有理数的分配律；这不是尝试从计算机代码中重新证明有理数域公理。每个指数处的系数相等，所以形式多项式相等。

再看代入。对于给每个出现的变量赋有理数的环境 $`\rho`$，常数和变量的规范化显然保值；若两个子表达式的规范化保值，加法的逐项合并和乘法的卷积也分别保值。由表达式结构归纳，可得：

```math
\mathrm{eval}(E,\rho)=\mathrm{eval}(N(E),\rho)
```

其中 $`N`$ 是上述规范化，$`\mathrm{eval}`$ 是递归求值。于是两个表达式具有同一规范形，就对所有有理赋值具有相同结果。这是数学上的普遍论证；测试程序不是一个已经机械化验证了自身正确性的证明助理。

演示还选取一组具体赋值 $`x=2/3`$、$`y=-3/5`$、$`z=7/2`$。原表达式、展开式和规范形都得到 $`29/15`$。这是一条可复算实例，不是普遍结论的来源。

### 同时替换与诱导环境

`substitute(E, replacements)` 对原表达式树作一轮替换。若 $`\sigma(x)=y+1`$、$`\sigma(y)=2`$，对单独的 $`x`$ 替换得到 $`y+1`$，而不是 $`2+1`$。插入的树不在同一轮被重新遍历。变量互换 $`x\mapsto y,y\mapsto x`$ 也不会造成循环。

给定数值环境 $`\rho`$，定义诱导环境：

```math
\rho_\sigma(x)=\mathrm{eval}(\sigma(x),\rho)
```

没有列入替换的变量按自身处理。合法环境必须给原式未替换的变量及相关替换像中的全部变量提供有理值。例如把唯一变量x同时替换为常数7以后，空的数值环境即可解释结果；无需再给已被替换掉的x赋值。对常数、变量、加法与乘法作结构归纳得到：

```math
\mathrm{eval}(E\sigma,\rho)=\mathrm{eval}(E,\rho_\sigma)
```

变量情形直接来自诱导环境的定义，加法和乘法情形把子树的归纳假设代入即可。程序用带有重复变量和交叉引用的替换检查这一关系，并检查替换前后分配律两边仍得到同一规范形。

环境的合法性不能略去：$`x+(-1)x`$ 的规范形是零，但原表达式求值仍要求给 $`x`$ 赋值。只给空环境时，规范形可求值，原式会报缺少变量；这不是保值定理的反例，因为该环境本来不在原式的定义域内。

### 有限测试负责哪一部分？

测试先在五个明确分数值的三变量笛卡尔积上检查分配律，共 $`5^3=125`$ 组赋值。另构造 85 棵表达式树，逐一与 17 组分数环境配对，共 $`85\times17=1445`$ 组，比较递归求值与规范形求值。

此外还实际检查 125 组同时替换与诱导环境的配对。上述案例数均由运行中的循环累计。

这些检查会发现某些程序错误，但任何有限样本都不能替代结构归纳证明。测试特意保留 $`x`$ 与 $`x^2`$ 的对照：在 $`x=1`$ 时相等，在 $`x=2`$ 时不同，规范形也不同。

实现的边界是小型教学表达式。递归深度和展开规模受 Python 与内存限制；它不承诺高性能、任意规模终止资源界，也不支持非交换乘法、实数近似运算或除法恒等式。

## 四、阅读输出而不夸大证据

可以按以下顺序核对：

1. 看 `linear_certificate.valid` 和实际合成的系数、右端；不能只看依赖标签。
2. 比较删除特殊前提前后的证书，以及直角目标的失败和反模型。
3. 看 `finite_sign` 的论域大小、平方边长和反例；不要把声明的三个案例当作整个几何世界。
4. 看相同规范形、具体代入结果和上面的归纳说明；把实现测试与数学论证区分开。
5. 看 `results.json` 中普通、`-O`、`-OO` 每次的退出码、实际方法数和尝试案例数。

三种优化模式都通过只能说明这批检查在这些运行配置下通过。它不能认证原文诠释，不能证明任何经验性心理学命题，也不能排除所有程序错误。
