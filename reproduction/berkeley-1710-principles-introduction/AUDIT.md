# 独立代码审计：Berkeley 1710 导论教学附件

## 结论与范围

结论：在下列实际执行、有限枚举、语义故障注入与人工代码检查的范围内通过，未发现未解决的模型实现缺陷。审计是独立于作者测试另写的检查，不是把作者的 PASS 复制为新证据。

审阅对象包括 `model.py`、`examples.py`、`test_model.py`、`run_checks.py`、README、逐步说明，以及文章中与这些实现对应的现代重构、例子、运行声明和练习答案。主文完整文件的 SHA-256 绑定只保证审阅的是同一版本；本代码审计不独立认证其他历史段落、1710 扫描来源或版本归属。主文第6–7节的数学解释、第11节的实现边界与运行说明是重点。

`audit/code_review.json` 逐项保存确切字节数和 SHA-256。它不绑定自身，也不相互绑定其他可变审计报告，避免散列循环。复核当前交付字节可运行：

```sh
python3 -B audit/verify_evidence.py
```

这个命令只读已保存证据，不重写结果或自动更新审核散列。若要重新执行全部测试：

```sh
python3 -B audit/run_audit.py
```

重跑会更新带执行时间的日志与 `audit/results.json`；此前的冻结散列随之失效，需要重新审阅后绑定，不能把重跑与原证据的静默替换混为一谈。

## 实际执行与计数

审计在实际记录的 CPython 环境中，分别以普通、`-O`、`-OO` 运行。具体 Python 版本、平台、UTC 起止时间、命令、退出码、每条标准输出及标准错误见 `audit/results.json` 与 `audit/logs/`。只使用 Python 标准库，不联网，不安装软件。Python 3.10 是作者声明的语法最低版本；本次不声称实测了所有受支持 Python 版本。

每种模式执行：

- 作者测试：52 个 `unittest` 方法，失败、错误、跳过均为0
- 作者示例：逐项检查证书、依赖、删除反例、有限外延、平方边长、规范形、精确数值和同时替换结果；三模式输出逐字节相同
- 独立完整检查：与作者不同的有界输入生成、参考表示和判定方式
- 13 个原模型目标探针，确认各探针在未变异程序上通过
- 对应的13个语义变异程序；每个均由语义检查失败检出
- 1 个刻意的框架异常探针；单独识别为框架错误，不计入语义变异检出

共90个子进程。13种变异在三模式中共39次语义检出，另有3次框架异常分类检查。这些是同一测试设计在不同解释器配置中的重复执行，不是39种独立缺陷或三倍独立实验。作者原有 `results.json` 和此次独立重跑的结果也相互核对。

作者每模式的嵌套案例为：125组分配律赋值、1,445组表达式/环境配对、125组同时替换赋值。它们不是额外的 `unittest` 方法。

## 独立有界参考检查

### 1. 线性证书、支持与删除

完整枚举两个前提、一个变量的系统：每行的系数与右端均取 $`\{-1,0,1\}`$，两个权重也取同一集合。总计729组系统/权重配对。

独立参考直接计算两个标量线性组合，核对合成系数、合成右端、有效性及非零权重标签。每组另外改变目标系数或右端，共1,458个错误目标，均应被拒为证明。

对每组证书枚举全部4种保留标签子集，共2,916次删除检查；特意把保留标签以反向顺序传入，确认输出仍保持原前提顺序。参考许可条件是“所有非零权重行都保留”，包括非零行相互抵消的情况。删除后直接再次检查目标。对于五个候选赋值，凡满足支持中前提者，核对目标，实际得到917个满足条件的赋值检查。

另有25组分数与大整数权重检查二维精确线性组合。程序不是求解器；错误证书被拒不意味着目标不存在其他证书。支持是当前证书的支持，不是最小逻辑前提集。

### 2. 三角形与有限词项

从 $`\{-1,0,1\}^2`$ 的9个点中，有序允许重复地选三个点，穷尽729组顶点元组。独立鞋带行列式判定273个退化输入；它们均被拒。其余456组按三个顶点的两条关联边之内积是否为零判断直角，不重复使用实现中的勾股等式作为右角参考。

对演示的三对象论域，枚举6种论域顺序、8种外延和8种谓词真值表，共384组。核对全域覆盖、首个反例、实际调用谓词的对象及停止位置。空外延无反例不等于覆盖非空论域；搜索不能越过外延，返回顺序必须服从显式论域顺序。

这些对象按顶点元组区分，不是按平移、旋转、顶点重排后的几何同构类区分。有限穷尽只针对已声明输入域。

### 3. 多项式规范形与求值

独立参考语法使用带标签元组，不调用实现来产生参考值。其规范形参考把单项式写成重复变量单词，例如 $`x^2y`$ 表示为 `('x', 'x', 'y')`，不同于实现的正整数指数元组。系数精确相加，乘法连接并排序变量单词。

五个叶子为 $`0,-1,1/2,x,y`$。枚举全部最多两个二元内部节点的有序表达式树：5个叶子、50棵单节点树、1,000棵双节点树，合计1,055棵。逐棵核对完整非零系数映射。每棵再与 $`\{-2,0,1/3\}^2`$ 的9种环境配对，共9,495组；独立递归解释、实现原式求值、实现规范形求值三者一致。

有限输入无法证明所有表达式的正确性。主文的结构归纳论证是数学理由，本审计是对实现出错的有限搜索；没有借测试声称程序已由证明助理认证。

### 4. 同时替换

对55棵最多一个内部节点的树，给每个变量分别选择不替换、替成 $`x`$、$`y`$、$`-1/2`$、$`x+y`$ 或 $`xy`$，共 $`55\times6^2=1980`$ 组树/替换映射。

独立参考只遍历原树，不再次遍历插入树。逐组核对替换后完整 AST 与系数表示；再与9种环境配对，共17,820组诱导环境检查。变量互换和交叉引用包含在域中。另检验把 $`x`$ 完全替成常数7后可以用空环境求值；原来的 $`x`$ 已不需要数值。

### 5. 结构校验与定义域

全部独立运行累计1,982次预期拒绝。这个数字包括不能删除非零支持、退化三角形以及非法结构/缺少变量等不同类型，不应称为1,982种畸形输入。

检查包括浮点、布尔、字符串冒充有理数，非法名字、错维度、错容器类型、重复标签，零/重复/无序规范项，非法指数，不属于表达式语言的对象，未赋值变量，非法或多余的环境字段，错误替换像，以及谓词不返回布尔值。常数值被精确规范化；安全校验不靠会被优化模式删除的 Python `assert`。

特别保留相消域反例：$`x+(-1)x`$ 规范化为零，但原式用空环境求值仍应报错。规范化保值关系要求原式所需变量都有值。

## 语义故障注入

每个变异只替换源码中唯一定位的一处，临时副本用于该目标探针，不改正式 `model.py`。具体旧文本、新文本、变异副本 SHA-256、退出码与输出均已保存。变异副本在执行后删除。

13种变异分别是：忽略证书右端；忽略证书系数；把零权重列入支持；放过删除非零支持；把直角相等判据改为不等式；把非空外延误作全覆盖；让反例搜索越过外延；规范化加法丢弃右项；乘法指数取最大值而非相加；原式乘法误作加法；规范形求值忽略指数；把同时替换变成递归重写；允许布尔数冒充精确数。

只有预期参考比较触发 `AssertionError` 并输出 `semantic_failure` 才计为语义检出。导入问题、语法错误、意外异常、超时或其他非零退出不能冒领这个结果。本次39次检出均是语义失败，3次故意的 `RuntimeError` 则输出 `framework_error`、退出码2，明确排除。

## 发现、修正与限制

初审发现执行器把绝对解释器及工作目录写入发布证据；作者改为记录解释器文件名和相对工作目录，实际仍使用当前解释器执行。最终审计核对的是修正后的版本。

逐步说明的同时替换环境条件已与主文对齐：只需覆盖原式未替换变量和相关替换像中的变量。实现原本正确，无需为此改变模型。

未发现其他待修实现缺陷。这不等于不存在缺陷。递归深度、展开内存、恶意反射修改被冻结对象、自定义有副作用映射等不在面向小型教学输入的保证内；不承诺任意资源规模。线性模块不从坐标建立几何前提，多项式没有除法，有限词项不穷尽所有真实三角形。

本审计不验证人的想象、语言理解或认知机制，不把模拟成功变成心理学证据，不把有限枚举当作普遍证明，也不认证历史文本解释。源码、明确语义、独立参考和实跑日志一起构成有边界的复核材料。
