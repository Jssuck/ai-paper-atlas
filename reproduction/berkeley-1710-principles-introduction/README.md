# Berkeley 1710 Introduction：三个可检验的教学模型

这是一份围绕 *A Treatise Concerning the Principles of Human Knowledge* 的 Introduction §§1–25 编写的现代教学重构。它不是 Berkeley 留下的程序，也不是对人类想象、理解或推理机制的实验复现。运行结果不能证明哲学主张正确，更不能据此宣称人工智能复现了人的认知过程。

这里只实现三件事：

1. 用精确线性组合检查 §16 三角形例子的证明是否依赖特殊图形条件。
2. 用有限论域区分一般词项的指称范围与一个代表案例。
3. 用有理数系数多项式演示符号运算、规范形和代入值的对应。

历史文本、版本与论证解释以同一发布包中的文章和出处审计为准。下面的变量、数据结构、程序与测试均为本教学重构新增。

## 运行

需要 Python 3.10 或更新版本；只用标准库，不访问网络，不安装第三方包。在本目录执行：

```sh
python3 examples.py
python3 test_model.py
python3 run_checks.py
```

`examples.py` 输出精确分数和可读 JSON；`test_model.py` 输出真实的 unittest 执行数；`run_checks.py` 分别启动普通、`-O`、`-OO` 三种解释器模式，并保存：

- `environment.json`：实际 Python、平台、执行时间、工作目录和源码 SHA-256
- `results.json`：每条命令、退出码、解析结果及计数
- `logs/`：每个子进程独立的标准输出和标准错误

当前测试设计有 52 个 unittest 方法。每种模式另外实际遍历 125 组分配律代入、1,445 组表达式／环境配对和 125 组同时替换／诱导环境配对；它们是方法内部的有限案例，不另算成 1,695 个测试方法。计数由执行中的循环累计。同一套方法在三种模式下重复执行，不等于三倍的独立测试设计。最终是否通过请读 `results.json`，不要只根据本段静态说明判断。

没有输入安全检查依赖 Python 的 `assert`；`-O` 或 `-OO` 不会把这些检查删掉。测试中的 `unittest` 检查也在优化模式下执行。

## 文件与入口

- `model.py`：全部模型和校验逻辑
- `examples.py`：一组确定性演示
- `test_model.py`：正常情况、反例、错误输入和有限枚举测试
- `run_checks.py`：三模式执行和证据记录
- `WALKTHROUGH.md`：完整变量说明、推导、限制和阅读路径

主要接口如下。它们返回普通 Python 对象，不调用外部证明器。

```python
check_certificate(premises, target, certificate)

FiniteSign(name, domain, denotation)

```

## 三个应观察到的结果

### 1. 证明的一般性来自实际依赖

三个一般前提为 $`a-u=0`$、$`c-v=0`$ 和 $`u+b+v=180`$。用权重 $`(1,1,1)`$ 相加，得到 $`a+b+c=180`$。

程序还提供特殊图形事实 $`b=90`$ 和 $`a-c=0`$。五行证书的权重是 $`(1,1,1,0,0)`$，因此后两行不会进入依赖集。删去这两行后，程序重新计算证书，仍然通过。

反之，目标 $`b=90`$ 的证书 $`(0,0,0,1,0)`$ 使用了特殊前提，不能迁移到删去该前提后的环境。一般前提还容许 $`(a,b,c,u,v)=(60,60,60,60,60)`$，这是反驳“一般前提已经蕴含直角”的明确反模型。

检查器检查的是线性后果，不会从坐标自动建立几何前提，也不会验证平行线构造、图形可实现性或欧氏几何公理。依赖集是这份证书所有非零权重前提的集合，不是计算出的最小逻辑假设集。

### 2. 一般指称不要求一个图像兼具互斥特征

三个三角形的边长平方分别是 $`(9,16,25)`$、$`(4,5,5)`$、$`(2,10,16)`$。只有第一个满足直角判据。一般词项的外延可以同时包括三者；只指称第一个案例的单元素外延不能覆盖整个三元素论域。

这只是一个显式有限集合模型。“覆盖全部”始终相对于声明的论域而言；穷尽三个数据点并不证明关于所有欧氏三角形的命题。对象是整点坐标的非退化直边平面三角形，边由顶点之间的直线段确定，不含球面三角形、曲边图形或退化三角形。

### 3. 恒等式与成功代入是不同层次

`normalize` 把 $`x(y+z)`$ 和 $`xy+xz`$ 都化为具有两项的同一规范形。逐步说明给出了规范形的数学语义及为何能支持对所有有理数赋值成立的恒等式。

实现还支持一轮同时替换：把变量换成表达式后，不在同一轮递归重写新插入的树；并检查其与诱导数值环境的对应。

有限代入测试用于查程序错误，不承担普遍证明的作用。反例也在测试中：$`x`$ 与 $`x^2`$ 在 $`x=1`$ 时相等，却不是同一多项式。

表达式语言只有常数、变量、加法和乘法。常数允许 `Fraction`；语言没有除法，也不尝试有理函数约分或处理分母为零的条件。

## 使用边界

适合：课堂阅读、检查模型假设、改动权重或数据寻找反例、理解规范化和证明依赖。

不适合：以运行成功替代原文解释、声称证明 Berkeley 的心理学、把有限论域冒充普遍范围，或当作高性能通用定理证明器。

更细的推导见 [逐步说明](WALKTHROUGH.md)。本目录不另设重复练习题；文章中的问题可以直接用这些入口验证。
