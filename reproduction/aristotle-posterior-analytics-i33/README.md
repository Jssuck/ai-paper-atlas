# 《后分析篇》I.33：真值、必然性与把握方式的最小教学模型

本目录是原创 Python 教学重构，对应 [中文深读](../../papers/ancient/aristotle-posterior-analytics-i33.zh-CN.md) 与 [来源核对](../../papers/ancient/aristotle-posterior-analytics-i33.sources.zh-CN.md)。它不复刻古代程序，不是完整知识论复现，也不把机器判定的标签叫作知识。

## 原文关联和建模分层

实读《后分析篇》I.33 **88b30–89b9** 的[希腊文／Mure 英译](https://aristotle.johnhboyer.com/APo/book/1/#ch-1-33)，具体原文版本与校勘见来源文档。

- 88b30–89a10：区分真与不能否则。本模型先计算一个指定实际情形中的真值，再计算所有已选情形中的真值；有限情形的选择是现代重构，不能代替原文的本质性必然。
- 89a11–22：相同中项／追溯至直接前提的理由链，不自动消除知识与意见的区别。`reason_trace` 因此与 `mode` 分开；意见不被定义成没有推理、没有理由或没有所以然。
- 89a23–36：同一对象并不保证同一命题或同一把握方式。对象标识、命题文字、把握标签是不同字段；字符串只是显式建模的记录，不是自然语言语义分析器。
- 89a37–89b6：同一人同时就同一方面接受“必然如此”和“可以不如此”时，本模型报告冲突。它是明示一致性约定，不是对人类心理的实验定律，也不是对现代广义 belief 与 knowledge 关系的定义。

## 接口与精确范围

`World(a,b,c)` 用有限集合表示三个谓词的外延；前提为 `C ⊆ B` 且 `B ⊆ A`，结论为 `C ⊆ A`。每个情形分别解释这些谓词。集合可以为空：全称包含可空真，但不据此产生存在结论；古代存在承诺不在这个模型中。

`modal_profile(truths, actual=0)` 返回实际真值、所有已选情形中都真的标志，以及某情形可假的标志。拒绝空情形集、非法实际索引、非布尔真值。这里“必要”始终是**相对于所给有限模型**，不是把词典定义、真实本质或全部可能世界交给程序验证。

`Judgment` 存储主体、时刻、方面、对象、命题、模式和理由链。模式有：

- `necessary`：主体断言不能不如此；标签本身不保证断言正确。
- `can_be_otherwise`：主体断言该谓述可以不成立；不是单纯的未知或置信度较低。
- `uncommitted`：未作上述两种模态断言；不自动称作意见。

`conflicts` 只检查同一五元上下文中是否同时有前两种相反模式。它**不是完整的逻辑一致性判定器**：例如命题字符串 `p` 与 `not p` 不会被自动解析。没有记录也不会产生知识或意见。对“真知识”的充分条件、事实与本质是否匹配、原因是否真正恰当，本程序都不判定。

## 本次实际结果

1. 对象域大小为 2。每个集合有 4 种取法，每个情形有 `4³ = 64` 个三集合结构，两个有序情形共 **4096** 个模型。
2. 单情形满足两前提的结构有 16 个（每个对象在嵌套链中有 4 个位置）。两个情形都满足前提的模型 **256** 个，结论不在两处都真的反例 **0** 个。
3. 实际情形满足前提的模型 **1024** 个，其中结论在另一情形为假的有 **448** 个。这是“实际正确推导”不自动等于“跨情形必要”的可复查反例族。另一个情形的前提并未被要求仍真，故不反驳集合传递律。
4. 长度 1–4 的全部布尔向量和所有有效实际索引共 **98** 组模态检查；3 种模式的全部 9 个有序配对在 6 类上下文下检查冲突，共 **54** 组。
5. 演示中相同理由链在不同主体处不报冲突；改成同一主体同一时刻同一方面则报 1 个冲突。还显式保存了“全情形真却被断言为可否则”与“非全情形真却被断言为必然”的错误把握，避免让认知标签生成客观事实。
6. 普通、`-O` 与 `-OO` 三种模式各 **13 个测试通过**；Notebook **4 个单元实跑成功**。测试使用 unittest 断言，而不是会被优化模式删除的裸 `assert`。

有限穷举仅核对这里的程序与声明范围，不证明一般定理。一般的集合传递证明很短：任取属于 C 的对象，由 C 包含于 B 得它属于 B，再由 B 包含于 A 得它属于 A；任取情形重复即可。该数学证明也不能单独证明亚里士多德关于知识、意见、本质与人类把握方式的整个主张。
