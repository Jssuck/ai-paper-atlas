# 《几何原本》IX.30：奇数度量偶数，也度量其半

给定奇数 $`A\ge3`$ 和偶数 $`B\ge2`$，以反复减 $`A`$ 求完整份数。如果余数非零，输入不满足命题前提。若整除，份数必偶：若份数为奇，按 IX.29 的等价改写（原证直接用 IX.23），取奇数 $`A`$ 的奇数份会产生奇数，与 $`B`$ 为偶矛盾。取份数的一半即可得到 $`B/2`$。例如 $`A=3,B=24`$，份数为 8，半数 $`12`$ 由 4 份组成。$`B=2A`$ 时半数恰等于 $`A`$，半份计数为一单位；这不是把单位作为原输入。

若去掉除数为奇的条件，结论失效：$`4`$ 度量 $`12`$，却不度量 $`6`$。$`(3,10)`$ 不整除，不可用本命题。单位、零和负输入不在该模型中。重复减法用于教学，耗时随份数增长；大整数测试选择小份数。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线在两输入各取 1 至 64 时，以取模筛查整除，直接算 $`B/2`$ 并再次核验整除，与反复减法比较。日志步数只计合规输入的减法。有限核验不能替代一般证明。Notebook 日志记录标准库实跑三个代码单元，不是 Jupyter 内核运行。
