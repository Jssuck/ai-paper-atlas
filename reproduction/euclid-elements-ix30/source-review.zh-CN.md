# IX.30 原典核对

- [Heath 1908 英译卷 II](https://www.wilbourhall.org/pdfs/Heath_Euclid_II.pdf#page=430)印页 417、扫描页 430，位于 IX.29 结束后、IX.31 开始前。图中 A 是奇约数，B 是偶被整除数，C 是量尽的次数。反设 C 奇后，原文写 A 乘 C 得 B，即依卷 VII 的乘法约定取 A 份 C；在说明 B 奇时明确括注 IX.23。
- [Fitzpatrick 希英对照本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=274)印页 274–275：题句、Α、Β、Γ 图和反设在 274，判 B 奇、矛盾、C 偶及量尽 B 的一半在 275。其英栏同样在奇数项求和处标 IX.23。IX.29 可以给出内容等价的现代重述，但并非这两个读本在此标出的直接依赖。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.30.html)希文有「量尽一半」及证毕，英文止于 A 量尽 B 偶数次。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX30.html)完整，并指本命题用于随后的 IX.31。该依赖说明不是原证的一步。
- [VII.定义 1–2](https://mathcs.clarku.edu/~djoyce/elements/bookVII/defVII1.html)将单位与数区分，次数一和被量的数为单位不能混淆。若 B 为 2A，则 A 正好量尽 B 的一半一次，而一半是数 A，不是单位；[VII.2](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII2.html)明确认可数可量尽自身。以整数表达减半后商为一是现代记法，不要求把单位列为原命题的奇数输入。所查读段未发现另行适用的正式勘误。
