# 《前分析篇》I.29：直接证明与反证的同项教学重构

## 定位与来源

对应原文 **45a23–46a2**，以两个直接/反证例及 “only” 附加条件为教学对象。原始文本入口：[Jenkinson 英译 Book I](https://en.wikisource.org/wiki/The_Works_of_Aristotle/Prior_Analytics/Book_I)。不同译本第三项字母有别，本代码统一用 G。

这是**原创现代严格集合语义重构**，不是古代证明系统的完整复原、一般定理自动证明器、原文全文翻译或古代模态逻辑实现。对非空性的补充是明确的现代建模要求，不能悄悄归作作者写下的额外前提。代码不分发原文 PDF。

## 语义和 API

`ALL(X,Y)` 表示 X⊆Y；`NO(X,Y)` 表示 X∩Y=∅；`SOME(X,Y)` 表示 X∩Y≠∅；`EX(X)` 表示 X≠∅。空术语允许存在，因此两个全称前提不能自行产生见证。

- `verify(proof, premises, expected)`：逐节点校验证书和结论，合法返回 `True`，不合法抛 `InvalidProof`。前提是调用者提供的假设，校验器不认证这些前提在现实中为真。
- `examples()`：返回 `(名称, 前提列表, 目标, 证书)` 构成的六案例列表（每个案例是四元组）。
- `holds(statement, model)`：独立的集合语义求值器；模型值用 `frozenset`。
- `finite_report()`：检验六个证书，并运行有限模型及反例检查。
- `node(rule, claim, *inputs, **extra)`、`given(index, claim)`、`assume(label, claim)`：创建可读的证明树节点。

证书节点字段严格限定。目标不由结果自动选择，而由调用者另行指定，防止把改写后的目标当成成功。`given` 必须准确匹配此前给定前提索引；布尔值不能伪装成整数索引。没有“某结论在测试中为真所以通过”的信任规则。

## 规则及局部正确性

| 规则 | 输入 → 输出 | 现代集合理由 |
|---|---|---|
| `all_trans` | ALL(X,Y), ALL(Y,Z) → ALL(X,Z) | 任取 X 中元素，依次进入 Y、Z |
| `no_sym` | NO(X,Y) → NO(Y,X) | 交集交换 |
| `no_sub` | ALL(X,Y), NO(Y,Z) → NO(X,Z) | 若元素在 X、Z，则也在 Y、Z，矛盾 |
| `some_map` | SOME(X,Y), ALL(Y,Z) → SOME(X,Z) | 原共同元素从 Y 进入 Z，仍在 X |
| `witness` | EX(X), ALL(X,Y) → SOME(X,Y) | 由非空取一个 X 元素，它同时属于 Y |
| `some_sym` | SOME(X,Y) → SOME(Y,X) | 同一共同元素 |
| `clash` | SOME(X,Y), NO(X,Y) → FALSE | 同一交集不能既空又非空 |
| `raa` | 在目标的精确矛盾式假设下导出 FALSE → 目标 | 使用经典二值集合语义；仅允许 NO 与 SOME 的互相矛盾 |

`raa` 为假设新建词法作用域；标签不能覆盖现有标签。子证明必须真的依赖该标签，得出 `FALSE`，才能卸除。其余规则传递实际依赖集合，最终不许有未卸除假设。交换术语虽在 NO/SOME 下语义等价，也必须显式用对称规则，不能靠标签近似匹配。这里拒绝不依赖假设的“空卸除”，是刻意采用的证书格式限制，**并非宣称经典逻辑不允许从既有矛盾推出结论**。

这些局部理由可用于对有限证明树作结构归纳的教学正确性说明；程序中有限枚举本身不代替一般证明。深度最多 64，最多访问 10000 个节点，故资源限制也会拒绝某些逻辑上有效的大证书。

## 六个案例

1. **否定直接式**：A⊆B 且 B∩E=∅，用 `no_sub` 得 A∩E=∅。
2. **同项目标反证式**：暂设 A∩E≠∅，对称得 E∩A≠∅，由 A⊆B 得 E∩B≠∅；与 B∩E=∅ 的对称式冲突；卸除暂设。
3. **特称直接式**：G≠∅、G⊆A、G⊆E。`witness` 产生 G∩A 的共同元素，对称、映射、再对称得 E∩A≠∅。
4. **同项目标反证式**：暂设 E∩A=∅；由 G⊆E 得 G∩A=∅，与 G≠∅、G⊆A 产生的共同元素冲突；卸除暂设。
5. **only 肯定提升**：E⊆G、G⊆A 得 E⊆A。
6. **only 否定提升**：E⊆G、G∩A=∅ 得 E∩A=∅。

原文 “only” 段还给 G⊆E，因此两向合起来是 E=G；案例 5、6 刻意只保留导出全称结论所需的 E⊆G，**不是说原文没给另一方向**。

## 必要的失败边界

- 缺非空：G=∅、A={0}、E={1}，两个包含前提都真，但 E∩A=∅。
- 缺 only 的肯定反例：G=A={0}、E={0,1}；G⊆A 且 G⊆E，不保证 E⊆A。
- 缺 only 的否定反例：G={0}、A={1}、E={0,1}；G∩A=∅ 且 G⊆E，不保证 E∩A=∅。
- 两世界诊断：世界 1 中 A=B={0}、C=∅；世界 2 中 A={0}、B=C=∅。A⊆B 在世界 1 成立，B⊆C 在世界 2 成立，却没有世界满足 A⊆C。它说明“分别可能”的存在世界量词不能无条件拼接，**不声称这是亚里士多德可能式的语义或对其模态定理的反驳**。

## 实跑、复跑与解释

仅需 Python 3 标准库。在本目录执行：

```bash
python3 run.py
```

`run.py` 实际运行并记录：

```bash
python3 -m unittest -v test_model
python3 -O -m unittest -v test_model
python3 -OO -m unittest -v test_model
python3 model.py
```

每种模式 **21 个测试**，六个正例为一个测试下的六个子例；所有校验判断使用显式异常而非 `assert`，优化模式不会关闭校验。测试覆盖错误目标/中项、缺存在、伪见证、错误或泄漏作用域、不依赖假设的卸除、错误矛盾式、缺 only、布尔/负索引、未知规则、多余字段、非法公式、深度边界和空术语。

域大小 1、2、3，四术语 A、B、E、G 的全部子集赋值共 **4368** 个模型。每个模型检测六个证书所对应的蕴含；前提满足次数依案例顺序为 **584、584、526、526、584、584**。对某个案例无关的术语仍枚举，因此这些数不是约去冗余后的本质模型数。另有 **3 个缺条件反例**与 **1 个两世界边界**；它们不混入 4368 模型计数。

见 `results.json`、`logs/tests-*.txt`、`logs/environment.json`。`manifest.sha256.json` 校验本目录文件（不含自身和 Python 缓存）；它用于完整性核对，不是数学正确性的证明。日志中的秒数与时间由实际运行生成，复跑允许改变。
