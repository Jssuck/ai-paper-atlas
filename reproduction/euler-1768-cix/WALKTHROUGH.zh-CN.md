# 第 CIX 信的可执行教学：保留、注意、输入与再认

**这是一份原创的现代教学重构。Euler 没有在第 CIX 信给出以下状态机；程序也不模拟人脑、不拟合心理数据、不证明或反驳心灵二元论。**

原文是 1768 年第二卷第 CIX 信，印 144–148 页，信末署 1761 年 3 月 10 日。请把出版年与署日分开。[出处与逐页范围](SOURCE.md)；[完整精读](../../papers/1768/euler-letter-cix.zh-CN.md)。精读正文第 7 节的三状态小模型只处理保持与活跃；下面的程序另加访问性、当前输入和再认，是明示的教学扩展。

## 1. 先运行，再看见程序到底报告了什么

要求 Python 3.10 或更新版本，只有标准库。没有安装步骤、密钥、付费服务或网络要求。进入本目录后运行：

```sh
python3 run_all.py
```

它依次运行测试、生成示例、穷举检查，并保存真实执行日志。也可单独运行：

```sh
python3 -m unittest discover -s tests -v
python3 memory_model.py --demo
python3 memory_model.py --check
```

主要结果是 [outputs/demo.json](outputs/demo.json) 和 [outputs/exhaustive.json](outputs/exhaustive.json)。实际命令、退出码、标准输出与错误输出在 [logs](logs) 中。环境记录在 [logs/environment.json](logs/environment.json)，代码与结果哈希在 [logs/run.json](logs/run.json)。

日志中的绝对解释器路径和工作目录已作可移植化处理，工作目录记为 `.`；真实标准输出、错误输出、退出码和计时保持原样。

**运行用时不是人的反应时间。** 本项目没有记忆分数、认知准确率或模型训练成绩。不要把测试全过读成“哲学主张已被实验确认”。

## 2. 为什么需要四个字段

程序固定只有两个内容标签：fire（火）和 bell（铃）。火来自原信例子；铃是为了比较而加的教学标签。它们只标识内容，不含火的图像、声音、语义特征或事件细节。

完整状态写成 $`S=(R,A,q,s)`$：

| 字段 | 代码名 | 要回答的问题 |
|---|---|---|
| $`R`$ | `retained` | 哪些表征仍被保留？ |
| $`A`$ | `recallable` | 哪些保留表征现在可被主动召回？ |
| $`q`$ | `attention` | 现在正关注哪个内容？ |
| $`s`$ | `sensory` | 现在独立呈现哪个输入？ |

必须满足 $`A\subseteq R`$。本模型还约定注意和当前输入要么为空，要么属于 $`A`$。这是便于核查的小模型限制，**不是**“人类注意到或感知到的内容必然都可主动回忆”的一般规律。

JSON 中 `null` 代表空。这里的“不可访问”精确指表征还在 $`R`$，但不在 $`A`$。它不同于根本不在 $`R`$。

程序没有保存第五个“以前见过”标志，也没有时间戳、计数器、外部数据库或随机状态。示例 JSON 能让读者看见过去，那是**外部观察者的日志**；状态转移函数从不读取它。不能在擦除后偷偷把日志喂回程序，再宣布程序凭空认出了过去。

## 3. 六种操作、九个具体动作

前三个带内容的操作各可作用于火或铃；其余三个不带内容，共九个具体动作。

- `perceive(x)`：先查看旧的 $`R`$ 是否已有 $`x`$，据此报告是否再认；然后把 $`x`$ 加入 $`R`$ 与 $`A`$，令注意与输入都变为 $`x`$。
- `recall(x)`：只有 $`x\in A`$ 才成功；成功只改变注意，失败不改变状态。**两种情况都不能改写当前输入。**
- `make_inaccessible(x)`：保留 $`R`$，把 $`x`$ 从 $`A`$ 移去，必要时清除对它的注意。只允许操作已保留、且当前没有独立呈现的内容。
- `withdraw`：撤去当前输入；注意可继续停留于刚才的观念。
- `set_aside`：移开注意；保留表征与当前输入不变。
- `erase_all`：把四个字段全部复位，包括撤去输入。这是为检查“完整状态相同”而规定的强控制操作，不是日常遗忘的心理机制。

`make_inaccessible` 同样是教学控制，不是从原文恢复出的遗忘算法。原文的“忘记”可能包含许多现实情况，这里只选择一种“存而不可主动取”的形式供比较。

每步还输出当前输入所对应的“当前存在确信”标签。标签总跟随输入，不能由召回单独生成。**这只是被规定的输入依据报告，不是外部世界真值。** 空标签不能证明现实中没有火，有标签也不证明传感器永不出错；模型根本没有“外部真的发生了什么”这一变量。

`recognized` 只在感知动作报告 `true` 或 `false`，其他动作是 `null`，意思是本步未检查再认。`recall_succeeded` 只在召回动作报告布尔值。不要把“不适用”误读为失败。

## 4. 手算例一：还记得，但此刻没在想

依次执行：

```text
perceive(fire)
withdraw
set_aside
```

逐步状态如下：

| 时点 | 保留 R | 可召回 A | 注意 q | 输入 s |
|---|---|---|---|---|
| 初始 | 空 | 空 | 空 | 空 |
| 看见火 | 火 | 火 | 火 | 火 |
| 撤去输入 | 火 | 火 | 火 | 空 |
| 移开注意 | 火 | 火 | 空 | 空 |

末态保留了火，却没有当前注意或输入。这就是“保留必然一直活跃”的一个形式反例。继续 `set_aside` 一千次，记忆仍在；这只检查幂等操作，**不是**把一千步解释为过了一千天。本模型没有时长或衰减参数。

再执行 `recall(fire)`，注意回到火，输入仍为空。程序重现的是**自定规则中的来源区分**，不是测得真实回忆一定成功。

## 5. 手算例二：回想火，不自动获得“现在有火”的依据

在上一例末态执行召回，输出包含：

```json
{
  "attention": "fire",
  "sensory_input": null,
  "current_existence_conviction": null,
  "recognized": null,
  "recall_succeeded": true
}
```

关键是 attention 与 sensory_input 两个不同字段：有火的注意内容，不等于有火的当前输入依据。

两个控制例能防止过强结论：

1. 先感知火，在输入仍存在时召回火。此时可以有火的当前依据；它来自独立输入，召回没有制造它。
2. 先保存火，再独立感知铃，最后召回火。此时注意为火、输入和其确信标签为铃。若程序把注意直接复制到输入，它就会在这个负例中露出错误。

因此规则不是“只要回忆，就绝无当前输入”，而是“回忆本身不能创建那个输入”。同样，没由回想获得当前有火的依据，不等于已证明当前没有火。

## 6. 手算例三：想不起来的报告相同，完整状态可以不同

分成两条路线：

**路线甲：** 感知火，撤去输入，使火不可访问，再尝试召回。

- $`R=\{\mathrm{fire}\}`$，$`A=\varnothing`$。
- 召回失败，注意与输入都空。
- 重新感知火时，旧的 $`R`$ 仍含火，因此报告再认 `true`，并恢复召回通路。

**路线乙：** 从空状态直接尝试召回火。

- $`R=A=\varnothing`$。
- 召回同样失败，输出与甲的失败输出相同。
- 第一次感知火时，旧的 $`R`$ 没有火，因此报告再认 `false`。

这说明“眼前看见相同的失败报告”不等于“所有内部状态相同”。甲乙下一次反应的差别已有明确来源：保留集合不同。没有凭空生成过去，也没有反驳下一节的同状态定理。

**实现陷阱：** 如果先把火写进 $`R`$ 再判断是否再认，那么所有初见都会被错报为曾见。代码与测试都核查先读旧状态、后写新状态的次序。

## 7. 手算例四：完整擦除后，历史差别没有藏身处

甲先感知火，再 `erase_all`。乙从未感知，保持初态。此时四个字段完全相同：两个空集合、两个空值。

给两者同样的 `perceive(fire)`，它们都报告初见，且到达相同的下一状态。这里的结论只依赖明确的函数条件。

把转移和报告合成一个确定性偏函数 $`F`$：

```math
F(S,u)=(S',o).
```

若 $`S_1=S_2`$ 且 $`u_1=u_2`$，传给同一个函数的两个参数相同，结果当然相同：

```math
F(S_1,u_1)=F(S_2,u_2).
```

本模型有不可用的操作，所以称偏函数。例如对从未保留的内容强行阻断访问会报错；相同状态下，相同动作的有效性也相同，不能一边成功一边失败。对相同的未来动作序列，用归纳法每步重复这条推理即可。

这不是对所有心灵、物理系统或形而上学的无条件定理。若保留 `ever_seen`、读取外部日志、参数不同、未来输入不同，就必须将差别写入完整状态或条件；此时不能再宣称前提全部相同。这个程序不回答人类完整状态是什么，更不决定它是否只由物质组成。

## 8. 为什么全域只有 29 个状态

每个内容有三种存储状态：不在 $`R`$；在 $`R`$ 但不在 $`A`$；在 $`A`$。若恰有 $`k`$ 个内容可访问，注意和输入各可从这 $`k`$ 个内容或空值中选一种。

```math
\sum_{k=0}^{2}\binom{2}{k}2^{2-k}(k+1)^2
=4+16+9=29.
```

这只是教学状态空间的大小，不是“人有 29 种记忆状态”。程序独立枚举合法状态，再从空状态搜索所有可达状态，两者完全相等。

29 个状态乘 9 个动作，共检查 261 对：235 对成功转移，26 对违反 `make_inaccessible` 的前提而被拒绝。拒绝是预期的负例，不是隐藏测试失败。检查器只捕获明确的 `PreconditionError`；其他实现或状态验证错误会暴露出来，不会伪装成合法拒绝。

穷举核查包括：不变量、再认是否读取旧保留集合、召回是否不改变输入、非擦除控制是否保留记录、等状态等动作是否等输出、全部合法状态是否可达。代码用显式条件抛出异常，**在 `python3 -O` 下也不会悄悄取消检查**。

另外的单元测试覆盖未知标签、错误类型、非法状态、多余或缺失字段、重复序列化元素、错误动作参数、命令行冲突、不可访问与从未见过、火与铃的互不混淆。测试通过的含义止于软件实现遵守定义。

## 9. 哪些原信内容刻意没有变成数值

原文还谈到愉快／不快、精神性、抽象观念、德性与智慧、意志、自由以及恶。程序没有把这些概念改写成任意分数，也不声称一个 `true` 就解释了再认的主观体验。

原文说重新遇到曾遗忘的对象会更容易把握，程序只示范再认这一分类差别，没有测量“容易多少”、快多少、成功率多少。模型还排除了虚假再认、错误记忆、幻觉、内容相似性、情绪、时间衰减以及复杂情境；这些都需要新问题、新规则或经验材料。

## 10. 有答案的检查题

1. **保留但未注意与不可主动召回相同吗？** 不同。前者可在 $`A`$ 中但 $`q`$ 为空；后者不在 $`A`$ 中。两者都可能还在 $`R`$。
2. **召回失败能证明完整擦除吗？** 不能。甲乙能给相同失败报告，但完整状态不同。
3. **擦除后留一个“曾见”位有错吗？** 作为另一种部分擦除模型可以；称作全部历史差异被擦除就不可以。
4. **首次输入为什么要先检查旧状态？** 先存后判会把第一次输入也判成熟悉，破坏初见／再认区分。
5. **相同状态但输入不同还能有不同输出吗？** 可以。同状态定理还要求同输入与同一规则。
6. **输出确信标签为空，现实就没有火吗？** 不成立。这里没有外部真值变量，缺少输入依据不等于证明相反事实。
7. **全域检查通过是否反驳了 Euler 的二元论？** 没有。它只检查一组明示的功能规则；体验与心灵本性的争论没有被这些字段解决。
8. **怎么做一个诚实的后续实验？** 先确定要测的心理现象、独立观察数据、操作化定义、替代解释与误差标准；不要先填“记忆强度 0.8”，再把程序算出的 0.8 当成发现。
