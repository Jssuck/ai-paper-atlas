# Euler 第 CIX 信：保留的观念、注意、召回与再认

**这是原创的现代教学反模型，不是历史算法，也不是经验性的认知模拟。** Euler 在这封信里没有给出状态机、数据集、拟合参数或计算步骤。本程序让其中若干区别可以被逐步检查；它不复现历史实验，不测量人类记忆，也不裁决心灵是物质还是非物质。

文献：Leonhard Euler，*Lettres à une princesse d'Allemagne*，第二卷（1768），第 CIX 信，印 144–148 页，信末署 1761 年 3 月 10 日。出版年与书信署日不同。印 144 页上部是 CVIII 的结尾；印 148 页 CIX 署日之后是 CX 的开头，两者均不在本练习范围内。可查看 [1768 扫描起页，PDF 第 165 页](https://archive.org/download/lettresuneprinc01eulegoog/lettresuneprinc01eulegoog.pdf#page=165)、[整卷机构书目](https://scholarlycommons.pacific.edu/euler-works/344/)及[来源说明](SOURCE.md)。程序运行时不读取原书扫描或 OCR。

## 1. 一分钟内运行

要求 Python 3.10 或更新版本，仅用标准库。随附实跑使用 CPython 3.12.14。无需安装依赖、API 密钥、付费服务、网络、GPU 或 Notebook。

在本目录运行：

```sh
python3 run_all.py
```

也可分别运行：

```sh
python3 -m unittest discover -s tests -v
python3 memory_model.py --demo
python3 memory_model.py --check
python3 memory_model.py --demo --output outputs/demo.json
python3 memory_model.py --check --output outputs/exhaustive.json
```

## 2. 哪些来自原信，哪些是另加的

- **印 144–145 页：** Euler 区分已获得的观念、正在发生的感觉，以及对象在外部存在的确信。**本项目另加：** 分开保存内容、注意与当前输入三个角色，并规定当前确信报告跟随输入。
- **印 145–146 页：** 观念不必一直在心灵面前才可被召回；想起火灾不等于相信现在有火灾。**本项目另加：** 召回只改变注意，不创建当前输入。
- **印 146 页：** 几乎遗忘的观念与从未获得的观念在重新遇到对象时可以不同，作者还说前者更容易把握。**本项目另加：** 不可主动访问但仍被保留的内容，在重新呈现时报告再认。程序没有模拟“更容易”的速度、强度或概率。
- **印 146–147 页：** Euler 陈述并批评一种唯物论印痕解释，质疑持久印痕是否要求观念持续呈现，以及完全擦除后如何知道曾有同一印痕。**本项目另加：** 把存储与当前注意分离，再把访问受阻与完整复位分离。反模型针对其中一个必然推论，不对作者整套论证作总裁决。
- **印 144–145、147–148 页：** 愉快／不快、精神实体、判断、抽象、德性、智慧、意志、自由及恶属于更广的论述。**本项目未建模：** 上述所有方面。一个布尔再认报告不等于解释了再认的主观感受。

火对应原信例子。铃是本项目添加的对照内容，用于检查“回忆内容”是否被错误地当成“当前输入”。

## 3. 完整状态：四个不同问题

令有限内容集合为 $`C=\{\mathrm{fire},\mathrm{bell}\}`$，完整状态为 $`S=(R,A,q,s)`$：

- $`R\subseteq C`$：哪些表征仍被保留？
- $`A\subseteq R`$：哪些保留表征现在可主动召回？
- $`q\in A\cup\{\bot\}`$：当前注意哪个内容？
- $`s\in A\cup\{\bot\}`$：当前独立呈现哪个输入？

$`\bot`$ 对应 Python 的 `None`。处于 $`R\setminus A`$ 的表征被保留但不可主动召回。不在 $`R`$ 的内容在这个完整模型状态中就是缺席；机器没有记录这种缺席究竟来自从未接触还是全部擦除。

对 $`q`$ 与 $`s`$ 的限制是教学简化，不是关于人类所有注意或感知内容都可主动召回的普遍主张。本模型每次最多有一个注意内容与一个输入内容。内容标签只标识身份，不含图像细节、语义特征或情景事件。

Python 状态**恰有四个字段**。它没有遇见次数、时间戳、隐藏历史位、随机生成器、外部数据库或保留下来的再认缓存。示例日志属于外部观察者；状态转移函数从不读取它。

## 4. 动作的精确定义

固定动作集合共有九个具体动作：三个带内容的操作各可作用于火或铃，再加三个不带内容的操作。

1. `perceive(x)`：先检查旧状态中是否有 $`x\in R`$，把结果作为本次再认报告；再把 $`x`$ 加入两个集合，并令 $`q=s=x`$。
2. `withdraw`：撤去当前输入，令 $`s=\bot`$；注意可以继续停留于观念。这使“当前想到”与“当前正在感觉”可以分开。
3. `set_aside`：清除注意，令 $`q=\bot`$；不擦除记忆，也不改变当前输入。
4. `recall(x)`：仅当 $`x\in A`$ 时成功。成功令 $`q=x`$，失败保持状态不变；两者均不改变 $`s`$。不可访问与从未保留给出相同的失败报告，没有秘密披露失败原因。
5. `make_inaccessible(x)`：**本项目虚构的教学控制操作**。把 $`x`$ 从 $`A`$ 移去，保留 $`R`$，必要时清除对它的注意。前提是该内容已被保留，且当前没有独立呈现它；必要时先 `withdraw`。这只规定一种形式化的“忘记”，不是人类遗忘机制。
6. `erase_all`：**按定义完整复位**四个字段，包含撤去当前输入。它不是自然发生的遗忘事件；撤去输入是为了避免所谓完整复位后，旧刺激仍留在接口中提供立即重新获得的依据。

每次转移的报告包含注意、当前输入，以及从 $`s`$ 复制的当前存在确信标签。`recognized` 仅在感知动作是布尔值；`recall_succeeded` 仅在召回动作是布尔值。其他动作的这两个字段为 `null`，表示“本步未检查”，不是 `false`。

确信标签只用于表达原文中的来源区别，**不是外部世界真值**，不证明对象真的存在，也不说明没收到输入就证明现实无火。本模型没有外部世界实际状态变量；错觉、幻觉、误识与虚假再认也不在其范围内。

## 5. 七组示例要看什么

### A. 保留不等于持续注意

从空状态感知火，撤去输入，移开注意。末态是 `retained=[fire]`、`recallable=[fire]`、`attention=null`、`sensory=null`。重复 `set_aside` 不改变它。这直接展示：在本模型中，存储不逻辑蕴涵当前注意。

没有时间参数或衰减定律；重复操作不模拟几个月或几年。

### B. 召回火灾不建立当前火灾

从 A 召回火。召回成功，注意变为火，但当前输入及其确信标签仍为空。

另一个正控制是在独立输入火仍持续时召回火：允许存在火的当前依据，但召回没有创建它。更强的负控制是先存火、再感知铃、最后召回火：注意为火，当前输入及其确信标签仍为铃。这能发现将所有注意内容直接复制进“当前存在”字段的错误实现。

### C. 不可访问与从未接触，召回失败相同，再呈现可以不同

路线一：感知火，撤去输入，使火不可访问，尝试召回。失败，注意为空。重新呈现火时，再认为 `true`，因为保留集合仍含火；此次呈现也恢复主动召回通路。

路线二：从空状态尝试召回。失败报告与路线一相同。第一次呈现火时，再认为 `false`，因为旧保留集合没有火。

两条路线会分开，是因为其**完整状态本来不同**。程序没有从无到有制造过去，也不证明人的再认怎样实现。读者能在 JSON 中看见内部状态，但仅凭召回失败报告分不清两种原因。

### D. 完全相同的状态不能区分不同的过去

路线一先感知火再 `erase_all`；路线二保持初态。两者此刻都严格等于 `State()`。

对两者施加同样的 `perceive(fire)`，都得到 `recognized=false` 与相同下一状态。若保留一个 `ever_seen` 位，就可能区别处理，但那时完整状态不相同，擦除也不完整。

这四类问题分别在 JSON 中展开为七条操作序列。

## 6. 什么得到证明，什么只是执行检查

**确定性状态机的形式事实。** 把转移与输出合成偏函数 $`F`$：

```math
F(S,u)=(S',o).
```

若 $`S_1=S_2`$ 且 $`u_1=u_2`$，同一函数收到相同参数。因此两个调用的有效性或前提状态一致；若有定义，结果也相同：

```math
S_1=S_2 \land u_1=u_2
\quad\Longrightarrow\quad
F(S_1,u_1)=F(S_2,u_2).
```

对相同的未来输入序列，用归纳法每步重复：相同当前状态产生相同下一状态与输出。若某个动作无效，两条路线会在同一步同样拒绝它。

**完整**是实质条件。熟悉性标志、不同参数、外部查询、不同输入或随机生成器状态若能影响结果，就必须纳入条件。这个定理不决定人类完整状态是什么、物理描述是否穷尽它、非物质心灵是否存在。它既不反驳二元论，也不证明唯物论。

**穷举软件核查。** 固定小模型有 29 个合法状态和九个动作。程序检查全部 261 个状态／动作组合：235 个成功产生合法状态，26 个因教学控制操作前提不满足而拒绝。从空状态可达全部 29 个合法状态。检查在优化模式 `python3 -O` 下也会运行，不依赖可被关闭的 `assert` 语句。

这些数字是小型形式定义域的覆盖范围，不是人类记忆数据。上面的证明是函数同一性与归纳论证；程序运行检查的是这一实现，没有用有限运行代替一般证明。

## 7. 不变量、严格验证与失败情形

始终要求：

- 记忆成员只能是支持的 `Cue`，记忆集合不可变。
- 可主动召回的内容必被保留。
- 在本模型的简化下，注意与输入为空或属于可召回内容。
- 成功召回不改变输入；失败召回不改变任何状态。
- 再认读取感知前的保留集合，不能先写新内容再假称认出。
- 移开注意和撤去输入都不删除已保留的内容。
- 全部复位得到精确的初始完整状态。

未知标签、错误枚举类型、可变集合、不可能状态、序列化缺字段或多字段、重复记忆元素、没有内容参数的召回，以及给 `erase_all` 传内容参数，都会报错。

阻断未保留或正在呈现的内容会抛出 `PreconditionError`（`ValueError` 的子类），且不改变原状态。穷举检查器只捕获这种预期前提异常；其他验证错误会向外暴露，不会被冒充为合法拒绝。

Python API 示例：

```python
from memory_model import Action, Cue, Kind, State, transition

state, perception = transition(State(), Action(Kind.PERCEIVE, Cue.FIRE))
state, _ = transition(state, Action(Kind.WITHDRAW))
state, _ = transition(state, Action(Kind.SET_ASIDE))
state, recall = transition(state, Action(Kind.RECALL, Cue.FIRE))
print(state.to_dict())
print(recall.to_dict())
```

## 8. 有答案的练习

1. **为何不能先存新感知再判断是否认出？** 那会把每个初次出现的内容都判断为已保留，初见全部误报为熟悉。必须先查看旧状态。
2. **召回失败证明完全擦除吗？** 不证明。缺席与不可访问可给出相同失败报告；重新呈现的差别以保留状态已有差别为条件。
3. **“完整”复位后可以保留 `ever_seen=True` 吗？** 若它影响未来输出，就属于完整状态；留下它把问题改成了部分擦除。
4. **`current_existence_conviction=null` 表示现实无火吗？** 不表示。只是没有当前输入所提供的确信标签，程序没有现实真值变量。
5. **是否解释了 Euler 的愉快／不快或自由意志？** 没有。这些被明确留在范围外，不是被解释掉了。模型只处理有限的保持／注意推论与历史敏感输出的状态条件。
6. **相同完整状态若接到不同输入，可以有不同输出吗？** 可以。定理还要求相同输入与同一转移规则。
7. **经验研究还需要什么？** 独立操作化任务、观察资料、误差模型、竞争假设及对数据的验证。这里都没有；随意添加“记忆强度”数字也不能补足这些条件。
