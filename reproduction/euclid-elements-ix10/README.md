# 《几何原本》IX.10：从单位起步时，平方和立方会出现在哪些位置？

正整数教学重构。单位是位置 1（指数 0），程序返回之后的非单位项。给定底数 $`q\ge 2`$，若 $`q`$ 不是平方，则恰有偶数指数项为平方；若 $`q`$ 不是立方，则恰有指数为 3 的倍数的项为立方。两支的前提相互独立；例如 $`q=8`$ 可走平方支，$`q=4`$ 可走立方支。整数根测试不使用浮点数，字段 `root=0` 表示没有相应的正整数根。

现代算术对照：对于任意次数 $`d\ge2`$，$`q^e`$ 是否为 $`d`$ 次幂取决于 $`q`$ 是否为 $`d/\gcd(d,e)`$ 次幂。不能把 IX.10 对素数次数的结论直接套到合数次数：$`4`$ 不是四次幂，但 $`4^2=2^4`$。
