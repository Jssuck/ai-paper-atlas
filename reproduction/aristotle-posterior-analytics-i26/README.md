## 模型和符号

`all_of(A,B)` 表示所有B是A，即B包含于A；`none_of(A,B)` 表示A、B不交。允许空集，故空主项上二者可同真。函数参数必须是set或frozenset；元素仅作可哈希对象，无现实本质或因果意义。

1. 直接模式：A、B不交，C包含于B，推出A、C不交。取任意C成员即属B，不能属A，不需C非空。
2. 有限类的归谬片段：A、C不交，C包含于B，且C非空，则不是所有B都属A。取C中一个对象，它是B且不是A。这只能保证特称否定，不能推出所有B都不是A。
3. 明确反例：宇宙{0,1}，A={1}，B={0,1}，C={0}。上述背景成立，但A和B有共同成员1。
4. 若C为空，A归于每个C和A不归于任何C可同时成立。把这两个全称句机械标为矛盾，会伪造反证。
5. 要证明全称否定A/C，可反设某w同时属于A和C。C包含于B给出w属于B，和A/B不交冲突。这里假设的是全称否定的矛盾命题（存在交集），不是全称肯定。`witness_trace`只核实际C成员，检查其被固定前提排除于A，不能在实际模型中创造矛盾见证。

原文归谬段省略一些量词；以上是分层教学重构，不能把不合法的全称提升说成原典已被程序证明。正文保留原文和现代补足的区别。

## 固定前提与错误归咎

另一模型固定规则“p且q蕴含r”。q为真、r为假时，每个背景模型都令p假；若只知道r假，则p真而q假的模型仍存在。`None`是未给信息，不是假。若p真、q真、r假同时给定，背景与规则矛盾，程序返回`inconsistent_background`与`not_p_supported: null`，不把空模型集的全称性质当成诊断证据。此处采用经典二值命题语义；不是完备证明搜索器，更不是亚里士多德科学认识论的实现。
