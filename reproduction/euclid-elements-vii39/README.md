# VII.39：同时拥有三种指定单位份

现代整数教学重构，不是古代实跑或一般定理的计算证明。给定三个份数名称 d₁、d₂、d₃，按 VII.36 构造它们的最小公倍数，然后按 VII.37 的方向恢复所需单位份。反向按 VII.38：若较小的整体同时拥有这些份，它也会被三个给定数整除，与最小性冲突。独立测试以精确 Fraction 搜索首个各商均为整数的整体。

(4,6,10) 的最小整体为 60，三个份分别为 15、10、6。它们不构成一个共同分割，总和只有 31。30 能给六分之一和十分之一，却缺整数四分之一；积 240 也拥有三种份，但不是最小整体。

程序默认所有分母大于 1，现代开关允许分母 1。重复和整除嵌套由有限模型单独检查，所算得的份可为单位；不将此类现代单位边界强加于原文的「数」。
