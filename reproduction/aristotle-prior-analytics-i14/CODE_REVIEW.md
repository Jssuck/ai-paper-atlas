# I.14 独立代码核验

## 核验对象与方法

本审查逐函数检查 `model.py`、`test_model.py` 与 `demo.py`，并用独立集合算法对照位掩码实现。审查不是把作者测试再运行一遍便认定正确：独立脚本不调用作者的语义函数来计算期望值，而将世界解码为 Python 集合，分别求并、交及差集，再逐对象求量词值。

形式证书层与世界语义层必须分开：`verify` 证明证书遵守声明的四条基本规则及质量互换，而不证明这些规则在任意世界模型中有效。`derive` 返回 `None` 是生成器范围的限制，不是语义无效性的证明。语义层将 a/e、i/o 分别赋相同真值，是明示的双向偶然教学定义，不能据此抹去语法标签。

## 逐项结果

- 谓项在前、主项在后；第一格中项匹配和三个项互异均受检查。16 种输入形态独立对照硬编码的期望表，8 种产生规定证书，8 种不产生。
- 质量互换保留项位；基规则严格区分全称与特称结论。证书拒绝额外前提、未来引用、布尔引用以及结尾不是原端项的合法中间式。
- 世界、论域和实际索引要求非空／合法整数，位掩码拒绝域外对象；布尔值不被误作整数索引。主项允许为空，因而全称空真、特称假，这是公开定义而非软件缺陷。
- 逐对象偶然集合是“至少出现一次”减去“每次出现”；广义可能集合包括恒真对象。实际索引只决定主项，不改变各世界求出的偶然集合。
- 非空反模型确实满足两个 aa 前提而不满足结论；这准确显示现代解释与声明规则不自动吻合，而不是否定所有古代解释。
- 数量反模型中，大前提见证与小前提见证为不同对象；两模型端项恒真／恒假的区别保留，均不支持双向偶然端项结论。
- 范围桥接独立检查不仅取 T=可能B，还遍历所有包含可能B的 T。仅在 T 中所有对象对 A 偶然、相应小前提也成立时计入检查，未把无条件传递混入结论。

## 独立有限枚举

[独立检查器](code-review/check.py)使用显式异常，不使用可被优化删除的 `assert`。输入为(论域大小,世界数)=(1,1)、(1,2)、(1,3)、(2,1)、(2,2)，每个模型分别遍历所有实际世界索引。共检查 **9,928 个模型/实际索引配置、436,416 个量词值、5,078 个满足前提的范围桥接蕴涵、16 个形式输入、32 个拒绝证书**。模型重复世界允许保留；没有同构去重，不代表穷尽所有有限模型。

普通、`-O`、`-OO` 三种运行均通过，结果分别保存为 [普通](code-review/run-normal.json)、[-O](code-review/run-O.json)、[-OO](code-review/run-OO.json)。一般证明仍须看正文；这些数字是执行覆盖而不是无限定理证明。

## 变异检查和修正

[变异脚本](code-review/mutations.py)选择八项局部实现错误，使用作者的单元测试检测。初次结果见 [初次真实记录](code-review/mutations-initial.json)：八项中只有六项被测试检出。初版测试保存在 [修正前测试快照](code-review/test_model-before-coverage-fix.txt)，其SHA-256与初次报告相符，便于核对覆盖修正。两项幸存变异是删除最终端项检查、允许布尔引用；原实现本身已拒绝这些输入，问题是回归测试没有把正确行为锁定。尤其原测试使用 `(True,1)`，会因项位错而失败，即使类型检查坏了也看不出来；需要 `(False,1)` 才能隔离布尔值冒充合法索引0的问题。

审查要求并回验补入最终端项、额外前提、quality未来引用三项测试，以及用 `(False,1)` 隔离类型限制。最终单元测试为 **29 个方法，普通/-O/-OO 三种模式均通过**。独立复跑日志见 [普通](code-review/tests-normal.txt)、[-O](code-review/tests-O.txt)、[-OO](code-review/tests-OO.txt)，演示同样逐模式复跑且输出一致。[最终变异记录](code-review/mutations-final.json)显示 **八项均被检出**，此前的六项检测也仍保持。审查摘要见 [sha256.json](code-review/sha256.json)。八个选定变异全部被检出也不等于测试完备，更不意味着不存在其他程序缺陷。

## 复跑

从本附件目录运行：

```sh
python3 code-review/check.py
python3 -O code-review/check.py
python3 -OO code-review/check.py
python3 code-review/mutations.py
```

`mutations.py` 仅在临时目录复制自有程序与测试，分别注入一个选定变更；不修改正式实现。所有实现、单元测试、独立脚本和相关说明的审查版本由摘要绑定；修改后不得沿用旧摘要冒充复审。
