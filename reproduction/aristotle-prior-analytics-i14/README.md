# I.14：规则证书与模态语义不能混为一谈

这是[正文](../../papers/ancient/aristotle-prior-analytics-i14.zh-CN.md)的原创教学最小实现，使用 Python 标准库；不是 Aristotle 古代系统的完整复现，也不是完整现代模态逻辑判定器。作者实际目验 Owen 1853 印刷页 110–112 全章及例块后制作。历史定位、原文与版本问题见正文和来源账本。

## 两个有意分开的层次

### 1. 声明规则、生成并检查推导证书

`Proposition(mode,predicate,subject)` 使用**谓项在前、主项在后**顺序。`mode` 为 `a/e/i/o`，记录双向偶然的全称肯定、全称否定、特称肯定、特称否定形式。字母只是历史规则的现代符号标签，绝不默认为实然 A/E/I/O。

`derive(major,minor)` 要求第一格：大前提 `Q(A,B)`，小前提 `Q(B,C)`，三项互异。四个声明的基本规则为 `aa→a`、`ea→e`、`ai→i`、`ei→o`。小前提为 `e/o` 时，先按 I.13 许可的质量互换改为 `a/i`，**不交换主谓项**，再应用基本规则。生成证书逐步列出前提、质量互换和基本规则；两前提各有四式，共 16 种输入，8 种生成证书，8 种大前提特称输入返回 `None`。程序未编码不定命题，也未证明整个历史体系的完备性。

`verify` 检查证书中的前提身份、早于当前步的引用、质量互换、第一格项位和四条基本规则；可验证在结论后继续质量互换的证书。它验证**相对于声明规则的推导是否合法**，不证明这些规则在任意现代可能世界上保真。`None` 也只表示此生成器不给该形态生成证书，不是由程序证明了语义无效。正文另给无效性的论证。

### 2. 独立的现代有限世界解释

`Model(n,worlds,actual=0)` 的固定非空论域为整数 `0…n−1`；世界非空，每个世界依次保存 A、B、C 的集合位掩码。第 x 位为 1 表示该对象具有属性。实际世界索引可改变；世界可重复，不需给世界赋概率。

对象对 P 双向偶然，定义为至少一世界有 P 且至少一世界无 P。`contingent_set(P)` 得到这些对象；`possible_set(P)` 是各世界 P 集合的并集，**包括恒真对象**，不能与偶然集合混淆。全称模式 a/e 检查实际主项集合包含于偶然集合；特称 i/o 检查两集合交非空。因此两种质量在此特定语义中值相等，语法却保留不同标签。空主项全称空真、特称假；一个世界没有双向偶然对象。

`nonempty_countermodel()` 返回两个世界、两个对象的完整反模型：实际 A={乙}, B={乙}, C={甲}；另一世界 A=空、B={甲}、C={甲}。两项全称偶然前提真而结论假，且实际三项均非空。这否定无条件把声明的 aa 规则当成本现代解释下的传递定理，**不是对 Aristotle 全部解释的反证**。

`quantity_countermodels()` 返回特称大前提的两个教学模型：共同 B0={甲,乙}、B1=空，C0=C1={乙}。正模型 A0={甲,乙}、A1={乙}；负模型 A0={甲}、A1=空。甲见证大前提特称偶然，乙见证小前提偶然；端项乙却分别恒为 A、恒非 A。两模型支持相同的特称大前提与全称/特称小前提，端项四种双向偶然句均假，实然与必然肯否则相反。这不是原文动物/白/人/衣服的逐字编码。

另外检查正文所证明的**加强主项范围**桥接：若所有可能为 B 的对象对 A 偶然，且实际 C 中每个/某个对象对 B 偶然，则实际 C 中每个/某个对象对 A 偶然。改变范围是增加条件，不是暗中修复原历史规则。

## 执行与证据

在本目录执行：

```sh
python3 -m unittest -v test_model
python3 demo.py
python3 -O -m unittest -v test_model
python3 -O demo.py
python3 -OO -m unittest -v test_model
python3 -OO demo.py
```

真实环境见 [environment.json](environment.json)，无安装依赖。测试分别见 [普通](logs/tests-normal.txt)、[-O](logs/tests-O.txt)、[-OO](logs/tests-OO.txt)；演示分别见 [普通](logs/demo-normal.json)、[-O](logs/demo-O.json)、[-OO](logs/demo-OO.json)。测试使用 `unittest` 断言，模型与演示中的错误检测不依赖可被优化删除的 `assert`。

三个模式均有 **29 个测试方法**通过；包含全部 16 个输入形态、量词伪造、换项伪造、引用错误（含布尔伪索引）、末尾目标错误、额外前提、非法参数、空项、单世界、非空反模型、数量反模型及范围桥接。有限枚举固定两个世界和实际索引 0，论域大小取 1 与 2，覆盖 **4160 个标号模型**：原实际主项 aa 前提成立 1332 次，其中结论失败 276 次；要求实际 A/B/C 全非空后为 302 次成立、72 次失败。桥接全称前提与小前提同时成立时检查 812 次，特称检查 584 次，未见失败。不是对同构模型去重后的计数，不是随机试验，也不代表全部有限或无限模型。

这些数字只说明这份实现的列明输入执行结果；一般桥接证明在正文，声明规则的历史依据在来源账本。有限通过不能证明一般数学定理，更不证明程序毫无缺陷。独立代码审查与复跑证据见 [CODE_REVIEW.md](CODE_REVIEW.md)；数学及正文证据另见[独立论证核验](../../papers/ancient/aristotle-prior-analytics-i14.audit.zh-CN.md)。
