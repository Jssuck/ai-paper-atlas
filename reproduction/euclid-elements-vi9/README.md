# 《几何原本》VI.9：从给定线段截取规定的一份

对应[中文深读](../../papers/ancient/euclid-elements-vi9.zh-CN.md)。以下是现代有理坐标模型；并非原典全文、完整尺规仿真或一般定理的形式证明。

## 复现步骤

从 A 出发在非共线辅助射线上重复取步长，把终点 C 连到 B，再过所选标记 D 作平行于 CB 的直线。源码通过行列式解平行线和底边的交点 F，不把目标分数直接代入构造；测试另用直接插值作为坐标预期。独立几何校验计算平行判据和 CD:DA、BF:FA。原文示范三分之一；多取等步得到 1/n，改选第 m 步得到 m/n，都在此明确标成教学推广。

- 正例：A=(0,0)，B=(12,0)，D=(1,3)，E=(2,6)，C=(3,9)。得到 F=(4,0)，两个余段比均为 2。
- 反例：改取 F=(5,0)，虽然仍在线段内部，余段比却为 7/5，且向量 DF 与 CB 的行列式为 −9。
- 等步边界：若 C 改为 (4,12)，仍过 D 作真正平行线，交于 (3,0)，截得四分之一而非三分之一。两边余段比仍相同，错误是没有按原定三等步选 C。

## 环境、命令与实跑

Python 标准库，无须第三方依赖；从本目录运行：

```sh
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B replay_notebook.py
```

[普通](normal.log)、[-O](O.log)、[-OO](OO.log) 每种模式各通过 8 项测试。每次扫描 1008 个构形：两个原点、三个底边方向、六个辅助步向量与 28 组整数索引，底边两侧各 504 个；另检查竖直底边、退化输入与端点排除。输入限定为精确有理坐标、非平行的非零辅助步及 0＜m＜n 的整数索引。

[Notebook](euclid-vi9.ipynb) 的 3 个代码格用标准库依次编译并执行，见[回放日志](notebook-replay.log)。这不是 Jupyter 内核运行；文件保持未执行状态供读者直接重跑。有限测试只检查相应构造与边界。
