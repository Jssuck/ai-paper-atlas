## 语义约定

固定非空有限对象域U，非空情形序列W，其第0项是实际情形。每个情形存(A,B,C)三个外延位掩码；位i为1表示对象i属于该项。对象身份跨情形保持，项的外延允许变化。`holds(mode, quantity, predicate, subject)`以谓项在前、主项在后输入。

- a/e/i/o分别是全称肯定/全称否定/特称肯定/特称否定。
- D：在实际主项S0内，按实际情形谓项P0判断。
- P：仍量化实际主项S0，每对象分别至少在一个情形满足所需肯定或否定。不是要求所有对象在同一情形满足。
- N：仍量化实际主项S0，每对象在所有情形满足所需肯定或否定。
- C：实际主项中的对象，对谓项既有属于情形也有不属于情形；a与e相等，i与o相等。不是把e定义成a的外层否定。
- BOX：每个情形重新取该情形主项并求实然命题，再要求所有情形成立。一般不同于N。

空实际主项使全称命题真、特称命题假。原典的存在负担不能由程序的空真自动消除。输入拒绝布尔数伪装整数、越界位、空情形序列、非法项/模态/量词。程序不限制有效输入的最大维度；大维度枚举会指数增长，本次只用下列小范围。

## 一般论证和代码所核查的东西

实际C包含于实际B，且对象x在实际C内对A双向偶然，则x也在实际B内且仍对A双向偶然。改变主项范围不改变对象的模态属性，故C_i(A,C)能迁移成C_i(A,B)。同样，P_o(A,C)能够迁移成P_o(A,B)。这两条由任取见证的集合论证成立，并非由枚举次数得证。

反证路线：若否认P_o(A,B)，则所有实际B对象在所有情形都是A，即N_a(A,B)。实际C⊆B随即给N_a(A,C)，与P_o(A,C)矛盾。这里精确得到弱可能否定P_o；没有仅凭“非必要肯定”升级成双向偶然C_o。

只给实际A包含C、B对C偶然，不会保证现在的B对象与C有交集。代码保留其反模型；不因原典使用换位规则便暗自将当前B改成某个可能B。实然否定路线还可能需要背景随情形保持，程序不会无声添加此条件。

## 八个显式配置

所有三元组都是位掩码(A,B,C)，对象0对应1、对象1对应2、{0,1}对应3。

|配置名|两个情形|用途|
|---|---|---|
|witness_transfer_success|(1,3,1);(2,3,1)|同一对象0从实际C迁移到实际B，C_i结论真|
|affirmative_actual_subject_failure|(1,2,1);(1,3,1)|D_a(A,C)与C_a(B,C)真，P_i(A,B)假；实际三项均非空|
|negative_background_failure|(2,2,1);(2,3,1)|D_e(A,C)与C_a(B,C)真，P_o(A,B)假；实际三项均非空|
|weak_not_strong|(2,3,1);(2,3,1)|P_o(A,C)真，C_o(A,C)假；对象0永不属于A|
|different_particular_witnesses|(1,1,3);(1,3,3)|D_i(A,C)见证0；C_i(B,C)见证1；C_i(A,B)假|
|contingent_conclusion_not_actual|(2,1,1);(3,1,1)|C_i(A,B)真，D_i(A,B)假|
|empty_middle|(1,1,0);(1,0,0)|U仅对象0；C全称空真但不能制造特称见证|
|worldwise_not_anchored_necessity|(1,1,1);(0,0,1)|U仅对象0；BOX_a(A,B)真而N_a(A,B)假|

前六例U={0,1}。最后两例U={0}。这些是自行设计的数值例，不冒充古代文本原例。

## 本次真实结果

正常、-O、-OO每种模式：16项单元测试通过；枚举4744配置。范围为(n,世界数)=(1,1),(1,2),(1,3),(2,1),(2,2)，分别8、64、512、64、4096个。五项规则检查无失败；成立前提计数依次为C见证迁移808、P否定迁移1144、N肯定迁移780、C_o⇒P_o 2000、P_o与非N_a对偶4744。

在实际三项均非空的子集，肯定实际主项失败32个、否定背景失败32个、双特称结论失败354个。计数不是概率或历史统计。三种模式JSON逐字语义相同；不是三个独立实现。
