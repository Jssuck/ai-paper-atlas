# II.9：不能用无根循环替代起点

本附件对应《后分析篇》II.9，93b21–28。它不是古代算术的复原，也不验证某个定义是否真正表达本质。它只核验两种现代教学关系：给定起点如何支持有限推导，以及同外延定义约束为什么不自动带来存在见证。

## 2. 形式对象与接口

有限命题集合V，本实验取a、b、c。基底F是V的子集。每条规则由非空前提集合B和结论h组成，解释为：B中所有命题都真时，h也真。它允许合取前提；禁止空前提规则，避免把隐藏事实伪装成规则。

- `derive(atoms, base, rules)`返回闭包及有序`(规则下标, 结论)`证书。
- `check_certificate(...)`只从基底开始，逐步确认规则前提已经可用，且结论、下标正确。它不验证基底的现实真实性，也不判定因果方向、本质或科学知识。
- `semantic_consequences(...)`枚举所有满足基底及规则的真值赋值，取交集，作为独立oracle。
- `definition_case(domain, unit, description)`分别报告两个谓词是否同外延、单位谓词是否非空、说明谓词是否非空。“unit”只是标签，不把算术单位等同于集合论对象。

## 3. 一般证明，不依赖枚举

**终止。** 推导只增加V中的新命题，每增加一个命题记录一步。因此最多增加|V−F|个命题，最终停止。程序可能多次扫描规则，但不会无限增加命题。

**可靠性。** 对证书长度归纳。起始F中的每个命题在所有满足基底的赋值中为真。若某规则的所有前提都已在该赋值中为真，由规则语义，其结论也真。故全部推导结果都是语义后果。

**完备性，限此有限正Horn片段。** 停止后的集合C包含F，且对全部规则封闭。因此把C中命题置真、其余置假，就是满足基底和规则的一个赋值。若q不属于C，这个赋值使q假，所以q不是语义后果。结合可靠性，闭包恰等于所有模型的交集。这里没有否定、任意一阶量词或科学因果关系，不应推广到任意推理系统。

**无根循环。** 由于所有规则前提非空，F为空时没有任何首条规则可以触发，闭包为空。a推出b、b推出a并不产生a。若加入F={a}，循环可产生b，但其结果对a的依赖仍然存在。

**定义不蕴涵存在。** 固定非空论域{0}，令两个谓词U和D都为空。所有对象上U与D等值，却没有U见证。另令二者都为{0}，定义约束仍真且有见证。故同外延条件本身不决定存在。反过来，在论域{0,1}中令U={0}、D={1}，二者均有见证却不同外延，故存在也不决定该定义约束。

这些证明是现代形式系统中的结论；不能据此宣称古代“直接本质”的真实性已由程序证明。

## 4. 手算例子与实验口径

**链。** F={a}，规则a→b、b→c。证书依次为(0,b)、(1,c)。把顺序倒过来会在第一步缺少b，被拒绝；把规则列表倒序则算法仍会通过多轮扫描找到合法证书。

**有边不等于有根据。** F为空，a→b、b→a：闭包空。F={a}时闭包{a,b}。空证书可以“接受”基底a，仅表示a被假定，不表示不靠假定证明了a。

**库内不可推出不等于绝对直接。** 库R为空，F={a}；程序不能从空基底推出a。给新语言加入d和规则d→a，并假定d，就可能推出a。相对一个规则库的失败不能证明自然中绝无其他原因；本实验没有寻找或认证这样的原因。

三命题每个结论允许其他两个命题的三个非空子集为前提，所以共有9条候选规则。每条可选或不选，得512套规则；8种基底，共4096套“基底+规则”实例。每套最多检查8个真值赋值。每个可推出目标都核验证书。

外延实验n=0至4，每个论域的两谓词有4^n对，总341对；相同外延有Σ2^n=31对，其中5对两者为空、26对非空。n=0仅是程序边界测试；否定“定义蕴涵存在”的关键反例使用n=1的非空论域，因此不依赖允许空论域的逻辑争议。

真实结果见`logs/experiments.json`：4096实例oracle差异0，无基底非空闭包0，无效生成证书0。三种优化模式各26项测试通过，Notebook4单元真实运行。计数不是科学知识样本量，不给出一般哲学结论的统计置信度。

## 5. 与原文的联系和界限

II.9区别另有原因的对象与直接起点，并以算术单位说明“是什么”及“存在”都需要承担。现代程序把承担放入显式基底，能防止把循环或标签当成新的证明。它不能决定哪些承担合理；更不能把“程序无规则”解释成亚里士多德所谓无另一原因。

原文允许假定或用另一方式使起点显明。本实验只演示“假定后能推出什么”，不实现另一认识方式，也不模拟II.19。另有原因者“通过证明显明本质”与“把本质作为证明结论”不同；本实验没有自动识别两者，因而输出字段不使用“本质已证明”。

## 6. 练习与答案

1. 无基底a→b、b→a能得出b吗？不能，没有第一步。
2. 加入a后，b是否无条件为真？不是，只是在当前基底和规则下为后果。
3. 规则a且b→c，只有a能推出c吗？不能，合取前提须全部满足。
4. 证书先写b→c再写a→b为何拒绝？首步b尚不可用。
5. 为什么闭包本身可作完备性证明的反模型？它包含基底且对全部规则封闭，而缺失目标被赋假。
6. 同外延而无存在的非空论域反例是什么？论域{0}、U=D=空集。
7. 两个谓词都有见证就同外延吗？不；{0}与{1}反例。
8. 程序把a列为基底能证明a是自然界直接原理吗？不能，分类由调用者提供且相对语言、规则。
9. 空前提规则为何禁止？若允许，它实质引入无条件事实，须另外标明承担，不能拿来反驳无根结论。
10. 4096次一致能替代一般完备性证明吗？不能；上面的归纳与闭包反模型证明才覆盖所声明片段。
