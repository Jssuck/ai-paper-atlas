# VII.25 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.25.html)、Heath 1908 卷 II 印刷页 326–327（扫描物理页 339–340，图在 326，最后两步在 327）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=214) 印刷页 214–215（图在 215）以及 [Joyce VII.25](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII25.html)。

希文 Α、Β、Γ、Δ 对应英文 A、B、C、D。原证先设 A 与 B 互素、C 为 A 自乘的积，再另外取 D 等于 A。于是 D 与 B 互素，A 也与 B 互素。这里“各自与 B 互素”不能读成“A 与 D 互素”：例如 A=D=4、B=9 满足两条所需的互素关系，但 A、D 的公因数包括 4。D 是等值副本，不是新因数，也不依赖图上两段看起来是否等长。

由 [VII.24](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII24.html)，D 乘 A 的积与 B 互素；再用 D=A 将此积认回 C。换成现代写法，即若 A 与 B 互素，则 A² 与 B 互素。古证明没有使用素因数分解、不先诉诸乘法交换，也没有单独证明所有幂次或更一般的两个幂互素。不同的幂次或不同组的乘积须另外论证。

Clay 英栏止于 D 乘 A 的积为 C，没有再明写 C 与 B 互素；希文、Heath、Fitzpatrick 和 Joyce 均保留最后结论。Fitzpatrick 第 215 页英栏在“乘”的词形处有拼写疏漏，不影响其 VII.24 的交叉引文，也不改变原证明中的乘法次序。

[VII.27](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII27.html) 直接援用本命题判定一方的平方与另一方互素，再得到两个平方互素；其后用 VII.26 处理两个立方。[IX.15](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX15.html) 也直接调用本命题：先用 VII.24 得辅助乘积与 EF 互素，再把 EF 换成其平方而保持互素。

所核 Heath 扫描卷前与命题页、Fitzpatrick 命题页及两个在线文本未见针对 VII.25 的正式勘误；并非所有印次的校勘。Heath 印 327 页另解释题句的希文省略“与自身相乘”，而正文的构造足以确定是平方。
