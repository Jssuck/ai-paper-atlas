# VII.25：平方保持对另一数的互素性

现代正整数教学重构，不是历史实跑或一般命题的计算证明。给定互素的 A、B，显式取 D=A。VII.24 的两个因数槽分别填 A、D，二者各自与 B 互素，所以乘积与 B 互素；乘积恰为 A 的平方。论证不要求 A 与 D 互素。程序调用单独的乘积引理检查器，并用重复加法算出乘积；有限测试用直接乘法和公因数枚举核对。
