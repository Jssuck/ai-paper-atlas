# VIII.4：把指定比接成最小整数链

现代正整数教学重构，不是古代运行记录或一般定理的计算证明。每个输入有序对指定相邻的前项与后项之比。先约分成最小比对；将旧链末项与新增比对首项的最小公倍数当作公共值，提高两侧必要倍数后连接，公共项只保留一次。每一步记录公共值、两边的倍数与新前缀。

(2:3,5:7,3:4) 的前缀从 (2,3) 放大到 (10,15,21)，最后公共值仍为 21，不需再次放大，结果 (10,15,21,28)。把最后一比改为 4:5，就需要让 21 与 4 在 84 对齐，得到 (40,60,84,105)。链 (6,10,15) 虽是 3:5、2:3 的最小表示，端点仍有公度 3；两步并非同一比，不能套用 VIII.3。默认要求给定比与约分后的数均大于 1；现代开关允许单位和相等比。

独立搜索累乘各个精确后项/前项的 Fraction，从首项 1 起上探。把所有原前项相乘得到的上界一定可行，因为每个前缀比的分母整除这个乘积。测试比较最终链以及施工过程中的每个新前缀。
