# Euclid《几何原本》I.11：在线上给定点立垂线

原创、低成本、精确教学复现。**不是古代算法、物理尺规模拟器或形式化定理证明；有限测试不能证明一般定理。** 仅用 Python 标准库，未安装依赖，不访问网络。

## 古代证明与现代检验分层

[I.11 原文与 Joyce 导读](https://mathcs.clarku.edu/~djoyce/elements/bookI/propI11.html)的构造在 C 两侧取等长 CD、CE，在 DE 上作等边三角形 DFE，连接 CF。DC=EC，CF 共边，DF=EF，以 I.8 得 ∠DCF=∠ECF；它们是直线上的相邻角，按定义10均为直角。等距截取关联 I.3，等边辅助调用 I.1。

本程序用现代坐标实现见证，另重算上述几何前提与点积结论；点积不是古代原文的操作或证明。程序对圆交点存在性、序关系及 I.8 没有给出证明助理式形式证明。

## 输入契约与延长

`construct(A,B,C,h,branch)` 要求：

- A、B 是不同的有理坐标点；C 在闭线段 AB（含端点）。
- h 是严格正的 `int` 或 `Fraction`，代表 **CD/AB**，不是绝对长度。浮点、布尔、字符串、无理输入均拒绝。
- `branch` 仅为整数 +1 或 −1。

D=C−h(B−A)，E=C+h(B−A)。本程序在 AB 的支撑线上允许延长；C 为端点或 h 太大时，D/E 可能在原线段外，`extension_report` 明示其参数及是否越界。

因此，程序并未声称原文内点图式无需说明便能在端点执行。对于内点参数 t，若要 D、E 均在原 AB 内，应选 h≤min(t,1−t)；若要两者严格在内，则需严格小于。端点不可能同时满足 h>0 与这个限制。闭线段之外的 C 虽然在现代支撑线上同样可立垂线，但此 API 有意拒绝，不扩张输入范围。

## 精确坐标模型

令 v=B−A，R(v)=(-v_y,v_x)。等边辅助公式由 DE 的两圆交点坐标模型给出：

```text
D=C−hv，E=C+hv
F±=(D+E)/2 ± (sqrt(3)/2)R(E−D)
  =C ± sqrt(3)hR(v)
```

`Q3` 以两个 `Fraction` 表示 a+b√3；四则运算、符号判定和所有几何判断均精确，无浮点容差。原始有理输入限制是机器表示范围，并不是古代命题仅对有理数成立。

对任意有效输入，现代代数可核：CD²=CE²=h²(v·v)，DF²=EF²=DE²=4h²(v·v)，CF²=3h²(v·v)>0，且 v·CF=0。此处一般代数推导与以下有限实跑是不同证据。两支 CF 向量互为相反数，故是两条相反射线、同一支撑直线；改变 h>0 只改变正比例。一般唯一性还需在现代模型中论证二维非零 v 的正交子空间为一维，不能只凭两支测试断言。

## 证书不是结论开关

`Certificate` 仅保存 branch、D、E、F。`check_certificate` 接收外部可信 A、B、C、h，重算输入绑定、截距参数、共线、非零反向射线、CD=CE、等边三角形、分支、CF 正长、两三角形非退化、DF=EF、I.8 SSS 前提、等邻角、定义10构形及现代垂直条件。

现代等角检查用有符号余弦比较，保留点积符号；只比较平方可能混淆补角。即使直接选取一个垂直点满足最后结论，若不是此次等边辅助构造也应拒绝。证书是几何一致性证据，不是签名或形式证明。

反例：C=(2,0)，D=(1,0)，E=(4,0)。DE 的等边顶点 F=(5/2,3√3/2)，但 CF 横分量 1/2≠0，所以 CF 不垂直水平线。等边辅助不能补救 CD≠CE。另有 E=D 的例子，CD=CE 却失去反向邻角；距离等式本身不足。

## 实跑与复现

本目录运行：

```sh
python3 run_all.py
```

普通、`-O`、`-OO` 三模式各执行 **28 项 unittest**、**864 份正例证书及 12 份负例证书**，模式间结果逐字一致。正例是 3 原点×6 非零有理方向×3 尺度×4 个 C 位置×2 截距×2 分支，包含 0 和 1 两端点、内点、`10^±80` 缩放。这不是不同相似类的枚举，更非所有输入。

单测另覆盖 `10^±200` 尺度、`10^150` 平移上叠加 `10^-150` 位移、字段和输入重绑定、非法类型、退化、两支同线、端点交换、160 步 Pell 近抵消符号判定。所有门禁为异常或 unittest，不依赖优化后消失的裸 assert。

具名例子：

- A=(0,0)，B=(6,0)，C=(3,0)，h=1/6：D=(2,0)，E=(4,0)，F±=(3,±√3)。
- 同一 AB，C=A：D=(-1,0)，E=(1,0)，F±=(0,±√3)，必须延长。
- A=(-2,1)，B=(4,9)，C=(1,5)，h=1/2：F+=(1−4√3,5+3√3)，另一支符号相反。

`results-*.json` 保存这些真实输出、拒绝原因和全部正例记录摘要；`logs/` 是真实 stdout/stderr 与退出码；`run-summary.json` 给出真实命令、时间和退出码；`environment.json` 是环境记录。源码继承本项目 I.10 的原创 Q3/向量辅助与标准库 Notebook 执行框架；I.11 构造、证书、案例、测试和教程为本次改写。
