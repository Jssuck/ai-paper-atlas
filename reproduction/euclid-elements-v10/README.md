## 如何读输出

1. 共同后项的输入主张是 A:C 的比大于 B:C；共同前项的输入主张是 C:B 的比大于 C:A。无论哪支，m 作用于前项，n 作用于后项。给定正整数 m、n，只当第一组整倍量严格超越、第二组不超越时，才返回证明所需的两对实测数值及结论 A>B（亦即 B<A）。程序不在返回前直接比原始 A 与 B。
2. 两个测试不等式可以接成一条严格尺度不等式；前者得到 mA>mB，后者得到 nA>nB。消去共同的正整数倍即得结论。这是现代教学短证。欧几里得原证依次排除等量和反向大小，依赖 V.7、V.8；两种写法都没有把比例预设成可直接运算的商。
3. (A,B,C)=(3,2,2) 的共同后项见证 (1,1) 得 (3>2, 2=2)。不能原样把该见证用于共同前项，此时新的第一比较变为等量；该方向另用 (3,2)，得 (6>4, 6=6)。在真正夹逼例 (7,4,4) 中，(2,3) 与交换后的 (3,2) 分别构成两方向的严格见证。
4. (102,101,100) 的两个方向在倍数组合均不超过 20 时找不到见证；上界 52 时分别找到 (51,52) 与 (51,50)。此处搜索的是 V.Def.7 较大比的定向见证，不是 V.Def.5 的任意符号不一致。验证不成立或搜索找不到时只返回 None，不声明相等，也不声明逆向结论。
5. 三种解释器模式各通过 10 项测试。网格由 11 种正有理量、16 对整数及两种方向叠合而成，共检查 42,592 次给定见证，接受 6,008 次，逐个核对原始量确实符合结论。另检验了不严格的第二比较、严格的第一比较、类型一致及正值整数条件。有限网格检查实现，不证明一般定理。
