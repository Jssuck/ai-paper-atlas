# 重复记忆、覆盖与全称断言：II.19 教学复现

性质：原创现代有限模型，配合[中文深读](../../papers/ancient/aristotle-posterior-analytics-ii19.zh-CN.md)。原文位置为 Aristotle《后分析篇》II.19，99b15–100b17；[希英转录定位](https://aristotle.johnhboyer.com/APo/book/2/#ch-2-19)。这里不模拟古代心灵，不认证 nous，不声称亚里士多德使用了相容解释集合或二值函数枚举。它也不证明或反驳他的完整归纳学说。

## 1. 模型假设与接口

- U 是已知、固定的有限对象域；每个对象有唯一非空字符串标识。
- 观察是 `(对象标识, bool标签)` 列表；假定标签准确，输入一致。同一对象可重复出现，冲突标签及域外对象报错。
- 每个对象只有真/假两种标签。候选解释是 U 上的全部二值函数，不加入其他背景约束。
- 没观察到不等于假。记录顺序不改变相容性，但重复事件仍计入观察总次数。
- `analyse(domain, observations)` 输出观察次数、唯一覆盖数、未见数、相容解释数、全称为真/假的相容解释数及状态。
- `compatible_explanations(...)` 显式枚举小域的全部相容解释，成本随域大小指数增长；计数接口不必枚举。
- `group_memories(..., classes)` 按外部给定分类统计记忆次数与不同对象，不能发现类别或本质。类别名必须对全部域对象给定且不多不少。

状态 `underdetermined` 表示相容解释对全称真假存在分歧；`refuted` 表示已经观察到准确负例；`certified_finite_domain` 表示在这个固定、完整、准确模型中全称成立。最后一种状态不是现实科学原理认证。

## 2. 一般推导与手算

设域大小为 n，已观察的不同对象数为 k，未观察数 m=n−k。每个已观察对象的标签被约束，每个未观察对象可独立取真或假；逐一选择这些 m 位，得到与全部相容解释一一对应的二值序列，因此共有 2^m 种相容解释。这里“独立”说的是组合选择没有附加约束，不是概率独立。

若没有负例，则恰有一种相容解释把所有未观察对象也设为真，其余 2^m−1 种至少包含一个假。因此当 m>0 时，全称不能由该记录单独决定；当 m=0 时，唯一解释全真。若已有负例，全称为真的相容解释为0，全称为假的相容解释为2^m。

重复同一准确记录不添加新约束，所以不会减少相容解释集合。形式上，重复前后每个候选解释需要满足的是同一组对象标签等式；一个等式列两次与列一次具有相同满足条件。观察次数增加不改变这一点。

取 U={a,b,c}：

| 记录 | 观察次数 | 覆盖数 | 相容数 | 全称真/假解释数 | 结果 |
|---|---:|---:|---:|---:|---|
| 无记录 | 0 | 0 | 8 | 1 / 7 | 未定 |
| a真重复100次 | 100 | 1 | 4 | 1 / 3 | 未定 |
| a真、b真 | 2 | 2 | 2 | 1 / 1 | 未定 |
| a真、b真、c真 | 3 | 3 | 1 | 1 / 0 | 有限域证书 |
| a真、b假 | 2 | 2 | 2 | 0 / 2 | 全称被反驳 |

反例用更小的 U={a,b}：仅见a真，解释一令b真，解释二令b假；二者对已见记录完全相同，对全称命题却相反。该构造只证明无附加背景约束的有限模型欠定性，不排除使用额外理论、对象本性或可靠证明获得知识。

空域有唯一空函数，全称按现代逻辑的空真约定成立。这是显式边界约定，不证明有现实对象，也不强加给亚里士多德。冲突输入直接报错，不把不一致数据变成任意命题的证书。

## 3. 已实际执行

核验日期：2026-10-26。环境见 [environment.json](environment.json)，仅 Python 标准库，没有安装依赖。

- 24 项单元测试在普通、`-O`、`-OO` 三种模式均通过。覆盖空域、无观测、重复正/负记录、全覆盖、混合记录、相反延伸、输入冲突、域外对象、标签类型、固定分类及输入不变性。
- [oracle.py](oracle.py) 对 n=0..5 的每个对象“未见/负/正”三态赋值全部枚举，共 364 个观测映射。每个映射另枚举该域的全部二值函数，累计 9331 次候选检查，计数和状态不一致为0。独立计数循环不调用模型的显式枚举函数，但会调用待测的计数接口进行比较。
- 上述穷举是对有限输入族的代码核验，不代替上一节的一般双射证明。
- [results.json](results.json) 保存示例与穷举结果，`logs/` 保存本次命令、退出码和真实输出。

`-O` 会删除普通 Python assert 语句；单元测试使用 unittest 的检查方法，穷举使用显式条件与异常，因此这些检查没有因优化模式消失。

## 4. Notebook 与执行边界

[tutorial.ipynb](tutorial.ipynb) 有5个代码单元：一次观察、重复记忆、相反延伸与反例、固定分组、有限穷举。按顺序实际执行全部5个单元，标准输出已写回。

执行方式是新 Python 进程内的标准库 `exec`，共享单元命名空间，不是 Jupyter 内核；`execution_count` 特意保持 null，元数据也注明方法。做了基本 JSON、单元类型及唯一ID检查，未声称完整 nbformat 模式认证或 Notebook 界面渲染验证。已有 Jupyter 的读者可在本目录打开并从头运行。当前复现不要求安装 Jupyter。

## 5. 重跑与文件

在本 README 所在目录运行：

```sh
python3 run_all.py
```

它重新生成示例、三模式测试日志、Notebook执行日志、环境与 SHA256 清单。也可分别运行：

```sh
python3 -m unittest -v test_model
python3 -O -m unittest -v test_model
python3 -OO -m unittest -v test_model
python3 oracle.py
python3 run_notebook.py
```

- [model.py](model.py)：校验、计数、小域枚举、外部分类分组。
- [test_model.py](test_model.py)：24项单元测试。
- [oracle.py](oracle.py)：独立循环核对364个观测映射。
- [run_all.py](run_all.py)：实际运行与记录生成。
- [run_notebook.py](run_notebook.py)：标准库单元顺序执行器。
- [logs/tests-normal.log](logs/tests-normal.log)、[logs/tests-O.log](logs/tests-O.log)、[logs/tests-OO.log](logs/tests-OO.log)：三模式真实测试输出。
- [logs/demo.log](logs/demo.log)、[logs/notebook-exec.log](logs/notebook-exec.log)、[logs/commands.json](logs/commands.json)：本次示例、Notebook及命令结果。
- [sha256.json](sha256.json)：公开复现文件的哈希，排除自身和Python缓存。

解释集合的个数不是统计置信度，也不是“全称正确概率”。没有指定采样分布、先验或误差模型，不能把1/4等计数比例称作可靠度。固定分类来自外部输入，准确标签与完整域更是强假设；这些假设失效时，有限证书不自动适用于现实。
