# II.14：继承证书、观察覆盖与显式类比

这是《后分析篇》II.14（98a1–23）的**原创现代教学重构**。它不复现古代动物学观察，不认证真实因果、本质、自然种或适当解释层级，更不是古书的一般定理证明器。原文与版本分析见[深读正文](../../papers/ancient/aristotle-posterior-analytics-ii14.zh-CN.md)。

## 1. 问题与数据

给定一个有限整数对象域，用集合表示子类D、共同属A和属性B；这些是人为输入，不是从样本中学出的真实分类。算法检查D包含于A及A包含于B，并分别报告结论和非空性。输入可迭代对象在入口固化，避免一次性生成器被先前检查消耗。

`taxonomy_path`只检查给出的从叶到根路径：每一相邻外延包含、根属性前提。重复节点、未知节点、空路径明确拒绝。它不搜寻全部路径，不检查一个未提供的分类树是否穷尽、分支是否互斥，也不推断何层级是最初的解释层级。单节点路径允许，表示直接检查其属性前提，不是凭空证明。

`observation`把样本和有限的拟定总体分开：样本全阳性不等于覆盖总体。样本越出拟定总体则拒绝；输出反例只针对输入有限总体。

`relation_map`给定两个有限整数域、二元关系及全映射，逐个检查源关系边的像是否在目标关系里。不要求单射，不检查逆向保持，不自动迁移其他关系或一元属性。空源关系可使检查真，这不说明类比有解释价值。这里的关系映射是教学补充，**不是把原文的乌贼内壳、鱼刺和骨标注成现代数学同态或现代生物同源关系**。

## 2. 一般证明与边界

若D包含于A且A包含于B，任取x属于D，第一前提给出x属于A，第二前提给出x属于B。因此D包含于B。任意有限链的结论由链长归纳得到：零条边时依赖根属性前提；增加一条边时应用上述传递步骤。证明对空D也有效，因此包含结论不证明对象存在。

反过来，D包含于B不足以证明指定A是有效中项。取D={0}、A={0,1}、B={0}，结论真但A包含于B为假。不能用真结论掩盖坏前提。

对观察：样本S={0}、拟定总体D={0,1}、B={0}，S中没有反例，但D中对象1反例明确。这证明“正样本推出整个类的全称句”不是一般有效的演绎；没有证明一切归纳都无用。

对关系映射f：若对每条源边(u,v)均核查(f(u),f(v))是目标边，则源中任一有限关系路径的像仍是目标关系路径。逐边应用前提即得，不要求单射。但是源中额外一元属性P(u)不会凭这个前提推出P(f(u))，更不能推出未输入的真实原因。

## 3. 手算

1. D={0}, A={0,1}, B={0,1,2}：两前提及结论均真；D非空另行报告。
2. D为空，A=B为空：两前提及结论真，存在标记假。
3. 两对象源只有0→1，映射0→2、1→3。目标有2→3则保持；删掉该边立即失败。
4. 映射0、1都到2且目标有2→2：关系保持但不单射，说明“保留一关系”不等于对象一一对应。

## 5. 局限与合理延伸

- 整数对象、全知有限外延、无噪声关系均是教学选择；没有实际动物数据、测量、统计估计或学习基线。
- 允许空项；不把现代集合蕴涵强加为古代所有句子的唯一语义。
- 原文共同性质的选取有认识论和自然研究要求，本程序只校验已输入的形式条件。
- 可后续添加来源证据、候选层级比较或缺失观察标记，但不应把新增评分直接称为因果或本质认证。

## 6. 练习与答案

1. 两继承前提中删掉任一条可否仍保证结论？不能；令D={0}, A为空, B为空，或D=A={0}, B为空。
2. D包含于B可否确认指定A？不能，见手算坏中项反例。
3. 空项测试为何必要？空项使全称条件成立但没有存在见证。
4. 单节点路径是否没有前提？不是，仍要检查该节点包含于属性。
5. 全阳性样本何时保证给定有限总体全阳性？还需样本覆盖该总体；这仍不是现实总体覆盖证据。
6. 有效继承链是否证明分类无遗漏？不证明；程序没有检查未给出的类或路径。
7. 关系保持是否必为单射？不是，常映射到有自环对象是反例。
8. 关系保持能迁移颜色吗？不能，除非颜色保留另有前提和核查。
9. 空关系映射通过意味着强类比吗？不意味着，可能只是没有可违背的边。
10. 如何证明任意链长度，而非只试三层？用链长归纳；有限测试不能覆盖无限多种长度。
