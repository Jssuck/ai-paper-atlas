# 《几何原本》IX.34：一个偶数的两种度量见证

`mixed_even_types(n)` 要求正偶数的一半仍是偶数，且原数不能从二只靠倍增得到（起始二也不满足偶半条件）。先用偶半度量原数两次，给出偶度量者、偶次数。再反复取半，直至遇到大于 1 的奇数；它度量原数的次数是一个正偶数。程序也保留混合见证的逆序以区分度量方向。元组按（度量者，次数）保存。

例：$`12\to6\to3`$，两种见证为 $`(6,2)`$ 与 $`(3,4)`$，后者逆序为 $`(4,3)`$。$`24\to12\to6\to3`$ 的混合见证为 $`(3,8)`$。$`16`$ 最终到单位，不能给出非单位奇因子；$`18`$ 一半为奇数；$`9`$ 不是偶数。程序均不接受。

使用 Python 3.9+ 标准库，在本目录运行：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线将所有积不超过 256 的有序非单位因子对按积归组，按两个位置的奇偶分类，与反复取半得到的见证核对。有限检验不替代一般证明。Notebook 日志来自标准库实际回放三个代码单元，不是 Jupyter 内核运行。

直接打开 [Notebook](euclid-ix34.ipynb)；核对 [普通模式](normal.log)、[-O](O.log)、[-OO](OO.log) 和 [Notebook 回放](notebook-replay.log)。
