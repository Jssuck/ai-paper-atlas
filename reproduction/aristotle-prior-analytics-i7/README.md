# I.7：从语义检验到可检查的归约证书

这是为《前分析篇》I.7编写的**现代教学重构**，不是亚里士多德的算法、古代证明文本的自动翻译，也不是整个三段论或一阶逻辑的完备证明器。它把“结论真”“存在有限验证”“有一条可检查的证明”分开保存。

## 1. 文件与运行

- [reduction.py](reduction.py)：AEIO语义、类型支持枚举、反模型、有限归约搜索及独立句法证书核。
- [test_reduction.py](test_reduction.py)：24个测试方法，含非法输入、空项、逆向结论和损坏证书。
- [run_verification.py](run_verification.py)：固定范围的双向分类与证书/语义比较。
- [classification.json](classification.json)：96行分类及每个失败结论的一个反模型。
- [certificates.json](certificates.json)：14个后世命名标准式的归约证书，以及Darii/Ferio两份短证书。
- [report.json](report.json)：实际计数；[逐步走查](WALKTHROUGH.md)。

从本目录运行：

```sh
python -m unittest -v test_reduction
python run_verification.py
python -O -m unittest -v test_reduction
python -O run_verification.py
python -OO -m unittest -v test_reduction
python -OO run_verification.py
```

标准库，无第三方安装，无网络、密钥、Notebook或Jupyter内核调用。优化模式用于检查程序不依赖被删除的assert作输入验证，不等于测量性能或证明无漏洞。

## 2. 符号与有限语义

命题是(q,x,y)：x为主项、y为谓项。A表示所有x是y，E表示没有x是y，I表示有些x是y，O表示有些x不是y。I不包含“并非所有”；O不包含“有些是”。三项为P、S、M，位权分别4、2、1。类型t=6表示该对象是P和S而非M。一个支持集合是非空论域中实际出现的类型集合，例如[1,6]；相同类型出现多次不改变这些命题的真假。

allow-empty允许某项没有成员，但论域仍非空，有255个支持。all-nonempty要求P、S、M各至少出现一次，有218个支持。绝不把非空论域偷换为每个项都非空。策略不是古代文本的自动解释，而是显式敏感性分析。

三格前提分别为：

|格|大项前提|小项前提|
|---|---|---|
|1|(q,M,P)|(r,S,M)|
|2|(q,P,M)|(r,S,M)|
|3|(q,M,P)|(r,M,S)|

正向结论为(c,S,P)，逆向为(c,P,S)。程序每格逐项检查16对前提和两个方向的四种结论，不把“无正向结论”说成“毫无后果”。

## 3. 为什么类型压缩适用任意论域

对任意非空论域D及三个一元集合，将每个对象映为其三个成员关系组成的0至7类型，取实际出现类型集合T。A的失败仅要求有x而非y的类型出现；E的失败和I的成立仅要求x与y共同出现；O的成立要求x而非y的类型出现。因此原结构与T对全部AEIO命题逐项同真，三项非空条件也被保持。

反向地，每个非空T都能实现为“每个类型一个对象”的结构。故**对这三个一元项、这些命题及指定策略**，支持枚举精确决定所测后承，不是随意抽样几个小宇宙。此处给出一般保持性论证，代码运行只检查实现；不由255个实验推断无限论域定理。它不处理二元关系、个体相等、数量超过零的约束、模态、时态或自然语言意义。

## 4. 两个不同的验证器

语义层countermodel遍历支持，返回满足两前提而否定结论的支持。证书层make_certificate则作有限规则闭包；verify_certificate只检查每行的规则及前向引用，不调用语义枚举。测试专门断开语义oracle后复核短证书。

证书允许的行：

1. premise：必须是证书明列的前提。
2. existence：仅all-nonempty下可加入I(X,X)。
3. assumption：只能是目标的矛盾命题；A/O互为矛盾、E/I互为矛盾。
4. conversion：E(x,y)变E(y,x)，I(x,y)变I(y,x)；不接受A全称换位或O换位。
5. Barbara：A(m,p)和A(s,m)得A(s,p)。
6. Celarent：E(m,p)和A(s,m)得E(s,p)。

末行信息clash必须指向一对相同项向、互相矛盾的命题。加入反设后推出矛盾，采用经典反证规则回到目标。**反证闭合、矛盾配对、换位与存在前提都是证明基础的一部分**，不能据此说“只用两个全称句子便推出所有特称事实”。

每条规则的一般可靠性很短：两个包含关系可传递；若m与p不交且s包含于m，则s与p也不交；交集的交换律支持E/I换位；存在策略明确保证I(X,X)。按证书行数归纳，每行在前提、策略与反设为真的结构中为真。A/O或E/I不可能同真，所以不存在反设结构；在经典二值语义下目标成立。这证明的是内核规则的可靠性，不证明搜索器对任意输入完备。

搜索为三个项上的36个命题计算闭包，有限终止。使用固定规则顺序，不保证最短或最接近古代行文。14份证书统一用反设闭合，即使某式本可直接证明；两份短证书另外保留I.7最关键的Darii/Ferio展开路径。对本次768个候选实际未见语义/证书差异，不外推为整个逻辑的完备性。

## 5. 实跑结果与证据

本次普通、-O、-OO三模式均通过24个测试方法。每模式分类96行，比较768个定向结论，得到59个有效结论及709个经过回验的反模型；两种存在策略分别单计，因此这些不是59个互不等价的新定理。14标准式在all-nonempty下均有证书；allow-empty下Darapti与Felapton失败，其余12式仍可证。标准式名称是后世教学标签，非I.7原文命名。

## 6. 解释边界

- I.7举出的“肯定＋全称否定”是逆向结果的一类充分条件，不能改成充要判据。分类还显示第二格O,A及第三格A,O等有逆向O结论；负前提不必都是E。
- A与E不是在空项政策下无条件矛盾；必须结合相应主体存在。内核只把A/O、E/I视为直接矛盾。
- 不定肯定与特称肯定的原章关系只在主文解释；本程序没有另设自然语言“不定”解析器。
- 本程序不恢复I.2暂缓的发布，不处理I.3模态及I.8以后；也不论证古代文本对现代AI的实际因果影响。
