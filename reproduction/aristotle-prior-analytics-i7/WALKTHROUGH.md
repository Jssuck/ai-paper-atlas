# 逐步走查：特称结论如何归约到全称规则

以下全部是现代记号重构；证书中的行号从0开始，主项在谓项之前。

## 1. Darii：不是把结论当工具

已知A(M,P)，I(S,M)，目标I(S,P)。

|行|命题|根据|
|---|---|---|
|0|A(M,P)|前提|
|1|I(S,M)|前提|
|2|E(S,P)|反设：目标的矛盾命题|
|3|E(P,S)|2的E换位|
|4|E(M,S)|3与0作Celarent|
|5|E(S,M)|4的E换位|

1与5矛盾。于是反设失败，得I(S,P)。原章通过第二格展示中间全称结论；这里把那个第二格步骤继续展开为E换位＋Celarent＋E换位。推导没有调用Darii，也不从全称前提凭空制造存在。存在见证已在I(S,M)中。

手算模型：支持[7]的一对象同时为S、M、P，前提与目标全真。反设要求S与P不交，不能与此见证共存。模型用于演示，不代替上述一般推导。

## 2. Ferio：换一个反设

已知E(M,P)，I(S,M)，目标O(S,P)。

|行|命题|根据|
|---|---|---|
|0|E(M,P)|前提|
|1|I(S,M)|前提|
|2|A(S,P)|反设：目标的矛盾命题|
|3|E(P,M)|0的E换位|
|4|E(S,M)|3与2作Celarent|

1与4矛盾，因此O(S,P)。推理同样不调用Ferio。支持[3]表示对象是S和M而非P，给出前提与结论同真的具体模型。

两条短证书可由以下标准库命令打印：

```sh
python -c "import reduction,json; print(json.dumps(reduction.explicit_first_figure('Darii'),indent=2))"
python -c "import reduction,json; print(json.dumps(reduction.explicit_first_figure('Ferio'),indent=2))"
```

## 3. 没有正向结论，不等于没有逆向结论

第一格A(M,P)、E(S,M)，在三项非空条件下不能推出S对P的任何A/E/I/O结论，却能推出O(P,S)。取一个M的成员，它属于P，且由E(S,M)不属于S，所以有P不是S。

这正说明方向不可省。程序调用classify(1,'A','E','all-nonempty')得到forward=[]、reverse=['O']。

去掉M存在条件则会失败：支持[0]使两全称前提都真，却没有P成员，O(P,S)为假。程序在allow-empty策略下因此不报告该逆向结论。

若大项前提换成I(M,P)，存在已明示，allow-empty也能得O(P,S)。另外第二格O(P,M)、A(S,M)仍得O(P,S)：O的见证属于P而不属于M，若它属于S便由A(S,M)属于M而矛盾。这个实例提醒我们别把E前提当成逆向结论的唯一条件。

## 4. Darapti的存在成本

A(M,P)、A(M,S)希望推出I(S,P)。若M为空，取支持[0]，两前提真而结论假。all-nonempty明确提供I(M,M)；加入目标的反设E(S,P)，结合A(M,S)得E(M,P)，再换位并结合A(M,P)得E(M,M)，与I(M,M)冲突。

这里不是A(M,P)本身有存在含义，而是策略额外声明存在。Felapton具有相同的中项存在成本。程序在弱策略下拒绝给两式证书，在强策略下才生成；这比无条件接受历史模式更能暴露建模前提。

## 5. 如何亲自破坏一份证书

复制Darii短证书，把第4行引用[3,0]改为[3,2]。两输入不再具有Celarent要求的共同中项，verify_certificate会抛出ValueError。即使目标在别处有其他证明，这份损坏的证书仍应拒绝。证明检查与重新判断目标是否真是两件不同的事。

查看classification.json可以逐个取出反模型：整数位4表示P，位2表示S，位1表示M。按这个说明展开成集合，再手算两前提与失败的结论，可以独立检查报告，而无需相信程序给出的布尔值。
