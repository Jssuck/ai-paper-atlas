## 语义约定

谓词在前：`A(X,Y)` 为 Y 是 X 的子集；`E(X,Y)` 为交集空；`I(X,Y)` 为交集非空；`O(X,Y)` 为 Y 中有元素不在 X。现代集合语义允许全称命题空真，不给 A、E 偷加存在含义。另行运行所有三个项均非空的制度；Darapti/Felapton 两条全称原式明确补 C 非空。论域始终非空。

每个 n 元论域中，三个项的全部有序赋值为 `2^(3n)`；全项非空制度为 `(2^n-1)^3`。n = 1、2、3、4 合计分别为 **4680、3746** 个模型。不同 n 分开计数，不把同构模型消去。12 条预期有效规则在两制度均有满足前提的模型且零反模型；另外 6 条 `invalid_` 提案故意保留错误，用来防止把范围更广的错误命题误写成定理。

| 被检验的错误提案 | 可空项反模型数 | 全项非空反模型数 |
|---|---:|---:|
| Darapti 不加 C 存在 | 120 | 0 |
| Felapton 不加 C 存在 | 120 | 0 |
| 结论与反向桥恢复全称肯定 | 554 | 554 |
| 结论与反向桥恢复全称否定 | 554 | 554 |
| 全称否定简单换位恢复特称肯定 | 440 | 156 |
| 两个独立 some 当作共同见证 | 334 | 270 |

前两项在全项非空制度无反例并不矛盾：该制度已经提供了省略掉的存在前提。

## 为什么“不能这样回证”不等于集合蕴涵无效

有序命题对象保留谓词/主词字段，不把 `I(C,B)` 与 `I(B,C)` 自动合并。`darii(A(C,A), I(A,B))` 得到 `I(C,B)`；再显式 `convert_i` 才得到目标 `I(B,C)`。这两个式子的集合真值总相同，测试穷举确认，不提供伪造的语义反例。另一方向 `disamis(A(C,B), I(A,B))` 直接产生 `I(A,C)`。

这些函数只实现所写的有序推理图式，**不是全部合法推导的穷举搜索，也不证明不存在别的推导**。章中的受限回证要求须由原文解释，不能由此小程序替代。Darii、Disamis 等是方便索引的后世式名。

## 负式补充假设的成本

取 U = {0,1,2}、A = {0}、B = {1}、C = {2}：某 B 非 A 为真，C 与 A 不交为真，某非 A 是 C 也为真，但 B 与 C 不交。两个存在断言的见证分别为 1、2，不能合并。

`negative_coverage_bridge_recovers_I` 加的 `U-A <= C` 是**教学采用的充分覆盖条件**，不是由 E(A,C) 换位所得，也不声称是文本唯一读法。`negative_shared_witness_bridge_recovers_I` 则明确要求某个 B 中的非 A 见证也在 C；它本身已经携带待恢复的交集信息，所以不能充作独立、非循环的证成。列出这两条正是为了暴露补充前提的成本，而非掩盖它。
