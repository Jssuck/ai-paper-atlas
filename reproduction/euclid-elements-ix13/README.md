# 《几何原本》IX.13：素数幂的真因子

正整数教学重构。给定素数 $`p`$ 与整数 $`n\ge1`$，目标为 $`p^n`$。程序生成较早的非单位项 $`p,p^2,\ldots,p^{n-1}`$。对指定的真因子，先验证整除，再逐次除以 $`p`$ 至单位，记录商作为提取证书。例：目标 $`3^4=81`$，候选 $`27`$ 给出 $`27,9,3,1`$。程序排除两端 $`1`$ 与 $`p^n`$；$`n=1`$ 时中间集合为空。底数若为合数则结论未必成立，例如 $`4\mid 6^2`$，但 $`4`$ 不是该链的较早项。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线不从底数生成因子，而按数值逐个试查到目标的整数平方根，并把整除时的配对商也加入，以确定全部真非单位因子。范围是 2 至 19 的八个素数、指数 1 至 6。有限算例不替代一般证明。Notebook 日志是标准库执行三个代码单元的记录，不是 Jupyter 内核运行。
