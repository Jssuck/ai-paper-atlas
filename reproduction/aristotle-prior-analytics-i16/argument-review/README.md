# 独立集合论证检查

此处程序独立使用 Python 集合，不导入作者的模型模块。它核对本文明确提出的现代教学命题，不宣称证明全部古代模态逻辑或用有限实验替代一般证明。

## 执行

环境与完整命令见 [environment.json](environment.json)。从本目录执行：

```sh
python check_arguments.py > normal.json
python -O check_arguments.py > O.json
python -OO check_arguments.py > OO.json
cmp normal.json O.json && cmp normal.json OO.json
```

三种模式均成功结束；[普通模式](normal.json)、[-O模式](O.json)、[-OO模式](OO.json)结果逐字相同。检查采用显式异常，不因优化选项去掉 `assert` 而丢失。

每模式枚举 **9,928** 个配置、执行 **23,914** 次显式检查。范围为一个对象配一至三个世界、两个对象配一至两个世界、所有实际索引；空词项、世界重排与同构配置都保留，不把配置数称为互不等价模型数。另核两个指定反例。

## 论证目标与结果

- 偶然全称大前提与必要肯定小前提：全称／特称的固定对象转移通过。
- 全世界包含桥与偶然小前提：正向弱可能通过；桥本身不由局部必要前提推出。
- 双向实际锚定否定桥与偶然小前提：实际全否／特否和弱可能否定通过。
- 上一步实际上只需小前提提供相同对象的正向可能，不需其反向可能；这一弱化也核过。
- 找到局部必要肯定不足以反向传递弱可能、单向必要否定不能默许换位、实际否定不能升级必要否定的实例。
- 全世界包含与实际主项必要肯定互不蕴含，两方向反例都找到。
- 三个实际词项均非空的指定模型仍展示“实际否定但非必要否定”。两个对象交替具有属性的模型展示逐对象可能不能改成全体共同可能。

计数的分支可以重叠，不能相加成为样本总数或统计有效率。全称到特称仍需要实际主项非空；脚本没有偷偷添加该前提。一般论证的任意论域、世界集合与反证步骤见[主文](../../../papers/ancient/aristotle-prior-analytics-i16.zh-CN.md)，全文独立审查见[论证审查记录](../../../papers/ancient/aristotle-prior-analytics-i16.audit.zh-CN.md)。
