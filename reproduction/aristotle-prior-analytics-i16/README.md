## 输入和符号契约

[model.py](model.py) 的 `Model(n, worlds, actual)`：

- 论域是编号0到n−1的对象，n为正整数；世界为非空元组，世界间全部可及，实际世界包含在其中。
- 每世界一个 `(A,B,C)` 非负整数位掩码三元组。位 `1 << x` 为真表示该对象属于相应词项；实际世界索引可变。
- 词项可以为空、可以随世界变化。模型不暗中要求每项非空或所有对象具有本质分类。
- 主项范围固定为**实际主项对象**；`quantity='all'`量化全部这些对象，`'some'`选择其中同一对象，然后才查其世界见证。全称空真、特称要求见证。
- `N+`：该对象在所有世界都有谓项；`N-`：所有世界都无谓项。
- `M+`：至少一个世界有谓项；`M-`：至少一个世界无谓项。
- `K`：同一个对象同时具有正、反世界见证。两个见证可以不同；不同对象分别提供正反见证不能拼成特称 K。
- `categorical(P,S,quality)` 为实际世界上的 A/E/I/O 全肯、全否、特肯、特否，不是模态命题。
- `symmetric_negative(A,B)` 为 **E* = N−(A,B) 且 N−(B,A)**，两方向都全称。它要求实际 B 对象永不为 A，且实际 A 对象永不为 B。它不是每世界 A、B 不交，也不禁止既非实际 A 又非实际 B 的对象未来同时属于两者。
- `stable_positive(A,B)` 为 **S+：每世界 B 都包含在 A 中**；它不是局部 N+，也不由局部 N+ 推出。
- `jointly_possible` 要求有一个共同世界使所有实际主项对象同时具有／不具有谓项，区别于逐对象可能。

非法尺寸、布尔值冒充整数、非元组结构、越界掩码／索引和未知模式／量词被拒绝。代码仅处理三个具名一元词项，未实现任意公式解析。

## 一般证明先于枚举

以下是任意非空论域和世界集上的数学论证；实际程序仅实例化有限模型。

### 1. 必要肯定小前提的直接路线

设全称 K(A,B)，且 N+(B,C)。任取实际 C 对象 x，N+ 在实际世界也成立，所以 x 是实际 B。大前提给 x 一个 A 世界及一个非 A 世界，故 K(A,C)。若小前提仅特称 N+，先选择它的固定实际 C 见证 x，得到特称 K(A,C)。不需所有对象共享同一个可能世界；也不能把结论升级为实际肯定、实际否定或必要性。

### 2. 必要肯定大前提的范围问题

局部 N+(A,B) 只约束实际 B 对象；K(B,C) 可能让实际 C 在未来进入 B。那个新 B 对象不一定受大前提覆盖。补上 S+ 后，任意满足 K(B,C) 的对象 x 有某世界 w 的 B 身份，S+ 在同一个 w 把它转成 A 身份，故得到 M+(A,C)。特称版本保持同一个 x。这个充分桥不是原文的自动译义。

该推理没有给出非 A 世界，因此不保证强 K，也不保证实际 A 或必要 A。不能因前提含“必要”就把结论的模态加深。

### 3. 必要否定的转换桥与实际否定

设 E*(A,B) 且全称 K(B,C)。任取实际 C 对象 x。若 x 也是实际 A，E* 的第二方向 N−(B,A) 会令 x 在所有世界都不是 B；这与小前提给出的 B 世界矛盾。所以 x 不是实际 A，得到实际 E(A,C)。特称 K 时选择其见证，得到实际 O(A,C)。

因为实际世界本身是可及世界，实际非 A 也是一个非 A 可能世界，于是得到相应 M−。这里**归谬推论必然有效**不等于“对象必然非 A”：归谬只排除实际 A 假设，没有排除未来 A。整个证明只用小前提 K 的正向可能一半；它没有把 K 改称必要性。

E* 的对称形式把所需转换许可公开化。其第二方向对本条实际否定证明已经足够；第一方向是与否定大前提及其换位合并的契约，不声称 E* 为最弱条件。单向 N−(A,B) 不自动推出转换方向。

## 实跑范围和读数

[demo.py](demo.py)检查1、2个对象、2个世界的全部词项赋值，并对每个赋值选择两个实际索引：**8,320个配置**。同构、世界排列、空真均未去重；不是独立随机样本。各分支可能重叠，不把检查数相加成成功率。

| 被检查的现代条件 | 全称 / 特称满足前提数 | 核查结果 |
|---|---:|---|
| K大前提＋N+小前提 | 1,624 / 744 | K结论全部成立 |
| S+大前提＋K小前提 | 1,404 / 1,040 | M+结论全部成立 |
| 同上却要求强K | 392 / 424次失败 | 不可升级为双向偶然 |
| E*大前提＋K小前提 | 1,012 / 708 | 实际E/O和M−全部成立 |
| 同上却要求N− | 172 / 188次失败 | 不可升级为必要否定 |
| 仅局部N+＋全称K小前提 | 236次M+失败 | 主项范围桥不能省略 |
| 仅单向N−＋全称K小前提 | 456次实际E失败 | 否定换位不能免费添加 |

完整读数和显式反模型保存在 [demo.json](results/demo.json)。3对象非空反例由测试明确验证，不计入上述1/2对象穷举总数。有限执行用于检测实现偏差和展示边界，不替代以上一般证明，不认证所有古代句子的唯一解释。

## 反例怎样读

掩码以二进制位给出对象集合。以下均为自造教学模型，不是作者提出的生物学或自然哲学实例。

- **local_positive_not_possible**：n=2，w0=(1,1,2)，w1=(1,3,2)。实际三个项都非空。实际 B 对象一直 A，但 C 对象只在未来成为 B、从不 A；局部必要肯定没有覆盖未来新 B。
- **stable_positive_not_strong**：n=1，w0=(1,0,1)，w1=(1,1,1)。S+ 与 K 小前提成立，A 却必要真；弱可能不能冒充强偶然。
- **stable_positive_not_actual**：n=1，w0=(0,0,1)，w1=(1,1,1)。S+ 与 K 小前提成立，实际 A 假；也不能升级为必要肯定。
- **symmetric_negative_not_necessary**：n=3，w0=(1,2,4)，w1=(5,6,4)。三个实际项都非空。E*成立，C对象实际非 A、未来是 A，且 B 双向可能。实际否定与弱否定成立，但必要否定不成立；未来该对象同时 A、B 不违反 E*。
- **symmetric_negative_not_strong**：上例只把 w1 的 A 改为1，C对象永远非 A。条件仍成立，说明输出也未必是强偶然。
- **one_way_negative_not_actual**：n=2，w0=(2,1,2)，w1=(2,3,2)。实际 B 对象永不 A，但实际 A 对象未来可以 B；单向 N−真、换位假、小前提 K 真、实际 E 假。
- **negative_minor_positive_endpoint / negative_endpoint**：必要否定小前提不把 C 放入 B；A 在 B 上变动，而在 C 上可永真也可永假。不是给出一条通用偶然结论的结构。
- **particular_major_no_positive_endpoint / positive_endpoint**：实际 B 有两个对象，必要特称大前提可由另一 B 对象提供见证；C 对象本身的 A 可永假或永真。原章数量失败的教学对应不是穷尽所有失败配置。
- **pointwise_not_joint**：两个对象交替为 A，每个都有正反见证，却没有全体同时为 A 或同时非 A 的世界。
- **different_witnesses**：一个对象永 A，另一个永非 A。分别“有些可能 A”和“有些可能非 A”成立，但不存在同一个双向偶然对象。
