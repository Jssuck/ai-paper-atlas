# 《几何原本》III.37：切割线等式的逆向判据

这是[精读正文](../../papers/ancient/euclid-elements-iii37.zh-CN.md)的现代教学检查，不是欧几里得原有程序或尺规作图。把原文的线段和面积翻译成二维有理数坐标、平方距离和点积，不使用浮点误差容限。

## 检查顺序

1. 检查半径为正、外点 $D$ 确在圆外、割线交点 $C,A$ 都在圆周上且沿同一射线附近至远。只有共线、同向、顺序正确才用点积记录 $DA\cdot DC$。
2. 检查 $DB^2=DA\cdot DC$ 且候选端点 $B$ 在圆周上。坐标版提前检查等式方便展示保留等式却违反圆周条件的反例；两项都是输入假设。
3. 单独构造参考切点 $E$：置 $v=D-F$、$m=v\cdot v$，令 $J$ 为逆时针九十度旋转，其两解为
   $$
   E=F+\frac{r^2v\pm r\sqrt{m-r^2}\,J(v)}{m}.
   $$
   构造不读候选点，随后选与 $B$ 不同者，验证 $E$ 在圆上且 $FE\perp DE$，再核对 III.36 给出的参考平方相等。
4. 比较 $DE^2,EF^2,FD^2$ 与 $DB^2,BF^2,FD^2$。代数版用点积恒等式体现 I.8 的对应角均为直角，得到切线判据需要的圆上垂直条件；III.16 推论给出的几何结论见正文。

## 例子与边界

- 圆心 $(0,0)$、半径 $5$，过心例的外点为 $(13,0)$，割线乘积与切线平方均为 $144$。非过心例外点 $(5,3)$，割线取水平线，乘积与切线平方均为 $9$，参考切点为 $(40/17,75/17)$。
- 在非过心例把候选点改为 $(2,3)$，距离平方仍为 $9$，但它不在圆周，候选线就是横穿圆的割线。程序显式拒绝。
- 有限扫测在两个圆心/半径设置上选择若干外点。用有理参数取一个圆周点，从直线代入圆方程所得二次式的根积确定另一交点，排除重根和重复近远点对，然后使用未经简化的坐标检查输入。另纳入过心定例，一共 527 个构形（3 个过心，524 个不过心）。选择不是对全体构形的代表性采样。若圆外点的参考式需要无理根，参考构造显式拒绝，这只反映本教学程序的数值范围，不是命题局限。
