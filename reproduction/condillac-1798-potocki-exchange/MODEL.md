# Condillac-Potocki 1798：模型、论证与边界

这些是为阅读第 202 页教学主张而另建的现代有限模型。以下数学论证依赖明确假设；测试是实现核对，不能代替论证，也不能证明历史作者持有这些形式系统。

## 一、单调前置条件规划

### 定义

给定有限技能集 $`U`$、初始已掌握集 $`S_0\subseteq U`$、目标集 $`G\subseteq U`$。每节课 $`\ell`$ 有前置集 $`P_\ell\subseteq U`$ 和非空增量集 $`A_\ell\subseteq U`$。同一节课的增量固定，没有遗忘、失败、概率或额外费用。每节课成本均为 1。

当 $`P_\ell\subseteq S`$ 时可执行，后继是 $`S\cup A_\ell`$。搜索和 `replay` 只接受严格增长的后继。增量非空并不保证每次都有新技能：已经学会增量后，该课成为冗余。

闭包迭代为：

```math
S_{t+1}=S_t\cup\bigcup_{\ell:\,P_\ell\subseteq S_t}A_\ell.
```

停止于不再改变的集合 $`C`$。每个改变的轮次至少增加一个技能，因此改变轮次至多为 $`|U\setminus S_0|`$。

### 为什么闭包恰好判定可达

1. 任意可执行序列的状态都包含于 $`C`$。起点包含于 $`C`$；若当前状态包含于 $`C`$，可执行课的前置也包含于 $`C`$；闭合性保证增量包含于 $`C`$。
2. $`C`$ 本身可达。对闭包每一轮，把该轮可用且尚有新增量的课依次执行。前置在轮首已经满足，单调增加不会使其失效。略去冗余课，仍能得到该轮的并集。
3. 因此存在达到目标的序列，当且仅当 $`G\subseteq C`$。此外，任意包含 $`S_0`$ 的闭合集都包含每轮 $`S_t`$，故 $`C`$ 是最小的这类闭包。

无初始技能的互相依赖可以一直停在空集；“存在两节课”并不意味着存在第一步。

### 为什么 BFS 返回最短序列

把技能集当成结点，把可执行且严格增长的一节课当成一条单位成本边。结点最多 $`2^{|U|}`$ 个。广度优先搜索按边数分层访问，首次得到包含目标的状态时，其路径长度最小。重复到达同一状态不必继续搜索：未来可执行课只由该状态决定，首次到达的路径不更长。略去冗余边不会改变可达性或最小课数。

这些结论只适用于给定的确定性转换及单位成本。最少课数不是最少真实学习时间，更不是“最容易”或“最有信心”。实现可能枚举指数级状态，不是大规模课程规划器。

### API

- `Lesson(name, prerequisites, gains)`：课名是非空白字符串；两个集合必须是 `frozenset[str]`，增量不得为空。
- `PlanningProblem(skills, initial, goal, lessons)`：集合均为 `frozenset[str]`；`lessons` 是 `Lesson` 元组，课名互异；所有技能都属于 `skills`。
- `closure(problem)`：返回最小闭包。
- `shortest_plan(problem)`：返回课名元组；同长度解按输入课表顺序打破平手。`()` 表示目标原已满足，`None` 表示模型内确实不可达。
- `replay(problem, names)`：返回执行后的技能集；允许尚未达到目标的部分路径；未知课名、前置不满足或冗余步均报 `ValueError`。
- `greedy_plan(problem)`：每步选新增技能数最多的课，平手按课名的字典序。它只作反例演示，不保证最短。

空技能集合法，此时初始集、目标集与课表都只能为空，最短计划是 `()`。空课表也合法，已有目标返回 `()`，缺少目标技能则返回 `None`。

## 二、有限无噪声候选过滤与最小教学集

### 定义

域是有序、互异的点名元组 $`X=(x_0,\dots,x_{n-1})`$，允许 $`n=0`$。候选是一个有限、有序的二元真值表行族；重复行合法。一个行 $`h`$ 在位置 $`i`$ 的值是 $`h_i\in\{0,1\}`$。目标 $`h^\star`$ 是一个同宽二元行。

观察 $`(x_i,y)`$ 的含义是该点标签恰为 $`y`$，没有标签噪声。给定观察序列 $`D`$，候选空间为：

```math
V(D)=\{j:\text{第 }j\text{ 行对 }D\text{ 的每条观察给出相同标签}\}.
```

重复观察可以出现；同一点的相互矛盾标签会使候选空间为空。这里区分三个命题：

- 可实现：$`h^\star`$ 确实出现在给定候选族中，与当前观察是否矛盾无关。
- 当前一致：$`V(D)`$ 非空，不代表目标可实现。
- 完整识别：$`V(D)`$ 非空，且每个幸存行在整个有限域上都等于 $`h^\star`$。

不能把“所有幸存行等于目标”的空集真值误当作识别成功。重复目标行可以同时幸存；识别的是函数行为，不是行号、内部过程或心理来源。

### 最小教学集及差异集论证

教学者知道目标全表，从域点中选一个非自适应子集 $`T`$，提供对应目标标签。对每个与目标不同的候选行定义：

```math
\Delta(h)=\{i:h_i\ne h_i^\star\}.
```

一个真目标观察会排除 $`h`$，当且仅当选中的点索引与 $`\Delta(h)`$ 相交。因此，可实现前提下，教学集识别目标，当且仅当它击中每个不同候选的差异集。相同目标行不要求被排除。

`minimum_teaching_set` 按大小从 0 到 $`n`$ 枚举点索引组合，对每个组合运行完整识别判定。首次通过的大小因此最小；同大小按域索引组合的字典序选第一个。可实现时，全部域点一定区分所有不同的行，故必定成功。不可实现时返回 `None`，不以空候选空间冒充成功。最坏要检查 $`2^n`$ 个子集，每次还要验证与过滤候选。

这是一项给定候选族中的最小辨识问题，不是关于任意真实学习者、未列入候选的函数、带噪数据或域外泛化的保证。

### API 与空域约定

- `HypothesisSpace(domain, rows)`：两个参数是元组；域点是互异非空白字符串；每个行是同域等长元组，标签必须是精确的整数 0 或 1。
- `version_space(space, observations)`：观察是 `((点名, 标签), ...)`，返回一致行的原始整数索引。空结果 `()` 表示没有一致候选。
- `is_realizable(space, target)`：目标是否在行族内。
- `is_identified(space, target, observations)`：非空幸存族是否在全域上都等于目标。
- `minimum_teaching_set(space, target)`：返回最少目标观察组成的元组；不可实现返回 `None`。候选只有目标行为时返回 `()`。
- 空候选族合法，但没有任何可实现目标，任何观察后的候选空间均为空。
- 空域只有一个可能行为，即空行 `()`。若候选族含至少一个空行，空目标可实现且零个例子已识别；若候选族为空，则不可实现。空域不接受任何观察点。

## 三、验证边界与历史解释

所有公开 API 均检查外部输入类型与形状。容器要求精确的不可变类型，不隐式把列表或集合转成元组或冻结集合；标签拒绝 `bool`、浮点数以及整数子类。错误类型用 `TypeError`，类型正确但越界、重复名称或尺寸错误用 `ValueError`。验证不使用会被优化模式删除的 `assert`。模型对象是冻结数据类，按正常构造与使用约定保持有效；不承诺抵御绕过构造器或强行改写对象内部的行为。

在这些假设下可以论证“可达”“最少课数”“完整域内行为识别”和“最少例子数”。不能从它们推导学习者真实觉得容易、形成信心或自行发现了规则。即使完整域上的输出全部相同，也可能来自讲授、模仿、记忆或其他过程。

第 202 页关于发明方法应在学校排他采用的断言不由模型验证；预留修订时间也不是已经实现的优化目标。这里通过可审查实现与可重跑检查保留修订的可能，但没有把史料压缩为一个已证实的现代定理。
