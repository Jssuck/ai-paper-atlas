# Condillac-Potocki 1798：手算与逐步输出

本文件可对照 `python3 demo.py`。点名 `x0` 至 `x3` 对应真值表位置 0 至 3，代码返回点名，候选空间返回行号。

## 一、短路径与“新增最多”的反例

技能宇宙为 `a,b,c,g,u,v,w`；初始为空；目标只要 `g`。课表顺序如下，每课成本为 1：

- A：无前置，增加 `a`
- B：前置 `a`，增加 `b`
- C：前置 `b`，增加 `g`
- D：无前置，增加 `u,v,w`
- E：无前置，增加 `c`
- F：前置 `c`，增加 `g`

### 闭包逐轮

1. 起点为空。
2. A、D、E 可用，第一轮并集为 `a,c,u,v,w`。
3. B、F 的前置已满足，第二轮得到 `a,b,c,g,u,v,w`。
4. C 也可用，但已不能增加新技能；闭包停止。目标 `g` 在闭包内，故可达。

闭包只判定能否到达，不是最短课程表。它把所有能增长的方向合并了。

### BFS 输出逐行

```text
BFS: ('E', 'F'); length=2
  after 0: empty
  after 1: c
  after 2: c,g
```

- 第 1 行：最短结果是 E、F，共两课。
- 第 2 行：执行前没有已掌握技能。
- 第 3 行：E 提供 `c`，为 F 准备前置。
- 第 4 行：F 提供 `g`，完成目标。

不可能只用一课：直接提供 `g` 的只有 C、F，其前置 `b`、`c` 起初都不成立。

### 贪心输出逐行

```text
greedy: ('D', 'A', 'B', 'C'); length=4
  after 0: empty
  after 1: u,v,w
  after 2: a,u,v,w
  after 3: a,b,u,v,w
  after 4: a,b,g,u,v,w
```

- 首先 D 新增 3 个技能，A、E 各新增 1 个，所以规则选 D。
- D 后 A、E 平手，按课名字典序选 A。
- A 后 B、E 平手，选 B；B 后 C、E 平手，选 C。
- 最后达到目标，但花了四课。`u,v,w` 对这个目标无用；增量计数没有表达用途。

这是指定平手规则下的反例，并非所有贪心平手策略都会得到这条路径。

### 无法启动的循环

P 的前置是 `b`，增量是 `a`；Q 的前置是 `a`，增量是 `b`。初始为空时，两节课都不能执行：

```text
cycle closure: ()
cycle shortest plan: None
```

这里 `None` 是在全部给定转换下确实无解，不是搜索超时。若初始已有 `a`，Q 就能提供 `b`，因此循环本身并不总是不可达。

## 二、从局部一致到全域识别

四个候选行依次为：

```text
index  x0 x1 x2 x3
0      0  0  0  0    target
1      1  0  0  0
2      0  1  0  0
3      0  0  1  1
```

最小教学集返回：

```text
(('x0', 0), ('x1', 0), ('x2', 0))
```

过滤结果逐行是：

```text
  after 0: rows=(0, 1, 2, 3); identified=False
  after 1: rows=(0, 2, 3); identified=False
  after 2: rows=(0, 3); identified=False
  after 3: rows=(0,); identified=True
```

1. 没有观察时，全部行都可能。
2. 观察 `x0=0` 排除第 1 行；第 2、3 行仍与已有观察相同。
3. 再观察 `x1=0` 排除第 2 行；第 3 行仍未被区分。
4. 再观察 `x2=0` 排除第 3 行；最后只剩目标行为。

为什么至少三个例子？第 1 行只在 `x0` 不同，必须教 `x0`；第 2 行只在 `x1` 不同，必须教 `x1`；第 3 行在 `x2,x3` 不同，至少再选一个。差异集是 `{0}`、`{1}`、`{2,3}`。所以 `(0,1,2)` 和 `(0,1,3)` 都最小；实现按域位置组合选择前者。

## 三、三个容易混淆的边界

### 候选空间为空

同一个 `x0` 同时观察到 0 和 1，任何确定性行都无法一致，故候选空间为空且 `identified=False`。目标行仍在原假设族中，`is_realizable` 仍为真。错误观察与目标缺席是两种问题。

### 目标不在候选族

目标改为 `1111` 时，`is_realizable=False`，`minimum_teaching_set=None`。缺少目标时，删除所有候选不能制造出目标。

### 不同索引表示同一行为

域只有 `x`，三行是 `0,0,1`。观察 `x=0` 后保留行号 `(0,1)`，但两行在整个域上相同，所以行为已经识别。若域为空、候选族含两个空行，则空教学集 `()` 已经充分。

这些输出没有告诉我们学习者是如何获得该行为的。相同的答案与真正“自己发现”之间，仍缺少关于过程的证据。
