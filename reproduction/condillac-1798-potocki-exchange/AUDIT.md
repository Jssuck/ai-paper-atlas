# 独立实现审计：Condillac–Potocki 有限教学模型

## 结论

对 `model.py` 全部实现、公开接口合同和示例进行了另行审阅；未发现与声明合同不符的实现缺陷。独立审计程序在普通、`-O`、`-OO` 三种真实子进程中均通过，受审模型代码没有因审计而修改。

这里的“独立”指由另一个审阅任务编写新检查程序，并使用不同的表示、预言机及输入范围；不是第三方机构认证、人类专家认证或形式化验证。有限枚举不能证明任意规模输入上的程序正确性；一般性主张仍依赖 `MODEL.md` 的明确假设和论证。

## 受审语义

- 规划是有限、确定、单调增加技能的正前置模型，每课成本为 1。闭包轮数不等于课数。
- 最短路径只含合法且严格增长的步骤。目标原已满足返回 `()`；确实不可达返回 `None`；同长路径按输入课表顺序选择。
- 候选过滤针对完整有限域的二元表。重复行保持不同索引，但识别针对相同的全域行为。
- 识别要求幸存候选非空；观察矛盾不能被当成识别成功。
- 最小教学集是非自适应、目标标签给定的点子集；不是学习者心理过程或域外泛化保证。
- 公共接口只接受合同声明的精确不可变容器和标量类型。布尔值、浮点数、整数子类不能充当标签；冻结对象不承诺抵御绕过正常构造或强行修改内部的行为。

这些语义与现代附件相符。审计没有检验十八世纪教学成效，也不把本代码称作历史作者的算法。

## 与作者测试不同的检查

### 规划：204,352 个完整问题

三种技能有 8 个集合，规则有 8 种前置集 × 7 种非空增量集 = 56 种。枚举长度为 0、1、2 的全部有序规则表，允许不同课名具有相同规则语义，共 `1 + 56 + 56² = 3,193` 个系统；每个系统检查全部 8 种初始集和 8 种目标集，共 204,352 个问题。

- 闭包预言机枚举并求交所有包含初始集的闭合状态，不重用模型的闭包迭代。
- 最短路径预言机把状态编码为整数位掩码；严格增长边必然增加整数值，因此按数值顺序作一次有向无环图动态规划。不使用 BFS 队列，也不使用作者测试的课程排列穷举。
- 不只比最短长度，还比较完整返回课名序列及平手规则；课名的字典序故意与输入顺序相反。
- 检查闭包可达性等价、返回路径重放合法性、严格增长路径长度界，以及贪心能否到达目标。
- 另有六技能汇合分支和平手例、六步前置链、空技能宇宙、部分重放及非法路径检查。贪心的精确教学示例另由原测试重跑核对；不据此宣称贪心最优。

作者原规划穷举使用两技能、至多三条互异规则的无序组合，以及课程排列预言机。新检查刻意改变技能数、规则顺序、重复语义和预言机算法；两个范围互补，不称一个包含另一个。

### 候选与观察：允许重复的有序行族

域宽度从 0 到 3；每个宽度枚举长度从 0 到 3 的全部有序候选行族，允许重复。合计 689 个行族，包含空域、空候选族、多个空行及全部目标缺席情形。

- 5,054 个行族—目标组合：最小教学集和可实现性。
- 27,049 个行族—观察序列组合：全部长度 0、1、2 的有序合法观察序列。它们包含重复一致标签、重复冲突标签及不同观察顺序。
- 208,594 个行族—观察序列—目标组合：完整域识别，包括非空但在域内未观察位置仍有歧义的候选族，以及空幸存族。

最小教学集预言机把“与目标在选定位置相同的行号集合”编码成整数位集合，以单比特递推计算全部投影等价类，再从精确等于目标行号集合的投影中选最小者。它不调用模型过滤函数、不用模型的组合枚举，也不用作者测试的差异集击中判据。过滤预言机以“必须为 0”和“必须为 1”两种位掩码表示全部约束，重叠则直接判定矛盾。

作者原教学检查覆盖三点域全部无重复候选子族；新检查重点覆盖有序、重复且较小的行族。没有把上述各类检查相加冒充独立学习实验数。

### 严格边界：153 个无效输入情形

逐项要求相应的 `TypeError` 或 `ValueError`，涵盖：

- 所有标签入口的 `bool`、浮点数、整数子类、非二元整数
- 空白名、非字符串名、字符串子类、冻结集合子类、元组子类
- 外层容器、行宽、观察形状、未知点、空域观察
- 初始集、目标集、前置条件或增量超出技能宇宙
- 课名重名、域点重名、空增量、模型对象子类

另检查三个冻结数据类实例的普通属性赋值失败。测试断言使用 `unittest`，不会随优化标志消失。还验证非空白 Unicode 字符串合法，而不会擅自增加 ASCII、标识符或去除首尾空格的限制。

审计程序预检中有一次统计常数的笔误，已改正为实际枚举数 208,594；它不是受审模型的错误。以下交付证据来自改正后重新执行的三个模式。

## 真实运行与证据

环境：CPython 3.12.14，Linux x86_64，标准库；`PYTHONHASHSEED=0`，`PYTHONDONTWRITEBYTECODE=1`。仅声明此解释器上的实测结果，没有另行实测 Python 3.10 或其他平台。

在本目录运行：

```sh
python3 audit_model.py
python3 -O audit_model.py
python3 -OO audit_model.py
```

每种模式各运行 4 个审计测试方法，内部枚举规模如上。4 是测试方法数，不是仅检查 4 个输入。

生成三种模式的真实日志和环境记录：

```sh
python3 audit_model.py --record
```

该命令只替换 `logs/audit-normal.log`、`logs/audit-optimized.log`、`logs/audit-double-optimized.log` 和 `logs/audit-environment.json`；退出码非零表示检查失败或运行期间源码改变。它记录解释器路径、版本、命令、优化级别、退出码、运行时间及运行前后源码散列。

## 结论的边界

没有发现缺陷不表示没有缺陷。此次未覆盖无限输入、任意规模课表、所有运行时、恶意绕过冻结对象、资源耗尽、实际教学实验或外部数据。它不验证“最少课数等于最少真实时间”“最小识别集足以让人理解”“正确输出能证明自主发现”，也不验证原信关于发明法排他采用的主张。
