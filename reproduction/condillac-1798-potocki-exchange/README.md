# Condillac-Potocki 1798：有限教学模型

这是一组原创的现代教学练习，对应 1798 年版Œuvres de Condillac第 XXII 卷第 199–202 页的委托与答复，重点是第 202 页。它不复原十八世纪算法，也不把教学主张当成已证实的心理规律。

历史阅读的起点是：先规定目的，使各部分与目的相关；安排短路径，用较易的障碍准备较难的障碍；让学习者仿佛自己形成逻辑；作者还作出关于发明方法的排他性断言，并要求保留修订时间。下面只形式化两个很窄的问题：

1. 已知固定前置条件与技能增量，目标能否到达，最少需要几节课？
2. 已知有限候选函数与无噪声标签，最少哪些例子能唯一确定目标的全域行为？

“容易”“信心”“真正自行发现”和修订工作的质量不在模型中。两模型独立，没有把例子数换算成课时，也没有给学习者估计能力。

## 运行

Python 3.10 及以上；仅用标准库，无安装、网络、随机采样或外部数据。进入本目录后运行：

```sh
python3 demo.py
python3 -m unittest -v test_model
python3 -O -m unittest -v test_model
python3 -OO -m unittest -v test_model
```

要重新生成完整记录，运行 `python3 run_checks.py`。它会替换本目录内 `logs/` 下的运行日志与环境记录；不会修改模型或访问远程服务。
