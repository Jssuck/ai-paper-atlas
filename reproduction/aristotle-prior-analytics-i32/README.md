# I.32：从论证到结构——最小教学复现

这是自有标准库教学程序，不是亚里士多德的程序、自然语言分析器、完整古代逻辑语义或通用证明器。它把本章「先取前提，再取词项」变成一个可检查的有限输入接口，并让形式识别与有限语义检查分开。

## 输入、符号及边界

`Prop(kind, subject, predicate)` 中 A/E/I/O 分别指「所有S是P／没有S是P／有些S是P／有些S不是P」。主项、谓项是已经完成释义的规范字符串；没有自动分词、消歧、同义词识别。大小写不同即不同词项。

语义是固定非空有限论域上的集合：A为包含、E为交为空、I为交非空、O为差非空。词项可以为空，A/E不自动承诺主项存在；`nonempty=('M',)` 是调用者另加的显式约束，不是从全称句偷偷推得。原典的必要后承也不等于这里程序实现了模态逻辑。

`analyze(premises, conclusion)` 只接受恰好两条前提、三个互异词项及两个不同端项。先按目标主项S和谓项P标出两端，再找同时出现于两条前提的第三项M。I格是 M→P、S→M；II格是 P→M、S→M；III格是 M→P、M→S。箭头只标主谓位置，**不将E/I/O改成集合包含**。相反方向模式被明确标为「不属前三格」，不是无效性的判定。主要／次要前提按端项而不是输入次序识别。接口接受各种极性和量词，返回 `shape_only` 绝不承诺是有效式。

`find_countermodel` 遍历论域大小1至 `max_size`（默认3，上限4）、至多四个词项的所有子集赋值。发现满足全部前提与非空约束而不满足目标的赋值，就返回实际反模型；否则只报 `no_countermodel_in_bound`。没有发现反例不等于一般有效性证明；矛盾前提也可能没有反例，须一起看 `premise_models`，不能当作已找到了可实现的材料。`checked`含被存在约束剔除的赋值，`admissible`不含，`premise_models`只计前提真赋值；发现反例时计数在当处停止。

`candidate_completions` 只检验**调用者给出的**候选，标记 `hypothesis_not_fact`；排除与目标或已有前提结构上完全相同的候选。它不自动生成遗漏前提，不确认其真实性、来源、最弱性、唯一性或语义非循环性；同义改写或否定换位后的目标不在简单语法去重保证内。输出还包括形状及有限检验结果，不能把候选视为原文已经说过的话。调用者应另作文本与事实审查。

`implication_chain_rows` 枚举三个存在句H/N/S的8种布尔赋值：H→N且N→S的4行全部满足H→S。这里的变量是整句，不是人物或词项集合。这说明现代命题逻辑后承可成立，不证明原文当下已经给出AEIO两前提，也不能从「有人就有动物」推出「所有人是动物」。

## 本次实际结果

| 演示 | 形式层 | 真实有限结果 |
|---|---|---|
| M⊆P，S⊆M，因此S⊆P | 第一格AAA | 584个赋值；84个前提真赋值；界内无反例 |
| P与M不交，S⊆M，因此S与P不交 | 第二格EAE | 584个赋值；84个前提真赋值；界内无反例 |
| P⊆M，S⊆M，因此S⊆P | 第二格AAA形状 | 1对象反例：M=S={0}，P为空 |
| M⊆P，M⊆S，因此有S是P | 第三格AAI形状 | 所有词项为空即反例 |
| 同上，另加M非空 | 同一第三格形状 | 584个原始赋值、500个满足约束、71个前提真；界内无反例 |

三词项在1、2、3对象论域的赋值数为8、64、512，合计584。表中的无反例结论由文章的一般逐对象证明支持，而不是由584次运行代替证明。

测试还覆盖换序、量词/极性记录、无共同中项、四词项、多余/缺失前提、第四种项位、非空反模型重验、不同见证的两特称失败、两否定失败、重命名、非法输入和逐对象量化参考检查。生产逻辑没有使用会随优化模式消失的Python `assert` 作为输入检查。

## 对I.32的有限对应

1. 先给两个结构化前提，再分词项：对应本章分析顺序，但不会从自然语言替读者找到它们。
2. 同一项位能有有效与无效配置：明确「共同中项／格」不是充分有效条件。
3. 缺前提不是自动补真：候选只是条件化重构，来源与真实性另查。
4. 有必然后承不等于输入已是三段论：命题链和词项模型互不偷换。

未实现实体毁灭例的完整本体论、自然语言省略恢复、古代模态体系或一般三段论判定；这些不在本次复现范围。有限程序只能检查规定模型与接口，不能证明一般数学定理或历史解释的唯一性。
