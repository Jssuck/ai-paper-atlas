# IX.4 原典与交叉引用

- [Heath 英译及注释，1908，卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)：实读印页 387（PDF 第 400 页）。边标按 IX.3、VII.17、VIII.19、VIII.8、VIII.23 排列；正文与 Q.E.D. 之后的译者小写符号提要分开。提要把建立辅助量立方性的引用放到最后，不改变依赖。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=255)：印页 255 底起标题与命题，256 上部续完命题与全部证明；256 的下一个标题才是 IX.5。希文 Γ 对应积 C、Δ 对应辅助量 D。未发现影响此次重构的适用正式勘误；这不是全面校勘。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.9.4.html)：希文有 D 为立方所以 C 为立方及收尾；英语栏在 VIII.8 中项迁移处停止，未给 VIII.23 收尾，不应据此省略最后推理。
- [Joyce](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX4.html)：正文保留最后传递；指数恒等式在 Guide 中。对照 [VII.17](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII17.html)、[VIII.19](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII19.html)、[VIII.8](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII8.html)、[VIII.23](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII23.html)，分别是保比、供见证、迁移、传立方。
- [中文深读](../../papers/ancient/euclid-elements-ix4.zh-CN.md) 的显式比例链、乘积边、具体数字与代码是教学重构。没有公开扫描、全文翻译或第三方程序。
