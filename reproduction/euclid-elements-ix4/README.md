# 《几何原本》IX.4：两个立方数的积

输入 $A=x^3,B=y^3$，构造四项 $(x^3,x^2y,xy^2,y^3)$，再把每项乘以 $A$，得到以 $A^2$ 和 $AB$ 为端点的连比链。已知首端根为 $x^2$，将放大后的第二项除以 $(x^2)^2$ 就得到末端根 $xy$；程序核对第三项与其立方。例：输入 $8,27$，原链 $(8,12,18,27)$，放大后 $(64,96,144,216)$，根为 $6$。

即使 $2\cdot4=8$ 是立方数，给定的两个因子都不符合本命题的前提。输入端点为 $1$ 的情形标记为现代正整数扩展。

在此目录运行，需 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

端点各取 1 至 216，穷举比较预先生成的端点与乘积立方表，另用精确分数按乘率幂核对两条链。这是有限检验，不是一般证明。Notebook 日志为标准库实跑三个代码单元，不是 Jupyter 内核运行。
