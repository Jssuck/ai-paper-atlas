# 《几何原本》VI.6：两边同比与夹角相等

对应[中文深读](../../papers/ancient/euclid-elements-vi6.zh-CN.md)。这里是现代有理坐标教学模型，不是原始尺规步骤的机器复原，也不是一般定理的形式证明。

把 AC 映到 DF，把垂直于 AC 的向量映到垂直于 DF 的向量，长度按同一倍数伸缩，方向可正可反。据此求出两侧的辅助顶点 G。对每个 G，程序分别检查三对无向角、三边长平方的共同伸缩、共同边 DF 下 DG 与 DE 的相等，以及将 DGF 的角转回 DEF 的证书。角签名是点积的符号与余弦平方：前者不能省，否则互补的锐角和钝角会混为一谈。边长非负，故用平方做精确比较无需算平方根；零边与共线三角形不在定义域。

正例中 A=(0,0)、B=(3,0)、C=(0,4)，D=(10,0)、E=(29/2,0)、F=(10,6)。两个 G 是 (29/2,0) 与 (11/2,0)，各自的 DG²、DF²、GF² 为 81/4、36、225/4。一个与 E 重合，另一个在 DF 对侧。负例将 E 改为 (127/10,18/5)，保留两边同比，但夹角的余弦从 0 变成 4/5，EF² 随之变成 261/20。另一负例保留两边和一个非夹角，第三边长平方却分别为 8 和 2。

## 实跑和边界

标准库即可，无需安装。以下在 Python 3.12.14 实际运行，从本目录执行：

```sh
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B replay_notebook.py
```

[普通](normal.log)、[-O](O.log)、[-OO](OO.log) 每次各七项测试。扫掠由四个 AB 向量、三个 AC 向量、四个 DF 方向、三个倍率和两种取向组成，计 288 个构形，其中 144 个输入用反射生成，共核对 576 个辅助点证书。生成器使用有理复数乘法展开式，验证器使用点积和行列式；二者是同一数学变换的两种编码，不是独立的理论证明。

[Notebook](euclid-vi6.ipynb) 的三个代码格使用共享命名空间由标准库依次编译并执行，见[回放日志](notebook-replay.log)。不是 Jupyter 内核运行；Notebook 保存为未执行状态以供读者重跑。有限有理构形不能代表所有实坐标，更不能证明 VI.6。
