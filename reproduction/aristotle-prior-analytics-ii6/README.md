# 《前分析篇》II.6：第二格互证的最小集合检验

这是原创**现代教学重构**，不是古代实验的复现，不是整套亚里士多德逻辑的自动证明器。对照原文：[Jenkinson 英译，Book II Part 6](https://classics.mit.edu/Aristotle/prior.2.ii.html)。原文逐段讨论第二格的全称否定、特称否定结论如何参与互证；程序中的模式名是方便索引的传统名称，不是声称原文使用这些名称。源码、输出和测试均为本项目原创；不收录译本全文。

## 约定与边界

`A(X,Y)` 表示所有 Y 都是 X，即 Y 是 X 的子集；`E(X,Y)` 是不相交，`I(X,Y)` 是交集非空，`O(X,Y)` 是 Y 中存在不属于 X 的元素。参数顺序是谓项在前。全称命题在空主项时真，特称命题要求见证；另跑全部 A、B、C 均非空的子域，不能把后者说成已经覆盖古代存在预设的所有争论。论域 U 非空；`not_b` 是相对于 U 的 B 的补集，不是亚里士多德原文里的第四个独立词项。

反向全称包含是**另加条件**，不是从原全称肯定命题合法换位所得。仅 E 的对换在这个模型里无条件成立。程序不将“负结论加简单换位无法恢复肯定前提”扩大为任意前提、任意逻辑系统都绝不可能证明肯定命题。

## 已检验规则

以 `a,b,c` 表示三个外延，箭头为条件蕴涵。

1. Camestres：`A(a,b) & E(a,c) -> E(b,c)`。
2. Cesare：`E(a,b) & A(a,c) -> E(b,c)`。
3. Baroco：`A(a,b) & O(a,c) -> O(b,c)`。
4. Festino：`E(a,b) & I(a,c) -> O(b,c)`。
5. Camestres 的加强恢复：`A(b,a) & E(b,c) -> E(a,c)`。
6. Cesare 的加强恢复：`A(c,a) & E(b,c) -> E(b,a)`，然后 E 换位得 `E(a,b)`。
7. Baroco 的加强恢复：`A(b,a) & O(b,c) -> O(a,c)`。
8. Festino 的**现代充分条件**：`A(a,U-b) & O(b,c) -> I(a,c)`。覆盖条件 `U-b <= a` 保证同一见证；它不是对 Part 6 末句唯一或最弱的译解。主规则只使用覆盖条件与 O，不把待恢复的肯定命题或原来的 E 塞入前提。另若再配原问题的 E(a,b)，则 a 等于 B 的补集；这不是主规则所需条件。

末句若弱读成 `I(a,U-b)`，则它与 `O(b,c)` 的见证可能不同，恢复失败。非空例：`U={0,1,2}, a={0}, b={1}, c={2}`。a 与补集的见证是0，c 与补集的见证是2，a 与 c 没有交集。即使保留 `E(a,b)` 也无济于事。

## 一般推理为何成立（不是把穷举当证明）

- Camestres 正向：若 x 同属 b、c，b 包含于 a 使 x 同属 a、c，矛盾。加强恢复交换包含方向：若 x 同属 a、c，a 包含于 b 使 x 同属 b、c，矛盾。
- Cesare 正向：c 包含于 a，a 与 b 不交，故 c 与 b 不交。加强恢复用 a 包含于 c，把 a 与 b 的假想交点送入 c 与 b 的空交集。最后用交集交换律，不需新的存在前提。
- Baroco 正向：取 x 属于 c 但不属于 a；b 包含于 a，故 x 不属于 b。恢复则取 x 属于 c 但不属于 b；a 包含于 b，故 x 不属于 a。
- Festino 正向：取 x 同属 a、c，a 与 b 不交使 x 不属 b。覆盖恢复：取 x 属于 c 且不属于 b，覆盖条件使这个**同一个** x 属于 a，因而给出 a 与 c 的交点。独立存在量词不能提供这个传递。

这些是适用于任意非空论域的直接集合论证明，包括无限论域。数值穷举另用于检查实现、定位反例。

## 为什么是255与218：成员型压缩

一个元素相对于 a、b、c 有8种成员型，编码 `4*[x in a]+2*[x in b]+[x in c]`。每种型只保留一个代表；一个非空模型因此对应8种型的一个非空子集，共 `2**8-1=255`。要求三个词项各自非空，排除任一个词项空的型集，容斥得到 `255-3*15+3*3-1=218`。

压缩的一般理由：子集关系失败、交集非空、差集非空都等价于某些成员型出现；相对补集也只取决于同一成员型中的 B 位。压缩不会删除一种已出现的型，也不会增加新型，故保留本程序涉及的每个原子命题及其布尔组合的真值。反过来，每个型子集都能用其型编号作论域实现。因此这对**此处的外延语言**是完整的反例搜索；不保留元素重数、精确基数、词项外谓词、模态或历史语义。一般压缩论证与实现穷举须分开；额外测试只以1至4个带标签元素共4680种赋型核对压缩实现，不能替代一般证明。

`least_countermodel` 按论域大小、再按成员型列表排序，因而保证元素数最小，不保证语言表达最短或反例唯一。任意更小的原模型也可压缩为不更大的型模型，所以这一元素数最小性不限于枚举中的编号表示。

## 文件与运行

仅Python标准库，无随机性，无外部数据或网络。环境见 [environment.txt](environment.txt)。在本目录执行：

```sh
python3 model.py
python3 -O model.py
python3 -OO model.py
python3 -m unittest -v test_model
python3 -O -m unittest -v test_model
python3 -OO -m unittest -v test_model
```

[model.py](model.py) 是语义与穷举；[test_model.py](test_model.py) 包括独立逐元素语义核对、非空计数、全部规则、最小性、不同见证、同见证覆盖、4680种赋型压缩核对与非法输入。运行时校验使用显式异常而非 `assert`，测试框架断言在优化模式仍生效。

真实输出：[normal JSON](logs/run-normal.json)、[-O JSON](logs/run-O.json)、[-OO JSON](logs/run-OO.json)；三者逐字一致。三组测试各10项通过：[normal](logs/test-normal.txt)、[-O](logs/test-O.txt)、[-OO](logs/test-OO.txt)。[命令及退出码](logs/commands.txt) 记录本次重跑，退出码均0。耗时仅作真实日志，不作性能结论。这里未声称完整复现古典逻辑、证明史解释的唯一性或以小实验证明一般定理。
