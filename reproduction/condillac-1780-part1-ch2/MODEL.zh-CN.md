# 一般模型、证明与检验范围

## 1. 文本命题与现代假设分开

原章没有下述方程、图论术语、算法、代价函数或实验。这里从 1798 年实际阅读本 I.II 的三个结构出发构造类比：19 页依次比较主要对象及从属对象的位置；21–22 页分解以便重组；23–24 页共同呈现与逐项清楚辨明之间的区别。

数学结果只在明确的现代假设下成立。特别是，原文的“主要对象”“最近”不会自动计算：教程手动指定 A、B 为主要对象，并事先给出正确对象身份与坐标轴。不会从“吸引目光”推导一般最优算法，也不把原章标题中的“唯一方法”当成已经证明的现代定理。

## 2. 数据与语义

设 $`U`$ 是非空有限对象清单，$`k`$ 是正整数维数，$`S\subseteq U`$ 是已登记的对象。$`U`$ 的存在与完整性由练习提供，不是模型发现的。一个对象记录只说明其身份已登记，不带位置。

每条关系 $`e=(u,v,d)`$ 的端点 $`u,v`$ 必须属于 $`S`$，$`d\in\mathbb{Z}^k`$。它表示：

```math
x_v-x_u=d
```

其中 $`x_v`$ 是对象 $`v`$ 在固定轴向和尺度下的位置向量。边可反向读取为 $`(v,u,-d)`$。自环和同端点的多条边都允许：零偏移自环无新信息，非零自环矛盾；不同偏移的平行边也可能矛盾。向量为精确整数，不接受布尔、浮点、缺失维度或自动类型转换。

对已登记对象的可行解集定义为：

```math
F(S,E)=\{x:S\to\mathbb{Z}^k:\forall (u,v,d)\in E,\ x_v-x_u=d\}
```

图的对象数、关系数有限；**所有可能平移构成的解集未必有限**。不要把有限图与有限解集混为一谈。未登记对象 $`U\setminus S`$ 不会被程序偷偷补成零坐标；其位置不在输出中。

### 三类覆盖

- 对象覆盖：$`|S|/|U|`$。这依赖完整清单 $`U`$ 的前提。
- 直接关系覆盖：实际记录过的不同无序对象对数，除以 $`\binom{|U|}{2}`$。同一对象对的重复、反向记录都只计一对，自环不计。
- 可识别关系覆盖：在非空解集 $`F`$ 中，其位移在所有解里相同的不同对象对数，除以 $`\binom{|U|}{2}`$。缺失对象不算可识别。

当只有一个对象时，分母为零，程序报告计数 0 和 0，而不计算 $`0/0`$。约束不一致时，程序报告可识别对数为 `null`，并拒绝位置查询，不利用“空解集上全称命题真”来伪称什么都知道。

## 3. 求解：分解记录、重组关系

1. 建立关系的双向邻接表，反向边的向量取负。
2. 按清单顺序取尚未访问的已登记对象为根，把它暂放在零向量。
3. 用队列沿边传播相对位置。首次抵达 $`v`$ 时，令 $`q_v=q_u+d`$。
4. 完成所有分量的传播后，逐条核对原始关系 $`q_v-q_u=d`$。
5. 若任何关系不满足，输出不一致及冲突见证；**不输出一幅似乎成立的图**。若都满足，输出每个分量的相对坐标。

邻接表按对象清单次序和偏移排序，以便相同关系集的诊断可复现。一个报告为冲突的边，表示它与当前生成树赋值不合，**并不证明那条边本身就是错误来源**。例如 A→D=8 与 A→B=6、B→D=3 不合；遍历若先用了 A→D，报告可能标出 B→D 的不合。没有外部真值，无法据此分派责任。

如果把整数算术和对象标识操作暂按单位成本计，并固定维数，图上的队列传播及逐边核验核心为 $`O(|S|+|E|)`$。实际函数还遍历完整清单 $`U`$ 来建立顺序、选择根及生成输出，并排序邻接表、分量内对象和冲突条目；保守总上界为 $`O(|U|+(|S|+|E|)\log(|S|+|E|+1))`$。维数变化时向量成本随 $`k`$ 增加；任意大整数的真实位运算成本也不能视作常数。反复查询和重新构建整个不可变记录还会有额外开销；本包未声称优化了增量性能或大规模吞吐量。

## 4. 一致性的充要条件

**性质一：存在解，当且仅当每条闭合游走上的有向偏移和为零。**

必要性：沿闭合游走累加 $`x_v-x_u`$，中间项抵消，起点和终点相同，和只能是零。

充分性：在每个连通分量选择根，令 $`q_v`$ 为从根到 $`v`$ 的路径偏移和。若选择另一条路径，两条路径合成的闭合游走偏移和为零，所以 $`q_v`$ 与选路无关。对任一边 $`u\to v`$，将到 $`u`$ 的路径再接此边，得到 $`q_v=q_u+d`$，因此 $`q`$ 满足全部方程。

程序无需穷举所有闭合游走。它只用一棵生成树给出候选 $`q`$，再核对每一条边；通过即提供一个具体解，不通过即证明至少一条约束与已传播的路径冲突。

这只证明记录自洽，不证明对象身份与位移来自真实世界。

## 5. 解的全部自由度与关系可识别性

**性质二：若有 $`c`$ 个已登记对象的连通分量且记录一致，那么每个解都且仅都形如下式。** 这里 $`S_j`$ 表示第 $`j`$ 个分量。

```math
x_v=q_v+t_j,\qquad v\in S_j,\qquad t_j\in\mathbb{Z}^k
```

证明：给某个分量所有对象加同一个向量不会改变任何边差分，所以这样构造的一定是解。反过来，设 $`x`$ 与 $`q`$ 都是解。任一边两端有 $`x_v-q_v=x_u-q_u`$；沿路径传播，整个分量的差都是同一个 $`t_j`$。没有别的自由变化。

因此程序报告 $`kc`$ 个整数平移参数。它们只描述 $`S`$ 上的解，不含未登记对象的任意未知位置。一个连通图仍有 $`k`$ 个整体平移参数；输出根为零是**坐标规范**，不是新增观察。

**性质三：一致前提下，两个已登记对象的相对位置可识别，当且仅当它们在同一个连通分量。**

同分量时，$`t_j`$ 相消，$`x_v-x_u=q_v-q_u`$。不同分量时，只平移其中一个分量就能改变二者位移，而且仍满足全部已录边。

推论：若 $`U`$ 的每个对象都已登记，一棵包含全部对象的生成树，只用 $`|U|-1`$ 条边，已经足以识别所有对象对的相对位移。额外边可以核验一致性，但不是每一对都必须直接观察。此推论只适用于本模型的精确、正确绑定、固定坐标系假设。

## 6. 重复与次序

给定关系的解集等于各条方程解集的交集。集合交满足交换律和幂等律：

```math
F(S,\pi(E))=F(S,E),\qquad F(S,E\cup\{e,e\})=F(S,E\cup\{e\})
```

其中 $`\pi`$ 是任意输入次序排列，第二式表达重复同一约束不会改变解集。

所以，只改变同一批精确关系的输入顺序，不改变最终解集。重复同一个对象名也不增加对象覆盖。重复相同记录没有新信息，**不等于人类再次观看永远不能学到新东西**：真实第二次观看可能抽出先前未辨明的关系，那在本模型里会是新的输入。

为了演示中途差异，教程另外定义：

令 $`L_t`$ 为第 $`t`$ 条关系后，已登记但还未连到固定参照 A 的对象数。然后定义：

```math
J=\sum_{t=1}^{|E|}L_t
```

比较排列时预先登记全部五个对象，只改变关系次序。这个分数表示“某张账本尚不能相对 A 定位的对象数随步骤累加”。它不测量时间、记忆、视觉注意、工作量或效用，也不用于证明原文主张普遍最优。选另一个参照、给查询不同权重，问题就会改变。

教程的 24 个排列最终完全相同，$`J`$ 的可能值为 6、7、8、9、10、11。A→B 先行的展示顺序得到 6，但别的顺序也能得到 6；例如 A→C、A→B、B→D、B→E。主要对象先行不是这里唯一最低分的顺序。

## 7. 同时保存与逐次读取

一次重组的结果保存全部 $`q`$ 与分量结构；`difference(u,v)` 每次读取一个对象对的关系。这个设计仅示范“整体可供关系比较”与“当前辨明哪一部分”可以区分。

它既没有测量人脑是否串行，也没有把第 20–22 页的共同呈现否定掉。第 23–24 页对“并不同样清楚”和整体核对的限定，反而要求读者避免把共同呈现翻译成无限注意或一次意识到所有细节。

## 8. 有限 oracle 为什么足够覆盖所列测试族

`exhaustive.py` 与 `model.py` 的判断路径不同。生产代码沿图传播；oracle 直接枚举坐标，逐条代入原方程。它不调用生产的向量辅助函数、路径求和或一致性判定。这里的“独立”是**算法路径独立**，不是独立作者评审；外部复核如有进行，应另列。

仅检验三对象 A、B、C，每个无序对象对至多有一个规定方向的边：

1. 一维：缺边，或偏移为 −2、−1、0、1、2，共 $`6^3=216`$ 个图。令 $`x_A=0`$，枚举 $`x_B,x_C\in\{-4,-3,\ldots,4\}`$，每图 $`9^2=81`$ 个赋值。
2. 二维：缺边，或偏移属于 $`\{-1,0,1\}^2`$，共 $`10^3=1000`$ 个图。令 $`x_A=(0,0)`$，枚举 $`x_B,x_C\in\{-2,-1,0,1,2\}^2`$，每图 $`25^2=625`$ 个赋值。

存在性界限：三个顶点的简单路径至多两条边。一维每边绝对值至多 2，根相对位置绝对值至多 4；二维每个坐标每边绝对值至多 1，根相对位置每个坐标绝对值至多 2。若有解，把每个分量根移到 0，便在上述框中得到一个解。因此此有限 oracle 不会因框太小而把所列图误判成无解。

跨分量可变性界限：三对象图若不连通，每个非单点分量至多有两个对象，所需一维跨度至多 2、二维每坐标跨度至多 1。上述框中留有至少一种非零平移余量。所以真正不固定的跨分量位移，枚举里也能找到至少两个不同值，不会因边界把它误当成固定。

对每个图，程序比较：有无解；框内每一个赋值是否既满足方程又恰好属于求解器的分量平移解族；每个对象对是否固定及其值；全部边反向后的同等结果。非零自环、重复边、矛盾平行边、缺对象和多种非法输入由单元测试补充，不冒充已包含在上述简单图穷举族中。

本次共有 430 个一致图、786 个不一致图，1,290 个一致图内的对象对查询，1,216 次整图反向检验。它们是代码证据；第 4–6 节的一般证明才说明任意有限图在假设下的性质。

核验代码使用显式 `require` 函数，不依赖会被 `python -O` 删除的裸 `assert`。统一运行脚本把自身优化级别传给全部子进程；常规和 `-O` 模式分别留下真实日志。两次运行覆盖同样的输入图，不把相同输入的重跑翻倍计成独立图。
