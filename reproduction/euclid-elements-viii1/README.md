# VIII.1：互素端点保证等比数列最小

现代正整数教学重构，不是古代实跑或一般定理的计算证明。程序要求至少两项、每个给定数大于 1，并先检查相邻后项与前项的精确比值一致。按 VII.33 的现代最大公度模型，若有严格较小的同比数列，则所有给定项都是对应最小项的同一整数倍，倍数大于 1。这会量度两个端点，违背互素前提。程序分别输出端点公度、最小同比数列和是否满足 VIII.1 的互素前提。

(8,12,18,27) 的相邻后项与前项比为 3/2，端点互素，找不到更小的正整数等比数列。(16,24,36,54) 的比相同但端点不互素，因子 2 可整列消去；不是定理反例。(6,10,15) 的相邻比不同，即便整体公度为 1，也不是此命题的输入。反向数列与常数列是现代程序的另行检查；例如 (5,5,5) 无互素端点，现代含单位的最小数列为 (1,1,1)。

有限独立搜索从首项 1 开始，利用 Fraction 的精确幂生成整列，找到首个全是正整数的候选。原输入是统一的有限上界。测试另外枚举端点公因数，不仅依赖待测的 gcd 调用。
