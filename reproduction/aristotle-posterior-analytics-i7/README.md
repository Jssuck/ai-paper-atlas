# 《后分析篇》I.7：有类型的推导与精确桥梁

这是原创的**现代教学重构**，不是古代科学的实现，不复现现实光学或几何测量，也不把程序接受当作亚里士多德意义的科学知识。对应[中文深读](../../papers/ancient/aristotle-posterior-analytics-i7.zh-CN.md)。原文依据为[MIT 的 Mure 英译 Book I，Part 7](https://classics.mit.edu/Aristotle/posterior.1.i.html)。原文限制跨属证明，但明确保留从属科学情形；这里通过显式声明模拟“不能无说明地搬运”的要求，而非断言本章提出了类型系统。

## 1. 模型范围与接口

Atom由领域名和谓词名组成。同叫relation的算术命题和几何命题不是同一个原子命题。这里没有对象变量、量词、亚里士多德的全部三段论或本质因果判据，只实现有限正命题与单前提规则。

- `Rule(source, target, kind, bridge_id)`：一种单前提条件规则。
- `local`：源、目标必须同领域，不许附带桥ID。
- `common`：共同公理的**已实例化规则**，仍须同领域；同名公理不自动消去对象类型。
- `bridge`：须跨领域，而且登记表中存在名称、源原子和目标原子均完全匹配的`Bridge`。桥的方向与属性不可从名字猜测，也不自动获得逆向或其他属性映射。
- `Step(rule, premise_index)`：引用事实或先前步骤的位置。负索引、布尔索引、前向引用均拒绝。
- `verify`：依次检查引用、规则适用范围，最后确认目标在已知集合中。
- `closure`：只使用被当前政策接受的规则，迭代到有限不动点。

输入事实、规则含义、共同公理的真实性和桥梁许可全部是外部假设，程序不发现它们。这里的“许可”是教学模型内部的声明，不是现实中的授权或古代科学从属关系的证成。

## 2. 具体推导和反例

设g是geometry领域的relation，o是optics领域的relation。登记精确桥`geometry_to_optics: g → o`，已给g，则步骤引用g并使用此桥，可以得到o。把g、o换成真实光学命题，需要另行证明几何结构与光学对象的联系；本实验没有做这件事。

删掉桥声明而保留同一规则，证书失败。只保留一个叫relation的算术事实，也无法利用叫common的规则跨到几何。将桥方向反转，或者目标改成beautiful，均失败。

同领域的一条`p → q`在给定p时可以通过。检查器并不证明此规则为真。尤其，直接把名为false_external_fact的命题放进事实表，并以它为目标，`verify`返回True。这一故意保留的反例展示：政策合规不等于内容真实，更不等于本质解释。

## 3. 一般性质及证明边界

**相对保真性。** 若初始事实在某一布尔赋值中均真，并且所有实际使用的已接受规则作为材料蕴涵都真，则任何通过证书的推导结果在该赋值中真。证明按步骤归纳：初始项由假设成立；每一步的引用指向此前已知的真源命题，规则蕴涵由假设成立，因此目标真。类型政策只是额外的可用性条件，并不为规则真实性提供证明。

**有限闭包。** 已知集合单调增长，原子有限，所以至多增加原子总数次后稳定。实际循环可能多扫描一次以检测不变。正单前提规则的闭包等于相对这些规则与事实的布尔逻辑后承：前向方向由上面的保真性；反向方向，把闭包内命题设真、其他设假，此赋值满足事实及所有规则，因而任何闭包外命题都有反模型。这个简短证明不依赖下面枚举的规模。

**无桥隔离。** 只有local/common规则时，从某领域事实出发，每步仍在该领域，按路径长度归纳成立。多领域初始事实允许在各自领域内推导，不意味着领域被合并。登记桥后，检查器只接受规定的转换；多个桥可能串联，程序没有额外证明该串联在某个现实科学中适当。

模型没有把领域排序成层级，没有验证从属关系的非循环性，没有自动发现同属/部分同属，也不表达真正的科学解释。这些是明确省略，而不是实验结论。

## 4. 真实实跑与可重跑命令

Python标准库，无第三方依赖。安装软件、下载原书或获取密钥都不需要。

```bash
cd reproduction/aristotle-posterior-analytics-i7
bash run.sh
```

`run.sh`在本目录生成日志和results.json。它分别执行`python3 -m unittest -v test_model`、`python3 -O -m unittest -v test_model`、`python3 -OO -m unittest -v test_model`及各模式下的model.py。所有断言使用unittest断言方法，不因优化模式而消失；model.py的失败出口使用显式条件。

## 5. 教学练习

1. g与o名字相同，为什么不能直接合并？答：领域是原子身份的一部分；同拼写不证明对象和谓词关系相同。
2. g→o的桥为什么不包含o→g？答：映射方向是声明的一部分；逆关系需要独立理由和声明。
3. 为何给出错误事实也可能通过？答：检查器验证的是相对输入的推导政策；真实初始事实是保真定理的前提，不是程序结论。
4. 真值oracle与闭包相同能证明全部正确吗？答：不能；这里只覆盖有限规则族，而且两者共享政策过滤函数。
5. 无初始事实的p→q→p循环得到什么？答：空闭包，循环自身不创造事实。
6. 应如何加强桥梁检查？答：可附映射的语义证明或审查证书，但这需要外部数学与科学证据；不能仅增加一个approved布尔位就宣布获得了因果知识。
