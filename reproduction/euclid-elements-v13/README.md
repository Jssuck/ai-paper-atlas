## 怎样读输出

- 探针 (m,n) 是任意一对正整数。每次比较 m·前项 与 n·后项，输出 −1、0 或 +1。严格大于的见证要求较大比给 +1，较小比给 0 或 −1。三个结果的顺序是第一比、中间比、末比。
- 对 3:2、6:4、2:2，探针 (1,1) 返回 (+1,+1,0)，(4,5) 返回 (+1,+1,−1)。严格方向不能反置；若较大比只给等号，例如 (2,3)，也不是见证。
- 有界搜索按 m 从小到大、再按 n 从小到大。对 102:100 与 101:100，上限 20 没找到，上限 60 首次找到 (51,52)。这个“首次”只指所限定的遍历顺序，不声称有唯一或全局最小的见证。
- 有理数精确法以较小比化简后的分母作为 m、分子作为 n，令它恰好取等号，较大比便取得严格大于。本例得到 (100,101)。有界搜索中的 None 仅表示窗口中没找到，不同于精确法在本数值模型中能判定两比不具有指定严格次序。一般几何量可能没有这样的有理端点。
- 三种解释器模式各通过 10 项测试。以 16 个有序正整数比构成 4,096 个有序三比组合，其中 512 个的前两比相等；每个合资格组合用 16 个探针，进行 8,192 次验证，其中传递 1,108 个真实见证。测试用较小商 ≤ n/m < 较大商另算预期。无训练数据、基线或性能主张，有限核验不替代原证明。
