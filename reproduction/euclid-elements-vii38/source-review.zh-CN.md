# VII.38 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.38.html)、Heath 1908 卷 II 印刷页 342–343（扫描物理页 355–356，图在 342，结论和评注在 343）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=224) 印刷页 224–225，以及 [Joyce VII.38](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII38.html)。

Α、Β、Γ、Δ 对应 A、B、C、D。A 是全数，B 是 A 实际具有的部分，C 是由该部分的分数名称指定的数，D 是单位。原文不是由 B 任意小于 A 推出 C 整除 A；前提已是 B 为 A 的 C 分之一。D 是 C 的同名部分，于是 D 量 C 的次数等于 B 量 A 的次数。由 [VII.15](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII15.html) 交替，得 D 量 B 的次数等于 C 量 A 的次数，故 C 量尽 A。现代记号可写作 B=A/C 且 B 为整数，所以 C 整除 A；这只是表达古证明的角色，不是将分数名称与部分大小混同。

希文在介绍 C 处括出 [ἀριθμός]，Fitzpatrick 英译也括出 [number]；这不改变 C 是分数名称所指的数。Joyce 证明比较同名部分的一句有介词疏漏，按希文和两个印本应读作 B 在 A 中所占部分，和 D 在 C 中所占部分相同。Clay 英栏止于 VII.15 交替后的等次数关系，希文、Heath、Fitzpatrick、Joyce 均明写 C 量尽 A 的结论。现代可允许部分 B 的大小为单位 1；但古证称 B 为数，不宜声称该边界已在原文显式处理。

这是 [VII.37](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII37.html) 的逆向，但证明独立调用 VII.15。[VII.39](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII39.html) 在最小性反证中直接用 VII.38：假设更小的 H 也具有同样三个命名部分，则三个对应的数都量尽 H，与已构造的最小公倍数矛盾。VII.37 则用于相反方向，先保证构造出的数确有这些部分。
