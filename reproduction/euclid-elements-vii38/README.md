# VII.38：从命名的一份恢复量度

现代整数教学重构，不是古代实跑或一般定理的计算证明。给定整体 A、给定的 B 以及份数名称 C；检查 C 个 B 的和恰为 A，亦即 B 是 A 的 C 分之一。沿 VII.15，将分组换成每块含 C 个单位，于是单位量度 B 的次数恰等于 C 量度 A 的次数。程序显示两种分割的切点和次数，测试另枚举离散位置的等长块来核对。

例如 (12,4,3) 先分为三块 4，再分为四块 3；单位量度 4 恰四次，3 也量度 12 四次。(14,4,3) 不满足命名份；(12,8,3) 的 8 是 12 的三分之二，而非三分之一。默认三个给定数都须大于 1；现代开关可单独检验单位或一份就是整体的情形。
