# VIII.6：首项不能量度第二项

现代整数教学重构，不是古代实跑记录或一般定理的计算证明。以正整数的恒定后项／前项比 v/u（已约分）表示链。若首项不量度第二项，u>1。任意向后的 k 步仍有约分分母 u 的 k 次幂；所以现代模型对任意向前数对都得出不可整除。程序保留命题前提是否成立，并把全数对结论标为同一模型的检查，而非声称古文列举这些数对。

(24,12,6,3) 的增长比为 1/2：此前项不能量度后项，但后项都可反向量度前项。(8,12,18,27) 的增长比 3/2，同样无向前量度。(5,15,45,135) 增长比为整数 3，前提不成立，向前确实可整除。默认给定数大于 1，常数链与含单位的链仅在现代模式检验。至少要有三项，且相邻比必须一致。
