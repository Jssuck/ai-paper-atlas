# 《几何原本》X.23：从中项线段传递中项性质

用参考长度 `u>0` 归一化，输入 `q=(A/u)^4`、`k=B²/A²` 和公共底边平方 `b=(CD/u)^2`。三者均是精确正有理数，且 `q` 不是有理平方。`transfer(q,k,b)` 输出 `(B/u)^4=k²q`、两宽 `ED,DF` 的相对平方 `q/b,k²q/b`、以及宽比 `ED/DF=1/k`。面积关系可用相对面积的平方核验，无需近似根式。因为 `k²` 为有理平方，`k²q` 与 `q` 同平方类别，故 `B` 同为中项。

命题正文要求 `B,A` 长度可公度，在模型里表现为 `k` 自身是有理平方；推论允许任意正有理 `k`，包括仅平方可公度的情形。代码分别报告正文前提是否满足；`k=4` 满足，`k=2` 仅由推论覆盖。非中项对照 `q=9/16` 被拒；模型不面向任意实数，也不模拟尺规作图。

独立基线将既约分数的分子与分母相乘再试除平方因子，比较剩余的平方自由整数，不调用整数开根。对各分子、分母均在 1–6 的 46,656 组有序代表（不去重），8,064 组满足正文前提，28,224 组只满足推论的较宽前提，10,368 组因 `q` 是平方而被拒。有限校验不代替一般性证明。
