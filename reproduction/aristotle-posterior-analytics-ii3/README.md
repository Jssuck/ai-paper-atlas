# 《后分析篇》II.3：最小有限教学核验

对应完整90a35–91a11；[正文](../../papers/ancient/aristotle-posterior-analytics-ii3.zh-CN.md)。仅原创现代教学模型，不声称复现古代科学或认证本质。集合中的整数只是匿名对象，不是原文数据。

## 模型与原文关联

- **90b34–38，组合不等于互谓**：把合取描述的外延记为两个集合的交集，只演示两成分不必互相包含。作者对定义统一性的哲学问题没有被集合模型解决。n点共有4^n对集合；A⊆B与B⊆A各有3^n对，交集是A=B的2^n对，因此两包含皆失败为4^n−2·3^n+2^n。n=3时64对中18对。算例A={0,1}、B={1,2}的组合为{1}，两个方向均失败。
- **91a1–6，全称向子类继承**：若S⊆T且T⊆P，则S⊆P。代码检查512组三点集合；不自动把属性换成定义。本例只演示传递逻辑，不重新证明欧氏三角形定理，不声称知道三角形本质。
- **90b23–27，证明须有根据**：边由前提指向结论。非空有限有向无环图必有无前提节点：若每点都有前驱，从任一点反复选前驱，由有限性必重复一点形成环，矛盾。这是一般数学论证；穷举只是实现核查。无自环三节点图共64个，25个无环，39个有环，27个无根（均有环）；不是所有有环图都无根。根只是相对该图没有前驱，**不是程序认证为真实定义或不可证明真理**。
- **90b1–3、91a7–11，目标区分**：`Goal`区分“定义”与“属性”；完全相同字符串换一个问题类型仍不匹配。这是现代防误用政策，不是对作者“不相容”的证明，匹配成功也不认证任何知识。II.3处于提出疑难阶段，不能由此断言后续不存在定义和证明的联系。

空集合和空图显式保留：空主项下全称包含可以为真，但不提供实际对象存在；空图没有根，不违背“非空有限DAG必有根”。自环、双向环、未知节点均测试拒绝。对图算法另用所有顶点排列作为独立oracle，避免仅用算法测试自身。
