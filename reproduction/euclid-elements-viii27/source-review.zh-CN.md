# VIII.27 原典与链接核对

- [Heath 1908 卷 II](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf) 印页 382 下部（PDF 页 395），同页完整题头、八字母线段图与结语。上方小写式简注属于 VIII.26，不归入 VIII.27。VIII.27 取中项处标 VIII.19，取最小四项处标 VII.33 或 VIII.2，立方端点处标 VIII.2 推论。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=251) 印页 251 后半，希文与英译完整，期望项数等于原链的四个位置。希文 Γ、Δ 与 Ε、Ζ、Η、Θ，对应英文 C、D 与 E、F、G、H；参考标记是 8.19、8.2、8.2 推论。对读范围内未识别适用正式勘误；不声称穷尽版本。
- [Clay 希英网页](https://www.claymath.org/library/historical/euclid/files/elem.8.27.html) 的英译止于最小组两端为立方，最后的比值回接与证明结束仍见希文；[Joyce](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII27.html) 全句完整，编号与 Heath 同向。
- [VIII.19](https://www.claymath.org/library/historical/euclid/files/elem.8.19.html) 交付两个整数中项；[VII.33](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII33.html) 是同比分量最小组的通用构造；[VIII.2](https://www.claymath.org/library/historical/euclid/files/elem.8.2.html) 在给定相邻比下形成最小等比链，其推论处理四项链的立方端点。主张只限 VIII.27，背景命题不在本轮计为新发表。
- [深读正文](../../papers/ancient/euclid-elements-viii27.zh-CN.md) 的逐边替换、互质证明、逆向例、Notebook 与实验是现代解释。无底本扫描或全文翻译随附。
