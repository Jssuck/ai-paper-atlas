# VII.34：构造两个数的最小公倍数

现代整数教学重构，不是历史实跑记录或一般命题的计算证明。输入 A、B 均为大于 1 的整数。互素时，A:B 已是最小比，构造 A×B；有公度时，先得到同比最小对 x:y，构造 A×y=B×x。程序用最大公度找 x、y，不宣称原证明以现代算法写成。若另有公倍数 H，则 H/B:H/A 与原比相同；这些次数必须是 x、y 的同一正整数倍。因此 H 不可能严格小于构造值。

(12,18) 的最小同比对是 (2,3)，构造 36；72 的对应整除次数为 (4,6)，是两倍。(8,15) 互素，构造 120。完全相等和整除嵌套可在现代单位计数模型中得到 (12,12)→12、(6,18)→18；这不把单位当作古文给定的「数」。
