# II.18：从假结论向假前提回溯的最小教学模型

[中文深读](../../papers/ancient/aristotle-prior-analytics-ii18.zh-CN.md) · [来源台账](../../papers/ancient/aristotle-prior-analytics-ii18.sources.zh-CN.md) · [独立数学代码审查](../../papers/ancient/aristotle-prior-analytics-ii18.technical-review.zh-CN.md)

## 原文与重构的边界

实际阅读材料：Owen 1853 印221章XVIII及其注2–3；[Jenkinson Book II](https://en.wikisource.org/wiki/The_Works_of_Aristotle/Prior_Analytics/Book_II)章18。原文给出两前提和复合论证两种情形。本程序采用原文的七个命题标签，但把依赖分配成 D、E 推 A；F、G 推 B；A、B 推 C，是显式的现代二叉教学展开。A等在这里是命题标签，不是三段论中的类项。

程序不读取事实世界，不判断一个论证是否在所有解释下有效，也不寻找唯一心理、历史或时间上的“首错”。使用者必须另行核实推理规则有效、输入真假可靠。本模型只检验每个具体赋值里，目标祖先步骤有没有“前提全真而结论假”。这个必要条件不能认证普遍有效性。目标无关分支不会当作目标的错误来源；图结构本身仍整体检查无环。

## 内容和运行

Python 3 标准库，无第三方依赖。运行：

```sh
sh run.sh
```

- `diagnose.py`：有限无环图校验，具体赋值局部条件核查，假父路径枚举，128赋值及四个例子。
- `test_diagnose.py`：15项单元测试，含多源、共享DAG、无效末步、真结论假前提、缺失值/循环/重复输出等。
- `results/environment.txt`：实际Python与平台信息。
- `results/tests-normal.log`、`tests-O.log`、`tests-OO.log`：三次真实测试输出。
- `results/output-normal.json`、`output-O.json`、`output-OO.json`：完整实际记录；三文件逐字一致。
- `SHA256SUMS`：源码、运行脚本及结果文件校验值。校验命令 `sha256sum -c SHA256SUMS`。

测试使用unittest，不依赖会被优化模式删除的裸assert。记录不包含主机名、私人路径或账号信息。

## 实跑结果

| 项目 | 数量 |
|---|---:|
| 七命题全部真值赋值 | 128 |
| 每个相关步骤符合具体赋值保真条件 | 82 |
| 其中C为假 | 33 |
| 这33个中能回溯至少一个假叶 | 33 |
| 假C且有多个可回溯假叶 | 17 |
| 满足局部条件、真C但D/E/F/G至少一个假 | 48 |

这些数字只描述该固定图，不是古代定理的验证次数，也不代表全部三段论分类。程序拒绝把局部条件失败的情况归咎于假前提。

四个教学例：

1. A、C、D假，其余真：回溯 C→A→D。
2. A、B、C、D、F假，其余真：回溯 C→A→D 和 C→B→F，不能挑一个声称是唯一来源。
3. 仅D假：C仍可真；假前提不强迫结论假。
4. 仅C假：末步前提A、B都真，局部保真条件失败；所有叶仍真，说明不能把无效推导纳入有效推导的回溯定理。

## 为什么一般论证还需要证明

在有限无环依赖图中，若目标假且每个相关步骤不把全真前提变成假结论，那么假内部节点必有假父节点。重复向父移动，由有限无环性必终止于叶；该叶是假。这是一般下降论证，不是穷举128个赋值的归纳猜想。图可有共享父节点；不同路径也可能抵达同一叶，程序分开记录路径和去重叶集合。

边界：循环会破坏此终止理由，缺失前提会使诊断不完整，错误真假标注会使结果不可靠；“找到一个假叶”不等于改变该叶便修复所有路径，更不是现实因果证明。原文没有给出本程序的API、路径枚举算法或固定128赋值实验。
