# 《几何原本》X.21：无理矩形面积与中项线

令 `u>0` 为参考长度，输入两边的平方坐标 `a,b`：实际边长是 `u√a,u√b`，其中 `a,b` 均为正有理数。函数 `classify(a,b)` 分别检查 `a/b` 和 `ab` 是否为有理数的平方，判断两边是否长度可公度，以及矩形面积是否与参考平方可公度。相对面积的标准根式为 `c√d`（`d` 为正平方自由整数）；等面积正方形的边长为 `u·(ab)^(1/4)`。代码保存这一正四次根的底数，不进行浮点近似。等面积关系可精确核对：矩形相对面积的平方是 `c²d=ab`，正方形边长相对 `u` 的四次幂也是 `ab`。

例：`(2,3)` 给出面积 `√6·u²` 和等面积正方形边 `6^(1/4)·u`，两边仅平方可公度，适用 X.21。`(2,8)` 的两边长度可公度、相对面积为 4，作为前提之外的对照；`(2/3,8/5)` 的相对面积为 `(4/15)√15`。区分相对参考平方的面积有理性和长度的有理性。模型不是任意实数或尺规判定器；标准根式以朴素试除生成，不是高效的大整数算法。

独立基线从整数 `1..8` 枚举所有有理平方数并作集合查找，不调用整数开根。原始输入的各分子分母均在 `1..8`，故两个被测分数约分后两项均不超过 64，有理平方根的既约两项均不超过 8。全部 4,096 个有序输入代表（未去重）中，456 个为长度可公度且面积有理，3,640 个仅平方可公度且面积无理。有限校验不能代替一般性证明。
