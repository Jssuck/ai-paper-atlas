# I.33 数学与代码独立审核

## 审核结论与范围

在下列绑定版本上，未发现阻止本教学包发布的数学或实现错误。审核对象是现代外延教学重构及受限证书检查器；此结论不是对古代原典唯一语义、自然语言消歧、所有三段论或所有软件输入的认证。来源及译文判定另见[来源审核](../../papers/ancient/aristotle-prior-analytics-i33.source-audit.zh-CN.md)。

审核并非仅重复作者测试：另写[独立脚本](independent_audit.py)，使用逐对象的布尔成员表与逐行蕴涵判定，不复用作者的`powerset`或子集运算实现；再用独立规则生成器覆盖三种命题类型和三个项名的全部证书组合。

## 一般证明与反模型

- 全称链：任取S中的对象，经S⊆M和M⊆P到P；任意性给全称结论。S为空仍成立，但没有获得存在结论。
- 单称实例化：同一个对象c由小前提进入M，大前提覆盖所有M成员，因此到P。不能以另一个特称见证替代c。
- 严格同一：固定解释下b=c时，对同一个谓词的成员真值相同。古例不能被硬译成严格身份同一之后的真前提假结论。
- 两元素反例及其一元素不可能性推导正确；正文关于全称大前提与特称小前提的共同见证证明正确。后一个有效式不在代码支持片段内，拒绝不等于无效。
- 角色的承载关系不是对象同一；时间/面向变化应保留。正文的两时刻与两情境例仅为明确的教学假设，不被称为原典唯一解释或经验实测。
- 20项练习答案已逐项核对；其中空类、存在见证、身份、可能/实际、有限实验的边界均与定义一致。

## 审核建议与修订核验

初审要求正文直说非空域/空域边界、接口谓项先的顺序，以及仅支持两式而拒绝不等于逻辑无效。最终稿已补齐，并与源代码及README一致。没有为凑通过修改数学结论或原始结果。

`Context`是调用者提供的标签，不证明输入真正共享时间或意义；`evaluate`要求调用者给出该上下文的解释，不自行解决跨上下文匹配。名字的类解释与个体解释分开；缺名字报错，不默造空类。代码没有同一性证明检查器；身份部分是明确的有限语义枚举。受限规则检查只验证形状，不验证现实前提真。
