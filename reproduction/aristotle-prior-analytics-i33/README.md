# I.33：全称覆盖与限定范围——最小教学核验

这套 Python 标准库代码是原创教学重构，不是古代文本的可执行翻译。它将本章关于“属于”和“属于每一个”的警告分解为可检查的三个层次：量词、项位、时间/面向上下文。它不推断人名的意义，不验证古代人物命运，不宣称解决 Aristomenes 或 Miccalus 例子的唯一解释。

## 文件与运行

- [model.py](model.py)：受限证书检查器、外延解释器及有限枚举。
- [test_model.py](test_model.py)：37项测试，包括负向输入、空类、错误量词、项位颠倒、上下文改变与名字/类分离。
- [results.json](results.json)：本次实际枚举结果。
- [environment.txt](environment.txt)：实际环境与命令。
- [test-default.log](test-default.log)、[test-O.log](test-O.log)、[test-OO.log](test-OO.log)：默认、优化、去文档字符串三模式真实测试输出。

无需第三方依赖。于本目录执行：

## 明确语法、语义和拒绝含义

`Proposition('All','A','B')` 表示“每个B是A”，即B外延包含于A外延；它的项顺序是谓项在先，不可反读。

`Some(A,B)` 表示两类外延有交集；这是**本附件为了显示量词不足而选定的现代存在语义**，不是将原文所有不定命题一律译成特称。

`Member(A,c)` 表示个体名字c所指对象属于A。个体解释和类解释使用不同字典；相同字符不自动意味着同一类型。未给出的名字抛出 `KeyError`，不会默认为空类。

检查器只接受两种证书：

1. `All(A,B)` 和 `All(B,C)` 导出 `All(A,C)`。
2. `All(A,B)` 和 `Member(B,c)` 导出 `Member(A,c)`。

三命题都必须带完全相同的 `Context(time, aspect)`。默认上下文是固定时间、完整对象；改变上下文不被自动补桥。上下文标签只是预先约定语义的元数据，**不是自动识别自然语言歧义的机器**。

`verified-shape-only` 仅证实给定证书形状；前提可以在实际解释中为假。反之，拒绝只表示不在这个检查器所支持的片段内。例如 `All(A,B), Some(B,C) => Some(A,C)` 在普通集合解释下有效，但此处故意不收录；`unsupported-minor` 不能被写成“该推理无效”。

## 一般理由（不是由实验推出来）

全称链：任选对象x，假定x属于C；小前提给出x属于B，大前提给出x属于A。由于没有对x作其他限制，得到每个C属于A。无需C非空：空类情形是空真，但不能据此产生存在结论。

单称链：把小前提给出的同一个对象c代入全称大前提即可。若只有“某个B是A”，那个见证可能不是c，不能代入。

严格同一：若两个名字指向同一个对象，且谓词及时间、面向没有改变，那么该对象对同一谓词的成员关系只有一个真值。因此不可能同时有“谓词适用于这个对象”与“谓词不适用于这个同一对象”。这不是新增的亚里士多德解释结论，而是本附件所选模型的同一规则。

## 最小反模型与古例的边界

取A={0}、B={0,1}、C={1}。某个B是A为真，每个C是B为真，但是每个C是A为假。失败点是大前提缺乏对整个B的覆盖；它不是Barbara全称式的反模型。

Aristomenes例涉及“被思考的对象”与个体、永恒/总是的范围；Miccalus例涉及人及音乐家限定、毁灭/死亡的用法。Owen158还在相关句使用“may”，不能把这直接当成无模态的明日死亡事实。这里不将它们硬编码为上述两元素集合例。

测试另以两枚不同标记 `(person, whole)`、`(person, musician-role)` 演示：属性可以对完整对象和限定角色不同；然而它们在代码中**不是同一个对象**。这只能显示为何换面向必须显式建模，不证明古例就是这个解释。严格同一的别名则仍保存属性。用“角色变了所以人死了”的推理，必须另有明确桥接前提；本程序不默认这种桥接。

所有实跑数字来自 `results.json`。零失败只说明有限范围未找到反例；上面的任意对象推导承担一般解释，有限枚举不能证明无限论域的一般定理。程序未模拟自然语言解析、模态语义、历史人物、全套三段论或原典唯一语义。
