# 《几何原本》IX.36：由素数和构造完全数

给定指数 $`p`$，从单位依次加倍得到 $`1,2,\ldots,2^{p-1}`$。和 $`M=2^p-1`$ 若为素数，程序返回 $`N=2^{p-1}M`$ 和两列真因子：纯二的幂（含单位）及 $`M`$ 乘以较早的二的幂。第二列不含与末项相乘得到的 $`N`$ 自身。两列的和等于 $`N`$。例如 $`p=2`$ 得 $`M=3`$ 和 $`N=6=1+2+3`$。$`p=4`$ 的和为 $`15`$，$`p=11`$ 的和为 $`2047=23\cdot89`$，都不能用于这一构造。

程序为控制试除成本，仅接受整数 $`2\le p\le20`$。素性试除、真因子列表及有限测试是现代教学实现；命题不声称每个完全数都用这个方法得到，也不保证素数指数的和必为素数。

在本目录使用 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线筛出 $`2^{20}-1`$ 以内素数，再对所有合格 $`N`$ 试查至整数平方根，用配对商补全真因子。有限检验不替代证明。Notebook 日志记录标准库实际回放三个代码单元，不是 Jupyter 内核运行。

直接打开 [Notebook](euclid-ix36.ipynb)；核对 [普通模式](normal.log)、[-O](O.log)、[-OO](OO.log) 和 [Notebook 回放](notebook-replay.log)。
