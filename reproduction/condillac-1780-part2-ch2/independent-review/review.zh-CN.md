# 独立复核：有限表达与候选模型

## 结论与范围

对发布版5个Python文件、3份说明及证明逐项复核，并以另写的有限关系预言机检验实现。未发现模型语义缺陷。审计指出并复核了三项修订：无标签聚合反例的结论补上适用范围；日志中的绝对执行路径归一化，保留真实输出与退出码；日志修订引入的同引号嵌套f-string改用兼容写法，避免与建议Python 3.10+的说明冲突。实际执行仍只覆盖日志中的Python版本。

这是独立于模型作者的复核过程，但仍是同一助手系统协作完成，不是第三方机构认证。复核只涉及新写的数学教学模型、实现与执行证据；原书版本、页码及引文应由正文来源审计负责。本复核不提供心理学或历史算法有效性证据。

## 实际执行

`review.log`保留正常、`-O`、`-OO`三个真实子进程模式的输出。每个模式记录`sys.flags.optimize`为0、1、2；三个模式各通过11个独立测试方法，并额外重跑作者28个测试方法。未使用会被优化删除的裸`assert`。

每模式的独立检查包括：

- 1至4个标签的全部4,165张无自环有向图：572个DAG的全部拓扑序与3,593个有环拒绝结果。预言机枚举双射排名并逐边检查，没有调用被测拓扑搜索来生成期望值。
- 两字段全部3个DAG×81张三词码字典，以及三字段全部25个DAG×64张二词码字典，共1,843个模型。词码包含空串，另覆盖中文。先从原始模式、边和字典构造“完整词码序列→消息集合”关系，再独立汇总前缀，比较59,320个前缀与14,987个完整帧判定，包含未知词码、重复词码与超长序列。
- 不等长值域和特殊标签的240次合法前缀计数，逐项核验剩余值域乘积公式与真实消息保留。
- 从七种含空串、引号、反斜线、换行、中文、括号逗号和空字符的词码，枚举长度0至3的400个不同JSON帧，验证单射分帧与往返；另拒绝非字符串数组及非法JSON。
- 三个符号的全部8张二值意义表，255个非空假设子集，以及长度0至2的全部43个观察序列，合计10,965次假设筛选；期望结果用约束集合交独立生成。
- 冻结输入快照、一次性迭代器、矛盾例子、布尔/越界索引、非单射字典在固定顺序下仍可唯一恢复，以及撤掉顺序约束后出现歧义。

这些计数互有重叠，不能相加冒充独立样本量。有限穷举检验实现；任意有限规模的结论仍依赖证明前提。

## 行为突变与故障分类

每模式另运行10个定向行为突变，每次仅运行一个独立哨兵测试；每个突变有对应的原版哨兵基线。10个基线通过，10个突变均在测试完整结束且无测试异常时以断言失败检出。突变涉及：忽略优先边、遗漏前缀末项、只看第一种合法顺序、抹去角色绑定、抹去多重数、谎报字典单射、反转解码值、接受含混帧、丢失分帧边界、仅要求任一已知例子相符。其中8类与作者突变检验的设计相同或相近，但使用另写哨兵；另加“只看第一序”和“接受含混帧”。不将其描述为发现了10个原版缺陷。

另有5个真实分类控制：语法错误、导入失败、提前正常退出、实际超时、测试运行异常。它们各归入相应类别，均不计作行为突变检出。测试方法数、计数记录、模式及退出码见`review-summary.json`；断言失败详情见唯一一份`review.log`。这是人工选择的有限故障集，不是突变覆盖率保证。

## 证明核对与限制

- DAG拓扑序枚举的可靠性、完备性及无重复论证成立。
- 完整带标签集合本身可唯一确定消息，因此反例针对丢失绑定，不针对“同时呈现”。
- 字典全局单射加可逆分帧是充分条件；不是所有唯一解码情况的必要条件。多合法序列和单一消息之间不是无条件双射。
- 前缀候选单调非增不要求单射；真实消息保留需要正确观察。精确计数额外依赖全笛卡尔积、单射字典和合法前缀，不能移用于碰撞字典或失配观察。
- 有限假设表的筛选与未见项的多值预测成立；额外的仿射假设来自模型设定，不能算作观察自动给出的结论。
- 实现预存所有拓扑序并枚举消息，最坏具有阶乘/指数规模；仅供小型教学。未测试其他解释器/平台、资源耗尽、无限输入或对冻结对象的底层绕过。

## 复现与源文件一致性

将本目录置于教学附件的`independent-review/`内，从教学附件目录执行：

```sh
python -B independent-review/run_review.py
```

也可在任意位置给出`--source-dir`指向含`model.py`的教学附件目录。脚本仅在临时副本中执行突变，不改作者文件；覆盖本目录的`review.log`和`review-summary.json`。依赖仅Python标准库，无安装与网络。实际解释器和时间保存在摘要中。

摘要记录所有作者Python/Markdown源文件及两份独立检查脚本的SHA-256，运行前后比较，若中途变化则拒绝认证成功。发布文件应与该摘要逐一对应。本报告作为解释说明不纳入被测源码哈希；作者日志另由其自身摘要说明。日志只将绝对项目、临时目录、解释器和标准库路径替换为占位符，不改输出内容或故障分类。所保留证据均来自最后一次对冻结源文件的完整运行。
