## 2. 对象、记号与封闭世界假设

令 $`F=(f_1,\ldots,f_n)`$ 是带有存储顺序的非空有限特征集，$`n\geq1`$，各标签互异。每个特征的值域 $`V_f`$ 非空、有限，各元素互异。程序中标签和值都是非空字符串。

消息空间是完整笛卡尔积：

```math
\mathcal M=\prod_{f\in F}V_f.
```

消息 $`m`$ 是给每个特征恰好一个值的映射；程序用按 $`F`$ 存储顺序排列的元组表示。不是概率分布，也没有“最可信”或“最显著”的排序。

带标签的原子集合与完整表示为：

```math
A=\{(f,v):f\in F,\ v\in V_f\},\qquad B(m)=\{(f,m(f)):f\in F\}.
```

语境 $`G=(F,E)`$ 是有向无环图。边 $`(a,b)\in E`$ 表示表达 $`a`$ 必须早于 $`b`$。$`\Pi(G)`$ 是所有满足这些边的完整拓扑序。语境已知，且本模型中不随消息改变；程序没有从人的“需要”推导这些边。

字典 $`d:A\to\Sigma^*`$ 把原子映为有限字符串，即“词码”。可以包含引号、逗号、换行和空字符串。字典必须覆盖全部且仅覆盖 $`A`$。构造器允许非单射字典，以便研究歧义；`injective` 是检测结果，不是构造器保证。默认字典以JSON二元数组编码原子，因而单射。

对合法序 $`\pi=(\pi_1,\ldots,\pi_n)`$ 定义词码序列：

```math
S_d(m,\pi)=\bigl(d(\pi_1,m(\pi_1)),\ldots,d(\pi_n,m(\pi_n))\bigr).
```

`pack` 把整个序列编码成JSON字符串数组，`unpack`解析回来。模型中的前缀指**已经完成切分的词码前缀**，不是网络上尚未传完的JSON字节前缀。双方共享模式、字典、语境和分隔协议；信道无误；思想在一次表达期间保持不变。这些是额外条件，不是历史文本证明的事实。

## 3. 为什么有合法顺序，为什么不止一个

### 命题1：有限DAG至少有一个拓扑序

非空有限DAG必有入度为零的顶点。否则从任一顶点不断选前驱，因为顶点有限，最终重复顶点，产生有向环，矛盾。先选一个无前驱顶点，删去它和关联边；余图仍无环。对顶点数归纳，得到余图拓扑序，把首顶点接在前面即可。空余图对应递归终止。

实现每一步只选择尚未出现、且所有前驱已在前缀中的特征。因此输出序列满足每条边，并恰好覆盖各特征一次。反过来，任一合法拓扑序的下一项在其此前各项给定后一定可选；按前缀长度归纳，搜索不会遗漏该序。两个不同分支在首次选择处不同，所以不会输出重复序。

### 命题2：变化不等于任意

若无边，所有 $`n!`$ 个排列合法；若有边 $`a\to b`$，任何把 $`b`$ 放在 $`a`$ 前的排列均不合法。某些不同排列仍可能同时满足全部边。例如 $`agent\to act`$、$`patient\to act`$ 只要求动作最后，允许两个角色交换表达先后。

这只是预设DAG的性质。它既不说明历史上的顺序确实由DAG生成，也不排除另一语境允许完全不同的顺序。加入边只会减少或保持合法序集合；若新边产生环，当前实现拒绝输入，不能把空序集合当成正常表达能力。

## 4. 保留什么才足以恢复

### 命题3：带标签集合已足以唯一确定消息

若 $`B(m)=B(m')`$，对每个 $`f`$，集合中唯一第一分量为 $`f`$ 的原子相同，所以 $`m(f)=m'(f)`$。逐特征得 $`m=m'`$。

因此，**同时展示完整带标签集合并不必然丢信息**。时间先后不是这条单射性的必要条件。逐项观察在人的认知中有何用途，不能由无标签聚合反例直接决定。

### 命题4：单射字典与可靠分帧使序列可恢复

假设 $`d`$ 单射。若 $`S_d(m,\pi)=S_d(m',\pi')`$，逐位置由字典单射性得到：

```math
(\pi_i,m(\pi_i))=(\pi'_i,m'(\pi'_i))\quad(1\leq i\leq n).
```

故 $`\pi=\pi'`$，又因各特征恰出现一次，得 $`m=m'`$。因此 $`(m,\pi)\mapsto S_d(m,\pi)`$ 是到合法词码序列集合的双射；固定 $`\pi`$ 后，消息到其序列像也是双射。

不能省去“固定顺序”而把全部序列与消息说成双射：同一消息可能有多个合法序列。`decode`返回消息，不返回表达顺序。

`unpack(pack(s))=s` 对有限字符串序列成立，因为JSON数组边界与字符串转义能恢复每个元素。于是不同词码序列不会在该分帧步骤合并。构造性解码可先解析数组，再逐词码查字典逆映射、检查特征覆盖和DAG；为便于和含碰撞情形统一，当前小程序用下节的有限候选枚举完成相同判定。

字典全局单射是**充分条件，不是一般必要条件**。例如两个单值特征均编码为同一码时，整个消息空间只有一个消息，即使字典不单射，完整表达仍可能唯一识别消息。更一般的特殊语境也可能帮助消歧。既不能从碰撞推出每个表达都歧义，也不能从某个表达无歧义推出整个字典单射。

## 5. 前缀观察：单调、保真与精确计数

对任意有限词码序列 $`p`$，用 $`p\preceq s`$ 表示 $`p`$ 是 $`s`$ 的前缀，定义：

```math
C(p)=\{m\in\mathcal M:\exists\pi\in\Pi(G),\ p\preceq S_d(m,\pi)\}.
```

这一定义允许不可能的输入：未知词码、超长序列、违反语境的序列可能给出空集合。字典单射时，重复同一特征的词码也不可能匹配完整合法表达。字典有碰撞时，同词码重复可能来自不同特征，不能只根据字符重复一律拒绝。

### 命题5：候选单调非增

如果 $`p\preceq q`$，而 $`m\in C(q)`$，则存在合法 $`\pi`$ 使 $`q\preceq S_d(m,\pi)`$。前缀关系传递给出 $`p\preceq S_d(m,\pi)`$，所以 $`m\in C(p)`$，即：

```math
C(q)\subseteq C(p).
```

不要求字典单射，也不要求观察来自真实消息。此结论不保证严格缩小，不保证非空，更不保证最后唯一。

### 命题6：真实消息何时不会被筛掉

若指定真实消息 $`m^*\in\mathcal M`$，并且每个观察前缀确实来自某一固定合法表达 $`S_d(m^*,\pi^*)`$，则用同一个 $`\pi^*`$ 作为存在量词见证，立即得 $`m^*\in C(p)`$。没有正确观察和真消息在初始空间内这两项前提，单调性不保护真相。

### 命题7：全积、单射、合法前缀下的候选数

额外假设 $`\mathcal M`$ 是第2节完整笛卡尔积、$`d`$ 单射、$`p`$ 是某个合法表达的长度 $`k`$ 前缀。单射性使前缀唯一指定互异特征 $`f'_1,\ldots,f'_k`$ 及其值。令这些特征组成 $`O_k`$，则：

```math
|C(p)|=\prod_{f\in F\setminus O_k}|V_f|.
```

证明分两边。任何相容消息都必须在 $`O_k`$ 上等于已解出的值。反过来，任意给其余特征选值，都会得到消息空间中的一个消息；沿已知可行前缀的某个拓扑扩展表达它，就有同一前缀。剩余值的组合与相容消息一一对应，故乘法原理给出公式。$`k=n`$ 时空乘积为1，因而唯一恢复。

真实流每观察一个新特征，相容数按其值域大小缩减；只有该值域大小大于1时才严格减少。若初始消息空间是受额外关系限制的真子集、字典不单射、前缀不可行，公式均不可直接使用。此模型的候选计数也不是人类理解程度的量表。

## 6. 三种不同的信息缺口

### 6.1 去掉角色绑定

定义 $`U(m)`$ 为所有值的多重集，保留重复次数但丢特征标签。两个特征 $`a,b`$ 若均允许不同值 $`x,y`$，则令 $`m(a)=x,m(b)=y`$，交换后为 $`m'`$，其余特征不变，便有 $`m\ne m'`$ 但 $`U(m)=U(m')`$。

在上述反例中，无标签聚合不是该消息空间上的单射。把这个聚合结果逐字念出来不会恢复已经丢失的绑定。另一协议也可以通过**双方预先约定的固定位置**保存角色，不必把标签写成独立词码；本模型选择原子字典是为了让表达顺序可以变化，并不证明显式标签是唯一办法。

### 6.2 覆盖完整仍有词义碰撞

若同一特征的两个值有相同词码，取只在该特征上不同的两个消息，沿同一合法序表达。每个位置都相同，因此全部 $`n`$ 项已观察后仍至少有两个候选。本例说明“项目都看过”不能代替“这些符号区分得开”。这是一类足够构造歧义的碰撞；不能推广成任意跨特征碰撞都必然如此。

### 6.3 词典单射仍需可判定的边界

令固定序为 $`a,b`$，设四个不同原子的词码依次为 a、ab、bc、c。两个消息的词码序列为 (a,bc) 与 (ab,c)，直接拼字符串都得 abc；字典仍可全局单射。问题发生在序列转为未分隔字节串的步骤。

JSON分帧使二者成为不同字符串数组，因此解决这个特定边界问题。实际通信还可用前缀码、长度字段或共享切分规则；本例不主张JSON是人的动作语言。

## 7. 类比的最小限度：还需要假设空间

这一模块与上述消息字典分开。符号位置集合为 $`X=\{0,\ldots,s-1\}`$，意义为字符串。给定非空有限假设集合 $`\mathcal H`$，每个 $`h\in\mathcal H`$ 是在 $`X`$ 上完整定义的映射。观察集合（实现接受有限序列）$`D`$ 中各项为 $`(x,y)`$。定义：

```math
\mathcal H_D=\{h\in\mathcal H:\forall(x,y)\in D,\ h(x)=y\},\qquad
P_D(x)=\{h(x):h\in\mathcal H_D\}.
```

增加例子使假设集合与预测集合单调非增，证明与命题5相同，使用“满足更多约束必满足较少约束”。在 $`\mathcal H_D\ne\varnothing`$ 时，一个未见符号的意义可由当前假设空间唯一确定，当且仅当 $`|P_D(x)|=1`$：必要性是两个不同预测无法同为唯一结果；充分性是所有剩余假设都给同一结果。假设集合为空表示矛盾或模型失配，不是唯一识别。

取三张表 (0,1,2)、(0,1,4)、(1,2,3)，观察符号0对应0、符号1对应1；前两张表都符合，但对符号2分别预测2、4。已知前两项不能在这个假设空间内决定第三项。若**事先**只允许所列两张仿射表 (0,1,2)、(1,2,3)，则只剩前者。结果改变来自先验结构约束，而不是已知词码自动生出未知意义。

一般地，对实数上的仿射映射 $`h(x)=ax+b`$，两个不同自变量的精确观察确定至多一个映射：两映射相减，$`(a-a')x_i+(b-b')=0`$，两式相减且 $`x_1\ne x_2`$ 得 $`a=a'`$，继而 $`b=b'`$。还须检查该映射存在于指定假设类。程序只筛选有限表，不声称实现了全部实数仿射推断。

115页的“类比”没有在原文中被规定成这个假设空间；有限例子只展示从若干已知项推广时需要说明额外结构，不能判决作者的整个类比理论。

## 8. API、计算规模与验证边界

- `Language(schema, edges, lexicon)`复制输入到不可变元组/冻结集合。域重复、空模式、缺失或额外字典项、未知边端点和有向环等普通无效输入会被拒绝。
- `encode`要求完整合法排列；`candidates`接受任意有限字符串前缀并按存在性返回集合；`decode`要求JSON数组长度恰为特征数，且候选恰有一个。它也可接受某些非单射字典下实际唯一的完整表达。
- `version_space`验证全部例子后筛选，不因较早矛盾而跳过后面输入检查；重复矛盾例子产生空集合。布尔值不当作整数符号位置。
- 正式契约只涵盖通常的有限Python容器/有限迭代器，不包括无限生成器、恶意对象、对冻结对象使用底层绕过或任意故障恢复。空字符串可以当词码和类比意义，但不能当特征标签或消息值。

这是刻意朴素的穷举。令 $`b=\sum_f|V_f|`$、$`M=|\mathcal M|`$、$`L=|\Pi(G)|`$。模式构造预先保存全部 $`L`$ 个拓扑序，最坏 $`L=n!`$；消息空间也可能指数增长。候选程序逐消息、逐合法序比较，并在每次编码中重建小字典及验证完整序。按字符串比较/哈希为单位成本的保守上界，单次候选计算为 $`O(|p|+ML(b+Ln+n+|p|))`$，空间为 $`O(Mn+Ln+b+|E|+|p|)`$。构造、输入读取与JSON处理另计；JSON成本须计入实际字符数。这里没有大型推理引擎的性能主张。

作者验证包括28个unittest方法，二值模式的29个DAG、402次完整编码、1588次合法前缀检查；另对81张三词码字典检查3240个前缀，并覆盖不等长值域、协议错误及类比反例。这些数字只界定实际有限枚举，不是上文任意有限规模命题的证明。
