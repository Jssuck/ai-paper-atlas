## 代数模型与判据

将圆心放在原点，半径是给定的正有理数，起点选在正横轴。令 u = (√5−1)/4 = cos 72°，V = 1−u²。一个坐标对 (x, y) 实际表示 (x, y√V)。x 和 y 都以有理数对表示 a+b√5。正向旋转一步给出 (ux−Vy, x+uy)，反向旋转取相反的正弦项；全程不用浮点门限。点积为 xx′+Vyy′，行列式的符号不受正因子 √V 影响。

验证包括：

- 五点互异且在同一圆上，检查弦长平方一致。
- 用余弦的符号与平方鉴别普通角。两项合起来能确定区间 [0,180°] 中的角；只比较平方可能把补角当成等角。
- 检验 ACD 的顶角 36°、两底角 72°，以同侧判据确认 CE、DB 是内部射线，再核对四个半角都与顶角相等。
- 用正横轴的有向穿越计算绕数，采用半开端点规则，避免对位于轴上的顶点重复计数；再独立检查不相邻边的严格交叉。此模型拒绝圆心落在边上的退化绕数问题。

## 实跑结果与边界

48 个有理半径各检查两个反射分支，得到 96 个边界正例和相同点集的 96 个五角星对照。正常边界没有交叉，绕数为 ±1，内角是 108°。五角星按 A、C、E、B、D（再回 A）连接，也满足等弦和普通顶角相等，但角为 36°，严格交叉有 5 处，绕数为 ±2。

另对同一组顶点枚举 120 种线性排列：10 种边界顺序、10 种均匀跳点的星形顺序、100 种既非上述两种的顺序。起点与方向计入排列，但不表示有那么多个几何形状。普通、`-O`、`-OO` 三个模式各通过 8 项具名测试，其中还检查非正半径、错误方向、重复顶点、离圆点和经过中心的弦。

这些只是精确教学样本，不是一般证明或古代数据的实验复现。代码不求不规则多边形、不模拟测量误差，也不承担任意圆心、任意起始方向的输入接口。
