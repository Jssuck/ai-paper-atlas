# 从本章论证到可检查模型

## 1. 先固定方向，再读三个字母

设 P 是大项、M 是中项、S 是小项。AAA 依次表示：

1. 每个 M 都是 P。
2. 每个 S 都是 M。
3. 因此每个 S 都是 P。

原文通常先写谓项，再说它属于哪些主项；本程序 `holds(kind, subject, predicate)` 采用主项在前。因此“P 属于每个 M”写作 A(M,P)，不是 A(P,M)。搞反这个约定会改变问题。

## 2. 四条最强路线怎样得到

- AA→A：任取一个 S，由小前提它属于 M，再由大前提它属于 P。
- EA→E：任取一个 S，它属于 M，而没有 M 属于 P，所以它不属于 P。
- AI→I：小前提给出一个同时属于 S、M 的对象；大前提让这个对象也属于 P。
- EI→O：小前提给出一个同时属于 S、M 的对象；大前提让这个对象不属于 P。

前两条无需假设存在 S 即成立；后两条的存在见证由小前提本身给出。I.4 所称“完善”的推理并不意味着作者使用现代集合、公理系统或遍历程序。

## 3. 空项为什么让 4 与 6 不一样

取 U={u}，P=M=S=∅。这就是 `Model((0,))`。A(M,P)、A(S,M)、E(M,P) 全为真，但 I(S,P)、O(S,P) 都为假。所以 AAA 不能在允许空项的语义中自动弱化为 AAI，EAE 也不能自动弱化为 EAO。

若额外保证 S 非空，上述两种弱化就成立。演示选择更对称的“三项全非空”作为第二套模型范围，得到六个有效字符串；有效字符串数与原章最强推理路线数不是同一种计数。

## 4. 两个模型排除一个前提对的所有结论

以 AE 为例：前提是 M⊆P 且 S∩M=∅。

- `Model((5,6))`：U={5,6}，P={5,6}，M={6}，S={5}。两前提为真，A(S,P) 为真，E(S,P)、O(S,P) 为假。
- `Model((1,6))`：U={1,6}，P=M={6}，S={1}。两前提仍为真，E(S,P) 为真，A(S,P)、I(S,P) 为假。

每个模型中三项都非空。把两个模型合起来看，四种候选正向结论各有反例。无需在同一个模型里让“所有 S 都是 P”和“没有 S 是 P”同时为真。运行程序能看到其余十一组同类见证。

这些新构造的小模型展现原章“同一前提配置可以配以不同的极端项关系”的反例策略；它们不是把原文动物、马、石头等项替换成历史引文。

## 5. IE 的方向陷阱

I(M,P) 保证某个 x 同时属于 M 和 P；E(S,M) 保证它不属于 S。所以存在 P 不是 S，即 O(P,S)。这对任意论域成立，无需附加三项非空条件。

但本章正向候选结论是关于 S 与 P 的关系。`Model((1,6))` 使 I(M,P)、E(S,M)、O(P,S) 为真，而 I(S,P) 为假。另一个 `Model((5,6))` 使同一前提成立，但 O(S,P) 为假。程序将反向形式单列，避免把另一方向的推论误加进正向分类。

## 6. 为什么只需检查 255 个支撑

任一对象的三项成员关系只有八种：000、001、010、011、100、101、110、111。每种出现过的类型保留一个代表即可：重复对象不会改变“是否所有”“是否没有”“是否存在”的真值。即使原论域无限，实际出现的类型仍至多八种。类型 000 不能扔掉，否则只剩三项之外对象的合法非空论域会消失。

“255”来自八种类型所有非空子集。另要求三项非空时，再过滤没有 P、M 或 S 见证的支撑，留下 218 个。一般的真值保持论证支撑完整性；有限测试只检查实现是否忠实。

反模型按支撑大小升序寻找。如果任何更小的任意模型构成反例，它压缩后也是至多同样大小的规范反例，必定已在更早位置出现。因此“最小”不只是当前有限搜索前缀中最小。

## 7. 读结果与检查程序

```sh
python walkthrough.py --format human
python walkthrough.py --format pairs-csv
python walkthrough.py --format forms-csv
python walkthrough.py --format json
```

JSON 同时保留完整的 16 对前提、两种语义各 64 个正向形式、全部反向诊断，以及每个失败形式的具体最小反模型。一个模型的 `support` 与 `type_bits_PMS` 告诉你有哪些对象类型，P/M/S 字段给出各外延，`premise_model_count` 可检查前提是否有实例。

测试中的 oracle 逐点判断“若主项真则谓项真”“不存在两者都真”等条件，与实现的集合包含、交、差操作分开。测试覆盖全部规范模型的原子真值、两种语义的全部形式及反模型最小性、反向结论、12 对见证、输入边界、不可变数据和导出格式。普通、`-O`、`-OO` 是三次独立实际运行；CLI 子进程也继承相应优化级别。

16 项小规模故障注入故意倒置集合包含、混淆否定与不等、遗漏类型、改变存在条件或接受布尔值作为整数，再运行对应测试。只有真实断言失败才算检出；崩溃、导入错误和超时不算。此实验不能证明软件没有其他错误。
