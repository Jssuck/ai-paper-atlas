# VI.16 教学复现：四项比例与矩形等积

[中文深读](../../papers/ancient/euclid-elements-vi16.zh-CN.md)

用有理坐标重建 Proposition VI.16 的两个矩形。给定四条正长度 a、b、c、d，先计算确切的 a:b 和 c:d，再在不同坐标位置构造 a×d 与 b×c，按实际顶点用鞋带公式算面积。测试另用沿对角线分割成的两个三角形计算面积。这里的坐标、标准化单位与数值计算是现代教学重构，不是欧几里得绕开 VI.14 的另一个原文证明。

## 复跑

在本目录使用 Python 3.12（本次实跑的详细版本见日志），不需要第三方依赖、外部数据或网络：

```sh
export PYTHONDONTWRITEBYTECODE=1
python3 -m unittest -v
python3 -O -m unittest -v
python3 -OO -m unittest -v
python3 replay_notebook.py
```

[普通模式](normal.log)、[优化模式](O.log)、[双优化模式](OO.log)各有 9 项测试，其中一项以六个正有理数作四项笛卡尔积，共 1,296 组，包含比例成立与不成立的情况。其余用例检查配对反例、比例角色、零和负值、非精确输入以及平移和改变顶点走向。

[Notebook](euclid-vi16.ipynb)可在已有 Jupyter 环境打开；这里以[标准库脚本](replay_notebook.py)执行三格代码并保留[真实回放日志](notebook-replay.log)，没有启动 Jupyter 内核。只用回放脚本运行本仓库可信 Notebook。

## 验算速览

- (6,4,9,6)：两比均为 3/2，正确矩形面积为 36 与 36。若误连 a×c 和 b×d，会得到 54 与 24。
- (2,3,3,2)：误配的乘积都是 6，正确矩形却分别为 4、9；误配也会产生假阳性。
- (6,4,8,6)：比例 3/2 与 4/3 不等，面积 36 与 32 不等。
- (1/2,3/4,2,3)：两比均为 2/3，面积均为 3/2。
- 输入须为正；零既不能成非退化矩形，也可能令一个比无定义。有限有理数测试不覆盖无理长度，更不能证明一般定理。
