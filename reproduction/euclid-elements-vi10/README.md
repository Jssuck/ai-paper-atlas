# 《几何原本》VI.10：搬运分段比例

对应[中文深读](../../papers/ancient/euclid-elements-vi10.zh-CN.md)。下面是有理坐标教学模型，并非完整尺规仿真或一般定理的形式证明。

给定共起点的两条非共线线段 AB 与 AC，后者有内部标记 A–D–E–C。先过 D、E 作平行于 CB 的直线，与 AB 交 F、G；再过 D 作平行于 AB 的直线，与 EG、CB 分别交 H、K。程序用行列式解这四次相交，不把所求分点的分数预先代入。验证程序检查平行和点序，核对平行四边形的对边向量 DH=FG、HK=GB，再用同一条边的参数差比较两组比例：在 DKC 中 CE:ED=KH:HD=BG:GF，在 AGE 中 ED:DA=GF:FA。坐标值正负不影响这里的长度比；比较使用有序参数差。

- A=(0,0)、B=(14,0)、C=(7,7)、D=(2,2)、E=(5,5) 给 F=(4,0)、G=(10,0)、H=(8,2)、K=(12,2)。两串比例分别为 2/3 与 3/2。
- 换成 G=(9,0) 虽仍满足点序，EG 却不再平行 CB。底边三段为 4、5、5，比例分别变为 1 和 5/4。
- 直接插值程序另取 D、E 在 AC 中的归一化参数，再映到 AB，作为不同求值路径的预期；它也接受任意个严格有序的内部标记。这是教学推广，不是宣称原文逐一演示任意个标记。倒置标记、重合标记、端点、共线底图及非有理输入均不视为原命题的有效构形。

## 环境与实跑

仅使用 Python 标准库；在本目录运行：

```sh
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B replay_notebook.py
```

[普通](normal.log)、[-O](O.log)、[-OO](OO.log) 每种模式通过 8 项测试；独立于单个示例，扫描 1,008 个精确构形（两个取向各 504 个），每个同时核对古证式的坐标证据及直接插值。扫描覆盖三个原点、三条底边向量、每条底边的两侧及分母 3 至 8 的所有有序两标记；非垂直且不等长的例子在单元测试中另测。

[Notebook](euclid-vi10.ipynb) 的三个代码格用标准库依次编译并在共享命名空间执行，见[回放日志](notebook-replay.log)。这不是 Jupyter 内核运行；文件保留未执行状态，便于读者重跑。有限测试不能取代一般证明。
