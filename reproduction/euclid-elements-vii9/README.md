# VII.9：按相同次数配对汇总

这是用现代整数写出的教学重构，不是古代运行记录、一般命题的计算证明或性能实验。可对读 [Fitzpatrick 的希英对照 VII.9](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=203)，印刷页 202–203。

- 输入顺序为 A、BC、D、EF。程序要求四个给定量均为大于 1 的整数、A 小于 D，且 BC 与 EF 分别由同一整数次（至少两次）的 A 与 D 组成。对照图中的 BG、GC 与 EH、HF，代码用重复计数压缩等块，不展开所有行。两个图示区段不限制一般的复制次数。
- 每对中，最大公度 g 把 A、D 分成互素的 m、k 份。把同一序号的各行小份合在一起，每份变为 n·g，合计仍是 m 和 k 份。m=1 对应「一份」，m>1 对应「若干份」。现代记法是 A/D=BC/EF；比值保留不意味着公度的绝对值不变。
- 一份例：A=4、BC=12、D=12、EF=36，n=3，比值为 1/3，公度 4 → 12。若干份例：A=6、BC=18、D=10、EF=30，n=3，比值为 3/5，公度 2 → 6。若只改 EF 为 40，两比为 3/5 与 9/20，不再相同。
- A=D 或 A>D 的现代分数等式仍可在共同倍数下成立，却不直接落入原「A 是 D 的一份或若干份」的方向；程序特意拒绝。共同的非单位分数也可以有现代换比等式，但不是本命题的一份前提。古代的「单位」并非给定的「数」；公度可为 1，并不把它误作四个给定的数之一。
