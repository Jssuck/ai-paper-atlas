# 《后分析篇》II.6：本质标准、支持来源与统一性的最小教学复现

2026-10-26。阅读单元92a6–33；原文见[Mure英译第二卷Part6](https://classics.mit.edu/Aristotle/posterior.2.ii.html)及[希英对读II.6](https://aristotle.johnhboyer.com/APo/book/2/#ch-2-6)。完整书目和文本边界见[来源台账](../../papers/ancient/aristotle-posterior-analytics-ii6.sources.zh-CN.md)。这是原创现代教学模型，不是古代论证的完整形式化，也不是用计算机认证真实本质。只用Python标准库，无外部数据集、训练、付费服务或依赖安装。

## 1 为什么做三个分开的模型

92a6–19问：把定义的一般标准写成前提，是否就证明了这份具体说明是本质？92a20–27检查相反者定义之间的假设转移，以及待证内容是否换一个名字重现。92a28–33则区分同一主体恰有多个属性与这些属性构成一个本质说明。三个问题不能压成一个“分类准确率”。

- 集合层只处理外延包含、相交和同延，不能决定本质统一。
- 有限Horn层只追踪明确事实的逻辑支持，不能自动判别科学根据或所有乞题。
- 相反转移层把桥接原则列为独立前提，不从两个“相反”标签自动获得它。

原文善、恶、可分、不可分是被检查的假设论证；程序不把善等于不可分当作已证哲学结论。这里的相反关系仅作为输入命题，不采用集合补集的数学公理。

## 2 外延模型与手算

`conjunction_report(H,P,Q,unity_claim)`输入任意三个有限集合，返回H是否分别包含于P和Q、是否包含于交集、是否与交集同延。`unity_claim`仅为调用者提供的布尔元数据，`unity_certified_by_sets`始终为False；这个字段是能力边界声明，不是证明所有真实定义都不统一。

取H={a}、P={a,b}、Q={a,c}，交集恰为H。把unity_claim从False改为True，全部外延关系不变。因此只观察这些集合关系的算法不能区分这两份扩充记录的统一性标签。它说明在**本模型没有添加连接公理**时，标签未由外延决定，不声称原典本质可以任意赋值。

一般证明：如果每个H对象属于P且属于Q，则任选x∈H，由交集定义得x∈P∩Q，故H⊆P∩Q。逆向也成立。这个逐元素证明不依赖有限域；枚举仅检验实现。H为空时全称包含仍真，不证明H存在。将“同一主体有音乐和语法属性”编码为交集，只证明共同谓述，不构造自然本质。

枚举n=0..3所有(H,P,Q)：共有1+8+64+512=585组。每个对象允许八种成员状态；满足H⊆P且H⊆Q的状态每对象有五种，因此总数1+5+25+125=156；要求H=P∩Q时每对象四种，总数1+4+16+64=85。同延情况下分别附两个外部标签，共170份记录。集合运算和逐对象成员oracle一致，违例0。

## 3 有限Horn支持集

`minimal_supports(facts,rules)`：原子为非空字符串，规则为(前提原子集合,结论原子)。规则数量和原子数有限，所有规则只含正原子。每条输入事实a的初始支持为{a}；规则前提各有支持时，取支持的并作为结论候选；删除被其他支持严格包含的候选，留下按包含关系最小的事实支持集合。

“最小”不是“元素数最少”，可以保留大小不同但互不包含的支持。空前提规则作为明确公理，其事实支持为空；这不意味着没有假设，因为规则本身始终是所接受的背景。事实的真假、别名是否真实、规则的科学正当性都未由算法认证。

例：事实alias与observation，两条规则alias→target、observation→target。target有两个最小支持{alias}与{observation}。`independent_support(...,'target',{'target','alias'})`返回True，只表示有一条记录的事实支持避开此禁用集合。删掉observation后返回False。别名必须由使用者明确列入；把目标隐含在规则里或通过未声明的等价关系偷渡，当前函数不能自动发现。

### 一般性质与证明

1. **可靠性。** 初始单事实支持确能推出对应事实。每次应用规则时，由各前提支持的归纳假设和所接受的Horn规则，支持并集能推出结论。删除支持不添加新结论。
2. **终止。** 有限事实集F只有2^|F|个子集。一个候选被已有更小支持支配后，其任何超集不会再变成有效最小候选；每次真正更新都增加新的不被支配支持或以严格更小支持取代旧支持。有限原子与有限支持候选保证停止。最坏情形支持数可指数增长，不能宣称一般线性时间。
3. **完备范围。** 在固定有限正Horn规则下，对每一有限推导作归纳：前提推导的最小支持被保留或被更小支持替代，替代后的并不大于原支持。达到固定点后，不会漏掉可推出原子的包含最小事实支持。此性质不扩展到任意一阶逻辑、非单调规则或真实认识论独立性。
4. **无根循环。** a→b、b→a而无事实或空前提公理时，没有起始支持，二者均不被推出；若已接受a，则b支持为{a}。循环形状本身不等于所有推导都无效，关键是根据从何而来。

真实枚举采用三原子a,b,c、六条不同原子之间的单前件规则。64种规则子集×8种事实集=512系统，检查1536原子。独立oracle不使用前向链，而枚举全部八个真值赋值，保留满足事实与规则的赋值，检查是否全部使查询原子真；并对事实所有子集枚举最小支持。闭包差异0，支持差异0。这项枚举不覆盖所有多前件规则；多前件、空规则、循环、替代支持由单元测试覆盖，一般论证如上。

## 4 相反定义的转移不免费

`opposite_transfer(d,c,f,b)`返回四个输入布尔值的合取。其中d为已接受的源定义，c为主体相反关系，f为说明相反关系，b为明确桥接原则。只有四项全部满足，模型才给出转移证书。它不自动查询现实善恶，不把contrary强制解释成complement。

设结论命题q独立，规则为“如果d、c、f、b，则q”。在五个布尔变量的32种赋值中，31种满足此规则；唯一被排除的是四前提真而q假。满足规则且四前提真者仅1种，结论违例0。这是规则语义检查，不是对桥接原则真实可靠性的实证证明。

手算反模型：d=c=f=True、b=False、q=False，仍满足规则；所以前三项 alone 不迫使q。`opposite_transfer`输出False表示**没有从这条规则得到证书**，不表示q为假；q也可能因别的理由为真。逻辑条件成立与根据不乞题是不同问题。

## 6 带答案练习与复盘

1. H={a}，P=Q={a,b}，共同谓述成立吗？是否同延？答：成立，不同延，交集多了b。
2. 同延后程序为何仍不认证unity？答：外延公理中没有本质统一关系，输入标签不是证明。
3. {a}和{b,c}能同时是最小支持吗？答：能，二者互不包含；最小不等于最少。
4. 无事实的互推循环能推出a吗？答：不能；若另有空前提规则→a，则可以，依据是新增公理。
5. 支持避开target是否足以证明不乞题？答：不够，还可能有未声明别名、规则中隐藏目标及认识论上的依赖。
6. 移除bridge后得到False能否断言目标定义错误？答：不能，只表示该规则未提供证书。
7. 32行真值表是否证明善的本质是不可分？答：没有，只检验自设的条件规则。
8. 是否可把相反公式一律写成集合补集？答：本模型没有这个授权；不同反对关系必须另立语义。
9. 512系统是否穷尽所有Horn逻辑？答：没有，仅三个原子、单前件非自环规则的有限范围。
10. 是否可用标准库exec输出声称Notebook内核兼容？答：不能，执行方式及未验证部分必须如实说明。

最重要的复盘是把“能算出一个结论”“该推导用了哪些明示事实”“这些事实是否解释本质”分开。前两项有局部可执行工具，第三项没有因为代码运行成功就自动获得答案。
