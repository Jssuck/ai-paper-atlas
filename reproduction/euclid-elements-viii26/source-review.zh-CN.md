# VIII.26 原典与链接核对

- [Heath 英译注本第二卷（1908）](https://commons.wikimedia.org/wiki/File%3AThe_thirteen_books_of_Euclid%27s_Elements_Volume_II.pdf)：印页 381 下部至 382 上部（PDF 第 394–395 页），含字母图和结论。381 页从相似性得中项，标 VIII.18；382 页取同单步比的最小组三项，标 VII.33 或 VIII.2，继而按 VIII.2 推论取平方端点。结论后有 Heath 自己的小写公式简述；不是另一条原文。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=250)：命题起于印页 250 底，251 页完整闭合，三处现代标注依次是 8.18、8.2、8.2 的推论。希文中项 Γ，三项 Δ、Ε、Ζ；英译同位置为 C 与 D、E、F。两份底本在证明的三步分工上相符。未在对读范围识别适用的正式勘误；不主张所有抄本、再版均已校勘。
- [Clay 希英网页](https://www.claymath.org/library/historical/euclid/files/elem.8.26.html) 的希文一直到端点比回接和结论，英译止于最小链两端为平方；[Joyce 完整在线译文](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII26.html) 的交叉链接与 Heath 相合。网页截断不是原典的结论缺失。
- 依赖依据：[VIII.18](https://www.claymath.org/library/historical/euclid/files/elem.8.18.html) 从对应边构造中项；[VII.33](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII33.html) 取同比分量中最小组；[VIII.2](https://www.claymath.org/library/historical/euclid/files/elem.8.2.html) 直接构造给定单步比的最小等比链，推论处理三项链的平方端点。[IX.10](https://mathcs.clarku.edu/~djoyce/elements/bookIX/propIX10.html) 的平方分支明确标作 VIII.26 的逆向；这里只定位引用，不扩作另一篇。
- [深读正文](../../papers/ancient/euclid-elements-viii26.zh-CN.md) 的现代单位边、整除证明、可执行证书和有限验证不是底本原话，也不是转写完整译文。本附件不包含原典扫描。
