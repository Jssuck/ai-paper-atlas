# 《几何原本》IX.3：立方数的自乘

正整数教学重构。若 $A=c^3$，先列表 $(1,c,c^2,A)$，再把每项乘以 $A$，得到 $(A,Ac,Ac^2,A^2)$。依据首端的根 $c$，把第二项 $Ac$ 除以 $c^2$，得到末端的根 $c^2$。例如 $A=8$ 得到 $(8,16,32,64)$，末端的根为 $4$。输入 $A=2$ 不满足前提。输入 $A=1$（即 $c=1$）是明确标记的现代扩展，不属于这里所讨论的古代给定数；原始链以单位起始并不等于其给定的立方数也可取单位。

在本目录使用 Python 3.9+，仅需标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立对照列出候选立方及其整数平方根，与程序按二分寻找首端根、再传递到末端的步骤分别比较。枚举涵盖 1 至 10,000 的输入；有限测试不是一般证明。Notebook 日志记录标准库顺序实跑三个代码单元，不是 Jupyter 内核运行。
