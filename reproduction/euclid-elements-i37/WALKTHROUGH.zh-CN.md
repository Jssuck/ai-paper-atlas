# I.37：精确模型的证明与边界

## 1. 原证接口

原文三角形ABC、DBC共底BC，顶点位于同一条与BC平行的直线。延长上直线，过B作BE平行CA，过C作CF平行BD；补出的边界顺序是EBCA和DBCF。I.35使两平行四边形等积；I.34使AB和DC分别将它们二等分，于是两三角形等积。相等量之半相等是最后的量论步骤。

此处数学量“相等”是面积相等，并不要求形状可叠合。来源：[Heath原证转录](https://www.maths.tcd.ie/~dwilkins/Courses/MA232A/Euclid_ETexts/EuclidBookI_Heath1908/EuclidBookIProp37_Heath1908.php)。下文是现代教学重构，不是原文代数。

## 2. 一般坐标重构，不靠枚举作证明

设u=C−B，v=A−B，且叉积δ=det(u,v)非零；同一上支持线意味着D=A+tu，其中t是实数（程序只接收有理输入）。置E=A−u、F=D+u。

于是E−B=A−C，F−C=D−B；另外A−E=u、F−D=u。因此EBCA、DBCF各有两组对边向量相等，均非退化平行四边形。这个向量相等只是现代模型对原构造的核验，不是I.31使用平移工具的历史主张。

相对B计算：det(C−B,D−B)=det(u,v+tu)=det(u,v)=δ。三角形ABC、DBC的无向面积都为|δ|/2。两补图面积分别为|δ|；AB和DC两侧三角形的行列式绝对值均为|δ|，故各半面积为|δ|/2。这套一般恒等式是声明了行列式面积模型后的代数推导，不是用程序运行证明任意几何空间中的定理。

δ可正可负；取绝对值避免把反射后有向面积符号误当物理面积变化。参数t可任意正负或零；顶点投影不必落在BC线段内。t=0时A=D，原文用AD给直线命名会失效，但结论退化为同一三角形等积；模型通过A和非零u命名上支持线。非退化仍不可删。

## 3. 手算

B=(0,0)，C=(4,0)，A=(1,3)，D=(9,3)。u=(4,0)，δ=12，t=2。E=(-3,3)，F=(13,3)。ABC、DBC面积都是6，EBCA、DBCF都是12。AB切出的EBA也面积6，DC切出的DCF同样面积6。两三角形的AB和DB长度平方分别为10和90，故等积不等于这组对应下的全等。

## 4. 反例和非必要条件

- 改D=(9,4)，DBC面积8，原三角形6，失去同一上支持线就不能引用I.37。
- 改D=(9,-3)，DBC面积仍6，但D在BC异侧。等积结论为真不意味着“同一对平行线间”这个输入条件成立；生成器直接拒绝，不把拒绝解释成面积不等。
- 改A=(1,0)，三角形退化；零面积等式不足以认证原定理的非退化对象。
- 改BC为零线段，则不能确定基线方向，更不能因为叉积为零就接受。
- 平移所有点保面积，但改变被证明的输入，因此旧证书必须拒绝；程序证书绑定不是面积不变量分类器。

## 5. 实跑范围

672输入来自7个顶点位移、4个A投影、3个有符号高度、2个底长度和4组可逆线性坐标基；原点统一平移。包括A=D、负高度、分数、非正交基。9个非法输入直接调用生成器期待ValueError，避免空证书本身的格式错误掩盖几何漏检。单测另覆盖解析、字段和篡改。任意实数输入、所有退化边界及外部形式化证明内核不在运行覆盖内。
