# 《几何原本》X.10：正根的符号构造

给定正有理长度 `A=a` 和正整数 `B=b,C=c`，计算平方比 `q=C/B`；若既约分子、分母均为完全平方数便拒绝，因为命题所需的非平方比前提不成立。否则输出 `D²=a²q` 与 `E⁴=a⁴q`。这里取正根，因此 `E²=AD`，不必把无理根转成浮点数。函数 `construct(a,b,c)` 的返回值只存精确的 `Fraction`，不宣称能输入或判定任意实数。

例：`A=1,B:C=3:6` 时两种根量的底数都为 2，但 `D=√2`，而 `E` 是 2 的正四次方根，两者不是同一长度。`B:C=16:9` 时 `q=9/16`，不满足前提；`6:3` 仍满足前提，但方向倒转后 `q=1/2`。保持 `B:C` 不变的同比缩放不改变结果；换 `A` 则两个幂量分别按二次、四次缩放。

独立基线直接生成分子、分母在 1–8 的整数比例的平方，不调用 `isqrt`。在 `B,C∈1..64` 的 4,096 个有序输入对中，如果存在既约有理根，其分子、分母的平方分别等于既约平方比的分子、分母，因而该枚举界覆盖所有可能见证。实测 3,916 对构造成功，180 对按平方比前提拒绝。有限检验不是一般定理的证明。
