# II.16：证明依赖的有限教学实验

本目录是原创现代教学代码，不是古代算法复刻、自然语言谬误检测器或完整历史复现。

来源定位：[Aristotle, Prior Analytics, II.16，Jenkinson英译](https://classics.mit.edu/Aristotle/prior.2.ii.html)，尤其直接自证、经由中介回到待证项、同样未知并不足以断定循环的段落。完整史源、项关系和校勘见[正文](../../papers/ancient/aristotle-prior-analytics-ii16.zh-CN.md)及[来源台账](../../papers/ancient/aristotle-prior-analytics-ii16.sources.zh-CN.md)。这里只把命题作为原子标识，不自动把同义句合并。

## 模型与接口

- `Rule((P, Q), T)` 表示两个前提同时成立时可推出T，是AND超边，不是两个任选边。
- `closure(rules, seeds)` 从明确接受的外部事实起反复加结论，返回最小闭包。
- `supports(rules, target, candidate_facts)` 枚举候选外部事实子集，保留能导出目标的包含极小集合。极小不等于基数唯一最小。
- `semantic_consequences(rules, seeds, atoms)` 独立穷举该有限原子全集的二值赋值，取满足规则与种子的模型共有真原子，用于交叉核验。

程序拒绝空前提规则，外部根据必须放在seeds中；允许规则集合为空。规则前提为非空、不重复的字符串元组；结论和事实必须是非空字符串。规则迭代器会先材料化，不因多轮遍历或候选子集枚举被耗尽。原子全集缺项会报错，不静默丢失变量。

## 为什么闭包有数学根据

设初始集合为S，规则集合有限。每一步仅加入前提已在集合中的规则结论，所得序列单调递增；至多加入有限个新原子，故终止。归纳可知每个加入项在所有满足S和规则的模型中为真。反之，终止集合自身是模型：若某条规则的前提已包含，其结论终止时也必已包含。因此未在闭包中的原子不被语义必然推出。这是一般的有限正Horn系统论证，实际枚举仅检查实现的一部分，不能替代这段证明。

有环不意味着必无独立证明：若E是独立外部根据，E推出C、C推出B、B推出A，则即使另有A推出C仍能从E得到A。反过来，无环也不意味着已获得论证根据：U推出V、V推出T，但U未获接受时，T仍未被此程序推出。

`supports`列出的是“如果这些候选获得外部支持”的条件结果，绝不自动把候选授予知识地位。即使规则T推出T有效，空种子闭包仍不含T；如果输入把T作为seed，程序会显示它可达，但这不构成对T的独立证明。此处不处理自明性的哲学裁定，也不裁定现实前提的真假、优先性或共同意见。

## 12个情境如何读

1. 直接T→T：空seed不导出T，候选支持为{T}。
2. 三节点循环：空seed不导出A；A、B、C任何一个被外部接受才可启动。
3. 循环加外部E：E足以启动，不可仅见环即判整个论证循环。
4. 无关环：A/B环不妨碍独立E→T。
5. U未知未接受：U→T有效仍不能从空seed得到T；不自动断言乞题。
6. 同一规则、U被接受：形式不变，输入的外部根据变了。
7. 显式T/Q双向桥：无seed不自发产生T。桥必须明列，名字相似不够。
8. T→Q不可反用：Q为seed不推出T。
9. 循环和独立路线并存：最小候选支持含{E}与{T}，所选证明来源不同。
10. P和Q共同推出T，仅P不足。
11. 同规则，P/Q都接受则T可达。
12. 无环未知链：依赖图无环仍不提供缺失的起点。

## 边界与复核

结果没有“begging_question=true”字段，原因是单凭有限图不能裁定II.16的认识论语境。本实验仅核对显式记录的依赖。三段论项包含、谓词换位、非空条件和科学/辩证语境不由这个命题级程序自动认证。有关原文的这些主张以正文和独立来源审查为准。

更大原子集支持枚举是指数级；该教学实现未追求通用证明器性能。它不接受否定、不建模经典爆炸、不检查原始推理规则是否可靠；这些是模型范围，不是遗漏的测试结果。
