# I.38：保留限定的两步包含证书

这是原创的**现代教学重构**，服务于[中文深读](../../papers/ancient/aristotle-prior-analytics-i38.zh-CN.md)，不是古代程序的复刻，也不是一般知识逻辑或自然语言推理器。所读原文是 Bekker 49a11–49b2；Owen 1853 印163–164的完整本章区分“大项附有限定”与“换掉限定”。印164尤其说明以“存在者”为中项，不能仅凭该路线得出“作为善而可知”的结论。

## 模型与输入

- `Term(name, qualifier)` 是完整原子谓词标签。空字符串表示本模型选用的无附加限定标签；非空限定是不可自动拆解的不透明标签。
- `Inclusion(C, B)` 表示 C 的外延包含于 B 的外延。
- `Model(domain, extensions)` 给每个已定义标签一个域内集合。没有提供外延会抛 `KeyError`，而非把未知解释成假。
- `chain_certificate(C→B, B→A, C→A)` 仅核验两步证书的**结构**。完整中项和完整大项必须逐项匹配。它不验证输入前提是否真实，也不声称拒绝的结论必假或不存在其他证明。

名称 `knowable/as-good` 只是原文有关区分的教学标签，不是“主体知道命题”的模态算子。模型没有认知主体、可能世界、因果解释或自动翻译。两个标签可以碰巧同外延，程序仍不会凭词形把它们识别为同一项；若要引入额外桥接，须另给前提。

## 一般论证与有限检查

包含的传递性有独立的一般证明：任取 C 中对象 x，由 C⊆B 得 x∈B，再由 B⊆A 得 x∈A，因此 C⊆A。此论证可用于任意集合；下列枚举只是对实现的有限回归检查，不是这条定理的证明。

将 A 换成不同标签 R，得到的仍是 C⊆R，而非 C⊆A。一个对象即可作反例：C=B=R={0}，A为空。另一个反例令 C=B={0}、改过限定的中项 M=A={1}；C⊆B 与 M⊆A 真，C⊆A 假。程序检查这两个具体模型。

全称包含允许空主项、空论域，因此不会从全称句自动生出存在见证。这是明确的现代语义选择，不把它归给原章。`as-good` 与无附加限定标签之间也没有内置桥接；45个反模型各自表明本模型不保证两个方向的包含。它们不证明自然语言“作为……可知”绝不能蕴含某种较弱的可知命题；后者需要先约定语义并提供桥接。

## 文件与运行

只用 Python 标准库；真实环境见 [environment.txt](logs/environment.txt)。在本目录执行：

```sh
python -m unittest -v
python run_checks.py
python -O -m unittest -v
python -O run_checks.py
python -OO -m unittest -v
python -OO run_checks.py
```

没有采用会在优化模式被删掉的 `assert` 校验；`run_checks.check(False)` 明确抛错，其行为亦受单测检查。
