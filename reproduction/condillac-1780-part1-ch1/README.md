# Condillac《逻辑学》第一部第一章：有限观察的现代教学复现

## 先说明复现的对象

这是一份原创、仅用 Python 标准库的**现代约定模型**。它把阅读中的几个问题变成可执行的小例子：怎样区别对象，怎样用后续观察检验判断，什么情况下观察仍不能确定对象，以及为什么“感到满意”不是“判断正确”的同义词。

它**不是**Condillac写下的算法，不是对十八世纪实验的重跑，不是婴儿认知或偏见的经验心理学模型，也不证明他影响了任何特定人工智能技术。候选消除、有限状态、签名和纤维都是本教学包引入的现代术语。

本次对读的是所提供的 1798 年巴黎 Ch. Houel 版《全集》第 XXII 卷《逻辑学》第一部第一章，印刷页 5–15，对应所提供 PDF 第 13–23 页（PDF 页码从 1 开始）。标题页为 an VI–1798。目录名中的 1780 是作品年代标签，不表示本包阅读或复现了 1780 年初版。

原书链接：[IA/Wellcome1798扫描](https://archive.org/download/b28772581_0022/b28772581_0022.pdf#page=13)。原扫描的出版、年代、印字疑点与第二扫描补核见[来源账本](../../papers/1780/condillac-logic-part1-ch1.sources.zh-CN.md)；[主文](../../papers/1780/condillac-logic-part1-ch1.zh-CN.md)给出逐步论证与一般证明。代码不依赖原扫描或OCR文件。

## 一分钟运行

使用 Python 3.10 或更新版本；本次实际核验为 CPython 3.12.14，Linux x86_64。没有第三方依赖、下载、账号、网络请求或随机种子实验。

进入本目录后执行：

```sh
python3 -B walkthrough.py
python3 -B -m unittest -v test_model
python3 -B exhaustive.py
```

一次运行全部验证并保存真实日志：

```sh
python3 -B verify.py
```

verify.py 使用当前解释器运行上述程序，再用 -O 重跑穷举，比较普通和优化模式的结果，并编译检查全部 Python 源文件。它仅在本目录 logs/ 下写日志；重复运行会更新这些日志。它不是基准测试，不记录或比较性能优势。

已捕获结果：11 个 unittest 测试方法通过，其中输入验证方法包含 37 个非法输入子案例；另有不同判断路径的作者编写穷举日志。完整环境、实际命令、退出状态、时间和源码 SHA-256 见 logs/verification.json。每次核验会重写该文件，因此以随包日志为准。

## 历史文字与教学操作之间的边界

| 对读位置（1798 印刷页） | 本包采用的教学操作 | 没有据此声称什么 |
|---|---|---|
| 5–8：感官、运用感官以及练习的必要性 | 必须选择并接受一条观察 | 没有把感官或心灵理论实现成程序 |
| 9–10：从他人中分辨乳母；远处相似者引起误判，再看纠正 | 粗观察保留两候选，细观察区分；草率猜测与证据状态分开 | 场景标签和观察表是本包编造的，不是实测婴儿数据 |

## 模型与 API

### 约定

- 世界域 W 是非空、有限、顺序固定的不同字符串元组；真世界在 W 内。
- 每个 Observation 是一个命名的、总定义、确定性、无噪声的函数。outcomes 按 W 的顺序列出结果。具有相同结果的世界构成该观察的一个分块。
- 每条被接受的 Evidence 包含查询名和结果；Belief 完整保留历史，候选集从全部历史重新计算。相同观察重复两次会留下两条记录，但不额外区分世界。
- 初始候选为整个 W。真实输入、完整域、无噪声和不遗忘都是保证真世界不被排除的前提。
- 任一历史的候选集，就是该历史中观察结果联合签名对应的纤维。recognizes() 当且仅当候选数量为一时返回名字，否则返回 None。
- Model.fiber(w) 使用**全部可用观察**的完整签名。尚未查询的观察不自动提供知识：完整纤维为单元素，不代表当前历史已足够辨认。
- distinguishes(q) 仅判断 q 在**当前候选集**上是否产生至少两个不同结果。在当前状态仍包含真世界时，接受这样的真实反馈会严格缩小候选集。
- 没有预设概率、置信度、统计推断、学习出的观察函数、噪声处理、数据集或最优查询策略。

### 可调用对象

- Observation(name, outcomes)：一个观察函数；不接受空结果表。
- Model(worlds, observations)：有限域和函数表；允许 observations=()，即没有可用观察。
- Belief(model, history=())：不可变证据状态；history 必须是 Evidence 元组。
- Belief.observe(query, outcome)：接受调用方给出的结果，返回新状态。检查域和一致性，**不验证结果真实与否**。
- Belief.consult(query, true_world, accept=True)：用于演示的外部“环境”助手，从表中产生真实反馈。true_world 是模拟器提供的，普通 observe/recognizes 不接收真值。
- accept=False：返回原状态，不增加证据。参数仍须合法。
- Belief.candidates：与全部保留证据一致的世界，按原始世界顺序排列。
- Belief.recognizes()：单候选名称或 None；输入如果一致但不真实，也可能得到错误的单候选。
- Belief.distinguishes(query)：该查询现在是否有区分力。
- Model.signature(world)、Model.fiber(world)：全部可用观察的签名及等价类。
- judge(model, guess, true_world, satisfied=...)：返回 Judgment(correct, satisfied)。两者分开记录，不改变 Belief。

所有集合输入都要求 tuple，标识与结果要求非空且不全为空白的 str，布尔开关只接受 bool（不把 0/1 当作布尔值）。世界名、查询名不能重复；表长必须与世界数一致。类型不符抛 TypeError，域值不符抛 ValueError；会消灭全部候选的历史抛 InconsistentEvidence（ValueError 的子类）。失败不修改旧状态。这里的不可变使用 frozen dataclass 和元组，不承诺防御恶意绕过 Python 对象机制的代码。

## 穷举边界与实际计数

exhaustive.py 穷举 n=1,2,3,4；每个模型恰有两条二值查询；两张函数表的每个位置取 0 或 1；遍历每个真世界和长度 0–3 的全部查询序列（包括重复查询），反馈始终取该真世界的真实表值。查询名和世界名只起标签作用，固定为 q0/q1、w0/w1/…。

- 模型：sum(2^(2n)) = 4 + 16 + 64 + 256 = **340**。
- 模型与真世界组合：sum(n × 2^(2n)) = **1,252**。
- 每种组合的历史：1 + 2 + 4 + 8 = 15；合计 **18,780**。
- 每种组合的逐步转换：0×1 + 1×2 + 2×4 + 3×8 = 34；合计 **42,568**。
- 其中实际有区分力且严格缩小候选的转换：**20,256**。
- 每一步同时检查拒绝反馈不改变原状态：**42,568** 次。
- 查询两条观察后的完整纤维检查：**1,252** 次。
- 对完整签名相同的不同世界，在每个历史检查其仍保留：**13,080** 次（有向“真世界—另一世界—历史”检查，不能理解为 13,080 个不同世界对）。

这些计数彼此有重叠，不能相加当作独立实验总数。运行时重复构造相同前缀，也会在转换数中再次计数。这是刻意的小规模穷举，不是对任意大空间的承诺。

### 作者编写的对照 oracle 与独立审计有何区别

被测程序以字符串表和保留历史计算候选；oracle 直接用生成的整数数组和索引，按“所有已问查询的值与真世界相等”计算应保留的世界。预测结果不调用被测程序的 outcome、candidates、signature 或 fiber。这份oracle与模型由同一作者编写，只是判断路径不同，不等于独立审查者复核。另行进行的独立代码审计及其不同实现、真实日志见[independent-review](independent-review/review.zh-CN.md)。两种检查均不保证数学上或工程上的零共因。

穷举检查真世界保留、候选不增长、区分查询严格缩小、无区分查询不缩小、历史保留、拒绝不更新、单候选辨认以及不可区分者保留。额外 unit tests 覆盖零查询、错误但一致的输入、矛盾输入、非法参数、满足感反例和不可变状态。

**测试只支持这些有限实例上的实现一致性，不替代一般数学证明。** 任意有限模型的性质需要配套文章中单独陈述前提并证明；这里不会把 340 个模型的穷举写成“证明了Condillac”。
