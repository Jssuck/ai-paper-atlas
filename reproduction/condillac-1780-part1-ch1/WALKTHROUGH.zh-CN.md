# 五步跑通这个例子

运行 python3 -B walkthrough.py。以下解释对应 logs/walkthrough.txt 的实际输出；三个“人物”、观察结果和真世界全部是人为指定的。

## 1. 看见相似，不等于认出对象

域中有 nurse、lookalike、visitor，分别可读作“乳母”“相似者”“访客”。我们指定实际出现的是 lookalike。

distant_view 把前两者都映成 familiar，把访客映成 unfamiliar。因此，接受“远看熟悉”以后，保留 nurse 和 lookalike。recognizes() 仍为 None。

此时，故事中的人草率猜 nurse；模拟器知道这是错的，也人为设定 satisfied=True。这个猜测没有被偷偷写入观察历史：程序的证据状态仍保留两名候选。

接着 closer_view 分别给三者不同的脸部标签。真实结果是 face_B，只剩 lookalike。历史里同时保留 distant_view=familiar 和 closer_view=face_B，初始状态未被改写。

这示范的是“更有区分力的新观察排除旧猜测”。它没有模拟含噪感知，也没有在第一步错误删除真世界以后凭空恢复它。

## 2. 拒绝咨询经验

从第一步的两候选状态重新开始，把 accept 设为 False。closer_view 本来可以区分这两人，但被拒绝了。程序返回同一个 Belief 对象，候选和历史完全不变。

此处的偏见不是算法学习出的心理特征，而是一个人为设定的“不接收反馈”动作。它只能说明：在本模型里，没有新增证据就没有这一步纠正。

## 3. 多问几次也可能无用

另建 A、B、C 三个世界：A 和 B 的 shape 都为 round，sound 都为 soft；C 对应 square 和 loud。真世界指定为 A。

按 shape、sound、shape、sound 查询四次，A 和 B 都保留。A 的完整签名纤维是 (A, B)，因此不可能只凭这两种观察辨认 A。

这区分了两种障碍：第二步是“有能区分的观察但拒绝使用”；第三步是“现有观察本身就没有区分力”。重复次数不是缺失信息的替代品。

## 4. 满意感不充当正确性测试

judge 枚举错误/正确猜测与不满意/满意两种状态，共四种组合。它不改变任何候选集。

“错误且满意”是本包明确允许的反例，因此这里不能由 satisfied=True 推出 correct=True。这只是约定模型内的逻辑关系，不是对真实人的情感概率、相关性或因果关系的测量。康狄亚克关于紧迫需要下的痛苦/快乐提示，与他对好奇心满足于错误的警惕，也不应被压成无条件的奖励信号理论。

## 5. 练习只是重复执行

最后对三个世界分别执行 distant_view 和 closer_view，每次从空历史开始。三次均得到唯一候选，各保留两条观察。

这让读者熟悉操作规则，但程序并未因为练习而学到新观察函数、加速或形成习惯。原文跨页脚注谈长期练习；这里的三次运行不能检验那个心理学主张。

## 接着验证什么

运行 python3 -B -m unittest -v test_model 可检查边界与失败情况。尤其注意 test_false_consistent_input_can_mislead：输入在模型内一致，仍可能是假输入，使程序认错对象。程序的“唯一候选”保证始终带有前提。

运行 python3 -B exhaustive.py 可重现有限 oracle 枚举。范围和计数见 README.md。它验证实现没有在这些小模型中违反约定，不承担一般定理证明或历史主张验证。
