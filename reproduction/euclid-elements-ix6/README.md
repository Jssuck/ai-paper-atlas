# 《几何原本》IX.6：从平方是立方推出原数是立方

正整数教学重构：给定 $A$，先检查 $B=A^2$ 的立方根 $b$。已知 $b^3=A^2$，可构造四项 $(b^3,b^2A,bA^2,A^3)$。全链各项除以 $A$，分别得到 $A,b^2,bA,A^2$；每次整除只用给定恒等式，并不预设 $A$ 为立方。程序再计算 $A/b$ 并核对其立方为 $A$。例如 $A=8$ 时两链为 $(64,128,256,512)$ 与 $(8,16,32,64)$，恢复的根为 $2$。输入 $1$ 标为现代扩展。

在此目录运行，需 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线预先枚举立方表，分别判定 $A$ 及 $A^2$ 的成员资格，再用精确分数按乘率幂核验两条链；$A$ 取 1 至 10,000。有限核验不是一般证明。Notebook 日志来自标准库实际回放三个代码单元，并非 Jupyter 内核运行。
