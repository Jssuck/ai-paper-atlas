# 《后分析篇》I.24：范围、桥梁与解释的最小教学模型

对应[正文](../../papers/ancient/aristotle-posterior-analytics-i24.zh-CN.md)，完整85a13–86a30。本目录只重构几种可机械核查的边界，不复现Aristotle的全部科学知识理论，不认证真正的本质或原因。

## 1. 要核查的五个问题

1. **范围限制。** 在同一个有限宇宙中枚举三个集合S、G、P。已知S包含于G、G包含于P，可以推出S包含于P；已知S包含于G和P，却不能反向推出G包含于P。这里的包含只是外延语义，不是“由于自身”的定义。
2. **明示桥梁。** 正命题Horn闭包把“所有三角形有指定角和”和“等腰类是三角形类”共同作为规则前提。缺后者时程序不输出等腰结论。该程序规则不是86a24–28的潜在知识定义：原文恰谈尚未知归属时仍某种潜在掌握，本文只展示显式推导需要哪些材料。
3. **换属性会换范围。** 对3至8边的平面凸欧氏多边形，假设已知内角和公式(n−2)×180度；外角和逐项为n×180减内角和。程序只做整数算术，不用几个多边形证明一般几何定理；不覆盖球面、双曲面、自交曲线、凹角的符号约定等。
4. **同名不同义。** 现代自造英文crane例中，鸟义与机器义作为不同键。若仅凭拼写合并就会造成错误属性传递。这不是原文的例子，也不是英文词义研究。
5. **同扩展不认证原因。** 两个任意标签有相同扩展且都满足P，只能判外延相合。程序返回“causal_status: undetermined”，它没有原因判定器。

## 2. 一般证明与有限实跑分开

范围限制的一般证明并不依赖枚举：任取x属于S，由S包含于G得x属于G，再由G包含于P得x属于P。逆向失败由S=P={0}、G={0,1}给出，不依赖空主项。

有限Horn闭包每轮只添加规则结论中的新原子；有限结论集耗尽后必停止。它是已声明规则系统的最小闭包。单调性、幂等性、空前提、循环及合取前提都有测试。闭包中出现的字符串不能因此被称为真实知识；规则本身真实性、含义一致性和因果相关性均在模型外。

原文“普遍”也不能直接替换为集合更大，或把“特定证明”误当成逻辑中的特称命题I/O。这个程序没有尝试为所有证明做优劣排名。

## 3. 本次真实结果

详见[results.json](results.json)、[运行日志](logs/model.log)。宇宙大小0、1、2、3、4的全部三集合赋值：

- 赋值总数4681，即各大小的8^n之和；包含空宇宙与空集合。
- 正向两包含前提成立341例，即4^n之和；结论违规0。
- 逆向错误推广反例440，其中S非空220；最小非空见证S=P={0}、G={0,1}。
- 缺归属桥梁时，等腰结论不在显式规则闭包中；增加桥梁后可推得。初始事实集未被原地改写。
- 多边形n=3至8，内角和只有n=3等于180度；依已知公式算出的外角和均360度。
- 同名合并错误和同扩展原因未定两种边界均展示。

[测试](test_model.py)使用unittest断言，普通、-O、-OO模式各20项通过。它们不是会在优化模式中被删掉的Python裸assert。测试日志：[普通](logs/tests.log)、[-O](logs/tests-O.log)、[-OO](logs/tests-OO.log)。这组有限验证只能帮助检查实现，不能替代一般集合证明，更不能证明原典哲学前提。

## 4. 文件、环境与命令

只用Python标准库；环境见[environment.json](environment.json)，完整命令见[commands.txt](commands.txt)。在本目录执行：

```sh
python model.py > results.json
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python verify_notebook.py
```

[model.py](model.py)给出纯函数与演示；[i24_teaching.ipynb](i24_teaching.ipynb)含四个短代码单元；[verify_notebook.py](verify_notebook.py)用新Python进程中的共享名字空间从上到下真实执行，保存stdout和执行序号，见[Notebook日志](logs/notebook.log)。本环境没有nbformat、nbclient、ipykernel，未擅自安装，因此**不是Jupyter内核执行或Jupyter前端兼容性全验收**。已读安装的Notebook技能，所述本地scaffold脚本不可用，故按标准nbformat4结构生成，非伪造运行输出。
