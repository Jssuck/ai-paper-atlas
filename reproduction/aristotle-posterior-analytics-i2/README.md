# 《后分析篇》I.2：形式有效性与说明根据的最小分层实验

对应[正文](../../papers/ancient/aristotle-posterior-analytics-i2.zh-CN.md)及[来源台账](../../papers/ancient/aristotle-posterior-analytics-i2.sources.zh-CN.md)。本目录是原创现代教学代码，不是复现古代实验，更不是能够自动认定科学知识的程序。

## 1. 原文动机与实验问题

实际对读[Mure转录Part2](https://classics.mit.edu/Aristotle/posterior.1.i.html)。原文区分一般三段论与产生科学知识的证明；列举真实、初始、直接、较熟知、在先和原因等要求，并区分“对我们”与“不加限定”的认识次序。后段讨论起点的公理、设定、假设、定义，以及前提与结论的确信关系。本实验只把这些区分转成可检查的输入层，绝不把标签齐全当作原文理论获得验证。

**主要问题：保持真值语义完全不变，只改变所声称的解释根据，结果会怎样？**

## 2. 有限模型及接口

`model.py` 使用三个未解释布尔原子，8个完整真值赋值。一个0至255的整数表示在这8个赋值中为真的世界集合，第w位表示世界w。没有概率、时间变化或必然性算子。

- `entails(premises, conclusion)`：所有前提共同为真的世界里结论均为真。无共同真世界时经典有效性空泛成立，代码没有将其称为知识。
- `counterworlds(...)`：列出共同真前提而结论假的世界编号。
- `Premise`：名称、真值mask、外部声明的初始性/直接性、优先级、确信级。
- `Candidate`：前提组、结论名称及mask、指定实际世界、结论优先级/确信级、外部声明的有向原因链接。
- `inspect_candidate(...)`：分别返回7个检查值、所有检查的合取`declared_policy_pass`，以及永远为False的`scientific_knowledge_certified`。
- `classify_starting_point(...)`：在已给定“直接起点”的教学前提下，按显式描述区分axiom、hypothesis、definition。`existence_assertion=False`是明确否认存在，仍属假设分支；`None`才表示未作存在断言。

7个检查由“有限域有效性”加“指定实际世界中前提真、初始声明、直接声明、严格确信政策、优先级政策、原因链接声明”组成。后一组并非6个客观事实的自动发现器。

优先级数字越小表示所声明的解释次序越先；确信级数字越大表示更确信，二者不能互换。程序不推导“对我们更熟悉”等于“自然次序更先”。这些整数是教学序数，不是测量值或贝叶斯概率。默认例采用**每一个**前提确信级严格高于结论的加强条件；这是一个明确偏强的政策，用于展示条件独立性，**不是**原文“某些，若非全部”句的必要充分翻译。等确信级会在本政策下失败，不据此宣布古代解释必然失败。

## 3. 可手算的例子

默认前提p为mask170（二进制10101010），结论q为238（11101110）。p的真世界是1、3、5、7，q另含2、6。因此p蕴涵q，但q不蕴涵p，反世界为2、6。指定实际世界1时两者真；改为0时前提与结论都假，蕴涵判断不变。

给默认例填满初始/直接声明，p优先级0而q为1，p确信3而q为2，声明原因链接p→q时，所有政策检查通过。删除链接不改变任何真值，却使原因声明检查失败。更重要的是：即使保留链接，程序也没有独立证据知道其确实是原因，所以“科学知识认证”仍为False。

把q改成与p相同的mask可令双向蕴涵同时成立。若不声明原因链接，程序不自动生成任一方向。这只显示**所给形式语义未编码解释方向**，不证明世界上不存在原因，也不否认某些领域有额外因果理论。

## 4. 运行方法与真实结果

仅需Python标准库；本次环境见[environment.json](environment.json)。在本目录执行：

```sh
python3 -m unittest -v test_model.py
python3 -O -m unittest -v test_model.py
python3 -OO -m unittest -v test_model.py
python3 exhaustive.py
python3 -O exhaustive.py
python3 -OO exhaustive.py
```

本次实际运行：18个单元测试在normal、-O、-OO下均通过，使用unittest断言而非可被优化移除的裸assert。原始stdout/stderr与命令保存在[normal测试](logs/tests-normal.log)、[-O测试](logs/tests-O.log)、[-OO测试](logs/tests-OO.log)。

枚举所有256×256=65,536对真值mask，其中6,561对满足单前提蕴涵。`exhaustive.py`按世界逐位计算蕴涵作为oracle，与生产代码的位集合包含判断逐项比较，差异0。固定默认语义，枚举5种二值元数据开关共32种组合，仅全部开关满足的1种通过所声明政策。结果见[results.json](results.json)，三模式原始枚举日志见[normal](logs/exhaustive-normal.log)、[-O](logs/exhaustive-O.log)、[-OO](logs/exhaustive-OO.log)。这份oracle由实现者编写，属于不同算法交叉核对；另行独立审查由正文所链接的技术审查报告说明，不能把自检冒充独立审稿。

6,561可手算为3的8次方：每个世界允许(p,q)为(0,0)、(0,1)、(1,1)，不允许(1,0)。这一计数解释是对当前有限模型的一般组合推导；其证据地位不扩展到亚里士多德全部科学知识理论。

## 5. 明确没有复现的内容

没有古代训练数据、受试者、真实因果干预、科学发现或人的确信测量。初始、直接、原因等都是输入声明；未实现它们的充分语义，也未核验“结论不可能另样”的形而上学要求。定义分类只追踪有没有存在断言，不从定义生成对象。有效性检查不考虑具体科学领域的适切性；政策通过仅表示此记录满足所写的强条件，不是科学证明的充分条件。有限枚举不替代一般证明，更不能认证原文唯一释义。
