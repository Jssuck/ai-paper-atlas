# 《几何原本》卷 V 命题 5：整倍数遇到减法

[回到中文精读](../../papers/ancient/euclid-elements-v5.zh-CN.md)。本附件比较两种构造。四个输入先统一量类和计量单位；程序只检查量类标签，不做单位换算。两个去掉的量都必须为正且严格小于各自的全量；两个全量与两个去掉的量分别共享同一个至少为 2 的整数倍。程序不把零当成可量尽的正量，也不把非整数比例当成这里的整倍。

- 原证路线：先用大余量除以共同倍数，得到小余量候选。将它与小去量相加，再用 V.1 核对重建的全量；同倍消去和减去相同部分给出所求。
- Simson 的加法路线：从已知小余量重复相加，得到大余量候选。与大去量合成新大全量，再以 V.1 对照原大全量并消去相同部分。在这一构造步骤不需要把给定量任意等分；验证输入前提时仍用精确除法读取共同整数倍。
- 数值示意：大全量 15，小全量 5；去掉 6、2。除法路线得到候选 3、重建小全量 5；加法路线得到候选 9、重建大全量 15。大、小余量 9、3 仍为 3 倍。
- 对照：把大去量换成 4，两个去量仍为真部分，但去量倍数 2 不等于全量倍数 3，不能套用本命题。即便数值意义的缩放公式对分数系数也成立，本程序也不把这种扩展算作原前提。

## 环境和运行

仅用 Python 3.12.14 标准库，在本目录执行：

```sh
export PYTHONDONTWRITEBYTECODE=1
python --version
python remainder_multiples.py
python -m unittest -v
python -O -m unittest -v
python -OO -m unittest -v
python replay_notebook.py
```

三个 Python 模式各通过 11 项测试。网格覆盖两类同类量，每类用三种小去量及三种小余量，配四个整数倍数，合计 72 个合法例。每例再把大去量增加半份小余量，在仍为真部分的情况下构成 72 个错配拒绝例。另测零、负值、浮点输入、量类混用和非整数共同倍数。日志仅统一显示的测试耗时。

环境无可用的 Jupyter 命令与模板脚本；三个代码单元由标准库顺序编译、执行，未启动 Jupyter 内核或前端。这里检验的是有理数教学模型与两个构造路径；不能由此证明古代模型中的任意量均可等分，也不能以有限测试代替原命题的证明。
