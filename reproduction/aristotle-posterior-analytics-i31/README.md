# 《后分析篇》I.31：观察、全称与原因的最小教学实验

对应正文：[中文深读](../../papers/ancient/aristotle-posterior-analytics-i31.zh-CN.md)。范围为 87b28–88a17。

这里运行的是**原创现代教学重构**，不是古代实验复现、原文逐式形式化或自然科学验证。原文中三角形、月食、玻璃与光的例子不在本程序中做物理实测。

## 问题与假设

声明封闭有限域 `U={0,...,n-1}`，假设类是其上全部 Boolean 函数。每条观察是 `(位置,真值)`；无噪声、时间不变、身份无误。相容模型满足所有观察。

若 `k` 个不同位置均被观察为真，剩余 `n-k` 个位置独立选择真假，所以相容模型数为 `2**(n-k)`。当 `k<n`，把一个未见位置置假而保留所有已见位置为真，即构造反模型；当 `k=n`，只剩全真赋值。后者只确认**该已声明有限域**的全称，不确认未知对象、未来时间或原因。反模型结论也依赖假设类确实包含全部赋值；限制假设类可能改变它。

重复相同观察不添加新约束。包含负观察则全真赋值被排除。矛盾观察令相容集合为空；`report` 显式报告不一致，不以空模型类的逻辑空真冒充经验确认。`n=0` 的现代集合语义另行展示为空域空真，并不归于亚里士多德。

第二模型人为规定两机制：`Y=X` 与 `Y=Z`。若观察条件始终 `X=Z`，输出相同；设定 `X=True,Z=False` 后输出不同。称其为干预必须额外规定结构方程及保持 Z 不变的操作，这不是从观察识别出的自然因果律，更不是关于月食或光学的发现。

## 真实结果

| 四位置观察 | 相容模型数 | 全称在全部相容模型为真 |
|---|---:|---|
| 无观察 | 16 | 否 |
| 两个不同位置真 | 4 | 否 |
| 上述观察各重复五遍 | 4 | 否 |
| 四个位置均真 | 1 | 是，仅此有限域 |
| 一个位置假 | 8 | 否 |
| 同一位置真假冲突 | 0 | 不一致，不当作确认 |

详见 [results.json](results.json)。两个机制在两条 `X=Z` 观察上都输出 `[false,true]`，规定的干预则分别输出 `true`、`false`。

## 能说明与不能说明

这是有限枚举结果与配套计数论证，不是通过小实验“证明一般定理”。它帮助区分眼前实例、外延全称、解释性原因；不把 I.31 读成反经验主义，也不证明反复观察永远无用。原文谈到从多次感知取得普遍者与某些观察可结束疑难；本模型并未模拟这种抽象、直观或第一原理获得过程。
