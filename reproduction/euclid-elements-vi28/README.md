## 对照与限制

- 固定总底 L、同形缺块的高宽系数 r，给正目标面积 S。令 m=L/2，最多能取 r·m²；超上界或非正输入拒绝构造。与中点的平方间距为 q=m²−S/r。现代坐标下两个缺块底是 m−√q 和 m+√q；当 q=0 两个值合一，不把另一分支归给欧几里得的原文操作。目标零面积仅产生端点的退化极限，未纳入构造。
- L=10、r=2 时，目标 32 对应间距 3、缺块底 2 与 8；目标 50 唯一给缺块底 5。目标 49 的平方间距是 1/2；两分支仍提供精确的面积证书。返回 `None` 表示这两根非有理数，不是没有实数解，也没有虚构无理坐标。
- 180 个有理配置（4 种总底 × 3 种高宽比 × 5 种缺块底比例 × 3 种偏斜），从坐标的鞋带面积生成目标，再通过平方间距恢复全部有理解；其中 36 个是中点配置。另以 27 个独立参数组合核对半底图上两个对角块、两个补形的面积、两个补形相等和剩余曲尺形面积。工作例小块面积 18，两个补形各 12，另一角块面积 8，曲尺形面积 32。拆分是现代坐标实现。
