# 模型说明：习惯如何重现观念，而不是储存观念

本模型是针对 Condillac《La Logique》第一部第九章的原创、可执行教学重构。依据为 1798 年版印刷页 72–94，PDF 第 80–102 页。1780 仅为已核一版书目年；未独立认证最早版次、1780 年版页码或文字。文件夹中的 1780 不表示本次使用了该年扫描。

它不是 Condillac 曾经提出的算法，不是脑机制复原，也没有神经科学或心理学验证。原文把记忆的物理、偶因条件归于已习得的运动习惯，同时多次承认机制未知。本模型只把若干结构关系做成可检验的规则；规则错误或成功，都不能直接证实或反驳他的整套哲学。

## 1. 原文约束与现代补充

| 原文范围（印刷页） | 本模型保留的结构问题 | 本模型自行加入的假设 |
| --- | --- | --- |
| 72–78 | 区分可观察现象、类比和不知道的机制；感官与脑的传递 | 离散字符串、离散时间与明确的接口开关 |
| 79–82 | 反复练习形成身体习惯；由手指类比脑的习惯 | 正整数计数的强化，不模拟快乐、痛苦或探索学习 |
| 83–85 | 当前观念会消失，重现依赖持续的习惯；反对观念仓库图景 | 单个暂时事件与稀疏反应表分离 |
| 85–88 | 最初刺激引出一串习惯运动；顺序混乱；内在重现可能被误当成外在所见 | 有上下文的一阶续接、并列即报告歧义、显式来源标签 |
| 88–90 | 脑、手指、耳朵等相互作用；记忆并非仅在一个部位 | 分开学习的传入、传出表；不宣称字符串等同器官活动 |
| 90–94 | 梦的重组；不练习、习惯过多以及通路受扰与记忆损失有关 | 固定量遗忘、边数容量及最弱最旧淘汰；不模拟疾病、衰老或梦 |

神经、动物精气、灵魂与身体的历史语境不能被程序中的数据结构偷偷替换。我们没有把原文断言当成今日医学事实；尤其不据此解释现实的失忆、瘫痪或幻肢感。

## 2. 对象、符号与状态

以下每个数学符号都在首次出现时定义。数学只是规定这个程序做什么。配套主文中的符号集合 $`V`$ 对应这里的 $`X`$，预算 $`B`$ 对应这里的 $`L`$；本文件第 8 节的 $`V_c`$ 专指传出习惯表，不是符号集合。

- $`X`$：一次实验使用的非空观念符号集合。程序用非空字符串，如 A 或 do。符号不是实际的观念体验。
- $`C`$：上下文标签集合。程序用字符串，空字符串表示未提供上下文。上下文由实验者提供，并非系统自动识别曲名。
- $`\bot`$：结束标志 END；它不属于 $`X`$，程序用 None。结束与没有学到续接是不同情况。
- $`x,y`$：当前符号和候选后继；$`x\in X`$，$`y\in X\cup\{\bot\}`$。
- $`c\in C`$：一次回放中固定不变的上下文。
- $`W_c(x,y)\in\mathbb N_0`$：从 $`(c,x)`$ 到 $`y`$ 的习惯强度。$`\mathbb N_0`$ 表示包含零的非负整数；未存边的强度为零。
- $`K`$：每张表最多保留的边数，为正整数或无限；程序用 None 表示无限。它不是脑容量，也不是总信息比特数。
- $`b(e)`$：当前保留边 $`e`$ 最近一次由不存在变为存在时的插入序号。
- $`N`$：下一个可分配的插入序号，从零开始。删除边不减小它。
- $`M=(W,b,N)`$：在容量参数 $`K`$ 固定时，中央表的完整持久状态。有限容量的后续演化依赖插入顺序，故不能只写成 $`W`$ 而忽略元数据。
- $`a`$：当前观念事件，或空值。事件含符号与来源；清除 $`a`$ 不清除 $`M`$。
- $`L`$：一次回放允许的最大转移判定次数，为非负整数。终止判定、缺失判定和歧义判定也各消耗一次。

程序返回的 Replay、EmbodiedReplay 和日志保存的是实验者看到的轨迹。它们不是下一次回忆会查询的内部经历库。内部只保留三个习惯表和至多一个当前事件；程序当然仍用符号与数值表示倾向，不能据此证明哲学上的“非表征主义”。

## 3. 练习、遗忘与容量

### 3.1 一次序列练习

给定非空序列 $`s=(x_0,\ldots,x_{n-1})`$，$`n`$ 是符号数。定义 $`x_n=\bot`$。按顺序对 $`i=0,\ldots,n-1`$ 执行：

```math
W_c(x_i,x_{i+1}) \leftarrow W_c(x_i,x_{i+1})+1.
```

因此长度为三的 A、B、C 学到 A→B、B→C、C→END 三条边，不能遗漏终止边。重复次数 $`r`$ 为正整数；程序依次重复完整序列 $`r`$ 次。共享符号会聚合出竞争后继，程序不暗中为它们添加位置编号。

在无容量淘汰的条件下，若 $`q_c(x,y)`$ 是一次练习中某条边的出现次数，则 $`r`$ 次练习后的强度为：

```math
W'_c(x,y)=W_c(x,y)+r q_c(x,y).
```

$`W'`$ 表示更新后的表。有限容量时，逐边淘汰会改变这个公式，不能把离线总次数公式直接套上去。

### 3.2 明示的容量规则

每次加一后，如果边数超过 $`K`$，删除按“强度最小，其次插入序号最小”选中的一条边。即选择 $`(W(e),b(e))`$ 字典序最小的边；这里 $`W(e)`$ 是边 $`e`$ 的强度。

这不是遗忘的经验定律。它只是让容量干扰可复现、没有随机种子依赖。一个新加入的弱边可能立即淘汰自己；先前强边也可能阻止新习惯累积。每张表最多有 $`K`$ 条边，但强度和序号是无上限整数，因此不能声称程序只有固定的比特存储量。

### 3.3 明示的遗忘规则

一次调用 forget(d)，其中 $`d`$ 是非负整数遗忘量，对每条边作：

```math
W'_c(x,y)=\max\{0,W_c(x,y)-d\}.
```

零强度边及其插入元数据被删除。没有时钟自动衰减；“一天”“一个月”都不对应任何 $`d`$。调用者负责决定何时练习、何时衰减，回放、感知与反馈本身均不会自动强化。

如果某边初始强度为 $`w`$，每轮减一且从不再练习、无其他改变，则它在第 $`w`$ 轮恰好消失。这是该规则的代数结果，不是人类遗忘曲线。均匀相减不会把一个严格胜者变成仍为正的原有较弱边的败者；它可以使全部边最终消失。练习竞争和容量淘汰才提供另一类干扰。

## 4. 检索规则与完全恢复定理

### 4.1 唯一胜者

对于某一行 $`(c,x)`$，把所有候选后继的最大正强度作为检索依据：

- 没有正强度边：missing（缺失）
- 最大强度由至少两个后继并列取得：ambiguous（歧义），不靠字典插入顺序猜测
- 只有一个最大值：chosen（选中）；选中 END 则结束，否则生成一个新符号

开始时输出提示符号 $`x_0`$，再重复上述判定。到 $`L`$ 次还未停止，返回 budget（预算用尽），并保留已产生的前缀。预算不是生理疲劳参数，只是保证有限计算的保护。

### 4.2 必要且充分条件

固定 $`M`$ 与 $`c`$，回放期间不练习、不遗忘、不改变上下文，目标为长度 $`n`$ 的 $`s`$。从目标首符号开始。若 $`L\ge n`$，程序以 end 停止且输出恰好为 $`s`$，当且仅当对每个 $`i=0,\ldots,n-1`$：

```math
W_c(x_i,x_{i+1})>
\max\left(\{0\}\cup
\{W_c(x_i,z):z\in X\cup\{\bot\},\ z\ne x_{i+1}\}\right).
```

$`z`$ 是其他候选后继。右侧的零保证所需边确实存在；最后一个不等式把 END 与普通续接一起比较。

证明：充分性用位置归纳。初始输出是 $`x_0`$。若目前最后符号为 $`x_i`$，不等式保证唯一胜者就是 $`x_{i+1}`$；非终止时追加它，终止时返回 end。经过 $`n`$ 次判定恰好结束。必要性反向读取执行：程序只有在 chosen 时才产生目标的下一符号，只有在唯一选择 END 时才以 end 返回；所以每步必满足该严格不等式。

注意：“刚刚练过这条曲子”不是充分条件；“存在正确路径”也不是充分条件。规则实际选择的每条边都必须胜过竞争边。

### 4.3 固定上下文的一阶限制

若两个目标在同一 $`(c,x)`$ 要求不同后继，就不可能同时满足唯一胜者条件。无论增加多少相同训练，都不能使同一行同时唯一选择 B 与 C。

更强的结论：固定上下文、固定转移规则下，任何以 END 正常结束的确定性回放，都不能在结束前重复同一符号。若先后两次到达相同状态，它们之后的演化完全相同；第二次到达会形成循环，不能恰好只在第二次选择另一个后继或 END。因此单独训练 A、B、A、C 已超出此模型的精确序列能力。

在单个序列、无限容量且从空表开始的特例中，精确恢复等价于序列中所有符号互异。互异时每行恰好有一条后继；有重复时以上结论排除精确恢复。测试穷举字母表 {A,B,C}、长度 1–5 的 363 条序列，只有 15 条互异序列满足这个条件。这里 15 是有限模型计数，不是记忆正确率的心理学估计。

## 5. 练习保证的正确适用范围

设目标序列符号互异，容量无限，已有表任意，接下来只重复练习此目标而不遗忘。每个目标行每轮增加一条所需边，同行竞争边不增加。

令 $`u_i=W_c(x_i,x_{i+1})`$ 是当前目标边强度；令 $`v_i`$ 是该行其余边与零的最大值。则额外练习 $`r`$ 次足以完全恢复的最小非负整数为：

```math
r_{\min}=\max_{0\le i\le n-1}\max\{0,1+v_i-u_i\}.
```

如果此数是零，不必再练；practice API 只接收正重复次数，零次对应不调用它。证明由每行条件 $`u_i+r>v_i`$ 直接得到。

一旦目标内部重复状态，目标本身可能同时强化同一行的不同后继。不能继续使用这个公式。若容量有限，某个弱新边可能每次出现都被立即删除，也不能保证多练会成功。

## 6. 历史信息丢失的不可能性

设两个不同训练历史为：

- $`H_1`$：A、B、A、C、A、B、A、C、A
- $`H_2`$：A、B、A、C、A、C、A、B、A

分别从空表训练一次，使用相同上下文且容量无限。两者都有以下计数：A→B 为 2，B→A 为 2，A→C 为 2，C→A 为 2，A→END 为 1。边首次出现的顺序也同为 A→B、B→A、A→C、C→A、A→END；因此 $`W`$、$`b`$、$`N`$ 全部相同。

令 $`F`$ 表示“把训练历史编译为完整持久状态”的函数，则 $`F(H_1)=F(H_2)`$ 且 $`H_1\ne H_2`$。假设存在一个只读取该状态与相同提示的解码器 $`D`$，可以对所有历史还原原顺序。它对同一输入必须给出同一结果，却被要求分别输出两个不同历史，矛盾。

这不是只针对唯一最大值解码器的弱点：任何只使用这个已丢失顺序信息的状态的确定性解码器，都不能普遍恢复两个历史。随机解码器也不能对两者都以概率一正确恢复。外部提供历史身份、位置或更多状态属于增加信息，已经改变问题条件。

不能只展示“相同次数”就草率断言完整状态相同：本实现的淘汰元数据可能保留首次出现顺序。因此示例特意保证插入顺序也相同。

## 7. 上下文修复及其成本

把共享提示 A 的两条序列分别放在 $`c_1`$ 与 $`c_2`$ 下，学习 A→B→END 和 A→C→END，就能在相应上下文中恢复两者。它们原本碰撞的中央键 $`(c,A)`$ 现在不同。

充分条件仍然是：扩展后的每个键具有一个正确唯一后继，并且所需边没有消失。一个固定曲名标签只能修复跨曲目的同提示碰撞；它不能修复同一曲目内 A 两次出现时的不同后继。

进一步扩展可以把前一符号、长度为 $`k`$ 的历史片段或位置一起纳入状态。其中 $`k`$ 是保留历史的长度；若相关历史仍重复且需要不同后继，固定阶数依然不够。逐位置标签可以让任意有限目标路径单值化，但要求额外的位置状态与同步，实质上保存了更多次序信息，不能把这个成本称为“免费上下文”。当前代码只实现固定上下文，不假称实现了所有这些扩展。

## 8. 身体与脑的双向接口

令 $`S`$ 是器官信号集合，每个信号是“器官标签、值”二元组。外围接口用另两张 WeightedHabits 表：

- $`U_c(s,x)`$：信号 $`s\in S`$ 到符号 $`x`$ 的传入习惯强度
- $`V_c(x,s)`$：符号到身体信号的传出习惯强度

teach 接收一串 Observation：每项同时给出一个符号和对应信号。它练习中央相邻关系，并把每项的两条方向关联分别加一。配对内容来自教学输入，不是模型独立发现的感觉概念。

sense 经 $`U`$ 产生 external 事件；recall 经 $`W`$ 产生 replay 事件；express 经 $`V`$ 产生 BodyEvent；feedback 把该身体输出再次送入 $`U`$，产生 feedback 事件。三个表各有独立的最多 $`K`$ 条边；它们不是一个共享容量池。forget 对三个表施加同一遗忘量。

两个布尔开关分别阻断传入、传出。阻断传入使新的感官激活失败；阻断传出不删除已有中央习惯。在显式提供 cue 时，中央回放仍可能继续，而身体输出为空。这个可分离性是现代实现的选择，并不表示 Condillac 已接受一种与器官活动完全独立的中央记忆。他在 88–90 页更强调相互作用；本模型的接口只展示双向路径，远未给出这种相互依赖的完整理论。

没有自动反馈循环。调用者须显式调用 feedback；这样既避免无止境循环，也使“输出后再感知”这一步能被检查。未选择唯一身体输出时 express 返回空值。没有当前激活时 recall 报错。

## 9. 来源归因：标签是检查工具，不是意识理论

IdeaEvent.source 有四种值：external、cue、replay、feedback。支持“独立外部输入”这一日志判定的只有 external。cue 是实验者直接设定的提示；replay 是中央续接生成；feedback 是自身输出经过传入通路回来。

这个标签由程序路径提供，系统没有学会可靠的人类来源监控。sense 也不证明被知觉对象真的存在：它只记录调用者把本次输入交给了外部输入接口。信号噪声、幻觉的医学机制、错误调用接口，都不在验证范围内。feedback 可能涉及真实的身体感觉，但不因此成为独立外部对象的证据。

令 $`P(e)`$ 为只保留事件 $`e`$ 的观念符号、丢掉来源的投影。external A 与 replay A 经过 $`P`$ 后均为 A。因此任何只读取 A 的函数，都不能对这两个事件可靠给出不同来源。其证明与上节信息丢失论证相同。这把“内部生成内容被当成当前外部输入”的结构风险显露出来，不能证明原文的生理解释。

## 10. 验证、范围与不做的承诺

可执行契约由 test_model.py 检查，优化模式不使用会被移除的裸 assert。mutation_check.py 每次复制代码、保留同一完整测试集，只修改一个指定代码位置。仅完整执行 40 项测试、出现断言失败且没有测试错误的运行计为行为杀死。语法/导入错误、空套件与运行时异常分别报告，不能充当有效检出。

边表用普通字典；choose 为求清晰会扫描全表，其一次复杂度为 $`O(E)`$，$`E`$ 为该表当前边数。一次最多 $`L`$ 次判定的回放为 $`O(LE)`$；有限容量插入时寻找牺牲边也会扫描全表。它是小规模教学程序，没有训练神经网络、下载模型、GPU 需求或第三方 Python 依赖。

本程序未覆盖感觉内容的形成、快乐和痛苦如何引导学习、动作控制的连续动力学、梦的随机拼接、真实时间、记忆巩固、衰老、病理、灵魂的形而上学地位。输出正确只说明指定假设下程序与数学条件一致。后续扩展应先说清新假设，再提出可反驳的测试，不能从古文中的一个类比跳到现代神经机制或模型性能主张。

## 11. API 信任边界

WeightedHabits 的键和值必须可哈希，而且在保留期间其哈希值与相等关系稳定。SequenceMemory 与 EmbodiedMemory 的常规入口限制为字符串和已验证的 Signal/Observation；通用表本身允许其他合适的可哈希对象。直接改写内部字典、重新赋值 capacity、直接构造 IdeaEvent/BodyEvent 或手工修改接口开关属于受信任的实验者低层操作，不在不变量保护和对抗性安全保证内。

来源标记不是防伪证明。调用者可以把一个自身输出的信号重新传给 sense()，它就会被记为 external；这说明该接口的来源归因依赖诚实的实验组织。即使路线确为外部输入，学习到的符号也可能错误，外部对象本身也没有被程序独立认证。这里既没有自动来源监控，也没有“知道当前重现的是过去”这一元记忆机制。
