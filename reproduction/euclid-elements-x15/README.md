# 《几何原本》X.15：相加相减保留同一个公度量

精确教学模型传入共同单位和整数次数，不预先寻找或更换单位。若两段分别含共同单位 `p,r` 次，`from_parts(unit,p,r)` 返回两段与整体的计数 `(p,r,p+r)`。若已知整体次数 `w` 和真部分次数 `p`，`from_whole(unit,w,p)` 则返回 `(p,w−p,w)`。两路返回同一个证书。单位需为正整数或有理分数；次数必须为正整数，拒绝无余段或负余段。

例：单位 `3/10`，计数 `(4,6,10)`，得到部分 `6/5`、余段 `9/5`、整体 `3`。这个单位不是最大公度量，后者为 `3/5`；命题不要求使用最大的量。若把三段同时乘以无理的 `√2`，整数计数仍不变，可在纸上把共同单位也乘 `√2`；程序只接收精确有理坐标。

独立校验用有理数的分母最小公倍数消去分母，再取整数最大公因数，核对三个成对最大公度量相等、且为原证书单位的正整数倍。另核对两条计算路径相同。覆盖 3 种单位乘上 `p,r∈1..32` 的全组合，3,072 个证书中 1,941 个已用最大单位、1,131 个未用。有限校验不是一般性证明。

Python 3.10+，仅标准库。在本目录执行：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```
