# VII.17：同乘数保持比

现代整数的教学重构，不是古代实跑记录或一般命题的计算证明。给定大于 1 的整数 A、B、C，分别把 A 个 B 与 A 个 C 加起来，得到 D、E。确认 B 量度 D 与 C 量度 E 都恰为 A 次，再得到内部的一份关系 B:D=C:E=1:A。接着按 VII.13 的换比思路检查 B:C=D:E。代码返回约分计数，测试另用整数乘法和 Fraction 从原数据核对。

A=3、B=4、C=6 时，两次独立的重复加法给出 D=12、E=18，内部均为 1/3，换比均为 2/3。若把 E 改为 24，实际次数为 4，结论不再成立。若把 D、E 都改成按 4 次得到的 16、24，换比虽相同，仍违反指定乘数为 3 的前提。

程序也用现代约分计数检查 B=C 和 B>C 的一致等式，不把相等或反向当作真份。A=1 或其他给定数为 1 的现代边界由测试另行检查。零乘数则给出 0:0，不能以约掉零乘数来说明保持比；它不进入本程序的给定数范围。
