# I.31：分支选择为何还需要证据——有限教学模型

这是配合《前分析篇》I.31 深读的**原创现代集合模型**，不是古代方法的完整复原，不验证现实分类、词义或本质。仅依赖 Python 标准库。

## 模型与接口

`FiniteModel(universe, terms)` 接收非空有限论域及非空名称字典。各集合必须是 `set` 或 `frozenset`，成员必须为非负整数；拒绝布尔值、越界成员和带首尾空白的名称。输入复制为不可变集合，映射只读。项允许为空，允许不同名称具有相同外延。论域非空是本程序约定；**并未为所有项偷偷加入存在预设**。

- `division_report(A, B, C, D)`：检查 A 被 B、C 覆盖，D 包含于 A，D 的每个对象是否落在 B 或 C，以及全体 D 是否同落于某一分支。还分别报告两支是否互斥、是否都在 A 内；覆盖本身不自动包含这两个条件。
- `select_branch(A, B, C, D, 'left', exclude_other=True)`：检验覆盖和 D 对 A 的归属，并要求调用者显式提交“D 与另一支无交集”证书，核验后返回所选项名称。对右支同理。没有证书，即使所选结论碰巧在该模型中成立，也拒绝这条证明路线。证书的布尔参数只是提交声明，**不是凭 `True` 就相信它**。
- `follow_path(D, [Step(A,B,C,'left',True), ...])`：逐层核验同一目标 D 的证书；后一层父项名称必须等于前一层所选项。空路径、断开的路径或缺少任何一步证书都拒绝。
- `definition_report(D, description)`：分别返回必要性、充分性、同外延。描述项可以由调用者事先构造成若干条件的交集。**外延相等也不等于证明历史意义的本质定义。**

所有输入检查使用显式异常，不依赖在 `-O` 下会消失的 `assert`。`division_report` 是事实诊断；`select_branch` 则只接受一种明示的充分证据路线。若两支有重叠，D 可以确实属于左支却不能排除右支，此时返回拒绝是有意的：排除另一支并非结论为真的必要条件。

## 最小例子

```python
from division import FiniteModel, Step
m = FiniteModel({0, 1}, {
    'A': {0, 1}, 'B': {0}, 'C': {1}, 'D': {0, 1}
})
r = m.division_report('A', 'B', 'C', 'D')
print(r['pointwise_disjunction'])  # True：每个对象都在某支
print(r['uniform_disjunction'])    # False：不存在包含全部D的一支
```

枚举得到的最小错误左支反例是 A=C=D={0}、B 为空；不是说人类项实际为空，而是展示给定前提不足。更强的非空、互斥分支反例就是上面的两对象模型。空 D 时两支全称结论都真，程序报告 `target_nonempty=False`，不把空项结果冒充存在性证据。

## 运行与真实证据

在本目录运行：

```sh
sh run.sh
```

脚本将覆写本目录 `logs/` 中的运行证据，任何命令失败立即退出。环境见 [environment.txt](logs/environment.txt)；精确命令见 [normal](logs/commands-normal.txt)、[-O](logs/commands-O.txt)、[-OO](logs/commands-OO.txt)。

此次真实运行 normal、`-O`、`-OO` 各 **33 个单元测试通过**，见 [normal](logs/tests-normal.txt)、[-O](logs/tests-O.txt)、[-OO](logs/tests-OO.txt)。`run.sh` 对三种模式的枚举 JSON 使用 `cmp` 核验相同。

[完整枚举结果](logs/models-normal.json)：对大小 1、2、3 的论域，遍历四项 A、B、C、D 的全部 **4368** 种外延赋值（包括空项），其中：

| 项目 | 数量 |
|---|---:|
| 满足覆盖及 D 包含于 A 的赋值 | 1110 |
| 上述赋值中 D 非空 | 711 |
| 满足前提但不能强化为全体 D 属于 B | 291 |
| 满足前提但不能强化为全体 D 同属 B 或同属 C | 56 |
| 满足前提且左支排除证书为真 | 584 |
| 满足前提且右支排除证书为真 | 584 |
| 定义双向与同外延一致性检查 | 4368 |

证书计数包含空目标，并且左右计数可以重叠；它们不是互斥类别，不能相加当作不同模型总数。上述两种错误强化计数也是在同一前提集合内分别统计，不是互斥类别。
