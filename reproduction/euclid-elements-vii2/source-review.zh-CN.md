# VII.2 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.2.html)、Heath 1908 卷 II 印刷页 298–300（图和共量论证在 298 页，最大性与推论在 299 页，校注跨 299–300 页）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=196) 印刷页 196–197（图在 196 页）。符号用各版英文图号；希腊文的 ΓΖ 和 Η 对应 CF 和 G，G 是假设的另一数而非余数。

## 两个分支与两条传播链

1. 已知 AB、CD 不互素，即不是「只有单位可共同量尽」的情形。若 CD 整除 AB，CD 也是自己的量尺，因此是共同量尺；任何比 CD 大的数不能量尽 CD。直接分支不需要产生余数。现代如果允许原输入未排序，可先取大数为 AB；原证没有一般零输入。
2. 若 CD 不整除 AB，逐轮以小量丈量大量，保留小于量尺的余量。若到单位，就按 [VII.1](https://www.claymath.org/library/historical/euclid/files/elem.7.1.html) 得原数互素，与假设矛盾。于是应当停在整除前项的非单位余量。正文没有单列一般终止定理；现代补明可用每次未整除时正整数余量严格下降。
3. 图中 CD 整除 BE，AB=BE+EA；EA 整除 DF，CD=DF+FC；最后 CF 整除 AE。先从 CF **逆推**：CF 整除 AE，从而整除 DF，加 CF 自身得其整除 CD；再整除 BE，加 EA 得其也整除 AB。这才证明结果是共同量尺，没有证明最大性。
4. 再从原数的任一共同量尺 **顺推**：若 G 同时整除 AB、CD，则 G 整除 BE，从而整除差 AE；于是也整除 DF，并整除差 CF。正文为证明最大性特设 G>CF，由「较大数不能整除较小正数」归谬。推论（πόρισμα）指出任一共同量尺都整除最大共同量尺；顺推不需要 G>CF。直接整除分支下也成立，因为 CD 本身就是输出。推论强于单纯的不大于：输出为 6 时，4 虽不大于 6，却不可能是共同量尺。

## 版本和历史边界

Clay 与 Fitzpatrick 的希腊文均将正文末尾的惯用结语放入方括号，而推论单列，不能因结语排印差异而漏读推论。Fitzpatrick 英译的「若不然」承接的是「不会留下单位」：反设确实留下单位，就与输入不互素矛盾。其最大性末句也应按语境理解为「没有比 CF 大的数能同时量尽两数」，不是较弱的「存在某个较大的数不能量尽」。Heath 校注指出较大假设仅用于最后归谬，不影响推出 G 整除 CF 的链条；他另以 Nicomachus 的 49、21 为后出比较材料，不是欧几里得原图指定数值。

[VII.3](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII3.html) 实际用 VII.2 先求 A、B 的最大共同量尺 D，再用推论把三数的共同量尺传到 D 和 C；若 D 不量尽 C，就对 D、C 再用 VII.2。现代把互素判定、整除分支与通用余数循环统一起来属教学重构；零余数表示整除，不是第七卷的「单位」。
