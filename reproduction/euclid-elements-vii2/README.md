## 核验与限制

- 用带余除法记录较大项、较小项、商和余数。取最后一行的除数，即归零之前的非零项，不将最终余数 0 当答案。倒推每一行的两个整数倍数，见证该非零项能量尽原两数；向前核对每个公共因子都量尽所有余数，因此也量尽该非零项。逆推函数核对由本程序生成的倍数证书；固定算例的商余关系和相邻状态由测试逐行对照，不把逆推函数当作任意外来轨迹的验证器。这一双向检查也区分「数值最大」与「其余共同量数皆量尽它」。
- 例 84、30 的余数为 24、6、0。倒推的两数为 6 的 (4,1)、(5,4)、(14,5) 倍。21、7 一开始即可整除。非互素是古命题的明示条件；等值非单位例 9、9 由直接整除规则处理，不添加原文未明说的不等前提。现代正整数模型另允互素或输入 1，以 gcd=1 收束；这些并不被说成古命题的非互素情形。
- 枚举 1 到 64 的 4,096 对有序输入；朴素枚举所有共同正因子作为独立对照，并核验与最终非零项的正因子集合完全相同。有限实跑不是对一般定理的证明，程序拒绝非正输入。
