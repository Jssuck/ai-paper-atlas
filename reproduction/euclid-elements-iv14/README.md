# 《几何原本》IV.14：检验正五边形的外接圆

[回到正文](../../papers/ancient/euclid-elements-iv14.zh-CN.md)。本目录用现代精确坐标重做构造路线中的两条内角平分线，以及独立的三点定圆。两个方法都只读取顶点；生成输入时用的中心只用于校验。代码不是尺规动作模拟，也不以数值测试代替一般性证明。

## 环境与实际命令

在本目录运行，只需 Python 标准库。环境为 Python 3.12.14。日志仅将 unittest 计时换成 `<elapsed>`；每份日志附真实运行命令。当前环境无可执行 Jupyter 命令及模板辅助脚本，Notebook 按教程结构生成。三个代码单元经标准库 `compile/exec` 从头重跑，没有运行 Jupyter 内核或前端渲染。

## 算法与对照

- 横坐标和纵坐标系数用有理数对表示 a+b√5。从 U=(√5−1)/4、V=1−U² 得实际坐标 (x,y√V)，点积为 xx′+Vyy′。行列式中的公共正因子 √V 不影响符号或求交比值。
- 主路线先查严格凸的边界顺序；在 C、D 分别把两条等长邻边向量相加，得到向内的方向。求两直线交点后核查两个射线参数为正、交点严格在五边内。这里的内侧检查是正五边形实验的防错条件，不是对一般外接圆的要求。
- 独立路线令出发点为 B，圆心偏移向量为 X，把到 B、C、D 等距的平方展开相减，得到两条线性方程：2X·(C−B)=|C−B|² 与 2X·(D−B)=|D−B|²，用行列式解出 X。共线时明确拒绝，钝角三角形的外心在三角形外仍可返回。
- 证书与构造分开：计算每个顶点的半径平方。将 A 沿原半径向外放大到原来的 11/10，只改变 A 的半径平方（变为原来的 121/100）。两个局部构造所得候选都不变，仍不能通过全部五点的证书。固定正五边形而平移圆心也不能通过。
- 另取五个边长不全等、已知共圆的点作方向相反的对照：三点算法可以给出五点共同的圆心，但不能直接套用本程序要求两条邻边等长的向量和构造。正五边形是原命题的输入，不是共圆的必要条件。

## 结果和适用范围

48 个有理外接半径，各取正反绕行，得到 96 个正例、96 个移动 A 的反例和 96 个只移动中心的反例；样本有非零平移。普通、`-O`、`-OO` 各运行 8 项测试。额外核对了共线、重复顶点、错序、非正共圆五边形、钝角三角形和内外半径平方的区别。有限样本只能检验这些实现和样本，不足以证明任意五点共圆，也不是浮点测量数据的鲁棒拟合程序。
