# X.5 原典核对

- [Heath 1908 英译卷 III](https://www.wilbourhall.org/pdfs/Heath_Euclid_III.pdf)印页 24 题句、图与比较的起步，印页 25 完成第二个比较并用 V.22 得到结论。C 是任一共同尺度，D、E 是分别记下的单位份数。图上以线段画出 D、E，不改变它们在证明中作为数的角色。
- [Fitzpatrick 希英本](https://farside.ph.utexas.edu/Books/Euclid/Elements.pdf#page=287)印页 287 载题、图、完整正文与脚注。方括引注指定 VII.定义 20、V.7 推论、V.22；脚注明言 VII.定义 20 涉及四个数。Heath 在 25 页评注中指出混合较量的论证须补第五卷的同比桥梁，并提及 Simson 的命题 C；这不是说结论为假。
- [Clay 希英页](https://www.claymath.org/library/historical/euclid/files/elem.10.5.html)希栏有末尾回述和证毕；英栏已经给出 V.22 所得数之比，但没有末尾回述和证毕。[Joyce 校读](https://mathcs.clarku.edu/~djoyce/elements/bookX/propX5.html)保留回述，且导读明说两种同比定义须兼容。
- 原证的比较方向依次是 C 对 A 如单位对 D，倒置成 A 对 C 如 D 对单位，再与 C 对 B 如单位对 E 接合。第五卷定义的教学补证比较任意正整数倍：C 为正、A 为 m 份 C 时，比较 r 份 C 与 s 份 A 等同于比较 r 与 sm；B 的比较同理。现代整数将 1 当作数，但古代 VII.定义 1–2 区别单位和数；若某个份数为 1，可在可平分量的现代重构里用半个尺度取两组份数都大于 1，不必先求最大公度。
