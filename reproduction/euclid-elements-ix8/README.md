# 《几何原本》IX.8：连比链的位置与幂

程序以正整数 $q\ge 2$ 从单位起步，每项乘 $q$ 得下一项。以 1 为第一位置，第 $e+1$ 位置的值为 $q^e$。只对 $e>0$ 标记位置保证：$2\mid e$ 时平方根为 $q^{e/2}$，$3\mid e$ 时立方根为 $q^{e/3}$，两种保证首次在第七位置重合。程序另用整数平方根和立方根测试实际性质。即使第二位置不受位置保证，$q=4,8,64$ 也分别可使它为平方、立方或两者兼有。单位本身不计入古代位置分类，实际判断栏将 $1=1^2=1^3$ 作为现代约定。

在本目录运行，需 Python 3.9+ 标准库：

```sh
python3 -B -m unittest -v
python3 -B -O -m unittest -v
python3 -B -OO -m unittest -v
python3 -B replay_notebook.py
```

独立基线对小底数试除分解，检查各素数指数乘以 $e$ 后的整除性，覆盖 $q=2,\ldots,64$ 和 $e=1,\ldots,12$。有限核验不代替一般证明。Notebook 由标准库实际回放三个代码单元，不是 Jupyter 内核运行。
