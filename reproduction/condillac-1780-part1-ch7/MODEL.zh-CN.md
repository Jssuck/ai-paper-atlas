# 有限教学模型：注意、比较、反思、想象与推理

## 1. 这是怎样的“复现”

本目录是依据孔狄亚克《逻辑》第一部第七章（所据1798年版印刷页58—66）设计的原创教学程序，不是作者算法的转写，也不是历史心理学实验的重复。它用可检查的数据结构和有限逻辑系统，分离原文的概念链中容易混为一谈的几个步骤。它不证明感觉能够产生必然性，不验证感觉主义、灵魂学说或“比较一发生便有判断”的心理必然性。

原文的概念顺序与本模型的约定必须分开：

| 原文论述 | 本目录的现代约定 | 不能据此得出的结论 |
|---|---|---|
| 注意使某感觉占据心灵，其他感觉仿佛未发生 | 选一个对象，记录指定特征，其余不写入当前记录 | 其他感觉被物理删除；这个选择器说明了注意的发生机制 |
| 比较是双重注意，对象可以不在眼前而由回忆提供 | 两份独立记录进入同一个比较函数，保留 current/recalled 来源 | 两个单对象投影的函数复合就是双重注意；回忆在现实中绝不出错 |
| 判断察觉相似或差异 | 同一特征的两个已知值相等、不同；缺值输出 unknown | 三值程序证明了作者所说的立即判断；不同特征值之间天然可比较 |
| 反思是一连串比较 | 按给定顺序比较多个特征；另考察完整特征投影的等价类 | 反思只是分类程序，或有限相似等于对象同一 |
| 想象重新组合性质，不必有相应现实对象 | 已观察质量的笛卡尔积，与有限目录见证分别计算 | 每个组合都现实存在；目录中没有就证明世界中不存在 |
| 推理借中介显明判断中原先未显明的内容 | 给定事实和正Horn规则，求闭包，检查证明和语义蕴涵 | 作者已经提出Horn逻辑；感觉自身已经证明这些规则 |

代码中的英文短标签只是机器可读名称。尤其 current/recalled 不是生理状态测量。给定目录是静态且被视为正确的；程序要求回忆记录与它一致，因此没有建模遗忘、错误回忆、对象随时间变化或知觉噪声。

## 2. 对象、特征与部分观察

令 $`D`$ 为有限命名对象集，$`K`$ 为非空有限特征集。对每个 $`k\in K`$ 给定非空有限值域 $`V_k`$，并给定全函数 $`v_k:D\to V_k`$。对象名互异；同名特征只能有一个值；对象必须具有所有特征。这是建模公理，而非从感觉经验推导出的事实。$`D`$ 可以为空。

Catalog(features, domains, objects) 用等长元组表达这些函数。对象名仅代表目录身份；两个不同名字可以拥有相同的全部特征，程序仍不把名字合并成同一个对象。

一次观察 $`O=(x,S,p)`$，其中 $`x\in D`$，$`S\subseteq K`$，$`p\in\{\text{current},\text{recalled}\}`$。其记录是 $`\{(k,v_k(x)):k\in S\}`$。attend 仅形成这一限制映射，允许 $`S=\varnothing`$。未记录不等于没有该性质。

对 $`O_x`$、$`O_y`$ 与 $`k\in K`$，compare 的定义为：

- 任一观察未记录 $`k`$：unknown；
- 两者都记录 $`k`$ 且值相同：equal；
- 两者都记录 $`k`$ 且值不同：different。

unknown 是信息不足，不是假值，也不等于相等或不相等。程序不会从目录中暗自补全缺失观察来回答 compare；目录只用来验证输入是否合法。recalled 记录仍可用于比较。

### 命题1：已知比较的正确性与对称性

如果两份合法记录都包含 $`k`$，compare 的答案恰好等于 $`v_k(x)=v_k(y)`$ 的真假分类；无论是否缺值，交换两个记录不会改变结果。

证明：合法性检查保证每个记录值就是 $`v_k`$ 的对应值；已知分支直接比较两个值。缺值条件是“任一缺失”，对交换对称；值的相等与不等也对称。证毕。这是数据约定下的正确性，不是关于人类必然立即判断的实验结论。

## 3. 反思、等价关系和隐藏特征

reflect 依次执行多个单特征比较，返回有序结果，保留其中的 unknown。它不会自动发现该比较哪些特征。

另一个函数 equivalence_classes 使用完整目录，定义

```math
x\sim_F y \quad\Longleftrightarrow\quad \forall k\in F,\ v_k(x)=v_k(y),\qquad F\subseteq K.
```

必须区分这一二值关系与部分观察上的三种输出。$`\sim_F`$ 只用完整选中坐标；不能把 unknown 当作 equal 后再称它是等价关系。

### 命题2：$`\sim_F`$ 是等价关系

自反：每个 $`v_k(x)`$ 等于自身。对称：数值相等可交换。传递：若每个选中坐标上 $`x`$、$`y`$ 相等且 $`y`$、$`z`$ 相等，则 $`x`$、$`z`$ 相等。这三点逐坐标成立，故对所有 $`k\in F`$ 成立。$`F=\varnothing`$ 时条件空真，所有对象属于一个类；$`D=\varnothing`$ 时没有类。代码以选中特征值元组为键，恰好输出这些等价类。

### 命题3：增加特征只会细化等价类

若 $`F\subseteq G\subseteq K`$，则 $`\sim_G\subseteq\sim_F`$。证明：在 $`G`$ 的所有坐标上相等，当然在其子集 $`F`$ 上相等。反向一般不成立。

反例是演示中的 $`a`$ 与 $`b`$：两者都是 red、round，但 $`a`$ 为 wood，$`b`$ 为 metal。在 $`F=\{\text{color},\text{shape}\}`$ 下相等，在 $`G=K`$ 下不同。即使 $`G=K`$，也只得到模型内所有特征一致，不能得到名字同一或现实对象在所有可能性质上相同。

“不冲突”也不是安全替代品：只看 `color=red` 的记录、只看 `shape=round` 的记录、只看 `color=blue` 的记录，相邻两份没有共同已知冲突，首尾却冲突，所以这一部分信息兼容关系不传递。不相等关系本身也不传递。

## 4. 想象：组合与见证的严格分离

给定若干合法观察和非空 $`F`$，令 $`P_k`$ 是这些观察实际记录过的 $`k`$ 的不同值集合。每个 $`P_k`$ 必须非空，否则程序拒绝假造该特征。想象空间定义为 $`\mathcal I_F=\prod_{k\in F}P_k`$。

对组合 $`c\in\mathcal I_F`$，目录见证集为 $`W(c)=\{x\in D:\forall k\in F,\ v_k(x)=c_k\}`$。imagine 返回每个组合与其完整见证列表，不删去 $`W(c)=\varnothing`$ 的组合。

### 命题4：枚举恰好覆盖所选质量池的全部组合

每个质量池去重后，itertools.product 对每个坐标独立取一个值，所以恰好产生每个选择元组一次。组合数为各 $`|P_k|`$ 的乘积。对每个组合，再逐对象检查全部选中特征，因此返回的见证既没有遗漏，也没有错误加入。

这没有宣称坐标独立在物理上成立。red/square 可以由既有 red/round 和 blue/square 重组出来，却没有当前目录见证。相反，red/round 可以有 $`a`$、$`b`$ 两个见证。只观察 $`F`$ 的组合，其见证也只要求 $`F`$ 一致；不能误读为完整对象复制。

## 5. 推理：有限正Horn系统

令 $`A`$ 为有限命题原子集；$`F_0\subseteq A`$ 为初始事实；$`R`$ 是有限规则集。每条规则 $`r`$ 有名字、前提集合 $`P_r\subseteq A`$ 和单一结论 $`h_r\in A`$，语义为 $`(\bigwedge P_r)\to h_r`$。空前提的合取为真，因此无前提规则可提供一个种子事实。规则不允许引用未声明原子，不接受同名规则或重复前提。

所有原子都是无内部结构的布尔命题。这里没有变量、量词、函数符号、否定结论、默认推理、概率或物理方程。尤其“未推出 $`q`$”不等于推出 $`\neg q`$；正理论永远有全真模型，不能用它研究矛盾、爆炸或不一致知识库。

定义闭包算子 $`T(X)=X\cup F_0\cup\{h_r:r\in R,\ P_r\subseteq X\}`$。从 $`X_0=F_0`$ 出发，迭代到固定点 $`L`$。closure 的实现按规则顺序就地增加已知原子，多扫描几轮至没有新增；这是同一最小固定点的有序实现。

### 命题5：终止和最小性

每次实质变化至少加入一个以前没有的 $`A`$ 中原子，最多新增 $`|A\setminus F_0|`$ 个。无新增的一轮即结束。所得 $`L`$ 包含 $`F_0`$ 且对每条规则封闭。任取包含 $`F_0`$ 且对 $`R`$ 封闭的集合 $`M`$：初始 $`X_0\subseteq M`$；每次添加的结论的全部前提已在 $`M`$，封闭性保证结论也在 $`M`$，故归纳得到 $`L\subseteq M`$。因此 $`L`$ 是唯一最小闭包，与规则排列无关。

### 命题6：Horn推导的健全性

令 $`M\subseteq A`$ 表示被赋值为真的原子集合，且 $`M`$ 满足全部事实及规则。每个初始事实在 $`M`$。若推导中某规则所有前提已在 $`M`$，满足规则要求其结论也在 $`M`$。沿加入顺序归纳，每个 closure 输出原子 $`q`$ 都在所有模型中，即 $`F_0,R\models q`$。

### 命题7：对正原子查询的完备性

固定一个查询原子 $`q\in A`$。$`L`$ 本身是一个模型：它包含所有事实；凡规则前提全在 $`L`$，其结论也因固定点封闭而在 $`L`$。若 $`q\notin L`$，取模型 $`M=L`$，得到全部前提成立而 $`q`$ 为假的反模型，所以 $`F_0,R\not\models q`$。与健全性合并，$`q\in L`$ 当且仅当 $`F_0,R\models q`$。

这证明的是这一有限正Horn语言中原子查询的完备性，不是任意自然语言推理、所有命题逻辑、第一阶逻辑或心理活动的完备性。“隐含”在此被明确定义为所有满足给定前提的赋值中都成立，不能不加论证地当作原文“观念包含”的同义词。

### 证书与独立语义检查

closure 返回 Step(atom,rule_name) 序列。rule_name=None 只用于已声明初始事实；其他步骤必须引用实际存在的规则，且规则结论必须正是该 atom，其全部前提必须已经在更早的步骤中出现。verify_certificate 不运行 closure，而逐步检查这些条件，拒绝伪造规则、错结论、重复步骤、循环自证和缺失依赖。证书可以只证明目标需要的局部片段，不必列出所有初始事实或整个闭包。

由步骤序号严格增加，引用只能指向较早前提，因此合法证书是良基的。对序号归纳即可得到每一步的健全性。反过来，closure 每次加入结论时前提已知，因此其生成证书合法。

semantic_oracle 不调用闭包或证书验证器，枚举 $`A`$ 的全部 $`2^{|A|}`$ 个布尔赋值，直接判定事实和各蕴涵式是否满足，再求所有模型真原子的交集。全真赋值保证模型集非空。它与闭包共享输入结构和验证，但不共享推导算法；它不是外部定理证明器，也不是代码绝对无错的保证。

两个必要反例：没有事实时 $`p\to q`$、$`q\to p`$ 的闭包为空，循环本身不能提供知识。只有 $`p`$ 和 $`q\to r`$ 时，缺少 $`p\to q`$ 这座桥，$`r`$ 也不在闭包；添加明确桥接前提或规则后才会被推出。

演示用 air_has_weight、pressure_bridge、column_supported 说明隐藏前提的角色。pressure_bridge 是人为提供的抽象辅助前提，规则 illustrative_bridge 也是现代教学设定；它没有证明气压计物理、给出汞柱高度或替代真实压力平衡方程。

## 6. 第65页脚注：有效性不等于教学赞同

脚注开头问的是“$`A`$ 包含 $`B`$”，若作集合包含翻译，方向是 $`B\subseteq A`$；稍后肯定式例子的前提却是“$`A`$ 包含于 $`C`$，$`C`$ 包含于 $`B`$”，方向是 $`A\subseteq C\subseteq B`$，结论 $`A\subseteq B`$。两处方向不能悄悄合并。本目录 API 用 small、middle、large 避免字母复用造成误读。

肯定式集合命题：$`A\subseteq C`$ 且 $`C\subseteq B`$ $`\Rightarrow`$ $`A\subseteq B`$。证明：任取 $`x\in A`$，第一前提给 $`x\in C`$，第二前提给 $`x\in B`$，故结论成立。subset_syllogism 对三个有限子集返回前提、结论、整体条件式和 small 是否非空。

否定式集合命题：$`A\subseteq C`$ 且 $`C\cap B=\varnothing`$ $`\Rightarrow`$ $`A\cap B=\varnothing`$。证明：若存在 $`x\in A\cap B`$，则由 $`A\subseteq C`$ 得 $`x\in C\cap B`$，与空集前提矛盾，所以不存在这样的 $`x`$。这个否定式在文档中证明，没有单独实现为Horn规则或程序接口；正Horn语言不能直接表达否定前提。

上述两个集合命题均允许空集，不附加存在预设。肯定式前提失败时，条件式仍可空真；因此 API 分别报告 premises 和 implication，不能只看 implication=True 就声称本例前提成立。作者对这种三段论教学用途的否定，不等于宣布这些包含关系推理无效。程序只复核有限集合有效性，不裁定教学价值。

## 7. 验证边界和资源预算

输入用显式 ValueError 检查；不依赖 Python assert，优化选项 `-O`、`-OO` 不会移除必要检查。外部输入限定为真正的不可变 tuple、字符串和指定记录类，不做隐式类型转换。格式错误抛异常；结构合法但推理不成立的证书返回 False。

预算：最多8个特征、每特征8个值、32个对象/观察、4096个想象组合、12个原子、128条规则。它们是防止教学样例意外爆炸的实现上限，不是原文理论命题。元组校验及日志字符串没有声称能抵御恶意的任意大字符串或被绕过冻结保护后破坏的Python对象；这里的输入契约不是安全沙箱。

将字符串比较、散列与集合查询视为常数成本，闭包的朴素最坏工作量为 $`O(n+1+(n+1)r(n+1))`$，其中 $`n=|A|`$、$`r=|R|`$；语义枚举为 $`O(2^n(1+n+r(n+1)))`$。这里保留加一项以涵盖空原子或空规则集；未把任意长字符串的处理成本算作零。想象空间本来就可能指数增长，程序在枚举前检查乘积上限。默认验证小于数秒到十余秒的CPU工作，不需要GPU、网络、下载或第三方包，实际时长依机器而异。

测试包含：18个测试方法；全部1024个两原子正Horn理论（全部8种不同规则的子集与4种事实集的笛卡尔积）；固定种子1780生成的200个三原子理论；特征子集的等价律和细化关系；三元素全集上的512组三子集包含实例；输入拒绝、隐藏特征、缺桥、无种子循环、证书伪造；以及8个语义变异。穷举与变异测试是在明确有限范围内提供证据，不能替代本节数学证明或独立代码审阅。
