# 第七章教学模型的独立代码审计

审计日期：2026-10-11。结论：所列有限范围全部通过；普通、-O、-OO三种模式结果一致，13种指定语义变异在每种模式全部被检出。独立检查由实现作者之外的复核角色另写，没有把作者测试改名当作独立证据。这里的“独立”不是外部学术同行评审。

## 范围与另一套预期值算法

检查对象是上一层model.py。检查程序不以生产closure、verify_certificate或semantic_oracle的输出作为其他函数的正确答案。

- 等价类先逐对构造关系，再逐次取出一个关系类；不复用生产签名字典分组。
- 注意记录和比较结果从另外构造的目录表及选中特征直接计算；current与recalled两来源都检查。
- 想象先枚举全局二值特征空间，再筛选各观察质量池中的组合；见证按对象逐个满足坐标条件计算。
- Horn后果先枚举全部真原子集合，按材料蕴涵判定是否满足事实和规则，再对所有模型求交。没有调用生产前向推导或其oracle。
- 任意声称的证书以步骤位置、较早出现的原子和声明规则另行判定。检查允许省略无关事实，但不许伪造、漏依赖、借未来步骤或循环自证。
- 包含推理由逐成员量化判定，不直接采用生产子集函数的返回值作预期。

这些算法与生产实现仍共享Python、数据契约和数学定义。因此不同算法一致是有限实现证据，不是完全独立公理基础或程序绝对正确性的保证。

## 精确检查范围

每种优化模式均运行以下同一范围：

| 检查对象 | 数量与边界 |
|---|---|
| 完整目录 | 三个命名对象、两个特征、每特征两值的全部64张表 |
| 等价类及细化 | 256个分区、576个嵌套特征选择对 |
| 部分注意 | 1536条记录，含全部特征子集及两种来源 |
| 单特征比较 | 73,728次，包含双缺值、单缺值、同值、异值 |
| 重组 | 10,304次有定义查询，共14,948个组合及其全部目录见证 |
| 缺质量池 | 1984次必须拒绝的查询 |
| Horn系统 | 三原子，所有至多三条不同规则组合与全部事实集，共18,600套 |
| 闭包证书 | 三目标各查，共55,800次 |
| 生产语义oracle | 在其中200套理论上与独立模型交集及模型数核对 |
| 任意证书 | 三套固定理论的8052条长度0至3记录，共24,156次目标验收 |
| 集合推理 | 全集大小0至4，共4681组三子集输入 |
| 非法输入 | 35项，包括类型、重复、未知名称、不一致回忆、域外值及尺寸上限 |
| 组合预算 | 4096组合恰达上限可计算，32768组合超过上限须拒绝 |

Horn计数为：24种可选规则，由8种前提子集各配3种结论；选0、1、2或3条共2325种规则集，再配8种事实集，得到18,600套。它不是所有24规则任意子集的穷举。任意证书允许重复原子、空序列及伪造规则标签，故包括大量应拒绝输入。

## 三模式结果与复现

[普通模式](logs/normal.json)、[-O模式](logs/O.json)、[-OO模式](logs/OO.json)均为PASS；各日志记录其实际优化级别、源文件SHA-256及全部分类计数。重复优化模式用于检查契约是否依赖可移除的assert，不把同一案例计为三个独立样本。

从本目录运行：

```sh
python review_model.py > logs/normal.json
python -O review_model.py > logs/O.json
python -OO review_model.py > logs/OO.json
```

程序只用Python标准库，无安装、下载或网络请求。默认审计相邻model.py；可选命令行路径仅供变异脚本指向临时副本。它会重写指定重定向目标日志，不改生产代码。发现语义不一致抛出AuditFailure，退出非零；生产文件在一次运行前后也须保持同一字节指纹。

## 指定语义变异

另写的[mutation_review.py](mutation_review.py)把13种错误分别注入临时副本，再运行上述独立检查，未借作者测试判断成败：

1. unknown误判equal
2. 相等与不同分支互换
3. 丢掉recalled来源
4. 忽略特征选择，强行按全特征分组
5. 伪造全部目录见证
6. 抹掉全部目录见证
7. 规则合取前提换成析取
8. 只扫描一次，跳过固定点继续扩展
9. 证书不核对前提
10. 证书不核对规则结论
11. 允许伪造初始事实
12. 倒转语义蕴涵条件
13. 倒转包含结论方向

[普通变异](logs/mutations.json)、[-O变异](logs/mutations-O.json)、[-OO变异](logs/mutations-OO.json)各13/13被独立语义检查检出，合计39次指定运行。脚本先在相同优化级别运行未修改基线，并把该级别传给每个临时副本的检查进程。仅明确的AuditFailure计为成功检出；语法错误、导入失败、其他崩溃、超时及不明失败都不算成功。

```sh
python mutation_review.py > logs/mutations.json
python -O mutation_review.py > logs/mutations-O.json
python -OO mutation_review.py > logs/mutations-OO.json
```

临时副本位于本目录内的临时子目录，完成后删除；最多并行三个。这里检查所列语义错误，未声称检出了全部可能程序缺陷。所有日志中的生产源码指纹均与最终model.py相同。
