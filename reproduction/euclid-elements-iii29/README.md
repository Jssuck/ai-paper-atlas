# 《几何原本》III.29：从指定弧到弦的教学复现

这里从指定的有向圆弧出发，再利用弧的两个端点求弦。它不反用 III.28 的「给弦找弧」程序，也不是对欧几里得尺规证明的执行。历史证明链见[中文精读](../../papers/ancient/euclid-elements-iii29.zh-CN.md)。

## 运行方式

依赖 Python 3.9+ 的标准库，无外部数据。在本目录运行：

```sh
python -B -m unittest -v
python -B -O -m unittest -v
python -B -OO -m unittest -v
python -B replay_notebook.py
```

程序为 [arcs_to_chords.py](arcs_to_chords.py)，测试为 [test_arcs_to_chords.py](test_arcs_to_chords.py)。实跑：[常规](normal.log)、[`-O`](O.log)、[`-OO`](OO.log)。[Notebook](euclid-iii29.ipynb) 可在本地支持 Python 的 Notebook 前端从头运行；此处用 [replay_notebook.py](replay_notebook.py) 将纯 Python 单元逐个编译执行，见[回放日志](notebook-replay.log)。没有运行 Jupyter 内核或验证 Notebook 前端渲染。

## 对照与范围

- 输入是半径、起点方向、指定弧的逆时针扫过整周比例，以及可选的平移中心，均为有理数；扫过比例严格在 0 和 1 之间。分别从两个圆的方向求端点坐标，再求端点欧氏距离的平方。参照路线只取半径及扫角，用半角正弦公式算弦长平方，不读取端点。
- 1,209 对有限测试由 3 个半径 × 31 个扫角（1/32 到 31/32 圈）× 13 个第二弧起点方向组成（585 短弧对、585 长弧对、39 半圆对），两个圆心不同。用 `math.isclose` 比较，平方距离的绝对与相对容差均设为 `2e-13`。这两条计算路线共享同一个扫角定义，并不独立测量弧长。
- 另有 12 种坐标轴上的精确配对：4 个起点 × 3 个扫角（四分之一、半周、四分之三），不用三角函数即可得距离平方，并与坐标浮点路线比对。两个不同扫角（1/4 与 3/4 圈）可给出同样的弦长平方，不能由弦长唯一推出未经指定类型的弧长。半圆则仍给出直径；在古典合成证明里，半圆要另讨论，不能称直径与圆心构成非退化三角形。
- 保留等弧长但删去等半径：半径 1 的半圆与半径 2 的四分之一圆，弧长同为 π，弦长分别是 2 和 2√2。圆心在原点时，精确的坐标轴计算给出弦长平方 4 和 8。
- 这些是受控构造与有限数值检查，不证明一般定理、不验证 III.27 或 I.4。小扫角、极端半径和巨大平移下的浮点消差未被充分覆盖。弧的方向、长短和长度是不同的信息；模型固定逆时针方向，只检验无向弦长。
