# V.22 教学复现：从顺次相邻比到首尾比

[中文精读](../../papers/ancient/euclid-elements-v22.zh-CN.md) · [源码](ratio_chains.py) · [测试](test_ratio_chains.py) · [Notebook](euclid-v22.ipynb)

每列至少有两项，用本列内一致单位的正整数或精确分数表示。量类标签只作检查，不做单位换算；左右两列可以不同类。逐对检查顺次相邻比。给每个位置选择任意正整数倍数；同位置的左右量用同一个倍数，不同位置可以独立选择。代码检查放大后依 V.4 保持的相邻同比，再逐段检查以共同中项为参照的 V.20 次序转移；长链以同比前缀归并，程序用精确分数核对该依赖。两项情形直接比较首末两个倍量，对应定义 5 的一次实例。

示例两列是 (8,4,2,1) 和 (12,6,3,3/2)。倍数组 (1,5,3,7)、(1,5,3,8)、(1,5,3,9) 分别得到同为大于、相等、小于。有限探测不是定义 5 的全部整倍比较；分数检查不适用于非公度量，不声称用程序代替欧氏证明。顺次比例不同于错序比例，不能只检查两个端点来验证前提。

## 重跑与证据

Python 3.12.14，只有标准库，无外部数据集及依赖。在本目录执行：

```sh
python -V
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B ratio_chains.py
python -B replay_notebook.py
```

[普通模式与示例](normal.log)、[-O](O.log)、[-OO](OO.log) 各通过 9 项测试。4,096 组构造分数试例枚举四个 1–8 整数，直接以倍量比较作对照；15,625 组穷举整数六元组（各项 1–5），独立检查整列同比的交叉乘积并核对首尾比较，157 组有效、15,468 组被拒。另检两项及四十项链，错误中项、错序配对、列长度不一致、非法量和倍数等边界。

[Notebook 回放](notebook-replay.log) 确实顺序执行全部三个代码单元。本环境未安装 Jupyter 内核或技能脚手架，未安装新依赖；用同一 Notebook 的代码单元经 Python 标准库回放，不宣称内核实跑。只对可信 Notebook 使用回放脚本。
