# V.18 教学复现：从分比到合比

[中文精读](../../papers/ancient/euclid-elements-v18.zh-CN.md) · [源码](ratio_composition.py) · [测试](test_ratio_composition.py) · [Notebook](euclid-v18.ipynb)

这是正有理数模型中的两条重放路径，不是古代程序或一般定理的计算证明。输入是四个正整数或精确分数，每组内部必须同类且单位一致，不做单位换算。组间允许不同类型，只核对无量纲比值或比较结果。所有探针均为正整数。

## 路径一：第四比例量，检查原证的分支结构

记两组部分为 `(a,b)` 与 `(c,d)`。给定右侧整体 `T=c+d`，用精确分数除法构造 `g=T*b/(a+b)`，检查它为正且小于 `T`。因此 `T:g` 同于 `(a+b):b`；分比得到 `(T-g):g` 同于 `a:b`。若原分比前提也成立，V.11、V.14 将要求 `T-g` 与 `c` 的比较方向和 `g` 与 `d` 相同。但同一整体内补量反转次序，因此只可能同时相等。

CLI 用长度组 2,3 和面积组 4,6 显示等号路径。另让右组的整体保持 10，把分割改成 3,7 或 5,5。两个严格分支均能展示次序反转，但它们都不满足分比前提，不是定理的反例。程序明确区分供观察的 `candidate_trace` 与要求前提成立的 `replay`。第四比例量的存在由现代有理数模型保证；这不是对任意抽象量系统或欧几里得古代作图的可构造性证明。

## 路径二：直接比较，不构造第四比例量

`direct_probe` 先用精确分数核验分比前提，再逐组比较 `m(a+b)` 与 `kb`，以及 `m(c+d)` 与 `kd`。若 `k<=m`，加上的正余量保证两组比较都严格大于；不构造零倍或负倍。若 `k>m`，去掉两侧共同量 `mb`（右组为 `md`）后，对应分比的任意一项比较变成倍率 `(m,k-m)` 的比较。程序核对两组整体比较与相应的分比比较确实同号。这个直接重放不同于原证的反证路线。

## 怎么重跑

在本目录用 Python 3.12.14 及标准库。无外部数据、第三方库或联网步骤。

```sh
python -V
python -B -m unittest -v
python -O -B -m unittest -v
python -OO -B -m unittest -v
python -B ratio_composition.py
python -B replay_notebook.py
```

[普通模式和 CLI](normal.log)、[一级优化](O.log)、[二级优化](OO.log)各通过 9 项测试。正例网格让六个整数 `u,v,s,t,m,k` 各取 1 至 4，用 `(us,vs,ut,vt)` 生成相同比的输入；把程序结果与独立的整数式 `m(u+v)-kv` 的符号逐项比较，4096 次全部相符。小于、等于、大于分别有 656、224、3216 次；2560 次无须调用分比探针，1536 次使用偏移后的正整数探针。网格包含重复量值与不同参数，不把它当成 4096 组独立历史测量。测试另含错误类型、非正值、浮点输入、非法探针、严格分支及前提失败。

[Notebook 实跑](notebook-replay.log)由 [标准库回放脚本](replay_notebook.py)逐个执行该 Notebook 的 3 个代码单元。当前环境未安装 Jupyter 内核，所以不声称在原生 Jupyter 会话验收。有限测试不覆盖不可公度量，也不代替全称证明。
