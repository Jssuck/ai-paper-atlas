# VII.10：若干份的换比

这是现代正整数上的独立教学重构，不是古代运行记录或一般命题的计算证明。

输入依次是 AB、C、DE、F。四个给定量是大于 1 的整数，AB 小于 DE，且两对有共同的真分数 m/n，约分后要求 1 < m < n。写成 AB=m·g、C=n·g、DE=m·h、F=n·h，则 g<h。这里 g 和 h 表示每一小份；g=1 是允许的现代单位边界，不表示欧几里得会把单位称为「数」。

以 VII.9 将 g、h 的比较提升到 C、F；再根据 g/h 是否为单位分数，按 VII.5 或 VII.6 的逻辑，将 m 对相同小块成对汇入 AB、DE。程序分别核对这些分组的计数，测试直接从输入构造 Fraction 作为独立检查。

- (8,12,16,24)：m/n=2/3；g/h=4/8，汇合走 VII.5，换比同为 1/2。
- (8,12,20,30)：m/n=2/3；g/h=4/10，汇合走 VII.6，换比同为 2/5。
- 只把第二例的 F 改成 32，两换比成为 2/5 与 3/8；共同若干份的前提失效。相等和反向仍可以有现代等式，却不在本程序采用的原比较方向内。
