# VII.10 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.10.html)、Heath 1908 卷 II 印刷页 310–311、[Fitzpatrick 希英对照本](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=203) 印刷页 203–204（图在 204）以及 [Joyce VII.10](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII10.html)。按图记 AB 为 C 的若干份，DE 为 F 的同样若干份；图中 AB 分为 AG、GB，DE 分为 DH、HE，希腊标号分别为 ΑΗ、ΗΒ、ΔΘ、ΘΕ。各画两份只是示意。

题设比较 AB 对 C、DE 对 F，结论改作 AB 对 DE、C 对 F，不是分别取倒数。把两个较小数按同数目的对应单份拆分，AG 对 C 与 DH 对 F 是同一单份，故 VII.9 给 AG 对 DH 与 C 对 F 同份或同样若干份；第二对 GB、HE 同理。用 VII.5（横向单份）或 VII.6（横向若干份）汇合对应片，得到 AB 对 DE 与 C 对 F 保持同样份关系。技术性的份关系是小对大；现代可用 C=nu、F=nv、AB=mu、DE=mv，其中原题的复数份用最低项写为 1<m<n，横向次序要求 u<v。等号和反向比较并非古题的术语范围。

Clay 英栏在首次援用 VII.9 后结束，希腊栏与印本有第二对和最终结论。Clay、Fitzpatrick 希腊栏在由单份合回总量处有较长括注，并另标短词 [ἄρα]；长括注展开相应份的配对、VII.5–6 的汇合以及回接 C 对 F。Heath 311 页报告，Heiberg 据手稿 P 由后手写入页边的情形，推测这段展开可归于 Theon；这是校勘判断。Joyce 正文一处把 F 说成 DE 的若干份、C 说成 AB 的若干份，而 F、C 较大；这不能按定义 3–4 理解，希腊文也没有倒置，仍重述 DE 对 F、AB 对 C。

[VII.13](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII13.html) 在定义 20 的数比例叙述下直接用到交替比较，Joyce 标 VII.10；就输入的术语分支而言，原比是单份可用 VII.9，若干份用 VII.10。不能由这一后续合并表述取消 VII.10 的原始条件。
