# VII.13 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.13.html)、Heath 1908 卷 II 印刷页 312–313（扫描物理页 325–326；正文与图同在 313）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=206) 印刷页 206（正文、两图与脚注同页）、[Joyce VII.13](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII13.html)。

## 原证与术语

四数按 A、B、C、D 排列，题设 A:B=C:D；交替（ἐναλλάξ）交换两个中项的位置，结论 A:C=B:D。希腊 Γ、Δ 对应英文 C、D，不是另两条线段。原证的三步如下：

1. 用第 VII 卷定义 20，把等比译为 A 对 B 与 C 对 D 是同一单份或同样若干份。
2. 原比为单份时用 VII.9，原比为若干份时用 VII.10，得 A 对 C 与 B 对 D 也为同一单份或同样若干份。原比的份型和交换中的份型不必一致。
3. 再用定义 20，把所得两种份关系写回比例 A:C=B:D。Clay 英栏到第 2 步结束，希腊栏和两个印本均保留第 3 步。Heath、Clay、Joyce 在交替步标 VII.10；Fitzpatrick 印本同时标 VII.9、VII.10，更明确覆盖原证分支。这些编号是译注标识；希腊文不含编号。

## 图、方向与边界

Heath 页 312 的连贯校注指出，VII.11–13 的“单份／若干份”字面直接适用于前项较小；VII.13 对交替后的比也如此。但页 313 的图把 A 画得比 B、C 长，和正文的直接方向不同。Fitzpatrick 页 206 的四线段重新绘成 A、B、C、D 递增，更符合正文这一次的比较方向；图的长度并非命题的具体输入。若某一方向反过来，现代正数式仍成立，但不能直接把较大数称为较小数的份。可先按原等比关系与横向关系分别所需的次序重排两个比，并在结论处反转相应比较；等值情况也可直接处理。例如 A=B 时由题设知 C=D，结论两边本来相同；A=C 时相应得到 B=D。

现代乘积等式 AD=BC 可检验前后两式，但古证不是直接做交叉相乘。第 V 卷 [V.16](https://mathcs.clarku.edu/~djoyce/elements/bookV/propV16.html) 是一般量的对应命题，而非这里的直接依赖。

[VII.14](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII14.html) 实际把 A:B=D:E 改为 A:D=B:E，把 B:C=E:F 改为 B:E=C:F；合并同一比后再交替得到端点关系。通常编号 [IX.35](https://www.claymath.org/library/historical/euclid/files/elem.9.35.html) 在连比证明中先消去相应项，再用交替改排差量对子、最后按 VII.12 汇合；Joyce 在相应步骤并标 VII.11 与 VII.13。VII.13 不独立给出求和公式。
