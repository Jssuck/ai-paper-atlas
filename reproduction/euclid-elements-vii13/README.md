# VII.13：换比

现代正整数上的教学重构，不是历史运行记录或一般命题的计算证明。按顺序给出 (A,B,C,D)，要求四个给定数都大于 1，A<B 且 A<C。只有两组原始约分计数相同才进入证明模型。约分计数是对定义 20 中比较同一份或若干份的现代表示。

若原比较 A:B 的约分分子为 1，走 VII.9；否则走 VII.10。两条路线都给出交叉比较 A:C 与 B:D。交叉的约分分子可独立为 1 或大于 1，不能用它选原分支。测试从原始输入另算 Fraction 核对前后比。示例：

| 输入 | 原比 | 路线 | 换比 |
| --- | --- | --- | --- |
| (4,8,12,24) | 1/2 | VII.9 | 1/3 |
| (6,12,10,20) | 1/2 | VII.9 | 3/5 |
| (4,6,12,18) | 2/3 | VII.10 | 1/3 |
| (8,12,20,30) | 2/3 | VII.10 | 2/5 |

把末例的 D 改为 32，交叉比为 2/5 与 3/8，原比例前提已失效。现代边界可另用 Fraction 描述：换比方向反了，可先交换两组，再取两边倒数；原比方向反了，可同时交换两组各自的分子与分母，再恢复两条交叉比的顺序；等项直接按现代等式处理。本函数不自动调整方向，也不把作为公度的单位等同于一种给定的「数」。
