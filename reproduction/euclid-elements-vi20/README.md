## 对照与限制

- 工作例按原文扇形锚点 E 取 ABE、EBC、ECD；目标图用 L 作相应锚点。源图三块二倍面积 16、12、11；坐标经 3/2 倍旋转与平移，目标为 36、27、99/4。单独用顶点顺序的鞋带公式计算整体二倍面积 39 与 351/4，目标对源比为 9/4。
- 用精确直线交叉另测两个图的内部辅助点：AC 与 BE、FH 与 GL 的交点分别为 M=(20/7,8/7)、N=(65/7,9/7)。第二组用 BD 与 EC、GK 与 LH，交点分别为 (80/23,60/23)、(163/23,51/23)。交点函数排除并行、重合、端点接触和延长线交点。
- 144 个受控凸多边形配置：3 个样例 × 4 个正比例因子 × 3 个旋转 × 2 个平移 × 2 个镜像选择，其中 72 个镜像。分别从坐标算边长平方、三角形行列式与全图鞋带面积。检查分块对应边平方比、面积比例、块面积占比、镜像符号及整体面积。已知生成变换不是未知图形的相似性判定器。
- 给定凹五边形，从 A 构造一般的有向扇形项得 16、−4、8；符号和 20 等于鞋带值，逐项取绝对值则误得 28。这个代数和不是原文的实际三角形分割，也不是一般凹多边形的三角剖分算法。
- 同底等高的 4×1 矩形与平移上边得到的斜平行四边形，面积与对应底边平方的比都为 1，但另一组对应边长度不同。平方比结论不单独保证相似。本模型有限实测不证明一般命题。
