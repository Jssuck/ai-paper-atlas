# Euler 第 CV 信复现：独立代码审计

**结论：通过，未发现数学语义、枚举计数、见证处理或报告生成错误。** 这份审计独立于作者自测，检查对象仅为本附件的三个目标形式，不是对 Euler 全部十九式或整个现代逻辑的验证。

## 结果

| 模型约定 | 支持模型总数 | 每式前提全真的模型数 | 有效式反模型 | 原无效式反模型 | 改正方向反模型 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 非空论域，类可空 | 255 | 32 | 0 | 16 | 0 |
| 非空论域，三类各非空 | 218 | 24 | 0 | 8 | 0 |

三个目标形式依次是：

1. `E(A,B) & I(B,C) => O(C,A)`。
2. `I(A,B) & E(B,C) => O(C,A)`。
3. `I(A,B) & E(B,C) => O(A,C)`。

无效式的完整反模型支持整数为：允许空类时 `8–15, 40–47`；三类非空时 `40–47`。最小论域分别为 1、2 个元素。两元素例 `U=A={s,v}, B={s}, C={v}` 的原结论确实为假；把 A 改为 `{s}`，原结论确实变真。全部结果见[独立结果 JSON](independent-results.json)。

## 怎样做到独立

[独立检查器](independent_check.py)用布尔三元组列出成员类型，按实际集合构造模型，并逐个对象直接计算 `all` / `any` 量词。它不调用被测代码的判定函数来计算期望值，也不复用被测代码的位掩码筛选逻辑。只有编码接口按题定规则 `t=a+2b+4c`、支持值为所占类型的 `2^t` 之和核对。

实跑覆盖：

- 全部 255 个非空支持；核对非空类过滤得到的完整 218 项列表。
- 1–4 个带标签对象的全部 4,680 个模型，包含重复成员类型，检查压缩是否丢失真值或见证信息。
- 全部 36 个 AEIO 命题，包含主词与谓词相同的边界情形；另核对 7 个命名例子及一组特殊字符串标签。
- 共 177,948 次直接量词真值比较，另有同数目的压缩后真值比较；88,974 次精确见证集合比较，另有同数目的见证映射像比较。
- 三个论证的逐模型真假及反模型标记；全部报告字段、完整反模型列表、最小反模型大小、例子、命令行 JSON/文本与交付报告的一致性。
- 42 项预期错误检查，包括空论域、非法支持值与类型、越界类成员、非法命题和类名、查询不存在的对象、对全称式索取存在见证及冻结模型不可修改。还核对调用后修改原输入集合不会改变模型。

生产自测 22 项全部通过。审计在临时隔离副本中另执行完整 `sh run.sh`，从四个源输入重新生成 JSON、文本和 SVG；三个输出与交付文件逐字节相同。审计没有改动生产文件。

## 一般证明与文字核对

一般结论来自证明，不来自测试数量：AEIO 命题只依赖八种成员类型是否被占据，保留每个已占类型即可同时保持全称式的禁区为空、特称式的见证存在及各类非空性。反过来，每个非空支持都能实现为真实集合模型。因此这三个目标形式的反模型若存在，必有一个被枚举的支持反模型。这个理由也适用于无限论域，但不适用于指定数量、对象相异性或任意关系公式。

有效式中，同一对象从 `B∩C` 进入 `C\A`；改正方向中，同一对象从 `A∩B` 进入 `A\C`。这分别给出不依赖枚举的一般证明。原无效式有明确两元素反模型，因此不能通过交换特称否定句的主谓挽救原结论。

已对照正文、复现说明及数学核查中的集合语义、两层编码、见证证明、余部可为空、255/218 与 32/24/16/8 的手算推导及真假关系。未发现冲突。正文与附件部分教学实例采用不同对象标签或不同空类约定，均有明确说明，并不影响论证。这里没有重新逐页校勘历史扫描件，历史来源核验不由本代码审计替代。
