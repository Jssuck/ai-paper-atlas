# 欧拉《第105封信》：追踪同一见证对象的可运行复现

本目录提供一套仅使用 Python 标准库的原创教学代码，配合阅读欧拉的 *Lettres à une princesse d'Allemagne* 第二卷（1768 年版）第105封信，即 Lettre CV，原书页码 119–126。第126页署明这封信写于 1761 年 2 月 24 日。代码用现代集合模型重建信中的两种论证，并呈现欧拉对“推理形式有效”与“结论碰巧为真”的区分。它不是历史软件，也不试图重建全部十九种形式，更不意味着欧拉曾采用现代的模型枚举方法。

## 模型究竟表示什么

每个模型包含一个非空的有限论域 U，以及任意三个子集 A、B、C。类本身可以为空。元素使用 `w`、`s` 等字符串作为标签；标签的拼写不影响逻辑意义。

四种直言命题采用现代集合语义：

- `A(X,Y)`：所有 X 都是 Y，即 X 是 Y 的子集。
- `E(X,Y)`：没有 X 是 Y，即二者的交集为空。
- `I(X,Y)`：有些 X 是 Y，即二者的交集非空。
- `O(X,Y)`：有些 X 不是 Y，即 X 与 Y 的差集非空。

`A(X,Y)` 最前面的 `A` 表示命题类型；作为括号内参数出现的 `A` 则表示一个类。这是同一个字母的两种不同用法。“有些”只表示“至少一个”，不暗含“有些但不是全部”。这里的全称命题不带存在预设：X 为空时，`A(X,Y)` 和 `E(X,Y)` 都为真。不能悄悄把这一现代约定套用到欧拉列举的全部十九种历史形式上。本复现研究的两种原文论证各含一个存在性前提；即使另加 A、B、C 都非空的要求，它们的有效性判断也不改变。

## 三种论证，两种非空约定

1. 有效例，原书第119–122页：`E(A,B) & I(B,C) => O(C,A)`。
   此处欧拉用 A 表示有德之人，B 表示诽谤者，C 表示有学问的人。
2. 无效候选形式，原书第123–125页：`I(A,B) & E(B,C) => O(C,A)`。
   此处字母的指代已经改变：A 是有学问的人，B 是吝啬者，C 是有德之人。后面的树、樱桃树、苹果树例子采用同一形式。
3. 为教学补出的修正形式：`I(A,B) & E(B,C) => O(A,C)`。
   将 O 型结论的主项和谓项交换即可。这是本复现推导出的修正，不作为第105封信中另一个独立表述来引用。

允许空类时，程序检查 255 种非空占用模式。三种论证各有 32 种模式同时满足两个前提；有效例、无效候选式和修正式的反模型数依次为 0、16、0。

要求三个类都非空时，程序检查 218 种模式。三种论证各有 24 种模式同时满足两个前提；对应的反模型数依次为 0、8、0。

这里统计的是**哪些成员关系类型被占用的模式**，不是所有带标签的有限论域，也不是结论为真的概率。如果不限制论域大小，有限模型仍有无穷多个。在同一种成员关系类型中重复添加元素，不会改变任何 AEIO 命题的真值。

## 沿着同一个见证对象走

对有效例，`I(B,C)` 保证存在一个同时属于 B 和 C 的元素 w。又因为没有 A 是 B，w 就不属于 A。因此，仍然是这个 w，见证了 `O(C,A)` 为真。

```math
w\in B\cap C,\quad A\cap B=\varnothing
\quad\Longrightarrow\quad w\in C\setminus A.
```

这一步约束的是 B 与 C 共有的部分，并没有确定 C 的其余部分 $`C\setminus B`$ 与 A 的关系。代码给出了三种具体可能，而且每个例子的三个类都非空：

- 其余部分与 A 不相交：U = {a, r, w}; A = {a}; B = {w}; C = {r, w}。其余部分为 {r}。
- 其余部分全部包含在 A 中：U = {r, w}; A = {r}; B = {w}; C = {r, w}。其余部分为 {r}。
- 其余部分一部分在 A 中，一部分在 A 外：U = {q, r, w}; A = {r}; B = {w}; C = {q, r, w}。其余部分为 {q, r}。

这些是为讲解选出的模型，不表示额外区域一定存在。例如 U = {a, w}, A = {a}, B = C = {w} 同样满足前提，却**根本没有其余部分**。其他可选区域也不必有元素，包括 A、B、C 三者之外的区域。

[原创 SVG 成员关系图](figures/membership-models.svg)用实心点表示属于某类，用空心圆表示不属于；另附[已检查像素的 PNG 版本](figures/membership-models.png)。这不是对欧拉原图的描摹或扫描。每一行表示一个实际元素；在不同列之间移动视线时，同一行始终是同一个元素。

## 不靠空类，也能看出无效性

考虑这个只有两个元素的模型：

```math
U=\{s,v\},\qquad A=\{s,v\},\qquad B=\{s\},\qquad C=\{v\}.
```

前提 `I(A,B)` 和 `E(B,C)` 都为真；候选结论 `O(C,A)` 却为假，因为所有 C 都属于 A。三个类均非空。在这一要求下，模型已经最小：非空的 B 和 C 必须不相交，因此至少需要两个不同元素。

现在保持 U = {s, v}，只把 A 改成 {s}。于是 A = B = {s}，C = {v}。两个前提仍为真，但这次 `O(C,A)` 也为真。同样的前提形式容许这两种结果。无效的意思是结论**没有得到保证**，不是说结论永远为假。

如果允许空类，还存在单元素反模型：U = A = B = {s}，C 为空。上面的双元素反模型则说明，这个形式的缺陷并不依赖空类约定。

修正后的结论继续使用 A 与 B 中原有的见证对象 s。由于 B 和 C 不相交，s 不属于 C，于是得到 `O(A,C)`。

## 八类型归约：为什么有限枚举已经足够

对每个元素，用三个二进制位记录成员关系：第0位对应 A，第1位对应 B，第2位对应 C。所得的**类型编号**为 0 至 7。编号0表示在三个类之外；编号3表示属于 A 和 B、但不属于 C；编号5表示属于 A 和 C、但不属于 B；编号6表示属于 B 和 C、但不属于 A。

**占用掩码（support mask）**再用一个二进制位记录每种类型是否有元素：第 i 位表示类型 i 是否被占用。因此，类型编号3对掩码贡献的是 `1 << 3`，而不是整数3。由于论域非空，掩码范围是 1 至 255。`from_support` 为每个被占用的类型恰好放入一个元素，**不会**自动添加一个位于所有类之外的元素；只有掩码第0位置1时，这样的元素才存在。

以下是一般性的论证，与程序中有限个测试实例相区分：

1. 每个元素恰好属于八种成员关系类型之一。对原模型中每个被占用的类型只保留一个代表，并把该类型的所有原元素映射到这个代表。
2. `A(X,Y)` 只取决于“属于 X、但不属于 Y”的类型是否被占用；`E(X,Y)` 只取决于“同时属于 X 和 Y”的类型是否被占用。替换前后，每种类型为空还是非空都不变，所以这两个全称命题的真值不变。
3. `I(X,Y)` 和 `O(X,Y)` 取决于相应交集、差集是否非空。原来的见证对象会映射到同类型的见证对象。反过来，每个代表都来自原模型中已经被占用的类型，所以代表模型里有见证对象，原模型里就也有。这两个命题的真值同样不变。
4. 各个类是否非空保持不变，论域非空也保持不变。因此，两种非空约定都得以保留。
5. 对由这些 AEIO 命题组成的论证，任何反模型都有一个在命题真值上等价、至多含八个元素的占用模式反模型。反过来，每个枚举出的模式本身也确实是一个模型。因此，穷尽这些模式足以判定这里讨论的论证是否有效。

这个归约同样适用于任意大的、甚至无限的集合模型，因为这些 AEIO 命题只用到了各类型是否被占用的信息。它一般不保持基数，也不能保证保持关于某类型中至少两个不同对象、对象同一性、二元关系或任意一阶公式的断言。它**不是所有逻辑都通用的八元素上界**。

代码检查了把一个、两个或三个带标签元素分配到八种类型的全部 584 种情况，验证归约是否保持 AEIO 真值、存在性见证对象和类的非空性。这些测试有助于发现实现错误；它们并不是上面一般性归约定理的证明。

## 手工推导精确计数

非空占用模式共有 $`2^8-1=255`$ 种。要求三个类都非空时，可以使用容斥原理。暂时把空模式也算在内：“某个指定类为空”包含16种模式；其中任意两个类同时为空包含4种模式；三个类同时为空则有 **2** 种模式，因为类型0可以不被占用，也可以被占用：

```math
256-3\cdot16+3\cdot4-2=218.
```

也可以直接从255种非空模式出发，得到 $`255-3\cdot15+3\cdot3-1=218`$，这样就不会引入零掩码。代码采用的是直接检查每个类是否非空的筛选方式，而不是把这个公式写死在程序里。

对有效例，`E(A,B)` 排除了类型3和7；`I(B,C)` 随后迫使类型6被占用。其余五种类型0、1、2、4、5均可自由选择是否占用，因此有32种满足前提的模式。再要求 A 非空，就必须占用类型1和5中的至少一种，剩下24种。类型6始终见证结论，所以没有反模型。

对无效候选式，`E(B,C)` 排除了类型6和7；`I(A,B)` 随后迫使类型3被占用。其余五种类型0、1、2、4、5仍可自由选择，因此也有32种满足前提的模式。候选结论需要类型4或6被占用；类型6已经被排除，所以结论为假当且仅当类型4未被占用。这给出16种反模型。再要求 C 非空，就必须占用类型4或5，得到24种满足前提的模式。当结论为假时，类型4不能被占用，于是类型5必须被占用，反模型数便降为8。修正式的结论 `O(A,C)` 则已经由必定被占用的类型3见证，因此没有反模型。

## 最后一段：不能丢掉有效性条件

用 P、Q 表示两个前提，用 R 表示结论。一个形式有效，意味着 $`(P\land Q)\Rightarrow R`$ 在每个模型中都成立。对这样的形式，R 为假就意味着 P、Q 不可能同时为真；但它不会指出究竟哪个前提为假。

```math
((P\land Q)\Rightarrow R)\quad\Longrightarrow\quad
(\neg R\Rightarrow(\neg P\lor\neg Q)).
```

仅仅把三个句子排成论证的样子，并不足以使用这一步。无效候选式就存在“前提都真、结论却假”的模型，测试也明确包含这样的例子。反过来，即使形式有效，前提为假也不迫使结论为假：取 U = {s, v}, A = B = {s}, C = {v}，有效例的两个前提都为假，结论却为真。

## 小练习

1. 为什么掩码40对应三个类都非空的反模型，而掩码24对应结论也为真的另一种模型？答：40 = 8 + 32，占用类型3和5；24 = 8 + 16，占用类型3和4。
2. 在类型3中再加一个元素，能修复无效候选式吗？答：不能；所有 AEIO 命题的真值都不变。
3. 在有效例中，有学问的人可以全部是诽谤者吗？答：可以；`valid_no_remainder` 示例就令 C = B。
4. 如果把“有些”读成“有些但不是全部”，为什么这里的见证论证就不能直接成立？答：一个交集中的见证对象，并不能证明主项还有别的元素落在谓项之外。
