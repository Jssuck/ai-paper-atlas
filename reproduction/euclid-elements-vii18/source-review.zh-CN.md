# VII.18 原典与证明核对

核读 [Clay 希英对照](https://www.claymath.org/library/historical/euclid/files/elem.7.18.html)、Heath 1908 卷 II 印刷页 318（扫描物理页 331，含图、证明和代数式评注）、[Fitzpatrick 希英对照](https://farside.ph.utexas.edu/books/Euclid/Elements.pdf#page=209) 印刷页 209 和 [Joyce VII.18](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII18.html)。

希文 Α、Β、Γ、Δ、Ε 对应英图 A、B、C、D、E。按第 VII 卷定义 15，先是 A 乘 C 生成 D、B 乘 C 生成 E，即 A、B 给出各自取用 C 的份数，而 C 是共同被乘数。希文的复数动作与单数对象明确区分了角色；Joyce 开头的英文短语按现代被动语法容易读反，但题述末尾的“乘数”及后文两次交换、导读都支持此读法。图中的五段只是示意，C 不是单位，且不同于 VII.17 中的单位 F。

原证不直接用比例的交叉乘积或约分。[VII.16](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII16.html) 先保证 C 乘 A 仍生成 D，同理 C 乘 B 仍生成 E。此时 C 从原来的被乘数变成两个乘积的共同乘数，才可按 [VII.17](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII17.html) 得到 A:B=D:E。Heath 和 Fitzpatrick 在第一次交换和末步分别标 VII.16、VII.17，第二次交换以同理略述。Heath 在 318 页另把这个顺序写成现代代数式作评注。Clay 的英栏到“C 乘 A、B 生成 D、E”即止，但其希文、两印本和 Joyce 保留由 VII.17 得到的结论；Joyce 网页末句的“Dis”只是字间少了空格。

[VII.19](https://mathcs.clarku.edu/~djoyce/elements/bookVII/propVII19.html) 直接用了本命题：A、B 各乘同一 C 得辅助积 G 与 F，从而 A:B=G:F，与经 VII.17 得到的另一比例共同服务于两个方向的证明。[VIII.2](https://mathcs.clarku.edu/~djoyce/elements/bookVIII/propVIII2.html) 的连比构造中也有两次直接应用：A、B 各乘 B 得 D、E，以及 A、B 各乘 E 得 H、K。最小性另用其他命题，不由 VII.18 单独推出。
