# 《几何原本》III.31：区分弓形内的角与端点的一侧极限

此教学代码接受圆心、弦端点及圆周上的角顶点。它用坐标点积分类「在弓形内的角」，另作端点割线角的一侧极限演示。后者是现代定义下的切向角，不是对欧几里得由弦与曲线围成的「弓形之角」作相等断言。原文与重构的边界见[中文精读](../../papers/ancient/euclid-elements-iii31.zh-CN.md)。

## 数学模型、对照与范围

- 输入四点为整数或有理数坐标，输入检查拒绝重合端点、非同圆点、浮点输入。把有向弦的端点固定为 A、B，圆周第三点 P 选择所在的一段弧（P 不是圆盘内部点）。计算圆心与 P 在直线 AB 上的有符号侧值（叉积）；同侧为大弓形，异侧为小弓形，圆心恰落在 AB 上则为半圆。角 APB 的锐、直、钝另由 PA 与 PB 的点积符号得到。三种输出依次为锐角、钝角、直角。分类不靠浮点角大小或容差。
- 精确网格在每个圆上放置 18 个不同的有理点；顺序选择三个不同圆周点作为 A、B、P；共 3 × 18 × 17 × 16 = 14,688 个有序配置：大弓形 11,022，小弓形 3,282，半圆 384。比较的是弦侧判断和实际角顶点向量点积两条计算路线，不是以第一条的分类结果作为第二条的输入。
- 端点 A 处分开定义另一个现代角：以 AB 为固定射线，从 A 向指定弧内部找有理点 Q，比对 AQ 与 AB 的夹角随 Q 接近 A 的一侧极限。若 P 在有向弦右侧，则取逆时针切向射线，反之取顺时针。切向射线和半径的垂直性及其与 AB 的点积符号仍可精确检查；角度输出才调用浮点三角函数。把切线当成一条无方向直线就会丢失分支，大、小弓形测试会在交换两条切向射线后翻转分类。
- 对照样本用单位圆的有理参数公式旋转圆心指向 A 的向量。参数为 `t=1/8, 1/64, 1/512, 1/4096`，角位移为两倍的 arctan(t)。割线方向相对同侧切向射线的偏差是 arctan(t)。测试先精确验证样本在原圆且落在同侧，再数值比较相应割线角与现代极限角的偏差，误差比较容差为 `2e-13` 弧度。半圆额外演示现代端点极限为直角，不将它补写成 III.31 后半句的原文命题。
- 有限验证不证明一般定理，也不独立考证古代曲直角的度量。网格没有覆盖任意平移、半径、极短弦或任意靠近端点时的浮点舍入；右角、锐角、钝角的精确点积分类不受这里的浮点角度演示影响。
